# 设计规范 — 归燕驿站 · 取件码输入（OTP）+ Toast 通知系统

> 2026-08-20 · V3 交互组件 · 生产级可复用 UI 组件对
> 纯 vanilla 单文件（HTML + CSS + JS），无 React / Babel / CDN / 外部字体硬依赖

## 一、设计母题

宿主场景「归燕驿站」社区快递驿站取件工作台：顾客报 6 位取件码 → 店员逐格输入 → 异步校验 → 成功/失败反馈 → Toast 队列播报后续事件（入库、滞留、库存预警）。两个组件类别正交（输入类 + 反馈类），在宿主场景自然串联，各自状态机完整。

设计 DNA：纸米白底 + 墨色正文 + 柿红主色 + 靛青辅助，材质取自老式驿站登记纸与木质柜台，克制不喧宾夺主——组件是绝对主角，展示页是配角。

## 三、字体

系统中文无衬线栈：`PingFang SC / Microsoft YaHei / Noto Sans CJK / sans-serif`。数字用 `font-variant-numeric: tabular-nums` 保证等宽对齐。无外部字体硬依赖。

字号阶：`--font-xs 12 / sm 13 / base 14 / lg 16 / xl 20 / 2xl 28 / 3xl 36`。

## 四、圆角与阴影

- 圆角：`sm 6 / md 10 / lg 14 / xl 20`（OTP 格用 md，Toast 卡用 lg）
- 阴影：`xs / sm / md / lg` + `--shadow-toast 0 8px 28px rgba(38,34,28,.16)`（Toast 专用）

## 五、动效系统

| 语义 | 时长 | 曲线 | 用途 |
| --- | --- | --- | --- |
| 快反馈 | `--duration-fast 120ms` | ease | OTP 边色/底色/阴影过渡 |
| 状态过渡 | `--duration-base 200ms` | ease | Toast 入场/出场位移 |
| 强调 | `--duration-slow 320ms` | ease | 大面板切换 |
| Toast 停留 | `--duration-toast 4500ms` | 线性 | 倒计时进度条 |
| OTP 抖动 | `--otp-shake-duration 300ms` | `cubic-bezier(.36,.07,.19,.97)` | error 态横向抖动余震 |
| OTP 逐格 | `--otp-stagger-delay 60ms` | — | success 逐格 stagger 变绿 |

五层手感：hover 预接触微抬升 → 按下 `scale(.97)` 咬合 → 输入/校验逐帧跟随 → 阈值质变（第 6 格填满自动提交、Toast 超上限挤压排队）→ 释放衰减（error 抖动余震、success stagger 收尾、Toast 滑出渐隐）。

## 六、OTP 取件码输入 · 状态机（8 态）

`rest / hover / focus / filled / loading / success / error / disabled`

- `data-state` 属性驱动整体态；每格 `aria-label="第 N 位取件码"`，组 `role="group"`，校验结果 `aria-live` 播报，error 态 `aria-invalid="true"`
- 键盘：数字输入自动跳格、`Backspace` 回退清空、`← →` 格间移动、`Home/End` 跳首尾、`Enter` 提交、`Tab` 进出组
- 智能粘贴：监听 `paste` 事件，从「您的取件码是 482913，请尽快取件」整段文本中正则提取 6 位数字拆分填充
- 演示码：`482913` / `107562` 成功；其余返回「未查到该取件码，请核对后重试」并 error 抖动
- success 态逐格 60ms stagger 变绿勾；loading 态逐格转圈禁用输入

## 七、Toast 通知系统 · 状态机

`entering / visible / paused / exiting`，4 种语义类型（成功/信息/警示/错误）

- 队列上限 3 条，超出排队先进先出；右上角堆叠，入场滑入 + 下方条目位移动画
- 每条含语义图标、标题、正文、可选操作按钮、关闭按钮、底部倒计时进度条（默认 4.5s）
- `hover` 暂停倒计时与进度条，移出续走
- `Esc` 关闭最上层一条（document 级 keydown）；`Tab` 聚焦操作/关闭按钮，焦点环可见
- `role=status`（信息/成功）/ `role=alert`（错误/警示），`aria-live=polite`
- 真实驿站文案：取件成功、新包裹入库、滞留件超时提醒、库存预警

## 八、工程红线

- 纯 vanilla，CSS/JS 分区注释，可独立抽取
- 所有定时器随 `visibilitychange` 暂停（`document.hidden` → `pauseAll`，恢复 → `resumeAll`），组件卸载清除
- RAF 驱动倒计时进度条；快速连续触发不叠加定时器
- 全局 `prefers-reduced-motion: reduce` 降级（OTP/Toast transition 置 none，抖动/位移降级）
- 移动端 `@media (max-width:480px)` 缩放 OTP 格（44px）与外边距，避免横向溢出
- Console 零 Error，1440/390 双尺寸零横向溢出（实测 scrollWidth = innerWidth）

## 九、可复用性

- 30+ CSS 变量（`--otp-*` / `--toast-*` / `--color-*` / `--radius` / `--duration-*` / `--shadow-*`），换肤改 ≤3 处
- JS 以 `OTPInput` / `Toast` 两个类封装，构造函数接收容器与配置，可独立抽取到任意项目
- 展示页与组件代码注释分区，`cs-`/`otp-`/`toast-` 命名空间隔离

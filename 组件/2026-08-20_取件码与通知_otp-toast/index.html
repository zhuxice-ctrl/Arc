组件用法文档

OTP 取件码输入

生产级验证码输入组件，支持 6 位取件码逐格输入、自动跳格、粘贴识别、完整状态机与无障碍支持。

状态机

  • rest — 空闲待输入
  • hover — 鼠标悬停微抬升
  • focus — 聚焦高亮描边
  • filled — 已填数字
  • loading — 校验中逐格转圈
  • success — 成功逐格弹动变绿
  • error — 错误抖动红边提示
  • disabled — 禁用灰显

键盘操作

  • Tab / Shift+Tab — 进出组件组
  • ← / → — 格间移动焦点
  • Home / End — 跳转首尾格
  • Backspace — 清空当前格并回退
  • Enter — 提交核验
  • 粘贴 — 自动提取 6 位数字拆分填充

调用方式

  • OTP.init(container, options) — 初始化
  • otp.getValue() — 获取当前值
  • otp.setValue(val) — 设置值
  • otp.setLoading() / setSuccess() / setError(msg)
  • otp.reset() — 重置为初始态
  • otp.destroy() — 销毁解绑事件

Toast 通知系统

队列化通知组件，支持四种语义类型、进度条倒计时、悬停暂停、键盘关闭与无障碍播报。

类型

  • success — 成功（绿色）
  • info — 信息（靛青色）
  • warning — 警示（琥珀色）
  • error — 错误（红色）

特性

  • 队列上限 3 条，超出排队先进先出
  • 右下角滑入 + 条目位移动画
  • 底部倒计时进度条（默认 4.5s）
  • hover 暂停倒计时，移出续走
  • Esc 关闭最上层一条
  • Tab 聚焦操作/关闭按钮
  • role=status/alert + aria-live

调用方式

  • Toast.show({ type, title, message, duration, action })
  • Toast.success(title, message) 等快捷方法
  • Toast.clearAll() — 清空全部
  • Toast.setMaxCount(n) — 设置同显上限

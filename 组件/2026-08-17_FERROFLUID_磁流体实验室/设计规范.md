## 展区结构（12 个交互特效装置）

1. Magnetic Spikes — 磁流体尖峰剖面，鼠标牵引 + 点击脉冲，弹簧物理
2. Ferro Chains — 铁磁粒子链，反平方引力 + 惯性阻尼 + 粒子连线
3. Magnetic Text — 文字解构为铁屑粒子，鼠标斥力 + 回弹
4. Spectrum Wave — 频谱磁浪，弹簧缓动物理条形波
5. Light Trail — 光绘拖尾，多层辉光 + 速度感知 + 点击爆裂粒子
6. Scanline Glitch — 扫描线故障风，RGB 分离 + 水平偏移 + 点击噪声爆发
7. Noise Flow — Perlin 噪波流场，鼠标扰动注入漩涡
8. 3D Tilt Cards — 卡片透视倾斜 + 磁吸辉光 + 弹簧缓动
9. Typewriter — 终端打字机 + 字符抖动 + 扫描线背景
10. Counter — 数字计数器，弹簧过冲 + 环形脉冲背景
11. Ripple Field — 涟漪场，点击扩散 + 多环干涉 + 阻尼衰减
12. Parallax Layers — 四层视差深度，光标驱动分层位移

## 系统级特性

- 自定义光标（白环 + 氰色内点 + 多层辉光 + 悬停形态切换 + 点击涟漪）
- 侧栏导航 + 搜索过滤 + 顶栏 + 状态栏（场强 / 温度 / FPS / 站号）
- 所有 RAF 循环在 `visibilitychange` 时暂停、切回恢复
- 切换展区时主动 `cancelAnimationFrame` 旧循环
- `prefers-reduced-motion` 降级支持

## 动效原理

基于物理模型（弹簧 Hooke / 反平方磁力 / 惯性阻尼 / RAF 积分器）与磁流体语义（尖峰隆起 / 磁链吸附 / 涟漪扩散 / 滚动驱动形变）。严禁整图缩放 / Ken Burns。

## 健壮性

纯 vanilla HTML/CSS/JS 单文件，零 React / Babel / 外部 CDN 依赖，从根本规避白屏；零未定义引用；RAF / 定时器随可见性暂停与卸载取消；高频鼠标事件直接操作 DOM transform。

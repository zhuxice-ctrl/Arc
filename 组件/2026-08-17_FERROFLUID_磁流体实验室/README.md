# FERROFLUID 磁流体实验室

- 日期：2026-08-17
- 方向：V3 UX 交互设计
- 主题：以铁磁流体为视觉母题的炫技特效实验室

## 简介

12 个可亲手把玩的组件级特效装置：磁流体尖峰、铁磁粒子链、磁化文字解构、频谱磁浪、光绘拖尾、扫描线 glitch、噪波流场、3D 倾斜卡、终端打字机、数字计数、涟漪场、四层视差。配色取炭黑 + 汞银 + 电青。

# 拨浪鼓·甩珠击鼓 — 设计规范

## 主题

拨浪鼓交互组件实验室：以传统拨浪鼓为原型，光标拖拽鼓身产生角加速度，两颗珠子受摆锤物理驱动甩击鼓面，冲击瞬间触发声效与视觉反馈。探索惯性、阻尼、冲击力与声效的物理映射关系。

### 物理模拟系统（RAF 驱动）

核心动效非 CSS 而是实时物理积分：

- **摆锤物理**：珠子位置 = 角度 θ 的极坐标，θ 受角加速度驱动，角加速度 = −g/L × sin(θ) − 阻尼 × 角速度
- **鼓身惯性**：拖拽鼓身产生角速度，松手后按阻尼系数衰减旋转
- **冲击检测**：珠子角度进入鼓面扇区 → 触发冲击事件（声效 + 视觉 + 计数）
- **冲击反馈**：鼓面形变（scale 弹性）+ 涟漪扩散 + WebAudio 合成鼓声 + 屏幕轻微震动

### 组件级特效（≥12）

1. 拨浪鼓鼓身拖拽旋转（惯性 + 阻尼）
2. 双珠摆锤物理摆动（重力 + 阻尼）
3. 珠子冲击鼓面检测与反馈
4. 鼓面弹性形变（冲击 scale 回弹）
5. 冲击涟漪扩散动画
6. WebAudio 合成鼓声（频率随冲击力度变化）
7. 屏幕冲击震动反馈
8. 铜钱装饰旋转入场
9. 冲击签名闪光
10. 页面入场淡入
11. 自定义光标（开页居中显示）
12. 拖拽轨迹尾迹
13. 冲击计数实时更新
14. 力度仪表盘实时反馈

## 技术栈

- 纯 vanilla 单文件 HTML（~39KB，无 React/Babel/CDN）
- Canvas 2D 绘制拨浪鼓 + 珠子 + 鼓面
- requestAnimationFrame 物理积分循环
- WebAudio API 合成鼓声（oscillator + gain envelope）
- Pointer Events 拖拽
- 随 visibilitychange 暂停 RAF
- prefers-reduced-motion 降级（减少物理振荡幅度）

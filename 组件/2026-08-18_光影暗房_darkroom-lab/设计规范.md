# 光影暗房 Darkroom — 设计规范

> 方向：V3 UX 交互设计 · 2026-08-18
> 主题：老式照相馆暗房拟物化小组件动画实验室

## 色彩系统

| 角色 | 色值 | 用途 |
|------|------|------|
| 主背景·暗房深棕黑 | `#0a0805` / `#1a120b` / `#2d1f14` | 页面底色，模拟暗房无光环境 |
| 次背景 | `#3d2817` / `#3d3020` | 装置外壳、工作台木纹 |
| 主色·安全灯琥珀橙 | `#d97706` / `#f59e0b` / `#fbbf24` | 安全灯光、激活态、高亮 |
| 深琥珀 | `#8b6914` / `#b8860b` | 金属部件、刻度、边框 |
| 暗红点缀 | `#ea580c` | 警示灯、显影液反光 |
| 相纸奶白 | `#f5ecd7` / `#fff8e7` / `#d4c4a8` | 相纸、文字前景、显影影像 |
| 木纹暖褐 | `#8b7355` / `#6b5a44` / `#5c4a35` | 装置木质底座、次要文字 |

严禁蓝紫渐变；整体为暗房安全灯暖色调。

## 字体排印

- 衬线：`serif`（展区标题，复古暗房铭牌感）
- 等宽：`monospace`（刻度、数值、说明标签）

## 展区（6 个拟物化微交互装置）

| 编号 | 装置 | 交互 | 物理效果 |
|------|------|------|----------|
| 01 | 安全灯拉绳 | 拖拽下拉 | 单摆摆动 + 弹簧回弹 + 灯光扩散与阴影变化 |
| 02 | 放大机调焦旋钮 | 旋转 | 阻尼旋转 + 12 档刻度磁吸 + 画面模糊→清晰 + 合焦峰值 |
| 03 | 显影计时器 | 拨动指针 | 圆周拖拽 + 60 秒刻度 + 倒计时滴答 + 液面波纹 |
| 04 | 胶片卷片摇杆 | 拖拽摇柄 | 旋转惯性 + 摩擦阻尼 + 齿孔档位吸附 + 胶片同步卷动 |
| 05 | 相纸显影盘 | 拖入显影液 | 拖拽 + 浸入检测 + 涟漪扩散 + 影像逐步浮现 |
| 06 | 倍率拨杆 | 上下推拉 | 4 档磁吸归位 + 刻度灯逐级点亮 + 投影尺寸同步 |

## 动效系统（≥16，全部基于物理模型）

单摆、弹簧（Hooke）、惯性动量、摩擦阻尼、磁吸归位（反平方近似）、涟漪扩散、液面波纹、胶片齿孔吸附、合焦峰值、刻度灯逐级点亮、光标拖尾、点击涟漪、灯光扩散阴影、画面模糊插值、投影尺寸同步、装置入场渐入。

## 自定义光标

开页即居中显示；白色粗环 + 琥珀内点 + 多层发光；悬停可交互装置时放大变色；点击涟漪扩散；z-index 最高。

## 健壮性

- 纯 vanilla HTML/CSS/JS 单文件（无 React / 无 Babel / 无外部 CDN 依赖）
- 所有 RAF 随 visibilitychange 暂停、卸载取消
- 重建定时器前先 cancel 旧的，快速操作不叠加
- 高频 mousemove 直接操作 DOM transform
- 支持 prefers-reduced-motion 降级
- 零未定义引用

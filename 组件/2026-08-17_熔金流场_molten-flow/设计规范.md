# 熔金流场 · 设计规范

> 日期：2026-08-17 · 方向：V3 UX 交互设计 · 主题：熔金流场特效实验室（炫技组件特效动画实验室）

## 色彩系统

以黑曜石黑为底，熔金为主亮色，铜红/余烬橙为火热渐变，灰白为文字/高光。禁蓝紫渐变。

| 角色 | 色值 | 用途 |
|------|------|------|
| 底色（黑曜石黑） | `#0c0a08` | 页面背景、最深层级 |
| 次底 | `#15110d` / `#1f1913` | 卡片底、展区容器 |
| 主亮色（熔金） | `#ffb627` | 主粒子、高亮、强调 |
| 熔金亮 | `#ffd875` | 高光、渐变末端 |
| 火热色（铜红） | `#c44510` | 渐变中段、火焰根部 |
| 余烬橙 | `#ff6b1a` | 粒子、火花、余烬 |
| 文字/高光（灰白） | `#e8e2d8` | 正文、高光描边 |
| 暖灰 | `#a79e91` | 次级文字、参数标签 |

## 字体

系统无衬线栈为主；参数面板/代码用等宽倾向。无外部字体 CDN。

## 圆角与间距

展区容器圆角 12-16px；参数滑杆面板胶囊化；间距 8/12/16/24 节奏。

## 展区结构（7 个炫技组件特效装置）

| 展区 | 特效类型 | 交互方式 |
|------|---------|---------|
| 01 熔金流场 | Perlin 噪波流场 + 热力扭曲 + 粒子引力环 | 鼠标移动驱动热源 |
| 02 余烬迸溅 | 粒子爆发 + 浮力阻尼 + 火花尾迹 | 点击引爆 |
| 03 熔金文字解构 | 像素级文字解构 + 熔滴下坠 + 余烬升腾 | 悬停触发熔化 |
| 04 磁力熔滴 | 反平方引力 + 弹簧阻尼回归 + metaball 熔合桥接 | 鼠标拖拽牵引 |
| 05 扫描锻造 | CRT 扫描线 + 色差偏移 + 热扰动波纹 | 鼠标驱动扭曲 |
| 06 熔金拖尾 | 惯性拖尾线 + 随机液滴 + 重力滴落 | 鼠标移动 |
| 07 熔金频谱 | 频谱光柱 + 包络分布 + 点击波纹 + 倒影反射 | 水平位置调频段 / 点击冲击 |

每个展区配 2-3 个参数滑杆实时调节。

## 动效系统（14 个组件级特效）

共享单 RAF 循环驱动：噪波流场粒子、热力扭曲、粒子爆发浮力阻尼、像素文字解构熔滴、反平方引力 metaball、CRT 扫描线色差、惯性拖尾重力滴落、频谱光柱包络、点击波纹倒影、自定义光标（白环+熔金内点+多层发光+悬停放大+点击涟漪）、参数滑杆实时响应、展区切换过渡、热扰动波纹、余烬升腾。

动效基于物理模型：弹簧阻尼回归、反平方引力、浮力+阻尼、惯性动量、RAF 积分器；主题语义：熔金流淌、余烬上升、热力扭曲、金属熔滴凝固。

## 健壮性

- 共享单 RAF 循环，visibilitychange 自动暂停/恢复，卸载统一取消。
- 高频鼠标事件直接操作 canvas，无 React setState 开销。
- prefers-reduced-motion 降级为静态展示。
- 纯 vanilla 单文件，无 React / 无 Babel / 无外部 CDN 依赖。

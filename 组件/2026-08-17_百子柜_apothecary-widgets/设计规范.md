# 百子柜 · 中药铺拟物组件实验室 设计规范

> 方向：V3 UX 交互设计 · 日期：2026-08-17 · 主题：老中药铺拟物化微交互装置

## 色彩系统

老药铺暖木质感：紫檀木棕为主、铜器暗金提亮、宣纸米白为底、朱砂印泥点睛。

| 角色 | 色值 | 用途 |
|---|---|---|
| 紫檀木棕（主） | `#6B4423` / `#3D2314` | 木质装置主体、深色背景 |
| 木纹浅棕 | `#A67C52` | 木纹纹理、次级木面 |
| 铜器暗金 | `#DAA520` / `#8B6914` / `#F0C040` | 铜器配件、金属高光、铜臼铜杵 |
| 宣纸米白（底） | `#F5EFE0` / `#EDE4CC` / `#E5D9B8` | 宣纸底面、浅色卡片 |
| 朱砂印泥 | `#D44634` | 印章、强调标记 |
| 墨绿 | `#556B2F` | 药材点缀、绿叶 |

## 字体

- 标题：衬线体栈，老字号牌匾气质
- 正文：无衬线体栈
- 装饰：手写体意趣，用于展区编号与说明

## 六大展区（光标驱动拟物微交互）

| 展区 | 核心交互 | 物理模型 |
|---|---|---|
| 壹·百子柜 | 拖拽拉开抽屉，松手弹簧回弹 | Hooke 弹簧 + 阻尼积分 |
| 贰·戥子秤 | 拖动秤砣左右，秤杆倾斜找平衡 | 杠杆力矩平衡 |
| 叁·铜臼捣药 | 按住药杵捣药，铜震药尘飞溅 | 重力粒子 + 震动反馈 |
| 肆·桑皮纸包 | 依次点击四边折纸，最后盖朱砂印 | 3D 翻折 + 印章弹出 |
| 伍·药牌挂牌 | 点击木牌翻转，挂绳摇摆如风 | 翻转 + 阻尼摆动 |
| 陆·掌柜算盘 | 点击算珠拨动，上下归位 | 拨动碰撞感 |

## 组件级特效（12+）

自定义光标（白环 + 铜芯 + 发光 + 三态切换 + 点击涟漪）、抽屉弹簧惯性、秤杆力矩物理、捣药药尘粒子、纸包 3D 翻折、木牌翻转摇摆、Hero 柜 3D 倾斜、导航项磁吸、编号视差滚动、光泽扫过、悬停发光、滚动渐入、数字计数、震动反馈。

## 健壮性

- 纯 vanilla HTML/CSS/JS 单文件（无 React / 无 Babel / 无外部 CDN）
- RAF / 定时器统一管理，visibilitychange 自动暂停
- prefers-reduced-motion 降级为静态
- 零未定义引用，零外部 JS 依赖

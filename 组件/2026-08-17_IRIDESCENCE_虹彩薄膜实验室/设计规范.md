# 设计规范 · IRIDESCENCE 虹彩薄膜实验室

> 方向：UX 交互设计（V3） · 日期：2026-08-17 · 主题：虹彩 / 薄膜干涉光学特效实验室

## 色彩系统

油膜虹彩风：深炭黑为底，翡翠绿 / 琥珀金 / 玫红三色构成油膜虹彩（teal-gold-rose，明确不用蓝紫），珍珠白为文字。

| 角色 | 色值 | 用途 |
|---|---|---|
| 主背景 / 深炭黑 | `#0B0B0F` | 页面底 |
| 深炭层 | `#12121A` / `#1A1A26` | 卡片、展区底 |
| 翡翠绿 | `#2DD4A7` | 虹彩主色、强调、光标内点之一 |
| 琥珀金 | `#F5B840` | 虹彩主色、高亮、数字 |
| 玫红 | `#FF5C8A` | 虹彩主色、磁力 / 警示 |
| 珍珠白 | `#F5F5F0` | 正文文字 |

油膜虹彩用 teal-green / gold / rose 三色随角度 / 距离流转，明确不使用蓝紫渐变。

## 字体

- 标题：`'Space Grotesk', 'Inter', system-ui, sans-serif`
- 等宽数字 / 标签：`'SF Mono', 'JetBrains Mono', monospace`

## 展区（6 个独立组件级特效装置，必须上手操作）

1. **Oil Film**——油膜虹彩 shader：Canvas 2D 逐像素干涉模拟，鼠标控制膜厚与视角，彩虹油膜随角度流转
2. **Particle Field**——反平方引力粒子散射场：左键排斥，粒子带虹彩拖尾（RAF 积分器）
3. **Text Deconstruct**——文字逐字弹簧解构：鼠标靠近飞散、远离弹性回归（Hooke 弹簧）
4. **Magnetic Core**——磁力按钮：距离反比吸附形变 + 涟漪 + 脉冲计数
5. **Spectrum Visualizer**——32 柱频谱：4 种波形（SINE / NOISE / PULSE / RAINBOW），点击切换
6. **Cursor Trail**——24 颗粒子弹性阻尼拖尾，每层不同 K 值与阻尼

展区切换：右侧 6 个圆点，或方向键。

## 动效系统（12+ 个组件级特效）

1. 自定义光标：白环 + 虹彩内点 + 多层发光，开页即现于屏幕中央，悬停三态切换，点击涟漪
2. 油膜流转（Canvas 逐像素）
3. 粒子引力（反平方 + RAF 积分器）
4. 文字解构（弹簧回归）
5. 磁力形变（距离反比）
6. 频谱柱振动（正弦叠加 + 噪声）
7. 光标拖尾（弹性阻尼）
8. 滚动渐入
9. 悬停发光
10. 数字计数
11. 光泽扫过（logo）
12. 展区切换过渡
13. Logo 自旋
14. 状态脉冲灯

动效基于 RAF 积分器 / 阻尼 / 弹簧 / 反平方引力，周期各不相同；严禁整图缩放 / Ken Burns。

## 健壮性

- 纯 vanilla 单文件（无 React / 无 Babel / 无外部 CDN 依赖）
- 零未定义引用
- RAF / 定时器随 `visibilitychange` 自动暂停，`beforeunload` 统一清理
- resize 去抖
- 高频鼠标事件直接操作 DOM / Canvas，不触发 setState
- 支持 `prefers-reduced-motion` 降级

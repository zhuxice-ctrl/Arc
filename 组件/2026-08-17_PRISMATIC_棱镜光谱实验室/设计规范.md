# PRISMATIC 棱镜光谱实验室 · 设计规范

> 方向：V3 UX 交互设计 · 主题：棱镜光谱/光线折射色散特效实验室
> 配色基调：纯黑底 + 光谱色散强调（红橙黄绿青），UI 银白（无蓝紫渐变作主背景）

## 字体排印

- UI/正文：`'Inter', -apple-system, BlinkMacSystemFont, 'Segoe UI', sans-serif`
- 等宽（数据/光谱读数）：系统等宽栈

## 展区（7 大可把玩装置）

1. 棱镜色散（旗舰大卡）— 拖动棱镜、滑块调入射角/折射率，白光实时分解成连续光谱（斯涅尔折射定律）
2. 镜面迷宫（光线追踪）— 点击镜面旋转 15°，光路实时重算多次反射
3. 光栅衍射 — 滑块调狭缝密度 + 波长，干涉条纹实时变化（N 缝干涉方程）
4. 光谱粒子流场（旗舰大卡）— 鼠标移动吸引粒子、点击爆炸，Perlin 噪波流场 + 拖尾
5. 霓虹光谱灯 Bloom — 鼠标靠近点亮对应灯管，多层 bloom 光晕扩散
6. 磁力形变场 — 反平方引力扭曲正交网格，栅格密度 + 磁力强度可调
7. 色散文字（旗舰大卡）— RGB 三通道跟随鼠标偏移，模拟镜头色差，可切换文字

## 动效系统（12+ 组件级特效）

- 自定义光标（白环 + 内点 + 多层发光，悬停放大三态、点击涟漪，开页即居中，z-index 最高）
- 弹簧物理（光标外环/内点分级跟随、卡片 3D tilt 阻尼）
- 滚动视差（Hero 标题分层位移 + 淡出）
- 弹簧入场动画（IntersectionObserver 触发）
- 真实光学计算（斯涅尔折射定律、光栅方程、镜面反射）
- 粒子拖尾 / 噪波流场 / bloom 光晕 / 网格磁力形变 等

## 健壮性

- 纯 vanilla HTML/CSS/JS 单文件，零 React / Babel / 外部 CDN 依赖
- 统一 RAF 注册中心 + visibilitychange 自动暂停 + 卸载取消
- prefers-reduced-motion 降级
- 高频鼠标事件直接操作 DOM transform

# 设计规范 · CHROMATIQUE 液态光学实验室

> 方向：UX 交互设计（V3） · 日期：2026-08-17 · 主题：光与色散的组件特效把玩实验室

## 色彩系统

| 角色 | 色值 | 用途 |
|---|---|---|
| 珍珠白（底） | `#F4F2EE` / `#E8E5DF` | 浅色展区背景、文字 |
| 石墨黑 | `#2a2a2a` | 深色展区背景、文字 |
| 电镀银 | `#C8CDD2` | 金属边框、中性强调 |
| 全息青 | `#39D0D8` / `#0f0`(示波绿) | 色散通道、CRT |
| 全息品红 | `#F05CC8` / `#FF00AA` | 色散通道 |
| 全息柠檬黄 | `#E8F04A` / `#FFFF00` | 色散通道、高光 |
| 光谱序列 | `#FF0000 #FF2200 #FF5500 #FF7F00 #FFAA00 #AAFF00 … #9400D3 #AA00FF` | 棱镜分解 12 色光谱 |

## 字体

- 展示：`'ChromatiqueDisplay'`（自定义展示字）
- 正文 UI：`'Times New Roman', 'Noto Serif SC', serif`
- 代码/参数：`'Courier New', monospace`

## 圆角

- 展区面板 12–16px；按钮 8px；参数滑杆轨道胶囊形

## 展区（6 个，全部可亲手把玩）

1. **色散实验室** — 鼠标驱动 RGB 通道分离文字 + 4 个几何形变体；可调强度/角度/模糊
2. **液态金属腔** — 水银液滴物理模拟（推挤/聚结/反弹）；可调表面张力/粘度/数量；3 种材质预设
3. **全息箔画廊** — 3 张全息卡片 3D 倾斜 + 彩虹干涉色带 + 高光跟随
4. **CRT 扫描线控制台** — 完整 CRT 滤镜（扫描线/扫描条/闪烁/渐晕/曲率/色偏）；5 开关 + 4 滑杆；打字机
5. **棱镜折射工作室** — 可拖拽棱镜 + 白光分解为 12 色光谱；可调光强/光束宽/棱镜旋转
6. **体积光尘** — 数百颗漂浮粒子随鼠标扰动 + 双层体积光轴 + 闪烁

## 动效系统（≥12 项，基于物理/光学语义）

- 自定义光标（白环 + 彩色内点 + 多层发光），开页居中、悬停形变、点击涟漪
- 横向滑动导航（滚轮/键盘/顶栏/右侧指示点）+ 石墨色 wipe 转场
- 色散 RGB 分离（鼠标距离驱动分离量）
- 液态金属推挤形变（表面张力 + 粘度物理）
- 全息箔 3D 倾斜 + 彩虹干涉色带（视角驱动）
- CRT 扫描线/闪烁/渐晕/曲率实时滤镜
- 棱镜折射光谱分解（几何光学）
- 体积光尘粒子扰动（鼠标力场）
- 流光渐变标题
- 打字机效果
- 卡片高光跟随
- 粒子闪烁

## 健壮性

- 纯 vanilla 单文件（无 React / 无 Babel / 无外部 CDN）
- `visibilitychange` 自动暂停 rAF；`beforeunload` 清理
- 高频事件只改 transform；无 undefined 引用
- 支持 `prefers-reduced-motion`

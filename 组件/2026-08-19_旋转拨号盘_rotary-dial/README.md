# 远方的声音 · 胶木拨号盘

V3 拟物化旋转拨号盘电话交互组件。纯 vanilla 单文件 HTML，无外部依赖（字体除外）。

**在线预览**：https://dcniaqwtmoca.feishu.cn/page/DhvLmwZZfdMBlDaT6woc86nFnPf

## 主题

一只胶木电话的旋转拨号盘。拨动号码盘，听远方的声音。

## 核心交互

- **拖拽拨号**：按住号码孔顺时针拖动到指挡处，松手后弹簧匀速回旋，棘轮咔哒计数
- **自动拨号**：点击下方三个预设号码按钮，可自动演示完整拨号流程
- **接通声波纹**：拨通预设号码后，显示窗切换为 Canvas 声波纹，WebAudio 合成通话声
- **清零重拨**：点击黄铜复位键挂断并清空号码

### 三个「远方的声音」

| 号码 | 声音 | 波形 |
|------|------|------|
| 010 | 胡同老人（北京低频喉音） | rumble 低频共振峰 |
| 021 | 外滩钟声（海关大钟） | chime 谐波泛音列 |
| 0755 | 南海潮声（深圳湾海浪） | waves 滤波噪声调制 |

## 五层反馈模型

1. **Pre-contact 预接触**：光标接近号码孔时孔位放大 + 金辉、光标切换抓取态
2. **Contact 接触**：按下瞬间黄铜涟漪扩散 + 弹簧绷紧声
3. **Continuous 持续**：拖拽中拨号盘跟随、光标握持态旋转虚线
4. **Threshold 阈值**：到达指挡时金属闷响 + 振动感
5. **Release-decay 释放衰减**：松手后匀速弹簧回旋、每 30° 一声棘轮咔哒、回零处数字入账

## 组件级动效（≥12 个）

1. 自定义光标（跟随/悬停/抓取/握持/点击五态）
2. 拨号盘拖拽旋转（直接 DOM 操作，无重渲染）
3. 弹簧匀速回旋（恒定角速度，非 linear/ease 默认值）
4. 棘轮咔哒声（WebAudio 合成：方波+正弦+噪声三叠加）
5. 号码孔预接触放大 + 金辉发光
6. 按下涟漪扩散（黄铜色环扩散消失）
7. 指挡金属撞击声（低频正弦+三角波共振）
8. 电话铃流（间歇双音铃 + 机身微振动）
9. Canvas 声波纹（根据声音类型不同波形：喉鸣/钟鸣/海浪）
10. 状态指示灯（待机/呼叫闪烁/接通常亮三态）
11. 复位按钮悬停 90° 旋转 + 按下 180°
12. 号码按钮扫光 + 浮起阴影
13. 拨号盘回位时黄铜光晕增强
14. 显示窗号码逐位入账（打字机感）

## 技术边界

- 纯 vanilla JS + CSS，单文件 HTML
- RAF 驱动动画，`visibilitychange` 时暂停
- `prefers-reduced-motion` 时关闭动画与自定义光标
- WebAudio 全部合成，无外部音频文件
- 声波纹使用 Canvas 2D 绘制
- 无 React / 无构建步骤 / 无 CDN 依赖（字体除外）

## 配色

胶木黑 `#1a1410` · 黄铜金 `#a8823d` · 奶白 `#f3ecd8`

## 操作说明

- 鼠标按住号码孔 → 顺时针拖动 → 到达指挡后松手 → 听棘轮咔哒并计入号码
- 拨完 3 位区号（010 / 021 / 0755）自动接通对应声音
- 点击底部按钮可直接自动拨号演示
- 点击右侧复位按钮清零重拨

# 旋转拨号盘 · 设计规范

## 1. 设计理念

「深夜的拨号盘」是一只 1960 年代胶木电话的旋转拨号盘交互组件。设计语言来自老式电话的真实材质——胶木的厚重黑、黄铜的温润金、奶白的号码盘。核心交互是拖拽号码孔顺时针旋转到指挡处，松手后弹簧匀速回旋，每 30° 一声棘轮咔哒。拨通预设区号后，显示窗切换为 Canvas 声波纹，WebAudio 合成三种「远方的声音」：北京胡同老人喉音、上海外滩海关钟声、深圳南海潮声。

## 3. 字体系统

- **正文 / UI**：系统等宽字体（monospace），强化机械感
- **数字**：等宽字体 700，号码孔数字与显示窗
- **标题**：系统无衬线，克制使用

## 4. 核心交互机制

### 4.1 旋转拨号

- 鼠标按住号码孔 → 顺时针拖动 → 拨号盘跟随旋转
- 到达指挡（金属挡块）时停止，触发金属闷响
- 松手后弹簧匀速回旋（恒定角速度，非 ease）
- 每 30° 回旋触发一声棘轮咔哒（WebAudio 合成）
- 回旋归零时数字入账显示窗

### 4.2 五层反馈

1. **预接触**：光标接近号码孔 → 孔位放大 + 金辉光环 + 光标切换抓取态
2. **接触**：按下 → 黄铜涟漪扩散 + 弹簧绷紧声
3. **持续**：拖拽中 → 拨号盘跟随 + 光标握持态旋转虚线
4. **阈值**：到达指挡 → 金属闷响 + 振动感
5. **释放衰减**：松手 → 匀速回旋 + 棘轮咔哒 + 回零入账

### 4.3 自动拨号

- 三个预设号码按钮：010（北京）/ 021（上海）/ 0755（深圳）
- 点击后自动演示完整拨号流程
- 拨通后显示窗切换为 Canvas 声波纹 + WebAudio 合成声音

### 4.4 三种「远方的声音」

| 号码 | 声音 | 波形 | WebAudio 合成 |
|------|------|------|--------------|
| 010 | 胡同老人喉音 | rumble 低频共振峰 | 方波 + 正弦 + 低通滤波 |
| 021 | 外滩海关钟声 | chime 谐波泛音列 | 多正弦叠加 + 衰减包络 |
| 0755 | 南海潮声 | waves 滤波噪声调制 | 白噪声 + 带通滤波 + LFO |

## 6. 健壮性

- 纯 vanilla JS + CSS，单文件 HTML
- 无 React / Babel / CDN 依赖（字体除外）
- RAF 驱动动画，`visibilitychange` 暂停，卸载取消
- `prefers-reduced-motion` 时关闭动画与自定义光标
- WebAudio 全部合成，无外部音频文件
- 声波纹使用 Canvas 2D 绘制
- 显示窗位置已修复（top:12px, height:50px），不遮挡拨号孔

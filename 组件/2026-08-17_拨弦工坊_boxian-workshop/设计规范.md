## 展区与交互装置（6个）

### 1. 拉绳吊灯
- **物理模型**：钟摆物理 + 弹簧回弹（Hooke定律）
- **交互**：拖拽拉绳点亮灯泡，拖拽幅度影响灯泡亮度
- **反馈**：光线从灯泡扩散、灯丝发光呼吸、松手弹性回弹

### 2. 日月切换滑动开关
- **物理模型**：弹性吸附 + 阻尼
- **交互**：拖动滑块从月亮端滑到太阳端切换昼夜
- **反馈**：背景星空渐变为蓝天白云、月亮变太阳、颜色渐变

### 3. 拨杆开关
- **物理模型**：弹性卡扣 + 阻尼振动
- **交互**：拖拽拨杆从一端拨到另一端
- **反馈**：微振动+声波纹扩散、触点发光、场景切换

### 4. 转盘调谐器
- **物理模型**：旋转惯性 + 指针弹性跟随
- **交互**：旋转转盘调节频率
- **反馈**：频率数字变化、指针弹性跟随、调谐成功指示

### 5. 弹簧按钮
- **物理模型**：Hooke定律压缩 + 回弹震荡
- **交互**：按压按钮使弹簧压缩
- **反馈**：松手弹回伴随微弹跳、涟漪扩散+光效、金属反光

### 6. 磁吸摇杆
- **物理模型**：磁性反平方引力衰减
- **交互**：拖动摇杆，松手被磁力拉回中心
- **反馈**：磁力线可视化、拖动距离影响回弹力度、等势圆环

## 动效系统

| 动效 | 实现方式 | 触发条件 |
|------|---------|---------|
| 自定义光标 | 白环+琥珀内点+多层发光，三态切换 | 开页即显示在屏幕中央 |
| 粒子光尘 | 漂浮微粒 | 持续运行 |
| 拉绳物理摆动 | RAF积分器+钟摆物理 | 拖拽/释放 |
| 灯泡光线扩散 | 亮度+box-shadow动画 | 拖拽拉绳 |
| 日月渐变过渡 | CSS渐变插值 | 拖拽滑块 |
| 拨杆阻尼弹性 | 弹簧物理模拟 | 拖拽/释放 |
| 转盘旋转惯性 | 角速度衰减 | 拖拽/释放 |
| 弹簧压缩回弹 | Hooke定律+阻尼 | 按压/释放 |
| 磁力线动画 | Canvas绘制磁力线 | 拖拽摇杆 |
| 涟漪点击 | 点击处光环扩散 | 点击 |
| 滚动渐入 | IntersectionObserver | 进入视口 |
| 悬停发光 | box-shadow过渡 | 鼠标悬停 |

## 健壮性

- requestAnimationFrame/定时器随 visibilitychange 暂停、卸载取消
- 快速操作不叠加定时器（重建前先 clearTimeout/cancelAnimationFrame）
- 高频鼠标事件直接操作 DOM transform 不触发重渲染
- 支持 prefers-reduced-motion（降级为静态或最小动效）
- 纯 vanilla HTML/CSS/JS 单文件实现（无 React/Babel/CDN 依赖）

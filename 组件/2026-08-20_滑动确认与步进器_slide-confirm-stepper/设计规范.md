# 设计规范 · 滑动确认 Slide-to-Confirm + 步进器 Stepper

> Art 设计实验室 · V3 交互组件 · 2026-08-20
> 场景：「山物集」土产小铺结算台

## 设计概念

两个生产级可复用 UI 组件，共用一套「米纸 × 柿橙」的土产铺视觉语言：

- **滑动确认 Slide-to-Confirm**：为「有分量的操作」（提交订单、删除、转账）提供的确认轨道。拖拽滑块越过 80% 阈值才触发，不足则阻尼弹簧回弹；触发后进入 loading → success / error 完整状态流。
- **步进器 Stepper**：整数数量输入。点击 ±、长按 500ms 后加速重复（最高 5 倍速）、手动输入失焦校验（非法值砖红抖动回退）、min/max 边界钳制且到界 disabled。

记忆点（Signature Moment）：滑块越过阈值瞬间轨道满填、滑块吸入末端，结算单上「已确认」印章盖下。

## 动效系统（真实曲线与时长）

| 用途 | 曲线 / 时长 |
|---|---|
| 弹簧吸附 / 回弹 | `cubic-bezier(0.34, 1.56, 0.64, 1)`（`--ease-spring`） |
| 一般过渡 | `cubic-bezier(0.22, 1, 0.36, 1)`（`--ease-out`） |
| 状态过渡 | `cubic-bezier(0.65, 0, 0.35, 1)`（`--ease-in-out`） |
| 时长 | fast 180ms / base 240ms / slow 420ms |

动效语义：弹簧曲线只用于弹性反馈（阈值吸附、未达标回弹、步进器 error 抖动）；阻尼用于确认的分量感；无装饰性特效。`prefers-reduced-motion` 下全局降级为瞬时切换。

## 状态机

**Stepper（6 态）**：rest / hover / focus（accent 描边+光晕）/ active / disabled（到界或整体禁用）/ error（非法输入抖动回退）

**Slide-to-Confirm（7 态）**：rest / hover / dragging（跟手放大）/ loading（呼吸脉冲）/ success（苔绿+对勾）/ error（砖红+叉号，自动回弹可重试）/ disabled

## 工程健壮性

- 纯 vanilla 单文件，零依赖、零 CDN、零外部图片字体
- 组件为独立 IIFE 模块（`Stepper` / `SlideConfirm` 全局命名空间），注释边界清晰
- 拖拽走 pointer events + RAF 直接写 DOM，不经框架重渲染
- RAF / 定时器随 `visibilitychange` 暂停，`destroy()` 可完整清理
- aria：`role="slider"` + `aria-valuemin/max/now` 实时同步、`aria-disabled`、`aria-live="polite"` 合计播报
- 键盘：步进器 ↑↓ / Shift±10 / Home / End / Enter / Esc；滑动确认 ←→ / Home / End / Enter / Space / Esc
- 全局 `:focus-visible` 焦点环（2px 柿橙实线 + 3px offset）

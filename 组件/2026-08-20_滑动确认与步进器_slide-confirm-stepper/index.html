Stepper 步进器

用于商品数量、人数等整数输入场景，支持点击、长按加速、键盘方向键与手动输入校验。

状态机

  • rest：默认静止态，边框细线
  • hover：鼠标悬停，边框加深
  • focus：输入框聚焦或按钮焦点，accent 色描边 + 光晕
  • active：按钮按下，背景变浅
  • disabled：整体禁用，透明度降低
  • error：输入非法值，砖红抖动提示后回退

使用方式

HTML 结构 + 初始化 JS 即可使用：

<div class="stc-stepper" data-min="1" data-max="10" data-step="1" data-value="2">
  <button class="stc-stepper__btn stc-stepper__btn--dec" aria-label="减少">−</button>
  <input type="number" class="stc-stepper__input" aria-label="数量" />
  <button class="stc-stepper__btn stc-stepper__btn--inc" aria-label="增加">+</button>
</div>

<script>
  // 初始化所有步进器
  document.querySelectorAll('.stc-stepper').forEach(Stepper.init);
</script>

键盘操作

  • ↑ / ↓：增减一步
  • Shift + ↑ / Shift + ↓：增减十步
  • Home / End：跳到最小 / 最大值
  • Enter：确认输入值
  • Esc：取消输入，回退原值

Slide-to-Confirm 滑动确认

为提交订单、删除账户、转账等"有分量的操作"提供的确认控件。拖拽滑块越过阈值才触发，不足则阻尼回弹。

状态机

  • rest：滑块在起点，轨道浅底
  • hover：滑块阴影柔和加深
  • dragging / active：拖拽中，滑块放大、跟手
  • loading：提交中，滑块呼吸脉冲
  • success：成功，轨道与滑块变苔绿，对勾显现
  • error：失败，轨道与滑块变砖红，叉号显现，自动回弹
  • disabled：禁用态，整体半透明

使用方式

<div class="stc-slide-confirm" id="confirm" role="slider"
     aria-label="确认提交" tabindex="0">
  <div class="stc-slide-confirm__fill"></div>
  <span class="stc-slide-confirm__hint">滑动确认</span>
  <div class="stc-slide-confirm__thumb">
    <svg class="stc-slide-confirm__thumb-icon-arrow">...</svg>
    <svg class="stc-slide-confirm__thumb-icon-success">...</svg>
    <svg class="stc-slide-confirm__thumb-icon-error">...</svg>
  </div>
</div>

<script>
  SlideConfirm.init(document.getElementById('confirm'), {
    threshold: 0.8,
    onConfirm: function(done) {
      // 异步操作，完成后调用 done(success)
      setTimeout(function() { done(true); }, 1500);
    }
  });
</script>

键盘操作

  • → / ←：步进 10%
  • End / Home：直接到末端 / 起点
  • Enter / Space：从当前位置确认提交
  • Esc：取消，滑块回弹

CSS 变量主题化

两个组件均通过 CSS 变量暴露全部视觉属性，抽取到其他项目后只需覆盖变量即可换肤。

Stepper 变量

--stp-size按钮尺寸 32px
--stp-radius圆角 8px
--stp-input-w输入框宽 48px
--stp-accent主色
--stp-bg背景色
--stp-line边框色
--stp-error错误色
--stp-dur动画时长

Slide-to-Confirm 变量

--sc-height轨道高度 56px
--sc-radius圆角 胶囊形
--sc-thumb-size滑块尺寸 48px
--sc-accent主色
--sc-track-bg轨道底色
--sc-track-fill填充色
--sc-success成功色
--sc-error错误色
--sc-dur-*动画时长系列
--sc-ease-spring弹簧曲线

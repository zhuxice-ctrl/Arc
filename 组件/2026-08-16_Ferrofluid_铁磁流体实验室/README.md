## 设计说明

以「铁磁流体 + 磁场」为核心的炫技特效实验室，鼠标即磁极。7 个可亲手把玩的展区，每个上手操作才有意义：① 铁磁流体尖刺场（反平方引力粒子尖刺，带强度/密度滑块）② 磁场线可视化（双磁极实时磁力线，N/S 极双色辉光）③ 磁吸粒子星团（600 粒子，吸引/排斥/涡旋三模式切换）④ 文字解构重组（文字采样成粒子，鼠标推开、Hooke 弹簧回弹）⑤ 磁吸按钮阵列（9 按钮磁性吸附 + 惯性动量 + 点击涟漪）⑥ 频谱涟漪（点击多环磁场涟漪 + 频谱柱振动）⑦ 噪波流体拖尾（Perlin 噪波三层拖尾：外辉光/中金属/内亮核）。

## 交互说明

- 自定义「磁针」光标：开页即居中显示，悬停三态切换（N 极/S 极/中性），点击涟漪
- 各展区可切换、滑块可调、按钮可点
- 鼠标移动直接驱动 canvas/DOM，不触发重渲染

## 动效原理（7 展区 + 光标，均基于物理模型）

铁磁流体尖刺（反平方引力 + RAF 积分器）/ 磁场线（磁偶极实时积分）/ 磁吸粒子星团（引力 + 阻尼涡旋）/ 文字解构（Hooke 弹簧回位 + 推力）/ 磁吸按钮（磁性吸附 + 惯性动量 + 弹簧回弹）/ 频谱涟漪（多环扩散 + 频谱振动）/ 噪波拖尾（Perlin 噪波 + 渐隐）/ 磁针光标（开页居中 + 三态 + 涟漪）。各展区周期不同。RAF 统一管理，`visibilitychange` 自动暂停/恢复，`prefers-reduced-motion` 降级，mousemove 直接操作 DOM/canvas 不触发重渲染。

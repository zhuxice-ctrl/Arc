# 设计规范 · Ferrofluid 铁磁流体实验室

> Arc 每日设计 Mock · 2026-08-16 batch4 · V3 UX 交互设计

## 主题

以「铁磁流体」为母题的炫技组件特效实验室 —— 7 个展区，每个都必须亲手把玩才有意义：拖动磁场看尖刺排列、推动磁簇聚散、解构文字、按磁力按钮……交互运动原理本身即展品。

## 7 展区

- **00 / Hero** — 铁磁流体标题与引导。
- **01 / Ferro Spikes** — 铁磁流体尖刺：鼠标即磁极，尖刺沿磁力线竖起（反平方引力 + 噪声扰动）。
- **02 / Field** — 磁场可视化：拖动磁极改变场线分布。
- **03 / Cluster** — 磁簇聚散：推动磁性粒子团，惯性 + 阻尼。
- **04 / Text Deconstruct** — 文字解构：悬停字符被磁场撕散再聚合。
- **05 / Magnet Button** — 磁力按钮：靠近即被吸引偏移，按下涟漪。
- **06 / Spec** — 设计规范色卡。
- **07 / Trail** — 光标拖尾：高频 mousemove 直接操作 DOM，多段残影衰减。

## 动效原理（12+）

1. **铁磁尖刺 Canvas**：粒子受鼠标反平方引力 + 法向噪声，竖立成尖刺。
2. **磁场场线**：场矢量积分渲染，拖动磁极实时重算。
3. **磁簇惯性**：粒子速度积分 + 摩擦阻尼。
4. **文字解构**：字符 transform 受磁极吸引偏离，松手弹簧回位。
5. **磁力按钮**：按钮跟随光标偏移（弹簧 Hooke），按下涟漪。
6. **自定义光标拖尾**：多段残影 DOM 直接操作，衰减。
7. **自定义光标**：白环 + 黄绿内点 + 发光，开页居中。
8. **滚动渐入**：展区进入视口触发。
9. **悬停发光**：展区边框呼吸。
10. **数字计数**：展区编号 00→NN。
11. **光泽扫过**：spec 色卡 shimmer。
12. **粒子涡旋**：hero 背景粒子绕中心旋转（角速度积分）。

## 健壮性

- 纯 vanilla 单文件，无 React/Babel/CDN（一次成功无白屏）。
- RAF 随 visibilitychange 暂停；卸载取消。
- 高频 mousemove 直接 DOM transform，不重渲染。
- prefers-reduced-motion 降级。

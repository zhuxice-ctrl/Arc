# 行影集 · 拖拽上传区与按钮系统 — 设计规范

> V3 交互组件 · 2026-08-20 · 类别：操作类（拖拽上传区）+ 操作类（按钮系统）
> 形态：Web 展示页（桌面优先，响应式至 640px）

## 一、主题与场景

「行影集 · 旅行照片管理台」——一个旅行照片归档工作台。组件是主角，展示页是配角：
- **ArcUpload**：照片拖拽上传区，FileReader 真实读取本地图片生成缩略图，模拟 determinate 上传进度。
- **ArcButton**：四族按钮系统，承载选择/粘贴/禁用/清空全部操作，并演示 loading→success/error 语义形变。

## 三、字体

- 正文：`-apple-system, "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", sans-serif`
- 等宽（文件大小、进度百分比）：`"SFMono-Regular", Consolas, Menlo, monospace`，启用 `font-variant-numeric: tabular-nums` 保证数字等宽不跳动。
- UI 文案全中文（「把婺源油菜花季的照片拖到这里」「上传中…」「确认清空？」）。

## 四、圆角 / 阴影 / 时长 / 缓动

- 圆角阶梯：sm 4px / md 8px / lg 12px / xl 16px
- 阴影阶梯：sm / md / lg（暗主题更深、亮主题更浅，随主题切换）
- 时长：fast 150ms / base 250ms / slow 400ms
- 缓动：
  - **弹簧** `cubic-bezier(0.34,1.56,0.64,1)` —— 落定、卡片入场、按钮按压回弹
  - **标准 out** `cubic-bezier(0.22,1,0.36,1)` —— 状态过渡、对勾描边
  - **线性** —— 进度条增长、spinner 旋转
- 焦点环：`2px solid var(--arc-accent)`，offset 3px

## 五、动效系统（语义匹配，非装饰）

| 动效 | 触发 | 曲线/时长 | 语义 |
|---|---|---|---|
| 边框收拢+呼吸光晕 | dragover | pulse 2s infinite | 拖入阈值预告 |
| 卡片弹簧落定 | 文件加入 | spring 250ms | 接触→落定 |
| 进度条线性增长 | uploading | linear 100ms | 持续上传 |
| 对勾描边生长 | success | out 400ms | 阈值跨过→确认 |
| 水平抖动 | error | ease 300ms | 失败反馈 |
| 按钮按压下沉 | active | spring 250ms | 咬合感 |
| 涟漪扩散 | 按钮点击 | out 500ms | 接触点确认 |
| spinner 旋转 | loading | linear 0.8s | 持续感 |

`prefers-reduced-motion: reduce` 下：所有 animation/transition 降至 0.001ms，呼吸光晕关闭。

## 六、状态机

### ArcUpload（9 态）
rest → hover → focus（Tab，焦点环）→ dragover（实线光圈）→ uploading（determinate 进度）→ success（苔绿+对勾）/ error（砖红+抖动+重试）；disabled（整区灰化 cursor:not-allowed）；empty（列表空状态文案）。

### ArcButton（4 族 × 8 态）
primary / secondary / ghost / danger × rest / hover / focus / active（涟漪+下沉）/ loading（spinner+宽度锁定）/ success（对勾描边）/ error（砖红+抖动）/ disabled。
矩阵区陈列 32 种组合，非展示态按钮点击演示 loading→随机 success/error 流转。

## 七、可配置 CSS 变量（37 个）

:root 暴露 37 个 `--arc-*` 变量（配色/圆角/阴影/时长/缓动/焦点/字体），换肤仅需覆盖这些变量。组件命名空间 `arc-up-` / `arc-btn-`，CSS/JS 以注释块包围可整段抽取。

## 八、健壮性

- 纯 vanilla 单文件，零外部依赖
- 自实现 `safeSetTimeout` / `safeRAF`，`visibilitychange` 暂停/恢复定时器
- `simulateUpload` 内「先清再设」避免快速操作叠加 RAF
- dragover 事件直接操作 class，不走重渲染
- `prefers-reduced-motion` 降级
- 零未定义引用、零 console Error（QA 实测）

## 展区（12 个可亲手把玩装置）

1. Particle Constellation — 180 粒子，引力/斥力/涡旋模式，光标驱动
2. Noise Flow Field — Simplex 噪声向量场 + tracer 粒子，3 预设
3. Text Deconstructor — 逐字符弹簧物理（Hooke 定律）+ 光标排斥
4. Magnetic Deform — 反平方磁吸 + skew/scale 形变
5. Spectrum Analyzer — 模拟频段 + 弹簧阻尼响应
6. CRT Terminal — 扫描线 + 磷光 + 启动序列 + 矩阵雨模式
7. 3D Tilt Card — 透视倾斜 + 光泽扫过，3 深度档
8. Ripple Pool — 点击落波 + 干涉 + 网格背景
9. Presence Pulse — 多层 CSS 环脉冲，3 速度档
10. Signal Typewriter — 变速打字 + 真实 typo/退格
11. Number Counter — 弹簧阻尼计数 + 脉冲
12. Volumetric Light — 径向光柱 + 光标驱动焦点，3 色模式

## 动效原理

基于物理模型：弹簧 Hooke 定律、反平方磁力、阻尼 RAF 积分器；动效周期各不相同。自定义光标开页即显示于屏幕中央，白环 + 彩色内点 + 多层发光，三态悬停切换 + 点击涟漪。

## 健壮性

- 所有 RAF 注册于中央管理器，`visibilitychange` 自动暂停、卸载清理
- 高频 mousemove（倾斜/磁吸/光标）直接操作 DOM transform，不触发重渲染
- 完整支持 `prefers-reduced-motion`
- Preflight PASS：无运行时错误

## 技术栈

纯 vanilla HTML/CSS/JS 单文件（无 React / 无 Babel / 无外部 CDN 依赖）。

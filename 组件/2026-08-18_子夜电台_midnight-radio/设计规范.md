# 子夜电台 · 设计规范

> 日期：2026-08-18 · 方向：V3 UX 交互设计 · 主题：深夜电台播音室拟物化小组件动画实验室

## 色彩系统

胡桃木深棕为底，铜金 + 墨绿天鹅绒 + 暖黄灯光点缀，呼应老式播音室场景语义。禁蓝紫渐变。

| 色值 | 用途 |
|---|---|
| `#0d0a07` / `#1a120b` / `#1a1a1a` | 胡桃木深棕多层（背景/底座/面板） |
| `#c9953a` / `#c47a1a` / `#a67828` / `#8b6332` | 铜金（旋钮/刻度/描边/机械件） |
| `#ffd27a` / `#ffe6a8` / `#fff5d6` / `#e8b860` / `#e8dcc8` / `#d4c4a8` | 暖黄灯光（灯牌/光晕/台灯/稿纸） |
| `#8fffb8` / `#32cd68` / `#6bb890` | 墨绿/荧光绿（VU 表/信号指示） |
| `#ff4d3c` / `#ff6b3c` / `#f5a623` | 霓虹红橙（ON AIR 灯牌/电键火花） |
| `#fff` | 高光/文字 |

## 字体排印

- 正文：`'Noto Sans SC', sans-serif`
- 衬线：`'Noto Serif SC', serif`（展区标题/品牌）
- 等宽：`'Space Mono', monospace`（频率数字/仪表读数）

## 圆角

`1px / 4px / 10px / 12px / 16px / 50%`，机械件偏方正，灯泡/旋钮用 50%。

## 展区（6 个独立拟物装置）

1. 调频旋钮 — 拖拽旋转，物理惯性 + 7 电台磁吸锁定，频率数字实时滚动
2. 音量推子 — 纵向拖拽，阻尼回弹 + VU 电平表实时摆动 + 峰值保持
3. 开播拉杆 — 拖拽/点击切换，霓虹 ON AIR 灯牌点亮 + 红光光晕扩散
4. 黑胶唱机 — 拨杆开关，转盘缓加速至 33⅓ RPM + 唱臂缓缓落下
5. 莫尔斯电键 — 按住/松开，触点火花 + 短按为点·长按为划—
6. 台灯拉绳 — 下拉绳，弹簧阻力 + 咔哒点亮 + 暖光晕染稿纸

## 动效系统

基于物理模型（Hooke 弹簧、惯性动量、磁性反平方吸附、阻尼、摩擦、RAF 积分器）与主题语义（旋钮阻尼/推子惯性/灯牌光晕扩散/转盘缓加速）。组件级特效 16 项：自定义光标 4 态（跟随/悬停放大/拖拽虚线/点击涟漪）、旋钮惯性+磁吸+刻度盘、推子阻尼回弹、VU 表波动+峰值、霓虹发光+光晕扩散、拉杆弹簧回弹、黑胶缓加速+唱臂落下、电键火花+点划识别、灯绳弹簧+台灯渐亮。各动效周期互不相同，禁 Ken Burns。

自定义光标：开页即显示在屏幕中央，高对比（白环+彩色内点+多层发光），z-index 最高；悬停可交互元素放大/变色/三态切换，点击有涟漪。

## 健壮性

纯 vanilla HTML/CSS/JS 单文件（无 React/Babel/CDN 依赖）；`visibilitychange` 暂停 RAF；快速操作先 cancelAnimationFrame 旧循环；高频鼠标事件直接操作 DOM transform；`prefers-reduced-motion` 降级。

## 技术栈

HTML5 + Canvas/SVG + 原生 JS（requestAnimationFrame 物理积分器）。

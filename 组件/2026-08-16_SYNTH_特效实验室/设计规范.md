# SYNTH · 特效实验室 — 设计规范

> 2026-08-16 · UX 交互设计（V3） · 炫技组件特效动画合集

以「组件级特效」本身为展品的交互实验室，6 个展区全部实时鼠标驱动，强调动效的视觉冲击与物理逻辑自洽，而非物理公式演示。

## 配色系统

炭黑底 + 霓虹品红 + 酸橙绿 + 银白的合成器波 / 赛博霓虹风，与本项目其余几套配色互斥、禁蓝紫渐变。

| Token | 值 | 用途 |
|---|---|---|
| `--bg-deep` | `#0a0a0f` | 页面最深层底 |
| `--bg-stage` | `#111118` | 展区画布底 |
| `--bg-panel` | `#16161f` | 侧栏 / 控制面板 |
| `--bg-inset` | `#0d0d13` | 内嵌凹陷区 |
| `--magenta` | `#FF2E9E` | 主强调色（霓虹品红） |
| `--lime` | `#B6FF3C` | 次强调色（酸橙绿） |
| `--silver` | `#E8E8F0` | 银白 / 光标 |
| `--text-primary` | `#E8E8F0` | 主文本 |
| `--text-secondary` | `#8A8A9A` | 次文本 |
| `--text-tertiary` | `#525264` | 三级文本 |
| `--line-subtle/soft/med/strong` | `rgba(232,232,240, 0.06~0.3)` | 四级分割线 |

辉光语义：`--magenta-glow = rgba(255,46,158,0.25)`、`--lime-glow = rgba(182,255,60,0.2)`，用于按钮 hover、选中态、粒子拖尾的 box-shadow / glow。

## 字体

- 全栈统一等宽：`'Courier New', 'Menlo', 'Consolas', monospace`（display / body / mono 共用），强化「实验室仪表」感
- `::selection` 背景 `--magenta`、文字 `--bg-deep`

## 6 个特效展区

| # | 中文 | 英文 | 核心动效 | 交互 |
|---|---|---|---|---|
| 01 | 粒子引力场 | Particle Gravity | 千颗粒子引力分布 + 拖尾流光 | 鼠标吸引聚拢 / 近距排斥飞散 |
| 02 | 噪波流体 | Noise Flow Field | Perlin 噪波驱动流线场 | 鼠标推开流体留涡旋余迹 |
| 03 | 文字解构 | Text Deconstruction | 点阵文字四散飞开 / 弹簧重组 | 靠近爆开、离开回弹复原 |
| 04 | 磁力按钮 | Magnetic Buttons | 按钮被光标磁力吸附形变 | 靠近吸附、悬停发光、磁场环可视化 |
| 05 | 频谱可视化 | Audio Spectrum | 霓虹频谱柱 + 环形放射 + 倒影 | 鼠标高度调振幅、节奏跳动 |
| 06 | 光标拖尾 | Cursor Trail | 钻石形粒子自旋消散星云拖尾 | 移动速度决定生成速率、重力可调 |

每个展区配套：特效介绍（中英标题 + 分类标签）、参数控制（4 项实时滑块）、实时读数（FPS / 粒子总数 / 平均速度 / 交互模式）、操作说明。

## 动效系统（12+ 组件级特效）

1. 自定义光标（银白环 + 品红内点 + 点击涟漪，开页即居中显示）
2. 入场模糊渐入（展区切换位移 + blur + 缩放）
3. 粒子拖尾流光
4. 弹簧回弹（文字解构重组）
5. 磁力形变（按钮吸附位移 + 磁场环纹）
6. 频谱跳动（柱 + 环 + 倒影三联动）
7. 噪波流场（Perlin 矢量场实时绘制）
8. 文字点阵解构 / 重组
9. 扫描线滤镜（CRT 质感叠加）
10. 呼吸光点（状态指示）
11. 磁场环纹扩散
12. 波纹涟漪（点击反馈）
13. 选中态辉光边框 + 内阴影

## 健壮性红线

- 纯单文件 vanilla HTML/CSS/JS，零框架、零外部脚本、零外链（字体用系统等宽），从根上规避妙搭平台 Babel/JSX 白屏问题
- `visibilitychange` 自动暂停 RAF，回前台恢复
- 全部 RAF / 定时器在切换展区 / 卸载时取消，快速操作不叠加定时器
- 高频鼠标事件直接操作 DOM / Canvas，不触发重渲染瓶颈
- 支持 `prefers-reduced-motion`：降级为静态展示，关闭粒子 / 拖尾 / 流场
- 参数滑块均做边界 clamp，避免 NaN / Infinity 导致粒子系统崩溃

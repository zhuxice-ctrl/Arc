# FLUXA 墨流光影实验室 — 设计规范

> 方向：UX 交互设计（V3） · 日期：2026-08-17 · 主题：墨流光影炫技组件特效实验室

## 色彩系统（漆黑鎏金冷青体系）

| 角色 | 色值 | 用途 |
|------|------|------|
| 漆黑 | `#050505` / `#0a0a0a` / `#0c0c0c` / `#151514` | 主背景、深色画底 |
| 鎏金 | `#d4a853` / `#f0d080` / `#9a7a32` / `#5a4520` | 主强调、粒子、光带 |
| 冷青 | `#4ac6c0` / `#7ee8e3` / `#1f6b68` / `#0a1a1a` | 次强调、频谱、光晕 |
| 银白 | `#ffffff` / `#fff` / `#e8e4d8` | 文本、高光 |
| 暗墨绿 | `#1f1e1b` / `#2a2824` / `#5a564a` / `#9a9484` | 次级文本、分隔 |

主色不使用蓝紫渐变；鎏金与冷青在漆黑底上形成「金 + 青」双色辉光锚点。

## 字体

- 标题/品牌：系统无衬线 + 等宽衬线混合
- 数据/参数：等宽字体
- 全部使用系统字体栈，无外部字体引用

## 展区（7 个可把玩装置）

1. 墨流流体场 — 600 粒子在噪声流场流动，鼠标反平方斥力 + 速度切向涡旋，点击注入墨滴爆发
2. 磁力文字解构 — 「墨流光影」像素采样为粒子，鼠标斥力推开、远离胡克定律弹簧归位
3. 光绘丝带拖尾 — 三层加性混合光带 + 头部径向光晕，4 种预设配色切换
4. 音频频谱可视化 — Web Audio 合成 3 首风格化音轨 + 麦克风输入，64 频带柱图带镜像反射
5. 多层视差幻境 — 7 层视差（月亮/远星/近星/远山/近山/孤亭）东方水墨夜境
6. CRT 扫描线画框 — 可调三旋钮（对比度/扫描线/辉光）+ 扫描线 + 荧光闪烁 + 暗角 + 示波器波形
7. 粒子星云引力 — 800 粒子反平方向心吸附 + 点击冲击波扩散

## 动效系统

全部动效基于物理模型：弹簧胡克定律、反平方引力/斥力、阻尼、摩擦、惯性动量、RAF 积分器。自定义光标：三层结构（白粗环 + 鎏金内点 + 冷青外晕），独立惯性系数，悬停放大变色，点击涟漪，z-index 9999。

## 健壮性

- 全局单一 RAF 循环 + 注册表，`visibilitychange` 自动暂停，`beforeunload` 清理
- 切换展区/音轨重建前统一 `clearTimeout` / 断开旧节点
- 高频鼠标事件直接走 transform / Canvas，不触发 setState
- `prefers-reduced-motion` 降级为静态/最小动效 + 粒子数减半
- 零未定义引用（28 个 getElementById 全部命中）
- 纯 vanilla 单文件实现（无 React / 无 Babel / 无外部 CDN 依赖）

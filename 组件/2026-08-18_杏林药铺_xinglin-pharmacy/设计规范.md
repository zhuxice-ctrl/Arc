## 展区结构（6 个光标驱动拟物装置）

| 展区 | 交互 | 物理模型 |
| --- | --- | --- |
| 〇一 · 抽屉药柜 | 拖拽木抽屉向下拉开 | 弹簧回弹 + 阻尼，松手滑回 |
| 〇二 · 戥子秤 | 拖动铜秤砣沿杆移动 | 杠杆力矩平衡 + 角阻尼振荡 |
| 〇三 · 铜铃 | 点击敲击铜铃 | 碰撞 + 衰减振荡 + 音波纹扩散 + WebAudio 铃声 |
| 〇四 · 药碾 | 拖动碾轮在船槽来回滚动 | 摩擦 + 惯性 + 旋转跟随 + 研磨累积 |
| 〇五 · 包药纸 | 点击触发四角折叠 | 错时 3D 翻折 + 药签浮现 |
| 〇六 · 拉绳吊灯 | 下拉绳结过阈值开关灯 | 弹簧回弹 + 暖光扩散 + 咔哒音效 |

## 动效系统（15+ 项）

1. 自定义光标：阻尼跟随 + 悬停放大 + 点击涟漪，开页居中显示
2. 环境灯微摇摆
3. 尘埃粒子飘浮
4. 抽屉弹簧回弹
5. 秤杆力矩振荡
6. 铜铃双振子 + 3 圈音波扩散
7. 碾轮旋转跟随 + 药粉散开
8. 包药纸四角 3D 翻折 + 药签弹出
9. 拉绳回弹 + 灯光扩散
10. 场景整体亮度联动（吊灯开关影响全局）
11. WebAudio 铃声/咔哒音效
12. 拖拽惯性 + 阻尼积分器

动效基于物理模型（弹簧 Hooke / 杠杆力矩 / 碰撞衰减 / 摩擦惯性），周期各不相同。

## 技术栈

纯 vanilla HTML/CSS/JS 单文件（无 React / 无 Babel / 无外部 CDN 依赖）。RAF 统一管理随 visibilitychange 暂停、beforeunload 清理；支持 prefers-reduced-motion 降级；事件委托覆盖动态元素。

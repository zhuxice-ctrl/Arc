# 设计规范 · 文房研物所 Bunbou Lab

> 方向：UX 交互设计（V3） · 日期：2026-08-17 · 主题：拟物化文房微交互实验室

## 色彩系统

深胡桃木 + 黄铜金 + 宣纸白 + 朱砂红的文房器物气质。

| 角色 | 色值 | 用途 |
|------|------|------|
| 深胡桃木（主背景） | `#3D2817` | 页面主底 |
| 胡桃中 | `#5C3E1A` | 卡片/装置底 |
| 黄铜金（主色） | `#8B6030` | 装置主体/边框 |
| 黄铜亮 | `#C49058` | 高光/金属反光 |
| 宣纸白（表面） | `#F6F1E3` | 纸张/浅表面 |
| 宣纸暗 | `#F0E8D3` / `#E5DCC5` | 纸张层次 |
| 朱砂红（强调） | `#B6452F` | 印记/火漆/重点 |
| 朱砂深 | `#8E3524` | 印记阴影 |
| 墨黑 | `#1a1a1a` / `#0a0a0a` | 文字/深底 |
| 炭灰 | `#2a2a2a` | 次级深色 |
| 暖白 | `#FFF9E6` | 高光点 |

## 字体

- 展示字体：衬线（展区标题/古风）
- 正文字体：无衬线（说明文字）

## 组件规范

- 装置容器：圆角 12-16px，胡桃木底 + 黄铜边框，内嵌宣纸表面
- 自定义光标：白色粗环 + 朱砂内点 + 多层发光，z-index 最高
- 展区入场：错峰淡入 + 轻微上移
- 说明文字：宣纸白底卡片，墨黑文字

## 动效系统（12+ 组件级）

1. 自定义光标（惯性缓动 + 悬停态切换 + 点击涟漪）
2. 墨条弹簧回弹（Hooke 定律，松手归位）
3. 墨色渐变 + 涟漪扩散（研磨越久越浓）
4. 印章弹簧回弹
5. 火漆压平形变（按压蜡粒被压扁）
6. 朱砂印记 bloom 拓印动画
7. 纸张震动反馈
8. 毛笔枯湿浓淡笔迹（拖拽速度影响墨量）
9. 镇纸反平方磁吸 + 阻尼振荡
10. 卷轴惯性 + 边界弹簧回弹
11. 火焰多频率叠加摇曳
12. 光晕与阴影实时联动
13. 展区错峰入场动画

## 六件展品

1. 研墨台 — 拖拽墨条研磨，墨色渐浓泛涟漪，松手弹簧回弹
2. 火漆印 — 拖拽印章按压，蜡粒压平，朱砂印记 bloom 拓开
3. 毛笔蘸墨 — 悬停蘸墨，宣纸上拖动画出枯湿浓淡笔迹
4. 镇纸磁吸 — 拖拽宣纸，镇纸反平方磁吸，松手阻尼振荡归位
5. 卷轴展开 — 拖拽轴杆横向展开山水画卷，惯性阻尼 + 边界弹簧
6. 铜油灯 — 拨动灯杆点亮，火焰多频率摇曳，光晕阴影联动

## 健壮性

- 纯 vanilla 单文件实现（无 React / 无 Babel / 无外部 CDN）
- RAF/定时器随 `visibilitychange` 暂停，卸载统一清理
- 拖拽重建前取消旧循环
- 支持 `prefers-reduced-motion` 降级

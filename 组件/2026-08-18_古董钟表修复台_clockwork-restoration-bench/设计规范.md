## 字体

- 标题：衬线体（思源宋体 / Noto Serif SC），serif 类
- 说明文字：无衬线体（系统默认）

## 展区结构（6 个展区）

1. **发条旋钮** — 顺时针拖拽上发条，阻尼随张力增大，上满后释放机芯级联转动
2. **摆轮调校** — 拖拽摆轮后松手，Hooke 定律 + 阻尼自由摆动衰减，快慢针调节频率
3. **齿轮咬合** — 拖拽齿轮到正确位置，磁力吸附（反平方引力）咬合，齿轮链联动
4. **游丝盘绕** — 沿螺旋路径拖拽游丝末端，贝塞尔曲线跟随，完成后弹性回弹
5. **指针调校** — 拖拽时/分/秒针，磁性归位到最近刻度，指针联动
6. **放大镜检视** — 光标移动放大镜在机芯上滑行，2× 放大 + 光影质感

## 组件规范

- 展区卡片圆角：12px
- 交互元素圆角：50%（圆形）/ 8px（方形）
- 展区间距：24px
- 工作台木纹：linear-gradient 多层棕色渐变

## 动效系统

| 序号 | 动效名称 | 物理模型/语义 |
|------|---------|-------------|
| 1 | 自定义光标 | 白环+黄铜金内点+发光，悬停变放大镜形态 |
| 2 | 发条阻尼旋转 | 阻尼物理模型，张力越大阻力越大 |
| 3 | 摆轮自由摆动 | Hooke 定律弹簧 + 阻尼衰减 |
| 4 | 齿轮磁力吸附 | 磁性反平方引力模型 |
| 5 | 游丝贝塞尔跟随 | 贝塞尔曲线 + 弹性回弹 |
| 6 | 指针磁性归位 | 磁性吸附到最近刻度 + 联动 |
| 7 | 放大镜区域放大 | CSS transform scale + clip-path |
| 8 | 台灯光晕偏移 | 背景光源随光标微微偏移 |
| 9 | 齿轮 RAF 积分器 | 物理转动积分 |
| 10 | 拖拽涟漪 | CSS ripple animation |
| 11 | 悬停工具发光 | box-shadow hover |
| 12 | 展区错峰淡入 | CSS animation delay |

## 健壮性

- 纯 vanilla HTML/CSS/JS 单文件实现（无 React / 无 Babel / 无外部 CDN）
- requestAnimationFrame 随 visibilitychange 暂停，beforeunload 清理
- 快速操作不叠加定时器：重建前先 clearTimeout/cancelAnimationFrame
- 高频鼠标事件直接操作 DOM transform
- 支持 prefers-reduced-motion 降级

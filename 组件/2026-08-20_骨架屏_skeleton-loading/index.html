用法

组件以纯 CSS + 原生 JS 实现，零依赖，可独立抽取至任意项目。

一、快速开始

从本文件中复制 /* Skeleton 组件 CSS */ 与 /* Skeleton 组件 JS */ 两个注释块之间的全部代码，放入你的项目。

import { createSkeleton } from './skeleton.js';

const sk = createSkeleton({
  target: document.getElementById('my-content'),
  load: fetchData,        // 返回 Promise 的加载函数
  template: [
    { type: 'row', items: [
      { type: 'circle', size: 48 },
      { type: 'col', flex: 1, gap: 8, items: [
        { type: 'text', width: '60%' },
        { type: 'text', width: '40%', height: 12 },
      ]},
    ]},
    { type: 'text', lines: 3, gap: 8 },
  ],
});

// 手动触发加载
sk.load();

// 销毁
// sk.destroy();

二、配置项

参数类型默认值说明
target HTMLElement 必填 骨架屏挂载的容器元素。
load Function 必填 数据加载函数，需返回 Promise。resolve 时进入 success，reject 进入 error。
template Array [] 骨架模板声明，由图元节点（text / circle / rect / image / row / col / grid）组合而成。
renderContent Function null 数据加载成功后，接收数据并返回 HTML 字符串或 DOM 节点，渲染到内容层。
autoLoad Boolean true 是否在创建后立即触发加载。
minDuration Number 0 骨架最少展示时长（毫秒），避免瞬时闪烁。
onStateChange Function null 状态变化回调，参数为 (state, data?)。
emptyText Object { title, desc } 空状态下的标题与描述文案。
errorText Object { title, desc, retry } 错误状态下的文案与重试按钮文字。

三、图元节点类型

类型属性说明
text width / height / lines / gap 文本行。lines 为行数，多行时末行宽度自动缩减为 60%。
circle size 圆形占位，常用于头像、图标。
rect width / height / radius 矩形块，用于卡片、图片、按钮等。
image width / height / ratio 图像块，可设置宽高比。
row items / gap / align / justify 横向排布容器，包裹子图元。
col items / gap / flex 纵向排布容器，包裹子图元。
grid columns / gap / items 网格容器，columns 可为数字或 CSS 模板字符串。

五、状态与方法

状态机：loading → success / error / empty，可由 load() 重新进入 loading。

实例方法：

  • sk.load() — 重新触发加载，回到 loading 状态。
  • sk.setState(state, payload?) — 手动设置状态（'loading' | 'success' | 'error' | 'empty'）。
  • sk.getState() — 获取当前状态。
  • sk.destroy() — 销毁实例，清理 DOM 与事件监听。

可访问性：容器自动设置 role="status"、aria-live="polite"，加载时 aria-busy="true"；错误状态下重试按钮 Tab 可达，焦点环可见。

六、抽取与复用说明

本 HTML 文件由三部分组成：

  1. 组件 CSS（可抽取） — 以 /* 【可抽取】Skeleton 组件 CSS · 开始 */ 与 · 结束 */ 为界，复制到项目的 CSS 文件。
  2. 组件 JS（可抽取） — 以 /* 【可抽取】Skeleton 组件 JS · 开始 */ 与 · 结束 */ 为界，可保存为 skeleton.js 并以 createSkeleton 导出。
  3. 演示页面（可删除） — 其余 CSS / HTML / JS 仅为演示与文档，抽取组件时可全部移除。

组件不依赖任何框架或外部库，在 IE11+ 及所有现代浏览器中可用。

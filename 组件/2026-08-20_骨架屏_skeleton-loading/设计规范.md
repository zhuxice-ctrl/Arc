# 骨架屏 Skeleton · 设计规范

> 2026-08-20 · V3 实用可复用 UI 组件 · 反馈类

## 一、组件定位

生产级**异步加载反馈组件**——「占位的艺术」。核心价值不是画几个灰色条，而是完整的异步体验闭环：声明式骨架模板 + loading→success/error/empty 三向状态流转 + shimmer 扫光。开发者把 `createSkeleton()` 包在任意异步区块外层，传入模板与数据 Promise，即可获得带状态播报、可重试、可降级的加载体验。

演示场景：**中文城市天气面板**（杭州 / 成都 / 厦门可切换），用四种不同布局区块（主卡 / 指标网格 / 逐时条 / 五日列表）验证骨架模板的表达力。

## 二、Design DNA

- **核心概念**：骨架是内容的影子——占位的形状必须镜像真实内容的布局结构，让加载到成功的过渡「无缝」。
- **视觉来源**：宣纸式暖白底 + 墨色骨架灰，克制无装饰；shimmer 扫光如纸面被光线扫过。
- **空间逻辑**：inline 组件展示纵向场景——组件是主角，场景是配角。
- **色彩逻辑**：米白底 + 深林绿主色 + 琥珀金点缀，骨架灰为暖中性；**无蓝紫渐变**。
- **动效语义**：shimmer 用 `linear` 1.6s 循环（持续加载感），内容淡入 `ease-out` 260ms（轻盈收束）；`prefers-reduced-motion` 时降级为静态骨架 + 直接显隐。

## 三、色彩系统（CSS 变量，可整块覆盖主题）

| 变量 | 值 | 用途 |
|---|---|---|
| `--sk-bg` | `#F6F3EC` | 页面底色（米白） |
| `--sk-base` | `#E5E1D8` | 骨架基色（暖灰） |
| `--sk-shine` | `#F1EEE6` | shimmer 扫光高亮 |
| `--sk-shine-edge` | `#EAE7DC` | 扫光边缘过渡 |
| `--sk-fg` | `#1C4A3C` | 主色（深林绿，文字/图标） |
| `--sk-muted` | `#6B7A70` | 次级文字 |
| `--sk-accent` | `#C98A2D` | 点缀（琥珀金） |
| `--sk-error` | `#A83F3F` | 错误态文字 |
| `--sk-error-bg` | `#F4E2E2` | 错误态底色 |
| `--sk-ring` | `rgba(28,74,60,0.35)` | 焦点环 |

共 **20 个** `--sk-*` 变量（含 radius / 文本尺寸 / gap / duration / easing / fade 等）。

## 四、字体

系统无衬线（`-apple-system, "PingFang SC", "Microsoft YaHei", sans-serif`），中文为主；大温度数字用 tabular-nums 等宽对齐。无外部字体。

## 五、动效系统

| 效果 | 时长 | 曲线 | 触发 |
|---|---|---|---|
| shimmer 扫光循环 | 1.6s | `linear` | loading 态持续 |
| 内容淡入 | 260ms | `ease-out` | loading→success |
| 重试按钮聚焦环 | 即时 | — | error 态自动聚焦 |
| reduced-motion 降级 | — | — | 关闭扫光，直接显隐 |

## 六、状态机

```
loading ──→ success（真实内容淡入）
   │
   ├──→ error（错误面板 + 可键盘重试，自动聚焦）
   │        └── 重试 ──→ loading …
   │
   └──→ empty（空状态插画文案）
```

覆盖：loading / success / error / empty / hover / focus / active / disabled（≥8 态）。

## 七、可访问性

- 容器 `role="status"` + `aria-live="polite"`，状态变化播报
- loading 时 `aria-busy="true"`
- 重试按钮 Tab 可达，焦点环可见，error 态自动聚焦
- `prefers-reduced-motion` 自动降级

## 八、工程边界

- 纯 vanilla 单文件，零 CDN / 外部字体 / 外部图片
- 组件 CSS / JS 以注释明确标出抽取边界，可整块复制
- 定时器 / 监听器在 `destroy()` 中清理
- 工厂 API：`createSkeleton({ target, template, load, onStateChange })`，实例方法 `load()` / `setState()` / `getState()` / `destroy()`

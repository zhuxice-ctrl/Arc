## 展区结构（6 个可上手操作的特效装置）

1. EX-01 Phosphor Decay 磷光拖尾：光标划过留下指数衰减发光残影，可调半衰期 / 粗细 / 双色模式
2. EX-02 CRT Filter 扫描线滤镜：实时扫描线 + 滚动电子束 + 噪声 + 暗角，参数可调
3. EX-03 Halftone 半调网点：磷光点阵构成图像，鼠标靠近推开形变
4. EX-04 ASCII Stream 字符流场：伪噪声流场驱动字符漂浮，光标扰动流场
5. EX-05 Chromatic Glitch 色差故障字：RGB 通道分离 + 随机切片，越靠近越剧烈
6. EX-06 Magnetic Fluid 磁流体 Metaballs：SVG goo filter，可拖拽融合、点击生成、双击删除

全局叠加：CRT 扫描线 + 暗角 + 随机闪烁；顶部导航锚点滚动高亮。

## 动效系统（12+ 组件级）

- 自定义光标：白环 + 磷光绿内点 + 多层发光，开页即居屏幕中央，悬停变色，点击涟漪
- 磷光指数衰减粒子（主题语义：荧光粉余晖）
- 扫描线滚动 + 电子束 + 噪点 + 随机闪烁（主题语义：电子束扫描 / 信号干扰）
- 网点形变、流场扰动、RGB 通道分离、切片 glitch 爆发
- Metaballs 液滴融合（goo filter 物理感粘连）
- 标题 glitch、导航高亮过渡
- 各动效周期独立、不整齐划一

## 健壮性

- 纯 vanilla 单文件：无 React / 无 Babel / 无外部 CDN 依赖，从根本规避白屏
- 所有 RAF 循环纳入统一注册器，`visibilitychange` 自动暂停 / 恢复，`beforeunload` 统一销毁
- 高频鼠标事件直接操作 DOM / canvas
- `prefers-reduced-motion` 降级为静态占位
- 响应式：≤900px 单列布局

## 技术栈

纯原生 HTML / CSS / JavaScript 单文件，Canvas 2D + SVG filter，零外部依赖。

## 字体系统

- `"Noto Serif SC", "Songti SC", "STSong", serif` —— 展区标题，宋体温润
- `"ZCOOL XiaoWei", "Noto Serif SC", serif` —— 装饰性手写标题

## 圆角

金属件 `8px`、卡片 `12px`、便签 `4px`、灯泡 / 阀门 `50%`。

## 展区结构（6 个拟物化装置）

1. **燃气灶旋钮** —— 点击点火"嗒"声感 + 拖拽旋转调 0–6 档火力 + 蓝色火焰多层闪烁呼吸
2. **铜壳水龙头** —— 旋转阀门控制水流 + 水滴粒子下落 + 水槽涟漪扩散 + 水位上升
3. **发条计时器** —— 向上拖拽上弦蓄力（0–60 分钟刻度）+ 指针倒走 + 到时铃响震动
4. **胡椒研磨器** —— 按住顶盖画圈旋转 + 木材质感 + 胡椒颗粒重力洒落（上限 30 颗）
5. **冰箱磁贴便签** —— 3 张便签可拖拽 + 松手弹簧回弹磁吸归位 + 双击翻面
6. **吊绳拉灯** —— 下拉超过阈值触发开关 + 灯泡点亮 + 暖光扩散 + 墙面阴影变化

每个展区有场景叙事文案（如"汤还温着"），中文为主。

## 动效系统

自定义光标（白环 + 暖黄内点 + 多层发光，悬停变形、点击涟漪、拖拽变虚线环，开页居中）、火焰多层呼吸、水流粒子、涟漪扩散、弹簧回弹（Hooke）、磁吸归位、颗粒重力洒落、发条蓄力倒走、灯光扩散与阴影、便签翻面、展区入场渐入、暖光呼吸、拖拽惯性阻尼。12+ 组件级特效，基于物理模型。

## 健壮性

- 全局 RAF 管理器：页面隐藏自动暂停、恢复续播、卸载统一取消
- 所有定时器重建前先 clear，无叠加
- 高频鼠标事件直接操作 DOM transform
- `prefers-reduced-motion` 完整降级
- 响应式：3 列 → 2 列 → 1 列
- 零未定义引用

## 技术栈

纯 vanilla HTML/CSS/JS 单文件实现，无 React / 无 Babel / 无外部 CDN 依赖。

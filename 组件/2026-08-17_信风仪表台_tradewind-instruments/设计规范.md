# 信风仪表台 Tradewind Instruments · 设计规范

> 日期：2026-08-17 · 方向：V3 UX 交互设计 · 主题：光标驱动的拟物化航海气象仪表交互实验室

## 色彩系统（黄铜航海仪表）

| 角色 | 色值 | 用途 |
|---|---|---|
| 黄铜金 | #B8860B | 主色 / 仪表外壳 / 刻度 / 光标 |
| 浅金 | #C9A96E / #d4a85a | 高光 / 拨杆 / 旋钮面 |
| 亮金 | #e8c878 | 反光 / 受光面 |
| 深铜 | #8a6220 / #7a5a18 / #5a4010 | 阴影 / 暗部 / 凹槽 |
| 朱红 | #C0392B | 指针 / 警示 / 强调点 |
| 墨绿 | #1F3A2E / #152a20 | 台面底色 / 场景背景 |
| 象牙白 | #F5EFE0 | 读数面板 / 刻度文字 / #8a7a5a 次中性 |

- 半透明衍生：`rgba(0,0,0,.3~.7)` 用于台面阴影与凹刻；`rgba(184,134,11,.3~.6)` 黄铜光晕；`rgba(255,220,150,.5)` 暖光反射；`rgba(100,160,200,.1)` 海景冷调点缀。
- 全局禁用蓝紫渐变；以黄铜金 + 墨绿 + 朱红构建航海仪表质感。

## 字体

- 仪表刻度 / 读数：`"Georgia", serif`
- 中文场景文字：`"Songti SC","STSong","Noto Serif SC",serif`

## 圆角

- 仪表盘外缘：10–12px
- 读数面板 / 凹槽：2–8px
- 微刻度：1–3px
- 异形圆角：`2px 2px 18px 18px / 2px 2px 12px 12px`（仪表底座弧形）

## 五件拟物微交互装置

1. 风向标 — 拖拽红色指针，八方位磁吸归位带弹簧回弹；风车叶片转速随风向角度动态变化。
2. 气压计 — 上下拖动铜质拨杆，水银柱高度联动，柱面高光随高度移动，松手弹簧回弹到整 5 刻度。
3. 雨量计 — 点击翻斗倒水，水位上涨、水面涟漪扩散、雨滴洒落动画，累计翻斗次数。
4. 温湿度双金属片 — 拖动旋钮左右滑动，金属片 SVG 路径实时弯曲形变（冷上弯 / 热下弯），温度湿度双读数联动。
5. 雾度计 — 旋转黄铜旋钮调节雾浓度，内置海景场景中帆船与太阳的可见度、模糊度实时渐变，棘轮刻度吸附。

## 动效系统（18 项）

光标跟随 + 悬停/拖拽态 + 点击涟漪 + 风车旋转 + 磁吸弹簧回弹 ×3 + 水银柱反光 + 水位波纹 + 雨滴下落 + 涟漪扩散 + 翻斗翻转 + 双金属片弯曲 + 雾层渐变 + 船体淡出 + 场景模糊 + 水面波动 + 指针闪光。

- 物理模型：磁吸归位 = 整数刻度吸附 + 弹簧（Hooke + 阻尼）回弹 RAF 积分器；拨杆 = 惯性 + 阻尼；双金属片 = SVG 路径随滑块线性插值形变。
- 健壮性：`visibilitychange` 暂停 RAF；拖拽状态统一管理无叠加定时器；支持 `prefers-reduced-motion`；纯 vanilla 单文件，无外部依赖。

## 页面结构

自定义黄铜光标 → 木纹台面弧形陈列 → 五件仪表装置（风向标 / 气压计 / 雨量计 / 双金属片 / 雾度计）横向排布，每件独立可操作，含场景叙事与读数。

## 技术栈

纯 vanilla HTML/CSS/JS 单文件（无 React / 无 Babel / 无外部 CDN 依赖），SVG + Canvas + DOM transform 实现拟物质感。

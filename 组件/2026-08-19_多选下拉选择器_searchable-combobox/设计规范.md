# 设计规范 · 可搜索多选下拉选择器

> 2026-08-19 · V3 交互组件 / 输入类

## 1. 配色系统

暖米纸质底色 + 墨青主操作色 + 陶土赭选中色，无蓝紫渐变。全部通过 CSS 变量暴露于 `:root`。

## 2. 字体

系统无衬线栈，中文优先：

```
-apple-system, BlinkMacSystemFont, "PingFang SC", "Microsoft YaHei", "Segoe UI", sans-serif
```

- 正文字号：`--mc-font: 15px`
- 芯片字号：`13px`
- 分组标签：`11px`（大写、字间距 `.08em`）
- 选项 meta：`12px`
- 代码块：`ui-monospace, SFMono-Regular, monospace`

## 3. 动效系统

### 时长

| 变量 | 值 | 用途 |
|------|-----|------|
| `--mc-d-fast` | `120ms` | 高亮跟随 / hover / 小按钮 |
| `--mc-d` | `200ms` | 浮层淡入 / chevron 旋转 / 边框过渡 |
| `--mc-d-slow` | `320ms` | 芯片弹入弹簧过冲 |

### 缓动

| 变量 | 值 | 语义 |
|------|-----|------|
| `--mc-ease` | `cubic-bezier(.4,0,.2,1)` | 标准缓动（浮层、边框、chevron） |
| `--mc-spring` | `cubic-bezier(.34,1.56,.64,1)` | 弹性过冲（芯片弹入、勾选缩放） |

### 关键动画

| 动画 | 触发 | 参数 |
|------|------|------|
| 芯片弹入 | 选中选项 | `mc-chip-in 320ms spring`：translateY(6px)scale(.85) → 0,scale(1) |
| 浮层展开 | 打开浮层 | `opacity 200ms ease + translateY(-6px)scale(.98) → 0,scale(1)` |
| chevron 旋转 | 打开/关闭 | `transform rotate(180deg) 200ms ease` |
| 勾选缩放 | 选项选中 | `opacity 0→1 + scale(.6)→scale(1) 120ms spring` |
| 高亮跟随 | 键盘/鼠标移动 | `background 120ms ease` |
| spinner 旋转 | 异步加载 | `mc-spin .8s linear infinite` |

### prefers-reduced-motion

```css
@media (prefers-reduced-motion: reduce){
  *,*::before,*::after{
    animation-duration:.001ms !important;
    animation-iteration-count:1 !important;
    transition-duration:.001ms !important;
  }
  .mc-chip{ animation:none; }
  .mc-spinner{ animation:mc-spin 1.2s linear infinite; } /* spinner 保留但减速 */
}
```

## 6. 状态机（9 态）

| 状态 | 触发 | 视觉 |
|------|------|------|
| closed | 初始 | 灰描边 + placeholder |
| hover-field | 鼠标悬停字段 | 强描边 |
| focus | Tab 聚焦 | 墨青描边 + 3px soft 光环 |
| open | 点击/Enter/↓ 展开 | 墨青描边 + 浮层 + chevron 旋转 |
| loading | 异步 loader 调用中 | 浮层内 spinner + "正在加载选项..." |
| error | loader reject | 浮层内错误图标 + "加载失败" + 重试按钮；关闭后字段红边框 |
| empty | 过滤无匹配 | 浮层内搜索图标 + "无匹配项" + 上下文提示 |
| disabled | config.disabled=true | 灰底 + opacity .62 + cursor not-allowed + tabindex=-1 |
| selected-pop | 选中选项 | 芯片弹入字段（spring 过冲）+ 勾选缩放 + aria-live 播报 |

## 7. 命名空间

- CSS 类前缀：`.mc-*`（mc = multi-combobox）
- BEM 风格：`.mc-field`、`.mc-chip`、`.mc-chip-x`、`.mc-panel`、`.mc-opt`、`.mc-opt-label`、`.mc-opt-meta`、`.mc-state`、`.mc-retry`
- JS 工厂函数：`createMultiCombobox(selector, config)`
- CSS 变量前缀：`--mc-*`
- ID 前缀：`mc{n}-field`、`mc{n}-panel`、`mc{n}-search`、`mc{n}-list`、`mc{n}-active`

## 8. 技术栈

- 纯 vanilla HTML + CSS + JS，零依赖
- 无 React / Babel / CDN / 外部字体
- CSS 自定义属性（变量）主题化
- IIFE 封装 + 工厂函数模式
- WAI-ARIA combobox + listbox 多选模式

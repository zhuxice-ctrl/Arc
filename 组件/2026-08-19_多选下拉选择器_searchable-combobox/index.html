可搜索多选下拉选择器

生产级表单选择组件：键入实时过滤、回车选中变芯片弹入字段、异步加载与失败重试、无匹配空态、分组、清空，完整 ARIA combobox 键盘模式。纯 vanilla 单文件，CSS 变量主题化，复制两段代码即可用。

主示例 · 多选 + 分组

选择负责的城市

multiple · grouped · searchable

点击或 ↓ 展开，键入"杭"过滤，↑↓ 移动，Enter 选中，Backspace 删末个芯片，Esc 关闭。

状态机演示

异步加载

async · loading → loaded

展开后模拟 1.2s 网络请求，浮层内显示 spinner，加载完成展示选项。

加载失败 · 重试

async · error → retry

展开后模拟请求失败，显示错误态与"重试"按钮，点击重试后成功。

禁用态

disabled

字段置灰、不可聚焦展开，展示 disabled 视觉。

单选模式

single · clearable

单选：选中后字段直接显示值，再次点击同项可取消，X 清空。

用法文档

组件自包含：一段 CSS（.mc-* 命名空间）+ 一段 JS（createMultiCombobox 工厂函数）。抽到别的项目改不超过 3 处即可用。

1. HTML 结构

<div class="mc-wrap" id="my-wrap"></div>

2. 初始化

createMultiCombobox('#my-wrap', {
  multiple: true,      // false = 单选
  searchable: true,    // 是否可键入过滤
  clearable: true,     // 是否显示清空按钮
  grouped: true,       // 是否按 group 分组
  placeholder: '请选择...',
  options: [
    { value:'hz', label:'杭州', group:'华东', meta:'0571' },
    { value:'sh', label:'上海', group:'华东', meta:'021' },
    // ...
  ]
});

3. 异步模式

createMultiCombobox('#wrap', {
  multiple: true,
  async loader(query) {
    const res = await fetch('/api/cities?q=' + query);
    if (!res.ok) throw new Error('fail');
    return await res.json(); // [{value,label,group,meta}]
  }
});

传入 loader 即进入异步模式：展开时调用 loader('')，键入时防抖调用 loader(query)。抛错自动进入 error 态并显示重试按钮。

4. 可配置 CSS 变量（节选）

--mc-primary
焦点环 / 主操作色（默认墨青 #2f5d54）
--mc-accent
选中 / 高亮色（默认陶土 #c25a36）
--mc-surface
字段与浮层表面色
--mc-line
描边色
--mc-field-h
字段高度
--mc-r-md
主圆角
--mc-d
过渡时长
--mc-panel-max-h
浮层最大高度

共暴露 30+ CSS 变量，覆盖颜色 / 圆角 / 时长 / 阴影 / 尺寸，改 :root 即全局换肤。

5. 键盘操作

  • Tab 聚焦字段；Enter / Space / ↓ 展开浮层
  • 键入字符实时过滤；↑ ↓ 移动高亮；Enter 选中/取消
  • Backspace（搜索框为空时）删除最后一个芯片
  • Esc 关闭浮层；Tab 离开组件
  • 芯片 X、清空按钮均可 Tab 聚焦并 Enter 触发

6. 文件说明

  • index.html —— 单文件，含组件 CSS + JS + 展示页
  • 组件 CSS 区段（.mc-*）可整段剪切独立使用
  • 组件 JS 区段（createMultiCombobox）可整段剪切独立使用
纯 vanilla 单文件 · 无 React / Babel / CDN · 支持 prefers-reduced-motion · ARIA combobox + listbox

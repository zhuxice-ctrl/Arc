## 色彩系统

| 令牌 | 色值 | 用途 |
|------|------|------|
| 虚空黑 | `#0d0d0d` | 主背景 |
| 深灰 | `#141414` | 卡片背景 |

## 动效系统

| # | 动效 | 物理模型 / 语义 |
|---|------|----------------|
| 1 | 按键涟漪爆炸 | Canvas 同心圆 + 阻尼衰减 + 随机三色 |
| 2 | 图标变形矩阵 | SVG path morphing + spring easing |
| 3 | 键盘频谱柱弹起 | spring 物理模型（stiffness + damping） |
| 4 | 开关连锁反应 | BFS 扩散 + 100ms 层级延迟 |
| 5 | 进度环过渡 | stroke-dasharray + ease-out-back |
| 6 | 文字粒子解构 | 重力 + 初速度 + 旋转 + 回收重组 |
| 7 | 标题呼吸发光 | 周期性 box-shadow 脉冲 |
| 8 | 柱顶发光渐变 | 品红→青柠→冰白渐变 |
| 9 | 开关光晕 | 品红 box-shadow glow |
| 10 | 100% 完成脉冲 | 环形发光 + 对勾 morph |
| 11 | 涟漪干涉 | 多涟漪叠加视觉效果 |
| 12 | 防重复叠加 | 动画完成前锁定 |

## 六个展区

1. **按键涟漪爆炸** — 按键/点击触发同心圆涟漪扩散，随机三色，带干涉效果
2. **图标变形矩阵** — 4 组 SVG 图标 path morphing（播放↔暂停、汉堡↔关闭、加↔减、心↔碎心）
3. **键盘频谱可视化** — 12 根柱条对应 A-L 键，spring 物理弹起
4. **开关连锁反应** — 5×5 网格 BFS 扩散切换
5. **进度环剧场** — 三环嵌套（品红/青柠/冰白），目标进度按钮
6. **文字粒子解构** — "KEYPULSE" 炸开成粒子后回收重组

## 健壮性

- 所有 RAF 由统一 `rafCallbacks` 管理，`visibilitychange` 暂停、`beforeunload` 取消
- 级联定时器每次重建前清除旧定时器
- 文字粒子动画防重复叠加（等完成后才能再次触发）
- 支持 `prefers-reduced-motion` 降级
- 纯 vanilla HTML/CSS/JS 单文件，无 React/Babel/CDN 依赖

## 技术栈

HTML5 + CSS3 + Vanilla JS + Canvas API + SVG，单文件 `index.html`

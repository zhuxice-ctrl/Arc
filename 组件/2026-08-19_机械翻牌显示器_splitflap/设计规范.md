# 设计规范 · 机械翻牌显示器

## 主题概念

以老式车站时刻牌的机械翻牌显示器（split-flap display）为核心展品。用户拖拽分页鼓（split-flap drum）旋转，翻牌在 180° 半翻时显示下一字符，松手后弹簧物理将鼓吸附到最近字符位。每次翻牌触发 WebAudio 咔哒声——还原机械时刻牌的触感与声感。

## 动效系统

### 核心：翻牌物理引擎（requestAnimationFrame）

| 机制 | 实现方式 |
|------|---------|
| 拖拽旋转 | mousedown/mousemove → angle 累加，直接操作 DOM transform |
| 惯性 | 松手后 velocity 衰减（friction 系数） |
| 弹簧吸附 | velocity 归零后 spring 力将 angle 拉向最近字符位 |
| 半翻显示 | angle 每经过 180° 触发一次翻面，显示下一字符 |
| 咔哒声 | 每次半翻触发 WebAudio createOscillator 短脉冲 |
| 余震 | @keyframes aftershock，翻牌到位后微小震颤 |

### 5 层反馈体验

1. 预接触：光标接近翻牌鼓时光标变为 grab 形态
2. 接触：按下时光标变 grabbing，鼓面微亮
3. 持续：拖拽中鼓实时跟随光标，翻面咔哒声持续
4. 阈值：每 180° 翻面瞬间，咔哒声+视觉闪动
5. 释放/衰减：松手后惯性旋转→弹簧吸附→余震

## 自定义光标

圆形光标，默认态小圆点，接近翻牌鼓时变为 grab 形态（张开手），拖拽中变为 grabbing（握拳）。开页即居中显示，高对比白色，z-index 最高。

## WebAudio 声效

11 处 AudioContext 调用：createOscillator + createGain 构建短促咔哒声。每次翻牌半翻触发一个 20-40ms 的方波脉冲，频率随机微变以模拟机械不规则性。

## 布局结构

- 中央：大型翻牌鼓（可拖拽旋转，显示当前字符）
- 上方：字符序列指示器（显示当前位/总位）
- 下方：操作提示+物理参数说明
- 背景：暗色金属质感+黄铜边框装饰

## 技术栈

纯 vanilla 单文件 HTML+CSS+JS，无 React/Babel/CDN 依赖。requestAnimationFrame 物理引擎（velocity/friction/spring）。WebAudio API 咔哒声效。CSS 3D transform（rotateX）实现翻牌半翻。

## 展区设计（6 个展区）

### 1. 水面焦散
- 机制：2D 波动方程 + 梯度幅值焦散模拟
- 交互：鼠标移动产生涟漪，光线穿过涟漪形成焦散光纹
- 物理模型：波动方程数值积分

### 2. 棱镜折射
- 机制：Snell 定律色散，7 段光谱分解
- 交互：滑块调入射角 / 光束宽 / 折射率
- 物理模型：Snell 定律 + 色散率

### 3. 光池汇聚
- 机制：1200 粒子 + 反平方引力 + 阻尼
- 交互：移动鼠标吸引光子，实时显示粒子数/平均速度/聚焦亮度
- 物理模型：磁性反平方引力 + 阻尼

### 4. 彩虹散色
- 机制：色相循环 + 屏幕混合色带扩散
- 交互：拖拽绘制色带，悬停也留轻痕
- 物理模型：色相空间映射 + 屏幕混合模式

### 5. 光线隧道
- 机制：30 环透视 + 弹簧形变 + 惯性速度
- 交互：滚动驱动穿越，速度越快环越形变
- 物理模型：弹簧 Hooke 定律 + 惯性动量

### 6. 扫描线焦散
- 机制：4 种模式（正弦/噪波/网格/分形）逐行显影
- 交互：右侧面板切换模式，已显影区域缓慢衰减
- 物理模型：逐行扫描 + 衰减函数

## 健壮性

- 单 RAF 主循环 + IntersectionObserver 分区激活（非可见区不跑计算）
- `visibilitychange` 自动暂停/恢复
- `prefers-reduced-motion` 全量降级
- 无外部依赖、无 React/Babel/CDN
- 移动端响应式适配

## 技术栈

纯 vanilla HTML/CSS/JS 单文件实现，无 React/无 Babel/无外部 CDN 依赖。Canvas 2D API + requestAnimationFrame + IntersectionObserver。

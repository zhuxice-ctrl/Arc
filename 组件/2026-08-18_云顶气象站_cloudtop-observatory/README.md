# 云顶气象站 · 拟物化仪器交互实验室

> 日期：2026-08-18 · 方向：V3 UX 交互设计 · 主题：光标驱动的拟物化气象仪器小组件动画

## 简介

「云顶气象站」是一件艺术品级的 UX 交互设计 mock，场景叙事为一座海拔 3000 米的山巅气象观测站，值班员用老式仪器工作。六个展区各为一个独立的、有场景叙事的拟物化微交互装置，核心是鼠标光标悬停/移动/点击/拖拽触发的细腻微交互。配色以黄铜金 + 墨黑 + 仪表米白为主，信号红做警示点睛，禁用蓝紫渐变。纯 vanilla 单文件实现，零外部依赖。

## 六个展区装置

1. 百叶箱照明拉绳灯——拖拽自然下垂拉绳点亮灯泡，光线扩散 + 阴影变化
2. 风向罗盘——拖拽旋转风向标，惯性 + 阻尼回摆
3. 水银气压表——磁吸指针跟随光标偏转，点击切换晴雨，玻璃光泽扫过
4. 昼夜观测切换滑杆——拖动太阳/月亮滑块切换昼夜，星空云朵渐变
5. 信号旗绞盘——旋转绞盘升旗，绳索联动 + 旗帜飘动
6. 雨量筒倾倒——点击倾倒雨水，液体流动 + 刻度归零

## 动效亮点

自定义光标三态（默认/抓手/点击）+ 涟漪 + 发光光晕，开页居中显示。12+ 项动效：灰尘粒子、3D 倾斜、视差、弹簧回弹、惯性阻尼旋转、磁吸偏转、玻璃光泽、星空闪烁、旗帜飘动、液面波动、下雨粒子、数字实时读数。全部基于弹簧/惯性/阻尼/磁吸物理模型。

# 云顶气象站 · 设计规范

> 日期：2026-08-18 · 方向：V3 UX 交互设计 · 主题：拟物化气象仪器交互实验室

## 色彩系统

| 角色 | 色值 | 用途 |
|---|---|---|
| 墨黑（底色） | #191712 / #242019 | 页面主背景，山巅夜色 |
| 仪表米白 | #EFE7D6 / #F0F0F0 | 仪器面板、表盘底色 |
| 黄铜金 | #B98A3E / #FFB347 | 金属部件、边框、绞盘 |
| 暖灯黄 | #FFE4A0 / #FFE066 / #FFC970 | 灯泡发光、暖光晕染 |
| 信号红 | #D8452C | 警示标记、信号旗 |
| 铜绿 | #2D4A27 / #4E7A6A | 仪器金属氧化色、植物点缀 |
| 深褐 | #2E2820 | 次级面板、木质纹理 |

配色层次：墨黑山巅夜色为底，黄铜金串联全部金属仪器，暖灯黄做光晕焦点，信号红做单一警示点睛，铜绿做植物/氧化质感。整体黄铜 + 墨黑仪表盘调性，与 V1（盐白珊瑚橙）、V2（苔藓绿米白）互不雷同。

## 字体系统

- 正文：`var(--font-body)`（系统无衬线）
- 标题/品牌：`var(--font-display)`（衬线，营造老式仪表铭牌质感）
- 数字/读数：`var(--font-mono)`（等宽，模拟仪表刻度读数）

## 组件规范（6 个拟物化展区装置）

1. **百叶箱照明拉绳灯**：自然下垂拉绳（重力 + 弹簧回弹），拖拽点亮白炽灯泡，光线扩散 + 箱内阴影变化
2. **风向罗盘**：拖拽旋转风向标，惯性 + 空气阻尼回摆，指针带动方位刻度联动
3. **水银气压表**：磁吸式指针跟随光标偏转，点击切换晴雨预测，表盘玻璃光泽扫过
4. **昼夜观测切换滑杆**：拖动太阳/月亮滑块切换白昼与夜空，窗外景色、星空闪烁、云朵随状态渐变
5. **信号旗绞盘**：旋转黄铜绞盘摇柄升旗，绳索联动 + 旗帜飘动 + 到位咔哒感
6. **雨量筒倾倒**：点击拿起雨量筒倾倒，液体物理流动 + 刻度归零后下雨重新积攒

每个展区必须用鼠标光标上手操作（悬停/点击/拖拽）才有意义。

## 动效系统（12+ 项）

自定义光标（三态：默认/悬停可拖拽变抓手/点击，涟漪 + 发光光晕，开页居中显示）、灰尘粒子漂浮、滚动渐入、卡片 3D 倾斜、Hero 视差、弹簧物理回弹、惯性阻尼旋转、磁吸指针偏转、玻璃光泽扫过、星空闪烁、旗帜飘动、液面波动、下雨粒子、数字实时读数。

物理模型：弹簧 Hooke（拉绳/回弹）、惯性动量 + 空气阻尼（罗盘回摆）、磁性反平方引力（气压表指针）、RAF 积分器（液体流动/粒子）。

## 健壮性

- 纯 vanilla HTML/CSS/JS 单文件实现，零外部依赖（无 React / 无 Babel / 无 CDN）
- 统一 RAF 动画循环 + `visibilitychange` 自动暂停
- `prefers-reduced-motion` 降级
- 光标 DOM 直操不触发重渲染
- 零未定义引用

## 页面结构

单页滚动叙事：Hero 标题（气象站铭牌）→ 六个拟物化展区装置依次排列 → 每个展区独立场景叙事 + 物理微交互。

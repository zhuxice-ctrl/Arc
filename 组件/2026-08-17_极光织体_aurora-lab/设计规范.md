# AURORA 极光织体实验室 · 设计规范

> 方向：V3 UX 交互设计｜日期：2026-08-17｜主题：极光/极夜视觉母题炫技特效实验室

## 色彩系统

| 角色 | 色值 | 用途 |
|---|---|---|
| 主背景（极夜墨黑） | `#0A0F0D` | 全站底色 |
| 次背景 | `#0E1613` / `#13201A` / `#08100E` | 面板分层 |
| 极光绿 | `#4DFFB8` | 主强调、极光帘幕、光标内点、粒子 |
| 品红 | `#FF3E8A` | 副强调、磁光丝带、全息扫描 |
| 冰青 | `#7FE7E0` | 辅助、星轨、冰晶 |
| 银白高光 | `#FFFFFF` / `#E8F5F0` | 文字、辉光、星点 |

配色互斥：极夜墨黑+极光绿+品红+冰青的冷冽极光体系，与当日 V1（浓墨+朱砂+鎏金暖皮影）、V2（深青+沙金+珊瑚橘赶海）完全区隔，无蓝紫渐变。

## 字体栈

系统等宽/无衬线栈，强调实验室仪表感。

## 展区结构（6 个独立可上手把玩装置，均 Canvas 2D 实时渲染 + 鼠标驱动）

1. 极光帘幕 Aurora Curtain — 多层噪声场极光带，横拖控风向、纵拖控褶皱强度
2. 星轨拖尾 Star Trails — 按住拖动绘长曝光星轨，松手缓慢消隐
3. 磁光丝带 Ribbon Field — 22 条 Verlet 积分丝带跟随鼠标缠绕流动
4. 冰晶生长 Frost Bloom — 点击生成分形冰花，蔓延后缓慢融化
5. 辉光粒子流 Particle Stream — 3000 粒子沿流场奔涌，鼠标形成斥力漩涡
6. 全息扫描 Hologram Scan — 扫描线逐行点亮文字，带雷达环 + 故障抖动

每个展区配独立 3 项控制滑杆（强度/速度/密度），展区切换 canvas 模糊淡出转场，键盘 1–6 快速切换。

## 动效系统（12+ 组件级）

1. 自定义光标（白环 + 极光绿内点 + 多层发光，开页居中，hover 放大变色，点击涟漪）
2. 极光帘幕噪声场动画
3. 星轨长曝光拖尾
4. Verlet 丝带物理流场
5. 分形冰晶生长
6. 冰晶融化消隐
7. 粒子流场奔涌
8. 鼠标斥力漩涡
9. 全息扫描线逐行点亮
10. 雷达环扫描
11. 故障抖动 glitch
12. 展区切换模糊淡出 + 面板位移
13. 控制滑杆交互反馈

动效基于物理模型（Verlet 积分、流场、分形）与主题语义（极光/星轨/冰晶/全息），均为纯视觉炫技组件特效，非物理公式演示；周期各异。

## 健壮性

纯 vanilla 单文件（无 React / 无 Babel / 无外部 CDN 依赖），一次成功无白屏；`requestAnimationFrame` 随 `visibilitychange` 自动暂停/恢复，`pagehide` 统一清理；每个展区独立动画循环、切换时取消旧循环；`prefers-reduced-motion` 降级。

# PHOSPHOR 磷光实验室 · 设计规范

> 日期：2026-08-17　方向：V3 UX 交互设计
> 实现：纯 vanilla HTML/CSS/JS 单文件，无 React / 无 Babel / 无外部 CDN 依赖

## 色彩系统（暗色荧光实验室）

| 角色 | 色值 | 用途 |
|---|---|---|
| 底·玄黑 | `#0C0C0E` | 页面主底 |
| 深灰 | `#141418` / `#1A1A20` | 卡片/展区表面 |
| 主光·磷光黄绿 | `#D4FF3F` | 主辉光、粒子、强调 |
| 辅光·珊瑚粉 | `#FF6B8A` | 次辉光、对比强调 |
| 珊瑚粉亮 | `#ffd4dc` | 高光、涟漪 |
| 银灰 | `#C9CCD3` | 正文、次要文字 |
| 中灰 | `#6B6F7A` | 说明文字 |

> 发光通过多层 box-shadow / canvas 辉光叠加实现；不用蓝紫渐变。

## 字体

- 等宽：`'Courier New', ui-monospace, monospace`（实验室仪表盘质感）

## 七件互动装置（每件上手操作才有意义）

1. 磷光拖尾 — 鼠标轨迹余晖衰减（alpha 衰减积分）
2. 粒子星尘 — 反平方斥力场 + 弹簧恢复 + 连线
3. 磁力文字解构 — 字母被光标吸引形变 + 色相漂移
4. 频谱辉光柱 — 4 种模式切换（wave/pulse/chaos/peak）
5. CRT 扫描线滤镜 — 密度/辉光双滑块实时调节 + 文字轮播
6. 余晖涟漪 — 点击扩散阻尼波纹 + 环境自发涟漪
7. 流体辉光 — 噪波流场粒子轨迹 + 鼠标搅动

## 组件级特效（12+）

自定义光标（三环 + 发光 + 悬停变色 + 点击涟漪）、hero 频谱可视化（鼠标交互）、数字计数、打字机轮播、3D 卡片倾斜、滚动渐入、视差大字、光泽扫过按钮、品牌脉冲、环境背景粒子、CRT 闪烁、弹簧物理。

## 动效逻辑

- 拖尾/涟漪：alpha 衰减积分（阻尼）
- 粒子星尘：磁性反平方斥力 + 弹簧恢复（Hooke）
- 文字形变：磁力吸引 + 色相漂移
- 频谱：procedural 生成多模式波形
- 流体：噪波流场向量场驱动粒子轨迹
- 严禁整图缩放 / Ken Burns；各装置周期不同

## 健壮性

- 所有 RAF 循环注册到统一调度器，visibilitychange 自动暂停/恢复
- 鼠标高频事件直接操作 DOM transform，无 setState
- prefers-reduced-motion 降级
- 移动端禁用自定义光标与倾斜
- 单文件 vanilla，从根本上规避 JSX/Babel 白屏

## 页面结构

单页实验室：Hero（品牌 + 频谱可视化）→ 7 件装置展区纵向排列，每展区独立 canvas / DOM 装置 + 操作控件。

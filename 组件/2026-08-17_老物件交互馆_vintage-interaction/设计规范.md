## 组件规范

- **展区面板**：深胡桃木背景 + 暖焦糖边框，12px 圆角，内含标题 + 场景描述 + 交互区
- **自定义光标**：白色粗环 + 琥珀内点 + 多层发光，z-index 99999，三态切换（默认/hover/拖拽）
- **拉绳开关**：SVG/Canvas 弹簧链模拟下垂曲线，拖拽有阻力感
- **日夜滑块**：渐变天空背景 + 云朵/星星粒子，滑块带惯性
- **留声机**：CSS 旋转唱片 + 拖拽唱臂 + 音波波纹扩散
- **拨号转盘**：旋转拖拽 + 惯性回弹 + 棘轮震动
- **弹簧门挡**：SVG 螺旋弹簧 + 拖拽弯曲 + 阻尼振荡
- **温度旋钮**：旋转拖拽 + 5° 棘轮吸附 + 刻度点亮 + 背景渐变

## 动效系统（12+ 组件级特效）

| 动效 | 实现方式 | 说明 |
|------|----------|------|
| 自定义光标 | mousemove → DOM transform | 白环+琥珀点+发光，三态切换 |
| 光标点击涟漪 | CSS animation + 动态元素 | 点击时扩散圆环 |
| 光标 hover 放大 | CSS transition | 悬停可交互元素时光标放大变色 |
| 光标拖拽态 | mousedown/mouseup 切换 | 拖拽时光标旋转变形 |
| 灯泡光线扩散 | CSS box-shadow + opacity | 点亮时光锥从灯泡向下扩散 |
| 阴影变化 | CSS filter/box-shadow | 灯光开关时周围物体阴影变化 |
| 日夜渐变过渡 | CSS transition + gradient | 天空从蓝天到星空渐变 |
| 星星闪烁 | CSS @keyframes + 随机延迟 | 夜空星星明灭 |
| 云朵飘动 | CSS @keyframes translate | 白天云朵水平移动 |
| 唱片旋转 | CSS @keyframes rotate | 黑胶持续旋转，放唱臂时加速 |
| 音波波纹 | CSS @keyframes scale + opacity | 从唱片中心扩散的波纹 |
| 惯性滑动 | requestAnimationFrame + 物理 | 滑块释放后继续滑+回弹 |
| 棘轮吸附 | 角度取整 + snap | 旋钮每 5° 一个吸附点 |
| 弹簧弯曲 | SVG path 动态计算 | 拖拽时弹簧路径弯曲 |
| 阻尼振荡 | requestAnimationFrame + 衰减 | 弹簧释放后来回摆动逐渐停止 |
| 弹性回弹 | requestAnimationFrame + 弹簧物理 | 拨号盘释放后带回弹回转 |
| 震动反馈 | CSS transform 微抖动 | 棘轮到位时轻微震动 |

## 展区结构（6 个独立展区）

1. **拉绳灯开关** — 弹簧链下垂 + 拖拽点亮灯泡 + 光线扩散 + 阴影变化
2. **日夜切换滑块** — 拖拽滑块切换昼夜 + 天空渐变 + 星空/云朵
3. **留声机唱臂** — 拖唱臂到唱片 + 音波扩散 + 转速变化
4. **拨号电话转盘** — 旋转拨号 + 惯性回弹 + 棘轮震动
5. **弹簧门挡** — 推弯弹簧 + 阻尼振荡 + 摆幅衰减
6. **温度调节旋钮** — 旋转旋钮 + 棘轮吸附 + 刻度点亮 + 背景渐变

## 健壮性

- 纯 vanilla HTML/CSS/JS 单文件实现（无 React / 无 Babel / 无外部 CDN 依赖）
- requestAnimationFrame 随页面可见性暂停，卸载取消
- 快速操作不叠加定时器（重建前先 clearTimeout/cancelAnimationFrame）
- 高频鼠标事件直接操作 DOM transform
- 支持 prefers-reduced-motion：降级为静态或最小动效
- 零未定义引用

# SANDFLOW 沙画流体实验室 · 设计规范

- 日期：2026-08-17
- 方向：V3 UX 交互设计 · 炫技组件特效实验室（纯 vanilla 单文件）

## 色彩系统（暗夜沙丘系）

| 角色 | 色值 | 用途 |
|------|------|------|
| 炭黑底 | `#14100C` / `#1a130c` / `#1c1610` / `#0a0806` | 页面底、展区卡底 |
| 琥珀金（主色） | `#E8A33D` | 光标内点、沙粒高亮、强调 |
| 燃珊瑚（强调） | `#E4574C` / 深阶 `#c93a30` | 拖尾循环色、警示、扰动着色 |
| 沙米 | `#F2E3C6` | 正文、沙粒基础色 |
| 暗铜 | `#8C5A2B` / `#2a1e14` | 描边、分区、次级面 |
| 石绿（墨滴三色之一） | `#4a7c59` | 墨滴展区石绿墨 |

无蓝紫渐变。

## 字体

- 全局 UI：`Helvetica Neue` / PingFang SC / Microsoft YaHei
- 圆角：展区卡 11px，小控件 6px，胶囊 100px，圆形 50%

## 展品（6 个特效展区，12+ 组件级特效）

1. **沙粒流场**：≤12000 粒子受鼠标速度场推动 + 摩擦衰减；按住堆沙（高度场累积）、松开流平（扩散）、双击撒沙；色彩随速度米黄→琥珀
2. **墨滴晕染**：徽墨 / 朱砂 / 石绿三色；多尺度 Perlin 噪声径向晕染 + 纸张纤维扩散；新旧墨 alpha 融合
3. **磁力字阵**：SANDFLOW 文字像素采样为字符粒子；反平方排斥 + Hooke 弹簧阻尼回位；位移越大越偏珊瑚色
4. **频谱沙柱**：64 根沙柱伪频谱（多频正弦 + 噪声 + 低频加权）；鼠标扫过激励冲高；点击触发双向波浪传播
5. **流场流线**：50×36 格点噪声向量场；200 条流线粒子生灭；鼠标制造切向漩涡 + 发光衰减轨迹
6. **扫描线视窗**：CRT 扫描线 + 辉光 + 色差；手写 3D 投影沙漏线框（13 环 × 16 段）+ 内部落沙；拖动改自转、滚轮调扫描线密度

## 全局组件

- 自定义光标：白环 + 琥珀核心 + 发光，开页即居中，z-index 99999；悬停形态变化、点击涟漪
- 霓虹拖尾缎带：40 点历史插值 ribbon mesh，宽度随速度，琥珀/珊瑚/米白循环，静止收束
- 「拾荒者模式」彩蛋：导航开关，全部展区叠加沙暴颗粒滤镜

## 健壮性

- 纯 vanilla 单文件，零外部依赖（无 React / Babel / CDN）
- `visibilitychange` 全局暂停 + IntersectionObserver 展区级启停 rAF；`beforeunload` 统一清理
- 高频 mousemove 直写 canvas / DOM；`prefers-reduced-motion` 降档（粒子减档、拖尾关闭）
- Canvas 随 resize 重建；离屏静止区域自动休眠

# 深夜电台 · 老式收音机工作台 — 设计规范

- 日期：2026-08-18
- 方向：V3 UX 交互设计（光标驱动的拟物化小组件实验室）
- 主题：老式电子管收音机 / 深夜电台
- 实现：纯 vanilla HTML/CSS/JS 单文件，无 React / Babel / 外部 CDN 依赖

## 色彩系统（胡桃木 + 黄铜 + 电子管辉光）

| 角色 | 色值 | 用途 |
|---|---|---|
| 深木色 | `#2C1F16` / `#1a110a` / `#2b1d12` | 机身底色 |
| 胡桃木 | `#4A3226` / `#3a281d` / `#5C3E2E` | 面板 / 木纹层次 |
| 黄铜 | `#C9A227` / `#8a7235` | 旋钮、拉绳、金属件 |
| 墨绿辉光 | `#24423C` | 魔术眼电子管 |
| 暖橙 | `#E8A54B` | 指示灯、刻度盘背光 |
| 奶白 | `#F2E8D5` / `#d9ccb3` | 刻字、刻度 |
| 朱砂红 | `#c0392b` | VU 表红区、警示 |

禁止蓝紫渐变。

## 字体

- 数字 / 频率显示：`"Courier New", monospace`（等宽，模拟数码管）
- 中文 UI：`"PingFang SC", "Microsoft YaHei", sans-serif`

## 展区结构（6 个拟物化微交互装置）

1. 拉绳电源开关：拖拽黄铜拉绳过阈值后咔哒回弹，整机通电、暖光渐亮、刻度背光扩散
2. 魔术眼电子管：绿色辉光随信号强弱开合，扇形张角与阴影三角实时响应
3. 调谐旋钮 + 刻度盘：竖向拖拽旋转、刻度带横移、惯性续转、靠近电台磁吸
4. 波段拨杆：MW / FM / SW 三档，弹簧回弹 + 触点微震，指示灯与刻度盘联动
5. 音量旋钮 + VU 表头：表针随音量 + 信号摆动，带过冲回弹与红区刻度
6. 天线伸缩杆：向上拖拽 5 节铜管依次伸出，信号强度与魔术眼联动

每个装置均有场景叙事，必须光标悬停 / 点击 / 拖拽上手操作。

## 光标系统

白色粗环 + 暖橙内点 + 多层发光，开页即居屏幕中央；悬停变黄铜色放大、拖拽变绿色虚线环、点击涟漪扩散。

## 物理引擎

RAF 积分器实现 Hooke 弹簧 / 惯性动量 / 阻尼摩擦；各装置动效周期各异、不整齐划一。

## 健壮性

- `visibilitychange` 自动暂停 RAF，卸载统一取消
- 快速操作不叠加定时器（先清旧再建新）
- mousemove 直操作 DOM transform
- 支持 `prefers-reduced-motion` 降级
- 无外部依赖，零白屏风险

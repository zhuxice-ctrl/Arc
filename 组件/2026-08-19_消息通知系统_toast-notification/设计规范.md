# Toast 通知系统 · 设计规范

## 组件定位

反馈类可复用 UI 组件。解决真实项目中消息通知的队列管理、自动消失、悬停暂停、滑动关闭需求。非物理演示装置，可直接 copy-paste 到任意项目使用。

## 动效系统

| 动效 | 时长 | 缓动函数 | 语义 |
|------|------|----------|------|
| 入场（appear） | 400ms | `cubic-bezier(0.34, 1.56, 0.64, 1)` | 弹簧过冲，通知从右侧滑入 |
| 退场（dismissing） | 300ms | `ease-out` | 向右滑出 + 淡出 |
| 队列位移（shift） | 200ms | `ease-out` | 通知消失后下方平滑上移 |
| 进度条（progress） | 与 duration 同步 | `linear` | 匀速递减，RAF 驱动 |
| 滑动回弹（swipe back） | 300ms | `cubic-bezier(0.34, 1.56, 0.64, 1)` | 未超阈值时弹簧回弹 |
| 状态过渡 | 150ms | `ease` | hover、focus 等微交互 |
| 主题切换 | 300ms | `ease` | 背景色、文字色过渡 |

### prefers-reduced-motion 降级
所有动画时长降级为 `0.01ms`，功能不受影响。

## 状态机（7 态）

| 状态 | 视觉表现 | 触发条件 |
|------|----------|----------|
| appear | 从右侧滑入，弹簧过冲 400ms | 新通知创建 |
| visible | 正常显示，进度条匀速递减 | 入场动画结束 |
| paused | 进度条冻结，显示暂停图标 | 鼠标悬停 / 页面不可见 |
| dismissing | 向右滑出 + 淡出 300ms | 倒计时结束 / 手动关闭 / 滑动超阈值 |
| queued | `display: none`，逻辑等待 | 超出 maxVisible |
| max-reached | 底部药丸提示"还有 N 条待显示" | 队列非空 |
| disabled | 全部灰化 + 不可交互 | 调用 Toast.disable() |

## 左侧色条

4px 宽，按严重级别着色，贯穿 Toast 左边缘全高。

## 图标

28×28px 圆角方块，背景为对应级别色的 12% 透明度（`color-mix(in srgb, <color> 12%, transparent)`），文字为对应级别色。

## 代码架构

- **CSS**：所有组件样式以 `.toast-` 前缀命名，通过 `/* === Toast Component === */` 注释与展示页样式分隔
- **JS**：`ToastManager` 类封装在 IIFE 中，挂载到 `window.Toast`，通过 `/* === Toast Component === */` 注释与展示页逻辑分隔
- **可抽取性**：复制 `.toast-` 前缀的所有 CSS + `ToastManager` 类即可独立使用，展示页代码不需要

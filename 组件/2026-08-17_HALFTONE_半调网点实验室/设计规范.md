# HALFTONE 半调网点实验室 · 设计规范

> 日期：2026-08-17 ｜ 方向：V3 UX 交互设计 ｜ 主题：印刷半调网点（Halftone）炫技特效实验室

## 色彩系统（CMYK 印刷气质）

| 角色 | 名称 | 色值 |
|------|------|------|
| 主背景 | 纸白 paper | `#FAF8F2` |
| 次背景 | 米白 | `#F2EFE5` |
| 主文字/深底 | 墨黑 ink | `#141414` |
| 次深底 | 深灰 | `#2A2A2A` |
| 品牌强调 | 品红 magenta | `#E6007E` |
| 品牌强调 | 青 cyan | `#00A0AF` |
| 辅助 | 黄 | `#F5C518` |

配色互不雷同于当日 V1（雪白+朱红+木金）与 V2（米白+石墨+荧光橙）。

## 字体

- 等宽展示：系统等宽 / mono（网点编号、参数标签）
- 衬线/无衬线由系统栈兜底，强调印刷工业感

## 圆角

装置卡片直角为主（印刷硬边），少量 4–8px 圆角辅助。

## 展区结构（9 大展区 + 全局特效）

| # | 展区 | 装置 |
|---|------|------|
| 00 | HERO | SVG 半调网点标题 + 呼吸脉冲 + 滚动渐入 |
| 01 | 网点发生器 | 实时调节线数/网角/网点大小/墨色 + 鼠标引力形变 |
| 02 | 抖动算法集 | Floyd-Steinberg / Bayer / Atkinson 三算法对照 + 3D 倾斜 + 光泽扫过 |
| 03 | CMYK 分色叠加 | 四色半调网版 + 乘法混色 + 独立开关 |
| 04 | 网点流场 | 噪声流场粒子 + 鼠标扰动 + 拖尾轨迹 |
| 05 | 磁力形变 | 反平方引力 + 弹簧回弹 + 阻尼 |
| 06 | 印刷数据 | 弹簧缓动数字计数（四色四数） |
| 07 | 网点诗篇 | 打字机逐字输出 + 光标闪烁 |
| 08 | 视差层叠 | 三层网点不同速率视差 |
| 09 | 声音成像 | 64 根频谱柱（四色分区）+ Play/Pause/Reset |

全局：自定义光标（白粗环 + 品红内点 + 光晕 + 悬停形变 + 点击涟漪）、侧栏圆点导航 + IntersectionObserver 激活态。

## 动效系统（12+ 组件级特效）

呼吸脉冲、滚动渐入、鼠标引力形变、3D 倾斜、光泽扫过、CMYK 乘法混色切换、噪声流场粒子、拖尾轨迹、反平方磁力 + 弹簧阻尼、弹簧数字计数、打字机、三层视差、频谱可视化。均基于 RAF 积分器/物理模型/主题语义，周期各不相同。

## 健壮性

- 纯 vanilla HTML/CSS/JS 单文件，无 React / 无 Babel / 无外部 CDN 依赖
- RAF 统一管理（`RAFS` Set）、定时器统一管理（`TIMERS` Set）
- `visibilitychange` 自动暂停、`prefers-reduced-motion` 降级
- 高频 mousemove 直接操作 transform，无 setState

## 技术栈

纯原生 HTML/CSS/JS 单文件，零外部依赖。

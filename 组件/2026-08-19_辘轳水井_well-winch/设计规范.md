# 设计规范 · 辘轳水井（拟物化机械组件实验室）

> 类别：组件/交互实验室　日期：2026-08-19
> 形态：纯 vanilla 单文件交互组件（光标驱动）

## 设计母题
一口老井上的木制辘轳——摇动曲柄把水桶从井底摇上来，扳开棘爪它就掉回井底。整页只此一件装置，做到极致。方向：机械结构 + 材质表现（木/水/石）。

## 装置结构
青砖井台 → 井体（井水青绿，越下越暗）→ 木架辘轳 → 横向滚轴 + 棘轮棘爪 + 操作摇柄 → 吊桶绳索 → 木质水桶（桶内水体可晃动）。侧边竖排标注「交互组件 · V3」「拟物装置」。

## 动效系统（RAF 物理驱动，无 CSS keyframe）
源码无 `@keyframes`——全部运动由 requestAnimationFrame 物理模型驱动，符合组件协议「高频输入直接操作 DOM、不走重渲染」：
- **角速度 + 摩擦阻尼**：曲柄拖多远转多远，松手惯性衰减。
- **棘轮档位吸附**：每过一齿「咔哒」一档（音 + 棘爪微弹），棘爪防倒转。
- **绳缠绕/松脱**：绳圈数随转动增减，桶随绳长升降。
- **阻尼弹簧余震**：扳开棘爪后桶自由落体，曲柄被绳带着倒转飞旋，余震衰减。
- **水体单摆晃动**：桶内水随加速度倾斜摆动；桶到井口时水微微晃出溢流。
- **水花粒子 + 涟漪**：仅坠落落井瞬间产生，与输入有因果（非装饰）。
- 自定义光标三态（默认/握持曲柄/扳棘爪），开页居中高对比层级最高。

## 五层反馈链
1. pre-contact：hover 曲柄 → 柄头发光、光标变手型。
2. contact：抓住瞬间阻尼吸附感。
3. continuous：逐帧转角跟手、绳逐圈缠绕、棘轮咔哒。
4. threshold：桶到井口溢流（完成）/ 扳开棘爪（逆转触发）。
5. release/decay：桶坠落、曲柄倒转惯性衰减、水花涟漪渐隐。

## 核心交互
1. 拖拽曲柄旋转（持续输入，角速度跟手）。
2. 扳动/点击棘爪杆 → 桶自由落体坠落、曲柄倒转、闷响水花。
- Signature Moment：摇到井口后扳开棘爪，桶带着绳呼啸坠回井底、闷响水花溅起。
- 禁键盘操作、禁物理公式演示、禁多组件堆叠。

## 技术栈
- 纯 vanilla 单文件（HTML+CSS+JS，无 React/Babel/CDN/外部图片），SVG 绘制装置。
- RAF 主循环，页面不可见时暂停、卸载取消；快速操作不叠加定时器；`prefers-reduced-motion` 降级；零未定义引用、零 Console 严重错误。
- 经 Browser QA：1440/800 渲染正常、截图非空白、无 console severe。共 17+ 组件级特效。

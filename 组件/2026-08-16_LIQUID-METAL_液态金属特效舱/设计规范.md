## 主题

液态金属 / 汞银 / 镜面流动的物理特性实验室

## 配色

深石墨黑 #1a1a1a + 镜面银 #c0c0c8 + 电弧青 #00d4ff

（严格禁蓝紫渐变）

## 字体

系统无衬线 + 等宽字体

## 动效设计

水银合并场 / 磁引力液 / 液态涟漪 / 熔融滴落 / 金属熔字 / 铬合金频谱

## 技术实现

- 单文件 HTML 实现（CSS + JS 全内联）
- 自定义光标开页即居中显示
- RAF 统一管理，visibilitychange 自动暂停/恢复
- 支持 prefers-reduced-motion 降级
- 无外部 JSX 引用，无外部本地文件依赖

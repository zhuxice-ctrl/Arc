# 舂米臼 — 设计规范

> 抓住木杵往上提，提得越高越沉手；松手砸进石臼，谷壳裂开，米粒溅起。

## 主题与概念

- **主题**：农家舂米——木杵与石臼的体力活
- **核心概念**：一个可反复把玩的拟物化舂米装置。拖拽木杵提升（重力随高度增加）、松手自由落体砸入石臼、臼体受冲击下沉回弹、米粒受击溅射、谷壳裂纹随舂击次数累积——五层反馈还原「舂」的手感。
- **交互隐喻**：实体劳动的「坠手感」被翻译成拖拽阻力与冲击反馈，不是物理公式演示，是体力模拟器。

## 色彩系统（源码实测）

| 谷壳金 | `#d4a84a` | 谷粒、壳裂高光 |
| 原木 | `#a67c4e` / `#9c6a35` / `#6b4420` | 木杵杆身三阶明暗 |

配色纪律：大地色系——米、木、石三色构成全部视觉，无蓝紫渐变。

## 交互机制（五层反馈）

1. **pre-contact**：光标接近木杵握柄，握痕高亮提示可抓
2. **contact**：抓住瞬间「坠手」——木杵微微下沉，光标切换为握紧形态
3. **continuous**：提升阻力随高度递增（提得越高越沉），杵身微颤
4. **threshold**：提升到裂壳线以上，谷壳裂纹预告可见
5. **release**：松手自由落体 → 砸入石臼冲击 → 臼体下沉回弹 → 米粒溅射 → 弹跳衰减至静止 → 尘雾弥散

计数器记录舂击次数，谷粒随次数逐步脱壳成米。

## 动效系统（组件级，≥12）

握痕高亮、抓住坠手、提升微颤、阻力递增、落体加速、臼体冲击下沉、臼体回弹、米粒抛物溅射、米尘雾弥散、壳裂纹理出现、舂击计数跳动、光标握合形变。

## 自定义光标

- 开页即显示于屏幕中央，高对比，层级最高
- 常态为手形，接近握柄变「可抓」，抓住变「握紧」

## 技术栈

- **纯 vanilla 单文件** `index.html`（40KB），无 React / Babel / CDN
- Canvas 2D 渲染 + 自绘物理：gravity / velocity / bounce / damping
- RAF 主循环，`visibilitychange` 时暂停、卸载取消
- `prefers-reduced-motion` 降级：溅射与颤动减弱，保留核心反馈

## 健壮性

- 零未定义引用、零 Console Error（Browser QA 实测）
- 快速连续抓放不叠加定时器（状态机单一所有权）
- 高频鼠标事件直接写 Canvas，不经框架重渲染

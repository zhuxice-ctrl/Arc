# 设计规范 · 黄铜蒸汽控制室 Brass Steam Control

> 日期：2026-08-17 · 方向：V3 UX 交互设计 · 主题：复古蒸汽朋克控制室面板（光标驱动拟物化微交互实验室）

## 六个展区（光标驱动拟物化装置）

1. **蒸汽压力表** — 光标悬停表盘附近，压力随距离升高，指针按弹簧阻尼模型摆动
2. **铜制转盘阀** — 拖拽旋转，松手吸附最近六档止点，金属卡位回弹手感
3. **电报电键** — 点击/按下铜键，火花闪烁，短按「·」长按「—」实时输出摩尔斯码
4. **拉绳吊灯** — 向下拖拽拉绳，超过阈值触发开关，松手弹簧回弹 + 阻尼单摆，灯泡暖光扩散
5. **三档拨杆** — 上下拖拽黄铜手柄，松手吸附最近档位，对应指示灯点亮
6. **磁吸指南针** — 光标产生反平方衰减磁场，指针受吸引偏转，距离越近偏转越强

## 动效系统（12+ 项）

自定义光标双环跟随 + 三态切换 + 点击涟漪、压力针弹簧阻尼、阀盘六档吸附、电键回弹 + 电火花、拉绳弹簧回缩 + 单摆阻尼 + 灯泡辉光、拨杆三档吸附 + 指示灯、磁针磁场偏转。全部基于弹簧/阻尼/反平方引力等物理模型，周期各不相同。

## 技术栈

纯 vanilla HTML/CSS/JS 单文件，零外部依赖。visibilitychange 自动暂停 RAF，beforeunload 统一清理，mousemove 只改 transform 不触发重渲染，prefers-reduced-motion 降级静态。

# 机械刀闸开关 · 设计规范

## 主题
光标驱动的拟物化机械刀闸开关——老式工厂配电箱刀闸，推拉手柄越过机械死点，双稳态吸合 + 电弧 + 仪表响应。

## 设计母题
机械双稳态开关——设计语言来自老式工厂铸铁配电箱与黄铜刀闸。核心机制为**双向双稳态越过死点**，区别于历史单向连续拖拽。

## 字体系统
- 系统 sans-serif（-apple-system 等），中文为主
- 极少文案：铭牌「主电源」、状态「合闸/断电」、操作提示「按住手柄·越过死点·听咔嗒」
- 仪表刻度数字

## 物理模型
双稳态势能阱：U(x)=0.5k(x²-1)²，F=-dU/dx。两稳定位为势能最低点，死点为势能峰。
- 手柄位置 x 用 RAF 实时积分（velocity += F*dt; x += velocity*dt）
- 拖动时手柄跟随光标但有阻尼；越接近死点阻力越大
- 越过死点后弹簧加速到位
- 到位撞击余震：振幅指数衰减振荡
- 仪表指针：二阶阻尼系统，合闸后从 0 阻尼振荡上升到读数，断电后衰减回 0

## 反馈七层
1. pre-contact：光标接近手柄，手柄微颤 + 光标颤动，暗示可抓
2. contact：抓住瞬间咬合感，手柄紧贴光标
3. continuous：推拉阻力随位置变化，越近死点越慢
4. threshold：越过死点阻力骤降，弹簧吸合 + 电弧粒子迸发
5. completion：到位咔嗒（面板震动 + 余振），指示灯亮 + 仪表指针摆起
6. release：松手稳定在新位
7. decay：仪表指针阻尼振荡余振衰减

## 视觉表现
铸铁拉丝面板 + 四角铆钉，黄铜刀闸手柄 + 黑色绝缘瓷座，红/绿指示灯，电压表（0~300V）+ 电流表（0~60A）圆形指针仪表，珐琅铭牌。合闸时灯亮 + 指针摆起 + 电弧 + 光影变化。

## 自定义光标
绝缘手套造型，悬停/抓取/拖拽三态形变，开页居中，高对比层级最高。支持 prefers-reduced-motion 降级。

## 技术栈
纯 vanilla 单文件 HTML（SVG + Canvas 绘制，零外部图片/CDN）。RAF 随 visibilitychange 暂停、beforeunload 清理。快速推拉不叠加定时器，高频 pointer 事件直接操作 DOM。支持 prefers-reduced-motion。

# 设计规范 · 区间滑块 Range Slider

> 生产级双滑块区间选择器 UI 组件 · 2026-08-19 · V3 交互组件

## 1. 组件定位

双滑块区间选择器（Dual Range Slider）。两个可拖动手柄共享一条轨道，选取 `[min, max]` 数值区间。解决真实界面刚需：价格筛选、时间区间、人数/年龄范围、双阈控制。设计目标是「copy-paste 进任何项目、改不超过 3 处 CSS 变量即可换肤直接用」。

## 2. 配色系统（非蓝紫渐变）

| 用途 | 变量 / 色值 | 说明 |
|------|------------|------|
| 页面底 | `#F6F2E9` 宣纸米白 | 低饱和暖白，不抢组件 |
| 文字主 | `#22281F` 墨色 | 高对比正文 |
| 主色 | `#1F3D33` 松烟墨绿 | 轨道填充、手柄边框、主按钮 |
| 主色 hover | `#284D40` | 深一档绿 |
| 强调 / 焦点 | `#D97B3F` 赭橙 | 焦点环、错误提示、强调按钮 |
| 卡片底 | `#FFFFFF` | 组件容器 |
| 错误底 | `#FEF3EE` | 错误态浅橙底 |
| 辅助底 | `#FFFCF6` / `#F0ECDF` | 次级容器 |
| 错误文字 | `#B5512A` | 错误态深橙 |

配色取意松烟墨、宣纸与赭石，三色互补、低饱和、信息层级靠明度而非色相堆叠。

## 3. 组件 CSS 变量（主题化接口）

组件变量全部挂在 `.rs-slider` 作用域内，换肤只需覆盖以下变量：

```css
.rs-slider {
  --rs-accent: #1F3D33;          /* 主色：轨道填充 + 手柄边框 */
  --rs-accent-hover: #284d40;     /* 主色 hover */
  --rs-track-bg: #E5DFCF;         /* 未选轨道底色 */
  --rs-fill-bg: #1F3D33;          /* 已选区间填充 */
  --rs-handle-bg: #ffffff;        /* 手柄填充 */
  --rs-handle-border: #1F3D33;    /* 手柄描边 */
  --rs-handle-size: 18px;         /* 手柄尺寸 */
  --rs-track-height: 4px;         /* 轨道高度 */
  --rs-radius: 999px;             /* 圆角 */
  --rs-focus-ring: rgba(217,123,63,.35); /* 焦点环 */
  --rs-duration: 180ms;           /* 过渡时长 */
  --rs-tooltip-bg: #22281F;       /* 数值气泡底 */
  --rs-tooltip-color: #fff;       /* 数值气泡字 */
  --rs-disabled-opacity: .5;      /* 禁用透明度 */
  --rs-error-color: #B5512A;      /* 错误色 */
}
```

## 4. 字体

- 正文：`"PingFang SC", "Microsoft YaHei", "Helvetica Neue", Arial, sans-serif`
- 数值 / 代码：`"SF Mono", "Menlo", "Consolas", monospace`

## 5. 动效系统（服务语义，非炫技）

| 场景 | 时长 | 曲线 | 说明 |
|------|------|------|------|
| 手柄 hover 放大 | 180ms | ease | `scale(1.15)`，预告可操作 |
| 手柄抓取 active | 180ms | ease | `scale(1.2)` + 阴影加深，咬合感 |
| 轨道点击跳转 | 180ms | `cubic-bezier(0.34,1.56,0.64,1)` | 弹性吸附到点击位 |
| 数值气泡淡入 | 150ms | ease-out | 拖动时浮出，松手 400ms 后淡出 |
| loading 脉冲 | 1200ms | linear 循环 | 持续感 |
| 状态切换 | 180ms | ease | disabled / error / loading 切换 |

**降级**：`@media (prefers-reduced-motion: reduce)` 下全部过渡时长归零，即时切换。

## 6. 状态机（8 态）

`rest` → `hover`（手柄放大）→ `focus`（赭橙焦点环）→ `active/dragging`（抓取放大 + grabbing 光标 + 气泡跟随）→ `disabled`（opacity .5 + pointer-events none）→ `loading`（脉冲 + 手柄禁用）→ `error`（错误条 + 恢复）→ `empty`（筛选结果空状态）。

## 7. 交互与无障碍

- 拖拽：pointer 事件 + setPointerCapture，pointermove 走 RAF 直写 DOM（`_requestUpdate`），不重渲染。
- 不交叉：`allowCross:false` + `minGap` 钳制，两手柄相遇时互相阻挡。
- 点击轨道：最近手柄跳转 + 自动聚焦 + 气泡显示。
- 键盘：Tab 聚焦手柄 → ←/→/↑/↓ 单步、PageUp/PageDown 十步、Home/End 到端点。
- aria：容器 `role="group"` + `aria-label`；每个手柄 `role="slider"` + `aria-valuemin/max/now/valuetext` 实时同步。
- 触屏：`touch-action:none`，手柄热区 ≥ 44px。
- 可见性：`visibilitychange` 隐藏时 `cancelAnimationFrame` 暂停。
- 卸载：`destroy()` 移除监听、清 RAF/定时器、还原 DOM。

## 8. JS 配置接口

```js
new RangeSlider(el, {
  min: 0, max: 100, step: 1,
  values: [25, 75],
  unit: '', allowCross: false, minGap: 0,
  label: '区间选择',
  onChange: (values) => {}
});
```

实例方法：`setValues([a,b])`、`setDisabled(bool)`、`setLoading(bool)`、`setError(bool)`、`destroy()`。

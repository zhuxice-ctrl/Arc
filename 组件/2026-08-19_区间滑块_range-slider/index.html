快速开始

组件由一段 CSS 和一个 JS 类 RangeSlider 组成，均用注释块标记起止位置，复制即可使用。

// 1. HTML 中准备容器
<div id="mySlider"></div>

// 2. 初始化实例
const slider = new RangeSlider(document.getElementById('mySlider'), {
  min: 0,          // 最小值
  max: 100,        // 最大值
  step: 1,         // 步进
  values: [20, 80],// 初始双值 [左, 右]
  unit: '',        // 单位前缀，如 '¥'
  allowCross: false, // 手柄是否允许交叉
  onChange: (values) => {
    console.log('当前区间:', values);
  }
});

// 3. 方法
slider.setValues([30, 70]);  // 外部设值
slider.setLoading(true);     // 加载态
slider.setDisabled(true);    // 禁用态
slider.setError(true);       // 错误态
slider.destroy();            // 销毁实例

CSS 主题变量

在容器或祖先元素上覆盖以下变量即可换肤，通常改动 1–3 处（主色、手柄大小、轨道高度）就够。

--rs-accent
主色调，用于填充轨道与手柄边框
--rs-track-bg
轨道背景色
--rs-fill-bg
已选中区间的填充色
--rs-handle-bg
手柄背景色
--rs-handle-size
手柄直径（默认 18px）
--rs-track-height
轨道高度（默认 4px）
--rs-radius
轨道圆角（默认 999px 全圆）
--rs-focus-ring
键盘焦点环颜色（带透明度）
--rs-duration
过渡动画时长（默认 180ms）
--rs-tooltip-bg
数值气泡背景色
--rs-error-color
错误态颜色

无障碍

  • 每个手柄 role="slider"，实时同步 aria-valuemin/aria-valuemax/aria-valuenow/aria-valuetext
  • 容器带 aria-label 描述作用
  • 键盘：Tab 聚焦手柄，←/→/↑/↓ 单步，PageUp/PageDown 十步，Home/End 到端点
  • 触屏热区 ≥ 44×44px，touch-action: none 防止页面滚动干扰
  • 支持 prefers-reduced-motion，自动降级为无动画

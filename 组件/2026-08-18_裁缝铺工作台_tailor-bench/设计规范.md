# 裁缝铺工作台 · 设计规范

> 方向：V3 UX 交互设计 · 主题：光标驱动的拟物化小组件动画实验室
> 日期：2026-08-18

## 字体

系统衬线/无衬线栈，中文为主，少英文。

## 展区（6 个拟物化微交互装置）

1. 拉皮尺 — 拖拽黄铜端头拉出亚麻色皮尺，松手弹簧回卷（Hooke 定律 + 阻尼）
2. 缝纫机 — 按住踏板加速，机针正弦上下、手轮同步旋转、布料送出针迹
3. 绕线轴 — 拖拽旋转木质线轴，惯性衰减停转，5 色可切换，匝数实时读数
4. 划粉片 — 拖拽在亚麻布料上留下粉笔颗粒痕迹，缓慢消散，可一键扫净
5. 蒸汽熨斗 — 悬停出现熨斗并喷蒸汽，拖过褶皱行被熨平，双击重新弄皱
6. 顶针纽扣盒 — 18 颗彩色纽扣带反平方磁性吸附归位，可一键倾倒散开

## 动效系统（12+ 项）

- 顶针造型自定义光标（白环 + 胭脂内点 + 暖光外晕），悬停黄铜态、按下收束、点击涟漪
- 皮尺弹簧回卷（Hooke + 阻尼 RAF 积分器）
- 机针正弦运动 + 手轮旋转 + 针迹生成
- 线轴惯性衰减（摩擦阻尼）
- 划粉颗粒拖拽生成 + 缓慢消散
- 蒸汽粒子扩散
- 纽扣反平方磁性吸附 + 倾倒碰撞
- 横向滚动展区画廊 + 顶栏导航点同步高亮

物理模型：弹簧 Hooke 定律、惯性动量、磁性反平方引力、阻尼/摩擦、RAF 积分器。严禁整图缩放/Ken Burns。

## 健壮性

- 纯 vanilla HTML/CSS/JS 单文件，零外部 CDN 依赖
- RAF/定时器随 visibilitychange 暂停、卸载取消
- 高频鼠标事件直接操作 DOM transform
- prefers-reduced-motion 降级

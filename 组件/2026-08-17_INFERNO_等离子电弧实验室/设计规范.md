# INFERNO · 等离子电弧特效实验室 设计规范

## 一、设计哲学

INFERNO 是一个等离子电弧特效实验室，以"熔火等离子"为主题。视觉语言源自高温等离子体、电弧放电与熔融金属——碳黑底色上迸发的橙红电弧、熔金琥珀光晕与电白弧光，营造出炽热、危险而迷人的实验室氛围。

## 四、间距与圆角

- 展区卡片圆角：12-16px
- 控制面板圆角：8px
- 按钮圆角：6-8px
- 滑块圆角：100px
- 间距系统：4 / 8 / 12 / 16 / 24 / 32px

## 五、核心组件

- **展区 Canvas**：全屏 Canvas 2D 渲染，光标驱动交互
- **参数控制面板**：每个展区 4 个滑块实时调节
- **侧边栏展品列表**：14 个展区可切换
- **顶部分类过滤**：Arc / Particle / Light / Distort 四类
- **底部状态读数**：FPS / 粒子数 / 鼠标坐标

### 组件级特效

- 自定义光标（白环 + 金内点 + 多层发光 + 悬停放大 + 点击涟漪）
- 展区切换过渡动画
- 参数滑块实时响应
- 侧边栏选中态指示
- 分类过滤标签切换

### 健壮性

- 纯 vanilla HTML/CSS/JS 单文件实现，无 React / 无 Babel / 无外部 CDN
- `visibilitychange` 自动暂停所有 RAF 动画循环
- `prefers-reduced-motion` 降级支持
- 切换展区时重建 Canvas，无 RAF 泄漏
- 快速切换不叠加定时器

## 七、页面结构

1. **顶部导航** — Logo + 分类过滤标签（Arc / Particle / Light / Distort）
2. **侧边栏** — 14 个展区列表，可点击切换
3. **主画布区** — 全屏 Canvas，光标驱动交互
4. **参数控制面板** — 4 个滑块实时调节当前展区参数
5. **底部状态栏** — FPS / 粒子数 / 坐标读数

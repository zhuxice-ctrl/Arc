# AURORA 极光帷幕实验室 — 设计规范

- **日期**：2026-08-17
- **方向**：V3 UX 交互设计
- **主题**：极夜天象主题的炫技特效舱，6 个可亲手操作的组件级特效装置
- **风格**：暗夜霓虹、极光天象、单 RAF 统一调度
- **实现**：纯 vanilla HTML/CSS/JS 单文件，零外部依赖（无 React / 无 Babel / 无 CDN）

## 色彩系统

| 角色 | 色值 | 用途 |
|------|------|------|
| 极夜黑 主底 | `#060A12` | 页面底色、深空 |
| 极夜深 | `#04070E` / `#02040A` | 最深暗角 |
| 面板深蓝 | `#0B1220` / `#111A2E` | 信息面板、展区容器 |
| 极光绿 主色 | `#39FF9A` | 品牌色、极光、强调 |
| 冰青 | `#7FE7DC` | 次极光、冰光、辅助 |
| 暖粉 | `#FF8FB2` | 点缀、高光对比 |
| 银灰 | `#B8C4C9` | 次级文字、状态指示 |

## 字体系统

- 显示 `--font-display`：`'Space Grotesk', 'Inter', system-ui, sans-serif`
- 等宽 `--font-mono`：`'JetBrains Mono', 'SF Mono', ui-monospace, monospace`

## 展区（6 个独立可操作特效装置）

| # | 展区 | 交互 | 物理模型 |
|---|------|------|----------|
| 01 | 极光帷幕 | 拖拽弯曲帷幕流向 | 多层正弦叠加流场 + 色相插值 + 3 模式 |
| 02 | 星轨拖尾 | 移动绘制长曝光星轨 | 曝光累积 + 衰减积分 + 闪烁相位 |
| 03 | 离子粒子流 | 磁化粒子束/散开 | 平方反比力场 + 阻尼 + 3 模式 |
| 04 | 光绘涂鸦 | 按压绘制发光轨迹 | 逐帧 alpha 衰减 + 径向辉光 + 4 色相 |
| 05 | 光谱折射棱镜 | 拖动光源 / 调角度 | Snell 折射 + 波长折射率 + 全内反射 |
| 06 | 电磁波文字解构 | 悬停击碎标题再归位 | 弹簧-阻尼 + 距离平方斥力 |

## 动效系统（12+）

1. 自定义光标（白环+极光内点+多层辉光+hover 放大+press 涟漪）
2. 极光帷幕 shader 流场
3. 星轨长曝光累积
4. 离子粒子平方反比力场
5. 光绘衰减发光
6. 棱镜 Snell 折射色散
7. 文字弹簧解构归位
8. 磁吸导航项
9. 视差信息面板
10. 扫描线滤镜 + 暗角 + 噪点颗粒
11. 品牌脉动徽标 / 状态指示灯
12. 按钮流光扫过
13. FPS 实时监测 / 键盘方向键切展 / 背景环境星点

## 工程特性

- 单 RAF 循环统一调度，`visibilitychange` 暂停，切站销毁旧 loop 防泄漏
- mousemove 直接改 transform，不 setState
- `prefers-reduced-motion` 降级静态
- 自定义光标页面加载即显示在屏幕中央
- 零外部依赖，纯 vanilla 单文件

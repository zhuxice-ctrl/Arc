# 潮汐灯塔控制室 · 设计规范

- 日期：2026-08-18
- 方向：V3 UX 交互设计（光标驱动的拟物化小组件动画）
- 主题：1887 年海角灯塔控制室——复古航海拟物化微交互实验室

## 色彩系统

赭石红 + 深海绿 + 黄铜金 + 旧木棕的复古航海配色，禁蓝紫渐变。

| 角色 | 色值 | 用途 |
|---|---|---|
| 黄铜金 | `#B8860B` / `#D4A84B` | 金属装置主色、光标内点 |
| 亮金 | `#FFE48A` / `#FFD700` | 高光、灯泡暖光 |
| 旧木棕 | `#7A5A1A` / `#5A3D0F` / `#8B5A2B` | 木质面板、抽屉 |
| 深海绿 | `#2D4A3E` / `#3D6B5A` | 仪表盘面、夜空 |
| 苔绿 | `#50C878` | LED 发光、指针 |
| 赭石红 | `#C0392B` / `#FF4444` | 警示、拉杆档位 |
| 旧米 | `#F5ECD7` / `#F0E6D0` | 纸面表盘、背景 |
| 深褐 | `#3D2817` | 暗部、阴影 |

## 自定义光标

白色粗环 + 黄铜色内点 + 发光光晕，三层缓动跟随；悬停放大变色、点击涟漪、按下收缩，开页即显示在屏幕中央，z-index 最高。

## 健壮性

- 纯 vanilla 单文件（无 React / 无 Babel / 无外部 CDN），根本规避白屏
- RAF 统一管理，`visibilitychange` 自动暂停/恢复，卸载清理全部循环
- 快速操作无定时器叠加（重建前先 clear）
- `prefers-reduced-motion` 全局降级

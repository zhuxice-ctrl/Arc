## 动效系统

所有动效基于物理模型（Hooke 弹簧 / 阻尼 / 惯性），使用 rAF 单循环积分器。

| 动效 | 展区 | 物理模型 |
|------|------|----------|
| 自定义光标 | 全局 | 白色粗环 + 暖铜内点 + 拖尾，rAF 平滑跟随 |
| 点击涟漪 | 全局 | 动态创建 div + CSS scale 消散 |
| 拉绳下垂/回弹 | 拉绳灯开关 | Hooke 弹簧 + 阻尼，拖拽时实时物理计算 |
| 灯泡发光扩散 | 拉绳灯开关 | CSS box-shadow 多层渐变 + 亮度动画 |
| 拨杆惯性回弹 | 拨杆开关 | 阻尼振荡，释放后弹性回归 |
| 电路通电视觉 | 拨杆开关 | 指示灯渐变亮起 + 电流粒子流 |
| 旋钮圆周拖拽 | 旋钮调谐器 | 鼠标角度计算 + 指针滞后跟随（弹性追踪） |
| 频率吸合 | 旋钮调谐器 | 接近目标频率时磁力吸附 + 指示灯亮 |
| 亮度色温渐变 | 滑动调光器 | 滑块位置 → 亮度 + 色温线性映射 |
| 弹簧按压形变 | 按压门铃 | 按下时 scaleY 压缩 + 松手 Hooke 回弹 |
| 涟漪三层扩散 | 按压门铃 | 三个同心圆延迟扩散 + 音频波纹可视化 |
| 摇杆 2D 拖拽 | 摇杆控制器 | 360° 拖拽 + 弹簧归中（Hooke XY 双轴） |
| 粒子方向流 | 摇杆控制器 | 40 颗粒子跟随摇杆方向流动 |

## 展区结构（6 件装置）

1. **拉绳灯开关** — 弹簧物理下垂 + 松手回弹 + 钨丝发光扩散
2. **拨杆开关** — 阻尼惯性回弹 + 电路导通指示灯
3. **旋钮调谐器** — 圆周拖拽 + 刻度指针滞后跟随 + 对准频点吸合
4. **滑动调光器** — 连续亮度 + 冷白→暖黄色温渐变
5. **按压门铃** — 弹簧下陷 + 三层涟漪扩散 + 回弹
6. **摇杆控制器** — 360° 拖拽 + 弹簧归中 + 40 颗粒子方向流

## 技术栈

- 纯 vanilla HTML/CSS/JS 单文件实现（无 React / 无 Babel / 无外部 CDN 依赖）
- rAF 单循环物理积分器
- Hooke 弹簧 / 阻尼 / 惯性物理模型
- 高频鼠标事件直接操作 DOM transform
- 支持 prefers-reduced-motion 降级
- rAF 随页面可见性自动暂停

## 展区（6 件拟物化微交互装置）

1. **扭蛋摇柄机** — 拖拽摇柄旋转（惯性 + 阻尼回弹），转满一圈出货
2. **黄铜杆秤** — 拖拽砝码到左盘，秤杆倾斜配平，刻度随动
3. **玻璃糖罐** — 点击开盖，拖拽糖球（罐内弹簧回弹 / 抛出重力弹跳），玻璃光泽扫过
4. **唤人铜铃** — 点击铃身摆动 + 铃锤敲击 + 多层声波涟漪 + 星光粒子迸发
5. **拉糖机滚筒** — 拖拽手柄旋转，三辊轴飞转，糖带拉出延展后弹簧回弹
6. **老式收银机** — 圆形按键按压反馈，萤光数字显示，钱箱弹出 + 小票吐出

## 动效系统（12+ 组件级特效）

自定义光标（三色三层 + 悬停/抓取/点击三态，开页居中）、卡片 3D 倾斜、滚动渐入、光泽扫过、弹簧回弹（Hooke 定律）、惯性旋转 + 阻尼摩擦、重力下落 + 弹跳、涟漪扩散、粒子迸发、数字计数跳动、浮动糖果装饰、打字机风格荧光显示。动效基于物理模型，周期各异。

## 健壮性

纯 vanilla HTML/CSS/JS 单文件，零外部依赖（无 React / 无 Babel / 无 CDN）；`visibilitychange` 自动暂停/恢复 RAF；定时器统一管理防叠加；支持 `prefers-reduced-motion` 降级。

纯 vanilla HTML + CSS + JS 单文件实现。

## 展区结构（6 个独立展区）

### 1. 光子引力场
- 500 粒子，反平方引力定律 F=G*m/r²
- 鼠标作为引力源，可切换吸引/排斥
- 粒子拖尾轨迹，颜色随速度渐变（橙→金→红）

### 2. 噪波流场
- Simplex noise 矢量场驱动 600 粒子
- 鼠标移动扰动流场
- 丝绸般流动纹理，熔金/猩红渐变

### 3. 文字解构
- 字符像素化分解为粒子
- 聚拢/吹散两种风场模式
- 预设词切换 + 自定义输入

### 4. 磁力形变按钮
- clip-path 波纹形变 + 三层磁吸环
- 鼠标靠近时表面拉扯变形
- 点击爆发 60 粒子环

### 5. 频谱可视化
- 正弦波叠加生成假频谱数据
- 熔金渐变柱状图 + 镜像倒影
- 峰值标记线缓慢下落
- 低频/全频/高频模式切换

### 6. 光线扫描滤镜
- 滑块控制扫描线位置
- 色散/故障/热成像三种模式
- 故障模式带随机干扰线

## 自定义光标

- 白色粗环 + 熔金内点 + 多层发光
- 开页即显示在屏幕中央
- z-index 最高
- 悬停可交互元素：放大变色
- 点击：涟漪扩散

## 技术栈

- 纯 vanilla HTML/CSS/JS 单文件
- 无 React / 无 Babel / 无外部 CDN 依赖
- Canvas 2D API 用于粒子系统
- CSS clip-path 用于磁力形变
- SVG 用于扫描线滤镜

## 健壮性

- visibilitychange 自动暂停所有 RAF
- 卸载时统一取消定时器/RAF
- 快速操作不叠加定时器
- 高频鼠标事件直接操作 DOM transform
- 支持 prefers-reduced-motion 降级
- 零未定义引用

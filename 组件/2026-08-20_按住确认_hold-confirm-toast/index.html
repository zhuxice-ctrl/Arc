用法文档

1. 引入方式

复制组件 CSS 与 JS 到项目中，或直接从单文件抽取。零依赖，纯 vanilla。

// CSS 变量块 + .hcc-* 样式
// JS 暴露全局对象：window.HoldConfirm
// 或按需使用：createHoldConfirm(el, options) / toast.show(options)

2. createHoldConfirm 配置

createHoldConfirm(element, {
  duration:   1200,     // 按住触发时长 (ms)
  onConfirm:  fn,       // 达到阈值时触发
  onCancel:   fn,       // 中途松手时触发
  onStart:    fn,       // 开始按下时触发
  disabled:   false,    // 是否禁用
  staySuccess: 1200,    // 成功态停留时长 (ms)
  labelHold:  '按住确认', // 按住态文案
  labelRest:  '按住确认', // 常态文案
  labelDone:  '已确认'   // 成功态文案
})

返回实例方法：.start() .cancel() .success() .setDisabled(bool) .destroy()

3. toast.show 配置

toast.show({
  type: 'success',      // success | error | info | loading
  title: '操作成功',
  description: '',      // 可选副文案
  duration: 4000,       // 停留时长 (ms)，0 = 不自动关闭
  action: {             // 可选操作按钮
    label: '撤销',
    onClick: fn
  },
  closable: true        // 显示关闭按钮
})

返回实例方法：.close()

4. CSS 变量清单

修改以下变量即可换主题，默认改 --hcc-color-lava / --hcc-color-ink / --hcc-color-pine 三处即可。

--hcc-color-bg 底色 / 背景 #F5F2EB --hcc-color-ink 深炭墨 / 主色 #26221F --hcc-color-lava 熔岩橙 / 进行态 #E4572E --hcc-color-moss 苔灰 / 辅助色 #8A8F85 --hcc-color-pine 松绿 / 成功态 #3E7C59 --hcc-color-error 错误红 #C23B22 --hcc-color-info 信息蓝 #4A6FA5 --hcc-duration-hold 按住阈值时长 1200ms --hcc-duration-decay 松手衰减时长 300ms --hcc-duration-snap 咬合回弹时长 250ms --hcc-radius-pill 按钮圆角 999px --hcc-ring-width 进度环宽度 3px

5. 无障碍

键盘可达：Tab 聚焦、Space/Enter 按住触发、Esc 取消。 ARIA：aria-disabled、aria-live=polite（Toast 容器）、role=status。 支持 prefers-reduced-motion：进度改线性、取消弹性，功能不变。

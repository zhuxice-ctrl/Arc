# 设计规范 · 按住确认按钮 × Toast 组件对

> 主题：「确认的分量」——危险操作需要持续施压的物理重量感，结果由 Toast 反馈承接，形成「施压确认→结果反馈」闭环。

## 设计母题

危险操作（删除/清空/发布/禁用）不靠二次弹窗打断，而让按钮本身要求持续施压。按住时进度环阻尼填充，填满瞬间弹性咬合确认；中途松手进度衰减归零。组件只取「持续施压」的交互语义，不做闸刀/拉杆等拟物造型。

## 配色（禁蓝紫渐变，与近期作品不雷同）

| 变量 | 色值 | 语义 |
| --- | --- | --- |
| `--hcc-color-bg` | `#F5F2EB` 石灰白 | 页面底色 |
| `--hcc-color-surface` | `#FFFFFF` | 卡片表面 |
| `--hcc-color-ink` | `#26221F` 深炭墨 | 主文字 / 按下态重量 |
| `--hcc-color-lava` | `#E4572E` 熔岩橙 | 危险 / 进行态进度环 |
| `--hcc-color-pine` | `#3E7C59` 松绿 | 成功态 |
| `--hcc-color-error` | `#C23B22` 错误红 | Toast error |
| `--hcc-color-info` | `#4A6FA5` 信息蓝 | Toast info |
| `--hcc-color-moss` | `#8A8F85` 苔灰 | 禁用 / 辅助 |

色彩承担功能：橙=危险进行、绿=成功确认、灰=禁用弱化、墨黑=文字与按压重量。非装饰性配色。

## 字体

继承宿主字体栈，无外部字体；展示页用系统无衬线，标题用字重对比建立层级，不引入 Display Font。

## 动效系统（全部服务状态语义）

| 动作 | 时长 | 曲线 | 语义 |
| --- | --- | --- | --- |
| 进度环阻尼填充 | 1200ms | `cubic-bezier(0.22, 1, 0.36, 1)` 先快后慢 | 持续施压的「分量」 |
| 阈值咬合回弹 | 250ms | `cubic-bezier(0.34, 1.56, 0.64, 1)` 弹簧 | 确认瞬间的弹性质变 |
| 松手衰减归零 | 300ms | `linear` | 安全取消的快速回退 |
| Toast 滑入 | 200ms | `cubic-bezier(0.22, 1, 0.36, 1)` | 结果出现 |
| Toast 滑出 | 180ms | `linear` | 消散 |
| 成功态停留 | 1200ms | — | 确认后短暂反馈 |

`prefers-reduced-motion` 降级：`--hcc-ease-damping` 与 `--hcc-ease-snap` 改为 `linear`，取消弹性回弹，进度环仍线性填充（状态信息保留），功能不受影响。

## 状态机（HoldConfirm 按钮，8 态）

`rest → hover → focus → pressing(进度填充) → success(触发后咬合+成功色) → cancelled(松手衰减) → disabled → loading(异步执行中)`

- `rest`：默认态，进度环空。
- `hover`：可操作预告。
- `focus`：2px 实线焦点环可见。
- `pressing`：按住时进度环以阻尼曲线填充，熔岩橙。
- `success`：达阈值瞬间环闭合、按钮微缩回弹、转松绿，停留 1200ms 后回调 `onConfirm`。
- `cancelled`：中途松手进度 300ms 线性衰减归零，回调 `onCancel`。
- `disabled`：`aria-disabled`，opacity 降低、`cursor: not-allowed`，所有交互无响应。
- `loading`：异步执行中显示 loading 指示，禁用重复触发。

## Toast 队列

4 种语义类型（success / error / info / loading）；多通知自动排队；悬停暂停倒计时；支持 `action` 撤销按钮；可手动关闭；`duration: 0` 不自动关闭。容器 `role=status`、`aria-live=polite`。

## 可访问性

- 键盘：Tab 聚焦 → 按住 Space/Enter 等效指针触发 → Esc 取消进行中的按压。
- 焦点环始终可见（`--hcc-focus-ring`）。
- `aria-disabled`、`aria-live`、`role=status` 正确。
- `prefers-reduced-motion` 降级。

## 可复用性

- 纯 vanilla 单文件，零依赖（无 React/Babel/CDN/外部字体/图片）。
- CSS 变量主题化：`--hcc-*` 前缀 12+ 变量（色值/圆角/时长/缓动/阴影全暴露），改 3 处色值即可换主题。
- 工厂 API：`createHoldConfirm(el, options)` 返回 `.start()/.cancel()/.success()/.setDisabled()/.destroy()`；`toast.show(options)` 返回 `.close()`。
- 命名空间 `.hcc-*`，CSS/JS 可独立抽取，与展示页解耦。
- 抽到别的项目改不超过 3 处即可用。

## 工程红线

- 零未定义引用、零运行时崩溃（Browser QA：无 Console Error、无 page error、无 404）。
- RAF 随可见性暂停、卸载取消；快速操作不叠加定时器。
- 桌面 1440px / 移动 390px 均无横向溢出。

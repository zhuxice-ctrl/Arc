## 展区结构（6 个独立交互装置）

| # | 展区 | 类型 | 交互 |
|---|------|------|------|
| 01 | Ripple Key | 按键交互 | `A`/`S`/`D`/`F` 按键波纹扩散 + 示波器轨迹滚动 |
| 02 | Morphing Icon | 图标动画 | 点击切换 Hexagon / Star / Cross / Diamond 路径变形 |
| 03 | Engraved Switches | 按键交互 | 三种开关：杠杆 / 摇杆 / 旋钮（各异机械动画） |
| 04 | Progress Ring | 图标动画 | 双环联动进度环 + 数字滚动 + 高值色变（铜金→金叶→朱砂） |
| 05 | Copper Burst | 按键交互 | 点击画布触发三重爆炸：冲击波环 + 圆形粒子 + 碎片 |
| 06 | Loading Atelier | 图标动画 | 四种加载动效同场：轨道 / 刻线 / 脉冲点阵 / 弧线追踪 |

## 动效机制（14+）

按键波纹扩散 + 示波器轨迹、SVG 路径 morphing（cubic-bezier 插值）、杠杆/摇杆/旋钮机械动画、双环进度联动 + 数字 easeOut 滚动 + 色变、点击爆炸三重粒子（冲击波环 + 圆形粒子 + 碎片，各自 RAF 积分器）、四种 loading 动效（轨道旋转 / 刻线扫描 / 脉冲点阵呼吸 / 弧线追踪），各展区周期互不相同。

## 健壮性

纯 vanilla HTML/CSS/JS 单文件（零 CDN 依赖）；`visibilitychange` 暂停所有 RAF/定时器；`safeTimeout` 防重复触发叠加；`prefers-reduced-motion` 全量降级；`beforeunload` 清理。

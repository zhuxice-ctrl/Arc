# 星航仪 Astrarium · 航海仪器交互实验室

> 日期：2026-08-17 · 方向：V3 UX 交互设计 · 主题：黄铜航海天文仪器 · 拟物化微交互实验室

## 简介

黄铜航海仪器的可把玩展厅。炭黑舱壁背景上陈列六件拟物化仪器，全部以鼠标光标悬停/点击/拖拽驱动：星盘惯性旋转、罗盘磁针吸附、沙漏翻转流沙、船铃声波涟漪、舵轮联动海平线、六分仪读取角度。每件仪器有场景叙事文案，交互反馈细腻、有物理质感。

## 动效亮点

- 自定义光标（开屏居中 + 悬停放大 + 点击涟漪 + z-index 最高）
- 星盘惯性阻尼自转、罗盘磁针弹簧吸附
- 沙漏粒子流动、船铃三重声波涟漪
- 舵轮联动舷窗海平线倾斜
- 黄铜质感径向渐变 + 点阵铜锈纹理 + 80 颗星点闪烁

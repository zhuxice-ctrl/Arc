# 设计规范 · 星航仪 Astrarium 航海仪器交互实验室

> 日期：2026-08-17 · 方向：V3 UX 交互设计 · 主题：黄铜航海天文仪器 · 拟物化微交互实验室

## 色彩系统

| 角色 | 色值 | 用途 |
|------|------|------|
| 主色 · 黄铜金 | #B98A2F | 仪器主体、刻度环、标题强调 |
| 黄铜亮 | #D9B25A | 高光、光泽扫过、悬停态 |
| 黄铜暗 | #8A6520 | 阴影、刻度深槽 |
| 背景 · 炭黑 | #1E1B16 | 页面底色、暗舱壁 |
| 背景深 | #171410 | 渐变底 |
| 背景中 | #2A2620 / #3A352C | 卡片底、分层 |
| 表面 · 象牙白 | #EFE6D2 | 文字、刻度数字、象牙盘面 |
| 象牙暗 | #E6DCC4 | 次要文字 |
| 点缀 · 铜绿 | #4F7A6A | 状态色、互动反馈 |
| 铜绿亮 | #6A9B8A | 悬停绿光 |
| 红铜 | #A0522D | 警示、船铃绳 |

配色策略：黄铜金为绝对主角，落在炭黑舱壁上，象牙白作刻度与文字，铜绿作互动反馈点缀。整体呈现黄铜仪器在暗舱中的质感。禁用蓝紫渐变。

## 字体

- 标题/刻度：`"Cinzel", "Noto Serif SC", serif`（古典衬线，仪器铭文感）
- 正文：`"Noto Sans SC", system-ui, sans-serif`

## 圆角与质感

- 仪器圆角：50%（圆盘）/ 8px（铭牌）
- 黄铜质感：径向渐变 `radial-gradient(#D9B25A, #B98A2F, #8A6520)` + 内外阴影模拟浮雕
- 点阵铜锈纹理背景（CSS 生成）+ 80 颗随机星点

## 六件拟物化展区（全部光标驱动，无键盘）

1. **星盘** — 拖拽旋转刻度环，松手惯性阻尼自转；悬停时照准臂带弹簧感跟随光标
2. **罗盘** — 悬停在盘面，磁针带弹簧阻尼吸附指向光标方位，卡片微视差位移
3. **沙漏** — 拖拽倾斜翻转，沙粒(5 颗粒子连续下落)实时流动计时，翻转即重置
4. **船铃** — 点击敲响，钟体振荡动画 + 三重声波涟漪依次扩散，计数器累加
5. **舵轮** — 拖拽旋转，8 根辐条+8 个握柄全拟物形态，上方舷窗海平线随转向倾斜
6. **六分仪** — 滑动标尺或直接拖拽活动臂，读取 0~120° 天体高度角

## 动效系统（12+ 组件级）

1. 自定义光标（开屏居中 + 悬停放大 + 点击涟漪 + z-index 最高）
2. 星盘惯性阻尼自转
3. 罗盘磁针弹簧吸附
4. 沙漏粒子流动
5. 船铃三重声波涟漪
6. 舵轮联动海平线倾斜
7. 卡片 3D 倾斜
8. 光泽扫过
9. 滚动渐入
10. 打字机效果（展区叙事文案）
11. Hero 视差微动
12. 星点闪烁
13. 数字实时读数（六分仪角度）

动效基于物理模型：弹簧(Hooke)、惯性动量、阻尼摩擦、RAF 积分器。严禁整图缩放/Ken Burns。

## 健壮性

- 纯 vanilla HTML/CSS/JS 单文件实现（无 React / 无 Babel / 无外部 CDN 依赖）
- `visibilitychange` 自动暂停/恢复动画，RAF 统一注册清理
- `prefers-reduced-motion` 全量降级
- 高频鼠标事件直接操作 DOM transform，无 React 重渲染

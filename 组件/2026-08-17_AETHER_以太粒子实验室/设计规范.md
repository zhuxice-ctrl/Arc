# 设计规范 · AETHER 以太粒子实验室

方向：V3 UX 交互设计 · 日期：2026-08-17 · 主题：炫技组件特效动画可把玩实验室

## 色彩系统

| 角色 | 色值 | 用途 |
|------|------|------|
| 底色 | #0C0C0E / #121216 / #1a1a20 | 炭黑底 / 表面层 |
| 主色 | #00E5D0 | 电青，主特效光 |
| 强调 | #FF2E7E | 品红，峰值 / 高亮 |
| 点缀 | #F0E040 | 柠黄，第三色 |
| 文字 | #E8E8EC / #9a9aa6 / #5a5a66 | 银白主文 / 次文 / 弱文 |

无蓝紫渐变。整体为炭黑底 + 电青/品红/柠黄三原色光效。

## 字体

- 展示标题：Space Grotesk / Geist（无衬线几何）
- 等宽：JetBrains Mono（数据 / 标签）

## 展区（6 个独立可操作装置）

1. 以太粒子场（Hero）— 鼠标吸引/排斥/漩涡三模式，粒子连线 + 发光辉光
2. 噪波流场 — FBM 值噪声驱动流动色彩粒子，点击重生成种子，三色调色板
3. 文字解构重组 — AETHER 字符打散为粒子，悬停推开 / 波浪 / 粉碎三模式，弹簧物理回弹
4. 磁力形变卡片 — 反平方引力拉扯形变 + 倾斜 + 缩放，三档强度
5. 频谱可视化 — 64 柱模拟音频频谱，BPM 可调 + 强度滑块，峰值品红发光
6. 光标拖尾 — 多色发光粒子拖尾，彩虹 / 纯青 / 火焰三模式，lighter 合成叠加

## 动效系统（12+ 组件级）

自定义光标（惯性外环 + 紧随点 + 点击涟漪 + 悬停形变）、Glitch 文字、扫描线 CRT 滤镜、粒子连线网、噪声流场、文字粒子弹簧、磁力形变、频谱柱渐变、拖尾辉光、导航下划线、卡片聚光灯、BPM 节拍脉冲。

物理模型：弹簧 Hooke 回弹、磁性反平方引力、阻尼积分器、RAF 积分器。

## 健壮性

- 所有 RAF 循环注册到统一调度器，visibilitychange 暂停/恢复，卸载统一取消
- IntersectionObserver 懒启动非首屏 canvas，离屏自动停循环
- 快速操作不叠加定时器（速率限制 / 弹簧积分器）
- 鼠标事件直接改 transform（非 left/top）
- 支持 prefers-reduced-motion
- 零未定义引用

## 技术栈

纯 vanilla HTML/CSS/JS 单文件，无 React/Babel/CDN 依赖。

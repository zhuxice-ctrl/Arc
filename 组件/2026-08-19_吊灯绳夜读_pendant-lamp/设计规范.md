# 吊灯绳·夜读 · 设计规范

## 作品信息
- **主题**：拟物化拉绳吊灯开关
- **日期**：2026-08-19
- **方向**：V3 交互组件
- **类型**：机械结构 + 材质表现
- **技术栈**：纯 vanilla HTML + CSS + JS（单文件，无外部依赖）

## 设计母题
一间深夜书房，画面中央悬挂一盏复古黄铜吊灯，灯罩下垂一根拉绳（末端是黄铜小球拉手）。用户抓住小球向下拉动，感受弹簧阻力，到达阈值时机械开关咬合，灯亮起——白炽灯丝从暗红升温到暖白，房间从月光冷暗变为暖光映照。松手后绳子如弹簧般回弹振荡。再次拉动则灯熄灭。

这是一个可以被反复把玩的单一组件，不是组件库、不是展示页。

## 物理模型
拉绳使用真实物理积分（requestAnimationFrame 驱动），非 CSS transition：

1. **静止钟摆**：重力 + 阻尼的正弦衰减振荡，绳子末端小球微摆
2. **拉伸弹簧**：胡克定律 F = kx，拉动距离越大阻力越大，绳子视觉变细
3. **阈值咬合**：拉动约 45px 时机械开关咬合——阻力骤降，灯座内开关机构闪光
4. **释放回弹**：阻尼谐振子（damped harmonic oscillator），振荡 3-4 次衰减到静止
5. **白炽灯升温**：灯丝颜色从暗红(#3a1010) → 橙红(#8B2500) → 暖黄(#E8A33D) → 暖白(#FFE4B5)，约 800ms

## 反馈层次
| 阶段 | 表现 |
|------|------|
| Pre-contact | 光标接近小球时，小球微微发光、摆动加剧 |
| Contact | 抓住小球瞬间，有"咬合"手感，小球略微跟随光标 |
| Continuous | 拉动过程中绳子持续拉伸、阻力可视化（绳子变细） |
| Threshold | 到达 45px 时开关闪光、阻力骤降、灯座内机构可见 |
| Completion | 灯亮起，白炽灯丝升温，房间从暗变亮 |
| Release | 松手后绳子回弹振荡 3-4 次 |
| Decay | 振荡逐渐衰减到静止 |

## 场景环境
- 黄铜灯罩 + 玻璃灯罩（吊灯主体）
- 书桌（摊开的书 + 钢笔）
- 扶手椅
- 书架（21 本不同颜色书脊）
- 右侧窗户（月光照入 + 飘动窗帘）
- 木质纹理地板
- 25 个漂浮尘埃粒子（灯亮时光束中可见）

## 自定义光标
发光圆点 + 十字线，开页显示在屏幕中央，z-index 最高。接近拉绳小球变为抓取手势，抓住变为握紧手势。支持 prefers-reduced-motion 时降级为系统光标。

## 动效系统（12+ 项组件级动效）
1. 拉绳钟摆微摆
2. 拉绳弹簧拉伸
3. 弹性回弹振荡
4. 白炽灯丝升温曲线
5. 光晕径向扩散
6. 家具阴影变化
7. 尘埃粒子漂浮
8. 月光透过窗户
9. 开关咬合闪光
10. 光标形态变换
11. 窗帘飘动
12. 书架微光（灯亮时书脊显现）

## 健壮性
- requestAnimationFrame 物理循环，页面隐藏时暂停，卸载时取消
- 完整支持 prefers-reduced-motion（直接开关，无物理动画）
- 快速操作不叠加定时器
- 高频鼠标事件直接操作 DOM
- 零未定义引用，零运行时崩溃
- 桌面 1200px+ 适配

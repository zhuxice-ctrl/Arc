## 字体

- 主字体：`"PingFang SC", "Microsoft YaHei", "Hiragino Sans GB", sans-serif`

## 组件规范

- **自定义光标**：白色粗环 + 琥珀金内点 + 多层发光，z-index 最高，开页即显示在屏幕中央
- **展区卡片**：圆角 16-24px，深色底 + 内发光，hover 边框高亮
- **拉绳**：SVG 路径 + 单摆物理摆动
- **滑块**：圆形手柄 + 拖拽轨道 + 状态渐变背景
- **拨杆**：金属渐变 + 弹簧回弹 + 火花粒子
- **旋钮**：圆形转盘 + 刻度环 + 阻尼惯性
- **灯泡**：径向渐变 + 光晕扩散 + 粒子发射

## 展区结构（6 个）

1. **壹·拉绳台灯** — 拖拽拉绳控制亮度，松手弹簧回弹，灯泡光线扩散+阴影+光晕粒子
2. **贰·日月开关** — 拖动日月滑块切换昼夜，星空云朵渐变，背景色从深夜到黎明
3. **叁·拨杆开关** — 金属拨杆上下切换，弹簧回弹，切换时灯泡亮灭+火花粒子
4. **肆·旋钮调光** — 旋转转盘控制亮度色温，阻尼惯性，暖黄→冷白渐变
5. **伍·磁吸触控** — 灯泡靠近底座磁性吸附，点击切换开关，磁力线动画
6. **陆·烛火摇曳** — 火柴点燃烛芯，多频正弦摇曳，点击熄灭，余烬+烟雾消散

## 技术栈

- 纯 vanilla HTML/CSS/JS 单文件
- 零外部 CDN 依赖（无 React / 无 Babel）
- Canvas 2D 粒子系统
- SVG 路径动画
- RAF 物理积分器
- visibilitychange 暂停 / prefers-reduced-motion 降级

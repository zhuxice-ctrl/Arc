# INKFLOW 墨流实验室 · 设计规范

> 2026-08-16 · V3 UX 交互设计 · 纯 vanilla 单文件实现（无 React / 无 Babel / 无 CDN）

## 色彩系统

宣纸白底 + 浓墨黑 + 朱砂红 + 金箔黄，东方水墨语义。

| 语义 | 色值 | 用途 |
|---|---|---|
| 宣纸白（底） | `#F7F2E7` | 页面主背景 |
| 暖纸阶 | `#F7E2D6` `#EDE6D6` `#E8D58A` | 渐变、卡片表面 |
| 浓墨黑（前景） | `#161412` | 主文字、墨迹 |
| 墨阶 | `#2A2420` `#3A3430` `#5A5550` `#6A6560` `#7A7560` | 次级文字、墨痕 |
| 朱砂红（强调） | `#D43D2A` `#B02D1E` | 主交互、印章、光标内点 |
| 金箔黄（点缀） | `#C9A24B` `#8B7028` | 频谱、光泽、徽章 |
| 暖灰 | `#8A8580` `#A09070` `#A09080` | 边框、辅助 |

## 字体

- 展示/标题：`"Songti SC", "STSong", "SimSun", "Noto Serif SC", serif`

- 宣纸质感底纹 + 墨色卡片分层
- 朱砂印章为强对比焦点元素

## 动效系统（19 项组件级特效）

自定义毛笔光标（三环 + 朱砂光点 + 多层发光，lerp 跟随）、墨滴拖尾粒子、点击涟漪（朱砂环，贝塞尔缓动）、Hero 标题逐字入场、打字机（随机间隔模拟手写）、Hero 背景墨团漂浮（正弦摇摆 + 径向渐变）、9 个展区装置、滚动渐入、展区卡片悬停上浮（弹簧阴影）、扫描线滤镜开关、朱砂印章脉冲。

## 健壮性

- `visibilitychange` 自动暂停所有 RAF，恢复后重启
- 所有定时器统一管理，重建前先清除旧的
- 高频 mousemove 直接操作 DOM transform，无重渲染
- `prefers-reduced-motion` 降级静态 + 系统光标
- 移动端回退系统光标
- **纯 vanilla 单文件**：无 React / 无 Babel / 无外部 CDN，从根本上规避白屏

## 技术栈

原生 HTML/CSS/JavaScript 单文件，Canvas 2D + DOM transform。

# 日期范围选择器 · 设计规范

> 提取自 `index.html` 源码，所有色值、字体、动效参数均为代码实际值。

## 1. 设计概念

**主题**：运营数据 · 时间区间筛选 — 档案式暖纸底 × 陶土强调色

将日期范围选择器置于一个真实的运营数据筛选场景中：用户在「统计区间」筛选器里选择日期范围，面板联动更新订单量、营收、客单价、退款率四个指标及柱状趋势图。组件是主角，展示页克制服务。

**设计 DNA**：暖纸档案底（#f4ecd8）模拟泛黄纸张的档案质感，陶土橙（#c46b3c）作为强调色传达操作焦点，整体低饱和、高对比，适合长时间数据浏览。

## 4. 动效系统

### 时长与缓动
| 变量 | 值 | 用途 |
|------|-----|------|
| `--dur-fast` | `120ms` | 悬停/颜色过渡 |
| `--dur-base` | `200ms` | 月份切换/按钮 |
| `--dur-slow` | `220ms` | 面板展开 |
| `--ease` | `cubic-bezier(0.4, 0, 0.2, 1)` | 标准缓动 |
| `--ease-spring` | `cubic-bezier(0.34, 1.56, 0.64, 1)` | 弹性（选中日弹跳） |

### 关键动画
| 名称 | 触发场景 | 实现 |
|------|---------|------|
| 面板展开 | 打开弹层 | `opacity 0→1` + `translateY(-6px) scale(0.98) → (0,1)` 220ms |
| 箭头旋转 | 开关面板 | `caret rotate(180deg)` 200ms |
| 选中日弹跳 | 点击日期 | `drp-pop`: scale `0.85→1.08→1` 200ms spring |
| 月份滑入 | 上/下月导航 | `slide-in-right/left`: `translateX(±20px)→0 + opacity 0→1` 200ms |
| 柱状图过渡 | 数据更新 | `height transition` 200ms |

### 无障碍降级
```css
@media (prefers-reduced-motion: reduce) {
  :root { --dur-fast: 0ms; --dur-base: 0ms; --dur-slow: 0ms; }
  .drp-panel { transition: opacity var(--dur-slow) var(--ease); transform: none; }
  .drp-day.range-start.selected-anim,
  .drp-day.range-end.selected-anim { animation: none; }
  .drp-cal-grid-wrap.slide-next-enter,
  .drp-cal-grid-wrap.slide-prev-enter { animation: none; }
}
```
所有动画时长归零，面板/选中日/月份切换保持功能完整但不产生运动。

## 5. 组件状态机

| 状态 | 触发器表现 | 面板表现 |
|------|-----------|---------|
| `rest` | 默认边框 | 关闭 |
| `hover`（触发器） | 边框加深 + 底色变暖 | — |
| `focus` | 陶土边框 + 3px pale 光环 | — |
| `open` | 箭头旋转 180° | 展开 |
| `selecting-start` | 显示起止日期 | 鼠标悬停预览范围 |
| `selecting-end` | 显示起止日期 | 鼠标悬停预览范围（含翻转） |
| `has-range` | 显示范围 + 天数 + 清除按钮 | 底部显示已选天数 |
| `disabled` | 灰底不可点 | — |
| `error` | 错误色边框 + 红底 + 错误提示 | — |

共 **9 个状态**，满足「至少 5 个」要求。

## 6. 交互语义

- **范围预览**：选中起始日后，鼠标悬停其他日期实时显示预期范围条
- **自动翻转**：第二次点击日期早于起始日时，自动交换起止（翻转语义）
- **手动输入**：触发器内可直接键入 `YYYY-MM-DD ~ YYYY-MM-DD`，Enter 或 blur 时校验
- **预设快捷**：今日/昨日/本周/上周/本月/上月/最近7天/最近30天/本季度
- **禁用日期**：维护日（划线不可选）、minDate/maxDate 边界钳制、指定星期禁用
- **键盘导航**：方向键移动焦点日、Enter 选择、Esc 关闭、Tab 在面板内循环

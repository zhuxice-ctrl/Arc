用法说明

快速上手 3 步

  1. 从本文件复制 .drp-* 样式块与 JS 逻辑到你的项目
  2. 在页面放置触发容器 <div id="drp-trigger">
  3. 调用 new DateRangePicker(el, options) 初始化
// 最小化用法
const drp = new DateRangePicker('#my-trigger', {
  presets: true,
  onConfirm: (range) => {
    console.log(range.start, range.end, range.days)
  }
});

配置项

  • presets — 是否显示预设侧栏，默认 true
  • minDate / maxDate — 可选范围边界
  • disabledDates — 禁用日期数组（YYYY-MM-DD）
  • disabledDaysOfWeek — 禁用星期 [0-6]
  • startDate / endDate — 初始选中范围
  • showFooter — 显示底部确认栏，默认 true
  • onConfirm / onChange / onOpen / onClose — 回调

主题定制 CSS 变量

--drp-accent主色/强调色
--drp-accent-pale区间淡填充
--drp-bg面板背景
--drp-ink文字主色
--drp-border边框色
--drp-radius圆角大小
--drp-font-size基础字号
--drp-duration基础动画时长

改 --drp-accent 一处即可整体换色。若需深度定制，覆盖 --drp-* 变量即可，无需改源码。

状态机

  • rest — 默认未选择状态
  • hover-day — 日期悬停预览
  • selecting-start — 已选起点，待选终点
  • selecting-end — 终点选择中（实时预览区间）
  • has-range — 已完整选择区间
  • keyboard-focus — 键盘聚焦态（可见焦点环）
  • disabled — 组件整体禁用
  • invalid — 手动输入越界/格式错误

键盘操作

  • Tab 聚焦触发器 → Enter/Space 打开面板
  • ← → 日期左右移动，自动跨周跨月
  • ↑ ↓ 切换上/下一周的同一天
  • PageUp / PageDown 切上/下月
  • Home / End 跳到周首/周末
  • Enter 选定日期起点或终点
  • Esc 关闭面板，焦点返回触发器

API 方法

  • drp.open() — 打开面板
  • drp.close() — 关闭面板
  • drp.getRange() → {start, end, days}
  • drp.setRange(start, end) — 编程式设置范围
  • drp.setDisabled(bool) — 切换禁用态
  • drp.destroy() — 销毁实例，解绑所有事件

可抽取性说明

组件完全自包含，无外部依赖。抽取到其他项目只需：① 复制全部 .drp-* 前缀的 CSS 规则；② 复制 DateRangePicker 类（位于脚本底部 IIFE 内）；③ 替换触发器 DOM 结构（或让 new DateRangePicker() 自动生成）。样式全部通过 --drp-* CSS 变量暴露，改 3 处即可适配新项目主题。

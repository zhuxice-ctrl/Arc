# 设计规范 · 苔径 · 分页与进度组件（2026-08-20）

> 从 `index.html` 源码提取的真实色值、字体、动效系统。主题「苔径」——苔藓绿主色 + 蜜黄强调，纸白底墨色字，浅色克制、无渐变堆叠。

## 一、色彩系统（CSS 变量）

| 变量 | 色值 | 用途 |
|---|---|---|
| `--color-bg` | `#FBF9F4` | 纸白底 |
| `--color-bg-2` | `#F2EFE6` | 次级底 / hover 底 |
| `--color-fg` | `#23281F` | 墨色正文 |
| `--color-fg-2` | `#5A5F55` | 次级文字 |
| `--color-fg-3` | `#8C9186` | 弱文字 |
| `--color-primary` | `#3E6B48` | 苔绿主色（当前页/进度/激活） |
| `--color-primary-hover` | `#315638` | 主色 hover |
| `--color-primary-active` | `#26422B` | 主色 active |
| `--color-primary-soft` | `#E5EDE3` | 主色软底（active-bg / success-soft） |
| `--color-accent` | `#E3B23C` | 蜜黄强调（焦点环 / 高亮） |
| `--color-accent-soft` | `#FBF1D6` | 强调软底 |
| `--color-border` | `#D9D6CB` | 常规边框 |

主色阶：`#3E6B48` → `#315638`(hover) → `#26422B`(active)，配 `#E5EDE3` 软底构成苔绿 4 阶。无蓝紫渐变。

## 二、字体

- `--font-sans`：系统无衬线栈（PingFang SC / Microsoft YaHei / -apple-system / Segoe UI / sans-serif），中文为主。
- 数字 / 百分比 / 页码：同 sans，`font-variant-numeric: tabular-nums` 等宽对齐。
- 无外部字体、无 CDN。

## 三、圆角与间距

- `--radius-sm` 4px / `--radius-md` 8px / `--radius-lg` 12px。
- 分页按钮 `--pg-radius: var(--radius-md)`；进度条 `--pr-radius: var(--radius-sm)`。
- 分页：`--pg-height: 32px`、`--pg-item-min-w: 32px`、`--pg-gap: 4px`、`--pg-font-size: 13px`。
- 进度条：`--pr-height: 8px`；环形 `--pr-circle-size: 72px`、`--pr-circle-stroke: 6px`；步骤 `--pr-step-size: 28px`。

## 四、动效系统

| 语义 | 时长 | 曲线 | 应用 |
|---|---|---|---|
| 轻量切换 | 250ms | `cubic-bezier(0.34,1.56,0.64,1)` 弹簧 | 分页当前页指示块滑入 |
| 状态过渡 | 300ms | `ease-out` | 进度条 determinate 值变化、骨架淡入 |
| 强调收笔 | 400ms | `ease-out` | 进度 success 勾号 stroke-dashoffset 描边 |
| 加载循环 | 1.2s | `linear` infinite | indeterminate 条形流动、环形旋转 |
| 禁用/错误 | 200ms | `ease` | 跳转输入 error 抖动 |

- `prefers-reduced-motion: reduce` 全局降级：动画时长 → 0.01ms、循环次数 → 1、过渡 → 0.01ms。
- RAF / 定时器：`visibilitychange` 隐藏时清除加载定时器；快速点击 `_loading` 锁防叠加。

## 五、组件状态机

**分页 Pagination**（≥7 态）：rest / hover / focus（焦点环 2px accent）/ active / disabled（边界首末页 + 状态展示柜）/ loading（列表骨架 600ms 模拟异步）/ error（跳转非法值抖动 + aria-invalid）。

**进度 Progress**：
- 条形 5 态：determinate（0-100 可控）/ indeterminate（循环）/ buffer（双层 已加载+缓冲）/ success（变绿勾描边）/ error（变红）。
- 环形：determinate 带 %，SVG `stroke-dashoffset`。
- 步骤条 4 态节点：未完成 / 当前 / 完成 / 错误。

## 六、可访问性

- 键盘：Tab 可达全部控件；分页 ← → 翻页、Home/End 首末页、Enter 跳转、Esc 清空跳转输入；焦点环 `--pg-focus-ring: 2px solid var(--color-accent)`。
- 焦点管理：分页 `render()` 重建后自动把焦点恢复到当前页按钮，保证连续键盘导航不中断。
- aria：`aria-current="page"`（当前页）、`aria-disabled`、`aria-label`（首页/上一页/…/跳转页码/每页条数）、`role="progressbar"` + `aria-valuenow/min/max`。
- 触屏：点击区域 ≥32px；系统光标语义化（pointer/not-allowed/text）。

## 七、技术栈

纯 vanilla 单文件（HTML + CSS + JS），无 React / Babel / CDN / 外部字体图片。四个独立类 `Pagination` / `ProgressBar` / `Steps`（+ 环形复用 ProgressBar）可独立抽取，CSS 变量前缀 `--pg-*`（分页）/ `--pr-*`（进度）+ 主题变量 `--color-*` 主题化。

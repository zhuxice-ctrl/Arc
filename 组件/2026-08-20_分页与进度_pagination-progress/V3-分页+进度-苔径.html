📖 用法文档

分页 Pagination

生产级分页组件，支持完整模式与紧凑模式，页码折叠逻辑正确，键盘可达，跳转输入校验。

初始化：

const pg = new Pagination('#el', {
  total: 237,
  pageSize: 10,
  current: 1,
  mode: 'full',   // 'full' | 'compact'
  showJumper: true,
  showSizeChanger: true,
  onChange: (page, pageSize) => {}
});

CSS 变量（部分）：

  • --pg-height32px
  • --pg-item-min-w32px
  • --pg-current-bg#3E6B48
  • --pg-radius6px

进度 Progress

多形态进度指示：条形、环形、步骤条。支持确定/不确定/缓冲/成功/错误五态，CSS 变量主题化。

条形用法：

const bar = new ProgressBar('#el', {
  value: 0,
  status: 'normal', // normal|success|error
  showCheck: true
});
bar.set(65);
bar.success();

CSS 变量（部分）：

  • --pr-height6px
  • --pr-bar#3E6B48
  • --pr-success#3E6B48
  • --pr-error#B84A3C

可抽取性

两个组件均为自包含 vanilla JS 类，CSS 变量集中在 :root。复制到新项目只需 3 步：

1. 复制 Pagination / ProgressBar / ProgressCircle / Steps 类

2. 复制对应的 CSS 块（--pg-* 与 .pagination / --pr-* 与 .progress-*）

3. 修改 3-5 个主题变量即可换肤

无障碍：aria-current / aria-disabled / aria-label / role 完整，Tab 全可达。

键盘操作

分页组件：

  • Tab 依次聚焦各控件
  • ← / → 上一页 / 下一页
  • Enter / Space 触发页码
  • Home / End 首页 / 末页
  • Esc 清除跳转输入

步骤条：

  • Tab 聚焦步骤组
  • ← / → 切换步骤

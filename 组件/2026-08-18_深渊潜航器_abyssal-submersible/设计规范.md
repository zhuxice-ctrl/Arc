# 深渊潜航器 · 设计规范

## 场景设定

老式潜水艇指挥舱——黄铜仪表、压力舷窗、声呐与车钟。每个展区是一个可上手把玩的拟物化微交互装置，全部由鼠标光标悬停 / 点击 / 拖拽驱动。

## 色彩系统

| 角色 | 色值 | 用途 |
|---|---|---|
| 主色 · 琥珀橙 | `#ff8a2a` / `#ffaa55` / `#ffd57a` | 仪表读数、灯罩发光、强调 |
| 警报红 | `#d4483a` / `#ff6a4a` | 警报信号灯、危险态 |
| 深青铜绿 | `#2d5e53` | 舱体金属、面板底色 |
| 背景 · 炭黑 | `#140e0a` / `#1a1410` | 舱内暗环境 |
| 表面 · 米白 | `#f5e6c8` / `#e8dcc0` / `#e8d9c0` | 仪表盘纸面、标签 |
| 点缀 | `#e5d09c` / `#fff5d0` / `#ffffff` | 高光、玻璃反光 |

「深青铜 + 琥珀橙 + 墨绿炭黑」三色体系，避开蓝紫渐变。

## 字体排印

- 标题 / 仪表：`PingFang SC, Microsoft YaHei, Noto Serif SC, serif`
- 装饰：`Georgia, serif`
- 读数 / 电文：`Courier New, monospace`

## 展区组件（11 个装置）

1. **深度计** — 拖拽滑杆，指针弹簧阻尼缓动，数字同步读数
2. **磁罗盘** — 光标靠近时磁针按反平方律磁力吸引，阻尼回弹归位
3. **舱门手轮** — 点击旋转 90°，六枚锁舌逐一弹开，黄铜把手落位
4. **节流阀门** — 点击逐级开启，铜轮旋转伴随流量条递增
5. **观察舷窗** — 深海生物多层视差游动，玻璃反光随光标偏移
6. **声呐探测** — 点击发射，扇形扫描区随机生成回波目标
7. **警报信号灯** — 拨动黄铜开关，红灯脉冲光晕扩散
8. **摩尔斯电键** — 短按发点、长按发划，弹簧回弹手感
9. **压载水舱** — 注水 / 吹除按钮，液面缓动升降，气泡升腾
10. **引擎车钟** — 拖拽手柄切换档位，磁吸咔嗒落位
11. **信号灯** — 按住点亮，黄铜灯罩拟物质感

## 动效系统

自定义光标（开页居中 + 惯性跟随 + 悬停形变 + 点击涟漪）、弹簧深度计、反平方律磁吸罗盘、旋转手轮 / 阀门、多层视差舷窗、声呐扫描 + 回波、警报脉冲发光、电报键回弹、气泡升腾 + 液面缓动、车钟磁吸档位、打字机底部文字、滚动渐入、卡片 3D 倾斜。

## 健壮性

- 纯 vanilla HTML/CSS/JS 单文件，零外部依赖
- `visibilitychange` 自动暂停动画循环，`beforeunload` 统一清理
- 定时器先清后建，快速操作不叠加
- 高频鼠标事件直接操作 DOM transform
- 完整 `prefers-reduced-motion` 降级

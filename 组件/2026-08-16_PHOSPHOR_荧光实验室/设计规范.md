# PHOSPHOR 荧光交互实验室 · 设计规范

> 2026-08-16 · V3 · UX 交互设计

## 主题

荧光 / 辉光物质为意象的炫技特效实验室

## 配色

石墨黑 #101014 + 荧光青 #2DE1C2 + 冰蓝白 #DFF6FF

（严格禁蓝紫渐变）

## 字体

系统无衬线 + 等宽字体

## 动效设计

辉光粒子引力场 / 电磁拉丝 / 荧光字形解构 / 磁力按钮 / 磷光频谱 / 信号尾迹

## 技术实现

- 单文件 HTML 实现（CSS + JS 全内联）
- 自定义光标开页即居中显示
- RAF 统一管理，visibilitychange 自动暂停/恢复
- 支持 prefers-reduced-motion 降级
- 无外部 JSX 引用，无外部本地文件依赖

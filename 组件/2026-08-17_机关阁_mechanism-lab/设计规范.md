# 机关阁 设计规范

> 日期：2026-08-17 · 方向：V3 UX 交互设计 · 主题：拟物化微交互实验室

## 色彩系统

| 色彩角色 | 色值 | 用途 |
|---------|------|------|
| 黄铜 | `#B8860B` | 主色，金属装置、装饰线 |
| 黄铜亮 | `#D4A628` | 高光态，金属反光 |
| 暖琥珀 | `#E8A535` | 强调色，灯光、指示灯 |
| 琥珀亮 | `#F5C058` | 灯光高亮态 |
| 铜绿 | `#4A7C6B` | 次强调色，氧化铜质感 |
| 铜绿亮 | `#6A9C8B` | 铜绿高光 |
| 深胡桃 | `#3E2A1A` | 木质装置底色 |
| 皮革棕 | `#8B5E3C` | 皮革质感、抽屉面板 |
| 炭黑 | `#1A1510` | 背景主色，深色工坊底 |
| 暗木 | `#241D15` | 区块底色 |
| 暖白 | `#F5E6C8` | 文字主色、灯光色 |
| 灯光白 | `#FFF8E0` | 灯泡亮起色 |

## 字体系统

- 正文：`"PingFang SC", "Microsoft YaHei", sans-serif`
- 标题：`"Songti SC", "STSong", serif`（衬线体呈现古典工坊感）
- 品牌字：`"Songti SC", "STSong", "Noto Serif SC", serif`

## 圆角与间距

- 装置容器：无圆角（方正机械感）或 4px 微圆角
- 按钮/开关：2px（锐利金属感）
- 卡片：8px
- 展区间距：100px 垂直
- 最大宽度：900px 居中

## 组件规范

- 自定义光标：白色粗环(3px) + 黄铜内点(6px) + 三层发光，z-index 99999，三态切换（默认/悬停/拖拽）
- 展区导航：左侧固定竖向导航，IntersectionObserver 高亮当前展区
- 拉绳灯：Canvas/CSS 绘制黄铜拉绳，简谐运动+阻尼摆动，拖拽弹性拉伸
- 黄铜拨杆：CSS 3D 旋转，弹簧回弹+惯性，指示灯亮灭
- 罗盘转盘：拖拽旋转，惯性+阻尼衰减，磁针双频正弦颤动
- 木盒暗锁：Hooke 定律弹簧压缩，盒盖旋转翻开
- 磁力旋钮：反平方引力吸附到刻度，仪表指针跟随
- 抽屉滑轨：摩擦阻尼+惯性滑动+限位回弹

## 动效系统

| 编号 | 动效 | 物理模型 |
|------|------|---------|
| 1 | 自定义光标三态 | 鼠标位置追踪，DOM transform |
| 2 | 拉绳摆动 | 简谐运动 θ(t) = A·cos(ωt)·e^(-γt) |
| 3 | 拉绳弹性拉伸 | 弹簧 F = -k·x |
| 4 | 灯泡光扩散 | 光强度随距离衰减 I ∝ 1/r² |
| 5 | 拨杆回弹 | 弹簧+阻尼振荡 |
| 6 | 指示灯亮灭 | 指数衰减发光 |
| 7 | 罗盘惯性旋转 | 角速度衰减 ω(t) = ω₀·e^(-γt) |
| 8 | 磁针颤动 | 双频正弦叠加 sin(ω₁t) + 0.3·sin(ω₂t) |
| 9 | 弹簧压缩回弹 | Hooke 定律 F = -k·x |
| 10 | 盒盖翻开 | 旋转+弹性回弹 |
| 11 | 磁力吸附 | 反平方引力 F ∝ 1/r² |
| 12 | 仪表指针跟随 | 线性插值+阻尼 |
| 13 | 抽屉滑轨 | 摩擦力+惯性+限位反弹 |
| 14 | 点击涟漪 | 圆形扩散+透明度衰减 |

## 展区结构

1. 首屏：深色工坊背景 + 标题「机关阁」+ 副标题 + 滚动提示
2. 拉绳灯展区：黄铜拉绳开关，拖拽点亮灯泡
3. 黄铜拨杆展区：三个拨杆控制不同氛围
4. 罗盘转盘展区：可旋转黄铜罗盘，惯性+磁针颤动
5. 木盒暗锁展区：弹簧锁扣木盒，按压弹开
6. 磁力旋钮展区：磁力吸附旋钮，旋转带动仪表
7. 抽屉滑轨展区：三个叠放抽屉，拖拽拉开
8. 页脚：署名信息

## 技术栈

纯 vanilla HTML/CSS/JS 单文件实现，无 React/Babel/外部 CDN 依赖，requestAnimationFrame 物理模拟。

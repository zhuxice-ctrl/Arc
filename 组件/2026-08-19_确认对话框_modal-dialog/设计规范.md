## 3. 动效系统

### 过渡

| 元素 | 属性 | 时长 | 缓动 |
|------|------|------|------|
| 遮罩层 | `opacity` | `180ms` | `cubic-bezier(0.2,0.8,0.2,1)` |
| 对话框 | `transform` | `180ms` | `cubic-bezier(0.2,0.8,0.2,1)` |
| 按钮 | `background, color` | `150ms` | `ease` |
| 输入框 | `border-color, box-shadow` | `150ms` | `ease` |

### 关键帧

| 名称 | 描述 |
|------|------|
| `modal-spin` | 确认按钮 loading 旋转动画，`0.7s linear infinite`，`0deg → 360deg` |

### 入场/退场

- **入场**：backdrop `opacity: 0→1`，dialog `translateY(8px) scale(0.98) → translateY(0) scale(1)`
- **退场**：反向播放入场动画

### 降级

```css
@media (prefers-reduced-motion: reduce) {
  :root { --modal-duration: 0ms; }
}
```

所有过渡绑定到 `--modal-duration` 变量，设为 `0ms` 即瞬间完成，无动画。

## 4. 状态机（8 态）

| 状态 | 触发 | 视觉表现 |
|------|------|----------|
| **rest** | 默认 | 按钮正常色，输入框默认边框 |
| **hover** | 鼠标悬停 | 按钮 `--modal-primary-hover`，输入框边框微深 |
| **focus** | 键盘/点击聚焦 | `outline: 2px solid --modal-focus-ring`，输入框边框变 `--modal-input-focus` |
| **active** | 按下 | 按钮 `--modal-primary-active`，`translateY(1px)` |
| **disabled** | 关键词未匹配/loading | 按钮 `--modal-primary-disabled`，`cursor: not-allowed`，`opacity: 0.5` |
| **loading** | 异步 onConfirm 返回 Promise | 确认按钮添加 `.is-loading`，旋转 spinner，按钮+取消按钮均 disabled |
| **success** | Promise resolve | dialog 添加 `.is-success`，显示成功面板（绿色 check 图标 + 标题 + 描述），`successDuration` 后自动关闭 |
| **error** | Promise reject / 关键词不匹配 | 输入框边框变红，hint 文字变红 |

## 5. 尺寸系统

| 尺寸 | 最大宽度 | 适用场景 |
|------|----------|----------|
| `sm` | 360px | 简单确认 |
| `md` | 440px（默认） | 标准确认 |
| `lg` | 600px | 长文本/表单 |

- 圆角：`--modal-radius: 10px`
- 按钮：高度 `36px`，圆角 `6px`
- 输入框：高度 `36px`，圆角 `6px`
- 阴影：`0 24px 60px -12px rgba(20,18,15,0.25), 0 8px 24px -8px rgba(20,18,15,0.18)`

## 6. 键盘交互

| 按键 | 行为 |
|------|------|
| `Tab` | 焦点在对话框内循环（focus trap） |
| `Shift+Tab` | 反向循环 |
| `Enter` | 触发确认（非输入框/textarea 内时） |
| `Escape` | 关闭对话框（`closable: true` 时） |
| 输入框内 `Enter` | 关键词匹配时触发确认 |

## 7. 响应式

- `≤480px`：对话框变为底部弹出（bottom sheet），按钮纵向堆叠，宽度撑满
- `≤720px`：展示页内边距缩小，标题缩放

## 8. 可访问性

- `role="dialog"` + `aria-modal="true"` + `aria-labelledby` 指向标题
- 焦点管理：打开时聚焦确认按钮/输入框，关闭时恢复原焦点
- 焦点陷阱：Tab/Shift+Tab 在对话框内循环
- `prefers-reduced-motion` 支持
- 焦点环可见（`outline: 2px solid`，非 `outline: none`）

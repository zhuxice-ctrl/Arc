Modal 确认对话框

生产级可复用弹窗组件。焦点陷阱、键盘导航、异步确认流转、 危险操作二次确认、Esc 与遮罩关闭、焦点恢复。 纯 vanilla 实现，CSS 变量主题化，零依赖可抽取。

功能概览

覆盖 8 种核心能力，状态机完整。

  • 焦点陷阱Tab 在弹窗内循环，不溢出到背景
  • 键盘导航Esc 关闭、Enter 确认、Space 触发按钮
  • 焦点恢复关闭后焦点回到触发元素
  • 异步确认loading → success 状态流转
  • 危险确认需输入指定文字才能确认
  • 无障碍aria-modal / aria-labelledby / role=dialog
  • 响应式移动端底部贴边，按钮堆叠
  • 主题化所有视觉变量通过 CSS 变量暴露

用法

引入 CSS 与 JS，调用 Modal.confirm() 即可。

基础确认

最简单的二选一对话框，返回 Promise，true 表示确认，false 表示取消。

const ok = await Modal.confirm({
  title: '确认删除这份草稿？',
  content: '删除后无法恢复，确定继续吗？',
  confirmText: '删除',
  variant: 'warn'   // 'warn' | 'danger' | 'info' | 'success'
});
if (ok) { /* 执行删除 */ }

危险操作（输入确认）

高危操作需用户输入指定关键词才解锁确认按钮。

const ok = await Modal.confirm({
  title: '永久注销账户',
  content: '注销后所有数据将被清除，且无法恢复。',
  variant: 'danger',
  confirmText: '确认注销',
  requireKeyword: '注销账户',
  keywordHint: '请输入「注销账户」以确认操作'
});

异步确认

onConfirm 返回 Promise 时，确认按钮自动进入 loading；resolve 后展示 success 面板再关闭。

await Modal.confirm({
  title: '发布到生产环境',
  content: '将当前版本部署到所有节点，预计耗时 2 分钟。',
  confirmText: '立即发布',
  onConfirm: async () => {
    await fetch('/api/deploy', { method: 'POST' });
  }
});

选项完整列表

  • title — 标题
  • content — 正文（字符串或 HTML 字符串）
  • variant — 图标变体：warn / danger / info / success / none，默认 warn
  • confirmText / cancelText — 按钮文案
  • confirmType — 确认按钮样式：primary / danger，默认 primary
  • size — 尺寸：sm / md / lg
  • onConfirm — 确认回调，返回 Promise 则进入 loading 状态
  • onCancel — 取消回调
  • closable — 是否显示关闭按钮 / 允许 Esc / 点击遮罩关闭，默认 true
  • closeOnBackdrop — 点击遮罩是否关闭，默认 true
  • requireKeyword — 危险确认关键词，设置后需输入匹配才解锁确认按钮
  • keywordHint — 输入框下方提示文案
  • successTitle / successDesc — 异步成功面板文案
  • successDuration — 成功面板停留时长（ms），默认 900

主题变量

覆盖 CSS 变量即可定制外观：

:root {
  --modal-primary: #2d6a4f;
  --modal-danger: #9d0208;
  --modal-radius: 14px;
  --modal-btn-height: 40px;
  --modal-focus-ring: 2px solid #2d6a4f;
}

状态一览

状态说明
rest初始渲染，首元素获得焦点
hover按钮悬停反馈
focus键盘焦点环可见，Tab 循环
active按钮按下态
disabled确认按钮禁用（关键词未输入 / 加载中）
loading异步确认中，按钮旋转指示
success异步成功面板，短暂展示后自动关闭
error关键词不匹配 / 提交失败时的输入框错误态

# 弹珠台发射器 · Pinball Plunger

**类别**：组件 Mock　**日期**：2026-08-19

## 主题
复古弹珠台的弹簧柱塞——可反复把玩的物理手感交互组件。

## 简介
一个聚焦极致手感的单组件交互实验室。光标抓取黄铜旋钮向下拖拽压缩弹簧（非线性阻力），释放后弹簧以阻尼振荡回弹，深红弹珠沿发射轨道射出。完整实现五层交互结构：预接触抬起 → 接触按压 → 持续拖拽（非线性阻力+刻度实时更新）→ 阈值微振 → 释放回弹+弹珠发射。阻尼谐振子物理模型（ζ=0.46，ωₙ=13.5），约800ms衰减至静止。

## 技术栈
纯 vanilla HTML + CSS + JS，无外部依赖。RAF 主循环物理模拟，SVG 弹簧实时绘制，document.hidden 暂停，prefers-reduced-motion 降级。

## 核心交互
- 抓取柱塞旋钮向下拖拽（非线性弹簧阻力）
- 超过 80% 压缩时阈值微振 + 满力提示
- 释放后阻尼弹簧回弹 + 弹珠发射
- 弹珠重力回落 + 柱塞振荡衰减（约 800ms）
- 三态自定义光标（准星/抓取/紧握）

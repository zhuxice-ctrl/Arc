# 设计规范 · 百草堂 · 中药铺拟物交互馆

> 日期：2026-08-17 · 方向：V3 UX 交互设计 · 主题：中药铺拟物化小组件交互实验室

## 色彩系统

主色取自老式中药铺的木质药柜、宣纸与朱砂。

| 角色 | 色值 | 用途 |
|---|---|---|
| 深木棕 | `#3B2A1E` / `#2A1810` | 药柜、主背景木纹 |
| 宣纸米白 | `#F4EBD8` | 纸面、印泥盒、文字 |
| 朱砂红 | `#B03A2E` / `#7A2018` | 印章、强调、朱砂 |
| 铜金 | `#A87C3F` / `#7A5233` | 铜环、戥子秤、铜臼 |
| 药青灰 | `#5B6B4A` | 药材点缀、药青 |
| 暗木 | `#24130A` / `#1A0E04` | 深层阴影、抽屉内壁 |

禁止蓝紫渐变。

## 字体

全中文界面，标题用粗黑体，药材名用楷体感衬线，读数用等宽。

## 展区与组件规范

| 展区 | 操作 | 拟物效果 |
|---|---|---|
| 壹 · 药柜抽屉 | 拖拽 / 点击抽屉 | 弹簧阻尼滑轨、铜环晃动、药材名签 |
| 贰 · 戥子秤药 | 拖拽铜砝码 | 力矩物理倾斜、秤杆摆动阻尼回稳、读数 |
| 叁 · 捣药铜臼 | 拖拽研杵画圈 / 下压 | 臼底支点旋转、研磨震动、药材颗粒飞溅 |
| 肆 · 珠算算盘 | 拨动算珠 | 惯性碰撞、弹簧吸附落位、进位读数 |
| 伍 · 朱砂印章 | 拖拽蘸砚台再按压 | 蘸墨检测、按压力度决定浓淡、印泥晕开 |
| 陆 · 油灯拉绳 | 下拉灯绳 | 下拉阻尼回弹、灯绳单摆、全局灯光明灭 + 阴影扩散 |

## 动效系统

1. 自定义光标（白环 + 朱砂内点 + 发光，悬停放大，拖拽变抓手，点击涟漪，开页居中）
2. 抽屉弹簧阻尼滑轨
3. 铜环晃动（单摆物理）
4. 戥子秤杆力矩倾斜 + 阻尼回稳
5. 研杵绕臼底旋转 + 研磨震动
6. 药材颗粒重力粒子飞溅
7. 算珠惯性碰撞 + 弹簧吸附
8. 印章蘸墨检测 + 印泥晕开
9. 油灯灯绳单摆 + 阻尼回弹
10. 全局灯光明灭 + 阴影扩散
11. 纸面纹理 + 木纹质感
12. 各展区入场渐入

## 技术栈

纯 vanilla HTML/CSS/JS 单文件，无 React / 无 Babel / 无外部 CDN 依赖。统一 RAF 管理器，visibilitychange 自动暂停，卸载统一取消。

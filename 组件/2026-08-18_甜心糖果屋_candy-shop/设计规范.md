## 展区结构（6 个独立装置）

1. **拉杆糖果机** — 下拉拉杆，齿轮联动，糖果球从出糖口蹦落弹跳（重力+弹性碰撞）
2. **转盘称重器** — 拖拽旋转刻度盘，指针带阻尼惯性摆动，读数实时显示（惯性动量+阻尼）
3. **拉绳门铃** — 下拉绳结，铃锤敲击铜铃，铃铛晃动 + 声波涟漪扩散（弹簧+阻尼）
4. **玻璃糖果柜** — 左右双门拖拽滑动，惯性 + 摩擦减速，展示柜内三层糖果（摩擦+惯性）
5. **按压泡泡糖机** — 按住顶部按钮，螺旋杆转动，糖球逐颗上升并滚落出口（连续转动+重力）
6. **摇杆糖浆搅拌器** — 绕圈拖拽摇杆，搅拌桨搅动糖浆，旋涡光泽旋转（圆周运动+旋涡光泽）

## 动效系统

| 动效 | 物理模型/主题语义 |
|------|------|
| 自定义光标 | 白环 + 草莓粉内点 + 多层发光，悬停放大变薄荷绿，拖拽变焦糖色，点击涟漪 |
| 拉杆下拉 | 齿轮联动 + 糖果重力弹跳滚动 |
| 转盘旋转 | 指针惯性摆动 + 阻尼停顿 |
| 拉绳铃铛 | 弹簧回弹 + 铃锤摆动 + 声波涟漪扩散 |
| 柜门滑动 | 惯性 + 摩擦减速 |
| 泡泡糖机螺旋 | 连续转动 + 糖球上升轨道 |
| 摇杆搅拌 | 圆周拖拽 + 旋涡光泽旋转 |
| 糖果反光 | 光泽渐变扫过 |
| 装置入场 | 滚动渐入 opacity+translateY |
| 装置悬停 | 轻微上浮 + 阴影增强 |
| 数字读数 | 实时跟随转盘角度更新 |
| 背景装饰 | 糖果粒子缓慢漂浮 |

所有拖拽直接操作 DOM transform，不走 React setState；物理模型用 RAF 积分器实现弹簧/惯性/摩擦/阻尼。

## 技术栈

纯 vanilla HTML/CSS/JS 单文件实现，无 React / 无 Babel / 无外部 CDN 依赖。requestAnimationFrame 随 visibilitychange 自动暂停，beforeunload 统一清理；支持 prefers-reduced-motion 全量降级。

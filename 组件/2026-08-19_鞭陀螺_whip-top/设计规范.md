# 鞭陀螺 · 抽陀螺物理组件 — 设计规范

**类别**：Component Mock　**日期**：2026-08-19

## 设计概念
一个可以反复把玩的抽陀螺：把鞭绳一圈圈缠上枣木陀螺，按住鞭柄向左猛拉，陀螺脱手飞旋——角速度、进动摇晃、摩擦衰减，全部真实可感。单一中心舞台：青砖地面上一枚陀螺，就是全部世界。

## 色彩系统（真实色值，取自源码）
- 青砖：`--brick-line #232a26` / `--brick-highlight #5d7066`（地面砖缝与砖面高光）
- 枣木：`--wood-dark #6b2a1e` / `--wood-mid #8b3a2a` / `--wood-light #a8503a` / `--wood-grain #5a1f15`（陀螺木身与木纹）
- 棉绳：`--rope-color #e8e0cc` / `--rope-shadow #b8ad8f`（鞭绳）
- 朱漆记：`--vermilion #c23a1f` / `--vermilion-dark #8e2a15`（陀螺顶端朱记、强调）
- 纸面文字：`--paper #f2ede0` / `--text-main #e8e3d4` / `--text-dim #9aa39c` / `--ink #1a1f1c`

无蓝紫渐变。配色与同日 V1（墨绿+金铜）、V2（胡桃木+奶油+黄铜）互不雷同。

## 字体系统
Noto Serif SC / Songti SC / SimSun（衬线，器物图鉴感）。

## 交互机制（操作闭环）
缠绕（绳圈可视地缠上陀螺）→ 按住鞭柄向左拉动（张力渐增、绳圈逐圈解开、陀螺预旋）→ 绳尽脱手（初始角速度由拉动距离与速度决定）→ 旋转（高速自旋 → 进动摇晃 → 摩擦衰减 → 失稳摇摆 → 缓缓倒下）。右下角 ↺ 可再抽一次。

## 五层反馈
预接触（光标接近时陀螺微晃、近柄放大提示）→ 接触（抓握咬合顿挫、光标变形）→ 持续（绳长/张力/解圈/预旋角速度逐帧对应，左侧张力条实时显示）→ 阈值（绳尽瞬间脱手、爆发闪光、满力一抽屏幕轻震）→ 释放/衰减（惯性自旋十余秒、进动圆锥摇摆、末段章动失稳、重力倒下多次弹跳、落地扬尘）。

## 物理模型
角速度指数衰减；进动角随角速度降低而增大（实测界面实时显示转速 rpm 与进动角，如 60 rpm / 33.5°）；倒下前失稳抖动；阴影随倾斜与进动实时跟随。不同拉力产生明显不同的转速、稳定度与旋转时长。

## 动效系统（16 组件级）
预接触微晃、近柄放大、抓握光标变形、绳圈解绕、预旋角速度随拉速变化、张力条、释放爆发闪光、绳屑棉絮粒子、满力屏幕轻震、高速旋转残影拖尾、进动圆锥摇摆、末段章动抖动、摩擦指数衰减、重力倒下弹跳、落地扬尘、阴影实时跟随。

## 自定义光标
鞭梢形，开页即显示在屏幕中央，高对比、层级最高；抓握时变形。

## 工程
纯 vanilla HTML/CSS/JS 单文件（无 React / Babel / CDN）；高频鼠标事件直接操作 DOM + requestAnimationFrame；RAF 随可见性暂停、卸载取消；快速连续操作不叠加定时器；支持 prefers-reduced-motion（降级系统光标与简化动效）；零未定义引用；1440px 与 390px 均无 console error、无横向溢出。

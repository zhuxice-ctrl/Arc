# 机巧堂 · 古法机械工坊交互实验室

> 日期：2026-08-17 · 方向：V3 UX 交互设计 · 主题：光标驱动拟物化小组件动画实验室

## 简介

「机巧堂」是一个以古法机械装置为展品的拟物化微交互实验室。每个展区是一个独立的、有场景叙事的拟物化微交互装置——灯绳开关、日月拨轮、铜钮机簧、黄铜转盘、拉杆电闸、磁吸罗盘，全部由鼠标光标悬停/点击/拖拽触发，反馈细腻、有物理质感。配色以黑胡桃深棕+黄铜金+古铜为主调，营造老式工坊的暖金属质感。

## 动效亮点

- 灯绳重力下垂与回弹摆动（Hooke 弹簧 + 阻尼 RAF 积分器）
- 日月拨轮惯性滑动 + 端点磁吸归位（动量 + 磁力反平方）
- 黄铜转盘惯性旋转 + 摩擦减速 + 刻度吸附顿挫
- 磁吸罗盘光标反平方引力偏转 + 阻尼回摆归北
- 铜钮按压回弹过冲 + 三圈涟漪 + 可拖拽磁吸归位
- 拉杆电闸棘轮式三档段落感
- 黄铜放大镜自定义光标（白环+金内点+多层发光+点击涟漪）
- 共 12 个组件级特效，全部基于物理模型

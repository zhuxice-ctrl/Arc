# HALO · 光学特效实验室 — 设计规范

- 日期：2026-08-16
- 方向：UX 交互设计（V3）
- 主题：以光与光学现象为包装的炫技组件特效实验室

## 色彩系统

| 角色 | 色值 | 用途 |
|------|------|------|
| 曜石黑（底） | `#0a0a0f` / `#12121a` / `#1a1a24` / `#252532` | 深色背景层次 |
| 电光青 | `#00f0ff` / `#00a0aa` | 主强调、光迹、光标内点 |
| 熔岩橙 | `#ff6b1a` / `#cc4a00` | 副强调、熔岩模式、对比光 |
| 银白 | `#ffffff` / `#f0f0f5` | 高亮文字、光标外环 |
| 中性灰 | `#a0a0b0` / `#6a6a7a` | 次要文字、边框 |

高对比夜色色系（曜石黑 + 电光青 + 熔岩橙），严格未使用蓝紫渐变。

## 字体

- 展示字：`var(--font-display)`（Space Grotesk）
- 等宽：`var(--font-mono)`（JetBrains Mono）

## 页面结构

单页实验室，12 个独立互动展区（每个带模式切换 chip）：

1. 粒子星座 — 反平方引力 + 连线距离衰减
2. 频谱分析 — 弹簧胡克定律 + 独立谐振频率
3. 噪波流场 — Perlin 类噪波矢量场
4. 文字解构 — 惯性 + 散射 / 波浪双模式
5. 磁力形变 — 反平方律磁力吸附 / 排斥
6. 光环脉冲 — 阻尼扩散 + 多频爆裂
7. 扫描线滤镜 — CRT 扫描 + 故障偏移
8. 光码打字机 — 可变速度 + 退格纠错
9. 光子计数器 — easeOutExpo 缓动积分
10. 涟漪池 — 多圈不同速度衰减传播
11. 视差光球 — 五层景深 + 速率差异
12. 棱镜分光 — 旋转光束 + 脉冲色散

全局特效：自定义光标（白环 + 青点 + 发光晕 + 三态切换 + 点击涟漪）、Hero 粒子星云、3D 卡片倾斜、滚动渐入、光泽扫过按钮、环境光球漂浮、四个全局控制台开关（光强增幅 / 熔岩模式 / 粒子密度 / 自定义光标）。

## 动效系统

纯 vanilla 单文件实现（无 React / 无 Babel / 无外部 CDN 依赖，零白屏风险）。所有动效基于物理模型（弹簧 Hooke / 惯性 / 反平方引力 / 阻尼 / RAF 积分器）或光学语义。`visibilitychange` 自动暂停所有 RAF、`beforeunload` 统一清理、IntersectionObserver 视口外停止动画、`prefers-reduced-motion` 完整降级。

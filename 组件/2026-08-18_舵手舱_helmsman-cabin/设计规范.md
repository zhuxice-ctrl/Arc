# 设计规范 · 舵手舱

> 日期：2026-08-18 · 方向：V3 UX 交互设计 · 主题：航海船长室拟物化小组件实验室

## 色彩系统

主配色为航海复古船舱色系，禁止蓝紫渐变。

| 角色 | 色值 | 用途 |
|------|------|------|
| 胡桃木深棕 | `#3B2A1E` | 主底色、船舱木纹背景 |
| 黄铜金 | `#C9A227` | 主点缀、金属构件、光标内点 |
| 海泡沫白 | `#E9F2EC` | 文字表面、浅色刻度 |
| 暗红 | `#8C3B2E` | 少量点缀、警示标识 |

扩展层次：深木 `#2d1f15`、浅木 `#5C4030`、古铜 `#B8A67A` / `#D4C5A0`、黄铜亮 `#E5C547` / `#FFE87C` / `#FFD700`、暖光 `#FFF8DC` / `#FFFFE0` / `#F0E68C`、海雾蓝绿 `#B8C9BC` / `#B0E0E6`（仅舷窗外景，非蓝紫渐变）、深海 `#1a3a5a` / `#2c5a7d`（舷窗夜空，局部实色）。整体以木质暖棕 + 黄铜金属为主基调。

## 字体

- 系统中文无衬线栈，刻度数字用等宽数字以保证仪表读数对齐。

## 圆角与质感

- 拟物化金属构件：黄铜径向渐变 + 高光描边 + 内阴影模拟浮雕。
- 木质背景：多层径向 / 线性渐变叠加模拟木纹与磨损。

## 展区结构（9 大拟物装置）

1. 舵轮 — 拖拽旋转 + 惯性动量 + 阻尼回弹 + 弹簧归位
2. 罗盘 — 光标磁力反平方扰动 + 迟滞摆荡 + 磁针微颤
3. 舷窗 — 下拉拉绳切换昼夜 + 海浪起伏 + 星辰闪烁 + 舱光流转
4. 汽笛 — 拉绳触发黄铜共鸣震动 + 三波声波涟漪扩散
5. 舱灯 — 黄铜拨杆按压回弹 + 暖光辐射 + 光锥扩散
6. 电报机 — 拖动手柄切换档位 + 弹簧阻尼 + 磁吸定位七档
7. 六分仪 — 指标臂拖拽测角 + 弧尺精确分秒刻度 + 边界回弹
8. 气压计 — 光标感应气压扰动 + 指针弹簧阻尼 + 微波动
9. 海图 — 羊皮纸拖拽浏览 + 惯性滑动 + 摩擦力渐止 + 边界回弹

每个展区有场景叙事文案，必须用鼠标光标上手操作（悬停/点击/拖拽）才有意义。

## 动效系统（12+ 组件级特效）

- 自定义光标：白环 + 黄铜内点 + 多层发光，开页即显示在屏幕中央，悬停三态切换 + 点击涟漪
- 物理模型：弹簧 Hooke 定律、惯性动量、磁性反平方引力、阻尼、摩擦、RAF 积分器
- 主题语义动效：海浪起伏、烛光摇曳、黄铜光泽流转、声波涟漪扩散
- 严禁整图缩放 / Ken Burns；动效周期各不相同

## 健壮性

- 纯 vanilla HTML/CSS/JS 单文件，零外部 CDN 依赖。
- 统一 RAF 循环，visibilitychange 自动暂停，卸载清理。
- 高频鼠标事件直接操作 transform，无 React setState 重渲染。
- 完整 prefers-reduced-motion 降级。

## 技术栈

纯 vanilla HTML/CSS/JS 单文件，无 React / 无 Babel / 无外部 CDN。

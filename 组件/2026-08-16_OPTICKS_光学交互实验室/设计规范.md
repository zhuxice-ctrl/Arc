# 设计规范 · OPTICKS 光学交互实验室

> 方向：UX 交互设计（V3） · 日期：2026-08-16 · 形态：可亲手把玩的物理原理展区

## 主题
以光学物理原理本身为展品的交互实验室，每个展区都是一种光学现象的可交互装置，用户拖拽 / 滑动 / 调参即可实时观察物理规律。围绕光子运动 / 棱镜色散 / 光线追迹组织动效语义。

## 色彩系统

| 角色 | 色值 | 用途 |
|------|------|------|
| 漆黑舞台底 | `#050508` / `#0a0a0f` / `#111118` | 多层暗底（深 / 舞台 / 面板） |
| 白光 | `#F8F8FF` / `#EDEDF2` | 主文字 / 光线 |
| 光学琥珀 | `#FFB347` | 强调色（光标内点 / 滑块 / 激活态 / 公式高亮） |
| 文字灰阶 | `#9A9AA8` / `#5E5E6E` / `#3A3A48` | 次级 / 三级 / 弱化文字 |
| 分隔线 | `rgba(255,255,255,0.06~0.32)` | 四级透明度线 |
| 棱镜光谱色 | 红橙黄绿青蓝紫 | **仅作为色散 / 干涉条纹的物理语义出现**，非装饰渐变 |

整体为黑底高对比光学暗室氛围，禁用蓝紫渐变作为装饰。

## 字体

- 展示 / 正文：`Space Grotesk`
- 衬线（公式 / 展区标题）：`Noto Serif SC`
- 等宽（数值读数 / 标签）：`JetBrains Mono`

## 展区结构（5 个可交互展区）

| 展区 | 物理原理 | 交互 |
|------|----------|------|
| 01 棱镜色散 | Snell 定律 + Cauchy 色散公式 | 调入射角 → 白光分解为七彩光谱，折射率实时读数 |
| 02 凸透镜成像 | `1/f = 1/u + 1/v` | 调物距 / 焦距 / 物高 → 像距 / 像大小 / 虚实实时变化，3 条特征光线追迹 |
| 03 双缝干涉 | `I = I₀·cos²(πd·sinθ/λ)` | 调缝距 / 屏距 / 波长 → 条纹间距 / 密度 / 光色实时变化，含强度曲线 |
| 04 阴影投影 | 本影 + 半影 | 调光源位置 / 尺寸 / 物体大小 → 阴影锐利度与长度渐变，点光源↔面光源对比 |
| 05 反射镜阵 | 反射定律 `θᵢ=θᵣ` | 调 4 面镜子角度 + 出射角 → 光线多镜接力反射，含目标落点计数 |

布局：左侧展区导航、中央 Canvas 舞台、右侧控制面板（滑块 + 公式 + 实时读数）、底部进度点。

## 动效系统（12+ 组件级特效）

- 自定义光标（白环 + 琥珀内点 + 多层发光 + hover 形变 + 点击涟漪）
- 光子粒子沿光线路径运动（色散分光 / 透镜追迹 / 干涉波前 / 反射接力）
- 光谱渐变描边（棱镜出射光谱 / 干涉条纹着色）
- 波前环形扩散动画（双缝展区）
- 悬停发光（导航项 / 滑块 / 按钮）
- 数值滚动读数
- 展区切换入场动画（位移 + 模糊 + 缩放）
- 底部进度点呼吸灯
- 反射目标点脉冲动效
- 滑块拖拽缩放与发光
- 网格背景 + 胶片噪点 overlay

动效基于物理模型（折射 / 成像 / 干涉相位差 / RAF 积分器）与主题语义（光子运动 / 色散彩虹），周期各不相同。

## 健壮性

- 所有 RAF / 定时器随 `visibilitychange` 暂停、卸载统一 cancel
- 高频鼠标事件直接操作 DOM/Canvas，参数用 ref 存储不触发 setState
- 快速切换展区不叠加定时器（每个展区独立 RAF，卸载即清）
- `prefers-reduced-motion` 降级静态展示
- 零 JS 错误

## 技术栈

纯 HTML + CSS + 原生 JS（Canvas 2D）。无构建步骤、无外部框架，`index.html` 直接打开即可运行。

用法文档

快速开始

  • 复制 HTML 中 .kb-board 容器
  • 复制 style 中所有 .kb-* 样式
  • 复制 script 中 Kanban 类
  • 实例化：new Kanban(el, options)

配置项

  • columns 列定义数组（id / title / wipLimit / disabled）
  • cards 卡片数据数组（id / title / column / tag / priority / assignee）
  • onMove(cardId, fromCol, toCol, toIndex) 移动回调
  • onAdd(card) 新增回调

主题变量

  • --kb-bg 页面底色
  • --kb-surface 列背景
  • --kb-accent 主色（墨青）
  • --kb-danger 警示色（赭红）
  • --kb-radius 圆角大小
  • --kb-duration 动画时长

状态机

  • 卡片：rest / hover / focus / dragging / loading
  • 列：rest / drag-over-allowed / drag-over-denied / empty / disabled
  • WIP 满：列头计数变赭红，拒收拖入
  • 所有状态带对应 ARIA 属性

键盘操作

  • Tab 在卡片间移动焦点
  • Space 或 Enter 拾起 / 放下卡片
  • ← → 向左 / 右切换列
  • ↑ ↓ 向上 / 下移动位置
  • Esc 取消拖拽，返回原位

健壮性

  • 零未定义引用，类型守卫完整
  • rAF / 定时器随页面可见性暂停
  • 快速操作不叠加定时器（单例管理）
  • pointercancel 正确清理拖拽状态
  • 支持 prefers-reduced-motion

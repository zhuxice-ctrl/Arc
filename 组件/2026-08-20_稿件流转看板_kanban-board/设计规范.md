# 设计规范 · 稿件流转看板 Kanban

## 组件定位
生产级看板 UI 组件。卡片在多列间拖拽流转，列可设 WIP（在制品）上限，鼠标拖拽与键盘操作双通道对等。面向项目管理、内容流转、客服工单、招聘漏斗等真实场景，可直接 copy-paste 复用。

## 视觉语言：编辑室稿纸
设计语言来自编辑部贴在墙上的稿件流转白板——暖纸底色、墨青标记、赭红警示。组件是主角，展示页克制。

## 色彩系统（CSS 变量，全部可换肤）
| 变量 | 色值 | 用途 |
|---|---|---|
| `--kb-bg` | `#FAF7F1` | 页面暖纸底 |
| `--kb-surface` | `#F1ECE2` | 列背景（比底深一档） |
| `--kb-card` | `#FFFFFF` | 卡片底 |
| `--kb-accent` | `#1E4A43` | 主色（焦点环、计数、强调） |
| `--kb-accent-soft` | `#2A6A52` | 主色浅调 |
| `--kb-danger` | `#B4552D` | 警示（WIP 满列头、拒放） |
| `--kb-danger-soft` | `#8A4A30` | 警示深调 |
| `--kb-text` | `#23292A` | 主文字 |
| `--kb-text-secondary` | `#8CA199` | 竹青灰辅助文字 |
| `--kb-border` | `#E5DFD3` | 描边 |

卡片优先级色条用语义色：`#8A5A20`（中）、`#B4552D`（高）、`#5A4A8A`（专栏）。禁蓝紫渐变。

## 字体
`--kb-font-stack`：系统无衬线栈（`-apple-system, "PingFang SC", "Microsoft YaHei", sans-serif`）。中文为主。

## 圆角与间距
- `--kb-radius` 12px / `--kb-radius-sm` 8px
- `--kb-column-gap` 16px / `--kb-card-gap` 10px
- 阴影三阶 `--kb-shadow-sm/md/lg`，卡片拾起时升到 lg + 微倾 2° + scale 1.02。

## 动效系统
| 场景 | 时长 | 曲线 |
|---|---|---|
| 卡片拾起浮起 | `--kb-duration` | `--kb-ease-out` |
| 目标列间隙展开 | `--kb-duration` | `--kb-ease-out` |
| 放下吸附 | 180ms | `--kb-ease-spring`（cubic-bezier(0.34,1.56,0.64,1)） |
| 拖拽跟手 | 0ms（直接 transform） | 无 transition |
| 拒放弹回 + 末端颤 | 250ms | `--kb-ease-out` |
| 新增卡片骨架→落卡 | `--kb-duration-slow` | `--kb-ease-out` |

`--kb-duration` ≈ 200ms，`--kb-duration-slow` ≈ 320ms。所有动画在 `prefers-reduced-motion` 下降级为瞬时切换。

## 状态机
**卡片**：rest / hover / focus（焦点环）/ dragging（aria-grabbed=true）/ loading（骨架态）
**列**：default / drag-over-allowed（间隙展开）/ drag-over-denied（WIP 满，列头计数变赭红、间隙不出现）/ empty（空列引导）/ disabled（只读列，不允许拖入拖出，如「已发布」）

## 交互机制
- 鼠标：按下卡片拾起（pointer 事件自实现，直接操作 DOM transform 跟手）→ 经过列时该列展开 placeholder 间隙 → 松开落下吸附；WIP 满列拒收（弹回 + 轻颤）。
- 键盘：Tab 聚焦卡片 → Space/Enter 拾起 → ←→ 换列 ↑↓ 换位置 → Enter 放下 → Esc 取消。焦点环始终可见。
- ARIA：`role="application"`、`aria-grabbed`、`aria-label`、`aria-live`（状态日志）、`aria-disabled`、`aria-hidden`。

## 可配置项（JS）
- `columns`：列定义数组（id / 标题 / WIP 上限 / disabled）
- `cards`：卡片数据数组（id / 标题 / 标签 / 负责人 / 优先级 / 所在列）
- `onMove`：卡片移动回调（card, fromCol, toCol, newIndex）

## 健壮性
- 零未定义引用；`pointercancel` 正确清理拖拽态
- rAF / setTimeout 随 `visibilitychange` 暂停恢复；快速连点「新增卡片」单例管理不叠加
- 高频 pointermove 直接改 style，不触发框架式重渲染
- 拖拽结束（成功 / Esc / cancel）必须落定位或归位，不允许卡片悬空

## 技术栈
纯 vanilla 单文件（HTML + 内联 CSS + 内联 JS），无 React / Babel / CDN / 外部资源。系统字体栈。无外部图片。

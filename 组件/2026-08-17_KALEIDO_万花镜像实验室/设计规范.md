# 设计规范 · KALEIDO 万花镜像实验室

> 方向：UX 交互设计（V3） · 日期：2026-08-17 · 主题：镜像对称 / 万花筒光学炫技特效

## 色彩系统

宝石切面气质，祖母绿 + 玫瑰金 + 墨黑 + 珍珠白四色体系。

| 角色 | 色值 | 用途 |
|------|------|------|
| 主色 · 祖母绿 | `#0E5E4A` | 主装置色、宝石核 |
| 祖母绿亮 | `#2DC49A` / `#1A8A6C` | 高光、发光端 |
| 祖母绿深 | `#083C30` | 深底、阴影 |
| 强调 · 玫瑰金 | `#D4A0A7` | 描边、镜面、标题 |
| 玫瑰金亮 | `#E8C5CA` | 高光 |
| 玫瑰金暗 | `#A8767C` | 压暗 |
| 文字/底 · 墨黑 | `#12100E` | 页面底 |
| 墨黑暖 | `#1C1916` / `#2A2622` | 卡片深、分隔 |
| 表面 · 珍珠白 | `#F4F1EC` | 浅文字、高对比 |
| 中性 | `#C8C2B8` | 次级文字 |

## 字体栈

- 展示字体：`'Cormorant Garamond', serif`（var(--font-display)）
- 正文：`'Inter', sans-serif`（var(--font-body)）
- 等宽：`'JetBrains Mono', monospace`（var(--font-mono)）

## 六座互动装置

1. N 重镜像万花筒 — 鼠标驱动粒子源，4 档（6/8/12/16）实时切换
2. 对称曼陀罗画笔 — 鼠标涂抹旋转对称成图，8/12/16 折对称 + 清空
3. 碎镜折射场 — 点击砸碎镜面，碎片递增至 120 片，可重置
4. 光圈棱镜旋转 — 8 层六边形光圈反向旋转，拖动偏移光心
5. 镜像频谱环 — 60 条对称频段，距离控制基频 80→880Hz
6. 多边形镜像扭曲 — 3–12 边切换，6 层 facet 嵌套 + 中心宝石

## 动效系统（12+ 组件级）

自定义光标（弹簧跟随/悬停三态/点击涟漪）、粒子系统、实时绘图、3D 卡片倾斜（直接 DOM transform）、滚动渐入、打字机、数字计数、状态脉冲、光泽扫过、宝石切面边角装饰、六边形背景棱镜、中心脉冲核。

## 健壮性

纯 vanilla 单文件（无 React/Babel/CDN 依赖）；统一 RAF 调度器；visibilitychange 自动暂停、卸载清理；prefers-reduced-motion 降级；移动端关闭自定义光标与倾斜。

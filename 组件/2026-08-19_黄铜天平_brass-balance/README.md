# 黄铜天平·精密机械秤量组件

## 简介
一座光标驱动的精密黄铜天平——拖动游码沿天平臂滑动、或点击添加/移除砝码，天平臂根据两侧力矩差（重量×力臂）实时倾斜，越过平衡点后阻尼振荡回弹至水平，吸附刻度。反复调平衡感受重量、力臂、阻尼、吸附、惯性的物理手感。

## 主题
黄铜天平·精密机械秤量组件——力矩平衡是核心物理模型。

## 技术栈
纯 vanilla 单文件，无 React / Babel / CDN。RAF 主循环随页面可见性暂停、卸载取消。支持 prefers-reduced-motion。

## 设计要点
- 配色：黄铜金木铜锈色系（黄铜金/深棕木/象牙白/暗绿铜锈），零蓝紫渐变
- 物理模型：力矩=重量×力臂实时计算，阻尼弹簧振荡（非linear）
- 五层体验：预接触→接触→持续→阈值→释放衰减
- 手感：重量、阻力、弹性、吸附、惯性、摩擦
- 动效：14个组件级特效，全部与交互有因果关系
- 自定义光标：四态（默认/悬停游码/拖拽中/悬停砝码），开页居中

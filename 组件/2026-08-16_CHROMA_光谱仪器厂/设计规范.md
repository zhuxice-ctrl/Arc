# 设计规范 · CHROMA 光谱仪器厂

> 方向：V3 UX 交互设计 · 日期 2026-08-16 · 光与色彩的炫技组件特效实验室（纯 vanilla 单文件）

## 色彩系统

浅色实验室底（与常见暗黑实验室拉开差异）+ 光谱六色局部点缀：

| 角色 | 色值 | 用途 |
|---|---|---|
| 纸白 / 主底 | `#F4F1EA` | 仪器台面底色 |
| 石墨黑 / 文字边框 | `#1C1A17` | 文字、仪器边框、深色块 |
| 朱红 | `#E4572E` | 光谱色 1 / 棱镜色散端 |
| 琥珀 | `#F2A81D` | 光谱色 2 |
| 柠檬 | `#F5D90A` | 光谱色 3 |
| 松石绿 | `#2EA87E` | 光谱色 4 |
| 青 | `#1B9AAA` | 光谱色 5 |
| 品红 | `#D93E8C` | 光谱色 6 |

配色原则：六色仅作局部点缀与光谱元素，禁止整体彩虹堆砌，禁止蓝紫渐变；白底 + 石墨黑构成仪器气质。

## 字体系统

- 展示字体：`var(--font-display)`（标题、展区名）
- 等宽：`var(--font-mono)`（参数、刻度、读数）
- UI：`var(--font-ui)`（导航、说明）

## 展区结构（6 个独立可把玩装置）

| 展区 | 交互 | 动效原理 |
|---|---|---|
| ① 棱镜色散 | 鼠标上下拖动控制入射角 | Snell 定律 + 6 色折射率色散 |
| ② 色差故障 | 快速移动鼠标产生 RGB 通道分离 | 惯性阻尼 + multiply 混合 |
| ③ 焦散光斑 | 鼠标划过扰动光斑网 | 反平方磁力排斥 + Hooke 弹簧回归 + value noise |
| ④ 半调网点 | 鼠标控制显影区域 | 旋转网格点阵 + 亮度映射 + 光谱色环 |
| ⑤ 油墨混色 | 拖拽四色油墨盘叠加 | multiply 减色混合 + CMYK→RGB 实时换算 |
| ⑥ 光谱频谱仪 | 振荡器 / 麦克风驱动 | Web Audio FFT + 弹簧柱条 + 示波器波形 |

方向键或顶部导航切换展区。

## 动效系统（12+ 项组件级特效）

自定义光标（弹簧跟随 + 悬停形变 + 点击涟漪）、棱镜色散光带、RGB 通道分离故障、焦散光斑扰动、半调网点显影、油墨混色、频谱柱条弹簧、示波器波形、展区切换过渡、导航悬停、刻度读数滚动、光斑呼吸。每个展区为独立 canvas / CSS 装置，动效周期各不相同，禁止整图缩放 / Ken Burns。

## 健壮性

纯 vanilla HTML/CSS/JS 单文件，无 React / 无 Babel / 无外部 CDN 依赖。`visibilitychange` 自动暂停 / 恢复 RAF；定时器统一管理无泄漏；`prefers-reduced-motion` 降级；画布 resize 正确重绘。

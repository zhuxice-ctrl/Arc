# 磁流剧场 Ferro Theatre · 设计规范

> 日期：2026-08-17　方向：V3 UX 交互设计
> 主题：以铁磁流体为灵感母题的炫技组件特效实验室

## 字体

- `--font-display: 'Cormorant Garamond', 'Songti SC', serif` — 展示标题
- `--font-body: 'Space Grotesk', 'PingFang SC', -apple-system, sans-serif` — 正文 / UI

## 圆角

`4px`（锐利金属感）/ `50%`（圆形）/ `999px`（胶囊）。

## 展区结构（6 个独立可把玩装置）

01 铁磁流体尖峰 Spikes — 光标驱动尖刺阵列生长，三档强度
02 液态金属 Blob — 拖拽主液滴与其他液滴 metaball 融合分裂
03 铜金星尘 Stardust — 光标磁化粒子流，跟随 / 环绕 / 爆炸三模式
04 金属文字解构 Letters — 悬停拆散文字粒子，三词切换
05 磁场线可视化 Field Lines — 扰动偶极 / 四极 / 噪波流场，流线粒子
06 全息扫描滤镜 Scan — 光标控制铜金光泽扫描带，单束 / 双束 / 级联

## 动效系统

自定义光标、点击涟漪、Hero 点场尖峰、弹簧入场、数字计数、滚动渐入、磁力按钮、悬停发光、光泽扫过、粒子拖尾、Metaball 融合、CRT 扫描线、向量场流线。

物理基础：尖峰生长用磁场反平方衰减 + 阻尼；粒子用惯性动量 + 磁力积分；Metaball 用等值面阈值；文字解构用弹簧回正。动效周期各异。

## 健壮性

纯 vanilla HTML/CSS/JS 单文件（无 React / Babel / 外部 CDN 依赖）；所有 RAF 循环统一管理，`visibilitychange` 暂停、卸载取消；高频鼠标事件直接操作 DOM transform；`prefers-reduced-motion` 降级。

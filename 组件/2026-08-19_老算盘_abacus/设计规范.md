# 老算盘·拟物化拨珠 — 设计规范

> 单一 index.html（纯 vanilla，无 React / Babel / CDN），打开即玩。组件实验室展品，核心是可反复把玩的真实物理手感。

## 设计母题
老式中式算盘的"木、竹、珠"机械手感。不做按钮加 glow，不做触发即播放——把一颗算珠的"重量、摩擦、碰撞、吸附、余震"做到极致。方向 = 机械结构 + 材质表现（信息操控由拨珠读数自然承载）。

## 算盘结构
9 档标准中式算盘：每档 1 上珠（值 5）+ 4 下珠（各值 1），中间一道梁分隔；木框四角黄铜包角；档头标"个十百千万…"位名。

## 核心交互：拨珠
按住算珠沿竹档上下拖动——珠子跟手但有重量 / 摩擦 / 轻微滞后；撞梁或相邻珠会推动对方（碰撞传递、自然堆叠、不穿透）；下珠靠梁计 1、上珠靠梁计 5、离梁归位不计；读数 = 各档靠梁珠值 × 位权之和。

## 五层反馈
1. 预接触：光标靠近，珠子微亮轻抬，光标变"可抓"
2. 接触：按下珠子下沉、档杆微弯、木质轻响
3. 持续：拖动全程跟手滑动，位置与输入量直接对应
4. 阈值：越过靠梁临界即吸附卡入 + WebAudio"嗒"声 + 读数即时更新
5. 释放 / 衰减：松手阻尼余震（轻微弹跳 1~2 下停稳），相邻被推动珠连锁衰减晃动

全部 RAF 真实物理积分（速度 / 阻尼 / 弹性 / 碰撞），无 CSS transition 假物理、无 linear 归零。

## 数值与口诀
- 顶部等宽大字"当前读数"实时更新
- 珠算口诀面板：按拨珠前后档位差值给出真实口诀（直加 / 下五加 / 进位 / 破五进位 / 直减 / 破五减 / 退位 / 退十补五 共八类）
- 两种玩法：自由拨珠 / 出题模式（随机两三位数加法，拨对盖朱砂"对"印章 + 庆祝音 + 自动下一题）
- 清盘：算珠从左到右级联瀑布式归位（非齐刷刷瞬间）

## 字体
- 标题 / 口诀：`Songti SC / SimSun / STSong / Noto Serif SC` serif
- 读数数字：`SF Mono / Menlo / Consolas` 等宽

## 自定义光标
小算珠造型，开页居中、高对比、层级最高（z-index 顶层、pointer-events:none）；常态 / 悬停可抓 / 按下握珠三态。`prefers-reduced-motion` 降级系统光标。

## 健壮性
零未定义引用；RAF/定时器随 `visibilitychange` 暂停、卸载取消；快速拨珠 / 清盘不叠加定时器（先清旧再起新）；高频鼠标直接操作 transform；WebAudio 首次交互后创建；1440/1024/768/390 整体缩放适配不裁切。

# 设计规范 · NEBULA 星云粒子实验室

> 方向：V3 UX 交互设计 · 日期：2026-08-17 · 主题：星云粒子特效陈列馆

## 色彩系统

| 角色 | 色值 | 用途 |
|------|------|------|
| 主色 | `#0A0A0F` | 虚空黑，主背景 |
| 主色层 | `#12121A` | 卡片表面 |
| 主色层 2 | `#1A1A26` | 次级表面 |
| 强调色 1 | `#C71585` | 品红，粒子/拖尾/磁力主色 |
| 强调色 2 | `#00E5FF` | 电青，频谱/流体/扫描线主色 |
| 辅助色 | `#C0C0C8` | 暖银，中性文字 |
| 点缀色 | `#FFB347` | 熔金，光绘/强调点缀 |
| 中性色 | `#7A7A85` | 次级文字 |

品红与电青双色霓虹对撞，禁止蓝紫渐变。

## 字体栈

- 标题：`'Space Grotesk', 'PingFang SC', sans-serif`
- 正文：`-apple-system, 'PingFang SC', sans-serif`
- 数字/参数：`'SF Mono', 'JetBrains Mono', monospace`

## 圆角与阴影

- 展区圆角：`12px`；按钮圆角：`8px`
- 发光阴影：`0 0 32px rgba(199,21,133,0.4)` / `0 0 32px rgba(0,229,255,0.4)`

# 步进器 Stepper · 设计规范

## 组件定位
生产级数量步进器（Stepper），可直接 copy-paste 到电商购物车、预订表单、设置面板中使用。核心交互：+/- 按钮步进、长按加速步进、直接输入数字校验、边界阻力反馈、异步库存校验。

## 字体
- 标题：Noto Serif SC 600/700（展示页用，组件不依赖）
- 正文：Noto Sans SC 400/500/600
- 数字/代码：SF Mono / ui-monospace / Menlo（font-variant-numeric: tabular-nums 等宽数字对齐）
- 组件本身继承父级 font-family，不强制字体

## 动效系统

| 交互 | 时长 | 曲线 | 说明 |
|------|------|------|------|
| 按钮按下 | 100ms | ease | scale(0.92) 触觉反馈 |
| 按钮回弹 | 150ms | ease-out | 松手恢复 |
| 值变化 count-up | 200ms | cubic-bezier(0.4,0,0.2,1) | 数字上移/下移淡入，有方向感 |
| 长按加速 | 递减 | 间隔 × 0.88 | 从 200ms 递减至 60ms，ease-in 加速感 |
| 边界 shake | 320ms | cubic-bezier(0.36,0.07,0.19,0.97) | translateX 振荡衰减 3 次 |
| 错误 shake | 320ms | 同上 | 红色边框 + shake |
| 成功闪烁 | 600ms | ease | 绿色短暂高亮 |
| 主题切换 | 250ms | ease | 背景色/文字色过渡 |

### prefers-reduced-motion 降级
- 跳过 count-up 动画 → 值即时更新
- 跳过 shake → 仅显示错误文字提示
- 跳过成功闪烁 → 仅状态切换
- 保留 disabled/error/loading 等状态视觉

## 状态机（10 态）

| 状态 | 触发 | 视觉表现 |
|------|------|----------|
| rest | 默认 | 正常显示 |
| hover | 鼠标悬停按钮 | 按钮变 accent 色 |
| focus | Tab 聚焦 | 焦点环 box-shadow |
| active | 按下按钮 | scale(0.92) + accent-press 色 |
| disabled | disable() 调用 | opacity 0.6 + not-allowed + aria-disabled |
| min-reached | value ≤ min | 减号按钮 disabled |
| max-reached | value ≥ max | 加号按钮 disabled |
| error | 输入非法/超范围 | 红边框 + shake + 错误提示气泡 |
| loading | async validate 中 | spinner + pointer-events none |
| success | validate 通过 | 绿色短暂闪烁 600ms |

## 键盘操作

| 按键 | 行为 |
|------|------|
| Tab | 聚焦 stepper 数值区 |
| ArrowUp | +1 步进 |
| ArrowDown | -1 步进 |
| PageUp | +10 步进 |
| PageDown | -10 步进 |
| Home | 跳到最小值 |
| End | 跳到最大值 |
| 0-9 | 进入编辑模式直接输入 |
| Enter | 确认输入 |
| Esc | 取消输入恢复原值 |

## 技术约束
- 纯 vanilla 单文件（HTML+CSS+JS，无 React/Babel/CDN）
- 组件 CSS 用 .stepper 命名空间，可独立抽取
- 组件 JS 用 Stepper 类（IIFE 挂载 window.Stepper），可独立抽取
- RAF 随 visibilitychange 暂停，destroy() 全量清理
- 展示页字体为可选渐进增强（miaoda CDN），组件本身零外部依赖

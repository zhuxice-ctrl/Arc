用法文档

拷贝即用，改不超过 3 处 CSS 变量即可换主题

HTML 结构

<div class="stepper" data-theme="light">
  <button class="stepper__btn stepper__btn--minus" aria-label="减少">−</button>
  <div class="stepper__value" tabindex="0" role="spinbutton"
       aria-valuenow="1" aria-valuemin="1" aria-valuemax="99" aria-label="数量">
    <span class="stepper__num">1</span>
  </div>
  <button class="stepper__btn stepper__btn--plus" aria-label="增加">+</button>
</div>

JS API

const sp = new Stepper(el, {
  value: 1, min: 0, max: 99, step: 1,
  longPress: true,          // 长按加速
  longPressDelay: 500,      // 触发延迟 ms
  longPressInterval: 200,   // 初始步进间隔 ms
  longPressMinInterval: 60, // 最小间隔 ms
  async validate(v) { /* 返回 boolean | Promise<boolean> */ },
  format(v)   { /* 返回显示文本，默认原值 */ },
  onChange(v) { /* 值变化回调 */ }
});

sp.getValue();   // 获取当前值
sp.setValue(5);  // 设值
sp.disable();    // 整体禁用
sp.enable();     // 整体启用

键盘操作

Tab / Shift+Tab — 切换焦点，焦点环清晰可见

ArrowUp / ArrowDown — 步进增减

Enter / Space — 触发 +（Enter 同样在输入模式下确认）

数字键 0-9 — 进入直接输入模式

Esc — 取消输入并恢复原值

Home / End — 跳到 min / max

PageUp / PageDown — 大步进（step × 10）

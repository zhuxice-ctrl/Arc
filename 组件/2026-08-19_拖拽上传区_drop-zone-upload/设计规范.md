# 设计规范 · 拖拽上传区 DropZone

## 主题
生产级可复用 UI 组件——拖拽文件上传区。解决真实项目中文件上传表单的拖放交互需求。

## 配色系统

| 用途 | 变量名 | 色值 |
|------|--------|------|
| 页面底色 | `--page-bg` | `#F0EDE6` 暖灰 |
| 页面文字 | `--page-text` | `#211D1A` 深炭 |
| 组件背景 | `--dz-bg` | `#FFFCF7` 暖白 |
| 悬停背景 | `--dz-bg-hover` | `#FFF7EC` |
| 拖拽背景 | `--dz-bg-drag` | `#FFF0D9` |
| 边框 | `--dz-border` | `#D9D3C8` |
| 主色/进度/高亮 | `--dz-accent` | `#E8821E` 琥珀橙 |
| 成功 | `--dz-success` | `#3D7A4A` 深苔绿 |
| 错误 | `--dz-error` | `#C4392B` 砖红 |
| 禁用 | `--dz-disabled` | `#B8B2A7` |

配色逻辑：暖灰底传递工具感，琥珀橙作为主色承担进度与拖拽高亮，苔绿/砖红承担成功/错误语义。无蓝紫渐变。

## 字体
- 正文：`-apple-system, BlinkMacSystemFont, "PingFang SC", "Microsoft YaHei", sans-serif`
- 代码：`"SF Mono", "JetBrains Mono", "Consolas", monospace`
- 基准字号：14px，标题 28px，区块标题 16px

## 圆角与间距
- 组件圆角：`--dz-radius: 12px`
- 列表项圆角：`calc(var(--dz-radius) - 4px)` = 8px
- 内边距：`--dz-padding: 32px`
- 列表项间距：8px gap

## 动效系统

| 动效 | 曲线 | 时长 | 语义 |
|------|------|------|------|
| 边框脉冲(drag-over) | `cubic-bezier(0.4,0,0.2,1)` | 1.2s 循环 | 预告可接收 |
| 释放吸入(dropping) | `cubic-bezier(0.34,1.56,0.64,1)` | 300ms | 弹簧反馈 |
| 进度填充(uploading) | `linear` | 120ms/帧 | 持续感 |
| 成功打钩(success) | `cubic-bezier(0.22,1,0.36,1)` | 300ms | 确认 |
| 错误抖动(error) | `cubic-bezier(0.36,0.07,0.19,0.97)` | 500ms 3次 | 阻尼衰减 |
| 文件入列(stagger) | `cubic-bezier(0.34,1.56,0.64,1)` | 300ms + 80ms间隔 | 级联 |
| 文件移除 | `cubic-bezier(0.4,0,0.2,1)` | 250ms | 淡出滑出 |

## 状态机（10 态）

1. **idle** — 虚线边框，默认态
2. **hover** — 边框变主色，背景变暖
3. **focus** — 焦点环（box-shadow 3px 主色柔色版）
4. **drag-over** — 实线边框 + 脉冲光晕循环
5. **dropping** — 弹簧缩放吸入动画
6. **uploading** — 进度环线性填充
7. **success** — 绿色勾标 + check-pop
8. **error** — 红色抖动 + 错误文案
9. **disabled** — 半透明 + not-allowed + pointer-events:none
10. **empty** — 空列表自动隐藏

## 五层体验

- **Pre-contact**：hover/focus 时边框变色预告
- **Contact**：dragenter 时边框脉冲光晕
- **Continuous**：dragover 维持高亮，拖动持续响应
- **Threshold**：drop 释放瞬间从 drag-over → dropping 质变
- **Release/Decay**：进度填充 → 成功级联打钩 / 错误阻尼抖动衰减

## 可访问性
- `role="button"` + `tabindex="0"` 上传区可 Tab 聚焦
- `:focus-visible` 焦点环可见
- Enter/Space 打开文件选择器
- Delete/Backspace 移除列表项
- 删除按钮 tabindex 动态管理（focusin=0, focusout=-1）
- `aria-label` 含文件名和状态
- `prefers-reduced-motion` 降级到 0.01ms
- `visibilitychange` 暂停/恢复上传 RAF

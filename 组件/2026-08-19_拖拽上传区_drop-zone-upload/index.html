用法文档

快速开始

复制组件的 HTML 结构、CSS 样式与 JS 逻辑到你的项目中，然后实例化：

// 最简用法——传入 DOM 元素即可
const dz = new DropZone(document.getElementById('my-dropzone'));

// 完整配置
const dz = new DropZone(document.getElementById('my-dropzone'), {
  accept: 'image/*',     // 允许的文件类型，同 input accept
  maxFiles: 5,           // 最大文件数量
  maxSize: 10 * 1024 * 1024, // 单文件最大字节数（10MB）
  uploadDelay: 1500,     // 模拟上传耗时（ms），接入真实接口时设 0
  onUpload: (file, updateProgress) => {
    // 自定义上传逻辑，调用 updateProgress(0-100) 更新进度
    // 返回 Promise 或直接调用 updateProgress
  },
  onSuccess: (file) => {},  // 单个文件上传成功回调
  onError: (file, error) => {}, // 单个文件上传失败回调
  onRemove: (file) => {},   // 文件被移除回调
});

键盘操作

  • Tab / Shift+Tab：在上传区与文件列表项之间移动焦点
  • Enter / Space：聚焦上传区时打开文件选择器
  • Delete / Backspace：聚焦列表项时移除该文件

状态机

  • idle — 默认态，虚线边框
  • hover / focus — 悬停或键盘聚焦，边框变主色
  • drag-over — 拖拽悬停，实线边框 + 脉冲光晕
  • dropping — 释放瞬间，弹簧收缩动画
  • uploading — 上传中，进度环线性填充
  • success — 上传成功，绿色勾标
  • error — 上传失败或校验不通过，红色抖动
  • disabled — 禁用态，半透明不可交互

API 方法

  • dz.addFiles(fileList) — 手动添加文件
  • dz.removeFile(id) — 移除指定 ID 的文件
  • dz.clear() — 清空所有文件
  • dz.setDisabled(bool) — 设置禁用状态
  • dz.getFiles() — 获取当前文件列表
  • dz.destroy() — 销毁实例，解绑所有事件

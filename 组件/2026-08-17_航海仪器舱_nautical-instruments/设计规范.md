# 设计规范 · 航海仪器舱

> 方向：V3 UX 交互设计 · 日期：2026-08-17 · 主题：光标驱动的拟物化航海仪器小组件实验室

## 色彩系统

| 角色 | 色值 | 用途 |
|------|------|------|
| 深海墨绿·舱体底 | `#0E2A24` | 主背景，深海舱壁 |
| 黄铜金·主色 | `#C9A24A` / `#8E6B2A` / `#5A4417` | 仪器金属、表盘、边框 |

配色为黄铜金 + 深海墨绿 + 骨白的航海仪器质感，禁止蓝紫渐变。

## 字体排印

- 标题/刻度：`"Cinzel", "Noto Serif SC", serif` —— 古典衬线，仪器铭牌感
- 正文：`"Noto Sans SC", "PingFang SC", "Microsoft YaHei", sans-serif`
- 铭文：`"Noto Serif SC", serif`

## 展区（6 件拟物化装置）

1. **舵轮** — 拖拽旋转，松手后弹簧阻尼回正（Hooke 定律 + 阻尼积分器）
2. **罗盘** — 指针磁吸跟随光标，带微扰动永不静止（磁吸 + 噪声扰动）
3. **船钟** — 下拉绳松手敲响，钟锤摆动 + 声波涟漪扩散（单摆 + 涟漪）
4. **舷窗** — 拖动铜制滑块切换昼夜，海景天色、星云雾随之变化（线性插值 + 状态叙事）
5. **六分仪** — 拖拽活动臂，每度刻度咬合的齿感反馈（量化咬合 + 触觉隐喻）
6. **气压计** — 点击表盘给气压脉冲，指针阻尼振动 + 天气文字联动（阻尼振荡 + 语义联动）

## 动效系统

1. 自定义光标（白环 + 金点 + 多层发光，开页居中）
2. 舵轮弹簧回正
3. 罗盘磁吸跟随
4. 罗盘指针扰动
5. 船钟钟锤摆动
6. 声波涟漪扩散
7. 舷窗昼夜渐变
8. 星云雾流动
9. 六分仪刻度咬合
10. 气压计指针阻尼振荡
11. 黄铜高光扫过
12. 悬停三态切换
13. 点击涟漪

## 技术栈

纯 vanilla HTML/CSS/JS 单文件实现，无 React / 无 Babel / 无外部 CDN 依赖。

## 健壮性

RAF 循环随 `visibilitychange` 自动暂停；拖拽事件直接操作 DOM transform；`prefers-reduced-motion` 降级为静态展示；零未定义引用。

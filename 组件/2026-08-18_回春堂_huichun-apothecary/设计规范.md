# 设计规范

## 一、主题概述

**回春堂** — 一间传统中药铺拟物化小组件实验室。以宣纸暖米黄为底、朱红 + 黄铜 + 木棕为核心配色，纯 Vanilla HTML/CSS/JS 单文件实现，无任何外部依赖。十二味交互小品皆为光标驱动（悬停 / 点击 / 拖拽）的拟物化微交互装置。

## 二、色彩系统

| 角色 | 色值 | 用途 |
|------|------|------|
| 宣纸底 | `#FAF3E0` / `#F3E6CC` | 页面背景 |
| 木棕 | `#3D2414` / `#5C3A21` / `#6B4520` | 装置木质 |
| 深墨 | `#2A1810` | 文字 / 阴影 |
| 朱红 | `#A05030` / `#A07040` | 强调 / 印章 |
| 黄铜 | `#8B6914` / `#D4A84B` / `#C9A870` | 金属件 |
| 浅木 | `#8B5A2B` / `#B07840` | 中间木色 |
| 高光 | `#FFD24A` / `#F5D678` | 灯光 / 点亮态 |
| 米卡 | `#E8D5B0` / `#D4C4A0` | 抽屉面 |

> 禁用蓝紫渐变；以暖宣纸 + 朱红黄铜的中式药铺质感统一全展。

## 三、字体

- 系统衬线 / 楷体栈，中文为主，少英文

## 四、圆角与质感

- 装置以渐变模拟立体光照（linear-gradient 高光 + 阴影）
- 木质纹理用多层渐变叠加
- 金属件用径向高光 + 暗边

## 六、动效系统

- 自定义光标：开页即居中，白环 + 彩色内点 + 多层发光，悬停 / 点击 / 拖拽三态，点击涟漪
- 统一 RAF 循环管理器 + `visibilitychange` 自动暂停
- 每处交互基于弹簧 / 阻尼 / 惯性 / 磁吸物理模型
- 支持 `prefers-reduced-motion` 降级

## 七、健壮性

- 纯 Vanilla 单文件，无 React / Babel / CDN 依赖，从根本上规避白屏
- 零未定义引用；定时器重建前先取消旧值
- 高频鼠标事件直接操作 DOM transform

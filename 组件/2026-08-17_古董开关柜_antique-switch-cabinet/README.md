# 古董开关柜 Antique Switch Cabinet

> 日期：2026-08-17 · 方向：V3 UX 交互设计 · 主题：拟物化机械开关/旋钮/拉杆交互装置实验室

## 简介

「古董开关柜」是一个以光标驱动的拟物化小组件动画为展品的可把玩实验室。每个展区是一个独立的、有场景叙事的拟物化微交互装置——拉绳点灯、日晷轮盘、磁性旋钮、拉杆换挡、翻页计数器、按压蜂鸣器、暗箱拨杆。核心是鼠标光标悬停/移动/点击/拖拽触发的细腻微交互，所有交互反馈基于物理模型（弹簧/惯性/磁性/阻尼/摩擦）。

## 动效亮点

- 自定义光标（开页居中、白环+黄铜内点、悬停三态、点击涟漪）
- 拉绳点灯（Hooke 定律弹簧+灯泡渐变发光+光线扩散）
- 日晷轮盘（旋转惯性+摩擦阻尼+昼夜场景渐变）
- 磁性旋钮（反平方引力吸附+阻尼回弹）
- 拉杆换挡（挡位吸附+机械震动+仪表盘指针）
- 翻页计数器（3D 翻转+惯性回弹）
- 按压蜂鸣器（深度回弹+涟漪+灯光闪烁+长按蓄力）
- 暗箱拨杆（弹性反馈+状态指示灯）

## 技术栈

- 纯 vanilla HTML/CSS/JS 单文件实现（无 React/Babel/外部 CDN 依赖）
- 物理模型：弹簧 Hooke 定律、惯性动量、磁性反平方引力、阻尼、摩擦、RAF 积分器
- 支持 prefers-reduced-motion 降级
- visibilitychange 暂停 RAF 动画
- 快速操作不叠加定时器

## 展区清单

1. 拉绳点灯 — 拖拽拉绳点亮灯泡
2. 日晷轮盘 — 旋转轮盘切换昼夜

5. 翻页计数器 — 点击/滚轮翻页计数

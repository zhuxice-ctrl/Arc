# OTP 验证码输入框 · 设计规范

## 组件定位

生产级可复用 UI 组件——多格分离输入的 OTP 验证码框，目的是方便利用到别的项目开发中。纯 vanilla JS + CSS 变量主题化，复制两个文件即可接入任意项目，零依赖零构建。

## 空间模型

居中聚焦式：标签 → 副标题 → 6 格数字输入区 → 底部消息+倒计时/重发。三主题并排展示于深色演示页中，每张主题卡内含一个独立 OTP 实例。

## 状态机（9 态）

| 状态 | 触发 | 视觉表现 |
|------|------|----------|
| `rest` | 初始 | 边框默认色，光标闪烁于第一格 |
| `hover` | 鼠标悬停 | 边框加深，背景微变 |
| `focus` | 聚焦当前格 | 强调色边框 + 3px 柔光环 + 18px 发光晕 + translateY(-1px) |
| `active` | 输入数字 | scale 弹跳入场（0.92→1.06→1），自动前进下一格 |
| `error` | 验证失败 | 逐格错位横向抖动（6 格各延迟 40ms）+ 红色边框/背景 + 自动清空重聚焦 |
| `success` | 验证成功 | 从左到右依次变绿脉冲（每格延迟 80ms）+ 对勾 SVG 描边动画 |
| `loading` | 异步验证中 | 边框呼吸闪烁（1.6s 周期）+ 旋转 spinner，禁用输入 |
| `disabled` | 手动禁用 | 整体半透明降饱和，pointer-events 全禁 |
| `empty` | 无输入 | 占位提示，光标就位等待 |

## 核心交互

- **键盘导航**：方向键 ←→ 移动光标、Home/End 跳首尾、Enter 提交、Backspace/Delete 删除并回退
- **粘贴整段**：复制 6 位验证码粘贴，自动分配到各格，带级联入场动画
- **倒计时重发**：SVG 圆环进度条倒计时，到点后按钮可用，页面隐藏时暂停
- **显示/隐藏**：眼睛图标切换数字遮罩（blur + 圆点），保护敏感场景
- **自动提交**：填满 6 格后自动触发 onSubmit 回调
- **自定义验证**：validate 回调返回 true/false/错误字符串

## 可访问性

- 键盘全程可操作，焦点环可见（`outline: 2px solid --otp-accent`）
- `sr-only` 屏幕阅读器标签
- `prefers-reduced-motion` 自动关闭大部分过渡动画
- `focus-visible` 样式区分键盘/鼠标聚焦

## 可复用性

- CSS 变量主题化：覆盖 30+ `--otp-*` 变量即可自定义主题
- JS 配置化：通过 options 传入 length/theme/validate/onSubmit 等参数
- 自包含：复制 `otp-input.css` + `otp-input.js` 两个文件即可
- 声明式/编程式两种初始化方式
- 公开 API：focus/blur/getValue/setValue/clear/setError/setSuccess/setDisabled/setTheme/destroy

## 技术栈

- 纯 vanilla HTML + CSS + JS，零依赖零构建
- 无 React/Babel/CDN，单文件可直接打开
- CSS 自定义属性（Custom Properties）主题化
- requestAnimationFrame 节流高频事件
- visibilitychange 暂停定时器
- SVG 圆环/对勾动画

组件状态

rest · 初始态
光标闪烁于第一格，提示文字引导用户输入。
focus · 聚焦态
当前格高亮发光，边框变为主题色，柔光外扩。
active · 输入中
数字弹入，自动前进至下一格，视觉节奏清晰。
error · 错误态
横向抖动 + 红色闪光，自动清空并重新聚焦首格。
success · 成功态
依次变绿脉冲 + 对勾描边动画，级联反馈。
loading · 加载态
边框呼吸闪烁 + 旋转加载指示，禁用输入。
disabled · 禁用态
整体半透明降饱和，指针事件全部禁用。
empty · 空态
无输入时显示占位提示，光标就位等待输入。
hover · 悬停态
边框加深 + 背景微变，暗示可交互。

交互特性

键盘全可操作
方向键移动光标、Home/End 跳首尾、Enter 提交、Backspace/Delete 删除。
粘贴整段填充
复制粘贴 6 位验证码，自动分配到各格并带级联入场动画。
倒计时重发
圆环进度条倒计时，到点后按钮可用，页面隐藏时暂停。
显示/隐藏切换
眼睛图标切换数字遮罩，保护敏感场景下的验证码隐私。
自定义光标
高对比双层光标，开页即显示在屏幕中央，层级最高。
减动效偏好
支持 prefers-reduced-motion，自动关闭大部分过渡动画。

# 设计规范 · 梅雨茶庭 · 拟物化小组件实验室

> 日期：2026-08-18 · 方向：V3 UX 交互设计 · 主题：梅雨季日式茶庭拟物化微交互实验室

## 色彩系统

| 角色 | 色值 | 用途 |
|------|------|------|
| 底色 | #F2F0E9 | 宣纸白，全局底 |
| 主色 | #5A6055 / #6A7065 | 苔绿/雨灰绿，主体材质 |
| 辅助 | #8FA98F | 竹青，竹帘/竹筒 |
| 深色 | #4A5048 / #4A5045 | 湿石灰/深苔，阴影、石面 |
| 暖色 | #F2C688 | 灯笼暖光 |
| 木色 | #8B7355 / #6B5540 | 绳结、木构件 |
| 中性 | #7A8075 / #6A7068 | 次级灰绿 |

配色取「梅雨季湿润灰绿 + 灯笼暖光」意象，无蓝紫渐变。

## 字体

- 标题/正文：Noto Serif SC / Noto Sans SC（思源宋体 + 黑体）

## 展区（6 个，全部光标驱动）

| 展区 | 交互 | 物理模型 |
|------|------|----------|
| 雨滴涟漪池 | 悬停激起微涟漪 / 点击三重同心波 | 同心圆扩散 + 阻尼衰减 |
| 竹帘卷放 | 拖拽底杆卷起，松手弹簧下落归位 | Hooke 弹簧 + 阻尼 + 边界回弹 |
| 惊鹿竹筒 | 点击注水，蓄满翻转"咚"一声回弹 | 重心偏移 + 弹簧恢复 + 边界碰撞 |
| 石灯笼 | 下拉流苏触发开关，暖光在纸面晕开摇曳 | 弹簧回弹 + 单摆摆动 + 随机微闪 |
| 青苔拭石 | 抚过石面擦去青苔，双击重置 | destination-out 径向笔刷擦除 |
| 雨链滴水 | 拖拽水珠顺链滑落，松手自由落体 | 重力 + 空气阻力 + 底部溅水 |

## 动效系统（16+ 组件级特效）

自定义光标（阻尼跟随 + 悬停放大变色 + 拖拽三态 + 点击涟漪）、环境雨幕、雾层、池面环境雨滴、竹帘竹片纹理与编绳、竹筒水位与竹节、绳结摆动（环境风驱动）、灯笼暖光摇曳、苔藓 300+ 颗粒纹理、链条 14 环连缀、水珠下落与溅水、导航点 hover 缩放、6 个展区独立物理积分循环。

## 健壮性

纯 vanilla 单文件（零外部依赖）、`visibilitychange` 自动暂停所有定时/动画、`prefers-reduced-motion` 降级、`beforeunload` 统一清理、所有 RAF/定时器带 ID 管理可随时取消。

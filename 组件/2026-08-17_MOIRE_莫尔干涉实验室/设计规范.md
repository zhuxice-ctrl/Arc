# MOIRÉ 莫尔干涉实验室 — 设计规范

## 主题
以「干涉 / 叠加 / 光栅」为统一视觉母题的炫技组件特效实验室。每个展区都是可亲手把玩的组件级特效装置。

## 实现方式
纯 vanilla HTML/CSS/JS 单文件，无 React / 无 Babel / 无外部 CDN 依赖，从根本上规避白屏风险。

## 色彩系统
| 角色 | 色值 |
|------|------|
| 背景 · 石墨黑 | `#0B0D10` |
| 面板黑 | `#111519` / `#1A1F26` |
| 强调 · 荧光青 | `#2EE6C8` |
| 强调 · 暖珊瑚 | `#FF7051` |
| 文字 · 银白 | `#E8EDF2` |

禁用蓝紫渐变。深色空间 + 高亮干涉色（青/珊瑚对比）。

## 字体
- 界面：`"PingFang SC", "Microsoft YaHei", "Helvetica Neue", Arial, sans-serif`
- 代码/数字：`"SF Mono", "Consolas", monospace`

## 圆角
`6px`（按钮/控件）、`16px`（展区面板）、`100px`（胶囊）、`4px`/`2px`（标签）、`50%`（光标环/圆点）。

## 6 个展区
1. **莫尔干涉仪**：两层线栅/圆环光栅，左/右半屏分别拖拽旋转，滚轮缩放，实时干涉色叠加
2. **波纹干涉池**：Canvas 高度场波方程求解，点击/拖动产生多波源，波前叠加形成干涉图样，可调波速与阻尼
3. **光栅拖影帘**：60 条竖直光栅条带，鼠标划过被反平方磁力牵拉错位，松手弹簧（Hooke）回弹
4. **字符干涉场**：两层 Perlin 噪波叠加驱动字符密度，鼠标划过产生涡旋扰动，ASCII/汉字切换
5. **扫描线 GLITCH 滤镜**：RGB 错位、扫描线、水平撕裂，三滑杆调强度 + 一键 GLITCH 爆发，打字机入场
6. **磁力网格**：24×24 网格节点受反平方磁力牵引形变，按下吸附、松开阻尼回弹，位移越大节点越偏珊瑚色

## 组件级动效（≥12）
自定义光标（白环 + 青点 + 多层发光 + 三态 + 点击涟漪）、hero 双光栅旋转干涉背景、数字计数、logo 脉冲、光泽扫过按钮、滚动渐入、打字机、悬停发光、扫描线动效、波纹传播、弹簧回弹、磁力形变。

全部基于物理模型（RAF 积分器 / 弹簧 / 阻尼 / 反平方引力 / 波方程 / 噪波场），周期各异；禁物理公式演示，禁 Ken Burns。

## 健壮性
- 零未定义引用
- RAF 随 `visibilitychange` 暂停、卸载取消
- 快速切换不叠加定时器
- 高频 mousemove 直接操作 DOM transform
- 支持 `prefers-reduced-motion` 降级
- 零外部 CDN 依赖

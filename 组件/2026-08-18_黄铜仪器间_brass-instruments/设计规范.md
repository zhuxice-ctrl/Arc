# 黄铜仪器间 · 设计规范

> 日期：2026-08-18 · 方向：V3 UX 交互设计 · 主题：黄铜精密仪器实验室（光标驱动的拟物化小组件动画）

## 色彩系统

| 角色 | 色值 | 用途 |
|---|---|---|
| 石墨灰（主背景） | `#2B2B28` / `#1a1a18` | 实验室底色、仪器暗面 |
| 黄铜金（主色） | `#C9A227` | 仪器主体、可交互件、光标内点 |
| 黄铜明暗阶 | `#8a6f17` `#5a4710` `#7a6212` `#3a2f0a`（暗）/ `#f3d766` `#e6c248` `#ffd97a`（亮） | 金属拉丝渐变、刻面高光 |
| 象牙白（表面色） | `#F5F0E6` / `#e8e0ce` | 刻度盘纸面、铭牌、说明卡 |
| 朱红（强调色） | `#C03A2B` | 警戒刻度、拖拽态光标、开关指示 |
| 铜绿包浆（辅助色） | `#4E7A6A` | 岁月包浆点缀、状态指示 |

无蓝紫渐变；金属质感全靠黄铜色阶的线性渐变与高光描边实现。

## 字体

- 标题 / 铭牌：`"Songti SC", "SimSun", "Noto Serif SC", "STSong", Georgia, serif`（宋体系衬线，旧实验室气质）
- 刻度 / 读数：`"Courier New", monospace`

## 展区结构（6 台独立拟物化装置，均有场景叙事）

1. 吊绳煤气灯：拖拽黄铜拉绳过阈值点亮，光锥扩散 + 桌面光斑，松手弹簧阻尼回弹
2. 指针式压力计：旋转旋钮，指针二阶阻尼超调回稳（弹簧 K + 阻尼 C 积分），27 道刻度
3. 黄铜拨码开关：三枚拨杆，主开关切换整间实验室昼夜氛围（背景 / 文本 / 指示联动）
4. 发条钥匙：下拖上弦，松手后大小齿轮惯性缓转（摩擦系数 0.975），钥匙弹簧回弹
5. 节流拉杆：拖动把手控制蒸汽开度，粒子频率与大小随开度 0–100% 连续变化
6. 磁吸图钉板：5 枚图钉可拖拽，松手按反平方磁吸 + 弹簧阻尼弹性归位，铭牌实时计数

## 动效系统（12+ 项）

自定义光标（白环 + 黄铜内点 + 朱红拖拽态 + 点击涟漪，开屏即居中）、卡片 3D 倾斜视差、滚动渐入错峰、悬停发光边框、蒸汽粒子系统、指针阻尼摆动、弹簧回弹、齿轮惯性、磁吸归位、昼夜氛围过渡、SVG 刻度盘、黄铜金属渐变质感。

## 健壮性

- 纯 vanilla HTML/CSS/JS 单页，无 React / Babel / 外部 CDN 依赖
- RAF 统一管理，`visibilitychange` 自动暂停，`beforeunload` 全部清理
- 高频 mousemove 直操 DOM transform；快速操作不叠加定时器
- 零未定义引用；`prefers-reduced-motion` 降级

# 设计规范 · NEON DRIFT 霓虹漂移实验室

> 方向：V3 UX 交互设计 · 炫技组件特效动画 · 2026-08-17

## 色彩系统

| 角色 | 色值 | 用途 |
|------|------|------|
| 主色（霓虹粉） | `#FF1A6B` | 主强调、光标内点、霓虹高亮 |
| 强调（酸橙绿） | `#C6FF00` | 次级强调、对比高亮 |
| 强调（电光青） | `#00F0D8` | 第三色、频谱、扫描线 |
| 底色（炭黑） | `#0A0A0F` | 页面主背景 |
| 深灰 | `#131318` / `#1C1C24` | 卡片底、分区 |
| 高光（银白） | `#E8E8EE` | 文字、高光 |
| 次级灰 | `#8A8A95` | 次级文字 |

整体气质：高对比、霓虹夜感、故障美学，严禁蓝紫渐变。

## 字体

- 展示（display）：`"Orbitron", var(--mono)` —— 科技几何体，标题。
- 正文（body）：`"Inter", system-ui, -apple-system, "PingFang SC", "Microsoft YaHei", sans-serif`。
- 等宽（mono）：`ui-monospace, SFMono-Regular, Menlo, Consolas, monospace` —— 参数、代码、数值。

## 组件规范

- 展区卡片：炭黑底 + 霓虹细边框 + 发光阴影，hover 边框亮起。
- 可调参数控件：滑杆 + 切换按钮，等宽字体显示数值。
- 按钮：霓虹描边 + 磁力形变。
- 自定义光标：白环 + 霓虹粉内点 + 多层发光。

## 动效系统

12+ 组件级特效（含展区特效本身）：

1. 自定义光标：白环 + 霓虹粉内点 + 多层发光，开页即显示在屏幕中央，悬停放大，点击涟漪。
2. 粒子引力场：鼠标吸引/排斥粒子流。
3. RGB 分裂故障：悬停三色错位撕裂，点击脉冲。
4. 扫描线滤镜：CRT 风格扫描线 + 光束。
5. 文字解构：鼠标划过碎裂重组，一键炸裂。
6. 光标拖尾：霓虹残影拖尾，可切换配色。
7. 噪波流场：Perlin 噪声粒子流 + 鼠标扰动。
8. 频谱可视化：悬停触发频谱柱起伏，3 种模式。
9. 磁力形变按钮：鼠标吸附形变 + 点击涟漪。
10. 滚动渐入。
11. 光泽扫过。
12. 数字计数。
13. 入场序列 + 打字机光标 + 脉冲点。

动效遵循物理 / 主题语义（粒子引力反平方、Perlin 噪声流场、磁力吸附），严禁整图缩放 / Ken Burns；周期各不相同。高频鼠标事件直接操作 DOM transform。`visibilitychange` 暂停 RAF，卸载统一取消。支持 `prefers-reduced-motion` 降级。

## 展区结构

8 个可交互展区（每个可调参数，上手操作才有意义）：

1. **粒子引力场** — 鼠标吸引/排斥，可调数量 / 力场强度 / 模式。
2. **RGB 分裂故障** — 悬停三色错位撕裂，可调幅度 / 速度 / 强度。
3. **扫描线滤镜** — CRT 风格，可调线密度 / 扫描速度 / 颜色。
4. **文字解构** — 鼠标划过碎裂重组，可调扩散范围 / 延迟 / 方向。
5. **光标拖尾** — 霓虹残影，可调长度 / 大小 / 4 种配色。
6. **噪波流场** — Perlin 噪声粒子流 + 鼠标扰动，可调数量 / 强度 / 配色。
7. **频谱可视化** — 悬停触发频谱柱起伏，3 种模式。
8. **磁力形变按钮** — 鼠标吸附形变 + 点击涟漪，可调强度 / 半径 / 形状。

## 技术栈

纯 vanilla HTML/CSS/JS 单文件（index.html），无 React / Babel / 外部 CDN 依赖，所有代码内联。可直接浏览器打开。

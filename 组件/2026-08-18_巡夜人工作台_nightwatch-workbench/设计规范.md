- 标题：Noto Serif SC（衬线，巡夜人手记质感）
- 正文：Noto Sans SC / 系统无衬线
- 装置铭牌：等宽字体，黄铜铭牌感

## 组件规范

- 展区卡片：石墨底 + 银白细描边 + 顶部装置铭牌，圆角 12px
- 装置主体：纯 CSS 绘制拟物化装置（黄铜、灯泡、齿轮、表盘），无图片
- 操作提示：装置下方冷青色提示文字，悬停变橙
- 自定义光标：白色粗环 + 橙色内点 + 多层发光，悬停放大、拖拽变青色虚线环、点击涟漪

## 动效系统（12+ 组件级特效）

1. 自定义光标 —— 开页居中显示，三态切换（默认/悬停/拖拽），点击涟漪
2. 拉绳汽灯 —— 拖拽拉绳点亮灯泡，光线扩散 + 阴影变化，松手弹簧回弹
3. 灯塔光束转盘 —— 拖拽旋转灯室，光束扫过海面，礁石被照亮检测
4. 黄铜闸刀拨杆 —— 向上推合闸，铰链摆动 + 吸附归位 + 火花粒子
5. 怀表上弦旋钮 —— 按住表冠旋转上弦，发条阻尼 + 指针走动
6. 磁吸巡更牌 —— 拖拽铜牌靠近挂钉，反平方引力 + 惯性过冲 + 回弹
7. 油灯调光阀 —— 旋转阀门调火苗，色温 + 房间照度 + 昼夜过渡
8. 火花粒子 —— 闸刀合闸瞬间火花飞溅（初速度 + 重力）
9. 灯光扩散 —— 汽灯/油灯火光径向渐变扩散
10. 发条阻尼 —— 怀表上弦旋转阻尼衰减
11. 磁吸引力 —— 反平方力吸附 + 过冲回弹
12. 光束扫描 —— 灯塔光束旋转 + 礁石照亮判定的 RAF 积分

物理模型：弹簧 Hooke 回弹、阻尼衰减、反平方磁吸引力、旋转惯性、RAF 积分器；快速操作不叠加定时器。

## 健壮性

- 纯 vanilla HTML/CSS/JS 单文件（无 React / 无 Babel / 无外部 CDN）
- 统一 RAF 动画管理器：页面隐藏时自动暂停，卸载统一清理
- 定时器管理器：防叠加，统一回收
- prefers-reduced-motion 全量降级
- 零 console error

# 设计规范 · 长按确认按钮 Long-Press Confirm Button

## 主题

暖陶编辑风——以陶土红为主色的温暖中性色调，适合需要"确认感"的操作场景。三套主题可切换，三种语义变体（danger/warning/info）驱动进度环与交互色。

## 动效系统

| 名称 | 时长 | 曲线 | 用途 |
|------|------|------|------|
| 基础过渡 | 200ms | cubic-bezier(0.4, 0, 0.2, 1) | 颜色/阴影/缩放状态切换 |
| 进度环填充 | 按真实经过时间 | 线性（RAF 驱动） | 1:1 跟随按住时长，无缓动 |
| 弹簧回弹 | 300ms | cubic-bezier(0.34, 1.56, 0.64, 1) | 取消时进度环弹簧式回零 |
| 进度环出现 | 180ms | cubic-bezier(0.34, 1.56, 0.64, 1) | 弹簧缩放入场 |
| 按钮按下 | 同基础过渡 | 同上 | scale(0.96) 下沉 |
| 震动反馈 | 350ms | cubic-bezier(0.36, 0.07, 0.19, 0.97) | 松手未完成/Esc 取消时 |
| 成功勾画 | 400ms | cubic-bezier(0.65, 0, 0.35, 1) | 延迟 150ms 后绘制 |
| 加载旋转 | 800ms | linear infinite | loading 态 spinner |
| 默认长按时长 | 1500ms | — | 可通过 data-hold-duration 配置 |

## SVG 进度环

- viewBox: `0 0 100 100`
- circle r=46, circumference = 2 × π × 46 ≈ 289.03
- stroke-width: 3
- stroke-linecap: round
- 起点旋转 -90deg（从顶部开始顺时针填充）
- 进度通过 JS 设置 stroke-dashoffset = 289.03 × (1 - progress)
- 按下时无 transition（1:1 跟踪）；取消时加 `.lp-spring-back` 类启用 300ms 弹簧过渡

## 状态机（9 态）

| 状态 | class | 视觉 | 触发 |
|------|-------|------|------|
| rest | （无） | 变体色底+白字 | 默认 |
| hover | :hover | 变体色浅底+hint 可见 | 鼠标悬停 |
| focus | :focus-visible | 2px 变体色 outline+2px offset | Tab 聚焦 |
| pressing | .lp-pressing | scale(0.96)+进度环开始填充+涟漪 | pointerdown/Space |
| progressing | RAF 运行中 | 进度环持续填充+百分比更新 | 按住期间 |
| confirmed | .lp-confirmed | 绿色底+勾画动画+进度环满+脉冲 | 进度达 100% |
| error | .lp-error | 红色边框+错误提示 | 操作失败 |
| loading | .lp-loading | spinner 旋转+禁止交互 | 异步处理中 |
| disabled | .lp-disabled | opacity 0.5+not-allowed | 禁用 |

|-----------|------|

| btn.lp.setDisabled(bool) | 设置禁用态 |

| lp:cancel 事件 | 取消时触发，e.detail.button |

## 健壮性

- pointerdown 防重复（已有进度则先取消）
- keydown 忽略 repeat（只首次启动）
- visibilitychange → 自动取消进度
- 卸载 → removeEventListener 全部事件 + 清理所有定时器
- prefers-reduced-motion → 所有动画降级为瞬时
- 零未定义引用
- touch-action: none 防止触屏滚动干扰
- pointercapture 确保拖出按钮仍可追踪

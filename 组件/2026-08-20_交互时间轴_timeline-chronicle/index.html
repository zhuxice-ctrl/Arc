用法文档

快速接入

// 1. 在页面中引入组件 CSS 与 JS（可整块抽取）
// 2. 准备一个容器
<div id="my-timeline"></div>

// 3. 初始化
const tl = new Timeline(document.getElementById("my-timeline"), {
  items: [
    { id: "1", title: "已揽收", meta: "08-15 09:30", state: "completed" },
    { id: "2", title: "派送中", meta: "08-17 14:00", state: "current" }
  ],
  layout: "single", // single | alternate
  loadDetail: async (item) => {
    // 返回 HTML 字符串或 DOM 元素；抛错则显示 error 态
    return `<p>${item.title} 详情</p>`;
  },
  onChange: (item, expanded) => {
    console.log(item.id, expanded ? "展开" : "收起");
  }
});

JS 配置项

配置项类型默认值说明
itemsArray[]节点数据数组，每项含 id/title/meta/state/detail
layoutString"single"布局方式：single 单侧 / alternate 左右交替
expandableBooleantrue节点是否可展开（upcoming 与 disabled 始终不可展开）
loadDetailFunctionnull异步加载详情的函数，返回 HTML 字符串或 DOM；抛错触发 error 态；返回空字符串触发 empty 态
onChangeFunctionnull展开/收起回调，参数 (item, expanded)
initialExpandedIdStringnull初始展开的节点 id
accordionBooleanfalse手风琴模式：展开新节点时收起其他

节点状态机

状态层级说明
rest节点默认静止态
hover节点鼠标悬停，节点放大 + 标题变色
focus-visible节点键盘聚焦，赭红焦点环
expanded节点展开态，详情面板展开 + 轴段生长
disabled节点禁用态，opacity 0.5 + cursor not-allowed
completed节点语义已完成节点（竹青实心）
current节点语义当前节点（赭红 + 脉冲呼吸）
upcoming节点语义待到达节点（灰色空心，不可展开）
loading详情骨架 shimmer 加载
error详情错误图标 + 重试按钮
empty详情空数据提示
success详情正常内容展示

键盘操作

按键功能
Tab进入/离开时间轴容器
↑ / ↓在节点间上下移动焦点（roving tabindex）
Home跳到第一个节点
End跳到最后一个节点
Enter / Space展开或收起当前节点
Esc收起当前展开的节点

可访问性

节点使用 <button> + aria-expanded + aria-controls 语义； 详情面板使用 role="region" + aria-label； 加载状态使用 aria-busy="true"； 采用 roving tabindex 模式保证键盘导航； 支持 prefers-reduced-motion，关闭所有非必要动画。

方法说明

# 设计规范 · 驿路编年 交互时间轴 Timeline

> 生成日期：2026-08-20 ｜ 类别：V3 交互组件（数据展示类）｜ 技术栈：纯 vanilla 单文件 HTML+CSS+JS

## 一、设计母题
**编年刻本·驿路里程碑**。视觉语言来自民国铁路时刻表与编年史刻本：纵向轴线是整个组件的空间主轴与视觉脊柱，节点沿轴分布，展开详情时轴段向下「生长」，详情面板从轴线上长出——而非凭空淡入的卡片。核心记忆点：**详情是从轴线上长出来的**。

## 二、空间模型
- **时间轴式（纵向轴线主轴）**：单条垂直主轴贯穿全部节点，节点标记沿轴左右排布。
- 两种布局模式：`single`（单侧，物流跟踪用）与 `alternate`（左右交替，版本日志用）。
- 展示页克制：窄列居中，无 Hero 大标题，组件本身是主角。

## 三、色彩系统（禁蓝紫渐变，与近期作品不雷同）
| 用途 | 色值（从源码 CSS 变量提取） | 语义 |
|---|---|---|
| 页面底色 | `--tl-bg: #FAF6EE` | 暖纸白 |
| 主文字 | `--tl-text: #2B2620` | 墨黑 |
| 轴线 | `--tl-axis-color: #D8CFC0` | 淡墨 |
| 已完成节点 | `--tl-node-done: #4A7C59` | 竹青 |
| 当前节点 | `--tl-node-current: #B4432F` | 赭红 |
| 待完成节点 | `--tl-node-pending: #A39B8B` | 灰 |
| 强调/链接 | `--tl-accent: #8C6A2F` | 赭石 |

共暴露 22 个 `--tl-*` CSS 自定义属性，覆盖色板、圆角、时长、缓动、字体栈。

## 四、字体逻辑
- 标题：系统衬线栈（serif fallback，刻本感，不外链字体）
- 正文：系统无衬线栈
- 日期/数字：等宽栈（monospace）

## 五、状态机（12 态，远超 5 态门槛）
**节点态**：rest / hover / focus-visible（焦点环）/ expanded / disabled
**节点语义态**：completed（竹青实心）/ current（赭红实心+呼吸脉冲）/ upcoming（灰空心，不可展开）
**详情态**：loading（骨架 shimmer 1.6s 线性循环）/ error（错误图标+重试按钮）/ empty（暂无记录）/ success

## 六、动效语言
- 展开/收起：250-350ms ease-out
- 轴线生长：`stroke-dashoffset` draw（轴段随展开绘制）
- current 节点：呼吸脉冲 2s 循环，**仅 current 节点**
- 骨架 shimmer：1.6s 线性循环
- `prefers-reduced-motion`：全部降级为瞬时状态切换，无动画

## 七、键盘与可访问性
- roving tabindex：仅当前聚焦节点 `tabindex=0`，其余 `-1`
- `↑/↓` 节点间移动焦点；`Home/End` 跳首尾；`Enter/Space` 展开收起；`Esc` 收起
- ARIA：节点 `button[aria-expanded][aria-controls]`，详情区 `role="region"`，loading 用 `aria-busy`，禁用 `aria-disabled`
- `document.visibilitychange`：页面隐藏时暂停 RAF/定时器，恢复时续跑

## 八、工程红线达成
- 零外部依赖（无 CDN/外链字体/外链图片），唯一 `http` 字符串为 SVG namespace
- 异步加载用 token 去重（`loadTokens` Map + `tokenCounter`），快速连续点击不叠加回调
- Console 无 error、无 404、无未定义引用
- 组件 CSS/JS 用 `BEGIN/END` 注释边界标记，可整块抽取

## 九、JS 配置与公开 API
配置项：`items / layout(single|alternate) / expandable / loadDetail(async) / onChange / accordion / initialExpandedId`
公开 API：`expand(id) / collapse(id) / toggle(id) / collapseAll() / update(items) / destroy()`

# 命令面板 Command Palette · 设计规范

> 主题：⌘K 命令面板｜类别：V3 交互组件（导航类）｜日期：2026-08-19

## 设计理念

一个可被任何项目接入的全局命令搜索面板（Linear / Notion / Vercel / Raycast 级）。开发者复制单文件到项目，注册命令列表，按 ⌘K 即得到命令面板。展示页克制——组件是主角，展示页是配角。组件本身适应系统光标（hover 态用 CSS cursor 语义化）。

## 状态机（8 态）

| 状态 | 说明 |
|------|------|
| closed | 面板关闭 |
| open-empty | 打开无输入，显示最近命令 |
| open-typing | 输入中，模糊匹配 |
| loading | 异步命令执行中（spinner） |
| results | 分组展示匹配结果 |
| no-results | 无匹配，空态 |
| error | 异步命令执行失败 |
| disabled | 命令禁用态 |

## 字体系统

- `--cmd-font-sans`：Noto Sans SC / -apple-system——UI 文字
- `--cmd-font-mono`：JetBrains Mono / ui-monospace——快捷键键帽、技术标注

## 动效系统（服务语义，禁 Ken Burns / 无关装饰）

- 面板弹簧出场（scale + fade，180ms）
- 列表项选中位移高亮（位移即焦点环，120ms）
- 命中字符高亮（`cmd-hit` 类）
- 执行后 Toast 反馈（success / error 余震收尾）
- 防抖搜索（避免快速输入叠加请求）

时长按语义：切换 150-250ms、过渡 200-400ms。弹簧用于弹性反馈，线性仅用于过渡。`prefers-reduced-motion` 降级为系统动画。

## 可访问性

- 全键盘：⌘K/Ctrl+K 开、Esc 关、↑↓ 导航（跨分组循环）、Enter 执行、Home/End 跳首尾
- 焦点顺序合理，焦点环可见（`--cmd-ring`）
- `aria-*` 完整（role/label/expanded/activedescendant 等）
- 触屏可用
- `prefers-reduced-motion` 降级

## 可复用性

- 自包含单 HTML 可运行，CSS / JS 可独立抽取（`.cmd-` 前缀 + `CommandPalette` 类边界）
- 20+ CSS 变量主题化，深浅双主题
- JS 通过 `commands` 数组配置（label / group / action / hotkey / keywords）
- 抽到别的项目改 ≤3 处即可运行
- README 含用法 / 配置项 / 定制方法 / 注意事项

## 技术栈

纯 vanilla 单文件（HTML + CSS + JS，无 React / Babel / CDN）。DOM 引用前判空，定时器集中管理（`_timers` Set + `destroy()` 清理），`visibilitychange` 监听，零未定义引用。

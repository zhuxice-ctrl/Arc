# 设计规范 · Chromatic Distortion Lab · 色散畸变特效实验室

> 方向：UX 交互设计（V3） · 日期：2026-08-17 · 主题：色散畸变视觉特效

## 色彩系统

| 角色 | 名称 | 色值 | 用途 |
|------|------|------|------|
| 主色 | 酸绿 | `#bfff00` | 主要强调色、粒子、高亮、文字 |
| 主色暗 | 虚空黑 | `#080808` | 全局背景、深色面板 |
| 强调色 | 电光品红 | `#ff00aa` | 对比强调、粒子双色、磁力场 |
| 文字色 | 亮白 | `#e8e8e8` | 正文文字 |
| 辅助色 | 灰暗 | `#6a6a6a` | 次要文字、说明 |
| 辅助色 | 纯白 | `#ffffff` | 光标外环、标题文字 |
| 辅助色 | 蓝 | `#4488ff` | RGB 通道 B 分量标识 |

### 色彩使用规则

- 粒子系统随机使用 `#bfff00` 或 `#ff00aa`，比例 ~50/50
- 磁力场吸引态用 `#bfff00`，排斥态用 `#ff00aa`
- CRT 扫描线使用 `#bfff00` 半透明叠加
- 整体禁止蓝紫渐变，蓝仅作 RGB 通道标识

## 组件规范

- **展区容器**：全宽分块，标题区 + 交互区 + 控制面板
- **控制面板**：底部水平排列，滑块 + 按钮 + 切换开关

## 动效系统（15+ 组件级特效）

1. **自定义光标**：白环 + 酸绿内点 + 品红辉光 + 涟漪点击
2. **光标拖尾粒子**：鼠标移动产生粒子拖尾
3. **标题 glitch 色散**：标题文字 RGB 通道分离抖动
4. **数字计数动画**：展区编号计数增长
5. **滚动渐入**：IntersectionObserver 触发
6. **Hero 粒子连线**：背景粒子 + 连线网络
7. **光泽扫过按钮**：悬停时光泽扫过
8. **打字机字符输入**：文字逐字输入效果
9. **弹簧物理回弹**：磁力场切换时弹性过渡
10. **Perlin 噪声流场**：800+ 粒子在噪声场中流动
11. **像素排序故障**：Canvas 像素重排产生故障条纹
12. **CRT 扫描线**：扫描线 + 曲率暗角 + 静电噪点
13. **磁力形变**：网格点阵磁力吸引/排斥
14. **SVG 通道分离**：三通道分别漂移
15. **Badge 脉冲**：状态指示器脉冲动画

## 展区结构（7 个独立展区）

1. **Chromatic Split** — 鼠标推动 RGB 通道分离，可切换文字 / 调节强度
2. **Pixel Sort Glitch** — 拖拽生成像素排序故障，可重洗 / 清屏 / 调节参数
3. **RGB Channel Drift** — SVG 三通道漂移，鼠标跟随与自动漂浮模式
4. **CRT Scanline Filter** — 扫描线 + 暗角 + 噪点 + 刷新率滚动，可开关调节
5. **Noise Flow Field** — 800+ 粒子 Perlin 噪声流场，鼠标排斥扰动
6. **Text Deconstruction** — 逐字 3D 悬停解构，键盘输入改字，3 种模式
7. **Magnetic Warp** — 网格点阵磁力场，吸引/排斥切换，点击增压

## 技术栈

- 纯 vanilla HTML/CSS/JS 单文件，无 React/Babel/CDN 依赖
- Canvas 2D API 实现粒子系统和像素操作
- SVG 实现通道分离
- requestAnimationFrame 统一管理 / visibilitychange 暂停 / beforeunload 清理
- prefers-reduced-motion 全量降级

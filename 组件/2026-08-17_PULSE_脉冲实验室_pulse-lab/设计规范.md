## 展区结构（6 个交互装置）

### PULSE-01 脉冲键盘
- 真实键盘 + 虚拟按键点击触发
- Canvas 波纹扩散 + 粒子爆炸
- 每次按键轮换颜色（品红/酸橙/银白）

### PULSE-02 图标变形剧场
- SVG 路径点插值 morphing
- 6 形状序列：齿轮→心脏→闪电→星星→花朵→六边形
- 支持逐帧/自动播放

### PULSE-03 节拍矩阵
- 6×8 网格序列器
- 点击切换节拍，播放节奏序列
- 可调速 60–200 BPM、随机、清空

### PULSE-04 进度环交响
- 三同心圆环异速旋转填充
- 可加速/减速/反转/重置
- 中心显示同步率

### PULSE-05 状态指示器花园
- 6 种状态图标：Loading / Breathing / Pulsing / Scanning / Heartbeat / Radar
- 点击开关动画

### PULSE-06 粒子爆发器
- 物理粒子：重力 + 地面弹跳 + 墙反弹 + 消散
- 三种触发：普通喷发 / Mega 爆炸 / 五彩纸屑雨

## 健壮性

- 共享 rAF 主循环 + `visibilitychange` 自动暂停/恢复
- `beforeunload` 统一清理
- `prefers-reduced-motion` 全面关闭动画
- 零外部 CDN 依赖（字体走自托管镜像）
- 零 React / Babel

## 技术栈

纯 vanilla HTML/CSS/JS 单文件实现，无 React / 无 Babel / 无外部 CDN 依赖。

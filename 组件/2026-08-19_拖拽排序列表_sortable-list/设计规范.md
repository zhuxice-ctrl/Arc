# 设计规范 · 拖拽排序列表 Sortable List

> 一周备餐计划场景。可复用 UI 组件，纯 vanilla 单文件，自包含可抽取。

## 1. 设计母题

实用可复用「拖拽排序列表」组件——开发者可直接 copy-paste 到自己项目里用。
内容场景选用一周备餐计划清单：为工作日五天的晚餐排定烹饪顺序，顺序本身具有真实意义（属于生活方式场景，非 B 端管理模板）。
设计语言：暖纸感中性风，克制让位给组件本身；展示页只承担说明与演示控制。

## 5. 动效系统（手感服务语义）

| 场景 | 时长 | 曲线 | 语义 |
|------|------|------|------|
| 条目悬停/聚焦 | `200ms` | `--sl-ease` | 预接触反馈 |
| 抓起上浮 | `--sl-duration` | 弹性 | 咬合感（阴影加深+微放大+微倾斜） |
| FLIP 兄弟让位 | `--sl-duration` | `--sl-ease` | 持续响应，非瞬移 |
| 放置回弹 | `--sl-duration-snap` | `--sl-ease-out` | 释放衰减 |
| 焦点环跟随 | `--sl-duration` | 弹性 | 注意力引导 |

五层体验结构：预接触（hover/focus 预告）→ 接触（抓起咬合）→ 持续（拖拽实时跟随+FLIP 让位）→ 阈值（跨过插入位状态质变）→ 释放衰减（放置回弹）。
**prefers-reduced-motion**：降级为无动画或极短过渡（源码 3 处守护）。

## 6. 状态机（8 态）

`rest` → `hover` → `focus`（焦点环可见）→ `grabbed`（抓起，aria-grabbed=true）→ `dragging-over`（放置目标指示线）→ 放下/取消回 `rest`；
外加 `disabled`（第 3 条固定禁用，灰化+cursor:not-allowed+tabindex=-1）、`empty`（清空后空状态+恢复按钮）、`loading`（骨架屏 5 条）。

边界处理：空数据（空状态）、加载中（骨架屏）、禁用项（不可拖）、错误恢复（Esc 取消还原原序）。

## 7. 可访问性

- `role="list"` / `role="listitem"`（JS 动态设置）
- 拖拽手柄 `role="button"` + `aria-label="拖拽手柄"` + `aria-disabled`
- `aria-grabbed`（抓取态）、`aria-pressed`、`aria-busy`（骨架）、`aria-hidden`
- `aria-live="polite"` 视觉隐藏播报区，中文播报抓取/移动/放下/取消
- 焦点环可见，`tabindex` 语义化（禁用项 -1）
- 键盘：Tab 聚焦 → Space 抓取 → ↑↓ 移动 → Enter/Space 放下 → Esc 取消
- 触屏：Pointer Events 统一鼠标/触屏
- `prefers-reduced-motion` 降级

> 注：`aria-grabbed` 在 ARIA 1.1+ 标记为弃用但浏览器广泛兼容，作为已知 MINOR；如需更严谨可改用 `aria-pressed` + roving tabindex。

## 8. 可复用性边界

- 组件 CSS 统一 `.sl-` 前缀，集中注释块「【组件区开始/结束】」划界
- 组件 JS 包成 `initSortableList(root, options)` 工厂，挂载 `window.initSortableList`
- 展示页逻辑（`defaultItems`、演示按钮、用法文档）独立 IIFE，注释标注「非组件代码，演示用」
- 抽取：复制 `.sl-root` CSS 区块 + `initSortableList` 函数即可；换主题改 `--sl-accent` / `--sl-bg` / `--sl-text` 等变量 ≤3 处

## 10. 技术栈

纯 HTML + CSS + JavaScript，零外部依赖（无 React / Babel / CDN）。单文件 `index.html`。
健壮性：RAF/定时器随 `visibilitychange` 暂停且卸载取消；高频 `pointermove` 直接操作 DOM 不触发重渲染；快速操作不叠加定时器；零未定义引用。

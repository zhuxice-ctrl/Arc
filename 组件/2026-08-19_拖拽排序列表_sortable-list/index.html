一周备餐计划

拖动或用键盘重新排定工作日的晚餐顺序

用法

引入方式

复制 .sl-root 区块的 CSS 和下方 initSortableList 函数到项目中即可使用。

// HTML
<div class="sl-root" id="my-list"></div>

// JS
const list = initSortableList(document.getElementById('my-list'), {
  items: [
    { id: '1', title: '香煎鸡胸配时蔬', subtitle: '腌料周日备好' },
    { id: '2', title: '番茄牛腩面', subtitle: '牛腩前一晚炖好' },
  ],
  onChange: (items) => console.log('顺序已更新', items),
  disabledIds: ['3'],
});

配置项

参数类型默认值说明
itemsArray[]条目数组，每项含 id / title / subtitle
onChangeFunction—顺序变更回调，参数为新 items 数组
disabledIdsArray[]禁用（不可拖拽）的条目 id 列表
animationDurationNumber200FLIP 让位动画时长（毫秒）
dragHandleBooleantrue是否显示拖拽手柄；false 则整行可拖

键盘操作

Tab
在条目间移动焦点
Space
抓起 / 放下当前条目
↑ ↓
抓起状态下逐项移动
Enter
放下并确认
Esc
取消，回到原位

主题定制

覆盖 .sl-root 下的 CSS 变量即可换肤，常用变量：

.sl-root {
  --sl-bg: #ffffff;
  --sl-accent: #C64524;
  --sl-helper: #6B7F4E;
  --sl-radius: 8px;
  --sl-duration: 200ms;
  --sl-ease: cubic-bezier(0.34, 1.56, 0.64, 1);
}

全部 24 个主题变量集中在组件 CSS 顶部的 .sl-root 块中。

暴露方法

  • list.setItems(items) — 替换全部条目
  • list.setLoading(bool) — 切换骨架屏加载态
  • list.setDisabledIds(ids) — 更新禁用 id 列表
  • list.getItems() — 获取当前顺序
  • list.destroy() — 卸载并清理事件监听

# 老电工工作台 · 设计规范

> 日期：2026-08-18 · 方向：V3 UX 交互设计 · 主题：光标驱动的拟物化小组件动画实验室

## 色彩系统

黄铜金 + 深炭灰 + 奶白 + 暖橙灯丝光，无蓝紫渐变。

| 角色 | 色值 | 用途 |
|---|---|---|
| 主底 / 深炭灰 | `#2E3338` | 工作台底色 |
| 炭黑层 | `#0a0b0c` / `#121416` / `#1a1d20` / `#23262a` | 渐进深色、阴影、凹陷 |
| 石墨 | `#3A3F45` / `#4a4f55` / `#5a5e64` | 金属件暗部、边框 |
| 黄铜金 | `#C9973B` | 金属件主色、旋钮、拨杆 |
| 浅黄铜 | `#E3B66B` / `#c89a55` / `#8C6A24` | 高光、刻度 |
| 奶白 | `#EFE9DC` | 表盘、文字 |
| 暖橙灯丝光 | `#F4A950` | 灯泡发光、辉光 |
| 暖光层 | `#FFD28A` / `#FFDD99` / `#FFE8C2` / `#FFF4D6` | 灯丝渐亮层次 |

## 字体

- 系统无衬线：`"PingFang SC","Microsoft YaHei","Helvetica Neue",sans-serif`
- 衬线（表盘数字）：`Georgia,serif`
- 等宽（读数）：`ui-monospace,monospace`

## 组件规范

- 金属件圆角：`50%`（旋钮/灯泡）、异形 `50% 50% 40% 40%`（铃铛）、`4-10px`（面板）
- 拨杆 / 旋钮带齿感刻度阻尼（24 格）
- 凹陷面板用内阴影 + 深色底表现金属厚度

## 动效系统（6 展区 / 12+ 特效）

统一 RAF 循环 + 弹簧积分器（stiffness / damping / mass 可配），visibilitychange 自动暂停，beforeunload 统一清理。

1. 自定义光标（白环 + 暖橙内点 + 多层发光，悬停放大变黄铜色，拖拽收束，点击涟漪）
2. 配电箱拨杆 — 拖拽/点击合闸，钨丝灯渐亮 + 墙面光影扩散
3. 吊绳拉灯 — 下拉回弹（弹簧阻尼），灯泡明暗 + 光线扩散 + 阴影
4. 指针电压表 — 旋转调压，表针惯性过冲 + 弹簧归位 + 刻度辉光
5. 磁带随身听 — 播放/快进/倒带，双轮不同速转动 + 可拖拽进度
6. 机械闹钟 — 按贪睡按钮回弹，铃锤敲击 + 铃铛高频震
7. 黄铜旋钮调光 — 拖拽旋转无级调光，色温暖橘→亮白连续变化 + 24 格齿感
8. 高频鼠标事件直操 DOM transform
9. 电流波纹 / 灯丝渐亮主题语义动效
10. 悬停辉光、点击涟漪
11. 滚动入场
12. 数值读数计数

健壮性：纯 vanilla 单文件（无 React / Babel / CDN），零未定义引用；RAF 随可见性暂停、卸载取消；快速操作不叠加定时器；支持 `prefers-reduced-motion`。

## 展区结构

单页工作台，6 件拟物装置横向/网格陈列，每件独立展区有场景叙事：配电箱拨杆、吊绳拉灯、指针电压表、磁带随身听、机械闹钟、黄铜旋钮调光器。全部以鼠标光标悬停 / 点击 / 拖拽驱动。

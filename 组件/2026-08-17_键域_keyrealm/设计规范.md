## 字体系统

- 全局：`Inter` — 现代无衬线，科技感
- 等宽：`monospace` — 数据/代码/编号

## 圆角系统

- 展区卡片：16px
- 按钮：8px / 12px
- 标签：6px
- 进度环：50%（圆形）

## 组件规范

- 展区卡片：暗色表面 + 辉光描边 + 标题编号
- 按键：3D 凸起按钮，下压形变 + 波纹扩散
- 开关：弹性滑动 + SVG 路径 cross-fade
- 粒子系统：物理粒子雨 + 冲击波环
- SVG 路径描绘器：stroke-dasharray 动画 + 形状切换
- 进度环：SVG circle 三环异步联动
- 密码输入：数字反馈 + 错误抖动 + 成功爆破

## 展区结构（6 个展区）

1. **脉冲按键** — 按键 K/E/Y 触发波纹扩散 + 双色辉光
2. **形变开关** — 弹性滑动 + SVG 路径 cross-fade + 粒子脉冲
3. **爆裂粒子** — 按钮下压 + 冲击波环 + 物理粒子雨 + 计数器
4. **路径描绘器** — SVG 路径描绘 + 3 种形状切换 + 长度读数
5. **进度环阵** — 三环异步联动 + 数字滚动 + 辉光描边
6. **密码序列** — 数字输入反馈 + 错误抖动 + 成功粒子爆破

## 技术栈

纯 vanilla HTML/CSS/JS 单文件，零外部依赖（无 React / 无 Babel / 无 CDN）。

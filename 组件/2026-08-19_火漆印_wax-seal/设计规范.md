# 火漆印 · 设计规范

## 主题
一个完整的「蜡封仪式」可把玩交互组件：深绿丝绒桌面上加热蜡粒→滴落堆积→垂直按压摊开→等待凝固→垂直揭开成印。蜡的材质（液态/固态两种表现）是全库首次引入。

## 色彩体系（源码提取）
| 用途 | 色值 |
|---|---|
| 丝绒墨绿（桌面底色） | #1E3A2F |
| 蜡红（主蜡色） | #A62639 |
| 亮红（液态蜡 / 强调） | #C93040 |
| 鲜红（滴落高光） | #E85568 |
| 烛火暖金（火光 / 金属高光） | #E8B84B |
| 黄铜（器具主色） | #A87A38 |
| 深铜（器具暗部） | #7A5525 |
| 浅金（提亮） | #D4A853 / #E8C878 |
| 米白信纸 | #F0E8D8 |

色彩语义：墨绿=丝绒台、蜡红=蜡、金=火与铜。无蓝紫渐变。

## 字体体系
系统 sans-serif，中文为主、少英文（操作提示如「拖到烛火上加热」「保持按压等待凝固」）。

## 交互机制（核心动作：拖、倾、压、提——全库首次垂直按压）
1. 加热：拖勺至烛火上方，勺内蜡粒随时间融化成液态晃动
2. 滴落：拖勺至信封上方倾斜，蜡液成滴落下、有表面张力的堆积高度
3. 按压：拖印章垂直下压，蜡被挤压摊开，摊开半径 ∝ 蜡量+按压力度
4. 凝固：保持按压，蜡色从亮红渐变暗红，凝固进度可见
5. 揭开：垂直上提，未凝固则拉丝/粘印章失败，完全凝固则完美脱模

## 五层反馈
- Pre-contact：光标接近物件微亮 + 烛火轻微偏斜
- Contact：抓取瞬间物件「落手」微沉，光标变握持形态
- Continuous：蜡滴量与倾角连续相关；摊开半径与按压深度连续相关
- Threshold：蜡量足够→「完美圆形」吸附提示；凝固 100%→印章微震 + 一声轻嗒
- Release/Decay：提印拉丝回弹；蜡滴余震微颤；烛火持续摇曳

## 物理手感
蜡的粘度（液态流动慢、有拖尾）、表面张力（滴落成圆堆）、冷却曲线（颜色+硬度同步）、按压力度（压越深摊越大、压过头边缘溢出碎裂）、拉丝断裂（粘弹性）。真实物理积分，禁 linear/ease 默认曲线。

## 失败态（再玩一次的动力）
凝固 <30% 揭开 = 蜡粘印章完全失败；<70% = 印面残缺；≥70% = 略带瑕疵；100% = 完美封印。右上角「重置」可反复制作。

## 自定义光标
开页居中显示，高对比，层级最高。四种形态切换：常态 / 可抓取 / 握持 / 按压。prefers-reduced-motion 降级为系统光标。

## 技术栈
纯 vanilla 单文件 HTML + CSS + JS，无 React / Babel / 外部 CDN / 外部字体。RAF 随页面可见性暂停、卸载取消；快速操作不叠加定时器；高频鼠标事件直接操作 DOM；支持 prefers-reduced-motion。Console 零 Error。

## 动效组件级特效（≥8 个，全部有功能语义）
烛火摇曳、蜡粒融化渐变、蜡液滴落拖尾、堆积表面张力形变、按压摊开、凝固色变、提印拉丝、余震微颤。

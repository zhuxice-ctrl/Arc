# 翻页间 · 分页导航组件 — 设计规范

> 本文件从源码真实提取，记录视觉、动效、状态机、可配置项等设计决策，供复用与二次定制参考。

## 一、设计母题

案头索引签条。页码是一排平放的签条，当前页的签条被轻轻抽出、染上竹青色。所有状态通过签条的位移、浮沉、染色表达，不依赖发光或渐变特效。

| 用途 | 变量 | 色值 |

| 米白底 | `--fyj-bg` | `#F7F4EC` |
| 墨色文字 | `--fyj-ink` | `#22271F` |
| 次级墨色 | `--fyj-ink-soft` | `#4B5247` |
| 弱化墨色 | `--fyj-ink-mute` | `#7A8075` |
| 竹青主色 | `--fyj-primary` | `#3E7C59` |

| 竹青淡底 | `--fyj-primary-soft` | `#E8F0EB` |

设计约束：柿红 `#C0532F` 仅用于错误态；禁用蓝紫渐变、禁用发光特效。

## 三、字体与尺寸

- 字体继承宿主 `font-family`，不强制引入外部字体。
- `--fyj-font-size: 14px`（正文）/ `--fyj-font-size-sm: 13px`（次级）。
- 页码按钮 `--fyj-btn-size: 36px`；紧凑变体 `.fyj-pagination--compact` 缩至 `30px`。
- 圆角 `--fyj-radius: 6px` / `--fyj-radius-sm: 4px`；间距 `--fyj-gap: 4px`。
- 窄屏（`max-width: 560px`）：按钮缩至 `32px`，隐藏信息文字，每页条数选择器换行居中。

## 四、状态机（8 态）

| 状态 | 触发 | 视觉表现 |
| ---- | ---- | ---- |
| rest | 默认 | 透明底、墨色字、细边框 |
| hover | 鼠标悬停非当前/非禁用按钮 | 竹青淡底、竹青边框与文字 |
| focus | 键盘聚焦 | 双层 box-shadow（2px 米白 + 4px 竹青）焦点环 |
| current | 当前页 | 竹青实底、米白字、加粗、`aria-current="page"` |
| active | 按下 | `scale(0.96)` 收缩 |
| disabled | 到边界时上一/下一页 + loading 时全部 | 浅灰竹字、禁用底、`cursor: not-allowed`、`aria-disabled` |
| loading | `setLoading(true)` | 整体 `opacity:0.6` + `pointer-events:none` + `aria-busy` |
| error | 跳页输入非法值 | 输入框柿红描边 + 柿红底 + 300ms 抖动 + 错误气泡提示 |
| jump-editing | 跳页输入框获焦 | 输入框竹青描边、外层 `.is-jump-editing` 标识 |

## 五、动效系统

| 动效 | 时长 | 曲线 | 语义 |
| ---- | ---- | ---- | ---- |
| 当前页指示条滑动 | `240ms` | `cubic-bezier(0.34, 1.4, 0.64, 1)` 弹簧 | 连续翻页时指示条连贯滑过，带轻微过冲与落点吸附 |
| 按钮 hover/active 过渡 | `120ms` | `cubic-bezier(0.2, 0, 0, 1)` | 利落的状态反馈 |
| 边界"顶墙"回弹 | `280ms` | 弹簧 | 首页按上一页/末页按下一页时按钮向墙方向偏移再回弹 |
| 跳页错误抖动 | `300ms` | `ease-in-out` | 非法输入的否定反馈 |
| 加载旋转 | `700ms` 线性循环 | linear | 持续感 |

`@media (prefers-reduced-motion: reduce)`：所有动画/过渡降为 `0.01ms`，指示条无过渡直接切换。

## 六、智能省略号算法

- `total <= 1`：仅显示第 1 页。
- `total <= 7`：全部页码直接显示。
- `total > 7`：首尾页恒定；当前页±1 邻域展开；当前页贴近首/尾时，邻侧省略号自动退化为直接页码。
- 省略号可点击：左侧向前跳 5 页（不低于第 2 页），右侧向后跳 5 页（不高于倒数第二页）。

## 七、可访问性

- `role="navigation"` + `aria-label="分页导航"`。
- 键盘：`←/→` 翻页、`Home/End` 跳首末页、`Enter/Space` 激活按钮、`Esc` 取消跳页编辑并复位、`Tab` 在上一页/当前页/下一页/条数/跳页间合理流转（页码列表采用 roving tabindex，仅当前页 `tabindex=0`）。
- 焦点环（`:focus-visible`）双层描边清晰可见。
- `aria-current="page"`、`aria-disabled`、`aria-busy`、各输入控件 `aria-label` 齐全。

## 八、可复用性

- 组件代码独立于展示页：`组件/翻页间/pagination.css` + `组件/翻页间/pagination.js`，各有清晰注释边界，可独立抽取。
- 主题全部走 `.fyj-pagination` 下的 CSS 变量，覆盖变量即可换肤，无需改 JS。
- 工厂函数 `initPagination(el, options)` 返回 API：`setPage / setTotal / setTotalPages / setPageSize / setLoading / getState / onChange / refresh / destroy`。
- 抽到别的项目：引入 CSS + JS、准备一个容器元素、调用 `initPagination`，改不超过 3 处（容器选择器、初始配置、onChange 回调）即可使用。

      用法说明

      引入方式

      组件由一份 CSS 和一份 JS 组成，直接在页面中引入即可。文件位于 组件/翻页间/ 目录。

      <link rel="stylesheet" href="pagination.css">
<script src="pagination.js"></script>

      调用工厂函数 initPagination 创建实例：

      const pager = initPagination('#my-pager', {
  current: 1,
  total: 100,        // 总条数
  pageSize: 10,
  showJumper: true,
  showSizeChanger: true,
  onChange: (page, pageSize) => {
    console.log('跳至第', page, '页，每页', pageSize, '条');
  },
});

      配置项

      参数 类型 默认值 说明
      currentnumber1当前页码
      totalnumber0总数据条数，与 pageSize 共同决定总页数
      totalPagesnumbernull直接指定总页数，优先于 total 计算
      pageSizenumber10每页条数
      showInfobooleantrue是否显示总条数信息
      showJumperbooleantrue是否显示跳页输入框
      showSizeChangerbooleanfalse是否显示每页条数选择器
      pageSizeOptionsnumber[][10, 20, 50]每页条数可选项
      showIndicatorbooleantrue是否显示当前页滑动指示条
      onChangefunctionnull页码或每页条数变化时回调，参数 (page, pageSize)
      sizeLabelstring'条/页'每页条数选择器的单位文字
      jumperLabelstring'跳至'跳页输入框前的文字
      jumperUnitstring'页'跳页输入框后的单位文字
      infoTemplatestring'共 {total} 条'信息文字模板，支持 {total}/{current}/{totalPages}/{pageSize}

      API 方法

      方法 参数 说明
      setPage(page)number设置当前页码
      setTotal(total)number设置总数据条数
      setTotalPages(n)number直接设置总页数
      setPageSize(size)number设置每页条数，自动重算当前页
      setLoading(bool)boolean设置加载状态，锁定交互
      getState()-获取当前状态对象
      onChange(fn)function设置变化回调（替换已有）
      refresh()-手动刷新渲染
      destroy()-销毁实例，移除 DOM 与事件监听

      主题化（CSS 变量）

      所有视觉属性均通过 CSS 变量暴露，只需在外部覆盖即可定制主题：

      .fyj-pagination {
  --fyj-primary: #3E7C59;     /* 主色：竹青 */
  --fyj-bg: #F7F4EC;          /* 底色：米白 */
  --fyj-ink: #22271F;         /* 文字：墨色 */
  --fyj-error: #C0532F;       /* 错误色：柿红 */
  --fyj-disabled: #9AA696;    /* 禁用色：浅灰竹 */
  --fyj-btn-size: 36px;       /* 按钮尺寸 */
  --fyj-radius: 6px;          /* 圆角 */
  --fyj-duration: 240ms;      /* 弹簧动画时长 */
  --fyj-ease-spring: cubic-bezier(0.34, 1.4, 0.64, 1); /* 弹簧曲线 */
}

      键盘操作

      焦点在组件内时，可使用以下快捷键操作（输入框编辑态下不生效）：

      ← 上一页
      → 下一页
      Home 跳至首页
      End 跳至末页
      Enter 激活当前焦点按钮
      Space 激活当前焦点按钮
      Esc 跳页输入框取消编辑
      Tab 在操作元素间移动焦点

      状态 触发条件 表现
      rest默认米白底 + 墨色文字 + 细边框
      hover鼠标悬停竹青淡底 + 竹青描边 + 竹青文字
      focus键盘聚焦2px 双层焦点环（白底 + 竹青）

      error跳页输入非法值输入框柿红描边 + 300ms 抖动 + 中文错误提示
      jump-editing跳页输入框获焦输入框竹青描边 + 焦点高亮

> 日期：2026-08-16 ｜ 方向：V3 UX 交互设计 ｜ 主题：棱镜分光 / 色散 / 光谱特效实验室

## 色彩系统

纯黑做暗房，光谱七色作光效色带，银白描线与文字。背景与大面色块禁止蓝紫渐变；彩虹仅作为"棱镜色散"主题语义的光效出现。

| 角色 | 色值 | 用途 |
|---|---|---|
| 暗房底 | `#0A0A0C` | 页面主背景，纯黑 |
| 深黑 | `#050508` / `#121218` | 分层暗背景、卡片底 |
| 银白 | `#E8EAF0` | 文字、线条、光标环 |
| 中性灰 | `#8A8DA0` | 次级文字、标签 |
| 光谱-红 | `#FF3B30` | 色散红端 |
| 光谱-橙 | `#FF9500` | 色散橙 |
| 光谱-黄 | `#FFCC00` | 色散黄 |
| 光谱-绿 | `#34C759` | 色散绿 |
| 光谱-青 | `#00C7BE` | 色散青 |
| 光谱-蓝 | `#007AFF` | 色散蓝（仅作光谱一环，非主色调） |
| 光谱-品红 | `#AF52DE` | 色散品红端 |

光谱色带渐变：`linear-gradient(90deg, #FF3B30, #FF9500, #FFCC00, #34C759, #00C7BE, #007AFF, #AF52DE)`，用于光绘拖尾、标题流光、棱镜分光扇形。

## 字体

- 展示字：`Space Grotesk`（标题，几何科技感）
- 标签字：`JetBrains Mono`（参数、坐标、展区编号）

## 展区（6 个可把玩装置）

1. 棱镜分光：滑块调入射角，白光经棱镜折射出七色光谱扇形（基于折射率差真实色散）
2. 万花筒镜像：鼠标绘制轨迹，N 重放射对称复制（2–20 段可调）
3. 光绘拖尾：长按绘制发光丝带，6 色光谱切换，速度敏感线宽
4. 磁力网格：粒子点阵被光标磁性排斥/吸引（反平方律），弹簧回弹
5. CRT 扫描线滤镜：三滑块实时调扫描线密度/色差/辉光
6. 光谱文字解构：粒子组成文字，鼠标扰动四散，移开弹簧重组

自定义光标（三态 + 涟漪）/ 光标粒子拖尾 / Hero 环境粒子连线 / 打字机 / 数字计数 / 卡片 3D 倾斜 / 滚动渐入 / 光谱标题流光 / 光泽扫过按钮 / 状态脉冲 / 扫描条下落 / Hero CTA 光扫。

## 健壮性

- 纯 vanilla 单文件 HTML/CSS/JS，无 React / 无 Babel / 无外部 CDN
- 统一动画注册表，visibilitychange 暂停全部 RAF，卸载回收
- 鼠标事件直接操作 DOM transform，不触发重渲染
- `prefers-reduced-motion` 降级为静态/最小动效

# 设计规范 — KINETIC 动力学交互实验室

> UX 交互设计 · 2026-08-16

## 设计基调

把 UX 运动原理本身当展品——整页是一座可以亲手把玩的交互美术馆。配色为深墨绿炭黑 + 酸性荧光黄绿 + 米白，与青绿琥珀（V1）、陶土奶白（V2）完全区分。所有运动均为 RAF 弹簧积分器驱动的物理模型，非 CSS 过渡。

`'JetBrains Mono', monospace` — 全站等宽，强化实验室 / 技术感。

## 五大展区（交互组件）

1. **弹性弹簧振荡** — 拖拽荧光球松手，Hooke 定律下的真实振荡衰减（F = -kx + 阻尼）
2. **惯性拖拽滑动** — 抓住轨道甩出去，动量 + 摩擦衰减的自然滑行
3. **磁性吸附按钮** — 悬停时核心被反平方引力场拖拽
4. **滚动驱动形变** — 往下滚，方形 → 圆形 → 流体，滚动进度即形变时间轴
5. **视差纵深空间** — 移动鼠标，四层以不同速率独立位移

## 自定义光标

8 段拖尾 + 抓取 / 悬停 / 拖拽三态形态切换，初始即显示在屏幕中央。

## 健壮性红线

- 零未定义引用
- RAF / 定时器随页面可见性切换自动暂停，卸载时取消
- 快速来回操作不叠加定时器（吸取 V2 白屏 / 卡死教训）
- 高频鼠标事件直接操作 DOM，不触发 React 重渲染
- 支持 `prefers-reduced-motion`

## 技术栈

纯 HTML + CSS + JavaScript（单文件），无框架依赖。双击 `index.html` 即可预览。

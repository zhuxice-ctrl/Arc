# 设计规范 — 黄铜天平秤

## 设计母题
黄铜天平秤 — 可操作的精密机械天平，拖拽砝码产生力矩，横梁物理响应，阻尼振荡。

## 组件类型
机械结构 — 齿轮、杠杆、连杆的物理传动关系。

| 色彩 | 色值 | 用途 |

| 黄铜亮 | #C9A24A / #E8C97A | 横梁、砝码主色 |
| 黄铜暗 | #8B6914 / #5C4510 | 砝码阴影、底座金属 |
| 深木色 | #3E2817 / #3D2418 | 底座、背景暗部 |
| 暗背景 | #2A1F15 / #140C06 | 最深背景 |

## 字体系统
- 正文：Georgia, serif — 衬线体营造精密仪器感
- 中文：Songti SC, STSong, SimSun, serif — 宋体配合古典仪器氛围
- 数字：Georgia 等宽数字显示

## 动效系统
- CSS：`ambientBreath` — 环境光呼吸（聚光灯微弱脉动）
- JS 物理引擎（requestAnimationFrame 驱动）：
  - 弹簧-阻尼系统：angle'' = -k*angle - c*angle' + torque
  - 砝码放置→力矩计算→横梁倾斜→阻尼振荡（2-3 次衰减摆动）
  - 磁吸平衡点：接近水平时吸附力增强
  - 静止检测：角速度<阈值时停止物理循环
  - 初始微扰动：页面加载时天平微微晃动

## 五层反馈结构
1. 预接触：托盘微晃（空气流动暗示）
2. 接触：抓取砝码（缩放+发光）
3. 持续：横梁实时倾斜（力矩差驱动）
4. 阈值：平衡点指示灯亮（金色发光）
5. 释放：阻尼振荡+余震（2-3 次衰减摆动）

## 物理模型
- 力矩：torque = Σ(weight × arm_length) per side
- 角加速度：angle'' = (leftTorque - rightTorque) * k - damping * angle'
- 限制：angle = clamp(angle, -maxAngle, maxAngle)
- 平衡判定：|angle| < threshold → 指示灯亮

## 砝码系统
5 种黄铜砝码：10g / 20g / 50g / 100g / 200g
- 可拖拽至左右托盘
- 双击放回砝码架
- 堆叠排列

## 自定义光标
黄铜镊子形态，高对比，屏幕中央起始，层级最高。
- 默认：镊子闭合
- 抓取：镊子张开
- 悬停可拖拽物：镊子微张

## 布局
- 中央：天平秤主体（大理石底座+立柱+横梁+左右托盘+指针）
- 右侧：砝码架（5 种砝码排列）
- 底部：读数面板（左盘总重/右盘总重/差值/倾角/平衡状态）
- 整体居中，深色背景，聚光灯效果

## 健壮性
- 纯 vanilla 单文件，无 React/Babel/CDN
- RAF 随 visibilitychange 暂停物理循环
- beforeunload 清理
- 支持 prefers-reduced-motion（降级为系统光标+静态展示）
- 零未定义引用

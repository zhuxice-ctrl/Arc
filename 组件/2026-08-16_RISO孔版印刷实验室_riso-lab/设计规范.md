# RISO 孔版印刷特效实验室 · 设计规范

## 主题
以孔版印刷（Risograph）美学为包装的炫技组件特效装置馆。纯 vanilla 单文件实现，零 React/Babel/CDN 依赖。每个展区可上手实时操作。

## 色彩系统
荧光粉 + 墨黑 + 米纸白 + 芥末黄/荧光橙点缀（RISO 经典荧光墨色系，禁蓝紫渐变）。

| 角色 | 色值 | 用途 |
|------|------|------|
| 荧光粉 | #FF4FA0 | 主墨色、光标内点、强调 |
| 荧光橙 | #ff7a2a | 第二套色、暖点缀 |
| 芥末黄 | #e8c547 / #9ab83e | 第三套色、高光 |
| 墨黑 | #1a1210 | 深底、墨层 |
| 暖黑 | #5a4a42 | 文字、阴影 |
| 米纸白 | #f5ecd9 / #efe4c8 / #e8d9b0 / #d4c49a / #a89580 | 纸底、网点 |

## 字体
- `'Courier New', 'Consolas', monospace`：等宽，印版感

## 展区（13 个，均可上手操作）
1. 网点漂移（halftone dither 实时渲染）
2. 套色偏移（拖拽分离 misregistration）
3. 油墨流场（Perlin 噪波流场）
4. 荧光叠印（glow 图层叠加）
5. 扫描干涉（扫描线/摩尔纹图案）
6. 文字解构（网点文字重组）
7. 色彩分离
8. 油墨洇染（扩散模型）
9. 印刷压力（滚筒压力衰减）
10. 纸纹噪波
11. 渐变映射
12. 网格印版
13. 综合叠印

## 组件
- 自定义光标（白粗环 + 荧光内点 + 多层发光 + difference 混合；悬停放大变色、点击涟漪）
- 滑块 / 按钮 / 开关 / 色板 / 拖拽 / 点击 全部真实可用

## 动效系统
基于弹簧、惯性、Perlin 噪波流场、油墨扩散模型、滚筒压力衰减等物理/语义模型；动效周期各异。

## 健壮性
- visibilitychange 自动暂停 RAF，unload 取消
- mousemove 直接操作 canvas，不触发重渲染
- prefers-reduced-motion 降级静态帧
- 纯 vanilla 单文件，无外部依赖

# 老中药铺调剂台 · 设计规范

> 日期：2026-08-18 · 方向：V3 UX 交互设计 · 主题：老中药铺调剂台 · 光标驱动的拟物化小组件动画实验室

## 一、设计理念

以传统中药铺柜台的实体物件为场景原型，将戥子、药柜、捣药臼、铜铃、瓷罐、香炉等器物转译为可被鼠标光标亲手操弄的拟物化微交互装置。整体气质素朴温润，强调木质、铜器与暖光的物理质感。

设计关键词：**铜木 · 暖光 · 拟物 · 手作**

## 四、页面结构

单页实验室，竖向排布七件光标驱动的拟物化展品（exhibit-card），每件含独立舞台（exhibit-stage）与说明（exhibit-info）：

1. **01 拉绳吊灯** — 拖拽铜球下拉，绳线自然摆动，松手弹簧回弹，灯泡点亮伴随暖光锥扩散
2. **02 铜秤戥子** — 拖动铜砣沿秤杆滑移，杆身随力矩倾斜，指针阻尼振荡归位
3. **03 药柜抽屉** — 拉开抽屉见草药，松手磁吸回弹，开阖间尘末轻扬
4. **04 铜捣药臼** — 点击舂捣，研杵弹簧回弹，药粉涟漪扩散、尘末飞散
5. **05 柜面铜铃** — 按下回弹振荡，叮铃声波圈层层扩散
6. **06 瓷药罐** — 悬停 3D 倾斜，提起罐盖草药气雾袅袅升腾
7. **07 铜制小香炉** — 点击点燃，暖光透出出烟孔，青烟扶摇而上

底部操作提示：悬停查看微反应 · 拖拽操作实体物件 · 点击触发动作反馈。

## 五、动效系统（12+ 组件级特效）

1. 自定义光标（白色粗环 + 赭石内点 + 多层发光），开页即显示在屏幕中央
2. 光标点击涟漪扩散
3. 拉绳弹簧摆动（Hooke 定律 + 阻尼）
4. 灯泡暖光锥扩散 + 阴影变化
5. 戥子秤杆力矩倾斜 + 指针阻尼振荡
6. 药柜抽屉磁吸回弹 + 尘末粒子
7. 捣药杵弹簧回弹 + 药粉涟漪
8. 铜铃声波圈层扩散
9. 瓷罐 3D 倾斜 + 气雾上升
10. 香炉青烟扶摇粒子
11. 暖光透出脉动
12. 展品卡片滚动渐入

所有动画基于物理模型（弹簧 Hooke、阻尼振荡、摩擦、RAF 积分器），周期各不相同。

## 六、健壮性

- 纯 vanilla HTML/CSS/JS 单文件，无 React / Babel / 外部 CDN 依赖
- `requestAnimationFrame` 随 `visibilitychange` 自动暂停，卸载统一取消
- 快速来回操作先 clearTimeout / cancelAnimationFrame 旧的，不叠加定时器
- 高频鼠标事件直接操作 DOM transform，不触发重渲染
- 支持 `prefers-reduced-motion` 降级

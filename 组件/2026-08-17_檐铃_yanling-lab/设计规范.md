## 展品结构（六件装置，全部光标可把玩）

1. 檐角风铃 — 拖拽铜铃摆动，铃舌撞击内壁，声波涟漪扩散（钟摆物理 + 撞击检测）
2. 走马观灯 — 拖动顶部转轴旋转，剪纸人影随转动在灯罩上投影流转（角速度阻尼 + 投影缩放）
3. 司南之指 — 拖动磁勺偏离方位，松手后磁性弹簧归位指向正南（胡克定律 + 阻尼）
4. 铜漏滴水 — 向下拖动水阀控制水量，水滴自由下落，水面涟漪扩散（重力下落 + 水面涟漪）
5. 茶筅击拂 — 按住茶筅旋转搅动，茶汤泡沫量随角速度增长，溅沫飞溅（惯性衰减 + 泡沫生成/消散）
6. 素弦余韵 — 拨动七弦，弦身正弦振动衰减，余韵波纹向上扩散（悬停磁性吸附 + 松手振动）

## 动效系统（18+）

自定义光标（白环 + 朱砂内点 + 发光 + 三态 + 点击涟漪，开页居中）、标题入场序列、数字计数器、滚动渐入、纸纹肌理、四角装饰线、钟摆物理、声波扩散、走马灯人影投影位移+缩放+透明、磁勺弹簧归位、磁力线强度变化、水滴重力下落、水面涟漪、茶汤泡沫量变化、旋涡旋转、溅沫抛物、琴弦正弦振动衰减、余韵波纹扩散。

物理模型：胡克定律弹簧归位、钟摆/阻尼、重力下落、惯性衰减、正弦振动衰减。支持 prefers-reduced-motion 降级；RAF/定时器随 visibilitychange 暂停、卸载清理；快速操作不叠加定时器。

## 技术栈

纯 vanilla HTML/CSS/JS 单文件实现，无 React / 无 Babel / 无外部 CDN 依赖，零白屏风险。移动端窄屏降级为原生光标。

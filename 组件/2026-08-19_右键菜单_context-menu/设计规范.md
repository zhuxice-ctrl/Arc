# 右键菜单组件 · 设计规范

## 组件定位

生产级右键上下文菜单（Context Menu），解决 Web 应用中列表/表格/编辑器场景的右键操作需求。开发者 copy-paste 即可用，含智能定位翻转、子菜单嵌套、全键盘导航、type-ahead 搜索。

## 字体系统

- 正文：`-apple-system, "PingFang SC", "Microsoft YaHei", sans-serif`，14px

- 通过 `--cm-font` / `--cm-font-mono` 变量可覆盖

## 动效系统

| 场景 | 时长 | 曲线 | 说明 |
|------|------|------|------|
| 菜单开启 | 180ms | cubic-bezier(0.16, 1, 0.3, 1) | opacity + scale(0.96→1) + translateY(4px→0) |
| 菜单关闭 | 180ms | 同上 | 反向 |
| 子菜单展开 | 180ms + 120ms delay | 同上 | hover delay 后触发 |
| 高亮移动 | 0ms（即时） | — | 保证跟手，无动画延迟 |
| 悬停背景 | 80ms | ease | 背景色过渡 |
| 按下反馈 | 80ms | ease | 背景色加深 |
| Spinner | 600ms | linear | 加载旋转，reduced-motion 下 1s |

### transform-origin 跟随翻转

菜单定位翻转时，`transform-origin` 自动跟随：左上展开 = `top left`，右下翻转 = `bottom right`，保证缩放动画方向正确。

### prefers-reduced-motion 降级

```css
@media (prefers-reduced-motion: reduce) {
  .cm-menu { transition: opacity 80ms ease; transform: none !important; }
}
```

移除缩放和位移，仅保留 80ms 淡入淡出。

## 状态机（7 态）

| 状态 | 触发 | 视觉表现 |
|------|------|----------|
| closed | 初始/Esc/点击外部 | 菜单移除，焦点回到触发器 |
| opening | 右键/键盘触发 | 淡入+缩放+位移动画 180ms |
| open | 动画结束 | 菜单可见，首项自动聚焦 |
| submenu-expanded | → / hover 子菜单项 | 子菜单出现，父项 accent-soft 背景 |
| item-disabled | 配置 disabled: true | 灰色文字，cursor: not-allowed，不可聚焦 |
| item-loading | 配置 loading: true | spinner 旋转，不可点击 |
| item-danger | 配置 danger: true | 红色文字，悬停红色背景 |

## 键盘交互

| 按键 | 行为 |
|------|------|
| ↑ / ↓ | 上下导航（跳过 disabled/loading 项） |
| → | 展开子菜单并聚焦首项 |
| ← | 收起当前子菜单，焦点回到父项 |
| Enter / Space | 执行当前项 |
| Escape | 逐级关闭（子菜单→根菜单→完全关闭） |
| Home / End | 跳到首项/末项 |
| Tab | 阻止（焦点陷阱） |
| 字母/汉字键 | type-ahead 搜索匹配项 |

## 图标系统

内置 13 个 SVG 图标（无外部依赖）：open / link / rename / folder / share / download / trash / copy / info / lock / eye / star / arrow。通过 `item.icon` 字段引用，可扩展。

## 工程约束

- 纯 vanilla 单文件（HTML + CSS + JS），无 React / Babel / CDN
- JS 封装为 `initContextMenu(triggerEl, items, options)` 工厂函数
- CSS BEM 命名（.cm-menu / .cm-item / .cm-submenu），可独立抽取
- 全局单例：同一时间只允许一个右键菜单打开
- 事件冒泡隔离：stopPropagation 防止嵌套触发器重复触发
- 视口变化自动关闭菜单
- RAF 清理：菜单关闭时移除所有 DOM 和事件监听

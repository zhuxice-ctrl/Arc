> 日期：2026-08-17 ｜ 方向：V3 UX 交互设计 ｜ 主题：故障艺术（Glitch Art）组件特效实验室

## 色彩系统

| 角色 | 色值 | 用途 |
|---|---|---|
| 主底 | `#101216` | 炭黑，主背景 |
| 主色 | `#00FFD1` | 信号青，主强调 / 交互高亮 |
| 强调 | `#FF4D00` | 警示橙，故障 / 警告态 |
| 文字 | `#E8EAED` | 银白，正文 |
| 深层 | `#161922` / `#1e2230` / `#2a2f40` | 卡片 / 面板分层 |

配色为炭黑 + 信号青 + 警示橙 + 银白（故障艺术系），无蓝紫渐变。

## 圆角

- 装置容器与控件以直角 / 极小圆角为主，呼应故障硬边美学；圆形元素 `border-radius: 50%`（光标、指示点）

## 12 台故障装置（展区）

每台可亲手调节参数 / 拖拽 / 移动光标实时把玩：

1. RGB 通道分离（偏移 / 强度 / 速度三档）
2. 扫描线干涉（密度 / 漂移 / 干涉强度）
3. 像素排序矩阵（亮度阈值 / 排序行数）
4. 数据弯折 Databend（弯折量 / 切片数 / 混乱度）
5. 字符乱流（流速 / 密度 / 字号）
6. VHS 画面撕裂（频率 / 幅度 / 色度偏移）
7. 磁力形变（光标互动，强度 / 半径 / 网格密度）
8. 频谱故障（频段数 / 故障概率 / 振幅）
9. 位压缩 Bit Crush（色深 / 像素块 / 抖动开关）
10. 波形故障（频率 / 振幅 / 噪声）
11. 马赛克解码（块大小 / 解码进度 / 扫描速度）
12. 拖尾残影（拖尾长度 / 粒子数 / 光晕强度）

## 动效系统

统一 rAF 循环驱动所有装置；自定义光标（白色环 + 青色内点 + 橙色悬停态 + 点击涟漪）；每台装置参数实时影响 Canvas / DOM 渲染；磁力形变基于反平方引力模型；频谱基于振动能量分布。

## 健壮性

纯 vanilla 单文件实现（无 React / 无 Babel / 无外部 CDN 依赖，从根本上规避白屏）；统一 rAF 循环 + visibilitychange 自动暂停 / 恢复；卸载清理；`prefers-reduced-motion` 全量降级；高频鼠标事件直操作 DOM transform。

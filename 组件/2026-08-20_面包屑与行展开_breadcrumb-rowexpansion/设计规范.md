# 设计规范 · 面包屑与行展开组件集

> Art 设计实验室 · V3 交互组件 · 2026-08-20
> 形态：实用可复用 UI 组件（非物理演示装置）｜技术：纯 vanilla 单文件

## 一、设计母题

**表格内层级导航 + 详情展开**——两个真实项目中高频出现的界面问题，以「实验室样品台账（滇池水质项目 2026-B07 批次）」为宿主场景串联：面包屑定位层级，行展开看样品检测详情。两个组件均 100% 未在历史 V3 中出现过，互补成对，同属表格 / 列表数据浏览语义。

设计观点：组件是主角，展示页是配角。克制的暖土编辑风，让状态机本身成为视觉焦点。

## 二、色彩系统（暖土编辑风，无渐变）

| 变量 | 色值 | 用途 |
|---|---|---|
| `--c-ink` | `#211D1A` | 炭墨 — 文字 / 深边框 |
| `--c-ochre` | `#A8632B` | 赭石 — 主色 / 焦点环 / 展开激活 |
| `--c-stone` | `#6E6A63` | 灰岩 — 次要文字 |
| `--c-cream` | `#F4EFE6` | 米白 — 页面背景 |
| `--c-paper` | `#FBF8F1` | 更浅米白 — 斑马纹 / 卡片底 |
| `--c-pine` | `#4A7A4F` | 松绿 — success / 通过 |
| `--c-rust` | `#B23A2A` | 赭红 — error / 失败 |
| `--c-rule` | `#E5DED0` | 分隔线 |
| `--c-rule-strong` | `#D6CEBD` | 深分隔线 |
| `--re-row-hover` | `#FDF9F0` | 行悬停底 |
| `--bc-disabled` | `#C8C2B4` | 面包屑禁用色 |

明确避开：蓝紫渐变、与近期苔绿 / 柿红 / 靛蓝主题雷同。所有颜色用 CSS 自定义属性暴露，三命名空间：`--c-*`（共享基础）、`--bc-*`（面包屑）、`--re-*`（行展开）。

## 三、字体系统

| 变量 | 字体栈 | 用途 |
|---|---|---|
| `--font-serif` | Source Han Serif SC, Noto Serif SC, Songti SC | 标题 |
| `--font-sans` | PingFang SC, Microsoft YaHei, Hiragino Sans GB | 正文 / 组件 |
| `--font-mono` | JetBrains Mono, SF Mono, Consolas | 编号 / 数值 |

中文文案为主，少英文。内容真实可信（真实样品编号、采集地、检测项、状态），无 Lorem Ipsum。

## 四、动效系统（服务语义，非炫技）

| 场景 | 时长 | 曲线 | 语义 |
|---|---|---|---|
| hover / focus 颜色过渡 | 150ms | ease | 预接触预告 |
| 展开图标旋转 | 180ms | ease | 接触咬合 |
| 省略号下拉打开 | 200ms | `cubic-bezier(0.34,1.56,0.64,1)` | 弹簧反馈 |
| 行展开高度 / 详情淡入 | 220ms | ease-out | 内容出现 |
| 加载 spinner | 0.8s | linear infinite | 持续感 |

- 2 个 `@keyframes`：`bc-spin`、`re-spin`（加载旋转）。
- 禁止 Ken Burns 整图缩放、禁止与组件无关的装饰粒子 / 光晕。
- `@media (prefers-reduced-motion: reduce)` 将所有动画时长置为 0.001ms、迭代次数为 1，组件仍完整可用。
- RAF / 定时器随 `visibilitychange` 暂停，卸载时取消；快速操作不叠加定时器。

## 五、状态机

### 面包屑 Breadcrumb（6 态）
`rest` / `hover` / `focus` / `active`（`aria-current="page"`）/ `disabled` / `collapsed-overflow`（中间项折叠为「···」省略号，点击 spring 下拉恢复）/ `loading`（异步加载子级）。

### 行展开 Row Expansion（7 态）
`rest` / `hover` / `focus` / `expanding`（展开动画中）/ `expanded` / `loading`（异步加载详情，spinner）/ `error`（加载失败，可重试）/ `empty-detail`（详情为空）/ `disabled`。

状态画廊区域并排展示全部状态变体，开发者一眼看全。

## 六、可访问性

- 键盘全可操作：Tab 顺序遍历；面包屑 ← / → 在项间移动、Enter 跳转、Esc 关闭省略号下拉；行展开 Enter / Space 展开折叠、Esc 折叠。
- 焦点环可见（`--bc-focus-ring` / `--re-focus-ring` = 赭石，15 处 outline 定义，不依赖默认 outline 丢失）。
- ARIA：`aria-current="page"`、`aria-expanded`、`aria-controls`（按钮→详情行 id `detail-{rowId}`）、`aria-haspopup`、`aria-disabled`、`aria-hidden`、`role="menu"` / `menuitem` / `row`。
- 触屏可用；`prefers-reduced-motion` 降级。

## 七、可复用性

- 纯 vanilla 单文件（HTML + CSS + JS，零 React / Babel / CDN / 外部资源）。
- 组件 CSS / JS 有清晰边界（`.bc-*` / `.re-*` BEM 命名 + 注释分隔），可独立抽取。
- 主题通过 CSS 变量暴露；JS 行为通过配置对象暴露（面包屑 `items` 数组、行展开 `asyncLoader` 函数）。
- 集成成本：抽到别的项目改不超过 3 处（改 CSS 变量色值 + 传 `items` 数据 + 传 `asyncLoader`）即可用。
- 页面底部附完整用法说明（HTML 骨架 / CSS 变量清单 / JS 配置参数）。

## 八、尺寸与圆角

- 面包屑：`--bc-radius` 4px，`--bc-gap` 6px，`--bc-item-px/py` 8/4px，`--bc-font-size` 14px。
- 行展开：`--re-radius` 6px，`--re-expand-size` 28px。
- 响应式：桌面 1280+ 无溢出；窄屏 390 表格可横向滚动，面包屑自动折叠更多层级。

# 深夜电台调音台 · 设计规范

> 方向：V3 UX 交互设计（光标驱动的拟物化小组件动画实验室） · 日期：2026-08-18
> 主题：凌晨两点的电台直播间——整张页面就是一台可把玩的拟物化调音台

## 色彩系统

| 角色 | 色值 | 用途 |
|---|---|---|
| 胡桃深棕 | `#2A1D14` | 台体主色 / 页面底 |
| 深木色 | `#1A120C` / `#0A0604` | 深沉背景 / 阴影层 |
| 木纹饰面 | `#3D2F25` / `#5C4030` / `#3D2B1E` | 台体面板的木质层次 |
| 胡桃浅阶 | `#6B5A4D` / `#5C4A3D` / `#2A2018` | 控件表面 / 边框 |
| 钨丝暖黄 | `#FFC24B` | 灯光 / 指示灯 / 强调 |
| 奶油 | `#F5E9D3` | 主文字 / 刻度 |
| 暖灰 | `#9A8A7B` / `#C9B89A` | 次要文字 / 金属件 |
| 孔雀石绿 | `#2E8B72` | VU 表 / 信号电平色 |
| 直播红 | `#E63946` | ON AIR 灯牌 |

禁止使用蓝紫渐变。整体为「胡桃木 + 钨丝灯 + 孔雀石绿信号」的深夜电台暖调。

## 字体

- 中文 UI：`PingFang SC, Microsoft YaHei, system-ui, sans-serif`
- 频率 / 数字读数：`SF Mono, Menlo, monospace`

## 圆角

- 旋钮 / 表头 / 磁带轮：`border-radius: 50%`
- 面板：8px / 14px；小控件：2px / 3px / 4px

## 展区结构（6 个独立微交互装置）

| 展区 | 交互方式 | 物理反馈 |
|---|---|---|
| ① 电源拨杆 | 点击拨动 | 弹簧回弹曲线、指示灯渐次点亮、电流涟漪扩散、电子管预热延迟 |
| ② 音量推子组 | 垂直拖拽 4 通道推子 | 每通道独立电平表实时波动、推子阻尼跟随、高度实时映射 |
| ③ 调谐转盘 | 左右拖拽旋转 | 频率数字滚动、刻度条横滑、越靠近电台信号越强、8 格 LED 信号表 |
| ④ VU 电平表 | 悬停 / 点击表罩 | 指针随信号实时摆动（弹簧缓动）、轻拍表罩指针晃动回弹 |
| ⑤ 磁带卡座 | 按压播放 / 停止 / 倒带 | 机械按压回弹位移、磁带轮正转 / 停止 / 高速倒转 |
| ⑥ 麦克风推杆 | 点击推杆 | 推上亮起 ON AIR 红灯牌、光晕扩散、整页直播间暗化 |

所有展区必须用鼠标光标悬停 / 点击 / 拖拽上手操作才有意义；无键盘按键类交互；无物理公式演示。

## 自定义光标

开页即居中显示（不等鼠标移动）：白色粗环 + 钨丝黄内点 + 双层发光，z-index 最高；悬停可交互元素放大变色，拖拽时变绿，点击有涟漪。

## 健壮性

- 纯 vanilla HTML/CSS/JS 单文件实现，无 React / 无 Babel / 无外部 CDN 依赖
- `visibilitychange` 自动暂停所有动画循环；定时器重建前先 clear
- 高频拖拽事件直接操作 DOM transform
- 支持 `prefers-reduced-motion` 降级

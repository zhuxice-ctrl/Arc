# 旧时作坊 · 设计规范

## 主题
旧时作坊 —— 拟物化小组件动画实验室。四个展区各为独立的、有场景叙事的拟物化微交互装置，以鼠标光标悬停/点击/拖拽为核心交互方式。

## 色彩系统
| 角色 | 色值 | 用途 |
|------|------|------|
| 深墨棕（主背景） | `#1a1208` / `#1a1408` | 页面底色，旧作坊暗调 |
| 深褐（次背景） | `#2a1f10` / `#2a1f14` | 卡片/展区背景 |
| 黄铜金（强调主） | `#c9a66a` / `#d4a84b` | 金属部件、高亮 |
| 亮黄铜（强调亮） | `#e8c878` / `#f0d888` | 悬停态、发光 |
| 暗红铜（点缀） | `#5c1a10` / `#8B2A20` / `#B23A2E` | 指示灯、警示 |
| 深墨绿（辅助） | `#2a5a40` / `#3a6b50` | 次要装饰 |
| 暖棕（中性） | `#5C4028` / `#6B4423` | 边框、框架 |
| 奶油米（表面） | `#E8DFC8` / `#EDE5D0` / `#F2EAD8` | 浅色表面、文字 |
| 暖灰（文字次） | `#c8b890` / `#d8cca8` | 次要文字 |

## 字体
- 展示字体：宋体/衬线 —— 旧物手作质感
- 数据字体：等宽字体 —— 用于刻度/数字

## 圆角
- 展区容器：`8px`（方正作坊感）
- 按钮/旋钮：`50%`（圆形）或 `4px`
- 拨杆/拉杆：`2px`（细长）

## 组件规范
- 拉绳吊灯：底部拉环可拖拽，钟摆物理摆动（弹簧+阻尼），过零点亮灯泡，光线扩散+地面阴影
- 铜制拨杆：三档拨杆开关，拖拽松手磁吸吸附至最近档位，对应红铜指示灯亮
- 珐琅拨号盘：拖拽旋转表盘，松手惯性衰减，指针指向 0-9，归位微磁吸咔嗒感
- 磁吸按钮组：光标靠近按钮被吸引位移（反平方律磁力），点击下压涟漪+8 粒火花扩散

## 动效系统（12+）
1. 钟摆摆动（弹簧+阻尼物理）
2. 灯光明暗渐变
3. 光线扩散（径向渐变动画）
4. 地面阴影位移
5. 拨杆惯性回弹
6. 档位磁吸吸附
7. 指示灯发光脉冲
8. 表盘惯性旋转
9. 刻度咔嗒磁吸
10. 按钮磁力位移（反平方律）
11. 按压涟漪扩散
12. 火花粒子散射
13. 自定义光标三态 morph（悬停放大变黄铜色/拖拽缩小变白/点击涟漪）

## 页面结构
单页实验室，四个展区纵向排列：
- 壹 · 拉绳吊灯（暗色房间场景）
- 贰 · 铜制拨杆（作坊操作台场景）
- 叁 · 珐琅拨号盘（老式电话/收音机场景）
- 肆 · 磁吸按钮组（黄铜面板场景）

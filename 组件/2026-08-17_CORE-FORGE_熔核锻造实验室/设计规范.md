# 设计规范 · 熔核锻造实验室 Core Forge Lab

> 日期：2026-08-17 · 方向：V3 UX 交互设计 · 主题：熔核锻造炫技组件特效实验室

## 色彩系统

| 角色 | 色值 | 用途 |
|------|------|------|
| 黑曜岩底 | `#0A0806` / `#14100C` / `#1A140F` / `#1E1812` / `#2A221A` | 页面底色、深色层级 |
| 熔橙 | `#FF5A1F` / `#FF8F1F` / `#F97316` | 熔核主色、强调 |
| 流金 | `#FFC24B` / `#FCD34D` / `#FBBF24` / `#F59E0B` | 高光、流金 |
| 电光柠绿 | `#D4FF2E` / `#A3E635` / `#10B981` | 电光点缀 |
| 棕褐 | `#7A6F62` / `#B8AA99` | 次要文字、边框 |
| 米纸 | `#F3E9DC` | 主文字、浅色表面 |
| 辅助 | `#FF6B9D` / `#E91E63` / `#DC2626` / `#00BCD4` | 万花筒/故障/液态形变多色 |

配色避开蓝紫渐变，以「黑曜岩底 × 熔橙 × 流金 × 电光柠绿」构成熔核锻造暖调；多色仅用于万花筒/故障等多混合模式展区。

## 字体

- `--font-display`：标题
- `--font-body`：正文
- `--font-mono`：数据/编号

## 展区（12 座特效装置）

1. 噪声流场（Simplex 噪声向量场 + 光标斥力扰动）
2. 磁力形变按钮（反平方引力 + 弹簧阻尼回弹）
3. 文字解构（每字符独立弹簧质点，周期各异）
4. 频谱可视化（32 柱正弦叠加 + 噪声 + 节拍冲击）
5. 3D 倾斜卡片（多层 Z 轴深度 + 光泽高光追踪）
6. 打字机 + 数字计数（人类节奏键入 + 缓出计数）
7. 轨道粒子系统（三层不同角速度公转 + 光标加速偏转）
8. 液态形变（八参数独立正弦振荡有机形态）
9. 故障艺术文字（RGB 双色通道错位 + 悬停变频）
10. 液态进度球（双层反向波浪 + 差值混合数字）
11. 熔核万花筒（六重镜像对称 + 多混合模式叠加）
12. 透视网格地平线（透视涌流网格 + 熔核落日）

## 全局系统

- 自定义光标（白环+熔橙内点+三层辉光+悬停/点击/拖拽三态+涟漪）
- 光标拖尾粒子（摩擦+微重力）
- 环境粒子背景（连线+鼠标反平方斥力）
- 英雄区视差环（三层深度）
- 滚动渐入 + 全站卡片 3D 微倾斜
- 扫描线 + 暗角胶片质感

## 动效物理依据

反平方引力、弹簧阻尼回弹、Simplex 噪声向量场、正弦振荡、多层 Z 轴深度、RAF 积分器。严禁整图缩放 / Ken Burns。

## 健壮性

- 纯 vanilla HTML/CSS/JS 单文件（无 React / 无 Babel / 无外部 CDN 依赖），从根本上规避妙搭平台 JSX/Babel 白屏风险
- `visibilitychange` 自动暂停所有 RAF 循环，卸载统一清理
- 所有鼠标事件直接操作 DOM transform，不触发重渲染
- `prefers-reduced-motion` 完整降级
- 定时器重建前先清理，绝不叠加

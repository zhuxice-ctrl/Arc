# 设计规范 · 级联选择器 Cascader

> 2026-08-20 · V3 交互组件 · Art 设计实验室
> 场景：山场档案登记（茶叶产地三级联动选择）

---

## 1. 设计母题与定位

**母题**：单输入框触发多列浮层的级联选择器——把"省 → 山场 → 微产地"这种树形层级数据，压缩进一个输入框尺寸的触发器里，展开后逐级揭示。

**设计观点**：级联选择器的本质不是"三个下拉框并排"，而是**一条被折叠的路径**。每展开一级，路径向前延伸一格；选中叶子，整条路径写入输入框。视觉语言围绕"路径"展开：输入框是路径的容器，面板是路径的施工现场。

**为何这个方向**：历史 V3 组件已覆盖 toggle/tooltip/tabs/accordion/tree/modal/drawer/kanban/timeline/skeleton 等，但"多列联动浮层 + 异步子级 + 面板内搜索"这一机制从未出现。地址/分类选择是真实项目高频需求，非演示装置。

## 3. 动效系统（服务语义，不炫技）

| 动效 | 时长 | 曲线 | 语义 |
|---|---|---|---|
| 面板展开（fade + translateY） | `160ms` | `cubic-bezier(0.2,0.8,0.2,1)` | 出场：轻快 |
| 新列从右侧滑入 | `200ms` | `cubic-bezier(0.2,0.8,0.2,1)` | 路径延伸 |
| 选项 hover / 选中底切换 | `120ms` | `cubic-bezier(0.2,0.8,0.2,1)` | 即时反馈 |
| 选中打勾（stroke-draw） | `200ms` | `cubic-bezier(0.2,0.8,0.2,1)` | 确认 |
| Spinner 旋转 | `700ms` | `linear infinite` | 加载持续感 |
| Error 抖动 | `300ms` | `cubic-bezier(0.2,0.8,0.2,1)` | 校验失败分量 |

**降级**：`@media (prefers-reduced-motion: reduce)` 将所有 `animation-duration` / `transition-duration` 降至 `0.001ms`，组件功能不受影响。

## 4. 状态机（9 态）

`rest` · `hover` · `focus`（焦点环可见）· `open` · `selected`（路径回显 + 可清除）· `loading`（列内 spinner）· `empty`（搜索无结果）· `error`（加载失败可重试 + 表单校验失败红框抖动）· `disabled`

- **loading**：异步子级加载时，对应列显示 spinner，列容器 `aria-busy="true"`。
- **error（加载）**：分支加载失败，列内显示「加载失败 · 点击重试」（`role=button` + Enter/Space 可重试）。
- **error（校验）**：表单提交未选产地，输入框红边框 + 抖动 + 错误文案，`aria-live="assertive"` 播报。
- **empty**：搜索无匹配，面板显示「未找到匹配的山场」。

---

## 5. 交互手感

- **轻快利落**是本组件语义（选择/导航类，非危险操作）：所有过渡 120–200ms，无弹簧 overshoot。
- 错误抖动 300ms 给校验失败一点分量，但不重（删除类才需阻尼）。
- 切换/选中用线性缓动出场曲线 `cubic-bezier(0.2,0.8,0.2,1)`，无物理弹簧。
- 禁 Ken Burns 整图缩放、禁与选择无关的装饰特效。

---

## 6. 可访问性

- 输入框 `role="combobox"` + `aria-expanded` + `aria-activedescendant`
- 每列 `role="listbox"`，选项 `role="option"` + `aria-selected`
- 加载列 `aria-busy`，状态变化 `aria-live` 播报
- 全键盘：↑↓ 列内移动、→ 展开子级、← 回退、Enter 选叶、Space 打开、Esc 关闭还焦、字符 typeahead、Backspace 清除、Tab 自然走焦
- 焦点环可见（`--cs-shadow-focus`）
- `prefers-reduced-motion` 全量降级

## 7. 工程红线达成

- 纯 vanilla，零依赖（字体为渐进增强 CDN，可去）
- 零未定义引用；Browser QA console 无 Error
- 定时器统一管理：同 key 先 `clearTimeout` 再 `set`（快速展开/重试不叠加）；`visibilitychange` 隐藏时 `_clearAllTimers()`
- 高频鼠标事件直接操作 DOM
- 1440px / 390px 均无横向溢出
- 组件 CSS/JS（`cs-` 命名空间 + 注释分区）与展示页严格分离，抽取改 ≤3 处（数据源 / 主题变量 / 挂载点）

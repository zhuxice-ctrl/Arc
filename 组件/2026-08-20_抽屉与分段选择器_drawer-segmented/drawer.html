抽屉 Drawer

左 / 右 / 底部 · 手势拖拽 · 焦点陷阱 · 完整状态机

内容状态：

用法

引入组件 CSS 与 JS 后，通过 new Drawer(options) 创建实例，调用 .open() / .close() 控制。

const drawer = new Drawer({
  direction: 'right',    // left | right | bottom
  title: '筛选条件',
  content: '<p>抽屉内容</p>',
  footer: true,
  confirmText: '确定',
  cancelText: '取消',
  draggable: true,
  closeOnOverlayClick: true,
  closeOnEsc: true,
  trapFocus: true,
  lockBodyScroll: true,
  onOpen: () => {},
  onClose: () => {},
  onConfirm: () => {},
});

drawer.open(triggerButton);
drawer.close();
drawer.setContentState('loading'); // normal | loading | error
drawer.setContent('新的 HTML 内容');
drawer.destroy();

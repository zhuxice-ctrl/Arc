## 四、动效系统

| 用途 | 曲线 / 时长 | 适用组件 |
|---|---|---|
| 弹簧归位 / 离场 | `cubic-bezier(0.34, 1.56, 0.64, 1)` 280–320ms | Drawer 拖拽未达阈值弹回、Segmented 指示器 overshoot 滑动 |
| 状态过渡（遮罩淡入/内容渐显） | `cubic-bezier(0.2, 0, 0, 1)` 200–260ms | Drawer 遮罩、面板滑入 |
| 加载脉冲 | 线性循环 | shimmer 骨架、Segmented loading 扫光 |
| 拖拽跟随 | RAF 直接写 DOM，无过渡 | Drawer 边缘拖拽 |

- `prefers-reduced-motion: reduce` → 所有弹簧/滑动降级为线性 ≤200ms，拖拽跟随保留（无动画依赖）。
- RAF / 定时器在 `document.hidden` 时暂停，组件卸载时 `cancelAnimationFrame` + `clearTimeout`。
- 快速重复操作不叠加定时器（先 clear 再 set）。

## 五、抽屉 Drawer 状态机（7+ 态）

`closed → opening → open → dragging → closing`，叠加内容态 `loading`（骨架 shimmer）/ `error`（重试页），触发按钮含 `disabled` 态。

- **三方向**：左 / 右 / 底部，由 `dr-drawer--left/right/bottom` 控制。
- **手势关闭**：拖拽过程 RAF 直接写 `transform`；越过 40% 距离阈值 **或** 快速甩动（速度 >0.5px/ms）即关闭，否则弹簧归位。
- **无障碍**：`role=dialog` `aria-modal=true` `aria-labelledby`；Tab 焦点陷阱（循环）、Esc 关闭、遮罩点击关闭；关闭后焦点归还触发按钮。
- **滚动锁定**：打开时锁定 `body` 滚动并记录滚动位，关闭恢复。
- **CSS 变量（dr- 前缀）**：`dr-width` / `dr-radius` / `dr-duration` / `dr-ease-spring` / `dr-overlay-color` / `dr-handle-color` 等 20+ 个。

## 六、分段选择器 Segmented Control 状态机（7 态）

`rest / hover / focus / active / selected / disabled / loading`。

- **指示器**：`sg-indicator` 弹簧滑动跟随选中段，带轻微 overshoot（280ms）。
- **布局变体**：`sg-segmented--equal`（等宽）/ `sg-segmented--fit`（自适应）。
- **键盘**：roving tabindex，`role=tablist` + `aria-selected` + `aria-disabled`；← → ↑ ↓ / Home / End / Space / Enter 全支持；焦点环可见。
- **单段禁用**：跳过不可选段，键盘与点击均跳过。
- **数字角标**：`sg-badge`，选中段自动反色。
- **CSS 变量（sg- 前缀）**：`sg-track-bg` / `sg-segment-color` / `sg-indicator-bg` / `sg-radius` / `sg-font` / `sg-ease-spring` 等 16+ 个。
- 响应窗口 resize 与页面可见性变化重算指示器位置。

## 七、可复用性

- 两个组件均有独立可抽取文件（`drawer.html` / `segmented-control.html`），CSS+JS 自包含、命名空间隔离。
- 接入新项目：复制对应文件 → 覆盖根 `--accent-*` / `--bg-*` / `--radius` 等 CSS 变量（≤3 处）即可适配主题。
- 展示页 `index.html` 为综合演示（含状态控制台、主题切换、用法说明），非组件本体。

## 八、真实场景文案

- Drawer：消息通知中心、筛选条件、快捷设置面板（含未读角标、骨架加载、错误重试）。
- Segmented：日视图/周视图/月视图、全部/未读/已标注（带角标）、列表/网格。

抽屉 Drawer

覆盖层类 · 左/右/底部三方向 · 手势拖拽关闭 · 焦点陷阱 · 完整状态机

内容状态
当前状态
已关闭
拖拽关闭阈值
40% / 快速甩动

用法说明

三种方向
left / right / bottom，通过 direction 配置。
手势拖拽
RAF 直接操作 DOM，越 40% 阈值或快速甩动即关闭，否则弹簧归位。
焦点陷阱
Tab 循环聚焦，Esc 关闭，点击遮罩关闭，关闭后焦点归还触发按钮。
七种状态
closed / opening / open / dragging / closing / loading / error。
ARIA 完整
role=dialog、aria-modal=true、aria-labelledby 指向标题。
背景锁定
打开时 body 滚动锁定，防止页面穿透滚动。
const drawer = new Drawer({
  direction: 'right', // left | right | bottom
  title: '消息通知中心',
  content: '#notif-template',
  onClose: () => {},
  draggable: true,
  closeOnOverlayClick: true,
  closeOnEsc: true
});
drawer.open();

分段选择器 Segmented Control

输入类 · 弹簧滑动指示器 · 全键盘操作 · 等宽/自适应双布局 · 角标

自适应布局 · 日历视图
等宽布局 · 消息筛选
组件状态
键盘操作
← → Home End
布局模式
equal / fit

用法说明

弹簧指示器
overshoot 缓动跟随，280ms 过渡，切换有弹性手感。
全键盘操作
roving tabindex，←→ 切换，Home/End 跳首尾，Space/Enter 选中。
两种布局
equal 等分宽度，fit 自适应内容宽度。
数字角标
每段可选带 badge，选中态自动变色。
七种状态
rest / hover / focus / active / selected / disabled / loading。
ARIA
role=tablist / role=tab / aria-selected / aria-disabled。
const seg = new Segmented({
  container: '#sg-demo',
  layout: 'equal', // equal | fit
  items: [
    { label: '日视图', value: 'day' },
    { label: '周视图', value: 'week', badge: 3 },
    { label: '月视图', value: 'month', disabled: true }
  ],
  defaultValue: 'day',
  onChange: (value) => {}
});

# 设计规范 · 标签输入器 Tag Input

> 视觉语言：报刊校样纸上的活字标签——骨纸底、墨色字、单一森绿重音。克制专业，像设计系统里的真实一员。

## 1. 色彩系统

### 浅色（默认）
| 用途 | 变量 | 色值 |
|---|---|---|
| 页面底 | `--page-bg` | `#F4EFE6` 骨纸 |
| 页面字 | `--page-fg` | `#1A1816` 墨 |
| 页面弱字 | `--page-muted` | `#6B655E` |
| 页面描边 | `--page-border` | `#D9D2C5` |
| 页面重音 | `--page-accent` | `#1B4332` 森绿 |
| 卡片底 | `--page-card` | `#FBF8F2` |

### 组件级（主题化入口，可被覆盖）
| 变量 | 浅色 | 深色 | 语义 |
|---|---|---|---|
| `--tag-bg` | `#ECE7DC` | `#2E2A26` | 标签底 |
| `--tag-fg` | `#1A1816` | `#EDE8DF` | 标签字 |
| `--tag-accent` | `#1B4332` 森绿 | `#5D8A66` | 重音/已选 |
| `--tag-accent-fg` | `#F4EFE6` | `#1A1816` | 重音上的字 |
| `--tag-focus` | `#B8860B` 琥珀 | `#D4A84B` | 焦点环 |
| `--tag-error` | `#B23A2E` 砖红 | `#D96A5D` | 错误/拒绝 |
| `--tag-surface` | `#FBF8F2` | `#221F1C` | 输入区底 |
| `--tag-border` | `#D9D2C5` | `#3A3631` | 描边 |
| `--tag-placeholder` | `#A8A196` | `#6B655E` | 占位符 |

色彩语义分工明确：森绿=已选/重音，琥珀=焦点，砖红=错误，墨=文字，骨纸=底。颜色承担层级与状态，灰度下层级仍成立。

## 2. 字体

- 正文：`-apple-system, "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", "Source Han Sans CN", "Noto Sans CJK SC", sans-serif`，基准 15px / 行高 1.6。
- 标题：同族，600 字重，28px（页标题）/ 18px（区块标题）。
- 代码/计数：`ui-monospace, "SF Mono", Menlo, Consolas`，`font-variant-numeric: tabular-nums`（计数对齐）。
- 无外部字体依赖，零网络请求。

## 3. 圆角与间距

- `--tag-radius: 6px`（标签 chip）
- `--tag-radius-lg: 8px`（输入区/下拉）
- 输入区：`min-height 44px`，`padding 8px 48px 8px 10px`（右侧 48px 为计数器预留）。
- chip：高 28px，`padding 0 8px 0 10px`，gap 6px。

## 4. 动效系统

动效服务语义，禁止 Ken Burns / 无关装饰。

| 名称 | 触发 | 时长 | 曲线 | 说明 |
|---|---|---|---|---|
| `tag-pop-in` | 标签入槽 | 220ms | `cubic-bezier(0.34,1.56,0.64,1)` 弹簧 | scale 0.85→1.04→1，轻微 overshoot 后回正，签名咬合感 |
| `tag-shake` | 重复/超限拒绝 | 300ms | `linear` | translateX ±4px 来回，有分量的拒绝 |
| `tag-spin` | 异步加载 | 700ms | `linear` infinite | spinner 旋转，持续感 |
| 建议下拉 | 开/关 | 160ms | `cubic-bezier(0.4,0,0.2,1)` | opacity + translateY(-4px→0) |
| chip 移除 | 删除 | 160ms | `ease` | opacity→0 + scale(0.9) + width→0 |
| 焦点环 | 聚焦 | 220ms | `--tag-ease` | border-color + 3px 外发光 |
| 主题切换 | 切深色 | 220ms | `ease` | 背景色/字色过渡 |

- 弹簧曲线专用于入槽弹性反馈；线性仅用于持续加载与拒绝抖动；`--tag-ease` 用于状态过渡。
- `prefers-reduced-motion`：所有动画/过渡降至 0.01ms，抖动关闭，spinner 放慢至 1.5s。

## 5. 状态机（9 个）

rest/empty → typing+建议过滤（debounce 280ms + 异步 320ms）→ suggestion-hover/active → focus 焦点环 → selected chip 入槽 → duplicate-error 抖动 → max-disabled（达上限禁用）→ loading 旋转 → removable-on-hover。

## 6. 五层反馈映射

- 预接触：hover 建议项/标签删除按钮透明度变化。
- 接触：聚焦瞬间琥珀焦点环咬合。
- 持续：键入每帧过滤建议、↑↓ 实时高亮。
- 阈值：达上限输入禁用；重复/超限跨阈值被拒。
- 释放衰减：入槽弹簧回正、抖动余震、chip 删除淡出。

## 7. 可访问性

- 键盘全操作：Enter 加/选中、Backspace 删尾、↑↓ 导航、Esc 关闭、逗号/分号批量、Tab 进出。
- `role=textbox` / `listbox` / `option` / `listitem`，`aria-expanded`、`aria-selected`、`aria-label`、`aria-live`（计数）。
- 焦点环可见（琥珀 3px 外发光）。
- 触屏：建议项 mousedown 触发，点击输入区聚焦。
- `prefers-reduced-motion` 降级。

## 8. 技术边界

纯 vanilla 单文件（HTML+CSS+JS），无 React/Babel/CDN/外部字体/图片。组件 CSS/JS 用 `BEGIN / END` 注释标记边界，可独立抽取。`visibilitychange` 暂停定时器，`destroy()` 完全清理。快速操作防叠加（shake timer 去重、debounce 取消旧定时器）。

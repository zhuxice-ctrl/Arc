      用法文档

      快速开始

      // HTML
<div class="tag-input-component" id="myTags" data-max-tags="10">
  <div class="tag-input-field">
    <input type="text" class="tag-input-real" placeholder="输入关键词">
    <div class="tag-suggestions">...</div>
  </div>
</div>

// JS
const tagInput = new TagInput('#myTags', {
  suggestions: ['编程', '设计', '产品', ...],
  initialTags: ['编程'],
  maxTags: 10,
  onTagsChange: (tags) => console.log(tags),
});

      状态机

      • rest / empty — 空输入，占位符可见
      • typing + 建议过滤 — 输入触发异步建议过滤
      • suggestion-hover — 鼠标悬停或 ↑↓ 键盘高亮建议项
      • focus 焦点环 — 琥珀色焦点环 + 3px 外发光
      • selected chip — 标签入槽，弹簧咬合动效
      • duplicate-error 抖动 — 重复标签被拒，线性横向抖动
      • max-disabled — 达到上限时输入框禁用并提示
      • loading — 异步建议加载中的旋转指示
      • removable-on-hover — 悬停标签显示删除按钮

      键盘交互

      • Enter — 添加当前输入为标签，或选中高亮建议
      • Backspace — 空输入时删除最后一枚标签
      • ↑ / ↓ — 在建议列表中导航
      • Esc — 关闭建议下拉
      • 逗号 / 分号 — 批量分隔添加
      • Tab — 焦点进出组件

      可复用性

      • 纯 vanilla，无依赖。CSS / JS 用 BEGIN / END 注释标记了组件边界
      • 改 CSS 变量即可换主题，集成成本 ≤ 3 处
      • 支持 dark 模式：给组件加 data-theme="dark"
      • prefers-reduced-motion 自动降级
      • 页面隐藏时自动暂停定时器，卸载时清理

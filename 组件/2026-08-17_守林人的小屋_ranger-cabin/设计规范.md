# 守林人的小屋·拟物实验室 — 设计规范

> 日期：2026-08-17 · 方向：V3 UX 交互设计 · 主题：光标驱动的拟物化小组件动画

## 色彩系统

| 角色 | 色值 | 用途 |
|------|------|------|
| 暖木棕 | `#2E1E14` | 主背景、木墙底 |
| 黄铜金 | `#C98A4B` | 金属件、旋钮、铜环 |
| 炉膛橙红 | `#D94F2B` | 火焰、马灯光晕、强调 |
| 羊绒米 | `#E8DCC8` | 高光、文字、羊绒织物 |
| 炭黑 | `#171310` | 最深底、阴影 |
| 辅助 | `#1A2A18` / `#233A20` / `#3D2817` / `#5A3820` | 夜林墨绿、木纹层次 |

整体为林间小屋暖木 + 黄铜 + 炉火的拟物质感，禁止蓝紫渐变。

## 字体

- 中文标题 / 标签：`"KaiTi", "STKaiti", "楷体", "Songti SC", serif`
- 等宽编号：`"Courier New", monospace`

## 圆角与材质

- 木质物件：8–16px 圆角 + 多层 box-shadow 模拟厚度
- 黄铜件：径向渐变 + 高光描边
- 火焰：径向渐变 + blur 滤镜

## 装置（6 件，光标驱动）

| 展区 | 交互 | 物理模型 |
|------|------|----------|
| 01 拉绳马灯 | 下拉拉绳点亮/熄灭 | Hooke 弹簧回弹 + 光晕抖动 |
| 02 拨杆风门 | 左右拨动调火焰档位 + 火星粒子 | 阻尼粒子 + 火焰缩放 |
| 03 磁吸鹿铃 | 鼠标靠近磁力吸附，快速划过摇响 | 反平方引力 + 摆动阻尼 |
| 04 旋转罗盘窗 | 拖拽旋转带动林景平移 + 色温变化 | 旋转惯性 + 日夜色调 |
| 05 弹簧信箱 | 按住下沉、松开回弹，信件弹出 | 弹簧阻尼 + 3D 翻转 |
| 06 烛火吹熄 | 快速划过吹熄，缓慢靠近光晕被推开 | 气流倾斜 + 青烟粒子 |

## 动效系统（12+ 项）

1. 自定义光标（白环 + 黄铜内点 + 发光，开页居中，悬停放大变色，拖拽缩小，点击涟漪）
2. 拉绳弹簧下垂 + 回弹
3. 马灯光晕扩散 + 墙面光影
4. 火焰径向缩放抖动
5. 火星粒子（阻尼上升 + 淡出）
6. 鹿铃反平方磁吸偏转
7. 鹿铃摆动阻尼衰减
8. 罗盘旋转惯性
9. 林景平移视差 + 色温插值
10. 信箱弹簧按压回弹
11. 信件 3D 翻转弹出
12. 烛火气流倾斜
13. 青烟粒子上升

物理模型：Hooke 弹簧（F=-kx）、反平方引力（F∝1/r²）、阻尼振动、旋转惯性积分（RAF 积分器）。

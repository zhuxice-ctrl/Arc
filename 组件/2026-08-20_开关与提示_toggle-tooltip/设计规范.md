# 设计规范 · 开关与提示（Toggle & Tooltip）

> 批次：V3 交互组件 · 2026-08-20
> 形态：生产级可复用 UI 组件（输入类 + 覆盖层类）
> 产出文件：`index.html`（纯 vanilla 单文件，零外部依赖）

## 1. 设计母题与定位

- **母题**：一张安静的「设置面板工作台」——米白纸面、墨黑控件，柿橙色只出现在焦点与激活的瞬间。不为炫技，只解决两个真实高频界面问题：设置项的布尔开关（含需请求后端的异步语义）与字段/图标的轻量释义浮层。
- **核心概念**：组件是主角，展示页是配角。所有装饰动画删掉后，两组件功能仍完整可用。
- **视觉来源**：现代中文效率应用的设置页 + 纸张印刷质感（细边框、轻投影、无玻璃拟态、无蓝紫渐变）。

## 4. Toggle 组件规范

### 尺寸
- 标准：轨道 `44×24px`，滑块 `18px`，圆角 `12px`
- 大号 `.tg-lg`：轨道 `52×28px`，滑块 `22px`

### 状态机（8 态，全部真实可演示）
| 状态 | 表现 | 触发/标记 |
|---|---|---|
| rest（未选） | 暖灰轨道，白滑块居左 | `aria-checked="false"` |
| checked（已选） | 柿橙轨道，滑块居右 | `aria-checked="true"` |
| hover | 滑块 `scale(1.06)`，轨道微亮 | 鼠标悬停 |
| focus | 2px 柿橙焦点环 + 2px offset | `:focus-visible`（Tab） |
| active（按下） | 滑块宽度 `×1.08` 拉伸（挤压感） | `:active` |
| disabled | 暖灰 + `cursor:not-allowed` | `aria-disabled="true"` |
| loading | 滑块变 spinner，禁用交互 | `aria-busy="true"` |
| error | 砖红描边 + 横向微震 300ms → 自动回滚原值 | `.is-error` |

### 动效系统
- 滑块位移：`220ms cubic-bezier(0.34, 1.56, 0.64, 1)`（弹簧 overshoot，轻量切换要利落带咬合感）
- 按下挤压：滑块宽度 `×1.08`
- error 微震：`translateX(-3/3/-2/2px)`，300ms `ease-in-out`
- loading spinner：`rotate 360°`，`800ms linear infinite`
- prefers-reduced-motion：以上全部退化为 ≤120ms 淡入淡出或直接切换，无位移无弹簧

### 无障碍
- `role="switch"` + `aria-checked`；键盘 Space/Enter 切换；`aria-busy` / `aria-disabled` 正确
- 异步：乐观更新 → loading → 成功保留 / 失败 `showError()` 回滚 `prevValue` 并行内提示「保存失败，已恢复原设置」

## 5. Tooltip 组件规范

### 触发（三触发）
- hover：进入延迟 `300ms`、离开延迟 `120ms`（连续扫过多锚点不连发，定时器按 key 复用）
- focus：聚焦立即显示（键盘可达）
- 触屏 tap：切换显隐，点别处关闭
- Esc：关闭并归还焦点

### 智能翻转（签名手感）
`computePlace()` 测量锚点 `getBoundingClientRect()` 与四向可用空间：
1. 首选方向空间够 → 用首选
2. 不够 → 试对侧（top↔bottom、left↔right）
3. 仍不够 → 试两个正交方向
4. 都不够 → 选可用空间最大的方向
阈值 = tooltip 尺寸 + 12px margin。箭头为 CSS 三角，跟随 `data-place` 四向翻转。

### 样式
- 墨黑底 `--tt-bg` + 米白字 `--tt-fg`（墨夜主题反相）
- 圆角 6px，padding `6px 10px`，13px，最大宽 240px，`z-index: 10000`
- 弹出：`scale(0.96→1) + opacity`，`180ms cubic-bezier(0.22,1,0.36,1)`

### 无障碍
- 锚点 `aria-describedby` 指向 `role="tooltip"` 浮层
- 禁用元素用 `.tt-disabled-wrap` 包裹（`pointer-events:none` 子元素）以承接 tooltip

## 6. 工程健壮性

- **PausableTimer 工具**：所有 `setTimeout` 经由它，按 key 复用（同 key 先 clear 再 set，快速操作不叠加定时器）；`visibilitychange` 隐藏时 `pauseAll()`、恢复时 `resumeAll()`。
- **Tooltip 定位**用 `getBoundingClientRect` 直接写 `style`，无框架重渲染；`resize`/`scroll`（捕获）触发重定位。
- **零未定义引用、零运行时崩溃**：Browser QA 实测 Console 无 Error，1440/390 两档渲染非空白（std 18.18 / 26.84），无横向溢出。
- **prefers-reduced-motion** 完整降级块覆盖 `.tg-switch/.tg-thumb/.tt-tip/.theme-btn/.btn/.icon-btn/.tg-row-error-tip`。
- **代码可抽取**：组件 CSS / 展示页 CSS 用注释块分区（`==== Toggle 组件开始/结束 ====`、`==== Tooltip 组件开始/结束 ====`、`==== 展示页样式开始 ====`）；JS 为命名空间 IIFE（`Toggle` / `Tooltip` / `PausableTimer`），互不污染全局。

## 7. 与历史作品的差异

- 类别正交：覆盖层（Tooltip）+ 输入（Toggle），近期 V3 已做骨架屏/抽屉+分段/拾色+评分/上传按钮/分页/OTP/命令面板/多选下拉/底部弹层/手风琴/拖拽排序/树形/步进/Toast/滑动操作/Modal/长按/区间滑块/标签输入/右键菜单/日期范围，**均无 Toggle 与 Tooltip**，无近亲重复。
- 配色（柿橙+苔绿+米白宣纸，无蓝紫）与近期（雾灰+teal、teal accent）不雷同。

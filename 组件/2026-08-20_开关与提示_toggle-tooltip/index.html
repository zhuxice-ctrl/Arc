引入方式

两个组件完全独立，零外部依赖。复制对应样式块与脚本块到你的项目即可使用，无需安装任何依赖。

<!-- 1. 复制 CSS 到 <style> 中 -->
/* ==== Toggle 组件开始 ==== */ ... /* ==== Toggle 组件结束 ==== */
/* ==== Tooltip 组件开始 ==== */ ... /* ==== Tooltip 组件结束 ==== */

<!-- 2. 复制 JS 到 <script> 中 -->
// ==== Toggle 组件 ==== ...
// ==== Tooltip 组件 ==== ...

<!-- 3. HTML 中使用 -->
<button class="tg-switch" role="switch" aria-checked="false">
  <span class="tg-track"></span>
  <span class="tg-thumb"></span>
  <span class="tg-spinner" aria-hidden="true"></span>
</button>

<button data-tip="提示文案" data-tip-place="top">锚点</button>

只需修改 --tg-* 与 --tt-* 开头的 CSS 变量即可完成主题定制，通常改 2-3 处变量即可适配你的设计系统。

Toggle JS API

// 基础实例化
const toggle = Toggle.create(el, {
  checked: false,       // 初始状态
  disabled: false,      // 是否禁用
  async: null           // 异步函数，返回 Promise
});

// 异步示例（模拟请求后端）
Toggle.create(el, {
  async: (nextValue) => {
    return fetch('/api/setting', {
      method: 'POST',
      body: JSON.stringify({ value: nextValue })
    }).then(r => r.ok);
  }
});

// 方法
toggle.setChecked(true);    // 直接设值
toggle.setDisabled(true);   // 设置禁用
toggle.destroy();           // 销毁实例

Tooltip JS API

// 自动实例化（所有 [data-tip] 元素）
Tooltip.init();

// 手动绑定
const tip = Tooltip.bind(el, {
  content: '提示文案',
  place: 'top',          // top|bottom|left|right
  delay: 300,            // hover 延迟 ms
  hideDelay: 120         // 离开延迟 ms
});

// 方法
tip.show();               // 立即显示
tip.hide();               // 立即隐藏
tip.update('新文案');     // 更新内容
tip.destroy();            // 销毁

无障碍说明

Toggle：使用 role="switch" 语义角色，状态通过 aria-checked 表达；禁用态使用 aria-disabled；加载中使用 aria-busy。焦点环可见且有 2px 偏移，确保键盘用户可定位。

Tooltip：浮层使用 role="tooltip"，锚点通过 aria-describedby 关联。聚焦锚点时自动显示，Esc 关闭后焦点回到锚点。禁用元素通过 wrapper 承载 tooltip，保证可聚焦性。

动效降级：完整支持 prefers-reduced-motion，所有过渡、动画、震动均退化为无位移的淡入淡出或直接切换。

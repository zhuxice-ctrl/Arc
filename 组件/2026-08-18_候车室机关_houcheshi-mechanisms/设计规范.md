# 候车室机关 · 拟物化小组件实验室 · 设计规范

> 日期：2026-08-18 · 方向：V3 UX 交互设计 · 主题：老火车站候车室拟物化机关装置实验室

## 一、设计概念

把老火车站候车室里的机械装置做成可上手把玩的拟物化微交互实验室。每件展品是一个有场景叙事的机关（翻牌时刻表、拉杆检票口、投币闸机、拨盘售票机、拉杆煤气灯、行李转盘），全部由鼠标光标拖拽 / 点击 / 悬停驱动，强调物理质感与细腻反馈。整体是"深栗木 + 烟青冷调 + 铜橙暖金属 + 奶油高光"的老物件气质。

## 二、色彩系统

| 角色 | 色值 | 用途 |
|---|---|---|
| 深栗（主底） | `#3d2b1f` | 木质底、深底 |
| 深褐 | `#2a2018` / `#251b13` / `#1a120d` / `#0a0705` | 木质暗部、阴影 |
| 烟青（冷调中性） | `#7a8b8b` | 金属冷调、边框 |
| 铜橙（暖金属强调） | `#c97b3a` | 黄铜部件、动作高光 |
| 黄铜金 | `#8b6914` / `#f0d080` | 金属高光、光泽扫过 |
| 奶油（高光/纸面） | `#f0e6d2` | 文字、高光、纸面 |

配色规则：深栗木质大面积铺底，铜橙承担金属部件与动作反馈，烟青作冷调中和，奶油用于文字与高光，制造"老木+黄铜+旧纸"质感。

## 三、字体

- 正文：`"Noto Sans SC", sans-serif`
- 衬线点缀：`"Noto Serif SC", "Songti SC", "SimSun", serif`
- 刻度/数字：`"Courier New", monospace`（机械刻度感）

## 四、圆角

以小圆角与硬边为主（1px / 2px / 3px），匹配机械零件的硬朗质感；圆形部件用 50% / 40% 40% 50% 50% 异形。

## 五、展区（6 件展品）

1. 翻牌时刻表：点击翻牌 / 拖拽连翻，机械咔哒感
2. 拉杆检票口：拖拽拉杆，弹性回弹 + 磁性吸附归位 + 闸门联动
3. 投币售票闸机：拖拽硬币投入，齿轮转动 + 三臂闸机旋转 + 火花粒子
4. 拨盘售票机：旋转拨盘，惯性阻尼 + 档位磁性吸附 + 价格联动
5. 拉杆煤气灯：拉绳开关，光线扩散 + 阴影联动 + 火焰闪烁
6. 行李转盘：拖拽旋转，惯性阻尼 + 3D 透视椭圆路径 + 深度排序

## 六、动效系统

1. 自定义光标（白环 + 铜点 + 发光 + 点击涟漪 + 拖拽形变）
2. 拖拽惯性（RAF 积分器）
3. 弹性回弹（Hooke 弹簧）
4. 磁性吸附归位（反平方引力）
5. 涟漪扩散
6. 光泽扫过
7. 光线扩散（拉杆灯）
8. 阴影联动
9. 火花粒子
10. 3D 倾斜卡片悬停
11. 数字翻牌
12. 滚动渐入

## 七、物理模型

- 弹簧 Hooke 定律（回弹）
- 惯性动量 + 阻尼 + 摩擦（拖拽旋转 / 拨盘）
- 磁性反平方引力（档位吸附）
- 统一 RAF 循环管理器，动效周期各不相同

## 八、健壮性

纯 vanilla 单文件（无 React / 无 Babel / 无 CDN）；rAF/定时器随 visibilitychange 暂停、卸载统一取消；重建前先 clearTimeout/cancelAnimationFrame；mousemove 直操 DOM transform；prefers-reduced-motion 降级；零未定义引用。

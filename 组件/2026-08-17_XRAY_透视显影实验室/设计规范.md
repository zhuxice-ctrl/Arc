# 设计规范 · XRAY 透视显影实验室

> 日期：2026-08-17 ｜ 方向：V3 UX 交互设计 ｜ 主题：X 光透视 / 显影炫技实验室

## 技术栈

纯 vanilla HTML/CSS/JS 单文件实现，无 React / 无 Babel / 无外部 CDN 依赖（字体除外）。从根本上规避平台 JSX/Babel 白屏风险。

## 色彩系统

| 角色 | 色值 | 用途 |
|------|------|------|
| 底色 碳黑 | `#0A0C0E` | 全局背景 |
| 主显影色 骨白 | `#E8E4D8` | 骨架、文字、显影层 |
| 强调色 透视青 | `#5EEAD4` | 扫描线、HUD、光标内点 |
| 点缀色 警示橙 | `#FF7A1A` | 热点、阈值警告、按钮发光 |
| 扫描线 | 半透青绿 `rgba(94,234,212,.12)` | 扫描叠加层 |

深色高对比，禁蓝紫渐变；三版配色与 V1（浅蓝橙）/ V2（绿米红）互斥。

## 字体

- 标题/代号：`'Space Grotesk', 'Noto Sans SC', monospace`（仪器面板感）
- 正文：`'Noto Sans SC', system-ui, sans-serif`

## 圆角 / 阴影

- 装置面板圆角 `4px`（仪器冷感）；按钮 `2px`
- 发光：`0 0 24px rgba(94,234,212,.35)`，警示橙 `0 0 18px rgba(255,122,26,.5)`

## 自定义光标

开页即显示在屏幕中央，白色粗环 + 透视青内点 + 多层发光，z-index 最高；悬停可交互元素三态切换；点击涟漪。

## 动效原理

基于物理模型（弹簧缓动 / 阻尼 / RAF 积分器）或显影主题语义（扫描显影 / 伪彩映射 / 频闪残影）。动效周期各异，禁整图缩放 / Ken Burns。

## 健壮性红线

- 零未定义引用
- 所有 RAF 通过统一注册系统管理，`visibilitychange` 自动暂停 / `beforeunload` 统一取消
- 高频事件直接操作 DOM transform
- 支持 `prefers-reduced-motion`

## 展区结构（六大拟物化微交互装置）

| 展区 | 交互方式 | 物理 / 叙事 |
|---|---|---|
| 壹 · 百子柜 | 拖拽抽屉拉出 | 松手弹簧阻尼回弹，药材露出 |
| 贰 · 戥秤 | 拖拽秤砣左右移动 | 秤杆按力矩平衡倾斜，剂量实时显示 |
| 叁 · 捣药铜臼 | 点击 / 按住研杵 | 研杵下落反弹，药粉粒子飞溅 |
| 肆 · 门帘铜铃 | 光标拨动铜铃 | 阻尼摆动 + 三层声纹光晕扩散 |
| 伍 · 纸包药包 | 拖拽旋转视角 / 点击折叠 | 四翼依次折叠打包，红绳显现 |
| 陆 · 紫砂壶 | 悬停壶身 | 壶盖蒸汽升腾，粒子随机漂移 |

## 动效系统

- 自定义光标：白色粗环 + 朱砂内点 + 黄铜发光，三态切换（普通 / 悬停 / 点击涟漪），加载即居中显示
- 红灯笼摇曳开场（场景叙事）
- 全部装置动效基于弹簧 / 阻尼 / 力矩物理模型（RAF 积分器），各装置周期各异
- 药粉飞溅、蒸汽升腾等粒子特效均为实时模拟，非贴图

## 技术栈

纯 vanilla HTML / CSS / JS 单文件，零外部依赖（无 React / 无 Babel / 无 CDN）。

## 健壮性

- 统一 RAF 调度器，页面隐藏自动暂停、卸载统一取消
- 零未定义引用
- 支持 `prefers-reduced-motion` 降级

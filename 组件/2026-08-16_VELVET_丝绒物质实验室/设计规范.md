# VELVET 丝绒物质实验室 · 设计规范

> 2026-08-16 · V3 · UX 交互设计

## 主题

丝绒、金箔、液态金属等奢华物质质感的炫技特效实验室

## 配色

深酒红 #6E1423 + 香槟金 #D8B26E + 象牙白 #F7F2E9 + 炭黑 #171014

（严格禁蓝紫渐变）

## 字体

系统无衬线 + Playfair Display

## 动效设计

丝绒粒子流场 / 金箔散落 / 液态金属涟漪 / 绸带拖尾 / 磁性吸附 / 光泽频谱

## 技术实现

- 单文件 HTML 实现（CSS + JS 全内联）
- 自定义光标开页即居中显示
- RAF 统一管理，visibilitychange 自动暂停/恢复
- 支持 prefers-reduced-motion 降级
- 无外部 JSX 引用，无外部本地文件依赖

## 组件规范

- **展区卡片**：圆角 16px，底色 #141414，边框 1px solid #1E1E1E，padding 32px
- **按钮**：圆角 8px，主色 #B6FF3C 底黑字 / 透明底+边框，悬停发光 box-shadow
- **开关**：多种风格（滑动/翻转/脉冲/弹跳/磁吸），各有独立尺寸和动画
- **进度环**：SVG circle，stroke-width 8，圆角 linecap
- **粒子**：Canvas 渲染，多种形状（圆/方/三角/星），带物理散落

## 展区结构（6 个交互装置）

1. **01 按键波纹风暴**：键盘任意键 → Canvas 三重环形涟漪 + 18 粒子飞溅 + 键名字母弹出消散
2. **02 图标变形矩阵**：6 个 SVG 图标（心/星/齿轮/闪电/对勾/铃铛）→ 点击触发 4 帧 morphing 路径变形
3. **03 开关交响曲**：5 种风格开关（滑动/翻转/脉冲/弹跳/磁吸）→ 切换时连锁动画反馈
4. **04 进度环星系**：全环/半环/分段环 → 按钮 START/RESET，错峰填充 + 数字计数
5. **05 点击爆破粒子工厂**：点击任意位置 → 4 种形状粒子（圆/方/三角/星）带重力弹跳碰撞
6. **06 状态指示器花园**：5 种指示器（呼吸灯/脉冲圈/加载点/波形条/旋转环）× 4 种状态（IDLE→RUN→DONE→ERROR）

## 技术栈

- 纯 vanilla HTML/CSS/JS 单文件（无 React / 无 Babel / 无外部 CDN 依赖）
- Canvas 2D API（粒子系统、涟漪、爆破）
- SVG + path morphing（图标变形）
- CSS Animation + Transition（开关、状态指示器）
- requestAnimationFrame（粒子物理、动画循环）
- 支持 prefers-reduced-motion
- visibilitychange 自动暂停/恢复 rAF

# INK 墨迹实验室 · 设计规范

> V3 UX 交互设计方向 · 2026-08-16 · 以水墨为灵感的炫技组件特效实验室

## 色彩系统

| 角色 | 色值 | 用途 |
|---|---|---|
| 宣纸米白（底） | `#F5F0E6` | 全站背景，模拟宣纸质感 |
| 松烟墨黑（主） | `#1A1A1A` / `#000` | 墨迹、文字、深色面板 |
| 朱砂红（强调） | `#B8322B` / `#8E241E` | 印章、强调标记、光标内点 |
| 金箔（点缀） | `#C9A961` / `#DBC48A` | 装饰线、次要强调 |
| 辅助层次 | `#E8E0D0` / `#D9CFB8` | 卡片表面、边框 |
| 次级文字 | `#555` / `#2A2A2A` | 说明文字 |

配色为水墨系，未使用蓝紫渐变。

## 字体栈

- 中文标题：`"Noto Serif SC", "Songti SC", serif`（衬线，书法质感）
- 正文：`"Noto Sans SC", system-ui, sans-serif`
- 西文：`Georgia, serif`

## 六大展区（每展区独立可把玩）

1. **墨迹晕染** — 点击落墨，基于表面张力扩散模型，边缘不规则纤维渗透。
2. **笔触拖尾** — 按住书写，速度-宽度映射还原提按顿挫，含散毫飞白粒子。
3. **飞白迸溅** — 快速划过触发动量衰减粒子群，速度越快迸溅越远。
4. **滴墨涟漪** — 点击滴墨，同心扩散 + 波的叠加干涉纹样。
5. **文字解构** — 鼠标扰动 + 点击切换文字，粒子系统缓动回归字形。
6. **纤维流场** — Perlin 噪声流场，数千纤维粒子沿向量场有机游动。

## 组件规范

- **自定义光标**：白环 + 朱砂内点 + 三态切换 + 涟漪 + 拖尾，z-index 最高。
- **展区卡片**：宣纸底 + 墨色细边框，圆角 12px，3D 倾斜随鼠标。
- **导航栏**：滚动收缩，墨色毛玻璃。
- **印章**：朱砂方形印章，悬停脉冲发光。

## 动效系统（12+）

1. 自定义光标（白环 + 朱砂内点 + 三态 + 涟漪 + 拖尾）
2. 打字机（展区标题）
3. 数字计数（展区参数）
4. 滚动渐入（IntersectionObserver）
5. 3D 卡片倾斜
6. Hero 漂浮墨点视差
7. 印章脉冲
8. 光泽扫过按钮
9. 悬停下划线
10. 导航栏滚动收缩
11. 六展区各自的粒子/流体/噪声系统（墨迹扩散、笔触压感、飞白动量、涟漪干涉、文字粒子回归、Perlin 流场）

## 健壮性

- 纯 vanilla HTML/CSS/JS 单文件实现，零 React/Babel/CDN 依赖。
- `visibilitychange` 暂停全部 RAF/定时器，卸载统一取消。
- 快速操作不叠加定时器（重建前 cancel 旧的）。
- 高频 mousemove 直接操作 DOM transform。
- `prefers-reduced-motion` 降级为最小动效。

# 设计规范 · 树形导航组件 Tree Navigator

> 2026-08-19 · V3 实用可复用 UI 组件 · 类别：导航类
> 设计母题：文件管理器目录树 / 权限分配树 / 组织架构树

## 一、设计观点

树形是中后台与工具型项目里最高频的层级导航与多选控件——文件目录、权限分配、组织架构、分类导航、多级筛选都绕不开它。本组件不追求视觉奇观，而是把开发者最常踩坑的三件事做对：**checkbox 级联半选、异步加载子节点、完整键盘导航**。视觉走冷石板专业基调，像代码编辑器文件树 / 权限树那样克制可信，是真实项目里的一员而非艺术装置。

## 三、字体

- 正文：`-apple-system, BlinkMacSystemFont, "Segoe UI", "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", sans-serif`（系统无衬线，中文优先）
- 等宽（计数 / 路径）：`"SF Mono", ui-monospace, "Cascadia Code", "Menlo", "Consolas", monospace`

## 四、动效系统（服务语义，非炫技）

| 动效 | 时长 | 曲线 | 语义 |
|---|---|---|---|
| 行 hover/focus 背景 | `var(--tree-duration)` 180ms | `ease` | 预接触预告 |
| 展开高度过渡 | 180ms | `cubic-bezier(0.4,0,0.2,1)` | 状态过渡 |
| 子项 stagger fade-in | 120ms ×N（30ms 间隔） | `cubic-bezier(0.4,0,0.2,1)` | 内容出现 |
| checkbox 勾选 | 180ms | `cubic-bezier(0.34,1.56,0.64,1)` | **弹簧反馈**（弹性咬合） |
| indeterminate 半选填充 | 180ms | `cubic-bezier(0.4,0,0.2,1)` | 阈值质变 |
| loading spinner | 线性 | 持续旋转 | 持续感 |
| chevron 旋转 | 180ms | `cubic-bezier(0.4,0,0.2,1)` | 方向指示 |

- 弹簧曲线 `cubic-bezier(0.34,1.56,0.64,1)` 仅用于 checkbox 弹性反馈；线性/标准缓动用于其余过渡。
- 支持 `prefers-reduced-motion`：动画降级为系统/无动画，功能不受影响。
- RAF / 定时器随 `visibilitychange` 暂停，卸载时取消，快速操作不叠加定时器。
- **删掉全部装饰动画后，组件功能完整可用**（展开/收起/选择/级联/键盘均不依赖动画）。

## 五、状态机（≥9 态）

| 状态 | 表现 |
|---|---|
| collapsed-rest | chevron 朝右，子节点隐藏 |
| expanded | chevron 旋转朝下，子节点可见（stagger 入场） |
| hover | 行底 `--tree-hover` |
| focus | 焦点环 `--tree-focus-ring`，键盘模式才显示（鼠标移动自动隐藏） |
| selected | 行底 `--tree-selected` |
| loading | 异步子节点展开时 spinner 旋转（`--tree-spinner-color`） |
| indeterminate | checkbox 半选——水平线填充，`aria-checked="mixed"` |
| checked / unchecked | 实心勾 / 空框，`aria-checked="true"/"false"` |
| disabled | 文字 `--tree-disabled-fg`，不参与级联，不可操作 |
| empty | 展开后无子节点显示「暂无子节点」 |

## 六、键盘

`Tab` 进树 → `↑↓` 移动焦点并滚动入视 → `→` 展开（已展开则进首子项）→ `←` 收起（已收起则跳父项）→ `Enter`/`Space` 选中或切换 checkbox → `Home`/`End` 跳首尾。鼠标移动自动退出键盘焦点环模式。

## 七、级联与异步

- **级联**：选父全选子并向上更新；选子向上更新父为 `checked`/`indeterminate`/`unchecked`；`disabled` 项不参与级联。
- **异步**：节点 `hasChildren` 且未加载时，展开触发 `loading` → 模拟延迟 800–1200ms → 填充子节点；`loader` 可配置为真实 fetch。

## 八、技术栈

纯 vanilla 单文件（HTML + CSS + JS），无 React / Babel / CDN / 外部字体 / 外部图片，相对路径。组件代码以 `/* === TREE COMPONENT === */` 命名空间划界，`Tree` 类封装，CSS 用 `.tree__` BEM 命名，可独立抽取。

用法 · Usage ▾

快速使用

const tree = new Tree(document.getElementById('tree-container'), {
  data: treeData,
  multiSelect: true,
  showCheckbox: true,
  loader: async (node) => {
    // 从后端加载子节点，返回子节点数组
    return await fetchChildren(node.id);
  },
  onSelect: (node) => console.log('selected:', node),
  onCheck: (nodes) => console.log('checked:', nodes),
});

配置项

  • data — 树形数据，节点字段：id / label / children / disabled / hasChildren
  • multiSelect — 是否支持多选（配合 checkbox 使用），默认 false
  • showCheckbox — 是否显示复选框，默认 false
  • loader — 异步加载子节点函数，接收 node，返回 Promise<TreeNode[]>
  • defaultExpandAll — 默认是否全部展开，默认 false
  • onSelect(node) — 单选变化回调
  • onCheck(nodes) — 勾选变化回调
  • onExpand(node, expanded) — 展开/收起回调

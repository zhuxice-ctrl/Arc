# 设计规范 · 弹弓打靶（拉伸释放物理实验室）

**类别**：交互组件　**日期**：2026-08-19

## 一、设计母题
黄昏打谷场上一枚 Y 形木杈弹弓——抓住皮兜向后下方拖拽拉伸皮筋，瞄准远处木桩上的易拉罐塔，松手弹射石子。核心机制=「拉伸储能 → 瞄准 → 释放飞行 → 命中坍塌」五段式操作闭环。

## 二、视觉与材质
| 角色 | 色值 | 用途 |
|---|---|---|
| 晚霞珊瑚橙 | #E07B39 | 天空/暖调 |
| 干草金 | #D9B36A | 地面/远景 |
| 原木棕 | #6E4B36 | 弹弓木杈/树桩 |
| 皮筋深褐 | #3E2A1E | 皮筋/皮兜 |
| 石灰白 | #EFE8DA | 罐体/信息卡 |
| 远天灰粉 | #C9A68E | 远山 |

材质：原木 + 皮革 + 金属罐 + 黄昏尘土。禁蓝紫渐变。

## 三、物理模型（非缓动函数堆砌）
- **胡克定律非线性拉伸阻力**：拉伸量越大阻力越大，越接近极限越难拉
- **阻尼弹簧振荡**：松手后皮筋回弹振荡 3-4 次衰减
- **重力抛物线**：石子飞行受重力，带自旋
- **碰撞冲量 → 角速度 → 阻尼摇摆**：罐子受击按冲量获得角动量倾倒，摇摆衰减后静止；堆叠连锁坍塌

## 四、双段皮筋几何
两条皮筋从木杈两端汇聚到皮兜，拉伸时实时变细变深、形变随拖拽连续更新。

## 五、五层反馈
| 层 | 现象 |
|---|---|
| pre-contact | 皮兜微亮、皮筋轻颤（光标接近） |
| contact | 抓住的咬合感 + 皮革吱嘎视觉反馈 |
| continuous | 每帧拉伸量=力度表 + 瞄准虚线抛物线 + 手部颤抖随拉伸增大 |
| threshold | 接近极限拉伸时警告性高频震颤 |
| release/decay | 皮筋回弹振荡 + 石子飞行旋转 + 罐子倒地余摆 + 尘土粒子 |

## 六、自定义光标
小石子——开页屏幕正中央、高对比、层级最高，三态变形：普通 / 抓取 / 瞄准。prefers-reduced-motion 降级为系统光标。

## 七、可玩性闭环
- 得分（一箭多罐加成）
- 剩余石子数（8 发）
- 剩罐计数
- 「重新摆罐」按钮重置罐塔
- 每发结果有真实方差（角度/力度/连锁坍塌）

## 八、技术边界
- 纯 vanilla 单文件（无 React/Babel/CDN）
- RAF 随 visibilitychange 暂停、cancelAnimationFrame 卸载取消
- 高频 mousemove 直接操作 DOM，不触发重渲染
- prefers-reduced-motion：简化颤振与粒子、保留核心物理
- 零 Console Error（1280×800 通过，拖拽后石子确认飞行）

## 九、文案
中文为主：「抓住皮兜向后拖拽，松手发射」「重新摆罐」「得分/石子/剩罐」。

# RISO 孔版印刷特效实验室 · 设计规范

> 方向：V3 UX 交互设计 · 日期：2026-08-17 · 主题：孔版油印（Risograph）美学组件特效实验室

## 1. 色彩系统

主配色为「荧光油墨叠印」调，取自 Risograph 孔版印刷专色油墨，无蓝紫渐变。

| 角色 | 色值 | 用途 |
|---|---|---|
| 底色 · 纸白 | `#F6F1E7` | 纸面背景 |
| 专色一 · 荧光洋红 | `#FF3E8A` | 主专色、自定义光标内点 |
| 专色二 · 亮橙 | `#FF6B1A` | 第二专色、点击涟漪 |
| 专色三 · 孔雀蓝绿 | `#0FA3A3` | 第三专色（teal，非蓝紫） |
| 墨黑 | `#1E1B16` | 文字、深色面板 |

派生层次：`#2a2620` / `#3a352e` / `#4a4238`（墨黑分层）、`#e6337a`（洋红暗阶）、`#d95a0f`（橙暗阶）。

## 3. 六个可把玩特效展区

每个展区必须上手操作才有意义：

1. **半调网点生成器** — 鼠标涂抹将画面实时转为可调大小 / 角度 / 对比度的 halftone 半调图像，支持 4 种专色。
2. **油墨叠印混色** — 拖动三层专色油墨（洋红 / 青蓝 / 橙黄）互相叠加，multiply / 滤色 / 叠加三种混合模式，可开启自动抖动。
3. **错版套准台** — 滑块或直接拖动控制洋红 / 青蓝层 XY 偏移，multiply 叠印出真实错版美感，支持切换文字内容。
4. **颗粒纸纹噪波** — 三种样式（随机噪点 / 纸纤维 / 点状颗粒），可调密度 / 大小 / 动画速度，专色可切换。
5. **丝网刮墨拖尾** — 按住鼠标拖动刮刀，油墨厚度随速度变化，带渐干衰减与颗粒感，支持多色模式。
6. **滚筒印刷机** — 按住滚筒滚过纸面，文字 / 图案随滚速被油墨转印（慢滚清晰、快滚变淡），三种印刷内容。

## 4. 动效系统

- 自定义光标：白环 + 荧光洋红内点 + 多层发光，页面加载即居中显示，悬停可交互元素放大变色，点击产生橙色涟漪。
- 各展区内部均为基于物理模型（速度衰减 / 阻尼 / RAF 积分器）或印刷语义（油墨厚度随刮墨速度、滚筒转速决定转印浓度）的组件级特效。
- 动效周期各不相同，无整图缩放 / Ken Burns。

## 5. 健壮性

- 零未定义引用。
- `visibilitychange` 自动暂停所有 RAF，卸载统一 cancel。
- 快速来回操作不叠加定时器，重建前先清除。
- mousemove 直接操作 DOM transform，不触发重渲染。
- `prefers-reduced-motion` 降级为静态。

## 6. 技术栈

纯 vanilla HTML/CSS/JS 单文件实现，无 React / 无 Babel / 无外部 CDN 依赖，从根本上规避妙搭平台 JSX/Babel 白屏风险。

# TERRA 玛瑙切片实验室 · 设计规范

- 方向：V3 UX 交互设计 · 日期：2026-08-16
- 形态：单页炫技组件特效实验室（纯 vanilla 单文件）
- 主题：矿石与地质切片的炫技特效舱

## 色彩系统

## 字体

- 终端/代码：`Courier New, monospace`
- UI：系统无衬线

## 六座展区装置（每个必须上手操作）

1. **玛瑙同心纹生长画布** — 按住拖动引导金红环带纹生长，速度越慢密度越高（Canvas 绘制 + 路径积分）
2. **晶体 3D 旋转矩阵** — CSS 3D 六面水晶立方，拖拽旋转 + 释放惯性滑行 + 摩擦衰减
3. **岩层剥离视差剖面** — 四层地层按不同深度速率水平错动，夹层金脉暴露
4. **剖光扫过光泽流** — 光标在矿石表面移动，高光圆弧扫过方向随移动角度变化
5. **矿脉电流文字** — 悬停字符触发电光脉络在字间随机闪烁传递（Canvas 电流束）
6. **砂砾沉积粒子** — 点击/拖动撒布金红砂砾，重力下落 + 安息角堆积 + 地基层理

## 动效系统（≥12 组件级特效）

1. 自定义光标（白环 + 金点 + 发光 + 悬停三态 + 点击涟漪）
2. 环境粒子尘
3. 滚动渐入
4. 数字计数
5. 打字机终端日志
6. 视差
7. 光泽扫过
8. 电流脉络
9. 粒子重力堆积
10. 惯性物理（晶体旋转）
11. 脉冲呼吸
12. 侧面导航 scroll spy

物理模型：重力/惯性/摩擦/安息角；无整图缩放。动效周期各不相同。

## 技术栈

纯 vanilla HTML/CSS/JS 单文件（无 React / 无 Babel / 无外部 CDN 依赖）。RAFManager 统一管理全部循环 + visibilitychange 自动暂停 + pagehide 清理；零未定义引用；鼠标事件直接操作 transform；支持 prefers-reduced-motion。

# 设计规范 · 墨签标签页（ARIA Tablist）

> V3 实用可复用 UI 组件 · 2026-08-19
> 组件类型：导航类 · Tablist / 标签页切换器

## 一、核心概念

生产级 ARIA Tablist——可关闭、可新增、内容区懒加载的标签页切换器。

签名记忆点是激活标签下方一条**共享「墨条」下划线**（单个 DOM 元素），用 `transform: translateX + width` 跟随当前激活标签平滑滑动。键盘 `← →` 连续切换时，下划线像游标一样在标签间流畅迁移——既是激活态指示，也是空间连续性的视觉锚。这是语义性 layout-shared 过渡，**不是装饰特效**。

置于「团队工作区设置」真实场景：概览 / 成员 / 权限 / 审计日志 / 回收站 / 计费六个标签，覆盖正常内容、懒加载成功、加载失败+重试、空状态、禁用标签、动态新增六种真实态。

## 二、视觉语言

**视觉来源**：编辑型内容界面。克制、专业、信息优先，组件本身是中性专业底，靠 CSS 变量承载主题，不靠装饰。

**配色（light 默认，oxblood 编辑风，非蓝紫）**：

| 用途 | 变量 | 值 |
|---|---|---|
| 底色 | `--tabs-bg` | `#F6F1E9` 象牙 |
| 面板/卡片 | `--tabs-surface` | `#FFFBF3` 暖白 |
| 主文字 | `--tabs-ink` | `#1F1B16` 墨 |
| 次文字 | `--tabs-muted` | `#6B5F50` 暖灰 |
| 重音/激活 | `--tabs-accent` | `#7A2E2E` 牛血红 |
| 重音柔 | `--tabs-accent-soft` | `#9E4A4A` |
| 重音前景 | `--tabs-accent-fg` | `#FFFBF3` |
| 边线 | `--tabs-border` | `#E2D8C7` |
| 强边线 | `--tabs-border-strong` | `#C7B99E` |
| 焦点环 | `--tabs-focus-ring` | `rgba(122,46,46,.35)` |

三主题预设（展示页切换器）：light（象牙/牛血红）、dark（`#1A1714` / `#221E1A` / accent `#C76B6B`）、warm（`#EFE6D6` / accent `#B5651D` 赭石）。换主题只覆盖 `.tabs` 上的同名变量。

**字体**：系统字体栈 `-apple-system, "PingFang SC", "Microsoft YaHei", "Helvetica Neue", sans-serif`，无外部字体。数字 `tabular-nums`。字号 `--tabs-font-size` 14px / sm 13px / lg 15px，行高 1.5。

## 三、动效系统（服务语义，非炫技）

| 元素 | 时长 | 曲线 | 语义 |
|---|---|---|---|
| 共享墨条下划线 | `--tabs-duration` 220ms | `cubic-bezier(0.4,0,0.2,1)` | 空间连续性，跟随激活标签 |
| 面板切换 | 180ms | `cubic-bezier(0.2,0.8,0.2,1)` | 内容进入 translateY(6px)+opacity |
| 关闭/chevron/hover | `--tabs-duration-fast` 150ms | ease | 状态过渡 |
| loading spinner | `--tabs-spinner-duration` 0.7s | linear 循环 | 持续加载感 |
| error 重试 shake | `--tabs-duration-slow` 320ms | damped ±6px | 警示/拒绝 |
| 标签新增 | 200ms | spring scale 0.92→1 | 入列 |
| 标签关闭 | 150ms | fade + 宽度收起 | 退场 |

**reduced-motion**：`@media (prefers-reduced-motion: reduce)` 下，下划线瞬移（duration:0）、面板切换无位移无动画、spinner 仍旋转（语义必要）、shake 关闭。

## 四、状态机

**标签维度**：`rest` / `hover` / `focus`（焦点环可见 `:focus-visible`）/ `active`（激活=aria-selected，墨色字重+下划线锚定）/ `disabled`（aria-disabled，降低对比，不可激活，hover 提示）。
**关闭按钮**：`rest` / `hover` / `focus`。
**内容面板**：`rest`（已加载）/ `loading`（spinner）/ `error`（失败信息+重试）/ `empty`（空状态插画+文案）。

共覆盖 5+ 维度，均真实工作。

## 五、键盘交互（ARIA tablist, roving tabindex, focus auto-activate）

| 键 | 行为 |
|---|---|
| `Tab` | 进入 tablist 落到激活标签（tabindex=0，其余 -1）；再次 Tab 进入面板内容 |
| `←` / `→` | 移动焦点并同步激活（下划线滑动 + 面板切换/懒加载） |
| `Home` / `End` | 首个 / 末个可选标签 |
| `Delete` / `W` / `Esc` | 关闭当前聚焦的可关闭标签，焦点按 WAI-ARIA 转移（后→前→首剩余→`+` 按钮） |
| `Enter` / `Space`（在 `+`） | 新增可关闭标签，自动激活并聚焦，面板 loading→success |

键盘处理绑定在 tablist 容器（非 document），面板内输入文字不会误触发 `W`/`Delete`。

## 六、可访问性

完整 ARIA：`role=tablist`（aria-orientation horizontal）、每个标签 `role=tab` + `aria-selected` + `aria-controls=面板id` + roving `tabindex`；面板 `role=tabpanel` + `aria-labelledby=标签id` + `tabindex=0`；禁用标签 `aria-disabled=true`、`tabindex=-1`；关闭按钮 `aria-label="关闭 标签名"`；新增按钮 `aria-label="新增标签"`；spinner `role=status`。焦点环 `:focus-visible` 可见。触屏可用（pointer 兼容）。`prefers-reduced-motion` 降级。

## 七、健壮性

- **代次计数器** `loadGen`：快速切换标签时旧回调因代次不匹配而失效，不串内容、不叠加——组件核心不持有 setTimeout，加载由用户 `lazy(done, tab)` 回调驱动。
- **visibility 暂停**：`document.hidden` 时新懒加载进入 `_pendingLoads` 不发起，可见后 `_resumeAllLoads` 恢复。
- **destroy()**：清空 `_loadGens`/`_pendingLoads`、移除 `visibilitychange`/`resize` 监听、清空 DOM。
- **零未定义引用**、零 console error（headless 实测）。
- resize 重算下划线位置。

## 八、API

```js
const t = new Tabs(containerEl, {
  tabs: [
    { id, label, closable, disabled, disabledHint, lazy(done, tab){...}, content }
  ]
});
t.on('change', (id, tab) => {});
t.getActive(); t.setActive(id);
t.addTab(cfg); t.closeTab(id);
t.disable(id); t.enable(id);
t.destroy();
```

## 九、可复用性

- 45 个 `--tabs-*` CSS 变量，覆盖颜色/圆角/间距/字号/时长/曲线，换主题只覆盖变量。
- 组件 `.tabs-*` 命名空间 + `Tabs` 构造函数，CSS/JS 可独立抽取，展示页代码用注释分区易删除。
- 抽到别的项目改不超过 3 处：① 根容器 CSS 变量值（主题色）；② `tabs` 数据源；③ `lazy` 异步函数。即可用。

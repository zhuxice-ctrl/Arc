ARIA Tablist · 可关闭可新增标签页

符合 WAI-ARIA 规范的生产级标签页组件，支持懒加载、可关闭、动态新增与键盘操作。

主题

用法：将容器元素与配置项传入 new Tabs(el, config)，即可获得具备完整 ARIA 语义、键盘操作与状态机的标签页组件。

import Tabs from './tabs.js'; const tabs = new Tabs(document.getElementById('my-tabs'), { tabs: [ { id: 'overview', label: '概览', content: '<p>已加载内容</p>' }, { id: 'members', label: '成员', lazy: loadMembersFn, closable: true }, ], }); tabs.on('change', (id) => console.log('切换到:', id)); tabs.on('close', (id) => console.log('关闭:', id)); tabs.on('add', (id) => console.log('新增:', id));

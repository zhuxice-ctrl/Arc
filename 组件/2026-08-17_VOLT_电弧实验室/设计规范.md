## 色彩系统

| 角色 | 色值 | 用途 |
|---|---|---|
| 底色 · 炭黑 | `#0E0E10` / `#0A0A0D` / `#0A0A0C` | 页面与展区底 |
| 深色分层 | `#15151A` / `#1E1E24` | 面板、边框分层 |
| 主强调 · 电弧黄 | `#FFE93C` | 电弧、火花、频谱、光标内点 |
| 电弧黄暗阶 | `#BBAE28` | 描边、暗部 |

无蓝紫渐变；辉光仅靠电弧黄/铜橙的透明度衰减叠加。

## 字体

等宽字体栈：`"SF Mono","Menlo","Consolas","PingFang SC","Microsoft YaHei"` —— 仪器读数、参数面板、展区标题，统一实验室仪器感。

## 展区（14 件可交互特效装置）

1. 高压电弧：电极间随机分形电弧，强度/分支/速度可调
2. 噪波流场：Perlin 噪波驱动粒子流体轨迹
3. 文字解构：文字拆成数千粒子，光标排斥散开
4. 磁力网格：点阵受光标磁力（反平方衰减）形变
5. 频谱可视化：柱状 / 波形 / 圆环三样式伪频谱
6. 光标拖尾：等离子辉光拖尾，速度越快越长
7. 流体粒子：Metaball 液态金属融合
8. CRT 扫描线：扫描线 + RGB 错位 + 故障条 + 暗角
9. 神光散射：辐射光束呼吸旋转 + 视差跟随
10. 视差星层：多层星点纵深 + 光标视差
11. 模拟电压表：复古指针表，机械抖动 + 阻尼
12. 等离子球：玻璃球内电弧游走，光标吸引额外放电
13. 火花矩阵：节点网格随机跳跃击穿的电火花链
14. 磁力示波器：多道电磁波形叠加 + 扫描点

## 自定义光标

白色粗环 + 电弧黄内点 + 多层发光，开页即居中显示，z-index 最高；悬停可交互元素形态变化，点击涟漪扩散。

## 技术实现与健壮性

纯 vanilla HTML/CSS/JS 单文件，零外部依赖（无 React / Babel / CDN）。`visibilitychange` 自动暂停/恢复全部动画循环，`beforeunload` 统一清理；重建前先 `cancelAnimationFrame` / `clearTimeout`；高频鼠标事件直接改 transform；`prefers-reduced-motion` 降级为静态；零未定义引用。

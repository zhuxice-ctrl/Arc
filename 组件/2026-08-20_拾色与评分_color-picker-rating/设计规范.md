# 设计规范 · 拾色与评分（文创手账定制商店 V3）

## 主题与场景
- **场景**：山屿系列硬壳手账定制商店。用户先用拾色器为手账封面选色，收货后用星级评分提交评价。
- **设计观点**：两个输入组件共享同一文具台氛围——色彩本身即内容，UI 外壳克制中性，组件是绝对主角。

## 色彩系统（取自源码 :root，可经 CSS 变量换皮）

| 用途 | 变量 | 色值 |
|---|---|---|
| 米纸底 | --paper | #F5EFE3 |
| 纸底浅 | --paper-soft | #F9F4E8 |
| 纸线/分隔 | --paper-line | #E0D5BC |
| 墨色正文 | --ink | #2B241E |
| 墨色次级 | --ink-soft | #5C5147 |
| 墨色弱化 | --ink-mute | #8A7F72 |
| 柿橙主色 | --persimmon | #C4552D |
| 柿橙深 | --persimmon-deep | #A4441F |
| 苔绿 success | --moss | #5A7A3E |
| 朱砂 error | --cinnabar | #B8382F |

组件层各自映射：拾色器 `--cp-*`（accent→柿橙、error→朱砂）、评分 `--rt-*`（star-active→柿橙、success→苔绿、error→朱砂）。**禁蓝紫渐变**，主色为柿橙，互补用苔绿。

## 字体
- 正文：`PingFang SC, system-ui, sans-serif`
- 数字读数（HEX / RGB / 色值 / SKU）：`"SF Mono","JetBrains Mono",Consolas,monospace`
- 中文为主、极少英文。

## 圆角与阴影
- `--radius-s` 4px / `--radius-m` 8px / `--radius-l` 12px
- `--shadow-s/m/l` 三级墨色柔阴影，无发光。

## 动效系统
| 语义 | 时长 | 曲线 |
|---|---|---|
| 轻量切换（hover/focus/色面过渡） | 120–200ms | --ease-standard `cubic-bezier(0.4,0,0.2,1)` |
| 落定反馈（星选定/色板 chip/拖拽释放） | 250ms | --ease-spring `cubic-bezier(0.34,1.56,0.64,1)` |
| 提交流（loading→success） | 300ms | --ease-standard |

`prefers-reduced-motion: reduce` 下全部降级为 0.01ms。

## 健壮性
- RAF / 定时器随 `visibilitychange` 暂停；组件提供 `destroy()` 取消。
- 高频指针事件走 `requestAnimationFrame` 直接操作 DOM。
- 零外部依赖（无 React / Babel / CDN），纯 vanilla 单文件。

## 命名空间与可抽取
- 拾色器 `.cp-*`、评分 `.rt-*`，各自 CSS 变量主题，互不耦合，可整块复制。
- 改 ≤3 处 CSS 变量（accent / radius / duration）即可换主题。

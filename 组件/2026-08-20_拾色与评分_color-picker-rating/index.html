用法文档

拾色器 ColorPicker

HTML 结构：将 .cp-root 整块复制到任意页面，保持类名与层级不变。

初始化：

const picker = new ColorPicker({
  el: '#colorPicker',
  initial: '#C4552D',
  alpha: true,
  onChange: (rgba, hex) => { /* ... */ }
});

CSS 变量主题：

变量说明默认
--cp-accent主色（焦点环等）#C4552D
--cp-radius圆角8px
--cp-duration过渡时长200ms
--cp-bg输入框背景#F9F4E8
--cp-panel面板背景#fff
--cp-error错误态颜色#B8382F

键盘操作：

按键作用
← →色相条 / SV 面板：微调色相或饱和度
↑ ↓SV 面板：微调明度
Shift + 方向键大步长（×10）调整
Tab在各可操作元素间切换
Enter确认输入框值

星级评分 StarRating

HTML 结构：将 .rt-root 整块复制，类名前缀 rt-* 独立命名空间。

初始化：

const rating = new StarRating({
  el: '#ratingNormal',
  max: 5,
  step: 0.5,
  value: 0,
  onChange: (val) => { /* ... */ },
  onSubmit: (val, text) => { /* 返回 Promise 触发 loading */ }
});

CSS 变量主题：

变量说明默认
--rt-star-color星星底色#B8AE9F
--rt-star-active激活色#C4552D
--rt-radius圆角8px
--rt-duration过渡时长250ms
--rt-error错误态颜色#B8382F
--rt-success成功态颜色#5A7A3E

状态机（共 6 种）：rest / hover / focus / active / disabled / error / loading / success

键盘操作：

按键作用
← →递减 / 递增 0.5 星
↑ ↓同 ← →
Home设为 0 星
End设为满星
Enter提交评价
0-5 数字键快速设为对应星级

抽取使用

两组件均为自包含：CSS 类名分别以 .cp-* 和 .rt-* 为前缀，互不冲突。JS 以构造函数暴露，不污染全局原型。复制对应 CSS 块 + JS 构造函数 + HTML 结构即可在其他项目中使用，修改 3 处以内 CSS 变量即可换主题。

无障碍与健壮性

支持 prefers-reduced-motion 降级；requestAnimationFrame 随页面可见性暂停、组件卸载时取消；高频指针事件直接操作 DOM 不触发重排；焦点环可见；ARIA 属性完整（role=slider/radiogroup、aria-valuenow、aria-valuetext 等）。

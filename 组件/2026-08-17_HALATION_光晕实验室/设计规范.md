# 设计规范 · HALATION 光晕实验室

方向：V3 UX 交互设计 ｜ 主题：胶片光晕/镜头炫光特效装置 ｜ 日期：2026-08-17

## 色彩系统

炭黑底 + 暖琥珀 + 玫瑰光晕橙红 + 银白高光，模拟胶片卤化银的高光溢出与暖调漏光。

| 角色 | 色值 | 用途 |
|---|---|---|
| 炭黑底 | #070706 / #0a0806 / #0b0a08 | 主背景层次 |
| 暖暗棕 | #1a120a / #1a1814 / #25211a / #2e2a22 | 面板、胶片导轨 |
| 焦褐 | #3a2a1a / #c94a2e | 灼烧边缘、火星 |
| 琥珀橙 | #FFB347 / #D98832 | 主光晕、光源、强调 |
| 玫瑰光晕 | #FF6B4A | bloom 高光溢出、内点 |
| 银白 | #E8E4DE / #8b857b | 高光、文字、银盐颗粒 |

## 字体

通过 CSS 变量定义：`--body`（正文）、`--display`（展示标题）、`--mono`（展区编号/参数）。

## 圆角

极小：1–2px（胶片齿孔/精密仪器质感），50%（光圈球/光源）。

## 展区（13 个可亲手操作的特效装置）

1. Halation Bloom — 可拖动光源 + 五层同心光晕，实时调强度/扩散
2. Anamorphic Flare — 蓝/琥珀横向拉丝光斑跟随指针，点击触发多条
3. Emulsion Grain — 颗粒大小/密度/色彩噪点三路可调
4. Acetate Burn — 从中心烧穿的不规则灼烧转场 + 火星粒子
5. Gate Weave — 画面微随机偏移 + 齿孔滚动 + 色边抖动
6. Chromatic Edge — RGB 通道随指针速度拉伸分离
7. Light Leak — 指针推动的暖调漏光 + 斜射光束
8. Dust + Scratches — 漂浮尘粒 + 点击添加发丝划痕
9. Shutter Flicker — 上下快门叶片开合 + 白闪
10. Vignette — 滚轮调节镜头暗角，内置暖光场景
11. Bokeh Orbs — 24 颗光圈球，点击拖拽施力（吸引/排斥）
12. Spectrum — 32 条棱镜频谱条，模拟音频响应
13. Magnetic Type — 单个字母受光标磁力场吸引形变

## 动效系统

自定义光标（白环 + 琥珀内点 + 玫瑰光晕，悬停放大变色，点击涟漪）；左侧齿孔胶片导轨作签名元素，帧推进光点亮起。所有特效基于 RAF 积分器/弹簧/磁性反平方引力/阻尼等物理模型；RAF 随 `visibilitychange` 暂停，卸载取消；高频鼠标事件直操作 DOM transform；支持 `prefers-reduced-motion`。

## 技术栈

纯 vanilla HTML/CSS/JS 单文件，零 React/Babel/CDN 依赖。

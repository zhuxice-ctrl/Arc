# 设计规范 — 底部弹层 Bottom Sheet（V3 实用 UI 组件）

> 2026-08-19 · Art 设计实验室 V3 · 覆盖层类 · PASS

## 一、组件定位

生产级移动端底部弹层（Bottom Sheet）。解决真实界面问题：移动端列表选择 / 筛选 / 详情展开等「从底部滑出、可中途停靠、可拖拽关闭」的高频交互。不是物理玩具，是可 copy-paste 到真实项目复用的 UI 积木。

## 二、配色系统（暖咖啡工坊，无蓝紫渐变）

| 角色 | 浅色主题 | 深色主题 | 用途 |
|---|---|---|---|
| 背景 / sheet-bg | `#F5EFE6` 米白 | `#2B2118` 炭棕 | 弹层与展示页底色 |
| 主色 / sheet-primary | `#6F4E37` 咖啡棕 | `#B8A58D` 暖灰 | 标题、强调 |
| 强调 / sheet-accent | `#C96F4A` 陶土橙 | `#D4845F` | 选中态、handle 激活 |
| 文字 / sheet-text | `#3D2B1F` 深咖 | `#EDE4D6` | 正文 |
| 弱文字 / sheet-text-muted | `#8B7355` | `#8B7355` | 距离、营业时间 |
| 分割 / sheet-divider | `#EDE4D6` | `#3a2e22` | 列表分隔 |
| 危险（休息中） | `#B85C5C` | `#B85C5C` | 营业状态红 |
| 纯白面 | `#FFFDF8` | — | 卡片高亮 |

配色逻辑：暖米白底 + 咖啡棕主色 + 陶土橙强调，对应演示场景「山丘咖啡」的品牌质感；颜色承担层级/状态/语义（营业中绿点 vs 休息中红字、选中项陶土橙），不依赖颜色单独建立层级（同时有勾选符号与底色高亮）。

## 三、字体

- 正文：`-apple-system, BlinkMacSystemFont, "PingFang SC", "Microsoft YaHei", "Helvetica Neue", Arial, sans-serif`（系统中文优先）
- 数字/代码：`"SF Mono", Menlo, Consolas, monospace`（距离、配置参数）

## 四、状态机（11 态）

`closed → opening → peek(rest) → dragging(grabbing) → settling → full(expanded) → dismissing → closed`
外加：`loading`（门店异步加载占位）、`error`（加载失败重试）、`empty`（无门店空状态）、`disabled`（触发按钮禁用）。

每个状态有对应视觉：dragging 时 handle 收紧变陶土橙且去掉 transition 跟手；settling 时弹簧曲线吸附；dismissing 时向下滑出并淡出遮罩。

## 五、动效系统（手感服务语义）

- **拖拽跟手**：`pointermove` 直接写 `transform: translateY()`，不走 transition，每一帧与指针直接相关。
- **弹簧吸附**：松手后 `transition: transform var(--sheet-spring-duration, 350ms) cubic-bezier(0.34, 1.3, 0.64, 1)`，带轻微过冲（阻尼弹簧）。
- **速度感知 flick**：记录最近 100ms 内指针速度，速度 > `flickVelocity`（默认 0.5px/ms）按方向直接吸附/关闭；慢速按位置阈值（拖过相邻吸附点中点）吸附。
- **遮罩**：`opacity` 200ms 线性淡入淡出。
- **prefers-reduced-motion**：弹簧吸附降级为 `transform 150ms linear`，拖拽仍保留（必要反馈）。

五层体验结构映射：预接触（handle hover/focus 陶土橙预告）→ 接触（pointerdown 咬合、handle 收紧）→ 持续（拖拽逐帧跟手）→ 阈值（越过中点 / 速度达标质变）→ 释放衰减（弹簧过冲回弹收尾）。

## 六、可访问性

- `role="dialog"` + `aria-modal="true"` + `aria-label`
- 打开时焦点进入弹层、关闭后归还触发按钮；Tab 在弹层内循环（焦点管理）
- Esc 关闭；列表项 ↑↓ 导航、Enter/Space 选中
- 焦点环可见（`outline` + `:focus-visible`）
- 背景滚动锁（`body.style.overflow`）
- 触屏可用（Pointer Events 统一 mouse/touch + `setPointerCapture`）

## 七、可复用性

- 17 个 CSS 自定义属性（`--sheet-bg/--sheet-radius/--sheet-handle-color/--sheet-backdrop/--sheet-spring-duration/--sheet-spring-easing/--sheet-max-width/--sheet-primary/--sheet-accent/--sheet-text/--sheet-text-muted/--sheet-divider/--sheet-border-color/--sheet-shadow/--sheet-item-hover/--sheet-ripple/--sheet-handle-size`）
- JS 配置项：`snapPoints`、`initialSnap`、`dismissThreshold`、`flickVelocity`、`dismissible`、`onSnapChange` 回调
- 代码边界：CSS 与 JS 均以 `/* === BottomSheet 组件 开始 === */` … `/* === BottomSheet 组件 结束 === */` 注释区块分隔，整块复制即可
- 集成成本：复制 CSS/JS 区块 → 创建容器 → `new BottomSheet(el, { snapPoints:[...] })`，改动不超过 3 处

## 八、健壮性红线

- 零未定义引用、零运行时崩溃（Browser QA：pageErrors / consoleErrors / failedRequests 全空）
- RAF 随关闭 `cancelAnimationFrame`；`visibilitychange` 预留；快速连续操作不叠加定时器
- Pointer Events 高频事件直接操作 DOM（transform），不触发重渲染

## 九、展示页（配角）

桌面浏览器内一个 390×760 手机比例容器，承载「山丘咖啡」点单演示（5 个饮品分类 + 商品列表 + 吸底栏「选择取货门店」按钮）；右侧配置面板可切换吸附点预设（两段/三段）、浅色/深色主题、「禁止拖拽关闭」「禁用按钮」开关，以及触发空/加载/错误三态演示——证明可配置与可换肤。展示页克制，组件是主角。

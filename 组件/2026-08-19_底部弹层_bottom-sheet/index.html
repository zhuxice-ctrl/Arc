用法文档

快速开始

从本文件中复制 /* === BottomSheet 组件 开始 === */ 到 /* === BottomSheet 组件 结束 === */ 之间的 CSS 和 JS 到你的项目中，然后创建实例：

const sheet = new BottomSheet({
  content: document.getElementById('myContent'),
  title: '选择门店',
  subtitle: '附近 8 家门店',
  snapPoints: [0.3, 0.6, 0.9],
  initialSnap: 1,
  onSnapChange: (index) => console.log('吸附到第', index, '段')
});

// 打开
sheet.open();
// 关闭
sheet.close();
// 销毁
sheet.destroy();

配置项

snapPoints
吸附点数组（0-1 比例值，相对视口高度）
initialSnap
初始打开时的吸附点索引
dismissThreshold
下滑关闭阈值（默认 0.15）
flickVelocity
快速滑动速度阈值 px/ms（默认 0.5）
dismissible
是否允许拖拽/点击遮罩关闭（默认 true）
onSnapChange
吸附点变化回调
onDismiss
关闭回调
onOpen
打开回调

状态机

组件完整状态：closed → opening → peek（rest）→ dragging → settling → full → dismissing → closed。 外加 disabled（触发按钮禁用）、loading（内容加载中）、error（加载失败）、empty（空数据）态。

系统等宽 / 衬线混排，刻度盘与仪表读数用等宽体。

## 动效系统（15+）

自定义光标（内环弹簧缓动 / 光晕慢跟 / 三态切换 / 点击涟漪）、表盘指针震颤、阀门惯性旋转、悬链线绳索变形、蒸汽粒子上浮、声浪均衡条、活塞弹簧回弹、压力计联动、拉杆过冲晃荡、舱门 3D 翻转、火焰随机摇曳、热浪 shimmer、环境金尘飘浮、铆钉金属高光、刻度盘红区警示。周期各不相同。

## 自定义光标

内环弹簧缓动跟随、光晕慢跟、三态切换（默认 / 悬停 / 抓取），点击涟漪，开页居中显示，z-index 最高。

## 健壮性

纯 vanilla HTML/CSS/JS 单文件，无 React / 无 Babel / 无外部 CDN。RAF / 定时器走 safeRaf / safeTimeout，visibilitychange 自动暂停、beforeunload 统一取消；拖拽重建前清理旧速度状态；mousemove 直操 DOM transform；prefers-reduced-motion 完整降级；零未定义引用。

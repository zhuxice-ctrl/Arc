## 色彩系统

| 角色 | 色值 | 用途 |
|------|------|------|
| 石墨黑（底） | `#141517` | 全页背景 |
| 铬银（主前景） | `#C9CCD1` | 主文字、金属高光、光标环 |
| 亮白 | `#FFFFFF` | 标题、最强高光 |
| 灰岩中性 | `#6B6E73` / `#A0A3A8` / `#B5A898` | 次级文字、面板边框 |
| 珍珠虹彩 | 局部 conic-gradient 旋转 + 混合模式 | 虹彩薄膜干涉展区 |
| 铜色（强调） | `#B0763C` / `#C89154` / `#E0AD6E` | 铜色点缀、参数滑块强调 |
| 暖砂 / 象牙 | `#E8E4DC` / `#E8D9C0` / `#C9BFAE` | 面板表面、分隔 |

无蓝紫渐变；虹彩由 conic-gradient 与混合模式生成，非蓝紫渐变贴图。

## 动效系统

- 自定义光标：三环白环 + 彩色内点 + 多层发光 + 悬停形变 + 点击涟漪，开页即居中显示
- 共享 RAF 管理器，`visibilitychange` 自动暂停 / 恢复
- 各展区独立 `IntersectionObserver`，不在视口内不跑动画
- 滑块参数实时可调（液滴数、张力、引力、弹性、阻尼、粒子数、噪波尺度等）
- 动效周期各不相同；高频鼠标事件直接操作 DOM / Canvas，不触发重渲染

## 健壮性

纯 vanilla 单文件（零 React / Babel / CDN 依赖）；支持 `prefers-reduced-motion`（降级为静态展示）；零未定义引用。

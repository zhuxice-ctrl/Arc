## 组件规范

每个展区是独立可上手把玩的组件级特效装置：

1. **繁花生成器**：点击生成参数化花朵，每朵独一无二（花瓣数 / 半径 / 色相随机）。
2. **花瓣粒子爆发**：拖拽喷射花瓣粒子，重力 / 漂浮双模式切换。
3. **万花筒绽放**：镜像对称花瓣，鼠标控制大小与转速。
4. **花丝光束**：弹性花丝被鼠标吸引弯曲（弹簧物理），末端发光。
5. **花阵形变场**（全宽旗舰）：网格化花朵受磁力场形变，弹簧物理回归。
6. **呼吸花环**：双环花朵呼吸律动，鼠标控制节奏与振幅，底部频谱条。

## 动效系统

12+ 组件级特效，全部基于物理模型（弹簧 Hooke / 惯性 / 磁性 / 阻尼 / RAF 积分器）或花朵语义：

1. 自定义光标（白环 + 珊瑚粉内点 + 拖尾轨迹，开屏居中，hover 三态，点击涟漪）
2. 繁花参数化生成动画
3. 花瓣粒子爆发（重力 / 漂浮）
4. 万花筒镜像对称绽放
5. 弹性花丝光束（弹簧物理跟随鼠标）
6. 花阵磁力形变（弹簧回归）
7. 呼吸花环律动
8. 底部频谱条
9. 滚动渐入展区
10. 展区切换过渡
11. 粒子拖尾
12. 悬停光晕

自定义光标开屏即显示屏幕中央，高对比，z-index 最高；RAF 统一动画循环管理器，`visibilitychange` 自动暂停、卸载清理；高频鼠标事件直控 DOM/Canvas 不触发重渲染；完整 `prefers-reduced-motion` 降级。

## 页面结构

单页实验室，6 个展区纵向排列，全宽旗舰展区居中放大。顶部品牌标题 + 展区导航。

## 技术栈

纯 vanilla HTML/CSS/JS 单文件，零 React / 零 Babel / 零外部 CDN 依赖。Canvas + DOM 混合渲染。

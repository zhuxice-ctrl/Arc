# 老式电报局 · 设计规范

## 色彩系统

| 角色 | 色值 | 用途 |
|---|---|---|
| 主色·深青灰 | #1A3A3A | 主背景、装置底盘 |
| 背景深·暗木褐 | #1A1208 | 页面底色、暗木纹理 |
| 更深 | #2a1a10 | 渐变端 |
| 黄铜金 | #B8860B | 金属装置主体、边框 |
| 亮金 | #D4A828 / #E8D06A | 高光、刻度 |
| 氧化铜绿 | #5E8B7E | 次金属、点缀 |
| 深铜绿 | #3D5E55 | 次金属深色端 |
| 朱砂红 | #C0392B | 强调红、火花、电键指示 |
| 电火花白 | #FFF9E6 | 火花、灯泡、高亮 |
| 羊皮纸米 | #E8DCC8 | 纸带、标签 |
| 暖灰 | #6B5D4F | 次要文字、木质 |

配色策略：暗木褐与深青灰托起黄铜金的复古机械质感，朱砂红与电火花白作为电火花与指示灯的高对比强调，营造老式电报局黄铜机关与复古电器的氛围。禁止蓝紫渐变。

## 字体

- 衬线/复古：'Noto Serif SC', serif（展区标题、装置铭牌）
- 正文：'Noto Sans SC', sans-serif

## 组件规范

- 自定义光标：白色粗环 + 朱砂红内点 + 多层发光，z-index 最高，悬停交互元素三态切换（放大/变色），点击涟漪
- 莫尔斯电键台：黄铜电键按压/释放，触发火花粒子 + 声波纹 + 灯泡亮灭 + 按压回弹
- 拨盘式频道选择器：拖拽旋转拨盘，8 频道均匀分布，到位"咔嗒"振动定位 + 指示灯
- 拉绳灯开关：拖拽下拉拉绳点亮灯泡（光线扩散 + 灯泡脉冲），松手弹簧回弹 + 阻尼
- 波段调谐器：40 档微卡顿旋转 + 指针联动 + AM 调制波形实时可视化
- 纸带发报机：拖拽滑块发送莫尔斯码（近=点/远=划），纸带滚动打出点划，松手磁性吸附归位

## 动效系统（12+）

1. 自定义光标（三态切换 + 点击涟漪）
2. 电火花粒子迸射（Canvas）
3. 声波纹扩散
4. 光线扩散
5. 旋转阻尼（拨盘/旋钮拖拽）
6. 弹簧回弹（Hooke 定律，拉绳松手）
7. 档位咔嗒振动定位
8. 磁性吸附归位（滑块）
9. 波形可视化（AM 调制）
10. 纸带滚动打出莫尔斯码
11. 灯泡脉冲发光
12. 光泽扫过金属

物理模型：弹簧 Hooke 定律（拉绳回弹）、阻尼摩擦（拨盘/旋钮卡顿）、磁性反平方吸附（滑块归位）、惯性动量（旋转 RAF 积分器）。RAF 随 visibilitychange 暂停、卸载取消；快速操作不叠加定时器；高频鼠标事件直接操作 DOM transform；支持 prefers-reduced-motion。

## 展区结构（5 个拟物化微交互装置）

1. ST.01 莫尔斯电键——按压发报 + 火花 + 声波 + 灯泡
2. ST.02 频道拨盘——拖拽旋转 8 频道 + 咔嗒定位
3. ST.03 拉绳灯开关——下拉点灯 + 光线扩散 + 弹簧回弹
4. ST.04 波段调谐器——40 档旋钮 + 指针 + 波形可视化
5. ST.05 纸带发报机——拖拽滑块发莫尔斯码 + 纸带滚动 + 磁性归位

每个展区用鼠标光标上手操作（悬停/点击/拖拽）才有意义，交互反馈细腻、有物理质感、有场景叙事。

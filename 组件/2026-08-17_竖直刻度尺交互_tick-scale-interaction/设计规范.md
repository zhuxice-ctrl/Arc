# 竖直刻度尺悬停注释交互 设计规范

> 日期：2026-08-17 · 方向：UX 交互组件 · 主题：刻度尺光标驱动的向右突出波形 + 注释卡片

## 圆角规范

- 刻度线：`1px`
- 卡片标签：`8px`
- 注释卡片：`20px`
- 列表圆点：`50%`

## 核心交互

### 刻度尺结构
- 60 条刻度线，左对齐于同一基准线，统一长度 52px、统一灰色 `#555`
- 每 6 条一条主刻度（加粗），其余为普通刻度
- 刻度容器宽度 90px，交互轨道宽度 160px（含左右缓冲带）

### 向右突出波形
- 光标经过刻度区域时，光标所在刻度**向右侧延伸最长**（最大 +28px）
- 邻近刻度按高斯衰减递减延伸，影响半径 8 条刻度
- 延伸同时配合灰→白变亮，中心最亮（RGB 线性插值）
- 离开交互区域后所有刻度恢复初始状态

### 注释卡片
- 60 条刻度每条都关联一条设计决策注释
- 内容围绕一个内容创作平台的设计走查：入口/导航/配色 → 文章列表/详情/排版 → 评论/个人主页 → 统计/通知 → 登录注册/编辑器/媒体库
- 卡片位置用 `requestAnimationFrame` + lerp 插值（系数 0.18）弹性跟随光标 Y 坐标
- 卡片上下边界 clamp，不超出视口
- 内容切换时轻微弹动（scale 0.96→1，cubic-bezier 弹性曲线）
- 离开轨道时卡片淡出消失

### 自定义光标
- 粉色箭头 SVG（20×24px），`#E8A0BF` 填充 + `#D488A8` 描边
- 光标位置用 lerp（系数 0.30）缓动跟随鼠标，有微滞后黏性手感
- 开页即在屏幕中央显示（pointermove 时添加 visible 类）
- 触屏设备隐藏自定义光标，使用系统默认

## 动效系统

| 动效 | 实现 | 参数 |
|------|------|------|
| 刻度波形 | rAF 循环 + 高斯衰减 | 影响半径 8，最大延伸 28px |
| 卡片跟随 | rAF + lerp 插值 | 系数 0.18 |
| 光标缓动 | rAF + lerp 插值 | 系数 0.30 |
| 卡片淡入淡出 | CSS transition | opacity 0.25s ease |
| 卡片弹动 | CSS transform | scale 0.96→1, cubic-bezier(0.34, 1.56, 0.64, 1) |
| 卡片位置 | CSS transition + JS rAF | top 实时更新 |

## 健壮性

- **快速滑动不丢交互**：全局 `pointermove` 监听 + 连续坐标直接计算刻度索引，不依赖逐条元素的 mouseenter
- **交互轨道缓冲带**：左右各外扩 30/80px，边缘抖动不断开
- **prefers-reduced-motion**：检测后禁用所有 lerp 缓动，光标和卡片直接同步
- **触屏支持**：touchstart/touchmove/touchend 完整事件链，preventDefault 阻止滚动
- **RAF 持续运行**：单一 rAF 循环驱动所有动画，不叠加定时器
- **resize 响应**：窗口大小变化时重新计算刻度位置和卡片 clamp

## 技术栈

- 纯 vanilla HTML/CSS/JS，无任何外部依赖
- 动效：requestAnimationFrame + lerp 线性插值
- 交互：全局 pointermove + 触屏 touch 事件

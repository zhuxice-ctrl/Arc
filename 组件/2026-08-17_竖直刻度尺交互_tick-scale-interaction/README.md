# 竖直刻度尺悬停注释交互

> 日期：2026-08-17 · 方向：UX 交互组件 · 主题：刻度尺光标驱动的向右突出波形 + 注释卡片

## 简介

复刻自录屏的竖直刻度尺交互组件。左侧 60 条等距刻度线左对齐排列，鼠标沿刻度上下移动时，光标所在刻度**向右延伸最长**，邻近刻度按高斯衰减递减，形成以光标为中心向两侧衰减的「向右凸起」波形——刻度自己凸出来指示位置。同时右侧弹出深灰圆角注释卡片，60 条刻度每条都关联一条设计决策内容，卡片弹性跟随光标位置平滑移动。

## 配色方案

- 纯黑 `#000000` 背景 + 刻度灰 `#555` → 白色激活
- 深灰卡片 `#1c1c1e` + 20px 圆角 + 22px 大号正文
- 粉色箭头光标 `#E8A0BF`

## 交互亮点

- **向右突出波形**：刻度从左对齐基准线向右延伸，光标中心最长（+28px），高斯衰减至两侧
- **60 条注释全覆盖**：每条刻度都有对应的设计决策内容（内容创作平台走查）
- **快速滑动不丢交互**：全局 pointermove + 连续坐标计算，不依赖逐条 hover
- **弹性卡片跟随**：rAF + lerp 插值（系数 0.18），卡片平滑跟随光标 Y 坐标
- **自定义粉色箭头光标**：lerp 缓动（系数 0.30），微滞后黏性手感
- **内容切换弹动**：scale 0.96→1 弹性曲线
- **触屏支持** + **prefers-reduced-motion** 支持

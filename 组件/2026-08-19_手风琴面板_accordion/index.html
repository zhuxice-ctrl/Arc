手风琴 Accordion

生产级可复用折叠面板组件。纯 vanilla 实现，零依赖，支持键盘操作、 多状态机、spring 动画、CSS 变量主题化，可抽取到任意项目中使用。

基础用法

同一时间仅展开一项。键盘操作：↑/↓ 在标题间移动焦点， Home/End 跳至首尾，Enter/Space 切换展开。

状态一览

组件覆盖 10 种状态：rest、hover、focus、active、 disabled、expanded、collapsed、loading、error、empty。

REST · 默认
HOVER · 悬停
FOCUS · 焦点
ACTIVE · 按下
DISABLED · 禁用
EXPANDED · 展开
展开后的内容区域，使用真实高度测量的 spring 曲线动画过渡。
LOADING · 加载
正在加载内容…
ERROR · 错误
网络异常，无法获取内容。
EMPTY · 空态
暂无内容

可多选模式

设置 multiple: true 后，可同时展开多个面板。每项独立开合，互不影响。

异步加载与错误重试

通过 load 回调配置异步内容。首次展开时触发加载， 失败后可点击「重试」按钮重新请求。点击下方第一项试试。

用法

一、引入样式与脚本

将组件的 <style id="accordion-styles"> 与 <script id="accordion-script"> 两块代码复制到项目中。 两者均零依赖，不依赖任何 CDN 或框架。

<link rel="stylesheet" href="accordion.css">
<script src="accordion.js"></script>

二、快速使用

在 HTML 中准备一个容器元素，然后用 JS 初始化：

const acc = new Accordion('#my-accordion', {
  items: [
    {
      title: '什么是手风琴组件？',
      content: '手风琴是一组垂直堆叠的可折叠面板…'
    },
    { title: '第二项标题', content: '第二项内容' }
  ],
  multiple: false,     // 是否允许多个同时展开
  defaultExpanded: 0,  // 默认展开项的索引（或索引数组）
  duration: 320        // 动画时长（毫秒）
});

三、配置项

属性 类型 默认 说明
items Array [] 面板数据，每项包含 title、content、可选 icon（SVG 字符串）、meta（右侧元信息文字）、disabled、load（异步加载函数，返回 Promise）。
multiple Boolean false 是否允许同时展开多个面板。
defaultExpanded Number | Array -1 初始展开项索引。多选模式下可传入数组。
duration Number 320 展开收起动画时长（毫秒）。设为 0 则无动画。
variant String 'default' 视觉变体：'default'、'bordered'、'filled'。
headingLevel Number 3 标题的 ARIA heading level，用于页面结构层级。

四、方法

方法说明
expand(index) 展开指定索引的面板。单选模式下会关闭其余已展开项。
collapse(index) 收起指定索引的面板。
toggle(index) 切换指定索引面板的展开状态。
expandAll() 展开全部（仅多选模式有效）。
collapseAll() 收起全部。
setLoading(index, bool) 手动设置某一项的加载状态。
setError(index, bool, message) 手动设置某一项的错误状态与错误信息。
destroy() 销毁实例，解绑事件与清理定时器。

五、CSS 主题变量

在 :root 或任意父选择器上覆盖以下变量即可换肤：

变量用途
--acc-accent强调色（展开箭头、焦点环、图标）
--acc-surface面板表面底色
--acc-surface-hover悬停底色
--acc-text / --acc-text-muted主文字与次级文字色
--acc-border分隔线与边框色
--acc-error错误态颜色
--acc-radius / --acc-radius-lg小圆角与大圆角
--acc-duration动画时长
--acc-ease缓动曲线（默认 spring）

六、键盘操作

按键行为
Tab按顺序在标题按钮间移动焦点
↑ / ↓上一项 / 下一项标题（循环，跳过禁用项）
Home移至第一项
End移至最后一项
Enter / Space切换当前面板展开 / 收起

七、无障碍

组件遵循 WAI-ARIA Accordion Pattern， 正确设置 role="heading"、aria-expanded、 aria-controls、aria-disabled、 aria-busy 等属性，并支持 prefers-reduced-motion 媒体查询以适配动效敏感用户。

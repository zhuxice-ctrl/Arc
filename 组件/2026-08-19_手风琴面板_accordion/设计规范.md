# 设计规范 · 手风琴折叠面板 Accordion

> Art 设计实验室 · V3 交互组件 · 2026-08-19
> 定位：生产级可复用 UI 组件（导航类·折叠面板），目的是开发者 copy-paste 到任意项目即可用。

---

## 一、设计母题

**「技术说明书活页」** —— 一组垂直堆叠的可折叠面板，如同翻开说明书的一节：
标题行锚定不动作为索引，内容区以高度 spring 展开，标记符号旋转，内容逐行浮现。
视觉语言取自工程说明书与档案条目：细线框、条款编号、等宽标注、克制的朱砂红强调。
组件本身保持中性可换肤（24 个 CSS 变量），展示页仅作克制衬托。

设计观点：折叠面板的核心语义是「垂直空间折叠/展开」，所以体验重心放在
**高度动画的真实测量与 spring 回弹**、**键盘导航的官方模式**、**状态机的完整覆盖**，
而不是堆叠装饰特效。

## 二、色彩系统（墨·朱砂主题）

底色取宣纸米白，文字取墨色，强调色取朱砂红，错误色取赭石。
全程不使用蓝紫渐变。内置深色模式（`prefers-color-scheme: dark`）。

| 令牌 | 浅色值 | 深色值 | 用途 |
| --- | --- | --- | --- |

| `--acc-surface` | `#ffffff` | `#24201b` | 面板项表面 |
| `--acc-surface-hover` | `#f7f1e8` | `#2f2a23` | hover 表面 |
| `--acc-surface-active` | `#efe6d6` | `#3a332a` | 按下表面 |
| `--acc-border` | `#e2d8c7` | `#3d362c` | 边框（墨灰偏暖） |

## 三、字体系统

| 令牌 | 字族 | 用途 |
| --- | --- | --- |
| `--acc-font-ui` | `-apple-system, BlinkMacSystemFont, "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", "Source Han Sans SC", sans-serif` | 面板正文与标题按钮（无衬线） |
| `--acc-font-title` | `"Source Han Serif SC", "Noto Serif SC", "Songti SC", "SimSun", serif` | 展示页大标题（衬线，呼应说明书气质） |
| 代码 | `ui-monospace, SFMono-Regular, Menlo, monospace` | 用法文档代码块与等宽标注 |

字号克制，标题与正文通过字重、颜色、编号建立层级，不依赖大字号。

## 四、动效系统

| 项 | 值 | 说明 |
| --- | --- | --- |
| `--acc-duration` | `320ms` | 展开/收起动画时长（可设 0 关闭） |
| `--acc-ease` | `cubic-bezier(0.34, 1.56, 0.64, 1)` | spring 回弹曲线（back-out 轻微过冲） |

- **高度动画真实测量**：展开时读取 `scrollHeight` 作为目标高度，动画结束切回 `auto` 以适配内容动态变化；禁止 `display:none` 硬切。
- **快速操作不叠加**：每次 expand/collapse 先取消上一次的 rAF 与 timeout，避免连续点击产生抖动。
- **可见性暂停**：`visibilitychange` 页面隐藏时清掉所有 rAF 与定时器并直接落终态，回来后再无残留。
- **卸载清理**：`destroy()` 解绑事件、清除定时器、置 `_destroyed` 标志。
- **reduced-motion**：`prefers-reduced-motion: reduce` 时禁用全部过渡与 spinner，状态直接跳变。
- **标记旋转**：展开/收起时箭头（chevron）旋转 180°，与高度动画同步，强化空间方向语义。

## 五、状态机（10 态）

组件按真实使用覆盖以下状态，至少满足 5 态硬性要求：

| 状态 | 表现 |
| --- | --- |
| `rest` | 收起的默认面板，边框与表面静止 |
| `hover` | 表面变 `--acc-surface-hover`，箭头微移，光标 `pointer` |
| `focus` | `:focus-visible` 显示 `--acc-focus-ring` 外环（2px 偏移），键盘可见 |
| `active` | 按下表面变 `--acc-surface-active`，轻微下沉 |
| `disabled` | 文字 `--acc-text-disabled`、`aria-disabled`、`cursor: not-allowed`、键盘跳过、不响应点击 |
| `expanded` | `aria-expanded="true"`，内容区高度展开，箭头旋转 |
| `collapsed` | `aria-expanded="false"`，内容区高度收起 |
| `loading` | `aria-busy="true"`，内容区显示 spinner，禁用切换 |
| `error` | `aria-invalid="true"`，显示错误信息与重试按钮 |
| `empty` | 内容为空时显示空态提示 |

## 六、无障碍（WAI-ARIA Accordion 模式）

- 标题按钮容器 `role="heading"` + `aria-level`（默认 3）。
- 触发元素 `aria-expanded` / `aria-controls` / `aria-disabled`；内容区 `role="region"` + `aria-labelledby`。
- 键盘：`Tab` 进入 → `↑`/`↓` 在标题间循环移动焦点（跳过 disabled）→ `Home`/`End` 跳首尾 → `Enter`/`Space` 切换展开。
- 焦点环可见；触屏可点击。

---

## 七、可复用性

- **自包含**：单 HTML 文件，`<style id="accordion-styles">` 与 `<script id="accordion-script">` 两块可整块抽取，零依赖（无 React/Babel/CDN）。
- **主题化**：24 个 `--acc-*` CSS 变量，`:root` 或父选择器覆盖即换肤；内置深色模式。
- **配置化**：JS `new Accordion(el, options)`，配置项 `items / multiple / defaultExpanded / duration / variant / headingLevel`。
- **方法 API**：`expand / collapse / toggle / expandAll / collapseAll / setLoading / setError / destroy`。
- **集成成本**：复制 CSS+JS 两段、改不超过 3 处 CSS 变量即可接入任意项目。

# 设计规范 · 卷尺（拉出与回卷）

**类别**：Component Mock（V3 交互组件）　**日期**：2026-08-19

## 设计母题
光标驱动的拟物化钢卷尺，全场唯一主角。抓住尺爪向外拉：刻度带阻力流出、读数实时更新、阻力随长度递增；松手瞬间弹簧储能释放，尺带高速回卷、末端弹跳余震。侧面锁定开关拨下后松手不回卷，再拨「唰」地收回。一维线性物理：拉伸弹簧储能 → 高速回卷 → 末端衰减弹跳。

## 物理模型
弹簧-阻尼-惯性数值积分（非 linear/ease）。拉出阻力随长度递增；越过整十/整百毫米刻度速度阻尼「咔哒」微顿；松手回卷有真实惯性曲线，末端 2-3 次弹跳衰减。锁定开关切换双态释放行为。

## 五层反馈
1. Pre-contact：光标距尺爪 40px 内，尺爪微颤 + 尺口阴影加深
2. Contact：按下咬合，光标缩为握紧态、尺带绷紧高光
3. Continuous：每帧对应输入——刻度 Canvas 实时流动、读数实时更新、阻力递增、速度条纹
4. Threshold：越过整米/整十刻度吸附微顿 + 脉冲
5. Release/Decay：弹簧回卷 + 末端撞击弹跳衰减（bounceDecay 0.45，2-3 次归零）

## 字体逻辑
系统 sans-serif（中文为主），读数大号数字 + 单位「厘米 / 米」。

## 自定义光标
三态光标：默认 / 悬停放大 / 抓握缩小变黄；开页居中、高对比、层级最高；prefers-reduced-motion 降级系统光标。

## 技术栈
纯 vanilla 单文件（HTML+CSS+JS，无 React / 无 Babel / 无外部 CDN）。Canvas 绘制刻度流动。RAF 随可见性暂停、卸载取消；高频鼠标事件直接操作 DOM；零未定义引用。

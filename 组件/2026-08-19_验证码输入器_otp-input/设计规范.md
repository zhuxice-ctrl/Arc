# 设计规范 · OTP 验证码输入器

> 版本：V3 交互组件 ｜ 日期：2026-08-19 ｜ 类别：实用可复用 UI 组件（输入类）
> 本规范从 `index.html` 源码中提取真实数值，供复用与主题定制参考。

## 一、设计母题

**生产级 OTP 验证码输入器**——不是物理演示装置，而是开发者可直接 copy-paste 到登录 / 支付 / 二次验证页面的实用 UI 组件。

核心观点：验证码输入是真实产品里高频却常被低估的场景。把「分格分发 + 自动跳格 + 倒计时重发 + 完整状态机」做对做透，就是这件作品的全部价值。展示页刻意克制，组件是唯一主角。

### 色彩语义

- 每种颜色承担明确职责：青绿 `#1f8a70` = 主交互 / 聚焦；朱红 `#d64b3c` = 错误；苔绿 `#2e8b5a` = 成功；墨黑 `#2b2a26` = 文本层级。
- 描边三阶：`#d9d7ce`（默认）→ `#b8b5a8`（hover）→ `#1f8a70`（focus），用明度递进表达可接近性。

## 三、字体系统

- 字体栈：`-apple-system, BlinkMacSystemFont, "PingFang SC", "Microsoft YaHei", "Segoe UI", Roboto, sans-serif`（系统无衬线，零外部字体加载，符合实用组件定位）。
- 数字：`font-variant-numeric: tabular-nums` 等宽数字，避免跳格时位移抖动。
- 层级：页面标题 24px/700 → 数字 22px/600 → 状态文案 14px → 提示 13px。

## 四、动效系统（真实曲线与时长）

动效全部服务组件语义，无一处装饰特效。

| 动效 | 时长 | 曲线 | 语义 |
|---|---|---|---|
| 状态过渡 | 240ms | `ease` | 描边 / 背景 / 阴影 / 颜色 / 位移的利落切换 |
| 错误抖动 | 420ms | `cubic-bezier(.36,.07,.19,.97)` | 阻尼振荡（translateX -6→5→-4→3→-2→1→0），错误要有分量 |
| 加载旋转 | 700ms | `linear infinite` | spinner 循环，加载持续感 |
| 成功显现 | 跟随 240ms | `ease` | 对勾浮现，轻量确认 |

### 五层体验结构

1. **预接触**：hover 描边加深 `#b8b5a8`，focus 时描边变青绿 + 3px 光晕预告可输入。
2. **接触**：数字键按下，当前格描边咬合、自动跳到下一格。
3. **持续**：连续输入 6 位，每格即时填入，`is-filled` 保持描边态。
4. **阈值**：第 6 位填满瞬间自动触发校验，进入 verifying（格子整体变青绿 + spinner）。
5. **释放与衰减**：成功对勾浮现；错误则 420ms 阻尼抖动衰减归零并清空回到第一格。

### 减弱动效偏好

`prefers-reduced-motion: reduce` 时：所有 transition 关闭、错误抖动动画关闭、spinner 动画关闭（保留状态本身，仅去掉运动）。

## 五、空间与尺寸

- 单格 52×58px，格间距 10px，6 格总宽约 372px，适配主流表单宽度。
- 圆角统一 10px（输入格），展示卡片 14px，控制按钮 8px——内圆外方的层级递进。
- 组件内部纵向间距 16px，状态区最小高度 20px 防布局跳动。

## 六、状态机（7 态）

`empty` → `focusing` → `filled` → `verifying` → `error` / `success`，外加贯穿的 `disabled`。

| 状态 | 视觉 | 触发 |
|---|---|---|
| empty | 默认描边 `#d9d7ce` | 初始 / 清空 |
| focusing | 描边 `#1f8a70` + 光晕 | Tab / 点击聚焦 |
| filled | 全部有值保持 `is-filled` 描边 | 输入 / 粘贴 |
| verifying | 格子整体青绿 + spinner + 禁用输入 | 填满自动校验 |
| error | 描边/背景/文字朱红 + 420ms 抖动 | 校验失败 |
| success | 描边/背景/文字苔绿 + 对勾 | 校验通过 |
| disabled | 透明度 .55 + `not-allowed` 光标 | 外部禁用 |

边界处理：非数字字符过滤、退格回跳并清空上一格、粘贴整段自动分发、快速重复提交防抖（150ms 去抖 + verifyTimer 防重入）、错误恢复自动聚焦第一格。

## 七、可访问性

- 每格 `aria-label="第 N 位验证码"`，整体 `role="group"` `aria-label="验证码输入"`。
- 状态文案 `aria-live="polite"`，校验结果对读屏用户可感知。
- 仅第一格 `tabIndex=0`（roving tabindex），格间用方向键移动，符合复合控件焦点规范。
- 触屏 `inputMode="numeric"` 唤起数字键盘，`autocomplete="one-time-code"` 支持系统自动填充。
- 焦点环可见（描边 + 光晕），支持 Home / End / 方向键 / Enter / Tab 全键盘操作。

## 八、工程

- 纯 vanilla 单文件（HTML + CSS + JS），零外部依赖、零 CDN、零运行时崩溃、Console 无错误。
- 定时器（倒计时 / 校验 / 错误恢复）均随 `visibilitychange` 暂停与恢复，`destroy()` 统一清理。
- CSS / JS 有清晰组件边界注释，展示页样式与脚本标注「可删除，不影响组件」。
- 对外 API：`clear / setValue / getValue / setDisabled / destroy`；配置项：`length / correctCode / countdown / onComplete / onSuccess / onError`。

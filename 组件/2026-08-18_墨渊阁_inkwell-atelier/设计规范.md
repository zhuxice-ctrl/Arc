# 设计规范 · 墨渊阁（荧石作坊 UX 交互实验室）

> 方向：V3 UX 交互设计 · 日期：2026-08-18 · 主题：深夜荧石作坊——光标驱动的拟物化小组件动画

## 色彩系统

主色调为「墨黑 + 荧黄绿 + 苔藓绿」暗绿系，与同批朱砂红金系、深空蓝系彻底不雷同，无蓝紫渐变。

| 角色 | 色值 | 用途 |
|------|------|------|
| 墨黑 / 深墨绿（底） | `#0a0d0a` / `#0d0f0d` / `#1f261f` / `#1a2418` | 页面背景、深色面板 |
| 荧黄绿（主） | `#d4ff6e` / `#a8e03a` / `#77b817` | 主光效、标题、能量值 |
| 苔藓绿（辅） | `#8bc278` / `#5c9a4a` / `#38692d` | 次级强调、装置主体 |
| 荧石明绿（强调） | `#aaff66` / `#66cc33` / `#c8f070` | 高亮、激活态、粒子 |
| 中性（文字） | `#c8d8c0` / `#a8c080` / `#5a6858` | 正文、次要文字 |

## 字体

- 展示字体：`var(--font-display)` → `'Noto Serif SC', serif`
- 正文字体：`var(--font-body)` → `'Noto Sans SC', sans-serif`
- 数字 / 数据：`var(--font-mono)` → `'JetBrains Mono', monospace`

## 圆角

装置主体 `20-24px`、按钮 `4px`、细节 `2-3px`、有机形状 `45% 45% 50% 50%`

## 八件交互装置

| 编号 | 名称 | 交互方式 | 物理模型 |
|------|------|----------|----------|
| 01 | 荧石吊灯 | 拖拽拉珠 | 弹簧回弹 + 阻尼振动 |
| 02 | 苔藓指南针 | 光标悬停移动 | 反平方引力 + 阻尼旋转 |
| 03 | 荧石能量盘 | 拖拽旋转 | 角度映射 + 熔光流动 |
| 04 | 孢子风箱 | 点击按压 | 按压回弹 + 火花粒子 |
| 05 | 荧曙光暮 | 拖拽滑块 | 弹性吸附 + 场景过渡 |
| 06 | 苔藓涟漪 | 点击水面 | 涟漪扩散 + 溅射粒子 |
| 07 | 荧石留声机 | 点击播放 | 黑胶旋转 + 声波扩散 |
| 08 | 玉石平衡秤 | 拖放砝码 | 弹簧阻尼 + 力矩平衡 |

## 动效系统（12+ 组件级特效）

自定义光标（三环三层 + 悬停 / 点击态 + 涟漪）、背景上浮粒子、打字机、齿轮轨道旋转、核心脉冲发光、3D 卡片倾斜、光泽扫过、滚动渐入、数字实时计数、荧液流动、恒星闪烁、声波扩散、火花溅射、波纹扩散。

## 技术栈

纯 vanilla HTML/CSS/JS 单文件实现（无 React / 无 Babel / 无外部 CDN 依赖）。自定义光标开页即居中，z-index 最高；`visibilitychange` 自动暂停动画循环；支持 `prefers-reduced-motion` 降级。

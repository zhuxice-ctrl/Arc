# DATAMOSH 数据故障实验室 — 设计规范

> 日期：2026-08-17 · 方向：V3 UX 交互设计 · 主题：数字信号故障美学特效实验室

## 一、色彩系统

| 角色 | 色值 | 用途 |
|---|---|---|
| 背景 · 碳黑 | `#0A0A0C` | 页面主底色 |
| 深炭 | `#121216` / `#1A1A20` | 展区卡片底色 |
| 炭灰 | `#2A2A30` | 边框、分隔线 |
| 信号青 | `#00E5D4` | 主强调色、青色通道、频谱、光标内点 |
| 噪点白 | `#F2F2EE` | 正文文字、白色通道、噪点颗粒 |
| 纯白 | `#FFFFFF` | 光标粗环、高亮文字 |
| 故障橙 | `#FF6B1A` | 次强调色、橙色通道、故障高亮、爆裂粒子 |

整体为「碳黑底 × 信号青 × 故障橙」的故障美学冷暗调，青橙双色形成 RGB 通道分离的视觉张力；禁用蓝紫渐变。

## 二、字体

- 等宽：`var(--mono)`（终端 / 代码 / 故障打字机）
- 无衬线：`var(--sans)`（标题 / 正文）

## 三、展区结构（7 个可把玩特效装置）

1. **RGB Split Matrix** — 鼠标驱动的青/橙通道分离，3 种模式，可改文本与强度
2. **Pixel Sort Engine** — 真实 Canvas 像素排序（阈值/长度/角度/速率）+ 4 个预设 + 行位移故障
3. **CRT Monitor** — 扫描线 + 荧光效果 + 打字机终端 + 32 柱频谱 + 5 种滤镜模式
4. **Noise Flow Field** — 600 粒子噪波流场（漂移/漩涡/网格/爆炸）+ 鼠标反平方斥力
5. **Glitch Typewriter** — 字符落地前先随机乱码再稳定，已打字符偶发故障抖动
6. **Magnetic Buttons** — 反平方引力吸附 + 弹簧回弹 + 点击粒子爆裂（青/橙/白三色）
7. **Live Spectrum** — 64 频段频谱可视化 + 峰值标记 + 4 种信号模式

## 四、全局动效系统（14+ 组件级特效）

自定义光标（白环 + 橙点 + 发光 + 8 粒拖尾 + 点击涟漪 + 悬停放大）、CRT 扫描线全屏覆盖、SVG 噪点颗粒、暗角、滚动渐入、数字计数器（带故障闪烁）、Hero 标题 RGB 通道动画。

## 五、健壮性

- 纯 vanilla 单文件（零 React / 零 Babel / 零外部 CDN 依赖）
- 所有 RAF / 定时器走 `safe_raf` / `safe_timeout` 统一注册
- `visibilitychange` 自动暂停恢复、`beforeunload` 全部清理
- `prefers-reduced-motion` 降级
- 鼠标高频事件直接改 DOM，不触发重渲染

## 六、技术栈

纯 HTML/CSS/JS 单文件（`index.html`），无任何外部依赖；Canvas 2D 像素操作、SVG 滤镜、RAF 动画循环原生实现。

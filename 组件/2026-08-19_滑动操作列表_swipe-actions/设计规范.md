# 滑信 SwipeActions · 设计规范

> 实用可复用 UI 组件 · 操作类 · 滑动操作列表行
> 2026-08-19 · Art 设计实验室 V3

## 一、组件定位

「滑动操作列表行」——按住列表行向左拖，行体 1:1 跟手平移，右侧操作区按露出比例渐入；越过 40% 阈值松手自动吸合到全开，删除走「信笺抽走 + 5 秒撤销」流程。覆盖邮箱收件箱、待办清单、购物车、消息列表等真实场景。

## 二、色彩系统（宣纸信笺）

| 角色 | 色值 | 用途 |
|------|------|------|
| 宣纸底 | `#F7F4EE` | 页面/卡片底 |
| 纸白 | `#FFFCF6` | 行体表面 |
| 墨色 | `#232019` | 主文字 |
| 次墨 | `#6B6557` / `#9A9384` | 次级/辅助文字 |
| 青瓷绿 | `#4A7C6F` | 归档 · 主色（`--sw-primary`） |
| 青瓷深 | `#3A6659` | 归档按下态 |
| 柿红 | `#C0392B` | 删除 · 危险（`--sw-danger`） |
| 柿红深 | `#A02D21` | 删除按下态 |
| 琥珀 | `#C9973B` | 焦点环 / 提示（`--sw-focus-ring`） |
| 灰阶 | `#E0DBCF` / `#EFEBE1` / `#F1EDE2` | 分隔/悬停/活动底 |

无蓝紫渐变、无装饰粒子光晕。语义色（青瓷=归档/安全操作，柿红=删除/危险）贯穿全局。

## 三、字体

`"PingFang SC", "Microsoft YaHei", "Noto Sans SC", system-ui, sans-serif`，通过 `--sw-font-family` 暴露。中文为主，邮件内容真实可信（如「青桐山居 · 八月廿三入住确认」）。

## 四、动效系统

| 场景 | 时长 | 曲线 | 说明 |
|------|------|------|------|
| 拖拽期 | 0（无过渡） | — | transformX 直接跟手，不靠 RAF 重渲染 |
| 释放回弹/吸合 | 260ms | `cubic-bezier(0.34, 1.4, 0.64, 1)` | 弹簧 overshoot，咬合手感 |
| 行内 hover/active | 150ms / 120ms | `cubic-bezier(0.2,0.8,0.2,1)` | 轻量过渡 |
| 删除收起 | 300ms | ease | height 收起 + 透明度 |
| 撤销条滑入 | 240ms | `cubic-bezier(0.2,0.8,0.2,1)` | 顶部落下 |
| 焦点/淡入 | 180ms / 200ms | ease | |

`prefers-reduced-motion: reduce` 时全部降级为瞬时切换，功能不受影响。

## 五、状态机（11 态）

`rest` → `hover` → `focus` → `dragging` → `revealed`（全开）/ `is-threshold`（过阈值待咬合）→ 释放 `is-released` 回弹或吸合 → `is-deleting` → `undo-pending`（撤销条 5s 倒计时）→ `is-error`（删除失败可重试）→ `is-disabled`（锁定行不可操作）→ `empty`（清空空状态）。

## 六、交互手感（五层体验）

1. **预接触**：行 hover 微抬升，右侧隐约透出操作色提示
2. **接触**：pointerdown 即锁定，行体失弹性进入跟手
3. **持续**：行体 transformX 1:1 跟手指，操作按钮按露出比例渐入
4. **阈值**：越过 40% 行宽，删除区底色由灰转柿红，行体阻力变化提示「即将咬合」
5. **释放**：未过阈值弹簧回弹归零；过阈值吸合全开并锁定，删除时行像信笺被抽走

## 七、可访问性

- 容器 `role="listbox"` + `aria-label`，行 `role="option"` + `tabindex` + `aria-selected`
- 键盘：`Tab` 行间穿行 / `↑↓` 移动 / `ArrowLeft` 展开操作 / `ArrowRight` 收起 / `Delete` 删除 / `Enter` 执行 / `Esc` 收起
- 焦点环 `--sw-focus-ring`（琥珀）可见
- 撤销条 `role="status" aria-live="polite"`，屏幕阅读器可感知
- `touch-action: pan-y`，不阻塞纵向滚动

## 八、可复用性

- 44 个 `--sw-*` CSS 变量（底色/文字/语义色/间距/动效/阴影/字体）
- 工厂函数 `createSwipeList(el, options){ …, destroy() }`，JS/CSS 可独立抽取
- 抽走 `sw` 段代码改 ≤3 处即可在新页面运行
- 用法文档随页面内置

快速开始

将 .sw-* 相关的 CSS 与下方 createSwipeList 函数复制到项目中，只需 3 步即可运行：

// 1. 准备数据
const items = [
  { id: '1', sender: '张三', subject: '你好', time: '10:30', snippet: '这是一封邮件' }
];

// 2. 创建实例
const listEl = document.querySelector('#myList');
const swipeList = createSwipeList(listEl, {
  items,
  actions: [
    { key: 'archive', label: '归档', type: 'primary' },
    { key: 'delete',  label: '删除', type: 'danger' }
  ],
  onAction: (key, item, row) => {
    if (key === 'delete') return true; // 返回 true 触发删除+撤销流程
  }
});

// 3. 销毁
// swipeList.destroy();

键盘操作

按键行为
Tab聚焦到列表行 / 操作按钮
ArrowLeft展开当前行的滑动操作区
ArrowRight收起操作区，行体回弹
Delete / Backspace对当前行执行删除动作
Esc收起展开的操作区
Enter展开时执行最后一个（主要）动作
↑ ↓在列表行间移动焦点

--sw-text

API 总览

createSwipeList(el, options) => {
  destroy(),            // 销毁所有事件与 DOM
  setItems(items),      // 重置数据
  removeItem(id),       // 编程式删除
  restoreItem(id),      // 编程式还原
}

options: {
  items,                // 数据数组
  actions,              // 右侧操作按钮配置
  onAction(key,item,row), // 动作回调，delete 返回 true 触发撤销流程
  onDelete(item),       // 删除确认回调
  onRestore(item),      // 撤销回调
  renderItem(item),     // 自定义行内容渲染
  undoDuration: 5000,   // 撤销窗口毫秒
  threshold: 0.4,       // 阈值 0-1
  disabled: false,      // 全局禁用
}

无障碍（A11y）

行带 role="option" 与 aria-selected，操作按钮带 aria-label。焦点环可见，键盘全流程可达。支持 prefers-reduced-motion 瞬时切换降级。

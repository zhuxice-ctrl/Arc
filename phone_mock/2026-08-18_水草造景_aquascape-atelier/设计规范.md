# 设计规范 · 水草造景 · 青川（微信小程序）

- **日期**：2026-08-18
- **方向**：V2 手机 UI
- **形态：微信小程序**

## 色彩系统

水潭色系，禁止蓝紫渐变。主色水草青绿，深色深潭墨绿，底色溪石米白，辅助沉木棕，点缀樱花虾橘红。每页 3-5 个色调层次，各有「色彩主角」。

| 角色 | 色值 | 用途 |
|---|---|---|
| 主色 | `#2E7D5B` | 水草青绿，TabBar/主按钮/标题 |
| 深色 | `#123B2E` | 深潭墨绿，深色区/正文 |
| 底色 | `#F2EEE3` | 溪石米白，页面底 |
| 辅助 | `#7A5230` | 沉木棕，学堂页暖调 |
| 强调 | `#E4572E` | 樱花虾橘红，点赞/价格/点缀 |
| 次主色 | `#5C7668` | 灰青绿，次级文字/图标 |
| 浅绿 | `#A8D5BA` | 水草浅绿，背景色块 |
| 鲜绿 | `#4A9973` | 活力绿，状态/进度 |
| 暖金 | `#F2B84B` | 工作坊横幅光泽 |
| 米浅 | `#EDE7D5` / `#FBF9F2` | 卡片次表面/高光 |
| 深墨 | `#1A2E25` | 极深文字 |

## 字体

`"PingFang SC", "Microsoft YaHei", -apple-system, sans-serif`；数字等宽用于统计。

## 小程序端侧交互（≥4 种）

- 右上角胶囊按钮（··· / ⊙）+ 自定义导航栏（透明/米白/深绿/沉木棕四态随页面变化）
- 底部 TabBar 4 个（首页/作品/学堂/我的），选中态弹性动效
- 页面栈 push/pop 切换（右滑入场感）
- 下拉刷新弹性回弹 + 水草摆动
- 左滑列表操作（加购弹簧回位）
- 吸顶 Tab（作品/学堂）
- 半屏弹层/ActionSheet（工作坊预约确认）
- 底部安全区主按钮（预约页）
- 骨架屏加载（学堂页）

## 组件规范

- 作品卡：圆角 12px，瀑布流双列；hover 浮起+阴影。
- 吸底操作栏：点赞/收藏/分享/模仿，半透明毛玻璃底。
- 票务/场次：日历式场次选择，选中沙金描边。
- 宫格：我的页头像+宫格入口+环形进度。

## 动效系统

签名动效（4 个页面级）：首页气泡上浮+标题入场、详情页视差滚动、列表下拉弹性水波、我的页环形生长进度。组件级（12+）：气泡粒子、涟漪点击反馈、TabBar 弹性、卡片悬停浮起、数字计数、光泽扫过、骨架屏呼吸、左滑弹簧回位、页面右滑入场、动作面板弹起、点赞数字弹出、卡片交错入场。全部周期各异，符合水的物理语义（浮力/阻尼/涟漪）。

## 页面结构（8 页，≥5 独特布局）

1. 首页（Hero 视差+气泡+卡片流）
2. 作品画廊（瀑布流+吸顶筛选+下拉刷新）
3. 作品详情（大图视差+吸底操作栏+材料清单）
4. 造景学堂（沉木暖调+吸顶分级 Tab+骨架屏）
5. 器材市集（左右分栏+左滑加购）
6. 工作坊预约（深色 Hero+日历场次+半屏弹层+安全区主按钮）
7. 设计规范页（本页）
8. 接口文档页（/api/aquascape/v1/* 伪接口契约）

## 健壮性

JSX 全部内联于 `<script type="text/babel">`，无外部 JSX src；CSS 内联；RAF/定时器随 visibilitychange 暂停、卸载取消；快速操作先 clear 后建；高频 mousemove 直接操作 DOM；支持 `prefers-reduced-motion`。

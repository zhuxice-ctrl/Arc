# 设计规范 · 古琴谱 · 减字谱学习与曲库

> 方向：手机 UI（V2） · 日期：2026-08-17 · 形态：微信小程序 · 主题：古琴减字谱学习与曲库

## 色彩系统

| 角色 | 名称 | 色值 | 用途 |
|------|------|------|------|
| 主色 | 墨黑 | `#1a1a1a` | 深色背景、导航栏、详情页底色 |
| 主色辅 | 深墨 | `#2a2520` | 卡片底色、次级背景 |
| 主色深 | 暗墨 | `#1a1512` | 渐变终点、沉浸式背景 |
| 强调色 | 朱砂红 | `#c8423c` | 主按钮、选中态、印章、强调 |

| 背景色 | 米纸 | `#f5ecd9` | 浅色页面底色、卡片背景 |
| 背景色辅 | 米纸暗 | `#d4c4a0` | 分割线、浅色渐变 |
| 辅助色 | 古铜 | `#8a8275` | 次要文字、图标 |
| 辅助色 | 暖棕 | `#3a2a1a` | 渐变中间、装饰 |

### 渐变

- 深色头渐变：`linear-gradient(160deg, #1a1a1a 0%, #2a2520 60%, #1a1a1a 100%)`
- 琴弦渐变：`linear-gradient(90deg, #3a2a1a, #5a3a22, #6b4a2a, #5a3a22, #3a2a1a)`
- 米纸光泽：`linear-gradient(90deg, transparent, #d4c4a0, #e8d8b8, #d4c4a0, transparent)`

## 字体

- **标题**：`Noto Serif SC`（衬线，400/600/700/900 字重）
- **正文**：`Noto Sans SC`（无衬线，300/400/500/700 字重）

## 圆角与间距

- 卡片圆角：`12px`
- 按钮圆角：`8px`
- 标签圆角：`16px`
- 手机外壳宽度：`375px`（iPhone 标准宽度）
- 页面切换过渡：`300ms cubic-bezier(0.4, 0, 0.2, 1)`

## 小程序端侧交互特性（6 种）

1. **胶囊按钮**：右上角"··· / ⊙"自定义导航栏
2. **底部 TabBar**：5 个 Tab，选中态弹起微动效
3. **页面栈 push/pop**：右滑返回手势感，左右推入转场
4. **下拉刷新**：弹性回弹 + 墨滴动效
5. **左滑列表操作**：置顶 / 删除
6. **ActionSheet 半屏弹层**：底部滑出操作面板

## 组件规范

- **手机外壳**：统一 375px 宽度，圆角边框模拟手机
- **导航栏**：随页面变化（透明 / 渐变 / 吸顶变色）
- **卡片**：阴影分层 + 按压收缩反馈
- **FAB 悬浮球**：右下角浮动操作按钮，展开菜单
- **吸底操作栏**：底部安全区主按钮
- **骨架屏**：加载时 shimmer 动画

## 动效系统

1. **墨粒漂浮**：首页背景墨色粒子缓慢漂浮
2. **朱印章盖印**：按压时印章缩放盖印效果
3. **标题毛笔扫过**：标题文字从左到右毛笔揭示
4. **Tab 选中弹起**：切换 Tab 时选中项向上弹起
5. **FAB 菜单展开**：悬浮球点击展开操作菜单
6. **减字谱点按缩放**：减字谱字符点击缩放反馈
7. **卡片按压收缩**：卡片按下时 scale(0.97)
8. **练习圆环**：连续天数圆环进度动画
9. **下拉墨滴**：下拉刷新时墨滴坠落动效
10. **Toast 弹入**：提示消息从顶部弹入
11. **页面左右推入**：页面切换时左右推入转场
12. **骨架屏 shimmer**：加载占位骨架屏流光效果

## 页面结构（8 页）

1. **首页** — Hero 琴身大图 + 连续习琴印章 + 分类宫格 + 继续习琴卡片流 + 新谱横向滚动
2. **曲库** — 吸顶筛选 Tab + 搜索栏 + 瀑布流琴谱卡片 + 难度指示
3. **减字谱详情** — 深色底全屏谱本 + 减字谱字符点按 + FAB + 吸底操作栏 + ActionSheet
4. **练习** — 深色渐变头 + 连续天数圆环 + 今日目标 + 左滑列表
5. **社区** — 标题区 + 筛选 chip + 瀑布流帖子 + 悬浮发布按钮
6. **我的** — 深色渐变头像区 + 数据统计 + 浮动宫格菜单 + 列表项
7. **设计规范** — 色板 + 字体排印 + 组件样式 + 设计理念
8. **接口文档** — 可展开端点列表 + 代码响应示例 + 错误码

## 技术栈

- React 18 + Babel Standalone（miaoda CDN）
- JSX 内联在 `<script type="text/babel">` 中
- CSS 内联在 `<style>` 标签中
- requestAnimationFrame 统一管理 / visibilitychange 暂停 / prefers-reduced-motion 降级

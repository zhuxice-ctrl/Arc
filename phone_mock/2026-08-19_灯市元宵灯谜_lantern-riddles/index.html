接口文档

Mock API · v1.0

获取灯市列表

GET/api/lantern/list

返回当前灯市所有花灯及对应谜笺信息

citystring城市，默认 "长安"
pagenumber页码，默认 1
响应示例
{
  "code": 0,
  "data": {
    "lanterns": [
      {
        "id": "lt_001",
        "type": "palace",
        "color": "red",
        "riddle": {
          "id": "rd_001",
          "question": "画时圆，写时方",
          "category": "字谜",
          "hint": "打一字",
          "answer": "日",
          "explanation": "日即太阳，画时圆形，写时方形"
        }
      }
    ],
    "total": 8
  }
}

提交谜底

POST/api/riddle/submit

提交用户答案，判定是否正确并返回结果

riddleIdstring谜笺 ID
answerstring用户答案
响应示例（正确）
{
  "code": 0,
  "data": {
    "correct": true,
    "answer": "日",
    "explanation": "日即太阳，画时圆形，写时方形",
    "reward": {
      "lanternId": "lt_001",
      "unlockedAt": 1700000000
    }
  }
}

我的灯册

返回用户已点亮的花灯列表

响应示例

  "data": {
    "items": [
      {
        "id": "cl_001",
        "lanternId": "lt_001",
        "riddleId": "rd_001",
        "unlockedAt": 1700000000,
        "pinned": false
      }
    ],
    "total": 1
  }
}

刷新灯市

POST/api/lantern/refresh

下拉刷新时调用，换一批新灯谜

响应示例
{
  "code": 0,
  "data": {
    "lanterns": [...],
    "refreshed": true,
    "newCount": 8
  }
}

灯册操作

POST/api/collection/action

灯册条目操作：置顶 / 取消置顶 / 删除

itemIdstring灯册条目 ID
actionstringpin / unpin / delete

## 核心 User Flow

**逛灯市 → 点谜笺（半屏弹层）→ 猜谜（选项/输入+吸底提交）→ 揭晓点亮 → 收入灯册**

## 端侧交互语言

1. **半屏弹层** — 谜笺从底部弹簧上升，阻尼曲线
2. **下拉刷新** — 灯市下拉换新谜，带状态指示
3. **左滑操作** — 灯册条目左滑显示置顶 / 删除
4. **吸底操作栏** — 猜谜页面底部固定提交栏

## 签名动效

- 烛光渐亮（透明度 + 光晕由小到大）
- 走马灯缓旋（点亮后灯面图案缓慢旋转）
- 谜笺轻摆（如夜风微动的正弦摆动）
- 弹层弹簧（cubic-bezier 阻尼上升）
- 猜中揭晓：花灯从墨色中渐亮，收入灯册

## 灯谜

共 8 条经典灯谜（字谜 / 物谜），每条含谜面、谜目、谜底、解注。

## 持久化

- 点亮状态通过 localStorage 持久化（key: `lantern_riddles_v2`）
- 刷新页面后灯市点亮状态与灯册列表保持
- 灯册的置顶状态同步持久化

## 健壮性

- 零未定义引用
- RAF 随页面可见性暂停
- 快速操作不叠加定时器
- 支持 `prefers-reduced-motion` 降级
- 390px 目标尺寸无横向溢出
- Thumb Zone 内可达主操作

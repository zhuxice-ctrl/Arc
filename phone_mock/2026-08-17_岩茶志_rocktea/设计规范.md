# 设计规范 · 岩茶志 RockTea

> 方向：V2 手机 UI · 原生 App 形态 · 生活方式（武夷岩茶品鉴） · 2026-08-17

整体气质：温暖、醇厚、茶山大地色系，无蓝紫渐变。

## 字体

- 衬线（serif）：`'Noto Serif SC', 'Songti SC', serif` —— 标题、茶品名。
- 无衬线（sans）：`'Noto Sans SC', -apple-system, BlinkMacSystemFont, sans-serif` —— 正文、UI 文字。

## 圆角

主用 `16px` / `20px`（卡片）、`50%`（头像/圆形元素）、`12px`/`14px`（按钮、标签）、`24px 24px 0 0`（吸底面板顶部圆角）。

## 组件规范

- 底部 TabBar：5 项，选中态弹性缩放 + 茶绿高亮。
- 卡片：奶白底 + 细描边 + 阴影分层，hover/选中浮起。
- 风味轮：SVG 圆环描边动画。
- 环形进度：SVG 描边动画（个人页）。
- FAB：悬浮操作按钮 + 展开菜单。
- 浮动面板：底部半屏抽屉（山场地图）。
- 模态弹窗：详情转场。

## 动效系统

12+ 组件级特效：

1. 自定义光标：白环 + 茶绿内点 + 多层发光，开页即显示在屏幕中央，悬停形变，点击涟漪。
2. 热气粒子升腾（茶汤主题语义）。
3. 茶叶飘落。
4. 列表入场序列动画。
5. 风味轮 SVG 描边动画。
6. 环形进度描边。
7. 数字计数滚动。
8. 视差滚动（详情页 Hero）。
9. 光泽扫过。
10. 卡片悬停浮起。
11. Tab 弹性缩放。
12. Toast 弹出。
13. 下拉刷新弹性。

签名动效：首页入场序列 + 详情页视差滚动 + 个人页环形进度。动效遵循茶主题语义，严禁整图缩放 / Ken Burns；周期各不相同。高频鼠标事件直接操作 DOM transform。支持 `prefers-reduced-motion` 降级。

## 页面结构

套在统一 iOS 手机外壳内，8 个页面（布局各异）：

1. **首页**：Hero 大图 + 横向滚动卡片流 + 列表卡片（下拉刷新）。
2. **茶仓**：瀑布流宫格 + 筛选芯片（我的收藏）。
3. **品鉴详情**：Hero 视差滚动 + 风味轮 SVG + 冲泡参数宫格 + 山场信息。
4. **山场地图**：SVG 山形地貌 + 可点击 Pin + 浮动底部面板（牛栏坑 / 慧苑坑 / 大坑口 / 流香涧）。
5. **品鉴笔记**：时间轴卡片堆叠。
6. **个人中心**：深色 Hero + 环形进度 + 功能宫格。
7. **设计规范页**：色彩系统 + 字体 + 组件 + 动效 + 页面结构。
8. **接口文档页**：8 个 API 端点可展开（/api/mobile/v2/teas、/api/mobile/v2/notes 等）。

原生端侧交互（6+ 种）：大标题导航栏、底部 TabBar、全屏详情页转场、下拉刷新、FAB + 展开菜单、长按快捷菜单、浮动面板抽屉。

内容围绕真实岩茶品种（大红袍、水仙、肉桂、铁罗汉、水金龟、半天腰、白鸡冠）与山场组织，无 lorem ipsum。

## 技术栈

单文件 index.html，JSX 内联于 `<script type="text/babel">`，CSS 内联于 `<style>`，无外部 src 引用。

# 焙豆所 · 精品咖啡烘焙工坊 — 设计规范

> V2 手机 UI（微信小程序形态）· 2026-08-17

## 形态说明

微信小程序：页面运行在带胶囊按钮（右上角「··· / ⊙」）的自定义导航栏之下，整体套在统一手机外壳内；导航栏随页面透明 / 吸顶变色。已实现 6 种小程序端侧交互：页面栈 push/pop 切换（右滑返回过渡）、底部 TabBar + 选中微动效、ActionSheet 半屏弹层、下拉刷新弹性回弹、吸顶 Tab、底部吸底操作栏 + 安全区。

## 签名动效

1. 首页咖啡蒸汽升腾（steamRise，主题语义）
2. 首页咖啡豆悬浮上升（beanFloat）
3. 烘焙页环形温度进度 + 实时温度跳动
4. 会员页等级环形进度

## 组件级动效（12+）

fadeUp 入场 / pulse 烘焙呼吸灯 / shimmer 骨架屏 / tabDot 指示点 / fabBounce 悬浮球 / beanRotate 豆款图标 / slideInRight 批次列表 / expandDown 折叠展开 / 卡片堆叠轮播 / 下拉刷新旋转 / ActionSheet slideUp / 底部抽屉

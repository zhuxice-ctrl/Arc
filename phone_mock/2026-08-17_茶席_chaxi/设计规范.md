# 设计规范 · 茶席 Chaxi · 茶文化微信小程序

> 方向：手机 UI（V2） · 日期：2026-08-17 · 形态：微信小程序 · 主题：茶文化（茶器商城/茶艺课程/茶席预约/茶友社区）

## 色彩系统

抹茶绿 + 陶土棕 + 瓷白 + 暗墨 + 鎏金 五色体系，取自传统茶席的器物与茶汤色调。

| 角色 | 色值 | 用途 |
|------|------|------|
| 主色 | #7A9B5E | 抹茶绿，TabBar 选中、主按钮、强调标签 |
| 辅助色 | #8B5E3C | 陶土棕，次级按钮、商品卡片装饰 |
| 背景色 | #F2EEE5 | 瓷白，页面底色 |
| 文字色 | #2C2825 | 暗墨，正文、标题 |
| 强调色 | #B8935A | 鎏金，价格、装饰线、光标点击态 |
| 浅瓷 | #E8E2D5 | 卡片交替背景 |
| 中灰瓷 | #D6CFC0 | 分隔线、禁用态 |
| 深灰瓷 | #BFB7A4 | 次要文字、图标 |

## 字体系统

- 标题字体：`'Noto Serif SC', serif` — 衬线体，标题与品牌名
- 正文字体：`'Noto Sans SC', -apple-system, 'PingFang SC', sans-serif` — 无衬线体
- 装饰字体：`'Ma Shan Zheng'` — 手写体，仅用于装饰性标题
- 字重：标题 600/700/900，正文 400/500

## 组件规范

- 手机外壳：圆角 40px，深色边框 8px，内屏圆角 32px
- 胶囊按钮：右上角，宽 87px 高 32px，圆角 16px，半透明白底
- TabBar：底部固定，4 个 Tab，选中态缩放 1.1 + 小圆点微动效
- 卡片：圆角 12px，瓷白底，box-shadow: 0 2px 12px rgba(44,40,37,0.06)
- 吸顶 Tab：sticky 定位，毛玻璃背景 backdrop-filter: blur(12px)
- 半屏弹层：从底部滑入，圆角 16px 顶部，遮罩 rgba(0,0,0,0.4)
- 骨架屏：灰阶脉冲动画，圆角 8px

## 端侧交互语言（8 种全部实现）

1. 页面栈 push/pop 切换 — 右滑返回手势感，新页面从右侧滑入
2. 底部 TabBar — 4 Tab（首页/茶器/社区/我的），选中缩放+小圆点
3. 半屏 ActionSheet — 规格选择/胶囊菜单/举报等 8 种
4. 下拉刷新弹性回弹 — 首页，阻尼回弹动画
5. 左滑列表操作 — 社区帖子，举报/删除按钮
6. 吸顶 Tab — 商城分类+社区分类+接口文档
7. 底部吸底操作栏 — 详情页，安全区适配
8. 骨架屏加载 — 首页 loading 态

## 技术栈

React + JSX（内联在 index.html 的 script type="text/babel" 中），Babel standalone 转译。CSS 内联在 style 标签。自定义光标用 vanilla JS。支持 prefers-reduced-motion 降级。

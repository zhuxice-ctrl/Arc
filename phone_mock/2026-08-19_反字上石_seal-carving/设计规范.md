# 设计规范 · 石上刻（篆刻治印工作台）

形态：微信小程序
日期：2026-08-19

## 一、核心创意

整个界面是一方正在被治印的印石工作台。用户在「石面」上设计篆书印稿，所见即所刻——但一切以镜像（反字）呈现（刻反字），唯有钤印那一刻印石翻转 180° 才显出正像。视觉来源是印石、刻刀、朱砂印泥与宣纸钤印的真实物质。

## 二、配色系统（印石材质主导）

以印石材质为底，朱砂仅作强调（印纹/钤印），不铺大面。禁止蓝紫渐变。

| Token | 色值 | 用途 |
|------|------|------|
| `--stone-base` | `#e8d9b8` | 寿山石暖象牙赭黄，工作台主底 |
| `--stone-highlight` | `#f5ebd4` | 石面高光 |
| `--stone-shadow` | `#b8a078` | 石面阴影/边沿 |
| `--qingtian-base` | `#c8d4c0` | 青田石淡灰绿，辅色/印稿区 |
| `--vermilion` | `#c42f1d` | 朱砂印泥，印纹/主操作/强调 |
| `--vermilion-deep` | `#9a2416` | 朱砂深，按压态 |
| `--vermilion-light` | `#e04a36` | 朱砂亮，hover |
| `--paper` | `#f5efe0` | 宣纸，钤印页底 |
| `--ink` | `#2a2420` | 墨黑，正文 |
| `--ink-soft` | `#4a4038` / `--ink-faint` `#7a6e62` | 墨灰，次级文字 |
| `--wx-bg` | `#f7f7f7` | 微信小程序系统背景 |
| `--wx-blue` | `#07c160` | 微信绿（克制使用） |

朱砂红 `#c42f1d` 全局出现 21 次，严格控制为印纹与主操作按钮，不泛滥。

## 三、字体系统

- 标题/篆刻气质：`"Songti SC", "SimSun", "Noto Serif SC", serif`（宋体衬线，呼应碑帖印谱气质）
- 正文/UI：`-apple-system, BlinkMacSystemFont, "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", sans-serif`
- 篆字字形：SVG path 手描写形（静/安/无/闲/真/乐），非字体依赖

## 四、空间与圆角

- 圆角：`--radius-sm` 6px / `--radius-md` 12px / `--radius-lg` 16px
- 微信容器尺寸：状态栏 44px、自定义导航 44px、胶囊按钮 87×32px、底部 TabBar 56px
- 手机壳约 390×844，壳克制，重点在屏幕内

## 五、动效系统（克制·功能优先）

| 关键帧 | 作用 | 触发 |
|--------|------|------|
| `stampPress` | 印石下压按压感 | 钤印按下 |
| `stampSeal flipped` | `rotateX(180deg)` 翻转显正像 | 钤印 signature moment |
| `sealBloom` | 印纹由中心绽放定形 | 翻转后印面显形 |
| `inkSpread` | 朱砂印泥由中心向外晕开 | 钤印落纸/下拉刷新 |
| `pagePushIn` / `pagePopOut` | 页面栈 push/pop 转场 | 导航进退 |
| `seal-stroke.carved` | 笔画刻制 `fill` 过渡 + 透明度 | 逐笔标记刻完 |

- 缓动：`--easing-spring` `cubic-bezier(0.34,1.56,0.64,1)`（翻转/弹性反馈）、`--easing-standard` `cubic-bezier(0.4,0,0.2,1)`（过渡）
- 无装饰性粒子/光晕/发光球
- 支持 `prefers-reduced-motion` 降级；RAF/定时器随 `visibilitychange` 暂停且卸载取消

## 六、Signature Moment

钤印验证页：按下「钤印」→ 印石 `rotateX(180deg)` 翻转 → 镜像反字翻为正字 → 朱砂印纹 `sealBloom`+`inkSpread` 在宣纸上由中心向外晕开定形 → 提示「已归档至印谱」并跳转印谱。

## 七、信息架构与流程

页面栈（pushPage/popPage）+ 底部 TabBar（治印/印稿/印谱/我的）：

```
治印(工作台) ──开始刻制──> 刻制页(逐笔标记+深度进度) ──前往钤印──> 钤印页(翻转显正+晕开) ──归档──> 印谱
   │ 选石(半屏弹层:方/圆/随形 × 寿山/青田/昌化/巴林)
   │ 刀法(半屏弹层:冲刀/切法)
   └ 朱文/白文 阴阳切换(实时镜像同步)
```

## 八、微信小程序端侧交互语言（6 种）

1. 胶囊按钮（··· ×）+ 自定义导航栏（返回/标题）
2. 页面栈 push/pop 转场 + 左边缘滑动返回
3. 底部 TabBar（治印/印稿/印谱/我的）
4. 半屏弹层 Bottom Sheet（选石/刀法说明）+ 遮罩
5. 下拉刷新（印泥晕开动效）
6. 左滑操作（印谱条目展开分享/删除）

## 九、内容真实性

- 篆字：静/安/无/闲/真/乐（SVG 手写篆形）
- 石种：寿山石·白田冻、青田石·封门青、昌化石·鸡血石、巴林石·彩冻（配真实特征描述）
- 刀法术语：冲刀法、切刀法、朱文、白文、边款、钤印、印谱
- 印谱预置 6 方印章 + 空状态

## 十、工程

- 单文件 `index.html`，纯 vanilla JS，零外部 CDN/框架依赖
- SVG 滤镜 `sealRough` 模拟印泥毛边粗糙感
- 健壮性：零未定义引用；RAF/定时器随可见性暂停且卸载取消；快速操作不叠加定时器；高频指针事件直接操作 DOM；支持 `prefers-reduced-motion`

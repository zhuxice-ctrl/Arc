# 一畦菜园 · 社区共享菜园

V2 手机端 Mock：社区共享菜园「一畦菜园」微信小程序高保真原型。城市邻里共同认领菜畦、打卡农事、分享收成。

## 形态

微信小程序（WeChat Mini Program）

端侧交互语言（≥4 种）：
- ✅ 胶囊按钮 + 自定义导航栏（88px 含状态栏，毛玻璃材质）
- ✅ 底部 TabBar（首页 / 我的菜园 / 发现 / 消息 / 我的，5 个主入口）
- ✅ 半屏弹层（菜畦详情，从底部上滑，带 handle）
- ✅ 下拉刷新（弹性 + 嫩芽生长图标）
- ✅ 左滑操作（种植日记条目左滑露出编辑/删除）

## 主题

社区共享菜园「一畦菜园」——让城市人也能有一畦属于自己的菜地。认领菜畦、打卡浇水、记录生长、与邻里分享收成。

## 核心交互

1. **菜畦格子地图** — 首页 4×4 菜畦网格，点击任一畦弹出半屏详情
2. **半屏农事弹层** — 菜畦信息、生长进度、照料记录时间线
3. **打卡浇水** — 「我的菜园」页面点击打卡，触发成功动效 + 飘花
4. **收获登记** — 任务列表勾选完成任务，进度实时更新
5. **邻里分享** — 首页邻里动态流，点赞 / 评论

## 签名动效

打卡成功时的飘花/落叶洒落 + 弹性弹层 + 波纹扩散——从土壤褐底色中迸发出的芽绿与晨光黄粒子。

## 配色

土壤褐主导：土壤褐 `#5C4033` · 芽绿 `#8BC34A` · 晨光黄 `#F5C24B`

（设计规范中另有 B 版芽绿主导、C 版晨光黄主导的配色方案文档，部署版本使用 A 版土壤褐。）

## 技术栈

- 纯 vanilla 单文件 HTML
- 无 React / Babel / 外部框架（字体除外）
- 375×812 设计稿，桌面端居中展示带设备边框
- 全部动效使用 CSS + 原生 JS
- `prefers-reduced-motion` 支持

## 内容

- 菜畦数据：16 畦（含 3 畦待认领），覆盖 6 种蔬菜
- 邻里动态：陈叔番茄丰收、李婶生菜分享等真实场景
- 农事任务：浇水/除草/施肥/采收，均为真实种菜流程
- 无 Lorem Ipsum / Feature One / Sample Text

# 一畦菜园 · 接口文档

## 概述

社区共享菜园「一畦菜园」微信小程序后端 API 接口文档。
- Base URL：`https://api.yiqicaiyuan.com/v1`
- 认证方式：微信登录 + JWT Token（Header: `Authorization: Bearer <token>`）
- 数据格式：JSON
- 字符编码：UTF-8

---

## 1. 用户模块

### 1.1 微信登录

**POST** `/auth/wx-login`

请求参数：

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| code | string | 是 | wx.login 返回的 code |
| userInfo | object | 否 | 用户昵称、头像等 |

响应：

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "token": "eyJhbGciOiJIUzI1NiIs...",
    "user": {
      "id": "u_12345678",
      "nickname": "菜农小朱",
      "avatar": "https://...",
      "level": 3,
      "levelName": "绿手指",
      "points": 128,
      "plotCount": 1,
      "checkinDays": 23,
      "harvestCount": 6
    }
  }
}
```

### 1.2 获取用户信息

**GET** `/user/profile`

响应：见登录接口 user 对象。

### 1.3 更新用户信息

**PUT** `/user/profile`

请求参数：

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| nickname | string | 否 | 昵称 |
| avatar | string | 否 | 头像URL |

## 2. 菜畦模块

### 2.1 获取菜畦地图

**GET** `/plots`

请求参数：

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| zone | string | 否 | 区域筛选（A/B/C），不传返回全部 |
| page | int | 否 | 页码，默认 1 |
| pageSize | int | 否 | 每页数量，默认 16 |

响应：

```json
{
  "code": 0,
  "data": {
    "total": 24,
    "list": [
      {
        "id": "plot_b05",
        "zone": "B",
        "number": "05",

        "harvestable": false,

        "expectedHarvestDate": "2026-09-02"

  }
```

**GET** `/plots/my`

响应结构同菜畦地图列表，仅返回用户认领的菜畦。

## 3. 农事任务模块

### 3.1 获取今日任务

**GET** `/tasks/today`

请求参数：

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| plotId | string | 是 | 菜畦ID |

响应：

```json
{
  "code": 0,
  "data": {
    "date": "2026-08-19",
    "total": 4,
    "completed": 2,
    "list": [
      {
        "id": "task_001",
        "type": "water",
        "typeName": "晨间浇水",
        "icon": "💧",
        "desc": "每株 200ml",
        "scheduledTime": "07:30",
        "completed": true,
        "completedTime": "2026-08-19 07:28"
      }
    ]
  }
}
```

### 3.2 完成任务（打卡）

**POST** `/tasks/:id/complete`

请求参数：

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| plotId | string | 是 | 菜畦ID |
| note | string | 否 | 备注 |

响应：

```json
{
  "code": 0,
  "data": {
    "taskId": "task_001",
    "streakDays": 13,
    "pointsEarned": 5,
    "message": "打卡成功！连续打卡 13 天"
  }
}
```

### 3.3 添加种植日记

**POST** `/diary`

请求参数：

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| plotId | string | 是 | 菜畦ID |
| type | string | 是 | 类型：water/weed/fertilize/harvest/other |
| content | string | 是 | 日记内容 |
| images | array | 否 | 图片URL数组 |

### 3.4 种植日记列表

**GET** `/diary`

请求参数：plotId, page, pageSize

### 3.5 删除种植日记

**DELETE** `/diary/:id`

## 8. 错误码

| code | message | 说明 |
|------|---------|------|
| 0 | success | 成功 |
| 1001 | 参数错误 | 请求参数校验失败 |
| 1002 | 未登录 | Token 无效或已过期 |
| 1003 | 无权限 | 无权操作该资源 |
| 2001 | 菜畦不存在 | 菜畦ID无效 |
| 2002 | 菜畦已被认领 | 重复认领 |
| 3001 | 任务不存在 | 任务ID无效 |
| 3002 | 今日已打卡 | 重复打卡 |
| 4001 | 动态不存在 | 动态已删除 |
| 5000 | 服务器错误 | 内部错误 |

## 9. WebSocket 通知（可选）

- 连接地址：`wss://api.yiqicaiyuan.com/ws`
- 用途：实时收获提醒、邻里新动态通知
- 心跳：30s ping/pong

消息格式：

```json
{
  "type": "harvest_reminder",
  "data": {
    "plotId": "plot_b05",
    "vegetableName": "番茄",
    "count": 8,
    "message": "你的番茄有 8 颗成熟啦"
  }
}
```

# 一畦菜园 · 设计规范

## 1. 设计理念

「一畦菜园」是社区共享菜园的微信小程序，连接城市里爱种菜的邻里。设计语言源自真实的菜园世界——泥土的质感、嫩芽的生机、晨光的温度。拒绝模板化的蓝紫渐变与毛玻璃，让每一个像素都有泥土的来由。

## 3. 字体系统

### 字族
- **正文 / UI**：Noto Sans SC（思源黑体简体中文）
  - 400 / 500 / 600 / 700
- **展示 / 大标题**：Noto Serif SC（思源宋体简体中文）
  - 500 / 700 / 900 — 克制使用，用于英雄区标题、统计数字

### 字号层级

| 层级 | 字号 | 字重 | 用途 |
|------|------|------|------|
| Hero 标题 | 24px | 700（宋体） | 首页大标题 |
| 页面标题 | 17px | 600 | 导航栏标题 |
| 区块标题 | 16px | 600 | 菜畦地图/邻里动态等 |
| 卡片标题 | 14px | 600 | 动态作者/任务名称 |
| 正文 | 13-14px | 400/500 | 卡片内容/描述 |
| 辅助文字 | 11-12px | 400 | 时间/标签/说明 |
| 极小文字 | 10px | 500 | Tab文字/菜畦编号 |

### 数字
统计数字（stat-num）使用宋体 700 粗体，增强质感与仪式感。

## 4. 间距系统

8px 基准栅格：
- 4px / 6px / 8px / 10px / 12px / 14px / 16px / 20px / 24px

页面内边距：16-20px
卡片内边距：14px
元素间距：8-12px

## 5. 圆角

- `--radius-sm` 6px — 小元素 / 菜畦格子 / 小图
- `--radius-md` 12px — 卡片 / 输入框 / 按钮
- `--radius-lg` 20px — 大卡片 / Banner
- `--radius-xl` 28px — 弹层 / 设备外壳

胶囊按钮全圆角（height / 2）。

## 6. 阴影

三层阴影体系（随主色调整色相）：
- shadow-sm：0 2px 8px rgba(主色, 0.06) — 卡片 / 输入框
- shadow-md：0 8px 24px rgba(主色, 0.08) — 悬浮卡片 / 弹层
- shadow-lg：0 16px 48px rgba(主色, 0.12) — 设备外壳 / 大弹层

## 7. 组件规范

### 7.1 导航栏（微信小程序）
- 高度：88px（含 44px 状态栏）
- 背景：半透明 + 毛玻璃效果
- 胶囊按钮：88×32px，圆角 16px，毛玻璃材质
- 标题：居中，17px 600

### 7.2 TabBar
- 高度：56px
- 5 个等分入口
- 激活态：主色图标 + 文字，线宽 2.2
- 默认态：ink-400 图标 + 文字，线宽 1.8

### 7.3 菜畦格子
- 4×4 网格，gap: 8px
- 圆角：8-10px
- 每畦带蔬菜 emoji 图标 + 编号标签
- 我的菜畦：右上角"我"字小圆标
- 可收获状态：呼吸光晕脉冲动画

### 7.4 按钮
- 主按钮：渐变填充 + 阴影 + 文字反白
- 次按钮：浅底 + 边框 + 主色文字
- 高度：36-44px
- 圆角：18-22px（胶囊）
- 点击态：scale(0.96) + 阴影变化

### 7.5 半屏弹层
- 最大高度：70% 屏幕
- 顶部 handle：36×4px，圆角 2px
- 从底部滑入，cubic-bezier(0.32, 0.72, 0, 1) 缓动
- 遮罩：rgba(深色, 0.4)

### 7.6 任务列表项
- 高度：自适应，padding 14px
- 左侧 40px 圆形图标背景
- 主标题 14px 600，副描述 11px
- 勾选框：22px 圆形，完成态填充主色 + 白勾
- 完成态：文字删除线 + 变灰

## 8. 动效规范

### 8.1 动效原则
- 物理合理：弹性、重力、惯性
- 主题契合：生长、发芽、阳光、飘落
- 克制：不为动而动，动效服务反馈与引导

### 8.2 缓动曲线
- 标准：cubic-bezier(0.25, 0.46, 0.45, 0.94)
- 弹性进入：cubic-bezier(0.34, 1.56, 0.64, 1)
- 底部弹层：cubic-bezier(0.32, 0.72, 0, 1)

### 8.3 时长
- 微交互（按钮/卡片点击）：150-200ms
- 页面切换/弹层：300-350ms
- 循环动画（脉冲/呼吸）：2-4s
- 入场动画：400-500ms

## 9. 栅格与布局

- 设计稿：375×812px（iPhone 12 尺寸）
- 内容区：左右 16-20px 内边距
- 菜畦网格：4 列等分，8px gap
- 活动卡片：2 列等分，10px gap
- 统计卡片：3 列等分，10-12px gap

## 10. 无障碍

- 文字与背景对比度满足 WCAG AA
- 所有交互元素有明确的点击反馈
- 下拉刷新 / 弹层等手势操作有对应按钮替代
- 动效尊重 prefers-reduced-motion（预留接口）

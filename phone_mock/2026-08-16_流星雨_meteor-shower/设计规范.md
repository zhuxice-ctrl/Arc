# 流星雨 Meteor Shower — 设计规范

## 主题

天文观测与流星记录 App。用户可以追踪流星雨预报、记录观测数据、浏览天文图库、管理观测计划。

## 色彩系统

| 令牌 | 色值 | 用途 |
|------|------|------|
| 主背景 | `#0B0E17` | 深夜空黑 |
| 深背景 | `#05070D` | 更深层背景 |
| 暗面板 | `#141828` | 面板/卡片背景 |
| 流星橙 | `#FF6B1A` | 主强调色 |
| 极光绿 | `#3DD68C` | 次强调色 |
| 暖琥珀 | `#E8A547` | 辅助强调 |
| 星尘银 | `#C0C5CE` | 主文字 |
| 白色 | `#FFFFFF` | 高亮文字 |

### 色彩分层

- 首页：以流星橙为主角，暖色调，倒计时数字高对比
- 画廊：星尘银+极光绿交替，冷色调，3D 轮播 Hero
- 日志：暖琥珀+流星橙混合，堆叠卡片 3D 倾斜
- 星图：极光绿为主角，冷色调，对角分割布局
- 个人中心：三色环形进度（橙/绿/琥珀），径向布局
- 规范页：Tab 切换，色阶条展示
- 接口页：左右分栏，深色代码风格
- 计划页：日历网格，暖琥珀高亮

## 页面结构（8 页）

1. **首页** — Hero 倒计时 + 视差星座线 + 横滑预报条 + 推荐观测点卡片 + 动态流
2. **流星画廊** — 3D 轮播 Hero + 瀑布流马赛克网格 + 分类 chips
3. **观测日志** — 3D 倾斜堆叠卡片 + 三格数据统计 + 脉冲 FAB
4. **实时星图** — 对角分割 + 倾斜星球体 + 辐射点脉冲 + 底部抽拉抽屉
5. **个人中心** — 三环径向进度 + 成就徽章网格 + 头像脉冲 + 菜单列表
6. **设计规范** — Tab 切换（色彩/字体/组件/动效）+ 色阶条 + 字号阶梯
7. **接口文档** — 左右分栏：左侧方法列表 + 右侧参数/响应详情
8. **观测计划** — 日历网格 + 时间轴竖线 + 装备清单

## 布局多样性

- 首页：Hero+横滑+卡片流
- 画廊：3D 轮播+瀑布流
- 日志：堆叠卡片+FAB
- 星图：对角分割+抽屉
- 个人：径向进度+网格
- 规范：Tab 切换
- 接口：左右分栏
- 计划：日历+时间轴

## 动效系统

| 动效 | 实现方式 |
|------|----------|
| 自定义光标 | 三态（默认/悬停/点击）+ 涟漪，流星橙色 |
| Canvas 流星粒子场 | 物理轨迹（初速度+重力+衰减） |
| 恒星闪烁 | 独立频率与相位 |
| 打字机入场 | 字符随机延迟 |
| 数字 count-up | easeOut 缓动 |
| 辐射点环形脉冲 | 多层扩散环 |
| FAB 脉冲呼吸 | scale 周期动画 |
| 卡片 3D 倾斜 | mousemove 驱动 |
| 头像光环 | 旋转 conic-gradient |
| 页面切换模糊入场 | filter blur 过渡 |
| 流星拖尾辉光 | Canvas 渐变拖尾 |
| shimmer 光泽扫过 | linear-gradient 动画 |

## Tweaks 面板

8 项实时调节：星辰密度 / 流星速度 / 辉光强度 / 色调氛围（极光/暖焰/深空）/ 毛玻璃 / 背景星辰 / 字体缩放 / 自定义光标

## 技术栈

- React（内联 JSX + Babel standalone）
- Canvas 2D 粒子系统
- CSS 变量驱动主题
- 手机外壳框架（ios-frame.jsx）
- Tweaks 面板组件（tweaks-panel.jsx）

# 爪印 Pawprint · 宠物社交微信小程序

> 日期：2026-08-17 ｜ 方向：V2 手机 UI ｜ 形态：微信小程序 ｜ 主题：宠物社交小程序

形态：微信小程序（上一轮最新为原生 App「岩茶志」，本轮交替为微信小程序）

## 简介

「爪印 Pawprint」是一个宠物社交微信小程序，套在统一手机外壳 + 小程序容器内，可切换 8 个页面。内容围绕真实可信的宠物社区组织：毛孩子动态（橘猫"大福"、柯基"布丁"、布偶猫"年糕"、柴犬"酱油"、玄凤鹦鹉"绿豆"等）、遛弯约伴活动、宠物友好地图、养宠百科、领养中心、个人中心。

## 动效亮点

- 首页卡片错落入场序列动画。
- 百科页视差滚动。
- 个人页环形进度动画。
- TabBar 选中态微动效、下拉刷新弹性回弹、左滑列表操作。

## 微信小程序端侧交互

胶囊导航栏 / 页面栈 push/pop / 底部 TabBar / 半屏弹层 ActionSheet / 下拉刷新弹性 / 左滑操作 / 吸顶 Tab / 安全区吸底主按钮 / 骨架屏加载。

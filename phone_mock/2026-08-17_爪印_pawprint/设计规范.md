# 爪印 Pawprint · 设计规范

> 方向：V2 手机 UI · 日期：2026-08-17 · 形态：微信小程序 · 主题：宠物社交小程序

## 1. 色彩系统

主配色为「奶油苔绿」柔和暖系自然调，取自宠物毛色与自然草地的温度，无蓝紫渐变。

| 角色 | 色值 | 用途 |
|---|---|---|
| 底色 · 奶油杏 | `#FBF3E4` | 页面主背景 |
| 主色 · 苔绿 | `#5B7A5E` | TabBar 选中、主按钮、标题强调 |
| 强调 · 蜜桃橙 | `#F2A65A` | 行动号召、标签、高亮 |
| 辅助 · 暖棕 | `#8C6A4F` | 次级强调、宠物毛色卡片 |
| 文字 · 深墨绿 | `#2E3B31` | 正文与标题文字 |

派生层次：`#EDE4D3` / `#F0E8D8` / `#F5EDDD`（纸面浅阶）、`#3D5A40`（苔绿暗阶）、`#6B8A6E` / `#B8C9A5`（苔绿亮阶）、`#C77B32` / `#E89040` / `#E07A5F`（蜜桃橙系过渡）、`#6D4C32`（暖棕暗阶）、`#D4A574`（暖棕亮阶）、`#5BD67D`（状态绿点缀）。

## 2. 字体

- 正文 `font-family: "Noto Sans SC", -apple-system, BlinkMacSystemFont, "PingFang SC", "Helvetica Neue", Arial, sans-serif`
- 系统字 `font-family: -apple-system, "SF Pro", system-ui`

## 3. 页面结构（8 页）

1. 首页 — 动态卡片流（毛孩子动态），入场序列动画。
2. 发现 · 宠物友好地图 — 地图浮层 + 宠物友好咖啡馆 / 公园 / 餐厅标记。
3. 活动约伴 — 遛弯约伴活动卡 + 统计区。
4. 养宠百科 — 视差 Hero + 文章列表。
5. 领养中心 — 瀑布流领养卡片。
6. 我的 · 个人中心 — 头像 + 宫格入口 + 环形进度。
7. 设计规范页 — 色彩 / 字体 / 组件展示。
8. 接口文档页 — 代码风接口文档。

## 4. 微信小程序端侧交互（≥4 种）

- 胶囊导航栏（右上角 ··· / ⊙），随页面透明 / 渐变 / 吸顶变色。
- 页面栈 push/pop 切换（右滑返回手势感）。
- 底部 TabBar（选中态微动效）。
- 半屏弹层 / ActionSheet 动作面板。
- 下拉刷新弹性回弹。
- 左滑列表操作。
- 吸顶 Tab 筛选。
- 底部安全区吸底主按钮。
- 骨架屏加载。

## 5. 布局多样性

卡片流 / 地图浮层 / 活动卡 + 统计 / 视差 Hero + 文章列表 / 瀑布流领养卡 / 宫格个人中心 / 规范展示 / 代码风接口文档，至少 6 种非重复布局骨架。每页有独立色彩主角（首页偏暖苔绿、地图偏蜜桃、百科偏深墨绿、个人偏奶油 + 暖棕）。

## 6. 签名动效

- 首页入场序列动画（卡片错落入场）。
- 百科页视差滚动。
- 个人页环形进度动画。
- 卡片错落入场过渡。

动效基于弹簧 / 阻尼 / RAF 积分器，周期各不相同。

## 7. 健壮性

- `visibilitychange` 暂停所有 RAF 与动画循环，卸载统一取消。
- `prefers-reduced-motion` 降级为最小动效。
- 高频鼠标 / 触摸事件直接操作 DOM transform，不走 setState 重渲染。
- 快速来回操作不叠加定时器，重建前先清除旧的。

## 8. 技术栈

单文件 `index.html`，内联 `<style>` + 内联 `<script type="text/babel">`（React + Babel standalone），无外部 JSX/CSS 文件引用。

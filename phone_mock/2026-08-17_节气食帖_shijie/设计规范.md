# 青瓷食帖 · 设计规范

## 色彩系统

青瓷水墨系（青瓷釉绿 + 宣纸米白 + 墨青 + 古铜金），浅底宣纸质感，无蓝紫渐变；与同日 V1 琥珀金系、V3 墨绿深底系互不雷同。

| 角色 | 色值 | 用途 |
|---|---|---|
| 主色 · 青瓷釉 | `#3d7a58` | 主按钮、TabBar 选中态、强调标签 |
| 青瓷浅阶 | `#7ab89a` / `#9db89a` | 次级标签、装饰面 |
| 墨青深阶 | `#1a2a22` / `#2a5a3e` / `#3d5a49` | 标题正文、深色区块 |

## 字体

- 正文：`'Noto Sans SC', -apple-system, system-ui, sans-serif`
- 标题衬线：`'Noto Serif SC', serif`
- 书法点缀：`'Ma Shan Zheng', serif`（节气名、印章式标题）

## 组件与圆角

- 卡片 12px / 20px 圆角；半屏弹层 `16px 16px 0 0`；胶囊/Chip 50%；输入框 8px
- 小程序胶囊按钮：右上角 `··· / ⊙`，自定义导航栏随页面透明/吸顶变色

## 小程序端侧交互（9 种）

胶囊导航栏、页面栈 push/pop 切换、底部 TabBar（选中弹跳微动效）、ActionSheet 半屏弹层、下拉刷新弹性回弹、左滑列表删除、吸顶 Tab 筛选、骨架屏加载 shimmer、详情页吸底操作栏。

## 页面结构（7 页，≥5 页独特布局）

1. 首页 — 卡片流 + Hero 节气横幅 + 当令食材网格（入场序列签名动效）
2. 分类页 — 吸顶 Tab 季节筛选 + 24 节气网格
3. 食谱详情 — Hero 视差滚动 + 步骤时间轴 + 吸底操作栏（签名动效）
4. 食札 — 瀑布流双列 + 筛选 Chip + 左滑删除 + 悬浮操作球
5. 我的 — 头像 + 宫格 + 环形进度
6. 设计规范页 ｜ 7. 接口文档页

## 动效系统（14+）

自定义光标（弹簧跟随/悬停放大/点击涟漪）、手机 3D 倾斜、下拉弹性、ActionSheet 弹入、Tab 弹跳、进度环、头像脉冲、骨架屏 shimmer、光泽扫过、spring-in 弹性入场、滚动渐入揭示、视差滚动、数字计数、打字机标题。

## 健壮性

JSX 全部内联于 index.html；visibilitychange 暂停所有 RAF；定时器重建前先清理；mousemove 直操 DOM 不触发 setState；prefers-reduced-motion 降级。

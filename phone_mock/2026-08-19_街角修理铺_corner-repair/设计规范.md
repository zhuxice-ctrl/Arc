# 街角修理铺 · 设计规范

形态：微信小程序

## 主题
城市街角修理铺的微信小程序：修鞋、修伞、配钥匙、修表、换拉链这些「快消失的手艺」，做成可下单、可追踪、有手艺人温度的服务平台。核心机制：选类目 → 拍照描述故障 → 师傅接单报价 → 修理进度时间线 → 到店取件码核销。

## 字体体系
- UI：苹方 / Noto Sans SC
- 价格与单号：等宽数字（JetBrains Mono 风格）
- 店铺招牌：宋体带手作感

## 端侧交互语言（微信小程序，6 种，全部真实可用）
1. 胶囊按钮（右上角）+ 自定义导航栏容器
2. 页面栈 push/pop 转场
3. 底部 TabBar
4. 半屏弹层（类目选择 / 报价确认）
5. 吸底操作栏（下单 / 确认按钮）
6. 下拉刷新（弹性回弹 + 齿轮转动 loading）
7. 左滑操作（订单列表左滑取消 / 再来一单）

## 签名动效
修理进度以「缝线缝合」动画呈现：进度线是一根被逐段缝上的线，每完成一步打上一个「线结」，当前节点脉冲呼吸。报价到达卡片从底部弹簧滑入 + 轻震；取件核销为印章式「已取件」盖下。

## 产品逻辑（完整闭环）
首页（类目 + 在修订单状态）→ 选类目（半屏弹层选故障+价格区间）→ 下单页（拍照+描述+取件方式）→ 师傅报价（3 秒滑入）→ 确认 → 进度页（已接单→检测中→修理中→待取件）→ 取件码（二维码 + 核销动画）。

## 内容（真实）
- 5 个修理类目：修鞋（开胶/换底/换跟）、修伞（换骨/换面/修开关）、配钥匙（家门/抽屉/老式挂锁）、钟表（换电池/换表带/洗油）、皮具（换拉链/补边油/缝线）
- 真实店铺：「陈记修理铺」，师傅陈建国，开店 32 年
- 真实价格区间（如换鞋底 45-80 元）
- localStorage 持久化订单状态

## 技术栈
单文件 HTML + 内联 CSS/JS（含 Babel 内联 JSX）。localStorage 持久化；RAF 随可见性暂停；支持 prefers-reduced-motion；目标尺寸 390×844。

## 页面清单
首页 / 类目半屏弹层 / 下单页 / 报价确认 / 进度时间线 / 取件码 / 设计规范页 / 接口文档页（7 个 API）。

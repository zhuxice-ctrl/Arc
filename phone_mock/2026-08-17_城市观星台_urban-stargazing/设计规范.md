## 小程序容器规范

- **胶囊按钮**：右上角"··· / ⊙"，固定定位
- **自定义导航栏**：高度 88px，滚动吸顶变色（透明→靛蓝）
- **底部 TabBar**：4 个 Tab（星空/地图/日志/我的），选中态微动效（缩放+颜色变化）
- **页面切换**：push/pop 动画，右滑返回手势感
- **下拉刷新**：弹性回弹，顶部出现加载指示器
- **左滑操作**：列表项左滑露出收藏/分享按钮
- **ActionSheet**：底部半屏弹层，6 项操作

## 组件规范

- **卡片**：圆角 12-16px，rgba 半透明底色 + 1px 边框
- **按钮**：主按钮琥珀金底白字圆角 8px，吸底安全区主按钮
- **头像**：圆形，外层脉冲光环
- **徽章**：宫格布局，3×3，选中态放大
- **时间线**：左侧竖线 + 节点圆点，渐入动画
- **星空画布**：Canvas 120 颗呼吸闪烁星 + 流星
- **星座连线**：SVG 描边动画 + 星点渐现

## 页面结构（8 页）

1. **今夜星空**（首页）— 星空 Canvas + 星座连线 + 月相卡片 + 观测指数 + 天体推荐横滑
2. **观测点地图** — SVG 光污染热力图 + 标记 + 吸顶 Tab 筛选 + 左滑列表
3. **观测日志** — 时间线布局 + 渐入动画 + 统计卡片
4. **个人中心** — 头像 + 数据统计 + 8 宫格成就 + 功能菜单
5. **天体详情页** — 浮动星球 + 旋转光环 + 参数网格 + 吸底操作栏
6. **设计规范页** — 色板 + 字体 + 间距 + 组件示例
7. **接口文档页** — 4 个可展开 REST 接口 + 参数表 + 代码块
8. **ActionSheet 示例** — 半屏弹层 6 项操作

## 技术栈

- React + Babel（JSX 内联在 `<script type="text/babel">`）
- CSS 内联在 `<style>` 标签
- Canvas 2D 星空渲染
- SVG 星座连线
- visibilitychange 暂停 / prefers-reduced-motion 降级

# 羽踪 · 观鸟记录 App · 设计规范

> 日期：2026-08-18 · 方向：V2 手机 UI · 形态：原生 App · 主题：观鸟记录原生应用

## 一、设计概念

「羽踪」是一款观鸟记录原生 App，覆盖鸟种图鉴、观测记录、观鸟地点与个人统计。整体气质为「林间暖光」——深墨绿主色配暖橙强调，模拟原生端侧的大标题导航栏、底部 TabBar、FAB、下拉刷新、模态弹窗、长按快捷菜单等交互语言。

## 二、色彩系统

| 角色 | 色值 | 用途 |
|------|------|------|
| 深墨绿 | `#1F4D3D` | 主色（导航、TabBar 选中、Hero） |
| 中绿 | `#3A8268` | 辅助绿、渐变 |
| 暖橙 | `#E8873B` | 强调色（CTA、FAB、进度） |
| 浅橙 | `#FBCC9E` | 暖色分区 |
| 米白 | `#F7F2E8` | 表面色/页面底 |
| 暖灰米 | `#E8DFCE` | 卡片次表面 |
| 羽灰 | `#6B7280` / `#9CA3AF` | 中性文字 |
| 深炭 | `#1F2937` | 标题正文 |
| 白 | `#FFFFFF` | 卡片/输入 |

每页有独立色彩主角：首页偏暖橙 Hero、图鉴偏米白底、详情偏深墨绿视差、个人页深墨绿 Hero+环形进度。

## 三、字体排印

- 标题：`Noto Serif SC`（500/700/900）——衬线，自然博物气质
- 正文：`Noto Sans SC`（300/400/500/700）

## 四、组件规范

- 圆角：卡片 16-20px，按钮 12px，标签 999px
- 阴影：`0 4px 16px rgba(0,0,0,0.05~0.1)`；TabBar/FAB 毛玻璃 `backdrop-filter: blur(12px)`
- 底部 TabBar：4 项，选中态暖橙+微动效
- FAB：悬浮操作按钮，呼吸脉冲

## 五、动效系统（12+ 组件级特效）

1. 自定义光标（阻尼跟随 + hover 放大 + 点击涟漪）
2. 羽毛飘落粒子
3. 数字 count-up 弹簧缓动
4. 卡片 hover 上浮
5. 声波条随机周期振动
6. 地图 Pin 脉冲发光
7. 按钮光泽扫过
8. Toast 弹跳入场
9. 模态弹入
10. Tab 下划线过渡
11. 下拉旋转指示器
12. FAB 呼吸脉冲

页面级签名动效：首页入场序列（Hero 渐入+卡片级联+数字计数）、详情页视差滚动+吸附标题栏+声波、个人页环形进度弹簧。

## 六、原生交互语言（6+ 种）

底部 TabBar（毛玻璃）、返回栈导航（侧滑转场）、下拉刷新弹性、FAB 悬浮按钮、模态弹窗（弹跳入场）、长按快捷菜单（底部 Sheet）、地图 Pin 脉冲+底部抽屉。

## 七、页面结构（8 页）

1. 首页今日观鸟（Hero+三格数据+横向记录+附近地点）
2. 鸟种图鉴（瀑布流双列+搜索+分类标签）
3. 鸟种详情（视差 Hero+毛玻璃吸附标题+声波+三栏切换+底部操作栏）
4. 新增观测记录（两步表单+步进器+地点卡+照片区+底部 CTA）
5. 观鸟地点（地图/列表双视图+脉冲标记+底部抽屉）
6. 个人中心（深墨绿 Hero+环形进度+四宫格+菜单）
7. 设计规范页
8. 接口文档页

# 拾光循环 · 设计规范

> 日期：2026-08-18 · 方向：V2 手机 UI · 形态：微信小程序 · 主题：社区旧物循环置换小程序

形态：微信小程序

## 色彩系统

复古绿 + 旧纸米 + 邮差橙 + 墨灰，辅以鼠尾草绿、芥子黄层次。无蓝紫渐变。

| 角色 | 色值 | 用途 |
|---|---|---|
| 主色 / 复古绿 | `#3E5C41` | 主品牌色、TabBar 选中、主按钮 |
| 深绿 | `#2A402D` | 深色面板、渐变深端 |
| 鼠尾草 | `#5A7A5D` / `#8AA68A` / `#B8D4B8` | 辅助层次、卡片描边 |
| 底 / 旧纸米 | `#F2EBDD` | 页面底色 |
| 浅米 | `#E5E0D5` / `#E0E5DA` / `#D5E0D5` | 卡片表面、分区底 |
| 强调 / 邮差橙 | `#D96C2C` | 强调按钮、标签、角标 |
| 暖橙 | `#E88B4E` / `#F0D8C8` | 渐变浅端、暖色分区 |
| 芥子黄 | `#C49A3D` | 次强调、进度 |
| 墨灰 | `#33352E` | 正文文字 |
| 砖红 | `#8B3A3A` / `#B9472E` | 警示、删除态 |
| 暗底 | `#0f0f0f` / `#1a1a1a` / `#2c2c2e` | 弹层遮罩、暗模式 |

## 字体

- 标题：`'Noto Serif SC', serif`
- 正文：`'Noto Sans SC', -apple-system, BlinkMacSystemFont, sans-serif`
- 等宽（编号/价格）：`'Courier New', monospace`

## 组件规范

- 圆角：卡片 `12-24px`，按钮 `10-14px`，胶囊 `50%`，顶部圆角 `20px 20px 0 0`
- 胶囊按钮导航栏（右上 ··· / ⊙），随页面透明 / 渐变 / 吸顶变色
- 底部 TabBar 4 项，选中态弹跳动效
- 半屏 ActionSheet、吸底操作栏、左滑操作、骨架屏

## 动效系统

12+ 组件级特效：

1. 自定义光标（双层环跟随，悬停放大变色，点击涟漪）
2. 首页入场序列动画
3. 详情页视差滚动
4. 个人页环形进度填充
5. 列表下拉弹性回弹
6. 邮戳印章盖印动画
7. 邮票旋转
8. TabBar 选中弹跳
9. 卡片悬停发光
10. 滚动渐入
11. 数字计数
12. 按钮涟漪

健壮性：RAF 随 `visibilitychange` 暂停、卸载取消；高频事件直操 DOM；JSX 全内联；支持 `prefers-reduced-motion`。

## 页面结构（8 页）

1. 漂流架首页（瀑布流 + 下拉刷新）
2. 分类页（吸顶 Tab + 筛选 chips）
3. 社区循环站页（Hero 视差 + 时间轴）
4. 个人中心页（环形进度 + 宫格菜单 + 悬浮按钮）
5. 物品详情页（画廊 + 吸底操作栏）
6. ActionSheet 半屏弹层
7. 设计规范页
8. API 接口文档页

端侧交互：胶囊导航栏、页面栈 push/pop 右滑返回、底部 TabBar、半屏 ActionSheet、下拉刷新弹性回弹、左滑操作、吸顶 Tab、吸底主按钮（≥4 种）。

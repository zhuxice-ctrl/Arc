# 点签 DianQian · 设计规范

> 形态：原生 App · 方向：V2 手机 UI · 日期：2026-08-19
> 主题：定向越野（Orienteering）训练伴侣

## 一、设计母题

把一次定向越野训练完整装进口袋：**领图 → 打点 → 交卷**。
设计语言来自定向运动独有的真实物件——IOF 国际定联五色地形图、点签器（打卡器）、打卡纸条。视觉不靠风格形容词，靠运动本身的地图语义与器械质感生长出来。

## 二、色彩系统（IOF 五色 + 动作色）

色彩承担地图语义与状态，不堆砌。每种主色都有明确用途：

| 色名 | 色值 | 语义 |
|------|------|------|
| 可跑树林白 | `#FFFFFF` | 通行无阻的林地（地图底色） |
| 植被绿 | `#7FB069` | 难通行植被；深绿 `#5B8C4A` 表最难通行 |
| 空旷地黄 | `#F5D97E` | 草地 / 开阔地 |
| 等高线棕 | `#B5793B` | 地形等高线、土崖、小丘 |
| 水系蓝 | `#4A7FA5` | 溪流、湖泊 |
| 岩石/人造黑 | `#2B2B2B` | 岩石、小径、人造物、正文墨色 |
| 检查点紫红 | `#B34A8C` | IOF 标准检查点圆圈、起点三角、终点双圈 |
| 动作色·指北针红 | `#D43D2A` | 主操作「点签」、指北针北针、当前目标脉冲 |
| 打卡纸米白 | `#FAF6ED` | 打卡纸条 / 成绩条卡片底 |

灰度审计：明度分层 白 > 黄 > 绿 > 棕 > 蓝 > 黑，删掉颜色后地图层级仍成立。禁蓝紫渐变。

## 三、字体系统

- 中文 UI：系统无衬线（PingFang SC / 苹方），标题 600、正文 400。
- 数字：等宽 `tabular-nums`（`font-variant-numeric: tabular-nums`）显示分段时间 `mm:ss`，保证位数对齐、滚动不抖。
- 比例尺 / 等高距 / 代号：小号等宽，呼应地图标注惯例。

## 四、信息架构

- **地图优先首页**：打开 App 第一眼是本周训练场地的 IOF 五色地图，不是问候语+搜索+Banner。
- **3 项底部工具条**（地图 / 历史 / 我的）：刻意避开通用 4-TabBar 模板。
- **页面栈 push/pop**：训练流程用栈导航（首页→打点→成绩），返回用左上 chevron + 手势。
- **半屏弹层**：检查点说明表从底部弹簧升起，可下滑关闭。

## 五、核心交互与签名动效

**签名交互——点签打卡瞬间**：
1. 按下「点签」按钮 → `pressing` 类按下回弹（scale 0.94 + translateY 4px）
2. 白闪 `punch-flash` + 指北针红 `compass-needle` 脉冲
3. Web Audio 1200Hz 正弦「嘀」声（0.12s 指数衰减）
4. 打卡纸条对应格 `punch-strip-cell` 加 `.done` → 针孔阵列（pinhole-grid）显现
5. 该分段时间实时写入成绩条预览，目标检查点光环移到下一个

**成绩条**：8 段分段时间条从左生长（`split-bar` width transition），最快分段绿、最慢分段棕红高亮。

**动效语言**：功能性弹簧反馈（原生 App 感）、纸张打孔顿感、时间条生长、页面栈横滑、半屏弹层弹簧升起。组件级动效 ≥10 个，全部服务打孔/计时/地图导航语义。无整图缩放 Ken Burns、无装饰粒子。

## 六、健壮性

- `visibilitychange`：页面隐藏时暂停计时器与 RAF，恢复时续算。
- `punchLock`：400ms 锁防连点叠加定时器。
- `prefers-reduced-motion`：全量降级（screen/sheet/split-bar/pinhole/btn-punch/compass/pulse/flash/toolbar/history-card 动画归零）。
- 零未定义引用、零外部依赖（系统字体 + Web Audio + 内联 SVG）。

## 七、状态设计

- 首次进入：地图首页 + 本周场地信息（场地/难度）+ 2 条示例历史
- 打点中：当前第几点 / 共 8 点、实时计时、目标代号、上一分段时长
- 完成：成绩条（总时长/平均/8 段 splits/最快最慢高亮）→ 保存写入 localStorage
- 历史：成绩条卡片列表，左滑删除，点开看分段详情
- 我的：累计训练次数、总打点数、最快单分段、本月热力小格

## 八、接口契约（假接口，/api/mobile/v2/*）

应用内接口文档页列出 4 个契约：场次列表、检查点说明、成绩上传、历史查询，均含 method/path/请求示例/响应示例 JSON。仅前端 mock，无真实后端。

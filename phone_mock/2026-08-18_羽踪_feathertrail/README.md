# 羽踪 · 观鸟记录原生 App UI

> 日期：2026-08-18 · 方向：V2 手机 UI · **形态：原生 App** · 主题：观鸟记录与自然探索 App

## 简介

「羽踪」是一款面向自然探索者的观鸟记录原生 App。在统一手机外壳内可切换 8 个页面：首页晨雾卡片流、鸟种图鉴瀑布流、观鸟记录时间线、鸟种详情（望远镜对焦转场）、观测点地图浮层、个人中心环形进度，以及设计规范页与接口文档页。配色取林间晨雾色系（墨绿+苔绿+雾灰+琥珀橙）。

## 动效亮点

- 羽毛振翅：下拉刷新弹性反馈 + 环形进度指针振翅摆动
- 望远镜对焦：详情页入场转场（圆形遮罩收缩 + 模糊→清晰）
- 环形观鸟进度：我的页羽毛指针沿圆周振翅推进
- 鸟鸣波纹：记录页麦克风按钮三层涟漪扩散
- 原生交互覆盖：底部 TabBar、大标题导航栏、返回栈、下拉刷新、FAB、底部半屏抽屉、模态弹窗、长按快捷菜单

# 设计规范 · 羽踪

> 日期：2026-08-18 · 方向：V2 手机 UI · **形态：原生 App** · 主题：观鸟记录与自然探索 App

## 色彩系统

主配色为林间晨雾色系，禁止蓝紫渐变。

| 角色 | 色值 | 用途 |
|------|------|------|
| 墨绿 | `#1E3A2F` | 主色、深色头部、TabBar 选中 |
| 苔绿 | `#6B8F71` | 辅助色、次级按钮、标签 |
| 雾灰 | `#D8DDD6` | 表面色、卡片底、分隔 |
| 琥珀橙 | `#E08A3C` | 强调色、FAB、进度高亮 |
| 奶白 | `#FAF7F0` | 页面底色、浅色卡片 |

扩展层次：深墨绿 `#2D4F3F` / `#2a3a2f`、浅苔 `#A8C4A8`、暖砂 `#F3EDE0` / `#F2C48A`、暮橙 `#E76F51` / `#E0553C` / `#C76A22`、金黄 `#E9C46A` / `#FFBD2E`、文字深灰 `#1a1a1a` / `#2a2a2a`、中性棕 `#8B7355`。每页有自己的"色彩主角"（首页偏墨绿晨雾、详情页偏暖橙对焦、我的页深色渐变头），整体统一在林间色系内。

## 字体

- `font-family: 'Noto Sans SC', -apple-system, system-ui, sans-serif`（全局统一中文无衬线栈）。

## 圆角与阴影

- 卡片圆角 16–20px，胶囊按钮 999px，底部抽屉顶部 24px。
- 阴影采用墨绿低透明叠加，营造卡片浮于雾面之上的层次。

## 页面结构（8 页）

1. 首页 — Hero 晨雾大图 + 视差滚动 + 下拉刷新（羽毛振翅弹性）+ 横向卡片流
2. 图鉴页 — 双列瀑布流 + 分类筛选胶囊条 + 长按快捷菜单（模态弹窗）
3. 记录页 — 时间线布局 + FAB + 底部半屏抽屉 + 鸟鸣波纹动效
4. 鸟种详情页 — Hero 视差大图 + 对角分割信息卡 + 毛玻璃导航 + 望远镜对焦转场
5. 观测点页 — 地图式顶图 + 定位 pin + 底部浮层卡片 + 横向轮播
6. 我的页 — 深色渐变头 + 环形观鸟进度（振翅羽毛指针）+ 成就网格拼贴
7. 设计规范页 — 色板 / 字体排印 / 组件示例 / 间距系统
8. 接口文档页 — 左右分栏 + 端点列表 + 请求/响应/参数 Tabs + 代码块

至少 5 个页面有独特非重复布局（瀑布流 / 时间线 / 对角分割 / 地图浮层 / 网格拼贴 / 左右分栏）。

## 原生交互（≥4 种）

底部 TabBar、大标题导航栏、返回栈导航、下拉刷新、FAB、底部半屏抽屉、模态弹窗、长按快捷菜单。

## 签名动效（≥2 页面级）

1. 羽毛振翅：下拉刷新弹性 + 环形进度指针振翅摆动
2. 望远镜对焦：详情页入场转场（圆形遮罩收缩 + 模糊→清晰）
3. 环形观鸟进度：我的页羽毛指针沿圆周振翅推进
4. 鸟鸣波纹：记录页麦克风按钮三层涟漪扩散

## 健壮性

- 所有定时器统一管理并在卸载时清理；RAF 按页面可见性暂停。
- 支持 `prefers-reduced-motion` 降级。
- 全部 JSX 内联于 index.html 的 `<script type="text/babel">`。

## 技术栈

React 18 + Babel Standalone（JSX 内联），单文件 HTML + components/ios-frame.jsx（已内联进 index.html）。

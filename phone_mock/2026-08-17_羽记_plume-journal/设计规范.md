# 羽记 · 观鸟微信小程序 设计规范

> 形态：微信小程序 · 方向：V2 手机 UI · 日期：2026-08-17 · 主题：观鸟记录与鸟类图鉴

## 色彩系统

晨光林间感：苔绿主调 + 米白底 + 赭橙强调，各页在体系内做色调层次偏移。

| 角色 | 色值 | 用途 |
|---|---|---|
| 苔绿（主色） | `#5DA87A` / `#4A8C66` | 主交互色、TabBar 选中、按钮 |
| 深苔绿 | `#3D7155` / `#2D533F` | Header、深色区块、强调 |
| 米白（底） | `#FAF7F0` / `#E6F2EA` | 页面背景、卡片底 |
| 赭橙（强调） | `#ED9539` / `#B5651D` / `#D47F2A` | Banner、点赞、强调标记 |
| 暖底 | `#FDF0D8` / `#FCE4EC` | 浅色分区、暖色卡片 |

## 字体

- 标题：Noto Serif SC（思源宋体），自然人文气质
- 正文：Noto Sans SC（思源黑体）
- 装饰：ZCOOL KuaiLe（站酷快乐体），用于趣味标签

## 小程序端侧交互（7 种）

1. 页面栈 push/pop 右滑返回手势感
2. 底部 TabBar（选中弹跳 + 小圆点微动效）
3. 半屏弹层 / Bottom Sheet 动作面板
4. 下拉刷新弹性回弹
5. 左滑列表操作
6. 吸顶筛选 Tab
7. 骨架屏 shimmer 加载

## 组件级特效（12+）

打字机光标、数字计数、涟漪点击、卡片入场序列、光泽扫过、环形进度描边、脉冲光环、骨架屏 shimmer、鸣声频谱波形、地图标记呼吸、Tab 下划线弹性、头像脉冲浮动。

## 健壮性

- 全部动效基于 requestAnimationFrame，随 visibilitychange 自动暂停
- 支持 prefers-reduced-motion
- 高频事件直接操作 DOM，避免 React 重渲染

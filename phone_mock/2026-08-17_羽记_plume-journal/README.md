# 羽记 · 观鸟微信小程序

> 日期：2026-08-17 · 方向：V2 手机 UI · 形态：微信小程序 · 主题：观鸟记录与鸟类图鉴

## 简介

一款观鸟记录与鸟类图鉴微信小程序，套在统一手机外壳内，含自定义导航栏 + 胶囊按钮。8 个页面覆盖首页记录流、鸟类图鉴瀑布流、鸟类详情（含鸣声频谱）、观鸟点地图、鸟友动态、个人观鸟档案，另含设计规范页与接口文档页。苔绿 + 米白 + 赭橙的晨光林间配色，每页布局差异化。

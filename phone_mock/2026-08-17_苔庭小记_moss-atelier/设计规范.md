# 苔庭小记 · 苔藓微景观手作工坊小程序 — 设计规范

> 方向：手机 UI（V2） · 日期：2026-08-17 · 形态：微信小程序 · 主题：苔藓微景观手作工坊

形态：微信小程序

## 色彩系统（苔庭植物体系）

| 角色 | 色值 | 用途 |
|------|------|------|
| 深苔绿 | `#3d5a3f` | 主色、导航栏、主按钮 |
| 苔绿 | `#5a7d52` / `#8aa88a` | 次级强调、Tab 选中 |
| 雾灰绿 | `#c4d4c0` / `#d8ddd6` / `#e8ede5` | 表面色、卡片底、分隔 |
| 陶土棕 | `#d4a574` / `#b87a56` / `#c2672e` | 辅助强调、价格、标签 |
| 米白 | `#faf6ef` / `#fdfaf3` / `#f5efe4` | 页面背景 |
| 暖橙 | `#e07856` / `#fff1e6` | 警示 / 提示 |
| 墨黑 | `#1a1a1a` | 正文 |

每页色彩主角：首页苔绿、商城雾灰绿瀑布流、社区米白卡片流、详情陶土棕视差、个人深绿渐变。整体统一在苔庭植物体系内，禁蓝紫渐变。

## 字体

- 标题：`'Noto Serif SC', serif`（衬线，文艺手作感）
- 正文：`'Noto Sans SC', -apple-system, BlinkMacSystemFont, sans-serif`
- 装饰：`'Ma Shan Zheng', cursive`（书法品牌字）
- 等宽：`monospace`（接口文档代码）

## 组件规范

- 自定义导航栏：胶囊按钮（··· / ⊙）+ 随页面透明/渐变/吸顶变色
- 底部 TabBar：4 项，选中态弹性下划线 + 微动效
- 课程卡：圆角 16px + 阴影分层 + 图片弹性拉伸
- 商品瀑布流卡：双列错位 + 吸顶筛选 Tab
- 吸底操作栏：底部安全区主按钮 + 模糊背景
- ActionSheet：底部半屏弹层 + 蒙版淡入 + 滑入
- 环形进度：个人中心收藏进度环

## 小程序端侧交互（≥4 种）

页面栈 push/pop 右滑返回感、底部 TabBar（选中弹性动效）、下拉弹性刷新（苔藓生长动效）、底部 ActionSheet、吸顶筛选 Tab、详情页吸底操作栏、骨架屏类名。

## 动效系统（12+ 组件级特效）

1. 孢子飘散粒子（首页入场）
2. 晨露滴落物理模拟（详情页）
3. 点赞弹跳
4. Tab 切换下划线弹性
5. 按钮 hover 上浮
6. 卡片图片缩放
7. 环形进度动画
8. 下拉苔藓生长
9. 入场序列 stagger
10. 视差滚动
11. 自定义光标弹簧跟随 + 涟漪
12. 苔藓图片弹性拉伸

## 页面结构（8 页）

1. 首页 — Hero 大图 + 入场序列 + 孢子飘散 + 分类宫格 + 横滑课程卡 + 双列商品网格 + 社区热帖
2. 苔材商城 — 瀑布流 + 吸顶筛选 Tab + 下拉弹性刷新
3. 社区 — Hero 头图 + 吸顶 Tab + 多图卡片流 + 悬浮发布球
4. 个人中心 — 渐变背景 + 环形收藏进度 + 宫格 + 学习进度条
5. 课程详情 — 视差滚动 + 晨露滴落 + 时间轴 + 吸底预约栏
6. 预约 ActionSheet — 底部半屏弹层
7. 设计规范页 — 色板 + 字体 + 间距 + 组件样例
8. 接口文档页 — 6 个 REST API + 可展开详情 + 语法高亮

## 健壮性

- visibilitychange 自动暂停 RAF/定时器，卸载统一 cancel
- reduced-motion 降级
- 光标直接操作 transform 不 setState
- 无外部 JSX 引用，全部内联

# 环线 Loopline · 设计规范

> 日期：2026-08-17 ｜ 方向：V2 手机 UI ｜ 形态：原生 App ｜ 主题：城市骑行路线社区 App

## 色彩系统

| 角色 | 色值 | 用途 |
|---|---|---|
| 主色 | `#FF5C1A` | 信号橙，CTA / 主强调 / 选中态 |
| 主色亮 | `#FF7A3D` | 悬停 / 渐变亮端 |
| 深底 | `#1E222B` | 沥青深灰，深色区块 / 导航栏 |
| 更深 | `#14171E` / `#0a0c10` | 极深底色层级 |
| 表面色 | `#F4F2ED` | 晨雾白，主背景 |
| 强调黄 | `#F2C230` | 赛道黄，徽章 / 数据高亮 |
| 黄亮 | `#FFD84D` / `#D4A920` | 黄色层级 |
| 文字白 | `#fff` / `#2E3238` | 深底白字 / 浅底深字 |
| 语义绿 | `#4CAF50` / `#81C784` | 完成 / 成功 |
| 语义红 | `#F44336` / `#EF5350` | 警示 / 难度 |

配色为运动系（信号橙 + 沥青深灰 + 晨雾白 + 赛道黄），无蓝紫渐变。每页色彩主角差异化：首页偏暖橙、运动数据页深色高对比、详情页暖橙 Hero、我的页浅底暖调。

## 字体

- `'Inter', -apple-system, BlinkMacSystemFont, sans-serif` — 正文 / UI
- `'Space Grotesk', sans-serif` — 数字 / 标题
- `'JetBrains Mono', monospace` — 代码 / 接口文档

## 圆角与间距

- 圆角：卡片 `16px`，按钮 / Chips `12px` / `14px`，深色头部底圆角 `32px`
- 间距刻度：8 / 12 / 16 / 20 / 24 / 32 px

## 组件规范

- 底部 TabBar：5 项含中心 FAB 凸起按钮，选中态微动效
- 大标题导航栏：滚动时收缩为标准导航
- 路线卡：信号橙难度标签 + 光泽扫过 hover + 距离 / 爬升 / 用时数据
- 环形进度条：弹簧物理动画
- 柱状图：从 0 展开入场
- 模态底部抽屉：从底部滑入 + 背景模糊
- 下拉刷新指示器：弹簧缩放 + 旋转

## 原生端侧交互（≥4 种）

底部 TabBar（含中心 FAB 凸起）、大标题导航栏 + 返回栈导航、模态底部抽屉、下拉刷新、瀑布流信息流、悬浮操作按钮 FAB、卡片 3D 倾斜跟随。

## 动效系统（12+）

1. 自定义光标（白环 + 橙色内点 + 多层发光 + hover 形变 + 点击涟漪）
2. iOS 设备外壳 3D 鼠标倾斜跟随
3. 弹簧物理数字计数器
4. 环形进度条动画（弹簧物理）
5. 打字机效果（首页 Hero 副标）
6. 路径绘制动画（路线详情 SVG 轨迹）
7. 粒子上升（首页 Hero）
8. 光泽扫过（路线卡 hover）
9. 卡片入场序列动画（延迟错位 fade-in-up）
10. 下拉刷新指示器（弹簧缩放 + 旋转）
11. 柱状图入场动画
12. 底部骑行模式模态弹窗（底部滑入 + 背景模糊）

## 页面结构（8 页）

首页（Hero + 数据 + 横滚路线卡 + 动态流）→ 探索（搜索 + Chips + 瀑布流 Masonry）→ 路书（列表卡片 + 难度标签）→ 路线详情（Hero 大图 + 轨迹绘制 + FAB）→ 运动数据（深色头 + 环形进度 + 柱状图）→ 我的（Banner + 成就宫格）→ 设计规范 → 接口文档。至少 5 个页面布局非重复。

## 健壮性

visibilitychange 自动暂停 / 恢复 RAF；reduced-motion 降级；mousemove 直操作 DOM transform；定时器重建前清除；零未定义引用。

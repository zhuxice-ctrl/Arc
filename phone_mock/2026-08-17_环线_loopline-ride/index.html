接口文档
REST API v2.0

Loopline Open API

城市骑行路线与运动数据接口，支持路线搜索、骑行记录、用户数据等核心能力。

GET /api/v2/routes
获取路线列表，支持按距离、难度、地区等条件筛选。
Query Parameters
  • city
    城市名称，如 上海市
    string
  • distance_min
    最小距离 km
    number
  • difficulty
    难度等级
    enum
Response
"routes": [ { "id": "rt_001", "name": "外滩晨曦环线", "distance": 18.4, "elevation": 86, "difficulty": "medium" } ]
GET /api/v2/routes/:id
获取单条路线的详细信息，包括轨迹点、路书、评价等。
Path Parameters
  • id
    路线唯一标识
    string
POST /api/v2/rides/start
开始一次新的骑行记录，返回 ride_id 用于后续上报位置。
Request Body
{ "route_id": "rt_001", "start_time": "2026-08-17T06:23:00Z", "device": "iPhone 15 Pro" }
PUT /api/v2/rides/:id/track
实时上报骑行轨迹点，支持批量上传。
POST /api/v2/rides/:id/finish
结束骑行并生成完整记录。
GET /api/v2/users/:id/stats
获取用户运动统计数据，支持周/月/年维度。
DELETE /api/v2/rides/:id
删除一条骑行记录。

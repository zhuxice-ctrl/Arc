# 麦芽笔记 · 设计规范

**形态：原生 App**

## 品牌理念

麦芽笔记是一款专注于精酿啤酒品鉴的移动应用。我们相信每一杯精酿都有故事，每一次品鉴都值得被认真记录。设计语言围绕「温暖、醇厚、有质感」展开，如同一杯精心酿造的啤酒。

## 六、动效规范 Motion

### 缓动函数

| 名称 | 曲线 | 场景 |
|------|------|------|
| 标准缓动 | `cubic-bezier(0.22, 1, 0.36, 1)` | 页面切换、卡片展开、列表动画 |
| 弹性缓动 | `cubic-bezier(0.34, 1.56, 0.64, 1)` | 按钮点击、星星评分、气泡弹出 |
| 渐入渐出 | `ease-in-out` | 颜色过渡、透明度变化 |

### 时长规范

| 时长 | 用途 |
|------|------|
| 150ms | 微交互（按钮状态、图标切换） |
| 300ms | 标准过渡（页面元素、Tab 切换） |
| 450ms | 页面转场（push/pop 导航） |
| 600ms | 弹性动画（下拉回弹、弹出） |
| 1.5s+ | 氛围动效（粒子、脉冲、光泽） |

### 动效原则

1. **物理感**：所有动效模拟真实物理规律，不做整图缩放
2. **节奏感**：不同元素动效周期不同，避免整齐划一
3. **克制使用**：动效服务于内容，不为动而动
4. **可降级**：支持 `prefers-reduced-motion` 媒体查询

## 七、组件规范 Components

### 按钮 Button

**主按钮 Primary**
- 背景：`var(--roast-700)`
- 文字：`var(--foam-50)` / 600
- 圆角：16px
- 内边距：16px 24px
- 阴影：`0 8px 24px rgba(46,31,19,0.3)`

**琥珀按钮 Amber**
- 背景：`var(--amber-500)`
- 文字：`var(--roast-900)` / 600
- 圆角：100px（胶囊）
- 阴影：`0 4px 20px rgba(224,146,60,0.4)`

**次级按钮 Secondary**
- 背景：透明
- 边框：1px `var(--roast-300)`
- 文字：`var(--roast-700)` / 500

### 卡片 Card

- 背景：`#fff`
- 圆角：16px / 20px
- 阴影：`0 2px 12px rgba(26,15,8,0.06)`
- 内边距：14-20px

### 标签 Tag/Chip

- 胶囊形状（100px 圆角）
- 内边距：4px 14px / 6px 14px
- 三种风格：琥珀色、啤酒花绿、中性灰

### 输入框 Input

- 背景：`var(--foam-100)`
- 圆角：12px
- 内边距：10px 14px
- 占位符色：`var(--roast-400)`

## 十、无障碍 Accessibility

- 正文文字最小 11px（标注级）
- 可点击区域最小 44x44px
- 支持动态字体大小
- 支持 `prefers-reduced-motion` 降级动效
- 色彩对比度符合 WCAG AA 标准

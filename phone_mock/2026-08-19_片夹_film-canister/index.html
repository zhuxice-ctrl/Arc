接口文档
说明：本 App 数据存储于 localStorage，接口仅作数据契约文档。所有请求均为本地模拟。
GET /api/film/list
获取所有胶卷列表，按状态分组（在拍 / 待冲扫 / 已归档）。
Response
{ "code": 0, "data": [ { "id": "film_001", "name": "Kodak Portra 400", "iso": 400, "total": 36, "shot": 14, "status": "shooting", "type": "color", "loadedAt": "2026-08-15T09:30:00Z", "frames": [ { "num": 1, "aperture": "f2.8", "shutter": "1/250", "note": "巷口的猫", "timestamp": "2026-08-15T10:15:00Z" } ] } ] }
GET /api/film/:id
获取单卷胶卷详情，包含所有张次记录。
Response
{ "code": 0, "data": { "id": "film_001", "name": "Kodak Portra 400", "iso": 400, "total": 36, "shot": 14, "status": "shooting", "type": "color", "loadedAt": "2026-08-15T09:30:00Z", "frames": [...] } }
POST /api/film/load
装入新胶卷（创建一卷新的在拍胶卷）。
Request
{ "name": "Kodak Portra 400", "iso": 400, "total": 36, "type": "color" }
Response
{ "code": 0, "data": { "id": "film_002", "name": "Kodak Portra 400", "iso": 400, "total": 36, "shot": 0, "status": "shooting", "loadedAt": "2026-08-19T14:00:00Z", "frames": [] } }
POST /api/film/:id/frame
记录一张拍摄参数（过片后调用）。
Request
{ "num": 15, "aperture": "f4.0", "shutter": "1/125", "note": "午后的咖啡馆" }
Response
{ "code": 0, "data": { "num": 15, "aperture": "f4.0", "shutter": "1/125", "note": "午后的咖啡馆", "timestamp": "2026-08-19T15:30:00Z" } }
POST /api/film/:id/rewind
回卷封卷，状态从 shooting 转为 developing（待冲扫）。
Response
{ "code": 0, "data": { "id": "film_001", "status": "developing", "developStatus": "pending", "pickupCode": null, "rewoundAt": "2026-08-20T11:00:00Z" } }
GET /api/film/:id/develop
获取冲扫进度。三态：pending（待寄出）/ processing（冲洗中）/ done（已完成）。
Response
{ "code": 0, "data": { "filmId": "film_001", "status": "processing", "stages": [ { "key": "sent", "label": "已寄出", "done": true, "time": "08-18 10:00" }, { "key": "received", "label": "工作室签收", "done": true, "time": "08-19 14:30" }, { "key": "developing", "label": "冲洗中", "done": false, "active": true }, { "key": "scanning", "label": "扫描归档", "done": false }, { "key": "done", "label": "可取件", "done": false } ], "pickupCode": "PJ-7824", "estimatedAt": "2026-08-22" } }
PUT /api/film/:id/develop/complete
标记冲扫完成，胶卷状态转为 archived（已归档）。
Response
{ "code": 0, "data": { "id": "film_001", "status": "archived", "archivedAt": "2026-08-22T16:00:00Z" } }
DELETE /api/film/:id
删除一卷胶卷及其所有张次记录。
Response
{ "code": 0, "message": "删除成功" }

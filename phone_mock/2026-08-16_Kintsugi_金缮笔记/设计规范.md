# Kintsugi 金缮笔记 · 设计规范

> 2026-08-16 · V2 · 手机应用 UI

形态：原生 App

## 主题

日本金缮修复哲学为灵感的器物修复日记 App

## 配色

漆黑 #1a1a1a + 金缮金 #d4a946 + 胡粉白 #f5f0e6

（严格禁蓝紫渐变）

## 字体

Noto Serif SC + Inter + JetBrains Mono

## 动效设计

金缮描金 SVG 路径生长 / 金粉粒子背景 / 自定义光标 / 裂纹金线生长

## 技术实现

- 单文件 HTML 实现（CSS + JS 全内联）
- 自定义光标开页即居中显示
- RAF 统一管理，visibilitychange 自动暂停/恢复
- 支持 prefers-reduced-motion 降级
- 无外部 JSX 引用，无外部本地文件依赖

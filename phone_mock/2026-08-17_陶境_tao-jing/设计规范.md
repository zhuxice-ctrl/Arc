## 原生交互模式（7 种）

1. 底部 TabBar（5 项，选中态弹性缩放微动效）
2. 返回栈导航（push/pop 转场）
3. 模态底部抽屉（半屏弹层）
4. 下拉刷新（弹性回弹）
5. 长按快捷菜单
6. FAB 悬浮操作按钮（旋转展开）
7. 全屏详情页转场

## 页面结构（8 页，≥5 独特布局）

1. **首页** — Hero 大卡片 + 分类 chip + 横向工坊卡 + 网格拼贴灵感卡（下拉刷新 + 入场序列）
2. **发现** — 搜索栏 + 瀑布流作品卡（长按快捷菜单）
3. **作品** — 深色画廊网格 + 筛选 filter
4. **我的** — 苔绿 hero + 环形进度（签名动效）+ 菜单列表
5. **工坊详情** — Hero 大图视差滚动（签名动效）+ 课程选择 + 吸底 CTA
6. **作品详情** — 全屏转场 + 点赞收藏
7. **设计规范** — 色彩 / 字体 / 间距 / 圆角 / 组件系统
8. **接口文档** — 深色代码风 + REST API 列表 + 请求响应示例

## 动效系统（15+）

首页入场序列、环形进度动画、下拉弹性、视差滚动、Tab 切换弹性缩放、卡片悬停上浮、Chip 选中位移、FAB 旋转展开、菜单弹出、点赞波纹、Toast 弹出、按钮按压缩放、骨架屏 shimmer、指针跟随缓动、长按菜单回弹。

自定义光标：开页居中显示，高对比白色粗环 + 彩色内点 + difference 混合，hover 放大、点击涟漪。RAF 由 `visibilitychange` 暂停 / 恢复；`prefers-reduced-motion` 降级。

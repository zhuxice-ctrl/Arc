# 银盐公社 · 设计规范

形态：微信小程序

## 主题
胶片摄影社群 + 胶片冲扫服务的微信小程序。炭黑 + 暗房安全灯红 + 米白 + 银灰的暗房美学，手机外壳内 8 页可切换。

## 色彩系统

| 角色 | 色值 | 用途 |
|---|---|---|
| 炭黑 | `#141210` | 主底色、深色块 |
| 极黑 | `#0a0908` | 暗房氛围底、Hero |
| 深炭 | `#2A2622` / `#1f1c19` / `#3a3530` | 卡片表面、分层 |
| 暗房安全灯红 | `#E8513D` | 主强调、选中态、CTA |
| 红亮 | `#f58a7a` / `#f06b58` | 高亮、悬停 |
| 红深 | `#d23a2a` | 按下加深 |
| 米白银 | `#F3EFE9` | 正文文字、浅底 |
| 暖米 | `#faf7f2` / `#f5f1eb` | 最浅表面 |
| 银灰 | `#B8AFA1` | 次级文字、边线 |
| 暖橙 | `#f2a734` | 辅助强调、标签 |
| 薄荷绿 | `#98c379` | 状态成功 |
| 沙金 | `#d19a66` | 装饰金 |

每页使用 3-5 个色调层次，各页有独立"色彩主角"（首页偏暖红、图鉴页偏银灰、个人页高对比）。

## 字体
- 展示：思源宋体 / Noto Serif SC（胶片质感）
- 正文：思源黑体 / Noto Sans SC
- 数据：JetBrains Mono / 等宽

## 页面结构（8 页）
| 页 | 布局特色 |
|---|---|
| 01 首页发现 | Hero 大图入场 + 胶卷卷轴分类 + 瀑布流卡片 + 下拉刷新弹性 |
| 02 冲扫服务 | 暗房红光氛围 + 工艺三列卡片 + 门店横列 + ActionSheet |
| 03 相机图鉴 | 对角分割卡片 + 吸顶筛选 Tab |
| 04 作品详情 | 胶片齿孔装饰 + 视差滚动（签名动效）+ EXIF 九宫格 + 吸底操作栏 |
| 05 社区活动 | 红 Hero + 轮播画廊 + 话题网格拼贴 |
| 06 个人中心 | 头像光环旋转 + 环形进度（签名动效）+ 宫格菜单 + 悬浮球 |
| 07 设计规范 | 色板/字体/间距/按钮/圆角五段 |
| 08 接口文档 | 终端风格 REST API，4 端点可折叠 |

## 小程序端侧交互（6 种）
页面栈 push/pop 右滑返回、底部 TabBar（5 个，选中弹跳）、半屏 ActionSheet、下拉刷新弹性回弹、吸顶 Tab、吸底操作栏。

## 动效系统（12+ 项）
Hero 入场序列、暗房安全灯脉冲、瀑布流错峰入场、Tab 弹跳、工艺卡片顶边伸缩、相机卡图片放大、点赞粒子飘散、头像光环旋转、环形进度填充、悬浮球旋转、列表项滑入、轮播指示器。

## 健壮性
- 所有定时器/RAF 随 `visibilitychange` 自动暂停，卸载统一清理
- 支持 `prefers-reduced-motion`
- JSX 全部内联于 index.html，无外部 src 引用
- 自定义光标：白环 + 安全灯红内点 + 双层发光，开页居中显示

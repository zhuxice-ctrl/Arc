## 页面结构（8 页）

1. **首页** — Hero 大图 + 浮动叶片签名动效 + 瀑布流卡片 + 分类 chips + 故事横幅
2. **分类页** — 吸顶筛选 Tab + 左右双列分类卡片 + 搜索框
3. **商品详情** — 轮播画廊 + 底部吸底操作栏 + 尺码选择
4. **个人中心** — 深酒红 Hero + 悬浮数据卡 + 会员渐变卡 + 宫格菜单
5. **店铺故事** — Hero 大图 + 章节叙事 + 引言卡片 + 时间轴
6. **设计规范** — 色板 + 字体 + 间距 + 组件展示
7. **接口文档** — RESTful 接口列表 + 响应示例 + 错误码表
8. **会员中心** — 成长进度卡 + 权益网格 + 积分渐变卡

## 布局多样性

至少 5 种独特布局：瀑布流（首页）、双列分类卡（分类页）、轮播+吸底栏（详情页）、Hero+时间轴（故事页）、宫格+数据卡（个人中心）。

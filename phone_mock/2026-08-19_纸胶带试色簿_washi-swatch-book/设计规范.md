# 纸胶带试色簿 · 设计规范

## 一、设计母题

纸胶带试色簿——一个纸胶带收藏试色手账微信小程序。用户像在文具店拉出一卷胶带试色：从卷轴拉出胶带条、释放时撕断（纤维毛边）、胶带条落入试色卡、标记色系/图案/品牌/宽度、归入色卡簿、按色系浏览、多条胶带拼贴到手账预览页。

视觉来源：文具店的胶带展示墙 + 手账拼贴本。空间逻辑：工作台式（首屏胶带拉拽区）→ 收藏册式（色卡簿网格）→ 拼贴台式（手账预览）。

## 六、签名动效系统

### 1. 胶带拉出（核心签名交互）
- 触发：按住卷轴拖拽（touch/mouse）
- 行为：胶带条随拖拽方向延伸，卷轴同步旋转放卷（`rollRotation = (len / 10) * 360 / (2π × 75)`）
- 拖拽距离 < 40px：弹性回弹收回（`cubic-bezier(0.34, 1.56, 0.64, 1)`）

### 2. 撕断纤维毛边
- 触发：释放拖拽且距离 ≥ 40px
- 行为：撕断边缘显现（`tape-tear-edge.show`），8 个纤维粒子飞散
- 粒子颜色取自当前胶带色系，随机角度/距离飞散后渐隐

### 3. 胶带落卡
- 撕断后 150ms 延迟，胶带条弹性落入试色卡区域
- 半屏弹层滑出，展示色系选择器

### 4. 半屏弹层
- 从底部滑入（`bottom: -100%` → `0`，`cubic-bezier(0.4, 0, 0.2, 1)` 350ms）
- 遮罩层渐显（`rgba(0,0,0,0)` → `0.4`）

### 5. 下拉刷新
- 拖拽超过阈值触发，卷轴图标旋转
- 刷新完成 Toast 提示

### 6. 页面栈转场
- 二级页面从右侧滑入（`translateX(100%)` → `-100%`，350ms）
- 返回时反向滑出

### 7. TabBar 切换
- 颜色过渡 200ms，激活态描边加粗

### 减少动效
```css
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after { animation-duration: 0.01ms !important; transition-duration: 0.01ms !important; }
}
```

## 十、技术栈

- 纯 vanilla 单文件 HTML（无 React/Babel/CDN）
- 内联 CSS + 内联 JS
- 无外部图片/字体/API 依赖
- 支持 `prefers-reduced-motion`
- `visibilitychange` 暂停交互状态
- 文件大小：~84KB

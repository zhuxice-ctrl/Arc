接口文档
GET /api/swatches
获取当前用户的全部试色卡列表，支持按色系筛选。
Query 参数
参数类型说明
familystring色系筛选，可选值 red/orange/yellow/green/blue/purple/brown/gray
pagenumber页码，默认 1
pageSizenumber每页数量，默认 20
POST /api/swatches
新增一张试色卡。传入胶带 ID 与色系分类。
Body 参数
参数类型必填说明
tapeIdstring是胶带唯一标识
familystring是色系分类
widthnumber否宽度，单位 mm
notestring否备注文字
DELETE /api/swatches/:id
删除指定试色卡。左滑删除操作调用此接口。
Path 参数
参数类型说明
idstring试色卡 ID
GET /api/tapes
获取全部胶带款式列表，含图案、品牌、宽度规格。
返回字段
字段类型说明
idstring胶带 ID
namestring胶带名称
patternstring图案类型 CSS class
widthnumber宽度 mm
brandstring品牌
familystring默认色系
POST /api/collages
保存拼贴方案，含各胶带位置、旋转角度与层级。
Body 参数
参数类型说明
tapesarray胶带实例数组，每项含 id/x/y/rotation/zIndex
namestring拼贴方案名称

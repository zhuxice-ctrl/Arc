# 设计规范 — Vinyl Arc 黑胶收藏 App

> 手机应用 UI · 2026-08-16

## 设计基调

复古暖调的黑胶收藏与播放体验。整套配色为暖棕陶土 + 深棕底 + 奶白文字，无任何蓝紫渐变。所有签名动效基于物理逻辑实现（黑胶旋转、唱针摆动、3D 倾斜），非简单缩放。

## 字体

系统字体栈（-apple-system / PingFang SC），数字与标签使用等宽字体增强复古感。

## 组件规范

- **黑胶组件**：圆形封面 + 中心标签 + 旋转动画，hover 时从封套露出
- **唱针**：平滑摆动入场，悬停可交互元素时放大
- **曲目列表**：按 Side A / B 分组，交错入场动画
- **Mini Player**：底部悬停弹出，进度条实时推进
- **iPhone 外壳**：统一设备框架，8 屏内可切换
- **Tweaks 面板**：底部调试面板，可调强调色 / 风格主题 / 唱片旋转开关

## 页面结构（8 屏）

1. 首页·收藏
2. 发现页
3. 唱片详情（大封面视差头图 + 按 Side 分组曲目）
4. 全尺寸播放器
5. 动态时间线
6. 个人中心
7. 设计规范
8. 接口文档（8 个 REST 端点）

## 签名动效

- 全尺寸播放器：黑胶持续旋转 + 唱针平滑摆动入场
- 唱片卡片：3D 倾斜跟随鼠标，hover 时黑胶从封套露出
- 唱针式自定义光标：内环精准点 + 外环缓动跟随，初始即显示在屏幕中央
- 列表交错入场、Mini Player 悬停弹出、进度条实时推进、Toast 提示

## 技术栈

React (JSX) · 纯前端 · localStorage 持久化。需妙搭运行时渲染，独立 HTML 无法直接预览，请通过在线预览链接浏览。

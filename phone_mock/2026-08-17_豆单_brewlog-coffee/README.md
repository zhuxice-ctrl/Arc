# 豆单 BrewLog · 手冲咖啡 · 手机 UI

> 日期：2026-08-17 · 方向：V2 手机 UI · 形态：微信小程序 · 主题：手冲咖啡笔记小程序

![预览](./thumbnail.png)

## 简介

「豆单 BrewLog」是精品咖啡领域的微信小程序，面向手冲咖啡爱好者。功能含首页豆单卡片流、冲煮记录（粉水比/水温/研磨度/冲煮时间线）、杯测笔记（风味轮/评分）、探店地图、个人中心（冲煮统计），另含设计规范页与接口文档页，共 8 页。深焙棕 + 焦糖 + 奶泡米白 + 生豆绿的咖啡色系，每页有独立色彩主角。

## 形态

微信小程序：胶囊按钮 + 自定义导航栏、底部 TabBar、页面栈 push/pop、半屏 ActionSheet、下拉刷新弹性、左滑列表删除、吸顶 Tab、吸底安全区按钮（共 6 种端侧交互）。

## 动效亮点

- 自定义光标：白环 + 焦糖内点 + 多层发光，开页居中，hover 放大 / 点击三态
- 首页蒸汽升腾 + 打字机副标题 + 入场错峰序列
- 冲煮页圆环计时器 + 脉冲 + 数字计数
- 杯测页 SVG 风味轮扇区悬停 + 评分条滑动
- 详情页视差滚动 + 光泽扫过吸底栏

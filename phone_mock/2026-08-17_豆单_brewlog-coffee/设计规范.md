# 设计规范 · 豆单 BrewLog · 手冲咖啡

> 日期：2026-08-17 · 方向：V2 手机 UI · 形态：微信小程序 · 主题：手冲咖啡笔记小程序

## 形态说明

本版为**微信小程序**形态：页面运行于带胶囊按钮（右上角 ··· / ⊙）的自定义导航栏之下，整体套在统一手机外壳内；采用页面栈 push/pop、底部 TabBar、半屏 ActionSheet、下拉刷新弹性回弹、左滑列表操作、吸顶 Tab、吸底安全区按钮等小程序端侧交互。

- 正文：`'Noto Sans SC', -apple-system, BlinkMacSystemFont, 'PingFang SC', sans-serif`

- 数据/代码：`'SF Mono', Menlo, monospace`

## 小程序端侧交互（6 种）

1. 胶囊按钮 + 自定义导航栏（随页面透明/渐变/吸顶变色）
2. 底部 TabBar（2–5 项，选中态微动效 + 指示点）
3. 页面栈 push/pop（右进切换 + 右滑返回手势感）
4. 半屏 ActionSheet 动作面板
5. 下拉刷新弹性回弹 + 左滑列表删除
6. 吸顶 Tab + 吸底安全区主按钮

## 组件规范

- **首页**：深色 Hero + 蒸汽动画入场，横滑豆单卡片流，快捷入口宫格，冲煮日记列表（左滑删除）
- **冲煮页**：中心圆环计时器 + 脉冲，四段注水步骤进度，三参数卡
- **杯测页**：SVG 风味轮六段扇区 + 中心总分计数，6 维评分条
- **探店页**：Hero 大图 + 吸顶筛选 Chip + 双列瀑布流
- **个人中心**：生豆绿顶部，悬浮统计面板（数字计数 + 环形进度），宫格 + 列表
- **咖啡豆详情**：大图视差 + 三栏吸顶 Tab + 吸底操作栏（光泽扫过）
- **设计规范页**：色板 + 字体排印 + 组件 + 间距圆角
- **接口文档页**：暗色顶 + 吸顶分类 Tab + 可折叠接口 + 代码高亮

## 动效系统（12+ 组件级特效）

自定义光标（白环+焦糖内点+多层发光+涟漪+hover 放大+点击三态）、蒸汽升腾、打字机副标题、圆环进度+脉冲、数字计数、风味轮扇区悬停、卡片 3D 悬停抬起、光泽扫过、入场错峰序列、视差滚动、评分条滑动、环形进度描边。

## 健壮性

RAF/定时器随 `visibilitychange` 暂停、卸载取消；高频 mousemove 直接操作 DOM；支持 `prefers-reduced-motion`；JSX 全部内联于 `<script type="text/babel">`。

## 技术栈

单文件 HTML + 内联 CSS + 内联 Babel/React JSX（手机外壳内多页面切换）。

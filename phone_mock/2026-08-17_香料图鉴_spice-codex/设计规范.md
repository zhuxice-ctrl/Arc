# 香料图鉴 Spice Codex · 设计规范

> 日期：2026-08-17 ｜ 方向：V2 手机 UI ｜ 形态：微信小程序 ｜ 主题：香料百科与配方分享小程序

| 暖红橙 | `#c46a30` | 渐变过渡、次级强调 |
| 辅助·姜黄 | `#e0a030` | 次级按钮、徽标、评分 |

配色基调：香料暖橙红系，无蓝紫渐变。每页有色彩主角但整体统一在暖橙红 + 深咖 + 米白体系内。

## 字体

- 中文：`'PingFang SC', 'Noto Sans SC', system-ui, sans-serif`（小程序原生字体栈）
- 英文/数字：`'Inter', -apple-system, sans-serif`
- 装饰标题：`'Noto Serif SC', serif`

## 圆角

- 卡片：`16px`
- 按钮：`12px`（主操作）/ `999px`（胶囊标签）
- 胶囊按钮容器：`8px`
- 图片：`12px`

## 组件

- **小程序导航栏**：自定义高度，右上角胶囊按钮（··· / ⊙），随页面透明/渐变/吸顶变色
- **底部 TabBar**：4 项（首页/分类/配方/我的），选中态放大 + 圆点微动效
- **香料卡**：圆角图片 + 标题 + 产地标签 + 风味色块
- **吸顶筛选 Tab**：味型/产地/用途/辣度，滚动吸顶
- **半屏弹层**：配方步骤详情，右滑返回 / 下滑收起
- **ActionSheet**：分享动作面板
- **吸底操作栏**：详情页收藏/分享/加入配方，安全区适配
- **环形进度**：个人中心本月探索度（SVG stroke-dashoffset）
- **骨架屏**：下拉刷新时闪烁占位

## 动效系统（12+ 组件级特效）

1. 自定义光标（白环 + 姜黄内点 + 发光，悬停变形 + 点击涟漪）
2. 滚动渐入（IntersectionObserver）
3. 悬停发光
4. 打字机（推荐语）
5. 数字计数（统计数字）
6. 按钮涟漪
7. 视差（详情页 Hero 滚动，直操 DOM）
8. 光泽扫过
9. 头像脉冲
10. 香气粒子扩散
11. TabBar 选中微动效（放大 + 圆点）
12. 骨架屏闪烁
13. 首页卡片错峰入场（签名动效）
14. 下拉刷新研磨弹性（弹簧物理，签名动效）
15. 环形进度生长（SVG stroke-dashoffset，签名动效）

动效基于物理模型（弹簧 Hooke / RAF 积分）与主题语义（香气扩散/研磨），周期各异，禁 Ken Burns。

## 页面结构（8 页）

1. **首页**：Hero 渐变头 + 搜索 + 今日精选轮播 + 香料卡片双列流 + 下拉刷新骨架屏
2. **分类页**：吸顶 Tab（味型/产地/用途/辣度）+ 二级筛选 + 瀑布流 masonry 网格
3. **香料详情页**：Hero 视差大图 + 前/中/后调气味金字塔 + SVG 风味雷达图 + 吸底操作栏
4. **配方页**：菜谱式卡片 + 半屏弹层步骤 + ActionSheet 分享
5. **市集页**：商品左滑操作（收藏/加购）+ banner
6. **个人中心**：头像脉冲 + 数字计数 + SVG 环形进度 + 宫格入口 + 收藏/配方横滑
7. **设计规范页**：6 色色板 + 字体标尺 + 组件展示 + 动效演示
8. **接口文档页**：REST 接口列表 + 方法徽章 + 代码高亮示例

8 页中至少 6 页布局独特非重复（卡片流/瀑布流/Hero视差/半屏弹层/左滑列表/宫格+环形进度）。

## 端侧交互语言（≥4 种）

页面栈 push/pop（右滑返回）、底部 TabBar、半屏弹层、ActionSheet、下拉刷新弹性、左滑列表、吸顶 Tab、吸底安全区按钮、骨架屏。

## 技术栈

纯 vanilla HTML/CSS/JS 单文件，无 React/Babel/外部 CDN 依赖。CSS 内联，JS 内联。

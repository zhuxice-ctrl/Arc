# 设计规范 · 古籍鉴 V2

形态：原生 App

## 一、设计理念

以宣纸、墨色、朱砂为视觉基调，将古籍版本学的文雅厚重融入现代 App 交互。核心是「拍书影→识别→判定→归档」的完整工具流，而非浏览型图鉴。

设计语言来自中国古籍本身：宣纸的米黄底色、墨色的行文、朱砂的印信——每一次鉴定都像在档案上盖一方印。

## 三、字体系统

### 字族
- **主字体**：Noto Serif SC（思源宋体）
- 标题、正文统一使用宋体族，呼应古籍刻本气质

### 字号层级
| 级别 | 字号 | 字重 | 用途 |
|------|------|------|------|
| 大标题 | 28–32px | 700 | 页面主标题 / 判定结论 |
| 标题 | 16–20px | 600 | 区块标题 / 卡片标题 |
| 正文 | 14–15px | 400–500 | 主要内容 |
| 辅助 | 11–13px | 400 | 标签 / 说明 / 日期 |
| 超小 | 10–11px | 400 | 标签文字 / 角标 |

### 字距
- 标题：letter-spacing 0.1–0.3em（营造古籍题签感）
- 正文：默认字距
- 英文/数字：monospace，用于 API 文档与代码

## 七、动效规范

### 核心原则
动效首先是功能，不是炫技。承担：状态反馈、空间关系、内容出现、操作确认。

### 缓动函数
- 出场 / 普通：`cubic-bezier(0.16, 1, 0.3, 1)`（ease-out）
- 弹性按压：`cubic-bezier(0.34, 1.56, 0.64, 1)`（spring）
- 循环动画：`cubic-bezier(0.65, 0, 0.35, 1)`（ease-in-out）

### 时长
- 微交互：150–250ms
- 页面转场：300–350ms
- 内容出现：400–500ms
- 签名动效：600–700ms

### 动效清单
1. **印章盖印** — 启动页签名动效，scale + rotate + 淡入
2. **扫描线** — 识别页扫描线上下往复，带光晕
3. **特征框渐现** — 检测到特征时依次出现
4. **页面推入** — 从右侧滑入，表达层级推进
5. **底部弹起** — Bottom Sheet 从底部滑入
6. **墨晕扩散** — 点击时径向扩散（纸张材质感）
7. **标签依次出现** — 识别特征标签 stagger 出现
8. **按钮按压** — scale(0.97) + 颜色加深
9. **卡片出场** — 列表元素 fade-in-up stagger
10. **置信度填充** — 进度条从 0 到目标值
11. **快门闪光** — 拍照白闪 + 按钮缩放
12. **Toast 弹出** — 中心弹出缩放

## 八、交互规范

### Thumb Zone
- 核心操作（拍照按钮、底部 Tab、底部 Sheet）位于屏幕下方 1/3
- 顶部导航按钮仅用于返回等次要操作

### 返回逻辑
- 所有详情页左上角返回箭头
- 返回时页面向左滑出（表示层级下降）

### 状态设计
- **空状态**：引导用户开始第一次鉴定
- **加载中**：扫描页进度 + 特征标签
- **结果态**：判定结论 + 置信度 + 特征 + 比对
- **归档成功**：Toast + 跳转档案页
- **错误态**：（预留）识别失败提示

### 手势
- 底部 Sheet 支持下滑关闭（视觉上有 grabber）
- 列表支持上下滚动

## 九、设计审计

### 视觉审计
- ✅ 删除所有动画，设计仍然成立
- ✅ 颜色全部变灰，信息层级仍然成立
- ✅ 有属于古籍版本鉴定主题的视觉记忆点（印章、宣纸、朱砂）
- ✅ 用户数秒内能理解主要功能

### 反模板审计
- ❌ 不是 greeting+search+banner+category 的首页模板
- ❌ 不是浏览型图鉴
- ❌ 没有大量假功能入口
- ❌ 不是网页缩进手机的形态

### 用户任务审计
去掉颜色图片品牌名，仅通过交互结构仍可判断：
1. 有拍照入口 → 图像识别类工具
2. 有扫描进度 → 识别过程
3. 有置信度 + 比对 → 鉴定/匹配类产品
4. 有档案库 → 个人记录管理
→ 版本鉴定工具型产品

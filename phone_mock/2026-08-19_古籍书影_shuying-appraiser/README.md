# 古籍鉴 · 版本鉴定工具 App V2

形态：原生 App

## 在线预览

妙搭应用预览链接：https://dcniaqwtmoca.feishu.cn/page/A87lmCsb7dgb6GajSuOcD02mn0g

## 项目简介

古籍鉴是一款面向古籍收藏者、版本研究者的工具型 App，核心功能是通过拍摄书影，AI 识别版式特征（版框、鱼尾、界行、字体、避讳字、纸张等），比对数据库后给出版本判定结果，并支持存入个人鉴定档案。

## 产品定位

- **类型**：工具型 App（非浏览型图鉴）
- **核心任务流**：拍照 → AI 识别版式特征 → 比对数据库 → 版本判定 → 存入档案
- **目标用户**：古籍藏家、版本学研究者、古籍爱好者

## Design DNA

### 核心概念
整个 App 像一册正在被研究的古籍——宣纸为底、墨字行文、朱砂印信，每次鉴定都是一次盖印归档的过程。

### 视觉来源
- **材质**：宣纸、墨、朱砂印泥
- **文化**：中国古籍版本学、雕版印刷
- **器物**：线装书、藏书印、牌记

### 空间逻辑
工具型单任务流 —— 功能聚焦，核心操作（拍照鉴定）始终在拇指可达区域。

### 色彩逻辑
- **宣纸色（#F0E6D2）**：主背景，奠定文雅基调
- **墨色（#2D2419）**：主要文字，信息层级核心
- **朱砂色（#B3392E）**：主强调色，印章、按钮、高亮
- **靛青色（#2D4A5E）**：次级强调，链接与辅助信息
- **金棕色（#8B6914）**：装饰点缀

### 字体逻辑
- **Noto Serif SC**：展示字体与正文统一使用宋体族，呼应古籍刻本气质
- 标题字重 700，字距宽松，模仿古籍版心题签

### 签名动效
印章盖印动效 —— 首页朱砂印从大到小带旋转压印而下，是品牌识别的核心记忆点。

## 功能模块

### 核心功能（1个）
1. **书影鉴定** — 拍书影→AI识别→比对→版本判定→归档

### 辅助功能（3个）
2. **鉴定档案** — 个人鉴定记录管理，支持朝代筛选
3. **版本学知识** — 鉴定常识与术语学习
4. **个人中心** — 统计概览 + 设置入口

## 完整 User Flow

```
打开 App → 启动页（印章动效）
  ↓
首页 → 点击「拍书影鉴定」/ 底部中心相机按钮
  ↓
底部 Action Sheet → 拍照 / 从相册选择
  ↓
相机页 → 取景框对齐版框 → 按快门
  ↓
识别页 → 扫描线 + 特征框依次出现 → 进度条推进
  ↓
结果页 → 版本判定 + 置信度 + 版式特征 + 比对结果
  ↓
存入档案 → Toast 提示 → 跳转档案页
  ↓
档案列表 → 查看详情 → 特征/比对/备注
```

## 真实数据状态

- 档案包含朝代、版本类型、置信度、扫描日期等内部关系
- 支持按朝代筛选（宋/元/明/清）
- 版本学知识条目均使用版本学真实术语

## 移动端交互

- **Thumb Zone**：底部中心相机按钮 + 底部 Tab 栏 + 底部 Sheet，均在拇指可达区域
- **返回逻辑**：所有详情页左上角返回按钮，回到上一级
- **Bottom Sheet**：拍照来源选择使用底部弹窗
- **状态设计**：空状态、加载中、识别中、结果、归档完成
- **反卡片化**：首页大操作区、列表使用分隔线、知识条目左侧色条

## 技术实现

- **框架**：React 18 + Babel Standalone（浏览器内 JSX）
- **设备框架**：iOS 26 Liquid Glass 设备边框
- **字体**：Noto Serif SC（Google Fonts 自托管镜像）
- **无后端**：前端模拟完整交互流程
- **数据**：内置 6 条样本档案 + 4 条知识条目

## 工程健壮性

- ✅ 零未定义引用
- ✅ RAF 随页面可见性暂停
- ✅ 定时器在组件卸载时清除
- ✅ 鼠标事件使用 requestAnimationFrame 节流
- ✅ 支持 `prefers-reduced-motion`
- ✅ 自定义光标：开页居中、高对比、层级最高

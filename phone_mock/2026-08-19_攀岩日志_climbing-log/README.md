# 岩痕 · 攀岩路线日志 App V2

攀岩爱好者的路线记录工具。从选岩场、选线路到记录攀登、完攀盖章签名，完整 user flow 一气呵成。

## 形态

原生 App（iOS 风格），V2 版本。上一版为微信小程序形态。

## 设计主题：岩 · 粉笔

以「岩壁上的粉笔痕迹」为视觉母题——暖调米色底（粉笔灰）、岩锈橙为主色（岩石锈迹），搭配苔藓绿与日光黄点缀。

## 完整 User Flow

1. **今日攀登** — 首页展示今日状态、附近岩场、最近记录
2. **岩场列表** — 6 个真实岩场（白河/阳朔/黎明/老君山/石鼓/千岛湖）
3. **岩场详情** — 线路列表，可按难度筛选
4. **线路详情** — 线路信息 + 攀登记录表单
5. **完攀盖章** — 手写签名 + 盖章落印动画
6. **进度统计** — 难度金字塔 + 成就系统

## 技术规格

- 纯 vanilla HTML/CSS/JS 单文件
- 零外部依赖（内联 SVG 图标、CSS 渐变模拟岩场图）
- 零未定义引用
- RAF / 定时器随页面可见性暂停
- 快速操作不叠加定时器
- 支持 `prefers-reduced-motion`
- 响应式：桌面下并排展示两台手机，窄屏自适应全屏

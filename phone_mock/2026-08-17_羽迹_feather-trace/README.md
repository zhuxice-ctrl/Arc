# 羽迹 · 观鸟手记 App

> 日期：2026-08-17 · 方向：V2 手机 UI · 形态：原生 App · 主题：观鸟手记

## 简介

「羽迹」是一款面向观鸟爱好者的原生手机 App，涵盖今日观鸟、鸟种图鉴、目击记录、个人中心等功能。使用 10 种中国常见鸟种（丹顶鹤、翠鸟、白鹭、戴胜、红隼、黑脸琵鹭、珠颈斑鸠、白鹡鸰、普通楼燕、灰喜鹊）的真实数据，配色以深林绿+奶油白+琥珀金为主调，营造自然田野感。

## 动效亮点

- 首页入场序列动画（元素依次浮现 + 飞鸟剪影横向掠过）
- 详情页 Hero 视差滚动
- 个人中心环形年度目标进度动画
- 记录页统计数字递增
- TabBar 胶囊滑移 + 图标弹跳
- 热点脉冲 + 拖拽抽屉阻尼 + FAB 扇形展开
- 自定义光标（白环+琥珀金内点+多层发光+点击涟漪）
- 共 12+ 个组件级特效

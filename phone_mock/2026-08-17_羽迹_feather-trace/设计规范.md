## 字体

- 标题：`'Noto Serif SC', serif`
- 正文：`system-ui, -apple-system, sans-serif`（通过 CSS 变量 --font-sans）
- 代码：`'SF Mono', 'Menlo', 'Consolas', monospace`

## 组件规范

- **TabBar**：底部 5 项，选中态胶囊背景滑移 + 图标弹跳
- **鸟种卡片**：网格拼贴（tall/wide/small 三种尺寸错落），保护等级色标条
- **吸顶 Tab**：分类筛选（雀形目/雁形目/隼形目/鹤形目/鸻形目）
- **吸底操作栏**：详情页底部主按钮区
- **半屏弹层**：可拖拽上拉/下拉关闭
- **FAB**：右下角悬浮按钮，展开扇形菜单

## 动效系统

| # | 动效 | 触发 | 物理/语义模型 |
|---|------|------|-------------|
| 1 | 自定义光标 | 鼠标移动 | 白环+琥珀金内点+发光+涟漪 |
| 2 | 首页入场序列 | 页面加载 | 元素依次浮现+飞鸟剪影掠过 |
| 3 | Hero 视差滚动 | scroll | 图片缩放位移 |
| 4 | 卡片悬停发光 | hover | box-shadow 渐变 |
| 5 | 滚动渐入 | IntersectionObserver | translateY+opacity |
| 6 | 数字计数递增 | 视口触发 | easeOut 缓动 |
| 7 | 环形进度动画 | 页面进入 | stroke-dashoffset 动画 |
| 8 | TabBar 胶囊滑移 | 点击切换 | transform 过渡 |
| 9 | 热点脉冲 | 持续 | scale+opacity 循环 |
| 10 | 拖拽抽屉阻尼 | 拖拽 | 弹簧回弹 |
| 11 | FAB 扇形展开 | 点击 | 角度+scale |
| 12 | 长按菜单弹出 | 长按 | scale+opacity |

## 页面结构（8 页）

1. 首页「今日观鸟」：Hero 视差 + 热点轮播 + 环形指数 + 瀑布流
2. 图鉴页：网格拼贴 + 吸顶分类 Tab + 长按菜单
3. 鸟种详情页：全屏 Hero 视差 + 四色拼块 + 吸底操作栏
4. 观鸟记录页：时间线 + 统计横幅 + FAB
5. 个人中心：头像 + 环形进度 + 宫格 + 徽章墙
6. 地图页：地图插画 + 脉冲热点 + 拖拽抽屉
7. 设计规范页：色卡 + 字体 + 组件 + 动效说明
8. 接口文档页：API 端点 + JSON 示例

## 原生 App 交互语言

大标题导航栏收缩 · 底部 TabBar · 卡片信息流 · 模态半屏弹层 · 长按快捷菜单 · FAB 扇形菜单 · 拖拽抽屉阻尼 · 下拉刷新弹性

## 技术栈

React + Babel standalone（JSX 内联在 script type="text/babel"），CSS 内联在 style 标签。支持 prefers-reduced-motion 降级。

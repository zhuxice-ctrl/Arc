设计规范

设计理念

蓝晒手帖的界面像一本蓝晒工作者的随身手册——记录每一次与阳光的合作。视觉语言全部来自蓝晒工艺本身：普鲁士蓝、水彩纸、药液黄绿。不是科技蓝，是化学反应蓝。

色彩体系

主色取自普鲁士蓝家族，辅助色来自水彩纸白与药液黄绿。严禁蓝紫渐变。

字体系统

  • 标题 / 数字：衬线体（Georgia / 宋体），呼应古典摄影气质
  • 正文：无衬线（system-ui / PingFang），保证小屏可读性
  • 数字：tabular-nums，计时器使用等宽数字

材质语言

  • 水彩纸质感贯穿全局——CSS noise 模拟纸纤维
  • 药液涂刷边缘有不规则晕染感
  • 卡片使用柔和阴影，模拟纸页层叠

动效语言

  • 化学与光的运动——缓慢、不可逆、渐变
  • 曝光是渐进变深，不用弹性回弹
  • 冲洗是溶解扩散，涟漪从中心向外
  • 计时器圆环匀速填充
  • 支持 prefers-reduced-motion 降级

空间逻辑

  • 编辑式 / 手册式——信息以区块+分隔线组织
  • 不全塞圆角卡片，避免卡片堆砌感
  • 时间线用竖线串联
  • 计时器页面留大面积给纸面预览

接口文档

基础信息

  • Base URL: https://api.cyanotype.app/v2
  • 认证方式：Bearer Token
  • 数据格式：JSON
  • 时区：所有时间均为用户本地时区

紫外线与天气

GET /weather/today
获取今日紫外线指数与日照信息
Query 参数：
lat number — 纬度
lon number — 经度
GET /weather/forecast
获取未来 7 天紫外线预报
GET /exposure/recommend
根据当前紫外线推荐曝光时长
Query 参数：
uvIndex number — 紫外线指数
paperType string — 纸张类型
tone string — desired 色调 (light/mid/deep)

作品管理

GET /works
获取作品列表（分页）
Query 参数：
page number — 页码，默认 1
pageSize number — 每页数量，默认 20
sort string — 排序 (date_desc/date_asc/uv_desc)
POST /works
创建一条作品记录
Body 字段：
title string — 作品名称
exposureSeconds number — 曝光秒数
uvIndex number — 紫外线指数
weather string — 天气
tone string — 色调
paperId string — 纸张 ID
batchId string — 药液批次 ID
note string — 备注
imageData string — 作品图像 base64
GET /works/{id}
获取作品详情
PUT /works/{id}
更新作品信息
DELETE /works/{id}
删除作品记录

药液与纸张

GET /batches
获取药液批次列表
POST /batches
新增药液批次
GET /papers
获取纸张库存
PUT /papers/{id}/stock
更新纸张库存数量

用户与统计

GET /users/me
获取当前用户信息
GET /stats/summary
获取晒版统计概览（累计作品、总曝光时长、最常时段等）

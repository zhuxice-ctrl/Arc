# 蓝晒手帖 · 设计规范

形态：原生 App

## 核心概念

整个界面像一本蓝晒工作者的随身手册——记录每一次与阳光的合作。蓝晒（Cyanotype）是古典摄影工艺：柠檬酸铁铵+铁氰化钾涂纸、紫外线曝光、水洗显影，未曝光部分溶于水、曝光部分生成普鲁士蓝。App 服务蓝晒手工爱好者，解决"今天的光够不够晒？晒多久？上次什么参数出了什么效果？"

## 字体系统

- **标题 / 数字**：Georgia, "Times New Roman", "Songti SC", "STSong", serif —— 衬线体呼应古典摄影与手工书写气质
- **正文**：-apple-system, BlinkMacSystemFont, "PingFang SC", "Helvetica Neue", system-ui, sans-serif —— 保证小屏可读性
- **数字**：`font-variant-numeric: tabular-nums` —— 计时器等宽数字

## 材质逻辑

水彩纸质感贯穿全局：
- 纸纤维纹理：CSS `radial-gradient` + 内联 SVG `feTurbulence` 噪点滤镜模拟，不用外部图片
- 药液涂刷边缘：不规则 `border-radius` + `box-shadow` 内阴影模拟晕染
- 卡片阴影：`rgba(13,43,78,0.08)` 墨蓝色调阴影，不用纯黑

## 动效系统

化学与光的运动——缓慢、不可逆、渐变。不用弹簧、不用弹性回弹。

### 缓动曲线
- `--ease-expose: cubic-bezier(0.25, 0.1, 0.25, 1)` —— 曝光类过渡
- `--ease-dissolve: cubic-bezier(0.4, 0, 0.2, 1)` —— 溶解类过渡

### 关键动画
| 动画 | 时长 | 曲线 | 用途 |
|------|------|------|------|
| 页面切换 | 0.35s | ease-expose | Tab 切换 transform+opacity |
| Tab 指示线 | 0.2s | ease | 颜色过渡 |
| 计时圆环 | 0.3s | linear | stroke-dashoffset 填充 |
| 纸面变色 | 0.5s | ease-expose | 曝光进度色阶过渡 |
| 涟漪扩散 | 2s | ease-dissolve | 冲洗水面涟漪（rippleSpread） |
| 蓝色浮现 | 3s | ease-dissolve | 冲洗显影普鲁士蓝渐现（dissolve） |
| 脉冲 | 2s | ease-in-out | 紫外线指数呼吸（pulse） |
| 按钮反馈 | 0.2s | ease | :active 缩放 0.97 |

### 签名动效：冲洗显影
1. 计时完成 → 纸面呈深灰绿色（充分曝光状态 `#3F4A38`）
2. 底部水槽区域升起（浅蓝半透明水面）
3. 用户点击"放入水中"
4. 纸面接触水面：黄绿未曝光部分溶解（opacity+blur 动画），普鲁士蓝从灰绿中渐变浮现（background 渐变 3s），水面涟漪扩散
5. 显影完成：清晰蓝晒影像（SVG 植物剪影，普鲁士蓝底+白色物影轮廓）
6. "保存入册"按钮淡入

## 空间逻辑

编辑式/手册式——信息以区块+分隔线组织，不全塞卡片。时间线用竖线串联。计时器页面留大面积给纸面预览。

## 健壮性

- 零 console error（Browser QA 实测通过）
- `prefers-reduced-motion`：全量降级，动画改为即时切换+淡入
- `visibilitychange`：页面隐藏时暂停所有 RAF（计时器圆环+冲洗动画）和 setInterval（状态栏时钟），恢复时续跑
- `beforeunload`：清理所有 RAF 和定时器
- 快速操作不叠加定时器：点击开始前先 `cancelAnimationFrame`
- 高频触摸事件直接操作 DOM
- 纯 vanilla 单文件，零外部 CDN/图片/字体依赖

## 页面结构

### 4 Tab 底部导航
1. **今日**：紫外线指数、太阳弧线图、最佳晒版窗口、三档曝光推荐、底部"开始晒版"按钮
2. **晒版**：SVG 圆环计时器、三档目标时间切换、纸面实时变色、冲洗显影签名动效
3. **作品**：垂直时间线、蓝晒缩略图、完整参数、详情页（右侧滑入）
4. **我的**：统计卡、药液批次进度条（绿/黄/红三态）、纸张库存、设置入口

- 设计规范页（从设置进入）
- 接口文档页（从设置进入）

# 旧书体温计 · 设计规范

**形态：微信小程序**

## 设计概念
旧书"兽医诊所"——每入手一本旧书，就像带一个新病人来就诊。逐页检查症状、计算体温、建立病历卡、跟踪恢复。

## 色彩系统

| 色值 | 用途 |
|------|------|
| `#F5F0E6` | 主背景（陈年纸张米白） |
| `#FFFDF7` | 卡片背景（稍亮纸白） |
| `#8B7355` | 主色调（皮革装订棕） |
| `#C4A265` | 强调色（烫金印鉴金） |
| `#8B0000` | 印章红（图书馆印章，严重症状标记） |
| `#D4573B` | 体温高温（红橙） |
| `#7A9E7E` | 体温低温（绿） |
| `#2C2416` | 文字主色（浓墨黑） |
| `#6B5D4F` | 文字辅色（淡墨灰） |
| `#B8A88F` | TabBar 未选中 |
| `#4A3C28` | 深棕（标题/重要文字） |
| `#3A2C18` | 更深棕（导航栏背景） |
| `#2A1C08` | 极深棕（TabBar 背景） |

色彩逻辑：每种颜色来自旧书的真实物理特征——纸是米白、皮是棕、印是红、墨是黑。

## 字体系统

| 层级 | 字体 | 说明 |
|------|------|------|
| 标题 | Noto Serif SC (serif) | 衬线体，书卷气 |
| 正文 | Noto Sans SC (sans-serif) | 无衬线体，清晰易读 |
| 数据/编号 | ui-monospace (monospace) | 等宽体，用于书号和体温值 |

## 微信小程序端侧特征
- 自定义导航栏容器 + 右上角胶囊按钮区域
- 页面栈 push/pop（右推入/左推出过渡）
- 底部 TabBar（首页/病历档案/我的）
- 半屏弹层/ActionSheet
- 下拉刷新弹性
- 吸底操作栏
- 左滑操作（详情/删除）

## 动效系统（12+ 组件级特效）

1. 羽毛笔自定义光标（开页居中）
2. 体温计渐变填充动画（签名动效）
3. 病历卡盖印（抖动+印泥晕染，签名动效）
4. 症状手绘勾选标记（签名动效）
5. 症状卡片 hover 微上浮
6. TabBar 底部弹性位移切换
7. 列表项左滑操作
8. 下拉刷新弹性拉伸
9. 病历卡 hover 3D 透视微倾斜
10. 表单输入框 focus 底线绘制动画
11. 页面右推入/左推出过渡
12. 空状态病历卡呼吸浮动
13. 统计数字滚动计数

## 工程约束
- 纯 vanilla 单文件 HTML（无 React/Babel/CDN）
- 390px 宽度模拟手机屏幕
- localStorage 持久化
- RAF 随可见性暂停
- 支持 prefers-reduced-motion
- 零未定义引用

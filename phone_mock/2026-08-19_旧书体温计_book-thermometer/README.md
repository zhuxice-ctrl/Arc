# 旧书体温计 · Used Book Thermometer

**类别**：Phone Mock　**日期**：2026-08-19　**形态：微信小程序**

## 主题
旧书收藏者的"兽医诊所"——给每本旧书建立病历卡，记录症状，计算体温。

## 简介
把二手书当作"病人"，每入手一本旧书就像带一个新病人来就诊。通过症状检查清单（水渍、黄斑、批注、藏书印、书脊磨损、页面脱落、虫蛀、异味）逐项评估，自动计算"体温"（健康评分），最终生成一份病历卡存档。微信小程序形态，含自定义导航栏、胶囊按钮、TabBar、半屏弹层、下拉刷新、左滑操作等端侧特征。

## 技术栈
纯 vanilla HTML + CSS + JS，无外部依赖。localStorage 持久化，RAF 可见性暂停，prefers-reduced-motion 适配。

## 核心流程
登记旧书 → 症状逐项检查 → 体温评分（温度计动画）→ 病历卡盖印存档 → 档案查看

## 签名动效
- 体温计渐变填充动画
- 病历卡盖印（抖动+印泥晕染）
- 症状手绘勾选标记

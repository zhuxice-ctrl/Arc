# 羽志·观鸟年表 — 设计规范

> 形态：原生 App　|　日期：2026-08-19　|　方向：V2 手机 UI

## 一、设计母题

随身观鸟图鉴「羽志」。设计语言来自**博物志手绘鸟类图鉴与田野笔记**，而非木器陶土手作气质。核心产品逻辑：浏览图鉴 → 记录目击 → 点亮个人图鉴 → 累积观鸟年表；每日「听音辨鸟」声谱挑战为独特交互记忆点。

一句话视觉逻辑：整个界面像一本会发声的随身博物图鉴，翻页是手绘羽翼线稿，翻开某一页能听到那只鸟的叫声。

## 二、配色系统（源码真实色值）

| 用途 | 色值 | 说明 |
|---|---|---|
| 主背景（冷雾米白） | `#F3F2EC` | 田野笔记纸面，冷调非暖纸 |
| 次背景（纸白） | `#FAFAF6` | 卡片/弹层底 |
| 主色（石青苔绿） | `#34554A` | 品牌主色、已见点亮、主操作 |
| 深苔 | `#2A4A3F` / `#2A3530` | 主色按压态、深色块 |
| 辅色（灰绿） | `#6E7F6A` | 次级文字、标签 |
| 雾灰 | `#9AA39D` / `#C9CDC6` | 分割线、占位、未见态 |
| 强调（赭橙鸟羽） | `#C16B3A` | 鸟羽强调、听音主操作、选中 |
| 警示（候鸟迁徙红） | `#B23A2E` | 候鸟提醒、夏候/旅鸟标签 |
| 主文字（墨绿黑） | `#1E2723` | 正文 |
| 深墨 | `#121815` | 标题 |

色彩承担功能：主色=已见/主操作、赭橙=听音/选中、迁徙红=候鸟季节语义、灰阶=未见/层级。禁蓝紫渐变、禁暖纸朱砂。

## 三、字体系统

- **正文 / UI**：`-apple-system, BlinkMacSystemFont, "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei"` — 无衬线，保证小屏可读。
- **学名（拉丁文）**：`"Times New Roman", "Songti SC", "STSong", Georgia, serif` + `italic` — 衬线斜体凸显博物图鉴气质，与正文形成学科层级。
- 字级自上而下：导航标题 > 物种中文名 > 学名 > 识别要点 > 标签/元数据，靠尺寸+衬线/无衬线对比建立层级，不依赖颜色。

## 四、信息结构

原生 App 外壳：顶部自定义导航栏（左返回/中标题/右操作）+ 底部 4 Tab。

| Tab | 内容 | 首屏结构（非通用模板） |
|---|---|---|
| 图鉴 | life list 网格 | 顶部类群+居留型双维筛选 chip → 14 种鸟网格（SVG 线稿+名+学名+居留型小标+已见/未见点亮态） |
| 听音 | 听音辨鸟挑战 | 神秘鸟鸣声谱（钢琴卷帘流动）+ 播放 → 4 候选声谱缩略可试听 → 选对点亮+得分 |
| 年表 | 观鸟统计 | 年度物种数/目击次数大数字 → 最近目击时间线 → 当季候鸟迁徙提醒 |
| 我的 | 个人档案 | 昵称/累计物种/目击/连续打卡 + 深色与动效开关 + 清除数据 |

页面栈 push/pop：图鉴网格 → 物种详情页（大 SVG+识别要点+居留说明+吸底「记录目击」→ 半屏弹层填地点/日期/数量 stepper/备注）。

## 五、核心交互与签名

**签名：听音辨鸟声谱挑战**
- WebAudio 真实合成：每只鸟有独立 `notes` 数组 `[频率, 起始, 时长]`，`playBirdSong` 用 `OscillatorNode + GainNode` envelope 逐音符调度发声（非静态图、非音频文件）。
- 钢琴卷帘式声谱：神秘鸟鸣声谱条 `requestAnimationFrame` 从左向右流动播放，播放进度与音频同步。
- 4 候选各带声谱缩略可单独试听，选出音型一致者；答对该物种图鉴点亮 + 得分 +1 / 连击。
- 首次用户交互后才 `ensureAudioContext()` 创建/resume AudioContext（autoplay 合规）。

**目击记录闭环**：物种页 → 记录目击弹层 → 提交 → 图鉴卡 `unseen→seen`（墨点扩散动效）→ 年表统计真实更新 → localStorage 持久化（刷新保留）。

## 六、动效语言

| 动效 | 实现 | 功能 |
|---|---|---|
| 声谱流动 | `requestAnimationFrame` 推进 + WebAudio 驱动 | 听音辨鸟进度反馈 |
| 图鉴点亮墨点扩散 | `@keyframes inkSpread`：`scale(0)→18, opacity 0.8→0` | 已见状态确认 |
| 年表计数弹跳 | JS 数字递增 | 统计反馈 |
| 候鸟提醒淡入 | CSS transition | 信息出现 |

皆为功能反馈，无装饰性特效。`prefers-reduced-motion` 下声谱改为静态高亮当前音、inkSpread/弹跳降级（源码 5 处降级判断）。

## 七、健壮性

- 零未定义引用、零 Console Error（puppeteer 实测 pageerror/consoleError 均空）。
- `requestAnimationFrame` 随 `visibilitychange` 暂停、卸载 `cancelAnimationFrame`；快速重复点击听音先停旧播放再启新（不叠加定时器）。
- `prefers-reduced-motion` 5 处降级。
- 纯 vanilla 单文件，无 React/Babel/CDN，鸟图全 inline SVG，无外部字体/图片外链。
- 390×844 及邻近尺寸无横向溢出、无文字重叠裁切。

## 八、技术栈

纯 HTML/CSS/JS 单文件 · Web Audio API · Canvas/DOM 声谱可视化 · localStorage · inline SVG · 无构建依赖。

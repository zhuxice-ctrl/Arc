# 设计规范 · 银幕之间 Intermission

## 0. 形态声明

**形态：原生 App**

iOS 原生设计语言，包含大标题导航栏、返回栈导航、底部 TabBar、模态弹窗、底部半屏抽屉、长按快捷菜单、悬浮操作按钮等原生端侧交互。

---

## 1. 品牌概述 Brand Overview

「银幕之间 Intermission」是一家独立艺术影院 App。

设计语言取自传统影院的物质质感——丝绒座椅的红、奶油幕布的米、放映机光束的金、影院暗场的炭黑。每一处细节都在致敬胶片时代的仪式感。

**受众**：影迷 / 艺术电影爱好者 / 追求观影仪式感的都市人群

**核心情感**：怀旧、优雅、静谧、有温度的仪式感

## 2. 色彩系统 Color System

### 主色 Primary

| 名称 | HEX | 用途 |
|------|-----|------|
| 丝绒红 Velvet | `#8E2A2B` | 品牌主色、主按钮、标签、重点强调 |

### 辅助色 Secondary

| 名称 | HEX | 用途 |
|------|-----|------|
| 奶油 Cream | `#F4EAD8` | 亮色模式背景、票根正面、正文 |
| 放映机金 Gold | `#D4A24E` | 强调色、评分、会员、光束 |

### 中性色 Neutral

| 名称 | HEX | 用途 |
|------|-----|------|
| 炭黑 Charcoal | `#1A1512` | 暗色模式主背景 |
| 深黑 Deep Black | `#0D0A08` | 深色页面背景、票根背面 |
| 暗场灰 Dark Ash | `#2A2420` | 卡片背景、列表分隔 |
| 暖棕 Warm Brown | `#5C4033` | 次级文字、层次分隔 |
| 柔棕 Soft Brown | `#8B6F5C` | 辅助文字、票根文字 |

### 使用原则

- 每页至少使用 3-5 个色调层次
- 暗场页面（排片 / 票根 / 详情）以炭黑为底，奶油为字，金色为强调
- 亮场页面（社区 / 规范）以奶油为底，炭黑为字，丝绒红为强调
- 每页可以有自己的"色彩主角"，但整体统一在同一配色体系内

## 4. 布局系统 Layout

### 栅格

- 手机端单列布局，内容宽度约 370pt
- 横向外边距：16–20pt
- 卡片内边距：14–16pt
- 卡片间距：12–20pt

### 页面结构多样性

- **排片日历**：Hero + 跑马灯带 + 横向日期选择器 + 垂直卡片列表
- **影片详情**：全屏海报视差 + 渐变叠层信息卡 + 双列场次网格 + 底部悬浮购买栏
- **票根收藏**：垂直堆叠的 3D 卡片（点击翻转）+ Tab 筛选
- **影人专题**：对角分割 Hero + 三列数据统计 + 网格拼贴作品
- **迷影社区**：分类横向滚动 + 轮播画廊 + 瀑布式动态流 + FAB
- **会员中心**：渐变头部 + 金卡卡片 + 四格数据 + 原生分组列表
- **设计规范**：分节卡片 + 色彩网格 + 字体列表
- **接口文档**：左侧列表 + 右侧详情 + Tab 切换代码

## 5. 组件规范 Components

### 按钮 Button

- **主操作按钮**：圆角 24px · 丝绒红渐变填充 · 1px 金色边框 · 字距 4px · 衬线体 16pt 600
- **次要按钮**：圆角 20px · 透明背景 · 细边 · 13pt 无衬线
- **标签按钮**：圆角 12px · 半透明填充 · 11pt

### 卡片 Card

- **影片卡片**：左侧海报（80×114）+ 右侧信息 · 圆角 16px · 微透明白边
- **票根卡片**：正面奶油底 + 齿孔分割 + 右侧存根 · 3D 翻转展示背面 QR
- **动态卡片**：白底 · 圆角 14px · 柔和阴影 · 头像 + 内容 + 底部操作

### 导航栏 Navigation Bar

- **标准模式**：居中标题 · 返回键左侧 · 高度 44pt
- **大标题模式**：左对齐大标题 · 34pt 衬线体
- 支持滚动渐显（详情页）

### TabBar

- 毛玻璃背景（backdrop-blur: 20px）
- 图标 + 文字垂直布局
- 激活态金色 · 未激活态半透明白
- 4 个 Tab：排片 / 票根 / 社区 / 我的

### 底部弹窗 Bottom Sheet

- 顶部 grab handle（40×5px）
- 圆角 24px（顶部）
- 半透明黑色遮罩
- 内容可滚动

## 6. 签名动效 Signature Motion

| 动效 | 页面 | 语义 | 周期 |
|------|------|------|------|
| 放映机光束呼吸 | 排片首页 Hero | 致敬放映机光束穿过黑暗 | 4s 循环 |
| 尘埃粒子漂浮 | 排片首页 Hero | 光束中的尘埃漂浮 | 6s 持续生成 |
| 票根 3D 翻转 | 票根收藏夹 | 实体票根翻看体验 | 800ms 单次 |
| 海报视差滚动 | 影片详情 | 电影画面的景深感受 | 跟随滚动 |
| 跑马灯片单 | 排片首页 | 电影片单滚动仪式感 | 40s 循环 |
| 胶片卷轴旋转 | 排片首页装饰 | 放映机运转 | 20s 循环 |
| 影人轮播 | 迷影社区 | 专题轮换展示 | 5s 切换 |

### 动效原则

- 所有动效符合主题语义，严禁整图缩放 / Ken Burns
- 动效周期各不相同
- 支持 `prefers-reduced-motion`，自动降级为静态
- 页面不可见时暂停所有定时器和 RAF

## 7. 图标语言 Iconography

- 线性图标，1.8pt 描边
- 圆角端点（stroke-linecap: round）
- 激活态金色，未激活态半透明
- 与 iOS SF Symbols 视觉风格一致

# 银幕之间 Intermission · V2 手机 UI Mock

独立艺术影院原生 App 高保真设计原型。

## 概览

「银幕之间」是一家专注于艺术电影的独立影院 App。围绕胶片时代的仪式感，构建了排片日历、影片详情、票根收藏夹、影人专题、迷影社区与会员中心等完整功能。

- **形态**：原生 App（iOS 原生设计语言）
- **媒介**：交互原型（Interactive Prototype）
- **尺寸**：402 × 874（iOS 设备框）
- **技术**：React + Babel（浏览器内 JSX），纯前端

## 字体系统

- **展示字体**：Cormorant Garamond（品牌气质，克制使用）
- **正文字体**：Noto Serif SC + SF Pro Text（标题用衬线、正文用无衬线）
- **数据字体**：JetBrains Mono（编码 / 数据 / 票号）

## 签名动效

1. **放映机光束**：首页 Hero 区金色光束呼吸 + 尘埃粒子漂浮，致敬放映机光束
2. **票根 3D 翻转**：票根收藏页，点击卡片 Y 轴 180° 翻转，正面奶油底信息 / 背面炭黑底 QR 码
3. **海报视差滚动**：影片详情页，滚动时海报以不同速率位移，营造深度感
4. **跑马灯片单**：首页丝绒红条带，影片名无限横向滚动
5. **胶片卷轴旋转**：首页装饰元素，缓慢持续旋转的胶片卷轴

## 原生交互

## 使用方式

在浏览器中打开 `index.html` 即可体验。通过底部 TabBar 切换主页面，点击卡片进入详情页，左上角返回按钮回退。

## 健壮性

- 支持 `prefers-reduced-motion`（减少动画用户自动停用动效）
- 所有动画 / 定时器随页面可见性切换自动暂停
- RAF 动画在组件卸载时统一取消
- 高频滚动事件直接操作 DOM transform，不触发 React setState
- 零外部 JSX 文件引用（全部内联）

# 纹枰 · 设计规范

## 主题与设计母题
围棋打谱原生 App。设计母题：**一方随身携带的榧木棋枰**。核心任务是打谱——选古今名局，逐手摆子研究，收藏妙手，生成棋谱笔记。视觉来源：榧木棋盘、蛤碁石、墨谱纸感。题材驱动配色与材质，朱砂仅作记号点。

## 产品信息架构
底部 TabBar 四 tab：今日 / 谱库 / 妙手集 / 我的。原生 App 形态：自定义导航栏、页面栈 push/pop 转场（非小程序胶囊）。

## 完整核心流程
今日一局推荐 → 谱库搜索筛选 → 打谱页逐手落子（前进/后退/自动播放/跳手数/显隐手数）→ 长按交叉点弹出变化图 → 收藏妙手飞入妙手集 → 编辑棋谱笔记。

辅助功能（做深不做多）：每日一道死活题（可作答判定、查看正解）；妙手收藏可编辑笔记。

## 真实内容
6 局名谱：当湖十局两局（范西屏 vs 施襄夏）、吴清源镰仓十番棋、Master 对连笑、AlphaGo 对李世石第四局、棋圣战。含真实棋手、年代、手数、谱注。

## 配色（取自源码真实色值）
- 榧木棋盘 浅黄：`#F5F1E8` / `#f6f4ef` / `#FFFEF9`
- 墨黑（谱注/文字/黑子）：`#1A1A1A` / `#1F2329` / `#2C1810`
- 蛤白（白子/卡片）：`#EBECEE` / `#DEE0E3` / `#F2F3F5`
- 深棕（盘缘/分隔）：`#29261b` / `#2C1810`
- 苔绿（妙手/正解语义）：`#6B8E5A`
- 朱砂（关键记号）：`#B85450` / `#D97757`
- 灰文（次要信息）：`#646A73` / `#86909C`
- 盘格木色：`#C8BFA8` / `#E8D4A8` / `#E8E0CC`

无蓝紫渐变。苔绿=妙手语义，朱砂=关键记号语义。

## 字体
- 正文/棋谱：`Noto Serif SC`（宋体，榧木盘的儒雅感）
- 标题装饰：`ZCOOL XiaoWei`

## 动效系统（≥12 组件级特效）
1. 落子下落 + 阴影先至 + 吸附弹跳 + 余震（签名）
2. 提子旋转飞离棋盘
3. Tab 切换连续过渡
4. 页面栈 push/pop 转场
5. 谱注浮现
6. 手数进度滑动
7. 妙手收藏飞入妙手集
8. 死活题正解揭示
9. 下拉刷新
10. 列表插入动画
11. 长按变化图弹出（缩放+遮罩）
12. 加载转完成（棋盘格逐格点亮）

落子动效有石子的重量感与余震，符合材质性格。

## 交互机制
- 点击交叉点落子（吸附+影子先至）
- 滑动切换手数、长按查看变化图分支
- 谱注高亮妙手并配合苔绿光晕脉动

## 光标
墨色圆环 + 苔绿内点自定义光标，开页居中，高对比，按压反馈。

## 健壮性
- RAF/定时器随可见性暂停、卸载取消
- 快速连续操作不叠加定时器
- prefers-reduced-motion 支持
- 390×844 与 360px 邻近尺寸不破版
- 零未定义引用，Console 无错误（本地渲染仅 1 个 404 资源，非致命）

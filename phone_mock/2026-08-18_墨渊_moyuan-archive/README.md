# 墨渊 · 古籍善本数字典藏 App

- 日期：2026-08-18
- 方向：V2 手机 UI（原生 App 形态）
- 主题：古籍善本数字典藏——宋代典籍意象的移动阅读社区
- 创作领域：文化艺术（古籍善本 / 非遗传承）
- 配色：墨黑 #1A1612 / 朱砂 #C23B22 / 鎏金 #B8914A / 宣纸 #F5EDE0 / 青瓷 #6B8E7A / 檀褐 #7A5C3E

## 简介

套在统一手机外壳内的古籍善本数字典藏原生 App，含首页、书匣、发现、个人中心、书籍详情、设计规范、接口文档共 8 个页面。墨色宣纸配朱砂鎏金，书法体标题，印章钤印、墨滴落字、墨迹晕染等中式动效。原生端侧交互齐全：底部 TabBar、返回栈导航、下拉刷新弹性、FAB 悬浮按钮、底部半屏抽屉、长按快捷菜单、详情全屏转场。

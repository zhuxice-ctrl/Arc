# 墨渊 · 古籍善本数字典藏 App — 设计规范

- 日期：2026-08-18
- 方向：V2 手机 UI（原生 App 形态）
- 主题：古籍善本数字典藏——宋代典籍意象的移动阅读社区
- 创作领域：文化艺术（古籍善本 / 非遗传承）

## 色彩系统

墨色宣纸 + 朱砂鎏金的中式典籍配色，每页有各自色彩主角，整体统一于墨纸体系。

| 角色 | 色值 | 用途 |
|---|---|---|
| 墨黑 | `#1A1612` | 深色页底、发现页、接口页 |
| 朱砂 | `#C23B22` | 主强调、印章、选中态、光标 |
| 鎏金 | `#B8914A` | 次级强调、金线、标签 |
| 宣纸 | `#F5EDE0` | 首页/书匣/详情页暖底 |
| 青瓷 | `#6B8E7A` | 辅助冷调、标签、状态 |
| 檀褐 | `#7A5C3E` | 个人中心头部、次级文字 |

页面色彩主角：首页暖宣纸、发现页深墨黑、个人中心檀褐深色、接口页深色代码风。

## 字体

- 标题：书法/宋体展示字（大标题导航栏）
- 正文：思源宋体 / Noto Serif SC 系
- 代码：等宽体（接口文档页）

## 圆角

- 卡片：16–20px
- 按钮：12px / 胶囊 999px
- 头像：50%

## 原生交互（7 种）

底部 TabBar（选中弹跳）、返回栈导航（push/pop）、下拉刷新弹性动效、FAB 悬浮按钮（呼吸脉冲）、底部半屏抽屉、长按快捷菜单、详情页全屏转场。

## 布局多样性

- 首页：大标题导航 + Hero 镇库 + 经史子集四部入口 + 横向滑卡 + 每日一书
- 书匣：Pill 筛选 + 高低错落瀑布流
- 发现：自动轮播画廊（深色）+ 学者列表 + 色条活动卡
- 个人中心：深色头部 + 环形阅读进度 + 统计网格 + 设置列表
- 详情：Hero 视差滚动 + 滚动显隐导航 + 吸底操作栏

## 签名动效（12+）

墨迹晕染入场、印章钤印下落、书页标题墨滴落字、列表逐帧淡入、Tab 图标弹性缩放、按钮涟漪、环形进度缓动填充、视差滚动、轮播缓慢推进、FAB 呼吸脉冲、下拉刷新旋转、光标阻尼跟随 + 悬停变形。

## 自定义光标

朱砂高对比光标（白环 + 朱砂内点 + 发光），阻尼跟随，悬停变形，点击涟漪，z-index 最高。

## 健壮性

- RAF/定时器随 `visibilitychange` 自动暂停，卸载统一取消
- 快速切换不叠加定时器
- 高频鼠标事件直接 DOM transform
- `prefers-reduced-motion` 降级
- JSX/CSS 全部内联单文件

## 页面结构（8 页）

首页 → 书匣（分类）→ 发现 → 个人中心 → 书籍详情 → 设计规范页 → 接口文档页 → 长按快捷菜单弹层。

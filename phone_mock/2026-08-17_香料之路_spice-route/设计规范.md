# 香料之路 · 设计规范

形态：微信小程序

> 日期：2026-08-17 · 方向：V2 手机 UI · 形态：微信小程序（上一次为原生 App，本次交替）· 主题：香料知识 / 图鉴 / 节气食谱 / 市集小程序（生活方式-美食领域）

## 色彩系统

以奶油白为底，藏红花橙为主色，肉桂棕为辅助/文字，姜黄强调，豆蔻绿点缀。禁蓝紫渐变。

| 角色 | 色值 | 用途 |
|------|------|------|
| 底色（奶油白） | `#faf3e7` | 页面主背景 |
| 浅米 | `#f5e6d0` / `#f5ede0` / `#efe6d6` | 卡片底、次表面 |
| 主色（藏红花橙） | `#e8742c` | 主交互、Tab 选中、按钮 |
| 主色暖 | `#8b4a1f` | 橙色暗调、悬浮 |
| 辅助色（肉桂棕） | `#6b3410` / `#3d2310` | 正文文字、深色头图 |
| 强调色（姜黄） | `#f0b429` / `#d49b1e` / `#b8860b` | 强调徽标、高亮、渐变 |
| 点缀色（豆蔻绿） | `#4a7c3a` / `#6b8f3a` / `#82c97a` | 等级、自然标签、点缀 |
| 暖灰中性 | `#9a8a78` / `#7a6a5a` / `#bdb0a0` | 次级文字、边框 |
| 深棕底 | `#1a0f08` / `#1e120a` / `#2a1a12` / `#2d1a0e` | 市集页深色头图 |
| 警示红 | `#b43232` | 错误/提示 |

每页有"色彩主角"：首页暖橙、食谱页橙黄渐变、市集页深棕、个人中心豆绿，整体统一在暖色香料体系内。

## 字体

系统无衬线栈（`-apple-system, BlinkMacSystemFont` 等），标题加粗；接口文档代码块用 monospace。无外部字体 CDN。

## 圆角与间距

- 卡片圆角 12px / 16px；胶囊 999px；按钮 8-10px。
- 安全区底部留白适配吸底操作栏。

## 微信小程序端侧交互语言（≥4 种）

1. 胶囊按钮自定义导航栏（右上角"··· / ⊙"，随页面透明/渐变/吸顶变色）。
2. 底部 TabBar（5 项，选中弹跳微动效）。
3. 半屏 ActionSheet 动作面板。
4. 下拉刷新弹性回弹。
5. 左滑列表操作手势。
6. 吸顶 Tabs 筛选。
7. 详情页底部吸底操作栏。
8. 骨架屏 shimmer 加载。
9. 页面栈 push/pop 切换（右滑返回手势感）。

## 签名动效（页面级，≥2）

1. 首页香料颗粒飘散入场序列。
2. 详情页 Hero 视差滚动（滚动驱动形变）。

## 组件级动效（≥12）

Tab 弹跳、卡片悬浮、香料粒子飘散、数字计数、风味环图、按钮脉冲、涟漪点击、视差滚动、收藏心跳、骨架 shimmer、导航吸顶变色、页面栈切换过渡。

## 健壮性

- visibilitychange 自动暂停动画；卸载统一取消。
- 快速切换不叠加定时器，重建前先 clear。
- 高频事件直接操作 DOM transform。
- prefers-reduced-motion 降级。
- 全部 JSX 内联在 `<script type="text/babel">`，CSS 内联 `<style>`，无外部 src。

香料简介

藏红花是世界上最昂贵的香料，每公斤需要约15万朵花，全部手工采摘。其柱头呈深红色，带有独特的金黄色泽和微甜的干草香气。原产于地中海地区，现在以伊朗产量最大（占全球90%以上）。藏红花不仅用于烹饪（西班牙海鲜饭、意大利烩饭、法式浓汤），在传统医学中用于活血养血、解郁安神，现代研究发现其含有的藏红花素具有抗氧化和抗抑郁的潜力。

香料相关接口
GET /api/spice/list 获取香料列表

分页获取香料列表，支持分类、产地、价格区间筛选。

请求参数 Query
category string 分类：spicy/herb/flower/seed/root/fruit 可选
origin string 产地筛选 可选
page number 页码，默认 1 可选
pageSize number 每页数量，默认 20 可选
响应示例
// 200 OK { "code": 0, "message": "success", "data": { "total": 46, "list": [ { "id": "spice_001", "name": "藏红花", "latinName": "Crocus sativus", "origin": "伊朗", "price": 220, "flavors": ["辛香", "甘香"] } ] } }
GET /api/spice/:id 香料详情

获取单个香料的详细信息，包括风味画像、用法、产地等。

路径参数
id string 香料唯一 ID 必填
响应示例
{ "code": 0, "data": { "id": "spice_001", "name": "藏红花", "latinName": "Crocus sativus", "family": "鸢尾科番红花属", "origin": ["伊朗", "西班牙", "克什米尔"], "flavorProfile": { "spicy": 75, "sweet": 50, "herbal": 40, "woody": 60 }, "uses": ["海鲜饭", "烩饭", "茶饮"], "benefits": ["活血养血", "解郁安神"] } }
POST /api/spice/search 搜索香料

根据关键词搜索香料，支持模糊匹配名称、别名、功效。

// Request Body { "keyword": "红花", "filters": { "category": "flower", "priceRange": [50, 500] } }
食谱相关接口
GET /api/recipe/list 食谱列表

获取食谱列表，支持按节气、难度、香料筛选。

solarTerm string 二十四节气筛选 可选
difficulty string 难度：easy/medium/hard 可选
// Response 200 { "code": 0, "data": { "list": [{ "id": "rec_001", "title": "印度黄金咖喱鸡", "cookTime": 45, "difficulty": "medium", "spices": ["姜黄", "孜然", "肉桂"] }] } }
GET /api/recipe/:id 食谱详情

包含食材清单、步骤、营养信息。

GET /api/recipe/seasonal 当季推荐

根据当前节气返回推荐食谱。

市集相关接口
GET /api/market/products 商品列表
spiceId string 关联香料 ID 可选
sortBy string 排序：price/sales/rating 可选

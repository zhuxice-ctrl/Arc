# 喫茶去 Kissa · 设计规范

> 方向：V2 手机 UI · 原生 App 形态 · 生活方式（日式喫茶店） · 2026-08-17

## 色彩系统

| 角色 | 色值 | 用途 |
|------|------|------|
| 抹茶绿（主色） | `#6B7F59` | TabBar 选中态、主按钮、品牌色 |
| 抹茶深绿 | `#4E5E3F` | 悬浮态、强调深色 |
| 抹茶浅绿 | `#A8B89A` | 辅助点缀、成功态 |
| 宣纸米（表面） | `#F5F0E4` | 页面背景、浅色卡面 |
| 宣纸米浅 / 暖白 | `#EDE7D8` / `#E8E1CE` / `#F8F4E8` | 卡片分层、分隔面 |
| 漆器黑（底/文字） | `#1C1A17` | 茶仓深色模式底、主文字 |
| 漆器深黑 | `#0E0D0B` / `#2A2722` | 深色模式分层 |
| 柿红（强调） | `#C6563A` | 限时标、HOT 标、价格强调 |
| 柿红深 | `#8B3A28` / `#A34028` | 强调按压态 |
| 焦糖棕 | `#8B6F47` / `#D4A574` | 次级文字、分类图标 |
| 樱粉点缀 | `#E8A5B4` | 茶会页花瓣飘落、柔化点缀 |

每页有独立"色彩主角"：今日茶單偏抹茶绿+米白；茶品详情偏暖米+柿红；茶仓深色漆器黑+绿；茶会对角分割绿粉撞色。无蓝紫渐变。

## 字体

- 标题 / 茶名：`'Noto Serif JP', 'Noto Serif SC', serif`
- 正文 / UI：`'Noto Sans SC', -apple-system, BlinkMacSystemFont, sans-serif`
- 数据 / 代码（接口页）：`monospace`

## 圆角

卡片 `16px`，按钮 `12px`，胶囊 / Tab 选中 `999px`，茶碗/圆形头像 `50%`。

## 组件

- 茶品瀑布流卡 + 和菓子横滑
- 茶品详情 Hero 视差大图 + 涟漪动效 + 冲泡参数卡 + 步进器 + 吸底购买栏
- 弹性展开预约日历 + 时间段网格 + 坐席列表
- 收据式预约确认卡
- 茶仓深色模式 + 不规则拼贴网格 + 会员卡
- 茶会对角分割 Hero + 花瓣飘落 + 活动卡
- FAB 悬浮扫码按钮（脉冲光晕）
- 底部半屏抽屉（菜单）+ 毛玻璃遮罩
- 下拉刷新（绿叶旋转）

## 原生端侧交互（≥4 种）

底部 TabBar、返回栈导航（页面左右滑动过渡）、底部半屏抽屉、FAB、下拉刷新、长按按压反馈 — 共 6 种。

## 签名动效

1. 茶汤注入涟漪（加购触发）
2. 蒸汽粒子上升（茶碗悬浮）
3. 茶筅摆动（页面装饰）
4. 日历弹性展开
5. 花瓣飘落（茶会页）

组件级特效 12+：Tab 图标弹跳、数字滚动入场、卡片渐入级联、心型跳动、下拉箭头旋转、FAB 脉冲光晕、shimmer 占位、列表错峰淡入、Tab 下划线滑动、底部抽屉上滑、按钮按压缩放、进度点脉冲。所有 JSX / CSS 内联在 index.html；支持 `prefers-reduced-motion`。

## 页面结构（8 页）

1. 今日茶單 2. 茶品详情 3. 座席予約 4. 预约确认 5. 茶仓 6. 茶会 7. デザイン規範（设计规范页）8. API ドキュメント（接口文档页）。至少 5 页布局互不重复。

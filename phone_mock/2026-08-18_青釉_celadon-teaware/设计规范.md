# 青釉 · 设计规范

**形态：微信小程序**

> 日期：2026-08-18 · 方向：V2 手机 UI · 主题：茶器美学电商小程序

## 色彩系统

青釉瓷色系：灰绿釉色 + 陶土褐 + 米白，零蓝紫渐变。

| 角色 | 色值 | 用途 |
|------|------|------|
| 青瓷灰绿 | `#3E4A3A` | 主色（导航、标题、主按钮） |
| 釉绿浅阶 | `#5C6B50` / `#6B7A60` / `#7E8E6E` | 辅助色阶、标签 |
| 豆青 | `#8FA181` / `#9FB093` / `#A8B69A` | 浅色块、徽标底 |
| 陶土褐 | `#6D4C41` / `#7A5747` | 暖色强调、价格 |
| 赭粉 | `#A67B6D` / `#C9A68B` | 次级强调 |
| 鎏金 | `#C9A86C` | 点缀、徽章 |
| 米白 | `#EDE8DD` / `#f0f0f0` | 页面底色、卡片底 |
| 墨色 | `#1a1a1a` | 正文 |

## 字体

- 标题衬线：`'Noto Serif SC', serif`
- 正文：`'Noto Sans SC', -apple-system, system-ui, sans-serif`

## 页面结构（8 页，≥5 种差异化布局）

1. 首页 — Hero 轮播 + 快捷入口 + 瀑布流卡片（入场序列签名动效）
2. 分类页 — 左右分栏 + 吸顶筛选 Tab
3. 发现页 — Hero 渐变大图 + 标签筛选 + 瀑布流文章
4. 购物车 — 左滑列表操作 + 底部结算栏
5. 个人中心 — 渐变头像 + 环形进度（签名动效）+ 宫格菜单 + 横向浏览记录
6. 商品详情 — 视差滚动 Hero + 吸顶变色导航 + 吸底操作栏（签名动效）
7. 设计规范页 — 4 Tab（色彩/字体/间距/组件）
8. 接口文档页 — 5 个 API 可展开折叠

## 小程序端侧交互

- 右上角胶囊按钮（··· / ⊙）自定义导航栏，随页面透明→实色变化
- 页面栈 push/pop，右滑返回式过渡
- 底部 TabBar 5 入口，选中态弹性微动效 + 红点徽标
- 下拉刷新弹性回弹 + 加载转圈
- 左滑列表操作（收藏/删除）
- 半屏底部弹层（订单确认）、骨架屏、Toast

## 动效系统（12+ 组件级 + 3 个页面级签名）

首页入场错峰 fade-up、详情页 Hero 视差 + 导航变色、个人页环形进度生长、悬浮茶器浮动呼吸（多周期）、卡片 hover 发光位移、Tab 指示器弹性跳动、爱心缩放弹跳、按钮涟漪、轮播自动切换、数量加减按压反馈、光泽扫过、背景缓慢旋转。

## 健壮性

- RAF/定时器随 visibilitychange 暂停，卸载统一清理
- prefers-reduced-motion 降级
- JSX/CSS 全内联于 index.html

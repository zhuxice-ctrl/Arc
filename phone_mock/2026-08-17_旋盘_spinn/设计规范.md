## 色彩系统

荧光运动系（青柠荧光 + 炭黑 + 暖白 + 点缀橙），无蓝紫渐变；与同日 V1 羊皮纸暖系、V3 炭黑珊瑚粉系互不雷同。每页色彩主角：首页暖白底 + 青柠强调、详情炭黑全屏 + 青柠渐变、地图暖白 + 橙标记、社区炭黑卡片流、个人暖白 + 环形青柠进度、规范页灰阶色卡、接口页炭黑代码底。

## 字体

- 标题：系统无衬线粗体（`-apple-system, 'PingFang SC', 'SF Pro Display', sans-serif`），大字号大标题导航栏
- 正文：同上常规字重
- 数字 / 数据：等宽倾向，Tabular 风格

## 组件规范

- **手机外壳**：统一 iOS 原生外壳，状态栏 + 圆角屏幕，页面在其内切换。
- **大标题导航栏**：大字号标题 + 返回按钮，透明 / 吸顶变色。
- **底部 TabBar**：原生质感，4-5 项，选中态飞盘旋转微动效 + 青柠指示。
- **活动卡片**：圆角卡片 + 阴影分层，悬停 / 按压反馈。
- **全屏详情页**：大图 Hero + 底部上滑详情，视差滚动转场。
- **底部半屏抽屉**：场地信息上滑抽屉。
- **FAB 悬浮按钮**：青柠圆形，旋转展开快捷菜单。
- **环形进度条**：个人中心成就，描边动画。
- **模态弹窗**：底部面板弹入。

## 动效系统

12+ 组件级特效，物理 / 语义驱动：

1. 自定义光标（白环 + 青柠内点 + 多层发光，开屏居中，hover 三态，点击涟漪）
2. 飞盘旋转（首页 Tab 图标 / 下拉刷新）
3. Hero 圆盘浮动（惯性）
4. 详情页视差滚动
5. 下拉刷新飞盘旋转 + 阻尼回弹（弹簧 Hooke）
6. FAB 旋转展开菜单
7. 卡片错落入场序列
8. Tab 指示器滑动
9. 地图标记弹跳（阻尼）
10. 环形进度条描边动画
11. 底部抽屉滑入
12. 模态底部面板弹入
13. 报名按钮状态过渡

签名动效：首页入场序列 + 详情页视差滚动 + 下拉刷新飞盘旋转弹性。

## 原生端侧交互（≥4 种）

大标题导航栏 / 返回栈导航、底部 TabBar、全屏详情页转场、底部半屏抽屉、FAB 悬浮按钮、模态弹窗、下拉刷新——共 7 种原生 App 交互语言。

## 页面结构

8 个页面，统一手机外壳内可切换，至少 5 种非重复布局：

1. **首页**：活动信息流（Hero 悬浮圆盘 + 三列统计 + 卡片流）
2. **活动详情**：全屏大图 + 底部上滑详情 + 报名吸底
3. **场地地图**：地图 + 底部抽屉场地信息
4. **队伍 / 社区**：3 Tab 切换（卡片 / 列表 / 网格三种形态）
5. **技巧教学**：横向画廊 + 教学列表
6. **个人中心**：头像 Hero + 成就网格 + 分组列表 + 环形进度
7. **设计规范页**：色卡 + 排版 + 间距三段式
8. **接口文档页**：API 折叠列表 + 代码块（炭黑底）

## 技术栈

React 18 + Babel standalone（内联 JSX）+ 纯 CSS（内联 `<style>`），单文件 index.html。CDN：feishu-static miaoda coding-unpkg-sdk。

# 弓道志·传统射箭训练日志 — 设计规范

形态：原生 App

## 主题

传统弓道射箭训练日志 App：以「一射一志」为产品理念，记录每次射箭的姿势、得分、心境，配合弓弦拖拽签名动效将拉弓-释放过程转化为数据录入交互。

## 动效系统

### CSS Keyframes（10 组）

| 名称 | 功能 |
|------|------|
| `fadeInUp` | 页面/卡片入场上浮 |
| `fadeIn` | 元素淡入 |
| `slideInRight` | 侧拉面板滑入 |
| `pulse-soft` | 录入按钮柔和脉动 |
| `arrow-drop` | 拉弓箭矢下落引导 |
| `target-ripple` | 靶心命中涟漪扩散 |
| `flip-up` | 卡片翻转 |
| `progress-ring` | 进度环填充 |
| `bow-aim` | 弓弦瞄准蓄力 |
| `string-vibrate` | 弓弦释放振动 |

### 签名动效：弓弦拖拽

核心交互动效：用户拖拽弓弦（触控/鼠标），弦的弯曲程度映射到拉弓力度，释放时触发 `string-vibrate` 振动 + `target-ripple` 命中反馈，同时将力度数据写入训练记录。物理模型：弦张力 = 拖拽距离 × 弹性系数，释放后阻尼振荡衰减。

### 组件级特效（≥12）

1. 弓弦拖拽拉弓（多点触控 + 弹性物理）
2. 弓弦释放振动（阻尼振荡）
3. 靶心命中涟漪扩散
4. 拉弓蓄力瞄准（bow-aim 渐变）
5. 训练卡片入场上浮
6. 侧拉面板滑入
7. 进度环填充动画
8. 卡片翻转切换
9. 录入按钮柔和脉动
10. 箭矢下落引导
11. Tab 切换过渡
12. 成就勋章弹出
13. 列表项交错入场

## 技术栈

- 纯 vanilla 单文件 HTML（~117KB）
- SVG 绘制靶环 + 弓弦
- CSS Custom Properties 管理设计令牌
- Touch Events + Pointer Events 拖拽
- requestAnimationFrame 驱动物理模拟
- prefers-reduced-motion 降级支持
- localStorage 持久化训练数据

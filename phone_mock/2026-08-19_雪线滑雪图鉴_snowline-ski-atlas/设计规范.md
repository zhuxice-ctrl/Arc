# 雪线·滑雪图鉴 · 设计规范

## 作品信息
- **主题**：高山滑雪场图鉴 + 个人滑行日志
- **日期**：2026-08-19
- **方向**：V2 手机 UI
- **形态**：微信小程序
- **技术栈**：纯 vanilla HTML + CSS + JS（单文件，无外部依赖）

## 设计母题
一本可以随身携带的高山滑雪场图鉴。滑雪者打开小程序查看今日雪况，浏览雪场详情，在滑道图上切换难度层级，记录每次滑雪日志，积累赛季统计。产品逻辑围绕「发现雪场 → 了解雪况 → 规划出行 → 记录体验 → 回顾赛季」展开。

## 色彩系统
| 变量 | 色值 | 用途 |
|------|------|------|
| --snow-white | #F8FAFD | 雪白背景 |
| --ice-blue | #B0C4DE | 冰蓝灰主色 |
| --ice-blue-deep | #6B8DAE | 冰蓝深色 |
| --ice-blue-dark | #3D5A73 | 冰蓝暗色 |
| --pine-green | #2D5016 | 松绿强调色 |
| --pine-green-light | #4A7C2E | 松绿亮色 |
| --amber | #D4A017 | 暖琥珀（木屋/住宿） |
| --amber-light | #E8C44D | 琥珀亮色 |
| --gondola-red | #C0392B | 缆车红（状态标记） |
| --trail-green | #4A7C2E | 初级道绿色 |
| --trail-blue | #4A90D9 | 中级道蓝色 |
| --trail-black | #2C2C2C | 高级道黑色 |

**色彩逻辑**：雪山冬季四色体系——雪（白色系）、冰（蓝色系）、松（绿色系）、暖（琥珀色系）。冰蓝承担主品牌色和 UI 框架，松绿用于强调和自然元素，琥珀用于温暖对比（木屋/住宿信息），缆车红用于状态警告。

## 字体系统
```
--font-ui: -apple-system, BlinkMacSystemFont, "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", sans-serif
--font-mono: "SF Mono", "JetBrains Mono", "Menlo", "Consolas", monospace
```
UI 文字使用苹方系统字族，数字（海拔/温度/趟数）使用等宽字体，保证数据对齐和可读性。

## 微信小程序 UI 约定
- **胶囊按钮**：右上角，三点+加号
- **自定义导航栏**：44px 高，标题居中
- **底部 TabBar**：4 个标签（雪况 / 雪场 / 记录 / 我的），84px 高含安全区
- **半屏弹层**：点击雪场卡片从底部弹簧上升
- **页面宽度**：390px（iPhone 14 标准）
- **安全区**：底部 34px

## 产品流程
```
打开小程序
  ↓
雪况页（今日天气 + 推荐雪场雪况）
  ↓ 下拉刷新
雪场页（搜索 + 筛选 + 雪场列表）
  ↓ 点击雪场
半屏弹层（雪场详情 + 滑道图 + 缆车信息）
  ↓ 切换难度图层
记录页（添加滑行日志：日期/雪场/趟数/天气/备注）
  ↓ 保存到 localStorage
我的页（赛季统计：天数/趟数/最陡坡度/最远雪场）
```

## 动效系统（12+ 项组件级动效）
1. Tab 切换横向滑动
2. 半屏弹层弹簧上升
3. 下拉刷新弹性回弹
4. 雪场卡片入场渐显
5. 滑道图层切换雪花飘散
6. 按钮按压回弹
7. 收藏星形弹跳
8. Toast 提示弹出
9. 搜索筛选 chip 激活
10. 天气数据数字滚动
11. 日志列表插入动画
12. 赛季统计进度条动画

## 自定义光标
雪花形状，开页显示在屏幕中央，高对比度，z-index 最高。

## 数据持久化
滑雪日志使用 localStorage 存储，支持添加/查看/删除，页面刷新后数据保留。

## 健壮性
- requestAnimationFrame 动画，页面隐藏时暂停
- 完整支持 prefers-reduced-motion
- 零外部依赖，零未定义引用
- 所有按钮真实可用（搜索筛选/收藏/日志保存/导出摘要）

接口文档
GET /api/today
获取今日饲养概览，包括龄期、生长进度、饱食度、待办列表和环境数据。
响应示例
{ "date": "2026-08-19", "day": 15, "instar": "4龄第3天", "growth": 60, "satiety": 0, "maxFeed": 3, "todos": [ { "id": "feed", "text": "喂桑叶", "done": false }, { "id": "clean", "text": "清理蚕沙", "done": false }, { "id": "temp", "text": "记录温度", "done": false }, { "id": "observe", "text": "观察蜕皮", "done": false } ], "env": { "temp": 25, "humidity": 65 } }
POST /api/feed
提交一次喂食操作，增加饱食度和生长进度。每日最多喂食3次。
请求参数
amountnumber喂食量（默认1次=33%）
响应示例
{ "success": true, "satiety": 1, "growth": 61, "isFull": false, "instarUp": false }
GET /api/journal
获取日志列表，支持按月份筛选和分页。
请求参数
monthstring月份，格式 YYYY-MM
pagenumber页码，默认1
limitnumber每页数量，默认20
响应示例
{ "total": 6, "items": [ { "id": "j001", "date": "2026-08-19", "instar": "4龄第3天", "content": "今天蚕体长到约5cm…", "photos": [] } ] }
POST /api/journal
创建一条新的日志记录。
请求参数
datestring日期 YYYY-MM-DD
instarstring龄期
contentstring日志正文
photosarray图片URL数组
响应示例
{ "success": true, "id": "j007", "createdAt": "2026-08-19T14:30:00Z" }
GET /api/breeds
获取家蚕品种列表，支持关键词搜索。
请求参数
keywordstring搜索关键词（可选）
响应示例
{ "total": 6, "items": [ { "id": "b001", "name": "菁松×皓月", "cocoonColor": "白茧", "feature": "丝质优良，茧层率高", "difficulty": "入门" } ] }
GET /api/breeds/:id
获取单个品种的详细信息。

idstring品种ID

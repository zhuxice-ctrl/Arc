# 养蚕志·桑蚕日记 — 设计规范

形态：原生 App

## 一、设计概念

**核心母题**：陪伴养蚕全生命周期的记录工具。

家蚕从蚁蚕到化蛾的完整生命周期约 40-50 天，每个阶段有明确的饲养任务（喂叶、清沙、控温、观察蜕皮）。App 以"今日状态 + 任务驱动"为首页结构，围绕"喂桑叶"这一最高频动作设计签名交互——拖动桑叶到蚕嘴边，蚕实时啃食，饱食度上升。

**视觉来源**：桑皮纸质感 + 桑叶绿 + 茧金。色彩取自真实养蚕场景——桑叶的绿、蚕体的粉白、蚕茧的金黄、桑皮纸的米白。

## 二、色彩系统

| 色值 | 名称 | 用途 |
|------|------|------|
| #FAF6EE | 软米白 | 主背景，仿桑皮纸 |
| #4A7C3A | 桑叶绿 | 主色调，TabBar 选中、强调元素 |
| #2D5A1E | 深桑绿 | 导航选中态、标题强调 |
| #F5F0E8 | 丝白 | 卡片背景 |
| #D4A84B | 茧金 | 成就徽章、里程碑强调 |
| #F9EDE0 | 蚕体粉白 | 蚕 SVG 填充 |
| #2C2416 | 墨黑 | 正文文字 |
| #8B7E6A | 暖灰 | 次要文字 |
| #C9871E | 琥珀 | 警告、提醒 |
| #E8F0E0 | 浅桑绿底 | 选中态背景 |

色彩逻辑：桑叶绿承担主交互色和导航选中；茧金承担成就和里程碑；琥珀承担警告。不使用蓝紫渐变。

## 三、字体系统

| 字体 | 用途 | 字号 |
|------|------|------|
| Noto Serif SC | 标题 / 品种名 / 龄期名 | 22px Bold |
| -apple-system, PingFang SC, Noto Sans SC | 正文 / UI | 14px Regular / 16px Medium |
| SF Mono / Roboto Mono | 数字 / 温度 / 天数 / 进度 | 20px Bold |

字体逻辑：衬线体用于品种名和龄期名，传达文化感和生命仪式感；无衬线用于日常 UI；等宽用于数据展示，保证数字对齐。

## 四、动效系统

### 缓动曲线

| 名称 | 曲线 | 用途 |
|------|------|------|
| Bounce Spring | cubic-bezier(0.34, 1.56, 0.64, 1) | 弹性反馈：Tab 弹跳、勾选弹跳、生长动画 |
| Page Enter / Exit | cubic-bezier(0.32, 0.72, 0, 1) | 页面栈 push/pop 转场 |
| Standard Ease | cubic-bezier(0.4, 0, 0.2, 1) | 通用过渡：进度条填充、颜色变化 |

### 动效清单

| 动效 | 时长 | 触发 | 类型 |
|------|------|------|------|
| 桑叶拖动喂蚕 | 持续 | 用户拖动桑叶到蚕头 80px 内 | 签名交互 |
| 蚕啃食动画 | RAF 驱动 | 桑叶靠近蚕头 | 材质表现 |
| 桑叶咬痕扩大 | RAF 驱动 | 啃食过程中 clip-path 扩大 | 状态反馈 |
| 蚕体蠕动 | RAF 驱动 | 啃食过程中 scaleY 微变化 | 材质表现 |
| 桑叶碎屑粒子 | RAF 驱动 | 啃食时 6 颗碎屑从咬痕处飞溅 | 状态反馈 |
| Tab 切换弹跳 | 0.45s | 点击 TabBar | 操作确认 |
| 页面淡入淡出 | 0.3s | Tab 切换 | 内容出现 |
| 页面栈 push | 0.35s | 进入品种详情/设计规范/接口文档 | 空间关系 |
| 待办勾选弹跳 | 0.4s | 点击待办项 | 操作确认 |
| 待办文字划线 | 0.3s | 勾选后 | 状态反馈 |
| 半屏弹层上升 | 0.4s spring | 点击日志条目/FAB 写日志 | 空间关系 |
| 饱食度进度条 | 0.8s spring | 喂食完成 | 状态反馈 |
| 生长进度条 | 0.8s spring | 喂食完成 | 状态反馈 |
| 成就光环脉冲 | CSS 无限循环 | 已解锁成就 | 情绪建立 |
| 蚕体呼吸 | CSS 无限循环 | idle 状态 | 情绪建立 |
| 下拉刷新蚕沙旋转 | 拖动驱动 | 下拉超过阈值 | 操作确认 |

### prefers-reduced-motion 降级

- 拖动喂蚕降级为点击桑叶直接 +33% 饱食度
- 蚕啃食动画跳过，直接更新饱食度
- 所有 CSS 动画通过 `@media (prefers-reduced-motion: reduce)` 降级为瞬时变化

## 五、组件规范

### TabBar
- 底部固定，4 个 Tab（今日/蚕记/蚕谱/我的）
- 选中态：深桑绿 #2D5A1E + 图标 scale 弹跳
- 未选中：暖灰 #8B7E6A

### 按钮
- 主按钮：桑叶绿背景 + 丝白文字
- 次按钮：浅桑绿底 + 深桑绿文字

### 卡片
- 丝白背景 #F5F0E8
- 圆角 16px
- 无阴影或极淡阴影

### 进度条
- 桑叶绿填充 + 0.8s spring 缓动
- 背景为浅桑绿底

### 半屏弹层
- 从底部 spring 上升（0.4s）
- 背景半透明遮罩

## 六、技术栈

- 纯 vanilla 单文件 HTML（无 React / Babel / CDN 依赖）
- Noto Serif SC / Noto Sans SC 通过 miaoda.feishu.cn 字体服务加载
- localStorage 持久化：喂食状态、待办勾选、日志条目
- 所有 SVG 内联绘制（蚕体、桑叶、品种示意图、成就徽章）
- 页面可见性监听：document.hidden 时暂停啃食 RAF

# 设计规范

**形态：微信小程序**

---

## 一、品牌概述

**榫卯堂** — 传统木作文化的数字传承平台。以中国古代榫卯木结构为核心主题，面向木艺爱好者、文化学习者和手工艺从业者，提供榫卯图鉴、匠师工坊、研习进度等服务。

**品牌调性**：温润 · 沉静 · 匠心 · 传承

---

## 二、色彩系统

### 主色 · 檀木棕 `#8B4513`
- 用途：主要按钮、强调文字、图标主色、品牌标识
- 语义：沉稳、厚重、木材本色

### 辅助色 · 赤铜 `#C97145`
- 用途：次级强调、图标、标签、链接、交互态
- 语义：温暖、手作、赤铜工具

### 点缀色 · 砂金 `#B8860B`
- 用途：稀有标记、金标、荣誉、难度五星
- 语义：珍贵、传世、金缮质感

### 警示色 · 朱砂 `#C94C2B`
- 用途：错误提示、删除操作、紧急提醒
- 语义：中国传统朱砂印色

### 背景色 · 米白 `#F5EDE4`
- 用途：页面主背景
- 语义：温润如宣纸

### 表面色 · 素白 `#FFFCF7`
- 用途：卡片背景、毛玻璃表面
- 语义：素雅洁净

### 文字色 · 深褐 `#2B1F17`
- 用途：主标题、正文
- 语义：墨色木刻

### 次级文字 · 灰褐 `#6B5A4A`
- 用途：副标题、辅助说明

### 弱文字 · 浅褐 `#9A8A7A`
- 用途：占位符、时间戳、次要信息

---

## 三、字体排印

### 展示字体：Noto Serif SC
- 字重：700（大标题）、600（小标题）
- 用途：页面大标题、卡片标题、数字统计、品牌名
- 气质：宋体刻本韵味，呼应古籍木刻传统

### 正文字体：Noto Sans SC
- 字重：400（正文）、500（强调）、600（小标题）
- 用途：正文描述、按钮文字、标签、辅助信息
- 气质：清晰易读，现代感与传统兼容

### 字号层级
| 层级 | 字号 | 字重 | 用途 |
|------|------|------|------|
| 特大标题 | 32px | 700 serif | 首页 Hero |
| 页面标题 | 28px | 700 serif | 二级页标题 |
| 区块标题 | 20px | 700 serif | 内容分区标题 |
| 卡片标题 | 15-17px | 600 serif / 600 sans | 列表卡片 |
| 正文 | 13-14px | 400 sans | 段落描述 |
| 辅助 | 11-12px | 400 sans | 标签、时间、说明 |
| 微型 | 10px | 400 sans | 角标、计数 |

## 四、组件规范

### 按钮
- **主按钮**：渐变背景（#a0522d → #8b4513），圆角 12px，阴影 0 4px 12px rgba(160,82,45,0.3)
- **次按钮**：透明底 + 1.5px 实色边框，圆角 12px
- **高度**：44px（标准）、40px（紧凑）
- **点击态**：scale(0.96) + 阴影减弱，150ms 过渡

### 卡片
- 圆角：14px（标准）、18px（大卡）
- 阴影：0 4px 14px rgba(90,58,32,0.06)
- 悬浮态：translateY(-4px) + 阴影增强，200ms
- 背景：#fff / 米白

### 标签 Tag
- 圆角：20px（药丸形）
- 字号：11px
- 内边距：3px 10px
- 变体：默认（棕底棕字）、金色、红色

### 列表
- 行高：54px / 56px
- 分隔线：0.5px solid #f0e6d8
- 两侧留白：16px

### 输入框
- 圆角：14px
- 高度：44px
- 图标色：#b0a090

## 五、间距系统

基于 4px 基准栅格：
- 4 / 8 / 12 / 16 / 20 / 24 / 32 / 40 / 48

页面边距：16-20px
卡片内边距：12-16px

## 六、动效规范

### 动画曲线
- 标准：`cubic-bezier(.2,.8,.2,1)`（0.3-0.35s）
- 弹性：`cubic-bezier(.34,1.56,.64,1)`（0.25-0.4s）
- 慢速入场：`cubic-bezier(.2,.8,.2,1)`（0.6-1.2s）

### 核心动效
| 动效 | 时长 | 曲线 | 说明 |
|------|------|------|------|
| 页面栈切换 | 0.35s | 标准 | 右入左出 |
| 榫卯拼装 | 1.2s | 标准 | 木块滑入咬合 |
| 榫卯拆解 | 0.8s | 标准 | 左右分离 |
| TabBar 选中 | 0.3s + 2s 循环 | 弹性 + ease-in-out | 上浮 + 脉冲 |
| 卡片悬浮 | 0.2s | ease-out | 上移 4px |
| 下拉刷新 | 弹性阻尼 0.5 比例 | - | 拉动 50px 阈值触发 |
| 入场序列 | 0.5-0.6s × stagger | 标准 | 逐项延迟 60-80ms |
| 打字机 | 120ms × 字数 | 随机 80ms 抖动 | 模拟手工敲击 |
| 数字计数 | 1.5-2.2s | 三次方缓出 | 数据统计 |
| 环形进度 | 1s | 标准 | 描边 dashoffset |
| 光泽扫过 | 3s · 1s 延迟 | ease-in-out 循环 | 精选卡片高光 |
| 脉冲环 | 2s | ease-out 循环 | Tab / 头像 |
| 浮动 | 4s | ease-in-out 循环 | 热门卡片上下浮动 |
| 视差滚动 | 实时 | 0.3 速率 | Hero 图慢移 |
| 吸顶变色 | 0.3s | 标准 | 导航栏背景显现 |

### 自定义光标
- 白环 + 琥珀内点 + 多层发光
- 悬停态：环放大至 60px + 变琥珀色
- 点击：涟漪扩散 600ms

## 七、小程序端侧规范

### 胶囊按钮
- 尺寸：87 × 32px，圆角 16px
- 位置：右上，距顶 54px，距右 12px
- 样式：毛玻璃半透明白底 + 细边框
- 深色模式：半透明白底（低透明度）

### 导航栏
- 高度：44px（状态栏 44px 之下）
- 标题：居中，17px 600 字重
- 返回按钮：28 × 28px，左对齐

### TabBar
- 高度：56px
- 项数：4 个
- 图标：24px，标签 10px
- 选中态：图标上浮 2px + 放大 1.1 倍 + 脉冲点

### ActionSheet
- 圆角：20px 20px 0 0
- 行高：56px
- 取消项：上方 8px 间距，加粗主色文字

### 下拉刷新
- 指示高度：60px
- 触发阈值：50px
- 回弹动画：0.3s 贝塞尔

### 左滑操作
- 操作宽度：80px × N
- 滑动距离阈值：80px
- 动画：0.3s 贝塞尔

### 吸底操作栏
- 安全区：底部 24px（home indicator）
- 毛玻璃背景
- 主按钮 + 2-3 个图标按钮

---

## 八、无障碍

- 支持 `prefers-reduced-motion`：开启时关闭自定义光标、动画降级为静态 / 最小动效
- 文字与背景对比度 ≥ 4.5:1
- 可点击区域 ≥ 44 × 44px

# 口袋天文台 Pocket Observatory · 设计规范

> 2026-08-16 · V2 · 手机应用 UI

形态：原生 App

## 主题

星空观测手机 App，围绕今夜天象、星座辨认、行星追踪、观测日志

## 配色

午夜黑 #0D0F14 + 月白 #F2EFE6 + 彗星橙 #FF7A1A + 极光绿 + 黄道金

（严格禁蓝紫渐变）

## 字体

Cormorant Garamond + Inter + JetBrains Mono

## 动效设计

SVG 星轨描边动画 / 自定义光标 / 星座连线动画 / 行星轨道运行

## 技术实现

- 单文件 HTML 实现（CSS + JS 全内联）
- 自定义光标开页即居中显示
- RAF 统一管理，visibilitychange 自动暂停/恢复
- 支持 prefers-reduced-motion 降级
- 无外部 JSX 引用，无外部本地文件依赖

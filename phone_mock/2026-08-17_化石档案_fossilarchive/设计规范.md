# 化石档案 Fossil Archive · 设计规范

形态：原生 App

> 方向：V2 手机 UI · 形态：原生手机 App · 主题：古生物化石收藏与鉴定
> 配色基调：土褐 + 骨白 + 铜绿 + 深褐 + 锈红（无蓝紫渐变）

## 色彩系统

| 角色 | 色值 | 用途 |
|------|------|------|
| 深褐（底） | `#2E211A` | App 主背景，沉稳地质感 |
| 近黑 | `#1A1410` / `#1A1814` | 深色区块、状态栏 |
| 土褐（主色） | `#6B4F3A` | 导航栏、主按钮、品牌色 |
| 浅土褐 | `#7B5A45` / `#8B6A55` | 次级表面、卡片边框 |
| 骨白 | `#EDE4D3` | 正文文字、浅色表面 |
| 铜绿（强调） | `#4A7C6F` | 鉴定状态、成功态、强调标签 |
| 浅铜绿 | `#5A8B7A` / `#3D6B5E` | 铜绿渐变、次级强调 |
| 锈红 | `#A0522D` | 警示、自定义光标内点、危险操作 |
| 暖橙 | `#FFBD2E` | 高亮、收藏星标、重点数据 |
| 深绿底 | `#1F2A24` | 铜绿区块底色 |
| 近黑面板 | `#111111` | 弹窗、底部 Sheet |

## 字体排印

- UI 字体：`'Inter', -apple-system, system-ui, sans-serif`
- 标题/品牌：`'Playfair Display', Georgia, serif`
- 等宽（数据/代码）：`'JetBrains Mono', monospace`

## 原生交互语言（>4 种）

大标题导航栏、底部 TabBar（含中央凸起按钮）、全屏详情页转场、下拉刷新、长按快捷菜单、FAB 悬浮操作球、分段控制、底部 Sheet。

## 组件规范

- 化石图鉴卡：圆角 20px，深褐表面 + 顶部化石图，铜绿年代标签
- 详情页 Hero：旋转光环（铜绿 SVG）+ 扫描动画，底部浮动面板上滑
- 采集地图：标记点脉冲（锈红），底部横滑记录卡
- AI 鉴定：扫描线动画 + 结果卡渐入
- 收藏馆：网格/列表双视图切换，画廊式拼贴

## 动效系统（12+ 组件级 + 2 签名动效）

1. 尘土颗粒飘浮（签名 1，首页背景）
2. 旋转光环 + 扫描（签名 2，详情页 Hero）
3. 下拉刷新弹性回弹
4. 心跳缩放（重要元素）
5. 卡片悬停抬起
6. Tab 图标弹性缩放
7. 进度条缓动
8. 标记点脉冲
9. 喜欢按钮弹跳
10. 淡入上移错峰
11. 骨架 shimmer
12. 粒子脉冲
- 自定义光标：白环 + 锈红内点 + 多层发光，悬停变形，点击涟漪，z-index 最高

## 页面结构（8 页，≥5 个独特布局）

1. 首页（图鉴信息流）— Hero 对角分割卡片 + 地质年代横滑芯片 + 垂直卡片堆叠
2. 分类图鉴 — 左年代侧栏 + 右瀑布流网格（左右分栏）
3. 化石详情 — 全屏转场 + 旋转光环 + 底部浮动面板 + 分段控制 + 长按菜单
4. 野外采集 — 地图标记点 + 底部横滑记录卡 + FAB
5. AI 鉴定 — 上传区 + 扫描线 + 鉴定结果卡
6. 个人收藏馆 — 网格/列表双视图 + 画廊式拼贴
7. 设计规范页 — 色彩/字体/组件/间距
8. 接口文档页 — 三 Tab 分类 + 端点列表 + 响应示例

## 健壮性

- 零未定义引用；JSX 全部内联在 `<script type="text/babel">`
- RAF/定时器统一清理，visibilitychange 自动暂停
- prefers-reduced-motion 降级
- 高频鼠标事件直接操作 DOM transform

# 泉阁 · 古钱币鉴赏柜 设计规范

## 一、设计母题

随身钱币鉴赏柜微信小程序。整个界面是一只分格抽屉的古钱收藏柜——核心对象是一枚古钱币，围绕"转动包浆显光泽"这一鉴赏最核心的把玩动作展开。每枚钱币的包浆独一无二，转出不同的光泽流。视觉语言来自铜钱包浆、天鹅绒展托与钱币学图录，金属冷硬质感贯穿全局。

## 二、色彩系统（金属包浆系）

| 角色 | 色值 | 用途 |
|------|------|------|
| 展托墨绿（底） | `#0f1410` / `#1a1408` | 全局深底，模拟天鹅绒展托 |
| 鎏金（主强调） | `#d4af37` | 标题、高亮钱币、主操作、分割线 |
| 浅金 | `#e8d5a0` / `#a07820` | 次级强调、标签底 |
| 牙白素绢（正文） | `#e8e2d6` | 主要文字、钱币名 |
| 铜绿锈 | `#4a7c59` / `#5ac48a` | 包浆光泽、朝代标签 |
| 古铜 | `#5c4d2d` / `#8a6a4a` | 暗铜钱币面、次级容器 |
| 铁锈红 | `#e06555` / `#a05030` | 朱砂锈、警示/涨跌 |
| 银白泽 | `#c0c0c8` | 银质钱币、数据高光 |
| 深褐 | `#3d3219` / `#2e1c17` | 卡片底、边框 |

配色逻辑：鎏金承担层级与主操作语义，铜绿/铁锈/银白承担材质与状态分类（对应青铜/铁/银钱币），墨绿展托承担氛围。无蓝紫渐变，与近期暖纸墨朱砂木质作品完全错开。

## 三、字体系统

| 字族 | 用途 |
|------|------|
| STKaiti / KaiTi（楷体） | 钱币名、朝代、标题——呼应钱文书法气质 |
| -apple-system / PingFang SC | UI 正文、按钮、标签 |
| monospace | 数值（估值、年份、计数）——钱币学数据感 |
| Times New Roman（衬线） | 英文小字标注 |

字级：大标题 22-24px、区块标题 16-18px、钱币名 15px、正文 13-14px、数据 12-13px。楷体仅用于与钱币直接相关的命名，不滥用。

## 四、空间与信息结构

- 首屏：今日收藏柜（非通用首页模板）——顶部自定义导航栏（胶囊按钮位）+ 今日统计三栏（藏币总数/涉及朝代/估值）+ 分屉网格（第一屉·唐宋遗珍，6 格钱币）
- 导航：底部 3 Tab（鉴赏柜 / 图谱 / 我的）+ 页面栈 push/pop（入册/行情/规范/接口）
- 弹层：半屏弹层（钱币详情）+ ActionSheet（排序/操作）
- 分屉结构：钱币按朝代分屉陈列，模拟实物收藏柜抽屉

## 五、签名动效：转动包浆

核心记忆点。点击钱币进入半屏详情，详情顶部为 canvas 钱币面：

- 拖动旋转钱币，包浆光泽（铜绿 `#4a7c59` / 银白 `#c0c0c8` / 铁锈 `#a05030` / 鎏金 `#d4af37`）随旋转角度流动交替显现
- 每枚钱币有独立 `patinaColors` 数组（5 色），转出不同的光泽分布
- `drawPatina(angle)` 按 angle 重绘 canvas，转动速度影响光泽流动强度
- 带惯性阻尼，松手后缓动停止
- `prefers-reduced-motion` 降级为静态包浆快照（固定一帧光泽）

## 六、动效语言

| 动效 | 触发 | 性格 |
|------|------|------|
| 转动包浆光泽流动 | 拖动旋转钱币 | 签名·金属光泽物理 |
| 半屏弹层弹簧上升 | 点钱币 | 小程序原生 spring |
| 页面栈 push/pop 滑动 | pushPage / 返回 | 层级转场 |
| 下拉刷新弹性回弹 | 顶部下拉 | 小程序原生弹性 |
| 左滑操作弹簧 | 列表项左滑 | 操作揭示 |
| 包浆提示脉冲 | 详情进入 | hintPulse 引导 |
| 钱币按下缩放 | 点按钱币格 | 0.95 缩放反馈 |

动效功能性优先：状态反馈、空间关系、操作确认。无装饰粒子、无 Ken Burns、无整图缩放。`prefers-reduced-motion` 下旋转键动画、脉冲、弹性均降级。

## 七、端侧交互（微信小程序形态，6 种）

1. 胶囊按钮 + 自定义导航栏（右上角更多操作）
2. 底部 TabBar（3 Tab：鉴赏柜 / 图谱 / 我的）
3. 半屏弹层 / ActionSheet（钱币详情、排序操作）
4. 页面栈 push/pop 转场（入册 / 行情 / 规范 / 接口）
5. 下拉刷新弹性（pull-indicator + spinner）
6. 左滑操作（swipe-cell + swipe-actions）

## 八、内容真实性

- 6 种古钱：开元通宝（唐）/ 宋元通宝（北宋）/ 崇宁通宝（北宋徽宗）/ 永乐通宝（明）/ 康熙通宝（清）/ 乾隆通宝（清）
- 品相术语：美品 / 极美品 / 近未流通 / 上品 / 中品
- 材质：青铜 / 铁 / 银 / 黄铜（materialClass 区分钱币面色）
- 朝代年表：唐宋元明清（图谱页速查）
- 每枚钱币含独立包浆描述（如"铜绿厚浆，间有红斑"）与 patinaColors
- 无 Lorem Ipsum / Sample / Feature One

## 九、技术栈

- 纯 vanilla 单文件 HTML（无 React / Babel / 外部 CDN 依赖）
- canvas 2D 实现包浆光泽旋转
- localStorage 持久化鉴赏柜（getItem / setItem）
- 390px 目标宽度 + 414px 邻近尺寸自检（均无横向溢出）
- 健壮性：RAF/定时器随可见性暂停且卸载取消，高频事件直接操作 DOM，支持 prefers-reduced-motion

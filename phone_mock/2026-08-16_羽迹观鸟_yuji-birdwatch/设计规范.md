# 羽迹 · 城市观鸟 — 设计规范

形态：微信小程序

- 日期：2026-08-16
- 方向：手机 UI（V2）
- 主题：城市观鸟爱好者的观察记录与鸟种图鉴微信小程序

## 色彩系统

| 角色 | 色值 | 用途 |
|------|------|------|
| 主色（晨曦橙） | `#F97316` | 强调、CTA、选中态 |
| 深橙 | `#E85D04` / `#B54708` | 主色层次、悬停 / 按下 |
| 亮橙 | `#FF8F33` | 渐变过渡、辅强调 |
| 米白 | `#FFFBF5` / `#FAF3E6` | 页面底色、卡片表面 |
| 暖橙面 | `#FFF0E0` | 次级表面、选中底 |
| 苔绿（图鉴页主角） | `#3A5546` / `#4A6B56` | 图鉴页头部、冷色页主角 |
| 黛青灰（暗色页主角） | `#40382D` / `#5A5144` / `#2E271E` | 个人中心暗色头部、正文深色 |

整体为晨曦橙 + 米白 + 黛青灰的自然色系，每页有自己的色彩主角：首页暖橙、图鉴苔绿、个人中心暗墨。严格未使用蓝紫渐变。

## 字体

- 标题：`'Noto Serif SC', serif`
- 正文：`'Noto Sans SC', -apple-system, BlinkMacSystemFont, sans-serif`
- 等宽：`'JetBrains Mono', monospace`

## 小程序端侧布局

- 容器：统一手机外壳 + 右上角胶囊按钮（··· / ⊙）自定义导航栏，导航栏随页面变化（透明 / 渐变 / 吸顶变色）
- 端侧交互（7 种）：页面栈 push/pop 切换、底部 TabBar（4 项 + 选中弹跳）、ActionSheet 半屏动作面板、下拉刷新弹性回弹、吸顶 Tab、骨架屏加载、底部安全区主按钮

## 页面结构（8 页，布局各异）

1. 首页 — 晨曦橙 Hero + 羽毛飘落入场 + 四宫格快捷 + 观察卡片流（下拉弹性刷新）
2. 鸟种图鉴 — 苔绿头部 + 吸顶 Tab 分类 + 瀑布流网格 + 骨架屏
3. 观察详情 — 视差滚动 Hero + 音频波形播放器 + 吸底操作栏
4. 记录地图 — 浮动面板 + 地图热点 Pin + 脉冲 Ping
5. 观鸟活动 — 卡片堆叠 + 时间轴 + 悬浮 FAB
6. 个人中心 — 暗色头部 + 环形进度 + 宫格入口 + 列表组
7. 设计规范 — 色彩 / 字体 / 组件 / 间距
8. 接口文档 — 左右分栏（左导航 + 右内容）

至少 5 个页面有独特非重复布局结构。

## 动效系统

羽毛飘落入场、Hero 视差滚动、下拉弹簧回弹、Tab 弹跳、卡片 hover 缩放、环形进度描边、音频波形脉冲、骨架屏 shimmer、ActionSheet 滑入、太阳呼吸光晕、心跳扩散、点赞心形粒子爆裂、地图 Pin 脉冲。基于弹簧 / 惯性 / 阻尼 RAF 积分器或主题语义（羽毛飘落 / 鸟鸣频谱 / 振翅）。动效周期各不相同。

全部 RAF / 定时器随 visibilitychange 暂停、卸载取消；快速操作不叠加定时器；mousemove 直接操作 DOM transform；支持 prefers-reduced-motion。JSX 全部内联在 `<script type="text/babel">` 中。

# 设计规范 · 方寸印稿（微信小程序）

形态：微信小程序｜日期：2026-08-20

## 一、设计母题

篆刻印稿设计与钤印工具。整个小程序是一方架在印床上的石章：查篆字 → 设计印稿（选字 / 朱白文 / 章法 / 边栏）→ 长按钤印（力度决定印色浓淡与飞白）→ 收入个人印谱。视觉来源是篆刻工作坊实物——宣纸、印泥缸、寿山/青田石章、印床、封泥、线装印谱。

## 三、字体

- 标题：衬线宋体感（`"Songti SC","STSong",serif`），讲求篆刻的笔墨意趣
- 正文：系统无衬线（`-apple-system,"PingFang SC",sans-serif`）
- 数字：`font-variant-numeric: tabular-nums`，精密计量（钤印时长、印谱计数）

## 四、空间逻辑

- 印台首页：工作台式，印床石章俯视为视觉中心，非「问候语+搜索+Banner」模板
- 印谱页：线装书式网格，带书脊分隔线，强调「印存」档案感
- 钤印页：宣纸居中、吸底操作栏，强调一次专注的落印动作

## 五、签名动效：钤印

吸底「钤印」按钮长按：
- 按压时长 < 0.8s → 印色浅淡缺角（反馈「过轻，印文未全」）
- 0.8–1.8s → 印面饱满带自然飞白（反馈「恰到好处，印文饱满」）
- > 2.5s → 印泥淤积漫漶（反馈「过重，印泥漫漶」）
- 每次生成略有随机差异（飞白位置、浓淡抖动），鼓励反复比较
- `prefers-reduced-motion`：降级为单击直接呈现完整印蜕，不做按压渐进

## 六、动效语言（功能优先）

- 钤印：印章下落 + 印泥晕开（canvas/SVG）— 签名
- 页面切换：push 滑入 / pop 滑出（页面栈）
- TabBar：选中态朱砂高亮 + 图标缩放
- 半屏弹层：从底部弹起、背景遮罩淡入
- ActionSheet：左滑触发后从底部升起
- 下拉刷新：弹性回弹 + 换一批篆字
- 印谱：左滑出现删除按钮，删除有 ActionSheet 二次确认

## 七、微信小程序端侧交互语言（7 种）

1. 胶囊按钮 + 自定义导航栏容器（右上角胶囊、自定义标题栏）
2. 底部 TabBar（5 项：印台/字典/印谱/规范/接口）
3. 页面栈 push/pop（返回箭头、滑入滑出）
4. 半屏弹层（篆字详情：九叠篆大图 + 字义 + 带入印稿）
5. ActionSheet（印谱条目操作、删除确认）
6. 左滑操作（印谱条目左滑露出删除）
7. 吸底操作栏（钤印页主按钮）+ 下拉刷新（字典换一批）+ 分段控件（朱文/白文）

## 八、组件

- 印稿预览：SVG 实时渲染（朱文=红字白底线，白文=红底留白字，边栏有/残/无）
- 九叠篆字形：20 字（吉印心安山水石书祥如意福寿乐富长风月花人）以 SVG 折线绘制
- 印床石章：SVG 俯视图（印钮+印面+印床底座）
- 印蜕：朱砂印面 + 随机飞白 mask

## 九、技术

- 纯 vanilla 单文件 HTML，零外部依赖（无 CDN / 无 React / 无外部字体）
- localStorage 持久化印谱
- 健壮性：RAF/定时器随 `visibilitychange` 暂停、卸载取消；快速连点不叠加定时器；指针事件直接操作 DOM；支持 `prefers-reduced-motion`

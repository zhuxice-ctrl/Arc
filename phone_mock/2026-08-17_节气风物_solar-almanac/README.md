# 节气风物 · 微信小程序 V2

JIE QI FENG WU Mini Program

## 项目简介

一款以中国传统二十四节气为主题的文化生活类微信小程序，探索节气中的风物、美食、手工艺与旅行。用现代极简的设计语言，重新诠释东方美学。

## 形态

微信小程序（WeChat Mini Program）
- 右上角胶囊按钮（··· / ⊙）
- 页面栈 push/pop 切换，右滑返回手势感
- 底部 TabBar（4 个，选中态弹性动效）
- 半屏弹层 ActionSheet
- 下拉刷新弹性回弹
- 吸顶 Tab/分类筛选
- 骨架屏加载
- 详情页吸底操作栏

## 主题领域

文化艺术 · 自然探索 · 生活方式

二十四节气，是中国人的诗意时间刻度。本小程序围绕每一个节气，展示对应的风物民俗、草木虫鱼、时令美食、传统工艺。

## 签名动效

1. **印章敲章动效** — 红色印章以 scale + rotate 的弹性动画盖在页面上，呼应传统书画落款
2. **水墨笔触描绘** — SVG path 的 stroke-dasharray 动画，模拟毛笔在宣纸上运笔

## 组件级动效（共 12+）

1. TabBar 选中弹性回弹
2. 页面 push/pop 过渡
3. 卡片入场错峰动画
4. 下拉刷新弹性回弹
5. 点赞按钮弹性缩放
6. ActionSheet 底部弹出
7. 浮动叶片环境动画
8. 头像光环旋转
9. 骨架屏 shimmer 加载
10. 搜索结果淡入
11. FAB 悬浮按钮按下反馈
12. 数字 count-up 动效
13. 收藏按钮主色填充

## 交互特性

- 底部 4 个 TabBar 可切换
- 详情页、搜索页、规范页以页面栈形式推入
- 下拉首页触发刷新
- 分享按钮唤起 ActionSheet
- 点赞按钮有弹性动画
- 日历可切换月份
- 搜索有实时建议

## 技术实现

- React 18 + Babel standalone
- 所有 JSX 内联于 index.html
- CSS 内联于 style 标签
- requestAnimationFrame 驱动自定义光标
- supports prefers-reduced-motion
- visibilitychange 暂停动画

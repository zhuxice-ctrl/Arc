# 潮间带 Intertidal · 设计规范

> 日期：2026-08-19　|　类别：Phone Mock · V2　|　形态：原生 App

## 一、设计理念（Design DNA）

**核心概念**：整个 App 像一本被翻旧的老式《潮信表》铅印小册子——纸白底、墨色铅字、朱砂圈注。首页不是问候语+Banner，而是一张占据视觉中心的「今日潮信大曲线」，当前时刻一枚朱砂指针，低潮赶海窗口以倒计时环呈现。

**视觉来源**：老式沿海潮信表铅印册（墨色印刷 + 朱砂手工圈注）+ 滩涂泥沙纹理。

**空间逻辑**：仪表盘式首页（潮汐曲线为视觉中心）+ 列表式滩涂 + 日历式日志，非卡片 Grid。

**产品逻辑**：赶海人打开 App 的第一秒就要能回答「今天几点能下滩」→ 选滩涂点位 → 赶海后记一笔收获 → 月历回看。产品机制从赶海行为本身生长。

| 朱砂软 | --cinnabar-soft | #D86B55 | 朱砂悬停 |
| 朱砂淡 | --cinnabar-faint | #F1DAD4 | 朱砂底纹 |
| 滩涂褐 | --mud | #8C7A5E | 退潮中状态、泥沙 |
| 滩涂软 | --mud-soft | #A9977A | 褐色悬停 |
| 滩涂淡 | --mud-faint | #E5DCCB | 褐色底纹 |
| 海苔绿 | --seaweed | #4F6B54 | 可下滩状态灯 |

色彩语义：墨色=信息、朱砂=当前/紧迫/今日、海苔绿=可行动（可下滩）、滩涂褐=过渡（退潮中）、墨淡=已结束（已涨潮）。层级与状态由颜色+空间共同承担，灰度下信息层级仍成立。

## 三、字体

- UI 中文：`"PingFang SC", "Noto Sans SC", -apple-system, sans-serif`（铅字感无衬线）
- 数字/潮位/时刻：`"SF Mono", Menlo, Consolas, monospace`（等宽表格数字，便于潮位与分秒对齐）
- 外部依赖：仅 `miaoda.feishu.cn` 镜像 Noto Sans SC 字体，纯 vanilla 单文件，无 React/Babel/其他 CDN。

## 四、页面结构（原生 App · 3 Tab + 栈式详情）

| 页面 | id | 作用 |
|------|----|------|
| 潮信（首页） | pageContent | 今日潮汐大曲线 + 当前潮位 + 低潮窗口倒计时环 + 高低潮时刻表 + 72h 时间尺 |
| 滩涂 | （tab 内） | 6 个福建沿海点位，按当前潮位实时标注可下滩/退潮中/已涨潮三态，含物种标签与窗口倒计时，支持状态筛选 |
| 日志 | （tab 内） | 月度统计卡 + 月历（有记录日海苔绿点，今日朱砂框）+ 收获记录列表 + 浮动记一笔按钮 |
| 点位详情 | pageDetail | 底质、常见物种、今日窗口（栈式 push） |
| 记一笔 | pageRecord | 物种/数量/点位/潮水时段表单（Sheet 式） |
| 设计规范 | pageSpec | 理念/色板/字体/组件/页面结构/成功条件 |
| 接口文档 | pageApi | `/api/tide/v2` 假接口（潮汐预报/当前潮位/点位列表与详情/收获 CRUD + 错误码） |

## 五、签名动效系统

- **潮汐曲线指针随时间尺拖动**：拖动 72h 时间尺，SVG 曲线 `stroke-dashoffset 0.15s linear` 随动，朱砂指针移动，潮位数字、潮汐状态、倒计时环、高低潮行高亮、滩涂点位状态灯**全部联动重算**。高频触摸事件直接操作 DOM，不触发重渲染、不叠加定时器。
- **低潮窗口倒计时环**：朱砂环形进度，随真实时间递减。
- **点位状态灯**：海苔绿呼吸（可下滩）/ 滩涂褐（退潮中）/ 墨淡（已涨）。
- **页面切换**：`transform 0.35s cubic-bezier(0.32, 0.72, 0, 1)`（iOS 弹性曲线）。
- **健壮性**：定时器随 `visibilitychange` 暂停、卸载取消；支持 `prefers-reduced-motion`（降级为瞬切）。

## 六、数据与状态

- 收获记录存 `localStorage`，3 条种子数据，记一笔后月历与统计即时更新。
- 潮汐逻辑遵循农历大小潮 + 半日潮（双高潮双低潮），数据具内部关系：拖时间尺 → 潮位/窗口/点位状态联动。

设计规范

潮间带 · 设计规范

形态：原生 App · 版本 v2.0 · 2026.08

设计理念

整个 App 像一本被翻旧的老式《潮信表》铅印小册子——纸白底、墨色铅字、朱砂圈注。首页不是问候语加 Banner，而是一张「今日潮信大曲线」，赶海的核心决策在打开 App 的第一眼就能完成。

组件规范

卡片：不使用圆角卡片容器。信息以发丝线分割、分栏排布，贴近铅印册的阅读体验。

状态灯：海苔绿 = 可下滩，滩涂褐 = 退潮中，墨色 = 已涨潮。

朱砂圈注：关键数字、当前时刻、倒计时环使用朱砂色，模拟手工红笔圈注的质感。

时间尺：底部 72h 时间尺为签名交互，拖动时全局联动更新。

成功条件

用户打开 App 3 秒内能回答「今天几点能下滩」；拖动时间尺能看到未来 72h 潮位与窗口联动变化；记一笔收获后月历与统计即时更新。

接口文档

潮信 API v2

Base URL: /api/tide/v2

潮汐数据

GET/tide/forecast
获取指定点位未来 72 小时潮汐预报数据，返回按 15 分钟间隔采样的潮位序列及高低潮时刻。
// Request
GET /api/tide/v2/tide/forecast?spot=xiaocheng&hours=72

// Response 200
{
  "spot_id": "xiaocheng",
  "spot_name": "小埕沙滩",
  "base_level": 2.0,
  "lunar_day": 17,
  "tide_range_max": 3.2,
  "tide_range_min": 0.8,
  "samples": [
    { "t": 0, "level": 2.45 },
    { "t": 15, "level": 2.61 },
    ...
  ],
  "high_low_tides": [
    { "type": "high", "t": 120, "level": 4.9 },
    { "type": "low", "t": 360, "level": 0.3 },
    ...
  ]
}
GET/tide/now
获取当前时刻潮位、状态（涨/落）、距下个高低潮的倒计时。轻量接口，用于首页首屏快速渲染。
// Response 200
{
  "level": 2.4,
  "status": "falling",
  "next_tide": {
    "type": "low",
    "minutes_left": 138,
    "level": 0.3
  }
}

滩涂点位

GET/spots
获取滩涂点位列表，支持按区域、底质过滤。每个点位返回可下滩潮位阈值与常见物种。
// Request
GET /api/tide/v2/spots?region=fujian&substrate=sand

// Response 200
[
  {
    "id": "xiaocheng",
    "name": "小埕沙滩",
    "coord": [26.34, 119.74],
    "substrate": "沙质",
    "walkable_threshold": 1.5,
    "species": ["花蛤", "蛏子", "青蟹"],
    "best_window": "低潮前2h至后1h"
  },
  ...
]
GET/spots/:id
获取单个点位的详细信息，含今日赶海窗口时段、底质详情、安全提示。

收获日志

POST/records
提交一条赶海收获记录，成功后返回记录 ID。
// Request Body
{
  "spot_id": "xiaocheng",
  "date": "2026-08-19",
  "tide_phase": "low",
  "catch": [
    { "species": "花蛤", "qty_kg": 2.5 },
    { "species": "蛏子", "qty_kg": 1.2 }
  ],
  "note": "今天收获不错"
}

// Response 201
{ "id": "rec_abc123", "created_at": "..." }
GET/records
按月查询收获记录，返回列表与月度统计汇总。
// Request
GET /api/tide/v2/records?month=2026-08

// Response 200
{
  "total_trips": 8,
  "total_kg": 24.5,
  "top_species": "花蛤",
  "records": [ ... ]
}

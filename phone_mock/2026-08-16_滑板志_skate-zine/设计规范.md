# SKYLINE 滑板志 · 设计规范

> 日期：2026-08-16 ｜ 方向：V2 手机应用 UI ｜ 主题：街头滑板文化 App

## 色彩系统

以"沥青水泥 + 街头荧光"为意象，石墨灰做底、荧光橙点燃、电光黄点睛、雾白透气。

| 角色 | 色值 | 用途 |
|---|---|---|
| 沥青深 | `#0A0B0D` | 最深背景（社区页/夜间场景） |
| 石墨灰 | `#23262B` | 主背景，水泥沥青 |
| 石墨浅 | `#2A2D33` / `#2D3138` / `#1A1D21` | 卡片分层、分区 |
| 中性深 | `#3A3F47` / `#5A5E66` | 边框、分隔线 |
| 中性 | `#8B8F97` / `#B4B8BF` | 次级文字 |
| 雾白 | `#F5F3EF` | 主文字、浅底（商店页） |
| 浅灰白 | `#D9D7D0` | 浅底辅助 |
| 荧光橙 | `#FF6B1A` | 主强调，CTA、地钉、激活态 |
| 橙暗 | `#E05A10` | 橙按压态 |
| 电光黄 | `#FFD21F` | 次强调，进度、徽章、等级 |
| 黄暗 | `#E6BC1C` | 黄按压态 |
| 语义-成功 | `#34D399` | 在线/完成 |
| 语义-错误 | `#EF4444` / `#F87171` | 难度/警告 |
| 语义-蓝 | `#60A5FA` | 信息标签（非主色） |
| 语义-紫 | `#A78BFA` | 特殊标签（非主色，无蓝紫渐变背景） |

## 字体

- 展示字：`Archivo Black` / `Bebas Neue`（标题、大数字，街头粗体）
- 正文字：`Inter`（正文、列表）
- 标签字：`JetBrains Mono`（编号、坐标、代码）

## 组件规范

- 手机外壳：统一 android-frame，圆角 40px，刘海/状态栏
- 卡片：暗底 `#2A2D33` + 8px 圆角，悬停发光
- FAB：荧光橙悬浮操作球，悬停旋转放大
- 故事环：conic-gradient 多色环 + hover 旋转
- 徽章：电光黄圆角块 + 阴影

## 签名动效（≥2 页面级）

1. 首页入场序列动画（标题→卡片→列表 依次 stagger）
2. 场地详情视差滚动（封面图减速跟随）
3. 动作勾选圆环进度（弹簧填充）
4. 个人页环形进度（成就达成率）

## 动效系统（12+）

自定义光标（弹簧 + 悬停放大 + 涟漪 + 混色）/ 环境粒子（橙黄上升）/ Hero 视差（直接 transform）/ 地图地钉弹簧弹跳 / 底部抽屉惯性滑入 / 动作勾选圆环 / 故事环 conic 旋转 / 光泽扫过 shimmer / 头像脉冲在线 / FAB 悬停旋转 / 徽章 hover 弹起 / 点赞心形填充发光 / 页面切换惯性过渡。

## 健壮性

- 全部 JSX 内联在 index.html，无外部 JSX src 引用
- RAF/定时器 visibilitychange 暂停、卸载清理
- 高频鼠标事件直接操作 transform，不触发 setState
- `prefers-reduced-motion` 降级
- 无蓝紫渐变背景

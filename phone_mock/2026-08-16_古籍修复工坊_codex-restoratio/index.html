《南华经》卷三 · 补缀开始
辰时三刻 · 08:45
第三卷第十七页虫蛀严重，计有蛀洞十七处，最大者约半指宽。选用乾隆年间楮皮纸为补纸，颜色略浅于原纸，以区分新旧。浆糊比例 1:12，稀稠适中。
《敦煌遗书》残卷 · 托裱完成
巳时正 · 10:00
残卷共二十三片，最大片约三十厘米见方。托纸选用净皮宣纸，帘纹与原纸方向一致。上浆后自然阴干，切忌日晒或烘培。
《兰亭集序》摹本 · 去污处理
午时二刻 · 12:30
右上角水渍霉斑面积约六平方厘米。先用蒸馏水润湿，再以漂白土轻轻吸附，反复三次，颜色渐浅。墨色未受影响，笔画边缘完好。

API · DOCUMENTATION 接口文档

GET /books
获取古籍藏架列表，支持按分类筛选与分页。
category string 经史子集分类
page number 页码，默认 1
pageSize number 每页数量，默认 20
GET /books/:id
获取单本古籍详情，含破损情况、修复进度、修复师信息。
id string 古籍唯一编号
POST /tasks
创建修复任务，指定古籍编号与修复工序。
bookId string 古籍编号
priority string urgent / normal
steps array 修复工序步骤
PUT /tasks/:id/progress
更新修复任务进度，记录当前工序与完成度。
stepIndex number 当前工序序号
progress number 0–100 百分比
POST /logs
记录修复日志条目，附时间戳与修复师签名。
taskId string 任务编号
content string 日志正文
GET /materials
获取材料铺库存列表，支持按分类筛选。

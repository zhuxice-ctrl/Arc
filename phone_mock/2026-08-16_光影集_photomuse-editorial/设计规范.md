# 光影集 PhotoMuse · 编辑室 Editorial 设计规范

## 设计方向
**Editorial 编辑室**——致敬高端时尚杂志封面。极致留白 + 衬线大标题 + 发丝线分割，以"杂志开本"的仪式感承载 AI 人像修图服务的下单、查询与管理全流程。整体气质克制、克制再克制，靠版式节奏与字体对比建立高级感，不依赖渐变与阴影堆叠。

## 色彩系统（--pm-* 设计令牌）
| 令牌 | 值 | 用途 |
|------|------|------|
| pageBg | `#FAFAF8` | 页面底色（暖米白） |
| surface | `#FFFFFF` | 卡片/浮层表面 |
| surfaceAlt | `#F5F3EF` | 次级表面 |
| ink | `#1A1A1A` | 主文字（墨黑） |
| inkSecondary | `#3D3D38` | 次级文字 |
| inkTertiary | `#737169` | 辅助文字 |
| inkFaint | `#B8B6AE` | 占位/禁用 |
| border / borderHover | `#E0DED8` / `#B8B6AE` | 描边 |
| hairline | `#D0CEC6` | 发丝线分隔 |
| divider | `#ECE9E1` | 区块分割 |
| accent / accentSoft / accentLight | `#B8860B` / `#F7EFE0` / `#D4AF6A` | 强调（低调琥珀金） |
| success / warning / error / info | `#2E6B3F` / `#C66A2E` / `#B23A3A` / `#2C5A7A` | 状态色 |

配色互斥说明：通体墨黑 + 暖米白为骨架，仅以低调琥珀金作单一高饱和锚点；状态色仅在订单状态机流转中出现，不参与品牌主视觉。

## 字体系统
| 角色 | 字体栈 |
|------|--------|
| display / serif | `'Playfair Display', 'Noto Serif SC', serif` |
| body | `'Inter', 'Noto Sans SC', sans-serif` |
| mono | `'JetBrains Mono', monospace` |

衬线大标题（Playfair Display + 思源宋体）承担杂志封面感，无衬线正文保证移动端可读性，等宽字体用于编号与英文副标题（如 `№ 02` / `PACKAGES`）。

## 页面结构（4 页）
1. **下单主页 index**——8 章节：选择套餐、效果范例、拍照引导、风格选择、制作要求、照片上传、授权勾选、提交；附订单号查询面板与「我的订单」入口。
2. **订单详情 detail**——衬线大标题状态区、进度条 + 四步节点动画、覆盖完整订单状态机流转、补拍上传、参考照与交付作品大图预览。
3. **管理登录 adminLogin**——Editorial 风格登录卡（口令校验 + 错误提示 + Loading）。
4. **订单管理 admin**——7 状态 Tab 筛选、统计卡、审核三动作（通过/重拍/拒单含原因弹层）、交付图上传（最多 9 张）、图片全屏预览。

## 组件语言
- **发丝线 Hairline**：1px、半透明，章节间分隔的视觉签名。
- **章节头**：金色序号 `№ NN` + 中文标题 + 英文副标题三段式。
- **套餐行 / 订单卡**：左勾选标识 + 主信息 + 右价格/状态，hover 浅底位移。
- **主按钮**：墨黑实色，hover 上浮 + 阴影加深、按下回弹。
- **次/幽灵按钮**：hover 反色填充。
- **风格 Tab**：选中下划线渐显。
- **单选/复选**：勾选弹性缩放 + 对勾淡入。
- **Toast**：居中浮层，毛玻璃背景，按类型着色。

## 动效（≥12 组件级特效，统一节奏）
- 页面进入：`slideUp 0.35s cubic-bezier(0.16,1,0.3,1)` 淡入上滑。
- 主按钮 hover 上浮 + 阴影加深、按下回弹。
- 次/幽灵按钮 hover 反色填充。
- 套餐行、订单卡、管理订单卡 hover 浅底 + 轻位移。
- 风格 Tab 选中下划线渐显。
- 上传照片与交付缩略图 hover 微放大。
- 单选/复选勾选弹性缩放 + 对勾淡入。
- 删除图标 hover 放大变红。
- 管理端操作按钮 hover 实色反白。
- 进度条与状态节点动画过渡。
- Toast 淡入淡出（`opacity 0.25s ease`）。
- 全局 Loading 旋转 + shimmer。

动效遵循 Editorial 调性：克制、物理感、不喧宾夺主。

## 契约层对齐
13 个云函数 / 7 个集合 / 订单状态机（waiting_photos → photo_review → queued → generating → qc → delivered，含 waiting_retake / cancelled 分支）/ snake_case 字段，均以《前端视觉重构设计汇报》为契约边界冻结。本 mock 仅深化表现层与交互，不触碰接口入参出参与调用时序。

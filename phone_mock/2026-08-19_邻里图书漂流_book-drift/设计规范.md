# 邻里图书漂流 · 设计规范

形态：原生 App

## 产品定义
社区图书漂流产品。用户把书放进漂流，他人扫码收书、阅读、留便签、再放漂；每本书有一条贯穿所有读者的"漂流足迹"。核心用户：爱书爱分享的社区邻里/城市青年。高频任务：扫码收书 → 阅读 → 写漂流便签 → 放漂 → 查看这本书的旅程。

## 产品机制
"一本书的漂流足迹"（travel log）是产品主轴。书是会流动的对象，串起每一位读者；足迹 Tab 以垂直时间线呈现每位读者一段。

## 信息架构 / 导航
原生 App 4 Tab（页面栈 push/pop 语义）：
1. 漂流（首页）— 当前书状态卡（阅读中/待放漂/在途）+ 附近漂流点迷你地图 + 漂流点列表（非通用问候语+搜索+Banner 模板）
2. 书架 — 按在读/待放漂/已传递分组，真实书脊，含空态
3. 足迹 — 朱砂印章节点 + 麻绳虚线时间线，滚动依次盖章
4. 我的 — 漂流统计 + 我发起的漂流 + 克制设置

## 配色（取自源码真实色值，禁蓝紫渐变）

- 墨蓝 `#2b3a55`（导航/标题/强调，非渐变）
- 朱砂印章 `#b8392f` `#952a22`（漂流印章/强调）
- 麻绳褐 `#7a5c3a`（足迹线/分隔）
- 苔绿 `#5e6b4a`（点缀）

## 字体
- 标题/正文：`--font-serif`（衬线/宋）
- 印章/手写感：`--font-brush`（毛笔体）
- 数字：`--font-mono`（等宽）

## 动效系统
41 处 `addEventListener`、5 处 `@keyframes`、3 处 `requestAnimationFrame`、30 处 `transition`、3 处 `visibilitychange`、2 处 `prefers-reduced-motion`。签名动效：漂流足迹时间线——节点是朱砂漂流印章，麻绳串连，滚动到当前段印章"盖章"落下、麻绳收紧；放漂完成书脊沿轨迹"滑"向下一位。微交互：书签印章光标 / 点击反馈 / Sheet 滑入 / 状态切换 / 印章盖章弹跳 / 麻绳浮现 / 书脊滑行 / 便签输入聚焦 / 扫码扫描线 / 下拉刷新 / Tab 切换弹跳 / 空态书本摇摆 / 长按菜单 / 地图标点浮动。

## 核心 User Flow
打开 → 漂流 Tab 见《平如美棠》"阅读中" → 写漂流便签（底部 Sheet）→ 提交（印章盖章）→ 状态变"待放漂" → 放漂 → 选扫码给下一位/投放漂流点 → 扫码识别成功（大印章落下）→ 书脊滑行离场 → 足迹时间线新增我这一段 + "在途中…"节点 → 自动切足迹 Tab。

## 真实内容
书：《平如美棠》《人间草木》《深夜食堂》《台北人》《我的天才女友》等。读者：阿禾、南城旧事、半山腰、不加香菜、拾贝人等。漂流点：梧桐街 24h 书房、三叶咖啡、老城厢居委会漂流角、地铁 2 号线长椅。

## 工程边界
单 HTML 文件（vanilla），390×844 手机屏；RAF/定时器随 visibilitychange 暂停、卸载取消；快速操作不叠加定时器；高频事件直接操作 DOM；支持 prefers-reduced-motion（关闭动效 + 系统光标）；无意外横向滚动。

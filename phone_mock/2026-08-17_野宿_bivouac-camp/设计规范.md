# 野宿 · 设计规范

形态：原生 App

## 一、设计哲学

以山野为灵感，以质感为底色。拒绝模板感，用真实的材质语言（帆布、木纹、苔藓、篝火）构筑一个有温度的露营社区。

**签名元素：** 篝火粒子 + 帐篷拉绳式下拉刷新

---

## 二、色彩体系

| 名称 | 色值 | 用途 |
|------|------|------|
| 苔藓绿 Moss | `#3A5A40` | 主色、按钮、主图标、品牌 |
| 篝火橙 Ember | `#E76F51` | 强调色、价格、CTA、状态指示 |
| 树皮棕 Bark | `#6B4423` | 辅助色、次要文字、木纹元素 |
| 月光银 Mist | `#D5DBDB` | 浅灰、禁用态、分隔线 |
| 米白底 Sand | `#F5F0E8` | 页面背景、卡片底色 |
| 深林墨 Forest | `#1a2a1e` | 深色背景、代码区 |

### 使用原则
- 主页面以米白底为底，苔藓绿为品牌锚点
- 每页有一个"色彩主角"：首页偏绿、装备页偏棕、营地页偏橙
- 渐变仅用于 FAB、Tab 中心按钮、Hero 遮罩，不滥用
- 文字层级：深棕 `#2c2416` → 中棕 `#5a4a35` → 浅棕 `#8a7a65`

---

## 三、字体排印

### 字族
- **展示字体**：Noto Serif SC（衬线，用于大标题、页面标题、hero 文案，传递户外杂志感与品质感）
- **正文字体**：Noto Sans SC（无衬线，用于正文、按钮、标签，保证可读性）

### 字号层级
| 级别 | 字号 | 字重 | 用途 |
|------|------|------|------|
| H1 页面大标题 | 34px | 700 | 原生大标题导航栏 |
| H2 区块标题 | 20px | 700 | 卡片区块标题 |
| H3 卡片标题 | 15px | 600 | 列表、卡片主标题 |
| Body 正文 | 13-14px | 400 | 描述文字 |
| Caption 辅助 | 11-12px | 400/500 | 标签、时间、小说明 |

---

## 四、间距系统

基础单位 4px，按 8 点网格递增：

`4px · 8px · 12px · 16px · 20px · 24px · 32px`

- 卡片内边距：14-16px
- 区块外边距：20px
- 卡片圆角：16-20px
- 按钮圆角：12-16px
- 头像圆角：50%

---

## 五、组件规范

### 按钮
- **主按钮**：苔藓绿实底 + 白字 + 14px 圆角
- **次按钮**：白底 + 绿边 + 绿字 + 14px 圆角
- **暖按钮**：篝火橙渐变 + 白字 + 16px 圆角（用于关键 CTA：预订、加入购物车）
- 点击态：scale(0.96) 缩放 + 涟漪

### 卡片
- 统一圆角 16-20px
- 阴影：`0 2px 16px rgba(58, 90, 64, 0.08)`
- 左侧彩条：装备卡片用绿棕渐变条
- 悬停/点击：scale(0.97-0.98) 微缩

### 标签
- 小圆角胶囊（10px 圆角）
- 浅色底 + 对应深色文字
- 三种：绿、橙、棕

### 底部 TabBar
- 毛玻璃背景 `backdrop-filter: blur(20px)`
- 激活态：苔藓绿填充 + 加粗
- 中间凸起按钮：篝火橙渐变 + 脉冲光环 + 阴影

## 六、动效规范

| 动效 | 参数 | 用途 |
|------|------|------|
| 页面转场 | 0.35s cubic-bezier(0.32, 0.72, 0, 1) | 导航栈切换 |
| 按钮缩放 | 0.2s ease | 点击反馈 |
| 弹性回弹 | 0.4s cubic-bezier(0.34, 1.56, 0.64, 1) | FAB、Tab 中心、心形 |
| 渐入上升 | 0.6s cubic-bezier(0.32, 0.72, 0, 1) | 列表入场 |
| 光泽扫过 | 3s ease-in-out infinite | 突出按钮、卡片 |
| 脉冲光环 | 2-2.5s ease-in-out infinite | Tab 中心、头像 |

**所有动效支持 `prefers-reduced-motion` 降级。**

---

## 七、布局规则

- 不同页面使用不同布局骨架，禁止所有页面共用"标题栏+列表"
- 首页：Hero 视差 + 四宫格分类 + 横条卡片 + 瀑布流 + 横滑轮播
- 装备页：大标题导航 + 分类横滑 Tab + 双列网格
- 营地页：顶图地图 + 筛选吸顶 + 横向卡片列表
- 详情页：全屏 Hero + 上移圆角面板 + 底部固定操作栏
- 个人中心：渐变头部 + 毛玻璃数据卡 + 悬浮菜单
- 规范/文档页：深色 Hero + 卡片列表 + 代码块

---

## 八、文案规范

- 以中文为主，英文仅用于必要品牌名与技术术语
- 主动语态，具体胜过抽象
- 标签用名词，按钮用动词
- 语气：温暖、专业、有探索感，不像电商叫卖

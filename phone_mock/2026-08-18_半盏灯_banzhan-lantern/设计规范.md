## 色彩系统

主配色：米纸白 + 竹青绿 + 柿橙 + 暖褐，明亮暖纸基调与灯火暖意。

| 角色 | 色值 | 用途 |
|---|---|---|
| 米纸白 | #F7F1E3 / #FFFDF8 / #FFFCF7 | 页面底色，宣纸质感 |
| 暖纸 | #EFE8DB / #E8DCC8 / #E8E4D8 | 次级背景、卡片底 |
| 竹青绿 | #4A7C59 | 主色，TabBar 选中、图标、标签 |
| 竹青浅 | #5D9470 / #7CB342 | 竹青提亮，辅助强调 |
| 柿橙 | #D96C2C | 强调色，价格、按钮、灯火 |
| 柿橙浅 | #E89B5A / #F0C898 | 柿橙提亮，高光、渐变 |
| 暖褐 | #6B4A2E / #5D4A38 | 深色文字、标题 |
| 深褐 | #3D2C1E | 最深文字、深色头部背景 |
| 暖灰褐 | #9A8A78 / #C8B8A5 / #D4C8B8 | 次级文字、分隔线 |
| 灯暖金 | #D4A852 | 灯火光晕、积分 |
| 朱砂红 | #D6524A / #C83C23 | 警示、删除、左滑操作 |
| 粉樱 | #E8A5B0 | 装饰点缀 |

每页色彩主角：首页暖橙、灯谱竹青绿、详情暖纸、工坊木色、订单暖褐、个人深褐。

## 字体

- 标题：Noto Serif SC（衬线，传统手作质感）
- 正文：Noto Sans SC / 系统无衬线
- 数字：等宽，灯暖金高亮

## 组件规范

- 小程序容器：自定义导航栏 + 右上角胶囊按钮（··· / ⊙），导航栏随页面变化（透明/渐变/吸顶变色）
- 底部 TabBar：5 项（首页/灯谱/工坊/心愿/我的），选中态点灯呼吸动效
- 卡片：圆角 12-16px，暖纸底 + 细描边 + 柔和阴影，灯火呼吸光晕
- 按钮：柿橙实底 / 竹青描边，按压回弹缩放
- 吸底操作栏：底部安全区主按钮 + 浮层阴影
- 半屏弹层 / ActionSheet：从底部滑入，遮罩淡入

## 动效系统（12+ 组件级特效）

1. 灯火呼吸光晕 —— 正弦相位，灯笼图标光晕周期性明暗
2. 灯笼悬浮摆动 —— 首页 Hero 灯笼轻微摇摆
3. 首页入场序列 —— 元素分批错峰渐入
4. 卡片按压回弹 —— 按下缩放 0.97 松开回弹
5. 轮播自动切换 —— 画廊定时滑动 + 指示器
6. Tab 选中缩放 + 点灯 —— 选中项放大并亮起灯火
7. 骨架屏 shimmer —— 加载态光泽流动
8. 环形积分入场 —— 个人页环形进度描边动画
9. 按钮按压缩放 —— 主按钮按压反馈
10. 下拉提灯弹性回弹 —— 下拉刷新如提灯上抬回弹
11. 左滑吸附 —— 列表项左滑操作吸附定位
12. 导航栏滚动渐显 —— 滚动时导航栏由透明渐变为实色

物理模型：下拉刷新用弹簧回弹；卡片按压用缓动；灯火用正弦呼吸。

## 小程序端侧交互（6 种）

1. 页面栈 push/pop 切换（右滑返回手势感）
2. 底部 TabBar（5 项，选中态点灯呼吸）
3. ActionSheet 半屏弹层
4. 下拉提灯刷新弹性回弹
5. 左滑列表操作
6. 吸顶 Tab + 吸底操作栏 + 底部安全区按钮

## 页面结构（8 页）

1. 首页 —— Hero 灯笼浮动 + 自动轮播画廊 + 分类胶囊 + 商品卡片流
2. 灯谱（分类页）—— 吸顶筛选 Tab + 瀑布流双列卡片
3. 灯笼详情页 —— Hero 大图视差 + 吸顶导航变色 + 匠人心语 + 吸底操作栏
4. 定制工坊页 —— 三步定制流（选骨架/糊纸/绘样）+ 实时预览
5. 订单/心愿单页 —— 状态 Tab + 左滑列表操作
6. 我的 —— 深褐渐变头 + 环形积分进度 + 宫格菜单
7. 设计规范页 —— 8 色体系 + 字体 + 组件规范
8. 接口文档页 —— 6 组 API + 代码高亮 + 锚点导航

## 健壮性

- visibilitychange 暂停动画定时器
- rAF 节流直接操作 transform，不触发 React setState 重渲染
- prefers-reduced-motion 支持
- 所有定时器/动画帧统一清理

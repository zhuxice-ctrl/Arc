## 简介

微信小程序形态的手工灯笼铺，呈现宫灯 / 纱灯 / 兔子灯 / 鲤鱼灯等传统手作灯笼的展示、定制与购买。8 个页面，含小程序胶囊按钮容器、底部 TabBar 点灯动效、下拉提灯刷新、左滑列表操作、吸底操作栏等端侧交互。

## 动效亮点

- 灯火呼吸光晕 + 灯笼悬浮摆动
- 首页入场序列动画 / TabBar 选中点灯呼吸
- 下拉提灯弹性回弹刷新 / 左滑列表吸附操作
- 个人页环形积分描边入场 / 骨架屏 shimmer 等 12+ 特效

# 折纸工坊 Origami Atelier · 设计规范

> 形态：原生 App
> V2 手机应用 UI 方向 · 2026-08-16 · 折纸爱好者的作品集与教程 App

## 色彩系统

| 角色 | 色值 | 用途 |
|---|---|---|
| 和纸米白（底） | `#F5EDE0` / `#FFFFFF` | 页面底色、卡片表面 |
| 珊瑚朱红（主色） | `#D45C3E` | 主交互、强调、CTA、进度 |
| 芥末黄（强调） | `#D4A74A` | 次强调、标签、API 页 header |
| 灰绿（辅助） | `#8B956D` | 辅助色、个人页、技能条 |
| 炭黑（文字） | `#1E1B18` / `#000` | 正文与标题 |
| 表面色 | `#E8DDCC` / `#D4C4A8` | 分层卡片、边框 |
| 深层 | `#4A423A` / `#2A2520` / `#1A1714` | 次级文字、深色面板 |
| 珊瑚深 | `#B4432A` | 按下/激活态 |

配色为纸感暖色系，未使用蓝紫渐变。

## 字体栈

- 中文：`"Noto Sans SC", "PingFang SC", system-ui, sans-serif`
- 标题加重：`font-weight: 700/800`
- 数字/英文：`"Space Grotesk", system-ui, sans-serif`

## 页面结构（8 页，5+ 独特布局）

| 页面 | 布局语言 | 色彩主角 |
|---|---|---|
| Home 首页 | Hero 大图 + 统计卡 + 双列瀑布 + 渐变挑战卡 + FAB | 珊瑚朱红 |
| Gallery 作品库 | 瀑布流 masonry + 分类 Tab + 悬停播放按钮 | 暖珊瑚 + 米白 |
| Tutorial 教程 | Hero 视差 + 环形进度 + SVG 折纸示意图旋转 + 步骤点指示器 | 珊瑚朱红 |
| Materials 纸张库 | 左右分栏 Hero + 3D 倾斜纸张样本卡 + 规格详情面板 | 芥末黄 + 灰绿 |
| Profile 个人 | 环形头像脉冲 + 统计三列 + 技能进度条 + 收藏架 | 灰绿辅助 |
| Collections 收藏 | 堆叠卡片（stacked cards）+ 底部抽屉 + 缩略图预览 | 多色卡片 |
| Design System 规范 | 分区 Tab + 色卡 + 字体样本 + 组件展示 + 动效清单 | 和纸米白 |
| API Docs 接口 | 深色 Header + 可折叠端点 + 参数表 + 错误码网格 | 炭黑 + 芥末黄 |

至少 5 页为非重复布局骨架，避免换皮不换骨。

## 组件规范

- **手机外壳**：统一圆角 48px 设备框，顶部状态栏 + 底部导航。
- **卡片**：圆角 16px，阴影 `0 4px 20px rgba(0,0,0,0.06)`，悬停上浮 4px。
- **FAB**：珊瑚朱红圆形浮动按钮，发光脉冲。
- **环形进度**：SVG stroke 描线动画。
- **底部抽屉**：spring 缓动上滑，可拖拽关闭。

## 动效系统（12+）

1. 自定义光标（lerp 平滑 + 悬停放大 + 点击涟漪）
2. 飘落纸片粒子
3. 数字计数上升
4. 卡片入场 stagger
5. 3D 卡片倾斜
6. 按钮悬停发光放大
7. 头像脉冲环
8. 圆形进度描线
9. 技能条宽度过渡
10. 页面透视折叠切换
11. 收藏堆叠卡 spring 缓动
12. FAB 发光脉冲
13. 签名动效：开场折纸鹤折叠入场（SVG 缩放旋转 + 米白遮罩淡入）
14. 签名动效：教程页折纸示意图随步骤旋转展开

## 健壮性

- 全部 JSX 内联在 `<script type="text/babel">`，无外部 src 引用。
- `visibilitychange` 暂停动画；`beforeunload` 清理事件监听。
- `prefers-reduced-motion` 降级。

## 五、动效系统（@keyframes，取自源码）

| 名称 | 作用 | 触发 |
| --- | --- | --- |
| stackEnter / stackLeave | 页面栈 push/pop 滑动转场 | 进入作钓中、设计规范、接口文档页 |
| spin | 加载旋转 | 数据加载 |
| rippleExpand | 鱼获入册水面涟漪 | 保存鱼获后 |
| fishJump | 鱼跃出水面 | 收线成功（reel success） |
| brokenPop | 断线提示弹出 | 收线红区超 2 秒断线 |
| 张力条波动 | RAF 驱动正弦波+随机扰动模拟鱼挣扎 | 中鱼收线中（reelLoop） |
| 弹簧弹层 | 半屏弹层上升 | 钓点详情/选钓点/鱼获登记 |
| 下拉弹性 | 下拉刷新回弹 | 钓况首页下拉 |

健壮性：RAF 循环在 `document.hidden` 时暂停、卸载取消；快速操作不叠加定时器；高频指针事件直接操作 DOM；`prefers-reduced-motion` 下收线面板退化为静态按钮+指示器、关闭鱼跃/涟漪等装饰动效。

## 六、微信小程序端侧交互（≥4 种，真实工作）

1. 胶囊导航栏：右上角"返回 + 关闭"，自定义导航栏容器
2. 底部 TabBar：钓况 / 钓点 / 鱼获 / 我的，4 标签切换
3. 半屏弹层：钓点详情、选钓点、鱼获登记（带遮罩点击关闭）
4. 下拉刷新弹性：钓况首页下拉回弹
5. 左滑操作：鱼获列表项左滑删除
6. 页面栈 push/pop：作钓中、设计规范、接口文档页进入/返回滑动转场

## 七、签名交互：收线张力

中鱼后进入收线面板：
- 张力条分绿（稳）/黄（挣扎）/红（危险）三区，RAF 驱动正弦波+噪声模拟鱼挣扎
- 按住"收线"按钮推进进度（约 12%/s），同时张力上升；松开张力回落
- 红区累计超 2 秒 → 断线重来（endReeling false，提示"鱼跑了"）
- 进度到 100% → 鱼跃出水面 → 鱼获登记半屏自动带出挣扎强度与预估重量
- 挣扎强度（maxStruggle）与预估重量联动：挣扎越强预估越重

## 八、页面结构

1. 钓况（首页/战术板）：宜钓指数 + 今日水情（水温/气压/风力/水位/湿度/风速/月相）+ 推荐钓点 + 开始作钓主操作
2. 钓点：钓点列表/卡片，点击→半屏详情（水深/底质/最佳时段/历史战绩）
3. 作钓中（push 页）：钓点/时长/抛竿次数/中鱼数/最大斤两 + 抛竿 + 模拟中鱼 → 收线面板
4. 鱼获（图鉴）：鱼获列表 / 水深分布双视图，左滑删除，空状态
5. 我的：战绩统计 + 月相钓获分布 + 设计规范/接口文档入口 + 单位/清空设置
6. 设计规范页 + 接口文档页

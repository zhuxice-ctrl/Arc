# 设计规范 · 巷往 · 城市漫步约伴小程序

形态：微信小程序

> 日期：2026-08-17 · 方向：V2 手机 UI · 形态：微信小程序 · 主题：城市漫步（citywalk）路线发现与同好约伴

## 形态标记

形态：微信小程序

## 色彩系统

砖红 + 鹅黄 + 深橄榄绿 + 奶油白，每页有色彩主角，禁蓝紫渐变。

|---|---|---|
| --brick | #B8523E | 砖红（主色，个人中心头图） |
| --brick-dark | #8A3A2A | 砖红深色 |
| --brick-light | #D6745F | 砖红浅色 |
| --goose | #F2D98D | 鹅黄（强调 / 选中态） |
| --goose-deep | #E8C55A | 鹅黄深色 |
| --olive | #4A5A3A | 深橄榄绿（约伴绿区） |
| --olive-light | #6B7D52 | 橄榄绿浅色 |

## 字体

系统无衬线，标题加粗，等宽体用于接口代码块。

## 小程序端侧交互（≥4 种，实际 8 种）

页面栈 push/pop 右滑切换、底部 TabBar（4 项弹跳动效）、ActionSheet 半屏弹层、下拉刷新弹性回弹、左滑列表操作、吸顶 Tab、吸底操作栏、骨架屏 shimmer。

## 页面结构（8 页，≥5 独特布局）

1. 首页 — Hero 入场序列动画 + 分类胶囊 + 精选路线横滑 + 附近漫步列表 + 悬浮操作球
2. 发现页 — 吸顶筛选 Tab + 瀑布流双列 + 下拉刷新
3. 路线详情 — 视差滚动 Hero + 时间轴路线节点 + 领走人卡片 + 吸底操作栏
4. 约伴活动 — 对角分割顶部绿区统计卡 + 左滑列表操作 + 头像堆叠
5. 个人中心 — 砖红渐变头图 + 三环形进度 + 宫格菜单
6. 活动报名 — 三步进度条 + 表单分步 + 标签选择 + 开关组件 + 底部安全区主按钮 + ActionSheet
7. 设计规范 — 品牌区 + 6 色色板 + 字体层级 + 组件展示 + 间距圆角
8. 接口文档 — 6 个 REST 接口 + 可折叠请求/响应代码块

## 签名动效（2+）

首页入场序列（5 段延迟渐入）、详情页视差滚动、个人页环形进度动画。

## 组件级动效（12+）

Tab 弹跳、收藏心跳、FAB 旋转、按钮按压、开关弹性、步骤点缩放、下拉回弹、左滑露出、点击涟漪、光标尾随、骨架屏 shimmer、时间线错落。

## 自定义光标

白色粗环 + 砖红内点 + 多层发光，悬停放大变鹅黄色，点击涟漪扩散，开页居中显示。

## 健壮性

requestAnimationFrame 统一管理、visibilitychange 自动暂停、reduced-motion 支持、所有 JSX/CSS 内联于 index.html（components/ 为源码组件，运行时内联引用）。

# 矿晶志 Mineralia — 设计规范

> 方向：V2 手机 UI · 形态：原生 App · 2026-08-18
> 主题：矿物标本收藏爱好类原生应用

## 色彩系统

| 角色 | 色值 | 用途 |
|------|------|------|
| 主色·孔雀石绿 | `#2E7E54` / `#5DB37E` | 品牌主色、TabBar 选中、主按钮 |
| 浅孔雀 | `#8FCCA1` / `#BFE0C9` | 卡片高光、进度填充、次强调 |
| 辅色·黄铜金 | `#D4A017` / `#E8B92E` / `#F0CF5B` | FAB、徽章、数字、鉴定高亮 |
| 深铜 | `#8B6914` / `#B8860B` | 文字金属质感、次级强调 |
| 强调·砖红 | `#C44536` / `#E57368` / `#8B2A1E` | 警示、稀缺度、产地标记 |
| 表面色·石灰白 | `#FAFCF7` | 卡片底、浅色页面背景 |
| 中性·墨灰 | `#3D423F` / `#7A6560` / `#B8BCBA` | 正文、次要文字、分隔 |
| 辅助色 | `#7B4FA8`(紫晶) / `#6FA8D4`(天河石) | 仅用于矿物标本本身的特征色，不用于 UI 框架 |

每页有独立色彩主角：收藏架偏孔雀绿、图鉴偏黄铜金、晶市偏砖红暖调、我的偏石灰白低饱和、详情页高对比深底。严禁蓝紫渐变。

## 字体排印

- 正文：`-apple-system, system-ui`（原生系统字体栈）
- 展示字体：`var(--font-display)`（大标题导航栏）
- 等宽：`var(--font-mono)`（接口文档代码块）

## 组件规范

- **大标题导航栏**：原生质感，半透明毛玻璃，滚动渐变吸顶
- **底部 TabBar**：4 项，选中态孔雀绿 + 弹性缩放微动效
- **卡片**：圆角 16px，阴影分层，棱镜反光（悬停光泽扫过）
- **FAB**：黄铜金圆形悬浮鉴定按钮，弹性入场
- **底部模态抽屉**：弹簧阻尼入场，半屏高度
- **环形进度**：SVG stroke-dashoffset 填充动画
- **Chip/标签**：圆角胶囊，悬停态色彩偏移

## 动效系统（≥12）

1. 晶簇生长入场（收藏架，主题语义：晶体逐枝生长）
2. 解理闪光 + 视差滚动（详情页，主题语义：晶体解理面反光）
3. 卡片棱镜反光（mousemove 光泽扫过）
4. 弹簧缩放按压（Hooke 阻尼回弹）
5. 环形进度填充（easeOut）
6. 扫描线往复（AI 鉴定弹窗）
7. 置信度进度条增长
8. FAB 弹性入场
9. Tab 切换位移过渡
10. 地图脉冲环（产地标记）
11. 底部抽屉弹簧入场
12. 徽章渐入序列
13. 下拉刷新弹性回弹
14. 全屏详情页右滑转场

## 原生 App 交互语言（6 种）

大标题导航栏、底部 TabBar、底部半屏模态抽屉、下拉刷新、FAB 悬浮按钮、全屏详情页右滑转场。

## 页面结构（8 页）

1. 收藏架（瀑布流 + 晶簇生长入场 + 下拉刷新）
2. 图鉴（Hero 渐变头 + 七大晶系双列网格）
3. 晶市（信息流 Feed + 黄铜金 FAB + Tab 切换）
4. 我的（环形进度 ×3 + 成就徽章横滑）
5. 标本详情（视差大图 + 解理闪光 + 底部操作栏 + 产地地图）
6. AI 鉴定弹窗（底部模态抽屉 + 扫描线 + 置信度条）
7. 设计规范页
8. 接口文档页（深色代码风 + 可折叠 REST 列表）

至少 5 页具备独特非重复布局。内容为真实矿物（孔雀石、萤石、黄铁矿、紫水晶、天河石等）与真实产地。

## 健壮性

- RAF/定时器随 visibilitychange 暂停、卸载取消
- 高频 mousemove 直接操作 DOM transform
- 支持 prefers-reduced-motion 降级
- JSX 全部内联于 `<script type="text/babel">`，无外部 JSX 文件引用
- 零未定义引用

## 字体

- **标题字体**：`'Noto Serif SC', 'Songti SC', serif` — 衬线体，传达手工质感与品质
- **正文字体**：`'Noto Sans SC', -apple-system, BlinkMacSystemFont, sans-serif`
- **等宽字体**：`Georgia, serif` / `monospace` — 接口文档区

## 圆角与阴影

- 卡片圆角：`12px`（柔和，呼应皮革柔软质感）
- 按钮圆角：`8px`
- 标签圆角：`4px`
- 阴影：多层柔和投影模拟皮革厚度感

## 动效系统

| # | 动效名称 | 触发方式 | 技术实现 |
|---|---------|---------|---------|
| 1 | 首页入场序列 | 页面加载 | 标题→卡片→列表逐级弹性滑入（staggered animation） |
| 2 | 商品详情视差滚动 | 详情页滚动 | 产品图随滚动缩放位移，背景与内容速度差 |
| 3 | TabBar 选中弹跳 | 点击 Tab | scale + translateY 弹性回弹 |
| 4 | 卡片悬停发光 | 卡片 hover | box-shadow 暖光晕扩散 |
| 5 | 下拉弹性回弹 | 下拉手势 | transform 弹性形变 + 回弹 |
| 6 | 半屏弹层滑入 | 点击操作按钮 | translateY 从 100% 到定位 + 遮罩渐入 |
| 7 | 左滑操作面板 | 左滑列表项 | translateX 露出操作按钮 |
| 8 | 骨架屏闪烁 | 加载中 | 渐变 shimmer 动画 |
| 9 | 吸顶 Tab 高亮 | 滚动 | IntersectionObserver 触发高亮转移 |
| 10 | 数字计数器 | 滚入视口 | 计数动画 |
| 11 | 卡片光泽扫过 | 卡片 hover | gradient 掠过表面 |
| 12 | 页面切换过渡 | 页面栈 push/pop | translateX + opacity 过渡 |

## 页面结构

1. **首页** — Hero 大卡 + 四宫格入口 + 横向滑动卡片流 + 匠人推荐
2. **分类页** — 吸顶 Tab 筛选 + 瀑布流双列布局
3. **商品详情页** — Hero 大图视差 + 底部吸底操作栏
4. **定制工坊页** — 分步表单 + 底部安全区主按钮
5. **匠人故事页** — 对角分割布局 + 时间轴 + 作品网格
6. **养护指南页** — 轮播画廊 + 步骤卡片
7. **设计规范页** — 色彩色板 + 字体样本 + 间距/圆角/阴影令牌
8. **接口文档页** — 可展开 API 列表 + 语法高亮 JSON

## 技术栈

- 纯 HTML/CSS/JS 单文件实现（无 React/Babel/CDN 依赖）
- IntersectionObserver（滚动检测）
- requestAnimationFrame（视差动画）
- 支持 prefers-reduced-motion 降级

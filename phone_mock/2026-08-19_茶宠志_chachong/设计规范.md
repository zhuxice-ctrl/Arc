# 设计规范 · 茶宠志

形态：微信小程序

## 主题概念

以「养茶宠」为核心产品逻辑的微信小程序。用户每日选择茶种浇茶，茶宠的包浆（patina）随浇茶次数渐变加深，积累到阈值后解锁成长日记。整个产品围绕「日复一日的仪式感」展开，不是宠物养成游戏，而是茶道文化的数字化隐喻。

## 动效系统（8 组 keyframes + JS 交互）

| 动画 | 触发条件 | 效果 |
|------|---------|------|
| splash | 浇茶按钮点击 | 茶汤溅落涟漪 |
| stream | 浇茶持续中 | 茶水流线条下落 |
| steam | 浇茶后 | 热气蒸腾上升 |
| pet | 茶宠待机 | 轻微呼吸缩放 |
| pot | 茶壶倾倒 | 壶嘴倾斜+旋转 |
| wisp | 茶烟散逸 | 透明度+位移淡出 |
| pulse | 包浆进度 | 脉冲发光 |
| badge | 成就解锁 | 弹跳出现 |

交互层：
- 浇茶流程：pourBtn → pouring 状态 → teaStream 动画 → patinaLevel 增加 → 茶宠颜色渐变
- 包浆系统：patina 值随 teaCounts 增长，分 5 级（素坯→浅润→蜜润→温润→深沉）
- 成长日记：累计浇茶达到阈值解锁新日记条目
- localStorage 持久化：teaCounts / patinaLevel / diaryEntries / selectedTeaType

## 微信小程序端侧交互模式

1. 胶囊按钮+自定义导航栏（顶部固定标题+状态栏占位）
2. 底部 TabBar（今日/日记/茶/我的，4 Tab 固定底部）
3. 半屏弹层（浇茶确认/成就弹出从底部滑入）
4. 页面栈 push/pop（今日→详情→日记详情，带返回手势）
5. 下拉刷新弹性（今日页下拉触发茶宠互动）

## 页面结构

| 页面 | 功能 |
|------|------|
| 今日 (today) | 茶宠展示+浇茶入口+今日进度 |
| 日记 (diary) | 成长时间线，按日期排列浇茶记录 |
| 茶 (tea) | 茶种选择（6 种茶对应不同包浆色调） |
| 我的 (profile) | 茶宠状态总览+统计数据+设置 |
| 设计规范 (spec) | 内嵌设计规范页 |
| 接口文档 (api) | 内嵌 API 契约文档 |

## 自定义光标

茶宠志为手机端微信小程序，使用系统触摸交互，无桌面自定义光标。

## 技术栈

纯 vanilla 单文件 HTML+CSS+JS，模拟微信小程序端侧布局与交互。localStorage 持久化用户数据。162 处 SVG 路径构建茶宠/茶壶/茶具图形。

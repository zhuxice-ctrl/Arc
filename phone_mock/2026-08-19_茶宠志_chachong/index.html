API 文档

茶宠志小程序后端接口 v1.0

GET 获取茶宠状态

GET /api/pet/status
获取当前用户茶宠的完整状态数据，包括养宠天数、累计浇茶次数、包浆等级、茶汤偏好等。
参数类型必填说明
userIdstring是用户唯一标识
// 200 OK { "code": 0, "data": { "petId": "pet_zisha_001", "petName": "小金蟾", "days": 42, "totalPours": 128, "patinaLevel": 4, "dominantTea": "puer", "todayPoured": false, "lastPourAt": "2026-08-18T08:30:00+08:00" } }

POST 浇茶

POST /api/pet/pour
向茶宠浇一壶指定茶汤，更新包浆值、累计次数、成长天数，并写入成长日记。每日首次浇茶成长天数 +1。
参数类型必填说明
userIdstring是用户唯一标识
teaTypestring是茶汤类型枚举：puer / green / oolong / black / white / yellow
notestring否当日备注，最长 50 字
// 200 OK { "code": 0, "data": { "patinaBefore": 3, "patinaAfter": 4, "totalPours": 129, "days": 43, "newDay": true, "diaryId": "diary_20260819" } }

GET 成长日记列表

GET /api/diary/list
分页获取茶宠成长日记，按日期倒序排列。包含每日茶汤、包浆变化、备注等。
参数类型必填说明
userIdstring是用户唯一标识
pageint否页码，默认 1
pageSizeint否每页条数，默认 20
// 200 OK { "code": 0, "data": { "total": 42, "list": [ { "id": "diary_20260819", "date": "2026-08-19", "teaType": "puer", "patinaLevel": 4, "note": "今日普洱浓汤，色泽醇厚" } ] } }

GET 茶汤列表

GET /api/tea/list
获取全部可选茶汤及其养宠特性描述。
// 200 OK { "code": 0, "data": [ { "id": "puer", "name": "普洱", "color": "#6B3A1A", "benefit": "包浆深褐，温润厚重" } ] }

DELETE 删除日记

DELETE /api/diary/:id
删除指定日期的日记记录，包浆值与累计次数回退一次。
参数类型必填说明
idstring是日记 ID

PUT 更新茶宠名称

PUT /api/pet/name
修改茶宠的昵称。
参数类型必填说明
userIdstring是用户 ID
petNamestring是新昵称，最长 10 字

形态：微信小程序

# 邻里工具箱 · 设计规范 V2

社区共享工具借用微信小程序设计系统。

## 设计理念

把"邻居家吃灰的电钻"变成扫码即借的邻里资源网。视觉语言来源于工具间的木质温暖感与工具的金属质感，营造「邻里互助、可信可靠」的产品氛围。

## 2. 字体排印

中文字体优先使用系统无衬线字体，保证小程序端原生体验。

```
font-family: -apple-system, BlinkMacSystemFont, "PingFang SC",
             "Helvetica Neue", Helvetica, "Microsoft YaHei", sans-serif;
```

### 字号层级

| 层级 | 字号 | 字重 | 用途 |

## 4. 动效规范

动效首先是功能，不为装饰而动。

| 动效 | 时长 | 曲线 | 说明 |
|------|------|------|------|
| 页面切换 | 300ms | ease-out | Tab 切换淡入+位移 |
| 半屏弹层 | 400ms | spring(0.32,1.28,0.64,1) | 底部弹出带弹性 |
| 扫码激光线 | 2s | ease-in-out 循环 | 上下扫描发光线 |
| 信用分数字滚动 | 800ms | easeOutQuart | 数字递增动画 |
| 信用分浮动 | 1.5s | ease-out | 向上浮动+淡出 |
| 下拉刷新 | 弹性 60px | 0.5 阻尼 | 手指拉动，松开回弹 |
| 左滑操作 | 250ms | ease | 80px 触发区域 |
| Toast 出现 | 300ms | spring | 缩放+淡入 |
| 按钮按下 | 150ms | ease | scale(0.96) |
| 列表进入 | 400ms | ease | 错位渐入 |
| 识别成功环 | 500ms | ease-out | 圆环弹出+勾号 |
| FAB 脉冲 | 3s | ease-in-out 循环 | 阴影呼吸 |

**总计 12 个组件级动效。**

### prefers-reduced-motion

尊重系统「减少动态效果」设置，所有动画降为最小幅度。

## 5. 端侧交互规范

### 5.1 胶囊按钮 + 自定义导航栏

- 位置：右上角，状态栏下方 4px
- 尺寸：87 × 32px
- 样式：半透明毛玻璃背景，两个图标按钮（更多 / 关闭）
- 自定义导航栏需考虑胶囊高度留出空间

### 5.2 底部 TabBar

- 高度：56px
- 四个 tab：工具广场 / 我的借用 / 信用 / 我的
- 选中色：木质暖棕，未选：钢灰更浅
- 图标：22px 线性 SVG
- 文字：10px

### 5.3 半屏弹层 Bottom Sheet

- 从底部弹出，最大高度 75%
- 顶部手柄条：36 × 4px
- 吸底操作栏：固定底部，随弹层一起移动
- 点击遮罩或下拉关闭

### 5.4 下拉刷新

- 仅在列表顶部下拉时触发
- 阈值：60px
- 指示器：旋转图标 + 文字提示
- 状态：下拉刷新 → 松开刷新 → 刷新中

### 5.5 左滑操作

- 左滑露出右侧操作区域（80px 宽）
- 滑动距离超过一半则自动打开，否则回弹
- 同一时间只有一项可打开
- 操作按钮：木质暖棕底白字

### 5.6 吸底操作栏

- 固定在半屏弹层底部
- 左侧显示信用预扣信息
- 右侧主操作按钮
- 底部安全区适配

## 6. 页面结构规范

### 信息架构

```
工具广场（首页）
├── 搜索栏
├── 分类筛选（横滑）
└── 工具列表（卡片）

我的借用
├── Tab 切换（借用中 / 即将到期 / 历史记录）
└── 借用记录列表（左滑归还）

信用
├── 信用分 Hero（数字滚动）
├── 信用规则三栏
└── 信用记录列表

我的
├── 用户信息卡片
└── 菜单分组
```

### 拇指热区

- 底部 TabBar 和 FAB 在单手可及范围内
- 吸底操作栏按钮靠右，方便右手拇指点击
- 重要操作位于屏幕下半部分

## 7. 材质与质感

### 木质纹理

- 用于导航栏背景、信用页 Hero
- 通过 CSS 渐变模拟木纹效果
- 透明度低，不喧宾夺主

### 扫码激光线

- 橙色发光线
- 扫描运动配合四角定位框
- 识别成功时绿色圆环弹出

### 信用分数字

- 等宽字体
- 数字滚动动效
- 变化时浮动提示

---

## 8. 内容规范

- 工具名称真实可信，含品牌型号
- 邻居昵称符合小区称呼习惯（X栋+称呼）
- 楼栋号、距离、信用分均为合理数据
- 借用规则清晰明确，无歧义
- 空状态提供行动指引

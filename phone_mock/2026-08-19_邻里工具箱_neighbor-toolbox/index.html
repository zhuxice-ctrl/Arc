接口文档
形态：微信小程序
邻里工具箱 后端接口文档 v1.0
工具模块
GET /api/tools/list
获取工具列表
请求参数
categorystring分类筛选（可选）
pageint页码，默认 1
pageSizeint每页数量，默认 10
返回示例
{
  "code": 0,
  "data": {
    "list": [
      {
        "id": "tool_001",
        "name": "博世冲击电钻",
        "owner": "5栋老王",
        "building": "5栋 3单元",
        "status": "available",
        "creditRequired": 50,
        "distance": 120
      }
    ],
    "total": 28
  }
}
GET /api/tools/:id
获取工具详情
路径参数
idstring工具 ID
POST /api/tools/borrow
申请借用工具
请求体
toolIdstring工具 ID
borrowDaysint借用天数
借用模块
GET /api/borrow/my
我的借用记录
请求参数
statusstringongoing/overdue/history
POST /api/borrow/return
确认归还
请求体
borrowIdstring借用记录 ID
信用模块
GET /api/credit/info
获取信用信息
GET /api/credit/records
信用记录列表

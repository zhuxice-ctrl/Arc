# 绿社 Florapost · 园艺植物交换社群原生 App

形态：原生 App

> 日期：2026-08-17 ｜ 方向：V2 手机 UI ｜ 主题：植物交换 / 寄养 / 养护日记社群

## 简介

围绕园艺植物组织的社群 App：植物交换帖、花友广场、养护日记、我的花园。8 个页面在统一手机外壳内可切换，花瓣粉 + 新叶绿 + 米白 + 深棕的春日花园色系。本轮交替判定：上一轮最新为微信小程序「纸上航行」，故本次做原生 App。

## 原生交互

底部 TabBar、大标题导航栏、返回栈导航、底部半屏抽屉 Modal、下拉刷新弹性、悬浮操作按钮 FAB——共 6 种原生端侧交互。

## 动效亮点

页面级签名动效 ×2：首页入场序列动画、花园页环形进度环。组件级 12+：下拉刷新弹性、点赞心跳、FAB 浮动、卡片悬停上抬、抽屉滑入、视差滚动、标签下划线滑动、叶片漂浮等。自定义光标白色粗环 + 粉色内点。

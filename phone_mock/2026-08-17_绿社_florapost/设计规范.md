# 绿社 Florapost · 设计规范

形态：原生 App

> 日期：2026-08-17 ｜ 方向：V2 手机 UI ｜ 主题：园艺植物交换 / 寄养 / 养护日记社群

## 色彩系统

| 角色 | 色值 | 用途 |
|---|---|---|
| 主色 · 新叶绿 | `#5C8A4D` | 主按钮、TabBar 选中态、强调标签 |
| 强调 · 花瓣粉 | `#E8738C` | 个人页头图、点赞、光标内点 |
| 深色 · 深棕 | `#3B2E2A` | 正文、标题、深色区块 |
| 中性 · 暖灰棕 | `#8B7A6A` / `#7A6A5C` / `#A89B8D` | 次要文字、分隔、图标 |
| 表面 · 米白 | `#FAF6EF` | 页面底色 |
| 表面次阶 | `#E8DED2` | 卡片底、输入框 |
| 深棕次阶 | `#5A4A3E` | 分层、描边 |
| 点缀 · 天青 | `#7AB8D9` | 养护提醒、水滴语义小面积点缀 |

每页 3-5 个色调层次，局部色彩分区；各页色彩主角不同（首页偏绿、个人页偏粉、发布页绿米对角分割），整体统一在春日花园色系内。无蓝紫渐变。

## 字体

- 展示字体：`Fraunces`（衬线）——大标题、页面主标题
- 正文字体：`DM Sans`（-apple-system / system-ui 回退）——正文、UI 控件

## 页面结构（8 页，5+ 种独特布局）

1. 首页：Hero 大图 + 分类胶囊 + 卡片信息流 + FAB
2. 详情页：全屏 Hero 视差滚动 + 底部操作栏 + 半屏抽屉评论
3. 花友广场：双列瀑布流 + 底部抽屉面板
4. 发布页：对角分割（上绿下米白）+ 类型切换器 + 表单
5. 我的花园：环形进度环 + 横向滚动植物卡 + 待办列表
6. 个人主页：粉色头图 + 统计网格 + 九宫格拼贴 + 设置列表
7. 设计规范页：色板 / 字体 / 间距 / 组件示例
8. 接口文档页：左侧导航 + 代码块 + 状态码

## 原生交互（6 种）

底部 TabBar、大标题导航栏、返回栈导航、底部半屏抽屉 Modal、下拉刷新弹性、悬浮操作按钮 FAB。

## 动效系统

页面级签名动效 ×2：首页入场序列动画（标题→Hero→分类→卡片错峰淡入上移 + 藤蔓叶片旋转）、花园页环形进度 0→72%（easeOutCubic）。组件级：下拉刷新弹性、点赞心跳、FAB 浮动、卡片悬停上抬、按钮缩放、抽屉滑入、视差滚动、标签下划线滑动、图片悬停缩放、键盘涟漪、叶片漂浮、Tab 指示器滑动。自定义光标：白色粗环 + 粉色内点 + 多层发光，悬停变绿放大、点击涟漪，开页即居中。

## 健壮性

RAF 随 `visibilitychange` 暂停/恢复；定时器重建前先清理；`prefers-reduced-motion` 降级；高频事件直接操作 transform；零未定义引用；JSX 全部内联于 `index.html` 的 `<script type="text/babel">`。

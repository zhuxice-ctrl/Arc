# 设计规范

**形态：原生 App**

## 一、品牌概述

**暗房日记** — 一款面向胶片摄影爱好者的原生 App。以暗房冲洗流程、胶卷管理、作品显影为核心，提供胶卷档案、冲洗计时、作品瀑布流与个人摄影档案。iOS / Android 原生交互语言。

## 二、色彩系统

| 角色 | 色值 | 用途 |
|------|------|------|
| 暖纸底 | `#FBF9F2` / `#F5EFE0` | 首页背景 |
| 米白 | `#F2EFE6` / `#E8E3D4` | 卡片面 |
| 墨黑 | `#2D2822` / `#3a342c` | 沉浸深色页 / 胶卷页 |
| 安全灯红 | `#B5432A` / `#8C2E1C` | 主强调（暗房红光） |
| 砖红 | `#D67962` | 交互态 |
| 黄铜 | `#C9A857` / `#9B7E3A` | 装饰 / 胶卷齿孔 |
| 鼠尾草绿 | `#7A8B6A` / `#A8B898` | 个人页色彩主角 |
| 中性 | `#8A8275` / `#C8C2B0` | 副文本 |

> 每页有独立"色彩主角"：首页暖纸+安全灯红、胶卷页墨黑+黄铜、暗房页深红安全灯、个人页鼠尾草绿+米白，整体统一在暖调胶片质感内。

## 三、字体

- 展示字体：`Noto Serif SC`（衬线，用于大标题）
- 正文字体：`Noto Sans SC`
- 等宽：`JetBrains Mono`（EXIF 参数 / 接口文档）

## 四、页面结构与布局多样性

| 页面 | 布局 | 色彩主角 |
|------|------|----------|
| 首页 | Hero 大图 + 胶卷横向滑动 + 卡片信息流 | 暖纸 + 安全灯红 |
| 发现 | 瀑布流 Masonry + 分类 Chip 切换 | 墨色 + 米白 |
| 胶卷 | 胶片齿孔条 + 深色沉浸 + 相机列表 | 黑底 + 黄铜 |
| 暗房 | 冲洗盘堆叠 + 步骤计时 + FAB | 深红安全灯 |
| 详情 | 全屏 Hero + 视差滚动 + EXIF 参数 | 深色沉浸 |
| 我的 | 环形进度 Canvas + 三栏网格 | 鼠尾草绿 |
| 设计规范 | 色板 + 字体 + 组件 + 间距 | 系统色 |
| 接口文档 | 深色代码块 + 折叠手风琴 | 暗色 + 语法高亮 |

## 五、原生交互要素（≥4 种）

底部 TabBar、返回栈导航、FAB 悬浮操作按钮、横滑胶片条、下拉滚动弹性、模态式详情页转场。

## 六、签名动效

1. 首页 Hero「胶片显影」入场：过曝 → 对比度饱和 → 全彩显影序列
2. 个人页环形进度：Canvas 三色渐变描边，easeOutCubic 绘制

## 七、组件级动效（12+）

Tab 弹性回弹、心形点赞弹跳、快门红光闪烁、FAB 呼吸浮动、卡片错位渐入、Chip 激活态、胶片推进抖动、安全灯脉动、开关位移动画、页面左右推入转场、暗房托盘堆叠切换、下拉弹性。

## 八、健壮性

- rAF / setInterval 卸载与页面隐藏时统一清理
- 视差用 rAF + 直接 DOM transform（不触发 React setState）
- 支持 `prefers-reduced-motion`
- 所有 JSX 内联在 `<script type="text/babel">`，零外部 JSX 引用

接口文档

路线相关

GET /api/v2/routes
获取全部夜跑路线列表，含路灯评分、距离、坡度等信息
{ "code": 0, "data": [ { "id": "r1", "name": "滨江绿道", "distance": 5.2, "lightingScore": 92, "elevation": 12, "suggestedPace": "5'30\"" } ] }
GET /api/v2/routes/:id/lighting
获取指定路线的分段路灯照明数据
{ "code": 0, "data": { "routeId": "r1", "segments": [ { "name": "滨江大桥段", "score": 98, "length": 0.8 }, { "name": "江滩步道段", "score": 85, "length": 1.2 } ] } }
GET /api/v2/routes/:id/blind-spots
获取路线上所有路灯盲区位置

夜跑会话

POST /api/v2/sessions
开始一次新的夜跑会话
{ "code": 0, "data": { "sessionId": "sess_abc123", "routeId": "r1", "startTime": "2026-08-19T21:30:00+08:00" } }
PUT /api/v2/sessions/:id
更新夜跑实时数据（位置、配速、心率）
POST /api/v2/sessions/:id/finish
结束夜跑会话，生成报告
GET /api/v2/sessions
获取历史夜跑记录列表
GET /api/v2/sessions/:id
获取单次夜跑详细数据（配速曲线、盲区复盘）

用户设置

GET /api/v2/user/profile
获取用户资料与夜跑设置
PUT /api/v2/user/settings
更新用户设置（目标配速、盲区提醒开关等）

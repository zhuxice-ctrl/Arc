# 设计规范 · 夜跑配速·城市夜跑路线

> 类别：Phone Mock　日期：2026-08-19　形态：原生 App　主题：夜跑者找路灯亮安全的路线并记录配速

## 一、形态标记

**形态：原生 App**（上一版雪线滑雪图鉴为微信小程序，本次交替为原生 App，遵循 V2 形态交替规则）

## 二、设计母题

路灯照明覆盖评分——以"路灯亮不亮、安不安全"为夜跑选路核心机制，区别于通用运动日志的"路线+配速"模板。路线按路灯覆盖打分，夜跑中实时提示路灯明暗，跑完复盘路灯盲区。

## 三、产品逻辑与 User Flow

完整核心流程可走通：选路线（看路灯评分）→ 开始夜跑（实时配速 + 路灯明暗提示）→ 结束（配速曲线 + 路灯盲区标注复盘）。历史记录存 localStorage。

- 底部 TabBar 4 Tab：今夜路线 / 我的夜跑 / 路灯地图 / 设置
- 今夜路线：4–5 条真实路线（滨江绿道 5.2km 评分92 / 环城夜道 7.8km 评分71 / 湖心环道 3.6km 评分88 / 山脊夜径 6.1km 评分43）
- 路灯地图：Canvas 明暗点阵表达照明覆盖
- 夜跑进行中：配速指针仪表盘 + 路灯明暗状态 + 已跑距离/用时/盲区提示
- 设置：目标配速 / 盲区提醒开关 / 紧急联系人

## 五、字体

系统无衬线（`-apple-system` / 系统默认），数字采用等宽变体突出配速读数。

## 六、动效系统（≥12 组件级特效）

1. 配速指针弹性摆动（cubic-bezier 回弹，签名动效）
2. 路灯明暗脉冲
3. 路线进度条流动
4. Tab 切换回弹
5. 半屏弹层上推
6. 路灯盲区屏幕边缘暗角脉冲
7. 页面 push/pop 过渡
8. 自定义光标琥珀拖尾
9. 点击涟漪
10. 数字滚动（配速/距离）
11. 路灯地图点阵呼吸
12. 开关旋钮回弹

## 七、签名动效

夜跑中进入路灯盲区 → 屏幕边缘暗角 + 警示色脉冲高亮（路灯盲区提示）。

## 八、技术栈

纯 vanilla 单文件 HTML+CSS+JS，390px 手机壳内渲染原生 App 界面，localStorage 存历史夜跑。自定义光标开页居中，RAF 随 `document.hidden` 暂停、卸载取消，支持 `prefers-reduced-motion`。含设计规范页 + 接口文档页（`/api/v2/routes`、`/api/v2/sessions` 等模拟接口）。

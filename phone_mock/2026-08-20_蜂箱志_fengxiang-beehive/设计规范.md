# 蜂箱志 · 设计规范

形态：原生 App｜日期：2026-08-20｜板块：V2 手机 UI

## 一、设计母题

养蜂人每 5–7 天必须开箱检查一次——「蜂箱志」把这套真实高频的查箱动作变成随身工具。核心机制：蜂场 → 蜂箱 → 抽脾式逐项检查（见王 / 卵虫脾 / 蜜粉脾 / 病害）→ 措施 → 蜡封提交 → 摇蜜转柄记批次 → 日志与统计回顾。视觉与交互都从「蜂蜡 + 桐木蜂箱 + 烟熏」的养蜂现场生长出来，不是套通用 App 模板。

## 三、字体系统

- **Noto Serif SC**（衬线，500/600/700/900）：蜂箱名 / 页面标题 / 蜂场名——有温度的名称与标题。
- **Noto Sans SC**（无衬线，400/500/600/700）：正文 UI / 交互文案 / 标签。
- **JetBrains Mono**（等宽）：数字 / 重量 / 日期 / 蜂箱编号——便于快速认读数据。

## 四、动效系统

签名动效（均服务功能，非装饰）：

1. **抽脾上拉**：巢脾卡片跟随手指上拉抽出，阻尼 + 回弹；缓动 `cubic-bezier(0.32, 0.72, 0, 1)`，模拟从蜂箱抽巢框的物理感。
2. **摇蜜转柄**：按住圆形转柄拖动旋转，跟随手指角度 + 松手惯性衰减缓停；蜜量刻度随累计转动圈数连续上升（`requestAnimationFrame` 驱动）。
3. **蜡封提交**：`@keyframes waxDrop` 蜂蜡滴落晕开成封缄，盖在记录卡片上作为提交确认（取代印章）。
4. **提示弹跳**：`@keyframes hintBounce` 数字徽标 / 提示出现时的轻弹。

通用过渡：`transition` 31 处、`transform` 35 处，缓动统一 `cubic-bezier(0.32, 0.72, 0, 1)`（弹簧感）与 `cubic-bezier(0.55, 0, 0.675, 0.19)`（入场）。

## 五、降级与健壮性

- 支持 `prefers-reduced-motion`：开启后弱化 / 关闭非必要动效。
- `cancelAnimationFrame` + `removeEventListener`：卸载时取消 RAF 与解绑事件，避免泄漏。
- 高频 `pointermove`（4 处）直接操作 DOM transform，不触发 React 重渲染。
- 数据 `localStorage` 持久化（key `fengxiangzhi_v2_data`），刷新不丢失；首次加载注入真实默认数据（12 蜂箱 / 5 查箱 / 4 摇蜜样本）。
- 已知次要项：未监听 `visibilitychange` 暂停 RAF（卸载清理已具备），后台标签页时签名动效的 RAF 仍可能运行——属可优化项，不影响功能。

- 底部 4 TabBar（今日 / 蜂场 / 日志 / 我的）+ 页面栈 push/pop + 半屏弹层 + 左滑删除（端侧交互语言 ≥4 种）。
- 蜂箱卡片（箱号 / 蜂种 / 群势力条 / 距上次查箱天数 / 病害标记）。

- 摇蜜步进器 + 转柄旋转盘 + 蜜量刻度。
- 日志时间线（查箱 / 摇蜜分段筛选）+ 删除撤销。
- 蜂场档案统计（蜂箱数 / 本季累计蜜量 / 累计查箱次数 / 蜂种构成）。
- 设计规范页、接口文档页（8 个 REST 接口，可展开请求 / 响应字段）。

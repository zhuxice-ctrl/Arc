# 纸鸢集 · 风筝放飞社群 App

> 日期：2026-08-17 · 方向：V2 手机 UI · 形态：原生 App · 主题：风筝放飞与扎制社群

![预览](./thumbnail.png)

## 简介

「纸鸢集」是一个风筝放飞与扎制社群的原生 App mock，套在统一手机外壳内可切换 8 个页面。棉纸白底 + 柳芽绿主色 + 天青辅助 + 燕脂红强调 + 竹篾黄点缀。内容围绕今日风力适飞指数、放飞场地（真实城市公园/河滩/草市）、风筝图谱（沙燕、龙头蜈蚣、板鹞、软翅蝴蝶等传统门类）、扎制教程（劈竹/绑扎/裱糊/绘彩）、约飞活动与放飞日记，全部真实可交互。

## 动效亮点

- 首页弹簧风力指针 + 多只纸鸢错相位浮动
- 详情页视差滚动 + 尾巴飘带波动 + 线轴转动
- 我的页弹簧环形进度填充
- 下拉阻尼刷新、卡片按压、FAB、Tab 切换微动效

## 原生交互

底部 TabBar、返回栈导航、下拉刷新、底部半屏抽屉、FAB 悬浮按钮、模态转场。

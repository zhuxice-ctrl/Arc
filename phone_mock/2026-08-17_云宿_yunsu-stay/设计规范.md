# 设计规范 · 云宿·山居民宿

> 日期：2026-08-17 · 方向：V2 手机 UI · 形态：原生 App · 主题：山居民宿发现与预订 App

## 色彩系统

| 角色 | 色值 | 用途 |
|------|------|------|
| 竹青（主色） | `#5B8C5A` | 主强调、TabBar 选中、按钮 |
| 山岩灰（辅助） | `#6B6963` | 次级文字、图标 |
| 暖米白（表面） | `#F7F3EC` | 页面底色、卡片背景 |
| 暮霞橙（强调） | `#E8915A` | 价格、点赞、高亮 |
| 深林绿（深色） | `#2D4A2B` | 深色区块、个人页上半屏 |
| 浅竹绿 | `#7AA87A` | 次级强调 |
| 米灰 | `#E0D9C8` | 边框、分隔 |

每页在主配色基础上取 3-5 色调层次，页面色彩主角差异化（首页偏暖米白、详情页 Hero 大图、体验页深林绿底、行程页深绿+暮霞橙）。

## 字体

- 正文：`'Noto Sans SC', -apple-system, BlinkMacSystemFont, sans-serif`
- 标题衬线：`'Noto Serif SC', serif`
- 代码（接口文档页）：`'SF Mono', Menlo, monospace`

## 页面结构（8 页，统一手机外壳内切换）

1. 首页·发现 — Hero 大图视差 + 分类药丸 + 民宿卡片流 + 下拉刷新
2. 房型详情 — 全屏图片视差 + 底部悬浮预订栏 + 设施网格
3. 山居体验 — 深林绿背景 + 横向滑动画廊（snap 对齐）+ 热门列表
4. 房东故事 — 对角分割头图 + 头像卡片 + 数据统计 + 民宿列表
5. 我的行程 — 深绿上半屏 + 环形进度条动画 + 三态 Tab 切换
6. 个人中心 — 渐变头像区 + 脉冲光环 + 菜单列表 + 数据统计
7. 设计规范 — 深色 hero + 色板 + 字体系统 + 组件/间距/圆角规范
8. 接口文档 — 黑色代码风格 + 可展开折叠的 5 个 RESTful 接口

至少 5 个页面布局非重复（Hero 视差 / 横向画廊 / 对角分割 / 环形进度 / 代码折叠）。

## 原生端侧交互（≥4 种）

底部 TabBar、底部半屏抽屉（快捷操作）、悬浮 FAB 按钮、下拉刷新、模态弹窗、返回栈导航。

## 签名动效

- 首页：竹叶飘落粒子 + 入场序列错峰上滑
- 详情页：Hero 视差滚动
- 行程页：环形进度条动画

## 组件级动效（14+）

自定义光标（弹簧跟随 + 悬停放大 + 点击涟漪 + 多层发光）、竹叶飘落粒子、Hero 视差滚动、入场序列动画、卡片悬停抬起 + 图片缩放、心形脉冲点赞、按钮光泽扫过、环形进度条动画、头像脉冲光环、设置按钮悬停旋转、FAB 悬停旋转放大、收藏按钮状态切换、Toast 弹性弹出、图标悬停变色反转。

物理模型：弹簧跟随光标、脉冲呼吸、错峰延迟。支持 prefers-reduced-motion 降级；RAF/定时器随 visibilitychange 暂停、卸载清理；高频 mousemove 直操 DOM。

## 技术栈

单文件 HTML（内联 CSS + JSX 内联于 `<script type="text/babel">`），React 18 + Babel standalone（feishucdn CDN）。

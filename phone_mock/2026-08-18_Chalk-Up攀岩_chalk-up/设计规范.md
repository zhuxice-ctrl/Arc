# Chalk Up 攀岩社区 · 设计规范

形态：原生 App

> 方向：V2 手机 UI · 日期：2026-08-18
> 主题：攀岩馆与攀岩爱好者社区 App（V2 双形态交替：上一轮为微信小程序「阳台花园」，本次交替为原生 App）

| 角色 | 色值 | 用途 |

## 字体

- 展示标题：`Noto Serif SC, serif`
- 正文 UI：`Noto Sans SC, -apple-system, BlinkMacSystemFont, sans-serif`
- 数据 / 编号：`JetBrains Mono, monospace`（难度、高度、次数）

## 圆角

- 卡片：10px / 12px / 14px（按层级）
- 小控件：8px
- 徽章 / 头像 / FAB：`border-radius: 50%`

## 页面结构（8 页，布局差异化）

| 页面 | 布局语言 |
|---|---|
| 首页 | 岩馆信息流 + 入场序列动画（Hero 渐入、统计卡错峰） |
| 线路墙 | 网格拼贴 + 难度色标筛选 + 入场级联 |
| 线路详情 | 全屏详情转场 + 视差岩点 + 吸底 CTA |
| 约爬广场 | 3D 卡片堆叠 + 拖拽滑动 + FAB |
| 训练打卡 | 环形进度 + 周训练柱状图 + 计划勾选 |
| 个人中心 | 徽章墙 + 动态时间线 |
| 设计规范页 | 色彩 / 字体 / 间距 / 圆角 / 难度色标展示 |
| 接口文档页 | 深色代码风格 + Tab 切换 + REST 方法色标 |

## 原生端侧交互（6 种）

底部 TabBar（选中微动效）、全屏详情页转场、模态底部抽屉（分享 / 设置）、长按快捷菜单、下拉刷新（弹性回弹）、悬浮操作按钮 FAB（旋转弹出菜单）。

## 动效系统（12+ 组件级特效）

入场序列、环形进度描边、柱状图生长、卡片堆叠缩放、FAB 旋转弹出、下拉弹性回弹、点赞切换、Tab 切换、Toast 浮动、ripple 点击涟漪、长按提示、视差岩点。

## 自定义光标

高对比双环开页即居中显示，悬停放大，点击涟漪，RAF 驱动跟随；`visibilitychange` 自动暂停；`prefers-reduced-motion` 兼容。

## 接口文档（摘要）

统一 `/api/v1/*` 风格：岩馆列表 / 线路墙 / 线路详情 / 约爬帖子 / 训练打卡 / 用户徽章，GET/POST/PUT/DELETE 方法色标区分，详见应用内「接口文档」页。

## 健壮性

- 零未定义引用；RAF / 定时器随页面可见性暂停、卸载统一取消
- 快速切换页面不叠加定时器（重建前先 clear）
- 高频触摸 / 鼠标事件直接操作 DOM transform
- 支持 `prefers-reduced-motion` 降级

## 字体系统

- **正文字体栈**：`"Noto Sans SC", "PingFang SC", -apple-system, sans-serif`
- **标题字体栈**：`"Noto Serif SC", serif`
- **等宽字体**：`monospace`（用于接口文档代码展示）

## 圆角规范

- 卡片圆角：`16px`
- 按钮圆角：`12px`
- 小标签圆角：`6px`
- 手机外壳圆角：`40px`
- 胶囊按钮圆角：`16px`

## 小程序端侧交互（6种）

| 交互 | 实现方式 | 所在页面 |
|------|----------|----------|
| 胶囊按钮导航栏 | 右上角 ··· / ⊙ 按钮，自定义导航栏随页面变化 | 全局 |
| 底部 TabBar | 4 个 Tab（首页/图鉴/日记/我的），选中弹跳微动 | 全局 |
| 半屏弹层 | 点击「加入待捕清单」弹出半屏选择面板，滑入滑出 | 物种详情页 |
| 下拉刷新 | 首页下拉触发刷新动画，弹性回弹 | 首页 |
| 左滑操作 | 日记页左滑显示删除/分享按钮 | 赶海日记页 |
| 吸顶 Tab | 图鉴页分类 Tab 滚动到顶部后吸顶固定，下划线滑动 | 物种图鉴页 |

## 动效系统

| 编号 | 动效名称 | 实现方式 |
|------|----------|----------|
| 1 | 自定义光标 | DIV + mousemove，白环+珊瑚橙内点+发光+点击涟漪 |
| 2 | 页面切换转场 | transform translateX 推入/推出 |
| 3 | 首页入场序列 | 各区块依次 animation-delay 淡入上浮 |
| 4 | 卡片 3D 倾斜 | mousemove 直接操作 transform |
| 5 | 潮汐波浪动画 | SVG path 动画模拟水位变化 |
| 6 | TabBar 弹跳 | CSS @keyframes 弹性缩放 |
| 7 | Tab 下划线滑动 | transform translateX + transition |
| 8 | 半屏弹层滑入 | transform translateY + transition |
| 9 | 左滑操作 | transform translateX + 手势判断 |
| 10 | 按钮按压缩放 | :active transform scale |
| 11 | 滚动渐入 | IntersectionObserver |
| 12 | 骨架屏加载 | 切换页面时显示 CSS 骨架占位 |
| 13 | 数字计数动画 | requestAnimationFrame 缓动计数 |

## 健壮性

- visibilitychange 暂停 requestAnimationFrame
- 快速切换页面不叠加定时器（重建前清除旧定时器）
- 高频 mousemove 直接操作 DOM transform
- 支持 prefers-reduced-motion 降级
- 零未定义引用

## 技术栈

- 纯 vanilla HTML/CSS/JS 单文件
- 无 React/Babel/CDN 依赖
- SVG 动画渲染潮汐波浪

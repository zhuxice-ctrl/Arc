## 一、色彩系统

以传统大漆五色为核心色板，宣纸米白为基底，水盘深墨青为画布色。拒绝蓝紫渐变，坚持矿物颜料的真实质感。

### 主色（颜料色）

| 色名 | 色值 | 用途 |
|------|------|------|
| 朱砂红 Cinnabar | `#C0392B` | 品牌主色 · 强调按钮 · TabBar 激活态 · 进度环 |
| 石黄 Ochre | `#D4A017` | 漆色色卡 · 配方芯片 · 暖色点缀 |
| 石青 Azurite | `#2E5A88` | 漆色色卡 · 冷色点缀 · 水盘深处 |
| 松烟墨 Pine Ink | `#1C1C1C` | 正文墨色 · 深色背景 · 删除按钮 |
| 金箔 Gold Foil | `#C9A14A` | 金箔颗粒 · 高光点缀 · 装饰性色 |

### 中性色（材质色）

| 色名 | 色值 | 用途 |
|------|------|------|
| 宣纸白 Paper | `#F5EFE6` | 页面背景 · 主底色 |
| 宣纸深 Paper Deep | `#EDE4D3` | 卡片底 · 分区底 · 输入框底 |
| 纸面 Sheet | `#FBF7F0` | 弹层面板 · 卡片凸起面 |
| 墨色 Ink | `#2c2420` | 主文字色 |
| 淡墨 Ink Light | `#6b5e56` | 次级文字 · 说明文字 |
| 灰墨 Ink Muted | `#a89a8d` | 辅助文字 · 占位符 · Tab 未激活 |
| 线色 Line | `#d9cdbd` | 分割线 · 边框 |
| 水盘深青 Water Dark | `#1a2630` | 水盘画布底色 |
| 水盘中青 Water Mid | `#243441` | 水盘渐变中间色 |
| 水盘浅青 Water Light | `#2f4555` | 水盘高光色 |

### 色彩使用原则

- 朱砂红为唯一激活色 / 操作色，全 App 不超过 2 处同时高亮
- 五色颜料以色卡形式出现时，保持圆形 + 投影，模拟真实颜料质感
- 中性色带暖调（偏米偏棕），避免冷灰，呼应宣纸材质
- 金箔只用于装饰性点缀（金箔颗粒、水面反光），不作功能性色

## 二、字体系统

系统默认中文字体栈，iOS 优先 PingFang SC，Android 回退 Noto Sans CJK SC / 微软雅黑。无外部字体依赖。

```
font-family: -apple-system, BlinkMacSystemFont, "PingFang SC", "Noto Sans CJK SC", "Microsoft YaHei", sans-serif;
```

### 字号层级

| 层级 | 字号 | 字重 | 行高 | 用途 |
|------|------|------|------|------|
| 大标题 Large Title | 32px | Bold (700) | 1.2 | 页面顶部大标题（扇册/色谱/规范） |
| 标题 1 Heading | 22px | Bold (700) | - | 扇面详情名称 |
| 标题 2 Nav Title | 17px | Semibold (600) | - | 导航栏标题 · 弹层标题 |
| 正文 Body | 14px | Regular (400) | 1.7 | 段落文字 · 卡片名称 |
| 辅助 Caption | 13px | Regular (400) | 1.5 | 说明文字 · 色卡描述 |
| 小字 Small | 12px | Regular (400) | - | 日期 · 标签 · 角标 |
| Tab 标签 | 10px | Medium (500) | - | TabBar 文字 |

### 字体使用原则

- 展示场合（大标题）保持较大字号与字重，形成视觉冲击力
- 正文行高 1.7，确保长文可读性
- 色值 / 接口路径用等宽字体（SF Mono / Menlo / monospace）

## 五、动效系统

功能性反馈优先，拒绝装饰性动效。动效时长 200–380ms，缓动曲线统一为 `cubic-bezier(0.32, 0.72, 0, 1)`。

### 动效清单

| 动效 | 时长 | 缓动 | 说明 |
|------|------|------|------|
| 漆滴入水扩散 | 400ms | easeOutBack | 模拟漆滴落入水面的弹跳扩散 |
| 搅纹流动 | ~1500ms | 线性 | 螺旋纹理舒展 |
| 扇入涟漪 | 400ms | ease-out | 扇面入水时的水波扩散 |
| 页面 push/pop | 320ms | cubic-bezier | 页面栈左右滑动 |
| 半屏弹层 | 380ms | spring (cubic-bezier) | Bottom Sheet 上滑 |
| **提扇显纹（签名）** | **800ms** | **cubic-bezier(0.22, 1, 0.36, 1)** | **扇面上提+纹样转印+金箔飘散** |
| 晾干进度 | 3000ms | linear | 环形进度 + 文字百分比 |
| Tab 切换 | 即时 | - | 无过渡，直接切换 |
| Toast 出现 | 240ms | ease | 缩放 + 淡入 |

### 签名动效细节

**提扇显纹**是整个 App 的签名时刻（Signature Moment）：

1. 扇面从小变大、从下往上升起（800ms）
2. 纹样随提拉进度逐步从底部向上显形，模拟转印过程
3. 提拉速度影响纹样疏密：快速=细密拉丝纹，慢速=大片晕染
4. 完全提出后金箔颗粒随机飘散（仅配方含金箔时）
5. 支持 `prefers-reduced-motion`：降级为静态快照，直接显示最终纹样

## 六、组件规范

### 底部 TabBar

- 高度：68px（含安全区）
- 背景：半透明宣纸白 + 毛玻璃（backdrop-filter: blur(20px)）
- 图标：24×24px，线形 1.8px
- 激活色：朱砂红 `#C0392B`
- 未激活色：灰墨 `#a89a8d`
- 4 个 Tab：水盘 / 扇册 / 色谱 / 规范

### 颜色色卡

- 尺寸：44×44px，圆形
- 投影：0 4px 12px 黑 20%
- 激活态：白色描边 2.5px + 放大 1.15 倍
- 右上角角标：滴漆数量，深色圆底白字

### 半屏弹层 (Bottom Sheet)

- 最大高度：75% 屏高
- 顶部 Grabber：36×5px 圆角灰条
- 背景：纸面色 `#FBF7F0`
- 内边距：横向 20px
- 遮罩：40% 黑 + 240ms 淡入

### 按钮

- 主按钮：朱砂红底白字，14px 内边距，12px 圆角
- 次按钮：宣纸深底墨字
- 点击态：缩放 0.98 + 不透明度变化

## 七、页面结构

### Tab 1：今日水盘
- 大标题 + 当前配方提示
- 圆形水盘 Canvas（核心交互区）
- 5 色色卡行（点击滴漆）
- 操作行（搅纹 / 清空 / 选扇胚）
- 可拖拽扇柄（拖入水区+上提显纹）

### Tab 2：扇册
- 大标题 + 数量副标题
- 双列网格（扇面预览 + 名称 + 日期 + 色卡）
- 空状态（引导去水盘创作）
- 下拉刷新
- 点击卡片 → 详情弹层（配方 + 复现 + 删除）

### Tab 3：色谱
- 大标题 + 副标题
- 大漆五色列表（色卡 + 名称 + 色值 + 描述）
- 扇胚介绍（3 种）
- 工艺参数说明（水温/角度/速度/搅拌/晾干）

### Tab 4：规范 / 接口
- 分段控件切换
- 设计规范页（色彩 / 字体 / 动效 / 令牌）
- 接口文档页（扇册 CRUD + 配方管理 + 数据结构）

## 九、技术边界

- 纯 vanilla 单文件 HTML，无 React / Babel / CDN 外部依赖
- Canvas 2D 实现水盘漆色与转印效果
- localStorage 持久化扇册数据
- 390px 目标宽度，414px 自适应
- 支持 `prefers-reduced-motion` 降级
- 响应式：移动端全屏，桌面端设备框预览

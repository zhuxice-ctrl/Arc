扇册管理

GET /api/fans
获取扇册列表，按创建时间倒序排列
参数：page=1&limit=20
返回：{ list: Fan[], total: number }
GET /api/fans/:id
获取单把漆扇详情及配方数据
返回：{ id, name, createdAt, blankType, recipe, patternData }
POST /api/fans
保存新完成的漆扇入扇册
Body：{ name, blankType, recipe, patternData }
返回：{ id, createdAt }
DELETE /api/fans/:id
删除指定漆扇
返回：{ success: true }

配方管理

GET /api/recipes
获取收藏的配方列表
返回：Recipe[]
POST /api/recipes/:fanId
从已有漆扇提取并保存配方
返回：{ id, name, recipe }

数据结构

Fan {

  name: string
  blankType: 'plain' | 'silk' | 'oilpaper'
  recipe: {
    colors: { name: string, hex: string, drops: number }[]
    waterTemp: number
    dipAngle: number
    liftSpeed: 'fast'|'medium'|'slow'
    stirPattern: string
  }
  patternData: string (base64 canvas)
  createdAt: number
}

# 云间茶馆 Cloudbrew · 设计规范

## 主题
高山云雾采茶 / 茶室预约 / 茶品收藏手机 App。统一手机外壳内 8 页可切换。

## 色彩系统
雾绿 + 栗棕 + 米白 + 釉青点缀 + 焙火橙（禁蓝紫渐变）。每页有独立"色彩主角"。

| 角色 | 色值 | 用途 |
|------|------|------|
| 雾绿主 | #2F5D55 / #3F7A70 / #4F9289 | 主色、Tab、强调 |
| 深绿底 | #00201c / #171d1b / #1F2922 | 沉浸页深底 |
| 叶绿阶 | #283F26 / #2E4431 / #324E2E / #3E6038 / #4D7946 | 卡片、辅助 |
| 栗棕 | #2C1D12 / #3F2A1B / #4a3f28 | 文字、木质元素 |
| 焙火橙 | 局部暖色点缀 | CTA、进度 |
| 中性 | #1F2329 / #333A44 / #49454f | 代码文档页 |
| 米白 | 卡片表面 | 浅页底 |

## 字体
- `'Noto Serif SC', 'Songti SC', serif`：标题
- `'Noto Sans SC', system-ui, sans-serif`：正文/UI

## 页面（8 页，≥5 种非重复布局）
1. 今日茶席（首页）— Hero 大图 + 滚动视差 + 茶烟蒸腾签名动效
2. 茶山探索 — 对角分割 + 地图卡
3. 茶品市集 — 瀑布流 + 底部弹出抽屉
4. 冲泡计时器 — 圆环进度 + 深色沉浸 + 水波涟漪签名动效
5. 我的茶仓 — 环形进度 + 网格拼贴
6. 茶品详情 — 画廊 + 渐变表头
7. 设计规范 — 色板/字体/组件展示
8. 接口文档 — 深色代码文档

## 组件
- 自定义光标（三态 + 涟漪）
- 3D 卡片倾斜
- 打字机
- 数字计数（缓出指数）
- 光泽扫过
- 脉冲环
- spring-pop 入场
- 弹性悬浮按钮（FAB）
- 毛玻璃面板
- 滚动渐入
- 叶片漂浮粒子
- 底部 Tab Bar 5 主页 + 浮层叠加详情/规范/文档

## 动效系统
12+ 组件级特效；2 个页面级签名动效：
- 首页茶杯蒸腾茶烟（RAF 粒子系统 + 正弦漂移）
- 冲泡计时器水波涟漪

动效基于弹簧/惯性/阻尼/RAF 积分器与茶主题语义；周期各异。

## 健壮性
- RAF/定时器随 visibilitychange 暂停，卸载取消
- prefers-reduced-motion 降级
- 高频 mousemove 直接操作 DOM transform
- 所有 JSX 内联于 index.html（components/*.jsx 为 inline 前源码留存，index.html 已自包含）

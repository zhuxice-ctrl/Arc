# 方寸集 · 设计规范

形态：原生 App

## 色彩系统

| 角色 | 色值 | 用途 |
|---|---|---|
| 主色·翡翠墨绿 | #1B6B52 | 主品牌色、TabBar 选中、强调 |
| 深翡翠 | #0F4A38 | 深色卡片、渐变端 |
| 亮翠 | #2D8A6B | 悬停、辅助强调 |
| 铜币橙 | #C9753A | 辅助强调、价格、币种元素 |
| 邮戳红 | #B23A2E | 强调红、邮戳、警示 |
| 暗红 | #8A2A22 | 邮戳深色端 |
| 宣纸米 | #F6F1E6 | 浅色页面背景、卡片表面 |
| 雾灰绿 | #E4EBE6 | 次表面、分割 |
| 暖灰 | #9BA3A0 | 次要文字 |
| 炭黑 | #14171A | 深色背景、文字 |
| 更深 | #0a0c0e | 全屏详情深底 |

配色策略：翡翠墨绿为品牌主色，呼应邮票钱币收藏的沉稳与历史感；铜币橙与邮戳红作为金属与印章质感的强调色，制造钱币/邮戳的实体隐喻。每页有自己的色彩主角但统一在墨绿体系内。禁止蓝紫渐变。

## 字体

- 正文：'Noto Sans SC', -apple-system, BlinkMacSystemFont, sans-serif
- 衬线标题：'Noto Serif SC', serif / 'EB Garamond', serif（藏品名、钱币面值）
- 数字/计数：'Noto Sans SC', sans-serif

## 组件规范

- 自定义光标：白色粗环 + 翡翠墨绿内点 + 多层发光，z-index 最高，悬停交互元素放大变色，点击涟漪
- 底部 TabBar：原生质感，选中态微动效（下划线滑动 + 图标缩放）
- 邮票齿孔卡片：齿孔光泽扫过 + 悬停按压缩放
- 钱币卡片：3D rotateY 翻转动效
- 长按快捷菜单：模态弹窗，弹簧入场
- 悬浮 FAB：点击旋转
- 环形进度环：stroke-dashoffset 动画
- 渐变头像环：旋转渐变
- 下拉刷新：弹性回弹

## 动效系统（12+）

1. 自定义光标（三态 + 涟漪）
2. 邮票齿孔光泽扫过
3. 钱币翻转（3D rotateY）
4. 弹簧入场（cubic-bezier 弹性曲线）
5. 卡片按压缩放
6. 环形进度 stroke-dashoffset
7. 旋转渐变头像环
8. 筛选 Chip 弹簧切换
9. 涟漪点击
10. Tab 下划线滑动
11. FAB 点击旋转
12. Postmark 邮戳盖印签名动效
13. 瀑布流逐项淡入
14. 滚动视差缩放

页面级签名动效：首页邮戳盖印入场动画；详情页 Hero 视差滚动。动效基于弹簧/阻尼物理模型与邮戳盖印语义。RAF 随 visibilitychange 暂停、卸载取消；高频事件直接操作 DOM transform；支持 prefers-reduced-motion。

## 原生端侧交互（≥6 种）

底部 TabBar、返回栈导航、下拉刷新弹性、长按快捷菜单、悬浮 FAB、模态弹窗。

## 页面结构（8 页，统一手机外壳内切换）

| 页 | 布局特色 |
|---|---|
| 首页 | 大标题导航 + 今日邮市渐变卡 + 邮票轮播画廊 + 下拉刷新 |
| 藏品页 | 瀑布流/网格拼贴 + 分类筛选 + 长按快捷菜单 |
| 市集页 | 卡片信息流 + 悬浮 FAB + 分类 Tab + 搜索栏 |
| 详情页 | 全屏转场 + Hero 大图视差 + 底部操作栏 |
| 藏友圈 | 对角分割/错落瀑布流 + 时间线双视图切换 |
| 我的 | 环形渐变头像 + 悬浮统计卡 + 成就勋章网格 + 环形进度环 |
| 设计规范 | 暗色主题 + 色彩/字体/组件/动效四段式 |
| 接口文档 | 分类 Tab + 方法色标 + 参数列表 |

至少 5 页有独特非重复布局结构，避免换皮不换骨。

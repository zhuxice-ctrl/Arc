# 设计规范

形态：原生 App

## 一、设计理念

木作开料 · 套裁工坊是一款为木工爱好者打造的移动端原生 App。设计语言取自真实木作工坊的器物与材质世界——松木板材的暖黄色作为画布、深胡桃的墨线作为文字与锯缝、角尺的钢灰色作为辅助信息、安全橙作为操作提示。整体视觉避免数字产品的通用审美，用具象的材质感传递行业属性。

- 木纹色 = 物料（板材、零件、木材）

## 三、字体系统

### 字体家族
- **标题字体**：Noto Serif SC（思源宋体）—— 承载木作工坊的手作质感与人文气息，用于大标题、页面标题、品牌标识
- **正文字体**：Noto Sans SC（思源黑体）—— 界面正文、按钮文案、列表项
- **等宽字体**：JetBrains Mono —— 尺寸数值、利用率百分比、代码展示、规格数据

### 字号层级
| 层级 | 字号 | 字重 | 用途 |
|------|------|------|------|
| H1 页面大标题 | 28px | 700 (Serif Bold) | 页面主标题（开料台、零件库等） |
| H2 区块标题 | 18px | 700 (Serif Bold) | 卡片组 / 区块标题 |
| H3 弹层标题 | 20px | 700 (Serif Bold) | 底部弹层标题 |

| Data 数据 | 28px | 700 (Mono) | 利用率大数字 |
| Mini 极小 | 9-11px | 400 | 标尺刻度 / 零件标签 |

## 四、动效系统

所有动效遵循 `prefers-reduced-motion` 系统设置，用户禁用动效时全部关闭。

| 动效名称 | 时长 | 缓动 | 触发场景 | 技术实现 |
|---------|------|------|---------|---------|
| 磁性吸附 | 即时（帧级） | — | 拖拽零件靠近板材边缘 / 其他零件 1.5% 范围内 | 位置硬切 + `snapped` 边框高亮 |
| 木屑溅落 | 500-800ms | ease-out quad | 零件放下到板材表面时 | DOM 粒子 + requestAnimationFrame |
| 数字滚动 | 400ms | cubic ease-out | 利用率数值变化时 | requestAnimationFrame + 缓动插值 |
| 页面过渡（push） | 300ms | cubic-bezier(0.25, 0.46, 0.45, 0.94) | 页面栈进入 | CSS slideInRight |
| 底部弹层 | 300ms | 同上 | sheet 弹出 | CSS slideUp + 背景 fadeIn |
| Toast 提示 | 300ms 淡入 + 2s 停留 | ease | 操作反馈 | CSS opacity + translateY |
| 按钮按压 | 150ms | — | 按钮 / 卡片点击 | `:active` scale(0.92-0.97) |

### 性能约束
- 高频指针事件（拖拽）直接操作 DOM style，不经 React state
- 吸附检查用 `requestAnimationFrame` 节流，不每像素计算
- 所有 rAF / 定时器随页面 `visibilitychange` 暂停
- 组件卸载时取消所有挂起的 rAF / setTimeout

## 五、间距栅格

基础单位 4px。所有间距为 4 的倍数。

| Token | 数值 | 典型用途 |
|-------|------|---------|
| xs | 4px | 图标内边距、标签间距、分割线 |
| sm | 8px | 卡片内紧凑间距、小 gap |
| md | 12px | 列表项垂直 padding、区块内间距 |
| lg | 16px | 页面水平边距、卡片间距 |
| xl | 24px | 区块间距、大标题下间距 |
| 2xl | 32px | 页面顶部留白 |

## 六、组件规范

### 主按钮（Primary Button）
- 高度：48px
- 字号：16px / 600
- 圆角：12px
- 背景：安全橙 `#E85D2B`
- 文字：白色
- 按压：opacity 0.8

### 次级按钮（Secondary Button）
- 高度：48px
- 字号：16px / 500
- 圆角：12px
- 背景：纸白浅 `#F0EBE0`
- 描边：1px 钢灰 3
- 文字：深胡桃

### 浮动操作按钮（FAB）
- 尺寸：48×48px
- 圆角：14px
- 主 FAB：安全橙背景 + 白色图标 + 橙阴影
- 次 FAB：纸白底 + 胡桃图标 + 棕阴影
- 按压：scale(0.92)

### 输入框
- 高度：44px
- 字号：15px
- 圆角：10px
- 背景：纸白浅 `#F0EBE0`
- 描边：1px 钢灰 3
- 聚焦：描边变安全橙 + 纸白底

### 卡片
- 圆角：10-14px
- 描边：1px rgba(61,43,31,0.08)
- 背景：纸白浅
- 按压：scale(0.97)

### 列表项
- 高度：约 52px（含 padding）
- 分割线：0.5px rgba(61,43,31,0.08)
- 图标框：40×40px / 圆角 10px / 松木黄底

### TabBar
- 总高度：84px（含 34px 安全区）
- 图标：24×24px
- 文字：11px
- 激活色：安全橙
- 未激活：钢灰 2
- 背景：纸白 0.92 + backdrop-filter blur(20px)

## 七、板材与零件视觉

### 板材画布
- 宽高比 = 板材实际尺寸（默认 1220×2440）
- 背景：松木黄 + 多层木纹纹理（repeating-linear-gradient）
- 网格：100mm 间隔的浅胡桃色细线
- 边框：1.5px 深胡桃实线（模拟裁切面）
- 标尺：四边毫米刻度，等宽字体 9px

### 零件块
- 填充：榉木色 + 细密木纹
- 描边：1.5px 深胡桃
- 标签：半透明白底 + 等宽字 9px
- 木纹方向指示：中心 1px 横线（旋转后变竖线）
- 选中态：2px 安全橙虚线描边 + 操作浮标

### 锯缝
- 宽度：4mm（吸附时自动保留此间距）
- 视觉：零件间空隙即为锯缝，不额外画线

## 八、页面结构

1. **开料台**（首页 / Tab 1）— 板材画布为核心，上部状态栏+标题，下部零件托盘，右下 FAB 组
2. **零件清单**（Tab 2）— 列表形式管理所有零件种类
3. **方案库**（Tab 3）— 双列网格展示保存的套裁方案缩略图
4. **我的**（Tab 4）— 设置项 + 设计规范入口 + 接口文档入口
5. **设计规范**（push 页）— 完整设计 token 文档
6. **接口文档**（push 页）— REST API 文档

### 导航模式
- 同级切换：底部 TabBar
- 层级跳转：页面栈 push/pop（左右滑动过渡）
- 上下文操作：底部半屏弹层（sheet）

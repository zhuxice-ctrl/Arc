> 方向：V2 手机应用 UI · 日期 2026-08-16 · 日式和菓子品牌 App（温润、克制、带一点甜）

## 色彩系统

主配色（当天体系），每页在主配色内有自己的「色彩主角」：

| 角色 | 色值 | 用途 |
|---|---|---|
| 奶油 / 主底 | `#FFF6EC` | 全局底色，温润留白 |
| 蜜桃粉 / 主色 | `#FFB4A2` | 今日页、菜单页主角，按钮、强调 |
| 酒红 / 深色强调 | `#6D1A2D` | 我的页深色块、会员卡、标题深色 |
| 浅豆绿 / 辅助 | `#B7C9A8` | 预订页、收藏页主角，辅助色块 |
| 焙茶褐 / 中性 | `#8C6A4F` | 次要文字、分隔、图标描边 |

层次扩展色（每页 3–5 个色调层次）：

- 粉系层次：`#FFB4A2` / `#FFD4C9` / `#E8907E` / `#FFFBF5`
- 绿系层次：`#B7C9A8` / `#D5E0CC` / `#8FA77B`
- 红系层次：`#6D1A2D` / `#8C2A3F` / `#4A0F1C`
- 暖中性：`#8C6A4F` / `#B59882` / `#5E4330` / `#3A2A1F` / `#F7E9D7`

配色原则：拒绝蓝紫渐变；以蜜桃粉 + 酒红 + 豆绿构成温润日系甜点气质，页面间色彩主角轮换制造节奏。

## 字体系统

- 日文标题 / 衬线：`'Shippori Mincho', 'Noto Serif JP', serif`（明朝体，和风气质）
- 正文：`'Noto Sans JP', 'Noto Serif JP', system-ui, sans-serif`
- 等宽：`ui-monospace, 'SF Mono', Menlo, monospace`（接口文档、参数表）

## 组件规范

- 手机外壳：统一外壳内切换页面，底部 4 Tab 导航
- 卡片：阴影分层 + 圆角，前后景关系明确
- 底部抽屉：弹簧曲线上滑，可拖拽
- 步骤条：进度圆 + 连接线
- 日历网格：日期选中弹跳
- 环形进度：stroke-dashoffset 描边
- FAB：悬浮操作球 + 阴影
- 会员卡：局部渐变（非蓝紫）

## 动效系统（12+ 项组件级特效）

| # | 动效 | 原理 / 语义 |
|---|---|---|
| 1 | 自定义光标 | 弹簧跟随、悬停形变、点击涟漪 |
| 2 | 首页入场序列 | 标题/价格/标签/卡片错峰弹性入场（cubic-bezier 弹簧） |
| 3 | 详情页抽屉弹簧上滑 | Hooke 弹簧曲线 |
| 4 | 详情页图片视差 | 滚动驱动形变 |
| 5 | 我的页环形进度 | stroke-dashoffset 描边 1.5s 缓出 |
| 6 | 卡片悬停上浮 | transform + 阴影 |
| 7 | 图片缩放 | 悬停放大 |
| 8 | 按钮涟漪 | 点击扩散 |
| 9 | 分类切换重排 | FLIP 过渡 |
| 10 | 日期选中弹跳 | 弹簧回弹 |
| 11 | 步骤进度圆 | 描边推进 |
| 12 | 收藏心形 / FAB 阴影 | 状态切换 |
| 13 | 导航栏选中态 | 指示器滑动 |

动效周期各不相同，禁止整图缩放 / Ken Burns。`requestAnimationFrame` 随 `visibilitychange` 暂停；`prefers-reduced-motion` 降级；高频鼠标事件直接操作 DOM transform。

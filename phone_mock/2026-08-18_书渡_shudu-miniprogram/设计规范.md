# 书渡 · 二手书漂流小程序 · 设计规范

> 日期：2026-08-18 · 方向：V2 手机 UI · 形态：微信小程序 · 主题：二手书漂流微信小程序

## 一、设计概念

"书渡"是一个二手书漂流微信小程序，让闲置好书在不同书友间流转。整体是"月白为底、苔绿为主、赭石为暖强调、暖灰为中性"的书卷自然气质，模拟小程序端侧的胶囊导航、底部 TabBar、半屏弹层、下拉刷新、吸底操作栏等交互语言。

## 二、色彩系统

| 角色 | 色值 | 用途 |
|---|---|---|
| 月白（主底） | `#eef0e8` | 页面底色 |
| 苔绿（主色） | `#4a6b3a` | 主题色、TabBar、主按钮 |
| 苔绿深 | `#355128` | 强调/深底 |
| 苔绿亮 | `#6b8f55` | 次级强调 |
| 赭石（强调） | `#a05c2c` | 行动点、价格、暖色点缀 |
| 赭橙 | `#c87844` | 亮色强调/状态 |
| 暖灰（中性） | `#8a8275` | 次级文本、边框 |
| 暖灰浅 | `#b8b2a6` / `#d6d0c4` | 分隔、卡片内层 |
| 米绿 | `#dfe2d3` | 卡片底色分区 |
| 奶纸 | `#e8c9a8` | 暖色高光 |
| 墨褐 | `#2a2620` | 标题、深底 |

配色规则：每页在主配色体系内可有自己的"色彩主角"（首页偏苔绿、书单页偏米绿、详情页偏暖赭、个人页偏墨褐），但整体统一在月白+苔绿+赭石体系内。

## 三、字体

- 主体：`'Noto Sans SC', -apple-system, system-ui, sans-serif`
- 衬线点缀：`'Noto Serif SC', serif`（书名、标题）

## 四、圆角

12px / 14px / 16px / 20px（卡片）/ 42px（TabBar 凸起）/ 50%（头像）/ 3px（标签）

## 五、页面结构（8 页）

1. 首页：Hero 卡片流 + 分类入口 + 最近漂流 + 书友圈
2. 书单页：吸顶 Tab + 筛选芯片 + 瀑布流
3. 书籍详情：视差滚动 + 底部吸底操作栏 + 漂流足迹时间轴
4. 漂流地图：站点脉冲 + 动效漂流路径 + 底部抽屉
5. 个人中心：环形进度 + 宫格菜单 + 动态列表
6. 设计规范页（标注「形态：微信小程序」）
7. 接口文档页（标注「形态：微信小程序」）
8. 发布漂流页：三步表单 + 底部安全区主按钮

## 六、端侧交互语言

- 胶囊按钮自定义导航栏（随页面透明/渐变/吸顶变色）
- 页面栈 push/pop 转场（右滑返回手势感）
- 底部 TabBar（选中态弹跳动效）
- 半屏弹层 / ActionSheet 动作面板
- 下拉刷新弹性回弹
- 吸顶 Tab
- 底部安全区主按钮
- 骨架屏加载

## 七、动效系统

1. 自定义光标（白环 + 赭石内点 + 多层发光 + 点击涟漪）
2. TabBar 弹跳
3. 数字计数（easeOutCubic）
4. 打字机
5. 环形进度
6. 下拉刷新弹性回弹
7. 头像脉冲
8. 站点脉冲涟漪
9. 漂流路径流动虚线
10. 滚动渐入列表
11. Hero 视差滚动
12. 导航栏滚动渐显
13. ActionSheet 弹层 / 骨架屏

## 八、签名动效

- 首页入场序列（卡片错位渐入 + Hero 视差）
- 详情页视差滚动 + 漂流足迹时间轴
- 列表页下拉弹性回弹
- 个人页环形进度

## 九、健壮性

所有 JSX 内联在 `<script type="text/babel">`、CSS 内联在 `<style>`；rAF/定时器随 visibilitychange 暂停、卸载取消；高频鼠标事件直操 DOM；prefers-reduced-motion 降级；零未定义引用。

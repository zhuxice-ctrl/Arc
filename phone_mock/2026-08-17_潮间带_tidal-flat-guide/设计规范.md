# 设计规范 · 潮间带 Tidal Flat Guide（赶海潮汐图鉴小程序）

> 日期：2026-08-17 · 方向：V2 手机 UI · 形态：微信小程序 · 主题：潮间带生物图鉴 / 赶海潮汐 / 潮池生态

## 色彩系统

以砂陶土为暖主色，海沫绿呼应潮间带生态，砂米色体系铺底，营造退潮后沙滩与潮池的温润质感。

| 角色 | 色值 | 用途 |
|------|------|------|
| 砂陶土（主色） | `#D97757` / `#a8553a` / `#b8744a` | TabBar 选中、主按钮、品牌强调 |
| 海沫绿（辅助） | `#5A7A6E` / `#4a655a` / `#3d554d` | 图鉴分类、生态标签、次级强调 |
| 砂米色体系（表面） | `#f8f3ea` / `#f5ede0` / `#d4c5a8` / `#c4b59c` | 卡片底、页面底、分隔色 |
| 深褐底 | `#2a1f15` / `#1a1814` / `#0a0907` | 深色区块、文字主色 |
| 暖棕中性 | `#8b6242` / `#9a7558` / `#6b4226` | 次级文字、图标 |
| 金沙 | `#c48f50` / `#b8a58d` | 装饰线、徽章 |

## 字体

- 正文：`"PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", sans-serif`
- 数据/潮汐数值：`"SF Mono", "Menlo", monospace`

## 小程序端侧布局

- 自定义导航栏：右上角胶囊按钮（··· / ⊙），首页透明渐变、详情页吸顶变色
- 底部 TabBar：4 项（首页/图鉴/潮汐/我的），选中态弹跳动效 + 砂陶土高亮
- 页面栈 push/pop 切换：右滑返回手势感
- ActionSheet 半屏弹层：长按图鉴卡片触发分享/收藏动作面板
- 下拉刷新弹性回弹：首页下拉刷新潮汐数据
- 悬浮操作球 FAB：图鉴页右下角发布新发现
- 表单页底部安全区主按钮：发布页吸底提交

## 页面结构（8 页）

1. 首页 — Hero 卡片流 + 宫格快捷入口，入场序列动画
2. 图鉴 — 瀑布流 + 吸顶分类筛选 Tab
3. 潮汐 — 大图表 + 周选器，潮位曲线动效
4. 详情 — 视差滚动 + 底部吸底操作栏（收藏/分享）
5. 我的 — 头像 + 环形进度 + 宫格统计
6. 发布 — 表单页吸底主按钮
7. 设计规范页
8. 接口文档页

至少 5 个页面有独特非重复布局；签名动效：首页入场序列、详情页视差滚动。

## 动效系统（12+ 项）

自定义光标、海浪滚动、数字计数入场、卡片 3D 倾斜、光泽扫过、脉冲环、头像脉冲光环、FAB 浮动、Tab 弹跳、骨架屏、涟漪、环形进度动画。

## 技术栈

React + Babel standalone（JSX 内联于 index.html `<script type="text/babel">`），CSS 内联。visibilitychange 暂停动画，prefers-reduced-motion 降级。

# 设计规范 · 回声现场 Echo Live

> 方向：V2 手机 UI｜日期：2026-08-17｜形态：原生 App

## 色彩系统

主配色：勃艮第酒红 + 燕麦米 + 炭黑（纯色，禁止蓝紫渐变）。

| 角色 | 色值 | 用途 |
|---|---|---|
| 酒红（主色） | `#7B1E3B` | 主按钮 / 强调 / 选中态 |
| 深酒红 | `#B83A5F` | 次级强调 / 渐变收尾 |
| 炭黑 | `#1C1917` | 深色模式底 / 乐队详情页 |
| 极黑 | `#0E0C0B` | 全屏沉浸底 |
| 暖墨 | `#2A2623` | 卡片深底 |
| 燕麦米 | `#F2EAD9` | 亮色页面底 / 正文 |
| 陈米 | `#E5D9BE` | 卡片表面 |
| 浅金 | `#F2BC86` | 高亮数据 |
| 暖橙 | `#D97B3A` | 次级点缀 |
| 粉霞 | `#FAE1E8` / `#E88BA3` | 社区页头部 / 标签 |

## 字体

- 正文 / 标题：`var(--font-sans)`、`var(--font-serif)`
- 代码 / 接口文档：`"SF Mono", "Fira Code", monospace`

## 原生端侧交互（≥4 种）

底部 TabBar、大标题导航栏 & 返回栈、FAB 悬浮操作按钮、下拉刷新、长按快捷菜单、模态抽屉（选座）、模态弹出入场。

## 动效系统（12+ 组件级特效）

- 声波条（7 条不同周期）、唱片旋转、脉冲圆点、入场 stagger
- 票卡漂浮、环形进度填充、光标涟漪、下拉刷新 spinner
- 芯片激活态、按钮按压缩放、卡片悬停放大、日期条弹性位移
- 页面级签名动效：首页声波 + 入场序列、乐队详情视差 + 唱片旋转、个人页环形进度、票卡漂浮

## 组件规范

- 卡片圆角 `16px`；按钮圆角 `12px`；标签 `999px`
- TabBar 高度 `56px` + 安全区；FAB `56px` 圆形酒红
- 阴影：`0 4px 20px rgba(28,25,23,.12)`

## 健壮性

零未定义引用 / JSX 全部内联在 `<script type="text/babel">` / `visibilitychange` 暂停动画循环 / `prefers-reduced-motion` 降级静态 / rAF 与定时器统一清理 / 高频鼠标事件直接操作 DOM transform。

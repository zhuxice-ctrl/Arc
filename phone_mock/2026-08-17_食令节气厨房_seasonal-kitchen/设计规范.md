# 设计规范 · 食令·节气厨房 (Seasonal Kitchen)

形态：微信小程序 · 方向：V2 手机 UI · 日期：2026-08-17 · 主题：二十四节气食谱与食俗小程序

## 色彩系统

| 角色 | 色值 | 用途 |
|------|------|------|
| 主色 | #B5482E | 陶土红，主操作 / 标题 |
| 底色 | #F5EDE0 | 米白，页面底 |
| 辅色 | #6B8E4E | 竹青绿，时令标签 / 进度 |
| 文字 | #2A2520 | 墨黑，正文 |
| 强调 | #D97E4A | 柿橙，强调 / 高亮 |
| 中性 | #8A8078 / #FAF7F2 / #EEE8DD | 次要文字 / 卡面 / 分割 |
| 浅辅 | #D7E5CC / #8BBF6A / #F5E2B8 | 竹青浅阶 / 亮绿 / 暖米黄 |

无蓝紫渐变。整体为陶土暖调 + 竹青凉辅的中式厨房质感。

## 字体

- 展示标题：Noto Serif SC（中文衬线）+ DM Serif Display（英文斜体）
- 正文：PingFang SC / Inter

## 页面结构（7 页，布局差异化）

1. 首页：Hero 大节气图 + 卡片堆叠流 + 四宫格快捷入口 + 悬浮 FAB
2. 节气图谱：24 节气旋转轮盘 + 四季色点切换 + 径向食俗卡片
3. 食单详情：Hero 视差 + 吸顶 Tab（食材/步骤/贴士）+ 吸底操作栏 + 分享半屏弹层
4. 时令食材：吸顶筛选条 + 瀑布流双列卡片
5. 我的：深色头部 + 三环进度 + 八宫格菜单 + 横滑收藏集
6. 设计规范：色彩色板 + 字体样本 + 间距刻度 + 组件预览
7. 接口文档：暗色代码风 + 可折叠方法卡片 + JSON 高亮

## 小程序端侧交互（6 种）

底部 TabBar（选中态弹跳）、页面 push/pop 切换过渡、半屏分享 ActionSheet、吸顶筛选 Tab、详情页吸底操作栏、可展开手风琴卡片。整体套在带胶囊按钮的自定义导航栏 + 统一手机外壳内。

## 动效系统（12+ 组件级）

1. 自定义光标（白环 + 柿橙内点 + 多层发光 + 悬停放大 + 点击涟漪）
2. 蒸汽上升动画（首页 / 详情页）
3. 24 节气轮盘缓旋 + 中心反向旋转
4. 三环进度环形填充
5. 头像呼吸脉冲光环
6. 卡片悬停发光跟随鼠标
7. 滚动渐入（IntersectionObserver）
8. Tab 切换下划线展开
9. 骨架屏 shimmer
10. 光泽扫过文字 shine-text
11. 数字计数 tab-nums
12. 下拉刷新旋转指示

## 健壮性

RAF/定时器随 visibilitychange 暂停、卸载统一取消；高频 mousemove 直接操作 DOM transform；支持 prefers-reduced-motion；零未定义引用。

## 技术栈

HTML + 内联 CSS + 内联 JSX（Babel standalone），单文件，无外部 JSX src 引用。

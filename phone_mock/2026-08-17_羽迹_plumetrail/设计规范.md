# 设计规范 · 羽迹 PlumeTrail

形态：原生 App

## 主题
观鸟记录与鸟种图鉴原生 App——围绕朱鹮、翠鸟、戴胜、红嘴蓝鹊、勺嘴鹬、白头鹎等真实鸟种组织观测记录、图鉴、分布与科普内容。

## 端侧交互语言（原生 App，6 种）
1. 底部 TabBar（原生质感，选中态微动效）
2. 大标题导航栏滚动折叠
3. 下拉刷新弹性回弹
4. 底部抽屉 Sheet（半屏弹层）
5. 悬浮操作按钮 FAB
6. 返回栈页面推入转场

## 页面结构（8 页，≥5 种独特布局）
1. **首页** — Hero 大图视差 + 三栏统计卡 + 焦点鸟种大卡 + 最新观测时间线
2. **分布地图** — 鸟种筛选 chip + 风格化地图 + 脉动分布点 + 详情卡
3. **图鉴** — 搜索栏 + 分类 tab + 瀑布流双列网格
4. **记录** — 拍照/录音/手动三模式切换 + 对焦框 + 声纹动画
5. **我的** — 暗色渐变头部 + 环形图鉴进度 + 三 tab（成就/历史/收藏）
6. **鸟种详情** — 全屏 Hero 视差 + 折叠导航栏 + 声纹播放 + 分布地列表
7. **设计规范页** — 色彩系统 + 字体 + 组件 + 间距 + 端侧交互列表
8. **接口文档页** — Base URL + 6 个可折叠 API 端点 + 错误码表

布局多样性：Hero 视差、地图、瀑布流、模式切换、环形进度头像区、全屏详情、规范网格、API 折叠列表——互不重复。

3. Hero 视差滚动
4. 下拉弹簧刷新
5. 环形图鉴进度描边
6. 声纹频谱柱
7. Tab 选中圆点弹跳
8. 收藏心形弹跳

10. 羽毛粒子飘散

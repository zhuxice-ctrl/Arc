# 设计规范 · 晒秋（家庭风物晾晒助手）

**类别**：Phone Mock　**日期**：2026-08-19　**形态**：原生 App

## 一、设计母题
阳台晾晒架上的时间——风物（腊肉/酱鸭/萝卜干/鳗鲞/柿饼）随天数改变色泽与油润度，随天气建议翻晒。产品机制=「挂晒 → 看天翻晒 → 观察变化 → 收成分装」的时间流。

## 二、空间模型
- 原生 App：状态栏 + 底部 TabBar（晾晒/天时/手账/我的）+ 中间 + 号操作按钮
- 堆栈页面 push/pop
- 首屏=今日晾晒架（木杆 + 竹夹 + 风物串），非问候+搜索+Banner

## 三、色彩体系（禁蓝紫渐变，秋阳暖调）
| 角色 | 色值 | 用途 |
|---|---|---|
| 谷壳米白 | #F6EFE3 | 背景 |
| 柿橙 | #D96C2C | 主操作/激活态 |
| 酱色深棕 | #5A3A28 | 风物/深色文字 |
| 柏木 | #8B6B4A | 木杆/次级 |
| 晒场红 | #B03A2E | 强调/收成 |
| 天青灰 | #7C8B8F | 天时/中性 |

## 四、字体
- 衬线（serif）— 标题
- 无衬线（sans）— 正文/UI
- 等宽（mono）— 数字（天数/重量/失水率）

## 五、核心流程（完整可走通）
1. 新建晾晒：选品类 → 重量 → 盐度 → 挂晒日（4 步，自动推进）
2. 每日翻晒打卡：详情页按住风物上滑翻面（3D 翻转 + 色泽推进 + 谷粒飘落）
3. 风干进度：失水率 S 型曲线（Canvas，已完成段实色 + 预测段虚线）
4. 收成分装入库

## 六、签名动效：时光拨盘
腊肉详情页拖动天数滑块，肉色从鲜红渐变到琥珀透亮、表面析出盐霜——时间可视化。

## 七、动效系统（功能型）
风物随风轻摆（重量不同摆速不同）、翻晒翻转弹性落位、打卡谷粒/桂花瓣飘落、失水曲线描边、Tab 切换内容连续滑动。

## 八、天时页
未来 5 日天气（湿度/风向/日照）+ 晾晒适宜度评级，mock 数据内部自洽。

## 九、接口文档
REST /api/v1/* 风格契约（晾晒记录 CRUD、翻晒打卡、收成入库、天气查询）。

## 十、健壮性红线
- 零 Console Error（390/360 双尺寸通过）
- RAF 随 visibilitychange 暂停、cancelAnimationFrame 卸载
- localStorage 持久化晾晒记录与手账
- prefers-reduced-motion 降级
- 无横向溢出（390/360 均无）

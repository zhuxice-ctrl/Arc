# 菌物图鉴 MycoDex — 设计规范

## 主题
自然探索 · 菌物图鉴：野生菌观察采集微信小程序。用户浏览菌种、记录采集点、学习辨识与安全知识。

## 色彩系统（暖色纸质基调，每页有色彩主角偏移）
| 角色 | 色值 |
|------|------|
| 背景 · 暖米白 | `#F5EFE3` |
| 表面米 | `#DDD2BB` / `#C8B8A0` / `#B8A590` |
| 主色 · 松露褐 | `#4A382A` |
| 褐辅 | `#3A2A1E` / `#241C14` / `#1A140E`（深墨褐） |
| 主色 · 苔绿 | `#6B7F59` |
| 绿辅 | `#5A6F4A` / `#5A4A3A` / `#7A8B6B` / `#8FA07A` |
| 强调 · 孢子橙 | `#DD8B3E` |
| 橙辅 | `#E59E5C` / `#8B7355` |
| 警示红（毒性） | `#C0504D` |

禁用蓝紫渐变。首页暖林绿、详情纸本暖、日记深褐、个人苔绿、接口文档深墨——各页色彩主角偏移但统一于暖纸体系。

## 字体
- 标题：`'Noto Serif SC', serif`
- 正文：`'Noto Sans SC', -apple-system, system-ui, sans-serif`
- 装饰：`'Cormorant Garamond', serif`

## 圆角
`8px`（卡片）、`16px`（面板）、`20px 20px 0 0`（吸底面板顶部）、`2px`（徽章）、`50%`（头像/圆点）。

## 页面结构（8 页，布局全部差异化）
1. 首页：Hero 大图视差 + 当季菌讯卡片流 + 横向轮播焦点菌种 + 分类宫格 + 最新发现列表
2. 发现：吸顶分类筛选 Tab + 双列瀑布流菌种网格 + 半屏筛选弹层
3. 菌种详情：Hero 大图滚动视差 + 透明→不透明导航栏 + 形态特征分栏 + 分布图脉动标记 + 吸底操作栏
4. 采集日记：深色头图 + 统计数据 + 时间轴卡片 + 左滑删除/编辑
5. 发布观察：表单页 + 半屏弹层选菌种 + 底部安全区主按钮 + 提交加载态
6. 我的：环形图鉴进度 + 头像 + 成就横幅 + 功能宫格 + 设置列表
7. 设计规范页：色板 + 字体层级 + 组件规范 + 间距圆角体系
8. 接口文档页：深色主题 + 接口 Tab 切换 + 参数列表 + JSON 响应示例 + 状态码表

## 小程序端侧交互（6 种）
底部 TabBar（4 个，选中圆点弹跳）、页面栈 push/pop 切换、下拉刷新弹性回弹、左滑列表操作、半屏弹层 ActionSheet、吸顶 Tab 筛选、吸底操作栏。

## 签名动效（≥2）
首页入场序列动画（staggered fade-up）、详情页 Hero 视差滚动、个人页环形图鉴进度描边、背景孢子飘散粒子。

## 组件级特效（≥12）
Tab 选中圆点弹跳、收藏心形变色缩放、轮播卡片位移、分布点脉动、邮票徽章旋转倾斜、按钮渐变阴影、骨架屏 shimmer、操作面板上升过渡、图片 hover 抬起、筛选 chip 选中发光、环形进度描边动画、胶囊按钮毛玻璃。

## 自定义光标
白粗环 + 孢子橙内点 + 多层发光，开页即居中，悬停放大变色，点击涟漪。

## 健壮性
- 所有 JSX/CSS 全内联单文件，零外部 src 引用
- RAF / setInterval 随 `visibilitychange` 暂停
- 支持 `prefers-reduced-motion` 降级

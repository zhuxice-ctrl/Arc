# 手冲咖啡冲煮日志 · 设计规范

## 主题
工具型手冲咖啡冲煮记录 App，选豆→记录参数→注水节奏→风味评分→方案库复现。

## 形态
原生 App（iPhone 样机，390px 宽，状态栏 + 底部手势条）

## 设计母题
手冲咖啡工坊——设计语言来自咖啡冲煮器具与暖棕烘焙色。产品逻辑为工具型单任务流，区别于通用 App 首页模板。

## 色彩系统
| 用途 | 色值 | 说明 |
|------|------|------|
| 深烘焙底 | #2B1D14 / #3D2B1F | 深棕 |
| 主棕 | #5C3D2E | 咖啡棕 |
| 中棕 | #7A4E3A / #8B5A2B | 冲煮器具棕 |
| 焦糖琥珀 | #A0633F / #C28756 | 强调色 |
| 砖红 | #B4533C | 评分强调 |
| 奶咖米 | #d9b089 | 浅色背景/奶白 |
| 豆绿 | #6B8E5A | 成功/注水状态 |

色彩逻辑：深烘焙棕（基底）+ 焦糖琥珀（强调）+ 奶咖米（浅层）+ 豆绿（状态），承担层级与咖啡语义。

## 字体系统
- UI 字体：var(--font-ui)（苹方/系统 sans-serif）
- 数字字体：var(--font-mono)（等宽，用于粉量/水温/克重/时间）
- 字级：参数数字等宽对齐，标题 sans

## 空间结构
原生 App 页面栈（Push/Pop + 半屏弹层）+ 底部 4 TabBar（冲煮/方案库/豆子/设置）：
1. 今日冲煮（首页）：当前进行中会话 + 开始新冲煮大按钮（拇指可达）+ 历史时间线
2. 选豆页：真实咖啡豆清单（耶加雪菲/西达摩/哥伦比亚/曼特宁）
3. 冲煮记录页：粉量/水温滑块 + 粉水比 + 研磨刻度 + 注水节奏时间轴
4. 风味评分页：5 维雷达 + 综合评分 + 风味标签
5. 方案库页：方案卡列表 + 按此方案冲煮复现
6. 设计规范页 / 7. 接口文档页

## 动效系统（功能型反馈）
1. 滑块调参数：阻尼感
2. 注水时间轴：分段水流动画（SVG 粒子沿路径，stroke-width 随流量变化）
3. 页面 Push/Pop 转场
4. 半屏弹层弹簧弹出
5. 评分卡弹出
6. 方案卡涟漪点击
7. 时间线记录卡渐入
8. 光标状态切换（咖啡杯/水滴，悬停放大/按压收缩/水温变色）

## 核心交互记忆点
冲煮记录页注水节奏时间轴上，拖动分段节点实时改变水流粗细/流速——粒子沿 SVG 路径流动，stroke-width 随流量变化。

## 自定义光标
咖啡杯/水滴形态，开页居中，高对比层级最高。支持 prefers-reduced-motion 降级。

## 数据持久化
localStorage 持久化冲煮记录与方案库，预置 3 条真实冲煮记录 + 2 个方案示例。接口统一 /api/coffee/v1/*。

## 技术栈
纯 vanilla 单文件 HTML，模拟原生 App 390px 容器居中。无外部依赖。RAF 随可见性暂停。支持 prefers-reduced-motion。

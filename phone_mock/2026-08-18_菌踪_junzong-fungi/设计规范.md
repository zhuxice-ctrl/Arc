# 菌踪 设计规范

## 色彩系统

| 角色 | 色值 | 用途 |
|------|------|------|
| 主色 | #C4621E | 菌盖赭橙，TabBar 选中、按钮主色、强调 |
| 主色亮 | #E8B088 | 亮赭橙，hover、渐变亮端 |
| 辅助色 | #4A6B3A | 林苔绿，次级按钮、标签、图标 |
| 辅助色亮 | #6B8C55 | 亮苔绿，hover、渐变 |
| 深色辅助 | #5C3D2E | 腐木棕，深色块、标题底 |
| 深色辅助2 | #2D3D2D | 深墨绿，页脚、深色区域 |
| 底色 | #F2EDE0 | 孢子白，页面背景 |
| 底色暖 | #E8E2D0 | 暖米色，卡片背景 |
| 文字 | #1E2A1E | 幽暗墨绿，正文文字 |
| 点缀红 | #B8412D | 警示红，毒性标识 |

## 字体

- 正文（sans）：`var(--font-sans)` — 系统无衬线
- 标题（serif）：`var(--font-serif)` — 衬线体
- 代码：`'SFMono-Regular', Consolas, monospace`

## 圆角

- 卡片：10px / 14px
- 按钮：20px（胶囊）
- 标签：2px
- 图标容器：50%

## 页面结构（7 页）

1. **首页** — Hero 大图 + 孢子飘散粒子 + 瀑布流当季菌物卡片 + 四宫格快捷入口 + 悬浮拍照按钮
2. **图鉴分类** — 吸顶筛选标签（6 类横向滚动）+ 生境分类卡片网格 + 瀑布流列表
3. **菌物详情** — Hero 视差滚动 + 吸顶变色导航 + 圆角悬浮主体 + 底部吸底操作栏（收藏/记录）
4. **采集记录** — 深绿色统计 Hero + 左滑操作列表（编辑/删除）+ 粘性筛选行
5. **个人中心** — 双色径向渐变 Hero + 玻璃态统计条 + 宫格菜单 + 列表菜单
6. **设计规范** — 色彩系统 + 字体排印 + 间距/圆角/阴影尺度
7. **接口文档** — 基础信息 + 5 个端点详情 + 代码示例块

## 小程序端侧交互（7 种）

底部 TabBar（选中态弹跳）、下拉刷新弹性回弹、ActionSheet 半屏动作面板、左滑列表操作、吸顶 Tab 筛选、骨架屏加载、底部安全区主按钮

## 动效系统

| 动效 | 物理模型/主题语义 |
|------|------|
| 自定义光标 | 白环 + 橙心 + 多层发光，悬停放大，点击涟漪 |
| 孢子飘散粒子 | 签名动效①——RAF 驱动粒子上升+漂移，模拟孢子随风扩散 |
| 详情页视差滚动 | 签名动效②——scroll 驱动 Hero 缩放+导航栏渐变变色 |
| 菌物卡片入场 | 错位生长动画，模拟菌柄破土生长 |
| Tab 切换弹跳 | spring 物理回弹 |
| 心型收藏爆裂 | 粒子爆裂 + 缩放回弹 |
| FAB 脉冲光晕 | 呼吸光圈动画 |
| 瀑布流错位入场 | IntersectionObserver 触发 opacity+translateY |
| 按钮点击缩放 | scale 弹性反馈 |
| 图片 Hover 放大 | transform scale 过渡 |
| ActionSheet 上滑 | translateY + 背景遮罩渐显 |
| 页面栈 Push/Pop | 右滑返回手势感，translateX 转场 |

## 技术栈

React + Babel 内联 JSX（script type="text/babel"），CSS 内联。自定义光标用 DOM transform 直操作，RAF 随 visibilitychange 暂停，支持 prefers-reduced-motion。

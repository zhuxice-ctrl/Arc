矿物简介
紫水晶是石英的紫色变种，其色泽源于晶体中微量铁离子经天然辐照作用形成的色心。作为二月生辰石，紫水晶自古便被视为抵御迷醉、保持清醒的象征。古希腊人以"不醉酒"（amethystos）为之命名，相信佩戴它可千杯不醉。

API DOCUMENTATION
接口文档
RESTful API · v1.0
Base URL: https://api.mineralcodex.com/v1
矿物标本
GET /minerals
分页获取矿物标本列表，支持按分类、颜色、硬度、产地等多维度筛选。
请求参数
参数类型必填说明
pageint否页码，默认1
pageSizeint否每页数量，默认20
categorystring否分类：quartz/carbonate/sulfide
colorstring否颜色筛选
hardness_minfloat否最低莫氏硬度
响应示例
{ "code": 0, "message": "success", "data": { "total": 156, "page": 1, "pageSize": 20, "list": [ { "id": "m_001", "name": "紫水晶", "latinName": "Amethyst", "hardness": 7, "image": "...", "origin": "巴西米纳斯吉拉斯" } ] } }
GET /minerals/{id}
获取单个矿物标本的详细信息，包含晶体参数、产地、科普描述等完整字段。
路径参数
参数类型必填说明
idstring是矿物标本ID
响应示例
{ "code": 0, "data": { "id": "m_001", "name": "紫水晶", "latinName": "Amethyst", "crystalSystem": "三方晶系", "hardness": 7.0, "cleavage": "无解理", "fracture": "贝壳状", "specificGravity": 2.65, "luster": "玻璃光泽", "origin": "巴西米纳斯吉拉斯州", "description": "..." } }
POST /collection
将矿物标本添加到用户的个人标本库中。
请求体
{ "mineralId": "m_001", "specimenName": "乌拉圭紫水晶簇", "acquiredDate": "2024-03-15", "weight": 235.5, "notes": "色泽深紫，晶体完整" }
响应示例
{ "code": 0, "data": { "collectionId": "c_042", "addedAt": "2024-08-15T10:30:00Z" } }
用户与收藏
GET /user/collection
获取当前用户的标本库列表与分类统计。
响应示例
{ "code": 0, "data": { "total": 12, "stats": { "quartz": 5, "carbonate": 3, "sulfide": 2, "silicate": 2 }, "items": [...] } }
DELETE /collection/{id}
从标本库中移除指定矿物标本。
响应示例
{ "code": 0, "message": "已从标本库移除" }
PUT /collection/{id}
编辑标本库中指定标本的信息（名称、备注、重量等）。
请求体
{ "specimenName": "乌拉圭极品紫晶簇", "notes": "2024年新品，色泽极为浓郁" }
响应示例
{ "code": 0, "data": { "updated": true } }

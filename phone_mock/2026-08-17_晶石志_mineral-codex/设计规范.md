# 晶石志 Mineral Codex · 设计规范

## 色彩系统

| 令牌 | 色值 | 用途 |
|------|------|------|
| `--color-surface` | `#d4ccc0` | 表面色 / 卡片底 |
| `--color-primary` | `#b8732e` | 主色 / 铜琥珀 / TabBar 选中 |
| `--color-accent` | `#1e6b4f` | 辅助色 / 深翡翠 / 标本库头部 |
| `--color-ink` | `#1a1a1a` | 文字 / 标题 |
| `--color-base` | `#faf5ee` | 底色 / 奶白背景 |
| `--color-warn` | `#c44b3a` | 警示色 / 删除操作 |

局部渐变：`linear-gradient(135deg, #e8e2d6 0%, #d4ccc0 100%)`（表面渐变）、`linear-gradient(160deg, #1e6b4f 0%, #154d38 100%)`（标本库头部）。

## 字体

| 令牌 | 字体栈 | 用途 |
|------|--------|------|
| `--font-serif` | `"Source Han Serif SC", "Songti SC", "Noto Serif SC", Georgia, serif` | 标题 / 矿物名 |
| `--font-sans` | `"PingFang SC", "HarmonyOS Sans SC", -apple-system, BlinkMacSystemFont, "Helvetica Neue", Arial, sans-serif` | 正文 |

## 组件规范

- **自定义导航栏**：含胶囊按钮（右上角"···/⊙"），可随页面变化（透明/渐变/吸顶变色）
- **底部 TabBar**：4 个标签（首页/图鉴/发现/我的），选中态 `--color-primary` + 弹性微动效
- **卡片**：圆角 12px，白色底 `#fff`，阴影分层
- **吸顶 Tab**：图鉴页分类筛选，滚动吸顶，选中态下划线 `--color-primary`
- **吸底操作栏**：详情页底部安全区主按钮（收藏/分享/加入标本库）
- **ActionSheet**：半屏弹层，长按触发（编辑/分享/删除）
- **下拉刷新**：弹性回弹动效
- **左滑操作**：列表项左滑露出收藏/分享按钮
- **FAB**：发现页悬浮发帖按钮，`--color-primary` 底色
- **环形进度图**：标本库页分类统计，SVG 环形 + 数字计数动画

## 动效系统

| 编号 | 动效 | 触发方式 | 语义 |
|------|------|----------|------|
| 1 | 首页卡片错峰入场 | 页面切换 | 阶梯式延迟淡入上移 |
| 2 | 详情页视差滚动 | scroll | Hero 大图随滚动速率差偏移 |
| 3 | 标本库环形进度 | 进入视口 | SVG 环形填充 + 数字计数 |
| 4 | TabBar 选中弹性 | tap | 缩放回弹微动效 |
| 5 | 下拉刷新弹性 | 手势 | 弹性回弹 |
| 6 | 左滑列表操作 | 手势 | 露出操作按钮 |
| 7 | 页面切换过渡 | 页面栈 push/pop | 右滑返回手势感 |
| 8 | ActionSheet 弹出 | 长按 | 半屏滑入 |
| 9 | 模态遮罩淡入 | tap | 背景渐显 |
| 10 | 卡片悬停发光 | hover | 边框高亮+阴影 |
| 11 | 涟漪点击 | tap | 点击处扩散圆环 |
| 12 | 导航栏变色 | scroll | 透明→渐变→吸顶 |

## 页面结构（8 页）

1. **首页** — 瀑布流交错卡片 + 横向分类标签 + 下拉弹性刷新
2. **图鉴页** — 吸顶 Tab（颜色/硬度/产地/晶系）+ 左滑收藏/分享
3. **矿物详情页** — Hero 大图视差 + 晶体参数四宫格 + 吸底操作栏
4. **标本库页** — 深翡翠渐变头部 + 环形分类统计 + 长按 ActionSheet
5. **发现页** — 卡片流 + FAB 悬浮发帖 + 推荐/关注/最新筛选
6. **我的页** — 低饱和风格 + 头像 + 统计卡 + 宫格菜单
7. **设计规范页** — 色彩系统 + 字体栈 + 组件规范 + 动效说明
8. **接口文档页** — 3 组 REST API + 可折叠详情 + 请求/响应 JSON 示例

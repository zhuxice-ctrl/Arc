# 草木染谱 · 设计规范

形态：微信小程序

## 一、设计母题
植物染（草木染）配方册与染色档案。界面像一本随身翻阅的染材标本册与色卡纸样簿：染材架为首页，配方为半屏详情，染色为步骤计时任务流，色卡册为可复现的档案。视觉来自传统草木染的染缸、棉麻素布、染液晕染与纸样色卡。

## 二、色彩系统（天然植物染多色，非蓝紫陈词）
| 角色 | 色值 | 用途 |
|---|---|---|
| 素布底 | #F4EDE0 | 全站背景（棉麻素布） |
| 卡片/纸样底 | #FBF7EE | 卡片、色卡纸样底 |
| 墨黑文字 | #2A2622 | 主文字 |
| 麻线褐辅 | #8A6E4E / #C4943A | 辅助文字、分隔、描边 |
| 苏木·胭脂红 | #A8324A | 红染材主色 / 强调 |
| 栀子·金黄 | #D9A441 | 黄染材主色 |
| 靛蓝 | #2E4A7C | 蓝染材主色（材质真实，六色之一非主导） |
| 茶褐 | #6B4423 | 茶染材主色 |
| 五倍子·墨灰 | #3D3A38 | 黑灰染材主色 |
| 槐米·嫩绿 | #7C8A3A | 绿染材主色 |
| 茜草 | #C25B3A | 橙红染材 |
| 洋葱皮 | #B8862F | 黄褐染材 |

每种染材含 6 级真实色阶 hex 数组（从浅到深），供浸染次数游标实时插值。靛蓝只是六色之一，不构成蓝调主导。

## 三、字体系统
- UI 正文：`-apple-system, BlinkMacSystemFont, ...` 系统无衬线。
- 标题/染材名：较重字重无衬线模拟书册工艺感（思源宋体感，未引外部字体）。
- 数字（配比/温度/时间/浸染次数/hex）：`'SF Mono', Menlo, Consolas, monospace` 等宽。
- 中文文案为主，无 Lorem Ipsum。

## 四、信息架构（4 Tab + 页面栈）
1. **染材**（首页）：胶囊导航栏（标题"草木染谱"）→ 今日推荐染材卡片 + 染材架网格。点染材 → 半屏弹层详情 → "查看配方"跳配方详情。下拉刷新。
2. **配方**：配方列表（按染材分组）→ 配方详情页（页面栈 push）：染材/媒染剂用量/染液浓度/温度/浸染时长/氧化/水洗晾干 + 浸染次数游标。吸底"开始染色"。
3. **色卡册**：染色档案，按染材/色系分组列表（色块+染材+浸染次数+日期+心得）。左滑置顶/删除。点开复现。空状态引导。localStorage 持久化（`ranrancao_colorbook`）。
4. **我的**：染材收藏、染色统计、关于、设置（prefers-reduced-motion 开关，`ranrancao_settings`）。

## 五、签名交互 · 浸染次数游标
配方详情页大色卡下方水平游标，刻度 1–6。拖动游标，色卡颜色按该染材 6 级真实色阶数组从浅到深实时插值（模拟草木染多次浸染叠色逐次加深）。松手 spring 阻尼吸附整数刻度。色卡旁实时显示当前 hex 与浸染次数。高频拖动直接操作 DOM + RAF，零定时器叠加。这是与工艺本体绑定、有信息含义的交互。

## 六、染色任务流
点"开始染色"进入染色执行页，步骤化倒计时：媒染 → 调染液 → 浸染（按游标次数逐次计时）→ 氧化 → 水洗晾干。每步完成勾选，全部完成进入成品入册页（选当前色阶色块 + 写心得 + 收入色卡册）。倒计时用 RAF，页面隐藏暂停（visibilitychange）、卸载取消。

## 七、端侧交互语言（微信小程序，6 种）
1. 胶囊导航栏（自定义导航栏 + 胶囊占位）
2. 底部 TabBar（4 Tab）
3. 半屏弹层（spring 滑出）
4. 下拉刷新（染液滴落 + 弹性回弹）
5. 左滑操作（色卡册置顶/删除）
6. 吸底操作栏（配方页"开始染色"）

## 八、动效系统
- 缓动：`cubic-bezier(0.32, 0.72, 0, 1)`（iOS 弹性过渡）、`cubic-bezier(0.32, 1.2, 0.4, 1)`（过冲 spring，用于游标吸附/弹层）。
- 浸染色块过渡：background-color 0.28s ease。
- 半屏弹层：translateY spring 滑出。
- 下拉刷新：染液滴落 + 弹性回弹。
- 左滑：translateX spring。
- 步骤完成：染液晕开确认（scale 圆形扩散）。
- prefers-reduced-motion：`transition: none !important` 降级。
- 动效功能优先，无每屏大型入场动画。

## 九、工程
- 纯 vanilla 单文件 index.html，CSS/JS 全内联，零外部依赖（无 React/CDN/外部字体/外部图片；颜色与图标用 CSS/SVG/Canvas）。
- localStorage 键：`ranrancao_colorbook`（色卡册）、`ranrancao_settings`（设置）。
- 移动端 375px，无横向溢出。
- 健壮性：零未定义引用；RAF/定时器随可见性暂停且卸载取消；快速拖动不叠加定时器；高频指针事件直接操作 DOM；支持 prefers-reduced-motion。

## 十、真实内容
8 种真实染材：苏木、靛蓝（蓼蓝）、栀子、茶、五倍子、槐米、茜草、洋葱皮。每种含学名/产地/可染色相/常用媒染剂/特性简介 + 至少 1 个真实配方（媒染剂+用量比、温度℃、浸染时长、浸染次数建议、注意事项）+ 6 级真实色阶 hex。

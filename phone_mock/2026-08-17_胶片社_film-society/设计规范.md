# 设计规范 · 胶片社 FilmSociety

> 日期：2026-08-17 · 方向：V2 手机 UI · 形态：微信小程序 · 主题：胶片冲扫预约与同好影集小程序

## 色彩系统

本次配色为暖调胶片色系，柯达黄主强调、暖黑承载深色区、奶白主底、安全灯红点缀、灰绿辅助。禁止蓝紫渐变。

| 角色 | 色值 | 用途 |
|---|---|---|
| 主强调 · 柯达黄 | `#F5A800` | 品牌色、主操作、TabBar 选中态 |
| 亮黄 | `#FFBE3D` / `#FFCE5C` | 渐变高光、徽标 |
| 深黄 | `#D49000` | 按压态 |
| 深色区 · 暖黑 | `#211D19` | 深色头部、图鉴页底 |
| 极深 | `#1a1612` / `#0a0806` | 最深层背景 |
| 主底 · 奶白 | `#F7F1E3` | 页面主底 |

## 微信小程序端侧布局

- **胶囊按钮**：右上角 `··· / ⊙`，自定义导航栏随页面变化（透明/渐变/吸顶变色）。
- **底部 TabBar**：4 项，选中态弹性放大微动效。
- **页面栈 push/pop**：右滑返回手势感转场。
- **ActionSheet 半屏弹层**：取件方式选择等动作面板。
- **底部安全区主按钮**：表单页主操作，光泽扫过动效。
- **吸顶筛选栏**：图鉴页 chips 筛选。
- **下拉刷新弹性回弹**结构。

## 组件规范

- **冲扫进度卡**：5 步进度条 + 脉冲指示点。
- **功能宫格**：首页 2×4 圆角图标网格。
- **轮播画廊**：同好影集自动播放。
- **瀑布流双列**：图鉴页 8 款真实胶卷卡片。
- **EXIF 参数卡**：样片详情页等宽数据排列。
- **环形进度**：个人中心冲扫统计（SVG 渐变环 + 数字计数）。
- **底部吸底操作栏**：样片详情页点赞（心跳动效）。

## 动效系统

至少 13 个组件级特效：

1. 自定义光标（白环黄点，悬停放大，点击涟漪）
2. 轮播画廊自动播放
3. 进度条脉冲指示
4. 按钮光泽扫过
5. 卡片入场渐显
6. 环形进度计数动画
7. 头像光环呼吸
8. 点赞心跳
9. 快门闪白
10. Hero 视差滚动
11. 胶片滑入
12. Tab 弹性缩放
13. 下拉刷新结构

## 页面结构（8 页）

1. **首页** — 柯达黄渐变 Header + 搜索 + 功能宫格 + 轮播画廊 + 冲扫进度卡片流
2. **胶卷图鉴页** — 深色底 + 吸顶筛选 + 瀑布流双列（Portra 400 / Ektar 100 / HP5 Plus / Cinestill 800T 等）
3. **冲扫预约页** — Hero 统计 + 工艺选择（C-41/ECN-2/D-76）+ 数量计数器 + ActionSheet 取件 + 底部安全区主按钮
4. **样片详情页** — Hero 大图视差 + EXIF 卡 + 同款胶卷横滑 + 底部吸底操作栏
5. **个人中心** — 深色渐变头 + 头像光环 + 宫格 + 环形冲扫统计 + 列表入口
6. **冲扫进度详情页** — 状态头 + 时间线 + 暗房实况卡
7. **设计规范页** — 色彩板 / 字体 / 间距 / 组件 / 动效
8. **接口文档页** — 深色代码风 + 分类 Tab + 参数表 + JSON 响应

布局多样性：8 页中至少 6 页采用非重复布局（渐变头卡片流 / 深色瀑布流 / 表单吸底 / 视差详情 / 环形统计个人 / 代码风文档）。

## 健壮性

- 所有 RAF/定时器随 `visibilitychange` 自动暂停，卸载时统一取消。
- 快速切换页面不叠加定时器，重建前先 clear。
- 高频事件直接操作 DOM transform。
- 支持 `prefers-reduced-motion`。
- 所有 JSX 内联于 `<script type="text/babel">`，CSS 内联于 `<style>`。

## 技术栈

React 18 + Babel Standalone，单文件 index.html，统一手机外壳内多页切换。

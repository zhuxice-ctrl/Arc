# 胶片社 FilmSociety

> 日期：2026-08-17 · 方向：V2 手机 UI · 形态：微信小程序 · 主题：胶片冲扫预约与同好影集小程序

## 简介

一个胶片摄影同好的微信小程序：冲扫预约、胶卷图鉴、样片画廊与个人冲扫统计。柯达黄主色配暖黑奶白，还原胶片盒与暗房的视觉气质。8 个页面在统一手机外壳内切换，覆盖小程序典型信息架构。

## 截图

![胶片社预览](./preview.png)

## 动效亮点

- 首页柯达黄渐变 Header + 冲扫进度卡片流（5 步进度条 + 脉冲指示点）
- 胶卷图鉴瀑布流双列 + 吸顶筛选 chips
- 样片详情 Hero 大图视差滚动 + 快门闪白转场
- 个人中心环形冲扫统计（SVG 渐变环 + 数字计数）+ 头像光环呼吸
- 底部 TabBar 选中弹性放大、点赞心跳、按钮光泽扫过
- 自定义光标（白环黄点，开页居中，悬停放大，点击涟漪）

## 微信小程序端侧交互

胶囊按钮自定义导航栏、底部 TabBar（4 项）、页面栈 push/pop 右滑转场、ActionSheet 半屏弹层、底部安全区主按钮、吸顶筛选、下拉刷新弹性回弹。

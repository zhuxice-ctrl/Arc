# 设计规范 · 飞盘约战局 · 飞盘社群小程序

形态：微信小程序

> 方向：手机 UI（V2） · 日期：2026-08-17 · 形态：微信小程序（与上一次「原生 App」交替） · 主题：飞盘社群约战记录

## 色彩系统

运动草坪风：草坪绿为主，落日橙为撞色强调，奶白为浅区卡片，炭灰为文字深区，亮黄为高亮。整体活力运动感，绿橙撞色。

| 角色 | 色值 | 用途 |
|---|---|---|
| 主色 / 草坪绿 | `#2E7D32` / `#3B7A2E` | 导航、TabBar 选中、主按钮、头部 |
| 辅助绿 | `#66BB6A` / `#A5D6A7` | 浅绿卡片、成功态、渐变层次 |
| 强调 / 落日橙 | `#E8762C` / `#F08A3C` / `#FFB74D` | 强调按钮、标签、数据高亮 |
| 高亮黄 | `#FFD23F` | 飞盘、点亮、勋章 |
| 深金 | `#B8860B` | 次级强调、边线 |
| 文字 / 炭灰 | `#2B2B2B` | 正文、深区底 |
| 浅区 / 奶白 | `#FAF6EE` | 卡片底、页面浅底 |
| 中性 | `#D4D4D4` | 分割线、骨架屏 |
| 警示红 | `#E53935` | 删除、失败态 |
| 分类紫（图表辅助） | `#BA68C8` / `#7B1FA2` | 战绩图表分类色（纯色块，非渐变） |

## 字体

- 系统：`-apple-system, 'PingFang SC', 'Microsoft YaHei', sans-serif`
- 数字等宽：`'SF Mono', 'Roboto Mono', monospace`（战绩数据）

## 组件

- 胶囊导航栏：右上角"··· / ⊙"胶囊按钮，自定义导航栏随页面变化（透明 / 渐变 / 吸顶变色）
- 底部 TabBar：2-5 个，选中态微弹跳动效
- 约战卡片：圆角 16px，阴影分层，悬停浮起
- 半屏弹层 / ActionSheet：底部滑入，遮罩点击关闭
- 吸顶 Tab：滚动吸顶，下划线滑动切换
- 吸底操作栏：详情页底部固定，报名 / 分享
- 环形进度：个人页战绩完成度
- 骨架屏：加载态微光 shimmer
- FAB 悬浮按钮：脉冲呼吸

## 端侧交互（7 种）

胶囊按钮导航栏、底部 TabBar（选中微弹跳）、ActionSheet 半屏弹层、下拉刷新弹性回弹、左滑列表删除、吸顶 Tab 下划线滑动、表单底部安全区主按钮。

## 动效系统（≥12 个组件级特效）

1. 自定义光标：白环 + 草坪绿内点 + 多层发光，开页即现于屏幕中央，悬停放大变色，点击涟漪
2. 飞盘旋转（签名元素）
3. 卡片浮入序列（首页入场动画）
4. 下拉刷新弹性回弹
5. 左滑揭示操作
6. Tab 下划线滑动
7. 环形进度填充（个人页签名动效）
8. 数字计数
9. 骨架屏微光
10. FAB 脉冲
11. 视差滚动（详情页 Hero）
12. Tab 选中弹跳

签名动效：首页序列入场动画、个人页环形战绩进度动画。

## 页面结构（8 页，≥5 个独特布局）

1. 首页约战——Hero 推荐局 + 卡片流 + 快捷入口 + FAB
2. 发现场地——吸顶 Tab 筛选 + 网格拼贴（错落 tall/wide 变体）
3. 约战详情——Hero 视差 + 信息列表 + 参与者头像 + 吸底操作栏
4. 发布约战——分组表单 + 水平选择器 + 左滑删除成员 + 安全区主按钮
5. 个人中心——绿色头部 + 数据卡 + 环形进度 + 宫格 + 动态
6. 战绩数据——对角分割 + 柱状趋势 + 成就勋章网格
7. 设计规范——色彩 / 字体 / 组件 / 动效 / 页面结构
8. 接口文档——6 个 API 契约（约战 / 战绩 / 场地 CRUD）

## 健壮性

- 零未定义引用
- RAF / 定时器随 `visibilitychange` 暂停，卸载取消
- 快速操作不叠加定时器（重建前取消旧的）
- 高频鼠标事件直接操作 DOM transform
- 支持 `prefers-reduced-motion`

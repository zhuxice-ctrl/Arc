# 设计规范 · 百子柜·调香

形态：原生 App

---

## 一、设计哲学

整个 App 是一间走进屏幕的老药铺——百子柜是货架，戥秤是工作台，方子册是账本。视觉语言全部从中药铺的真实物件生长出来：核桃木柜、黄铜戥秤、麻纸药包、朱砂封印。不是「中式风格」的形容词堆砌，而是具体材质与功能对象的界面化翻译。

## 三、字体系统

字体服务于内容类型，非装饰：

| 字体族 | 适用场景 | 示例 |
|--------|----------|------|
| Noto Serif SC / 思源宋体 | 药名、方名、页面大标题、设计规范标题——承载「药材名/方名」的传统感 | 百子柜、化湿醒脾方 |
| PingFang SC / 系统无衬线 | 正文、说明、按钮文字——手机阅读舒适度 | 湿浊困脾，头重胸闷 |
| SF Mono / Menlo | 秤重读数、份量 stepper、接口代码——数字等宽精确感 | 12.5 g / 2.50 钱 |

## 五、材质与图形语言

### 材质逻辑（贯穿全 App）
- **核桃木**：百子柜柜体、戥秤底座、头部深底——主导深色材质
- **黄铜**：戥秤杆/砣/盘、抽屉铜环拉手、Tab 激活态——功能金属件
- **麻纸**：调配台、方子册、设置页——书写/记录面
- **朱砂**：封印印章、主按钮、关键数字——仪式高点强调色

### 图形语言
- 抽屉=木质立体格 + 铜环拉手 + 手写体药名标签
- 戥秤=黄铜刻度杆 + 双盘 + 滑动铜砣 + 木质底座
- 方子卡=麻纸底 + 左侧红条（自创方）/棕条（经典方）+ 翻页入场
- 香囊=金棕条纹布袋 + 红色系带 + 朱砂方印
- 图标=线性 SVG，stroke 风格，与药铺工具感一致

## 六、动效系统

动效由材质与功能驱动，不堆砌入场动画。

| 动效名 | 触发场景 | 时长 | 缓动 | 说明 |
|--------|----------|------|------|------|
| 抽屉滑出 | 点击百子柜抽屉 | 0.4s | cubic-bezier(.32,.72,0,1) | 木质滑轨感，从下往上滑出药材卡 |
| 戥秤回衡 | 加药/调份量后 | 弹性阻尼 | 弹簧物理（k=60, c=8） | 秤杆倾斜后阻尼摆动回水平，模拟真实铜杆秤 |
| 药袋束口 | 封囊第 1 步 | 0.8s | cubic-bezier(.32,.72,0,1) | 两侧系带向中间收紧 |
| 朱砂封印 | 封囊第 2 步 | 0.6s 下落 + 1s 墨晕 | 下落：cubic-bezier(.55,.06,.68,.19) | 印章自上方落下压印，印泥墨晕向四周扩散 |
| 方子翻页 | 方子册入场 | 0.5s | ease-out | 卡片 rotateX 渐入，模拟翻页 |
| 页面栈 push | 打开详情/规范/接口 | 0.35s | cubic-bezier(.32,.72,0,1) | 原生右向左滑入 |
| Tab 切换 | 底部 TabBar | 0.2s | ease | 直接切换，无过场（原生习惯） |
| Token 加入 | 药材加入调配台 | 0.3s | ease-out | scale 弹入 |

### 无障碍
- 支持 `prefers-reduced-motion`：所有动画降级为瞬时/淡入
- 删去全部动画后，信息层级与流程仍成立
- 灰度下图层仍可分辨（依靠空间/尺寸/深浅而非颜色）

## 七、组件规范

### 抽屉（Drawer）
- 尺寸：宽高比 1.4:1，4 列网格
- 状态：关闭（立体木纹 + 铜环）/ 打开（暗内凹 + 药材卡滑出）
- 交互：点击切换，同屏仅开一个（模拟真实药铺）

### 戥秤（Scale）
- 尺寸：340×220px 容器
- 左盘放药、右盘为空（视觉简化为铜砣在杆上滑动）
- 读数：上方木框显示「X.XX 钱」（5g = 1 钱）
- 物理：阻尼弹簧方程，初始倾斜角 = 重量 × 0.8°，12° 封顶

### 方子卡（Recipe Card）
- 左侧色条：朱砂红=自创方，木棕=经典方
- 右上角 Badge 标识类型
- 结构：方名 + 描述 + 药材 token 列表 + 总重量 + 操作按钮
- 操作：查看 / 复配

### 按钮层级
- 主按钮：朱砂渐变底 + 白字 + 阴影（封囊、存方、加入调配）
- 次按钮：麻纸深底 + 深木字（清空、查看）
- 文字按钮：朱砂色文字（返回、跳转）

## 八、端侧交互（原生 App）

1. **底部 TabBar**：4 Tab（百子柜 / 调配台 / 方子册 / 我的），百子柜页 TabBar 为木质深色底 + 黄铜激活
2. **页面栈 push/pop**：药材详情、设计规范、接口文档均以栈页面从右侧滑入
3. **抽屉交互**：点击抽屉 → 滑出药材卡 → 点击加入调配 → chip 弹入
4. **戥秤称量**：加药/调份量 → 秤杆阻尼摆动回平衡 → 读数跳动 → 盘中药材颗粒堆叠
5. **份量 stepper**：−/+ 按钮调整克数，1–30g 范围
6. **封囊覆盖层**：半屏覆盖 + 三步仪式动效 + 输入方名 + 存方
7. **方子册翻页**：卡片依次 rotateX 入场
8. **下拉刷新**：百子柜、方子册支持下拉（移动端 touch 事件）

## 九、健壮性

- 零未定义引用：所有 DOM 操作前判断存在性
- RAF 动画随 `visibilitychange` 暂停，页面卸载 cancel
- 快速操作不叠加定时器（先清后建）
- `localStorage` 读写 try/catch
- 空状态（无方子）有引导
- 390 与 414 宽度下不溢出
- 支持 `prefers-reduced-motion`
- 纯 vanilla 单文件，无外部 JS/CDN 依赖
- 图片全部 CSS + 内联 SVG 绘制

# 一席书场 · 设计规范

形态：微信小程序

## 一、色彩系统

| 变量名 | 色值 | 语义 | 用途 |
|--------|------|------|------|
| --xuanqing | #232B33 | 玄青 | 主文字色、导航栏底色、深色卡片 |
| --yuebai | #F3EFE5 | 月白 | 页面背景、浅色卡片底 |
| --qingbi | #5E8B7E | 青碧 | 辅助强调色、书场标签、次要按钮 |
| --jianghong | #A23B2E | 绛红 | 主行动色、醒木按钮、选中态、价格 |
| --sajin | #C9A25B | 洒金 | 装饰色、签条、分割线、序号 |
| --yuanmu | #8A6B4F | 原木 | 辅助文字、书场位置、次要信息 |

### 配色逻辑
以苏州评弹书场的物理空间为母题：玄青=书场木构梁柱与深色围壁，月白=宣纸窗棂透光，绛红=评弹演员长衫与醒木，洒金=折扇金边与匾额题字，青碧=茶碗青瓷，原木=八仙桌椅。整体为暖调暗色系，无蓝紫渐变。

## 二、字体系统

| 变量名 | 字体栈 | 语义 |
|--------|--------|------|
| --font-song | "Songti SC", "Noto Serif CJK SC", "SimSun", "STSong", serif | 宋体——书名、回目、标题、正文内容 |
| --font-hei | "PingFang SC", "Microsoft YaHei", "Helvetica Neue", sans-serif | 黑体——导航栏、TabBar、按钮、状态栏 |
| --font-mono | "SF Mono", "Menlo", "Consolas", "Courier New", monospace | 等宽——接口文档代码块 |

宋体用于一切内容性文字（评弹书目、回目名、书场名），黑体用于功能性 UI 文字，等宽字体仅用于 API 文档页。两种主字体形成「内容是文化的、操作是现代的」层次。

## 三、动效系统

### 签名动效：醒木开书
1. **震屏**：点击「醒木·开书」按钮后，整个 `.phone` 容器执行 `transform: translate` 抖动（3 次，每次 60ms），模拟醒木拍桌的物理冲击
2. **折扇展开**：`#fanOverlay` 全屏遮罩从顶部展开，`#fanText` 显示当前回目名，持续 1.8s 后自动收起
3. **签条翻转**：折子卡片上的进度签条执行 3D 翻转动画，进度 +1
4. **按钮变灰**：开书完成后按钮文本变为「已听此回」、禁用点击

### 页面过渡动效
- `@keyframes pagePushIn`：新页面从右侧滑入（translateX 100%→0，280ms ease-out）
- `@keyframes pagePopOut`：返回时页面向右滑出（translateX 0→100%，250ms ease-in）

### 微交互动效
- `@keyframes spin`：加载旋转动画（600ms linear infinite）
- 座位选中：scale(0.92) 缩放反馈
- 卡片点击：active 态 scale(0.98) + opacity 0.85
- TabBar 切换：active 态色彩渐变 + 底部圆点指示器
- 折子卡片左滑：translateX 滑动露出删除按钮

### 动效约束
- 所有动效支持 `prefers-reduced-motion: reduce`（降级为瞬时切换）
- RAF 和定时器随 `document.visibilitychange` 暂停，`beforeunload` 清理
- 快速操作不叠加定时器（每日限制通过日期比对实现）

## 五、微信小程序端侧交互清单

| 交互 | 实现位置 | 说明 |
|------|----------|------|
| 胶囊按钮+自定义导航栏 | `.nav-bar` + `.capsule-btn` | 右上角胶囊按钮模拟微信原生胶囊，自定义导航栏含标题和返回 |
| 底部 TabBar | `.tab-bar` + `.tab-item` | 4 Tab（今日/在演/折子/我的），active 高亮+圆点指示 |
| 半屏弹层 | `#bottomSheet` + `.bottom-sheet.show` | 选座面板从底部滑入，可关闭，不遮满屏 |
| 页面栈 push/pop | `pushPage()` + `.nav-back` | 书目详情/规范/API 页面从右侧推入，返回键滑出 |
| 下拉刷新 | `.pull-refresh` 区域 | 今日页顶部下拉触发刷新提示 |
| 左滑操作 | `.swipeable-wrap` + `.swipe-action` | 折子页卡片左滑露出删除按钮 |
| 吸底操作栏 | `.seat-footer` | 选座面板底部固定操作栏（已选座位+确认按钮） |

## 六、数据持久化

- 存储键：`yixi_shuchang_v2`（localStorage）
- 存储内容：已收入折子的书目 ID 列表、每日开书记录（lastKaishuDate）、统计数据
- 每日限制：通过 `state.lastKaishuDate === todayStr()` 判断，每日每部书只能开书一次

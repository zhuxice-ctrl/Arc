# 设计规范 · 星野（星空观测微信小程序）

> 形态：微信小程序 · 方向：V2 手机 UI · 日期：2026-08-18 · 主题：星空观测小程序

## 色彩系统

主色调为「深空靛蓝 + 星光金 + 青空蓝 + 星紫」深空冷调，无蓝紫渐变。

| 角色 | 色值 | 用途 |
|------|------|------|
| 深空靛蓝（底） | `#0A0E1A` / `#0F172A` / `#0D1B30` | 页面背景、深色面板 |
| 星光金（主） | `#D4AF6A` / `#FFD700` / `#B8945A` | 主按钮、强调标题、星光 |
| 青空蓝（辅） | `#6AD4F0` / `#4AB0CC` | 次级强调、链接、星座连线 |
| 星紫（强调） | `#A080D0` | 点缀、特殊状态 |
| 中性（文字） | `#F2F2F7` / `#E8E0D0` / `#B8C4D0` / `#5A7A9A` | 正文、次要文字 |

## 字体

- 正文字体：`'Noto Sans SC', -apple-system, BlinkMacSystemFont, sans-serif`

## 圆角

卡片 `12-16px`、按钮 `8-12px`、头像 `50%`

## 小程序端侧交互（≥4 种）

- 右上角胶囊按钮（··· / ⊙）+ 自定义导航栏（随页面透明 / 渐变 / 吸顶变色）
- 底部 TabBar（选中态微动效弹跳）
- 页面栈 push/pop（右滑返回手势感）
- ActionSheet 动作面板 / 半屏弹层
- 下拉刷新弹性回弹
- 吸顶筛选 Tab
- 详情页吸底操作栏
- 骨架屏加载

## 页面结构（8 页，布局各异）

1. 星野首页（Hero + 卡片流 + 流星）
2. 星座图鉴（吸顶筛选 + 瀑布流 + 下拉刷新）
3. 星座详情（视差滚动 + 星象雷达 + 吸底操作栏）
4. 星轨曝光（环形计时器 + 旋转星轨 + 步骤引导）
5. 观星点地图（暗空地图 + 列表）
6. 个人中心（头像脉冲 + 成就环 + 宫格）
7. 设计规范（色板 / 字体 / 圆角 / 按钮层级）
8. 接口文档（深色代码风格）

## 动效系统（16 个组件级特效）

自定义光标（白环 + 焦糖内点 + 涟漪）、涟漪点击、打字机标题、数字计数、头像脉冲、光泽扫过、视差滚动、卡片 3D 倾斜、下拉弹性、环形进度、星空闪烁、流星划过、星座连线动画、星轨旋转、TabBar 弹跳、入场 fadeUp 序列。

## 签名动效

- 首页入场序列：流星划过 + 卡片 fadeUp 错落
- 星座详情：视差滚动 + 星象雷达扫描

## 技术栈

React + 内联 Babel JSX（内联于 index.html），无外部 src 依赖。支持 `prefers-reduced-motion` 降级；RAF / 定时器随 `visibilitychange` 暂停。

# 星野 · 星空观测微信小程序

> 日期：2026-08-18 · 方向：V2 手机 UI · 形态：微信小程序 · 主题：星空观测小程序

## 简介

「星野」是一款面向天文爱好者与城市观星者的微信小程序，提供星座图鉴、星轨曝光计算、观星点地图与观测记录。配色取深空靛蓝为底、星光金为主、青空蓝与星紫点缀，营造暗空下的星野氛围。包含 6 个真实星座、4 处观星点、4 种观测方式，内容真实可信。

## 形态

形态：微信小程序

## 动效亮点

- 自定义光标：白环 + 焦糖内点 + 涟漪
- 星空闪烁 + 流星划过 + 星座连线动画 + 星轨旋转
- 视差滚动、环形进度、卡片 3D 倾斜、下拉弹性、TabBar 弹跳、入场 fadeUp 序列等共 16 个组件级特效
- 签名动效：首页入场序列（流星 + fadeUp）、星座详情视差 + 星象雷达

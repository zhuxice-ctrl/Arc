# 设计规范 · 卷 · 古籍善本馆

形态：原生 App

> 日期：2026-08-17 · 方向：V2 手机 UI · 形态：原生 App（上一次为微信小程序，本次交替）· 主题：古籍善本阅读与收藏 App（文化艺术领域）

## 色彩系统

| 角色 | 色值 | 用途 |
|---|---|---|
| 底色 · 墨黑 | `#1C1917` | 深色头区、详情页暗底 |
| 主色 · 朱砂红 | `#B94A3A` | 印章、主按钮、强调标签 |
| 纸面 · 宣纸米白 | `#FBF6EC` | 主背景、卡片表面 |
| 金 · 藏经纸金 | `#C9A961` | 分隔线、收藏标记、次级强调 |
| 竹青 | `#6B8E5A` | 状态标签、可读性标记 |
| 茶褐 | `#8B7355` | 次级文字、边框 |
| 灰 | `#A39C8E` | 辅助文字 |
| 深灰 | `#3F3A34` | 卡片描边 |
| 浅纸 | `#F5ECD8` | 次级表面、分隔区 |

配色以宣纸/墨色/朱砂印章为视觉语言，完全避开蓝紫渐变。

## 字体

- 标题：衬线字体栈（书卷气）
- 正文：系统无衬线
- 编号/数据：等宽字体栈

## 页面结构（8 页，布局各异）

1. 发现页 — Hero 镇馆之宝大卡 + 分类横向轮播 + 列表堆叠
2. 藏书阁 — 三列网格书架 + 分段控件筛选 + 悬浮操作球 FAB
3. 详情页 — 封面视差滚动 + 毛玻璃吸顶导航 + 章节列表
4. 阅读页 — 翻页入场动效 + 底部半屏抽屉（字号/主题切换）+ 进度条
5. 雅集社区 — 瀑布流双列 + 下拉刷新 + 标签筛选
6. 我的 — 深色头区 + 环形进度环 + 分组设置 + 关于模态弹窗
7. 设计规范 — 色卡/字体/圆角/阴影/签名元素
8. 接口文档 — 分组 Tab + 可展开端点 + 代码块 + 状态码

## 原生交互（≥4 种）

底部 TabBar、返回栈导航、毛玻璃导航栏、模态弹窗、底部半屏抽屉、下拉刷新、悬浮操作球 FAB、大标题滚动收缩。

## 动效系统（12+）

印章按压、翻页 3D 旋转、环形进度描边、Hero 视差缩放、下拉弹性旋转、入场渐入序列、FAB 浮动、弹簧缩放 Tab 图标、列表错峰入场、进度条缓动、模态升降、设置抽屉毛玻璃。

## 健壮性

- RAF 随页面可见性自动暂停、定时器统一清理
- 支持 `prefers-reduced-motion` 降级
- 所有交互可用，ios-frame 组件已内联于 index.html（无外部 jsx 引用）

## 技术栈

React 18 + Babel standalone，JSX 全部内联于 `<script type="text/babel">`，CSS 内联 `<style>`。

# 设计规范 · 星野 · 星空观测 App

形态：原生 App

> 日期：2026-08-18 · 方向：V2 手机 UI · 形态：原生 App · 主题：星空观测与拍摄社区

## 色彩系统

| 角色 | 色值 | 用途 |
|------|------|------|
| 底色 | #0E1513 | 深青黑夜空，全局背景 |
| 强调色 | #F2C94C | 星黄，主按钮、关键数据、选中态 |
| 点缀 | #D9534F | 观测红（红光夜视模式语义），警示、活跃标记 |
| 辅助 | #7DBE9N / #6B8E9F | 星辉绿 / 雾蓝灰，次级强调 |
| 文字 | #E8EDEA / #C9D1C8 | 银辉主文字 / 次文字 |
| 表面 | #1F2329 / #2a1a1a | 卡片表面、深层面板 |
| 中性 | #86909C / #DEE0E3 | 辅助文字、分隔线 |

配色取「深夜星空 + 星光黄 + 红光夜视」意象，无蓝紫渐变。

## 字体

- 标题：Noto Serif SC，400/600/700/900
- 正文：Noto Sans SC，300/400/500/700
- 数据：JetBrains Mono，400/500

## 原生端侧交互（6 种）

底部 TabBar、大标题导航栏 + 返回栈、下拉刷新弹性、FAB 悬浮按钮、底部半屏抽屉、模态详情页转场。

## 组件

- 手机外壳：统一设备框，页面在框内切换
- 星空视差：Hero 背景多层星点视差滚动
- 流星动效：随机划过 + 拖尾
- 环形进度：个人页等级描边动画
- 脉冲光环：观测点地图标记呼吸
- 半屏抽屉：底部上滑面板 + 抓手

## 动效系统（12+ 组件级特效）

星星闪烁、流星划过、视差滚动、脉冲光环、浮动缓动、环形进度描边、旋转星座、入场序列、发光呼吸、弹跳进入、下拉弹性、页面切换过渡。所有 RAF 随 `visibilitychange` 暂停、卸载统一清理；支持 `prefers-reduced-motion`。

## 页面结构（8 页）

1. 首页（今夜天象）— Hero 星空视差 + 下拉刷新 + 堆叠卡片
2. 星座图鉴 — 瀑布网格拼贴 + 星座连线 SVG + 季节筛选
3. 观测点地图 — 中国地图 + 脉冲标记 + 底部半屏抽屉 + 旋转指南针
4. 社区 — 卡片信息流 + FAB + 点赞 + Tab 切换
5. 我的 — 环形进度等级 + 成就徽章 + 设置列表
6. 天象日历 — 日历网格 + 左侧色条事件
7. 设计规范页 — 色板/字体/间距/组件 4 Tab
8. 接口文档页 — 折叠接口列表 + JSON 高亮 + 错误码表

## Tweaks 面板

主色调切换（星黄 / 星辉绿 / 玫瑰 / 青灰）、红光夜视模式开关、动画强度调节。

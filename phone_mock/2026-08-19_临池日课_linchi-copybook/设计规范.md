# 设计规范 · 临池日课（书法临帖原生 App）

> 类别：Phone Mock　日期：2026-08-19　**形态：原生 App**
> （上一版「街角修理铺」为微信小程序，按交替规则本版做原生 App）

## 设计母题
书法爱好者的每日临帖 App——每天一个字，写完叠在原帖上看差在哪。核心机制：选帖 → 单字临写 → 叠影对比 → 收入日课集字墙。

## 产品结构（9 屏，完整 User Flow）
今日日课（home：今日一字 + streak + 开始临写）→ 碑帖库（兰亭序/九成宫醴泉铭/多宝塔碑）→ 碑帖详情 → 临写页（毛笔画布·笔触粗细随速度）→ 叠影对比（透明度滑杆 0~100%）→ 集字墙（按碑帖分组收藏）→ 我的；另含设计规范页、接口文档页。
- 导航：底部 TabBar（今日/碑帖/集字/我的）+ 页面栈 push/pop + 右上角返回。
- 反首页模板：home 为「今日一字 + 连续天数 + 等级」状态卡，非问候语+搜索+Banner。

## 动效系统（≥12 组件级，服务产品反馈）
CSS keyframes（源码提取）：`fadeUp`（入场）、`inkSpread`（墨色晕染）、`modalEnter`/`modalExit`（半屏弹层）、`pageEnterLeft`/`pageEnterRight`/`pageExitLeft`/`pageExitRight`（页面栈 push/pop 转场）。
另有：笔触书写回放、笔触粗细随速度、叠影渐变、评分条渐入、印章微震、Tab 切换连续关系、streak 打卡点亮。克制，无粒子光晕。

## 核心交互
1. 临写画布真实书写（鼠标/触摸模拟毛笔，粗细随速度/压力变化）。
2. 叠影对比透明度滑杆（0~100%）——Signature Moment：拖到 50% 自己的字与原帖重叠显结构偏差。
3. 三种对比模式：叠影/左右/点击切换；笔画计数 + 回放 + 撤销。
4. localStorage 持久化：连续天数、集字墙、等级进度。
5. 真实碑帖内容：兰亭序、九成宫醴泉铭、多宝塔碑各 5 个真实单字配释文。

## 技术栈
- React 18 + Babel standalone（飞书 CDN）+ 外部 jsx 模块（js/ 目录）。**部署版经 http 正常加载**；本地 file:// 打开因 babel fetch 受限会白屏，须以 http 服务或妙搭预览链接访问。
- 手机舞台 430×904 居中，桌面外层深色舞台；自定义光标开页居中高对比；`prefers-reduced-motion` 降级；零 Console 严重错误。
- 经 Browser QA（本地 http 服务）：430×932 / 390×844 渲染正常、9 屏可走通、无 console severe。

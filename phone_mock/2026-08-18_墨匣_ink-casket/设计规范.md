# 墨匣 App · 设计规范

形态：原生 App

## 一、设计理念

「墨匣」以中国传统文房四宝为精神源头，将墨、纸、砚、笔的质感融入现代移动端 UI。整体气质温润雅致，沉静而有力量，强调东方审美的留白与气韵。

设计关键词：**温润 · 沉静 · 东方 · 文房**

## 四、间距系统

基于 4px 网格，组件间距以 8 的倍数递增：

- `4px` — 图标与文字间隙
- `8px` — 紧凑卡片内间距
- `12px` — 元素之间隙
- `16px` — 标准内边距
- `20px` — 页面左右边距
- `24px` — 区块间距
- `32px` — 大区块间距

- 标签：10px / 字重 500
- 选中色：`#2d4a3e`，未选中：`#9aa5a0`

## 八、动效规范

### 8.1 缓动函数

- 标准弹性：`cubic-bezier(.2, .8, .2, 1)`
- 入场弹压：`cubic-bezier(.34, 1.56, .64, 1)`
- 淡出：`cubic-bezier(.4, 0, .2, 1)`

### 8.2 时长

- 微交互：150-200ms
- 组件过渡：300-400ms
- 页面转场：400ms
- 入场动画：600ms
- 滚动渐入：500ms

### 8.3 动效原则

- 物理质感：基于弹簧 / 阻尼 / 惯性模型
- 错峰入场：列表项 50-80ms 级差
- 降级策略：尊重 `prefers-reduced-motion`
- 可见性：页面隐藏时自动暂停 RAF 循环

## 九、交互规范

### 9.1 原生手势

| 手势 | 行为 |
|------|------|
| 左边缘右滑 | 返回上一页 |
| 下拉（列表顶部） | 下拉刷新 |
| 长按卡片 | 弹出快捷操作菜单 |
| 点击 FAB | 弹出发布模态 |
| 点击色卡 | 进入详情页 |

### 9.2 反馈

- 可点击元素：按下 `scale(0.92-0.96)` 回弹
- 悬停：卡片上浮 2-4px + 阴影加深
- 加载：旋转环形指示器
- 成功：绿色文字 + 打钩动画

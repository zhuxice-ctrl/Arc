# 设计规范 — 信鸽竞翔训练台

**形态：原生 App**

---

## 一、设计母题

### 核心概念
训放罗盘仪 — 整个界面像飞行员腕表上的方位计时器。信鸽爱好者在罗盘上设定放飞方向与距离，确认放飞瞬间鸽群从中心扇形扩散消失在天际，归巢时光点从各方向收敛回巢。航空仪表盘视觉语言贯穿全局。

### 视觉来源
- 航空驾驶舱计时仪表盘
- 飞行员腕表（Pilot Watch）
- 信鸽竞翔赛事计时传统
- 深色仪器面板 + 发光读数

### 空间逻辑
仪器式 — 中央罗盘量表为视觉核心，环绕读数面板呈放射状排布，信息围绕核心仪表组织。

### 图形语言
- 线条：发丝线刻度 + 古铜色仪表边框
- 边界：1px 古铜色描边，轻微内阴影模拟仪表面板凹陷
- 图标：线性 stroke 风格，琥珀色激活态
- 几何结构：圆形（罗盘/仪表/状态指示）主导
- 纹理：径向渐变模拟玻璃罩反光

- **琥珀**：操作、激活、数据读数（仪表传统色）
- **磷光绿**：完成、归巢、成功、适宜（飞行员仪表盘绿=正常）
- **信号红**：警告、放飞矢量、北针（航空红色=正北/警示）
- **古铜**：结构、边框、刻度（金属表圈质感）

### UI 文字

```
用途：界面所有通用文字、按钮、标签、说明文字。
跟随系统，保证原生 App 观感。

### 等宽数字
```
font-family: "SF Mono", "JetBrains Mono", "Menlo", "Consolas", monospace
```
用途：计时器、脚环号、分速、距离、日期编号、代码示例。
航空仪表感 — 数字对齐、稳定、精确感。

### 血统/呼名（衬线）
```
font-family: "Noto Serif SC", "Songti SC", "STSong", serif

用途：信鸽血统名称（詹森系/凡龙系等）、呼名单字。
中国传统信鸽文化传承感，与仪器感 UI 形成材质对比。

## 四、组件系统

### 按钮
- **主按钮**：琥珀色渐变背景 + 深色文字 + 发光阴影。圆角 26px（胶囊形）。
- **次按钮**：深色面板底 + 古铜色描边 + 奶白文字。圆角 10px。
- 按下态：`scale(0.97)` + 颜色微调。

### 状态标签（Status Pill）
- 圆角 8px，字体 10px，半透明背景 + 对应主题色文字
- 四态：在巢（绿）/ 训练中（琥珀）/ 已归巢（绿）/ 丢失（红）

### 距离刻度（Dist Step）
- 等宽字体，圆角 6px，高度 28px
- 激活态：琥珀填充 + 深色字 + 加粗
- 常态：钢灰字 + 深色面板底

### 卡片（Pigeon Card）
- 左侧圆形头像（首字衬线体）+ 中部信息 + 右侧状态标签
- 头像：48×48px 圆形，古铜色边框
- 背景：`#25282B` + `#8B6914 30%` 描边

### 进度条
- 高度 4px，深色底槽 + 磷光绿填充
- 填充带发光效果（`box-shadow: 0 0 8px rgba(74,157,63,0.4)`）

### 罗盘仪表
- 外圈：碳黑金属质感渐变 + 古铜色边框 + 内阴影
- 刻度环：每 6° 一刻度，每 30° 一主刻度（琥珀色）
- 方向标签：8 方位字母标注，正北红色、正南钢灰
- 中心盘：径向渐变深色玻璃 + 距离数字（琥珀等宽）

## 五、动效系统

### 核心签名动效

#### 1. 放飞扇形扩散
- 触发：点击「放飞」按钮
- 表现：6-12 个琥珀色粒子从罗盘中心出发，沿选定方向 ±15° 扇形扩散
- 曲线：`cubic-bezier(0.22, 0.61, 0.36, 1)`（初快后慢，模拟抛体）
- 时长：约 1.2s
- 消失：渐缩至 20% + 透明度渐隐

#### 2. 归巢光点收敛
- 触发：点击「归巢」确认
- 表现：6 个磷光绿色光点从屏幕四周随机边缘位置，匀速向中心汇聚
- 到达：脉冲光环向外扩散一次（`pulseExpand` 0.8s ease-out）
- 丢失状态：红色光点，无脉冲

#### 3. 罗盘旋转
- 交互：触摸/鼠标拖动外圈
- 手感：拖动时实时跟随（无过渡），松手后吸附到最近 45° 方向
- 缓动：0.1s 延迟 + 过渡吸附

### 过渡动效
- 页面转场：右入左出，`translateX` + `cubic-bezier(0.25, 0.46, 0.45, 0.94)`，0.3s
- 底部弹层：`translateY(100%)` → 0，0.3s
- 按钮反馈：`scale(0.97)`，0.15s

### 健壮性
- 所有动画支持 `prefers-reduced-motion` 降级为瞬时切换
- 定时器随 `visibilitychange` 暂停（基于时间戳重算，不依赖计数）
- 页面卸载时清理所有定时器
- 快速操作有防抖保护（`finishTraining` 1s 防抖）

## 七、导航结构

底部 TabBar 4 标签：
1. **今日** — 仪表盘首页（罗盘仪表 + 数据 + 快捷入口）
2. **鸽舍** — 信鸽列表 + 筛选 + 详情弹层
3. **训放** — 罗盘选向 + 距离选择 + 选鸽 + 放飞
4. **档案** — 训练记录 + 统计 + 设计规范/接口文档入口

二级页面（Push 栈）：
- 设计规范页
- 接口文档页
- 归巢记录页（训放流程内）

## 八、完整 User Flow

```
今日仪表盘 → 开始训放 → [训放页]
                         ├─ 拖动罗盘选方向
                         ├─ 点击距离档选距离
                         ├─ 勾选参训鸽子
                         └─ 放飞（扇形粒子动画）
                                    ↓
                           [归巢记录页]
                         ├─ 实时计时
                         ├─ 逐只确认归巢（收敛动画）
                         ├─ 批量确认
                         └─ 完成训练 → 写入档案
                                    ↓
                              [档案页]
                         ├─ 统计数据
                         ├─ 历史记录列表
                         ├─ 设计规范
                         └─ 接口文档
```

## 十、技术栈

- **纯 Vanilla HTML/CSS/JS** — 单文件、无框架、无外部依赖
- **CSS 变量** — 设计 token 化
- **DOM 操作** — 高频触控事件直接操作 `transform`
- **localStorage** — 训放档案持久化
- **CSS transition + RAF** — 粒子动画
- **Touch Events + Mouse Events** — 罗盘拖动双端支持

# 竹编志 · 竹编工艺微信小程序

> 日期：2026-08-17 · 方向：V2 手机 UI · 形态：微信小程序 · 主题：竹编工艺微信小程序

## 简介

竹编志是一个展示中国传统竹编工艺的微信小程序 mock，以竹青、暖木棕、深竹墨为主色调，呈现竹材质感的自然温润。包含 8 个页面：首页瀑布流、分类筛选、作品详情、匠人故事、编织学堂、材料百科、个人中心、设计规范与接口文档。完整实现微信小程序端侧交互语言。

## 动效亮点

- 竹叶飘落粒子动画，呼应竹编自然主题
- 下拉刷新弹性回弹，竹叶旋转指示
- 3D 倾斜卡片效果（材料百科页对角分割卡片）
- 环形进度动画（个人中心页）
- 骨架屏加载+光泽扫过（编织学堂页）
- ActionSheet 半屏弹层+底部抽屉滑入

## 微信小程序端侧交互

- 胶囊按钮导航栏（透明/渐变/吸顶变色）
- 底部 TabBar（4 Tab，选中微动效）
- 页面栈 push/pop 切换
- ActionSheet 动作面板
- 吸底操作栏
- 下拉刷新弹性回弹
- 骨架屏加载
- 深色模式切换

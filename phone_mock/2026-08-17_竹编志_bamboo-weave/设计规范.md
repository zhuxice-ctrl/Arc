## 字体系统

- 正文：`'Noto Sans SC', -apple-system, system-ui, sans-serif`
- 标题/品牌字：`'ZCOOL XiaoWei', 'Noto Serif SC', serif`
- 代码/数据：`'SF Mono', monospace`

## 圆角与间距

- 卡片圆角：16px
- 按钮圆角：24px（胶囊形）
- 小标签圆角：8px
- 图片圆角：12px
- 页面间距：16px 水平
- 卡片间距：12px

## 组件规范

- 微信胶囊导航栏：右上角"··· / ⊙"按钮，导航栏可透明/渐变/吸顶变色
- 底部 TabBar：4 个 Tab（首页/分类/学堂/我的），选中态竹青色+微动效
- 半屏弹层/ActionSheet：从底部滑入，半透明遮罩，可关闭
- 吸顶 Tab：滚动时吸顶，切换有下划线动效
- 吸底操作栏：固定底部安全区，主按钮胶囊形
- 骨架屏：灰色占位+光泽扫过动画
- 下拉刷新：弹性回弹，竹叶旋转指示
- 左滑操作：列表项左滑露出操作按钮

## 动效系统

| 编号 | 动效 | 触发方式 | 物理模型/语义 |
|------|------|---------|-------------|
| 1 | 自定义光标 | 鼠标移动 | 白环+竹青内点+涟漪 |
| 2 | 竹叶飘落粒子 | 页面加载 | 重力下落+左右摆动 |
| 3 | 数字计数 | 滚入视口 | requestAnimationFrame 插值 |
| 4 | 打字机光标 | 页面加载 | 逐字显示+光标闪烁 |
| 5 | 卡片入场渐入 | 滚入视口 | 延迟序列上移淡入 |
| 6 | 3D 倾斜 | 鼠标悬停 | 透视变换+视差 |
| 7 | 视差滚动 | 滚动 | 图片位移映射 |
| 8 | 下拉弹性回弹 | 下拉手势 | 弹簧物理回弹 |
| 9 | 环形进度 | 页面加载 | SVG 描边动画 |
| 10 | 头像脉冲 | 页面加载 | scale 缩放循环 |
| 11 | 光泽扫过 | 骨架屏 | 渐变条横向移动 |
| 12 | Tab 微动效 | 点击 | 下划线滑动+内容淡入 |
| 13 | ActionSheet 弹层 | 点击 | 底部滑入+遮罩淡入 |
| 14 | 抽屉滑入 | 点击 | 底部半屏抽屉弹性滑入 |

## 页面结构（8 页）

1. 首页：Hero 大图 + 瀑布流卡片 + 吸顶搜索栏
2. 分类页：吸顶双层 Tab + 卡片堆叠列表 + 左滑操作
3. 作品详情：Hero 视差滚动 + 吸底操作栏 + ActionSheet
4. 匠人故事：轮播画廊 + 底部半屏抽屉
5. 编织学堂：步骤式教学卡片 + 进度条 + 骨架屏
6. 材料百科：网格拼贴 + 对角分割卡片 + 3D 倾斜
7. 个人中心：头像宫格 + 环形进度 + 设置列表 + 深色模式
8. 设计规范 + 接口文档：色板展示 + API 卡片

## 微信小程序端侧交互

- 胶囊按钮导航栏（透明/渐变/吸顶变色）
- 底部 TabBar（4 Tab，选中微动效）
- 页面栈 push/pop 切换
- ActionSheet 动作面板
- 吸底操作栏
- 下拉刷新弹性回弹
- 骨架屏加载
- 深色模式切换

## 技术栈

React + Babel standalone（JSX 内联在 `<script type="text/babel">` 中），CSS 内联在 `<style>` 标签中。

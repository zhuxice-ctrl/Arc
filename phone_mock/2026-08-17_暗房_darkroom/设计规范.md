# 设计规范 · 暗房 Darkroom 胶片摄影原生 App

形态：原生 App

> 日期：2026-08-17 · 方向：V2 手机 UI · 主题：胶片摄影原生 App（iOS 形态）

## 形态标记

形态：原生 App（V2 双形态交替：上一次为「微信小程序」，本次为「原生 App」）

## 色彩系统

| 角色 | 色值 | 用途 |
|------|------|------|
| 墨黑（底） | `#0E0E10` / `#0a0a0a` | 页面底色、深色层级 |
| 暗房红灯 | `#C73E1D` / `#3a1208` | 暗房 Lab 主色、强调 |
| 琥珀黄 | `#D9A441` | 高光、进度、徽章 |
| 相纸米白 | `#E8E4DA` / `#F7F7F7` | 主文字、浅色表面 |
| 银盐灰 | `#8A8A8A` / `#A8A297` | 次要文字、边框 |
| 定影蓝 | `#2D4A6B` | 冷调点缀 |
| 暖棕 | `#2a2520` / `#1A1715` / `#3A2A26` | 卡片表面、分隔 |

配色避开蓝紫渐变，以「墨黑 × 暗房红灯 × 琥珀黄 × 相纸米白」构成胶片暗房主调；每页有自己的色彩主角（暗房页偏红、胶卷库偏琥珀、我的页偏暖棕）。

## 字体

- `DM Serif Display`：大标题导航栏、详情标题
- `Inter`（-apple-system / BlinkMacSystemFont / Segoe UI）：正文
- `JetBrains Mono`：EXIF 数据、编号、接口字段

## 页面结构（8 页）

1. 发现页：Hero + 胶片卷轴横向滚动 + 瀑布流
2. 照片详情：全屏转场 + 视差 + EXIF 悬浮条
3. 胶卷库：环形拍摄进度 + 卡片堆叠 + FAB
4. 暗房 Lab：对角分割 + 红灯计时器
5. 我的：头像光环 + 徽章网格
6. 工作坊详情：底部模态弹层
7. 设计规范页
8. 接口文档页

至少 5 个页面有独特非重复布局（发现/详情/胶卷库/暗房/我的），避免换皮不换骨。

## 原生交互（7 种，≥4 要求满足）

大标题导航栏、底部 TabBar（原生质感）、全屏详情转场、底部模态弹层、下拉刷新、悬浮操作按钮 FAB、毛玻璃导航。

## 签名动效（4 项）

1. 照片显影入场（灰度→彩色 + 颗粒消散）
2. 胶片卷轴横向滚动
3. 环形拍摄进度动画
4. 暗房红光计时器

## 组件级特效（13 项）

自定义光标、入场序列、3D 倾斜、悬停发光、数字计数、光泽扫过、头像脉冲、视差、涟漪、骨架屏、环形进度、红灯呼吸、TabBar 微动效等。

## 健壮性

- JSX 内联于 `index.html` 的 `<script type="text/babel">`；组件文件 `ios-frame.jsx` / `tweaks-panel.jsx` 由妙搭构建系统打包（平台预览渲染正常）
- rAF/定时器随 `visibilitychange` 暂停，卸载统一清理
- 高频 mousemove 直接操作 DOM transform
- `prefers-reduced-motion` 全量降级

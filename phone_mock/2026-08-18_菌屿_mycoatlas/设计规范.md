# 菌屿 · 设计规范

> 日期：2026-08-18 · 方向：V2 手机 UI · **形态：微信小程序** · 主题：山野菌物图鉴小程序

形态：微信小程序

## 色彩系统

| 角色 | 色值 | 用途 |
|---|---|---|
| 苔藓绿（主色） | #5B7A4E | TabBar 选中态、主按钮、Tab 高亮 |
| 深林墨绿 | #22301E | 顶部导航渐变、首页 Hero 底色 |
| 菌柄米白 | #F4EEE2 | 页面主背景、卡片底色 |
| 鹅黄强调 | #E8C547 | 数据高亮、进度环、徽章 |
| 赭石橙 | #C9722E | 周末标记、警示、稀缺标签 |
| 警示红 | #C44536 | 毒性警示、危险菌种标识 |
| 浅米 | #EDE6D6 / #E8E0D0 | 次级卡片底、区块分隔 |
| 中性灰 | #DEE0E3 / #D9D1C0 | 边框、次要文字 |

每页色彩主角：首页深林墨绿→米白渐变、图鉴米白底+苔藓绿 Tab、详情页随菌种主题色变化、日历苔藓绿+赭石橙周末、社区米白+多彩标签、个人中心墨绿渐变头+金色进度。

## 字体系统

- 正文/UI：`'Noto Sans SC', -apple-system, system-ui, sans-serif`
- 标题/品牌：`'Noto Serif SC', serif`（衬线体营造博物图鉴质感）
- 数字/代码：等宽 `monospace`

## 组件规范

- 自定义导航栏：胶囊按钮（···/⊙）右上角，随页面透明/渐变/吸顶变色
- TabBar：5 项，选中态弹跳动效（cubic-bezier(0.34,1.56,0.64,1)）
- 卡片：米白底 + 阴影分层，圆角 12-16px
- 吸底操作栏：安全区适配，主按钮苔藓绿
- ActionSheet：半屏弹层，缓动上滑
- 环形进度：SVG 环 + 数字 easeOut 增长

## 小程序端侧交互（6 种）

自定义导航栏 + 胶囊按钮、底部 TabBar（选中态弹跳）、页面栈 push/pop 右滑感切换、ActionSheet 半屏弹层、下拉刷新弹性回弹、左滑列表操作、吸顶 Tab、吸底操作栏。

## 动效系统（12+ 项）

- 页面级签名动效：首页雨季雨滴阵列、详情页 Hero 视差滚动
- 组件级：Tab 点弹跳、按钮弹簧缩放、入场错落 fade-up、蘑菇浮动、卡片涟漪、环形进度数字增长、下拉弹性、左滑抽屉、骨架屏 shimmer、胶囊按钮高亮、导航栏渐变变色、ActionSheet 缓动上滑
- 物理模型：弹簧缓动 cubic-bezier(0.34,1.56,0.64,1)、惯性动量、阻尼过渡

## 健壮性

- 零未定义引用（Babel 编译通过）
- `visibilitychange` 自动暂停 rAF
- 页面切换前 clearTimeout 清理旧定时器
- `prefers-reduced-motion` 降级 + 隐藏光标
- 自定义光标：白环 + 鹅黄内点 + 多层发光，悬停放大变金，点击涟漪，开页居中显示

## 页面结构（8 页）

首页（雨季采菌卡片流）→ 图鉴（吸顶 Tab + 瀑布流网格拼贴 + 左滑 + 下拉刷新）→ 菌物详情（Hero 视差 + 属性三格宫 + 吸底操作栏 + ActionSheet）→ 采菌日历（月历网格 + 产季圆点）→ 社区（话题 Banner + 双列瀑布流）→ 个人中心（色块分区 + 悬浮用户卡 + 环形进度 + 数据宫格）→ 设计规范页 → 接口文档页。至少 5 页布局互不重复。

# 云裳阁 · 设计规范

## 设计理念

以宋明美学为骨，以丝绸织锦为韵。设计语言取意于水墨、卷轴、织金，以现代交互承载传统服饰文化之美。

## 色彩系统

| 名称 | 色值 | 角色 | 用途 |
|------|------|------|------|
| 石青 | `#2B4C6B` | 主色 Primary | 导航栏、主按钮、重点文字 |
| 胭脂 | `#C24D4D` | 强调色 Accent | 点赞、标签、重点标记 |
| 缃黄 | `#E8D5A3` | 辅助色 Secondary | 装饰线、图标、金边 |
| 月白 | `#F5F0E6` | 表面色 Surface | 页面底色、卡片底色 |
| 纸白 | `#FAF7F0` | 卡片色 Card | 内容卡片背景 |
| 墨藏 | `#2C2925` | 文字色 Text | 标题与正文文字 |
| 褐 | `#8B7355` | 次级文字 Muted | 辅助说明文字 |
| 青灰 | `#B5A88E` | 边框 Border | 分割线与边框 |

### 色彩语义

- 石青：取自明代一至四品官员常服色，象征庄重与品级
- 胭脂：传统胭脂虫红色，用作点缀与强调
- 缃黄：传统书画用缃色纸，用作辅助与装饰
- 月白：浅淡的青白色，用作大面积底色

## 字体系统

### 展示字体

- **字体族**：Noto Serif SC
- **用途**：标题、品牌名、大字号展示
- **字重**：500 / 600 / 700
- **特点**：衬线字体呼应古籍刻本气质

### 正文字体

- **字体族**：Noto Sans SC
- **用途**：正文、标签、辅助文字
- **字重**：300 / 400 / 500
- **特点**：黑体确保移动端可读性

### 字号层级

- 页面大标题：26px / 700 / Serif
- 区块标题：17px / 600 / Serif
- 卡片标题：15px / 600 / Serif
- 正文：13-14px / 400 / Sans
- 辅助文字：10-12px / 400 / Sans

## 间距系统

以 4px 为基础单位：

- 4px — 紧凑间距（图标旁文字）
- 8px — 小组件间距
- 12px — 卡片内边距
- 16px — 页面水平边距
- 20px — 区块间距
- 24px — 大区块间距

## 圆角系统

- `sm` 8px — 小型卡片、按钮
- `md` 14px — 内容卡片
- `lg` 20px — 大卡片、面板
- `xl` 28px — 详情页底部弧面

## 阴影系统

- `sm` — 0 2px 8px rgba(44, 41, 37, 0.06)
- `md` — 0 4px 20px rgba(44, 41, 37, 0.08)
- `lg` — 0 8px 32px rgba(44, 41, 37, 0.12)
- `gold` — 0 4px 20px rgba(232, 213, 163, 0.3)

## 组件规范

### 按钮

**主按钮**
- 背景：石青 #2B4C6B
- 圆角：100px（胶囊形）
- 文字：白色 / 14px / Serif / 500
- 阴影：md
- 按压：scale(0.96) + 0.15s

**次级按钮**
- 背景：月白 #F5F0E6
- 文字：墨藏色
- 其余同主按钮

### 标签 (Tag)

- 圆角：4px
- 内边距：3px 10px
- 字号：10px / Serif / 500
- 背景：主色/强调色 15% 透明度
- 文字：对应主色/强调色

### 卡片

- 背景：纸白 #FAF7F0
- 圆角：sm / md（依场景）
- 边框：0.5px solid 青灰 20% 透明
- 阴影：sm

### TabBar

- 背景：月白 85% 透明 + blur(20px) 毛玻璃
- 图标：24x24
- 选中色：石青
- 未选中色：青灰
- 选中态：translateY(-2px) scale(1.08) + 红点脉冲

## 动效规范

### 缓动函数

- 标准：cubic-bezier(0.2, 0.8, 0.2, 1)
- 弹性：cubic-bezier(0.34, 1.56, 0.64, 1)
- 出场：cubic-bezier(0.4, 0, 1, 1)

### 动画时长

- 微交互：150ms（按钮按压）
- 组件过渡：250-300ms（Tab 切换、面板展开）
- 页面转场：450ms（页面入场）
- 长动画：1.5-4s（团花旋转、数字计数）

### 签名动效一览

1. **丝绸光泽** — 图片上掠过的斜向光泽扫过，4s 循环
2. **卷轴展开** — max-height + opacity 从顶部向下展开
3. **团花旋转** — SVG 团花图案缓慢漂浮旋转，4s/8s 循环
4. **水墨晕染** — 点击涟漪如水墨晕开，600ms
5. **抽屉开合** — 木质抽屉 X 轴位移展开
6. **数字滚动** — 从 0 缓动增长至目标值，1.5s
7. **心跳脉冲** — 点赞时 1.2 倍缩放回弹
8. **弹性指示器** — Tab 指示器弹性滑动切换
9. **页面入场** — 从下方 12px 渐入，450ms
10. **滚动渐显** — IntersectionObserver 驱动逐行显露
11. **光标涟漪** — 点击时多层圆环扩散
12. **视差滚动** — 详情页大图随滚动 0.3 倍位移

## 无障碍

- 支持 `prefers-reduced-motion`，开启时降级为静态或最小动效
- 文字与背景对比度达标（墨藏/月白 ≥ 12:1）
- 可交互元素最小尺寸 ≥ 36px

## 布局规范

- 设备宽度：390px（iPhone 14 规格）
- 安全区顶部：62px（灵动岛 + 状态栏）
- 安全区底部：34px（Home Indicator）
- 页面水平内边距：20px

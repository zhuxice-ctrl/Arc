# 云裳阁 · 汉服衣橱 App

一款为汉服爱好者打造的原生移动端 App，集汉服藏品管理、形制浏览、穿搭推荐、同袍社区于一体。

## 形态说明

- **形态**：原生 App（iOS 风格）
- **日期**：2026-08-17
- **版本**：v2.0

## 页面清单

| 序号 | 页面 | 说明 | 布局特色 |
|------|------|------|----------|
| 1 | 首页 | 每日推荐 + 形制入口 + 同袍精选 | Hero 大图 + 横向滚动 + 列表卡片 |
| 2 | 形制分类 | 按朝代/形制筛选藏品 | 吸顶 Tab + 瀑布流双列 |
| 3 | 藏品详情 | 汉服详情与形制源流 | 视差滚动 + 卷轴展开信息 |
| 4 | 我的衣橱 | 木质格柜式藏品收纳 | 木匣抽屉式展开 + 收藏统计 |
| 5 | 社区广场 | 同袍穿搭分享 | 卡片式信息流 + 标签筛选 |
| 6 | 个人中心 | 用户信息与功能入口 | 深色色头 + 环形进度 + 宫格菜单 |
| 7 | 设计规范 | 视觉与组件规范文档 | 色板 + 字体 + 组件展示 |
| 8 | 接口文档 | API 说明与示例 | 深色代码风 + 折叠展开面板 |

## 原生 App 交互特性

1. **底部 TabBar** — 5 个主 Tab，选中态有缩放动画 + 红点脉冲
2. **返回栈导航** — 详情页/规范页/文档页从右侧推入，左上角返回按钮
3. **卡片式信息流** — 社区页的卡片流，点赞有心跳动画
4. **悬浮操作按钮 FAB** — 衣橱页和社区页的圆形悬浮按钮
5. **模态式详情页** — 详情页覆盖式进入，底栏吸底操作按钮
6. **下拉式内容面板** — 详情页如卷轴般展开的分段信息

1. 丝绸光泽扫过（silk shimmer）
2. 卷轴展开转场（scroll unfurl）
3. 团花漂浮旋转（medallion float）
4. 数字滚动计数（number count-up）
5. 环形进度动画（ring progress）
6. 抽屉开合动画（drawer slide）
7. 心跳点赞脉冲（heart pulse）
8. Tab 切换弹性指示器（elastic indicator）
9. 页面入场渐入（page enter）
10. 滚动渐显（scroll reveal）
11. 自定义光标（custom cursor with ripple）
12. 视差滚动（parallax scroll）

## 技术实现

- React 18 + Babel Standalone（浏览器内 JSX）
- 全部代码内联于 index.html，无外部 JSX 依赖
- 自定义光标高亮 + 点击涟漪
- 支持 prefers-reduced-motion 降级
- requestAnimationFrame 动画循环随页面可见性暂停

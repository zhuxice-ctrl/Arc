# 夜市美食地图 · 微信小程序

> 日期：2026-08-17 · 方向：V2 手机 UI · 形态：微信小程序 · 主题：夜市美食摊位发现

形态：微信小程序

## 简介

统一手机外壳内的 8 页夜市美食发现微信小程序。带胶囊按钮的自定义导航栏，底部 5 个 TabBar，夜色炭黑底 + 灯笼暖橙主调 + 辣椒红辅助的烟火气配色。含首页瀑布卡片流、分类吸顶筛选、摊位详情吸底操作栏、夜市平面图地图、左滑收藏列表、个人中心宫格，附设计规范页与接口文档页。

## 动效亮点

- 灯笼摇曳（4 盏灯笼节奏错开摆动）
- 热气升腾（食物图片上方蒸汽粒子上浮消散）
- TabBar 选中弹跳缩放 + 发光
- 辣椒图标跳动（热销标签）
- 霓虹闪烁（地图页标记点）
- 悬浮操作球上下浮动
- 页面栈 push/pop 滑动过渡
- 自定义光标（白色粗环 + 暖橙内点）

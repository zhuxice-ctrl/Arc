# 设计规范 · 夜市美食地图 · 微信小程序

> 方向：手机 UI（V2） · 日期：2026-08-17 · 形态：微信小程序 · 主题：夜市美食摊位发现

形态：微信小程序

## 色彩系统

夜市烟火气配色，夜色炭黑底 + 灯笼暖橙主调 + 辣椒红辅助 + 芝麻白正文 + 葱绿状态色。每页有不同色彩主角。

| 角色 | 色值 | 用途 |
|------|------|------|
| 主背景 | #1a1815 | 夜色炭黑，全站底色 |
| 主强调 | #ff9a3c | 灯笼暖橙，按钮/价格/徽标 |
| 辅助强调 | #d63a2a | 辣椒红，热销/删除/重要标记 |
| 正文色 | #f5f0e0 | 芝麻白，主要文字 |
| 状态色 | #7aba4a | 葱绿，营业中/评分绿点 |
| 深底色 | #0d0c0a | 更深层次背景 |
| 浅橙 | #ffb066 | 灯笼浅色变体 |
| 深红 | #b8291e | 辣椒深色变体 |
| 深绿 | #5a9430 | 葱绿深色变体 |
| 暖白 | #e8e0c8 | 次要文字 |
| 金色 | #e8b94c | 评分星星/装饰 |
| 深炭 | #221f1a | 卡片底色 |

## 字体系统

- 标题：`"PingFang SC", "Noto Sans SC", sans-serif` — 苹方无衬线，清晰有力
- 正文：`"PingFang SC", "Helvetica Neue", sans-serif`
- 数字：`"DIN Alternate", "Helvetica Neue", sans-serif` — 数字略带工业感

## 圆角与间距

- 卡片圆角：12px
- 按钮圆角：8px（吸底主按钮 24px 胶囊）
- 图片圆角：8px
- 标签圆角：4px
- 间距体系：4px / 8px / 12px / 16px / 24px / 32px

## 页面结构（8 页）

1. **首页** — Hero 大图瀑布卡片流 + 热门夜市横滑卡片 + 悬浮操作球
2. **分类页** — 吸顶 Tab 筛选 + 大小错落分类网格（含宽卡穿插）
3. **详情页** — Hero 大图 + 菜品列表 + 底部吸底操作栏 + 灯笼摇曳
4. **地图页** — 夜市平面图风格 SVG + 气泡标记 + 底部半屏抽屉面板
5. **收藏页** — 左滑删除操作列表
6. **个人中心** — 头像 Hero + 宫格菜单（4 列）+ 数据卡
7. **设计规范页** — 配色色板 + 字体排印 + 组件/圆角/间距展示
8. **接口文档页** — Tab 筛选 + 手风琴展开式接口列表 + 响应示例

## 技术栈

- React + Babel（JSX 全部内联在 script type="text/babel" 中）
- CSS 内联在 style 标签中
- 零外部 JSX/CSS 文件引用
- 支持 prefers-reduced-motion 降级
- rAF 随页面可见性自动暂停

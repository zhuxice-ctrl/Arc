# 设计规范 · 发酵实验室 Fermentary

> 方向：手机应用 UI（V2） · 日期：2026-08-16 · 形态：统一手机外壳内多页 App

## 主题
面包与发酵爱好者的时间管理 App：发酵批次（酸种面包 / 康普茶 / 味噌 / 精酿）列表与详情、发酵时间线倒计时、新建批次流程、风味笔记、探索、我的，另含设计规范页与接口文档页。围绕酵母活性 / 气泡上升 / 面团膨胀 / 温度曲线组织动效语义。

## 色彩系统

| 角色 | 色值 | 用途 |
|------|------|------|
| 奶白 | `#F7F2E9` | 浅模式底色 / 主文字（深模式为背景暖黑） |
| 深可可黑 | `#2B1D16` | 深模式底色 / 强对比 |
| 黄油暖黄 | `#D9A441` | 主强调（倒计时环 / 光标内点 / 高亮） |
| 焦糖棕 | `#B87333` | 辅助强调 / 阶段色 |
| 暖黑底 | `#1A130E` → `#070504` | 深模式舞台径向渐变 |

Tweaks 面板可切换 butter / cream / cocoa / accent 四色、深浅模式。配色禁用蓝紫渐变。

## 字体

- 衬线展示：`Fraunces`（optical-sizing，发酵手作质感）
- 正文：`Inter`
- 数据 / 计时：`JetBrains Mono`

## 页面结构（8 页）

1. **首页** — 发酵批次列表 + Hero 倒计时卡
2. **批次详情** — 倒计时环 + 温度曲线 + 阶段时间线
3. **新建批次** — 4 步流程
4. **风味笔记** — 笔记列表与编辑
5. **探索** — 配方灵感
6. **我的** — 统计与收藏（内含进入设计规范页 / 接口文档页入口）
7. **设计规范页**
8. **接口文档页**

另含 **Tweaks 调参面板**：黄油色 / 焦糖棕 / 奶白可可色切换、面团呼吸幅度、气泡活性倍率、整体速度、深浅模式。

## 动效系统（12+ 组件级特效）

- CO₂ 气泡上升（Canvas 粒子，速度随发酵活跃度变化）
- 面团呼吸膨胀（SVG Catmull-Rom 贝塞尔变形，模拟酵母产气）
- 环形倒计时 + 数字滚动
- 自定义光标（白环 + 黄油色内点 + 多层发光 + 涟漪点击反馈，mix-blend-mode difference）
- 页面转场（模糊 + 位移 + 弹簧缓动）
- 滚动渐入（IntersectionObserver）
- 光泽扫过 shimmer
- 按钮涟漪、卡片悬浮态、Tab 弹性缩放
- 温度点呼吸脉冲、进度条发光、酵母爆裂动效

动效基于物理模型（弹簧 / 阻尼 / RAF 积分器）与主题语义（气泡上浮随活跃度 / 面团随温度膨胀）。

## 健壮性

- 所有 RAF / 定时器随 `visibilitychange` 暂停、卸载取消
- 高频 mousemove 直接操作 DOM transform，不走 React setState
- `prefers-reduced-motion` 全量降级
- 触摸设备禁用自定义光标
- 零未定义引用、零外部图片依赖

## 技术栈

React 18（CDN UMD）+ Babel Standalone + 纯 CSS。无构建步骤，`index.html` 直接打开即可运行（需公网 CDN）。

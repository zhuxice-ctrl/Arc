# 山径·徒步路线社区 — 设计规范

> 日期：2026-08-17 · 方向：V2 手机 UI · 形态：原生 App · 主题：徒步与山野路线社区

## 色彩系统

| 角色 | 色值 | 用途 |
|------|------|------|
| 苔原绿 | `#3D5A45` | 主色、TabBar 选中、主按钮 |
| 岩壁灰 | `#5A5A58` | 次要文字、边框 |
| 暖曦橙 | `#E8963C` | 强调、进度、FAB |
| 雾米白 | `#F2EFE7` | 浅色页面底 |
| 深炭黑 | `#26261F` | 深色模式底 |
| 辅助 | `#E8EFEA` / `#D9C9A8` / `#F2B060` | 表面色、卡片、渐变 |

每页有独立色彩主角：首页偏雾米白+暖曦橙、轨迹记录页深炭黑+荧光绿、成就页深炭黑+金，整体统一在山野自然调内。禁止蓝紫渐变。

## 字体

- 全局：`'Noto Sans SC', -apple-system, BlinkMacSystemFont, sans-serif`

## 圆角与间距

- 卡片圆角：12–16px
- 手机外壳圆角：48px
- 安全区底部按钮：吸底 16px 圆角

## 组件

- 手机外壳：iOS 风格统一外壳 + 状态栏 + 底部 TabBar
- 底部 TabBar：5 项原生质感，选中态缩放高亮
- Hero 大图 + 视差滚动
- 瀑布流卡片 / 网格拼贴 / 对角分割 Hero / 轮播画廊 / 底部半屏抽屉 / FAB 悬浮球
- 环形进度（SVG 描边动画）
- 高程剖面 SVG

## 原生端侧交互（>4 种）

底部 TabBar、返回栈导航（右滑入/出）、底部半屏抽屉模态、长按快捷菜单、下拉刷新、FAB 悬浮操作球、大标题导航栏、卡片式信息流。

## 动效系统（12+ 项）

1. 自定义光标（白环 + 暖曦橙内点 + 发光，悬停 1.6×，点击涟漪，mix-blend-mode: difference）
2. 首页入场序列（卡片 fade-up 分级 delay）
3. 下拉弹性回弹刷新
4. 详情页视差滚动 + 环形进度实时填充
5. 点赞弹跳
6. Tab 缩放高亮
7. 按钮脉冲涟漪
8. 进度条缓动
9. 勾选圆弹出
10. FAB 扩散脉冲环
11. 导航栏滚动渐显
12. 卡片 colorbar 过渡

物理逻辑：下拉弹性用弹簧阻尼；FAB 脉冲用 RAF 积分扩散；环形进度 SVG stroke-dashoffset 缓动。

## 页面结构（8 页）

1. 首页（发现）— Hero + 瀑布流 + 下拉刷新
2. 路线详情 — 视差 Hero + 半屏抽屉 + 环形完成度 + 高程剖面
3. 轨迹记录 — 深色模式 + FAB + 脉冲环 + 实时数据
4. 社区动态 — 卡片流 + 长按快捷菜单 + 点赞
5. 装备清单 — 对角分割 Hero + 网格拼贴 + 勾选
6. 我的成就 — 深色 + 轮播勋章 + 等级环形进度 + 三宫格
7. 设计规范页 — 色彩/字体/间距/组件/动效
8. 接口文档页 — 左右分栏，5 组 RESTful API

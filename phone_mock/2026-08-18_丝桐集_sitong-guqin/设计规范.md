# 丝桐集 · 设计规范

形态：微信小程序

> 日期：2026-08-18 · 方向：V2 手机 UI · 形态：微信小程序 · 主题：古琴学习与雅集预约小程序

## 色彩系统

宣纸米白为底，紫檀深棕 + 黛青 + 朱砂点缀，呼应古琴雅集的东方文人语义。禁蓝紫渐变。

| 色值 | 用途 |
|---|---|
| `#FAF6EE` / `#F4EDE0` / `#EDE4D1` / `#D9CEBC` | 宣纸米白多层（背景/表面/分隔） |
| `#5C3A21` / `#3D2614` / `#2B241D` | 紫檀深棕（主文字/导航/重点） |
| `#2D4A47` / `#1A302E` / `#4A6B68` | 黛青（辅助/次级强调） |
| `#C23B22` / `#8B2815` / `#E35A3F` | 朱砂（主操作/活动标记/价格） |
| `#C9B896` / `#B8A888` / `#9B8E7E` / `#8B5A2B` / `#5A4E42` | 木色中性（边框/图标/次要文字） |
| `#b8d4cf` | 黛青淡调（徽章背景） |

## 字体排印

- 标题：`'Noto Serif SC', serif`（衬线，文人气质）
- 正文：`'Noto Sans SC', -apple-system, BlinkMacSystemFont, sans-serif`
- 等宽：`monospace`（接口文档/代码）

## 圆角

`10px / 12px / 16px / 20px / 22px / 20px 20px 0 0`，温润柔和，卡片多用 16-22px。

## 小程序端侧交互（≥4 种）

胶囊按钮导航栏、页面栈 push/pop 转场、底部 TabBar（选中弹跳）、半屏 ActionSheet、下拉刷新弹性、左滑列表操作、吸顶 Tab、骨架屏样式。

## 动效系统

基于物理模型（弹簧跟随、阻尼）与主题语义（琴弦振动、徽位淡入、墨迹涟漪、减字谱展开）。组件级特效 12+：琴弦振动（3 组不同相位）、徽位淡入、页面转场、Tab 弹跳、环形练琴进度、点赞心跳、视差滚动、瀑布流入场序列、墨迹涟漪光标、下拉弹性、减字谱悬停、卡片悬浮。各动效周期互不相同，禁 Ken Burns。

## 页面结构（8 页）

1. 首页 — Hero 琴弦振动 + 快捷宫格 + 今日一曲 + 名师横滑 + 雅集预告
2. 琴课页 — 吸顶分类 Tab + 课程网格 + 下拉刷新（琴弦式）
3. 雅集页 — Hero 视差 + 月历选日 + 雅集列表
4. 琴谱页 — 搜索栏 + 分类标签横滑 + 瀑布流琴谱卡
5. 琴友社区 — 话题 Banner + 三 Tab + 动态流（点赞心跳）
6. 个人琴斋 — 深色 Hero + 环形进度 + 功能宫格 + 左滑列表
7. 设计规范页 — 色彩/字体/组件/减字谱/动效
8. 接口文档页 — 接口列表/数据模型/错误码三 Tab + 代码高亮

签名动效：首页入场序列、雅集页视差滚动、个人页环形进度。

## 布局多样性

8 页中至少 5 页采用非重复布局：宫格+横滑卡片、吸顶 Tab+网格、视差 Hero+月历、瀑布流、深色 Hero+环形进度宫格。

## 健壮性

JSX 内联于 `<script type="text/babel">`；`visibilitychange` 暂停 RAF/定时器；快速操作先 clearTimeout 旧定时器；高频鼠标事件直接操作 DOM transform；`prefers-reduced-motion` 降级。

## 技术栈

React 18 + Babel standalone（CDN：react.production.min / react-dom.production.min / babel.min，均内联于 index.html 的 `<script>` 标签），纯前端无后端。

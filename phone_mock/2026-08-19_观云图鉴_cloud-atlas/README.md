# 观云图鉴 · 天空手记

V2 手机 UI · 原生 App mock · 2026-08-19

## 概述

抬头看云的人随身携带的野外气象手册。拖对流层剖面高度尺认云 → 读云属详情 → 记录今日天空 → 积累个人天象档案。

## 形态

原生 App（自定义导航栏、底部 TabBar、页面栈 push/pop、半屏详情）。

## 页面结构

- **今日** — 今日天空概览、今日可见云属、观测状态卡片、最近记录
- **认云** — 对流层剖面高度尺（核心签名交互）、云族云属列表
- **档案** — 观测统计、时间线记录、空状态
- **关于** — App 信息、设置入口、设计规范入口、接口文档入口
- **云属详情页**（push）— 云形大图、高度带/云族/缩写、形态/天气预兆/辨认要点
- **记录天空页**（push）— 云属、日期时间、地点、备注
- **设计规范页**（push）— 色彩系统、字体排印、间距系统、组件规范、交互语言
- **接口文档页**（push）— 云属数据、观测记录、统计数据接口

## 核心交互

在 0–12km 对流层垂直剖面上拖动高度游标：
- 拖动时高度读数实时变化，游标线划过云层
- 经过云族高度带时云族区域高亮，下方云属列表切换
- 松手后游标阻尼吸附到该云族中心，伴随弹性定格
- 层内云形以水彩笔触晕染显形

## 签名时刻

高度游标松手吸附入层的瞬间：游标弹性定格、剖面该层云形水彩晕染显形、云属名以衬线大字浮现——"原来这叫鬃积雨云"。

## 技术说明

- 单文件 vanilla HTML/CSS/JS，无框架、无外部依赖
- 目标尺寸：390×844（iPhone 14 规格）
- localStorage 持久化观测记录
- 页面可见性变化时暂停定时器与 RAF
- 支持 `prefers-reduced-motion`
- 零未定义引用

## 数据

国际云图十云属：
- 低云族：积云 Cu、积雨云 Cb、层云 St、层积云 Sc、雨层云 Ns
- 中云族：高积云 Ac、高层云 As
- 高云族：卷云 Ci、卷积云 Cc、卷层云 Cs

# 节气厨房 · 设计规范

## 色彩系统

| 角色 | 色值 | 用途 |
|------|------|------|
| 主色·陶土橙 | #c8704d | 主按钮、选中态、品牌色 |
| 辅助色·鼠尾草绿 | #7a9460 | 标签、成功态、食材分类 |
| 背景色·暖奶白 | #f8f3e9 | 页面主背景 |
| 文字色·深炭灰 | #3d3530 | 主文字 |
| 强调色·蜜糖金 | #d4a04a | 评分、强调点缀 |

| 浅绿 | #8cae6f | 辅助标签 |

## 字体

- 标题：衬线体（思源宋体 / Noto Serif SC）
- 正文：无衬线体（思源黑体 / Noto Sans SC）

## 页面结构（8 页）

1. **首页（处暑）** — Hero 节气大卡片 + 推荐食谱横滑卡流 + 养生贴士 + 透明→吸顶导航栏
2. **节气食谱列表** — 吸顶 Tab（全/早/午/晚/甜品）+ 瀑布流卡片 + 骨架屏 + 下拉弹性刷新
3. **食谱详情** — 大图视差 Hero + 食材清单 + 可展开步骤卡 + 吸底操作栏
4. **食材百科** — 3×3 宫格当季食材 + 左滑操作 + 半屏弹层详情
5. **个人中心** — 渐变头像区 + 环形进度统计 + 数字计数 + 功能宫格
6. **设计规范** — 色彩系统、字体排版、组件样例
7. **接口文档** — 5 个 API 契约 + JSON 响应示例
8. **设置/关于** — 分组设置列表 + 开关控件

## 微信小程序端侧交互

- 胶囊按钮导航栏（右上角"··· / ⊙"）
- 页面栈 push/pop 切换（右滑返回手势感）
- 底部 TabBar（选中态微动效）
- 半屏弹层 / ActionSheet 动作面板
- 下拉刷新弹性回弹
- 左滑列表操作
- 吸顶 Tab
- 骨架屏加载

## 组件规范

- 卡片圆角：12px
- 按钮圆角：8px
- TabBar 高度：56px
- 安全区底部留白：34px

## 动效系统

| 序号 | 动效名称 | 实现方式 |
|------|---------|---------|
| 1 | 自定义光标 | 白环+陶土橙内点+发光 |
| 2 | TabBar 选中弹跳 | CSS transform scale |
| 3 | 页面右滑 push/pop 过渡 | transform translateX |
| 4 | 卡片悬浮发光 | box-shadow hover |
| 5 | 下拉刷新弹性回弹 | 弹簧物理模型 |
| 6 | 骨架屏 shimmer | CSS gradient animation |
| 7 | 环形进度条 | SVG stroke-dashoffset |
| 8 | 数字计数动画 | RAF counter |
| 9 | 半屏弹层滑入 | transform translateY |
| 10 | 左滑操作揭示 | transform translateX |
| 11 | 涟漪点击 | CSS animation ripple |
| 12 | 节气卡片入场序列 | CSS animation delay |

## 签名动效

- 首页入场序列：节气卡片依次淡入上浮
- 详情页视差滚动：大图随滚动缩放

## 健壮性

- requestAnimationFrame/定时器随 visibilitychange 暂停
- 快速操作不叠加定时器
- 支持 prefers-reduced-motion
- 所有 JSX 内联在 index.html 中

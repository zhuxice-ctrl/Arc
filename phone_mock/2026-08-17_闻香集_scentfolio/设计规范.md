# 闻香集 Scentfolio · 设计规范

> 方向：V2 手机 UI ｜ 日期：2026-08-17 ｜ 形态：原生 App ｜ 主题：香道线香收藏与品香记录

## 色彩系统

| 角色 | 色值 | 用途 |
|------|------|------|
| 主色·烟熏乌木 | `#2B2118` | 深色底、导航、页脚区 |
| 主色·檀红 | `#A63D2F` | 主强调、评分、关键 CTA |
| 表面·香灰白 | `#E8E2D6` / `#F5F1E8` | 页面背景、卡片表面 |
| 点缀·金箔 | `#C9A24B` | 等级、徽标、次级强调 |
| 辅助·青竹 | `#6B8E6E` | 香会页色彩主角（偏冷页） |
| 辅助·檀红亮阶 | `#C0472A` | 悬停 / 高亮过渡 |
| 辅助·暖橙 | `#E07A3C` | 余烬、火星明灭动效 |
| 中性·深木层次 | `#3A2E24` / `#241A10` / `#1E170F` | 深色区内部层次 |
| 中性·木灰 | `#5A4A3C` | 次级文字、边框 |

约束：无蓝紫渐变；每页 3-5 个色调层次；香会页以青竹为「色彩主角」偏冷，品香录偏暖金，藏香阁低饱和纸色。

## 字体

- 无衬线：`"Noto Sans SC", -apple-system, "PingFang SC", system-ui, sans-serif`
- 衬线（展示 / 香品名）：`"Noto Serif SC", "Songti SC", "Source Han Serif SC", serif`

## 页面结构（统一 iOS 手机外壳内 8 页可切换）

1. 首页：Hero 青烟粒子签名动效 + 今日推荐 + 横滑品香 / 香会入口
2. 藏香阁：瀑布流双列网格 + 分类筛选芯片 + 下拉刷新 + FAB（布局：瀑布流）
3. 品香录：香气雷达环形签名动效 + 评分记录卡 + 数据统计面板（布局：数据面板）
4. 香会：大色块 Hero + 青竹色系活动卡 + 参与者头像堆叠（布局：Hero 大图）
5. 我的：用户资料 + 等级进度条 + 分组菜单（布局：资料+宫格）
6. 香品详情：全屏转场 + 浮动香体 + 前/中/尾调进度条 + 雷达大图（布局：全屏详情）
7. 设计规范页：Tab 分栏（色彩/字体/间距/组件）+ 色阶/圆角/阴影标本
8. 接口文档页：可折叠 API 列表 + JSON 语法高亮

原生交互（7 种）：底部 TabBar、返回栈导航、大标题导航栏、长按底部半屏抽屉、FAB 悬浮按钮、下拉刷新、模态 Toast。

## 动效系统（12+ 组件级）

- 页面级签名动效 ×2：①首页青烟粒子 Canvas 袅袅升起（25+ 粒子，独立周期/相位/摆动）；②品香录香气雷达环（描边动画 + 数据多边形）
- 余烬闪烁（火星明灭）、FAB 脉冲光环、大 Hero 漂浮
- 香调进度条错峰入场、卡片按压缩放、Tab 切换点光
- 自定义光标：白环 + 金箔内点 + 多层发光，开页居中，悬停放大，点击涟漪
- 底部抽屉滑入、下拉刷新旋转器、Toast 弹入、特色卡自动轮播

## 健壮性

- RAF 随 `visibilitychange` 暂停、卸载统一取消定时器 / RAF
- 高频指针事件直接操作 DOM transform，不触发 React 重渲染
- `prefers-reduced-motion` 禁用装饰性动画
- 全部 JSX 内联于单文件 `<script type="text/babel">`，无外部 src 引用

## 技术栈

单文件 HTML + 内联 JSX（React via Babel standalone），Canvas 粒子，无外部图片依赖。

# 设计规范 · 骑迹 VeloRoute · 骑行路线 App

> 方向：手机 UI（V2） · 日期：2026-08-17 · 形态：原生 App · 主题：骑行路线与记录

## 字体栈

- UI 字体：`'Inter', -apple-system, 'SF Pro', system-ui, sans-serif`
- 标题字体：`'Space Grotesk', sans-serif`
- 等宽（数据/代码）：`'JetBrains Mono', monospace`

## 原生交互（≥4 种）

底部 TabBar（中央 FAB 凸起）、返回栈导航、模态全屏弹窗、下拉刷新、毛玻璃导航、长按弹性卡片。

## 页面结构（8 页，≥5 独特布局）

1. 发现首页 — Hero 大图 + 搜索 + 分类胶囊 + 路线卡片堆叠（入场序列动效）
2. 路线详情 — 全屏深色转场 + 滚动视差缩放 + 海拔剖面 + 底部行动栏
3. 骑行记录 — 实时计时器 + 数据网格 + 地图轨迹动画 + FAB 控件
4. 装备库 — 对角分割 Hero + 精选大卡 + 双列网格
5. 骑行圈 — 瀑布流双列 + 下拉刷新弹性 + Tab 切换
6. 个人主页 — 渐变封面 + 环形进度 + 数据卡片 + 功能列表
7. 设计规范页 — 色彩/字体/按钮/间距/圆角/阴影
8. API 文档页 — 暗色代码风 + 三分类 Tab + 接口参数表

## 动效系统（12+ 组件级）

自定义光标（白环+橙点+发光+涟漪）、入场序列错峰、滚动视差缩放、环形进度动画、实时计时器/速度变化、地图路径描绘、脉冲指示器、按钮悬停弹性缩放、Tab 下划线过渡、FAB 发光、下拉刷新旋转器、卡片悬浮抬升。

## 健壮性

JSX/CSS 全内联；prefers-reduced-motion 降级；visibilitychange 自动暂停 RAF；定时器清理；鼠标事件直接操作 DOM transform。

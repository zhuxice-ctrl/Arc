## 动效系统

| # | 动效 | 物理/语义 |
|---|------|-----------|
| 1 | TabBar 切换选中态 | 图标弹跳 + 颜色过渡 |
| 2 | 卡片入场序列 | 依次淡入上浮（stagger delay） |
| 3 | 下拉刷新弹性回弹 | spring 物理模型 |
| 4 | 左滑操作露出按钮 | 阻尼滑动 |
| 5 | 详情页 Hero 视差 | scroll-driven transform |
| 6 | 骨架屏加载 | 闪烁动画 |
| 7 | 头像呼吸脉冲 | 周期性 scale |
| 8 | 按钮点击涟漪 | 涟漪扩散 |
| 9 | Tab 指示器跟随 | 手势跟随滑动 |
| 10 | 卡片 hover 阴影 | 阴影变化 |
| 11 | 数字计数动画 | 缓动 |
| 12 | 页面转场过渡 | push 滑入 / pop 滑出 |

## 端侧交互语言（微信小程序）

1. 页面栈 push/pop 切换（右滑返回手势感）
2. 底部 TabBar（4 项：首页/广场/消息/我的，选中态微动效）
3. 半屏弹层 / ActionSheet 动作面板
4. 下拉刷新弹性回弹
5. 左滑列表操作（收藏/举报）
6. 吸顶 Tab 筛选

## 页面结构（8 页）

1. **首页** — 公告横幅 + 分类宫格 + 瀑布流卡片
2. **广场页** — 吸顶 Tab 筛选 + 列表 + 左滑操作
3. **物品详情页** — Hero 大图 + 信息 + 底部吸底操作栏
4. **发布页** — 表单分区 + 底部安全区主按钮
5. **消息页** — 对话列表 + 骨架屏
6. **个人中心** — 头像 + 宫格入口 + 我的发布
7. **设计规范页** — 色彩/字体/组件规范
8. **接口文档页** — API 列表与请求/响应示例

## 签名动效

- 首页入场序列动画（卡片依次淡入上浮）
- 详情页 Hero 视差滚动（图片随滚动缩放）
- 下拉刷新弹性回弹（spring 物理模型）

## 健壮性

- RAF/定时器随 `visibilitychange` 暂停、卸载取消
- 快速操作不叠加定时器
- 支持 `prefers-reduced-motion` 降级
- 所有 JSX 内联在 `<script type="text/babel">`，CSS 内联在 `<style>`

## 技术栈

React（CDN Babel standalone）+ HTML + CSS，单文件 `index.html`

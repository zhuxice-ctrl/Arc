# 设计规范 · 旅行打包手账

形态：微信小程序

---

## 一、设计母题

旧行李箱贴纸墙 + 登机牌 + 行李标签。整个界面像在收拾一只贴满旅行贴纸的旧行李箱：物品是贴纸，装箱是把贴纸贴进箱子，封箱是拉上拉链，完成是登机牌「READY TO GO」弹出。视觉来源是旅行手账与机场行李托运的实物语言。

## 二、色彩系统（Design Tokens）

| Token | 色值 | 用途 |
|-------|------|------|
| `--kraft` | `#C8A06A` | 牛皮纸暖棕，行李标签主色 |
| `--sticker` | `#E8842A` | 贴纸明橙，主操作 / 强调 / 封箱按钮 |
| `--ink-teal` | `#2E6B7A` | 登机牌墨青，次级强调 / 标签描边 |
| `--cream` | `#FAF6EE` | 奶白底，页面背景 |
| `--cream-2` | `#F3EAD7` | 奶白次，卡片 / 分区底 |
| `--vermilion` | `#C8423B` | 警示朱红，必带物品 / 危险操作 |
| `--pine` | `#5B9A6A` | 进度松绿，已装箱 / 完成态 |
| `--ink` | `#3B2E1E` | 墨褐，主文字 |
| `--ink-2` | `#6B5A46` | 次级文字 |
| `--ink-3` | `#A89882` | 弱化文字 |
| `--line` | `#E6D9C2` | 分割线 |

色彩逻辑：暖橙主导操作，墨青承担登机牌/标签语义，松绿=完成、朱红=必带警示、牛皮纸棕=标签容器。明亮、非蓝紫渐变，与近期米纸墨朱 / 暖棕陶土系拉开。

## 四、尺寸与间距

- 手机舞台：`390 × 844`（兼容 414）
- 状态栏 `--status-h: 20px`
- 自定义导航栏 `--nav-h: 44px`
- 胶囊按钮 `--capsule-h: 32px`
- 底部 TabBar `--tab-h: 56px`
- 安全区底部 `--safe-bottom: 24px`
- 阴影三档：`--shadow-s` / `--shadow-m` / `--shadow-l`（统一基于墨褐 `rgba(59,46,30,*)`）

## 五、动效系统

| 动效 | 时长 / 曲线 | 语义 |
|------|------------|------|
| 物品飞入装箱 | `.5s / .6s cubic-bezier(.34,1.56,.64,1)` | 弹簧 overshoot，物品归位吸附 |
| 进度环填充 | `stroke-dashoffset .5s / .6s cubic-bezier(.2,.8,.2,1)` | 装箱进度连续增长 |
| 拉链封箱 | `left .7s cubic-bezier(.4,0,.2,1)` 700ms | 拉链头从左滑到右，箱子合拢 |
| 登机牌弹出 | `transform .25s cubic-bezier(.2,.8,.2,1)` | READY TO GO 出场 |
| Tab 页面栈横滑 | `transform .32s cubic-bezier(.2,.8,.2,1)` | push/pop 转场 |
| 下拉刷新 | `top .25s cubic-bezier(.2,.8,.2,1)` | 弹性回弹 |
| 左滑操作 | `transform .25s cubic-bezier(.2,.8,.2,1)` | 列表项露出操作 |
| 物品 hover/active | `.15s / .2s` | 即时反馈 |
| 半屏弹层 | `transform .32s / opacity .25s` | ActionSheet 升起 |

动效原则：功能优先、克制；弹簧曲线仅用于弹性反馈（装箱吸附），阻尼曲线用于进度/转场；禁止 Ken Burns / 整图缩放 / 无意义发光。全部支持 `prefers-reduced-motion`（`transition: none !important` 降级）。

## 六、端侧交互语言（微信小程序）

1. 自定义导航栏 + 右上胶囊按钮
2. 底部 TabBar（4 Tab，带红点提示）
3. 页面栈 push/pop 横滑转场（非 active 页 `translateX(390)` 屏外，`overflow:hidden` 裁切）
4. 半屏弹层 ActionSheet（物品详情、数量调整）
5. 下拉刷新弹性回弹（4 Tab 均支持）
6. 左滑操作（清单项左滑删除/编辑）
7. 吸底操作按钮（封箱出门）

## 七、组件库

- 行程进度环（SVG stroke-dashoffset）
- 场景卡片（6 种：出差 / 海岛度假 / 露营 / 回国探亲 / 亲子游 / 短途周末）
- 物品贴纸（贴纸墙式清单，6 分类：证件 / 电子 / 洗护 / 衣物 / 药品 / 专项）
- 行李箱装载区（拖拽落点 + 进度环）
- 封箱拉链动画（拉链头 + 箱体 open/closed + 登机牌）
- 模板卡（内置场景 + 自建模板，空状态引导）
- 设计规范页 / 接口文档页（二级页，真实色值 / 字体 / 动效 / REST API 端点）

## 八、技术栈

纯 vanilla 单文件 HTML（无 React / 无 Babel / 无 CDN / 无外部图片 / 无外部字体文件）。所有样式与脚本内联。localStorage 持久化当前行程进度、自建模板、已完成行程。RAF / 定时器随 `visibilitychange` 暂停且卸载取消，支持 `prefers-reduced-motion`。

接口文档
GET /api/trip/scenarios
获取内置旅行场景列表，包含场景名称、图标及默认物品清单。
返回示例
// 200 OK { "code": 0, "data": [ { "id": "island", "name": "海岛度假", "icon": "umbrella", "days": "5天4晚", "itemsCount": 28 } ] }
POST /api/trip/create
选择场景后生成当前行程，返回完整物品清单。
请求体
{ "scenarioId": "island", "tripName": "三亚度假", "days": 5 }
返回示例
// 200 OK { "code": 0, "data": { "tripId": "trip_abc123", "scenario": "island", "items": [ { "id": "item_001", "name": "护照", "category": "证件", "quantity": 1, "packed": false } ] } }
POST /api/trip/pack
将物品标记为已装箱，返回更新后的进度。
请求体
{ "tripId": "trip_abc123", "itemId": "item_001", "packed": true }
返回示例
// 200 OK { "code": 0, "data": { "packedCount": 15, "totalCount": 28, "progress": 0.536 } }
POST /api/trip/seal
全部物品装箱后封箱，行程完成，记入历史。
返回示例
// 200 OK { "code": 0, "data": { "tripId": "trip_abc123", "status": "completed", "sealedAt": "2026-08-19T10:30:00Z", "boardingPass": { "flight": "CA1835", "seat": "22A", "gate": "B15" } } }
GET /api/templates
获取模板列表（内置 + 用户自建）。
返回示例
// 200 OK { "code": 0, "data": { "builtIn": [ ... ], "userTemplates": [ ... ] } }
POST /api/templates/save
将当前行程保存为自定义模板。
请求体
{ "name": "我的出差模板", "scenario": "business", "items": [...] }

# 设计规范 · 招领处（失物招领微信小程序）

## 一、设计理念

把线下社区失物招领处的「登记簿 + 对暗号认领 + 盖章归档」流程数字化。软木材质感的招领墙 + 米黄便签 + 墨绿印章，营造有温度、可信、有人情味的体验，区别于千篇一律的列表式 App。

## 二、色彩系统

| 色名 | 色值 | 用途 |
|------|------|------|
| 软木棕 | `#B8895A` | 招领墙背景、我的页头部，主材质底色 |
| 便签米黄 | `#F4E9C1` | 便签卡片、头像底、空状态图标 |
| 暖白 | `#F7F2E6` | 页面底色、弹窗底色 |
| 墨绿 | `#3E6B4F` | 主操作按钮、印章、标签文字、Tab 激活态 |
| 墨黑 | `#2A2620` | 正文文字、标题 |
| 赭 | `C2823A` | 便签钉、次强调、错误态、星标 |

**辅助色**：
- `#FFFDF8` 卡片底色
- `#928A7D` 次级文字
- `#6B6358` 描述文字
- `#CCC5B8` 占位文字 / 弱化分隔
- `rgba(42,38,32,.06)` 浅分隔线

**约束**：零红色、零蓝紫渐变。全色板围绕「木 + 纸 + 墨」三色展开。

## 四、核心组件规范

### 4.1 便签卡片（Note Card）
- 尺寸：宽度自适应，内边距 14px 16px
- 底色：`#F4E9C1`
- 阴影：`2px 3px 8px rgba(0,0,0,.18), inset 0 0 0 1px rgba(42,38,32,.05)`
- 倒角：2px（接近直角，模拟真实便签纸）
- 顶部图钉：12px 圆形 `#C2823A`，带内阴影高光
- 微旋：左右交替 `rotate(-1.2deg)` / `rotate(1deg)`
- 交互：按下 `scale(.98)`

### 4.2 墨绿印章（Stamp）
- 双层圆形：外虚线圆 + 内实线圆
- 文字：「已归还」主文 18px 宋体 900 字重 + 「招领处·验讫」副文 10px
- 颜色：`#3E6B4F` 不透明 92%
- 角度：`rotate(-15deg)`
- 动效：旋转下压（`cubic-bezier(.2,1.6,.4,1)`），带过冲回弹

### 4.3 软木墙（Cork Board）
- 底色：`#B8895A`
- 纹理：4 层不同大小的径向渐变圆点模拟软木颗粒
- 时间轴：左侧 2px 半透明白线 + 赭色节点圆点

### 4.4 半屏 ActionSheet（对暗号）
- 高度：最大 80% 屏高
- 顶部圆角：16px 16px 0 0
- 遮罩：`rgba(42,38,32,.5)` 250ms 淡入
- 升降：`translateY` 300ms `cubic-bezier(.25,.8,.25,1)`
- 进度点：4 个圆点，当前项拉长为 2 倍

### 4.5 微信小程序导航栏
- 高度：44px
- 胶囊按钮：右上 87×32px，半透明白底 + 毛玻璃，圆角 16px
- 标题：居中 17px 600
- 返回按钮：左侧圆形 32×32px

### 4.6 底部 TabBar
- 高度：56px
- 底色：`#FFFDF8`
- 图标 + 文字：22px 图标 + 10px 文字，间距 2px
- 激活态：`#3E6B4F` 墨绿
- 未激活：`#999185`

### 4.7 主按钮
- 高度：44px
- 圆角：22px（全圆角胶囊）
- 底色：`#3E6B4F`
- 文字：`#F7F2E6` 15px 600 字间距 1-2px
- 按下：`scale(.98)`

## 五、动效系统

| 动效 | 曲线/时长 | 用途 |
|------|-----------|------|
| 页面 push/pop | `cubic-bezier(.25,.8,.25,1)` 300ms | 页面栈切换 |
| ActionSheet 升降 | `cubic-bezier(.25,.8,.25,1)` 300ms | 半屏弹层 |
| 印章盖下 | `cubic-bezier(.2,1.6,.4,1)` 600ms | 核验通过签名记忆点 |
| 便签按下 | ease 150ms | 卡片点击反馈 |
| 按钮按下 | 100ms | 操作反馈 |
| 飞入档案 | 900ms ease-in 弧线 | 归还归档动效 |
| 错误抖动 | 400ms | 核验答错反馈 |
| 下拉刷新 | 阻尼 0.5 + 回弹 | 首页更新 |

**降级**：`prefers-reduced-motion: reduce` 时所有过渡/动画置为 none，直接显示终态。

## 六、端侧交互清单（7 种）

1. **自定义导航栏 + 胶囊占位**：所有页面右上角微信小程序胶囊
2. **底部 TabBar**：招领 / 寻物 / 我的 3 Tab
3. **页面栈 push/pop**：详情页、归还档案、登记页均为二级推入页面
4. **半屏 ActionSheet**：对暗号核验流程载体
5. **下拉刷新弹性**：招领页软木墙下拉刷新
6. **左滑删除**：寻物匹配列表左滑删除
7. **吸底操作栏**：物品详情页底部「我要认领」吸底按钮

## 七、信息架构

```
招领处
├─ 招领（Tab 1）
│  └─ 物品详情页
│     └─ 对暗号 ActionSheet（4 题核验）
│        └─ 盖章 → 飞入档案
├─ 寻物（Tab 2）
│  └─ 匹配列表（左滑删除）
│     └─ 去对暗号 → 物品详情
└─ 我的（Tab 3）
   ├─ 归还档案页
   ├─ 我发布的寻物
   └─ 认领进度
```

## 八、核心流程

**认领流程**：首页翻登记簿 → 点击便签进详情 → 点击「我要认领」→ 半屏 ActionSheet 升起 → 4 道对暗号题（颜色/品牌/标记/附带物）→ 答错抖动提示重试 → 全对 → 墨绿大章闪 + 便签盖章 → 便签飞入档案 → 详情按钮变为「已归还」→ 我的页找回率 +1。

**登记流程**：首页右上「登记捡到」→ 推入登记表单 → 填写物品信息 + 对暗号特征 → 发布 → 回首页，新便签上墙。

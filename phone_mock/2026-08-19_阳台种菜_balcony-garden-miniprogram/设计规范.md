# 设计规范 · 阳台种菜 · 都市农夫种植日历

> 类别：Phone Mock　|　日期：2026-08-19　|　Art Orchestrator batch14

形态：微信小程序

## 设计母题
阳台种菜日常管理小程序。每日打开花两分钟照看阳台作物：今日待办（浇水/施肥/采收）、作物档案、生长记录（拍照+笔记）、种植日历提醒。完整 user flow：打开→今日待办→作物详情→记录生长→生长时间轴→日历提醒。

## 产品机制
核心功能=每日照看（今日待办清单）。辅助=作物档案、生长记录、种植日历。3-4 个功能做深，无社区 feed / 关注点赞。

## 空间模型
任务驱动 + 作物详情页面栈 + 日历（task_today_crop_detail_pagestack_calendar）。4 Tab：今日 / 菜园 / 日历 / 我的。

## 微信小程序端侧交互语言（≥4 种，真实可用）
1. 顶部右上角小程序胶囊按钮（≡ 更多 + ⊙ 关闭）+ 自定义导航栏容器
2. 页面栈 push/pop（进作物详情有进入动画、返回箭头与返回动画）
3. 底部 TabBar（今日/菜园/日历/我的）
4. 半屏弹层 ActionSheet（"记录生长"从底部升起）
5. 下拉刷新弹性回弹
6. 列表左滑出现操作（左滑作物"标记完成"）
7. 吸底操作栏（详情页底部固定操作按钮）

## 字体
系统无衬线（-apple-system / PingFang SC / 雅黑 / Source Han Sans）。圆润无衬线标题，等宽数字。无外部字体。

## 材质语言
红陶土花盆 + 麻绳 + 牛皮纸标签 + 瓷白底。作物图标为简约 SVG 线稿。

## 签名动效
拖动浇水壶给作物浇水——按住浇水壶拖动，壶口倾斜流出水滴（粒子），水滴落入花盆土壤，浇水进度条上涨，浇满时作物轻微"舒展"放大反馈，对应浇水待办自动标记完成 + toast 确认。服务产品的核心交互记忆点。

## 动效系统（≥12 组件级特效）
浇水壶倾斜出水/水滴粒子/进度上涨/作物舒展、Tab 切换连续、页面栈 push/pop 过渡、ActionSheet 升起、下拉刷新弹性、左滑操作、待办勾选反馈、时间轴节点冒芽、日历日期点标记、天气卡渐变、列表 stagger 进入。均服务产品状态变化，非炫技。RAF 随可见性暂停，卸载取消；支持 prefers-reduced-motion。

## 自定义光标
圆形触摸点光标（模拟手指），开页居中于手机容器内，高对比层级最高；拖动浇水壶时光标变形贴合；reduced-motion 降级。

## 内容真实性
作物真实（樱桃番茄/罗勒/小辣椒/薄荷/香葱/生菜），待办真实可信（浇水 200ml/掐尖保留 2-3 对叶/采收红透 3 颗/施加稀释液肥），笔记真实口语。无 Lorem Ipsum / Item 01。

## 工程边界
单 HTML 纯 vanilla，390×844 手机容器居中展示（外层淡背景+作品名标注），所有视觉内联 SVG，无外部图片/CDN。Console 无严重 Error，零未定义引用。

# 汐时 Tidemark

> 日期：2026-08-17　方向：V2 手机 UI
> **形态：原生 App**（与上一次「微信小程序」交替）

赶海潮汐助手原生 App——统一手机外壳内 8 页可切换。围绕赶海活动组织真实可信内容：今日潮汐曲线、最佳赶海时段、滩涂生物图鉴（蛏子 / 花蛤 / 石蟹 / 海螺 / 海星 / 海参 / 章鱼）、赶海日记、附近赶海点、潮位预警、个人中心，另含设计规范页与接口文档页。

## 截图

![汐时预览](./preview.png)

## 动效亮点

潮汐曲线波动（多层正弦叠加）、详情页视差滚动、自定义光标（白粗环 + 珊瑚内点 + 发光）、数字计数、头像脉冲光环、定位针弹跳、FAB 悬停旋转、Shimmer 光泽扫过、波浪粒子气泡上浮、Tab 指示器弹性，共 12+ 组件级特效。签名动效：首页潮汐曲线、详情页视差。

## 原生端侧交互

底部 TabBar、模态半屏抽屉（潮位预警）、全屏详情转场、悬浮操作按钮 FAB、返回栈导航、下拉刷新。

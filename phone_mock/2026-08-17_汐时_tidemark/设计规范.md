## 字体

- `'DM Serif Display', serif` — 大标题展示字
- `'Noto Serif SC', serif` — 中文衬线标题
- `'Noto Sans SC', -apple-system, BlinkMacSystemFont, sans-serif` — 正文
- `'JetBrains Mono', monospace` — 数据 / 潮位数字 / 接口代码

## 圆角

`10px / 12px / 14px / 16px / 18px / 20px` 分级圆角；胶囊 `999px`；局部 `1px`。

## 页面结构（统一手机外壳内 8 页切换）

1. 首页·今日潮汐 — 墨青 Hero + 实时潮汐波动曲线 + 粒子气泡 + 最佳赶海时段卡 + 快捷入口 + 横向推荐卡
2. 图鉴页 — 搜索栏 + 分类 Tab + 瀑布流双列错落卡片
3. 详情页 — 大图视差滚动 + 毛玻璃返回/分享 + 物种信息 + 特征列表 + 小贴士
4. 赶海日记 — 沙金渐变头 + 时间轴 + 悬浮 FAB
5. 附近赶海点 — 深色地图区 + 跳动定位针 + 列表卡
6. 个人中心 — 渐变 Hero + 三栏统计 + 分组设置菜单
7. 设计规范页 — 六色板 + 字体样 + 按钮组件 + 设计原则
8. 接口文档页 — 深色代码风 + 分类 Tab + 可折叠端点 + 语法高亮

布局差异化：Hero 视差、瀑布流、时间轴、地图区、渐变 Hero 统计、代码文档六种不同骨架，≥5 页非重复布局。

## 原生端侧交互（≥4 种）

底部 TabBar（原生质感）、模态半屏抽屉（潮位预警）、全屏详情页转场、悬浮操作按钮 FAB、返回栈导航、下拉刷新。

## 动效系统

潮汐曲线波动（多层正弦叠加）、详情页视差滚动、自定义光标（白粗环 + 珊瑚内点 + 发光 + 悬停放大 + 点击涟漪）、数字计数（cubic ease-out）、头像脉冲光环、潮位趋势箭头浮动、定位针弹跳、卡片悬停提升 + 图片放大、FAB 悬停旋转、Shimmer 光泽扫过、波浪粒子气泡上浮、Tab 指示器弹性动画。

签名动效：首页潮汐曲线波动（主题语义）、详情页视差滚动（主题语义）。

## 健壮性

所有 RAF 循环随 `visibilitychange` 暂停、卸载取消；高频鼠标事件直接操作 DOM transform；`prefers-reduced-motion` 降级；JSX/CSS 全内联（零外部 src 引用）。

物种接口

GET/api/species
获取全部物种列表，支持按食毒/季节/科属筛选
// Response { "list": [ { "id": "chanterelle", "name_cn": "鸡油菌", "name_latin": "Cantharellus cibarius", "toxicity": "edible", "season": ["6", "7", "8", "9"] } ], "total": 13 }
GET/api/species/:id
获取物种详情：形态特征、生境、相似毒菌、孢子印色

检索接口

GET/api/identify/key
获取二叉检索表结构（节点 + 选项 + 目标物种映射）
POST/api/identify/step
提交一步选择，返回排除后的候选物种列表
// Request { "current_node": "q1", "choice": "a", "eliminated": [] } // Response { "next_node": "q2a", "candidates": ["morel", "chanterelle"], "eliminated": ["amanita_virosa"], "is_final": false }

采集记录接口

GET/api/records
获取用户采集记录列表，支持按时间/物种/地点筛选
POST/api/records
新增一条采集记录
// Request { "species_id": "chanterelle", "date": "2026-08-20", "habitat": "混交林", "location": "云南楚雄·紫溪山", "lat": 25.04, "lng": 101.52, "quantity": 3 }
DEL/api/records/:id
删除一条采集记录

季节日历接口

GET/api/season/current
获取当月可采菌种列表 + 采菌季进度百分比

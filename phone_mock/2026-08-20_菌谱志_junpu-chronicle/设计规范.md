# 菌谱志 · 设计规范

## 1. 主题与概念

野生菌采集者的随身食毒辨识工具与采集档案。核心体验：采菌季日历看当季 → 遇到陌生菌进辨识用二叉检索表逐级排除定种 → 食毒灯亮起 → 记入采集档案 → 多视图浏览。

## 5. 动效系统

### 缓动曲线
- `cubic-bezier(0.4, 0, 0.2, 1)` — Material 标准，通用过渡
- `cubic-bezier(0.34, 1.56, 0.64, 1)` — 弹性回弹，下拉刷新 / 锁定脉冲

### 关键帧动画
- `@keyframes spin` — 唱片旋转（导航栏装饰）
- `@keyframes lightPulse` — 食毒灯锁定脉冲（box-shadow 扩散+收缩）

### 过渡时长
- 0.15s — 快速反馈（选项 hover/active）
- 0.2s — 常规过渡（透明度 / 颜色）
- 0.3s — 布局过渡（transform / 页面切换）
- 2~6s — 装饰动画（旋转 / 脉冲周期）

### 动效语言
功能性阻尼反馈（小程序感）：检索排除淡出灰化、锁定食毒灯脉冲、地图标记弹入、下拉刷新弹性、左滑删除回弹。克制、功能性、无装饰粒子。

### prefers-reduced-motion
全局支持：所有动画在 `@media (prefers-reduced-motion: reduce)` 下降级为瞬切。

## 8. 数据模型

### 菌物种（8 种）
可食：鸡油菌 / 松茸 / 美味牛肝菌 / 羊肚菌 / 松乳菇 / 平菇 / 香菇 / 黑木耳
剧毒：白毒伞 / 灰花纹鹅膏 / 亚稀褶红菇 / 毒红菇
慎食：见手青（需充分加热）

每种含：id / 中文名 / 拉丁学名 / 食毒性 / 生境 / 季节 / 菌盖色 / 质感 / 菌褶类型 / 是否有菌环 / 是否变色 / 描述 / 形态特征(cap/gill/stipe/spore) / 相似毒菌 / 产地。

### 二叉检索表
7 节点二叉树，每节点含 question + 两个选项(a/b)，每选项指向下一节点或 result(物种id)。覆盖全部 8 个可辨识物种。

### 采集记录
localStorage 键 `junpu_records_v2`，含物种 / 地点 / 生境 / 日期 / 数量 / 备注。

## 9. 技术栈

- 纯 vanilla 单文件 HTML（无 React / 无 CDN / 无外部依赖）
- localStorage 持久化
- CSS 变量主题化
- 支持 prefers-reduced-motion
- 目标设备：390px + 414px

# 晨雾花市 Chenwu Flower Market

> 日期：2026-08-17 · 方向：V2 手机 UI · 形态：原生 App · 主题：鲜花市集原生 App

形态：原生 App

## 简介

「晨雾花市」是一个以"清晨花市"为灵感的鲜花选购与花艺鉴赏原生 App。清晨薄雾中，花农带着新鲜采摘的花卉来到市集，用户可以浏览、选购、学习花艺知识。采用雾霾玫瑰粉+鼠尾草绿的晨雾般柔和配色，8个完整页面含签名动效、设计规范页、接口文档页。

## 动效亮点

- 入场签名动画：首页元素逐个延迟入场序列
- 视差滚动：详情页Hero随滚动差速位移
- 自定义光标：白环+玫瑰粉内点+多层发光
- 下拉弹性、3D倾斜卡片、进度环动画、头像脉冲、光泽扫过、标签切换滑动指示器

## 原生 App 交互语言

底部 TabBar（选中态微动效）、全屏详情页转场、模态弹窗、手势滑动切换、长按快捷菜单、下拉刷新、悬浮 FAB

## 页面结构（8页）

1. 首页——瀑布流花束卡片 + Hero大图轮播 + 入场序列动画
2. 分类页——吸顶筛选标签 + 横向滚动分类 + 花束网格
3. 花束详情页——Hero大图视差滚动 + 底部吸底操作栏 + 花材清单
4. 购物车页——左滑删除 + 数量增减 + 底部结算栏
5. 花艺课堂页——左右分栏课程卡片 + 进度环
6. 个人中心页——头像脉冲 + 宫格功能入口 + 订单状态徽章
7. 设计规范页——色彩系统/字体/组件/动效/圆角展示
8. 接口文档页——API接口列表

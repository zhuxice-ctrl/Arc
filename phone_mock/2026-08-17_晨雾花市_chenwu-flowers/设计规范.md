## 字体系统

- **正文字体**：`'Noto Sans SC', -apple-system, system-ui, sans-serif`
- **标题/品牌字体**：`'Cormorant Garamond', 'Noto Serif SC', serif`（英文衬线+中文衬线组合）
- **次级标题**：`'Noto Serif SC', serif`
- **字重**：300 / 400 / 500 / 600 / 700

## 圆角规范

- 小元素/标签：`3px` / `8px`
- 中等卡片：`14px` / `16px`
- 大卡片/弹层：`18px`
- 底部弹层/TabBar：`24px 24px 0 0`
- 圆形元素：`50%`

## 组件规范

- **底部 TabBar**：5个Tab（首页/分类/课堂/购物车/我的），选中态玫瑰粉+微缩放动画
- **花束卡片**：瀑布流布局，圆角图片+花材标签+价格，悬停3D倾斜
- **Hero轮播**：全宽大图+左右滑动切换+指示点
- **吸底操作栏**：详情页底部固定，加购/立即购买按钮
- **筛选标签**：吸顶横向滚动，选中态玫瑰粉底色
- **进度环**：SVG圆环动画，课程进度
- **宫格入口**：个人中心2x4网格，图标+文字
- **FAB**：悬浮加购按钮，玫瑰粉圆形

## 动效系统

| 动效 | 实现方式 | 触发条件 |
|------|---------|---------|
| 自定义光标 | 白环+玫瑰粉内点+多层发光 | 开页即显示在屏幕中央 |
| 入场签名动画 | 元素逐个延迟入场序列 | 首页加载 |
| 视差滚动 | 详情页Hero随滚动差速位移 | 滚动 |
| 下拉弹性 | 顶部下拉弹性回弹 | 下拉手势 |
| 3D倾斜卡片 | 鼠标位置映射rotateX/Y | 鼠标悬停 |
| 悬停发光 | box-shadow过渡 | 鼠标悬停 |
| 涟漪点击 | 点击处光环扩散 | 点击 |
| 进度环动画 | SVG stroke-dashoffset动画 | 进入视口 |
| 头像脉冲 | scale呼吸+发光 | 持续运行 |
| 数字计数 | ease-out缓动 | 进入视口 |
| 光泽扫过 | 斜向高光带translateX | 鼠标悬停 |
| 标签切换指示器 | 滑动条translateX过渡 | 点击Tab |

## 原生 App 交互语言

1. **底部 TabBar**（选中态微动效）
2. **全屏详情页转场**（列表滑入详情）
3. **模态弹窗**（花束详情弹层）
4. **手势滑动切换**（Hero轮播左右滑动）
5. **长按快捷菜单**（长按花束卡片弹出快捷操作）
6. **下拉刷新**（首页下拉弹性回弹）
7. **悬浮操作按钮 FAB**（快速加购）

## 页面结构（8页）

1. **首页**——瀑布流花束卡片 + Hero大图轮播 + 入场序列动画
2. **分类页**——吸顶筛选标签 + 横向滚动分类 + 花束网格
3. **花束详情页**——Hero大图视差滚动 + 底部吸底操作栏 + 花材清单
4. **购物车页**——左滑删除 + 数量增减 + 底部结算栏
5. **花艺课堂页**——左右分栏课程卡片 + 进度环
6. **个人中心页**——头像脉冲 + 宫格功能入口 + 订单状态徽章
7. **设计规范页**——色彩系统/字体/组件/动效/圆角展示
8. **接口文档页**——API接口列表（方法/路径/说明/参数表格）

## 健壮性

- requestAnimationFrame 随 visibilitychange 暂停
- 高频鼠标事件直接操作 DOM transform
- 支持 prefers-reduced-motion
- JSX 全部内联在 script type="text/babel" 标签中

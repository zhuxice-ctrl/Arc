## 组件规范

- **手机外壳**：iOS 设备外壳，20px 圆角，顶部状态栏 + 底部 TabBar
- **导航栏**：大标题滚动收缩为小标题（iOS Large Title Navigation）
- **TabBar**：5 个 Tab（首页/药典/药方/节气/我的），选中态草药绿 + 微动效
- **草药卡片**：米纸色背景 + 性味标签 + 插画式图标
- **药方堆叠卡片**：层叠效果，可左右滑动切换
- **环形进度**：个人页已收录草药进度，SVG 绘制动画
- **FAB**：个人药柜页悬浮操作按钮，赤陶红
- **吸底操作栏**：详情页底部固定操作栏

## 动效系统

| 动效 | 实现方式 | 说明 |
|------|----------|------|
| 首页入场序列 | CSS animation + 交错延迟 | 分层渐入，节气 Hero → 轮播 → 网格 |
| 详情页视差 | scroll 事件 → Hero 缩放 + 模糊 | 滚动时 Hero 图缩小并模糊 |
| 下拉刷新 | 触摸事件 + 弹性回弹 | 药典页下拉触发刷新动画 |
| 环形进度绘制 | SVG stroke-dashoffset 动画 | 进入个人页时从 0 绘制到目标值 |
| TabBar 选中动效 | CSS transition | 图标缩放 + 颜色过渡 |
| 卡片堆叠滑动 | touch 事件 + transform | 药方页左右滑动切换 |
| 长按快捷菜单 | touchstart 计时 + 模态弹窗 | 长按药方卡片弹出操作菜单 |
| 模态弹窗过渡 | CSS opacity + transform | 筛选面板、操作确认弹出 |

## 原生端侧交互（8 种）

1. 大标题导航栏（滚动收缩）
2. 底部 TabBar（选中态微动效）
3. 全屏详情页转场（卡片展开到详情）
4. 模态弹窗（筛选面板、操作确认）
5. 手势滑动切换（药方页左右滑）
6. 长按快捷菜单（药方卡片长按）
7. 下拉刷新（药典页弹性回弹）
8. 悬浮操作按钮 FAB（个人药柜页）

## 页面结构（8 页）

1. **首页** — 节气 Hero 大图 + 横向卡片轮播 + 拼贴网格
2. **药典页** — 吸顶分类 Tab + 草药卡片列表
3. **药方页** — 堆叠卡片式药方 + 左右滑动
4. **节气养生页** — 24 节气时间轴
5. **个人药柜页** — 深绿头部 + 环形进度 + 宫格入口 + FAB
6. **草药详情页** — 全屏 Hero + 视差滚动 + 吸底操作栏
7. **设计规范页** — 色板 + 字体 + 圆角/间距规范
8. **接口文档页** — 8 个 API 接口折叠卡片

## 内容

- 24 种真实中草药（当归、黄芪、枸杞、人参、甘草、白芍、熟地黄、茯苓、川芎、丹参等）
- 6 个经典药方（四物汤、六味地黄丸、四君子汤、归脾汤、逍遥散、补中益气汤）
- 24 节气养生建议

## 健壮性

- requestAnimationFrame 随页面可见性暂停，卸载取消
- 快速操作不叠加定时器
- 高频鼠标事件直接操作 DOM
- 支持 prefers-reduced-motion
- JSX 全部内联在 index.html 的 script type="text/babel" 标签中

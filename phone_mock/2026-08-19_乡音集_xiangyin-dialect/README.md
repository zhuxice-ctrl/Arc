# 乡音集·方言词典

> 形态：微信小程序

一个方言词典微信小程序 mock。今日一词条、按六大方言区（粤语 / 吴语 / 闽南语 / 四川话 / 东北话 / 客家话）浏览真实词条，点词条从底部弹出半屏详情——词条卡可以翻面，正面是方言词，背面是普通话对照、例句和使用场景。看到喜欢的词，盖上一枚朱砂"方言印章"收进自己的乡音册；也可以贡献你家乡的词。

## 文件说明

- `设计规范.md` — 设计系统 / 端侧交互 / 接口文档
- `preview.png` — 首屏渲染截图（390×844）

## 技术栈
纯 HTML + CSS + JavaScript 单文件。localStorage（`xiangyin_` 前缀）持久化收藏与贡献；`prefers-reduced-motion` 降级；定时器随可见性暂停。

## 设计观点
把"收藏一个词"做成"盖一枚印"——让词典从工具变成可积累的乡土收藏。

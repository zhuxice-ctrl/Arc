接口文档
API Documentation · v1
GET /api/mini/v1/terms
获取方言词条列表，支持按地区筛选与关键词搜索。
请求参数 (Query)
字段类型说明
regionstring方言地区，可选值见备注
keywordstring搜索关键词，模糊匹配方言词与释义
pagenumber页码，默认 1
pageSizenumber每页条数，默认 20
响应示例
// 200 OK { "code": 0, "message": "success", "data": { "list": [ { "id": "term_001", "word": "饮茶", "region": "cantonese", "regionLabel": "粤语", "pronunciation": "jam2 caa4", "meaning": "去茶楼吃点心喝茶", "example": "得闲一齐去饮茶啦。", "scenarios": ["饮食", "社交"] } ], "total": 48, "page": 1, "pageSize": 20 } }
GET /api/mini/v1/terms/:id
获取单条词条的详细信息。
路径参数
字段类型说明
idstring词条唯一标识
响应示例
// 200 OK { "code": 0, "data": { "id": "term_001", "word": "饮茶", "region": "cantonese", "regionLabel": "粤语", "pronunciation": "jam2 caa4", "meaning": "去茶楼吃点心、喝茶...", "example": "得闲一齐去饮茶啦。", "scenarios": ["饮食", "社交"], "audioUrl": "https://...", "isFavorited": false, "contributor": "anonymous", "createdAt": "2024-01-15T08:00:00Z" } }
POST /api/mini/v1/favorites
收藏 / 取消收藏词条。
请求体
{ "termId": "term_001", "action": "add" // add | remove }
响应示例
{ "code": 0, "message": "收藏成功", "data": { "termId": "term_001", "isFavorited": true } }
POST /api/mini/v1/contributions
用户贡献新词条，提交后进入审核。
请求体
字段类型必填说明
wordstring是方言词
regionstring是所属地区
pronunciationstring否注音
meaningstring是普通话释义
examplestring否例句
响应示例
{ "code": 0, "message": "提交成功，待审核", "data": { "contributionId": "contrib_42a9f", "status": "pending" } }
GET /api/mini/v1/today
获取今日推荐方言词与热词列表。
响应示例
{ "code": 0, "data": { "region": "cantonese", "greeting": "早晨", "wordOfTheDay": { ... }, "hotWords": [ ... ] } }
GET /api/mini/v1/favorites
获取用户收藏的词条列表。
响应示例
{ "code": 0, "data": { "list": [ ... ], "total": 12, "regionCount": 4 } }
备注：地区可选值 — cantonese(粤语) / wu(吴语) / minnan(闽南语) / sichuan(四川话) / dongbei(东北话) / hakka(客家话)

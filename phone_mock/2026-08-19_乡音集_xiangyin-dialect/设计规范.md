# 乡音集·方言词典 — 设计规范

> 形态：微信小程序
> 单文件 HTML 手机端 mock（纯前端，localStorage 持久化，键前缀 `xiangyin_`）。

## 设计母题
方言的"乡土纸感 + 印章收藏"。以米白纸、深墨、朱砂、土金构建一套带人文温度的词典系统；收藏动作被设计成"盖一枚方言印章"，让"学一个词"变成"收一枚印"。

## 产品逻辑
- 为什么存在：帮用户认识 / 学习 / 收藏各地方言词汇，理解"同一句话在不同方言怎么说"。
- 核心流程：今日推荐 → 词条库（地区筛选 / 搜索）→ 半屏详情（翻卡看对照）→ 盖章收藏 → 我的乡音册；另可贡献新词条。

## 页面（6 页）
今日 / 词条库 / 收藏（我的乡音册）/ 我的 / 设计规范 / 接口文档。

## 微信小程序端侧交互（≥4，实做 6）
1. 右上胶囊按钮（··· / ⓧ）+ 自定义导航栏容器
2. 底部 TabBar（今日 / 词条 / 收藏 / 我的）
3. 半屏弹层 Sheet（词条详情 + 贡献表单）
4. 下拉刷新（弹性回弹）
5. 列表项左滑操作（收藏 / 删除）
6. 详情页吸底操作栏

## 字体
- UI 正文：`-apple-system / PingFang SC / Hiragino Sans GB / Microsoft YaHei` sans
- 方言词 / 标题强调：`Noto Serif SC / Songti SC / SimSun` serif

## 签名交互
- 词条卡 3D 翻转：正面方言词，翻面普通话对照 + 真实例句 + 使用场景
- 切换地区：顶部问候语与今日词联动（粤语"早晨"、四川话"巴适"等）
- 收藏：朱砂印章从天而降盖到词条卡上（下落 + 落印 + 扩散）

## 真实内容
15 条真实方言词条，覆盖粤语 / 吴语 / 闽南语 / 四川话 / 东北话 / 客家话，每条含方言词、地区、普通话对照、例句。

## 自定义光标
小印章 / 毛笔点造型，开页居中、高对比、层级最高；hover 可点元素时放大旋转。`prefers-reduced-motion` 降级系统光标。

## 健壮性
零未定义引用；定时器随可见性暂停；快速点击不叠加；支持 `prefers-reduced-motion`；390 / 360 / 414 宽度不溢出不裁切；无横向意外滚动；所有按钮 / Tab / 弹层 / 搜索 / 筛选 / 收藏 / 贡献真实可用，无假功能。

## 接口文档（假设后端）
- `GET /api/mini/v1/terms?region=` 词条列表
- `GET /api/mini/v1/terms/:id` 词条详情
- `POST /api/mini/v1/favorites` 收藏
- `POST /api/mini/v1/contributions` 贡献新词条
（含请求 / 响应 JSON 示例与字段说明，见应用内"接口文档"页）

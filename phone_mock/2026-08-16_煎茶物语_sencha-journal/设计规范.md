## 色彩系统

抹茶绿主色 + 米白底 + 栗棕辅助 + 柿橙点缀，每页有独立"色彩主角"。

| 语义 | 色值 | 用途 |
|---|---|---|
| 抹茶绿（主） | `#5F7D4E` | 主品牌色、主按钮 |
| 深抹茶 | `#3D542E` `#4A6538` `#2E3A22` | Hero 深底、深色分区 |
| 苔绿阶 | `#8A9A70` `#B8C99A` `#D4E0C0` | 次级强调、浅底 |
| 米白（底） | `#F6F1E6` | 页面主背景 |
| 暖米阶 | `#FAF6EE` `#EFE7D6` `#E8DFCC` `#D4C7AE` | 卡片表面、边框 |
| 栗棕（辅助） | `#6B4A32` `#5A3D2A` `#3A2E22` | 文字、深色头图 |
| 暖灰棕 | `#8A7560` `#A08870` `#C9B8A0` | 次级文字 |
| 柿橙（点缀） | `#D96C2C` `#C45520` `#FFB888` | 强调、计时器高光 |
| 深色代码底 | `#1C1C1E` `#0F1810` `#1A2214` | 接口文档页深色风 |
| iOS 系统灰 | `#595959` `#F2F2F7` `#DEE0E3` | 系统组件 |

## 字体

- 正文：`'Noto Sans SC', 'PingFang SC', sans-serif`
- 标题/品牌：`'Noto Serif SC', 'Songti SC', serif`
- 代码/数据：`'SF Mono', 'Menlo', monospace`

## 圆角与层级

- 卡片圆角 16–24px（茶器圆润感）
- 阴影 + 毛玻璃分层；重要元素尺寸/色彩/留白突出
- 色彩分区与局部渐变制造节奏

## 健壮性

- `visibilitychange` 自动暂停 RAF/定时器，卸载统一取消
- 快速切换计时器预设先清理旧定时器
- 高频滚动 RAF 节流 + DOM transform
- 支持 `prefers-reduced-motion` 降级
- 全 JSX/CSS 内联 `index.html`（ios-frame.jsx 已内联），无外部 JSX fetch

## 技术栈

React 18 + Babel Standalone（CDN），统一手机外壳 + 多页切换，单 HTML 文件。

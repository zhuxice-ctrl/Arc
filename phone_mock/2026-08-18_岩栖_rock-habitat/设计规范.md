# 岩栖 · 设计规范

## 主题
岩栖 —— 矿物标本收藏 App，原生 App 形态。面向矿物爱好者与收藏家，提供标本管理、矿物识别、晶藏展览、个人田野笔记等功能。

## 色彩系统
| 角色 | 色值 | 用途 |
|------|------|------|
| 橄榄林绿（主色） | `#3A442B` | 导航栏、主色调 |
| 深橄榄（主色深） | `#2C3322` | 底栏、深色背景 |
| 琥珀金（强调） | `#D4A02A` | 高亮、选中态、FAB |
| 亮琥珀（强调亮） | `#E8BC4A` / `#F0D078` | 悬停、数据高亮 |
| 赭石铁锈（辅助） | `#8A4B27` / `#B05E2E` | 次要标签、分类 |
| 羊皮纸米（表面） | `#EDE4CB` / `#F5EFE0` | 浅色卡片表面 |
| 暖炭灰（深中性） | `#1a1714` / `#2d2820` | 深色背景、文字 |
| 蔷薇辉粉（点缀） | `#C97B7B` / `#E6B0B0` | 特殊矿物标识 |
| 苔绿（辅助亮） | `#7D9458` / `#99AD70` | 成功态、自然标识 |
| 奶油白（文字主） | `#F3F2E4` / `#F8F3E6` | 正文文字 |

## 字体
- 展示字体：`'Noto Serif SC', serif` —— 衬线，博物馆标签美学
- 正文字体：`'Noto Sans SC', -apple-system, system-ui, sans-serif`
- 数据字体：`'JetBrains Mono', monospace` —— 编号/坐标

## 圆角
- 卡片：`16px`
- 按钮：`12px`
- 标签/Chip：`20px`（胶囊形）
- 手机外壳：`48px`

## 组件规范
- 手机外壳：iOS 风格圆角边框，状态栏+底部 TabBar
- 底部 TabBar：5 个标签（晶藏/识别/展览/笔记/我的），选中态琥珀金+弹性指示器
- FAB 悬浮按钮：右下角圆形，琥珀金底色，弹性缩放动画
- 标本卡片：六边形晶面纹理装饰，博物馆标签风格
- 筛选 Chip：胶囊形，选中态填充色

## 原生端侧交互（7 种）
1. 底部 TabBar 切换（原生质感+弹性指示器）
2. 下拉刷新（六边形自旋动画）
3. 全屏详情页转场（模态滑入）
4. 底部半屏抽屉（Bottom Sheet）
5. 长按快捷菜单
6. FAB 悬浮操作按钮
7. 模态弹窗

# 城市漫游手册 · 设计规范

## 主题
城市步行探索微信小程序，收集城市的隐秘角落、老街故事、街角小店。用户可发现路线、收藏地点、记录漫步足迹。

## 形态：微信小程序

- 小程序容器：自定义导航栏 + 胶囊按钮（··· / ⊙），导航栏随页面变化（透明/渐变/吸顶变色）
- 底部 TabBar：4 个 Tab（首页/发现/漫步记录/我的），选中态微动效
- 端侧交互：页面栈 push/pop（右滑返回手势感）、下拉刷新弹性回弹、左滑列表操作、吸顶筛选 Tab、半屏 ActionSheet、骨架屏加载

## 健壮性

- requestAnimationFrame/定时器随 visibilitychange 暂停
- 触摸端自动隐藏自定义光标
- 快速操作不叠加定时器
- 支持 prefers-reduced-motion
- 所有 JSX/CSS 单文件内联

## 技术栈

React + Babel standalone（JSX 内联在 script 标签中），纯前端单文件实现。

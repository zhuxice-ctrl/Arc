# 城市漫游手册 · V2 手机 UI

形态：微信小程序

**日期**：2026-08-18
**方向**：V2 手机 UI
**形态**：微信小程序
**主题**：城市漫游手册 — 城市步行探索小程序

## 简介

城市步行探索微信小程序，收集城市的隐秘角落、老街故事、街角小店。用户可发现漫游路线、收藏地点、记录漫步足迹。页面运行在带胶囊按钮的自定义导航栏之下，采用小程序端侧交互语言（页面栈 push/pop、底部 TabBar、半屏 ActionSheet、下拉刷新弹性、左滑列表操作、吸顶筛选 Tab）。

## 动效亮点

- 首页入场序列动画 + 下拉刷新弹性回弹
- 路线详情 Hero 视差滚动 + 底部吸底操作栏
- 漫步记录环形进度动画 + 悬浮操作球
- 个人页头像脉冲 + 徽章墙滚动
- 自定义光标（白色粗环+彩色内点+多层发光）

## 页面结构（8 页）

| 页面 | 布局 |
|------|------|
| 首页（Tab1） | 砖红渐变 Header + 路线卡片流 |
| 路线详情 | Hero 大图 + 滚动视差 + 底部吸底操作栏 |
| 发现页（Tab2） | 吸顶筛选 Tab（6 类）+ 左滑列表操作 |
| 地点详情 | 轮播画廊 + 半屏 ActionSheet + 评价区 |
| 漫步记录（Tab3） | 环形进度统计卡 + 路线历史时间轴 + 悬浮操作球 |
| 我的页（Tab4） | 头像脉冲 + 宫格入口 + 徽章墙 + 设置列表 |
| 设计规范页 | 色彩系统 + 字体 + 圆角 + 组件 + 动效规范 |
| 接口文档页 | 8 个 API 可展开折叠 |

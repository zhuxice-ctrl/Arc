# 设计规范 · 毛线圈 · 编织手作社群小程序

> 日期：2026-08-17 · 方向：V2 手机 UI · 形态：微信小程序 · 主题：毛线编织手作社群

## 形态说明

微信小程序形态。页面运行于带胶囊按钮（右上角 ··· / ⊙）的自定义导航栏之下，整体套在统一手机外壳内。导航栏随页面变化（透明 / 渐变 / 吸顶变色）。使用端侧交互：页面栈 push/pop 右滑返回、底部 TabBar、半屏弹层 ActionSheet、下拉刷新弹性回弹、左滑列表操作、吸顶 Tab、吸底主按钮、骨架屏加载。

## 色彩系统

| 角色 | 色值 | 用途 |
|------|------|------|
| 主色 · 焦糖棕 | `#C4803F` | TabBar 选中、主按钮、强调 |
| 深主 · 焦糖深 | `#B8863A` / `#C97B6B` | 按钮按压、深态 |
| 辅 · 鼠尾草绿 | `#8A9B7E` / `#A8B89A` | 成功、辅助标签、选中态 |
| 点缀 · 桃粉 | `#E8B4A0` / `#E8898C` | 点赞、收藏高亮 |
| 金辅 | `#D4A84B` | 星标、进度点缀 |
| 背景 · 燕麦奶白 | `#F5EFE4` / `#F2EFE8` | 页面底 |
| 表面浅 | `#E5E0D5` / `#EDE6D8` / `#F0ECE2` | 卡片表面分层 |
| 中性 · 雾灰 | `#6B6B66` / `#B0A99B` | 次要文字、描边 |
| 文字 | `#2A2A2A` / `#1A1A1A` | 主文字 |

每页有色彩主角：首页偏燕麦暖白、线材铺偏桃粉、织友圈偏鼠尾草绿、我的页偏焦糖，但统一在暖调体系内。

## 字体系统

- 系统栈：`-apple-system, "PingFang SC", "Microsoft YaHei", sans-serif`
- 等宽（代码 / 接口）：`monospace`

## 圆角

卡片 `12px`、按钮胶囊 `999px`、标签 `6px`、头像 `50%`。圆角偏柔和，贴合手作温度。

## 页面结构（8 页）

1. 首页 —— 图解教程卡片瀑布流 + 骨架屏加载 + 下拉刷新弹性回弹 + 入场序列签名动效
2. 分类页 —— 棒针 / 钩针 / 阿富汗针吸顶筛选 Tab + 网格拼贴
3. 图解详情页 —— 步骤图解 + 材料清单 + 底部吸底操作栏（收藏 / 开工）
4. 线材铺页 —— 线团色卡轮播画廊 + 半屏弹层选规格数量
5. 织友圈页 —— 作品瀑布流 + 左滑收藏 / 点赞
6. 我的页 —— 头像 + 宫格 + 编织时长环形进度签名动效
7. 设计规范页
8. 接口文档页

布局差异化：瀑布流 / 网格拼贴 / 轮播画廊 / 半屏弹层 / 左滑列表 / 环形宫格，至少 6 种非重复结构。

## 动效系统

签名动效：①毛线球滚动 loading（下拉刷新）②毛线走线式进度条（详情页编织进度）③编织时长环形进度（毛线球沿圆环绕行）。组件级 12+：Tab 切换弹跳、卡片入场 fade-up 序列、涟漪点击、点赞心跳、数量步进、色卡选中外环、骨架屏闪光、毛线编织渐变流动、弹性回弹、弹窗上滑、导航栏滚动态变色、环形进度 unravel。自定义光标（焦糖棕描边 + 中心点，悬停放大变鼠尾草绿，点击涟漪，开页居中）。

## 健壮性

- RAF / 定时器随可见性暂停，卸载取消
- 高频事件直接操作 transform
- 支持 `prefers-reduced-motion`
- JSX 全部内联于 `<script type="text/babel">`
- 零未定义引用

## 技术栈

React（Babel standalone 内联 JSX）+ 自定义手机外壳组件，localStorage 模拟数据。

## 色彩系统

| 角色 | 色值 | 用途 |
|------|------|------|
| 主色-橄榄绿 | `#5A6B3B` | 导航、主按钮、品牌色 |
| 主色-赤橙 | `#D2691E` | 强调、打卡高亮、FAB |
| 表面色-羽白 | `#F4F1E8` | 页面底色 |
| 中性-暖灰 | `#3A3A32` | 深色区块、文字 |
| 辅助-米黄 | `#E8DDB5` | 卡片、次级背景 |
| 辅助-浅灰 | `#9A9A8A` / `#5A5A4A` | 次级文字、分隔 |

页面色彩主角差异化：首页橄榄绿主调、图鉴页米黄+橄榄绿、鸟点页手绘地图暖灰底、详情页深色渐变 Hero、打卡页赤橙主题、个人页深色渐变。

## 字体

- 正文：`'Noto Sans SC', 'PingFang SC', sans-serif`
- 标题/衬线：`'Noto Serif SC', serif`
- 数据/代码：`monospace`

## 端侧交互（小程序形态，8 种全覆盖）

页面栈 push/pop 滑入滑出（右滑返回手势感）、底部 TabBar（4 个，选中弹性动效）、半屏 ActionSheet 动作面板、下拉刷新弹性回弹、左滑列表操作、吸顶 Tab、表单页底部安全区主按钮、骨架屏加载。自定义导航栏带胶囊按钮（··· / ⊙），随页面透明/渐变/吸顶变色。

## 组件

- 首页：Hero 大图 + 飞羽飘落入场 + 搜索栏 + 4 宫格快捷入口 + 热门鸟横滑 + 鸟友动态流
- 图鉴：渐变 Hero + 吸顶分类 Tab + 瀑布双列网格 + 骨架屏
- 鸟点：手绘地图 + 脉冲标记 + 左浮动操作球 + 底部半屏弹层 + FAB
- 详情：Hero 视差 + 鸣声波形 + 迁徙轨迹 Canvas + 吸底操作栏
- 打卡：赤橙 Hero + 日历热力图 + 左滑操作
- 个人：深色渐变 Hero + 年度目标环形进度 + 宫格菜单
- 设计规范页、接口文档页（6 个 API 分组）

## 动效系统（12+ 项）

飞羽飘落入场、Hero 视差滚动、迁徙轨迹绘制、鸟鸣波形、环形进度动画、Tab 脉冲点、FAB 光环、地图标记脉冲、骨架屏 shimmer、下拉弹性回弹、页面滑入滑出、自定义光标（白环+橙点+涟漪+悬停放大）。

## 页面结构（8 页）

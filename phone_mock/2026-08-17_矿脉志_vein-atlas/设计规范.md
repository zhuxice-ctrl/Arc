# 矿脉志 Vein Atlas · 设计规范

- 日期：2026-08-17
- 方向：V2 手机 UI · 微信小程序形态（矿物标本收藏与图鉴）

## 色彩系统（矿晶色系）

| 角色 | 色值 | 用途 |
|------|------|------|
| 深板岩墨（底） | `#1F2430` / `#2a3140` / `#111418` | 首页 Hero 底、导航、标本页统计头 |
| 孔雀石绿（主色） | `#0E7C5B` / 深阶 `#0b6348` | 主按钮、Tab 选中、强调图标 |
| 红纹石珊瑚（强调） | `#E4574C` | 强调按钮、徽标、ActionSheet 警示 |
| 萤石黄（点缀） | `#F2C14E` | 评级、硬度标记、会员卡 |
| 米白（表面） | `#F7F4EC` / `#F0EDE4` / `#ebe7dd` | 卡片底、列表页背景 |
| 晶体浅青 | `#A8D5C5` | 晶形插画、辅助面 |
| 中性灰 | `#888d96` / `#555a63` / `#9aa0aa` / `#d5d8dd` / `#aaaeb6` | 次级文字、描边、骨架屏 |

无蓝紫渐变；每页 3–5 个色调层次，首页深底、列表/发现页米白底、我的页色块拼接。

## 字体

- 展示标题：`Playfair Display` + `Noto Serif SC`（品牌名、详情页大标题）
- 正文 UI：`Noto Sans SC` / PingFang SC（300–700）
- 数据 / 化学式：monospace

## 圆角与组件

- 卡片圆角 12–16px，弹层 20px（顶部圆角），小标签 4px，胶囊/头像 50%
- 小程序导航栏：左标题 + 右上「··· / ⊙」胶囊；透明 / 白底吸顶 / 滚动渐变三态
- 底部 TabBar：4 Tab，选中态图标上浮 + 主色点亮 + 顶部指示条滑入

## 页面结构（8 页，统一手机外壳 390×844）

1. 首页：透明导航 + 水晶簇 Hero + 逐字标题 + 横滑上新 + 8 类宫格
2. 图鉴列表：吸顶筛选 + 双列瀑布流 + 骨架屏渐入
3. 矿物详情：大晶体视差 + 数据条 + 晶格图 + 吸底「加入标本匣」
4. 标本页：暗色统计头（环形进度 + 计数）+ 左滑收藏列表
5. 发现页：吸顶 Tab + 文章卡片流
6. 我的页：头像 + 统计行 + 功能宫格 + 会员卡
7. 设计规范页、8. 接口文档页（/api/miniprogram/v2/*）

## 小程序端侧交互（7 种）

页面栈右滑入 / 左滑出、半屏 ActionSheet（下滑关闭）、首页下拉刷新弹性回弹、标本左滑「转让/删除」、发现页吸顶 Tab、详情吸底操作栏、图鉴骨架屏。

## 签名动效

- 首页入场序列：晶体簇光点脉动 + 标题逐字浮现
- 详情页晶体滚动视差 + 缩放
- 标本页环形进度动效 + 数字计数

## 健壮性

JSX 全内联 `<script type="text/babel">`；定时器随 `visibilitychange` 清理；视差走 rAF 直操作 DOM；`prefers-reduced-motion` 降级；晶体全部内联 SVG（8 种晶形变体）。

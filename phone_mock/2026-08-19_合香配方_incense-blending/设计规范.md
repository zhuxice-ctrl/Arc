## 页面结构

4 TabBar + 页面栈 push/pop：
1. **今日** — 节气推荐卡片 + 香气雷达缩略图 + 开始合香主按钮 + 最近焚香时间线
2. **香料** — 6 类横滑筛选 chip + 10 种香料列表 + 半屏详情 Sheet
3. **合香** — 戥秤签名交互工作台 + 香料架拖拽 + 重量滑杆 + 香气雷达 + 存方
4. **香录** — 焚香日记时间线 + 新建日记弹窗

附加页：设计规范页、接口文档页（齿轮入口）

## 签名交互：戥秤称量

- 秤杆横跨中央，中心支点（三角底座），左盘放香料，右盘显示目标总重
- 倾斜角度 = atan2(左盘总重 - 右盘目标重, 灵敏度)，限制 ±15°
- 拖拽：pointerdown/pointermove/pointerup，从底部香料架拖香料包到秤盘
- 落入动画：@keyframes bundleDrop（scale 0→1 + translateY 弹簧）
- 重量滑杆：0.1-5.0g 精度，实时更新秤杆倾斜
- 香气雷达：Canvas 2D 六边形雷达（甘/辛/苦/酸/木/花），加权平均计算，200ms 过渡

## 动效系统

| 动画 | 类型 | 用途 |
|------|------|------|
| bundleDrop | @keyframes | 香料包落入秤盘的弹簧动画 |
| motionBounce | @keyframes | 按钮点击/状态切换的弹性反馈 |
| spin | @keyframes | 加载旋转 |
| 秤杆倾斜 | CSS transition + transform rotate | 重量变化的物理反馈 |
| 页面栈转场 | CSS transition slide | push 左入 / pop 右出，300ms |
| 雷达更新 | Canvas 200ms ease | 香气配方变化平滑过渡 |

所有动画支持 prefers-reduced-motion 降级。RAF 随 document.visibilityState 暂停，卸载时 cancelAnimationFrame。

## 数据持久化

| localStorage 键 | 内容 |
|-----------------|------|
| incense_recipes | 用户保存的合香配方数组 |
| incense_journal | 焚香日记记录数组 |

初始化时预载 3 个预设配方（梅花合香/清远香/百和香）+ 1 条示例日记。

## 内容数据

10 种真实香料：沉香、檀香、龙脑、丁香、藿香、甘松、零陵香、降真香、白芷、肉桂。每种含产地、性味归经、功效、香气描述、用法用量、六维香调值（甘/辛/苦/酸/木/花，0-10）。

3 个预设配方：梅花合香（沉香3+檀香2+零陵香1+龙脑0.5）、清远香（檀香4+沉香1+丁香1）、百和香（沉香2+檀香2+藿香1+甘松1+降真香1）。

焚香场合标签：独处静坐/读书写字/待客会友/睡前安神/晨起提神/祭祀供奉/瑜伽冥想。

## 技术栈

- 纯 vanilla 单文件 HTML（无 React/Babel/外部 CDN）
- Canvas 2D 绘制香气雷达图
- Pointer Events 实现拖拽交互
- localStorage 持久化
- 390px 目标宽度 + 414px 邻近尺寸
- 健壮性：RAF/定时器随可见性暂停且卸载取消、支持 prefers-reduced-motion

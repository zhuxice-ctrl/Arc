# 设计规范 · 邮驿 StampPost 邮票收藏 App

> 日期：2026-08-17 ｜ 方向：V2 手机 UI ｜ 形态：原生 App ｜ 主题：邮票收藏与鉴赏

## 形态

形态：原生 App（iOS 风格）。本次交替判定：上一次 phone_mock（香料图鉴）为微信小程序，故本次为原生 App。

## 色彩系统

| 角色 | 色值 | 用途 |
|------|------|------|
| 主色 邮差绿 | `#1E5945` | 导航栏、TabBar、主按钮 |
| 底色 羊皮纸米 | `#EFE6D5` | 页面背景 |
| 强调色 邮戳红 | `#B34A3A` | 邮戳盖印、稀有标签、警示 |
| 文字色 墨黑 | `#1C1A17` | 标题与正文 |
| 点缀色 黄铜金 | `#B08D4C` | 徽章、分割线、稀有邮票描边 |

每页在主配色基础上使用 3-5 个色调层次，允许局部渐变与色块分区。整体禁蓝紫渐变。

## 字体

- 标题：`'Noto Serif SC', serif`（邮票年代质感）
- 正文：`'Noto Sans SC', system-ui, sans-serif`
- 装饰：`'Playfair Display', serif`（发行年份、面值）

## 圆角 / 阴影

- 邮票卡圆角 `6px`（接近票面直角）；底部弹层 `20px` 顶部圆角
- 阴影：`0 8px 28px rgba(28,26,23,.18)`；FAB 阴影带绿色辉光

## 页面结构（8 页，布局均不重复）

1. 首页 — Hero 今日珍邮大卡 + 分类 chips + 精选双列网格 + 藏友动态信息流
2. 图鉴页 — 分类横滑 tab + 瀑布流邮票卡片（masonry columns）
3. 行情页 — 对角分割数据卡 + Tab 切换 + 列表 + 邮市观察卡
4. 藏友社区 — 三栏数据格 + 热门话题标签墙 + 动态 feed
5. 邮票详情页 — 全屏转场 + 大邮票展示 + 四 Tab（故事/参数/鉴赏/行情）
6. 设计规范页 — 色彩系统 / 字体排印 / 核心组件 / 图标系统
7. 接口文档页 — 端点选择器 + 参数说明 + JSON 响应示例
8. 底部快捷操作弹层 — FAB 展开菜单 + 6 项快捷入口

## 原生端侧交互语言（≥4 种）

大标题导航栏 / 返回栈、底部原生 TabBar、卡片式信息流、全屏详情转场、模态弹窗、手势滑动、长按快捷菜单、下拉刷新、FAB。

## 签名动效（2 个，邮票主题语义）

- 邮戳盖印动画：详情页进入后 0.6s 红色邮戳从放大→缩小→旋转盖下
- 齿孔撕纸质感卡片：所有邮票卡片使用 SVG 齿孔边缘 + 光泽扫过

## 组件级特效（13 个）

自定义光标（白环+红内点+发光）、环境粒子（上浮+左右摆动）、数字计数、脉冲发光、邮票光泽扫过、屏幕切换左右滑入、列表项渐入级联、FAB 展开旋转+选项级联、底部弹层半屏抽屉、长按快捷菜单、下拉刷新指示器、标题字重揭示、信封漂浮装饰。

## 健壮性

- 所有 RAF/定时器随 `visibilitychange` 暂停、卸载清理
- mousemove 直接操作 DOM；支持 `prefers-reduced-motion`
- JSX 全内联单文件；零未定义引用

## 字体栈

- 西文标题/数字：`"Cormorant Garamond"`（衬线，潮汐曲线/大标题）
- 西文 UI：`"Outfit"` 300–700（导航、按钮、正文）
- 代码/接口：`"JetBrains Mono"` 400/500/600（接口文档、字段）

## 页面结构（8 页，布局差异化）

1. 今日潮汐首页 — Canvas 潮汐曲线动画（签名动效①）+ 双频 SVG 波浪 + 高低潮时间轴 + 安全警报卡 + 快捷功能网格
2. 赶海点探索页 — 深色 Hero 搜索头 + 轮播画廊式卡片流（渐变背景+装饰图案）
3. 海物图鉴页 — 马赛克拼贴网格（tall/wide 变化）+ 长按快捷菜单
4. 图鉴详情页 — 全屏转场 + 视差 Hero 大图 + 季节条 + 识别要点卡
5. 渔汛月历页 — 月相指示 + 月历网格（大潮红点/小潮青点）+ 详情卡 + 最佳赶海日横滑
6. 社区晒收获页 — 瀑布流 + 下拉刷新回弹 + FAB 悬浮按钮
7. 设计规范页 — 色彩/字体/按钮/间距/圆角五大模块
8. 接口文档页 — 深色侧边栏 + 7 个假接口 + 可交互 API 调试器 + 响应底栏

## 原生端侧交互（6 种）

大标题导航栏、底部 TabBar（原生质感）、全屏详情页转场、模态底弹窗、长按快捷菜单、下拉刷新、悬浮操作按钮 FAB。

## 布局丰富度

8 页中 7 页为非重复布局（曲线 Hero / 轮播画廊 / 马赛克拼贴 / 视差详情 / 月历网格 / 瀑布流 / 侧栏调试器），每页 3–5 个色调层次，每页有各自"色彩主角"（首页偏深青、图鉴偏青绿、社区偏米白、接口页全深色）。

## 动效系统（12+ 组件级）

1. 潮汐曲线 Canvas 绘制 + 余波振荡（签名动效①）
2. 双层 SVG 波浪流动（签名动效②，不同频率）
3. 自定义光标（悬停放大 + 点击涟漪 + 跟随环）
4. 动态岛扩展动画
5. 页面左右滑入转场
6. 模态缩放 + 背景模糊
7. 下拉刷新弹性回弹
8. 卡片按下缩放反馈
9. TabBar 选中态下划线滑动
10. 季节条高亮渐变
11. 按钮弹簧动效
12. 月历红点/青点脉冲

## 假接口

`/api/v2/tides`（今日潮汐）、`/api/v2/tides/forecast`（七日预测）、`/api/v2/spots`（赶海点）、`/api/v2/spots/{id}`（详情）、`/api/v2/species`（海物图鉴）、`/api/v2/species/{id}`（图鉴详情）、`/api/v2/community`（社区晒收获）。

## 健壮性

JSX 全部内联 `<script type="text/babel">`，CSS 内联 `<style>`；Babel/React CDN 仅在妙搭运行时引用，本地截图时已下载为 `_lib` 本地文件；RAF/定时器随 `visibilitychange` 暂停、卸载取消；快速操作先 `clearTimeout`；高频鼠标事件直接操作 DOM transform；`prefers-reduced-motion` 降级。

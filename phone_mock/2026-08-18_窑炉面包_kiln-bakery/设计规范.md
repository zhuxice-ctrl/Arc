# 窑炉面包 · 设计规范

> 日期：2026-08-18 · 方向：V2 手机 UI · 形态：原生 App · 主题：窑烤面包房手机应用

## 色彩系统

| 角色 | 色值 | 用途 |
|---|---|---|
| 炭黑（主深色） | `#241A12` / `#1A120B` | 深色页头、会员页底色、文字主色 |
| 焦糖琥珀（主色） | `#C8712B` / `#8B4F1D` | 主按钮、TabBar 选中态、价格强调 |
| 奶油（表面色） | `#FBF3E4` / `#F0E8D8` / `#E8DEC8` | 页面底色、卡片表面 |
| 麦金（辅助色） | `#D9A84E` / `#E8C478` | 徽章、积分、麦穗装饰 |
| 浆果红（强调色） | `#A63D2F` / `#7A2B20` | 结算按钮、限量标记、收藏态 |
| 陶棕（中性辅助） | `#8B6240` / `#3A2E24` | 次级文字、图标、分隔 |

每页色彩主角差异化：首页偏暖（琥珀+炭黑窑火）、预订页奶油底、烘焙日志深炭顶、会员页炭黑+麦金、接口文档页全深色代码模式。无蓝紫渐变。

## 字体

- 全端统一：`'Noto Sans SC', -apple-system, system-ui, sans-serif`
- 通过字重 / 字号 / 字距拉开层级（大标题导航 34pt 粗体 → 正文 15pt）

## 页面结构（8 页，6 种独特布局）

1. 首页：Hero 窑炉大图 + 视差滚动 + 横向卡片流 + 入场序列动画
2. 预订：瀑布流双列网格 + FAB 购物车悬浮球
3. 烘焙日志：时间线卡片流 + 展开式 FAB 菜单
4. 会员：环形积分进度 + 权益 3×2 网格 + 头像脉冲
5. 面包详情：全屏大图视差 + 底部浮动购买栏
6. 购物车：底部半屏抽屉 + 遮罩滑入
7. 设计规范页：色板 / 字体 / 组件 / 间距刻度
8. 接口文档页：Tab 分类 + 代码块响应示例

## 原生交互语言（6 种）

底部 TabBar（选中微动效）、返回栈导航、全屏模态详情转场、底部半屏抽屉、下拉刷新（弹性回弹）、FAB 悬浮操作按钮。

## 动效系统（12+ 项）

自定义光标（白环+琥珀内点+发光+悬停变形+点击涟漪，开屏居中）、窑炉火星粒子、蒸汽升腾、Hero 视差缩放、数字计数、入场渐入序列、光泽扫过、面包浮动、环形进度绘制、头像脉冲、FAB 展开旋转、卡片 3D 弹跳。

## 健壮性

- RAF / 定时器随 `visibilitychange` 自动暂停，卸载统一取消
- 高频事件直操 DOM transform；快速切换不叠加定时器
- 零未定义引用；`prefers-reduced-motion` 降级
- JSX 全部内联于 `<script type="text/babel">`，无外部 src

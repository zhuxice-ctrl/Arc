## 字体系统

## 组件规范

- **小程序导航栏**：高度 44px + 状态栏，右上角胶囊按钮（···/⊙），随页面透明/吸顶变色
- **底部 TabBar**：4 个 Tab，高度 56px + 安全区，选中态弹性微动效
- **卡片**：圆角 12px，白色底，阴影 0 2px 8px rgba(0,0,0,0.06)
- **半屏弹层**：从底部上滑，圆角 16px 顶部，遮罩 rgba(0,0,0,0.4)
- **吸顶 Tab**：滑动指示器，高度 3px，过渡 300ms
- **骨架屏**：灰色块 #E8E8E8 + 闪烁动画
- **环形进度**：SVG circle，stroke-dashoffset 动画

## 页面结构（8 页）

1. **首页**：Hero 大图视差 + 当季染料横向卡片流 + 工坊活动列表 + 故事专题卡片（骨架屏）
2. **染料图鉴**：搜索框 + 吸顶分类 Tab（蓝/红/黄/棕褐四系）+ 瀑布流卡片 + 色样展示
3. **工坊预约**：靛蓝渐变头部 + 日期选择 + 课程卡片 + 时间场次 + 半屏弹层确认 + 底部安全区按钮
4. **作品展示**：自动轮播画廊 + 拼贴网格 + 左滑操作列表（收藏/分享）
5. **染坊故事**：杂志式阅读页，首字下沉 + 引用卡片 + 滚动渐入 + 封面视差
6. **个人中心**：渐变头像区 + 环形进度 + 数字计数 + 宫格入口
7. **设计规范页**：色彩系统 + 字体排版 + 组件展示 + 间距系统 + 动效曲线
8. **接口文档页**：API 表格 + 分组折叠 + JSON 响应示例

## 小程序端侧交互

- 胶囊按钮容器 + 自定义导航栏
- 页面栈 push/pop 右滑过渡
- 底部 TabBar（4 Tab）
- 半屏弹层 / ActionSheet
- 下拉刷新弹性回弹
- 左滑列表操作
- 吸顶 Tab 滑动指示器
- 底部安全区主按钮

## 技术栈

- 纯 vanilla HTML/CSS/JS 单文件
- SVG（环形进度、图标）
- CSS Transition + transform（页面过渡、弹层）
- IntersectionObserver（滚动渐入）
- requestAnimationFrame（数字计数、动画）
- 支持 prefers-reduced-motion

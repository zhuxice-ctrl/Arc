# 草木染日记 Natural Dye Diary

> 日期：2026-08-17 · 方向：V2 手机 UI · 形态：微信小程序 · 主题：古法植物染工坊小程序

形态：微信小程序

## 简介

草木染日记是一个古法植物染工坊微信小程序，围绕蓼蓝、茜草、栀子、紫草、核桃青皮等天然染料植物，提供染料图鉴、工坊预约、作品展示、染坊故事等功能。靛蓝 + 亚麻米 + 陶土赤 + 苔绿 + 米白的草木染主题配色，在统一手机外壳内呈现 8 个页面，含胶囊按钮导航栏、底部 TabBar、半屏弹层、下拉刷新等小程序端侧交互。

# 设计规范 · 飞羽 · 观鸟记录小程序

> 方向：V2 手机 UI　形态：微信小程序　日期：2026-08-18

## 形态标记

**形态：微信小程序**

## 色彩系统

主配色：墨绿 + 鹅黄 + 雾灰 + 米白（无蓝紫渐变）。

| 色值 | 用途 |
| --- | --- |
| #2D4A3E | 墨绿主色（导航/TabBar/标题） |
| #3d5c4e | 墨绿次色（卡片/分割） |
| #1a2d26 | 墨绿深态（页脚/底栏） |
| #E8D48A | 鹅黄强调色（选中态/高亮/按钮点缀） |
| #c79a00 | 鹅黄深态 |
| #8A9A97 | 雾灰中性色（次文字/边框） |
| #5a6e68 / #4a5c57 | 雾灰层次 |
| #F5F2EB | 米白主背景 |
| #f2efe8 / #f0ede6 / #e8e4dc / #e0ddd5 | 米白层次（表面/卡片/分割） |
| #e06666 / #c05050 | 警示红（删除/左滑操作） |
| #2e8b57 / #8ebaa3 | 羽毛绿（成功/自然点缀） |

每页色彩主角：首页偏暖墨绿 + 鹅黄；图鉴页冷雾灰网格；详情页深墨绿 Hero；个人页墨绿渐变头图 + 鹅黄环形进度。

## 字体

`"PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", sans-serif`；代码/接口文档 `monospace`。

## 小程序端侧布局（硬约束达成）

- 胶囊按钮：右上角「··· / ⊙」自定义导航栏，随页面变化（透明/渐变/吸顶变色）
- 页面栈 push/pop：右滑返回手势过渡
- 底部 TabBar：5 项，中间悬浮发布按钮带振翅微动效，选中态微动
- ActionSheet 半屏弹层：发布页鸟种选择 / 图片位
- 下拉刷新：弹性回弹
- 吸顶分类 Tab：图鉴页
- 表单页底部安全区主按钮：发布页
- 骨架屏加载：列表加载态

## 页面结构（8 页）

1. 首页：渐变 header + 统计卡 + 观鸟动态卡片流 + 悬浮发布按钮
2. 图鉴页：搜索栏 + 吸顶分类 Tab + 双列瀑布网格
3. 详情页：Hero 大图 + 信息网格 + 横向画廊 + 吸底操作栏（收藏/分享/记录）
4. 发布页：九宫格上传 + 鸟种选择（ActionSheet）+ 表单 + 安全区主按钮
5. 个人中心：渐变头图 + 环形进度（观鸟数）+ 宫格菜单 + 横向记录流
6. 消息通知：通知列表（左滑删除语义）
7. 设计规范：色彩体系 + 字体排版 + 间距 + 组件示例
8. 接口文档：可折叠分组 + 代码高亮 + 错误码

## 布局多样性

首页卡片流、图鉴瀑布网格、详情页 Hero+吸底、发布页九宫格+表单、个人页渐变头图+宫格、消息列表、规范页文档、接口页手风琴——8 页中 ≥5 页独特非重复布局。

## 签名动效

- 首页：羽毛飘落入场序列 + 下拉刷新弹性回弹
- 个人页：环形进度动画 + 宫格交错入场
- 详情页：滚动视差 + 收藏心跳
- TabBar：选中态微动 + 发布按钮振翅微动效

共 12+ 组件级特效，动效周期各不相同，符合观鸟主题语义。

## 技术栈

React 18 + Babel standalone（JSX/CSS 全内联 index.html）。支持 prefers-reduced-motion 降级；RAF/定时器随页面可见性暂停、卸载取消。

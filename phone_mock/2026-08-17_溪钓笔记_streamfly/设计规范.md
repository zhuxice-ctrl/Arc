# 设计规范 · 溪钓笔记 Streamfly

> 日期：2026-08-17 · 方向：V2 手机 UI · 形态：原生 App · 主题：溪流飞钓手账应用

## 形态说明

原生手机 App 形态（iOS / Android 原生产品形态）。使用大标题导航栏、返回栈导航、底部 TabBar（原生质感）、悬浮操作按钮 FAB、底部半屏抽屉、下拉刷新弹性、长按快捷菜单、模态详情页转场等原生端侧交互。

## 色彩系统

主色取自溪流与山林，冷杉绿为主、鳟鱼橙点睛。

| 角色 | 色值 | 用途 |
|---|---|---|
| 深杉绿 | `#1F3D2B` / `#0E1A14` | 主背景、导航栏 |
| 杉绿 | `#2A5238` / `#1A2F22` | 卡片底、分区 |
| 溪石青 | `#7FA8A0` / `#A8C6BF` | 辅助、图标、分割 |
| 鳟鱼橙 | `#E07B39` / `#C46428` | 主强调，FAB、选中态、CTA |
| 溪雾白 | `#F2F5F1` / `#E8EDE6` | 正文、浅色页面底 |
| 岩灰 | `#3A3935` / `#4F4E48` | 次级文字、中性 |
| 浅绿 | `#C8E6C9` / `#8E8D85` | 标签、成功态 |

禁止蓝紫渐变。

## 字体

- 展示字体 `--font-display`：页面大标题。
- 正文 `--font-body`：渔获记录、图鉴说明。
- 等宽 `--font-mono`：坐标、重量读数。

## 组件规范

- 底部 TabBar：5 项，选中态鳟鱼橙 + 图标弹跳。
- FAB 悬浮按钮：鳟鱼橙圆形，点击展开新建渔获。
- 卡片堆叠：渔获记录页 card stack 布局。
- 底部半屏抽屉：标点地图页可展开收起。
- 瀑布流：毛钩图鉴双列拼贴。
- 毛玻璃指标卡：溪流情报页视差 Hero 上的半透明卡。

## 动效系统

1. 自定义光标（白环 + 橙点 + 发光，悬停形变，点击涟漪，开页居中）
2. 三层波浪（首页 Hero，周期各异）
3. 鱼游动轨迹
4. 毛钩漂浮
5. 定位钉脉冲
6. 环形进度条填充
7. 入场序列动画（staggered）
8. 点击涟漪
9. Tab 下划线弹性
10. 卡片 hover 抬升
11. FAB 图标旋转
12. 视差滚动
13. 水波条纹

## 页面结构（8 页）

首页（Hero 波浪 + 快捷入口 + 渔获横滑 + FAB）→ 渔获记录（卡片堆叠 + 筛选 + 下拉刷新）→ 标点地图（脉冲定位钉 + 半屏抽屉）→ 毛钩图鉴（瀑布流 + 搜索 + Tab）→ 溪流情报（视差 Hero + 毛玻璃卡 + 五天钓况）→ 钓友社群（分段控件 + 信息流）→ 设计规范 → 接口文档。

## 技术栈

React + Babel 内联 JSX（`<script type="text/babel">`），CSS 内联，无外部 src 引用。

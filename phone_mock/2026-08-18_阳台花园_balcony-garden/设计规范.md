# 阳台花园 · 设计规范

形态：微信小程序

> 方向：V2 手机 UI · 主题：阳台园艺种植微信小程序
> 日期：2026-08-18

## 色彩系统

| 角色 | 色值 | 用途 |
|------|------|------|
| 苔绿主色 | `#6b8e5f` / `#4a6b3d` | 主品牌色、TabBar 选中、主按钮 |
| 深苔绿 | `#2d3a2e` | 深色块、导航栏深态 |
| 陶土橙 | `#d68b54` / `#c27340` | 辅助强调、提醒、价格 |
| 鹅黄 | `#d4a017` / `#b8860b` | 点缀、评分、徽标 |
| 奶白底 | `#f7f5ee` / `#f0ede5` | 页面背景、卡片表面 |
| 浅绿白 | `#e8f0e3` / `#a8d5a0` | 次级表面、标签底 |
| 暖白 | `#fff7e6` / `#fff0e0` | 高光卡片、提醒卡 |
| 警示红 | `#e05b5b` | 删除、过期 |
| 信息蓝 | `#4a90c9` | 链接（少量） |

每页在主配色基础上取 3–5 个色调层次作"色彩主角"：花园页偏苔绿、图鉴页偏鹅黄网格、提醒页偏陶土橙、个人页偏深苔绿渐变，整体统一无蓝紫渐变。

## 字体

系统字体栈：`-apple-system, BlinkMacSystemFont, "PingFang SC", "Microsoft YaHei", sans-serif`，字号阶梯遵循小程序规范。

## 端侧交互语言（9 种）

页面栈 push/pop、底部 TabBar（选中微动效）、半屏弹层 ActionSheet、下拉刷新弹性回弹、左滑列表操作、吸顶 Tab、吸底主按钮、骨架屏加载、浮动操作球。

## 页面结构（8 页，布局全差异化）

1. 我的花园（首页）— Hero 大图 + 双列瀑布流卡片 + 浮动操作球，入场序列动画 + 叶片摇曳
2. 植物图鉴 — 吸顶筛选 Tab + 横向精选轮播 + 三列网格拼贴
3. 养护提醒 — 环形进度卡片 + 时间线列表，左滑操作（完成/删除）
4. 花友圈 — 话题流 + 社交卡片流（点赞/评论/分享）
5. 个人中心 — 渐变 Hero + 数据条 + 四宫格 + 列表项
6. 植物详情 — Hero 大图视差 + 吸顶分段 Tab + 吸底操作栏 + 半屏弹层浇水确认
7. 设计规范 — 对角分割 Hero + 色卡矩阵 + 字体/间距/圆角/组件规范
8. 接口文档 — 深色代码风 + 分组 Tab + 三接口分组（植物/养护/花友圈）

## 签名动效

- 首页入场序列动画（stagger fade-up，植物生长语义）
- 环形进度 + 叶片摇曳 + 水滴浮动（园艺主题语义）

## 健壮性

- 全部 JSX/CSS 内联
- RAF/定时器随 visibilitychange 暂停、卸载取消
- 高频事件直接操作 DOM transform
- prefers-reduced-motion 降级

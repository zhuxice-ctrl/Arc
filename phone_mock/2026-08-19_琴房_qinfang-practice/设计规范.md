# 琴房 · 乐器练习 App — 设计规范

**类别**：Phone Mock　**日期**：2026-08-19　**形态：原生 App**

## 设计概念
「琴房」是乐器练习者每天打开的原生 App：今天练什么、琴调准了没有、节拍稳不稳、练了多久——一条真实完整的练习流，不是作品集展示。视觉来源是一间安静的私人琴房：深胡桃木、奶油谱纸、黄铜节拍器、墨黑谱线。

## 色彩系统（真实色值，取自源码高频统计）
- 深胡桃木棕：`#2a2420`（54 处，主背景）/ `#3d2f20`、`#1a1410`（深色层级）
- 黄铜金：`#c99a3e`（40 处，主强调）/ `#8b6914`、`#e8c87a`、`#f4d487`、`#6b4d0e`（黄铜明暗自阶）
- 奶油谱纸：`#f5edd9`（25 处）/ `#fff9ec`（谱纸卡片）
- 调音绿区：`#2e7d32`（"准了"状态）
- 朱砂印章红：`#8b2020`（打卡印章）
- 辅助暖橙：`#e08a2a` / `#c95520`

无蓝紫渐变。色彩分工：胡桃木=琴房空间，奶油=谱纸与内容，黄铜=乐器与强调，绿=调准状态，朱砂=打卡完成。

## 字体系统
- 正文/UI：Noto Sans SC（原生 App 无衬线系统字感）
- 曲目名/标题：Noto Serif SC（谱面感）

## 产品结构
原生形态：状态栏 + 动态岛 + 底部 TabBar（今日 / 调音 / 记录 / 我的）+ Home Indicator。核心 User Flow：今日练习任务 → 调音器（弹簧-阻尼指针，进绿区显示"准了"，六弦切换）→ 节拍器（拖拽黄铜摆锤设定 BPM 40–208，松手单摆物理摆动，端点节拍脉冲；广板60/行板76/中板100/快板132/急板168 速度铭牌；2/4、3/4、4/4、6/4 拍号切换）→ 练习计时 → 打卡印章 → 周记录（连续天数、时长统计）。「我的」内含设计规范页与接口文档页（6 个 API 端点）。

## 动效系统（≥12 组件级）
摆锤单摆物理、调音指针阻尼摆动、打卡印章落纸、谱纸翻页、数字翻牌、节拍呼吸、烛火微抖、柱状图生长、按钮涟漪、页面滑入、Tab 上浮、进度条填充。

## 签名交互
节拍摆锤：按住摆锤滑块沿摆杆上下拖动设定 BPM，松手后摆锤以真实单摆物理来回摆动，摆到端点触发节拍脉冲与计数，界面随节拍微微"呼吸"。

## 自定义光标
黄铜金圆点，开页即显示在屏幕中央，悬停放大，拖拽变细。

## 内容系统
真实曲目：《渔舟唱晚》《茉莉花》《阳关三叠》，含目标小节、当前熟练度、分段进度；调音记录、连续练习天数、本周时长统计均为内部一致的可信数据。

## 工程
单 HTML 文件；390×844 与邻近尺寸无横向溢出、无 console error；RAF/定时器随可见性暂停；快速操作不叠加定时器；支持 prefers-reduced-motion。

# 纸上航行 · 独立出版小程序

> 日期：2026-08-17 · 方向：V2 手机 UI · 形态：微信小程序 · 主题：独立出版与 Zine 小店小程序

## 简介

「纸上航行」是一个独立出版与 Zine 小店的微信小程序形态手机端 mock。围绕独立杂志、Zine、艺术家书、小志出版物组织真实可信内容（刊物详情、出版人故事、新刊上架、线下翻阅会活动等），在统一手机外壳内提供 8 个可切换页面，涵盖小程序端侧交互语言（胶囊按钮、页面栈 push/pop、吸顶 Tab、下拉刷新弹性回弹、左滑列表操作、骨架屏加载、半屏 ActionSheet、底部安全区主按钮）。

## 形态

形态：微信小程序（V2 双形态交替：上一次为「原生 App」，本次为「微信小程序」）

## 动效亮点

- 首页 Hero 入场序列动画（文字渐入 + 打字机 + 卡片堆叠）
- 详情页视差滚动 Hero + 骨架屏加载
- 我的页环形阅读进度动画 + 环形头像光效
- Tab 指示器弹性滑动、下拉刷新弹簧回弹、FAB 旋转、光泽扫过按钮等共 12+ 组件级特效

## 配色

芥末黄 `#E3B23C` + 深墨绿 `#2F4A3E` + 纸白 `#F7F3E9` + 珊瑚橙 `#E8714A`，每页独立色彩主角，整体统一在同一体系内（禁用蓝紫渐变）。

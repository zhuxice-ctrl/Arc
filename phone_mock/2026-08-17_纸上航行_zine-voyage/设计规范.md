# 纸上航行 · 独立出版小程序 — 设计规范

> 日期：2026-08-17 · 方向：V2 手机 UI · 形态：微信小程序 · 主题：独立出版与 Zine 小店小程序

## 一、色彩系统

| 角色 | 色值 | 用途 |
|---|---|---|
| 主色 · 芥末黄 | `#E3B23C` | TabBar 选中、主按钮、强调标签 |
| 浅芥末 | `#EFC96B` | 主色悬停 / 渐变亮端 |
| 深墨绿 | `#2F4A3E` | 详情页 Hero、深色区块底、标题 |
| 深墨绿 2 | `#3E5F50` | 卡片深色变体 |
| 暗墨 | `#1E3329` | 出版人页暗底 |
| 纸白 | `#F7F3E9` | 页面主底色（纸质感） |
| 暖纸 | `#F0E8D5` | 卡片表面、分区底色 |
| 珊瑚橙 | `#E8714A` | 活动页 Hero、强调 CTA、状态点 |
| 浅珊瑚 | `#F09070` | 珊瑚橙渐变亮端 |
| 深珊瑚 | `#D05A36` | 珊瑚橙按压态 |
| 炭褐 | `#2A251E` / `#1a1814` | 正文文字 |
| 中性灰褐 | `#5A5449` / `#8B8578` | 次级文字、辅助说明 |
| 薄荷绿 | `#93c5a0` | 辅助点缀（发现页色块） |

每页有独立「色彩主角」：首页暖调（芥末黄主导）、发现页纸白、详情页深绿、活动页珊瑚橙、个人页深绿+金黄，整体统一在「芥末黄 × 深墨绿 × 纸白 × 珊瑚橙」体系内。禁用蓝紫渐变。

## 二、字体

- 标题 / 装饰：`'Noto Serif SC', serif`（思源宋体，呼应出版物的纸本质感）
- 正文 / UI：`'Noto Sans SC', -apple-system, BlinkMacSystemFont, sans-serif`
- 代码 / 数字：`'Space Mono', monospace`（接口文档页）

## 三、小程序端侧交互（≥4 种）

1. **胶囊按钮导航栏**：右上角「··· / ⊙」胶囊，点击弹出 ActionSheet 半屏面板
2. **页面栈 push/pop**：详情页右滑返回式过渡动画
3. **吸顶 Tab**：发现页分类吸顶切换，指示器弹性滑动
4. **底部安全区主按钮**：详情页吸底操作栏
5. **下拉刷新弹性回弹**：列表页顶部下拉弹簧回弹
6. **左滑列表操作**：我的页订单左滑删除
7. **骨架屏加载**：详情页进入时骨架屏过渡
8. **半屏弹层 ActionSheet**：胶囊按钮触发的动作面板

## 四、页面结构（8 页，布局各异）

1. **首页** — Hero 入场序列（文字渐入 + 打字机 + 卡片堆叠）、搜索框、分类 chip、新刊横向滚动、出版人头像条、活动大卡
2. **发现页** — 吸顶 Tab 切换、瀑布流双列、下拉刷新弹性回弹、逐张滚动渐入
3. **刊物详情页** — 视差滚动 Hero、骨架屏加载、数据统计行、内页画廊、底部吸底操作栏
4. **出版人页** — 大字号暗底 Hero、左侧色条卡片列表、关注交互
5. **活动页** — 珊瑚橙渐变 Hero、时间轴布局、脉冲状态点、悬浮操作球 FAB
6. **我的页** — 环形阅读进度动画、环形头像光效、四列宫格菜单、左滑列表操作
7. **设计规范页** — 色板、字体排印、图标系统、间距标尺、圆角阴影
8. **接口文档页** — 深色代码风格头部、7 个 `/api/miniprogram/v1/*` 假接口端点，可展开含参数表与 JSON 响应

## 五、动效系统（12+ 组件级特效）

打字机光标、Hero 入场序列、堆叠卡片悬停浮起、涟漪点击、滚动渐入、视差滚动、环形进度填充、头像环旋转、脉冲呼吸点、光泽扫过按钮、Tab 指示器弹性、FAB 旋转、数字计数、下拉弹簧回弹。

## 六、技术栈

React + Babel 单文件内联（`index.html`），所有 JSX 内联于 `<script type="text/babel">`，CSS 内联于 `<style>`；支持 `prefers-reduced-motion` 降级、`visibilitychange` 动画暂停。

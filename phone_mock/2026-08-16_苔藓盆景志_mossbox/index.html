物种简介
白发藓 · Leucobryum glaucum
白发藓科白发藓属，植物体密集丛生，呈灰绿色或灰白色。叶细胞大形，无色透明，常与绿色细胞相间排列。多生于林下腐木或岩面薄土，喜高湿环境，是苔藓微景观中的常见品种。

接口文档
苔盆管理
GET /api/v1/terrariums
获取当前用户所有苔盆列表
响应示例
// 200 OK { "total": 12, "items": [ { "id": "ter_001", "name": "青雪", "species": "leucobryum_glaucum", "humidity": 78, "days": 42, "health": "excellent" } ] }
POST /api/v1/terrariums
创建新的苔盆
请求体
{ "name": "翠峦", "species_id": "sp_002", "container": "陶土方盆", "substrate": "赤玉土+水苔" }
GET /api/v1/terrariums/:id
获取单个苔盆详细信息与湿度历史
响应示例
// 200 OK { "id": "ter_001", "name": "青雪", "humidity_history": [ [1692000000, 72], [1692086400, 78] ], "watering_schedule": { "next_spray": "2023-08-16T20:00:00", "frequency": "BID" } }
养护记录
POST /api/v1/records/spray
提交一次喷雾记录
{ "terrarium_id": "ter_001", "sprays": 12, "humidity_before": 62, "humidity_after": 78, "note": "晨间喷雾" }
GET /api/v1/records
获取养护记录列表（分页）
// Query: ?page=1&limit=20&type=spray { "page": 1, "total": 128, "items": [...] }
GET /api/v1/weather/:city

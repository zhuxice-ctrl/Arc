## 概述

一个完整多页面的苔藓微景观养护 App，在统一手机外壳内可切换 8 个页面：今日晨露、花园、图鉴、喷雾日志、市集、详情、设计规范、接口文档。围绕「养护一盆苔藓」的日常仪式组织内容与动效。

- **方向**：手机应用 UI
- **主题**：苔藓盆景养护
- **配色**：苔藓深绿 #2d4a1f + 羊皮米 #fffdf6 + 陶土棕 #a67b5b（无蓝紫渐变）
- **实现**：纯 vanilla 单文件 HTML+CSS+JS，8 页面 + 设计规范 + 接口文档

## 交互说明

- 底部 Tab 切换 8 页面，带滑动指示条与内容渐入。
- 今日页湿度/光照/温度数字计数动画，顶部苔藓随湿度「呼吸」。
- 花园盆景卡片 3D 倾斜（随设备指向/鼠标）。
- 详情页顶部喷雾粒子动画。
- 日志页时间线逐条展开。
- 自定义光标开页居中显示，悬停可交互元素形态变化，点击涟漪。

## 动效原理

详见 [设计规范.md](./设计规范.md)。12+ 组件级特效，基于物理模型（弹簧回正、粒子重力下落、正弦呼吸）与主题语义（喷雾、晨露、苔藓呼吸）。

## 健壮性

- 切换页面前清理旧定时器/RAF，不叠加。
- 高频事件直接 DOM transform。
- visibilitychange 暂停 RAF；卸载取消。
- 支持 prefers-reduced-motion。

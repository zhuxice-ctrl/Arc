# 屿浪 · 设计规范 v1.0

> 海岛声音图鉴小程序 · 设计系统文档

## 一、设计理念

屿浪的视觉语言来自海岛本身的材质——暖沙的底、珊瑚的色、浪纹的节奏。
不追求科技感，而追求「把耳朵贴在贝壳上」的温度。

## 二、色彩体系

### 2.1 核心色板

| 色名 | HEX | RGB | 用途 |
|------|-----|-----|------|
| 珊瑚棕 · 主色 | `#C67A5C` | 198,122,92 | 主按钮、选中态、强调文字、图标色 |
| 浅珊瑚 · 辅助色 | `#E8B89C` | 232,184,156 | 渐变起点、柔和强调、淡标签底 |
| 暖沙 · 页面底 | `#F8F3EB` | 248,243,235 | 页面背景、卡片底（白上加一层暖意） |
| 深棕 · 主文字 | `#2C2620` | 44,38,32 | 一级标题、正文、深色图标 |
| 沙灰 · 次文字 | `#9A8C7A` | 154,140,122 | 二级文字、占位、未选中态 |
| 深底 · API 页 | `#2C2620` | 44,38,32 | 接口文档深色背景 |

### 2.2 使用原则

- 主色占比控制在 10–15%，作为视觉锚点而非铺陈
- 暖沙底色是基调，所有白色卡片在暖沙上有温度感
- 每页保持 3–5 个色调层次：主色 / 辅助色 / 表面色 / 中性色 / 强调色
- 不同页面可以有自己的"色彩主角"：
  - 首页：暖沙 + 珊瑚（偏暖）
  - 分类页：米黄 Hero + 暖沙底（明暗对比）
  - 详情页：图片主导 + 珊瑚操作区
  - 接口文档页：深棕底 + 沙色文字（冷暖反转）

## 四、间距与圆角

### 4.1 间距基准（4px 栅格）

```
4px  ·  8px  ·  12px  ·  16px  ·  20px  ·  28px
```

- 元素内边距：12 / 16 / 20
- 元素间距：8 / 12 / 16
- 节间距：24 / 28

### 4.2 圆角基准

```
6px  ·  10px  ·  14px  ·  18px  ·  24px  ·  28px
```

- 小按钮 / 标签：6–10px
- 卡片 / 列表：12–14px
- 大卡片 / Hero 装饰：18–28px
- 弹层顶部：24–28px

## 五、组件规范

### 5.1 按钮

| 类型 | 样式 | 使用场景 |
|------|------|----------|
| 主按钮 | 珊瑚渐变 + 阴影 + 光泽扫过 | 主要行动：立即收听、提交 |
| 次按钮 | 白底 + 棕边 | 次要行动 |
| 图标按钮 | 暖沙底 + 圆形 | 工具栏 |
| 标签按钮 | 珊瑚淡底 + 全圆角 | 分类标签 |

### 5.2 卡片

- 白底 + 14px 圆角 + 柔和阴影（`rgba(92,74,54,0.06–0.1)`）
- 图片区：`object-fit: cover`，悬停 `scale(1.05)`
- 信息区：10–14px 内边距

### 5.3 列表

- 左图右文，64px 方形图 + 12px 圆角
- 分隔线：`rgba(0,0,0,0.05)`
- 左滑操作：64px 宽按钮，收藏（珊瑚）/ 删除（深棕）

### 5.4 TabBar

- 高度：83px（含安全区）
- 毛玻璃背景：`rgba(255,253,248,0.92)`
- 选中色：珊瑚 `#C67A5C`
- 未选中色：沙灰 `#9A8C7A`
- 选中动效：图标 `translateY(-2px) scale(1.08)` + 底部圆点弹出

## 六、动效规范

### 6.1 缓动曲线

- 标准：`cubic-bezier(.2,.8,.2,1)`（页面切换、弹层）
- 弹性：`cubic-bezier(.2,.9,.3,1.3)`（图标、按钮缩放）
- 进入：`cubic-bezier(.2,.8,.2,1)` 0.3–0.8s

### 6.2 动效原则

- 符合主题语义：波浪起伏、声波扩散、贝壳开合
- 周期各不相同：避免整齐划一的同步感
- 克制使用：每个页面 2–3 个签名动效，其余为微交互
- 支持 `prefers-reduced-motion`：降级为最小动效

### 6.3 动效清单

| 动效 | 位置 | 物理模型 |
|------|------|----------|
| 双层波浪 | 首页 Hero | 正弦叠加，相位差 |
| 声波脉冲点 | 岛屿卡片 | 呼吸缩放，阻尼振荡 |
| 频谱柱振动 | 详情页波形 | 正弦 + 随机噪声 |
| 环形扩散 | 详情页播放 | 同心环匀速扩散 |
| 下拉回弹 | 首页 | 弹簧（位移阻尼） |
| 光标拖尾 | 全局 | 线性插值（lerp 0.18） |

## 七、页面布局语言

| 页面 | 布局特色 |
|------|----------|
| 首页 | Hero 大图 + 横向岛屿卡片 + 瀑布流声音卡片 |
| 分类页 | 渐变 Hero + 吸顶 Tab + 左滑操作列表 |
| 详情页 | 全屏 Hero 视差 + 底部圆角切角 + 吸底操作栏 |
| 个人页 | 渐变顶栏 + 三列统计 + 四列宫格 + 环形进度 |
| 设计规范 | 纵向分节 + 5 色色卡 + 字号样本 + 间距栅格 |
| 接口文档 | 深色代码风 + API 卡片堆叠 |

每一页布局结构均不同，避免了"标题栏 + 列表"的统一骨架。

## 八、无障碍

- 正文对比度 ≥ 4.5:1（深棕 #2C2620 ／ 暖沙 #F8F3EB → 约 10.2:1）
- 支持 `prefers-reduced-motion`
- 所有可交互元素有明确的 hover / active 视觉反馈
- 图标均有文字标签配合，不单独依赖颜色传达信息

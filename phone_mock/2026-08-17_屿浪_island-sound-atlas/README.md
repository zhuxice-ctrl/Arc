# 屿浪 · 海岛声音图鉴

> V2 手机 UI mock · 微信小程序形态
> 收录海岛的声音，踏足 12 座岛屿，收集 142 段海岸、崖壁与潮池之声。

## 一、主题与领域

- **领域**：文化艺术 / 自然探索——海岛声音图鉴
- **产品形态**：微信小程序
- **命名**：屿浪（Sound Atlas）
- **一句话定位**：一座可随身携带的海岛声音博物馆，记录与分享中国沿海岛屿的自然之声。

## 二、形态标记

本次为 **微信小程序** 形态（交替规则：上一次 phone_mock 最新产出为「骑迹 veloroute」——原生 App 骑行产品，故本次切换为小程序）。

下一次 V2 手机 mock 应做：**原生 App**。

## 三、页面清单（8 个视图）

1. **首页**（卡片流 + 岛屿横向滚动 + 声音瀑布流 + Hero 大图）
2. **分类图鉴页**（吸顶 Tab + 左滑操作列表）
3. **声音详情页**（Hero 视差 + 底部吸底操作栏 + 声波可视化 + ActionSheet 分享）
4. **个人中心页**（头像脉冲 + 数据统计 + 宫格入口 + 环形收集进度）
5. **设计规范页**（色彩 / 字体 / 间距 / 组件示例）
6. **接口文档页**（深色代码风，5 个接口示例）
7. **骨架屏加载态**（首页 / 列表 / 个人中心三套）
8. **分享 ActionSheet**（半屏弹层动效）

## 四、小程序端侧交互语言（已实现 ≥4 种）

- 自定义胶囊按钮（右上角 "··· / ⊙"）
- 底部 TabBar 4 栏，选中态有微动效与下圆点指示
- 页面栈 push/pop 切换（详情页 / 接口文档页叠层进入）
- 半屏弹层 ActionSheet（分享面板）
- 下拉刷新弹性回弹（首页声波图标 + 刷新指示）
- 左滑列表操作（分类图鉴页收藏 / 删除）
- 吸顶 Tab（分类页 5 个分类标签）
- 底部吸底操作栏（详情页安全区主按钮）
- 骨架屏加载（首页/列表/个人中心三套骨架）

## 五、签名动效（≥2 个页面级）

1. **首页 Hero 声波动画**——SVG 双层波浪，不同周期上下错位起伏
2. **详情页声波可视化**——48 条频谱柱，基于正弦 + 噪声实时振动，播放时激活
3. **个人页环形收集进度**——SVG 圆环渐变，带脉冲光环
4. **详情页声波环形扩散**——三层同心环向外扩散，播放时激活
5. **首页入场序列动画**——逐层 fade-up 错峰入场

## 六、组件级动效（≥12 个）

1. 自定义光标（白色粗环 + 珊瑚色内点 + 多层发光 + 悬停放大变色 + 点击涟漪）
2. 声波脉冲圆点（island-card 上的呼吸点）
3. TabBar 选中缩放 + 底部圆点弹出
4. 卡片悬停上浮 + 图片微缩放
5. 主按钮光泽扫过（shine 动效）
6. 头像脉冲光环
7. 骨架屏渐变扫光
8. 详情页 Hero 视差滚动
9. ActionSheet 底部滑入 + 遮罩淡入
10. 左滑操作弹性滑出
11. 下拉刷新弹性回弹 + 旋转加载
12. 宫格图标悬停上浮缩放
13. 页面切换位移 + 透明度过渡

## 七、配色方案

暖沙海色系，避开蓝紫渐变陈词滥调：

| 色名 | 色值 | 用途 |
|------|------|------|
| 主色（珊瑚棕） | #C67A5C | 主按钮、选中态、强调 |
| 辅助色（浅珊瑚） | #E8B89C | 渐变、辅助强调 |
| 暖沙底色 | #F8F3EB | 页面背景 |
| 深棕文字 | #2C2620 | 标题、正文 |
| 辅助文字 | #9A8C7A | 次要信息、占位 |

## 八、字体

- **标题展示字体**：ZCOOL XiaoWei（站酷小薇宋体）——兼具手写温度与宋体端正
- **衬线字体**：Noto Serif SC —— 次级标题、卡片名称
- **正文字体**：Noto Sans SC —— 正文、辅助文字

## 九、健壮性

- 所有 RAF / 定时器在 visibilitychange 时暂停
- 自定义光标支持 reduced-motion 降级
- 组件卸载统一清理
- 无外部 JSX src 引用，全部内联在 index.html

## 十、交互入口速查

- 点击底部 TabBar 切换 4 个主页面
- 点击声音卡片 / 列表项 → 进入详情页（左上角返回）
- 详情页点击分享 → 弹出 ActionSheet
- 详情页点击播放 → 声波柱开始

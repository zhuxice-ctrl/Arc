# 便当手帖·设计规范

形态：微信小程序

## 设计母题
便当盒拼装 + 营养均衡环 + 周手帖——把便当盒可视化成 4 格（主食/主菜/配菜/点缀），点食材落入对应格，营养四维环实时反馈，装满生成便当卡片存入手帖，周回顾看均衡趋势。

## 空间模型
便当盒 4 格拼装（bento grid compose）+ 周手帖时间线。禁用通用首页模板（问候语+搜索+Banner+分类图标+推荐+底部导航那套）。

## 色彩系统（漆木红便当盒 + 食材自然色，禁蓝紫）
| 变量 | 色值 | 用途 |
|---|---|---|
| --lacquer-red | #8B3A3A | 便当盒漆木红 / 主品牌 |
| --rice-white | #F5EFE0 | 米白背景 |
| --ink-black | #2A2622 | 墨黑文字 |
| --plum-red | #C0392B | 梅干朱红 / 维生素 |
| --egg-gold | #E8B84B | 玉子金黄 / 碳水 |
| --broc-green | #6B8E4E | 西蓝花绿 / 纤维 |
| --brown-rice | #C9A87C | 糙米褐 |
| --salmon-pink | #E89880 | 三文鱼 / 蛋白 |
| --burdock-brown | #8B6F4E | 牛蒡 |

营养环语义色：碳水=#E8B84B（金黄）、蛋白=#E89880（鲑粉）、纤维=#6B8E4E（西蓝绿）、维生素=#C0392B（朱红）——四色一一对应食材真实色，营养维度可视即懂。

## 字体
- 展示标题：`"Apple Chancery", "Kaiti SC", "STKaiti", "楷体", cursive`——手写楷体，便当手帖的私人手账感。
- 正文：系统无衬线（var(--font-body)）。
- 数字：`"SF Mono", "Menlo", monospace`——等宽，营养数值对齐。

## 动效系统（小程序原生弹簧感 + 食材落入物理）
CSS keyframes：foodDrop（食材落入弹簧）、readyPulse（就绪脉冲）、scorePop（分数弹跳）、signWrite（便当签名书写）、tabSlide（Tab 切换）、enterRight/leaveLeft（页面栈进出）、spin（loading 旋转）。
缓动：弹簧 `cubic-bezier(.34,1.56,.64,1)`、ease-out `cubic-bezier(.22,.61,.36,1)` / `cubic-bezier(.23,1,.32,1)`。
- 下拉刷新弹性回弹、半屏弹层弹簧上滑、左滑操作、Tab 弹簧切换、盒盖合拢。
- RAF/定时器随可见性暂停且卸载取消，支持 `prefers-reduced-motion`。

## 微信小程序端侧交互（≥4 种）
1. 底部 TabBar（4 Tab：今日 / 便当盒 / 手帖 / 我的）
2. 胶囊按钮自定义导航栏
3. 半屏弹层（half-sheet，弹簧上滑）
4. 下拉刷新弹性回弹（touchmove 阻尼 + 回弹）
5. 左滑操作（手帖项收藏 / 删除）
6. 页面栈 push/pop 转场

## 核心交互
1. 点食材 → 落入便当盒对应格（主食/主菜/配菜/点缀），掉落弹簧动画
2. 营养均衡环（碳水/蛋白/纤维/维生素）SVG stroke-dasharray 实时计算
3. 4 格装满 → 盒盖合拢 + 签名动效 + 半屏弹层生成便当卡片
4. 存入今日手帖 → 周回顾折线趋势 + 营养均值 + 洞察文案

## 内容
16 种真实食材：糙米饭、照烧鸡腿、玉子烧、西蓝花、梅干、毛豆、三文鱼、牛蒡丝、腌萝卜、味噌汤等，各含营养属性。3 个灵感预设（经典/三文鱼/野菜便当）一键填入。

## 持久化
localStorage：手帖历史、收藏状态、今日便当。

## 接口契约
假接口统一 `/api/mobile/v2/*`，含设计规范页 + 接口文档页。

## 技术栈
纯 vanilla 单文件（HTML + CSS + JS），无 React/Babel/CDN。手机尺寸 375×812 及邻近正常显示，拇指可达区考虑。

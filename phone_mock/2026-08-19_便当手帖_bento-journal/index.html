设计规范 · Design System

便当手帖 · 微信小程序。设计语言源自日式便当盒的漆木红与米饭米白，配以食材自然色，传达「好好吃饭」的温暖日常感。

字体系统

使用系统原生字体栈，保障小程序性能与一致性。

-apple-system, BlinkMacSystemFont, "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", sans-serif

标题 22px · Bold

副标题 16px · Semibold

正文 14px · Regular

辅助 12px · Light

间距系统

基于 4px 网格的间距体系：4 / 8 / 12 / 16 / 20 / 24 / 32px。

圆角：6 / 12 / 20 / 28px，对应 sm / md / lg / xl。

动效系统

采用微信小程序原生弹簧感曲线：

--spring: cubic-bezier(.34, 1.56, .64, 1) — 强弹簧

--spring-soft: cubic-bezier(.23, 1, .32, 1) — 软弹簧

--ease-out: cubic-bezier(.22, .61, .36, 1) — 标准缓出

所有动效遵循 prefers-reduced-motion 设置，页面不可见时暂停 requestAnimationFrame。

端侧交互语言

① 底部 TabBar：4 个 tab 切换，原生回弹

② 胶囊按钮导航栏：微信小程序标志性自定义导航

③ 半屏弹层（half-sheet）：从底部滑入，弹簧曲线

④ 下拉刷新：touchmove 弹性阻尼 + 回弹

⑤ 左滑操作：transform translateX 露出操作按钮

形态说明

本作品为微信小程序形态的设计原型，在手机尺寸（375×812）下完整呈现。所有交互遵循微信小程序端侧语言规范。

接口文档 · API

Base URL: /api/mobile/v2

全部接口返回格式：{"code": 0, "msg": "ok", "data": {...}}

保存便当

POST /api/mobile/v2/bento/save

将拼装好的便当存入今日手帖。

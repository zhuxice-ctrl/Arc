# 岩点 BetaLab · 攀岩馆微信小程序 — 设计规范

形态：微信小程序

- **日期**：2026-08-17
- **方向**：V2 手机 UI
- **主题**：抱石攀岩馆微信小程序——今日线路墙、线路 Beta 分解、约课、岩友打卡、会员次卡
- **风格**：岩壁质感、难度色标体系、暗色 Hero + 暖面卡片

- 显示 / 数字：`'Space Grotesk', 'Noto Sans SC', sans-serif`

## 小程序端侧交互（已实现 8 种）

页面栈 push/pop 右滑返回、底部 TabBar（5 个弹跳选中）、半屏 ActionSheet、下拉刷新弹性回弹、左滑列表操作、吸顶筛选 Tab、骨架屏加载、吸底操作栏、胶囊按钮自定义导航栏

## 页面结构（8 页，布局各异）

1. 首页 — 深色 Hero + 宫格入口 + 今日线路墙 + 热门卡片流
2. 线路中心 — 吸顶筛选 chips + 难度色标瀑布流 + 下拉刷新 + 骨架屏
3. 线路详情 — Hero 视差大图 + 上滑内容 + Beta 分步 + 吸底操作栏 + 分享半屏弹层
4. 约课中心 — 渐变 Hero + 周历 + 课程卡 + 教练列表 + 预约确认抽屉
5. 岩友动态 — 分段控件 + 动态卡片流 + 左滑操作 + 悬浮发布脉冲
6. 个人中心 — 深色 Hero 头像 + 会员次卡渐变 + 环形训练进度 + 功能宫格
7. 设计规范 — 色板 + 难度色标 + 字体 + 圆角/间距/按钮/图标
8. 接口文档 — 5 个 REST API + 参数 + 响应示例

## 动效系统

1. 自定义光标（白环+橙点+发光+悬停放大+涟漪）
2. 岩点入场序列
3. Tab 弹跳选中
4. FAB 脉冲光环
5. 环形进度渐变描边
6. 数字计数增长
7. 按钮光泽扫过
8. Hero 视差滚动
9. 骨架屏 shimmer
10. 下拉刷新旋转
11. 页面切换 slide-in
12. 滚动渐入揭示
13. 会员卡进度条填充

## 工程特性

- RAF 随 `visibilitychange` 暂停 / 恢复，卸载清理
- mousemove 直接 DOM transform，不触发 React 重渲染
- 支持 `prefers-reduced-motion`
- JSX/CSS 全内联单文件

黑板墨绿为主背景色，粉笔白黄为主要文字色，番茄红用作价格低于心理价时的高亮提示，微信绿为主操作色，符合小程序生态规范。全程禁用蓝紫渐变。

字体系统
展示字体Ma Shan Zheng / 楷体
正文字体PingFang SC
数字字体粉笔手写体 (SVG path)

菜品名、价格、日期等「黑板上的内容」使用楷体/马善政体，模拟粉笔手写质感；UI 辅助文字与操作按钮使用系统默认无衬线字体，形成「黑板内容」与「系统界面」的材质区分。

核心组件

1. 黑板价签：菜品 emoji + 粉笔体菜名 + 粉笔黄价格 + mini sparkline 走势
2. 半屏手写输入：长按菜品唤起，数字以粉笔逐笔 stroke-dashoffset 绘制落定
3. 粉笔粉尘动效：价格写入时从笔尖飘散粉笔粉尘粒子
4. 下拉刷新：下拉超过阈值后弹性回弹，刷新黑板内容
5. 左滑操作：列表项左滑露出删除/编辑操作
6. 底部 Tab 栏：标准微信小程序 4 Tab 导航

动效语言

所有动效围绕「用粉笔在黑板上写字」的核心隐喻展开：

• 粉笔逐笔 stroke 绘制 — 价格写入的签名反馈
• 粉笔粉尘飘落 — 书写时的材质感强化
• sparkline 笔尖延伸 — 新价格即时融入历史走势
• 半屏弹层弹簧上升 — 符合 iOS/小程序的物理感
• 下拉刷新弹性回弹 — 模拟擦拭黑板重写

支持 prefers-reduced-motion 降级为即时呈现，无动画版本信息层级保持完整。

接口文档
GET /api/prices/today
获取今日黑板上所有已记录的菜价列表
Query 参数
market 菜场标识 string
date 日期 YYYY-MM-DD string
{ "date": "2026-08-20", "market": "xingyuan", "items": [ { "id": "tomato", "name": "番茄", "price": 4.5, "unit": "斤", "stall": "张记蔬菜", "history": [4.8, 5.2, 4.5] } ] }
POST /api/prices
记录一条新的菜价（今日黑板记价）
Body 参数
produceId 菜品 ID string
price 单价 number
stall 摊位名 string
bought 是否已购买 boolean
quantity 购买数量（可选） number
{ "code": 0, "message": "ok", "data": { "id": "rec_xxx", "belowTarget": true, "savedAmount": 0.8 } }
GET /api/trends
获取指定菜品的历史价格走势数据
Query 参数
produceId 菜品 ID string
days 天数 7/14/30 number
GET /api/wishlist
获取用户的想买清单
返回字段
id 清单项 ID string
targetPrice 心理价位 number
priceAlert 是否低于心理价 boolean
GET /api/ledger
获取账本数据（按月分组）
Query 参数
month 月份 YYYY-MM string
DELETE /api/prices/:id
删除一条菜价记录

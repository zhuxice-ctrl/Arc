# 设计规范 · 菜场时价黑板

形态：微信小程序

## 一、设计母题

老菜场摊位门口的手写粉笔价目黑板。

整个界面的视觉逻辑：用户打开就像走进自己常去的菜场，看到一块属于自己的、已经写满粉笔价的黑板。记一次价 = 用粉笔写一个数，即时、顺手、有手写质感。

## 二、色彩系统

| 色名 | 色值 | 用途 |
|------|------|------|
| 黑板绿 | #1F3B2D | 主背景色（黑板底） |
| 黑板深 | #0F241A | 弹层/输入区深色底 |
| 粉笔白 | #F5F2EA | 主要文字色 |
| 粉笔黄 | #F2D57A | 价格/标题强调色（粉笔主色） |
| 番茄红 | #E5563A | 低于心理价高亮提示 |
| 微信绿 | #07C160 | 主操作按钮色（符合小程序规范） |
| 木棕 | #6B4A2B | 黑板木框装饰 |

色彩语义：黑板墨绿为主背景，粉笔白黄为主要文字色，番茄红用作价格低于心理价时的高亮提示（番茄本身就是红色，语义贴切），微信绿为主操作色。全程禁用蓝紫渐变。

## 三、字体系统

- **展示字体**：Ma Shan Zheng / 楷体 / STKaiti — 用于菜品名、价格、日期等「黑板上的内容」，模拟粉笔手写质感
- **正文字体**：PingFang SC / 系统默认 — 用于 UI 辅助文字、操作按钮
- **数字字体**：粉笔手写体（SVG path 逐笔绘制）— 价格写入时的签名动效

字体区分形成「黑板内容」与「系统界面」的材质区分。

## 四、核心组件

### 1. 黑板价签
- 结构：菜品 emoji + 粉笔体菜名 + 粉笔黄价格 + mini sparkline 走势
- 交互：长按唤起手写输入，左滑露出操作
- 状态：低于心理价时左上角番茄红便宜标签

### 2. 半屏手写输入区
- 深色黑板背景 + 木框质感
- 粉笔数字以 SVG path 逐笔 stroke-dashoffset 绘制落定
- 摊位选择 chips + 是否购买 toggle + 数字键盘

### 3. Sparkline 走势
- 粉笔黄折线 + 圆点笔尖
- 番茄红虚线标记心理价位
- 新价格写入时延伸一笔

### 4. 下拉刷新
- 下拉超过阈值后弹性回弹
- 模拟擦拭黑板重写

### 5. 左滑操作
- 列表项左滑露出编辑/删除按钮
- 弹簧物理感

### 6. 底部 Tab 栏
- 标准微信小程序 4 Tab 导航
- 微信绿选中态

## 五、动效语言

所有动效围绕「用粉笔在黑板上写字」的核心隐喻展开：

1. **粉笔逐笔 stroke 绘制** — 价格写入的签名反馈（核心记忆点）
2. **粉笔粉尘飘落** — 书写时的材质感强化
3. **sparkline 笔尖延伸** — 新价格即时融入历史走势
4. **半屏弹层弹簧上升** — 符合小程序物理感
5. **下拉刷新弹性回弹** — 模拟擦拭黑板重写
6. **价格写入闪烁放大** — 确认反馈

动效原则：所有动效服务"手写记价"的即时反馈，不为炫技。

## 六、降级与无障碍

- 支持 `prefers-reduced-motion`：降级为即时呈现，无动画版本信息层级保持完整
- 灰度模式下层级仍成立（主要靠字体大小/字重/空间位置区分，颜色仅作辅助强调）

## 七、栅格与间距

- 目标宽度：390px
- 内容区左右内边距：16px
- 列表项垂直间距：通过 dashed 分隔线区分，内部 padding 14px
- 卡片圆角：8px（黑板木框感）/ 20px（半屏弹层顶部）
- 按钮高度：48px（主操作）/ 40px（次级操作）

## 八、图标与图形

- 菜品图标使用 emoji（🍅🥬🥔🥚🥩🐟🧈🧄🥒🦐），形象直观且与主题贴切
- 功能图标使用 SVG 线条图标，2px 描边，与小程序视觉一致
- 装饰元素克制，仅保留黑板木框、粉笔纹理等主题相关元素

## 九、信息层级

1. 第一眼：日期 + 菜价（粉笔黄大字，视觉焦点）
2. 第二眼：菜名 + 摊位（粉笔白，识别对象）
3. 第三眼：sparkline 走势（辅助信息）
4. 操作提示：长按记价（右上角小字提示）

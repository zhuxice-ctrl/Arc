# Miel 设计规范

形态：原生 App

## 一、设计哲学

Miel 的设计语言源自蜂蜜、蜂蜡与蜂巢的自然质感——温暖、通透、有生命感。每一个界面元素都呼应养蜂人的日常：蜂巢的六边形几何、蜂蜜流动的光泽、蜂蜡温润的琥珀色调。

## 三、字体排版 Typography

### 字体家族

- **展示字体 Display**：Fraunces（衬线，温暖人文感）
- **正文字体 Body**：Inter（无衬线，清晰易读）
- **等宽字体 Mono**：SF Mono（代码、数据）

### 字号层级

| 层级 | 字号 | 字重 | 字体 | 用途 |
|------|------|------|------|------|
| H1 大标题 | 34px | 700 | Fraunces | 详情页标题、重要页面名 |
| H2 中标题 | 28px | 700 | Fraunces | 页面主标题 |
| H3 小标题 | 20px | 600 | Fraunces | 板块标题 |
| Body 正文 | 15px | 400-500 | Inter | 主要内容 |
| Caption 辅助 | 12-13px | 500 | Inter | 描述、副标题 |
| Label 标签 | 11px | 600 | Inter | Chip、状态标签 |

## 五、圆角与阴影

### 圆角

- 页面大卡片：20-24px
- 中等卡片：16-18px
- 小卡片 / Chip：10-14px
- 按钮 / 圆形按钮：100px（胶囊 / 圆形）
- FAB：50%

### 阴影

- 软阴影（卡片）：`0 2px 8px rgba(90,55,10,0.08), 0 12px 32px rgba(90,55,10,0.10)`
- 发光阴影（强调元素）：`0 0 24px rgba(245,166,35,0.35), 0 0 48px rgba(245,166,35,0.18)`
- 按钮阴影：`0 4px 12px rgba(217, 142, 28, 0.35)`

| 类型 | 样式 | 使用场景 |

| Primary | 蜂蜜金渐变 + 阴影 + 白色文字 | 主要操作、CTA |

### Chip 标签

- 胶囊形状
- 主色：蜂蜜金渐变
- 变体：橄榄绿、奶油白描边

- 毛玻璃背景（backdrop-filter: blur(20px)）

- 选中态：蜂蜜金色 + 顶部小圆点指示
- 点击反馈：0.9 缩放

## 七、动效规范 Motion

### 原则

- 所有动效基于物理模型（弹簧、惯性、阻尼）
- 动效周期各不相同，避免整齐划一
- 尊重 `prefers-reduced-motion` 设置

### 常用缓动

- 出场 / 点击反馈：`cubic-bezier(.2,.8,.2,1)`（弹性感）
- 进度填充：`cubic-bezier(.2,.8,.2,1)` 1.2s
- 页面过渡：滑入 0.5s + 透明度

### 签名动效

1. **首页入场序列** — 元素级联错峰渐入（80-100ms 间隔）
2. **详情页视差** — 滚动驱动的 Hero 缩放 + 标题位移
3. **FAB 脉冲** — 2.5s 呼吸光晕
4. **地图标记脉冲** — 2s 扩散消失
5. **头像脉冲环** — 3s 缓慢扩散

## 八、图标系统 Icons

- 风格：线性 SVG，2px 描边，圆角端点
- 尺寸：22px（导航）/ 20px（按钮）/ 16px（辅助）
- 颜色：继承 currentColor，随上下文变化

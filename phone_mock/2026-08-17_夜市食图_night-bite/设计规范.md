## 色彩系统

| 角色 | 色值 | 用途 |
|---|---|---|
| 主色 霓虹品红 | #ff3d7f | 品牌主调、TabBar 选中、CTA |
| 烛橙 | #ff8a3d | 辅助强调、价格、徽章 |
| 琥珀金 | #ffb627 | 星标、高亮、渐变 |
| 午夜墨 | #0f0a1e | 页面底色、深色区块 |
| 碳灰 | #2a2135 | 卡片表面、次级底色 |
| 暖白 | #fff5e6 | 正文文字、浅色表面 |
| 衍生色 | #1a1229 / #352a45 / #d62868 / #f59e0b / #f0e6d0 / #e69c0e / #e06a1d / #a89fb8 | 渐变层次、阴影、分隔 |

配色语义：夜市霓虹灯牌 + 炭火暖光，午夜墨底配霓虹品红/琥珀高对比，禁用蓝紫渐变。每页有色彩主角（首页偏暖橙、图鉴页高对比霓虹、详情页低饱和深色）。

## 字体

- 标题 `font-family: 'Noto Serif SC', serif`（摊点招牌感衬线）
- 正文 `font-family: 'Noto Sans SC', -apple-system, BlinkMacSystemFont, sans-serif`
- 数据/编号 `font-family: monospace`

## 小程序端侧交互（6 种）

页面栈 push/pop 右滑返回、底部 TabBar（4 项选中微动效+发光圆点）、半屏弹层筛选面板、下拉刷新弹性回弹、左滑列表操作、吸顶 Tab 筛选。

## 页面结构（8 页，每页布局差异化）

1. 首页：霓虹 Hero + 灯笼摇曳 + 搜索栏 + 快捷入口宫格 + 今日推荐卡片流
2. 夜市地图：示意街道网络 + 彩色脉冲标记点 + 底部半屏抽屉摊点列表
3. 摊点详情：Hero 大图视差滚动 + 吸底操作栏 + 菜单列表 + 信息卡
4. 美食图鉴：吸顶筛选 Tab + 双列瀑布流 + 点赞角标
5. 路线页：Hero 卡片 + 三色时间线步骤 + 路线类型切换
6. 心愿单：左滑删除/加入路线（真实拖拽）+ 列表项
7. 个人中心：渐变头像环 + 数据统计 + 4×2 宫格 + 菜单列表
8. 设计规范 + 接口文档：色板 + 字体排印 + 间距 + 组件预览 / REST 接口可折叠列表

## 动效系统（12+ 项）

霓虹灯牌闪烁（两种节奏）、灯笼摇摆、炭火摇曳光晕、入场序列动画、标记点脉冲环、下拉刷新弹簧、Tab 切换弹性缩放、时间线渐进进入、头像环形旋转、骨架屏 shimmer、自定义光标 lerp 跟随+悬停放大+点击涟漪、收藏心形变色发光。

物理模型：弹簧（下拉刷新/Tab 切换）、lerp 跟随（光标）、正弦摆动（灯笼）。动效周期各不相同。

## 健壮性

- visibilitychange 暂停动画循环，自定义光标 RAF 随可见性启停
- prefers-reduced-motion 降级
- 全部代码内联在单 index.html（JSX 内联于 `<script type="text/babel">`，CSS 内联于 `<style>`）

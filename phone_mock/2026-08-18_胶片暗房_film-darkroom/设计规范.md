# 胶片暗房 · 胶片相机与冲扫社区 — 设计规范

形态：原生 App

- 日期：2026-08-18
- 方向：V2 手机 UI（原生 App 形态）
- 领域：收藏爱好 · 胶片相机与冲扫社区

## 色彩系统（暗房安全灯氛围）

| 角色 | 色值 | 用途 |
|---|---|---|
| 炭黑 | `#1A1512` | 全局主底 |
| 深黑 | `#0E0B09` | 更深背景层 |
| 深棕 | `#2E241C` / `#2A2522` | 卡片 / 表面色 |
| 米白 | `#F2EBDD` | 主文字、浅色表面 |
| 暗房红 | `#C0392B` | 强调色、安全灯、主按钮 |
| 琥珀 | `#D98E32` | 辅助强调、评分、标签 |
| 显影绿 | `#4CAF50` | 状态成功 / 订单状态点缀 |

禁止蓝紫渐变；页面内用色块分区与局部暖色偏移制造节奏（社区页偏暖、图鉴页高对比、胶卷库低饱和）。

## 字体

- 标题：`Noto Serif SC`（400/600/700）
- 正文：`Noto Sans SC`（300/400/500/700）
- 参数 / 编号：`JetBrains Mono`（400/500）

## 页面结构（8 页，统一 iOS 外壳内切换）

1. 首页：社区样片瀑布流 + 下拉弹性刷新（显影提示）
2. 相机图鉴页：网格拼贴（徕卡 M6 / 康泰时 T2 / 禄来 35 等真实机型）
3. 相机详情页：Hero 视差大图 + 参数卡
4. 胶卷库页：胶片轮播画廊（Portra 400 / C200 / HP5 等真实卷型）
5. 冲扫预约页：步骤向导 + 底部半屏抽屉
6. 个人暗房页：环形进度（收藏完成度）+ 冲扫订单
7. 设计规范页
8. 接口文档页

至少 5 页布局结构互不重复（瀑布流 / 网格拼贴 / Hero 视差 / 轮播画廊 / 步骤向导 / 环形进度）。

## 原生端交互（≥4 种）

底部 TabBar（原生质感）、返回栈导航、下拉刷新、FAB 悬浮按钮、底部半屏抽屉、模态选择器、步骤进度条、长按卡片效果。

## 签名动效（贴主题语义）

- 显影渐现：照片从灰白渐变显影
- 快门按下全屏白闪
- 安全灯呼吸光晕
- 下拉弹性刷新（"显影中"提示）
- 环形进度、胶片过片轮播吸附、页面切换弹簧过渡
- 卡片 staggered 入场、FAB 旋转、抽屉弹簧弹出、模态缩放进入、Tab 图标上浮

## 自定义光标

白色粗环 + 红色内点 + 多层发光，开页即居中；悬停放大变色，点击涟漪。

## 健壮性

- RAF 随页面可见性暂停，定时器卸载清理
- RAF 积分器驱动光标惯性跟随，高频 mousemove 直操作 DOM
- 支持 `prefers-reduced-motion`
- JSX 全部内联于 index.html

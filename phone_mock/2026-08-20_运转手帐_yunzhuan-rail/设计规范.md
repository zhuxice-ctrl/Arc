# 运转手帐 · 设计规范

## 1. 设计理念

「运转」是铁道亚文化术语——为了体验某趟列车而专程乘坐并记录。本 App 将硬板车票的物理质感（齿孔、检票钳打孔、蓝笔划线）数字化为可触摸的交互仪式。一张票 = 一次真实乘车的完整闭环：查车次 → 登记出票 → 检票钳打孔 → 票入票夹 → 点亮搪瓷水牌 → 累计里程。

## 3. 字体

- **标题/票面**：`"Noto Serif SC", "Songti SC", "SimSun", "STSong", serif` — 衬线体呼应硬板票的印刷感
- **正文/UI**：`-apple-system, BlinkMacSystemFont, "PingFang SC", "Helvetica Neue", "Microsoft YaHei", sans-serif`
- **票号/代码**：`ui-monospace, "SF Mono", "Menlo", "Consolas", monospace`

## 4. 动效系统

### 页面转场
| 动画 | 时长 | 说明 |
|------|------|------|
| `pagePushIn` | 0.32s ease-out | push 页面从右侧滑入 |
| `pagePushOut` | 0.32s ease-in | push 时当前页微缩+变暗 |
| `pagePopIn` | 0.32s ease-out | pop 返回时底层页恢复 |
| `pagePopOut` | 0.32s ease-in | pop 页面向右滑出 |

### 签名交互
| 动画 | 说明 |
|------|------|
| `ticketPrint` | 出票时硬板票从顶部吐出下滑（0.5s） |
| `signalPulse` | 空状态信号灯呼吸（2s 无限循环） |
| `plaqueGlow` | 水牌点亮脉冲发光（0.8s） |
| `fadeInStagger` | 列表项逐条淡入（每项延迟 50ms） |
| `spin` | 进度环旋转（检票钳长按计时） |

### 检票钳打孔（核心签名交互）
1. 长按钳形按钮 0.6s，进度环 SVG 旋转计时
2. 触发时：票右下角 M 形锯齿缺口真实镂空（CSS clip-path）
3. 4-6 片纸屑粒子从缺口飘落（JS 动态生成 DOM + CSS animation）
4. 蓝笔斜线 SVG `stroke-dashoffset` 逐笔动画划过票面日期
5. 手写体「已检」小字浮现
6. 票整体 `scale(0.98)` 微沉转已检态
7. 按钮变灰禁用，打孔不可逆

## 5. 健壮性保障

- `prefers-reduced-motion`：所有动画在用户偏好减少动效时降级为瞬切
- `visibilitychange`：页面隐藏时暂停所有 RAF 和定时器，恢复时续接
- `pagehide`：卸载时取消所有定时器和事件监听
- 快速操作不叠加定时器（检查并清除前一个再新建）
- 高频事件（touchmove）直接操作 DOM，不触发重渲染
- localStorage 持久化（键 `yunzhuan_state_v1`）：票夹、水牌点亮、统计数据刷新后保留

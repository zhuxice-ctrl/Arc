# 古籍善本 · 微信小程序 — 设计规范

- 日期：2026-08-18
- 方向：V2 手机 UI（微信小程序形态）
- 主题：古籍善本 / 线装本收藏与展览的微信小程序
- 创作领域：文化艺术（古籍善本、非遗传承）

## 色彩系统

| 角色 | 色值 | 说明 |
|---|---|---|
| 宣纸米底 | `#F5EFE0` | 页面背景，模拟宣纸 |
| 朱砂主强调 | `#B5321D` | 印章、按钮、Tab 选中态 |
| 墨黑 | `#1C1B19` | 主文字、标题 |
| 金 | `#C9A961` | 装饰线、徽章 |
| 松绿 | `#6B8E7A` | 次级强调、标签 |
| 黛蓝 | `#3E4A5E` | 信息分区 |
| 褐 | `#8B6F47` / `#7A5C3E` | 仿古书封色 |
| 浅米 | `#EDE5D2` / `#E8E1D0` | 卡片表面分层 |
| 暗朱 | `#8B2715` | 朱砂深态 |

整体「宣纸米 + 朱砂印泥 + 墨黑金线」中式古籍体系，无蓝紫渐变；各页以朱砂、松绿、黛蓝为色彩主角做层次偏移。

## 字体

- 书法标题：`'Ma Shan Zheng', 'Noto Serif SC', serif`
- 中文衬线：`'Noto Serif SC', serif`
- 中文正文：`'Noto Sans SC', -apple-system, BlinkMacSystemFont, 'PingFang SC', sans-serif`

## 页面结构（8 页）

1. 首页：Hero 大图 + 分类宫格 + 横向展览画廊 + 善本瀑布流 + 学人列表
2. 分类页：左右分栏 + 吸顶 Tab（经史子集 / 丛书 / 佛藏等）
3. 详情页：视差滚动 + 环形进度 + 印章盖章动效 + 吸底操作栏
4. 砚田社区：吸顶 Tab + 瀑布流 / 列表切换
5. 个人中心：环形进度头像 + 宫格菜单 + 阅读挑战 + 左滑列表
6. 搜索页：骨架屏 + 热门标签 + 搜索结果
7. 设计规范页
8. 接口文档页

## 小程序端侧交互（8 种）

页面栈 push/pop 右滑入场、底部 TabBar 选中弹跳、ActionSheet 半屏动作面板、下拉刷新弹性回弹、左滑列表操作、吸顶 Tab 变色、详情页吸底操作栏、胶囊按钮自定义导航栏。侧栏悬浮按钮直达设计规范与接口文档。

## 动效系统（12+）

毛笔刷揭示、印章盖章弹跳、墨滴扩散、视差滚动、骨架屏加载、数字计数、脉冲光环、旋转装饰环、卡片 3D 倾斜、光泽扫过、涟漪点击、Tab 弹跳等。

## 组件规范

- 卡片：宣纸米表面 + 金线边框 + 朱砂角标；瀑布流卡片支持 3D 倾斜
- 按钮：朱砂实底 / 描边两态，吸底主按钮带安全区
- 印章：朱砂方印，盖章式弹跳入场
- TabBar：5 项，选中态弹跳 + 朱砂下划线

## 健壮性

- JSX 全部内联于 `index.html`，无外部 JSX 引用
- 定时器统一管理、`prefers-reduced-motion` 降级
- 高频事件直接操作 DOM

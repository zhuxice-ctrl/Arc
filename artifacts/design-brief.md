# V1 网页设计·设计简报 — 夜行候车厅（night-train-board）

> 这是一份给实现方的完整设计简报。请严格按本简报实现一个真实可交互的完整网站（单文件 vanilla HTML），不要做成设计稿图片、不要做成工具平台罗列、不要做成通用 landing page。

## 一句话设计逻辑
整个网站是一座深夜长途夜车终点站的候车厅，抬头是那只活着的机械翻牌发车牌——翻牌板是唯一脊柱，牌面翻动=时间推进、车次终呼、车次离站；附以夜行列车衰落与复兴的编辑正文、一趟精选线路的纵深（站点阶梯+卧铺铺位剖面）、全球卧铺网络地理图。

## 网站类型
Content / Editorial（写给夜行列车的一封情书），以翻牌发车牌为活体脊柱，非 landing page、非仪表盘。

## 配色（严格使用，禁蓝紫渐变，禁纸本水墨木色，禁石墨灰主导）
- `--ink: #141414`（主文字/翻牌字面）
- `--teal: #0E3A38`（主导：翻牌板框架、页面 chrome、候车厅墙）
- `--teal-deep: #0A2A28`（凹陷区、面板背板）
- `--mint: #DCE7DA`（翻牌牌面、亮面卡片）
- `--mint-dim: #C4D2C6`（牌面分隔/次级面）
- `--coral: #E8564A`（终呼·即将发车 / 紧迫状态 / 强调链接）
- `--ash: #6B7270`（已发车灰出 / 次要文字）
- 背景：`--teal-deep` 到 `--teal` 极淡纵向渐变 + 极淡横向扫描线纹理（reduced-motion 关闭纹理动画，静态保留）。
- 文字主色 ink 在 mint 牌面/亮面上；在 teal 背景上用 `#E8EDE8` 近白文字。

## 字体（系统字体栈，禁外部 CDN 字体）
- 标题/牌面车次号：`'SF Mono','JetBrains Mono',ui-monospace,Menlo,monospace`（等宽，呼应机械牌/车次号/时刻表）
- 正文/编辑长文：`-apple-system,'PingFang SC','Microsoft YaHei',system-ui,sans-serif`
- 数字/时刻/里程：等宽 mono
- 中文标题可用思源宋体栈 `'Songti SC','SimSun',serif` 仅用于编辑正文大标题（呼应"情书"气质），其余 mono/sans。
- 字级跨度要大：发车牌车次号特大约 2.4rem，站点名中约 1rem，编辑正文约 0.95–1.05rem 行高 1.75。

## 信息结构（自上而下，但发车牌是脊柱不是"section 堆叠"）
1. **顶栏 chrome**：左「夜行候车厅 · Sleeper Hall」mono 小标 + 右一个活体小时钟翻牌（秒级轻翻）+ 一条票根齿孔进度条贯穿顶栏下沿（滚动推进）。
2. **发车牌（HERO/脊柱，占首屏主体）**：一只机械翻牌板，≥6 行今夜出发夜车。每行：[车次号 mono 大] [目的地中文+外文] [发车时刻 mono] [行程时长] [铺位类型] [站台号] [状态牌：准点/终呼·即将发车/已发车]。下方一组「推进时间 −15 / +15 / 跳到发车」按钮（点击推进，非拖拽）。提示语：「点击车次查看线路纵深 · 推进时间看牌面翻动」。
3. **编辑正文·情书**：一段真实编辑长文（夜行列车衰落与复兴史：欧洲夜车 2007 后萎缩、ÖBB Nightjet 2016 复兴、碳中和与慢旅行回潮、西伯利亚大铁路 9288 公里 7 天、日本 Sunrise 出云濑户是最后定期夜车等真实事实），克制留白，无小标题卡片化，用排版与引文建立节奏。
4. **精选线路纵深**（点击车次打开/或默认展开一趟）：垂直站点阶梯（SVG，自上而下真实站点 + 里程 + 时刻，stroke-dashoffset 绘制点亮）+ 卧铺车厢铺位剖面（SVG 车厢横截面，上/中/下铺位，依占用依次点亮）+ 行程数据（总里程、总时长、跨越时区、铺位价档）。
5. **全球卧铺网络地理图**：一张极简 SVG 世界轮廓 + 几条代表夜车线路的弧线（ÖBB Nightjet 欧洲、Caledonian Sleeper 英国、西伯利亚大铁路、Sunrise 日本、Intercités de Nuit 法国、中国 Z 字头），dashoffset 滚入视口时绘制，点击弧线高亮该线路名。
6. **编辑收尾·复兴**：短段收束 + 一张"已发车"灰出的牌面作视觉句号。页脚极简（一行 mono：致敬夜行列车 + 时区说明 + 样表声明）。

## 核心交互与动效（≥12 个组件级，符合机械/铁路物理，禁 Ken Burns/禁 glow 球/禁鼠标跟星光斑）
1. **翻牌级联**：推进时间 → 多行牌面 3D rotateY 翻牌半幅翻转级联（每行错峰 ~80ms），机械落位带轻微震颤。
2. **终呼脉冲**：临近发车行牌面翻成珊瑚红「终呼·即将发车」，珊瑚红 1.2s 呼吸（opacity/brightness，非缩放）。
3. **离站滑出**：到点行翻成「已发车」后灰出向左滑出，下一行顶上补位（transform translateX + opacity）。
4. **自定义光标**：列车员打孔剪票器（珊瑚红圆环 + 墨十字准星），开页即显示在屏幕正中、高对比、z-index 最高，pointer 事件直接操作 DOM（不走 React 重渲染）。触屏隐藏。
5. **顶栏活体时钟**：右上一个小翻牌时钟，秒级轻翻一次（reduced-motion：静态显示）。
6. **票根齿孔进度**：顶栏下沿一条票根齿孔，随页面滚动推进填充（scroll-linked，reduced-motion：满）。
7. **行 hover**：牌行 hover 时该行牌面微仰角倾斜 + 右侧浮现"查看线路 ›"。
8. **线路纵深滑入**：点击车次 → 线路纵深面板从右滑入（translateX），遮罩淡入。
9. **站点阶梯绘制**：SVG 站点阶梯 stroke-dashoffset 从起点向终点逐站绘制点亮（面板打开时触发，reduced-motion：即时全显）。
10. **铺位依次点亮**：卧铺剖面铺位依占用状态依次点亮（错峰，reduced-motion：静态点亮）。
11. **线路弧绘制**：全球网络 SVG 弧线滚入视口时 dashoffset 绘制（reduced-motion：即时）。
12. **线路弧高亮**：点击弧线 → 该弧加粗高亮 + 浮出线路名标签。
13. **推进按钮反馈**：按钮按下凹陷 + 牌面整体一次极轻"震动"反馈（transform 微抖，reduced-motion：无）。
14. **编辑标题墨痕揭示**：编辑正文大标题滚入视口时墨痕式揭示（clip-path，reduced-motion：即时）。
15. **页脚票根撕边**：页脚顶沿票根齿孔撕边，hover 时轻微"撕开"位移。

所有 RAF/定时器：页面隐藏(document.hidden)时暂停、卸载时取消；快速连点推进按钮不叠加定时器（取最新一次）；prefers-reduced-motion 下所有动效即时/静态。

## 自定义光标规格
- 元素：一个 28px 圆环（coral 2px 描边）+ 中心 6px 墨点 + 十字准星（两条 14px coral 细线）。
- 开页：定位到视口正中，0.4s 淡入。
- 跟随：pointermove 直接 set transform translate3d（不触发重排/重渲染），轻微 lerp 平滑（reduced-motion：无 lerp 即时跟随）。
- 状态：hover 可点击元素时圆环放大 1.25 + 准星收缩；按下时圆环变实心半透明。
- 层级：z-index: 2147483647；pointer-events:none；mix-blend 不用（保证高对比）。
- 触屏：display:none。

## 健壮性红线（必须满足）
- 零未定义引用：所有变量先声明后使用；翻牌数据数组初始化完整。
- 纯 vanilla 单文件：单一 index.html，无外部 CDN/无 React/无 Babel；内联 CSS 与 JS。
- 无白屏：首屏直出可见发车牌，JS 失败也不空白（牌面用静态 HTML 兜底）。
- RAF/定时器随可见性暂停且卸载取消；快速操作不叠加定时器；高频 pointermove 直接操作 DOM。
- 支持 prefers-reduced-motion（全部动效降级）。
- 响应式：1440 / 1024 / 768 / 390 无横向溢出、无重叠、无裁切；移动端翻牌板可纵向滚动，字号/间距自适应。
- 无 Console Error；无 404；无错误引用。
- 真实内容，禁 Lorem/Feature One/Sample Text/John Doe。

## 技术栈
纯 vanilla 单文件 HTML + 内联 CSS + 内联 JS。翻牌用 CSS 3D transform (perspective + rotateY)；站点阶梯/铺位剖面/线路弧用内联 SVG + stroke-dashoffset；自定义光标用 pointermove + transform。无任何外部依赖。

## 交付要求
产出单一 index.html，开页即见发车牌，可推进时间翻牌、可点击车次打开线路纵深，完整编辑正文 + 精选线路纵深 + 全球网络图 + 收尾。视觉为深汽油青主导 + 薄荷牌面 + 珊瑚红强调，机械翻牌为签名。

# 渊海志 设计规范

> 日期：2026-08-17 · 方向：V1 网页设计 · 主题：深海生物图鉴沉浸式官网

## 色彩系统

| 角色 | 色值 | 用途 |
|------|------|------|
| 主背景 | `#06141a` | 深渊墨青，全站底色 |
| 次背景 | `#0a2a2e` | 深海蓝绿，分区背景 |
| 极深 | `#030a0d` | 最暗层，阴影/折叠区 |
| 卡片表面 | `#0d2530` | 生物卡片底色 |
| 主强调 | `#00d9c0` | 生物荧光青绿，主要交互色 |
| 辅助强调 | `#ff8c42` | 琥珀橙，数据高亮 |
| 点缀色 | `#ff4757` | 深珊瑚红，警示/特殊标记 |
| 主文字 | `#e8f4f8` | 冷白正文 |
| 次文字 | `#7a9ba8` | 灰蓝辅助文字 |

## 字体

- 标题：`'Noto Serif SC', serif`（衬线，深渊质感）
- 正文：`system-ui, -apple-system, sans-serif`

## 组件规范

- **生物卡片**：圆角 16px，荧光边框 1px solid rgba(0,217,192,.3)，悬停发光阴影 0 0 30px rgba(0,217,192,.4)
- **导航栏**：固定顶部，滚动后毛玻璃 backdrop-filter: blur(20px)
- **深度刻度尺**：垂直渐变条，从 #0a2a2e 到 #030a0d
- **按钮**：荧光青绿描边，hover 填充

## 动效系统

| # | 动效 | 触发 | 物理模型 |
|---|------|------|----------|
| 1 | 荧光水母光标 | 鼠标移动 | DOM transform 直操作 |
| 2 | 浮游粒子上升 | canvas RAF | 摆动轨迹+发光 |
| 3 | 标题逐字浮现 | 入场 | translateY + opacity |
| 4 | 卡片 3D 倾斜 | mousemove | rotateX/rotateY 跟随 |
| 5 | 卡片荧光边框 | hover | box-shadow 渐变 |
| 6 | 滚动渐入 | IntersectionObserver | translateY+opacity |
| 7 | 深度数字递增 | 视口触发 | easeOutExpo |
| 8 | 视差滚动 | scroll | 不同层速率 |
| 9 | 导航吸顶毛玻璃 | scroll>50px | rAF 节流 |
| 10 | 时间轴展开 | scroll | 中线填充+节点浮现 |
| 11 | 页脚波纹 | SVG 动画 | 三层错速位移 |
| 12 | 光泽扫过 | hover | 斜向 sheen transform |

## 页面结构

1. Hero 区：粒子背景 + 大标题 + 滚动提示
2. 生物图鉴区：卡片瀑布流网格
3. 深度分层区：垂直深度可视化
4. 特色生物详情：展开介绍 + 数据计数
5. 科考时间线：里程碑时间轴
6. 页脚：波纹动画

## 技术栈

纯 vanilla HTML/CSS/JS 单文件，无 React/Babel/外部 CDN 依赖。支持 prefers-reduced-motion 降级。

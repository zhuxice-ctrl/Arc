# 渊海志 · 深海生物图鉴官网

> 日期：2026-08-17 · 方向：V1 网页设计 · 主题：深海生物图鉴沉浸式艺术官网

## 简介

「渊海志」是一个以深海生物为主题的沉浸式图鉴官网。深渊之下，万物有光——从海面到 6000 米深渊，逐层展示鮟鱇鱼、皇带鱼、巨型乌贼、吸血鬼乌贼等深海生物的形态与栖息深度。配色以深渊墨青为底、生物荧光青绿为主调，营造深海探险的神秘氛围。

## 动效亮点

- 荧光水母自定义光标（白环+青绿内点+多层发光，开页居中显示）
- Canvas 浮游粒子上升模拟深海浮游生物
- 卡片 3D 倾斜跟随鼠标，荧光边框悬停发光
- 深度数字计数递增（easeOutExpo 缓动）
- 视差滚动 + 时间轴展开 + 页脚波纹动画
- 共 12 个组件级特效

## 页面结构（单页滚动）

导航（滚动变色 + 移动端汉堡）→ Hero 主视觉 → 活动故事 → 萤火图鉴（黄缘萤 / 条背萤 / 窗胸萤 三物种卡）→ 观测指南（装备 / 礼仪 / 拍摄 / 安全 四 Tab）→ 夜航路线（19:00–21:50 五站时间线）→ 生态保护（动态数据统计 + 知识卡）→ 预约报名（表单校验 + Toast）→ Footer。

## 动效系统

萤火虫粒子群（Canvas，闪烁呼吸 + 随机游走 + 鼠标反平方斥力躲避）、自定义光标（白粗环 + 萤火黄内点 + 多层发光，悬停放大变色、点击收缩）、点击涟漪、3D 卡片倾斜（弹簧阻尼插值，直接操作 transform）、光泽扫过（径向渐变跟随鼠标）、滚动渐入（IntersectionObserver）、品牌标志脉冲呼吸、数字计数（cubic 缓动 + 进入视口触发）、Hero 视差滚动、导航栏滚动变色、按钮光泽 hover、卡片悬浮发光 + 顶部光边、滚动指示器下落光点、Tab 切换面板淡入。

物理基础：粒子游走使用惯性动量 + 阻尼；卡片倾斜使用弹簧（Hooke）回正；斥力使用反平方衰减。动效周期各异、不整齐划一。

## 健壮性

统一 RAF 管理器 + `visibilitychange` 自动暂停/恢复；卸载清理所有循环；`prefers-reduced-motion` 降级为静态；移动端自动关闭自定义光标；JSX/CSS 全内联（零外部 src 引用）。

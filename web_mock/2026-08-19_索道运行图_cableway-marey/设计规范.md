# 云顶索道运行图 · 设计规范

> 一张活的索道运行图（Marey 时间-距离图）作为整页界面——图纸即网站，不是图纸插图。

## 设计母题
索道运行图调度台。整张网页就是一张 19 世纪铁路 Marey 运行图：横轴为营业日时间（07:00–19:10），纵轴为海拔与五个站点，6 辆吊厢的上下行轨迹以斜线穿越图纸，斜线交点即会车点。用户像调度员一样俯瞰全天运行。

## 网站类型
Data / Tool——公共信息 + 数据产品（索道公司实时运行信息页）。非 Landing Page、非滚动叙事、非卡片平台。

## 空间模型
单屏调度台：顶栏（品牌 + 实时时钟/倍速）+ 主舞台（SVG 运行图占视口 ≥65%）+ 右侧信息栏（下一班 / 站点一览 / 吊厢档案 / 风速告警）。运行图为绝对主角，信息栏为辅。无纵向 section 堆叠。

## 色彩系统（取自源码 :root）
| 变量 | 值 | 用途 |
|------|----|----|
| `--paper` | `#f5efe0` | 暖白纸底 |
| `--paper-2` | `#ebe2cc` | 次纸色（面板） |
| `--ink` | `#1f1d1a` | 墨黑主线/正文 |
| `--ink-soft` | `#4a463f` | 墨灰 |
| `--ink-faint` | `#9b9382` | 浅墨标注 |
| `--grid` | `#cfc6b2` | 网格细线 |
| `--grid-major` | `#b8ae97` | 主网格 |
| `--up` | `#c0392b` | 上行朱红（实线） |
| `--down` | `#2c3e70` | 下行靛青（虚线） |
| `--alert` | 信号橙 | 风速告警区段 |

色彩承担功能语义：上行/下行靠朱红实线 vs 靛青虚线区分（灰度下仍可辨），告警靠橙，层级靠墨色三阶。无蓝紫渐变。

## 字体系统
- 中文：PingFang SC / Hiragino Sans GB / Microsoft YaHei / Noto Sans SC
- 等宽数字与图纸标注：SF Mono / Menlo / Consolas（时刻、海拔、编号、坐标）
- 字体逻辑来自"运行图纸"——等宽保证时刻对齐，中文无衬线保证信息可读。

## 图形语言
墨黑网格 + 站点水平基准线 + 斜线轨迹 + 空心会车点圆圈 + 等宽数字标注。图纸纹理为底。一切图形皆为信息，无装饰性插画。

## 核心交互
1. **点击吊厢斜线/吊厢点** → 全天轨迹高亮 + 右侧吊厢档案弹出（编号/载客量/累计里程/当前位置/运行状态/上下站时刻/今日往返），图章式盖章入场
2. **点击会车点**（预计算斜线交点空心圆）→ 时间跳转至交会瞬间 + 会车特写浮层（双吊厢在三号支架区间擦身 + 响铃波纹）
3. **点击站点名** → 该站上下行发车时刻带高亮（departure-band）
4. **播放控制**：暂停 / 1× / 4× / 8× / 复位（内置时钟驱动，倍速切换不叠加定时器）

## 动效系统（≥12 个组件级特效，机械-图纸语言）
1. 吊厢沿斜线匀速运动（电气线性，RAF 驱动）
2. 会车瞬间双吊厢微停顿后交错（机械避让）
3. 吊厢档案图章式弹入（`@keyframes stampIn`，弹性曲线）
4. 会车响铃波纹扩散（`@keyframes ring`）
5. 实时心跳点脉动（`@keyframes pulse`）
6. 自定义十字准星光标 + 缓动拖尾
7. 光标 hover 可交互元素时放大变朱红
8. 发车时刻带淡入
9. 站点 hover 反馈
10. 会车特写浮层缩放进入
11. 倍速按钮选中态切换
12. 风速告警区段在图上标灰 + 告警闪烁
13. 时间游标随播放推进
14. 网格纸张底纹

## 签名时刻
会车——上下行吊厢斜线在 3 号支架区间交叉，点击交叉标记后图纸聚焦，特写视窗中两吊厢在山谷间擦身而过，响铃波纹一声。

## 健壮性
- 纯 vanilla 单文件 HTML，无 React/Babel/CDN
- RAF 随 `visibilitychange` 暂停 / 恢复；页面卸载 `cancelAnimationFrame`
- 倍速切换不叠加定时器
- 高频鼠标事件直接操作 DOM（光标跟随），不触发框架重渲染
- `prefers-reduced-motion` 降级为静态图纸 + 当前时刻快照
- 自定义光标开页即显示在屏幕中央，高对比，层级最高

## 响应式
- 1440 / 1024：主舞台 + 右侧信息栏
- 768：信息栏折叠至底部
- 390：降级为纵向站点列表 + 下一班发车倒计时 + 控制栏

## 内容真实性
5 站点海拔里程（云溪镇 580m→望湖台 960m→松垭口 1280m→风穴 1680m→云顶 2110m）；6 辆吊厢（编号/载客量/累计里程）；班次表由同一套时刻数学生成、任一时刻位置可复算；风速告警 4 段（07:20–07:45/11:10–11:35/14:05–14:55/17:40–18:10，≥17m/s）。无 Lorem Ipsum。

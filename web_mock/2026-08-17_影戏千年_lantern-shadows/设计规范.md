# 影戏千年 Lantern Shadows · 设计规范

> 方向：V1 网页设计｜日期：2026-08-17｜主题：中国皮影戏非遗沉浸式官网

## 色彩系统

| 角色 | 色值 | 用途 |
|---|---|---|
| 主背景（浓墨） | `#14100C` | 全站底色，幕布后的夜 |
| 次背景 | `#1E1812` / `#2A2118` | 板块分层、卡片底 |
| 正文米（宣纸） | `#F2E8D5` | 主文字、镂空透光 |
| 强调红（朱砂） | `#C7352B` | 灯笼光源、标题点缀、影人朱彩 |
| 强调金（鎏金） | `#C9A227` | 金边、光泽扫过、计数高亮 |
| 高光金 | `#E6C14A` | 悬停发光、灯尘粒子 |
| 暖红亮 | `#E65248` | 灯影辉光外缘 |
| 暗金/暗红 | `#8B7320` / `#8A241C` | 次级描边、阴影 |

配色互斥说明：本版为浓墨+朱砂+鎏金的暖色皮影体系，与当日 V2（深青+沙金+珊瑚橘）、V3（极夜墨黑+极光绿+品红）完全区隔，无蓝紫渐变。

## 字体栈

- 中文标题：`"Ma Shan Zheng"`（马善政毛笔楷书）— 皮影剧目、大标题
- 中文正文/次标题：`"ZCOOL XiaoWei"` / `"Noto Serif SC"` — 工艺说明、流派描述
- 拉丁/数字：`"Noto Sans SC"` 300/400/500/700 — 数据统计、导航

## 组件规范

- 皮影镂空卡：暗底 + 鎏金细描边，hover 时背后径向金光 `#C9A227` 从镂空剪影透出，斜向金色光带 350ms 扫过。
- 工艺流水线：六道工序节点（选皮→过稿→雕镂→敷彩→发汗熨平→缀结），节点间虚线 path 滚入视口时 `stroke-dashoffset` 绘制动画。
- 流派卡：`#2A2118` 底 + 朱砂左色条，hover 金边发光上浮 `translateY(-6px)`。
- 传承人卡：头像双环交替脉冲扩散（朱砂环 + 鎏金环），交错周期。
- 光标：白色粗环 + 朱砂内点 + 双层发光，z-index 最高；hover 放大变鎏金；点击涟漪扩散。

## 动效系统（12+ 组件级）

1. 自定义光标（开页居中、悬停三态、点击涟漪）
2. 粒子灯尘（Canvas，60 颗金色尘埃上升，各自周期）
3. 打字机（Hero 描述逐字，随机间隔）
4. 数字计数（easeOutExpo 滚入递增）
5. 涟漪点击
6. 视差滚动（工艺区金/红模糊光斑差速位移）
7. 悬停发光（卡片/流派/传承人金边上浮）
8. 光泽扫过（剧目卡斜向金带）
9. 灯影跟随（Hero 灯笼光源随鼠标，照亮皮影）
10. 镂空透光（剧目卡 hover 径向金光透出）
11. 工序连线绘制（stroke-dashoffset）
12. 皮影关节拖拽（Hero 影人双臂铰链物理，松手回弹+空闲摆动）
13. 头像脉冲
14. 滚动渐入 fade-up

动效基于物理模型（铰链回弹弹簧）与主题语义（灯尘/灯影/镂空透光），周期各异；无整图缩放/Ken Burns。

## 页面结构（单页七板块）

1. Hero 灯影开场（灯笼光源 + 可拖拽影人）
2. 数据统计（2000 年历史 / 300+ 剧目 / 28 流派 / 6 道工序）
3. 经典剧目（6 张镂空卡：三打白骨精、火焰山、哪吒闹海、千里走单骑、白蛇传、穆桂英挂帅）
4. 匠人工艺（六道工序流水线）
5. 流派纷呈（陕西东路 / 唐山 / 湖南 / 川北）
6. 近期演出（4 天可切换排班表）
7. 传承人手记（3 位国家级非遗传承人）

## 健壮性

零外部 JSX 引用（全部内联 `<script>`）；RAF/定时器随 `visibilitychange` 暂停、卸载统一取消；快速操作先 `clearTimeout`/`cancelAnimationFrame` 旧的；高频鼠标事件直接操作 DOM transform；`prefers-reduced-motion` 完整降级。

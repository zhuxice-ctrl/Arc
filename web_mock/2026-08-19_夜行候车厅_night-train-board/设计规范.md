# 设计规范 · 夜行候车厅（night-train-board）

> 本规范由源码 index.html 真实提取，与实现一致。

## 一、设计母题
**机械翻牌发车牌为唯一脊柱**。整站是一座深夜长途夜车终点站的候车厅：抬头是那只活着的 Solari 式机械翻牌发车牌，牌面翻动 = 时间推进、车次终呼、车次离站。围绕"看着发车牌翻动等一趟夜车"展开，附以夜行列车衰落与复兴的编辑正文、一趟精选线路纵深（站点阶梯 + 卧铺铺位剖面）、全球卧铺网络地理图。

- 网站类型：Content / Editorial（写给夜行列车的一封情书），非 landing page、非仪表盘。
- 空间模型：`split_flap_departure_board`（固定翻牌板为脊柱，非竖向 section 堆叠、非卡片网格、非横向脊柱迹线）。
- 主交互：`clock_step_cascade_flip`（点击推进时间 → 翻牌级联；点击车次 → 线路纵深），非拖拽、非 scroll-descent。

## 二、配色（禁蓝紫渐变，禁纸本水墨木色，禁石墨灰主导）
| 变量 | 色值 | 用途 |
|------|------|------|
| `--ink` | `#141414` | 主文字 / 翻牌字面 |
| `--teal` | `#0E3A38` | 主导：翻牌板框架、页面 chrome、候车厅墙 |
| `--teal-deep` | `#0A2A28` | 凹陷区、面板背板、页面底 |
| `--mint` | `#DCE7DA` | 翻牌牌面、亮面卡片 |
| `--mint-dim` | `#C4D2C6` | 牌面分隔 / 次级面 |
| `--coral` | `#E8564A` | 终呼·即将发车 / 紧迫状态 / 强调 |
| `--ash` | `#6B7270` | 已发车灰出 / 次要文字 |
| `--light-text` | `#E8EDE8` | teal 背景上的近白文字 |

- 页面背景：`--teal-deep → --teal → --teal-deep` 纵向渐变 + 极淡横向扫描线纹理（`repeating-linear-gradient` 4px 周期，mint 1.5% 透明度），`background-blend-mode: overlay`。
- 全部 `linear-gradient` 仅 teal-deep/teal 系，无蓝紫。
- 与近期 telegraph（graphite 灰 + brass + vermilion + cream）错开：主导色青 vs 灰、牌面薄荷 vs 奶油、强调珊瑚 vs 朱砂。

## 三、字体（系统字体栈，无外部 CDN 字体）
- `--mono: 'SF Mono','JetBrains Mono',ui-monospace,Menlo,monospace` —— 车次号 / 时刻 / 里程 / 顶栏小标，呼应机械牌与时刻表。
- `--sans: -apple-system,'PingFang SC','Microsoft YaHei',system-ui,sans-serif` —— 编辑正文。
- `--serif: 'Songti SC','SimSun',serif` —— 编辑正文大标题（呼应"情书"气质）。
- 字级跨度大：发车牌车次号约 2.4rem，站点名约 1rem，编辑正文 0.95–1.05rem / 行高 1.75。

## 四、信息结构（自上而下，翻牌板为脊柱非 section 堆叠）
1. **顶栏 chrome**：左「夜行候车厅 · Sleeper Hall」mono 小标 + 右活体秒级翻牌时钟 + 票根齿孔滚动进度条。
2. **发车牌 HERO/脊柱**：≥6 行今夜夜车，每行 [车次号 mono 大] [目的地中+外] [发车时刻] [行程时长] [铺位类型] [站台] [状态牌：准点/终呼·即将发车/已发车]；下方 −15/+15/跳到发车 推进按钮。
3. **编辑正文·情书**：夜行列车衰落与复兴史（2007 后萎缩、ÖBB Nightjet 2016 复兴、9288km 西伯利亚、Sunrise 出云、flygskam/慢旅行/碳中和回潮），排版与引文建立节奏。
4. **精选线路纵深**：NJ466 维也纳→威尼斯，垂直站点阶梯（stroke-dashoffset 绘制）+ 卧铺车厢铺位剖面（上/中/下依占用点亮）+ 行程数据。
5. **全球卧铺网络图**：极简 SVG 世界轮廓 + 6 条夜车线路弧线（dashoffset 滚入绘制，点击高亮）。
6. **编辑收尾·复兴**：短段收束 + 灰出牌面句号；页脚极简（致敬 + 时区 + 样表声明）。

## 六、动效系统（≥12 组件级，符合机械/铁路物理，禁 Ken Burns/禁 glow 球/禁鼠标跟星光斑）
1. **翻牌级联**：推进时间 → 多行牌面 3D rotateY/rotateX 半幅翻转级联（错峰），机械落位震颤。
2. **终呼脉冲**：临近发车行翻成珊瑚红「终呼·即将发车」，1.2s 呼吸（opacity/brightness，非缩放）。
3. **离站滑出**：到点行翻成「已发车」灰出向左滑出，下行顶上补位（translateX + opacity）。
4. **自定义光标**：列车员打孔剪票器（珊瑚红圆环 + 墨十字准星），pointermove 直接 transform translate3d 操作 DOM，hover 放大、按下实心。
5. **顶栏活体时钟**：秒级轻翻。
6. **票根齿孔进度**：随滚动推进填充。
7. **行 hover**：牌面微仰角倾斜 + 浮现「查看线路 ›」。
8. **线路纵深滑入**：点击车次面板从右滑入。
9. **站点阶梯绘制**：SVG stroke-dashoffset 逐站绘制点亮。
10. **铺位依次点亮**：卧铺剖面铺位依占用错峰点亮。
11. **线路弧绘制**：滚入视口 dashoffset 绘制。
12. **线路弧高亮**：点击弧加粗 + 浮出线路名。
13. **推进按钮反馈**：按下凹陷 + 牌面整体一次极轻震动。
14. **编辑标题墨痕揭示**：滚入视口 clip-path 墨痕揭示。
15. **页脚票根撕边**：hover 轻微撕开位移。

## 七、自定义光标规格
- 28px 圆环（coral 2px 描边）+ 中心 6px 墨点 + 十字准星（两条 14px coral 细线）。
- 开页定位视口正中，0.4s 淡入；`pointermove` 直接 `transform: translate3d`（轻微 lerp 平滑）。
- hover 可点击元素圆环放大 1.25 + 准星收缩；按下变实心半透明。
- `z-index: 2147483647`；`pointer-events: none`；触屏 `display:none`、恢复系统光标。

## 八、健壮性红线（已验证）
- 纯 vanilla 单文件，0 外部 URL 引用（CDN/字体/JS 全无），0 Console Error。
- `prefers-reduced-motion`：全部动效 `animation/transition-duration: 0.01ms` 降级，背景静态。
- `visibilitychange` / `document.hidden`：RAF 与定时器随可见性暂停、卸载取消；快速操作去抖不叠加定时器；高频 pointermove 直接操作 DOM。
- 响应式：1440 / 1024 / 768 / 390 实测无横向溢出（`overflow-x:hidden` + 自适应）、无重叠裁切。
- 截图像素 std 23.03 > 5（非空白）。

## 九、技术栈
纯 vanilla 单文件 HTML + 内联 CSS + 内联 JS。翻牌用 CSS 3D transform（perspective + rotateY/rotateX）；站点阶梯/铺位剖面/线路弧用内联 SVG + stroke-dashoffset；自定义光标用 pointermove + transform。无任何外部依赖。

# 鲸落档案馆 — 设计规范

| 令牌 | 色值 | 用途 |
|------|------|------|
| `--deep-sea` | `#0a0e1a` | 主背景（深海黑） |
| `--deep-sea-2` | `#0d1320` | 次级背景 |
| `--bone-white` | `#e8e4d8` | 主文字 / 高亮（骨白） |
| `--bone-dim` | `#b8b4a8` | 次级文字 |

| `--rust` | `#8b3a3a` | 警示 / 血锈红 |

## 动效系统

| # | 动效 | 物理模型 / 语义 |
|---|------|----------------|
| 1 | 深海粒子上浮 | 浮力模型（不同大小/速度/透明度） |
| 2 | 滚动深度标尺 | scroll-driven 数字变化（0m→4000m） |
| 3 | 鲸鱼骨架沉落 | scroll-driven transform |
| 4 | 声呐脉冲波纹 | 同心圆 RAF + 阻尼衰减 |
| 5 | 滚动渐入 | IntersectionObserver + CSS transition |
| 6 | 生物图鉴 3D 倾斜 | mousemove 直接操作 DOM transform |
| 7 | 数字计数动画 | 缓动函数 |
| 8 | 标题打字机 | 逐字显示 |
| 9 | 导航栏变色 | scroll-driven 透明→实色 |
| 10 | 按钮光泽扫过 | CSS animation |
| 11 | 章节过渡渐变 | CSS gradient transition |
| 12 | 环形生物多样性图 | SVG stroke-dasharray 动画 |

## 自定义光标

白色粗环 + 荧光青内点 + 多层发光（box-shadow），页面打开即居中显示，z-index 最高。悬停可交互元素放大变色，点击触发涟漪扩散。高频 mousemove 直接操作 DOM transform，不触发 React 重渲染。

## 页面结构

1. **Hero** — 全屏深海场景 + 标题 + 声呐动画
2. **深度标尺** — fixed 侧边栏，随滚动从 0m 变化到 4000m
3. **四个阶段叙事区** — 移动清道夫期 / 机会主义者期 / 化能合成期 / 礁体期，每个有独特布局
4. **生物图鉴网格** — hover 3D 倾斜卡片
5. **数据统计区** — 数字计数 + 环形图
6. **页脚**

## 健壮性

- 所有 RAF/定时器随 `visibilitychange` 暂停、`beforeunload` 取消
- 高频 mousemove 使用 lerp 阻尼直接操作 DOM
- 支持 `prefers-reduced-motion` 降级
- 纯 vanilla HTML/CSS/JS 单文件，无 React/Babel 依赖

## 技术栈

HTML5 + CSS3 + Vanilla JS，Google Fonts CDN，单文件 `index.html`

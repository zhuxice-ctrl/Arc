# 海玻璃博物馆 Sea Glass Atlas · 设计规范

> 日期：2026-08-17 ｜ 方向：V1 网页设计 ｜ 主题：海玻璃收集与海岸艺术品牌官网

## 色彩系统

| 角色 | 色值 | 用途 |
|---|---|---|
| 主色 海泡绿 | #5fb8a8 | 品牌主调、强调按钮、Hero 标题 |
| 深海青 | #1a5a52 | 深色区块底、页脚、导航高亮 |
| 强调 珊瑚橙 | #e87b5d | CTA、徽章、链接 hover |
| 沙金黄 | #d4a574 | 辅助强调、分割线、图标 |
| 奶油白 | #f7f3ea | 页面底色、卡片表面 |
| 礁石灰 | #8a9a93 | 次要文字、边框 |
| 衍生色 | #2a7d70 / #8ad0c2 / #eaf4f1 / #9c4730 / #e8c57a | 渐变层次、图鉴色系分类 |

配色语义：模拟潮间带质感——海泡绿如浪花、珊瑚橙如贝壳、沙金黄如沙滩，禁用蓝紫渐变。

## 字体

- 展示字 `--font-display`：衬线展示字体（标题/Hero）
- 正文字 `--font-body`：无衬线（正文、卡片）
- 等宽 `--font-mono`：数据、编号

## 圆角与间距

卡片圆角 18-24px；按钮 999px 胶囊；间距体系 8/12/16/24/40/64。

## 页面结构

1. 导航栏（滚动毛玻璃 + 吸顶变色）
2. Hero（潮汐粒子画布 + 三行标题渐入 + 打字机副标 + 浮动海玻璃装饰 + 脉动三色 orb）
3. 数据统计栏（4 个数字计数滚动）
4. 馆藏图鉴（9 件标本网格，按色系筛选，点击展开磨砂光箱）
5. 海岸故事（3 篇日志，多速度层滚动视差）
6. 工坊预约表单（实时校验 + 提交成功态）
7. 页脚（4 栏 + 社交磁吸按钮）

## 动效系统（16 项）

1. 自定义光标（弹簧跟随 + 悬停放大变色 + 点击涟漪 + 多层发光）
2. 潮汐粒子画布（多正弦波叠加 + 粒子潮汐漂动 + 光晕）
3. 3D 卡片倾斜（鼠标驱动，直接操作 DOM transform）
4. 磨砂玻璃光箱（点击展开 + 漂浮动画）
5. 滚动渐入（IntersectionObserver + 交错延迟）
6. 海岸故事视差（多速度层 RAF 驱动）
7. 磁吸按钮（反平方引力 + 弹簧缓动）
8. 数字计数（ease-out cubic 缓动）
9. 打字机（hero 眉标轮播 4 词）
10. 按钮光泽扫过
11. 卡片光泽横扫
12. 脉动光环（hero 三色 orb）
13. 工坊图标脉冲光晕
14. 导航栏滚动毛玻璃
15. 光标三态切换（普通/悬停/点击）
16. 浮动海玻璃装饰（独立漂浮）

物理模型：弹簧 Hooke（光标/磁吸）、正弦叠加（潮汐粒子）、ease-out 积分（计数）。动效周期各不相同。

## 健壮性

- 全部 RAF / 定时器随 visibilitychange 暂停、卸载统一取消
- prefers-reduced-motion 降级，光标隐藏回系统默认
- 触屏自动隐藏自定义光标
- 单文件 index.html，无外部 src 引用（仅字体 CDN）
- 高频鼠标事件直接操作 transform，不触发重渲染

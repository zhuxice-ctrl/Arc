# 活字印刷工坊 · 设计规范

## 主题
俯视一张木质活字印刷工作台，亲手完成李白《静夜思》的活字排版与印刷。

## 设计母题
活字印刷工坊——设计语言来自传统木作印刷台与铅活字。空间模型为**俯视工作台三区**（字盘 / 印版 / 器具），区别于竖向滚动堆叠。

## 色彩系统
| 用途 | 色值 | 说明 |
|------|------|------|
| 工作台深木底 | #0a0602 / #1a0f05 | 近黑深棕，竖纹木纹 |
| 木纹中调 | #2a1810 / #3a2514 | 中棕木纹 |
| 宣纸 | #f5ecd9 系 | 米白 |
| 墨 | #151515 / #1a1a1a | 墨黑 |
| 活字字面 | 铜金/铅灰 | 反刻字面 |
| 印版高亮 | 铜金色 | 排版完成呼吸边框 |

色彩逻辑：纸（米白）+ 墨（黑）+ 木（棕）+ 铜（金）四色体系，承担材质与层级。

## 字体系统
- 标题/活字：宋体衬线（Serif），体现古典印刷感
- 活字模面：反刻字（scaleX(-1) 镜像），印刷后转正
- UI 辅助：系统 sans-serif
- 字级跨度：主标题大号衬线 → 步骤提示小号 sans

## 空间结构
俯视工作台三栏：
- 左「字·盘」：5×4 反刻活字模库，打乱排列
- 中「印·版」：5×4 空凹槽排版区，竖排成诗
- 右「器·具」：墨刷 / 宣纸 / 压印扳手 / 成品区
顶部步骤进度条：排版→上墨→覆纸→压印→揭纸

## 动效系统（木质物理逻辑）
1. 字模拾起：阴影加深 + 轻微缩放
2. 字模放下：咬合微弹 cubic-bezier(0.34,1.56,0.64,1)
3. 字盘剩余字模：微妙浮动
4. 墨刷滑过：逐字墨迹扩散晕染
5. 宣纸覆盖：飘落
6. 压印扳手：杠杆下压
7. 揭纸：纸张翻起 + 墨字渐显（分列延迟）
8. 工作台木纹：微妙光影
9. 光标状态切换：毛笔尖/抓取/握持
10. 排版完成：印版铜金边框呼吸高亮
11. 成品纸：墨迹细微晕染
12. 重置：字模归位渐入

## 自定义光标
毛笔尖形态，RAF 阻尼跟随，开页居中显示，高对比层级最高。悬停字模变抓取态、拖拽变握持态。支持 prefers-reduced-motion 降级。

## 交互闭环
拖字模排版 → 点墨刷上墨 → 覆纸 → 压印扳手下压 → 揭纸成品 → 重置重玩

## 技术栈
纯 vanilla 单文件 HTML（HTML+CSS+JS 内联），无 React/Babel/CDN 外部依赖。RAF 随 visibilitychange 暂停、beforeunload 清理。响应式 1440/1024/768/390。

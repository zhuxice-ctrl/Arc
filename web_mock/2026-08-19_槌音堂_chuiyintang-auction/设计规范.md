# 槌音堂 · 春季拍卖会 — 设计规范

**类别**：Web Mock　**日期**：2026-08-19

## 设计概念
整个网站是一间正在进行中的拍卖现场。用户不是"浏览页面"，而是"走进拍卖厅"：穿过场次、驻足展台、举牌竞价、见证落槌。空间模型为「场次房间制」——瓷器场 / 书画场 / 钟表场三个拍卖厅，房间式导航，非 Section 垂直堆叠。

## 色彩系统（真实色值，取自源码）
- 深墨绿丝绒：`--velvet-deep #0d2a1e` / `--velvet-mid #163d2d` / `--velvet-light #1f503a`（帷幕、大厅基调）
- 象牙白图录纸：`--ivory #f3ebd6` / `--ivory-warm #e8ddc0` / `--ivory-dark #cdbf9a`（档案、图录、标题）
- 金铜：`--bronze #b8893a` / `--bronze-light #d4a856` / `--bronze-dark #8c6427` / `--gilt #e6c36a`（号牌、烫金成交价、展台描边）
- 落槌朱砂红：`--cinnabar #c0392b` / `--cinnabar-deep #922b21`（举牌按钮、成交印记、帷幕流苏）
- 墨色文字：`--ink #1a1a1a` / `--ink-soft #3a3a3a`

色彩分工：墨绿=空间氛围，象牙白=信息与档案，金铜=价值与仪式，朱砂红=动作与成交。无蓝紫渐变。

## 字体系统
- 中文展示/正文：Noto Serif SC / Songti SC（衬线，图录感）
- 英文展示字：`--display-en`（拍品编号、价格数字）

## 空间与结构
入场仪式（丝绒帷幕+标题推门）→ 大厅（顶栏：品牌印、直播状态、号牌、成交额）→ 当前场次展台（拍品编号、图录照、估价区间、当前出价）→ 举牌竞价区 → 成交记录侧栏 → 底部场次切换（01 瓷器场 / 02 书画场 / 03 钟表场）。

## 动效系统（≥12 组件级）
丝绒帷幕拉开、标题浮入、展台射灯亮起、价格机械翻牌、号牌光标三态（跟随/举起/按下）、木槌闪光+画面震动、烫金"成交"印记定格、成交记录条目滑入、尘埃漂浮、场次推门横切、拍品入场淡入、钟表摆锤物理摆动、档案抽屉上滑。

## 签名交互
按住"举牌"→ 价格沿竞价阶梯连续跳动（80万→90万→100万→120万…）→ 松手定格 → 三声报价（第一次/第二次/最后一次）→ 木槌落下 → 成交价烫金定格并写入成交记录。

## 自定义光标
象牙白拍卖号牌形（`.cursor-paddle`，28×40，z-index 9999，pointer-events: none），开页即显示在屏幕中央；跟随/举起/按下三态。

## 内容系统
9 件真实可信拍品（如 LOT001 青花缠枝莲纹梅瓶·明永乐），每件含年代、尺寸、品相、估价区间、"来源 Provenance"流转年表（档案抽屉内）。

## 工程
单 HTML 文件（React + Babel 内联）；RAF/定时器随可见性暂停；快速操作不叠加定时器；支持 prefers-reduced-motion；无 console error；1440px 与 390px 均无横向溢出。
修复记录：初版 `.entrance{pointer-events:none}` 导致入场标题无法点击，已在 `.entrance-title` 补 `pointer-events:auto` 修复（工程修复 1 次）。

# 设计规范 · 灼兆 · 殷墟甲骨占卜台

## 设计母题
殷墟甲骨灼兆占卜台。整站是一座固定的贞人祭坛——用户执青铜灼锥，灼烧骨版钻凿凹位，兆纹当面迸裂生长，贞人据兆占断、朱砂判词与刻辞显现。「灼→裂→断」的因果链即占卜本身，不是装饰。

## 空间模型
`fixed_ritual_altar_stage`（固定祭坛单屏舞台）
- 桌面端 100vh 单屏无滚动：顶部 header（标题+步骤指示 整治·钻凿·灼兆·占断·刻辞）/ 主舞台（骨版+钻凿点+灼锥交互）/ 右栏卜问档案 / 底部五骨索引条。
- 移动端 <768px 转竖向可滚动：header / 主舞台 / 档案 / 底部索引横向 chip。

## 核心交互机制
1. 进入：开场夯土幕布 + 「灼兆」朱印落下，点击「执灼锥」揭幕并恢复 AudioContext。
2. 自定义灼锥光标（青铜锥杆+尖端，开页居中 left/top 50%，z-index 最高）；pointermove 实时跟随，直接操作 DOM transform。
3. 灼锥接近主钻凿点（checkNearDrill 距离判定）：钻凿点热呼吸增强（drillBreathNear）。
4. pointerdown 且 nearDrill 已置位 → startHeating：蓄热 heatLoop（RAF，heatDuration=1300ms），灼点橙光膨胀、骨面光晕、WebAudio 低嗡渐强、步骤推进「灼兆」。
5. 进度≥1 自动 triggerCrack，或 pointerup 时进度>0.35 触发：兆纹 7 条 path 按 data-delay/data-duration 逐段 stroke-dashoffset 生长（主干先行、分叉滞后爆裂）、骨面 boneShake 阻尼微颤、裂帛声短爆点。
6. 兆成：右栏「王占曰」判词朱砂擦除填入 + sealStamp 印章盖下 + 刻辞逐字显现；底部该骨 chip 状态由「未卜」变「兆成」。
7. 五骨皆兆成 → 结语「五兆既成，契于龟甲」浮现。

## 动效系统（热力学 + 脆性断裂语言）
@keyframes：boneShake（骨面迸裂微颤阻尼）、drillBreath（钻凿点 idle 呼吸）、drillBreathNear（接近时呼吸增强）、sealStamp（印章盖下）、tipGlowPulse（灼锥尖端发光）、sealDrop（朱印落下）、fadeUp（元素入场）。
配合 JS 驱动：兆纹 dashoffset 逐段生长、灼点光晕蓄热膨胀、浮尘上升（ambient）、刻辞逐字、骨切换淡入淡出。共 ≥12 个组件级动效，全部服务「热（呼吸式慢膨胀）」与「裂（爆发式分叉）」两种物理，无任何装饰性特效。

## 健壮性
- 纯 vanilla 单文件，零外部依赖（无图片/字体/JS CDN，骨版与兆纹全部内联 SVG）。
- requestAnimationFrame 9 处 / cancelAnimationFrame 6 处配对；visibilitychange 暂停 RAF 与音频；无 setInterval。
- prefers-reduced-motion：裂纹一次性出现、浮尘关闭、印章无旋。
- WebAudio 仅在用户首次手势后 resume，autoplay-policy 安全。
- pointermove 高频事件直操 DOM，不触发框架重渲染（无框架）。
- 零未定义引用，控制台零 error，无 404。

## 技术栈
HTML + 内联 CSS + 原生 JS（无构建、无框架、无依赖）。文件 index.html 单文件 57.5KB。

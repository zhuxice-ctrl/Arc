## 组件规范

- **琥珀球 Hero**：径向渐变球体 + 内部昆虫 SVG 剪影，3D 视差随鼠标驱动（弹簧平滑）
- **磁性按钮**：13 处，反平方引力 pull，hover 时按钮 +6% scale + 琥珀金描边发光
- **标本卡片**：圆角 12px，perspective 800px 3D 倾斜，hover 弹簧回归
- **Tab 指示器**：底部 3px 琥珀金条，cubic-bezier(0.4,0,0.2,1) 滑动
- **自定义光标**：三环（弹簧阻尼外环 36px / 快跟内点 6px / 惯性环），白色粗环 + 琥珀金内点 + 多层 box-shadow 发光，z-index 99999，difference 混合

## 动效系统

14 个组件级特效，均基于物理模型 / 语义：

1. 自定义光标（弹簧阻尼 + 惯性环）
2. 磁性按钮（反平方引力 pull）
3. Hero 琥珀球 3D 视差（弹簧平滑）
4. 尘埃粒子漂浮（32 颗，正弦横向摆动 + 上升循环，各不同周期）
5. 打字机标题（6 词循环，打字/删除速度差 + 停顿）
6. 数字计数器（easeOutExpo）
7. 滚动渐入（IntersectionObserver + 错落延迟）
8. Tab 滑动指示器（cubic-bezier）
9. 标本卡片 3D 倾斜（perspective + rotateX/Y 弹簧回归）
10. 多层视差引言段（三层 SVG 不同速度滚动）
11. 放大镜 loupe（hover 镇馆之宝局部放大）
12. 票价数字过渡（cubic 补间）
13. 头像脉冲点（朱砂红呼吸脉冲）
14. 光泽扫过按钮（skew 斜光错位周期）

所有 RAF 由统一调度器管理，`visibilitychange` 暂停 / 恢复；定时器重建前 clearTimeout；高频 mousemove 直接改 transform；`prefers-reduced-motion` 全量降级。

## 页面结构

单页纵向滚动：导航栏 → Hero（琥珀球 + 打字机标题 + 统计计数）→ 镇馆之宝（放大镜）→ 标本卡片网格（3D 倾斜）→ 视差引言 → 票种切换 → 参观信息 → 页脚。

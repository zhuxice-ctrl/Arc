# 长夜书店 · 设计规范

> 方向：V1 网页设计 · 主题：24 小时不打烊的深夜独立书店官网
> 日期：2026-08-18

## 色彩系统

| 角色 | 色值 | 用途 |
|------|------|------|
| 夜色底 | `#0A1628` | 页面主背景，深夜墨蓝 |
| 深夜次底 | `#1A2E52` | 分区深色块、卡片暗底 |
| 蜜金灯光 | `#D4A84B` | 主强调色，台灯光晕、标题描金、链接 |
| 暗金 | `#8B6914` | 灯光暗部、边框金属感 |
| 灯光亮调 | `#F0D68A` / `#F6E5AE` | 高光、悬浮态 |
| 纸米白 | `#F5EFE0` | 正文文字、卡片纸面 |
| 米白暗调 | `#EDE4CD` / `#DDD0AE` | 次级文字、分隔线 |
| 冷月光 | `#BFCBDD` / `#8BA0BE` | 辅助文字、冷色点缀 |
| 砖红 | `#7A2E2E` | 警示/活动标签 |
| 深绛 | `#4A2545` | 装饰暗色块 |

配色逻辑：深墨蓝夜色作底，蜜金灯光作唯一暖光源串联全站，纸米白承载文字，冷月光做低饱和冷色平衡，无蓝紫渐变。

## 字体

- 展示字体：`Noto Serif SC`（书名、大标题，400/500/600/700/900）
- 正文字体：`Noto Sans SC`（正文、导航、按钮，300/400/500/700）
- 字号阶梯：Hero 64–96px / H1 40px / H2 28px / 正文 16px / 辅助 13px

## 组件规范

- 书籍卡片：3D 翻转 + 光泽扫过，hover 翻起书脊
- 事件列表项：hover 左侧金线从上展开 + 箭头右移
- 导航栏：滚动收缩，吸顶半透明毛玻璃
- Modal：弹簧缩放出现（cubic-bezier 弹簧）
- 按钮：蜜金描边，hover 灯光填充

## 动效系统（14 项，周期各不相同）

1. 自定义光标（三环：外框/内点/光晕，弹簧跟随，三态切换）
2. 点击涟漪扩散
3. 台灯呼吸光晕 + 轻摇（正弦 4s）
4. 尘埃粒子漂浮（RAF 积分 + 正弦摆动 + 上升漂移）
5. 打字机副标（随机速度扰动）
6. 滚动渐入（IntersectionObserver，stagger）
7. 书籍 3D 翻转 + 光泽扫过
8. 书架视差（鼠标位置驱动多深度层）
9. 数字计数（cubic ease-out，进入视口触发）
10. 地图脉冲定位（径向扩散环）
11. 导航栏滚动收缩
12. 事件列表 hover 金线展开 + 箭头位移
13. Modal 弹簧缩放出现
14. 滚动提示线流

物理模型：弹簧跟随（光标）、RAF 积分器（粒子/计数）、正弦周期（灯光呼吸）；语义模型：书页翻转、灯光呼吸、尘埃浮动。严禁整图缩放/Ken Burns。

## 页面结构

1. Hero 首屏 — 呼吸台灯光晕 + 悬浮尘埃 + 打字机副标 + 数字统计
2. 深夜选书 — 4 分类 Tab（深夜推荐/文学经典/人文思想/诗歌散文），16 本真实书名；下接 22 册书架视差
3. 夜读活动 — 5 场真实活动（朗读会/工作坊/夜读马拉松/交换市集/作家对谈）
4. 书店日志 — 5 篇真实感随笔（含 1 篇 Featured 大图卡），点击进文章弹窗
5. 到店指南 — 地址/营业时间/到店须知 + 脉冲定位地图卡（sticky）
6. 长夜来信 — 邮箱订阅表单 + 成功反馈

## 健壮性

- 全部 JSX/CSS 内联，零外部文件引用
- RAF/定时器随 visibilitychange 暂停、卸载取消
- 高频鼠标事件直接操作 DOM transform
- prefers-reduced-motion 完整降级（含光标关闭）
- 响应式：1024px / 768px 两档断点，移动端关闭自定义光标

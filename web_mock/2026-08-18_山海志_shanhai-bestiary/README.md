# 山海志 · 异兽图鉴数字展

- 日期：2026-08-18
- 方向：V1 网页设计
- 主题：山海经异兽沉浸式线上展

## 简介

一个以《山海经》异兽为主题的沉浸式数字展览网站。卷轴式首页展开后进入异兽图鉴（九尾狐 / 烛龙 / 白泽 / 精卫 / 应龙 / 夔牛，每只附典籍原文节选、形态描述与寓意），下设青丘秘境、钟山幽都、昆仑悬圃、东海惊涛四大展区。全站采用中国传统矿物颜料配色：宣纸米白底、赭石、石绿、墨色、朱砂点缀。

## 动效亮点

- 自定义光标：弹簧物理跟随，开页即居中，悬停形变 + 点击涟漪
- 图鉴卡片 3D 倾斜（弹簧阻尼）
- 印章盖章回弹、打字机副标题、数字计数缓动
- 流云漂浮、滚动渐入、悬停发光描边、滚动进度条

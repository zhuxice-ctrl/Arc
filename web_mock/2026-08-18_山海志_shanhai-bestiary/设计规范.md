# 山海志 · 异兽图鉴数字展 — 设计规范

- 日期：2026-08-18
- 方向：V1 网页设计（真实可交互的完整网站 · 沉浸式线上展）
- 主题：山海经异兽图鉴数字展

## 色彩系统（中国传统矿物颜料风）

| 角色 | 色值 | 用途 |
|---|---|---|
| 宣纸米白 | `#F5EFE0` | 页面主底色 |
| 宣纸深色阶 | `#E8DFC9` / `#EFE6CE` | 卡片 / 分区表面 |
| 墨色 | `#2B2620` | 主文字、深色区块 |
| 浓墨 | `#1A1814` | 页脚 / 深底展区 |
| 赭石 | `#9C4A2F` / `#B86244` | 辅助强调、按钮 |
| 朱砂 | `#C0392B` / `#A52E22` | 印章、强调点缀 |
| 石绿 | `#4A7A6A` / `#6A9A8A` | 辅助色、图标、标签 |
| 赭金 | `#B8860B` / `#D4A84B` | 品级标记、装饰线 |
| 灰墨 | `#6B6257` / `#4A4238` | 次要文字、边框 |

禁止蓝紫渐变；全站无渐变滥用，以实色 + 纸纹质感分层。

## 字体

- 标题 / 书法字：`'Ma Shan Zheng'`（马善政毛笔体，cursive）
- 副标题 / 展区名：`'ZCOOL XiaoWei'`（站酷小薇，serif）
- 正文：`'Noto Serif SC', 'Source Han Serif CN', serif`

## 页面结构

1. 卷轴式 Hero：展览标题、印章盖章动效、打字机副标题、远山剪影与流云
2. 异兽图鉴：九尾狐 / 烛龙 / 白泽 / 精卫 / 应龙 / 夔牛 6 张图鉴卡（原文节选、形态、寓意、品级）
3. 四大展区：青丘秘境 / 钟山幽都 / 昆仑悬圃 / 东海惊涛
4. 关于展览：统计数字计数 + 古籍背景介绍

## 动效系统（12+，全部贴主题语义）

- 自定义光标：弹簧物理跟随，悬停形变，点击涟漪，开页即居中显示
- 图鉴卡片 3D 倾斜（弹簧阻尼，mousemove 直操作 DOM transform）
- 印章盖章回弹、打字机文字、数字计数缓动
- 流云漂浮、卷轴印章出现、滚动渐入揭示
- 悬停发光描边、底部滚动进度条、导航栏滚动压缩、模态框缓动展开

## 健壮性

- `visibilitychange` 自动暂停所有 RAF / 定时器，卸载统一取消
- 重建定时器前先清理旧的，快速操作不叠加
- 高频鼠标事件不触发 React 重渲染
- 支持 `prefers-reduced-motion` 降级
- JSX 全部内联于 index.html，无外部 jsx 引用

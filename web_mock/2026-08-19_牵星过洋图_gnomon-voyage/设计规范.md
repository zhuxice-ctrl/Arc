# 過洋牽星圖志 · 設計規範

> V1 網頁設計 · 2026-08-19 · 牽星過洋圖 Gnomon Voyage

## 1. 主題與空間模型

### 1.1 主題
明代鄭和下西洋時期的**牽星過洋圖**——航海羅經、星官定位、牽星尺觀測的三維互動複原。

### 1.2 空間模型
**水平海圖 + 垂直觀測台 雙層疊合（horizontal_horizon_dual_layer）**
- 底層（z-index:1-2）：海圖 SVG + 波紋 canvas
- 中層（z-index:3）：天幕星海 canvas
- 頂層（z-index:6-9）：寶船、羅經盤、牽星尺、讀數標籤
- 邊緣固定 UI：頂部文獻條、左側星官錄、右側航程簿、底部操作帶

### 1.3 視覺隱喻
- **海圖即世界** ── 觀者既在船上、也在案卷前
- **牽星尺 = 船長的手指** ── 拖動它指向星辰
- **羅經盤 = 辨方正統** ── 永遠指向寶船下一段的方向
- **港口節點 = 朱砂印** ── 已經到過的是銅金印，正在經過的是朱砂放光

## 5. 互動模型

### 5.1 牽星操作（核心）
- **拖動牽星尺**（`.gnomon`）→ pointerdown/move/up → 找最近星 → lockStar
- 鼠標在星點 140 像素內時自動鎖定，否則自由指向
- 鎖定後右側「牽星高度」自動更新，羅經盤指向下一段方位
- 鍵盤：M = 自動牽星、R = 回中、←/→ = 進退一段、Space = 過洋

### 5.2 航段切換
- 點擊底部節點 → jumpTo
- 點擊左側星官 → lockStar
- 點擊海圖上的港口 → jumpTo
- 點擊時辰按鈕 → 切換航海時辰
- 過洋按鈕 → 自動牽星 + advance

### 5.3 視覺回饋
- active 段港口：朱砂亮 + 光暈
- passed 段港口：銅金
- 整個航線：朱砂主線 + 已經走過的加粗朱砂
- 牽星記（左下）：即時更新 `取牽星尺，量${星名}得${指數}指（古籍原話）`

## 6. 數據真實性

### 6.1 12 港口（鄭和下西洋真實航線）
應天府 → 五虎門 → 占城 → 爪哇 → 舊港 → 蘇門 → 錫蘭山 → 古里國 → 祖法兒 → 天方 → 亞丁 → 慢八撒

每站配備古名、今地、經緯度、牽星語錄、距離。

### 6.2 12 星辰
北辰(Polaris)、華蓋(Dubhe)、織女(Vega)、牛郎(Altair)、參宿七(Rigel)、北斗三(Phecda)、北斗五(Megrez)、南十字(Acrux)、燈籠星(Canopus)、畢宿五(Aldebaran)、室宿一(Alpheratz)、軒轅十四(Regulus)

### 6.3 牽星高度（《過洋牽星圖》原圖）
- 1 指 ≈ 1°54′ = 0.5833°
- 「見北辰星四指 看水六托 ── 錫蘭山」
- 「華蓋八指半 高低依此 ── 祖法兒」
- 「織女星七指 船到柯枝 ── 古里國」
- 「燈籠星低 出赤道南 ── 爪哇」

## 7. 健壯性

- 純 vanilla 單文件（無 React/Babel/CDN）── 從根本上避免白屏
- RAF 動畫隨 `document.hidden` 暫停（`visibilitychange`）
- 高頻事件（pointermove）直接操作 transform/rotate，不觸發重排
- 縮放時 resizeTimer 防抖 150ms
- `prefers-reduced-motion` 媒體查詢全量降為 0.001ms

## 8. 自定義光標

- `mix-blend-mode: exclusion` 疊加，米黃在深底上清晰
- 雙環 + 十字符號 + 銅光指針 + 度數標籤
- drag 牽星時環線變朱砂光暈
- 鼠標出窗口自動隱藏

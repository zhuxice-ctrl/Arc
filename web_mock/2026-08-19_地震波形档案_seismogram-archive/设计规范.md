# 设计规范 · 地震台网波形档案

> 类别 Web Mock｜日期 2026-08-19｜类型 数据 / 科学档案工具型

## 一、设计母题与空间模型

**母题**：`horizontal_seismogram_trace_spine`——水平多台站地震波形迹线为页面唯一脊柱。

整页像一台可翻阅的地震台网记录仪：顶部是仪器控制条（台网切换 / 震例选择 / 时间窗 / 操作提示），中段是 5 条台站波形轨纵向堆叠成的横向"胶卷带"，底部是跨台站走时剖面与走时弧回放区。点击波形上的 P 波 / S 波到达点，右侧浮出真实震情档案面板并触发走时弧回放。

**非**：竖向 section 堆叠、卡片网格、固定单舞台、可平移地图、拖拽时间游标。

## 二、配色系统（CSS 变量，禁蓝紫 / 禁纸本水墨木色）

| 变量 | 色值 | 语义 |
|---|---|---|
| `--console-bg` | `#0B0E11` | 控制台深近黑底 |
| `--panel-line` | `#1f262d` | 面板分隔线 |
| `--grid-line` / `--grid-minor` | `#1a2026` / `#14181d` | 迹线网格主 / 次 |
| `--trace-amber` | `#E8A23B` | P 波主迹线（磷光琥珀） |
| `--trace-amber-dim` | `#7a5722` | 琥珀暗调（震前背景微震） |
| `--trace-teal` | `#3FB8AF` | S 波迹线（青绿） |
| `--trace-teal-dim` | `#266964` | 青绿暗调 |
| `--warn-red` | `#E8453B` | 峰值 / 警示红 |
| `--warn-red-dim` | `#7a241f` | 警示暗调 |
| `--paper` | `#E8E2D4` | 主文字（米白） |
| `--paper-dim` / `--paper-faint` | `#a39e92` / `#5a574f` | 次 / 弱文字 |
| `--dossier-bg` | `#0f1318` | 档案面板底 |
| `--scan-glow` | `rgba(232,162,59,0.12)` | 扫描辉光 |

色彩承担层级 / 状态 / 语义：琥珀=P 波（先到、小振幅）、青绿=S 波（后到、大振幅、破坏性强）、红=峰值震级、米白=信息文本。灰度下 P/S 双迹与幅度仍可辨。

## 三、字体系统

- 正文 / 界面：`"PingFang SC", "Microsoft YaHei", "Hiragino Sans GB", sans-serif`
- 数据 / 代号 / 时刻：`"SF Mono", "Menlo", "Consolas", monospace`
- 仅用系统字体栈，无外部字体加载。中文文案为主，台站代号 / 科学术语保留英文。

## 四、动效系统（≥12 组件级，符合地震波物理）

1. 走时弧扩散——点击后从震中向各台站按真实走时差依次点亮
2. P / S 波段辉光——波至区段沿迹线高亮
3. 峰值脉冲环——最大振幅处警示红环呼吸
4. 记录仪扫描线——琥珀扫描线沿迹线脊柱横移
5. 震例切换横移过渡——切震例时胶卷带横向位移
6. 波至点 hover 放大——到达标记悬停放大
7. 记录红点呼吸——当前选中波至点持续脉冲
8. 台站轨渐变网格——网格随扫描线明暗
9. 面波振幅包络——大震面波段振幅包络起伏
10. 尾波衰减——`coda` 段振幅指数衰减
11. 档案面板滑入——右侧档案面板滑入 / 滑出
12. 光标形态切换——十字准星记录笔光标随交互区切换

物理逻辑：波至突跳 → 衰减振荡 → 走时扩散；禁整图缩放 Ken Burns、禁无意义发光球。`prefers-reduced-motion` 下减弱动画。

## 五、交互

- **主交互**：点击波形迹线上的 P 波 / S 波 / 峰值到达点 → 右侧浮出真实震情档案 + 触发走时弧回放。
- **键盘**：← → 在 6 个震例间步进；ESC 关闭档案；空格触发回放。
- **自定义光标**：十字准星记录笔，开页居中、高对比、层级最高（`cursor:none` + 自绘元素）。

## 六、签名时刻

点击东日本 9.0 那道刺破全轨的峰值，5 条台站轨按真实走时差依次重绘波形，走时弧从震中向各台站逐条点亮扩散——亲手触发"波如何到达台站"。

## 七、内容（全部真实）

6 次历史大震：汶川 8.0（2008-05-12 14:28 四川，深 14km）、唐山 7.8（1976-07-28 03:42 河北，深 11km）、东日本 9.0（2011-03-11 14:46 太平洋近海，深 24km）、尼泊尔 7.8（2015-04-25，深 8km）、智利 9.5（1960-05-22，深 33km，有记录以来最大）、印度洋 9.1（2004-12-26 苏门答腊外海，深 30km）。每条含震级 / 深度 / 位置 / 发震时刻 / 简述与影响。

5 个台站：恩施 ENH / 昆明 KMI / 牡丹江 MDJ / 拉萨 LSA / 佘山 SSE（含经纬度）。离震中越近的台站波至越早，符合地震波传播规律；P 波先到、S 波后到、幅度承载震级。

## 八、技术栈

纯 vanilla 单文件 HTML（HTML + CSS + JS），无 React / Babel / CDN / 外部图片。波形用 Canvas 渲染，种子化伪随机保证可重现。RAF 随页面可见性暂停、卸载时取消；快速操作不叠加定时器；高频鼠标事件直接操作 DOM；支持 `prefers-reduced-motion`。

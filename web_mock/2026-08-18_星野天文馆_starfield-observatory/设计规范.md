# 星野天文馆 · 设计规范

> 日期：2026-08-18 · 方向：V1 网页设计 · 主题：高山天文台官方网站

## 一、设计概念

「星野天文馆」是一座高山天文台的官方网站，围绕星空观测、星座故事、天象日历与望远镜参观预约组织内容。整体气质为「深空夜色为底、星金为脉」，营造仰望星空的沉静与精密感。配色严格避开蓝紫渐变，以深空蓝黑夜空底配星金强调。

## 二、色彩系统

| 角色 | 色值 | 用途 |
|------|------|------|
| 深空底 | `#0a0e1a` | 页面最底层背景 |
| 夜空蓝 | `#121a2e` | 主区块背景 |
| 暗夜蓝 | `#1a2540` | 卡片/面板表面 |
| 星金 | `#d4af37` | 主强调色（标题点缀、连线、光标内点） |
| 亮金 | `#e6c76a` | 高亮文字、统计数字 |
| 雾白 | `#e8e6e0` | 正文文字 |
| 暗银灰 | `#4a5266` / `#8a8f9c` | 次要文字、分隔线 |

金色透明度阶层：`rgba(212,175,55, 0.1/0.15/0.2/0.3/0.5)` 用于光晕、边框、悬浮发光。

## 三、字体排印

- 标题：`Noto Serif SC`（400/600/700/900）——衬线，沉稳天文气质
- 正文：`Noto Sans SC`（300/400/500/700）
- 数据/坐标：`JetBrains Mono`（400/500）

## 四、组件规范

- 圆角：卡片 16px，按钮 10px，徽章 999px（胶囊）
- 阴影：暗夜蓝卡片 `0 8px 32px rgba(10,14,26,0.8)`；金色发光 `0 0 24px rgba(212,175,55,0.3)`
- 导航栏：滚动收缩 + 毛玻璃 `backdrop-filter: blur(12px)`
- 按钮：磁性吸附（反平方引力模型），光泽扫过动效

## 五、动效系统（14+ 组件级特效）

1. 全屏星野粒子（大气闪烁：正弦+谐波叠加）
2. 流星（重力弧线 + 缓出）
3. 自定义三层光标（白环+金点+辉光，阻尼惯性跟随）
4. 光标悬停形变（放大+十字准星+涟漪）
5. Hero 元素错峰渐入
6. 打字机轮播标语
7. 统计数字弹性计数
8. 滚动渐入（网格错峰）
9. 磁性按钮（反平方引力）
10. 圆顶卡片 3D 倾斜（RAF 阻尼积分器）
11. 星座卡片 3D 倾斜 + SVG 连线描边
12. 望远镜 SVG 视差浮动 + 鼠标驱动旋转
13. 按钮光泽扫过
14. 金色标题微光呼吸
15. 导航栏滚动收缩+毛玻璃

## 六、页面结构（单页 7 区块）

首屏 Hero → 关于天文台 → 当季星座（6 张） → 天象日历（5 月可切） → 望远镜设备（4 台可切） → 参观预约（表单） → 页脚。

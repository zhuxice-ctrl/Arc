# 琉璃光院 Glaze Garden · V1 网页设计

> 日期：2026-08-17 · 方向：V1 网页设计 · 主题：琉璃艺术工坊展览网站

## 简介

「琉璃光院」是一个虚构的琉璃艺术工坊与展览空间的官方网站。工坊结合传统琉璃烧制技艺与当代艺术表达，展示琉璃作品、工坊课程、艺术家驻留、展览信息。配色取自琉璃在火与光中的质感——琥珀铜色、翠绿玻璃、深炭黑与古铜金。

## 动效亮点

- 自定义光标（白色粗环+铜色内点+发光晕+悬停放大+点击涟漪）
- 琉璃熔融标题（多色渐变流动）
- 光线折射背景（鼠标移动时五条光束动态偏转）
- 60 颗粒子系统（琉璃碎片/火花飘浮）
- 作品卡片 3D 倾斜+光泽扫过
- 数字计数滚动、视差滚动、打字机效果、脉冲发光
- 导航栏滚动变色（模糊+描边+高度收缩）

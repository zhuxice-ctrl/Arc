# 雾夜马戏团 Cirque Brume — 设计规范

## 主题
一支巡回奇幻马戏团的官方网站：雾气、丝绒幕布、聚光灯、空中飞人、火舞与小丑，神秘华丽的夜间马戏氛围。

## 色彩系统
| 角色 | 色值 | 用途 |
|------|------|------|
| 主色 · 深绯红 | `#7A1E2B` | 幕布、强调、品牌 |
| 深红辅 | `#4A1018` / `#5A141D` | 渐深层次、阴影 |
| 背景 · 炭黑 | `#14100E` | 主背景 |
| 炭黑辅 | `#1E1814` | 卡片底 |
| 强调 · 旧金黄铜 | `#C89B5A` | 按钮、装饰线、光标内点 |
| 金辅 | `#8B6A35` / `#E4BE7E` | 金属层次 |
| 文字 · 象牙白 | `#F3EAD8` | 正文 |
| 米辅 | `#C8BFA8` | 次要文字 |
| 点缀苔绿 | `#6B8E5A` | 自然细节点缀 |

禁用蓝紫渐变。整体暗色基调 + 绯红与旧金点缀。

## 字体
- 标题：`'Playfair Display', serif`、`'IM Fell English SC', serif`（古典戏报感）
- 正文/装饰：`'Cormorant Garamond', Georgia, serif`

## 圆角
以拱形与圆形为主：`border-radius: 50%`（聚光灯/光标环）、`50% 50% 0 0 / 100% 100% 0 0`（帐篷拱顶）、`50% 50% 30% 30%`（帐篷底）。

## 页面结构
1. 开场：点击「Ouvrir le Rideau」拉开左右分轨深红丝绒幕布 → 聚光灯摆动 → Hero
2. 节目单：6 个完整节目卡片（空中飞人 / 火舞 / 柔术 / 哑剧小丑 / 魔术 / 现场乐队），点击展开详情模态框
3. 在线选座购票：帐篷环形座位图（8 排 / VIP 与普通区 / 5 个日期切换 / 实时计价）
4. 剧团编年史：1887–1926 时间线，6 个节点
5. 巡演城市：8 个城市
6. 页脚

## 组件级动效（≥12）
自定义光标（白粗环 + 旧金内点 + 多层发光，开页即居中，悬停放大三态，点击涟漪弹簧）、幕布开启、聚光灯摆动、尘埃粒子（Canvas 缓慢上升+左右摆动）、卡片 3D 倾斜（弹簧阻尼，直接操作 DOM）、滚动渐入、打字机、数字计数（ease-out cubic）、光泽扫过按钮、选座弹跳、时间线节点发光脉冲、跑马灯、视差聚光灯。

## 健壮性
- 所有 JSX/CSS 内联在单文件 `index.html`
- RAF / 定时器随 `visibilitychange` 暂停，卸载取消
- 高频 mousemove 直接操作 DOM transform
- `prefers-reduced-motion` 全降级；移动端隐藏自定义光标

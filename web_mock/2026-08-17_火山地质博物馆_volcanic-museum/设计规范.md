| 层级 | 字体栈 | 用途 |

## 圆角规范

| 值 | 用途 |
|----|------|
| `2px` | 小元素、标签 |
| `4px` | 卡片、按钮 |
| `50%` | 圆形元素、光标 |

## 组件规范

- **展厅卡片**：深色表面 `#2a211c`，4px 圆角，hover 时发光边框 + 3D 倾斜
- **统计卡**：数字使用大字号 + 岩浆橙强调色，hover 时图标脉冲呼吸
- **导航栏**：半透明深色背景 + 模糊滤镜，滚动时收缩
- **自定义光标**：白色粗环（36px）+ 岩浆橙内点（6px）+ 多层 box-shadow 发光，z-index 99999

## 动效系统

| 动效 | 实现方式 | 说明 |
|------|----------|------|
| 岩浆粒子背景 | Canvas + requestAnimationFrame | 粒子物理上升 + 水平摆动 |
| 自定义光标 | mousemove → DOM transform | 直接操作 DOM，不触发 React 重渲染 |
| 滚动渐入 | IntersectionObserver | 元素进入视口时添加 visible class |
| 卡片 3D 倾斜 | mousemove → DOM transform | 基于 mouseenter/mouseleave 计算 rotateX/Y |
| 数字计数 | requestAnimationFrame + easeOutCubic | 从 0 计数到目标值 |
| 热浪扭曲 | SVG feTurbulence + feDisplacementMap | 滤镜动画模拟热空气上升 |
| 悬停发光 | CSS box-shadow transition | 卡片边框从暗到亮渐变 |
| 滚动视差 | scroll 事件 → 多层 translateY | Hero 区和特展区不同速度移动 |
| 打字机效果 | setInterval 循环 | 3 句标语循环打字 + 删除 |
| 图标脉冲 | CSS @keyframes pulse | 统计卡 hover 时触发 |
| 光泽扫过 | CSS @keyframes shine | 卡片表面伪元素从左到右扫过 |
| 入场序列 | CSS animation + 延迟 | 页面元素分层渐入 |

## 页面结构

1. **Hero 区** — 博物馆名称 + 打字机标语 + 火山背景 + 岩浆粒子
2. **展厅导航** — 5 张展厅卡片（地球之火 / 岩浆走廊 / 地质年代表 / 火山口实景 / 互动实验区）
3. **特色特展** — "岩浆之魂" 大图 + 文字 + 视差滚动
4. **馆藏数据** — 4 项数字计数（标本 12,680+ / 矿石 356 种 / 火山口模型 48 / 研究论文 1,200+）
5. **参观信息** — 开放时间轴 + 门票/地址/须知卡片
6. **页脚** — 品牌信息 + 链接 + 社交媒体

## 健壮性

- requestAnimationFrame 随页面可见性暂停（visibilitychange），卸载时取消
- 高频鼠标事件直接操作 DOM transform，不触发 setState
- 支持 prefers-reduced-motion：降级为静态最小动效
- 移动端自动隐藏自定义光标

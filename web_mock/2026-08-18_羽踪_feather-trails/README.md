# 羽踪 · 候鸟迁徙观测站

> 日期：2026-08-18 · 方向：V1 网页设计 · 主题：候鸟迁徙观测站杂志式官网

![羽踪预览](./preview.png)

## 简介

一个关于候鸟迁徙的杂志式观测站官网，霜白底 + 墨羽黑 + 落日橙的编辑杂志质感。内容含首屏鸟群粒子编队、世界迁徙路线 SVG 地图、四种候鸟（丹顶鹤 / 鸿雁 / 北极燕鸥 / 斑尾塍鹬）3D 图鉴卡片、实时观测数据面板、观测手记文章网格等，围绕候鸟主题组织真实可信内容。

## 动效亮点

- 鸟群粒子编队飞行（Canvas + 正弦波 + 翅膀拍动）
- 迁徙路线 SVG 滚动驱动路径绘制
- 3D 卡片倾斜 + 光泽扫过
- 雷达频谱柱状图模拟回波
- 磁性按钮、打字机、数字计数、羽毛飘落
- 自定义光标（弹簧跟随 + 悬停三态 + 点击涟漪），开页即显示在屏幕中央

共 16 个组件级特效，全部基于物理模型或候鸟主题语义。

# 设计规范 · 羽踪 · 候鸟迁徙观测站

> 日期：2026-08-18 · 方向：V1 网页设计 · 主题：候鸟迁徙观测站杂志式官网

## 色彩系统

| 角色 | 色值 | 用途 |
|------|------|------|
| 底色 | #F4F1E8 | 页面霜白底，编辑杂志质感 |
| 次底 | #FBF9F2 / #E8E4D8 / #DDD8C9 | 卡片表面、分区底色 |
| 主文字 | #1F242C | 墨羽黑，标题与正文 |
| 强调色 | #E46A2B | 落日橙，关键数据、按钮、迁徙路线 |
| 辅助色 | #7C8694 | 羽灰，次要文字、边框、图标 |
| 点缀 | #D97706 | 暖琥珀，数据高亮 |
| 生命色 | #4ade80 | 苇绿，状态/在线指示 |

配色取「霜白湿地 + 落日余晖 + 墨羽」意象，无蓝紫渐变。

## 字体

- 标题：Noto Serif SC（思源宋体），400/600/700/900
- 正文：Noto Sans SC（思源黑体），300/400/500/700
- 数据/代码：JetBrains Mono，400/500

## 组件

- 导航栏：滚动后背景模糊 + 高度收缩，固定顶部
- 卡片：3D 倾斜（mousemove 直接操作 transform）+ 光泽扫过
- 数据条：数字计数（easeOutCubic 滚动触发）
- 按钮：磁性吸附（反平方引力）
- 迁徙路线：SVG path 滚动驱动 stroke-dashoffset 绘制

## 动效系统（16 个组件级特效）

1. 自定义光标（弹簧跟随 + 悬停放大变色 + 点击涟漪）
2. 鸟群粒子编队飞行（Canvas + 正弦波 + 翅膀拍动）
3. 羽毛飘落（多层正弦摇摆 + 淡入淡出）
4. 3D 卡片倾斜（mousemove 直接操作 DOM transform）
5. 光泽扫过（hover 斜向光带）
6. 滚动渐入（IntersectionObserver + 错峰延迟）
7. 打字机效果（CTA 标题逐字输出）
8. 数字计数（easeOutCubic）
9. 涟漪扩散（点击波纹）
10. Hero 视差（背景慢移 + 内容淡出）
11. 迁徙路线 SVG 路径绘制
12. 雷达频谱柱状图（多层正弦叠加模拟回波）
13. 头像脉冲光环（呼吸式扩散）
14. 磁性按钮（反平方引力吸附）
15. 导航栏滚动形变
16. 标题逐字入场（错峰上滑淡入）

所有 RAF/定时器随 `visibilitychange` 暂停、卸载统一清理；支持 `prefers-reduced-motion` 降级；移动端隐藏自定义光标。

## 页面结构

单页到底：首屏 Hero（鸟群粒子 + 数据统计）→ 迁徙路线（SVG 地图 + 三条迁飞区）→ 物种图鉴（4 种候鸟 3D 卡片）→ 实时观测（深色数据面板 + 频谱）→ 观测手记（杂志文章网格）→ 加入观测 CTA → 页脚四栏。

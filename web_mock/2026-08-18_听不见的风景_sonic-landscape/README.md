# 听不见的风景 · 声音艺术展交互官网

> 日期：2026-08-18 · 方向：V1 网页设计 · 主题：沉浸式声音艺术展官网

## 简介

《听不见的风景》是一个沉浸式声音艺术展的交互官网，围绕"听觉风景"展开叙事。页面以暖墨黑为底，朱砂红与鼠尾草绿交织，琥珀金点缀，营造深夜展厅般的氛围。包含 Hero 主视觉、展览前言、8 位参展艺术家、作品展区（带分类筛选）、现场活动时间线、三档票务等完整板块。

## 动效亮点

- 自定义光标：白色粗环 + 朱砂内点 + 多层发光，三态切换 + 涟漪 + 弹簧尾迹
- 交互式声波：鼠标位置实时影响多层正弦叠加波形
- 频谱柱振动 + 驻波 Cymatics 同心环：每根柱 / 每环独立弹簧物理
- 3D 卡片倾斜、滚动渐入、打字机、数字计数、光泽扫过、头像脉冲等共 14 个组件级特效

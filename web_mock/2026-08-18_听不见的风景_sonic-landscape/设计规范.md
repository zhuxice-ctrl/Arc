# 设计规范 · 听不见的风景（声音艺术展交互官网）

> 方向：V1 网页设计 · 日期：2026-08-18 · 主题：沉浸式声音艺术展官网

## 色彩系统

主色调为「朱砂红 + 鼠尾草绿 + 琥珀金」暖墨系，无蓝紫渐变。

| 角色 | 色值 | 用途 |
|------|------|------|
| 暖墨黑（底） | `#0D0B09` / `#12100D` / `#1A1612` | 页面背景、深色面板 |
| 朱砂红（主） | `#C9452B` / `#E86A4A` / `#8B2A1A` | 主按钮、强调标题、声波 |
| 鼠尾草绿（辅） | `#5A6B2A` / `#A8B85A` / `#C4D47A` | 次级强调、标签、驻波 |
| 琥珀金（强调） | `#D4A84B` / `#E8C46E` / `#8B6A2A` | 高亮、票务、数字计数 |
| 象牙白（文字） | `#F2EDE4` / `#BFB5A6` / `#7A7062` | 正文、次要文字、边框 |

## 字体

- 展示字体：`'Noto Serif SC', serif`（标题、Hero）
- 正文字体：`'Noto Sans SC', -apple-system, BlinkMacSystemFont, sans-serif`
- 数字 / 标签：`'JetBrains Mono', monospace`

## 圆角与间距

- 圆角：`3px`（卡片 / 按钮）、`50%`（头像 / 圆形元素）
- 间距体系以 8px 基准网格递进

## 组件规范

- 自定义光标：白色粗环 + 朱砂内点 + 多层发光，三态切换（默认 / 悬停 / 点击涟漪）
- 卡片：深色底 + 细边框 + 悬停发光边
- 按钮：朱砂红实底 + 光泽扫过 + 涟漪点击
- 导航栏：滚动后背景模糊 + 高度收缩

## 动效系统（14 个组件级特效）

1. 自定义光标（弹簧跟随 + 三态 + 涟漪 + 尾迹惯性）
2. 粒子系统（漂浮 + 连线 + 发光光晕）
3. 交互式声波（鼠标位置影响多层正弦叠加波形）
4. 3D 卡片倾斜（弹簧物理，mousemove 直接操作 transform）
5. 滚动渐入（IntersectionObserver + 错落延迟）
6. 悬停发光（卡片边框 + 按钮阴影）
7. 打字机效果（Hero 副标题，变速节奏）
8. 数字计数（缓动立方，进入视口触发）
9. 按钮涟漪（点击扩散波纹）
10. 频谱柱振动（每根柱独立弹簧物理 + 不同频率）
11. 驻波图案（Cymatics 同心环，各自频率 + 鼠标牵引）
12. 头像脉冲（艺术家头像悬停呼吸光圈）
13. 光泽扫过（按钮 hover 光泽掠过）
14. 导航栏滚动形变（背景模糊 + 高度收缩）

## 页面结构

Hero 主视觉 · 展览前言 · 参展艺术家（8 位） · 作品展区（分类筛选） · 现场活动时间线 · 票务（三档） · 页脚

## 技术栈

纯 HTML + 内联 CSS + 内联 Babel JSX，单文件 `index.html`，无外部 src 依赖。支持 `prefers-reduced-motion` 降级；RAF / 定时器随 `visibilitychange` 暂停。

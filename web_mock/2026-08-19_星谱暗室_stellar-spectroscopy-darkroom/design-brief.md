# Design Brief — 星谱暗室 · Stellar Spectroscopy Darkroom

## 网站类型
Science / Editorial / Interactive Instrument — 天体物理光谱学交互式分析台

## Design Contract（锁定方向，不得偏离）

### Core Idea
整个网站是一座天文台暗房。琥珀色安全灯下，一条水平光谱色散带横贯屏幕——这是一颗恒星的光被棱镜分解后的可见光谱（380nm-750nm）。用户沿光谱拖拽光标分析不同波长，暗色吸收线（夫琅禾费线）切割光谱，点击任一暗线即识别出吸收该波长的化学元素及其电子跃迁。围绕"在暗房中读星光"展开，附以恒星光谱分类（OBAFGKM）、温度-颜色关系、元素丰度的编辑正文。

### Must Keep
1. 光谱色散带为唯一导航脊柱（水平全宽，可见光波长 380-750nm 连续映射，红端左紫端右）
2. 沿光谱拖拽光标→实时恒星数据：当前波长(nm)、频率(THz)、能量(eV)、该波段主要吸收元素、该波段在哪种恒星类型中最强
3. ≥8 条真实夫琅禾费吸收线可点击：H-alpha 656.3nm(氢) / H-beta 486.1nm(氢) / Na-D 589.0nm(钠) / Mg-b 518.4nm(镁) / Ca-K 393.4nm(钙) / Ca-H 396.8nm(钙) / Fe 527.0nm(铁) / H-d 410.2nm(氢)。点击→元素识别+电子跃迁图+恒星类型推断
4. 恒星分类区（OBAFGKM 七型：O≥30000K蓝 / B 10000-30000K蓝白 / A 7500-10000K白 / F 6000-7500K黄白 / G 5200-6000K黄(太阳) / K 3700-5200K橙 / M 2400-3700K红），与光谱联动
5. 自定义光标：铜框放大镜（圆环+十字准星），开页居中、高对比、层级最高
6. 动效≥12个组件级特效，符合暗房/光学物理
7. 纯 vanilla 单文件，RAF随可见性暂停/卸载取消，prefers-reduced-motion降级
8. 响应式 1440/1024/768/390

### Must Not Regress To
竖向section堆叠 / 卡片网格 / 蓝紫装饰渐变 / 纸本水墨木色 / 石墨灰主导 / 通用landing page / 拖拽物理物件 / 固定单舞台 / 横向滚动画卷 / 冷色深空黑主导 / 光谱做装饰背景（必须保留分析功能）

### Primary Interaction
暗房读谱：拖动光标沿光谱色散带移动 → 实时显示恒星数据 → 遇吸收暗线点击 → 元素识别+电子跃迁+恒星类型推断

### Signature Moment
拖到 656.3nm 的 H-alpha 吸收线并点击 → 铜框放大镜聚焦 → 氢原子能级图浮现 → n=3→n=2 电子跃迁轨道绘制 → 推断文字："这条线的强度告诉你：很强且窄=M型红巨星；很弱=O型蓝白星"

### Motion Language
暗房光学：安全灯琥珀呼吸(极慢亮度脉动) / 底片显影式内容渐入(opacity+contrast) / 光谱带微脉动(色相微移) / 吸收线点击→铜框放大镜聚焦+电子跃迁stroke-dashoffset绘制 / 恒星类型卡片横向滑动 / 波长读数数字滚动 / 暗房微粒尘埃缓慢飘浮

## 配色系统

- 底片奶白 #E8E2D0 — 数据/文字面板背景
- 暖调近黑 #1A1410 — 页面底色（非纯黑，带暖色调）
- 墨棕 #3A2A1A — 底片上文字
- 铜 #B8860B — 仪器/边框/放大镜装饰

### 编辑正文要点
- 1814年夫琅禾费(Joseph von Fraunhofer)用棱镜和望远镜发现太阳光谱中的暗线，编目570余条
- 1859年基尔霍夫(Kirchhoff)和本生(Bunsen)证明每条暗线对应一种元素的吸收——人类首次知道恒星由什么构成
- 恒星分类口诀："Oh Be A Fine Girl/Guy, Kiss Me"
- H-alpha线在发射星云中呈亮红色，在冷恒星吸收光谱中呈暗线
- 色温与光谱型直接对应：温度越高，连续谱蓝端越强

## 技术要求
- 纯 vanilla 单文件 HTML（无 React/Babel/CDN 外部依赖）
- CSS linear-gradient 实现可见光谱带（映射真实波长色域）
- SVG 实现氢原子能级图/电子跃迁轨道
- pointer 事件直接操作 DOM（不用 RAF 节流拖拽）
- RAF 仅用于安全灯呼吸/尘埃飘浮/光谱微脉动，随 visibilitychange 暂停
- prefers-reduced-motion: 光谱即时响应、内容即时显现、跃迁静态、尘埃/呼吸停止
- 响应式 1440/1024/768/390

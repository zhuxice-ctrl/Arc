# 设计规范 — 星谱暗室 · Stellar Spectroscopy Darkroom

## 设计母题
天文台暗房中的恒星光谱分析台。整站是一只活在屏幕上的摄谱仪：琥珀色安全灯下，水平光谱色散带是唯一导航脊柱，暗色夫琅禾费吸收线切割光谱，点击即可识别化学元素及其电子跃迁。

## 空间模型
**spectral_band_horizontal**（光谱色散带水平导航）——全库首现。光谱带横贯屏幕，380nm（紫端）到 750nm（红端）连续映射，所有信息围绕波长轴组织。非竖向 section 堆叠、非卡片网格、非固定单舞台、非横向滚动画卷。单屏仪器界面（100vh fixed，无滚动）。

## 动效系统（18 个组件级特效）
1. **安全灯呼吸** — safelightBreath 8s ease-in-out infinite，极缓慢亮度+缩放脉动
2. **暗房微粒尘埃** — dustFloat 15-35s linear infinite，20颗琥珀色微粒缓慢上浮
3. **底片显影渐入** — filmDevelop 2-2.5s，opacity+brightness+contrast 变化模拟照片显影
4. **光谱微脉动** — spectralDrift 12s ease-in-out alternate，saturate+hue-rotate 极微移
5. **吸收线悬停** — width 过渡 0.2s，暗线变宽+琥珀色高亮
6. **吸收线标签** — opacity+translateY 过渡，悬停显示线名+波长
7. **扫描指示器** — 实时跟随光标在光谱上的位置（直接 DOM 操作）
8. **放大镜缩放** — 光标进入光谱区时 class toggle，56px→80px
9. **光标平滑跟随** — RAF 插值 0.25 lerp，铜框放大镜手感
10. **原子核脉动** — nucleusPulse 3s ease-in-out infinite
11. **电子跃迁绘制** — drawPath 1.2s，stroke-dashoffset 从满到0
12. **光子箭头** — opacity 0.5s 延迟1s，跃迁后释放光子
13. **详情面板滑入** — transform 0.6s cubic-bezier(0.2,0.8,0.2,1)
14. **恒星分类悬停** — translateY(-2px)+box-shadow 0.3s
15. **底栏圆点脉动** — safelightBreath 4s 复用
16. **操作提示淡入** — hintFade 3s，先显现后半透明
17. **历史注释滑入** — slideInNote 1.5s，从左滑入
18. **提示面板滑入** — slideInRight 1.5s，从右滑入

## 核心交互
1. **沿光谱拖拽** — 鼠标在光谱带上移动 → 扫描指示器跟随 → 实时更新波长/频率/光子能量/特征元素
2. **点击吸收线** — 点击夫琅禾费暗线 → 右侧详情面板滑入 → 氢原子能级图+电子跃迁动画+恒星类型推断+发现历史
3. **恒星分类切换** — 点击 OBAFGKM 七型 → 更换观测目标/光谱类型/表面温度 + 光谱色温微调

## 响应式
- 1440px：完整布局，7列恒星分类，4列数据卡
- 1024px：数据卡2列，恒星分类4列，提示面板隐藏
- 768px：副标题隐藏，详情面板底部弹出
- 390px(480px断点)：头部信息隐藏，光谱高度缩减，光标禁用改系统光标

## 技术栈
纯 vanilla 单文件 HTML（无 React/Babel/JS框架 CDN 依赖）。CSS 内联，JS 内联在 IIFE 中。字体由妙搭平台托管。SVG 实现氢原子能级图。CSS linear-gradient 实现可见光谱带。RAF 仅用于光标跟随，随 visibilitychange 暂停、beforeunload 取消。prefers-reduced-motion 全降级。

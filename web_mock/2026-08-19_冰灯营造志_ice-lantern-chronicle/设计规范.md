# 冰灯营造志 · 设计规范

## 设计概念
夜间冰灯公园漫步——滚动即步行深入哈尔滨冰灯公园，每个章节是一个冰灯工艺站点，温暖灯光从半透明冰体内透出。

## 色彩系统

| 色值 | 用途 |
|------|------|
| `#0A0A0F` | 夜空背景（极暗冷调） |
| `#C8DCE4` | 冰体表面（苍白冰白） |
| `#3A5868` | 冰体阴影（暗青绿，体积感） |
| `#FF9F43` | 内部暖光（琥珀暖橙，核心光源色） |
| `#FFD4A3` | 暖光晕染（柔和扩散） |
| `#E8F4F8` | 冰晶高光（最亮冰面反光） |
| `#D4D4D8` | 暗底文字 |
| `#1A1A2E` | 亮底文字 |
| `#0c1015` | 深色区域变体 |
| `#08080c` | 极暗过渡 |
| `#e87a1a` | 暖光强调变体 |

色彩逻辑：暖冷对比——冰是冷白青色，灯是暖琥珀色，夜是暗的。色彩承担氛围与信息层级。

## 字体系统

| 层级 | 字体 | 说明 |
|------|------|------|
| 标题 | Noto Serif SC (serif) | 衬线体，传达工艺与文化的厚重感 |
| 正文 | Noto Sans SC (sans-serif) | 无衬线体，保证可读性 |
| 数据标注 | JetBrains Mono (monospace) | 等宽体，用于数值与参数 |

## 空间模型
竖向深度叙事——不是 Landing Page 的 Section 堆叠，而是一条有节奏的夜行路线：入口（暗）→ 采冰场 → 雕琢工坊 → 浇筑与组装 → 内嵌灯光 → 点灯时刻（高潮）→ 尾声（消融）。

## 材质语言
冰的透明感贯穿全站：半透明叠加表现体积、内部暖光透出、表面结晶高光。不是装饰性材质，而是冰灯工艺的物质基础。

## 动效系统（13+ 组件级特效）

1. 六角冰晶自定义光标（开页居中、微旋转）
2. 冰灯从内向外渐亮（滚动驱动，非简单 fadeIn）
3. 采冰切割线绘制动效
4. 冰晶粒子飘落（≤12 个粒子）
5. 数据数字滚动计数
6. 冰体半透明层次（hover 微增透）
7. 手绘风工具图标（hover 微动）
8. 暖光呼吸（亮度微变）
9. 文字逐行揭示
10. 章节暗角过渡
11. 鼠标视差（±5px）
12. 尾声消融模糊
13. 顶部暖色进度条

## 工程约束
- 纯 vanilla 单文件 HTML（无 React/Babel/CDN）
- RAF 随可见性暂停，卸载时取消
- 支持 prefers-reduced-motion
- 零未定义引用、零运行时崩溃

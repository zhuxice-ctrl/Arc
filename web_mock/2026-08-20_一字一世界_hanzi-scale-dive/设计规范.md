# 一字一世界 · 设计规范

> 深夜图书馆连续缩放潜入 · continuous_scale_zoom_dive

## 一、设计母题

整站是一次连续缩放潜入：从深夜图书馆大厅出发，经书架、书脊、摊开的书页、一行字、一个「書」字、一笔一画，最终潜到纸张纤维与墨色微观。滚轮 / 拖拽 / 键盘即显微镜调焦，尺度连续、由用户推动。视觉来源 = 光学显微镜调焦台 + 深夜图书馆绿玻璃台灯光池。

## 二、空间模型

`continuous_scale_zoom_dive`——8 个尺度层级在同一个固定舞台中心叠放，层间用 `scale` + `opacity` 高斯插值连续过渡，禁止跳切。用户输入驱动单一 `logZoom` 状态（log10 尺度，×1 → ×100K），每层在各自目标 `logZoom` 处不透明度最高、`scale` 刚好填满视口短边 × 0.78。

| # | 层级 | 目标 logZoom | 倍率 | 内容 |
|---|------|---|---|---|
| 1 | 图书馆大厅 | 0.0 | ×1 | 穹顶、4 盏绿玻璃台灯＋光柱、长阅览桌、书墙剪影 |
| 2 | 书架 · 中图法 | 0.65 | ×4.5 | 5 层书架、I/K/G 分类牌、真实古籍书脊（诗经/史记/资治通鉴…） |
| 3 | 书脊 · 说文解字 | 1.55 | ×35 | 《说文解字》书脊，点击翻开 |
| 4 | 书页 · 说文解字叙 | 2.45 | ×280 | 竖排古籍排版，真实《说文解字·叙》原文、朱印、卷次 |
| 5 | 一行文字 | 3.20 | ×1.6K | 聚焦「書，箸也。从聿者聲。」 |
| 6 | 字 · 書 | 3.80 | ×6.3K | 「書」大字 + 《说文》字源解说 + 反切注音 |
| 7 | 笔画 · 永字八法 | 4.25 | ×18K | 侧/勒/弩/趯/策/掠/啄/磔描红（stroke-dashoffset），米字格 |
| 8 | 微观 · 纸纤维 | 5.00 | ×100K | Canvas 纸纤维星野、墨滴晕染、星点闪烁 |

## 三、色彩系统

非蓝紫、非米色宣纸+朱砂的高频组合，改用深夜墨蓝 + 台灯绿玻璃 + 暖光体系。

| 变量 | 色值 | 用途 |
|---|---|---|
| `--ink-deep` | `#0E1A24` | 深夜墨蓝主背景 |
| `--lamp-glass` | `#2E5D4B` | 台灯绿玻璃罩 / 绿玻璃质感 |
| `--lamp-warm` | `#F2C879` | 暖光 / 高亮 / 倍率尺活跃态 |
| `--paper` | `#F5F0E6` | 纸白 / 古籍底 |
| `--ink-black` | `#1a1a1a` | 墨黑文字 |
| `--fiber` | `#c9b98a` | 纸纤维 / 星点暖色 |
| `--seal-red` | `#8B2500` | 朱印（仅书页朱印，低饱和，不滥用） |

## 四、字体系统

系统字体栈，零外部字体文件。

- 标题 / 汉字大字：`"Noto Serif SC", "Songti SC", "STSong", "SimSun", serif`（宋体）
- 引文 / 字源：`"Noto Serif SC", "STKaiti", "Kaiti SC", serif`（楷体）
- 正文：`"PingFang SC", "Microsoft YaHei", "Hiragino Sans GB", sans-serif`
- 倍率数字 / 编号：`"SF Mono", "Menlo", "Consolas", monospace`

## 五、交互系统

四通道等价，全部驱动同一 `logZoom` 状态（带阻尼惯性 0.07）：

1. **滚轮 / 触控板**：`deltaY` × 灵敏度 0.0014（触控板 pixel mode × 0.6 精细化）
2. **右侧倍率尺**：拖拽手柄 / 点击刻度直达（×1 / ×10 / ×100 / ×1K / ×10K / ×100K）
3. **键盘**：`↑↓` `+ -` 微调 0.18；`1`–`8` 跳层；`Home`/`End` 回首 / 到底
4. **移动端**：双指捏合（`pinchStartLog + log10(ratio)×1.5`）

附加交互：书脊点击 → 直接翻到书页层（logZoom 2.45）。

## 六、动效系统（组件级 ≥ 12）

光学调焦语言，所有动效符合"光与墨"物理感，无整图缩放 Ken Burns：

1. 穹顶呼吸光晕（`domeBreath`）
2. 台灯灯泡闪烁（`bulbFlicker`）
3. 光柱摇曳（`coneSway`）
4. 尘埃在台灯光锥中浮升（35 颗粒子，随大厅/书架层可见度联动）
5. 书脊 hover 上浮
6. 层间景深模糊过渡（`--dof-blur` 随最亮层透明度反向插值）
7. 倍率尺填充 / 手柄随 logZoom 实时滑移
8. 光圈光标阻尼跟随（0.3 lerp）+ 缩放方向指示（zoom-in/out 形态）
9. 光圈暗角呼吸
10. 笔画永字八法描红（`stroke-dashoffset` 逐笔 380ms 错峰）
11. 纸纤维 Canvas 绘制（70 根二次贝塞尔纤维 + 摆动）
12. 墨滴晕染扩散（径向渐变，logZoom > 4.4 渐显）
13. 星点闪烁（logZoom > 4.8，30 颗）
14. 微观标题渐显（logZoom > 4.75）

## 七、健壮性

- 纯 vanilla 单文件，零 CDN / 零外部图片 / 零外部字体
- RAF 随 `visibilitychange` 暂停（`stop()`），`pagehide` 取消，可见时 `start()` 恢复
- 高频 `wheel` / `pointermove` 直接操作 DOM transform，不进渲染框架、不叠加定时器
- `prefers-reduced-motion`：降级为层级淡入淡出，关闭粒子摆动
- 响应式：1440 / 1024 / 768 / 390 四尺寸无横向溢出、无内容裁切
- 自定义光圈光标：开页居中（viewport 中心），`mix-blend-mode: difference` 高对比，`z-index: 9999`

## 八、签名记忆点

从一页摊开的古籍无缝潜入「書」字的一笔——墨色在视野中涨满，化作新的夜空，纤维如星野浮现（层 6 → 7 → 8 连续过渡）。

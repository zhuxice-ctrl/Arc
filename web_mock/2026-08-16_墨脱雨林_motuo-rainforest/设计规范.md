# 墨脱雨林 · 垂直生态探索 — 设计规范

- 日期：2026-08-16
- 方向：网页设计（V1）
- 主题：西藏墨脱从海拔 700m 到 5000m 的垂直生态带沉浸式自然探索官网

## 色彩系统

| 角色 | 色值 | 用途 |
|------|------|------|
| 底色（深松绿） | `#0f1f17` / `#1a2f23` | 页面主背景，雨林林冠深处 |
| 苔绿 | `#3d5c47` / `#5a7a5c` | 次级背景、卡片底、分隔 |
| 雾白 | `#e8ebe5` / `#f0f2ed` / `#c8cfc4` | 正文文字、卡片前景 |
| 中性灰绿 | `#6b7867` / `#a8b3a4` | 次要文字、边框、辅助 |
| 琥珀点缀 | `#d4913a` / `#e8b060` / `#a66820` | 强调色、CTA、数据高亮 |
| 朱砂红 | `#d9644f` | 警示 / 状态点 |

严格未使用蓝紫渐变。整体为深松绿 + 雾白骨架 + 琥珀单一高饱和锚点的自然色系。

## 字体

- 标题：`'Noto Serif SC', serif`（衬线，呼应自然博物气质）
- 正文：`'Noto Sans SC', sans-serif`
- 数据 / 等宽：`'JetBrains Mono', monospace`

## 页面结构（7 屏单页）

1. Hero — 雨林全景 + 海拔计数器（700m→5000m 随滚动实时更新）
2. 垂直生态带 — 4 张 3D 倾斜卡片（热带季雨林 / 亚热带常绿林 / 温带针叶林 / 高山苔原）
3. 瀑布秘境 — 视差滚动 + 引言打字机
4. 生物多样性 — 异形网格物种卡
5. 数据统计 — 4 项弹簧缓动数字计数
6. 自然之声 — 48 条频谱条有机波动 + 4 段音轨切换
7. CTA 订阅 — 磁性吸附按钮 + 表单反馈

## 组件规范

- 卡片：圆角 16–24px，深色半透明底 + 细苔绿描边，悬停 3D 倾斜
- 按钮：主按钮琥珀实色 + 光泽扫过；次按钮描边反色 hover 填充
- 物种卡：异形 clip-path 网格，非等高排布

## 动效系统

| 动效 | 物理模型 |
|------|----------|
| 自定义光标（三环：外环+内点+光晕） | 弹簧 Hooke 定律 + 双层阻尼 |
| 点击涟漪 | 径向扩散 + 淡出 |
| 漂浮雾气粒子 | 正弦漂移 + 包裹循环 |
| 海拔 / 统计数字计数 | 弹簧积分器缓动 |
| 卡片 3D 倾斜 | 反平方磁引力 + 弹簧 |
| 英雄区 / 瀑布区视差 | 滚动驱动 translateY |
| 引言打字机 | 随机间隔模拟人类节奏 |
| 频谱可视化 | 多频正弦叠加（非整齐划一） |
| 光泽扫过按钮 | 斜向 skewed 扫光 |
| 滚动渐入 | IntersectionObserver + 错位延迟 |
| 磁性按钮 | 反平方引力 + 弹簧跟随 |
| 状态脉冲光点 | 呼吸脉冲 |

全部 requestAnimationFrame / 定时器随 visibilitychange 暂停、卸载取消；mousemove 驱动的倾斜/视差直接操作 DOM transform，不触发 React 重渲染；支持 prefers-reduced-motion 降级。JSX 全部内联在 `<script type="text/babel">` 中。

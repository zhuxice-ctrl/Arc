## 字体系统

- **主字体栈**：`"PingFang SC", "Microsoft YaHei", "Noto Sans CJK SC", "Songti SC", serif`
- 标题使用大字号 + 粗体，副标题使用中字号 + 常规
- 正文使用中等字号，行高 1.6-1.8 保证阅读舒适

## 圆角规范

- 卡片圆角：`16px`
- 按钮圆角：`12px`
- 输入框圆角：`8px`
- 头像/圆形元素：`50%`

## 组件规范

- **导航栏**：固定吸顶，半透明毛玻璃（backdrop-filter），滚动时从透明渐变为半透明深绿
- **Hero 区**：全屏高度，粒子萤火虫 Canvas 背景，大标题居中
- **体验卡片**：3D 倾斜悬停（perspective + rotateX/Y），荧光绿发光边框
- **图鉴卡片**：荧光脉冲呼吸动画（box-shadow keyframes），错位相位
- **表单**：输入框聚焦时发光（box-shadow 荧光绿）
- **按钮**：悬停光泽扫过（::before 伪元素 + transform translateX）

## 动效系统

| 编号 | 动效名称 | 实现方式 | 触发条件 |
|------|----------|----------|----------|
| 1 | 粒子萤火虫系统 | Canvas + requestAnimationFrame，70 个光点随机飘动+呼吸闪烁+鼠标吸引 | 页面加载即运行 |
| 2 | 自定义光标 | DIV + mousemove 跟随，白环+荧光绿内点+多层发光 | 开页即显示屏幕中央 |
| 3 | 滚动渐入 | IntersectionObserver，元素进入视口时添加 .visible 类 | 滚动至元素可见 |
| 4 | 数字计数动画 | requestAnimationFrame + easing，从 0 滚动到目标值 | 关于区进入视口 |
| 5 | 导航栏滚动变色 | scroll 事件监听，修改 navbar 的 background/blur | 页面滚动 |
| 6 | 卡片 3D 倾斜 | mousemove 直接操作 DOM transform，不触发重渲染 | 鼠标悬停卡片 |
| 7 | 卡片发光边框 | CSS box-shadow + transition | 鼠标悬停卡片 |
| 8 | 图鉴荧光脉冲 | CSS @keyframes box-shadow 呼吸，各卡片错位相位 | 持续运行 |
| 9 | Hero 标题逐字淡入 | CSS animation + animation-delay 逐字 | 页面加载 |
| 10 | 按钮光泽扫过 | ::before 伪元素 + translateX + transition | 悬停按钮 |
| 11 | 森林视差滚动 | 多层 div 以不同速度 translateY | 页面滚动 |
| 12 | 表单聚焦发光 | CSS :focus + box-shadow transition | 输入框聚焦 |
| 13 | 返回顶部按钮 | scroll 监听显隐 + click 平滑滚动 | 滚动超过一屏 |

## 页面结构

1. **导航栏**（固定吸顶）— Logo + 6 个导航项
2. **Hero 区**（全屏）— 粒子萤火虫 + 大标题 + 副标题 + 预约按钮
3. **关于区** — 使命介绍 + 4 项数据计数动画
4. **体验项目区** — 3-4 个体验套餐卡片，3D 倾斜 + 发光
5. **萤火虫图鉴区** — 4-6 种萤火虫卡片，荧光脉冲
6. **预约区** — 表单（日期/项目/人数/联系方式）
7. **页脚** — 地址/电话/社交/版权

## 健壮性

- visibilitychange 暂停 requestAnimationFrame
- 高频 mousemove 直接操作 DOM transform
- 支持 prefers-reduced-motion 降级
- 触屏设备自动隐藏自定义光标
- 零未定义引用

## 技术栈

- 纯 vanilla HTML/CSS/JS 单文件
- 无 React/Babel/CDN 依赖
- Canvas 2D 渲染粒子系统
- IntersectionObserver 滚动监听

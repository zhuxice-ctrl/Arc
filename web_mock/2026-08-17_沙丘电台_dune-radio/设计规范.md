# 设计规范 · 沙丘电台 Desert Radio

> 日期：2026-08-17 · 方向：V1 网页设计 · 主题：沙漠腹地短波电台官网

## 色彩系统

主色取自沙漠与黄昏电磁波的色调，整体偏暖、低饱和、高反差。

| 角色 | 色值 | 用途 |
|---|---|---|
| 墨黑底 | `#1E1B16` / `#151210` | 页面主背景，夜色电台基调 |
| 深沙 | `#2A2620` / `#252018` | 卡片底、分区背景 |
| 沙漠金 | `#C9973F` | 主强调色，按钮、指针、标签 |
| 浅金 | `#E0B562` | 高亮、悬停态 |
| 赭红 | `#A6482E` / `#C4623A` | 直播中、警示、信号强 |
| 米白 | `#F5EDE0` | 正文文字、标题 |
| 沙灰 | `#D9D0C0` | 次级文字 |
| 铜褐 | `#A87A28` | 辅助分隔 |

禁止蓝紫渐变；无任何冷蓝/紫色调。

## 字体

- 展示字体 `--font-display`：电台大标题，宽体重。
- 正文 `--font-body`：节目表、信件正文。
- 等宽 `--font-mono`：频率、呼号、信号读数。
- 衬线 `--font-serif`：听众来信引文。

## 组件规范

- 调谐表盘：圆形指针 + 阻尼摆动，频率数字等宽对齐。
- 节目卡片：深沙底 + 左侧赭红直播条 + 频率芯片；悬停上浮 + 光泽扫过。
- 主持人卡片：3D 倾斜跟随鼠标，头像脉冲光环。
- 频谱条：多根柱体各自周期跳动，底部光泽扫过。
- 信号波形：SVG 多正弦叠加路径动画。
- 沙暴卡：风线流动 + 进度条强度。

## 动效系统

1. 自定义光标（白环 + 沙金内点 + 多层光晕，悬停放大变色，点击涟漪）
2. 沙粒粒子漂移（Canvas，速度 + 正弦漂移）
3. 调谐指针阻尼摆动
4. 信号频谱柱跳动（各柱周期不同）
5. 实时信号波形（SVG 多正弦叠加）
6. 信号波纹扩散
7. 主持人卡 3D 倾斜（弹簧物理，直接 transform）
8. 头像脉冲光环
9. 打字机呼号（含删除）
10. 数字滚动计数（easeOutCubic + IntersectionObserver）
11. 滚动渐入揭示
12. Hero 鼠标视差
13. 光泽扫过按钮 / 频段条
14. 沙暴风线动画

## 页面结构

Hero（调谐表盘 + 统计）→ 节目表（三档 Tab）→ 主持人（3D 卡片）→ 全波段频率 → 信号报告 + 沙暴实况 → 听众来信 → Footer。

## 技术栈

纯 vanilla HTML/CSS/JS 单文件，Canvas + SVG 动画，无外部 CDN 依赖。

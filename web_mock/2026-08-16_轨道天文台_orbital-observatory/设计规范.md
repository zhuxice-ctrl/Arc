## 字体

- 标题衬线：`Noto Serif SC`（300–900）
- 正文无衬线：`Noto Sans SC`（300–700）
- 数据 / 坐标 / 编号：`IBM Plex Mono`

## 组件

- 望远镜收藏卡：3D 倾斜（直接 DOM transform）+ 悬停光泽扫过 + 黄铜边框发光
- 预约日历：真实可交互，可翻月、选日期、可约/约满状态
- 天象档案：三栏 Tab（天象/深空/行星）+ 时间线节点悬停发光
- 统计带：滚动触发数字计数（easeOutCubic）
- 观测控制台（Tweaks）：右下浮动入口，深色面板融入设计

## 动效系统（13+）

1. 自定义光标：弹簧物理跟随、白环+橙点、悬停放大变色、点击涟漪、mix-blend-mode
2. 全页星空 Canvas：三层视差 + 闪烁，橙/黄铜/月白星点
3. 行星轨道环：4 层不同方向/速度/线型旋转
4. 流星：周期随机生成 + 衰减尾迹
5. 打字机副标题 + 闪烁光标
6. 滚动数字计数、7. 卡片 3D 倾斜、8. 光泽扫过、9. IntersectionObserver 滚动渐入、10. 导航下划线延伸、11. 观测状态脉冲点、12. 滚动指示箭头、13. Tab 下划线滑动

## Tweaks 调节项（7）

强调色切换 / 背景深度 / 星点密度（--star-density）/ 轨道转速（--orbit-speed）/ 流星开关 / 自定义光标开关 / 动效强度（--effect-intensity），全部 CSS 变量实时生效。

## 健壮性

visibilitychange 暂停全部 RAF；卸载统一取消定时器；高频 mousemove 直改 DOM；prefers-reduced-motion 降级。

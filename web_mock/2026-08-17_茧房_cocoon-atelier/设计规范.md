# 茧房 Cocoon Atelier · 设计规范

> 方向：V1 网页设计 · 主题：蚕桑丝织手工艺工坊官网
> 配色基调：米白底 + 绛红 + 墨黑 + 暖金 + 蚕青（无蓝紫渐变）

## 色彩系统

| 角色 | 色值 | 用途 |
|------|------|------|
| 米白（底） | `#F5EFE6` | 页面主背景，温润纸感 |
| 浅米 | `#FAF5EB` | 卡片表面/次级背景 |
| 暖米 | `#EDE5D6` / `#F0E8D8` | 分区背景、悬浮面板 |
| 绛红（主强调） | `#9B2D20` | 主标题、主按钮、品牌色 |
| 深绛 | `#6E1F16` | 绛红按下态、深色文字 |
| 暖金 | `#C8A14B` | 装饰线、图标、光晕、次要强调 |
| 浅金 | `#D9B868` | 金色渐变过渡 |
| 蚕青 | `#A8B89F` | 辅助色、标签、蚕丝粒子 |
| 深蚕青 | `#7E9073` | 蚕青按下、次级文字 |
| 米褐 | `#D9CDB8` | 边框、分隔线 |
| 墨黑 | `#1A1614` | 正文文字、深色区块 |

## 字体排印

- 衬线（标题/品牌）：`Georgia, 'Times New Roman', serif`
- 无衬线（正文/UI）：`var(--sans)` 系统无衬线栈
- 字号层级：Hero 标题 64–96px / 章节标题 36–48px / 正文 16–18px / 标注 13–14px

## 组件规范

- 工序卡：圆角 16px，米白表面 + 顶部 4px 暖金/绛红色条，hover 抬升 8px + 阴影加深
- 画廊卡：圆角 12px，3D 磁性倾斜（鼠标反平方引力），筛选切换淡入
- 课程 Tab：底部下划线滑动指示器（弹簧缓动），面板进入错位延迟
- 磁力按钮：鼠标靠近时受反平方引力吸引位移，光泽扫过 hover
- 数字计数：easeOutCubic 缓动，滚动入视触发

## 动效系统（14 个组件级特效）

1. 自定义光标：白环 + 绛红内点 + 金色光晕，弹簧物理分级跟随，三态切换，点击涟漪
2. 蚕丝飘动粒子 Canvas：波动曲线 + 鼠标反平方引力
3. 茧 SVG 脉动 + 丝线缠绕轨迹
4. 茧 3D 磁性倾斜（惯性缓动）
5. 滚动渐入（IntersectionObserver + 错位延迟）
6. 导航滚动变形（毛玻璃 + 收缩）
7. 画廊筛选切换 + 卡片 3D 倾斜
8. 课程 Tab 切换（下划线滑动 + 面板进入）
9. 磁力按钮（反平方引力吸引）
10. 数字计数（easeOutCubic）
11. 织机经纬网格视差背景
12. 匠人头像脉冲光环
13. Hero 背景视差 + 光泽扫过按钮
14. 打字机循环（四句蚕丝古诗，增删速度不一）

## 页面结构（单页长滚动）

Hero 首屏（品牌主张 + 脉动蚕茧 + 蚕丝粒子）→ 工艺之道（育蚕/剥茧/缫丝/织造 四步工序卡）→ 丝织画廊（6 件作品，丝巾/面料/成衣 筛选）→ 匠人之心（三位守艺人故事卡）→ 工坊课程（缫丝体验/草木染/织造入门 Tab）→ 数字统计（4 项品牌数据）→ 页脚（导览/到访/联系）

## 健壮性

- 零未定义引用；全部 requestAnimationFrame 由统一 RAF 管理器调度
- visibilitychange 自动暂停/恢复，beforeunload 清理
- 定时器均有清除机制；打字机页面隐藏时暂停
- 支持 prefers-reduced-motion：降级为静态、光标隐藏、计数直接显示终值
- 高频鼠标事件直接操作 DOM transform，无 React 重渲染负担

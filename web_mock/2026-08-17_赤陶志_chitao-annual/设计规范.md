# 设计规范 · 赤陶志·民间陶艺年鉴

> 日期：2026-08-17 · 方向：V1 网页设计 · 主题：民间陶艺在线年鉴/杂志站

## 色彩系统

| 角色 | 色值 | 用途 |
|------|------|------|
| 赤陶红（主色） | `#C8553D` | 主强调、标题装饰、光标内点 |
| 赭黄（辅助） | `#D9A441` | 次强调、高亮、数字计数 |
| 奶白（表面） | `#F5EFE0` | 页面底色、卡片背景 |
| 墨褐（文字） | `#2B2118` | 正文、深色区块 |
| 釉青（点缀） | `#4A7C74` | 交互态、冷色平衡 |
| 陶土棕 | `#8B6F5A` | 次级文字、边框 |
| 深褐 | `#3d2f24` | 深色区块底 |

整体为暖陶土色系，无蓝紫渐变；局部用釉青做冷暖对比。

## 字体

- 标题衬线：`"Noto Serif SC", "Songti SC", "SimSun", serif`（杂志感）
- 装饰标题：`"ZCOOL XiaoWei", "Noto Serif SC", serif`
- 正文无衬线：`"Noto Sans SC", "PingFang SC", "Microsoft YaHei", sans-serif`

## 页面结构

封面 Hero（陶轮拉坯动画 + 副标题打字机）→ 釉色色谱（10 张釉色卡）→ 窑口地图（10 处窑口可交互光点）→ 匠人故事（3 张 3D 翻转卡）→ 千年窑火年表（7 段可展开时间线）→ 订阅 Footer（表单 + 成功反馈）。

## 组件规范

- 釉色卡：3D 倾斜（mousemove 直操 DOM transform，lerp 跟随）+ 光泽扫过 + 悬停抬起
- 匠人卡：Y 轴 3D 翻转，hover 触发
- 时间线节点：hover 放大 + 外发光脉冲
- 窑口光点：脉冲扩散动画

## 动效系统

1. 自定义光标（白环 + 赤陶红内点 + 多层发光，开页居中，悬停放大变色，点击涟漪）
2. 辘轳陶轮匀速旋转 + 陶坯随转
3. 副标题打字机逐字显现 + 光标闪烁
4. Hero 数字计数（easeOutCubic）
5. 釉色卡 3D 倾斜（lerp 跟随）
6. 釉色卡光泽扫过
7. 滚动渐入（IntersectionObserver，错峰延迟）
8. 窑口光点脉冲扩散
9. 匠人卡片 3D 翻转
10. 时间线节点 hover 放大 + 外发光
11. 鼠标驱动 Hero 视差（陶轮与塑型手反向位移）
12. 塑形手印脉冲呼吸
13. 滚动提示线呼吸动画

物理/语义模型：陶轮匀速旋转、光点脉冲、打字机定时器、视差反向位移。支持 prefers-reduced-motion 降级；RAF/定时器随 visibilitychange 暂停、卸载清理。

## 技术栈

单文件 HTML（内联 CSS + JS），无外部框架依赖；移动端 768px 断点响应式，窄屏隐藏自定义光标。

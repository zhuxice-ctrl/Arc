# 设计规范 · 远航班机 LONG HAUL · 航空黄金时代档案展

> 方向：网页设计（V1） · 日期：2026-08-17 · 主题：民航黄金时代沉浸式档案展官网

## 色彩系统

复古旅行海报气质，深酒红 + 奶油纸 + 铜金 + 炭墨四色体系。

| 角色 | 色值 | 用途 |
|------|------|------|
| 主色 · 深酒红 | `#7A1E2B` | 标题、强调、印章 |
| 深酒红压暗 | `#5A1520` | hover、阴影边 |
| 表面色 · 奶油纸 | `#F5EBDD` | 页面底色、卡片底 |
| 米沙 | `#E8DCC8` | 次级表面、分隔 |
| 强调 · 铜金 | `#B98A44` | 描边、图标、光晕 |
| 铜金亮 | `#D6A85E` | 高光、渐变端 |
| 文字 · 炭墨 | `#221E1B` | 正文、深底 |
| 炭墨暖 | `#2A2522` / `#3A3028` | 次级文字、卡片深 |

## 字体栈

- 展示标题：`'Playfair Display', serif`
- 正文衬线：`'Crimson Pro', Georgia, serif` / `'Cormorant Garamond', serif`
- 打字机/票号：`'Special Elite', monospace`

## 组件规范

- 卡片圆角 12px，铜金 1px 描边，奶油底，多层柔阴影。
- 机票卡：3D 倾斜 + 光泽扫过 + 翻面弹簧 + 盖章弹入。
- 导航栏：滚动收缩，毛玻璃吸顶。
- 按钮：酒红实底铜金描边，hover 铜金光晕。

## 动效系统（12+ 组件级）

1. 自定义光标：弹簧阻尼跟随 + 白色粗环 + 铜金内点 + 多层发光，z-index 最高；悬停放大、点击涟漪。
2. 英雄区金色粒子：阻尼漂浮 + 摇摆。
3. 罗盘玫瑰匀速旋转 + 指针钟摆（不同周期）。
4. 打字机副标：随机速度多句循环。
5. 滚动渐入：错峰延迟。
6. 机票 3D 倾斜 + 光泽扫过 + 翻面弹簧 + 盖章弹入。
7. 航线 dash 流动 + 城市点脉冲扩散。
8. 机型卡片惯性 3D 倾斜（直接 DOM transform）。
9. 制服卡片 hover 信息滑出。
10. 数字计数缓动（IntersectionObserver 触发）。
11. 导航栏滚动收缩。
12. 机舱顶灯呼吸闪烁。

## 页面结构

英雄首屏（罗盘+打字机）→ 复古机票（翻面+盖章）→ 环球航迹地图（8 航线+脉冲点）→ 机型档案（6 架+分类切换）→ 空中时装（4 套制服）→ 天空客厅（机舱剖面）→ 数据纵览（计数）→ 预约页脚。

## 健壮性

JSX/CSS 全内联；RAF/定时器随 visibilitychange 启停、卸载取消；高频鼠标事件直操 DOM；支持 prefers-reduced-motion 降级。

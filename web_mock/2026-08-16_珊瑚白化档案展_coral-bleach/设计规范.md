# Coral Bleach 珊瑚白化档案展 · 设计规范

> 2026-08-16 · V1 · 网页设计

## 主题

全球珊瑚白化危机气候数据艺术展官网，单页滚动叙事

## 配色

深海墨青 + 白化珊瑚白 + 警示橙红

（严格禁蓝紫渐变）

## 字体

系统无衬线 + 等宽字体

## 动效设计

海床三层视差 / 光柱呼吸 / 水下粒子 / 白化时间轴 / 热点海域交互地图 / 海温频谱条

## 技术实现

- 单文件 HTML 实现（CSS + JS 全内联）
- 自定义光标开页即居中显示
- RAF 统一管理，visibilitychange 自动暂停/恢复
- 支持 prefers-reduced-motion 降级
- 无外部 JSX 引用，无外部本地文件依赖

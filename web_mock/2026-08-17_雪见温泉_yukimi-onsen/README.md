## 简介

「雪见温泉」是一家虚构的越后雪国百年温泉旅馆官网。以雪白与炭墨为底、朱红为品牌锚点，呈现汤池、四季会席、九间客房与预约入口。全页真实可交互，配 15+ 基于物理/语义的组件级动效。

![预览](./preview.png)

## 动效亮点

- 雪花粒子系统：正弦摆动 + 重力 + 鼠标反平方斥力
- 蒸汽粒子（汤气语义）、3D 倾斜料理卡、磁性 CTA 按钮
- 自定义光标：弹簧阻尼跟随、朱红内点、悬停三态、点击涟漪
- 数字计数、打字机、滚动视差、光泽扫过、客房滑入填充

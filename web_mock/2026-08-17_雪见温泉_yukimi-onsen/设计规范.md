# 雪见温泉 Yukimi Onsen · 设计规范

> 日期：2026-08-17 ｜ 方向：V1 网页设计 ｜ 主题：越后雪国百年温泉旅馆官网

## 色彩系统

| 角色 | 名称 | 色值 |
|------|------|------|
| 主背景 | 雪白 snow | `#F7F5F0` |
| 次背景 | 雪白柔和 snow-soft | `#EDEBE4` |
| 主文字/深底 | 炭墨 ink | `#23262B` |
| 次文字 | 炭墨柔和 ink-soft | `#3A3D43` |
| 中性文字 | ink-mid | `#5A5D63` |
| 强调/品牌 | 朱红 vermilion | `#C73E3A` |
| 暗朱 | 暗朱红 | `#8B2E2B` |
| 暖色点缀 | 暖木金 wood | `#C9A96E` |

配色基调：雪白 + 炭墨构成极简留白底，朱红作为品牌锚点（汤印、CTA、定位标记），暖木金点缀于料理与客房区，营造雪国旅馆的温度与克制。

## 字体

- 衬线展示字：`Shippori Mincho`（标题、品牌名，日式明朝气质）
- 正文衬线：`Noto Serif JP`
- 无衬线辅助：`Noto Sans JP`
- 字重层级：800/700（标题）→ 600 → 400/300（正文）

## 圆角与间距

- 卡片圆角：16–24px；按钮圆角：999px（胶囊）；图角：8–12px
- 章节垂直间距：96–160px；卡片内边距：32–48px

## 页面结构

全屏 Hero（雪景 + 品牌引言 + 滚动指示）→ 品牌叙事 → 汤池展示（雪见露天风吕大图 + 光泽扫过）→ 四季会席料理卡（3D 倾斜）→ 九间客房列表（滑入填充）→ 传承数字统计（计数动画）→ 预约 CTA（磁性按钮 + 大字视差）→ 页脚。

## 动效系统（15+ 组件级特效，均基于物理/语义）

- 自定义光标：弹簧阻尼跟随，白色粗环 + 朱红内点 + 多层发光，z-index 最高；悬停三态切换，点击涟漪
- 雪花粒子：正弦摆动 + 重力下落 + 鼠标反平方斥力拨开
- 蒸汽粒子：客房区上升膨胀消散（汤气语义）
- 3D 倾斜卡：阻尼弹簧插值，直接操作 DOM transform（不 setState）
- 磁性按钮：反平方距离衰减吸引
- 滚动渐入：IntersectionObserver + cubic-bezier
- Hero 视差：背景 0.35× + 内容 0.15× 双速
- CTA 大字视差、光泽扫过、脉冲装饰点、打字机、数字计数（easeOutExpo 阻尼趋近）、导航栏滚动模糊、按钮涟漪、客房滑入填充、滚动指示线条

## 健壮性

- 所有 JS/CSS 内联，零外部 JSX src
- `visibilitychange` 自动暂停/恢复全部 RAF
- `beforeunload` 统一取消定时器与 RAF
- 高频 mousemove 直接操作 DOM，无 React setState
- `prefers-reduced-motion` 完整降级（光标/雪花/蒸汽/倾斜/视差全关）
- RAF 重建前先 cancel 旧循环，定时器走 `safeSetTimeout` 管理

## 技术栈

纯原生 HTML/CSS/JS 单文件，无框架无外部 JS 依赖（仅字体 CDN）。

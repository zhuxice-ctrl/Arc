# 回声档案室 · 设计规范

## 主题
回声档案室 —— 一家非营利声音档案机构的完整单页官网，记录与保存正在消逝的声音（胡同鸽哨、侗寨大歌、寒山钟声、戈壁驼铃、老街叫卖、冰川裂鸣）。

## 色彩系统
| 角色 | 色值 | 用途 |
|------|------|------|
| 墨黑（主背景） | `#1a1612` | 页面底色，档案文献质感 |
| 深棕（次背景） | `#2a241d` | 卡片/分区背景 |
| 暖棕（中性深） | `#3d342a` | 边框/分割线 |
| 琥珀金（强调主） | `#d4882e` | 标题高亮、交互元素 |
| 亮琥珀（强调亮） | `#e8a84a` | 悬停态、数据高亮 |
| 赭石红（点缀） | `#b54b2e` | 警示/特殊标记 |
| 橄榄绿（辅助） | `#6b7a3a` | 次要标签、自然类标识 |
| 羊皮纸米（表面） | `#e8dcc8` | 浅色卡片表面 |
| 奶油白（文字主） | `#f5ece0` | 正文文字 |
| 暖灰（文字次） | `#c9b89a` | 次要文字 |

## 字体
- 展示字体：`"Songti SC", "SimSun", "Noto Serif SC", Georgia, serif` —— 宋体衬线，档案卷宗阅读体验
- 数据字体：`"Courier New", monospace` —— 等宽，用于编号/时间码

## 圆角
- 卡片：`12px`
- 按钮/标签：`6px`
- 圆形元素：`50%`

## 组件规范
- 磁带卷轴：四层同心圆，正反转交错，周期各异（8s/12s/6s/10s）
- 频谱可视化：64 条柱状频谱，弹簧物理驱动，5 种声音预设可切换
- 档案卡片：3D 倾斜跟随鼠标，光泽扫过动画，悬停光晕
- 导航栏：滚动后加模糊底+分割线，滑入背景动画

## 动效系统（15+）
1. 自定义光标 — 白色粗环+琥珀内点+脉冲外圈，悬停放大变色，点击涟漪
2. 粒子漂浮 — 40 颗暖金粒子，浮力+摆动+鼠标反平方斥力+摩擦阻尼
3. 标题逐字升起 — 字符级随机偏移入场
4. 磁带卷轴旋转 — 四层正反转交错
5. 频谱可视化 — 64 条弹簧物理柱
6. 卡片 3D 倾斜 — 惯性阻尼插值
7. 光泽扫过 — 斜向高光
8. 数字计数 — 缓出动量
9. 滚动渐入 — IntersectionObserver 分段揭示
10. 黑胶旋转 — 悬停播放
11. 旋钮旋转 — 三旋钮不同最大角度
12. 头像脉冲环 — 悬停扩散
13. 视差滚动 — 英雄区磁带卷轴惰性位移
14. 导航滑入背景 — 滚动加模糊底
15. 打字机光标 — 闪烁竖线
16. 吐司提示 — 弹性出现

## 页面结构
单页网站，自上而下：英雄区（磁带卷轴+标题）→ 声音档案卡片流 → 频谱交互区 → 统计数字区 → 关于机构 → 页脚

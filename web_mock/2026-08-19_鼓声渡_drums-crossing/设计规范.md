# 鼓声渡 · 设计规范

## 主题与设计母题
端午龙舟竞渡文化体验网站。设计母题：**横向江面长卷 + 击鼓节奏驱动**。整站不滚动成图，而是用户敲击朱漆大鼓打出节奏，鼓点驱动龙舟在横向江面上推进，里程推移展开端午龙舟的真实文化内容。视觉来源：桐油木龙舟、朱漆大鼓、江水墨绿、白浪花、鎏金。

## 空间模型
横向江面长卷（horizontal scroll racing lane）。5 个里程段：祭江起龙 → 竹林采青 → 石桥舟形 → 急滩竞渡 → 标旗归航。底部水尺为导航兼进度，已到埠头可回溯。

## 配色（取自源码真实色值）
- 江水/主背景 墨绿：`#1a2e26` / `#2D4A3E`
- 朱漆大鼓/强调 朱红：`#B8261C`（鼓身）/ `#d4463c` / `#e85a50`
- 桐油深木 棕：`#5D2E0F` / `#8B4513` / `#3B2410`
- 鎏金点缀：`#C9A24A` / `#d4af37` / `#8a6d2e`
- 米白浪花/纸面：`#F5EFE0` / `#fff8e7`
- 江岸苔绿：`#4a6b3a`

无蓝紫渐变。朱红为鼓的语义色，鎏金为仪式/夺标语义色。

## 字体
- 标题书法体：`Ma Shan Zheng`（毛笔感，用于"鼓声渡"主标与段名）
- 正文宋体：`Noto Serif SC`（阅读用）

## 动效系统（≥12 组件级特效）
1. 江面波浪起伏（多层正弦叠加）
2. 浪花粒子（船头破水生成）
3. 船体随浪浮沉
4. 水面倒影
5. 鼓面震动涟漪（击鼓瞬间）
6. 击鼓声波扩散环
7. 桨手齐桨/乱桨切换（节奏稳定度驱动）
8. 速度线（船速提升时）
9. 埠头内容展开过渡
10. 里程旗飘扬
11. 终点冲刺彩带
12. 节奏稳定度指示（金/红指针）
13. 龙头胡须摆动 / 龙尾摇摆 / 舵叶摆动
14. "齐桨同心"金色闪光（节奏首次打稳的签名时刻）

## 交互机制
- 主输入：点击/空格敲击鼓面。节奏稳定度算法：相邻击鼓间隔的方差越小越稳。
- 因果：稳定 → 桨手齐桨、船速提升；凌乱 → 船体晃动、桨影散乱。
- 副交互：水尺导航点击回溯已到埠头。

## 光标
自定义鼓槌形光标，开页居中，高对比、层级最高，击鼓时敲击反馈形变。

## 健壮性
- RAF 随页面可见性暂停、卸载取消
- 快速连续击鼓不叠加定时器
- prefers-reduced-motion 降级为静态全文展示
- 零未定义引用，Console 无错误

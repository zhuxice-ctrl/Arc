# 设计规范 · 盐田色谱 Salt Pan Spectrum

> 日期：2026-08-17 · 方向：V1 网页设计 · 主题：海盐田文化遗产官网

## 色彩系统

| 角色 | 色值 | 用途 |
|------|------|------|
| 主色-雾蓝灰 | `#6B7B8C` | 导航、次要文字、冷调背景 |
| 主色-赭红 | `#B5533C` | 强调、按钮、肖像边框、光标内点 |
| 表面色-盐白 | `#F2EDE3` | 页面底色、卡片背景 |
| 深底色-深海墨 | `#1E2A33` | 深色区块底、页脚 |
| 辅助-麦秆金 | `#C9A24B` | 高亮、光泽、节气节点 |
| 辅助-浅盐 | `#E8E1D4` / `#D4A574` / `#8B7355` | 色阶过渡、次级元素 |

盐田色阶六阶（产盐六阶段）：深灰蓝 `#2A3F4D` → 茶青 `#4A636E` → 茶褐 → 赭红 `#B5533C` → 金砂 `#C9A24B` → 盐晶白 `#F2EDE3`。

## 字体

- 衬线展示：`var(--serif-display)` — DM Serif Display（大标题/Hero）
- 衬线正文：`var(--serif-body)` — Noto Serif SC（正文叙述）
- 无衬线正文：`var(--sans-body)` — Noto Sans SC（UI 文字）
- 通过 Google Fonts（miaoda 字体服务）引入。

## 组件

- 导航栏：滚动 >100px 触发毛玻璃浮现。
- 色阶图鉴：6 色带，底部向上 scaleY 展开，交错延迟。
- 节气时间轴：6 节点，光环呼吸 2s 周期，点击切换详情。
- 工序卡片：3D 倾斜（perspective + rotateX/Y），悬停翻转。
- 数字计数器：三次方缓出，进入视口触发。
- 按钮：斜向光泽扫过，点击径向涟漪 800ms。

## 动效系统（14 项）

自定义光标（弹簧积分器，外环滞后内环）、点击涟漪、盐粒粒子背景（重力+摩擦+随机游走）、盐晶生长 Canvas（晶簇生长→脉动→渐隐）、Hero 视差（0.3 倍滚动速率）、色阶渐显、节气脉冲、数字计数、3D 倾斜卡片、滚动渐入（IntersectionObserver）、光泽扫过、潮汐实时模拟、导航毛玻璃、工序翻转。

所有 RAF/定时器随 `visibilitychange` 暂停、卸载取消；`prefers-reduced-motion` 全局降级。

## 页面结构

Hero 首屏（鸟瞰+潮汐指示）→ 盐田色阶图鉴 → 二十四节气产盐志 → 古法晒盐四道工序 → 盐工口述 → 盐晶生长 Canvas → 页脚。单页滚动，6 大板块。

# 设计规范 · 穗浪 Golden Sheaf 谷物文化艺术节官网

> 日期：2026-08-17 · 方向：V1 网页设计 · 主题：谷物 / 麦田 / 土地文化艺术节官网

## 色彩系统

| 角色 | 色值 | 用途 |
|------|------|------|
| 主色 · 麦浪金 | #E0A92E | 标题强调、CTA、音柱、光标内点 |
| 主色深 | #B8861F | 悬停态、按压态 |
| 辅助 · 土壤赭 | #8C5A33 | 次级标题、卡片描边、田园质感 |
| 辅助 · 陶土 | #A87450 | 分隔线、图标 |
| 辅助 · 草绿 | #6B8F4E | 自然标签、成功态 |
| 草绿深 | #4F6D38 | 文字链接 hover |
| 表面 · 米白纸底 | #F7F1E3 | 页面背景 |
| 表面 · 浅麦 | #EBE2CD | 卡片底色 |
| 强调金 | #F0C75A | 高亮、光泽扫过 |
| 文字 · 深褐 | #6B4424 / #7A6A55 | 正文 / 次要文字 |

配色策略：以麦浪金为视觉主角，土壤赭与草绿作大地色辅佐，整体落在米白纸底上，呈现丰收与土地的温润质感。禁用蓝紫渐变。

## 字体

- 标题：`"Noto Serif SC", "ZCOOL XiaoWei", serif`（衬线，呈现节庆与刊物气质）
- 正文：`"Noto Sans SC", system-ui, sans-serif`
- 数字 / 西文：`Georgia, "Times New Roman", serif`

## 圆角与阴影

- 卡片圆角：16px；按钮圆角：999px（胶囊）；图片圆角：12px
- 卡片阴影：`0 8px 30px rgba(108,68,36,.12)`；悬停上浮 `-6px` 并加深阴影
- 门票卡片顶部金条：hover 从左滑满宽 350ms

## 组件

- 自定义光标：白色粗环(3px) + 麦浪金内点 + 多层发光(`0 0 12px rgba(224,169,46,.6)`)，z-index 9999，开页居中显示，悬停可交互元素放大 1.4× 三态切换，点击涟漪。
- Hero：全屏麦田视觉 + 标题分级淡入 + 副标题打字机 + 双 CTA(光泽扫过)。
- 声波律动柱：24 根不等高金色音柱，各柱周期 0.8–1.6s 随机，基于正弦相位摆动。
- 展区 Tab：六大主题展区切换，大图 3D 倾斜跟随鼠标(RAF 阻尼插值)。
- 日程时间线：四天切换，条目逐条左滑入场。
- 票务卡片：三档，中间档高亮，hover 上浮 + 顶部金条展开。
- 数字计数：easeOutCubic 递增统计(创作者/展区/活动数)。

## 动效系统（12+ 组件级）

1. 自定义光标（居中+三态+涟漪）
2. 麦浪粒子飘落（Canvas 80+ 颗粒，相位摆动）
3. Hero 标题/副标题/按钮分级淡入
4. 打字机效果（副标题逐字）
5. 声波柱律动（24 柱各异周期）
6. 滚动渐入（IntersectionObserver，多段延迟）
7. 数字计数动画（easeOutCubic）
8. 3D 卡片倾斜（RAF 阻尼插值）
9. Hero 视差滚动（背景 0.3 倍速平移）
10. 导航滚动收缩 + 毛玻璃
11. 艺术家头像脉冲光环
12. 光泽扫过（CTA 斜向光带）
13. 门票卡片悬停上浮 + 金条展开
14. 时间线条目逐条左滑入场
15. Tab/日程切换淡入过渡

动效基于物理模型（RAF 积分器、阻尼插值、正弦相位）与主题语义（麦浪飘落、声波律动、光泽扫过）。严禁整图缩放 / Ken Burns。

## 页面结构

Hero 全屏 → 关于节(介绍+数字统计) → 六大主题展区(Tab) → 四天日程表 → 驻场创作者 → 票务三档 → 地点信息 → 页脚导航。单页完整官网，非多页工具平台。

## 健壮性

- `visibilitychange` 暂停所有 RAF/定时器，`beforeunload` 统一清理
- 高频 mousemove 直接操作 DOM transform，不触发 React 重渲染
- `prefers-reduced-motion` 降级为静态/最小动效
- 全部 JSX 内联于 `<script type="text/babel">`，CSS 内联于 `<style>`

# 铸字局 IronPress · 设计规范

> 方向：V1 网页设计 · 日期：2026-08-17 · 主题：活字铸造品牌官网

## 1. 色彩系统

主配色为「墨纸朱铜」暖纸墨系，取自铅活字与手工纸的材质语言，无蓝紫渐变。

| 角色 | 色值 | 用途 |
|---|---|---|
| 底色 · 墨黑 | `#1B1712` | 页面主背景、深色区块 |
| 主色 · 朱砂红 | `#C0392B` | 标题强调、铸字机高亮、按钮 |
| 纸面 · 米纸白 | `#F4EDDE` | 浅色卡片底、正文反衬区 |
| 点缀 · 铜金 | `#B08D57` | 分隔线、编号、金属质感描边 |
| 暖灰中性 | `#6E6558` | 次级文字、图标 |

派生层次：`#0F0D0A`（最深底）/ `#2A241D`、`#3A332A`、`#4A4338`（卡片分层）/ `#EAE0CC`、`#DED1B5`（纸面浅阶）/ `#D95242`、`#922C22`（朱砂亮/暗阶）/ `#CCA96E`、`#8A6D40`（铜金亮/暗阶）。

## 2. 字体

- 展示字 `--display: 'Ma Shan Zheng', 'Noto Serif SC', serif` — 标题与活字展示，毛笔楷书气质。
- 正文 `--sans: 'Noto Sans SC', 'PingFang SC', sans-serif` — 阅读正文。
- 衬线 `--serif: 'Noto Serif SC', 'Songti SC', serif` — 段落引文、时间线。

## 3. 页面结构（7 区块）

1. Hero — 工坊背景 + 粒子粉尘 + 标题逐字入场。
2. 铸字工艺 — 熔铅 / 铸字 / 拣字 / 排版 / 打样 / 印刷 六道工序卡。
3. 在线铸字机 — 输入文字实时渲染铅字凸版，可调字重 / 字号 / 油墨浓度。
4. 字库馆藏 — 72 字网格，四档字重切换，逐字悬停浮雕。
5. 活字历史 — 时间线叙事（毕昇泥活字 → 王祯木活字 → 明铜活字 → 清聚珍版）。
6. 设备馆藏 — 三台复古印刷机藏品卡。
7. 拣字盘 — 点击空格置入铅字、点击取出，可重置；CTA + 页脚。

## 4. 动效系统

基于物理模型与铸造语义，动效周期各不相同：

- 自定义光标：外环弹簧阻尼跟随 + 内点灵敏跟随 + 多层发光晕；悬停三态切换、点击涟漪。
- 粒子粉尘：反平方引力 + 缓慢上升 + 正弦漂移 + 呼吸闪烁。
- 标题字符逐字入场（不同延迟）。
- 滚动渐入揭示（IntersectionObserver，多级 delay）。
- 卡片悬停凸起：铅字 3D 倾斜 + 发光。
- 字库网格字重切换过渡。
- 数字计数：easeOutCubic 缓动，视口触发。
- 打字机效果。
- 光泽扫过（CTA 标题 / 按钮 shine sweep）。
- 滚动进度条。
- 工艺卡编号偏移 + 图标旋转。
- 拣字盘铅字弹性浮动。
- 铅字铸入动画（逐个延迟弹出）。
- Hero 滚动提示脉冲。

## 5. 健壮性

- `visibilitychange` 暂停所有 RAF 与动画循环，卸载统一取消。
- `prefers-reduced-motion` 全局降级为静态。
- 高频鼠标事件直接操作 DOM transform，不走 setState。
- 移动端自动隐藏自定义光标、降级原生光标。

## 6. 技术栈

单文件 `index.html`，内联 `<style>` + 内联 `<script type="text/babel">`（React + Babel standalone），无外部 JSX/CSS 文件引用。CDN 依赖在妙搭环境内可达。

# 设计规范

## 一、品牌概述

**回声剧院** — 一座为声音艺术建造的沉浸式数字剧院官网。以"声音、剧场、田野"为核心叙事，呈现本季演出、驻院艺术家、田野录音档案与公教工作坊。面向声音艺术爱好者、策展人与城市文化探索者。

## 二、色彩系统

| 角色 | 色值 | 用途 |
|------|------|------|
| 主背景 | `#FBF7EE` | 米奶油纸底 |
| 次背景 | `#F6EFE0` / `#EDE1C9` | 分区底色 |
| 主文字 | `#2A1F1A` | 深棕墨色 |
| 朱砂红 | `#B83B2C` | 强调 / 标题重音 |
| 赭石金 | `#D4983B` / `#8B6914` | 装饰线 / 印章 |
| 苔绿 | `#6B8E5A` / `#8EAF7D` | 次级强调 / 标签 |
| 砖红 | `#D96B5A` | 交互态 |
| 中性棕 | `#5C4A3D` / `#8B7860` | 副文本 |

> 全站禁用蓝紫渐变；以暖纸底 + 朱砂赭金的东方剧场质感为统一基调。

## 三、字体

- 展示字体：`ZCOOL XiaoWei`（刻隶风格，用于大标题与栏目标）
- 正文字体：`Noto Sans SC` / `PingFang SC`，无衬线
- 字重梯度：300 / 400 / 500 / 700 / 900

## 四、圆角与间距

- 卡片圆角：`16px`；按钮：`999px`（胶囊）/ `8px`
- 栏目内边距：桌面 `80px` 两侧留白，移动端 `24px`
- 节段间距：`120px`

## 五、页面结构

Hero 主视觉 → 关于剧院 → 本季演出 → 驻院艺术家 → 田野录音档案 → 公教工作坊 → 参观购票 → 页脚

## 七、健壮性

- 所有 RAF / 定时器随 `visibilitychange` 自动暂停，卸载统一取消
- 高频鼠标事件直接操作 DOM transform，不触发 React setState
- 支持 `prefers-reduced-motion` 全量降级
- 所有 JSX 内联在 `<script type="text/babel">`，零外部 JSX 引用

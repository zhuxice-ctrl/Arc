## 组件规范

- **导航栏**：固定顶部，滚动时收缩，骨白半透明背景 + 底边线
- **釉色卡片**：3D 倾斜跟随鼠标，悬停光泽扫过，渐变背景模拟釉面质感
- **画廊网格**：不规则网格布局，悬停放大 + 信息浮入
- **时间线**：竖向连接线动画绘制，节点图标悬停浮起
- **CTA 按钮**：磁力吸附效果（鼠标靠近时位移），铁锈红底 + 骨白文字

## 动效系统

1. **自定义光标**：外环阻尼跟随 + 内点即时跟随 + 点击涟漪扩散
2. **Hero 粒子**：釉色尘埃粒子漂浮，随机轨迹
3. **逐字入场**：标题文字逐字淡入上移
4. **滚动渐入**：IntersectionObserver 触发，各区块依次淡入
5. **3D 卡片倾斜**：mousemove 直接操作 transform，不触发重渲染
6. **数字计数**：指数缓出动画，统计数字从 0 增长到目标值
7. **磁力按钮**：鼠标距离反平方衰减，按钮向鼠标偏移
8. **窑变光斑漂浮**：径向渐变光斑随机漂浮，模拟窑变效果
9. **光泽扫过**：卡片悬停时对角线高光扫过
10. **开片纹扩散**：点击卡片时裂纹纹路从点击点扩散
11. **导航收缩**：滚动时导航栏高度减小、透明度增加
12. **Hero 视差**：Hero 区元素随滚动以不同速率位移
13. **窑火亮度**：工作室区块火焰亮度随滚动位置变化
14. **时间线绘制**：SVG 路径动画绘制连接线

## 页面结构

1. **Hero** — 青瓷瓶视觉 + 窑变光斑 + 逐字入场标题
2. **四大经典釉色** — 青瓷 / 铁锈红 / 骨白 / 乌金卡片展示
3. **窑变画廊** — 不规则网格，悬停放大 + 信息浮入
4. **工作室介绍** — 柴窑火焰动画 + 数字计数
5. **五道工艺流程** — 时间线 + 图标悬停
6. **品牌故事 CTA** — 深色沉浸背景 + 磁力按钮
7. **Footer** — 四栏导航

## 技术栈

- 纯 HTML/CSS/JS 单文件，无 React/Babel 依赖
- IntersectionObserver 实现滚动渐入
- requestAnimationFrame 统一管理动画循环
- visibilitychange 自动暂停 / prefers-reduced-motion 降级

# 流光阁 · 设计规范

## 色彩系统

| 角色 | 色值 | 用途 |
|---|---|---|
| 主色 · 珊瑚霓虹红 | `#FF5A4F` | 霓虹标题、主按钮、发光强调 |
| 主色亮阶 | `#FF8A7A` / `#FFB89A` | 霓虹发光晕、悬停态 |
| 辅助色 · 黄铜金 | `#D4A856` | 次级标题、边框、标签 |
| 辅助亮阶 | `#E8C982` | 金色高光、分割线 |
| 点缀色 · 翡翠绿 | `#3FB68A` / `#7FD6B2` | 状态点、次级霓虹管 |
| 背景 · 炭黑 | `#1A1714` / `#24201A` / `#2E2821` | 页面底、卡片底、分区底 |
| 中性 · 暖灰 | `#5A5144` / `#8A7F6E` / `#C8BDA9` | 正文辅助、说明文字 |
| 表面 · 米白 | `#F2E8D5` | 亮色文字、票面元素 |

配色为「炭黑暖灰底 + 珊瑚霓虹红 + 翡翠绿 + 黄铜金」，完全避开蓝紫渐变。

## 字体排印

- 标题：`Noto Serif SC, serif`（衬线，招牌字体质感）
- 正文：`Noto Sans SC, -apple-system, sans-serif`
- 数据 / 标签：`IBM Plex Mono, monospace`

## 组件规范

- 馆藏卡片：炭黑底 + 细金边，悬停 3D 透视倾斜 + 图片视差位移
- 按钮：珊瑚红实心（光泽扫过 + 弹簧上浮）/ 描边金（幽灵按钮）
- 导航栏：滚动收缩 + 毛玻璃 backdrop-filter
- 模态框：弹性缩放入场（spring）
- 时间线：节点圆点悬停发光脉冲

## 动效系统（16 项）

自定义光标（白环 + 红点 + 发光晕，悬停变色放大、点击涟漪）、霓虹闪烁入场、霓虹呼吸脉冲、尘埃粒子漂浮、频谱条振动（多频率正弦叠加）、3D 卡片倾斜、数字计数缓动（easeOutCubic）、滚动渐入（IntersectionObserver）、Hero 视差、按钮光泽扫过、按钮弹簧上浮、门票数量脉冲、导航滚动收缩、滚动提示线流、模态框弹性缩放、时间线节点悬停放大。

## 页面结构

单页完整网站：导航栏 → Hero（霓虹大标题 + 粒子 + 视差）→ 馆藏展区（3D 倾斜卡片）→ 霓虹的嗡鸣（频谱振动）→ 数据统计（计数）→ 工艺时间线 → 参观预约（票价 + 模态框）→ 页脚。

## 健壮性

- visibilitychange 自动暂停 / 恢复所有 RAF 循环
- prefers-reduced-motion 降级为静态
- 移动端隐藏自定义光标
- 所有动画由统一 animHandlers 管理，卸载时全部清除

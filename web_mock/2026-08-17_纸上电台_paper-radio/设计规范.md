# 设计规范 · 纸上电台 · 短波之声

> 方向：V1 网页设计 · 日期：2026-08-17 · 主题：复古短波广播电台杂志风官网

## 色彩系统

| 角色 | 色值 | 用途 |
|------|------|------|
| 纸感底色 | `#FAF6E8` / `#F5EFD8` | 页面主背景，泛黄纸质感 |
| 次级表面 | `#E8DFC2` | 卡片底、分隔区块 |
| 铁锈红·主强调 | `#D46A4A` | 直播指示、主按钮、重点标题 |
| 铁锈红·深 | `#B84A2F` / `#8C3621` | 悬停态、深色强调 |
| 琥珀金 | `#B8922F` | 装饰线、次要图标、刻度盘指针 |
| 墨绿·辅助 | `#3F6354` / `#2D4A3E` | 标签、次级按钮、文化长文衬底 |
| 午夜蓝 | `#2A3B4C` | 听众来信深色区块 |
| 炭黑·文字 | `#2A2722` / `#1C1A17` | 正文、标题文字 |

配色禁止蓝紫渐变；整体为奶油黄纸质底 + 铁锈红主色 + 墨绿辅助的复古印刷质感。

## 字体排印

- 标题/展示：`'ZCOOL XiaoWei', 'Noto Serif SC', serif` —— 复古衬线宋体，带印刷字感
- 正文：`'Noto Sans SC', sans-serif`
- 文化长文：`'Noto Serif SC', serif` —— 双栏衬线排版

## 圆角与间距

- 卡片圆角 8–12px，按钮 6px，标签胶囊形
- 章节纵向间距 80–120px，卡片内边距 24–32px

## 组件规范

- **导航栏**：台标 + 菜单（节目/主持人/来信/文化/指南）+ 直播指示灯 + 移动端汉堡
- **巨型刻度盘**：弹簧物理驱动，指针自动扫频 + 实时数字跳动
- **节目时间表**：5 天 Tab 切换，直播中高亮，卡片悬停左移 + 左侧色条展开
- **主持人卡片**：3D 倾斜悬停、节期数与听众数滚动计数
- **听众来信**：深色反向卡片、已阅邮戳装饰
- **频率跑马灯**：6 个短波频率横向无缝滚动

## 动效系统

1. 自定义光标（弹簧跟随 + 悬停放大 + 点击涟漪）
2. 声波柱振动（多正弦波合成，40 柱）
3. 指针扫频（阻尼指数逼近）
4. 打字机标题（自然变速节奏）
5. 数字计数（ease-out cubic）
6. 3D 卡片倾斜（鼠标位置驱动）
7. 磁性按钮（反平方引力）
8. 滚动渐入
9. 跑马灯无缝循环
10. 直播脉冲灯
11. 磁带卷装饰旋转
12. 链接下划线扩展

## 页面结构

导航栏 → Hero（打字机标题 + 刻度盘 + 声波频谱）→ 频率跑马灯 → 节目时间表 → 主持人专栏 → 听众来信 → 电波文化长文 → 收听指南 → 页脚

## 健壮性

RAF/定时器随 `visibilitychange` 自动暂停、卸载统一取消；`prefers-reduced-motion` 全量降级；移动端关闭自定义光标；响应式适配。

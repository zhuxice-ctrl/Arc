# 设计规范 · 琥珀纪 Amber Chronicle

> 日期：2026-08-17 · 方向：V1 网页设计 · 主题：远古树脂中的时空胶囊（琥珀化石自然特展官网）

## 色彩系统

以幽暗展柜为底，琥珀金为主光，松绿点缀生命意象，象牙白带做正文，焦橙强调行动。

| 角色 | 色值 | 用途 |
|------|------|------|
| 展柜底色（深赭石） | `#0c0a02` / `#1a120b` / `#241810` | 页面背景、深色区块 |
| 琥珀金 | `#d97706` / `#f59e0b` / `#fbbf24` | 主品牌色、标题强调、琥珀滴 |
| 焦橙 | `#ea580c` / `#c2410c` | CTA 按钮、行动号召 |
| 松绿点缀 | `#4d7c0f` / `#84cc16` / `#14532d` | 生命标签、标本分类 |
| 象牙白带 | `#f5e6d3` / `#fef9c3` / `#fef3c7` | 正文文字、卡片表面 |
| 暖棕中性 | `#a8927a` / `#92400e` / `#78350f` | 次级文字、边框、阴影 |

## 字体

- 展示字：`"Noto Serif SC", "Songti SC", "STSong", serif`（思源宋体，标题与标本名）
- 正文字：`"Noto Sans SC", "PingFang SC", "Microsoft YaHei", sans-serif`（思源黑体）
- 数据/编号：`"JetBrains Mono", "SF Mono", Consolas, monospace`

## 组件规范

- 标本卡片：圆角 18px，深色玻璃底 + 1px 琥珀色描边，hover 光泽扫过 + 内嵌琥珀微旋转
- 磁性按钮：CTA 采用反平方引力模型，鼠标越近按钮偏移越多，松手回弹
- 时间线节点：圆点 + 脉冲环，交错入场
- 自定义光标：白色粗环 + 金色光点 + 光晕拖尾，三层结构，z-index 最高

## 动效系统（13 项）

1. 自定义光标（三层跟随 + 悬停放大 + 点击涟漪）
2. Hero 粒子系统（80 颗琥珀光点上浮 + 相位呼吸）
3. 琥珀滴漂浮（双正弦叠加 + 微旋转）
4. 标题字逐一升起入场
5. 打字机效果（导言末句逐字，随机间隔）
6. 数字计数动画（ease-out 缓动）
7. 标本卡片 3D 倾斜（鼠标驱动，弹簧阻尼）
8. 卡片光泽扫过 + 琥珀放大 hover
9. 滚动渐入（IntersectionObserver）
10. 时间线交错入场 + 节点脉冲环
11. 视差滚动（Hero 内容与琥珀滴差速消退）
12. 磁性按钮（反平方引力）
13. 标本卡内琥珀微旋转（各自独立周期）

## 页面结构

单页纵向叙事：Hero（展名 + 悬浮琥珀滴）→ 导言（打字机）→ 统计数字 → 标本画廊（3D 倾斜卡片网格）→ 地质时间线 → 参观信息（磁性按钮 CTA）→ 页脚。

## 技术栈

纯 vanilla HTML/CSS/JS 单文件，零外部依赖（字体走镜像站）。visibilitychange 暂停所有 RAF/定时器，prefers-reduced-motion 降级静态。

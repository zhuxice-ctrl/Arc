# 设计规范 · 八音筒机械乐谱

## 一、设计核心概念

整站是一只可拖拽旋转的黄铜八音筒。用户拖动筒体旋转，筒面针钉经过钢梳齿时触发音符（Web Audio 实际发声），旋律随之流淌。筒面可展开为 2D 乐谱面板，针钉排列即音符矩阵。

**Design DNA**：十九世纪精密机械仪器 — 黄铜 + 核桃木 + 钢 + 暖琥珀光。

- **金色系**：主交互对象（筒体、按钮、激活态）、强调信息

- **木色系**：背景、基座、安静区域
- **琥珀橙**：声音可视化（涟漪、闪光、播放头）

## 四、空间结构

### 布局模型
固定舞台式布局，非滚动 Landing Page。以中央黄铜八音筒为视觉中心，左右侧栏承载曲目与档案，底部可展开乐谱面板。

```
┌────────── 顶部标题栏 ──────────┐
│                                │
├──────┬───────────────┬─────────┤
│ 曲目 │   八 音 筒    │  机 械  │
│ 列表 │   演 奏 区    │  档 案  │
│      │  (拖拽交互)   │         │
├──────┴───────────────┴─────────┤
│    乐谱面板（可展开收起）       │
└────────────────────────────────┘
```

### 视觉节奏
- **强中心**：筒体 + 钢梳 + 暖光 = 第一视觉重心
- **弱两侧**：曲目列表、档案面板为辅助信息，低对比
- **可展开**：乐谱面板默认收起，展开后进入阅读模式

## 五、动效系统（共 14 个组件级特效）

| 编号 | 动效名称 | 触发条件 | 时长/曲线 | 物理逻辑 |
|---|---|---|---|---|
| 1 | **筒体惯性旋转** | 拖动释放后 | 摩擦衰减 0.985/帧 | 模拟机械惯性，速度越高滑行越远 |
| 2 | **针钉沿曲面运动** | 筒体旋转 | 实时（sin 曲线） | 圆柱曲面投影，近大远小，背面不可见 |
| 3 | **针钉接近发光** | 针钉接近钢梳 1.5 列内 | 亮度递增 | 金属高光聚焦，接触时峰值 |
| 4 | **钢梳齿振动** | 针钉触齿瞬间 | 120ms ease-out | 高频微振动 2px→1.5px→1px→0 |
| 5 | **音符涟漪扩散** | 音符触发时 | 800ms ease-out | 暖琥珀圆环从梳齿根部向外扩散并淡出 |
| 6 | **背景暖光呼吸** | 常驻 + 音符触发脉冲 | 6s 循环 + 300ms 脉冲 | 与演奏密度呼应的光影呼吸 |
| 7 | **曲目切换针钉重排** | 切换曲目 | 缩进 240ms + 弹出 stagger 80ms | 错位回缩再弹出，模拟换筒操作 |
| 8 | **乐谱面板展开/收起** | 点击展开按钮 | 600ms cubic-bezier(0.2,0.8,0.2,1) | 3D→2D 平滑过渡，内容延迟淡入 |
| 9 | **乐谱播放头同步** | 筒体旋转 | 50ms linear | 与旋转位置 1:1 对应 |
| 10 | **乐谱点激活闪光** | 当前拍的针钉点 | 持续到下一拍 | 缩放 1.2 + 增亮 |
| 11 | **曲目项悬停左金条** | 鼠标悬停 | 350ms | 左侧金色色条从顶部展开 |
| 12 | **播放按钮悬停放大发光** | 鼠标悬停 | 300ms | 缩放 1.08 + 金色光晕 |
| 13 | **自定义光标跟随 + 拖拽旋转** | 鼠标移动 / 按下拖动 | 200ms 缓动跟随 | 调音钥匙形态，拖拽时旋转 15° |
| 14 | **页面入场动画** | 首次加载 | 错落 0.3-1.4s | 顶部下滑、两侧滑入、舞台淡入、曲目逐项出现 |

### 减动效模式（prefers-reduced-motion）
- 无惯性旋转（释放即停）
- 无涟漪扩散
- 无入场动画
- 无针钉重排动画（直接切换）
- 光标无缓动跟随

## 六、图形与材质

### 黄铜筒体
- 纵向渐变：暗金→亮金→高光→暗金→深棕（模拟圆柱光影）
- 纵向细纹：每 4px 一条深色细线（车削纹理）
- 中间高光带：42%-58% 位置的横向亮带（环境光反射）

### 钢梳
- 金属灰渐变，顶亮底暗
- 15 齿，低音长、高音短（左→右音高递增，齿长递减）
- 振动时变为金色发光

### 针钉
- 圆柱钉形态，上亮下暗
- 黄铜色渐变 + 发光光晕
- 沿筒体曲面做 3D 投影（近大远小、背面消隐）

### 木基座
- 深棕木纹 + 水平木纹纹理线
- 内嵌高光线 + 投影

## 七、交互系统

### 核心交互：拖拽旋转 = 演奏
- 水平拖动筒体 → 筒体绕长轴旋转
- 释放后 → 物理惯性滑行，逐渐减速
- 针钉经过钢梳 → 自动触发音符 + 视觉反馈

### 次要交互
- 左侧点击曲目 → 针钉重排 + 切换旋律
- 播放按钮 → 自动匀速旋转循环
- 速度滑块 → 0.2x - 3x 播放速度
- 底部「展开乐谱」→ 显示完整针钉矩阵

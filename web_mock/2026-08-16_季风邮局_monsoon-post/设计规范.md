# 季风邮局 Monsoon Post · 设计规范

## 主题
虚构的南洋季风邮政工作室品牌站——信件乘着季风跨洋送达。单页沉浸式卷轴叙事。

## 色彩系统
暖赭石橙红 + 深靛墨蓝 + 宣纸米白 + 黄铜金点缀（禁蓝紫渐变）。

| 角色 | 色值 | 用途 |
|------|------|------|
| 纸底 | #FBF7EC / #F5EEDB | 页面底色、信纸 |
| 米白 | #EDE3C8 / #E3D5AE | 次级表面 |
| 赭石橙 | #B03A17 / #D4542A / #E8734A | 主强调、火漆、CTA |
| 黄铜金 | #B8913A / #D4AF5A / #E8C97A | 点缀、徽章、描边 |
| 深靛墨 | #0A1128 / #050A1A / #141D3E | 深底、文字、航线 |
| 靛蓝阶 | #24305C / #414D85 / #6672AA / #97A1C8 | 中性过渡 |
| 暖褐 | #6A390C / #8C4F12 | 阴影、墨迹 |

## 字体
- `--font-display`：标题展示字（衬线/手写感）
- `--font-serif`：正文衬线
- `--font-mono`：编号、邮票面值

## 组件
- 自定义光标（白粗环 + 彩色内点 + 多层发光 + 点击涟漪 + 三态）
- Hero 视差层（鼠标惯性阻尼）
- 数字计数统计卡（ease-out cubic 缓动）
- 信纸打字机（自然节奏变速）+ 3D 倾斜（摩擦积分器）
- 邮票卡（齿孔边 + 3D 倾斜 + 光泽扫过）
- 航线 Canvas（风向流动正弦波 + 港口脉冲）
- 磁吸引按钮（反平方引力 + 回弹阻尼）
- 火漆封印 CTA
- 导航滚动收缩

## 动效系统
14+ 组件级特效，均基于物理/语义模型：
1. 自定义光标弹簧跟随
2. Hero 鼠标视差（惯性阻尼）
3. 数字计数缓动
4. 打字机变速
5. 信纸 3D 倾斜（摩擦积分器）
6. 邮票卡 3D 倾斜 + 光泽扫过
7. 全球粒子风层（风向流动 + 纸屑飘落 + 正弦漂移）
8. Hero 风脉 canvas（条纹 + 大型正弦风脉）
9. 磁吸引按钮（反平方引力 + 回弹）
10. 滚动渐入（IntersectionObserver）
11. 航线节点脉冲
12. 导航滚动收缩
13. 按钮光扫 + 填充滑入
14. 信封漂浮（周期浮动）

动效周期各异，不整齐划一；严禁整图缩放/Ken Burns。

## 页面结构
Hero → 季风之旅（四段卷轴叙事）→ 写信室 → 风向航线图 → 邮票画廊 → 宣言区 → 页脚

## 健壮性
- RAF/定时器随 visibilitychange 暂停，卸载统一取消
- 快速切换航线/信件模板先清旧定时器
- 高频 mousemove 直接操作 DOM transform
- 完整 prefers-reduced-motion 降级
- 所有 JSX 内联于 index.html `<script type="text/babel">`

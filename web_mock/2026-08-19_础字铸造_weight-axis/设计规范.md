# 设计规范 · 础字铸造「础方」字族发布站

> 项目：础字铸造 CHU TYPE FOUNDRY — 础方 Chu Fang 九字重字族品牌官网

---

## 一、Design DNA

| 项目 | 内容 |
|------|------|
| **核心概念** | 全屏中央巨字舞台 + 左侧垂直字重轴，用户以键盘 ↑↓ 沿字重轴攀爬，亲手掂量一个字族的重量 |
| **视觉来源** | 传统活字铸造 / 字体校样稿 / 印刷规格表 |
| **空间模型** | 固定舞台式（Fixed Stage）—— 巨字恒居中央，内容层叠于舞台之上，垂直字重轴为左侧控制枢轴 |
| **图形语言** | 细发丝线 / 校样格 / 刻度标尺 / 方块印记 / 无装饰极简排版 |
| **字体逻辑** | 系统无衬线 + font-weight 变量轴 + -webkit-text-stroke 增强细字可见性，字体本身即设计主角 |
| **色彩逻辑** | 暖纸白底 + 墨黑主色 + 铸字砖红强调色，三色体系克制克制再克制 |
| **材质逻辑** | 纸张的温感 + 铅字的重量感 + 刻度的精密感 |
| **动效语言** | 字重过渡 = 铅字浇铸感（font-weight 连续变化 260ms ease）；轴柄攀爬 = 弹性吸附；章节切换 = 淡入上移 |
| **交互记忆点** | 按住 ↑ 从 Hairline 一路攀到 Black，中央巨字从发丝轮廓变实心铅块，整屏气质同步迁移 |

## 三、字体系统

### 字体栈

```
-apple-system, BlinkMacSystemFont, "Segoe UI", "PingFang SC",
"Hiragino Sans GB", "Microsoft YaHei", "Helvetica Neue", Helvetica, Arial, sans-serif
```

- 纯系统无衬线，不加载外部字体文件，零白屏风险

## 四、动效系统

> 动效总数：15 个组件级特效。动效语言统一为「铅字浇铸感」—— 重量的连续迁移而非跳跃。

### 核心动效（字重驱动）

| 编号 | 名称 | 触发 | 效果 | 时长 | 缓动 |
|------|------|------|------|------|------|
| M1 | 巨字字重过渡 | 字重切换 | font-weight 100→900 连续变化 + stroke 宽度同步缩放 | 260ms | cubic-bezier(0.25, 0.1, 0.25, 1) |
| M2 | 巨字描边过渡 | 字重切换 | -webkit-text-stroke 宽度随字重减小而增大（增强细字可见性） | 260ms | 同上 |
| M3 | 巨字微缩放 | 字重切换 | 细字稍大、粗字稍小，补偿视觉重量 | 260ms | 同上 |
| M4 | 字重数字同步 | 字重切换 | 右下角数字本身的字重随当前档位变化 | 260ms | 同上 |
| M5 | 正文感应字重 | 字重切换 | 各章节标题/正文字重随当前档位同步迁移 | 260ms | 同上 |

### 轴柄与刻度动效

| 编号 | 名称 | 触发 | 效果 | 时长 |
|------|------|------|------|------|
| M6 | 刻度标记伸缩 | 字重切换 | 当前档刻度从 8px → 16px，颜色变砖红 | 180ms |
| M7 | 刻度标签变化 | 字重切换 | 当前档标签字号/字重/颜色变化 | 180ms |
| M8 | 轴柄弹性吸附 | 拖动释放 | 轴柄弹性缩放到最近刻度 | 260ms |
| M9 | 轴柄 Hover 缩放 | 鼠标悬停 | 轴柄放大 1.15 倍 + 砖红描边 | 180ms |
| M10 | 填充条高度变化 | 字重切换 | 轨道填充条高度随字重变化 | 260ms |

### 章节与内容动效

| 编号 | 名称 | 触发 | 效果 | 时长 |
|------|------|------|------|------|
| M11 | 章节下划线滑入 | 章节切换 | 当前章节底部下划线从 0 扩展到全宽 | 260ms |
| M12 | 章节内容淡入 | 章节切换 | 内容层淡入 + 上移 12px | 260ms |
| M13 | 字汇格 Hover | 鼠标悬停 | 边框变砖红 + 淡红底 + 砖红字色 | 150ms |
| M14 | 授权卡 Hover | 鼠标悬停 | 背景变深 + 箭头右移 4px | 180ms |

### 交互反馈动效

| 编号 | 名称 | 触发 | 效果 | 时长 |
|------|------|------|------|------|
| M15 | 巨字脉冲 | 点击字汇格 | 巨字放大 1.05 倍后回弹 | 120ms |

### 启动动效

- **Boot 遮罩**：中央「础」字在 100–900 字重间呼吸 1.8s，随后整体淡出 600ms
- 禁止 Ken Burns 整图缩放 / 粒子 / 光晕 / 视差

## 六、交互系统

### 主交互路径（键盘优先）

| 快捷键 | 行为 |
|--------|------|
| ↑ / ↓ | 沿字重轴逐档攀爬（按住连续攀爬，速度递增） |
| ← / → | 切换上一 / 下一章节 |
| 直接输入文字 | 替换中央巨字（输入框聚焦时） |

### 次级交互路径（指针）

- **轴柄拖动**：鼠标按住轴柄上下拖动，松手吸附最近刻度
- **刻度点击**：点击任一轴刻度直接跳转
- **轨道点击**：点击轨道任意位置跳转最近刻度
- **章节点击**：顶部章节标签 / 右侧页码点
- **字汇格点击**：点击字符替换巨字
- **滚轮**：鼠标在左轴区域内滚轮可切字重

### 无障碍

- 键盘全路径可达
- `prefers-reduced-motion` 全面降级（所有动画 0.01ms）
- 触摸设备支持轴柄拖动
- 输入框聚焦时光标变矩形提示

## 七、图形元素

### 品牌印记

左上角「铸造印记」由方块 + 文字标签组成，三行透明度递减（1 / 0.5 / 0.2），模拟活字印刷的深浅层次。

### 校样格底纹

全屏径向渐隐的 80px 网格线（1px 发丝线），仅在中央区域可见，模拟字体设计校样稿的坐标纸。

### 自定义光标

- 内点：6px 实色圆，`mix-blend-mode: difference` 高对比
- 外环：28px 发丝线圆，缓动跟随（lerp 0.18）
- Hover 态：环放大至 44px + 砖红色
- 输入态：环变 56px 方形圆角
- 拖动态：环放大至 60px + 半透明实心

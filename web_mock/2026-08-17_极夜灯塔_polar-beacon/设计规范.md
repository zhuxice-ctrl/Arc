# 设计规范 · 极夜灯塔 Polar Beacon

> 方向：网页设计（V1） · 日期：2026-08-17 · 主题：北欧灯塔档案馆官网

## 色彩系统

| 角色 | 色值 | 用途 |
|---|---|---|
| 深夜墨黑（背景） | `#0A0F14` | 主背景、页脚深色区 |
| 近黑 | `#111820` / `#1a2430` | 次级面板、卡片底 |
| 雾白（前景） | `#E8EDF2` | 正文、标题 |
| 信号橙（强调） | `#FF5C1F` | 主 CTA、灯束、链接 hover |
| 暖橙 | `#ff7040` / `#ffaa80` | 灯束外晕、渐隐 |
| 冰川青灰 | `#8FB3BC` | 次级文字、分隔线 |
| 灰青 | `#b8c2cc` | 辅助文字 |
| 旧铜金 | `#C9A227` | 数字计数、装饰描边 |
| 暗铜 | `#8a7119` | 铜金阴影 |

## 字体

- 标题展示：`'Cormorant Garamond', serif`（衬线，档案感）
- 正文 UI：`'Inter', -apple-system, sans-serif`
- 数字 / 代码 / 日志：`'IBM Plex Mono', monospace`

## 圆角与层次

- 卡片圆角 12–16px；按钮 8px；标签胶囊形
- 阴影：墨黑多层投影 + 信号橙微光描边（hover 时增强）
- 毛玻璃：导航栏滚动后 `backdrop-filter: blur()` 雾化

## 组件

- 自定义光标：白环 + 信号橙内点 + 多层发光，z-index 最高，点击涟漪
- 灯塔卡片：3D 倾斜（鼠标驱动 transform）+ 径向光点 + 悬停边框发光
- 菲涅尔透镜剖面：滚动驱动旋转 + 呼吸透明度的折射光带
- 守灯人日志：打字机逐字输出 + 光标闪烁 + 条目切换
- 雾笛波形：基频 + 泛音 + 颤音数学模型的可播放频谱
- 历史纪年时间线：左侧竖轴 + 节点脉冲

## 动效系统（15 项，均基于物理/语义模型）

1. 自定义光标三环（惯性外环 + 发光晕 + 信号色内点）
2. 星空粒子（RAF 正弦闪烁、偶发暖星）
3. 灯塔旋转灯束（角度积分、双速双束）
4. 导航栏滚动毛玻璃
5. 滚动渐入（cubic-bezier 缓动）
6. 数字计数（ease-out cubic）
7. 档案卡 3D 倾斜（直接操作 DOM transform）
8. 菲涅尔透镜光带（滚动驱动旋转 + 呼吸透明度）
9. 守灯人日志打字机（随机可变节拍）
10. 雾笛波形频谱（基频+泛音+颤音数学模型，可播放/暂停/跳转）
11. 光程计数器（弹簧物理 + 阻尼）
12. 环境雾气粒子（径向渐变 + 正弦漂移）
13. 磁性按钮（反平方引力 + 缓动趋近）
14. Hero 视差（鼠标驱动多元素错位）
15. 按钮光泽扫过（120° 渐变滑入）

## 页面结构

Hero（旋转灯束 + 标题入场）→ 档案统计（4 项计数）→ 精选灯塔卡片（3 座）→ 菲涅尔透镜剖面 → 守灯人日志 → 雾笛声纹 → 历史纪年时间线 → 页脚四栏导航。

## 健壮性

- `visibilitychange` 自动暂停 RAF；`beforeunload` 统一清理
- 高频 mousemove 直接操作 transform，不触发重渲染
- 全部 CSS/JS 内联单文件，零外部引用
- 支持 `prefers-reduced-motion` 降级

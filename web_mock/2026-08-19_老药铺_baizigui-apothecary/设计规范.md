## 空间模型

垂直柜墙索引：4×3 药性分类格（解表/清热/补益/理气），每格 3×3 抽屉网格共 36 位。12 味真实药材配竖排毛笔体药名 + 黄铜拉手，其余为暗格占位增强真实感。底部固定药戥秤杆。

## 动效系统

| 动效 | 物理模型 | 触发 |
|------|----------|------|
| 抽屉滑出 | CSS transition + cubic-bezier 阻尼 | 拖拽拉手 |
| 抽屉到位微弹 | transform scale 弹簧 | 滑出完成 |
| 药材标本墨迹浮现 | opacity + transform 入场 | 抽屉打开 |
| 药戥秤杆平衡 | CSS transform rotate + transition | 拖入药材 |
| 自定义光标 | requestAnimationFrame 跟随 | mousemove |
| 光标状态切换 | CSS class + transition | hover/drag/grab |

## 自定义光标

- 朱砂红点（6px）+ 米白圆环（24px）
- z-index: 9999（层级最高）
- 三态：默认 → hover-drawer（放大金色环）→ dragging（虚线旋转环）
- 开页居中显示

## 交互流程

1. 拖拽抽屉拉手向下 → 抽屉滑出 → 药材标本与档案呈现
2. 档案面板含完整药性数据 + 「放入药戥」按钮
3. 点击放入药戥 → 底部秤杆倾斜平衡 → 总重量显示（单位：钱）
4. 寒温并用/过量/药味过多 → 朱砂配伍警示浮现
5. 点击药盘药材 → 移除

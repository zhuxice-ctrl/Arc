# 设计规范 · 打铁花 · 城墙花谱

> 主题：确山打铁花（国家级非物质文化遗产）｜ 类型：仪式型体验 + 工艺档案（Experimental + Content）
> 空间模型：wall_face_canvas_stage（墙面画布舞台）｜ 日期：2026-08-20

## 一、Design DNA

**核心概念**：用户扮演打铁花艺人，在古城墙前击打铁水；每一次击打都是真实物理的火花迸溅，并在墙面上留下不可逆灼痕，多次累积烧成一幅只属于自己的「火花壁画」。先操作、后阅读——开屏即舞台，10 秒内完成第一次击打并看到墙面被永久改变。

**视觉来源**：夜晚城墙前的打铁花实景——熔炉、柳木花棒、赤膊艺人、铁水撞墙溅落如星雨。一切视觉语言来自「热」与「力」。

**空间逻辑**：首屏是占满视口的城墙舞台（Canvas 绘制砖墙/垛口/夜空），下方铁水槽与花棒操作区，右缘窄条温度标尺；向下滚动进入「花谱志」编辑式连续档案；尾声「退火收工」回到舞台执行收工仪式。

## 二、色彩系统（铁温度色阶，禁蓝紫渐变）

所有强调色都来自铁的温度色阶，承担层级/状态/氛围语义，无装饰性配色。

| 角色 | 色值 | 用途 |
|------|------|------|
| 夜黑底 | `#0a0806` | 页面/舞台背景，夜空 |
| 城墙砖土深 | `#1a120a` / `#3d2d1e` / `#6b4a2a` | 砖墙明暗交错 |
| 砖缝灰土 | `#c8bdae` / `#d8cfc2` | 次级文字、砖缝 |
| 米黄砖面 | `#e8d9bd` | 主文字、亮砖 |
| 白炽铁水 | `#fff4c4` / `#fff` | 铁水最高温、灼痕中心 |
| 金橙流动 | `#ffc880` / `#ffb060` | 1320°C 档、蓄力槽、强调 |
| 橙红初熔 | `#ff9a3c` / `#ff8c3c` | 火花中段、温度标尺 |
| 赤红将熔 | `#d64a1a` | 火花末段、警示 |
| 暗红余烬 | `#8b1a0a` | 低温档、冷却铁星 |
| 朱红落款 | `#d64a1a` 系 | 收工花谱印章 |

铁温度色阶（火花冷却曲线）：白炽 `#fff4c4` → 金橙 `#ffc880` → 橙红 `#ff9a3c` → 赤红 `#d64a1a` → 暗红 `#8b1a0a` → 熄灭。

## 三、字体系统

- 主字体：`"PingFang SC", "Microsoft YaHei", "STKaiti", "KaiTi", serif`——中文衬线/楷意，贴合传统工艺语境。
- 标题「打铁花」大字 + 副标题「一夜千树」竖排小字，化用「东风夜放花千树」。
- 数字（击打数/温度/花谱编号）使用同字体 tabular 感，与文案形成字级跨度。
- 无外部字体加载，全部系统字体，零外部依赖。

## 四、动效系统（≥12 个组件级特效，全部围绕热与力）

| # | 特效 | 物理逻辑 |
|---|------|----------|
| 1 | 火花弹道 | 初速 + 重力 + 空气阻力，蓄力决定规模 |
| 2 | 火花冷却色变 | 温度随时间衰减，色阶白炽→橙→红→熄 |
| 3 | 撞墙迸裂 | 火星撞墙二次溅射，速度反射 |
| 4 | 灼痕累积 | burnCanvas 不可逆叠加，墙面即画布 |
| 5 | 余温呼吸 | 墙面灼痕处明暗缓慢呼吸 |
| 6 | 蓄力脉动 | 花棒后拉 + 铁水槽升温发光 + 光标灼热脉动 |
| 7 | 熔光涌动 | 铁水槽表面流动光斑 |
| 8 | 击打震屏 | 挥板瞬间轻微 screen shake |
| 9 | 温度标尺联动 | 蓄力时右缘标尺上升，拖动档案标尺切换五档铁色 |
| 10 | 花棒后拉 | 蓄力时 stickCanvas 花棒向后倾斜 |
| 11 | 收工暗场 | 场灯渐暗，灼痕整体显影 |
| 12 | 花谱卡显影 | 花谱卡带编号 + 朱红落款印淡入 |
| 13 | 自定义光标 | 白炽烙铁点，蓄力时 pulse-heat 脉动 |

动效语言：一切运动来自热与力。禁止与热无关的特效（粒子漂浮、光晕装饰、Ken Burns）。

## 五、交互系统

- **核心交互**：在铁水槽区按住（鼠标/触摸）蓄力 → 花棒后拉、铁水升温、温度标尺上升、光标灼热脉动；松开挥板击打 → 一蓬铁水向上飞出撞墙迸溅。蓄力时长决定初速与火花规模。
- **灼痕累积**：每次击打在墙面留下不可逆痕迹，可连续击打。
- **退火收工**：场灯渐暗，灼痕整体显影，生成「今夜花谱」卡（编号 = 日期+击打数、击打数、火花数、朱红落款印），「再打一场」重置。
- **花谱志档案**：花棚与仪式 / 花棒解剖（「展开剖面」可展开）/ 温度色阶（拖动标尺看五档铁色状态）/ 艺人规矩四条 / 传承。
- **自定义光标**：`position:fixed; top:50%; left:50%` 开页即居中，z-index 9999 最高，白炽 radial-gradient + glow，`mix-blend-mode:screen` 高对比；hover 可交互元素时放大，蓄力时 pulse-heat 脉动。

## 六、健壮性红线

- 纯 vanilla 单文件（HTML+CSS+JS），无 React/Babel/CDN/外部图片/外部字体。
- 零未定义引用（`clamp` 等工具函数已定义）。
- RAF/定时器随 `visibilitychange` 暂停，卸载清理。
- 快速连续击打破旧定时器，不叠加。
- 高频鼠标事件直接操作 DOM（cursor），不触发框架重渲染。
- `prefers-reduced-motion`：火花/脉动降级为静态灼痕淡入，光标脉动关闭。
- 触摸兼容（touchstart/touchmove/touchend）。
- 响应式：1440 / 1024 / 768 / 390 均无横向溢出。

## 七、内容真实性

确山打铁花真实知识（非 Lorem Ipsum）：
- 河南确山流传的民间焰火技艺，2008 年入选国家级非物质文化遗产扩展名录，北宋已有记载，明清时盛。
- 生铁熔点约 1538°C，击打时铁水约 1600°C；火花离棒即冷却，落地前已降温。
- 花棚：柳木搭三层棚架，棚顶铺新鲜柳枝，铁花打上棚顶溅落如瀑。
- 花棒：新鲜柳木浸水制成，上棒「舀棒」端有凹坑盛铁水，下棒「打棒」平直有力。
- 艺人规矩：赤膊上阵、击打要准而脆、力道忌拖泥带水、逆风不打。

## 八、自评（Designer 视觉审计）

- 删动画是否成立：是——城墙舞台、灼痕、档案在静态下层级仍成立。
- 灰度下层级是否成立：是——靠砖墙明暗、字级跨度、留白建立层级，不依赖颜色。
- 轮廓是否与近期重复：否——「墙面画布舞台」在 51 条历史 web 指纹中无先例。

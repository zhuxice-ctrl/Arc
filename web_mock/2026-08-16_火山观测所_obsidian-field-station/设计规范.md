## 色彩系统

玄武炭黑底色 + 熔岩橙强调 + 火山灰米前景 + 铜金点缀，暗调暖色地质科学氛围。

|---|---|---|
| 玄武炭黑（底） | `#1A1510` | 页面主背景 |

| 火山灰米（前景） | `#EDE5D8` | 主文字、卡片表面 |

## 字体

通过 CSS 变量统一管理：

- `--font-display`：标题展示字（衬线/地质感）
- `--font-body`：正文
- `--font-mono`：数据/编号等宽

## 圆角与层级

- 卡片圆角 12–18px，按钮 8–10px
- 阴影分层：深底卡片用内发光 + 外投影制造前后景；熔岩元素加多层 box-shadow 发光

## 组件规范

- **自定义光标**：白色粗环 + 熔岩橙内点 + 多层发光，z-index 最高；悬停可交互元素放大变色，点击涟漪
- **地震波形仪**：Canvas 实时绘制，多频率正弦叠加 + 随机微震 spike，RMS 震级计算
- **倾斜仪气泡**：弹簧阻尼 + 鼠标磁吸引
- **气体频谱柱**：正弦振荡 + 噪声扰动，每柱周期不同
- **火山灰粒子场**：重力沉降 + 横向风力 + 正弦摆动，四档强度切换（Calm → Eruption Plume）
- **时间线**：交替左右布局，滚动渐入
- **数据卡片**：3D 倾斜 + 磁性反平方引力 + 光泽扫过

## 健壮性

- `visibilitychange` 自动暂停所有 RAF 循环
- 所有 RAF/setTimeout 统一注册表，卸载清理
- 鼠标驱动倾斜/视差直接操作 DOM transform，不走 React setState
- 支持 `prefers-reduced-motion`（降级静态、隐藏自定义光标）
- 全 JSX 内联于 `index.html`，无外部 JSX src

## 页面结构

Hero 火山景观视差 → 实时数据跑马灯 → Live Monitoring（波形仪/倾斜仪/频谱/指标卡）→ Eruption Archive 时间线 → Ash Dispersion Lab 粒子场 → Field Logs 观测员日志 → Rock Specimens 岩石标本 → Footer + CTA

## 技术栈

React 18 + Babel Standalone（CDN），单 HTML 文件，JSX 全内联，Canvas 2D 绘制。

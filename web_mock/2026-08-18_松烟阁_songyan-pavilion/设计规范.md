# 松烟阁 · 设计规范

## 色彩系统

以宣纸、松烟墨、朱砂印为美学基调的暖土色系，零蓝紫渐变。

| 角色 | 色值 | 用途 |
|------|------|------|
| 宣纸米白 | `#F3EBD9` | 页面主底色 |
| 绢黄浅底 | `#FAF4E5` | 卡片/区块浅底 |
| 米灰过渡 | `#E8DDC4` | 分隔、次级表面 |
| 墨烟黑 | `#1A1612` | 正文、深色区块 |
| 朱砂红 | `#B23A28` | 主强调色（印章、CTA、光标内点） |
| 深朱砂 | `#8C2A1A` | 强调色暗部 |
| 赭石橙 | `#C47A3A` | 辅助强调、粒子 |
| 绢金 | `#D4A574` / `#D9C89A` | 装饰线、描边 |
| 茶褐 | `#A67C52` / `#8B7355` | 次级文字、图标 |

## 字体

- 标题/书法字：`"Ma Shan Zheng", cursive`（毛笔行书，用于主标题与巨型背景汉字）
- 正文/衬线：`"Noto Serif SC", "Songti SC", serif`
- 点缀标题：`"ZCOOL XiaoWei", serif`

## 动效系统（14 个组件级特效）

1. 自定义光标：白色粗环 + 朱砂内点 + 多层发光，开页即居中，悬停放大变色，点击涟漪
2. 墨粒粒子系统：45 颗墨/赭石/朱砂粒子布朗运动缓漂，独立相位与呼吸周期
3. 标题逐字揭示：「松烟阁藏」错落渐入 + 模糊消散
4. 印章盖下动效：朱砂印弹簧回弹盖章
5. 打字机副标题：随机速度逐字打出
6. 卡片 3D 倾斜：RAF 阻尼积分，直接操作 DOM transform
7. 修复师头像脉冲环：错相位扩散
8. 数字计数：easeOutCubic，进入视口触发
9. 滚动渐入：IntersectionObserver 错落揭示
10. 视差装饰：巨型背景汉字反向位移
11. 光泽扫过：珍品卡片 hover 斜向光带
12. 磁性按钮：反平方引力微位移
13. 导航毛玻璃：滚动后模糊 + 底边渐变
14. 按钮形态切换：主按钮填充延展、次按钮描边变色

## 健壮性

- visibilitychange 自动暂停动画，卸载统一清理
- prefers-reduced-motion 降级为静态/最小动效
- JSX 全内联于 index.html，无外部 fetch
- 移动端隐藏自定义光标，响应式单列布局

## 页面结构

单页艺术展官网：Hero（书法标题 + 打字机副标 + 磁性 CTA）→ 六道修复工序卡片（3D 倾斜）→ 珍品展示（光泽扫过）→ 修复师团队（头像脉冲）→ 数据统计（数字计数）→ 预约/参观 CTA → 页脚。

# 雾岭气象台 · 设计规范

> 方向：V1 网页设计 · 日期：2026-08-18
> 主题：海拔 2400 米山间气象观测站官方网站（单页艺术品级完整网站）

## 色彩系统

| 角色 | 色值 | 用途 |
|---|---|---|
| 深岩灰 | `#23272E` | 页面主底色 |
| 岩黑 | `#1A1D22` | 深层背景 / 页脚 |
| 岩面 | `#2D323A` | 卡片 / 分区表面 |
| 雾白 | `#F2EFE9` | 主文字 / 浅色卡片 |
| 信号橙 | `#FF5C00` | 强调色：按钮、数据高亮、光标内点 |
| 浅橙 | `#FF8A3D` | 强调色辅助 / 悬停态 |
| 冻湖青 | `#3FA7A0` | 辅助色：图表、指示、次要强调 |
| 浅青 | `#63C4BC` | 辅助色浅阶 |
| 石灰 | `#A8A398` | 次要文字 / 说明 |
| 雾灰 | `#D8D4CC` | 分隔线 / 弱文字 |

禁止使用蓝紫渐变。整体为「深岩灰底 + 雾白 + 信号橙 + 冻湖青」的冷调高山色系。

## 字体

- 展示标题：`Noto Serif SC, serif`（衬线，用于大标题与叙事段落）
- 正文 UI：`Noto Sans SC, -apple-system, BlinkMacSystemFont, sans-serif`
- 数据 / 编号：`JetBrains Mono, monospace`（观测数值、海拔、频率等）

## 圆角与形态

- 卡片圆角：4px（小）/ 2px（紧凑标签）
- 圆形元素：`border-radius: 50%`（指示灯、光标、风速杯）
- 整体语言偏硬朗、仪器感，圆角克制

## 页面结构（单页六板块）

1. **英雄区**：全屏山景 + canvas 风场流线 + 三层云雾漂移 + 打字机副标题
2. **实时观测数据**：气温 / 湿度 / 风速 / 气压 / 能见度五张数据卡（数字滚动 + 迷你趋势图）
3. **值守纪事**：观测站历史与值守人故事、里程碑计数
4. **四季山景画廊**：春夏秋冬 Tab 切换 + 季节数据
5. **登山安全指引**：浓雾 / 雷雨 / 大风三张守则卡
6. **访客预约**：预约表单（提交成功动画）+ 页脚信息

## 动效系统（15 项组件级特效）

| 动效 | 模型 / 语义 |
|---|---|
| 自定义光标（白环+橙点+发光，悬停放大，点击涟漪，惯性跟随） | RAF 惯性跟随 |

## 健壮性

- `visibilitychange` 自动暂停所有 RAF 循环，`beforeunload` 统一清理
- 定时器统一经 safeSetTimeout / safeRequestAnimationFrame 管理，重建前先清旧
- 高频 mousemove 直接操作 DOM transform，不触发框架重渲染
- 完整 `prefers-reduced-motion` 降级（动画关闭、光标隐藏、静态展示）
- 响应式布局，移动端自动隐藏自定义光标

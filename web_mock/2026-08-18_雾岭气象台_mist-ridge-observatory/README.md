# 雾岭气象台 Mist Ridge Observatory

> 方向：V1 网页设计 · 日期：2026-08-18
> 主题：海拔 2400 米山间气象观测站官方网站

## 简介

「雾岭气象台」是一座山间气象观测站的官网单页，真实可交互的完整网站：英雄区风场流线与云雾、实时观测数据卡（数字滚动 + 趋势图）、值守纪事、四季山景画廊、登山安全指引、访客预约表单。深岩灰 + 雾白 + 信号橙 + 冻湖青的高山仪器色系，衬线展示字体搭配等宽数据字体，15 项基于物理 / 语义模型的组件级动效。

## 动效亮点

- 自定义光标开页即居中显示：白色粗环 + 信号橙内点 + 多层发光，悬停放大、点击涟漪
- Canvas 风场流线粒子（80 条流线带正弦紊动）与三层错峰漂移云雾
- 风速杯惯性旋转、气压表弹簧指针、数字滚动计数、3D 卡片阻尼倾斜
- Hero 视差 + 滚动渐入 + 打字机副标题 + 导航收缩

# 羽翼航线 Flyway Atlas · 设计规范

## 设计母题
夜间航空航海图——8 条真实候鸟迁徙航线铺在世界地图上，用户像夜航调度员俯瞰全球迁徙网络，点选航线进入「伴飞」，镜头沿真实路径飞行、停歇点逐个点亮。

## 色彩系统（自源码提取）
| 用途 | 色值 | 说明 |
| --- | --- | --- |
| 主底 | `#0E1832` | 深靛夜空（扁平色，无渐变） |
| 深空暗角 | `#080E1F` | 最深层夜空 |
| 大陆轮廓描边 | `#2A3A5C` | 比底色略亮的陆地边界 |
| 文字 / 陆地 | `#C9D2E0` | 星银 |
| 次级文字 | `#5B6478` | 暗银灰 |
| 航线 / 强调 | `#E8B34B` | 烛金 |
| 起点高亮 | `#F0C76B` | 亮金 |
| 物种辅助 | `#E8914B` `#E85A4B` `#7EC8A4` | 琥珀 / 朱 / 青绿点缀 |

禁任何蓝→紫渐变；全部扁平色。

## 字体系统
- 标题：`Cormorant Garamond` + `Noto Serif SC`（serif）
- 正文：`Noto Sans SC`（sans）
- 数字 / 数据：`JetBrains Mono`（等宽）

## 空间模型
- 全屏 SVG 世界地图为唯一主导航，航线即目录，无传统顶部导航栏。
- 右侧（桌面）/ 底部抽屉（移动）为「航线索引」：8 物种按钮，悬停联动地图高亮。
- 手绘简化大陆轮廓（示意性非精确地图），CSS 生成星点呼吸。

## 动效系统（≥12，符合物理/主题逻辑）
星点呼吸闪烁 · 航线流光呼吸 · 航线悬停加粗高亮 · 点击航线镜头平滑 pan+zoom · 停歇点逐个点亮+光晕扩散 · 飞行进度点沿路径运动 · 数据卡段落淡入滑入 · 结算数字滚动计数 · 自定义十字准星光标跟随+伴飞变烛金 · 索引-地图联动高亮 · 返回全景镜头回退 · 星点鼠标轻微视差。

## 核心交互：伴飞模式
点选航线 → 镜头沿路径平滑推进、飞行进度点沿路径移动 → 停歇点顺序点亮、数据卡同步翻页 → 抵达越冬地结算「总里程 / 天数 / 体重变化」。滚轮缩放、拖拽平移（全景态）。切换航线先清上一个飞行定时器。

## 自定义光标
细十字准星 + 外环（星银），开页居中、高对比、z-index 最高；伴飞时外环变烛金；prefers-reduced-motion 降级系统光标。

## 健壮性
RAF 随 `document.hidden` 暂停/续跑、卸载取消；快速切航线不叠加定时器；光标/视差直接操作 transform；支持 prefers-reduced-motion；响应式 1440/1024/768/390，移动端索引改底部抽屉；零 console error。

# Rooftop Harvest 屋顶农场 · 设计规范

> 方向：V1 网页设计 ｜ 日期：2026-08-17 ｜ 类型：城市屋顶农园品牌官网（单页艺术品级站点）

## 色彩系统

| 角色 | 色值 | 说明 |
|---|---|---|
| 主色 · 罗勒绿 | `#4A7C4A` | 品牌主色，导航强调、按钮、图标 |
| 深绿 · 藤蔓 | `#3A6339` / `#6BA36A` | 绿色阶两端，描边与hover态 |
| 强调 · 番茄红 | `#D64532` / `#B53624` / `#E8745F` | 三阶红色阶：主强调 / 深压 / 浅亮 |
| 点缀 · 向日葵黄 | `#E8B23A` | 徽章、评分、数字计数高亮 |
| 表面 · 麦乳白 | `#F5F0E6` / `#E8E0D0` / `#E8DCC4` | 页面底色与卡片表面三阶 |
| 中性 · 炭灰 | `#2A2A28` / `#4A4A48` | 正文与次级文字 |
| 反白 | `#FFFFFF` | 深色区文字、光标粗环 |

## 字体

- 展示标题：`'DM Serif Display', serif`（衬线，质朴精致）
- 正文/UI：`'Inter', -apple-system, BlinkMacSystemFont, sans-serif`
- 数据/标签：`'DM Mono', monospace`

## 圆角与形态

- 胶囊/圆形元素：`50%`（11 处，头像、徽章、按钮）
- 大卡片：`50px` 超圆角（8 处，有机感）
- 常规卡片：`16px` / `20px`；小控件：`10px` / `12px`

## 组件规范

- 导航栏：滚动时由透明变紧凑实底（RAF 节流）
- 作物卡片：Tab 三组切换（蔬菜/香草/花卉），悬停 3D 倾斜 + 斜向光泽扫过
- 市集区块：深色反白（炭灰底）与全站浅底形成节奏对比
- 预约表单：体验类型三选 + 完整表单 + 提交成功态

## 动效系统（13 个组件级特效）

1. 自定义光标：白色粗环 + 番茄红内点 + 多层发光，开页即居中，悬停放大、点击涟漪
2. 飘落叶片粒子（正弦摆动 + 旋转 + 循环生成，Canvas）
3. 打字机标题（四组词轮播）
4. 数字计数（2800㎡ / 47+ 品种 / 12 位农夫，easeOutCubic）
5. 3D 卡片倾斜（mousemove 直操作 DOM transform）
6. 光泽扫过（作物卡片 hover 斜向高光）
7. 叶片轻摆（悬停 sway）
8. 藤蔓生长描边（IntersectionObserver 触发 SVG dashoffset）
9. 滚动渐入 reveal
10. 浮动徽章（上下浮动 + 主图旋转）
11. 阳光射线缓慢旋转（60s/圈装饰 SVG）
12. 头像脉冲光环
13. 导航滚动紧凑化

## 页面结构（7 区块）

Hero（打字机+计数+浮动图）→ 农园故事（双图错落+藤蔓描边）→ 当季作物（Tab 9 款真实作物）→ 周末市集（深色反白，4 场活动+6 摊位）→ 农夫团队（3 位+头像脉冲）→ 预约体验（表单全流程）→ 页脚

## 健壮性

visibilitychange 暂停动画、prefers-reduced-motion 降级、RAF/定时器统一清理、JSX 全内联无外部 src。

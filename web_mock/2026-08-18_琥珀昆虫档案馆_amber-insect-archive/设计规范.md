# 琥珀昆虫档案馆 · 设计规范

## 色彩系统

| 角色 | 色值 | 用途 |
|---|---|---|
| 主色·琥珀金 | #D4A02A | 标题强调、光标内点、琥珀光泽 |
| 蜜糖橙 | #E8852A | 辅助强调、按钮渐变 |
| 松脂绿 | #4A6B3A | 次要强调、自然元素 |
| 深背景·墨褐 | #2B1A0E | 页面主背景 |
| 更深 | #1a0f08 | Hero 渐变底、卡片底 |
| 暖棕 | #6b3d1a | 边框、分隔 |
| 羊皮纸米 | #F5E6C8 | 卡片表面、次背景 |
| 暖灰 | #8B7355 | 次要文字、标签 |
| 暖白 | #FFF8E7 | 主文字 |

配色策略：墨褐深底托起琥珀金光泽，营造博物馆夜间展厅的神秘庄重感；羊皮纸米用于内容卡片形成前后景层次。禁止蓝紫渐变。

## 字体

- 正文：'Noto Sans SC', 'PingFang SC', 'Microsoft YaHei', sans-serif
- 标题/衬线：'Noto Serif SC', serif（用于馆名、章节大标题，赋予古典博物馆气质）

## 组件

- 自定义光标：白色粗环 + 琥珀金内点 + 多层发光，z-index 最高，悬停可交互元素放大变形，点击涟漪
- 标本卡片：琥珀金描边 + 悬停发光 + 光泽扫过 + 图片缩放 + 点击弹出详情 Modal
- 时间轴：左右交替地质年代节点，滚动驱动渐入
- 数字计数：easeOutCubic 计数动画
- 导航栏：滚动收缩 + 毛玻璃

## 动效系统（12+）

1. 自定义光标（三态切换 + 点击涟漪）
2. 琥珀粒子系统（Canvas 上升闪烁光晕）
3. Hero 琥珀石光晕脉冲
4. 三颗流动光团视差漂浮（鼠标驱动）
5. Hero 文字入场渐入序列
6. 标本卡片悬停发光 + 光泽扫过 + 图片缩放
7. 标本详情 Modal 缩放展开
8. 时间轴滚动渐入（左右交替滑入）
9. 数字计数动画
10. 滚动渐入（IntersectionObserver 分级延迟）
11. 导航栏滚动收缩 + 毛玻璃
12. Hero 标题滚动视差位移
13. 树脂滴落 / 按钮光泽扫过微交互

物理模型：光团漂浮基于鼠标视差位移；粒子基于上升速度 + 闪烁衰减；计数基于 easeOutCubic 缓动。RAF 随 visibilitychange 暂停、卸载取消；高频鼠标事件直接操作 DOM transform；支持 prefers-reduced-motion。

## 页面结构（单页滚动）

1. Hero 首屏：馆名 + 副标题 + 琥珀光泽流动背景 + 入场动画
2. 标本图鉴：8 件琥珀昆虫标本卡片网格，悬停发光、点击弹详情
3. 地质年代时间轴：6 时期左右交替，滚动驱动
4. 数字统计：馆藏/年代/物种/论文 4 组计数
5. 科研故事：特稿大图 + 3 篇故事卡
6. 参观信息：开放时间/地址/门票三卡片
7. 页脚 + 回到顶部

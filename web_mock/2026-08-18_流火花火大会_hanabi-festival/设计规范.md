# 流火花火大会 · 设计规范

> 日期：2026-08-18 · 方向：V1 网页设计 · 主题：夏日河畔花火大会活动官网

## 色彩系统

以深夜黑为底，朱红 + 鎏金 + 暖白点缀，呼应花火升空爆裂的暖色语义。禁蓝紫渐变。

| 令牌 | 色值 | 用途 |
|---|---|---|
| `--vermilion` | `#c23a2a` | 朱红主色（花火主视觉） |
| `--vermilion-light` | `#e8593d` | 朱红亮调（高亮/悬停） |
| `--vermilion-deep` | `#8f2618` | 朱红深调（压暗/阴影） |
| `--gold` | `#d4a24c` | 鎏金主色（点缀/描边） |
| `--gold-light` | `#f0c878` | 鎏金亮调（光泽扫过） |
| `--gold-deep` | `#9c7428` | 鎏金深调 |
| `--ember` | `#ff8c3a` | 余烬橙（粒子/火星） |
| `--warm-white` | `#f5ebe0` | 暖白正文 |
| `--warm-gray` | `#b8a99a` | 暖灰辅助 |
| `--warm-dim` | `#6b5d52` | 暖灰暗调 |
| 夜空底 | `#0a0708` / `#120c0f` / `#1a1216` / `#24181d` / `#2a1f24` | 多层夜黑背景 |

## 字体排印

- 展示字 `--font-display`：`"Noto Serif SC", "Songti SC", "SimSun", serif`（标题/品牌）
- 正文 `--font-body`：`"Noto Sans SC", "PingFang SC", "Microsoft YaHei", sans-serif`
- 等宽 `--font-mono`：`"JetBrains Mono", "SF Mono", monospace`（数字/时间轴）

## 圆角

`1px / 2px / 4px / 50%`，整体偏方正锐利，仅粒子与圆形元素用 50%。

## 动效系统

基于物理模型（重力 + 空气阻力的花火粒子积分器）与主题语义（火星余烬飘落、涟漪扩散、灯笼 sin 摇摆）。缓动：

- `--ease-spring: cubic-bezier(0.34, 1.56, 0.64, 1)`（弹性回弹）
- `--ease-out-expo: cubic-bezier(0.16, 1, 0.3, 1)`（急停缓出）

组件级特效 15+：自定义光标（白环+朱红内点+发光层+三态+涟漪）、Canvas 花火粒子、余烬飘浮、打字机、数字计数、3D 卡片倾斜（damping 插值）、磁性按钮、滚动渐入、Hero 视差、双卡视差、灯笼摆动、导航滚动收缩、按钮光泽扫过、跑马灯、地图标记脉冲、品牌徽标呼吸。各动效周期互不相同。

## 页面结构（7 大区块）

1. Hero 开场（大标题 + Canvas 花火 + 余烬 + 打字机副标题）
2. 大会简介（百年叙事 + 4 项数字计数 + 视差双卡）
3. 花火节目单（三档切换 + 6 段时间轴）
4. 会场交通（SVG 手绘地图 + 可点击标记 + 交通卡）
5. 观赏席票务（3 档票价卡 + 3D 倾斜）
6. 夜市屋台（8 家屋台卡 + 摇曳灯笼）
7. 历史回顾画廊（6 届横向滚动）

## 健壮性

纯 vanilla HTML/CSS/JS 单文件，无外部依赖；`prefers-reduced-motion` 全量降级；`visibilitychange` 暂停花火动画；`beforeunload` 清理全部 RAF/定时器；高频 mousemove 直接操作 transform。

## 技术栈

HTML5 + Canvas 2D + 原生 JS（IntersectionObserver / requestAnimationFrame）。

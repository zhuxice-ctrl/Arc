## 字体

- 主字体：`"PingFang SC", "Microsoft YaHei", "Noto Sans SC", sans-serif`
- 字重层次：300 / 400 / 600 / 700 / 900

## 组件规范

- **卡片**：圆角 12-20px，底部 1px 半透明边框，hover 3D 倾斜 + 光泽扫过
- **按钮**：主按钮珊瑚红底白字圆角 8px，次要按钮透明底沙金边框
- **导航栏**：顶部固定，滚动后收缩 + 毛玻璃 backdrop-blur
- **时间线**：SVG 波浪曲线 + 脉冲标记点
- **自定义光标**：白色粗环 + 珊瑚红内点 + 多层发光，z-index 最高

## 页面结构

1. **Hero 沉浸区** — 海浪画布 + 粒子 + 潮汐实时数据 + 逐字标题
2. **潮汐时间线** — SVG 波浪曲线 + 高低潮标记
3. **演出排期表** — 7 天切换，标注潮汐状态
4. **剧目卡片** — 3D 磁悬浮 + 光泽扫过
5. **剧场介绍** — 层叠图片 + 数字计数
6. **艺术家阵容** — 头像脉冲 + 悬停放大
7. **票务信息** — 三档票卡 + 购票反馈
8. **页脚**

## 技术栈

- 纯 vanilla HTML/CSS/JS 单文件
- 零外部 CDN 依赖
- Canvas 2D 渲染海浪与粒子
- SVG 路径动画
- IntersectionObserver 滚动监听
- visibilitychange 暂停 / prefers-reduced-motion 降级

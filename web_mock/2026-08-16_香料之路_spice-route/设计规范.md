# 香料之路 The Spice Route · 设计规范

- 方向：V1 网页设计 · 日期：2026-08-16
- 形态：单页滚动叙事互动杂志网站（艺术品级单页）
- 主题：从马拉巴尔海岸到泉州港的香料贸易之旅

## 色彩系统

| 角色 | 色值 | 用途 |
|---|---|---|
| 主色·藏红花橙 | #E8590C | 强调按钮、航线、标题点缀 |
| 深棕·肉桂 | #6B3F23 | 正文、深色背景区块 |
| 表面色·豆蔻奶白 | #FAF3E3 | 纸面底色、卡片表面 |
| 辅助·姜黄金 | #E9B44C | 高光、色轮、数字 |
| 墨黑·胡椒 | #20180F | 极深文字、页脚 |
| 焦橙 | #C74A08 | 藏红花橙阴影态 |
| 暖米 | #EFE4CC | 次级表面 |
| 铜棕 | #B87333 / #A0522D | 边框、分隔 |

整体为暖色纸感杂志风，无蓝紫渐变。

## 字体

- 标题（display）：`'Cormorant Garamond', 'Times New Roman', serif`
- 正文（body）：`'Source Serif 4', Georgia, serif`

## 组件规范

- 香料卡片：圆角 18px，纸面阴影分层，悬停 3D 倾斜 + 光泽扫过；点击展开详情模态窗
- 贸易航线 SVG：滚动驱动 stroke 绘制，港口节点脉冲标记
- 气味色轮：8 段圆环，可拖拽旋转 + 惯性阻尼 + 自动缓转
- 模态窗：弹簧入场（cubic-bezier 弹簧）
- 自定义光标：白环 + 藏橙内点 + 三层发光，悬停三态变形，点击涟漪

## 动效系统（≥12 组件级特效）

1. 自定义光标（白环+藏橙内点+三层发光+悬停变形+点击涟漪）
2. 打字机副标题
3. Hero 标题光泽扫过
4. 地图视差（滚动驱动）
5. 港口脉冲标记
6. 罗盘摆动（惯性）
7. 香料卡片 3D 倾斜 + 光泽扫过
8. 滚动渐入（错开延迟）
9. SVG 航线滚动绘制 + 商船沿路径行进
10. 可拖拽色轮（惯性阻尼 + 自动缓转）
11. 数字计数（easeOutCubic）
12. 漂浮香料粒子（正弦摆动）
13. 纸纹颗粒
14. 模态窗弹簧入场

物理模型：阻尼/惯性/弹簧/正弦摆动；无整图缩放/Ken Burns。动效周期各不相同。

## 页面结构

Hero（航线地图入场）→ Compendium 香料图鉴（8 种真实香料）→ Trade Route 贸易航线（6 港口）→ Color Wheel 气味色轮 → Numbers 数字轶事 → Epilogue 结语。

## 技术栈

React 18 + Babel standalone（JSX 全内联于 `<script type="text/babel">`，CSS 内联于 `<style>`），原生 RAF 动效，无外部组件库。支持 visibilitychange 自动暂停、prefers-reduced-motion 降级。

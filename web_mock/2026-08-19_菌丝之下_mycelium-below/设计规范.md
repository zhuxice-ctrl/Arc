# 菌丝之下 · 设计规范

## 主题与设计母题
云南雨季野生菌垂直剖面 editorial 网站。设计母题=「连续垂直剖面」——整页是一张不断裂的森林纵切长卷，滚动即从雨林冠层下潜至地下菌丝网络。菌子只是地下网络的果实，空间模型与题材合一。

## 空间模型
连续垂直剖面（无 section 断点、无卡片网格、无传统 Hero）。阅读节奏：冠层（密·雨）→ 树干（过渡）→ 地表落叶层（菌物密集·主内容）→ 腐殖层 → 地下菌丝网络（高潮·荧光）。左侧贯穿深度标尺（海拔 2100m → 深度 -1.2m），右侧层位索引（冠层/树干/地表/腐殖/菌丝）跟随滚动高亮、可点击跳转。

## 色彩体系（从源码提取）
| 角色 | 色值 | 用途 |
|---|---|---|
| 墨绿冠层 | #1E2B1F | 顶部雨林背景 |
| 林绿 | #2D3F2A / #3A4E35 / #33472F | 冠层叶片层次 |
| 腐殖棕 | #4A3A28 / #5A3A1A | 地表/腐殖层 |
| 深炭土 | #2D2418 | 地下层背景 |
| 暖白文字 | #F5ECD8 / #F2EDE4 / #F0E8D8 | 正文与「宜食」标记 |
| 菌盖橙红 | #E88A7C | 菌物点缀 |
| 朱红 | 见可食性标记 | 「慎食」语义警示 |
| 荧光菌丝绿 | #C8F04B | 地下菌丝网络点亮（signature） |

配色随深度由墨绿渐变至深炭，再以荧光绿点亮。严禁蓝紫渐变。

## 字体
- 标题：Georgia, serif（衬线，自然志气质）
- 正文：'Noto Sans SC', -apple-system, sans-serif
- 层位名/古典短注：竖排衬线标注

## 动效系统（≥12 组件级，均符合菌物/雨水物理）
1. 冠层雨滴持续下落（Canvas + RAF，随页面可见性暂停）
2. 三层视差叶丛（远/中/近不同滚动速率）
3. 菌褶孢子缓慢飘散
4. 滚动下潜驱动整体剖面视差
5. 点击菌物 → 识别卡从侧缘滑出
6. 越过地表线色温由绿转暗
7. 地下菌丝网络随滚动逐段点亮（SVG stroke-dashoffset + 荧光节点）
8. 深度标尺数字随滚动实时变化
9. 菌物 hover 弹性摇晃
10. 层位索引当前位置高亮跟随
11. 自定义光标形态随可点对象变化
12. 页尾菌子识别卡收束动效

## 交互记忆点
越过地表线瞬间视觉重心由绿转暗，菌丝荧光网络随继续下潜逐段蔓延亮起——「看不见的网络」被看见。

## 自定义光标
采集小刀/放大镜造型，开页居中、高对比、层级最高；hover 可点对象时光标放大变形，遇文字变 I 形。prefers-reduced-motion 降级为系统光标。

## 技术栈
纯 vanilla 单文件（HTML+CSS+JS），无 React/Babel/CDN，全部 SVG/CSS/Canvas 绘制，零外部图片。RAF/定时器随 visibilitychange 暂停且卸载取消；支持 prefers-reduced-motion。响应式 1440/1024/768/390px。

## 内容真实性
6 种真实云南菌物：鸡枞（7-8 月·白蚁巢共生·宜食·鸡枞油）、松茸（6-9 月·松林·宜食·炭烤/刺身）、美味牛肝菌（6-9 月·宜食·爆炒）、见手青（6-9 月·慎食须熟透）、青头菌（7-9 月·宜食）、干巴菌（7-9 月·宜食·炒饭）。配田野笔记式短文，无 Lorem Ipsum。

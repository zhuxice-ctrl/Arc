# 设计规范 · 日晷博物馆·光影计时器演化展

## 主题
日晷博物馆·光影计时器演化展——一座以光影本身为核心展品的数字博物馆。

## 配色系统（暖陶土铜器色系）
| 用途 | 色值 | 说明 |
|------|------|------|
| 主背景 | #2D241E | 墨褐底色，博物馆暗厅 |
| 赭石金 | #8B6914 | 日晷铜器主色 |
| 铜青绿 | #2E4A3E / #4A7C6B / #6A9C8B | 铜锈青绿，辅助色 |
| 铜橙 | #C65D3A / #8E3E24 | 日落铜光 |
| 米白 | #C9B493 / #BFA884 | 暖白文字 |
| 浅陶 | #AD8E62 / #B08968 | 次级文字 |

零蓝紫渐变。配色从青铜日晷器物的氧化色泽中生长出来。

## 字体系统
- 标题/展示：var(--font-serif)——衬线体，博物馆铭牌气质
- 正文/UI：var(--font-sans)——无衬线，保证阅读清晰度
- 时间刻度：等宽数字

## 空间模型
固定舞台 + 光影滚动叙事。中央固定一座可交互日晷，向下滚动穿越四个演化阶段（赤道式 → 地平式 → 子午晷 → 便携式），舞台背景色调与太阳最大高度角随章节平滑过渡。

## 核心交互
拖动太阳沿半圆形轨迹移动——日晷晷针阴影的方向、长度、宽度、透明度均由太阳高度角和方位角物理计算得出，准确对应十二时辰刻度。这是本站的浏览记忆点。

## 动效系统（17个组件级特效）
1. 太阳拖拽轨迹跟随
2. 晷针阴影实时旋转
3. 影长随太阳高度精确变化
4. 影宽随太阳角度变化
5. 影透明度衰减
6. 章节滚动背景色平滑过渡
7. 十二时辰刻度高亮跟随
8. 百刻制细分刻度
9. 季节赤纬线
10. 太阳轨迹弧线绘制
11. 章节标题入场
12. 日晷底盘旋转入场
13. 滚动视差
14. 自定义光标三态切换
15. 拖拽吸附反馈
16. 章节指示器
17. 页面入场序列

所有动效服务于光影物理与状态反馈，无 Ken Burns 整图缩放。

## 自定义光标
三态光标：默认 / 拖拽 / 文本。差值环跟随，高对比，层级最高。

## 技术栈
纯 vanilla 单文件（HTML + CSS + JS，约 48KB），无 React / Babel / CDN 依赖。支持 prefers-reduced-motion、页面可见性暂停 RAF、卸载清理。

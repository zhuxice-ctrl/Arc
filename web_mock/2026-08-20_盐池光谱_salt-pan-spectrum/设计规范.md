# 设计规范 · 盐池光谱 · 晒盐场

## 主题
海盐晒制（盐田、蒸发、结晶）——以一片可亲手晒盐的盐田为整个网站的空间与交互。

## 设计母题
salt_pan_aerial_evaporation_晒盐场调色盘：俯瞰田埂网格是导航，进入单池后拖动日轨加速蒸发，卤水随浓度从藻绿→黄褐→藻粉→结晶白迁移，越过 25.5°Bé 结晶析出，最后拖木盐耙收盐、露出天空之镜。

## 空间模型
俯瞰田埂网格地图（24 池，4×6，行 A–D / 列 01–06，每池处于真实工序阶段）→ 点击入池进入「池畔剖面」固定舞台（天顶日轨 + 池面 Canvas + 池畔读数）。双层空间，互为索引。

## 色彩系统（蒸发阶段语义色）
| 工序 | 色值 | 含义 |
|------|------|------|
| 纳潮 | `#3a6b52` 深藻绿 | 引入海水 |
| 蒸发 | `#6b7a3a` 黄绿 | 初级浓缩 |
| 调节 | `#8a6a3a` 棕褐 | 中级浓缩 |
| 结晶 | `#b87a5a` 藻粉棕 | 杜氏盐藻 β-胡萝卜素显色 |
| 收盐 | `#f0e8c8` 米白 | 盐析出完成 |

基底：`#f2ede0` 米纸底 / `#3a2e1a` 墨棕字 / `#a89563` 田埂边线 / `#7a4a20` 深棕 / `#f0d98a` 日光金。日光为 `rgba(255,240,150,0.3~0.4)` 暖光。整体低饱和复古米黄，与近期深色琥珀系彻底错开，无蓝紫渐变。

## 字体逻辑
- 宋体 `Songti SC / SimSun`：盐志正文与大标题（叙事感）。
- 等宽 `SF Mono / Menlo`：池号（A-06）、波美度读数（27.4 °Bé）——测量仪表感。
- 黑体 `PingFang SC`：UI 标签、阶段名、工序色谱说明。
字体来自内容：测量读数用等宽，叙事用宋体，界面用黑体。

## 材质逻辑
卤水镜面反光（收盐后池面映天光）、多边形盐晶颗粒、田埂夯土边线、木盐耙。材质贯穿全局，不只在某一处。

## 核心交互
- 拖日轨控蒸发：蒸发是状态机（蒸发量→水位→波美度→显色阈值→结晶），非线性时间插值。
- 拖盐耙收盐：按住木盐耙从左拖到右，盐晶被真实推拢到池角成坨，池面变镜面。
- 俯瞰图 hover 池格读数（池号/工序/面积/波美度/预计可收）；点击入池；返回俯瞰时全场池色随全局时间同步推进。

## 自定义光标
`.cursor-wrap`（ring + dot + label），开页居中（top/left 50%），`mix-blend-mode` 高对比，层级最高；拖盐耙时 label 显示「收盐中」、`is-drag` 态变化。`cursor: none` 全局禁用系统光标。

## 健壮性
- 纯 vanilla 单文件，零 CDN / 零 React / 零外部图片。
- RAF 随 `visibilitychange` 暂停、卸载 `cancelAnimationFrame`。
- 高频鼠标事件直接操作 DOM，快速拖动不叠加定时器。
- 完整 `prefers-reduced-motion` 降级。
- 响应式 1440 / 1024 / 768 / 390。

## 真实内容
波美度（°Bé，法国化学家波美发明）、海水约 3.5°Bé、25.5°Bé 氯化钠结晶析出、杜氏盐藻 β-胡萝卜素显色、纳潮→蒸发→调节→结晶→收盐五道工序、运城解池地名、盐工「老陈」、卤水面积（亩）、预计可收（吨）。

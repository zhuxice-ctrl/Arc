# 盐花纪 · 设计规范

> 日期：2026-08-18 · 方向：V1 网页设计 · 主题：手工海盐工坊品牌官网

## 色彩系统

| 角色 | 色值 | 用途 |
|---|---|---|
| 盐晶白（底色） | #FAF7F2 | 页面主背景，模拟海盐结晶表面 |
| 石墨炭灰 | #2B2B2E | 标题与正文主文字 |
| 珊瑚橙 | #E8603C | 强调色：CTA 按钮、关键数据、品牌点睛 |
| 暖沙金 | #C9A86A | 辅助强调：分隔线、徽章、工艺编号 |
| 浅陶粉 | #F2D8C9 | 卡片次背景、柔和区块填充 |
| 暖灰 | #9B9B9E / #6B6B6E | 次要文字、说明文字 |
| 海雾白 | #F5EFE6 | 次级区块背景 |
| 薄荷青 | #A8C8B8 | 海洋元素点缀 |

色彩层次：盐晶白底 + 石墨灰文字为主调，珊瑚橙作为单一视觉焦点穿透整页，暖沙金串联叙事节奏，浅陶粉做卡片分层。

## 字体系统

- 标题/品牌字：`'Ma Shan Zheng', 'Noto Serif SC', serif`（马善正手写体营造手作温度）
- 正文：`inherit`（系统无衬线，保证可读性）
- 层级：Hero 标题特大体量，章节标题加粗配暖沙金编号，正文 16px 行高 1.7

## 组件规范

- 产品卡片：白底 + 细边框 + 悬停 3D 倾斜 + 光泽扫过，圆角 16px
- 磁性按钮：珊瑚橙实底 + 反平方引力吸附光标，圆角胶囊
- 工艺盐柱：高度递增柱状条，渐变色由浅陶粉→暖沙金
- 数字计数：easeOutQuart 缓动，珊瑚橙强调
- 导航条：透明吸顶，下划线 + 圆点弹出贝塞尔动画

## 动效系统（14 项）

1. 自定义光标（白环 + 橙心 + 白点 + 光晕，四层 lerp 跟随，开页居中显示）
2. 悬停放大 + 点击涟漪扩散
3. 盐晶粒子场（正弦潮汐漂移 + 上浮 + 旋转 + 闪烁）
4. 标题逐字入场（位移 + 旋转 + 错峰）
5. 滚动渐入（IntersectionObserver 触发）
6. 数字计数（easeOutQuart 缓动）
7. 产品卡片 3D 倾斜（鼠标驱动 + 弹簧阻尼 lerp）
8. 光泽扫过（卡片 hover 斜向光斑）
9. 多层潮汐波浪（三条不同频率/振幅正弦路径）
10. Hero 视差（盐晶 + 网格随滚动差速位移）
11. 磁性按钮（反平方引力吸附）
12. 工艺盐柱生长（高度递增柱状动画）
13. 盐晶装饰漂浮（多层错峰浮动 + 反向）
14. 导航下划线 + 圆点弹出（贝塞尔弹性）

动效物理模型：弹簧 lerp（卡片倾斜/光标跟随）、反平方引力（磁性按钮）、正弦潮汐（粒子/波浪）、easeOutQuart（计数/入场）。各动效周期不同，不整齐划一。

## 健壮性

- `visibilitychange` 统一暂停所有 RAF/定时器
- `prefers-reduced-motion` 降级为静态，隐藏光标与粒子
- 高频 mousemove 直接操作 DOM transform，不触发重渲染
- 所有计时器走 safe 封装，重建前清除旧的

## 页面结构

首屏 Hero（大标题 + 盐晶 SVG + CTA）→ 盐的故事（叙事 + 三项数据）→ 古法晒制（六步工序 + 盐柱动效）→ 盐品甄选（6 款卡片 + 分类筛选）→ 潮汐引语（金句 + 多层波浪）→ 工坊体验（3 档套餐）→ 数据看板（4 项计数）→ 页脚。

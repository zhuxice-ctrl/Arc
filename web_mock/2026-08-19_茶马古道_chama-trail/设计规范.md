# 设计规范 · 茶马古道·马帮驿站图鉴

> 类别：Web Mock　日期：2026-08-19　主题：茶马古道马帮驿站横向长卷

## 一、设计母题

横向山道长卷——"滚动即行路"。整站是一条可横向滚动的茶马古道山道，马帮图示随滚动沿山道行进，沿途 7 个驿站节点是信息入口，顶部里程标尺同步标记当前行路里程（0–1800 里）。

## 二、空间模型

- `horizontal_mountain_trail_scroll`：横向山道卷轴为主轴，山道 SVG 在画面中部蜿蜒，上下为横断山体轮廓与雾气分层。
- 导航方式 = 沿路行进（滚轮 / 拖拽 / 方向键横向），非目录跳转。
- 驿站节点嵌于山道，点击聚焦展开记忆卡片。

## 三、配色（从源码提取）

| 角色 | 色值 | 用途 |
|------|------|------|
| 赭石红 | `#A0522D` | 驿站节点、强调、印章 |
| 茶褐 | `#6B4423` | 近山体、木质元素 |
| 松烟绿 | `#3A4A3A` / `#556B55` | 远山体、植被 |
| 雾灰 | `#C8B89A` / `#DBCDBA` | 雾气、中景 |
| 宣纸米 | `#EDE3D0` / `#F5EDDC` | 底色、纸张 |
| 深褐 | `#4A2E18` / `#2A1F14` | 文字、深山轮廓 |

禁蓝紫渐变，全暖色大地色系。

## 四、字体

- 主字体：`Georgia, serif`（衬线，呼应古道行记的编辑感）
- 中文随系统衬线回退

## 五、动效系统（≥12 组件级特效）

1. 三层山体雾气视差（远山慢、近山快，随横向滚动位移）
2. 云雾带飘移
3. 马帮图示随滚动位移 + 上下颠簸步伐
4. 驿站节点接近时脉冲高亮
5. 里程标尺游标随滚动同步流动
6. 山道轮廓呼吸描边
7. 险段（溜索/雪山垭口）警示纹路闪烁
8. 节点展开过渡（记忆卡片滑入）
9. 自定义光标赭石红圆环 + 拖尾
10. 点击涟漪
11. 开页印章动效
12. 纸张纹理叠加 + 刻度跳动

## 六、核心交互

- 横向滚动驱动马帮沿山道行进
- 滚到/点击驿站节点 → 展开该站记忆卡片（马帮规模 / 货物 / 客栈 / 前方险段 / 行记短文）
- 走到险段 → 山道变窄 + 警示短文

## 七、技术栈

纯 vanilla 单文件 HTML+CSS+JS，无 React/Babel/CDN，所有资源内联。自定义光标开页居中，RAF 随 `document.hidden` 暂停、卸载取消，支持 `prefers-reduced-motion`。

## 八、驿站节点（真实内容）

雅安·茶马起点 → 泸定·铁索桥 → 康定·锅庄城 → 理塘·世界高城 → 巴塘·宁静山 → 昌都·茶马交会 → 拉萨·终点。货物：茶砖 / 盐袋 / 布卷 / 铜锅 / 药材。

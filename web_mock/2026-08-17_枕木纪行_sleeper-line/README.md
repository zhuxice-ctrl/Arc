# 枕木纪行 Sleeper Line · 复古铁道旅行官网

> 日期：2026-08-17 ｜ 方向：V1 网页设计 ｜ 主题：复古铁道旅行品牌官网

## 简介

蒸汽机车、枕木、黄铜铭牌、老式车票、沿途小站的怀旧铁道旅行品牌站。深墨绿 + 黄铜 + 奶油 + 铁锈红的复古铁道色系，衬线字体承载印刷感，等宽字体承载站牌与时刻表数据。

## 动效亮点

自定义三环光标、蒸汽粒子画布、铁轨延伸视差、翻牌站牌逐字 3D 翻转、机车车轮滚动耦合转动、卡片 3D 倾斜（DOM transform 阻尼插值）、滚动渐入、黄铜光泽扫过、打字机副标题、数字计数、磁性按钮、Logo 脉冲光环。共 12+ 组件级特效。

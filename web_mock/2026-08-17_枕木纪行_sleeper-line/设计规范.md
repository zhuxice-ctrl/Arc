## 色彩系统

| 角色 | 色值 | 用途 |
|---|---|---|
| 主色 · 深墨绿 | `#14251F` | 页面底色、页脚、深色区块 |
| 深绿次阶 | `#1D332C` | 卡片底、区块分层 |
| 强调 · 黄铜 | `#C89B4E` | 标题点缀、按钮、光泽扫过、站牌字符 |
| 黄铜亮阶 | `#E0B56A` | 高光、hover 态 |
| 黄铜暗阶 | `#9A7533` | 描边、暗部金属 |
| 表面 · 奶油 | `#F4EBD8` | 浅色区块底、正文反白 |
| 奶油次阶 | `#E8DCBE` | 车票纸面、分隔 |
| 警示 · 铁锈红 | `#A63D2F` | 状态标记、强调标签 |
| 辅助 · 锈红亮阶 | `#C95748` | hover / 活跃态 |

无蓝紫渐变；金属感仅靠黄铜色阶的明度偏移与光泽扫过动效表达。

## 字体

- 展示字体：`Playfair Display`（`--f-display`）——大标题、站名
- 正文字体：`Noto Serif SC`（`--f-body`）——衬线中文正文，怀旧印刷感
- 等宽字体：`IBM Plex Mono`（`--f-mono`）——时刻表、站牌数据、编号

## 页面结构（单页七区块）

1. Hero：蒸汽机车 SVG + 翻牌站牌 + 打字机副标题
2. 运营线路：3 张线路卡（3D 倾斜 + 光泽扫过）
3. 列车时刻表：实时时钟 + 状态标记
4. 车票：硬纸卡样式 + 打孔交互
5. 沿途画廊：四栏错位网格 + 分类切换
6. 数字统计：滚动触发计数
7. 预订表单 + 页脚：成功态反馈

## 动效系统（12+ 组件级）

自定义三环光标（外框/内点/辉光，开页即居中，悬停变形、点击涟漪）、蒸汽粒子画布（上升+摆动+淡入淡出）、铁轨延伸视差（透视枕木逐根远去）、翻牌站牌（逐字 3D 翻转轮播 6 站）、机车车轮转动（滚动速度耦合转速）、卡片 3D 倾斜（DOM transform 阻尼插值）、滚动渐入（IntersectionObserver 分级延迟）、光泽扫过、打字机、数字计数（easeOutCubic）、磁性按钮、Logo 脉冲光环。

## 健壮性

`visibilitychange` 统一暂停/恢复全部 RAF 循环（animRegistry 注册管理）；`prefers-reduced-motion` 全局降级；定时器/RAF 重建前先清理；高频鼠标事件直接操作 DOM transform；零未定义引用；JSX/CSS 全部内联单文件。

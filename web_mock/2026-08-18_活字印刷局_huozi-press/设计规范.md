# 活字印刷局 · 设计规范

> 日期：2026-08-18 · 方向：V1 网页设计 · 主题：活字印刷博物馆官网

## 一、设计概念

以"活字印刷"为核心叙事，将一座活字印刷博物馆的铸字、拣字、排版、敷墨、刷印、装订完整工艺搬上网页。整体气质是"宣纸为底、墨黑为骨、朱砂为印、黄铜为饰"的东方匠人美学，配合纸纹质感与油墨晕染肌理，营造沉静、厚重、可细品的阅读感。

## 二、色彩系统

| 角色 | 色值 | 用途 |
|---|---|---|
| 墨黑（主骨） | `#1a1a1a` | 正文、标题、深色底 |
| 宣纸米（主底） | `#f5ecd9` | 页面底色、卡片底 |
| 朱砂红（强调） | `#c8392e` | 印章、强调按钮、关键标记 |
| 黄铜（点缀） | `#b8923a` | 描边、图标、金属高光 |
| 黄铜亮金 | `#d4b060` | 光泽扫过、悬停高光 |
| 深褐 | `#3a2a1a` / `#5a4025` | 木质/深底分区、次级文本 |
| 纸纹米 | `#ebe1c8` / `#d9cfb6` | 卡片内层、分隔 |
| 墨黑次阶 | `#2a2a2a` | 深色过渡 |

配色规则：以宣纸米大面积铺底，墨黑承担结构与文字，朱砂红仅用于印章与关键行动点（克制使用），黄铜用于描边与高光点缀，制造"老木+黄铜+朱砂印"的层次。

## 三、字体

- 中文标题/正文：`"Songti SC", "Noto Serif SC", "STSong", "SimSun", serif`（衬线，书卷气）
- 整体以衬线宋体为主，传递活字印刷的雕版质感。

## 四、组件规范

- 悬浮导航 + 朱砂印 Logo
- 工艺流程卡（刻铜模 → 铸铅字 → 拣字排版 → 敷墨上版 → 覆纸刷印 → 装订成册）
- 字库典藏字模翻转卡（永 / 墨 / 印 / 章）
- 珍品卡（SVG 插画）
- 历史年表节点（1041–1968）
- 展览活动列表项
- 参观预约表单

## 五、动效系统

1. 自定义光标：白粗环 + 朱砂内点 + 黄铜发光，悬停形变，点击涟漪
2. 活字粒子上浮（Canvas，含鼠标斥力、阻尼、循环再生）
3. 铅字压印标题（逐字坠落 + 回弹 + 多层阴影）
4. 滚动渐入（IntersectionObserver，错位延迟）
5. 悬停发光（字模卡片黄铜 glow）
6. 打字机（三句文案循环）
7. 数字计数（easeOutExpo，入视口触发）
8. 涟漪（点击 + 表单提交反馈）
9. 视差（Hero 内容反向位移 + 淡出）
10. 墨迹晕染（卡片 hover 径向晕散）
11. 字模翻转（3D rotateY，入视口依次翻转）
12. 导航下划线生长（hover 从左生长）
13. 墨辊光泽扫过（预约按钮 hover 黄铜高光斜扫）

## 六、页面结构

悬浮导航 → Hero（活字粒子 + 压印标题 + 打字机）→ 馆藏数字统计 → 六大工艺流程 → 字库典藏 + 珍品 → 活字千年年表 → 近期展览 → 参观预约表单 → 页脚四栏。

## 七、健壮性

rAF/定时器统一管理、visibilitychange 暂停、卸载清理、prefers-reduced-motion 降级、mousemove 直操 DOM transform、单文件内联零外部依赖。

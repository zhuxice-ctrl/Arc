# 苔原气象站 Tundra Observatory

> 日期：2026-08-17 · 方向：V1 网页设计 · 主题：极地科考站年度观测年报沉浸式官网

## 简介

一座虚构极地科考站的年度观测年报网站。以长滚动叙事呈现极夜时间轴、全年气温风速数据故事、越冬队员手记、苔原生态画廊与访客留言。冷调冰白底色配苔原灰绿与极光青，信号橙点亮关键数据。

![苔原气象站预览](./preview.png)

## 动效亮点

- 极光带三条异周期漂移 + 60 颗雪花粒子飘落
- 风速仪持续旋转、温度计水银升降、风速频谱条实时跳动
- 卡片 3D 倾斜（直接操作 DOM transform，不触发重渲染）
- 队员手记打字机逐字呈现 + 头像脉冲发光
- 自定义光标（白环 + 极光青内点，开页居中，悬停放大变色，点击涟漪）
- 滚动驱动的极夜时间轴进度条发光

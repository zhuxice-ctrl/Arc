# 设计规范 · 苔原气象站 Tundra Observatory

> 日期：2026-08-17 · 方向：V1 网页设计 · 主题：极地科考站年度观测年报沉浸式官网

## 色彩系统

本次配色为冷调极地色系，主底冰白、辅以苔原灰绿与极光青，信号橙作强调点缀，墨黑承载文字。禁止蓝紫渐变。

| 角色 | 色值 | 用途 |
|---|---|---|
| 主背景 · 冰白 | `#F4F7F5` | 页面主底色 |
| 主色 · 苔原灰绿 | `#5F7161` | 品牌色、章节标记、次要图标 |
| 强调色 · 极光青 | `#2FA39A` | 数据高亮、链接、进度条发光 |
| 信号橙 | `#E8722A` | 关键数字、警示、按钮强调 |
| 深橙 | `#d4631f` | 橙色按压态/阴影边 |
| 主文字 · 墨黑 | `#1C2426` | 标题与正文 |
| 最深底 · `#12181a` | `#12181a` | 极夜时间轴深色区 |

## 字体排印

- 标题/衬线：`"Noto Serif SC", serif`
- 正文/无衬线：`"Noto Sans SC", -apple-system, BlinkMacSystemFont, sans-serif`
- 数据/等宽：`"JetBrains Mono", monospace`

字重梯度：300 / 400 / 500 / 700 / 900。大标题用 900 重衬线，正文 400，数据指标用等宽 500。

## 组件规范

- **数据卡**：冰白底 + 细边框 + 悬停 3D 倾斜（perspective 1000px，rotateX/Y 跟随鼠标，直接操作 DOM transform）。
- **时间轴节点**：深色底圆点，滚动驱动进度条发光依次点亮。
- **温度计**：水银柱升降（height 过渡 + 语义着色）。
- **风速频谱条**：实时跳动柱状条，异周期。
- **画廊网格**：非对称拼贴，悬停光泽扫过（伪元素渐变位移）。
- **导航栏**：滚动凝缩（高度+模糊度随 scroll 变化）。

## 页面结构

单页长滚动叙事，六大板块：

1. **卷首 Hero** — 极光带 + 雪花粒子 + 风速仪 + 4 项年度关键数字
2. **极夜时间轴** — 7 节点深色时间轴
3. **观测数据故事** — 3 张数据卡 + ECharts 全年气温/风速折线 + 关键指标
4. **队员手记** — 4 位越冬队员切换，打字机呈现
5. **苔原生态画廊** — 7 幅非对称网格 SVG 插画
6. **访客留言** — 真实可提交表单 + 预置留言

## 健壮性

- 所有 RAF 循环随 `visibilitychange` 自动暂停/恢复，卸载时统一 cancel。
- 定时器重建前先 clear（打字机、加载进度等）。
- 卡片倾斜用 mousemove 直接操作 transform，不触发 React 重渲染。
- 支持 `prefers-reduced-motion` 降级。
- 响应式适配移动端（900px 断点）。
- 所有 JSX 内联于 `<script type="text/babel">`，CSS 内联于 `<style>`。

## 技术栈

React 18 + Babel Standalone + ECharts 5，单文件 index.html。

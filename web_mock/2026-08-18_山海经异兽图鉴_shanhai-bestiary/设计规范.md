# 山海经异兽图鉴 · 设计规范

## 主题
以《山海经》上古奇书为灵感的数字异兽图鉴网站。宣纸米白底 + 朱砂红 + 黛青 + 金箔的东方古籍美学，单页完整体验。

## 色彩系统

| 角色 | 色值 | 用途 |
|---|---|---|
| 宣纸米白 | `#F5EFE0` | 页面底色、卷轴背景 |
| 浅宣 | `#F0E6D0` / `#EDE4CE` | 卡片表面、分层底 |
| 朱砂红 | `#C23A2B` | 主强调、印章、标题点缀 |
| 朱砂深 | `#B8342A` / `#9E2A1E` | 印泥暗部、悬停加深 |
| 朱砂亮 | `#D9513F` | 高亮、链接 |
| 黛青 | `#1A2E3A` | 正文深色、深底块 |
| 黛青中 | `#2D4350` / `#4A6070` | 次级文字、边线 |
| 远山青 | `#2A6F8A` | 辅助点缀、数据色 |
| 金箔 | `#D4B377` | 装饰描边、分隔金线 |
| 古铜金 | `#B8935A` / `#8A6D3B` | 次级金、图标色 |

## 字体
- 标题：书法/宋体栈（楷体 → STKaiti → serif），大字号营造碑刻感
- 正文：思源宋体 / Noto Serif SC / serif
- 数据：等宽字体栈

## 页面结构
1. Hero 首屏：水墨山水背景 + 大号书法标题「山海经」+ 三大数据计数（山川/异兽/篇卷）+ 鼠标视差
2. 异兽图鉴画廊：8 只经典异兽卡片（九尾狐、凤凰、麒麟、应龙、烛龙、白泽、精卫、毕方），瑞兽/神鸟分类筛选
3. 异兽详情弹窗：卷轴式展开，含出处、描述、古籍原文、栖息之地、异能，打字机逐字呈现
4. 流传沿革时间轴：先秦 → 西汉 → 东晋 → 明代 → 今日
5. 古籍原典引用：深色沉浸式郭璞序文段
6. 页脚：四栏导航 + 回到顶部

## 动效系统（16 项组件级特效）
1. 自定义光标（弹簧跟随 + 悬停放大变色 + 点击涟漪 + mix-blend-mode）
2. 墨点粒子系统（随机飘移 + 脉冲发光）
3. Hero 视差背景（鼠标移动联动）
4. 卡片 3D 倾斜（弹簧物理积分）
5. 数字计数器（缓动立方）
6. 频谱条动画（弹簧物理）
7. 朱砂印脉冲光环
8. 光泽扫过文字
9. 打字机描述呈现
10. 滚动渐入揭示（IntersectionObserver）
11. 模态框弹簧弹出
12. 导航栏滚动隐藏/显示
13. 筛选按钮液体填充
14. 回到顶部浮动按钮
15. 关闭按钮旋转
16. 滚动指示器下拉动画

## 健壮性
- 所有 RAF/定时器随 `visibilitychange` 自动暂停，卸载统一取消
- 支持 `prefers-reduced-motion` 降级
- JSX 全部内联于 index.html，零外部引用
- 圆角统一 8px / 12px / 16px 三级

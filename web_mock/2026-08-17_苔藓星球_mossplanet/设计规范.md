# 苔藓星球 Mossplanet · 设计规范

> 日期：2026-08-17 ｜ 方向：V1 网页设计 ｜ 主题：苔藓微缩景观艺术展官网

## 色彩系统

| 角色 | 色值 | 用途 |
|------|------|------|
| 主色·深苔绿 | `#1a3d2e` | 品牌主色、Hero 背景、标题 |
| 深苔绿 2 | `#2a5a42` | 卡片底、次级背景 |
| 深苔绿 3 | `#3d7a5a` | 分隔线、次级文字 |
| 辅助·黄绿 | `#8fbf3f` | 强调按钮、活体苔藓高光、链接 |
| 强调·暗金 | `#b8923a` | 数字计数、装饰描边、徽标 |
| 暗金浅 | `#e8c872` | 光泽扫过、高光点缀 |
| 表面·米褐 | `#d9c9a3` | 纸张质感卡片表面 |
| 米褐浅 | `#e8dfc8` | 次级表面、表单底 |
| 中性·墨绿黑 | `#0f2018` | 页脚、最深底色 |
| 墨绿黑深 | `#0a1610` | 全局背景 |

配色基调：深苔绿系，无蓝紫渐变。整体偏暗绿底 + 黄绿/暗金点缀，呈现潮湿苔藓质感。

## 字体

- 中文标题：`'Noto Serif SC', 'Source Han Serif', serif`（衬线，厚重感）
- 中文正文：`'Noto Sans SC', system-ui, sans-serif`
- 英文/数字：`'Cormorant Garamond', Georgia, serif`（策展语）+ `'Inter', sans-serif`（UI）

## 圆角

- 卡片：`16px`
- 按钮：`999px`（胶囊）/ `8px`（方形）
- 图片容器：`12px`

## 组件

- **自定义光标**：白色粗环 + 黄绿内点 + 多层发光，z-index 最高；悬停可交互元素放大变色，点击涟漪扩散
- **作品卡**：3D 倾斜悬停（mousemove 直接操作 transform），光泽扫过伪元素
- **声波柱**：48 根柱体，三频正弦叠加振动，周期各异
- **导航**：吸顶，滚动时背景从透明渐变为墨绿半透明
- **预约表单**：输入框聚焦黄绿描边，提交后打字机反馈

## 动效系统（12+ 组件级特效）

1. 自定义光标（中心即显 + 悬停变形 + 点击涟漪）
2. 苔藓孢子粒子飘浮（布朗运动 + 缓慢沉降，RAF 积分）
3. 滚动渐入（IntersectionObserver）
4. Hero 大图视差（滚动驱动 translateY，直操 DOM）
5. 作品卡 3D 倾斜悬停（mousemove 直操 transform）
6. 光泽扫过（伪元素 + transform）
7. 数字计数（展出作品数 / 参观人次）
8. 策展前言打字机（逐字）
9. 声波柱振动（三频正弦叠加）
10. 苔藓生长 SVG path 描边动画
11. 页脚涟漪
12. 导航吸顶变色

动效基于物理模型（布朗运动/RAF 积分器）与主题语义（孢子飘落/声波/苔藓生长），周期各异，禁 Ken Burns 整图缩放。

## 页面结构

单页竖向滚动：导航 → Hero 沉浸开场 → 策展前言（打字机）→ 6 件微缩苔藓景观作品（3D 倾斜卡）→ 声音装置区（声波柱可视化）→ 工坊介绍（SVG 苔藓生长）→ 参观预约表单 → 页脚。

## 技术栈

纯 vanilla HTML/CSS/JS 单文件，无 React/Babel/外部 CDN 依赖。CSS 内联 `<style>`，JS 内联 `<script>`。

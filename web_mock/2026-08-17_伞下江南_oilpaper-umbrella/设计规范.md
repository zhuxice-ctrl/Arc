# 设计规范 · 伞下江南 · 油纸伞工坊官网

> 日期：2026-08-17 · 方向：V1 网页设计 · 主题：油纸伞非遗工坊品牌官网

## 色彩系统

以宣纸米白为底，桐油琥珀金为主调，黛青为沉稳骨架，朱红作点睛印章色，禁用蓝紫渐变。

| 令牌 | 色值 | 用途 |
|---|---|---|
| --paper | #F5EFE0 | 宣纸米白底色 |
| --paper-deep | #EAE1CC | 米白深一阶 / 卡片底 |
| --amber | #C88A2E | 桐油琥珀金（主强调） |
| --amber-deep | #A66D1C | 琥珀深色 |
| --amber-light | #E0B156 | 琥珀浅色 / 高光 |
| --dai | #2D3E4E | 黛青（深色区块底） |
| --dai-light | #4A5F73 | 黛青浅色 |
| --zhu | #B8342A | 朱红（印章 / 点缀） |
| --zhu-light | #D44A3E | 朱红浅色 |

| --paper-gray | #8B8374 | 纸灰辅助文字 |

深色区块使用 `linear-gradient(135deg, var(--dai) 0%, #1e2d3a 100%)`。

## 字体

正文中文衬线 / 标题加重，配合宣纸质感。代码与数字使用等宽体。

## 页面结构

1. 加载遮罩（伞面展开动画）
2. 固定导航（滚动变色）+ 移动端汉堡菜单
3. Hero 区：标题 + 打字机副标题 + 3D 倾斜交互油纸伞
4. 数字统计条（72 道工序 / 365 年 / 56 位匠人 / 12000 把伞，滚动计数）
5. 工坊故事（图文 + 引言 + 朱砂印章）
6. 伞骨结构（3D 俯视 + 竹骨生长动画 + 可悬停标签）
7. 五道大工（选竹/削骨/裱纸/上桐油/绘花，Tab 切换 + 淡入）
8. 伞面画廊（分类筛选 + 悬停遮罩渐入 + Masonry 网格）
9. 匠人团队（3 位匠人卡片，悬停上浮）
10. 预约体验（完整表单 + 提交反馈，深色黛青底）
11. Footer + 回到顶部

## 动效系统

16 个组件级特效：自定义光标（白环 + 朱红内点 + 多层发光，三态切换）、光标点击涟漪、雨滴粒子系统（80 滴 RAF 驱动含地面涟漪）、Hero 油纸伞 3D 倾斜（弹簧阻尼 lerp）、伞面光泽扫过、打字机、滚动渐入（IntersectionObserver）、数字计数（easeOutExpo）、竹骨生长（stroke-dasharray）、卡片悬停发光上浮、按钮光泽扫过、导航下划线伸展、工序 Tab 切换淡入、画廊图片悬停缩放遮罩渐入、加载伞面展开遮罩、视差漂浮。

动效基于弹簧阻尼 lerp / IntersectionObserver / RAF 积分器，周期各不相同，无整图缩放偷懒动效。

## 健壮性

visibilitychange 自动暂停/恢复 RAF、卸载统一清除、定时器重建前清理、mousemove 直接操作 DOM transform、prefers-reduced-motion 全降级、零未定义引用。所有 CSS/JS 内联于 index.html。

# 拐弯 Detour · 城市漫游独立杂志 — 设计规范

- **日期**：2026-08-17
- **方向**：V1 网页设计
- **主题**：一本关注城市街巷、社区人物与在地文化的独立纸刊的官方网站
- **风格**：暖调纸刊编辑风，印刷质感、衬线标题、版式网格

## 色彩系统

| 角色 | 色值 | 用途 |
|------|------|------|
| 砖红 主色 | `#C14A33` | 品牌、CTA、强调标题、印章 |
| 砖红 深 | `#9E3A26` | 悬停态、深色印章 |
| 奶油 底 | `#F6F1E7` | 页面底色、纸面 |
| 奶油 深 | `#EDE6D6` | 卡片表面、分隔区 |
| 墨黑 | `#191512` | 正文、标题 |
| 墨黑 深 | `#2A241F` | 页脚暗区 |
| 芥末黄 | `#D9A62E` | 贴纸、点缀、高亮 |
| 灰绿 | `#6E7F6A` | 辅助标签、次级链接 |
| 灰绿 深 | `#4F5E4C` | 暗色文字 |

## 字体系统

- 标题 `--font-display`：`"Playfair Display", "Noto Serif SC", Georgia, serif`
- 正文 `--font-body`：`"Noto Serif SC", "Source Serif 4", Georgia, serif`
- 无衬线 `--font-sans`：`"Inter", "Noto Serif SC", sans-serif`

## 组件规范

- 杂志封面卡：3D 倾斜 + 浮动贴纸 + 阴影分层
- 专题文章卡：左色条 + 箭头旋转 hover + 图文左右分栏
- 往期目录 Tab：底部下划线滑动指示
- 作者头像：脉冲光晕 hover
- 订阅表单：砖红背景 + 内联成功态

## 动效系统

1. 自定义光标（白环 + 砖红内点 + 芥末黄发光 + 三态切换 + 涟漪）
2. 打字机循环标语（5 句交替）
3. 数字计数（expo easing）
4. 滚动渐入（IntersectionObserver 错位延迟）
5. 3D 卡片倾斜（弹簧回弹）
6. 磁性按钮（反平方引力吸附）
7. 封面贴纸浮动（sine 周期 4s）
8. 头像脉冲光晕
9. 导航栏滚动收缩玻璃态
10. Tab 切换淡入
11. 滚动提示扫光
12. 粒子爆炸（重力 + 摩擦）
13. 光泽扫过（CTA shine）

## 页面结构

Hero 首屏（杂志名+封面+数字计数）→ 精选专题（3 篇主推）→ 封面故事（暗色跨栏）→ 城市漫游路线（5 条）→ 专栏作者（4 位）→ 往期目录（4 期 Tab）→ 订阅区 → 页脚

## 工程特性

- 所有 RAF/定时器随 `visibilitychange` 暂停，`beforeunload` 清理
- 高频 mousemove 直接操作 DOM transform，不触发 React 重渲染
- 支持 `prefers-reduced-motion` 降级
- JSX/CSS 全内联单文件，响应式适配 <768px

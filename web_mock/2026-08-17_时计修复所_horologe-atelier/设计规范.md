# 设计规范 · 时计修复所 HOROLOGE

## 主题
古董钟表修复工坊品牌官网——围绕怀表/座钟修复工艺、修复师传承、馆藏时计、预约保养组织内容。

## 组件
- Hero 怀表（实时走时指针 + 摆轮 + 齿轮视差）
- 工艺流程时间轴
- 馆藏表款卡片网格（3D 倾斜 + 光泽扫过）

- 顶部毛玻璃导航 + 滚动进度条
- 跑马灯（品牌名/机芯名）

## 动效系统
1. 自定义光标（白环+酒红内点+黄铜光晕，悬停放大变色、点击涟漪）
2. 实时走时怀表（时/分/秒针跟随系统时间，秒针连续扫秒）
3. 摆轮振荡（2.5s 周期往复 + 游丝呼吸）
4. 齿轮视差（三枚不同速率/方向旋转）
5. 表壳 3D 倾斜（mousemove 驱动 perspective + lerp 阻尼）
6. 数字计数（easeOutCubic，IntersectionObserver 触发）
7. 滚动渐入（reveal 上滑淡入 + 阶梯延迟）
8. 磁吸收纳按钮（反平方引力）
9. 卡片 3D 倾斜 + 径向高光跟随
10. 标题逐行 slideUp
11. 导航下划线弹簧滑动 + 滚动毛玻璃态
12. 主按钮斜向光斑扫过
13. 跑马灯无限横向滚动
14. 表单聚焦下划线 scaleX 展开
15. 提交成功 spring 弹出
16. 顶部滚动进度条

物理模型：弹簧 lerp 阻尼、反平方磁力、惯性计数；动效周期各不相同。

## 页面结构
单页长滚动：Hero 怀表 → 工艺理念（数字计数）→ 修复师 → 工艺流程时间轴 → 馆藏表款网格 → 预约保养表单 → 页脚跑马灯。

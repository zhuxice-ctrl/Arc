# 盐田 Saltworks — 设计规范

## 主题

海盐制作工艺与盐田景观展览官网「The Quiet Alchemy of Salt」。展现海盐从卤水到结晶的完整工艺流程、世界各地盐田的航拍景观、盐文化历史。

## 页面结构

1. **Hero 区** — 航拍盐田背景 + 大标题 + 打字机副标题 + 磁吸按钮
2. **The Process** — 4 步制盐工艺卡片（卤水收集 / 蒸发 / 结晶 / 收获）
3. **Gallery** — 6 张作品网格，分类切换（All / Aerial / Landscape / Detail）
4. **Stats** — 4 组数字计数动画
5. **History** — 纵向时间线，4 个历史节点
6. **Visit CTA** — 日落盐田背景 + 展览信息三栏
7. **Footer** — 完整页脚导航

## 动效系统

| 动效 | 实现方式 |
|------|----------|
| 自定义光标 | 三环弹簧系统（外框 damped spring + 内点紧随 + 金色光晕），点击涟漪 |
| 盐晶粒子系统 | Canvas，漂浮 + 滚动视差 + 结晶呼吸脉动 |
| 3D 卡片倾斜 | mousemove 驱动，damped spring 积分，直接操作 DOM transform |
| 滚动渐入 | IntersectionObserver，分级延迟 |
| Hero 视差 | 背景图滚动位移 |
| 打字机效果 | 随机抖动速度 |
| 数字计数 | easeOutCubic 缓动，滚动触发 |
| 磁吸按钮 | 反平方引力模型 |
| 光泽扫过 | 按钮 hover 光带 |
| 盐结晶生长 | 工艺卡片悬停晶体图形放大旋转 |
| 时间线脉冲环 | 悬停扩散动画 |
| 滚动指示线 | 下落动画 |

## Tweaks 面板

8 项实时调节：主色切换 / 粒子密度 / 动效强度 / 暗色模式 / 自定义光标开关 / 排版缩放 / 盐晶粒子开关 / 一键减少动效

## 技术栈

- 单文件 HTML（内联 CSS + JavaScript）
- Canvas 2D 粒子系统
- CSS 变量驱动主题
- IntersectionObserver 滚动触发
- prefers-reduced-motion 降级

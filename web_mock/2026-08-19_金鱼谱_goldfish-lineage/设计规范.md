# 金鱼谱系馆 · 设计规范

## 主题
金鱼从野生鲫鱼到数百培育品种的演化史，以清代《金鱼图谱》工笔彩绘美学做成可探索的「演化谱系树」。

## 网站类型
Archive / Editorial —— 谱系档案，不是 Landing Page。

|---|---|
| 宣纸阅读面板 / 主体背景 | #F5F0E1 |

## 字体体系
- 标题：`var(--font-serif)` / Georgia, serif（图谱题跋感）
- 品种名/注解：`var(--font-kai)` 楷体（古典注释）
- 正文：`var(--font-sans)` 无衬线（保证可读）
- 拉丁学名：斜体

## 空间模型
演化谱系树（radial/tree SVG 画布）为主结构，左侧「驯化时间轴」（宋→明→清→当代）为第二导航，右侧「对照阅读面板」滑出。全库首次使用谱系树空间模型。

## 交互系统
1. **谱系树导航**：点击品种节点 → 画布平移缩放聚焦该枝 → 节点墨线生长
2. **对照阅读面板**：祖先 vs 变异品种并排对照（体形/尾鳍/眼型/鳞型逐项），印章落下动画
3. **时间轴联动**：拖动时间轴 → 树上高亮该朝代培育出的品种，节点吸附
4. **画布操控**：拖拽平移、滚轮缩放、缩放按钮、全景重置
5. **自定义光标**：开页居中，hover 品种节点变为「鱼眼」形态，浅/深背景自动适配

## 动效系统（≥12 组件级特效，全部符合「水墨+水波」逻辑）
- 谱系墨线生长（描边动画）
- 水波涟漪（点击反馈）
- 鱼形摆尾（节点 hover 微动）
- 宣纸面板展开
- 印章落下
- 节点光晕
- 时间轴吸附
- 背景水深渐变呼吸
- 鱼群游入场
- 标题墨迹晕染
- 缩放过渡缓动
- 光标形态切换

禁 Ken Burns 整图缩放、禁无语义鼠标跟随光斑。

## 内容
11 个真实金鱼品种：野生鲫鱼 / 草金 / 文鱼 / 龙睛 / 水泡眼 / 珍珠鳞 / 狮头 / 蝶尾 / 琉金 / 朝天眼 / 绒球，各含真实培育朝代与变异特征。

## 技术栈
纯 HTML + CSS + 原生 JS（拆分 css/style.css 与 js/{cursor,data,main,panel,timeline,tree}.js），无框架依赖。RAF 随页面可见性暂停、卸载取消，支持 prefers-reduced-motion。响应式断点 1440/1024/768/390。

## 健壮性
零未定义引用；快速点击不叠加定时器；高频鼠标事件直接操作 DOM；移动端对照面板改为底部抽屉。

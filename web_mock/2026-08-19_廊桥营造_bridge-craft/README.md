# 营造法式 · 木拱廊桥

**类别**：Web Mock　**日期**：2026-08-19

## 简介
一座数字营造场。以工程图纸语言拆解福建屏南万安桥这座编木拱廊桥——滚动即搭建，构件从桥台、三节苗、五节苗、剪刀撑到桥屋风雨板逐根沿榫卯方向落位，三节苗系统自锁成形的一瞬不用一钉一铆，拱架立起。读者不是在浏览介绍，而是在看着一座桥被重新造出来。

## 主题
浙闽木拱廊桥 / 编木拱营造技艺（万安桥原型）

## 文件说明

- `设计规范.md` — 色彩/字体/动效系统

## 技术栈
单 HTML 文件，无外部 CDN 运行依赖；自定义图纸十字线光标；支持 prefers-reduced-motion；RAF 随可见性暂停。

## 设计要点
- 空间模型：图纸仪器式（非 Landing/卡片网格）
- 配色：米白图纸 + 墨线 + 杉木棕 + 朱砂批注
- 真实数据：全长 47.6m / 净跨 27.3m / 桥屋 13 间 / 0 钉铆
- 交互：滚动驱动装配 + 构件 hover 批注 + 整体/分解切换

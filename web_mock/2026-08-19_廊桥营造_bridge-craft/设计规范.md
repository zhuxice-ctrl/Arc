# 设计规范 · 营造法式 · 木拱廊桥

**类别**：Web Mock　**日期**：2026-08-19　**主题**：浙闽木拱廊桥（福建屏南万安桥）

## 设计母题
工程图纸拆解——整站是一张会动的营造图纸，滚动即搭建：桥台→三节苗→五节苗→剪刀撑→桥屋→风雨板，构件逐根沿榫卯方向落位。读者"看着一座桥被重新造出来"。

## 空间模型
图纸仪器式（非 Landing、非卡片网格）。米白图纸底 + 横向格线 + 右侧章节标尺（00–12）+ 底部「整体桥 ↔ 拱架分解」视图切换。

## 字体逻辑
- 标题：Noto Serif SC（宋体气质，呼应古籍营造）
- 正文/标注：Noto Sans SC
- 构件编号/尺寸数字：JetBrains Mono（图纸字）

## 动效系统（≥12 组件级，服务"搭建"语义）
构件沿榫卯方向短促滑入落位、墨线描边生长、朱砂批注手写浮现、右侧标尺刻度生长、整体/分解切换分离、章节过渡、三节苗牛头锁合闪光（Signature Moment）。禁 Ken Burns 整图缩放。

## 自定义光标
图纸十字线光标，开页居中、高对比、层级最高；prefers-reduced-motion 降级。

## 内容真实性
万安桥真实参数：全长 47.6m / 净跨 27.3m / 矢高 5.8m / 桥屋 13 间 / 0 枚钉铆。术语：桥台、三节苗（九木相贯）、牛头、五节苗、剪刀撑、桥屋、风雨板、神龛。无 Lorem Ipsum。

## 技术栈
单 HTML 文件，内联 SVG + vanilla JS，无外部 CDN 运行依赖。RAF 随可见性暂停、卸载取消；支持 prefers-reduced-motion。

# 设计规范 · 候鸟迁徙观测站 Migratory Atlas

> 方向：网页设计（V1） · 日期：2026-08-16 · 形态：单页可交互官网

## 主题
一个虚构的候鸟迁徙观测组织官网，围绕候鸟 / 羽翼 / 季风 / 纬度组织视觉与动效：观测站介绍、当季迁徙走廊地图、物种图鉴、实时观测日志、志愿者招募。

## 色彩系统

| 角色 | 色值 | 用途 |
|------|------|------|
| 蛋壳米白底 | `#F5F1E8` | 页面底色 / 卡片底 |
| 炭黑墨色 | `#1C1B1A` | 正文 / 标题 / 强对比 |
| 落日茜红橙 | `#E4572E` | 主强调色（迁徙路线、站点、按钮、罗盘指针） |
| 羽灰 | `#8A8680` | 次要迁飞区色 / 辅助文字 |
| 浅羽灰 | `#B5B0A8` | 分隔 / 罗盘外环 |
| 大陆浅米 | `#EDE8DC` / `#D9D4CA` | 地图大陆填色 / 经纬网线 |

配色基调：暖米白 + 炭黑 + 茜红橙，整体田野笔记式自然观感，禁用蓝紫渐变。

## 字体

- 展示字体：`Source Serif 4`（田野笔记 / 期刊气质）
- 正文：`IBM Plex Sans`（理性观测感）
- 数据 / 仪器读数：`JetBrains Mono`

## 页面结构（单页 7 节）

1. **Hero** — 打字机大标题、迁徙飞线描边进入、数字计数动画、罗盘视差跟随鼠标
2. **观测站介绍** — 双栏布局 + 里程碑时间线 + 羽翼分隔符
3. **迁徙走廊地图** — 4 大迁飞区切换（东亚-澳大利西亚 / 中亚 / 西非-东亚 / 美洲）、SVG 路线上 3 鸟编队飞行、悬停站点信息、整体 3D 倾斜
4. **物种图鉴** — 6 种鸟类卡片、3D 倾斜 + 光泽扫过、点击展开详情弹窗、分类筛选
5. **实时观测日志** — 自动滚动日志流（每 8–20 秒新增）、24h 柱状图（ECharts）、6 站在线状态
6. **志愿者招募** — 4 方向角色选择、表单底线展开动效、提交成功态弹跳
7. **Footer** — 深色反转、订阅表单、回到顶部按钮

## 动效系统（15+ 组件级特效）

- 自定义光标：弹簧跟随 + 悬停放大 + 点击涟漪 + 标签
- 羽毛粒子飘落（Canvas，旋转 + 漂移）
- Hero 飞线描边（stroke-dashoffset 动画）
- 迁徙路径光点巡航（沿 SVG path 运动）
- 打字机标题
- 数字计数（expo 缓动）
- 罗盘视差（mousemove 直接操作 DOM transform）
- 卡片 3D 倾斜（perspective + rotateX/Y）
- 光泽扫过 shimmer
- 滚动渐入（IntersectionObserver）
- 新日志滑入
- 按钮滑动填充
- 时间线点放大
- 弹窗弹簧展开
- 表单底线延展

动效基于物理模型（弹簧跟随 / 阻尼 / RAF 积分器）与主题语义（羽翼飘落 / 编队飞行 / 路线延展），周期各不相同。

## 健壮性

- 所有 RAF / 定时器随 `visibilitychange` 暂停、卸载取消
- 高频 mousemove 直接操作 DOM transform，不走 React setState
- `prefers-reduced-motion` 全局降级
- 自定义光标在触摸设备自动禁用
- 零未定义引用

## 技术栈

React 18（CDN UMD）+ Babel Standalone + ECharts 5.6 + 纯 CSS。无构建步骤，`index.html` 直接打开即可运行（需公网 CDN）。

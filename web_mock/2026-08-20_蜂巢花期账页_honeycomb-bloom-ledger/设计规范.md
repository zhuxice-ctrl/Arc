# 蜂巢花期账页 · 设计规范

> 一面悬挂的蜂巢脾——蜂群社会的活体账页。巢房按生物学分区，花期轴驱动巢房经历「空房→注入花蜜→水分蒸发→封盖成熟」四态。

## 1. 设计母题与观点

- **母题**：蜂巢花期账页（Honeycomb · Bloom Ledger）
- **设计观点**：蜂巢不是装蜜的罐子，而是一面由蜂群按日龄分工、随花期共同书写并逐格封盖的活体账页。
- **视觉来源**：真实蜂巢巢脾（propolis 蜂胶 + beeswax 蜂蜡 + honey 蜂蜜 + pollen 花粉 + brood 育子）。
- **空间模型**：固定六边形巢脾场为唯一空间舞台 + 顶部水平花期轴。巢房共享蜂蜡壁，是一整面连续蜡质结构，非离散卡片。

## 2. 空间结构与分区

整面巢脾按真实蜂巢生物学垂直分区：

| 分区 | 位置 | 巢房状态 |
|------|------|----------|
| 封盖蜜区 | 上方 | 空房 / 注入花蜜 / 蒸发 / 封盖成熟（四态随花期轴推进） |
| 花粉带 | 中部 | 花粉颗粒堆积 |
| 育子圈 | 下中 | 虫卵→幼虫→蛹→成蜂脉动 |
| 蜂王区 | 最底 | 金环呼吸光 |

- 左侧信息栏：工蜂日龄分工 / 酿蜜化学 / 蜂群社会 / 8 字舞通信。
- 顶部花期轴：早春→仲春→盛夏→晚秋→冬蜜 五节点，可拖动。

## 6. 核心交互

- **拖动花期轴**：巢房批量经历四态并封盖，水分占比由 60% 连续降至 18%（象征酿蜜化学进度），季节标签与统计数联动。
- **悬停巢房**：蜡壁共鸣向邻房扩散；已封盖巢房旁侧绽放蜜源植物名牌（植物名 / 花期 / 蜜色 / 结晶特性）。
- **记忆点「封盖瞬间」**：六边形蜡盖向心闭合，蜜色由透亮金转为成熟浊金。

## 7. 自定义光标

- 形态：微缩工蜂 / 蜂蜡滴；开页即显示在屏幕正中央。
- 层级：`z-index: 9999`，最高。
- 反馈：跟随鼠标带轻微滞后（蜂飞感），高对比（象牙色于深褐上）；悬停巢房时形态微变。

## 8. 真实内容（无 Lorem Ipsum）

- **蜜源植物与蜂蜜（10 种）**：油菜花蜜（油菜·3-5 月·浅琥珀·易结晶乳白）/ 椴树蜜（紫椴·7 月·浅黄·结晶细腻似脂）/ 洋槐蜜（刺槐·5 月·水白透亮·不易结晶）/ 荔枝蜜（荔枝·3-4 月·琥珀·结晶细）/ 枣花蜜（枣·5-6 月·深琥珀·不结晶）/ 柑橘蜜（柑橘·4-5 月·浅黄·带果香）/ 枇杷蜜（枇杷·11-12 月冬蜜·琥珀·结晶）/ 野桂花蜜（柃木·10-11 月冬蜜·水白·稀贵）/ 荆条蜜 / 鸭脚木蜜。
- **蜂群日龄分工**：1-3 日清巢保温 / 4-8 日饲喂大幼虫蜂粮 / 9-12 日饲喂小幼虫蜂王浆 / 13-18 日泌蜡造脾 / 19-21 日守卫巢门扇风酿蜜 / 22 日+采集。
- **酿蜜化学**：花蜜（蔗糖约 60%）→ 转化酶 → 葡萄糖+果糖；水分由约 60% 蒸发降至 18% 以下后泌蜡封盖成熟。
- **蜂群社会**：蜂王（产卵，3-5 年）/ 工蜂（雌不育，承担全部劳作，4-6 周）/ 雄蜂（交配）。
- **8 字舞通信**：腹部摆动方向相对太阳指示蜜源方向，摆动时长与距离成正比。

## 9. 技术栈与健壮性

- 纯 vanilla 单文件 HTML/CSS/JS，无 React/Babel/CDN/外部图片。
- 零 Console Error、零 404、无白屏（Browser QA 实测四尺寸无横向溢出）。

- 支持 `prefers-reduced-motion`（降级为静态可读）。
- 响应式：1440 / 1024 / 768 / 390 均不崩。

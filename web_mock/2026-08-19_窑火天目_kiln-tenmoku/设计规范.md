# 窑火天目·建盏烧成 — 设计规范

## 主题

建盏烧成可视化走廊：以宋代建窑天目盏为锚点，沿窑温梯度（600°C→1350°C）展示四种经典釉面（兔毫/油滴/曜变/柿天目），参观者以自定义光标在温区走廊中穿行，光标本身即是一团窑火。

## 色彩系统

从源码提取的 80+ 唯一 hex 色值，按语义分组：

| 语义组 | 代表色值 | 用途 |
|--------|----------|------|
| 窑火赤 | `#FF6B2A` `#FF8A3D` `#E84820` `#D9431A` `#B03010` `#7A1F0F` | 火焰/高温区/强调 |
| 琥珀金 | `#D4A24A` `#E8A050` `#C8863A` `#FFD27A` `#FFE4A8` `#FFE8D6` | 兔毫纹/金线/高光 |
| 木棕 | `#6B4423` `#8B5238` `#9A7860` `#B89560` `#D4B080` `#5C3A1E` | 器物胎体/木架/容器 |
| 炭灰墨 | `#050201` `#080402` `#0A0604` `#1A0D08` `#2D0B06` `#3A0E08` | 背景/窑壁/阴影 |
| 奶油 | `#E8D5BC` `#FFE8D6` `#FFF4D6` `#D4CCC0` `#EBD6C4` | 釉面高光/文字 |
| 青苔 | `#7EA894` `#B8D0C0` `#606858` `#808878` `#E8F0E8` | 低温区/冷却/辅助 |
| 光斑 | `#7AB8FF` `#A87BFF` | 射灯 spotColors（非背景渐变） |

主色调：暖赤 → 琥珀金 → 炭灰墨 的温度梯度，禁蓝紫渐变合规。

## 动效系统

### CSS Keyframes（4 组）

| 名称 | 功能 |
|------|------|
| `cursor-pulse` | 自定义光标（窑火团）脉动呼吸 |
| `hint-breathe` | 提示文字呼吸渐显 |
| `arrow-slide` | 滚动引导箭头下滑 |
| `arrow-slide-back` | 箭头回弹 |

### Transition 系统（12 组）

核心缓动变量 `--ease-kiln` 贯穿全场，用于：
- 滤镜过渡 `filter 0.6s` — 釉面温变
- 透明度过渡 `opacity 0.5s–2s` — 展品淡入
- 变换过渡 `transform 0.6s–1.2s` — 器物浮入
- 组合过渡 `opacity + transform 0.8s 0.2s` — 滚动触发入场

### 组件级特效（≥12）

1. 自定义窑火光标（脉动 + 色温随温区变化）
2. 温度梯度走廊背景（视差滚动 + 色温渐变）
3. 四盏建盏实时滤镜变化（随滚动温区调 filter）
4. 釉面纹路动态生成（Canvas 兔毫/油滴/曜变粒子）
5. 温度计侧栏（随滚动填充高度）
6. 滚动入场动画（opacity + transform 组合）
7. 射灯光斑（spotColors 随机投射）
8. 引导箭头弹性循环
9. 提示文字呼吸渐显
10. 温区标签切换动效
11. 器物浮入 + 悬停抬升
12. 页面入场遮罩淡出

## 技术栈

- 纯 vanilla 单文件 HTML（无 React/Babel/CDN 依赖）
- Canvas 2D API 绘制釉面粒子纹路
- CSS Custom Properties 管理设计令牌
- requestAnimationFrame 驱动光标脉动
- IntersectionObserver 触发滚动入场
- prefers-reduced-motion 降级支持

# 纸寿千年 · 中国纸文化博物馆 — 设计规范

> 日期：2026-08-17 · 方向：V1 网页设计 · 主题：中国传统纸文化博物馆

## 色彩系统

以宣纸暖纸色为底，楮皮赭、朱砂印泥红、松烟墨为主调，金泥作点缀，整体呈现古纸温润质感。

| 角色 | 色值 | 用途 |
|---|---|---|
| 宣纸底 | `#faf6ed` | 页面主背景 |
| 米纸 | `#f5efe0` | 卡片/区块底色 |
| 浅楮 | `#ebe0c7` | 次级表面、分隔 |
| 麦秆金 | `#d8c89e` | 高光、装饰线 |
| 楮皮赭 | `#c1a76a` / `#a7823e` | 强调色、标题描边、印章环 |
| 深褐 | `#6b5e4f` | 次级文字 |
| 松烟墨 | `#3d352c` / `#2c2620` | 正文与主标题 |
| 朱砂印泥 | `#b3241a` / `#c23a2a` | 印章、预约按钮、点缀红 |
| 深朱 | `#8e2a1d` | 印章阴影 |

## 字体

- 标题：`"LXGW WenKai", "Noto Serif SC", serif`（霞鹜文楷，呈现毛笔楷书韵味）
- 正文：`"Noto Serif SC", "Songti SC", "STSong", serif`（宋体衬线，便于长文阅读）
- 数字：同正文宋体

## 圆角与阴影

- 卡片圆角：`12px`；按钮圆角：`8px`；印章圆形
- 阴影：`0 8px 24px rgba(44,38,32,0.12)`，暖灰调，营造纸页浮起感

## 组件

- 自定义光标：白色粗环 + 朱砂内点 + 多层暖光，悬停三态切换，点击朱砂涟漪
- 印章按钮：预约 CTA 为旋转下压式朱砂印章
- 工序手风琴：造纸工序可点击展开
- 馆藏卡：3D 倾斜 + 光泽扫过 hover
- 导航：顶部居中导航，logo 为朱砂印章

## 动效系统（14 项，基于物理模型 / 主题语义）

1. 自定义光标 — 双层弹簧物理（ring 快、glow 慢）
2. 漂浮纸纤维 — 80 粒子正弦摆动 + 摩擦阻尼向上飘散
3. Hero 竖排标题 — 逐字弹跳入场
4. 打字机 — 描述文案随机间隔逐字
5. 数字计数 — easeOutCubic 馆藏数滚动
6. 卡片 3D 倾斜 — mousemove 直操 transform
7. 印章盖下 — 预约按钮旋转下压
8. 光泽扫过 — 馆藏卡 hover 斜向高光
9. 滚动渐入 — IntersectionObserver 交错 reveal
10. 视差滚动 — 故事区三层墨线不同速度
11. 造纸轮旋转 — 匀速 + 唱针式摆针
12. 工序手风琴 — 高度弹性过渡
13. 导航印章摇晃 — logo hover 旋转回弹
14. 滚动指示线 — 呼吸式竖线缩放

## 健壮性

- `visibilitychange` 自动暂停 RAF，卸载统一取消
- 定时器重建前 `clearTimeout` / `cancelAnimationFrame`
- mousemove 直操 DOM transform，不触发重渲染
- 支持 `prefers-reduced-motion` 全降级
- 单文件内联，无外部 src 引用

## 页面结构

单页滚动：Hero 竖排标题 → 馆藏数字 → 造纸故事视差区 → 工序手风琴 → 馆藏卡网格 → 预约印章 CTA → 页脚

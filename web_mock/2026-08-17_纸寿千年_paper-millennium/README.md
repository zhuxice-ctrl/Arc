# 纸寿千年 · 中国纸文化博物馆

> 日期：2026-08-17 · 方向：V1 网页设计 · 主题：中国传统纸文化博物馆

## 简介

一座以「纸」为唯一主角的线上博物馆——从楮皮捣浆到松烟制墨，从宣纸千年寿到活字印坊，以暖纸色调与楷书衬线呈现中国纸文化的温度。单页滚动官网，真实可交互。

## 配色

宣纸米黄 `#faf6ed` / 楮皮赭 `#a7823e` / 朱砂印泥 `#b3241a` / 松烟墨 `#2c2620` / 金泥 `#d8c89e`，零蓝紫渐变。

# 锔瓷 · 裂纹长河 — 设计规范

## 设计母题
「裂纹即导航」。整页空间本身就是一只碎成七瓣的南宋龙泉窑葵口青瓷碗的侧影纵剖；一条主裂纹从页面顶部贯穿到底部，是全页唯一导航主轴。七个章节锚定在裂纹上的七枚锔钉节点，滚动=沿裂纹下行修复，滚到碗底即「完璧」。换成任何别的主题，裂纹主轴立即不成立——这是题材与结构不可分离的设计。

## 网站类型
Editorial / Archive（非遗工艺叙事），非 Landing Page、非卡片网格。

## 空间模型
单一器物纵剖 + 裂纹主轴（crack_spine_repair_vertical）。裂纹 SVG 路径贯穿全页，章节内容沿裂纹左右交替排布；右侧固定「锔钉进度索引」七枚钉形图标随修复进度逐个点亮、可点击跳转。

## 色彩体系（取自源码 CSS 变量）
| 角色 | 色值 | 用途 |
|------|------|------|
| 宣纸暖白底 | `#F2EEE4` | 主背景 |
| 宣纸次色 | `#EDE8DA` | 分区底 |
| 青瓷粉青 | `#C7D6CE` | 瓷面主色 |
| 青瓷深 | `#9BB5A8` / `#6E8B7D` | 釉面层次 |
| 月白釉面 | `#F4F6F2` | 高光 |
| 黄铜锔钉 | `#B08D4A` | 钉体；亮 `#D4B46B`、深 `#8A6B2E` |
| 裂纹墨褐 | `#3A322B` | 裂纹/正文；柔 `#5C5045`、淡 `#8A7D6F` |
| 大漆朱 | `#A63A2B` | 印章/字级强调（极克制） |

严格无蓝紫渐变。材质：纸张底纹（双重 `repeating-linear-gradient` 叠 `radial-gradient` 噪点 + multiply 混合）、青釉径向渐变、黄铜金属线性渐变与高光扫过。

## 字体逻辑
- 标题 / 工序名号：`"Noto Serif SC", "Songti SC", "SimSun", serif`（宋体类）
- 正文：系统无衬线（PingFang/YaHei 回退栈）
- 数字 / 工序编号：等宽 `ui-monospace, SFMono-Regular, ...`
- 工序名号用 `writing-mode: vertical-rl` 竖排作装饰性标注。字体服务题材（古器修复），非为「高级感」套用 serif。

## 动效系统（≥12 个组件级特效，瓷的脆 + 铜的韧）
1. 主裂纹 `stroke-dashoffset` 随滚动自绘
2. 开篇碗身轻震、七瓣微裂错位
3. 瓷屑粒子飞溅（短促、带重力）
4. 铜锔钉从旁飞入跨缝
5. 铜钉阻尼弹跳锁定（cubic-bezier 弹性）
6. 裂纹两侧边缘随铆合微微拉拢
7. 右侧钉形进度索引逐个点亮
8. 金属高光沿钉面扫过
9. WebAudio 低频轻「嗒」锁定声（首次手势后创建 AudioContext，不自动播放）
10. 金刚钻钻杆光标随运动方向微倾、悬停下压
11. 章节内容沿裂纹相交点左右交替 reveal（非统一 fade-up）
12. 收尾完璧碗釉面呼吸微光
13. 末章朱红「惜」字印章落章

## 核心交互
- 主交互：滚动沿裂纹下行，经过锔钉节点触发完整铆合流程（钻孔瓷屑→铜钉飞入跨缝→阻尼弹跳锁定→裂纹拉拢→金属高光→WebAudio 嗒）。
- 签名时刻：第一枚锔钉跨缝铆合——裂纹两侧拉拢、铜钉带阻尼弹跳锁定。
- 进度索引点击可平滑跳转到对应章节。

## 工程红线
- 纯 vanilla 单文件 `index.html`：零外部依赖（无 CDN / 无外部字体 / 无图片，视觉全部 SVG+CSS）。
- 单一 RAF 循环驱动进度；`visibilitychange` 暂停、`beforeunload` 取消；高频 mousemove 直接操作 DOM transform。
- `prefers-reduced-motion` 全量降级（cursor 回退为系统光标，静态展示但层级不变）。
- 响应式：1440 / 1024 / 768 / 390 实测无横向溢出、无重叠；移动端索引与竖排标题自动简化。
- Browser QA（chromium 渲染 4 视口）：零 Console Error、零 PageError、零 Failed Request。

## 内容（七章，沿裂纹自上而下）
1. 碎——开场：完整葵口青瓷碗震裂，主裂纹自绘，引言「一只碗的跌落」
2. 对缝——工序一：找碴对缝，三分锔七分对
3. 捧瓷——工序二：绳十字绑扎固定
4. 金刚钻——工序三：拉弓打眼只入三分，俗谚「没有金刚钻，别揽瓷器活」
5. 上钉——工序四：铜锔钉跨缝铆合，一字钉/米字钉/花钉形制
6. 弥缝——工序五：蛋清调石灰补漏，盛水不漏
7. 完璧——东京国立博物馆藏南宋龙泉窑「蚂蟥绊」（锔钉形似蚂蟥得名），惜物美学收束，朱红「惜」字印章

## 静态审计
- 删光动画：裂纹—锔钉—章节的空间锚定关系仍成立（裂纹是物理结构，非特效）。
- 灰模：仅矩形/文字/留白，七节点沿一条纵线排布的层级仍清晰。
- 内容不可替换性：换成别的主题，裂纹主轴导航立即失去意义。

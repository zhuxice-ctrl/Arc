# 设计规范 · 冰晶晕象仪（Ice Halo Apparatus）

> 从 `index.html` 源码提取的真实设计参数，非示意。

## 设计母题
大气光学仪器：高纬冬季日晕的成因可视化。**晕象的本质 = 六棱冰晶在云中的取向分布**，所以「拨动冰晶」就是「拨动天空」——交互即成因，这是本设计不可替换的核心逻辑。

## 空间模型
`zenith_dome_projection_plus_crystal_chamber`（天穹穹顶投影 + 冰晶微舱双窗联动）
- 上部 ~60%：天穹视窗——半圆 azimuth-altitude 投影盘，带角度刻度，太阳位置由滑杆驱动
- 下部 ~40%：冰晶舱——深黛青舱体，140–400 枚六棱冰晶（密度 = 画布面积/4000）+ 钻石尘微粒
- 右侧：晕象图例档案（8 种），点击 → 天穹高亮 + 单晶光路特写弹窗
- 底部：三控件（晶形 / 取向拨杆 / 太阳高度滑杆）

## 字体系统
- 标题：`Noto Serif SC → Songti SC → SimSun`（宋体系，仪器铭牌感）
- 正文：`Noto Sans SC → PingFang SC → Microsoft YaHei`（黑体系）
- 数值/角度：`ui-monospace → JetBrains Mono → Consolas`（等宽，仪器读数感）

## 晕象状态机（真实权重逻辑）
- 片晶 + 纷乱→定向：`h22 = 1 - o*0.85`（22°晕从满环衰减至 ~0.15）、`parhelia = 0.7 + o*0.5`（幻日增亮至 1.2 倍）、幻日环 `o*0.5`、下日 `o*0.6`
- 柱晶 + 纷乱：46°晕 `0.6`；定向：上切弧 `o`、下切弧 `o*0.7`
- 卷晶：环天顶弧 `0.9`（仅太阳高度 < 32° 渲染）
- 签名时刻：取向 0→100%，满舱冰晶逐一对齐，弥散晕环碎裂收拢成两个明亮幻日

## 动效系统（14 项，全部服务物理/主题逻辑）
冰晶自转→定向对齐 / 棱面干涉虹彩闪烁 / 晕环透明度插值 / 幻日聚光增亮 / 太阳高度弧实时位移 / 单晶光路折射色散动画 / 注释卡展开收合 / 六棱冰晶自定义光标（开页居中、difference 混合、层级最高）/ 天穹刻度呼吸 / 钻石尘飘落 / 图例-天穹联动高亮 / 角度数值滚动 / 舱缘冷光呼吸 / `prefers-reduced-motion` 全量降级

## 内容（全部真实）
8 种晕象档案：22°晕 / 幻日（假日）/ 46°晕 / 环天顶弧 / 上切弧 / 下切弧 / 幻日环 / 下日，各配成因、观测条件、单晶光路特写（入射角、偏向角、冰晶折射率 n≈1.31）。
观测地：内蒙古根河 / 新疆阿勒泰 · 冬季钻石尘天气。

## 技术
纯 vanilla 单文件，零框架零构建依赖；Canvas 双画布（天穹 + 冰晶舱）；RAF 随 `visibilitychange` 暂停、`beforeunload` 取消；高频鼠标事件直接操作 DOM；响应式 1440/1024/768/390 四档验证通过。

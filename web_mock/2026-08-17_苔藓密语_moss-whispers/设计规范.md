## 组件规范

- **导航栏**：固定顶部，滚动 50px 后从透明变为 `rgba(13,31,13,0.85)` + backdrop-filter blur
- **Hero 区**：全屏高度，孢子粒子 canvas 背景 + 大标题 + 展览信息
- **物种卡片**：表面色底，悬停时边缘发光 + 3D 倾斜 + 光泽扫过
- **按钮**：主色背景 + 6px 圆角，点击产生金色涟漪
- **数字计数器**：金色强调色，从 0 滚动到目标值

## 动效系统

| # | 动效 | 触发方式 | 实现方式 |
|---|------|---------|---------|
| 1 | 自定义光标 | 全局 | 白色粗环+金色内点+多层发光，DOM transform |
| 2 | 孢子粒子系统 | Hero 区 canvas | 浮力+布朗运动物理模拟 |
| 3 | 滚动渐入 | IntersectionObserver | 从下方淡入上移 |
| 4 | 卡片 3D 倾斜 | 鼠标 hover | perspective + transform，直接操作 DOM |
| 5 | 数字计数 | 滚动到视口 | RAF 从 0 计数到目标值 |
| 6 | 视差滚动 | 滚动事件 | 背景图层不同速率移动 |
| 7 | 光泽扫过 | 卡片 hover | CSS gradient + animation |
| 8 | 打字机效果 | 艺术家手记 | 逐字显现 + 签名淡入 |
| 9 | 涟漪扩散 | 点击交互元素 | 从点击点扩散金色涟漪 |
| 10 | 苔藓生长 SVG | 滚动到视口 | path 描边动画 |
| 11 | 头像脉冲 | 持续 | 三层金色呼吸光环 |
| 12 | 导航吸顶变色 | 滚动 50px | 透明 → 半透明深色 + 毛玻璃 |

## 页面结构

1. 导航栏（固定顶部）
2. Hero 区（孢子粒子 + 大标题 + 展览信息）
3. 装置介绍（关于苔藓生态的艺术陈述）
4. 苔藓物种图鉴（4 种真实苔藓卡片网格）
5. 展览信息（时间/地点/数字计数）
6. 艺术家手记（打字机效果 + 头像脉冲）
7. 页脚

## 健壮性

- 所有 RAF 随 visibilitychange 暂停，卸载时取消
- 高频鼠标事件直接操作 DOM transform，不触发 setState
- 支持 prefers-reduced-motion 全量降级
- 零未定义引用

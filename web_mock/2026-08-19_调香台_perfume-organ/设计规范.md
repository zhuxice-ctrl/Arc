# 调香台·设计规范

## 设计母题
香水管风琴祭坛（perfume organ）——整站是一座调香师管风琴，半圆形精油瓶阵列如音管排列，演奏瓶身释放香调滴入中央试香条，金字塔前/中/后调渐满成配方。

## 空间模型
径向半圆祭坛（radial semicircular altar）——精油瓶沿黄铜拱弧排列，中央高两侧低；正中是试香条 + 金字塔三阶。祭坛为唯一导航与视觉重心，无竖向 section、无卡片网格。

## 色彩系统（琥珀精油调，禁蓝紫/禁水墨）
| 变量 | 色值 | 用途 |
|---|---|---|
| --amber | #C8860C | 主琥珀（精油液体） |
| --amber-light | #E8A04A | 前调 / 高光 |
| --amber-deep | #8A5A08 | 深琥珀 |
| --rose | #C77B8A | 中调 / 玫瑰 |
| --sage | #7A8B6F | 后调 / 鼠尾草 |
| --cream | #F5EFE0 | 奶油背景 |
| --wood | #4A3829 | 木质基座 |
| --brass | #B8860B | 黄铜管风琴框架 |
| --parchment | #F0E6CC | 羊皮试香条 |

调性语义色：前调 #E8A04A（琥珀）、中调 #C77B8A（玫瑰）、后调 #7A8B6F（鼠尾草），三色一一对应金字塔三阶与试香条晕染色。

## 字体
- 标题/正文：`"Georgia", "SimSun", serif`——衬线带来古典实验台气质，中英文混排稳定。

## 材质语言
玻璃瓶身（CSS/SVG 绘制）+ 琥珀色液体层 + 黄铜管风琴框架 + 羊皮试香条 + 木质基座。材质贯穿全局，非局部点缀。

## 动效系统（14 项组件级特效，液体/精油物理逻辑）
CSS keyframes：blotGrow（试纸吸收晕染）、bottleVibrate（瓶身演奏振动）、cursorPulse（光标脉冲）、dustFloat（尘埃漂浮）、haloPulse（嗅闻光晕）、revealBreath（揭幕覆盖层呼吸）、rippleOut（黄铜涟漪）、tierGlow（金字塔阶点亮）。
JS 驱动：液体滴落上浮（拉长形变）、精油漩涡涟漪、试纸吸收晕染、金字塔渐进填充、瓶身悬停上浮、玻璃高光、木座阴影。
- 禁整图缩放 Ken Burns。
- RAF 随页面可见性暂停、卸载取消；滴粒子带节流；拖拽高频事件直接操作 DOM；`prefers-reduced-motion` 全量降级。

## 核心交互
1. 点击 / 按住拖拽滑过瓶身 → 演奏（瓶身振动 + 黄铜涟漪 + 金色液滴从瓶底滴落至试香条）
2. 试香条累积对应色调晕染斑迹 → 配方成型
3. 金字塔前/中/后调按调性实时归位渐满
4. 演奏 ≥3 种不同精油后激活「嗅闻揭幕」→ 试香条散发三调光晕、金字塔三阶点亮、显示配方名（可自定义命名）

## 内容
13 种真实精油：前调（佛手柑、柠檬、甜橙、葡萄柚）、中调（玫瑰、茉莉、薰衣草、天竺葵、依兰依兰）、后调（檀香、雪松、广藿香、岩兰草），每瓶含中英文名与气味描述。

## 自定义光标
金色液滴光标，开页即显示在屏幕中央，高对比，层级最高。

## 技术栈
纯 vanilla 单文件（HTML + CSS + JS），无 React/Babel/CDN，无外部图片（瓶身与液体全部 SVG/CSS 绘制）。

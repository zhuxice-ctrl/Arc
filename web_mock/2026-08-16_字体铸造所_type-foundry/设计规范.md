# 设计规范 · 字体铸造所 Type Foundry

> 方向：V1 网页设计 · 日期 2026-08-16 · 瑞士国际主义排版风（Swiss International Typographic Style）

## 色彩系统

| 角色 | 色值 | 用途 |
|---|---|---|
| 纸白 / 主底 | `#FAFAF7` | 大面积留白底色，瑞士海报的呼吸感 |
| 信号红 / 强调 | `#E4002B` | 强调色块、关键标签、CTA、网格刻度高亮 |
| 墨黑 / 文字 | `#141414` | 标题与正文文字、深色色块 |
| 中灰 / 辅助 | `#8A8A82` | 次要文字、分隔线、刻度文字 |
| 浅灰 / 表面 | `#E8E6DF` | 分区表面、卡片底、时间轴轨道 |

配色原则：大面积纸白 + 红黑强烈对比，拒绝蓝紫渐变；红色仅作点缀与强调，不堆砌。

## 字体系统

- 标题：`'Archivo Black', sans-serif`（极粗无衬线，海报级字重）
- 正文：`'Inter', 'PingFang SC', 'Microsoft YaHei', sans-serif`（中性无衬线，中英文混排）
- 衬线点缀：`Georgia, serif`
- 等宽标注：`'JetBrains Mono', monospace` / `'Courier New', monospace`（刻度、参数、技术标注）

## 组件规范

- 巨型排版 Hero：三行滑入式标题 + 打字机逐字入场
- 字体试排工坊：输入框 + 字体家族（Sans/Serif/Mono）切换 + 字号滑杆（24–200px）+ 7 档字重 + 字距 + 三向对齐 + 预设（海报/标题/正文）+ 一键重置
- 字体家族陈列卡：3D 物理插值倾斜 + 悬停字重频谱柱动画 + 发光边框
- 网格系统：12 列栅格叠加线，可开关，淡入淡出
- 时间轴：横向滚动，8 个节点，悬停圆点放大
- 海报画廊：3 张瑞士风海报，鼠标惯性视差
- 数据统计：4 项数字计数动画（easeOutExpo）
- CTA 磁吸按钮：反平方引力磁性吸附 + 光泽扫过
- Marquee 页脚：无限滚动字幕

## 动效系统（14 项组件级特效）

| # | 动效 | 原理 |
|---|---|---|
| 1 | 自定义光标 | 弹簧跟随 + 悬停放大 + 点击涟漪 |
| 2 | 打字机 | 逐字入场，可变速 |
| 3 | Hero 行入场 | 错峰滑入 |
| 4 | 数字计数 | easeOutExpo 缓动 |
| 5 | 3D 卡片倾斜 | 鼠标位移物理插值 |
| 6 | 海报视差 | 惯性插值 |
| 7 | 磁性按钮 | 反平方引力吸附 |
| 8 | 光泽扫过 | 伪元素 translate 扫光 |
| 9 | 字重频谱柱 | 悬停触发柱状动画 |
| 10 | 滚动渐入 | IntersectionObserver |
| 11 | 网格淡入淡出 | opacity 过渡 |
| 12 | Logo 脉冲点 | 周期缩放 |
| 13 | 跑马灯 | 无限 transform 循环 |
| 14 | 时间轴节点 | 悬停放大 |

动效周期各不相同，禁止整图缩放 / Ken Burns。`requestAnimationFrame` 随 `visibilitychange` 暂停；`prefers-reduced-motion` 全量降级。

# 设计规范 · 年画印坊（木版年画套版层叠站）

> 类别：Web Mock　日期：2026-08-19
> 形态：桌面/响应式网页（叠版层叠式空间模型）

## 设计母题
整个网站是一张正在被套印的木版年画——内容随印刷进程逐版展开，用户像在作坊里看师傅一版一版把年画印出来。题材：中国传统木版年画（门神·秦琼尉迟恭）。

## 空间模型
- **叠版三栏**：左侧版层索引（壹墨线/贰朱砂/叁槐黄/肆品绿/伍桃红）｜中央宣纸画布（SVG 五层叠加的门神）｜右侧编辑式内容章节。
- 非卡片 Grid、非 Hero Landing；以「版层堆叠」作为唯一空间逻辑。
- 响应式：1440 桌面三栏 → 1024 紧凑 → 390 移动纵向堆叠。

## 字体系统
- 标题：`"Ma Shan Zheng", "Noto Serif SC", serif`（榜书/手写感）
- 正文：`"Noto Serif SC", "Songti SC", "SimSun", serif`（宋体）
- 字体来自飞书字体 CDN。

## 动效系统（≥12 组件级，符合纸张/油墨/木印物理）
CSS keyframes（源码提取）：`alignShake`（对版微晃抖动）、`chapterFade`（章节淡入上移）、`eyeOpen`（开眼点睛 Signature Moment）、`inkSpread`（油墨晕染）、`pressDown`（纸张按压）、`rollerSweep`（滚筒过墨扫过）。
另有：宣纸落纸、版层入场模糊消散、进度杆节点弹缩、印章盖落回弹、光标弹性跟随与形态切换、悬停项位移动画。全部贴合印刷物理，无粒子/光晕/Ken Burns。

## 核心交互
1. 拖动顶部「套印进度杆」（0~5）→ 画布逐版叠色。
2. 点击左侧版层索引 → 跳转/单独切换该版显隐。
3. 对版微调（横向/纵向偏移滑杆）→ 模拟套印误差，一键复位带回弹。
4. 键盘 ← → 翻版。
5. 末版「开脸」点睛为 Signature Moment。

## 内容真实性
五章真实年画知识：刻线版工艺与梨木存放三年、门神秦琼尉迟恭由来、朱砂颜料、槐金甲胄与胖娃娃题材、品绿配色与四大产地（杨柳青/桃花坞/武强/朱仙镇）风格差异、桃红开脸与灶王题材。无 Lorem Ipsum。

## 技术栈
- 单文件 HTML（内联 CSS+JS+SVG），React+Babel via 飞书 CDN（jsx 内联在 `text/babel`，无外部 src）。
- 自定义光标开页居中、高对比、层级最高；`prefers-reduced-motion` 降级；页面隐藏暂停 RAF；零 Console 严重错误。
- 经 Browser QA：1440/1024/390 三档渲染正常、截图非空白、无 console severe。

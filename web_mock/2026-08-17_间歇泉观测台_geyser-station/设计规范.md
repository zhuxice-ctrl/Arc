## 组件规范

- **导航栏**：固定顶部，滚动收缩 + 毛玻璃效果，高度 64px→48px
- **数据卡片**：圆角 12px，深色底 #1a1a1a，边框 1px solid #262626，悬停光泽扫过
- **按钮**：圆角 8px，主色 #E85D2F 底白字，悬停发光
- **脉冲点**：三种颜色（橙/青/红），不同周期呼吸动画
- **时间线**：左侧竖线 + 圆点节点，交替左右布局

## 页面结构

1. **Hero**：大标题 + 打字机副标题 + 喷发倒计时 + 蒸汽粒子背景
2. **实时监测面板**：4 座间歇泉数据卡（Old Faithful / Strokkur / Fly Geyser / Waimangu）
3. **喷发模拟**：Canvas 四阶段动力学循环（加热→压力→喷发→消散）
4. **地质科普**：原理三卡片 + 四阶段形成图解
5. **观测网络**：SVG 世界地图 + 脉冲标记点 + 站点列表
6. **历史时间线**：1870–2018 四大事件
7. **Footer**：导航 + 版权

## 技术栈

- 纯 vanilla HTML/CSS/JS 单文件
- Canvas 2D API（喷发模拟）
- SVG + SMIL（频谱、地图）
- IntersectionObserver（滚动渐入）
- requestAnimationFrame（粒子、光标）
- 支持 prefers-reduced-motion
- visibilitychange 自动暂停/恢复动画

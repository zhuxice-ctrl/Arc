# 设计规范 · 纸上蝶 · 剪纸蝴蝶艺术展

> 方向：网页设计（V1） · 日期：2026-08-17 · 主题：中国传统剪纸蝴蝶艺术在线展览

## 色彩系统

中国传统纸艺美学，宣纸底色 + 墨色排版 + 朱砂红点缀 + 金箔装饰 + 翠玉绿辅助。

| 角色 | 色值 | 用途 |
|------|------|------|
| 主背景 | #f8f5ed | 宣纸白，全站底色 |
| 主文字 | #1a1a1a | 墨黑，标题与正文 |
| 强调色 | #d4423a | 朱砂红，印章/按钮/高亮 |
| 装饰色 | #c8a548 | 金箔，装饰线/分割线/光标内点 |
| 辅助色 | #5a8a6a | 翠玉绿，次要标签/自然元素 |
| 次背景 | #f0ebe0 | 浅宣纸，卡片底色 |
| 深底色 | #2a2a2a | 艺术家区块深色反转 |

## 字体系统

- 标题：`"Noto Serif SC", "Songti SC", serif` — 衬线体，端庄古典
- 正文：`"Noto Sans SC", "PingFang SC", sans-serif` — 无衬线，清晰易读
- 印章/装饰：`"KaiTi", "STKaiti", serif` — 楷体，传统书法感

## 圆角与间距

- 卡片圆角：8px（克制，不过度圆润）
- 按钮圆角：4px
- 印章圆角：50%（圆形）
- 间距体系：8px / 16px / 24px / 40px / 64px

## 动效系统

| 动效 | 触发方式 | 实现原理 |
|------|----------|----------|
| 自定义光标 | 鼠标移动 | 白色粗环 + 朱砂红内点 + 金箔光晕，rAF 跟随，悬停放大变色 |
| 点击涟漪 | 鼠标点击 | 动态创建 div + CSS scale 动画消散 |
| 粒子蝴蝶群 | 自动 | Canvas 绘制微型剪纸蝴蝶，缓慢漂浮 + 翅膀扇动 |
| 3D 倾斜 | 鼠标悬停 | 卡片跟随鼠标位置计算 rotateX/rotateY，直接操作 DOM transform |
| 滚动渐入 | 滚动 | IntersectionObserver 触发 reveal 动画 |
| 悬停发光 | 鼠标悬停 | 卡片抬升 + 顶部渐变彩条 + 印章弹跳 |
| 打字机 | 自动 | 首屏副标题逐字显示，循环 |
| 数字计数 | 滚动入视 | easeOutCubic 缓动计数到目标值 |
| 视差 | 鼠标移动 | 背景随鼠标微移，导航栏毛玻璃 |
| 光泽扫过 | 鼠标悬停 | 按钮 shine 伪元素扫光 |
| 翅膀扇动 | 悬停/自动 | CSS @keyframes flap 动画 |
| 印章脉冲 | 自动 | CSS 呼吸发光 animation |
| 导航下划线 | 悬停 | 红线从中间向两侧展开 |
| 表单提交 | 点击提交 | 成功态缩放弹入 + 庆祝蝴蝶生成 |

## 页面结构

1. **首屏 Hero** — 大标题 + 打字机副标题 + 主视觉剪纸蝴蝶 + 双 CTA 按钮
2. **展览介绍** — 双栏布局 + 装饰相框 + 数字计数器（128 件 / 36 位 / 90 天）
3. **蝴蝶图鉴** — 8 种 SVG 剪纸蝴蝶 + 4 类 Tab 筛选 + 3D 倾斜卡片
4. **艺术家介绍** — 深色反转区 + 剪纸风格肖像 + 朱砂印章浮动
5. **互动展区** — 8 只可交互飞行蝴蝶，鼠标吸引 + 点击召唤
6. **参观预约** — 展览信息卡 + 完整预约表单 + 提交成功动效

## 技术栈

- 纯 vanilla HTML/CSS/JS 单文件实现
- 零外部 CDN 依赖
- Canvas 粒子系统
- IntersectionObserver 滚动监听
- CSS @keyframes + JS rAF 动画
- 支持 prefers-reduced-motion 降级

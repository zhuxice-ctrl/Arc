# Featherline 田野图鉴 · 设计规范

- 日期：2026-08-17
- 方向：V1 网页设计（单页品牌官网 / 自然博物学手稿 × 现代杂志）

## 色彩系统

| 角色 | 色值 | 用途 |
|------|------|------|
| 羊皮纸底 | `#F4ECD8` | 页面主背景 |
| 羊皮纸深阶 | `#EBE1C6` / `#E0D4B5` | 卡片、分区底 |
| 赭石（主色） | `#B5651D` / 深阶 `#8A4A10` | 标题强调、按钮、时间轴 |
| 苔绿（辅助） | `#4A6B3A` / `#6B8E50` / `#2F4A24` | 居留型标签、生态语义 |
| 靛蓝墨（对比） | `#1E3A5F` / `#3A5A8C` / `#122642` | 时间轴深底区、拉丁名 |
| 燃橙（强调） | `#E8590C` / `#F57A2B` / `#B84008` | 光标内点、数据高亮、hover |
| 羽毛炭（正文） | `#2B2419` / `#1E1A12` / `#4A4132` | 正文、深底区文字 |
| 暖金 | `#D48B3F` | 装饰线、渐变过渡 |

无蓝紫渐变；渐变仅限同族暖色（羊皮纸 → 赭石 / 琥珀）。

## 字体

- 展示标题：`Cormorant Garamond`（斜体衬线，品牌名 / Hero）
- 正文中文：`Noto Serif SC`（300–700）
- 数据 / 时间戳：`JetBrains Mono`
- 手写引言：`Caveat`

## 圆角与表面

- 卡片圆角：3–4px（手稿纸感，刻意克制）
- 胶囊 / 标签：99px 全圆角
- 圆形元素：50%
- 表面分层：羊皮纸底 + 1px 暖灰边 + 柔和投影（无大圆角毛玻璃）

## 页面结构（6 区块）

1. Hero：SVG 手绘朱雀 + 打字机 slogan + 「第 7 卷 · 立秋候鸟志」
2. 今日观察：3 条田野记录卡片
3. 物种索引墙：6 物种卡片（中文名 + 拉丁名 + 体长/翼展 + SVG 羽毛）
4. 田野日志摘录：散文式观鸟日记
5. 当季候鸟时间轴：靛蓝深底、24 密度柱 + 8 候鸟条目、横向滚动
6. 页脚：手写体引言逐字浮现 + 版权

## 动效系统（14 个组件级特效）

- 自定义光标（开页居中 / 白环 + 燃橙内点 / 悬停放大变色 / 点击涟漪）
- Canvas 羽毛粒子飘落（空气阻力：速度衰减 + 摆动，密度随滚动变化）
- Hero 鸟翅膀不对称周期扇动、尾羽轻摆
- 物种卡 mousemove 3D 倾斜（直接 DOM transform）
- hover 羽毛抖动、卡片光泽扫过
- IntersectionObserver 滚动渐入
- 数字计数、打字机 slogan、Hero 视差
- 时间轴条目脉冲、导航吸顶变色、页脚逐字浮现

## 健壮性

- 纯 vanilla 单文件，零外部 CDN 依赖（字体自托管镜像）
- rAF / 定时器随 `visibilitychange` 暂停，卸载统一取消
- 支持 `prefers-reduced-motion` 降级；触屏自动隐藏自定义光标

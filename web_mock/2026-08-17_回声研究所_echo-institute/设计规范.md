# 设计规范 · 回声研究所 Institute of Echoes

> 日期：2026-08-17 · 方向：V1 网页设计 · 主题：声音艺术驻留与展览机构官网

## 色彩系统

| 角色 | 色值 | 用途 |
|---|---|---|
| 主色 · 烧赭石 | `#D9642A` | 标题强调、CTA、频谱柱、光标内点 |
| 底色 · 深墨 | `#1A1612` | 页面深色区段背景、正文暗底 |
| 纸面 · 暖骨纸 | `#F2EBDF` | 主背景、卡片表面 |
| 辅助 · 苔藓绿 | `#6B7F3E` | 次级标签、链接 hover |
| 辅助 · 氧化青 | `#3A5249` | 数据区、次级强调 |
| 深赭 | `#8C3A1A` | 标题描边、印章感元素 |
| 浅纸 | `#E6DDCB` | 卡片分隔、表单底 |
| 灰文 | `#5a534a` | 辅助正文 |

配色完全避开蓝紫渐变，以暖纸 + 烧赭 + 苔绿构建声音艺术机构的温润质感。

## 字体

- 标题：`'Cormorant Garamond', serif`（衬线，展览级气质）
- 正文：`'Space Grotesk', sans-serif`
- 数据/编号：`'JetBrains Mono', monospace`

## 页面结构（单页到底）

1. 英雄区 — 64 根频谱柱 + 卷轴 reel SVG 视差背景 + 主标题
2. 横向跑马灯 — 展览主题滚动（hover 暂停）
3. 展览卡片网格 — 含一张 2× 大 featured card
4. 数据统计 — 数字计数动画（IntersectionObserver 触发）
5. 驻留艺术家 — 头像脉冲环
6. 驻留项目 — 打字机 + Tab 切换
7. 试听室 — 真转动黑胶 + 唱针落下 + 播放列表 + 进度条
8. 页脚 — 订阅表单

## 动效系统（12+ 组件级）

1. 自定义光标（弹簧阻尼跟随，白环 + 赭点 + 多层发光，悬停放大变色、点击涟漪）
2. 英雄区 64 根频谱柱（每根独立弹簧振荡，不同频率/权重）
3. 卷轴 reel 背景 SVG 视差
4. 漂浮尘埃粒子（正弦 wobble + 边界包裹）
5. 卡片 3D 倾斜（perspective + RAF lerp）
6. 卡片内波形条（独立振荡）
7. 数字计数（easeOutCubic）
8. 头像脉冲环（悬停呼吸光晕）
9. 打字机效果（变速 + 循环切换 4 段文案）
10. 黑胶旋转 + 唱针落下 + 播放/暂停
11. 滚动渐入（IntersectionObserver + translateY）
12. 磁性按钮（反平方引力拖拽）
13. 顶部滚动渐变导航
14. 跑马灯悬停暂停
15. CTA 按钮光泽扫过

## 健壮性

- 所有 RAF / 定时器在 `visibilitychange` 时暂停、卸载时取消
- 重建定时器前先 clear，避免叠加
- mousemove 驱动的倾斜/视差/光标直接操作 DOM transform，不走 React setState
- 支持 `prefers-reduced-motion`，移动端降级原生光标

## 技术栈

React 18 + Babel standalone（JSX 内联于 `<script type="text/babel">`），CSS 内联 `<style>`，无外部组件文件。

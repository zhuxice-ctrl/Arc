## 组件规范

- **自定义光标**：36px 白色粗环 + 6px 荧光青绿内点 + 48px 外发光环；悬停放大至 56px、内点变白；点击缩放 0.7 + 涟漪扩散
- **卡片**：深色半透明底 + 荧光边框 + 3D 倾斜（鼠标映射 + 惯性阻尼）+ 光泽扫过
- **导航栏**：固定顶部，滚动时收缩高度 + 增加毛玻璃效果
- **按钮**：荧光描边 + 悬停发光扩散 + 点击涟漪
- **表单**：深色输入框 + 荧光下划线聚焦态

## 动效系统

共 16 个组件级特效：

1. 自定义光标（弹簧阻尼跟随 + 三态变化 + 点击涟漪）
2. 深海背景粒子（脉动发光 + 缓速漂移）
3. 上浮气泡（随机尺寸/周期）
4. 鼠标跟随深渊光斑
5. 打字机 slogan（打字 + 回删循环）
6. 3D 卡片倾斜（惯性阻尼 + 鼠标映射）
7. 光泽扫过卡片
8. 滚动渐入（上/左/右三向 + 阶梯延迟）
9. 深度条进场填充
10. 生物图鉴切换形变
11. 声谱可视化（多频率正弦叠加 + 呼吸待机模式）
12. 深度模拟器（拖动 + 点击弹簧缓动）
13. 数字计数动画（easeOutExpo）
14. 深海生物 SVG 呼吸漂浮 + 发光点脉冲
15. 导航栏滚动收缩
16. 表单提交反馈动画

## 页面结构

1. **首屏 Hero** — 展览主视觉 + 打字机 slogan + 粒子背景
2. **四大展区** — 鮟鱇鱼 / 巨型乌贼 / 管虫 / 水熊虫卡片
3. **生物图鉴** — 6 种深海生物可切换详情面板，含手绘 SVG
4. **互动体验** — 深海声谱可视化 + 深度模拟器（拖动潜水器）
5. **展览信息** — 展期 / 地点 / 时长 + 数字计数动画
6. **参观预约** — 完整可交互表单

## 技术栈

- 纯 vanilla HTML/CSS/JS 单文件，无外部依赖
- RAF 积分器驱动物理动画
- visibilitychange 暂停 + beforeunload 清理
- prefers-reduced-motion 完整降级

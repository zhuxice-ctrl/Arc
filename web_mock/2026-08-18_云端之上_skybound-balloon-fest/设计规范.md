# 设计规范 · 云端之上 Skybound · 高原热气球节官网

- **日期**：2026-08-18
- **方向**：V1 网页设计
- **主题**：高原热气球节「云端之上 Skybound」官方网站——单页艺术品级节庆官网

## 色彩系统

大地色系，禁止蓝紫渐变。主色陶土红，强调沙金，底色石灰白，深色文字深栗棕，辅助墨橄榄。

| 角色 | 色值 | 用途 |
|---|---|---|
| 主色 | `#C1502E` | 陶土红，主标题/主按钮/热气球球皮 |
| 强调色 | `#D9A441` | 沙金，强调装饰/光晕/票务高亮 |
| 辅助深色 | `#4A5230` | 墨橄榄，次级文字/分隔/草甸元素 |
| 底色 | `#F4EDE0` | 石灰白，页面底色 |
| 文字深色 | `#3B2A20` | 深栗棕，正文标题 |
| 浅米 | `#E8DCC5` | 卡片次表面/分隔 |
| 纸白 | `#FBF6EC` | 高光表面 |
| 日光金 | `#F9EFD8` | Hero 日光渐变端 |
| 辅助红 | `#A84225` | 深陶土红，hover/按下 |
| 钢蓝点缀 | `#8FB0C9` | 高空色点缀（非渐变主调） |

局部允许暖色渐变（橙金日出方向），禁止蓝紫渐变。

## 字体

中文：`"PingFang SC", "Microsoft YaHei", -apple-system, BlinkMacSystemFont, sans-serif`
英文标识：`Georgia, "Times New Roman", serif`（节日名 Skybound 装饰用）
数字：等宽 `ui-monospace, "SF Mono", monospace`

## 组件规范

- 按钮：陶土红底+沙金描边，圆角 8px，悬停抬升 4px + 光泽扫过，点击涟漪。
- 卡片：石灰白底 + 1px `#E8DCC5` 描边 + 柔和阴影；hover 抬升 + 阴影加深。
- 票卡：三档，选中态沙金顶色条从左滑满宽 350ms。
- 时间轴：水平进度线随滚动填充，节点脉冲。
- 热气球：CSS/SVG 绘制拼布球皮，每只独立漂浮周期。

## 动效系统

自定义光标（开页居中、白环+陶土红内点+多层发光、悬停放大、点击涟漪，弹簧阻尼跟随）、热气球浮空物理（正弦+阻尼，8 只周期各异）、标题入场序列、数字计数（IntersectionObserver 触发）、3D 卡片倾斜（直接操作 DOM transform）、光泽扫过、时间轴进度线、SVG 热点脉冲、画廊滚动视差（惯性阻尼）、打字机标语、按钮磁性吸附、页面滚动进度指示、气球拼布悬停微旋、导航栏滚动背景切换、卡片滚动渐入。共 15 个组件级特效，周期各不相同。

## 页面结构

1. Hero 主视觉（晨光+拼布热气球+标题入场）
2. 数字统计栏（4 项滚动计数）
3. 节庆日程（三天时间轴+Tab 切换）
4. 飞行员阵容（3D 倾斜卡片）
5. 票务（三档票卡+展开权益）
6. 场地指南（SVG 峡谷地图+热点）
7. 历届瞬间（横向视差画廊）
8. 页脚（订阅表单+合作方）

## 健壮性

RAF/定时器随 `visibilitychange` 暂停、卸载统一取消；重建前先 clear；高频 mousemove 直接操作 DOM transform；支持 `prefers-reduced-motion` 降级；移动端隐藏自定义光标回退系统指针。

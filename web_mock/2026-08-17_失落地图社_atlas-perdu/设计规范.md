## 字体

- 标题：`'Cormorant Garamond', 'Lora', serif` — 衬线，古典制图气质
- 装饰标题：`'IM Fell English', serif` — 古印本风，用于品牌字与章节标题
- 正文：`'Lora', Georgia, serif` — 易读衬线
- 数字 / 标签：系统无衬线兜底

## 组件规范

- **藏品卡片**：羊皮纸浅底 + 深棕描边 + 金箔顶饰条；悬停 3D 倾斜 + 光泽扫过；点击展开模态（卷轴展开动效）。
- **航线图**：SVG `stroke-dashoffset` 动态绘制 + 虚线流动，锈红主色。
- **数据条**：深棕墨底 + 金箔数字滚动计数。
- **导航栏**：透明 → 滚动后羊皮纸底 + 深棕描边渐变。
- **按钮**：锈红实底 / 金箔描边两档；金色光泽扫过 + 悬停发光。

## 动效系统

12+ 组件级特效，全部符合物理 / 主题语义，无整图缩放 Ken Burns：

1. 自定义光标（白环 + 锈红内点 + 金色多层发光，开屏居中显示，hover 放大，点击涟漪）
2. Hero 三层古地图视差（鼠标 + 滚动双驱动，直控 DOM transform）
3. 罗盘玫瑰缓慢自转
4. 藏品卡片 3D 倾斜（mousemove 直控 DOM）
5. 打字机导语（多文本循环）
6. 数字计数动画（IntersectionObserver 触发）
7. 滚动渐入（IntersectionObserver）
8. 按钮金色光泽扫过 + 悬停发光
9. 点击涟漪
10. 航线路径 SVG stroke-dashoffset 绘制 + 虚线流动
11. 卡片光泽扫过（sheen）
12. 扬尘粒子系统（25 粒独立相位漂浮）
13. 模态羊皮纸卷轴展开
14. 导航栏滚动渐变

## 页面结构

单页滚动网站，5 大板块：

1. **Hero**：三层古地图视差 + 旋转罗盘玫瑰 + 打字机导语 + 双 CTA
2. **藏品图鉴**：9 张古地图卡片，7 类筛选（年代 / 区域 / 工艺），点击展开详情模态
3. **数据统计**：深色馆藏数据条（4 项数字滚动计数）
4. **探险航线**：5 条著名航线可切换，SVG 路径动态绘制 + 虚线流动
5. **制图工艺**：4 章故事（铜版雕刻 / 手工着色 / 羊皮纸 / 装饰图饰）

## 技术栈

React 18 + Babel standalone（内联 JSX）+ 纯 CSS（内联 `<style>`），单文件 index.html。无外部 UI 框架。CDN：feishu-static miaoda coding-unpkg-sdk。

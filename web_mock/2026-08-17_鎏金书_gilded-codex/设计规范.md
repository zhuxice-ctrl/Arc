# 设计规范 · 鎏金书 Gilded Codex

> 方向：V1 网页设计 · 金缮手抄本经文艺术展 · 2026-08-17

## 色彩系统

| 角色 | 色值 | 用途 |
|------|------|------|
| 主色（陈年酒红） | `#6B1F2E` | 标题、强调、深色块 |
| 深酒红 | `#4A1520` | hover、阴影底 |
| 暗红 | `#8A2A3D` | 次级强调 |
| 强调金（古金） | `#C9A24B` | 金箔标题、边框、高亮 |
| 暗金 | `#8C6D2E` | 金色阴影、次级金 |
| 亮金 | `#E5C97A` | 扫光、光泽高光 |
| 底色（羊皮纸） | `#F4E8D0` | 页面主背景 |
| 旧纸 | `#E8D9B8` | 卡片底、分区 |
| 墨色 | `#1A1410` | 正文文字、深底 |
| 深褐 | `#3A2E24` | 次级文字 |

整体气质：温暖、古典、金箔手抄本质感，无蓝紫渐变。

## 字体

- 展示字体（display）：`'Cormorant Garamond', 'Songti SC', 'Noto Serif SC', 'Source Han Serif', Georgia, serif` —— 衬线，用于金箔标题、展品名。
- 正文字体（body）：`'Noto Serif SC', 'Songti SC', 'Source Han Serif', Georgia, serif` —— 衬线，正文统一衬线体，呼应手抄本气质。

## 组件规范

- 展品卡片：羊皮纸底 + 金色细边框（hover 时金框亮起发光），圆角，阴影分层。
- 金箔标题：渐变金色文字 + 扫光动画。
- 按钮：酒红实底 + 金色描边，hover 发光，点击涟漪。
- 时间轴：竖向轴线，金点节点，年代标签。
- 导航栏：滚动渐变（顶部透明→滚动后酒红实底）。

## 动效系统

13 个组件级特效：

1. 自定义光标：白色粗环 + 金色内点 + 多层发光，开页即显示在屏幕中央，悬停可交互元素放大，点击涟漪。
2. 金粉粒子飘落：缓慢下沉 + 轻微闪烁。
3. 滚动渐入：展品卡片错位依次浮现。
4. 卡片悬停金框发光。
5. Hero 3D 倾斜视差：手抄本图随鼠标轻微倾斜。
6. 数字计数：展品数量 / 年代统计滚动到位。
7. 金箔标题扫光。
8. 打字机：展陈序言逐字显示。
9. 按钮涟漪。
10. 羊皮纸视差滚动：背景纹理缓慢移动。
11. 印章脉冲。
12. 入场序列动画。
13. 导航滚动渐变。

动效遵循物理 / 主题语义（金粉重力下沉、扫光线性插值），严禁整图缩放 / Ken Burns；周期各不相同。高频鼠标事件直接操作 DOM transform。支持 `prefers-reduced-motion` 降级。

## 页面结构

单页滚动，含 7 大区块：

1. **Hero**：展览主视觉 + 金箔标题 + 3D 倾斜手抄本 + 飞玄阁印章。
2. **序言 Prologue**：打字机逐字显示展陈序言。
3. **展品画廊 Gallery**：6 件手抄本卡片（圣哥伦巴福音书、贝里公爵时祷书、林迪斯法恩福音书、金缮本《启示录》等），悬停金框 + 详情。
4. **金缮工艺 Craft**：4 步修复流程。
5. **千年时间轴 Timeline**：年代轴 + 金点节点。
6. **修复师手记 Conservator**：Eleanor Voss 第一人称手记。
7. **参观信息 Visit**：地址、时间、票务。

## 技术栈

纯 vanilla HTML/CSS/JS 单文件（index.html），无 React / Babel / 外部 CDN 依赖，所有代码内联。可直接浏览器打开。

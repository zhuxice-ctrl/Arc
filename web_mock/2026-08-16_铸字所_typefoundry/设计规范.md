## 主题

百年古法活字铸造工坊品牌官网

## 配色

铅灰 #2B2F33 + 朱砂红 #C03A2B + 米白纸色 #F5F0E6 + 油墨黑 #1A1C1E

## 字体

Unna + Noto Serif SC + Space Mono

## 动效设计

铅字立体视差 / 油墨晕染 / 金属光泽扫过 / 导航滚动收缩 / 工艺卡片3D倾斜

## 技术实现

- 单文件 HTML 实现（CSS + JS 全内联）
- 自定义光标开页即居中显示
- RAF 统一管理，visibilitychange 自动暂停/恢复
- 支持 prefers-reduced-motion 降级
- 无外部 JSX 引用，无外部本地文件依赖

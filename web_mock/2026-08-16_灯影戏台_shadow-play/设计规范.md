# 灯影戏台 Shadow Play · 设计规范

> 日期：2026-08-16 ｜ 方向：V1 网页设计 ｜ 主题：皮影戏数字剧院

## 色彩系统

以"幕布后的灯光与剪影"为意象，墨黑做幕、朱红点血、暖金透光、宣纸米衬底。

| 角色 | 色值 | 用途 |
|---|---|---|
| 幕布底色 | `#14100C` | 页面主背景，最深的夜色 |
| 深幕过渡 | `#1C1611` / `#1a130d` / `#231911` / `#261E17` | 分层暗色，卡片/分区底 |
| 朱红 | `#C93B2E` | 主强调，皮影红、按钮、标题点缀 |
| 朱红亮 | `#E05A4D` | 朱红高光态 |
| 暖金 | `#E8B84B` | 次强调，灯笼光、描边、关键数字 |
| 暖金浅 | `#F0CE7A` | 暖金高光 |
| 宣纸米 | `#F3E9D2` | 正文文字、浅色衬底 |
| 米浅 | `#E8DCC0` | 次级正文/边框 |

## 字体

- 展示字：`ZCOOL XiaoWei`（标题、皮影题字，带笔锋的国风感）
- 正文字：`Noto Serif SC`（正文衬线，呼应古卷气质）
- 标签字：`JetBrains Mono`（序号、标签、英文小字）

## 组件规范

- 卡片：暗幕底 `#1C1611` + 朱红/暖金 1px 描边，悬停发光（box-shadow 暖金 0 0 24px）
- 按钮：朱红实底 + 暖金描边，光泽扫过（shimmer 1.6s 线性渐变）
- 影人卡：剪影 PNG + 信息浮起（translateY），悬停缩放 1.04
- 导航：顶部锚点链接，下划线展开（width 0→100% 240ms ease-out）
- 分割线：暖金 1px 渐隐

## 动效系统

12+ 组件级特效，全部基于 RAF 积分器 / 弹簧插值 / 主题语义：

1. 自定义光标：白色粗环 + 暖金内点，弹簧跟随（lerp 0.18），悬停放大 1.6×，点击涟漪
2. 浮动灯笼粒子：5 盏，正弦摇摆（各自相位/速度），多层发光
3. 金光尘埃粒子：30 粒向上飘升，寿命循环重生
4. 幕布透光呼吸：radial-gradient 透明度 0.6↔1 正弦呼吸（4s）
5. 开场幕布拉开：左右两片 cubic-bezier(0.7,0,0.3,1) 1.2s
6. Hero 皮影视差：鼠标位移驱动多层深度位移（RAF 积分，直接操作 transform）
7. 剧目卡片 3D 倾斜：弹簧插值 rotateX/rotateY + 鼠标光斑 radial
8. 滚动渐入：IntersectionObserver 触发 translateY+opacity
9. 打字机副标题：三句循环，光标闪烁 530ms
10. 数字计数器：easeOutCubic，进入视口触发
11. 皮鼓按钮涟漪：多层波纹扩散（scale 0→4 + opacity 衰减）
12. 影人卡悬停发光 + 缩放 + 信息浮起
13. 工艺环多层旋转：不同速度/正反方向
14. 主按钮光泽扫过：shimmer 线性渐变
15. 导航下划线展开

## 健壮性

- 全部 RAF/定时器在 `visibilitychange` 暂停，卸载清理
- 高频鼠标事件直接操作 DOM transform，不触发 setState
- `prefers-reduced-motion`：光标隐藏、动画暂停、计数器直显终值
- 全部 JSX/CSS 内联在 index.html，无外部 JSX src

## 页面结构

# 云锦织造局 · 设计规范

## 主题
南京云锦传统织造工艺品牌官网，以"寸锦寸金"为核心理念，展示云锦的纹样图谱、织造工艺、匠人故事与传习活动。

| 令牌 | 色值 | 用途 |
|------|------|------|
| --cinnabar | #C8392B | 朱砂红，主色调，印章/强调 |
| --vermilion | #A62A1F | 朱红深，按钮 hover/阴影 |
| --gilt | #D4A843 | 鎏金，装饰线/高亮 |

| --paper | #F5F0E6 | 宣纸白，页面背景 |
| --paper-deep | #E8DFCD | 宣纸深，卡片背景 |

| --ink-soft | #2B2B2B | 墨灰，次级文字 |

## 字体

- 主字体：`"Noto Serif SC", "STSong", serif` — 衬线体，体现传统工艺质感
- 背景色：`var(--paper)` 宣纸白
- 文字色：`var(--ink)` 墨黑

## 页面结构

1. **Hero 区** — 大标题"云锦织造局"+ 朱砂红印章，背景 Canvas 动态织机经纬线（经丝波动+纬丝穿梭流动+金色粒子飘散）
2. **纹样图谱** — 6 款纯 SVG 绘制的云锦纹样（龙纹/凤纹/牡丹/祥云/八宝/寿字），悬停放大+金色光泽扫过+信息浮入
3. **织造工艺** — 4 步滚动驱动工艺展示（选丝→染色→织造→成品），交错左右布局，数字计数动画
4. **匠人故事** — 4 位匠人卡片，3D 倾斜悬停效果+头像脉冲涟漪+从艺年数计数
5. **传习活动** — 4 场活动手风琴列表，点击展开详情
6. **页脚** — 品牌信息+三列导航

## 动效系统（12+ 组件级特效）

| 动效 | 类型 | 说明 |
|------|------|------|
| 自定义光标 | 交互 | 白色粗环+鎏金内点+多层发光，悬停变形，点击涟漪 |
| 织机经纬线 | Canvas | 经丝波动+纬丝穿梭流动，模拟织机运动 |
| 金色粒子飘散 | Canvas | 粒子随机飘散，金线质感 |
| 文字光泽扫过 | CSS | 金色渐变光泽从左到右扫过标题文字 |
| 印章脉冲 | CSS | 朱砂红印章呼吸脉冲 |
| 打字机标题 | JS | 逐字显现标题 |
| 数字计数 | JS | 滚动到视口时从 0 计数到目标值 |
| 纹样悬停光泽 | CSS | 悬停时金色光泽扫过纹样 |
| 3D 卡片倾斜 | JS | mousemove 驱动卡片 3D 旋转变换 |
| 头像脉冲环 | CSS | 匠人头像周围脉冲涟漪 |
| 滚动渐入 | JS | IntersectionObserver 驱动元素淡入上移 |
| 手风琴展开 | JS | 点击展开/收起活动详情 |
| 导航滚动变色 | JS | 滚动时导航栏背景变色 |

## 健壮性

- requestAnimationFrame/定时器随 visibilitychange 暂停，卸载时取消
- 高频鼠标事件（光标、3D 倾斜）直接操作 DOM transform
- 支持 prefers-reduced-motion，自动降级
- 所有 CSS/JS 单文件内联

## 技术栈

纯 vanilla HTML/CSS/JS 单文件，Canvas 2D 织机动画，SVG 纹样绘制，IntersectionObserver 滚动驱动。

# 设计规范 · 夏夜烟火祭 Hanabi Night

> 方向：网页设计（V1） · 日期：2026-08-17 · 主题：仲夏河畔烟火大会活动官网

## 色彩系统

夜空烟火气质，墨黑底 + 茜红 + 烟火金 + 暖月白五色体系。

| 角色 | 色值 | 用途 |
|------|------|------|
| 夜空墨黑（主背景） | `#0E1116` | 页面主底色 |
| 深炭黑 | `#23262B` | 卡片/分区底 |
| 极夜黑 | `#0a0c10` | 全屏花火画布底 |
| 茜红（强调） | `#C73E3A` | 主按钮/烟火/重点标题 |
| 暗茜红 | `#8F2A27` | 茜红阴影/渐变端 |
| 烟火金（强调） | `#D9A441` | 次强调/光晕/数字 |
| 暖金 | `#E8BE6A` | 金色高光 |
| 橙金 | `#ffb36b` | 灯笼暖光 |
| 暖月白（正文） | `#F4EBDD` | 主文字 |
| 暖灰 | `#C8BFB0` / `#8A8478` | 次级文字 |

## 字体

- 展示字体 `--font-display`：Noto Serif SC（衬线，标题/节目单）
- 正文字体 `--font-body`：Noto Sans SC（无衬线，正文/按钮）

## 组件规范

- 卡片：圆角 16px，深炭黑底 `#23262B`，悬停 3D 倾斜 + 金色光晕边
- 主按钮：茜红→暗茜红渐变，圆角 999px，光泽扫过动效
- 节目时间轴：左侧时间锚点 + 右侧节目卡，竖向连接线
- 座位图：网格点阵，hover 高亮席位档位
- 倒计时：四宫格数字块，等宽数字

## 动效系统

1. 自定义光标（白色粗环 + 金/茜色内点 + 三层发光，弹簧缓动跟随，开页居中）
2. 点击涟漪扩散
3. 烟花粒子系统（重力 + 摩擦 + 尾迹，菊/牡丹/柳/轮四种爆炸模式）
4. 星星正弦闪烁（相位错峰）
5. 河岸灯笼摇曳（不同周期/相位）
6. 打字机标题（随机节奏）
7. 数字计数（easeOutCubic，0→12000）
8. 倒计时（每秒更新，visibilitychange 暂停）
9. 卡片 3D 倾斜（mousemove 直接操作 transform）
10. 滚动渐入（IntersectionObserver，错开延迟）
11. 萤火虫浮动粒子（正弦闪烁 + 随机游走 + 边界反弹）
12. 光泽扫过按钮（线性渐变平移）
13. Logo 脉冲呼吸
14. 河面流动波纹（translate 循环）

## 页面结构

单页长滚：Hero 首屏（星空+烟花画布+河岸灯笼）→ 倒计时 → 节目单（五幕时间轴）→ 屋台摊位（6 卡）→ 观赏席位（3 档+座位图）→ 交通指南（4 卡）→ 夜空花火秀（全屏画布+点击发射）→ 页脚。

## 健壮性

- RAF 由 `rafManager` 统一管理，`visibilitychange` 暂停/恢复，`beforeunload` 清理
- 支持 `prefers-reduced-motion` 降级
- 移动端关闭自定义光标、响应式布局

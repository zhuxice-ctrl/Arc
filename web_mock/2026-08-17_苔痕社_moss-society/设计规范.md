# 苔痕社 Moss Society · 设计规范

## 色彩系统

| 令牌 | 色值 | 用途 |
|------|------|------|
| `--forest-deep` | `#1a3d2e` | 主背景 / 深色区块 |
| `--forest-mid` | `#2a5a42` | 次级背景 / 卡片底色 |
| `--forest-light` | `#3d7a58` | 辅助色 / 边框高亮 |
| `--moss-yellow` | `#b8d934` | 强调色 / 按钮主色 / 光标内点 |
| `--moss-yellow-soft` | `#d4e86b` | 强调色浅 / hover 态 |
| `--cream` | `#f5f0e1` | 浅色背景 / 正文文字 |
| `--cream-warm` | `#ebe4cf` | 卡片表面 / 分隔区 |
| `--cream-deep` | `#d9d0b5` | 边框 / 次级文字 |
| `--ochre` | `#c66a3a` | 点缀色 / 警示 / 装饰 |
| `--ochre-soft` | `#d98a5c` | 点缀浅色 |
| `--ink` | `#1a2a22` | 标题文字 / 深色文字 |
| `--ink-soft` | `#3a4a40` | 正文文字（深色背景） |

Hero 背景：`#0f2519` 渐变至 `--forest-deep`。

## 组件规范

- **导航栏**：透明初始态，滚动后背景渐变为 `rgba(26,61,46,0.95)`，padding 收缩
- **卡片**：圆角 16px，背景 `--cream-warm`，hover 时边框变为 `--moss-yellow` + 阴影加深 + 光泽扫过
- **按钮**：主按钮 `--moss-yellow` 底色 + `--ink` 文字，圆角 8px，hover 光泽扫过
- **苔藓图鉴卡片**：SVG 生成的苔藓插画，9 种品种，5 类筛选标签
- **活动日历**：真实月历组件，可切换月份，选中日高亮 `--moss-yellow`
- **模态框**：背景遮罩 `rgba(0,0,0,0.5)`，内容卡片 `--cream` 底色

## 动效系统

| 编号 | 动效 | 触发方式 | 物理模型 / 语义 |
|------|------|----------|----------------|
| 1 | 自定义光标（白色粗环+黄绿内点+发光） | 鼠标移动 | 双层缓动跟随，开页即显示在屏幕中央 |
| 2 | 苔藓孢子粒子飘浮 | 持续 | 40 颗粒子，物理式缓升+横向摆动+呼吸透明度 |
| 3 | 滚动渐入 | IntersectionObserver | 多级延迟阶梯式淡入上移 |
| 4 | 卡片悬停发光放大 | hover | 边框高亮+阴影+缩放 |
| 5 | 数字计数动画 | 进入视口 | easeOutCubic 缓动 |
| 6 | 图片视差滚动 | scroll | 叶片元素随滚动速率差偏移 |
| 7 | 导航栏滚动变色 | scroll | 透明度+背景+padding 过渡 |
| 8 | 苔藓纹理生长 | 页面加载 | 5 个模糊光斑依次放大淡入 |
| 9 | 涟漪点击效果 | click | 点击处扩散圆环 |
| 10 | 打字机标题 | 持续循环 | 4 句中英交替，随机打字速率 |
| 11 | 页面入场序列 | 页面加载 | Hero 元素阶梯式淡入上移 |
| 12 | 卡片光泽扫过 | hover | 斜向光带扫过 |

## 页面结构

1. **Hero 首屏** — 打字机标题 + 渐变入场序列 + 孢子粒子背景
2. **关于协会** — 统计数字计数 + 浮动卡片 + 视差叶片
3. **苔藓图鉴** — 9 种苔藓 SVG 插画 + 5 类筛选 + 点击弹详情模态框
4. **地衣专栏** — 3 个 Tab（图鉴/科普/生态功能），可展开
5. **活动日历** — 真实月历组件，可切月选日，6 场活动
6. **会员加入** — 3 档会员卡片 + 申请表单模态框
7. **页脚** — 联系方式 + 社交链接

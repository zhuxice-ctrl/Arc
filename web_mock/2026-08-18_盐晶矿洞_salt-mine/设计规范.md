# 盐晶矿洞博物馆 · 设计规范

## 配色系统

| 角色 | 色值 | 用途 |
|------|------|------|
| 矿物白 | #F5F2ED | 页面底色、卡片背景 |
| 琥珀蜜 | #C8902E | 主强调色、按钮、图标 |
| 深锈红 | #8B3A1F | 标题强调、展览标签 |
| 矿洞棕 | #2A1F15 | 深色背景、页脚 |
| 盐晶淡粉 | #E8C5C0 | 装饰色块、过渡区域 |
| 浅棕 | #d4c8b8 | 次要文字、分割线 |
| 中棕 | #6b5948 | 正文文字 |
| 暗棕 | #3d2e20 | 次级标题 |
| 深暗 | #1a120b | 最深背景层 |

## 字体系统

| 角色 | 字体栈 |
|------|--------|
| 标题/展示 | "Songti SC", "SimSun", "STSong", "Noto Serif SC", serif |
| 正文 | "Songti SC", "SimSun", "STSong", "PingFang SC", "Microsoft YaHei", sans-serif |

整体采用宋体衬线风格，呼应矿洞石刻与地质博物馆的厚重质感。

## 组件规范

- **卡片**：圆角 16px，背景 #F5F2ED，阴影 0 8px 32px rgba(42,31,21,0.12)
- **按钮**：琥珀蜜底色 #C8902E，白色文字，圆角 12px，hover 光泽扫过
- **标签**：深锈红 #8B3A1F 底色，白色文字，圆角 6px
- **时间线节点**：圆形 12px，琥珀蜜边框，矿洞棕填充
- **地图兴趣点**：脉冲呼吸动画，琥珀蜜色

## 动效系统（14 个组件级特效）

1. 自定义光标（白色粗环 + 琥珀内点 + 多层发光 + 点击涟漪）
2. 盐晶飘落粒子（Canvas，菱形/方形/六角三种晶形）
3. 3D 倾斜卡片（鼠标跟随旋转）
4. 滚动渐入（IntersectionObserver 触发）
5. 悬停发光（卡片边框 + 内部辉光）
6. 数字计数动画（easeOutExpo 缓动）
7. 光泽扫过（按钮/卡片对角线光带）
8. 视差滚动（区块标题微位移）
9. 晶体生长动画（Hero 区域晶体 scaleY 从 0 到 1）
10. 矿灯光斑追踪（跟随鼠标的锥形光）
11. 呼吸光晕（介绍图圆形辉光脉动）
12. 文字逐字浮现（Hero 标题逐字出现）
13. 地图点脉冲呼吸（7 个兴趣点标记）
14. 旋转光斑（特展视觉区 conic-gradient 旋转）

## 页面结构

1. Hero 盐晶森林（晶体生长 + 标题逐字 + 滚动指引）
2. 博物馆概览（4 项数据计数 + 图文介绍）
3. 历史沿革时间线（6 个年代节点，左右交替）
4. 矿物收藏（3 张 3D 倾斜标本卡）
5. 当前展览（年度特展大卡 + 3 个常设展小卡）
6. 互动矿洞地图（7 个兴趣点）
7. 参观信息 + 预约表单

## 健壮性

- 单文件内联，零外部依赖
- requestAnimationFrame 随页面可见性自动暂停
- 高频鼠标事件直接操作 DOM transform
- 支持 prefers-reduced-motion 全局降级
- 移动端关闭自定义光标与粒子

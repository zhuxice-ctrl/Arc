# 浮世花火 · 夏夜烟花大会 — 设计规范

> 方向：V1 网页设计 · 2026-08-18
> 主题：夏夜烟花大会活动官网（浮世绘风祭典氛围）

## 色彩系统

| 角色 | 色值 | 用途 |
|------|------|------|
| 主背景（墨黑夜空） | `#0a060d` / `#120810` | 页面底色，深墨黑略带紫调 |
| 次背景 | `#1a0f15` / `#2a1515` | 分区/卡片底，比主背景浅一阶 |
| 主色·朱红 | `#ff4d2e` | 烟花主色、强调色、链接、按钮 |
| 深朱红 | `#c1272d` / `#8a1a1a` | 标题异色、节目单红金条 |
| 鎏金 | `#ffd97a` / `#ffcc44` | 数字、徽章、装饰描边、灯笼 |
| 暖橙 | `#ff9a3c` / `#ff6a4a` | 烟花渐变次色、悬停高光 |
| 烟白 | `#fff8e7` / `#f2e8d5` | 正文文字、卡片前景 |
| 暖灰金 | `#c8b896` / `#8a7a5c` | 次要文字、分隔线、辅助说明 |

严禁蓝紫渐变；整体为暖色系浮世绘祭典调性。

## 字体排印

- 展示字体：`ZCOOL XiaoWei`（标题、节目单、大字）
- 衬线正文：`Noto Serif SC`（400 / 600 / 900）
- 无衬线辅助：`Noto Sans SC`（300 / 400 / 500 / 700，用于数字与说明）
- 来源：Google Fonts

## 组件规范

- **导航栏**：顶部固定，滚动后收缩；半透明墨黑底 + 金色描边下沿
- **节目单卡片**：左侧朱红/鎏金竖条 + 悬停右移；三夜 Tab 切换
- **工匠卡片**：3D 倾斜（mousemove 直接 transform），头像脉冲发光
- **票务卡**：三档席位，鎏金描边 + 光泽扫过伪元素动画
- **画廊**：筛选标签 + Lightbox 缩放过渡
- **按钮**：朱红实底 + 光泽扫过 + 点击涟漪

## 动效系统（≥12，全部基于物理/语义）

1. 全屏 Canvas 烟花系统：火箭升空（重力）+ 三种绽放（圆形/垂柳/双环），粒子带阻尼衰减
2. 自定义光标：白环 + 朱红内点 + 多层发光，悬停放大、点击涟漪
3. 余烬飘落粒子：小画布，带闪烁与飘动（布朗运动）
4. 灯笼视差：鼠标移动多层深度位移
5. 工匠卡片 3D 倾斜：mousemove 直接操作 DOM transform
6. 数字计数动画：easeOutCubic
7. 滚动渐入：IntersectionObserver
8. 按钮光泽扫过：伪元素位移动画
9. 节目单红金条 + 悬停位移
10. 头像脉冲发光
11. 地图标记点脉冲扩散
12. 画廊缩放 + Lightbox 过渡
13. 导航滚动收缩
14. 标题逐字异色入场
15. 点击页面任意位置发射烟花（交互彩蛋）

## 页面结构

大会缘起（含余烬画布 + 数字统计）→ 烟花节目单（三夜 21 场次）→ 烟花工匠（六位人间国宝）→ 会场地图与交通（SVG + 四种交通切换）→ 票务预约（三档席位）→ 历年回顾画廊（筛选 + Lightbox）。

## 健壮性

- 所有 RAF/定时器随 `visibilitychange` 暂停、卸载取消
- 高频 mousemove 直接操作 DOM transform，不触发 setState
- 支持 `prefers-reduced-motion` 降级
- 全部 JS/CSS 内联于单文件，无外部 fetch 依赖

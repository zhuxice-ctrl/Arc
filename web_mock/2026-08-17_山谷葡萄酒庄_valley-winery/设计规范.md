整体为冷暖对比的酒庄质感：酒红主导氛围、藤叶绿呼应葡萄园、橡木金点睛、羊皮纸作底，禁止蓝紫渐变。

## 字体

- 标题：`"Noto Serif SC", "Songti SC", serif`（衬线，古典书卷感）
- 正文：`"Noto Sans SC", "PingFang SC", sans-serif`（无衬线，清晰易读）

## 圆角与阴影

- 卡片圆角 12–16px；按钮圆角 8px；图片微圆角 6px。
- 阴影：`0 8px 30px rgba(92,26,36,.18)` 暖色调投影，与酒红色调统一。

## 组件规范

- **导航栏**：固定顶部，滚动收缩（高度/字距变化），羊皮纸底 + 金色描边。
- **Hero**：全屏大标题 + 打字机副标题 + 浮尘粒子 + 视差背景。
- **酒款卡片**：3D 倾斜（mousemove 直接操作 DOM transform）、悬停光泽扫过、点击弹出弹簧模态窗。
- **磁性按钮**：鼠标靠近时按钮向光标方向吸附（磁吸位移 + 回弹）。
- **预约表单**：输入聚焦金色下划线、提交成功涟漪反馈。

## 动效系统（12+ 组件级特效）

自定义光标（白环+金点+多层发光，开页居中，hover 放大/点击涟漪）、浮尘粒子、打字机副标题、数字计数、滚动渐入（错峰）、3D 卡片倾斜、磁性按钮、光泽扫过、视差滚动、酒瓶光影、弹簧模态窗、导航滚动收缩。动效周期各异，基于 RAF 积分器与弹簧/惯性模型。

## 页面结构

导航栏 → Hero 大标题 → 酒庄故事 → 风土特色 → 酒款典藏（红/白/桃红筛选）→ 酿造工艺 → 预约品鉴 → 页脚。

## 健壮性

RAF/定时器随 `visibilitychange` 暂停、卸载取消；高频 mousemove 直接操作 DOM；支持 `prefers-reduced-motion` 降级；JSX 全部内联于 `<script type="text/babel">`，无外部 JSX 引用。

## 技术栈

单文件 HTML + 内联 CSS + 内联 Babel/React JSX。

# 黑胶回廊 · 声音艺术馆 — 设计规范

- 日期：2026-08-18
- 方向：V1 网页设计（真实可交互的完整单页网站）
- 主题：黑胶唱片博物馆 / 昏暗聆听室氛围的线上声音艺术馆

## 色彩系统

| 角色 | 色值 | 说明 |
|---|---|---|
| 深炭黑底 | `#0A0908` | 页面最底层背景，模拟熄灯后的聆听室 |
| 炭黑次层 | `#1A1614` | 卡片 / 区块表面色 |
| 琥珀金（主强调） | `#D97706` | 标题强调、按钮、光标内点、频谱柱 |
| 亮琥珀 | `#F59E0B` / `#F5B548` | 光泽扫过、发光层级 |
| 酒红点缀 | `#9F2B2B` | 唱片标签、点缀色 |
| 米白主文 | `#F5EFE6` | 主文字 / 标题 |
| 暖灰次文 | `#D4C4A8` | 次级说明文字 |
| 深木色 | `#2A1F18` 等 | 胡桃木质感分区 |

整体为「深炭黑 + 暖琥珀金 + 酒红」的暗色聆听室体系，无蓝紫渐变。

## 字体

- 标题衬线：`'Playfair Display', 'Noto Serif SC', serif`
- 中文正文：`'Noto Sans SC', sans-serif`
- 中文衬线：`'Noto Serif SC', serif`

## 页面结构

单页沉浸式网站：Hero（旋转大唱片 + 打字机标题 + 数字统计）→ 馆藏封面廊（3D 倾斜 + 黑胶滑出）→ 聆听室（频谱柱振动 + 播放脉冲）→ 尾注。所有卡片 / 按钮 / 导航均可真实交互。

## 动效系统（14 个组件级特效）

1. 自定义光标：白色粗环 + 琥珀内点 + 多层发光，弹簧-阻尼跟随，开页即居中显示
2. 光标点击涟漪：圆环扩散衰减
3. Hero 大唱片匀速旋转（24 秒/圈，真实黑胶转速语义）
4. 唱片光泽扫过（对角渐变位移）
5. 馆藏封面 3D 倾斜（mousemove 直接操作 DOM transform，不经 React 重渲染）
6. 黑胶从封套滑出（hover 位移 + 旋转）
7. 频谱柱振动（每柱独立弹簧 + 正弦/噪声调制，播放/停止两态）
8. 打字机标题（随机间隔字符浮现）
9. 数字计数（easeOutExpo 缓动）
10. 滚动渐入（IntersectionObserver）
11. 尘埃粒子漂浮（正弦摇摆 + 缓慢上升，30+ 粒）
12. 卡片光泽扫过（hover 对角强光带）
13. 播放按钮脉冲环（声波扩散语义）
14. 滚动指示点（线性下落循环）

## 组件规范

- 卡片：炭黑表面 + 细边框 + 琥珀 hover 光泽；封面卡支持 3D 倾斜与抽片
- 按钮：琥珀描边 / 实底两态，hover 发光，点击涟漪
- 光标：固定最高层级，悬停可交互元素放大变色

## 健壮性

- 全部 RAF / 定时器随 `visibilitychange` 暂停、卸载取消
- 高频 mousemove 直接写 DOM transform
- 支持 `prefers-reduced-motion` 降级
- JSX 全部内联于 `index.html`，无外部 JSX 引用

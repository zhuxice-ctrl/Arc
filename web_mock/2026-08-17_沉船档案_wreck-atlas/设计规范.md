# 设计规范 · 沉船档案 The Wreck Atlas

方向：V1 网页设计 ｜ 主题：深海沉船沉浸式档案馆 ｜ 日期：2026-08-17

## 色彩系统

以「下潜」为叙事的深海色阶，从海面墨绿到深渊近黑，配磷光青与沉铜金作高光。

| 角色 | 色值 | 用途 |
|---|---|---|
| 深渊黑 | #010504 / #020807 | 页面最底背景、4000m 层 |
| 深海墨黑 | #05100E | 主背景 |
| 海藻绿 | #2E5E4E | 次级背景、卡片底 |
| 深海绿 | #0A2320 / #0D2922 / #3A7A64 | 层次面板、分割 |
| 磷光青 | #7EE8C7 | 强调色、光标内点、数据高亮 |
| 浅磷光 | #4FC4A0 | 次强调、声呐线 |
| 沉铜金 | #B08D57 | 文物金、标题点缀 |
| 古铜 | #6B4423 / #8B5E3C / #5C3D28 | 文物质感、边框 |
| 骨白 | #EDE6D6 | 主文字 |
| 砂灰 | #C8BFAD / #C9A874 | 次文字、标签 |
| 纯白 | #ffffff | 高对比标题 |

## 字体

- 正文/UI：`'Inter', 'Helvetica Neue', system-ui, sans-serif`
- 标题/展示：`'Playfair Display', serif`（衬线，营造档案/历史质感）
- 数据/代码：`'JetBrains Mono', monospace`（深度计、坐标、年代）

## 圆角

极克制：1–4px 为主，文物档案卡 12px，整体偏锐利冷硬，呼应金属/深海冷感。

## 组件

- 深度计：左侧固定竖向刻度，随滚动从 0m 推进至 4000m，数字 easeOutExpo 计数
- 声呐扫描器：旋转扇形 + 脉冲信号点，SVG 实现
- 沉船档案卡：Tab 切换（泰坦尼克/俾斯麦/圣何塞/南海一号），打字机标题 + SVG 剖面图
- 文物档案卡：3D 鼠标跟随倾斜 + 光泽扫过
- 声纹频谱：32 根声波柱，多正弦波合成振动
- 深度层时间线：节点涟漪脉冲

## 动效系统（14 项组件级）

1. 自定义光标（白环 + 磷光青内点 + 发光拖影，悬停形变，点击涟漪）
2. 海洋雪粒子（RAF 积分器摆动下落）
3. 光柱摇曳（多束不同周期入射光）
4. 声呐扫描（旋转扇形 + 脉冲点）
5. 数字计数（easeOutExpo，滚动触发）
6. 打字机标题（沉船切换逐字）
7. 3D 倾斜卡片（文物卡鼠标透视）
8. 光泽扫过（hover 斜向光带）
9. 频谱振动（32 柱多正弦合成）
10. 滚动渐入（IntersectionObserver）
11. 视差深度感（多层背景 + 光晕呼吸）
12. 时间线脉冲点（节点涟漪）
13. 导航 logo 声呐脉冲
14. 剖面扫描线 + 沉船 SVG 自身动画

所有 RAF/定时器随 `visibilitychange` 暂停，卸载取消；鼠标事件直操作 DOM transform；支持 `prefers-reduced-motion`。

## 页面结构（单页滚动叙事）

海面 Hero → 声呐扫描区 → 沉船档案（4 艘 Tab）→ 打捞文物（6 张卡）→ 声纹频谱 → 深度层剖面 → 深渊底部 Footer

## 技术栈

纯 vanilla HTML/CSS/JS 单文件，零外部依赖，零 React/Babel。

### 配色原则

- 底色为暖褐黑系（`#161310`），非冷黑或纯黑，营造深夜棋院暖灯氛围。
- 朱砂 `#B23A2A` 仅用于关键语义（印章、关键手刻度、关键手落盘），不大面积铺色。
- 竹青 `#6E7F5C` 用于选中/激活描边，与朱砂形成冷暖对比。
- 禁用蓝紫渐变、毛玻璃、发光球。

## 三、布局系统

CSS Grid 三栏 + 顶底条布局：

```
grid-template-rows: 56px 1fr 88px;
grid-template-columns: 200px 1fr 320px;
grid-template-areas:
  "topbar   topbar   topbar"
  "demolist board    paper"
  "control  control  control";
```

| 区域 | 尺寸 | 内容 |
|------|------|------|
| 顶部条 | 56px 全宽 | 朱砂印章 logo「枰上玄机」+ 六谱目索引 + 自动播放/音效开关 |
| 左侧谱目列表 | 200px | 六个手筋卡片（名称/副题/手数），竹青描边选中态 |
| 中央棋盘舞台 | 1fr | 19 路楸木棋枰（正方形，min(78vh)），取景框+spotlight 聚焦左上角区 |
| 右侧批注卷 | 320px | 宣纸底色，手筋释义 + 逐手批注 + 原理短文 |
| 底部控制条 | 88px 全宽 | 手数刻度尺 + 前/后按钮 + 自动播放 + 黑提/白提计数棋罐 |

### 响应式

- `≤768px`：重排为纵向（棋枰在上、控制在下），谱目列表折叠。
- 棋盘 `max-width: calc(100% - 40px)` + `aspect-ratio: 1` 保持正方形。

## 四、动效系统（16 项组件级特效）

### @keyframes 动画清单

| # | 名称 | 触发 | 曲线/时长 | 物理逻辑 |
|---|------|------|-----------|----------|
| 1 | `lineGrow` | 开场 | `ease-out 1.2s` | 棋盘线自中心向外生长绘制 |
| 2 | `starLight` | 开场 | `ease-out` 延迟级联 | 九星位逐一点亮 |

| 4 | WebAudio 落子声 | 落子 | 合成 2-oscillator | 棋磐脆响，黑白子音高微差（黑≈180Hz 白≈240Hz） |
| 5 | `stoneCapture` | 提子 | `ease-in 0.6s` | 死子沿弧线飞入棋罐 |
| 6 | `countBump` | 提子入罐 | `cubic-bezier(0.34,1.56,0.64,1) 0.4s` | 罐中计数弹跳 +1 |
| 7 | `sealStamp` | 关键手 | `cubic-bezier(0.34,1.56,0.64,1) 0.5s` | 朱砂"妙"印钤盖（缩放+淡入+轻压感） |
| 8 | `boardShake` | 关键手 | `cubic-bezier(0.36,0.07,0.19,0.97) 0.35s` | 全枰轻震（X/Y 微位移 3px） |
| 9 | `viewfinderBreath` + `spotlightBreath` | 谱目切换 | `ease-in-out 3.5s infinite` | 取景框呼吸 + spotlight 随战区聚焦 |
| 10 | `inkReveal` | 批注更新 | `ease-out` 逐行延迟 | 墨字逐行显现（非整段 fade-up） |
| 11 | `tickPulse` | 关键手刻度 | `ease-in-out infinite` | 刻度尺关键手朱砂色微脉冲 |
| 12 | `boardFadeIn` | 谱目切换 | `opacity 0.5s ease` | 棋盘淡换/翻篇 |

| 14 | `controlBreath` + `playPulse` | 自动播放 | `ease-in-out infinite` | 控制条呼吸节奏 |
| 15 | ghost stone + 坐标提示 | hover 交叉点 | JS 驱动 | 预览落点 + 坐标文字 |

### 动效原则

- 所有动效服务于"棋子物理质感"与"打谱节奏"，禁止整图缩放 Ken Burns。
- 关键手五感叠加：沉落 + 脆响 + 朱砂印 + 全枰震 + 取景框亮。
- `prefers-reduced-motion: reduce` 全部降级为 `0.01ms` 即时呈现。

## 五、自定义光标

- 形态：米白云子 + 黄铜金描边（径向渐变 + box-shadow）。
- 开页位置：`left: 50%; top: 50%`（屏幕正中央）。
- 层级：`z-index: 9999`（最高）。
- 跟随方式：`requestAnimationFrame` 更新 `left/top`，`pointer-events: none`。
- 状态变化：hover 可交互区时 `scale(1.25)` + 朱砂光环；不可见时 `opacity: 0`。
- `body { cursor: none }` 隐藏系统光标。

## 六、技术栈

- **纯 vanilla 单文件**：一个 `index.html`（69KB），内联 CSS + JS，零外部依赖。
- 无 React / Babel / CDN / 外部图片 / 外部字体文件。
- 棋盘 / 棋子 / 朱砂印 / 取景框：CSS + SVG 绘制。
- 落子声 / 提子声：WebAudio API 合成（双振荡器 + 噪声 + 包络），无音频文件。
- 数据：`fetch('demos.json')` 加载，含兜底空数组。
- 健壮性：`visibilitychange` 暂停自动播放与 RAF；`beforeunload` 清理定时器 / RAF / AudioContext。

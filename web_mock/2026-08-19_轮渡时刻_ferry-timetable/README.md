# 江上渡口 · 长江轮渡时刻表

V1 网页设计：长江轮渡公共信息服务网站。时间游标驱动的实时氛围系统——拖动游标穿越一天，江面色带从墨蓝夜航渐变到雾白黎明再到暮橙日落，码头信号灯逐盏亮起，时刻表班次随当前时刻高亮。

## 主题

武汉长江轮渡（武汉关↔中华路）的公共信息服务网站。以「时间」为主轴串联视觉与信息：用户拖动顶部时间游标或点击时段锚点（早班/通勤高峰/午间/午后/晚归/夜航），页面江面带的色调随时刻连续变化，码头信号灯在日落时分逐盏点亮，时刻表自动高亮当前时段班次。

## 核心交互

1. **时间游标拖拽** — 横向滑轨可拖拽，精度到分钟，实时驱动全页氛围
2. **时间锚点跳转** — 点击 6 个时段按钮，easeOutCubic 动画跳转
3. **江面带色调系统** — 9 个色态段 + 线性插值，深夜墨蓝→黎明雾白→白昼青灰→日落暮橙→夜航墨蓝
4. **码头信号灯** — 日落（16-18h）逐盏亮起，夜间闪烁
5. **时刻表高亮** — 当前时段班次 signal-orange 高亮，过去班次灰显

## 签名时刻

游标滑过日落时刻的瞬间——江面带从青灰染成暮橙，码头信号灯逐盏亮起。

## 技术栈

- 纯 vanilla JS + CSS，单文件 HTML
- 无 React / Babel / CDN 依赖（字体除外）
- RAF 驱动动画，`visibilitychange` 暂停
- `prefers-reduced-motion` 支持
- 自定义光标：开页居中显示，高对比，层级最高

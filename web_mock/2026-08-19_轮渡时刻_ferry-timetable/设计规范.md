# 长江轮渡时刻表 · 设计规范

## 1. 设计理念

「江上渡口」是长江轮渡的公共信息服务网站。设计语言源自渡口的真实世界——雾白的江面、船铁的墨青、信号灯的橙光。时间游标是核心交互：拖动游标穿越一天 24 小时，江面横向带的色调随时刻连续变化（深夜→黎明→白昼→日落→夜航），码头信号灯在日落时分逐盏亮起，时刻表班次随当前时刻高亮。江面带是氛围主体而非装饰。

### 江面带色态系统（JS 连续插值）

| 时段 | 顶部色 | 底部色 | 氛围 |
|------|--------|--------|------|
| 深夜 night (0-4h) | `#1E2A33` | `#0D1418` | 墨蓝暗夜 |
| 夜→晨 (4-6h) | 插值 | 插值 | 渐亮 |
| 黎明 dawn (6-8h) | `#E8E5DF` | `#BFC7CC` | 雾白晨光 |
| 晨→昼 (8-9h) | 插值 | 插值 | 渐亮 |
| 白昼 day (9-16h) | `#A9B8BF` | `#6B7E87` | 青灰江面 |
| 昼→暮 (16-18h) | 插值 | 插值 | 渐暖 |
| 日落 dusk (18-19h) | `#D48A5A` | `#6B4A3E` | 暮橙染江 |
| 暮→夜 (19-21h) | 插值 | 插值 | 渐暗 |
| 夜航 night (21-24h) | `#1E2A33` | `#0D1418` | 墨蓝夜航 |

插值使用线性 lerp，每帧根据游标当前时刻计算 top/bottom 两色，写入 CSS 变量 `--river-top` / `--river-bottom`。

## 5. 核心交互

### 5.1 时间游标

- 横向滑轨贯穿页面顶部，可拖拽
- 游标位置对应 0:00-24:00，精度到分钟
- 拖拽时实时更新：江面带色调、时刻表高亮、码头信号灯、天空标签
- 点击时间锚点按钮（早班/通勤高峰/午间/午后/晚归/夜航）自动动画跳转

### 5.2 江面带色调

- 140px 高横向带，始终在视口
- 背景渐变随时刻连续变化（9 个色态段 + 插值过渡）
- `transition: background 0.8s ease` 平滑过渡
- 表面叠加 `repeating-linear-gradient` 模拟江面波纹，`riverFlow` 动画横向流动

### 5.3 码头信号灯

- 江面带下方一排信号灯
- 日落时分（16-18h）逐盏亮起，按进度比例
- 夜间（18h 后）全部亮起，带闪烁延迟
- 白天全部熄灭

### 5.4 时刻表

- 按时段分组（早班/通勤高峰/午间/午后/晚归/夜航）
- 当前时刻附近的班次高亮（signal-orange 边框）
- 过去的班次灰显
- 每条班次含：时间、类型、是否车渡、航程时长、是否快船

## 6. 组件级动效（≥12 个）

| 编号 | 动效 | 机制 |
|------|------|------|
| 1 | 自定义光标 | 跟随/悬停/抓取多态，高对比层级最高 |
| 2 | 江面带色调连续插值 | JS lerp → CSS 变量 → gradient |
| 3 | 江面波纹流动 | repeating-linear-gradient + animation |
| 4 | 码头信号灯逐盏亮起 | class toggle + animation-delay |
| 5 | 信号灯闪烁 | box-shadow 脉冲 |
| 6 | 游标拖拽跟随 | mousemove → DOM 直接操作 |
| 7 | 时间锚点跳转动画 | easeOutCubic 600ms |
| 8 | 时刻表班次高亮 | class toggle + border 过渡 |
| 9 | 过去班次灰显 | opacity + color 过渡 |
| 10 | 天空标签实时更新 | textContent + 颜色跟随 |
| 11 | 天空指示点发光 | box-shadow 随时段变色 |
| 12 | 页面入场渐显 | opacity + translateY |
| 13 | 滚动锚点导航 | smooth scroll |

## 7. 健壮性

- RAF 动画在 `visibilitychange` 时暂停
- 游标拖拽使用 `mousemove` 直接操作 DOM，不触发重渲染
- `prefers-reduced-motion` 时跳过动画直接跳转
- 零未定义引用，零 Console Error
- 纯 vanilla 单文件，无 React/Babel/CDN（字体除外）

# 设计规范 · 鎏金铜镜馆 · 古镜博物馆

> 方向：网页设计（V1） · 日期：2026-08-17 · 主题：中国古代铜镜博物馆官网

## 色彩系统

古铜文物质感：青铜深褐为底，铜绿锈为辅助，鎏金为高光强调，朱砂红为印章点缀，米白宣纸用于浅区与正文。

| 角色 | 色值 | 用途 |
|---|---|---|
| 主背景 / 古铜深褐 | `#2E1F12` / `#3E2A1A` | 页面深底、章节深区 |
| 铜绿锈 | `#6B8E6B` / `#4A6B4A` | 辅助色、纹饰描边、标签 |
| 鎏金（强调） | `#C9A227` / `#E0B83A` / `#F0D96A` | 标题、高光、按钮、光泽扫过 |
| 暗金 / 古铜中 | `#8B6914` / `#5A3F26` / `#4A3520` | 次级文字、分割线、卡片边 |
| 朱砂红（点缀） | `#A83232` / `#7A2424` | 印章、警示、强调标记 |
| 米白宣纸 | `#F2EAD6` / `#E8DEC0` | 浅区底、正文文字、拓片纸面 |
| 极深 | `#1A120A` | 最深底色 |

## 字体

- 标题：`'Noto Serif SC', 'Songti SC', 'STSong', serif`（衬线宋体，铜镜铭文气质）
- 正文：`'Noto Serif SC', serif`（思源宋体）
- 铭文 / 楷体：`'KaiTi', 'STKai', serif`
- 等宽：数字与年代用等宽衬线

## 组件

- 导航栏：吸顶，滚动后渐变出深褐半透明底 + 鎏金下边线，锚点跳转
- 铜镜卡片：圆角 12px，铜绿描边，悬停鎏金光泽扫过（伪元素渐变 translateX）
- 详情弹窗：四 Tab（纹饰解析 / 铭文释读 / 修复档案 / 拓片），Tab 切换下划线滑动
- 铭文切换器：5 篇铭文，打字机逐字输出
- 数据统计：馆藏数字计数动画（缓动 RAF）
- 朱砂印章：圆形，脉冲呼吸
- 纹饰：纯 SVG 绘制（葡萄纹、瑞兽、四山纹、人物故事），描边动画

## 动效系统（≥12 个组件级特效）

1. 自定义光标：铜镜圆环 + 鎏金内点 + 多层柔光，开页即显示在屏幕中央，悬停可交互元素放大变色，点击涟漪
2. 铜绿浮尘粒子：青铜尘粒 + 金色光斑，各自不同周期漂浮
3. Hero 铜镜 3D 倾斜：随鼠标惯性阻尼倾斜 + 镜面高光漂移（直接操作 DOM transform）
4. 滚动渐入：stagger reveal，章节依次浮入
5. 悬停鎏金光泽扫过：卡片 / 按钮伪元素渐变掠过
6. 馆藏数字计数：缓动计数到目标值
7. 铭文打字机：逐字输出，可切换 5 篇
8. 章节切换过渡
9. 铜镜浮动 + 光斑漂移
10. 朱砂印章脉冲
11. 纹饰描边动画（SVG stroke-dashoffset）
12. 导航栏滚动渐变背景

动效基于 RAF 积分器 / 阻尼 / 惯性，周期各不相同；严禁整图缩放 / Ken Burns。

## 页面结构

导航 → Hero 主镜 → 馆藏珍品（6 面铜镜网格）→ 数据统计 → 铭文释读（5 篇切换）→ 铸造修复工艺 → 当前展览 → 学术研究 → 页脚。铜镜卡片点击弹出详情弹窗（四 Tab）。

## 健壮性

- 零未定义引用
- RAF / 定时器随 `visibilitychange` 自动暂停，卸载统一取消
- 高频鼠标事件直接操作 DOM transform，不触发重渲染
- 支持 `prefers-reduced-motion` 降级为静态

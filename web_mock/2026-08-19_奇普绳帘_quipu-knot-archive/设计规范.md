# 设计规范 · 奇普绳帘 印加结绳记事档案室

## 1. 设计母题
**印加奇普（Quipu）结绳记事**。整站是一面垂落的奇普绳帘——一根粗主绳横贯顶部，七根染色的羊驼毛子绳垂直下垂成帘幕。每根子绳承载一组真实印加结绳数据（人口、黄金、玉米、棉布、羊驼、白银、驻军）。拨动子绳，绳索像被弹拨般物理摆动，摆动过程中其上的结节自上而下（千→百→十→个位）逐个点亮解码成十进制数字，底部档案条滑入显示该绳对应的地区、年份、类别与数量。

设计语言来自安第斯印加帝国的结绳记事实物：羊驼毛绳 + 植物染料 + S/Z 长结 + 8 字结 + 单结的十进制编码。

## 2. 空间模型
**绳索垂直阵列帘幕（rope_array_vertical_curtain）**。水平主绳横贯，子绳垂直下垂，形成"帘幕"结构——非竖向 section 堆叠、非卡片网格。视觉重心为居中绳帘，底部为固定档案面板。首屏即可见完整绳帘主绳 + 垂落子绳。

## 3. 配色系统（植物染料原色，禁蓝紫渐变）
从源码 `:root` CSS 变量提取的真实色值：

| 变量 | 色值 | 用途 |
|------|------|------|
| `--bg-main` | `#B8A682` | 主背景（陈旧羊驼毛褐，档案室暖光） |
| `--bg-deep` | `#3B2E22` | 深背景区（深木色） |
| `--ink` | `#2B2622` | 主文字（墨褐） |
| `--paper` | `#EDE4D3` | 羊驼白（浅底/白银绳） |
| `--gold` | `#D9A441` | 金赭（结节点亮高亮） |
| `--rope-red` | `#A8412C` | 赭红绳·人口/军事 |
| `--rope-gold` | `#C8923A` | 姜黄绳·黄金/贡品 |
| `--rope-green` | `#6B7A4F` | 苔绿绳·农作物/玉米 |
| `--rope-indigo` | `#2F5D6E` | 靛青绳·远方行省/棉 |
| `--rope-charcoal` | `#2B2622` | 炭黑绳·牲畜/羊驼 |
| `--rope-white` | `#EDE4D3` | 羊驼白绳·和平/银 |

绳色承担分类语义功能，靛青为植物染料单色（非蓝紫渐变）。

## 4. 字体系统
- 标题/衬线：`"Songti SC", "STSong", "Noto Serif SC", serif`（宋体，手工档案感）
- 拉丁副标：`"Times New Roman", Georgia, serif`
- 数字/编号：等宽（结节解码数字）
- 中文为主，克丘亚语词汇（Qosqo、Quipucamayoc、Pikara、Waraqah）配中文释义

## 5. 奇普编码逻辑（学术还原）
基于印加奇普真实编码规则：
- **个位**：8 字结 = 1，长结 = 2–9（缠绕圈数对应数字）
- **十/百/千位**：单结堆叠，结数 = 位数
- **结节位置**：沿绳自上而下为千→百→十→个位（高位近主绳，低位远主绳）
- **绳色**：表类别（赭红=人口/军事，姜黄=黄金/贡品，苔绿=农作物，靛青=远方行省，炭黑=牲畜，羊驼白=和平/银）

验证：库斯科人口绳结节解码 千1·百4·十2·个6 = 1,426 户，与档案记述一致。

## 6. 动效系统（RAF 物理驱动，≥12 组件级特效）
核心动效由 `requestAnimationFrame` 驱动物理模拟，非 CSS @keyframes：
1. **绳体弹簧阻尼摆动**（`animate()` + `state.rafId`，贝塞尔控制点偏移模拟绳体波形传递）
2. **结节点亮**（拨绳回弹瞬间结节自高位到个位逐个染料浸染式高亮）
3. **数字滚动计数**（`animateNumber()` 解码数字浮现）
4. **位号标签显现**（千/百/十/个位标注）
5. **档案条滑入展开**（羊皮卷轴展开感）
6. **子绳逐根滴落入场**
7. **主绳呼吸式微摆 + 挂珠随主绳波动**
8. **光尘粒子浮动**（档案室斜光悬浮微粒，极克制）
9. **自定义光标缓动跟随**（`mouseRaf` 节流，高频鼠标事件直接操作 DOM 不触发重渲染）
10. **光标悬停绳体旋转 45° 放大 1.15**（`.cursor.hover-cord`）
11. **弹拨瞬间光标缩放 0.9 反馈**（`.cursor.plucking`）
12. **纸纹噪点基底**

健壮性：RAF 随页面可见性自动暂停/恢复，卸载取消所有定时器，`prefers-reduced-motion` 全量降级，移动端触屏支持 + 光标隐藏。

## 7. 核心交互
**拨动子绳 → 弹簧阻尼物理摆动 → 摆动衰减中结节按"距主绳由近到远"逐个高亮（量级高位先亮）→ 每个结节解码出数字 → 全部解码后底部档案条滑入显示完整数据档案。** 七根子绳分别对应库斯科人口、黄金贡品、玉米增量、棉布征收、羊驼存栏、白银投入、驻军人数。

## 8. 自定义光标
纺锤形结绳指针，`cursor: none` + 自定义 `.cursor` 元素，开页居中、高对比、层级最高。悬停子绳旋转 45° 放大，弹拨瞬间缩放反馈。移动端隐藏。

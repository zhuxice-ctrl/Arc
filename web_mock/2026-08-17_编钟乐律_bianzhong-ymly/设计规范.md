# 编钟乐律 设计规范

> 日期：2026-08-17 · 方向：V1 网页设计 · 主题：中国古代编钟与乐律文化展示官网

## 色彩系统

| 角色 | 色值 | 用途 |
|------|------|------|
| 主色 | `#3a6b5a` | 青铜绿，主标题、强调元素、导航栏 |
| 强调色 | `#c4a04e` | 暗金，按钮、高亮、装饰线条 |
| 背景深色 | `#1a1a1a` | 玄黑，Hero 区背景、Footer |
| 背景浅色 | `#f0ebe0` | 宣纸米，正文区域背景 |
| 辅助红 | `#c0392b` | 朱砂红，警示标签、热点标记 |
| 辅助灰 | `#4a4a4a` | 墨灰，正文文字、次要信息 |
| 青铜深 | `#234036` | 青铜暗色，卡片背景、悬停态 |
| 青铜浅 | `#5a8b7a` | 青铜亮色，次要按钮、边框 |
| 金浅 | `#e0c377` | 浅金，渐变过渡、光效 |
| 铜锈 | `#8a6538` | 铜锈棕，纹理装饰 |

## 字体系统

- **展示字体**：`var(--font-brush)` — 毛笔楷书风格，用于主标题与编钟名称
- **正文字体**：`var(--font-serif)` — 衬线体，用于正文段落
- **小标题字体**：`var(--font-xiaowuei)` — 小微体，用于副标题与卡片标题
- **数字/代码**：系统等宽字体

## 组件规范

- **卡片**：圆角 8px，宣纸米背景，1px 青铜色边框，悬停时 3D 倾斜 + 青铜辉光
- **按钮**：暗金背景，玄黑文字，圆角 6px，悬停光泽扫过
- **导航栏**：固定顶部，滚动后从透明变为毛玻璃玄黑底
- **编钟展品卡**：左侧编钟图形 + 右侧信息（名称/年代/出土地/音域），悬停发光
- **五声音阶交互**：宫商角徵羽五个可点击按钮，点击触发编钟振动 + 声波扩散
- **时间线**：垂直排列，滚动驱动金色进度条展开

## 动效系统

| 编号 | 动效名称 | 触发方式 | 物理模型/语义 |
|------|---------|---------|-------------|
| 1 | 自定义青铜光标 | 鼠标移动 | 弹性跟随，悬停放大，点击涟漪 |
| 2 | Hero 标题逐字浮现 | 页面加载 | 序列入场，每字延迟 80ms |
| 3 | 青铜粒子上升 | 页面加载 | 粒子物理，向上漂浮+淡出 |
| 4 | 卡片 3D 倾斜 | 鼠标悬停 | 基于鼠标位置的 rotateX/rotateY |
| 5 | 滚动渐入 | 滚动进入视口 | IntersectionObserver，fade-in+slide-up |
| 6 | 编钟悬停辉光 | 鼠标悬停 | box-shadow 青铜色扩散 |
| 7 | 声波扩散 | 点击编钟 | 同心圆波纹，ease-out 扩散 |
| 8 | 五声音阶振动 | 点击宫商角徵羽 | 编钟缩放+声波+Web Audio 合成 |
| 9 | 数字计数滚动 | 滚动进入视口 | easeOutCubic 数字增长 |
| 10 | 时间线进度展开 | 滚动驱动 | 金色进度条随滚动填充 |
| 11 | 光泽扫过 | 鼠标悬停卡片 | CSS 渐变光带掠过 |
| 12 | 导航栏吸顶变色 | 滚动位置 | 透明→毛玻璃玄黑底过渡 |

## 页面结构

1. **Hero 区** — 编钟乐律主标题 + 副标题 + 青铜纹理动态背景 + 粒子
2. **馆藏珍品** — 3 件真实编钟展品卡片（曾侯乙编钟、王孙诰编钟、晋侯苏编钟）
3. **五声音阶** — 宫商角徵羽交互演示区
4. **铸造工艺** — 陶范法/失蜡法时间线
5. **虚拟敲钟** — 点击编钟产生声波动画的互动区
6. **近期展览** — 展览活动列表
7. **Footer** — 版权信息与导航链接

## 技术栈

- 纯 HTML/CSS/JS 单文件实现（无 React/Babel/外部 CDN 依赖）
- Web Audio API 合成五声音阶钟声
- IntersectionObserver 滚动检测
- 支持 prefers-reduced-motion 降级
- visibilitychange 暂停 RAF 动画

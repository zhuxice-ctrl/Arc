# 候光·光影艺术展 设计规范

> 日期：2026-08-17 · 方向：V1 网页设计 · 主题：光影艺术展览官网

## 色彩系统

| 色彩角色 | 色值 | 用途 |
|---------|------|------|
| 炭墨黑 | `#1a1a1a` | 主背景色 |
| 深炭黑 | `#141414` | 次级背景 |
| 暗炭灰 | `#242424` / `#2e2e2e` | 卡片背景、分隔 |
| 暖金 | `#d4a574` | 主强调色、按钮、标题高亮 |
| 浅金 | `#e0bc8f` | 次级强调、悬停态 |
| 暗金 | `#b8894f` | 深色强调 |
| 雪花白 | `#f5f0e8` | 正文字色、浅色文字 |
| 深绛红 | `#8b3a3a` | 点缀强调色（预约/重要标识） |
| 浅绛红 | `#a84848` | 悬停态绛红 |
| 纯白 | `#ffffff` | 最高对比文字 |

## 字体系统

- **正文字体**：`'Noto Sans SC', 'PingFang SC', 'Microsoft YaHei', sans-serif`
- **标题字体**：`'Noto Serif SC', serif`（衬线体，体现艺术展览质感）
- **字重**：300 / 400 / 500 / 600 / 700

## 圆角规范

- 卡片/容器：`2px`（极小圆角，克制冷峻）
- 圆形元素：`50%`

## 组件规范

- **导航栏**：固定顶部，半透明黑底+底部金线，logo + 导航链接 + 预约按钮
- **作品卡片**：暗底卡片，悬停时3D倾斜+发光边框+光影扫过
- **模态框**：点击作品展开详情，ESC/遮罩可关闭
- **预约表单**：暗底输入框，金色聚焦边框，绛红提交按钮
- **页脚**：暗底，金色分隔线，展览信息+联系方式

## 动效系统

| 动效 | 实现方式 | 触发条件 |
|------|---------|---------|
| 自定义光标 | 白色粗环+金色内点+多层发光，RAF跟随 | 开页即显示在屏幕中央 |
| 粒子光尘 | 80颗金色微粒，微扰动+鼠标近避 | 持续运行 |
| 3D倾斜作品卡 | 鼠标位置映射rotateX/Y | 鼠标悬停 |
| 滚动渐入 | IntersectionObserver | 元素进入视口 |
| 悬停发光边框 | CSS box-shadow过渡 | 鼠标悬停 |
| 光影扫过 | 斜向高光带translateX | 鼠标悬停 |
| 打字机标题 | 逐字setTimeout | 页面加载 |
| 数字计数器 | ease-out cubic缓动 | 元素进入视口 |
| 视差滚动 | scroll事件差速位移 | 滚动 |
| 涟漪点击 | 点击处金色光环扩散 | 点击 |
| 光束扫射 | 5道光束缓慢摆动+鼠标跟随 | 持续运行 |
| 标题脉冲发光 | 逐字呼吸式text-shadow动画 | 持续运行 |

## 页面结构

1. 导航栏（固定顶部）
2. Hero展区（展览标题+打字机副标+光影动效背景+光束+粒子）
3. 展览介绍（文字+数据计数器）
4. 作品画廊（6件光影装置作品，3D倾斜卡片网格）
5. 艺术家介绍（3位艺术家卡片）
6. 参观信息（时间/地点/票价）
7. 预约表单（可填写提交）
8. 页脚

## 健壮性

- requestAnimationFrame 随 visibilitychange 暂停
- 高频鼠标事件直接操作 DOM transform
- 支持 prefers-reduced-motion（禁用全部动效与光标）
- 模态框支持 ESC 关闭、点击遮罩关闭

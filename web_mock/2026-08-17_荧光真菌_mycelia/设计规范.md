# 设计规范 · MYCELIA 生物荧光真菌数字档案

> 日期：2026-08-17 · 方向：V1 网页设计 · 主题：夜光蘑菇田野考察档案站

## 色彩系统

| 角色 | 色值 | 用途 |
|------|------|------|
| 深森林黑（底） | `#0a0d07` / `#12170e` / `#1a2114` | 页面底色、深色层级 |
| 荧光酸橙绿 | `#c8ff4a` / `#6ab023` | 生物荧光高亮、菌丝信号、强调 |
| 金黄鸡油菌 | `#e8a445` / `#ff7a3c` | 暖色高光、孢子粒子、计数器 |
| 暖琥珀 | `#3d3222` | 卡片表面、分隔 |
| 大地棕 | `#5c5a4a` / `#a8a490` | 次要文字、边框 |
| 米纸 | `#f2f0e6` | 主文字、浅色表面 |

配色避开蓝紫渐变，以「深森林黑 × 生物荧光绿 × 鸡油菌金黄」构成夜光菌态主调。

## 字体

- `--font-serif`：标题与档案名（衬线，博物学手稿感）
- `--font-sans`：正文
- `--font-mono`：编号 / 坐标 / 数据

## 组件

- Hero 区：打字机标题 + 视差背景 + 数字计数器（147 sp. / 23 / 12.4k / 150 Myr）
- 标本卡片：3D 倾斜磁吸 + 生物发光呼吸 + 光泽扫过
- 菌丝网络 SVG：周期性行波信号传播 + 节点脉冲
- 生物发光频谱柱：正弦叠加 + 高斯包络
- 顶部导航：滚动收缩 + 毛玻璃
- 滚动渐入：IntersectionObserver 级联延迟

## 动效系统（17 项组件级特效）

1. 自定义光标（白环+绿点+多层发光，RAF 阻尼 lerp，开屏居中）
2. 光标悬停三态切换
3. 点击涟漪（Web Animations API 自销毁）
4. 孢子粒子系统（重力+布朗运动+正弦气流+摩擦阻尼）
5. 英雄区打字机（变速度自然节奏）
6. 英雄区背景视差（滚动速度×0.35 damped lerp）
7. 数字计数器（easeOutCubic）
8. 标本卡片 3D 倾斜磁吸（damped lerp）
9. 卡片生物发光呼吸（CSS keyframes）
10. 卡片光泽扫过
11. 菌丝网络 SVG 信号传播（行波+相位偏移）
12. 菌丝节点脉冲（频率各异，半径+透明度双调）
13. 生物发光频谱柱（正弦+随机游走+高斯包络）
14. 滚动渐入级联（cubic-bezier）
15. 导航栏滚动收缩+毛玻璃
16. 事件行悬停位移+箭头填充
17. 滚动提示下落光点

物理依据：RAF 阻尼积分器、布朗运动+摩擦阻尼、正弦气流、反平方磁吸。严禁整图缩放 / Ken Burns。

## 页面结构

单页艺术品级网站：Hero → 物种档案网格 → 菌丝网络可视化 → 生物发光频谱 → 考察日志时间线 → 页脚。所有按钮/卡片/导航真实可交互。

## 健壮性

- 所有代码内联在 `index.html` 的 `<script type="text/babel">` 与 `<style>` 中
- rAF/定时器随 `visibilitychange` 暂停，卸载统一清理
- 高频 mousemove 直接操作 DOM transform，不触发 React 重渲染
- `prefers-reduced-motion` 完整降级

# 琉璃光境 · 设计规范

> 日期：2026-08-18 · 方向：V1 网页设计 · 主题：古法琉璃艺术博物馆官网「琉璃光境」

## 一、设计理念

以东方古法琉璃「火中取色，光里成形」为精神内核，将琉璃的透、润、烈、沉转译为暗调厚重的长滚动官网。整体气质典雅神秘，强调光影粒子与金质光泽的层次呼吸。

设计关键词：**炽焰 · 流光 · 古法 · 厚重**

## 二、色彩体系

| 角色 | 色值 | 用途 |
|------|------|------|
| 主色 · 朱砂红 | `#B9301A` | 强调标题、关键按钮、火光 |
| 辅助 · 琥珀金 | `#E8A94B` | 高光、装饰描边、渐隐金 |
| 点缀 · 冰青 | `#E8F4F0` | 冷调反差、琉璃透感 |
| 底色 · 墨褐 | `#2A1812` | 页面主背景 |
| 深底 | `#1a0f0a` | 最深层背景 |
| 赤金 | `#C69A5B` | 品牌金、Logo、细线 |
| 暖砂 | `#E4D4BA` / `#F2E8D9` | 浅色文字、卡片表面 |
| 琥珀亮 | `#F2CB7A` / `#E0BC7E` | 标题金质渐变 |
| 暗红层 | `#7A1E12` / `#5C2818` / `#4A1508` | 火焰渐变层次 |
| 翠青暗 | `#2D4A3E` / `#1E3D35` | 琉璃冷色暗部 |

渐变：标题金 `#F2CB7A → #C69A5B → #8B6B55`；火焰 `#B9301A → #7A1E12 → #2A1812`。禁止蓝紫渐变。

## 三、字体排版

| 用途 | 字体栈 | 字重 |
|------|--------|------|
| 标题 / 品牌名 | `'Noto Serif SC', serif` | 700 / 900 |
| 正文 / UI | `'Noto Sans SC', 'PingFang SC', sans-serif` | 400 / 500 |

字号阶梯：Hero 大标题 72-96px、区段标题 40-48px、小标题 24px、正文 16px、标注 13px。

## 四、页面结构

六大内容区块（单页长滚动）：

1. **顶部导航** — 品牌菱形 Logo + 五栏导航（渊源 / 工艺 / 典藏 / 匠人 / 特展）+ 预约参观按钮，吸顶毛玻璃
2. **Hero** — 金光泽变大标题 + Canvas 琉璃粒子背景 + 入场序列
3. **渊源** — 琉璃瓶 3D 倾斜交互 + 气泡上浮 + 数字计数统计
4. **工艺** — 脱蜡铸造五步卡片（塑模 → 注蜡 → 结壳 → 焙烧 → 退火），SVG 工艺图标
5. **典藏** — 六件历代珍品（西汉 → 清乾隆），悬停揭示详情，朝代筛选
6. **匠人** — 传承人沈清和介绍，画像光晕跟随鼠标 + 作品缩略图
7. **特展** — 时间轴进度条 + 三张展览卡片（光泽扫过）
8. **页脚** — 版权与联系方式

## 五、组件规范

- **按钮**：金边描边按钮（1.5px `#C69A5B`），hover 填充朱砂；主按钮朱砂底 + 暖砂字
- **卡片**：墨褐底 + 1px 暖砂半透明边框 + 内阴影金光；hover 上浮 4px + 金色光晕
- **导航**：吸顶 `rgba(26,15,10,0.72)` + backdrop-blur(12px)
- **分割线**：金色渐隐 `linear-gradient(90deg, transparent, #C69A5B, transparent)`

## 六、动效系统（16 个组件级特效）

1. 自定义光标三环跟随 / hover 变形 / 点击涟漪
2. Canvas 琉璃粒子漂浮 + 鼠标排斥
3. 琉璃碎片浮动装饰
4. 标题逐字金光泽变
5. 琉璃瓶 3D 倾斜 + 气泡上浮
6. 数字计数动画
7. 工艺卡片错峰渐入
8. 典藏图片缩放 + 朝代筛选切换
9. 画像光晕跟随鼠标
10. 时间轴进度填充
11. 展览卡光泽扫过
12. 导航吸顶毛玻璃
13. Hero 滚动视差
14. Logo 旋转呼吸
15. 全页滚动渐入（IntersectionObserver）
16. 按钮金色光泽扫动

缓动：`cubic-bezier(.2,.8,.2,1)` 标准、`cubic-bezier(.34,1.56,.64,1)` 弹压。基于 RAF 积分器与弹簧阻尼模型。

## 七、健壮性

- 纯 vanilla HTML/CSS/JS 单文件，零 React / Babel / 外部 CDN 依赖
- `requestAnimationFrame` 成对清理，`visibilitychange` 自动暂停
- `prefers-reduced-motion` 降级为静态
- 移动端关闭自定义光标

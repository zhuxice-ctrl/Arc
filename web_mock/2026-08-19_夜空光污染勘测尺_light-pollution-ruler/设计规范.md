# 夜空光污染勘测尺 · 设计规范

> 主题：城市观星者光污染勘测尺｜类别：Web Mock｜日期：2026-08-19

## 设计理念

把 Bortle 光污染等级做成一条横向可拖动的连续光尺，作为页面脊柱。拖动光尺，头顶星空在 pristine 暗夜（满目繁星）到市中心（只剩 2-3 颗最亮星淹没在橙色光雾）之间连续变化——让"光污染吞星"成为可被亲手推动的过程。视觉来源：天文星图 + 城市夜景钠灯 + 测光仪器。

## 空间模型

仪器式横向布局（非纵向 Section 堆叠、非居中 Hero、非卡片 Grid）：
- 顶部仪器标头（品牌 + LIVE READING 指示 + 实时时钟）
- 左上读数面板（Bortle 等级 / 极限星等 / 可见恒星数）
- 中央星空画布（Canvas + 城市天际线剪影 + 光雾层）
- 底部横向光尺（脊柱，1-9 级刻度 + 城市标记 + 可拖游标）
- 下方可滚动 Bortle 九级对照表 + 光污染来源说明
- 右侧半屏城市详情面板（点击城市标记弹出）

## 色彩系统（非蓝紫渐变）

| 名称 | 色值 | 用途 |
|------|------|------|
| 深空黑 | `#060709` | 主背景 |
| 深空黑 2 | `#0c0e12` | 次背景 |
| 钠灯琥珀 | `#F5A623` | 光雾、强调、游标、城市标记 |
| 钠灯亮 | `#FFB347` | 高亮光雾 |
| 钠灯暗 | `#c98a1a` | 次强调 |
| 星点银白 | `#E8EDF3` | 恒星、主文字 |
| 星点暖 | `#f0e6d2` | 暖色恒星 |
| 星点冷 | `#d6e4f5` | 冷色恒星 |
| 仪器灰 | `#4a5058` / `#7a828c` / `#2a2d33` | 仪器刻度、次要文字、分割线 |
| 读数绿 | `#6ee8a6` | 良好读数状态 |

色彩承担：层级（银白主 / 琥珀强调 / 仪器灰辅助）、状态（绿=良好 / 琥珀=光污染）、氛围（深空黑底营造夜空）。

## 字体系统

- 等宽 `--font-mono`：SF Mono / JetBrains Mono / Consolas——用于仪器读数、刻度标签、技术标注，营造测光仪器感
- 无衬线 `--font-sans`：PingFang SC / Noto Sans SC——正文与 UI
- 展示 `--font-display`：PingFang SC——品牌标题

## 动效系统（≥12 组件级特效，符合物理/主题逻辑）

1. 恒星呼吸闪烁（按真实星等亮度，周期错相位，非整图缩放）
2. 光雾径向扩散（强度随 Bortle 值连续渐变）
3. 游标拖动阻尼惯性
4. 城市标记 hover 聚光
5. 载入进度条充能（钠灯光晕）
6. 读数数字缓动变化
7. 详情面板滑入
8. 刻度尺分段吸附反馈
9. 实时时钟跳动
10. LIVE READING 指示灯呼吸
11. 天际线剪影随光污染加深
12. 自定义十字光标跟随（difference 混合，高对比）
13. 滚动时光尺淡化

动效原则：用户输入量 ≈ 视觉状态变化量（拖尺即推动星空退化）；RAF 随 `visibilitychange` 暂停、卸载取消；支持 `prefers-reduced-motion` 降级。

## 核心交互

- **拖动光尺游标**：星空星点密度/亮度连续变化 + 光雾扩散（签名记忆点）
- **点击城市标记**：右侧半屏详情（该城 Bortle 等级、天光亮度、光污染来源构成、观测提示）
- **键盘**：← → 调整 Bortle 值，Esc 关闭详情
- **滚动**：光尺随滚动克制淡化

## 真实数据

6 个城市标记：青海冷湖（1.2 级）、阿里（2.0 级）、安吉天荒坪（3.0 级）、杭州（7.0 级）、北京（8.0 级）、上海（8.2 级），含天光亮度值与可见星等。

## 技术栈

纯 vanilla 单文件（HTML + CSS + Canvas + JS），零外部依赖。自定义光标开页居中高对比。`prefers-reduced-motion` 全面兼容。

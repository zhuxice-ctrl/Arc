## 页面结构（8 个区块）

1. **Hero 主视觉** — 品牌标识 + 拉丁文打字机轮播 + 双 CTA + 背景齿轮旋转视差
2. **时代收藏馆** — 4 个时期 Tab 切换（文艺复兴/巴洛克/工业革命/现代），每期 3 件藏品
3. **制表工艺** — 六大技艺卡片网格（复杂功能/表面修饰/调速/擒纵/珐琅/齿轮系）
4. **齿轮传动原理** — 5 级齿轮组咬合旋转演示，不同速率比
5. **擒纵机构与钟摆** — 2.5s 物理周期钟摆 + 擒纵轮动画
6. **展览与活动** — 3 张展览卡片
7. **参观信息** — 地址/时间/门票卡（锥形光泽旋转）
8. **Newsletter + Footer** — 订阅表单 + 实时时钟

## 健壮性

- 所有 `requestAnimationFrame` / `setInterval` 受 `visibilitychange` 管理
- `beforeunload` 统一清理定时器
- 支持 `prefers-reduced-motion`
- 纯 vanilla HTML/CSS/JS 单文件实现，零外部依赖

## 技术栈

- HTML5 + CSS3（CSS 变量/动画/flex/grid）
- 原生 JavaScript（IntersectionObserver / Canvas / requestAnimationFrame）
- 无 React / 无 Babel / 无外部 CDN

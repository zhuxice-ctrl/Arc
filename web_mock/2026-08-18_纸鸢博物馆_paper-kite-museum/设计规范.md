# 设计规范 · 纸鸢博物馆

> 日期：2026-08-18 · 方向：V1 网页设计 · 主题：中国风筝艺术数字博物馆官网

## 色彩系统

主配色为东方纸艺暖色系，禁止蓝紫渐变。

| 角色 | 色值 | 用途 |
|------|------|------|
| 宣纸米白 | `#F7F2E7` | 页面底色、卡片表面 |
| 朱红 | `#C73E2E` | 主强调色、CTA、自定义光标内点 |
| 黛绿 | `#2F5D50` | 辅助色、深色板块背景、匠人区 |
| 藤黄 | `#E8B54A` | 点缀色、高亮、图标悬停 |
| 墨色 | `#26221C` | 正文文字、标题 |

中性层次（基于墨色 `#26221C` 的透明叠加）：`rgba(38,34,28,0.03~0.5)` 用于边框、阴影、分隔线；宣纸色透明层 `rgba(247,242,231,0.4~0.92)` 用于毛玻璃导航栏与浮层。

## 字体

- 正文 / 标题：系统中文衬线 + 无衬线回退（`font-family: inherit`，沿用浏览器默认中文栈，保证纸质感与可读性）。
- 标题字号层级：Hero 主标题 ≈ 64px、板块标题 36px、卡片标题 20px、正文 16px。

## 圆角与阴影

- 卡片圆角 12–16px，按钮圆角 999px（胶囊）。
- 阴影采用低饱和墨色透明叠加（`0 8px 30px rgba(38,34,28,0.08)` 量级），呈现纸面浮起感。

## 页面结构（8 大板块）

1. 首屏 Hero：悬挂摆动的沙燕风筝 + 打字机副标题
2. 数据统计：馆藏 / 匠人 / 展厅 / 历史年数（数字滚动计数）
3. 馆藏珍品：分类筛选（沙燕/龙头/蝶形/鹰形）+ 3D 倾斜卡片
4. 匠人传承：黛绿深色背景 + 脉冲头像环
5. 当前展览：特展大图 + 展览列表（左侧彩条滑入）
6. 活动日历：时间轴布局
7. 参观信息：指南 + 预约表单
8. 页脚

## 动效系统（15+ 组件级特效）

1. 自定义光标：白环 + 朱红内点 + 多层发光，悬停放大三态，点击涟漪
2. 风筝物理摆荡：钟摆方程 + 随机风力扰动，带动风筝线同步摆动
3. 风粒子系统：25 颗粒子横向飘动 + 垂直正弦摆动
4. 滚动渐入：IntersectionObserver + 错落延迟
5. 打字机：三句副标题循环打字 + 光标闪烁
6. 数字计数：easeOutExpo 缓动 + 滚动触发
7. 3D 卡片倾斜：mousemove 直接操作 transform + 阻尼跟随
8. 悬停光泽扫过：CTA 按钮 shine 斜向扫光
9. 头像脉冲环：三个匠人错开相位持续呼吸
10. 展览卡片左侧彩条 scaleY 展开
11. 导航栏滚动收缩 + 毛玻璃背景
12. 滚动提示线缩放动画
13. 风筝图片悬停微放大（transform 缩放，非 Ken Burns）
14. 筛选胶囊激活发光
15. 图标悬停变色上浮

动效周期各不相同、不整齐划一；均基于物理模型（钟摆/阻尼/缓动）或主题语义（风的流动、纸面翻飞）。

## 健壮性

- 所有 RAF / 定时器在 `visibilitychange` 时暂停、页面卸载时取消。
- mousemove 触发的倾斜 / 光标跟随直接操作 DOM，无 React 重渲染。
- 支持 `prefers-reduced-motion` 全面降级。
- 所有 JSX / CSS 内联在单文件 index.html 中，零外部图片引用。

## 技术栈

React 18 + Babel Standalone（JSX 内联于 `<script type="text/babel">`），单文件 HTML，零外部图片引用。

# 设计规范 · 苔痕 Moss Trace · 苔藓微观生态艺术展

> 方向：网页设计（V1） · 日期：2026-08-17 · 主题：苔藓微观生态艺术展

## 色彩系统

深绿+奶白为主色调，琥珀金为强调色，营造湿润幽静的森林苔藓气质。

| 角色 | 色值 | 用途 |
|------|------|------|
| 主色-苔绿 | #4A6741 | 品牌色、按钮、标题强调 |
| 深色-深林墨绿 | #1A2F1A | 背景、深色区块 |
| 深色-暗墨绿 | #0F1F0F | Hero 背景、最深层次 |
| 辅助-灰绿 | #6B7A5B | 次级文字、边框 |
| 中性-石灰岩灰 | #C4BBA8 | 卡片背景、分割线 |
| 中性-浅米 | #E8E1D0 | 浅色背景层 |
| 强调-琥珀金 | #D4A44A | 按钮悬停、链接、光标内点 |
| 背景-奶白 | #F5F0E1 | 页面主背景 |

## 字体系统

| 用途 | 字体栈 |
|------|--------|
| 正文/界面 | "PingFang SC", "Microsoft YaHei", "Noto Serif SC", serif |
| 标题/装饰 | serif（衬线体） |

## 组件规范

- **卡片**：石灰岩灰背景 #C4BBA8，悬浮阴影，3D 倾斜效果
- **按钮**：苔绿底色 + 琥珀金悬停态，光泽扫过动效
- **导航**：固定顶部，半透明毛玻璃效果
- **展厅 Tab**：切换式标签栏，内容区淡入过渡
- **图鉴卡**：网格布局，悬停展开详情

## 动效系统

1. 自定义光标：白色粗环 + 琥珀金内点 + 多层发光，弹簧阻尼跟随
2. 孢子粒子系统：Canvas 实现，鼠标反平方引力磁性吸附
3. 漂浮苔藓颗粒：正弦摇摆，每颗粒独立周期
4. 3D 倾斜卡片：弹簧积分器，图鉴卡 + 工坊卡
5. 滚动渐入揭示：IntersectionObserver + 缓动
6. 数字计数器：ease-out cubic
7. 悬停光晕 + 光泽扫过按钮
8. 打字机式入场错峰动画
9. 点击涟漪扩散
10. 视差滚动 + 鼠标视差（Hero 背景）
11. 频谱可视化：12 条独立频率柱
12. 磁性按钮：鼠标靠近位移
13. 滚动进度指示条
14. 展厅 Tab 切换动画
15. Logo 悬停旋转脉冲

## 页面结构

1. Hero 首屏 — 中英双语主标题 + 预约按钮 + 漂浮颗粒
2. 展览概述 — 数据统计计数动画
3. 六大主题展厅 — Tab 切换：微观之境/演化之旅/生态织网/苔藓盆景/声音苔藓/未来苔原
4. 苔藓图鉴 — 4 张物种卡片，悬停展开
5. 手作工坊 — 3D 倾斜卡 + 详情信息
6. 参观信息 — 日期/地点/票价
7. 策展人引言 + 页脚

## 健壮性

- visibilitychange 自动暂停所有 RAF/定时器
- prefers-reduced-motion 降级为静态
- 移动端自动关闭自定义光标
- 纯 vanilla HTML/CSS/JS 单文件，零外部依赖

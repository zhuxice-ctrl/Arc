# 七十二候 · 物候环 设计规范

## 一、设计理念

### 核心概念
可拖拽旋转的二十四节气七十二候物候轮盘。母题=「天体运行般的节气轮回」，轮盘本身即内容——季节的循环本质被空间化为一个可拨动的圆。

### 空间模型
径向环形（radial wheel）。24 节气段沿圆周排列，圆心联动呈现当前节气三候。与近期横向长卷 / 全屏地图 / 垂直剖面 / 工程图纸等线性模型正交。

### 信息层级
- 第一眼：圆环整体四季色带 + 顶部朱砂指针指向当前节气
- 第二眼：圆心当前节气名 + 三候物候辞
- 第三步：拖动旋转 / 点击节气段看详情
- 辅助：节气段小字节气名、候序

## 二、色彩系统（禁蓝紫渐变）

| 用途 | 色值 | 说明 |
|---|---|---|
| 陈纸底 | #F2EDE2 | 主背景，米纸质感 |
| 墨 | #2A2622 | 主文字 / 描边 / 轮盘线 |
| 朱砂 | #C0392B | 指针 / 当前节气强调 / 印章 |
| 春·嫩芽绿 | #8CB369 | 春季色带 |
| 夏·翠绿 | #3E8E5A / #C73E1D | 夏季色带（翠→朱） |
| 秋·赭金 | #C9923A / #B5482A | 秋季色带（金→枫红） |
| 冬·墨青 | #4A5D6B / #C8CDD0 | 冬季色带（墨青→雪灰） |

色带沿圆周按四季连续渐变，跨季节平滑插值。

## 三、字体系统

| 用途 | 字体栈 |

| 物候辞 | 楷体 KaiTi / STKaiti / Noto Serif SC, serif |

## 四、材质

陈纸 + 水墨 + 朱砂印。圆环如一卷环形古历，背景极淡纸纹（CSS / SVG 噪点，克制）。

## 五、交互系统

- **拖拽旋转**：pointer 按住圆环拖动，转动量≈视觉变化量（连续性）
- **阻尼惯性**：释放后角速度非线性衰减
- **滚轮微调**：滚轮可微转
- **点击吸附**：点击节气段吸附放大到该节气详情
- **节气段 hover**：段微微外推 + 高亮描边
- **顶部指针**：朱砂指针固定指示当前节气

## 六、动效系统（13 项，符合物理 / 主题逻辑）

1. 拖拽旋转（连续输入响应）
2. 释放阻尼惯性衰减
3. 节气段 hover 外推高亮
4. 圆心物候辞墨迹晕染淡入
5. 朱砂指针微浮动呼吸
6. 四季氛围粒子（春瓣 / 夏蝉影 / 秋叶 / 冬雪，按当前季节）
7. 色带跨季节连续插值
8. 节气段点击吸附过渡
9. 当前节气印章盖印动效
10. 纸纹极缓微动
11. 光标拖动尾迹（克制）
12. 圆心古典出处逐字浮现
13. 物候辞切换过渡

## 七、自定义光标

- 开页居中显示
- 朱砂指针形态，hover 节气段变抓取 / 放大镜态
- 高对比，层级最高（z-index 9999，pointer-events none）
- prefers-reduced-motion 降级系统光标

## 八、健壮性

- 零未定义引用、零运行时崩溃
- RAF / 定时器随 visibilitychange 暂停、卸载取消
- 快速拖动不叠加定时器；高频 pointer 直接操作 transform
- 支持 prefers-reduced-motion
- 无横向溢出；桌面与移动尺寸下圆环可见可用

## 九、设计审计

- 删动效：轮盘 + 节气段 + 圆心信息仍成立 ✓
- 灰度：节气段四季明度差异仍在 ✓
- 轮廓：径向圆环，与近期线性 web 不同 ✓
- 内容不可替换性：换掉七十二候内容页面不成立 ✓

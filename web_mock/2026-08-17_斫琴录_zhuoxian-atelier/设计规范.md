# 斫琴录 · 古琴工坊 设计规范

> 方向：V1 网页设计 · 日期：2026-08-17 · 主题：古琴斫制工坊官网

## 色彩系统

以大漆器物为灵感，玄黑为底、朱砂点睛、金箔提亮、桐木暖黄温润。

| 角色 | 色值 | 用途 |
|---|---|---|
| 大漆玄黑（底） | `#0D0B09` / `#1C1713` | 页面主背景、深色区块 |
| 桐木深褐 | `#2A221B` / `#3D342C` | 次级背景、卡片底 |
| 木纹灰褐 | `#6B5A47` | 辅助文字、边线 |
| 朱砂红（点睛） | `#B4331F` / `#D94A30` / `#8A2616` | 强调按钮、落款印章、关键交互 |
| 金箔亮色 | `#D4A24A` / `#E8C06E` | 标题高光、徽标、分隔线 |
| 桐木暖黄 | `#F5E4B8` / `#EAE0CC` | 浅色文字、暖色点缀 |

## 字体

- 标题：衬线体栈（Noto Serif SC / 思源宋体），呼应古琴器物的古典气韵
- 正文：无衬线体栈（系统默认），保证可读性
- 落款：手写体意趣，朱砂印章字

## 组件规范

- **古琴 SVG Hero**：纯代码绘制伏羲式古琴，含 13 金徽、龙池凤沼、岳山琴轸、七弦、朱砂落款
- **琴制式卡片**：伏羲 / 仲尼 / 蕉叶三式，3D 倾斜 + 光泽扫过
- **斫琴工序流**：选材 → 制形 → 髹漆 → 安弦 → 调音，五道工序滚动渐入
- **琴曲 Tab**：传统名曲 / 原创琴曲 / 禅意修心 三分类，8 首曲目
- **预约表单**：含成功态反馈

## 动效系统（12+ 组件级特效）

1. 自定义光标（外环阻尼缓动 + 内点跟随 + 悬停三态 + 点击涟漪）
2. 金箔微粒粒子系统（缓速上浮、生命周期循环）
3. 琴弦振动（播放琴曲时触发）
4. 打字机效果（Hero 副标题循环切换）
5. 滚动渐入（IntersectionObserver）
6. 卡片 3D 倾斜（鼠标驱动 + RAF 阻尼积分）
7. 卡片光泽扫过（径向光晕）
8. 数字计数（easeOutCubic 缓动，滚动触发）
9. 印章脉冲呼吸（匠人肖像）
10. 声波频谱柱跳（播放中曲目）
11. 光泽扫过按钮（斜切高光掠过）
12. 导航滚动渐变（scroll 节流 + backdrop-filter）
13. 金箔噪点呼吸（背景层 18s 周期）

## 健壮性

- `visibilitychange` 自动暂停所有 RAF
- `beforeunload` 统一清理定时器与 RAF
- `prefers-reduced-motion` 完整降级
- 高频 mousemove 直接操作 DOM transform
- 响应式断点：1024px / 768px，移动端隐藏自定义光标

## 页面结构

Hero（古琴 SVG + 打字机）→ 琴制式（三式卡片）→ 斫琴工序（五道流）→ 匠人介绍（肖像 + 数字）→ 琴曲琴谱（Tab + 频谱）→ 预约品鉴（表单）→ 页脚

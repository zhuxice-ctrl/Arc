# 设计规范 · 一线牵 · 天空放飞场

> 2026-08-20 V1 网页设计 · Art 设计实验室
> 空间模型：竖向天空高度轴（vertical_sky_altitude_flight_field）
> 核心交互：线拐子收/放/带线 + 筝线张力物理

## 一、设计母题
「一线牵」——整站是一片竖向天空放飞场。地面在下、云层在上，0–120m 高度标尺是唯一空间主轴。用户执线拐子收放筝线，靠线的张力与阵风把纸鸢送上天。三种真实风筝（硬翅沙燕 / 软翅蝴蝶 / 串式龙头蜈蚣）各自有真实的适飞风域、升力特性与操控手感。

设计语言来自潍坊风筝放飞场：线拐子、风筝线、蒲福风级、硬翅沙燕手绘谱式。题材全库首次出现。

| `--sky-warm` | `#C9B8A8` | 晨昏暖调，顶部一道平涂暖带 |
| `--paper` | `#F5F1E6` | 云白纸米，信息卡片与图文底 |

## 三、字体系统
- 字体栈：`"PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", "Source Han Sans SC", sans-serif`
- 标题「一线牵」大号黑体，"线"字内嵌线轴图形，呼应主题
- 正文宋体/无衬线，等宽用于高度/风速读数（仪器语义）
- UI 文案以中文为主

## 四、空间结构
- `.sky` fixed 全屏平涂天青，顶部 14% 暖带（平涂，非渐变）
- 左侧竖向高度标尺 0–120m（6 刻度），常驻
- 左上：高度卡；右上：气象+张力卡；底部：操作提示+风筝选择栏+版权
- 无竖向 section 堆叠、无卡片网格、无 Landing 结构

## 五、筝线张力物理（核心）
- 悬链线↔绷直：张力低时筝线呈二次贝塞尔悬链下垂弧线，张力高时绷直
- 三态可视化：松弛（麦秆黄）/ 适中（麦秆黄）/ 紧绷→危险（朱砂红 + 颤动）
- 张力过载 → 断线失败态：风筝翻卷飘落，可重试
- 起飞需放线（滚轮向下）借风；线长 0 时高度归零

## 六、阵风系统
- 蒲福风级真实描述（0–12 级，含"人面感觉有风，树叶微响"等真实物征）
- 风速实时读数 + 风向箭头缓动
- 随机阵风触发：风筝跃升、草加速摇、风流线加速、阵风闪光
- 签名时刻：阵风来时松垮筝线瞬间绷直成斜线，风筝昂首跃升

## 十、自定义光标

# 蓝晒植物志·日光显影 — 设计规范

## 核心概念

整页是一张正在被日光显影的蓝晒感光纸。用户向下滚动 = UV 紫外线曝光时长增加，纸面从奶油白渐变为普鲁士蓝。12 种本土植物剪影随曝光加深从不可见渐变为白色影子——像在暗房红灯下看到蓝晒纸上影像浮现。底部到达"水洗定影"后的成品蓝晒图鉴。

## 空间模型

**scroll_as_exposure**（滚动即曝光）

页面总高度约 11791px，分为 7 个连续区段：
1. 引言区（奶油白·未曝光的纸）
2. 涂药过渡区（黄绿色·涂布感光液）
3. 春季曝光区（浅蓝·4种植物密集）
4. 夏季曝光区（中蓝·4种植物繁盛）
5. 秋季曝光区（深蓝·2种植物疏朗）
6. 冬季曝光区（普鲁士蓝·2种植物极简）
7. 水洗定影区（纯普鲁士蓝·12格成品图鉴）

## 自定义光标

**放大镜 Loupe**

- 外形：圆环（直径 48px，2px 描边）+ 中心十字准星（水平+垂直各一条 1px 线）
- 初始位置：屏幕正中央（top:50%, left:50%）
- 层级：z-index: 99999
- 移动方式：mousemove 事件直接操作 transform（不用 RAF）
- hover 植物时：放大至 72px，显示拉丁名缩写（属首字母+种加词）
- 颜色自适应：描边色随 CSS 变量 --text-color 变化（浅背景深色、深背景浅色）
- 移动端（≤900px）：隐藏 loupe，恢复原生光标

## 动效系统

共 8 个 @keyframes 动画 + 12 个 transition，服务于"显影"化学物理过程：

### 核心动效
1. **曝光渐变**：scroll 事件 → requestAnimationFrame → 5 级色阶线性插值 → CSS 变量更新（连续非 step）
2. **剪影浮现**：opacity 0→0.85 + blur 8px→0，模拟化学反应中影像逐渐显现
3. **信息面板浮现**：opacity 0→1 + translateY(20px→0)，跟随剪影出现
4. **放大镜光标**：width/height transition 0.25s cubic-bezier(0.2,0.8,0.2,1)
5. **水波纹**：底部水洗区 3 条 SVG path 正弦波，CSS animation 驱动，相位各异
6. **成品卡片渐入**：12 张卡片 setTimeout 逐张延迟 80ms 渐入
7. **银杏散叶**：秋季区散落银杏叶，不同角度+大小
8. **背景色过渡**：transition 0.05s linear，保证色彩切换平滑

### prefers-reduced-motion 降级
- 所有 animation-duration 设为 0.01ms
- 所有 transition-duration 设为 0.01ms
- 剪影/信息/卡片强制 opacity:1 + blur:0 + transform:none（内容立即可见）

## 技术栈

- 纯 vanilla 单文件 HTML（HTML + CSS + JS）
- 无外部依赖（无 React/Babel/CDN/外部字体/外部图片）
- 所有 SVG 内联
- CSS 变量驱动色彩插值
- 系统字体栈
- 文件大小：约 91KB

## 健壮性措施

- scroll 事件 passive listener + requestAnimationFrame + ticking flag（防叠加）
- mousemove 直接操作 transform（不触发重渲染）
- visibilitychange 暂停所有 CSS animation
- beforeunload 清除事件监听器
- resize 防抖 200ms 重新计算曝光
- 零未定义引用（IIFE 严格模式）

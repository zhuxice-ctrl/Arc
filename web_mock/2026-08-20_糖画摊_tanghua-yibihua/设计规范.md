# 设计规范 · 铜勺琥珀（糖画摊·一笔画）

> V1 网页设计 · 2026-08-20 · 民间街头手艺题材
> 以下色值、字体、动效均从 `index.html` 源码实测提取。

## 一、Design DNA

- **核心概念**：整站就是一张街头糖画摊——大理石板为案，铜勺盛炭炉上化开的糖稀，用户转草靶转盘定题，执勺以一笔不断的手势浇出糖画；糖线当面从炽亮液态冷却成半透明琥珀，铲起上草靶收藏。
- **网站类型**：展览 + 实验型（一个可玩的糖画摊）。
- **空间模型**：`stall_workbench_fixed_stage`——固定摊位工作台舞台：左侧铜锅 + 八卦转盘，中央大理石画板（绝对视觉中心，桌面 `--slab-w: min(62vw,780px)`、`--slab-h: min(55vh,560px)`），右侧草靶收藏 + 糖谱档案；下滚为糖画小史编辑区。
- **视觉来源**：成都街头糖画摊——大理石板、铜勺铜锅、炭炉、麦秆草靶、木转盘十二生肖。
- **材质逻辑**：糖（半透明 / 光泽 / 脆）× 石（哑光 / 纹脉）× 铜（高光）三种材质贯穿全站每一控件。

| 用途 | font-family |

## 四、动效系统（12+ 组件级特效，均服务糖的温度与时间）

CSS 关键帧（实测 `@keyframes`）：
1. `charcoal-glow` — 炭炉火光呼吸
2. `steam-rise` — 糖稀蒸汽粒子上浮
3. `pawl-click` — 转盘棘爪咔哒弹跳
4. `sweep` — 冷却高光从头到尾扫过（签名时刻）
5. `liftAnim` / `shovel-lift` — 铲刀滑入 + 糖画弹性弯曲离板
6. `insert-wobble` — 草靶插入轻晃
7. `pulse-subtle` — 状态点微脉
8. `scroll-bounce` — 下滚提示弹跳

Canvas / JS 驱动（实测函数）：
9. `drawSugarSegment` + `drawSugarDrop` + `drawTailOff` — 糖线实时渲染，宽度随手速、起笔垂滴 / 收笔拉丝
10. `startCooling` → `onCoolingComplete` → `drawHighlightSweep` — 冷却颜色插值渐变 + 高光扫过
11. `spinTurntable` + `settleTurntable` + `getPointerAngle` — 转盘惯性旋转 + 摩擦减速 + 停稳对格
12. `createSteamParticle` / `startSteam` / `stopSteam` — 蒸汽粒子系统（随可见性暂停）
13. `animateCursor` — 自定义铜勺光标缓动跟随（开页居中、高对比、层级最高）
14. `generateMiniSugarSVG` + `renderStrawCollection` — 收藏糖画缩略图生成与草靶渲染

**动效语言**：液态物理——糖线内部高光流动、冷却时颜色插值、热锅蒸汽、转盘惯性棘爪、铲起弹性弯曲、草靶插入轻晃。禁用整图缩放 Ken Burns。

## 五、核心交互闭环

`setGuidePath`（转盘定题→石板烙虚线引导）→ `startDraw`/`moveDraw`/`endDraw`（按压起笔 / 拖动走糖 / 抬勺收笔，线宽随手速）→ `startCooling`→`onCoolingComplete`（约 6–10 秒炽热→琥珀渐变）→ `liftSugar`/`shovel-lift`（铲刀起糖、弹性离板）→ `addToCollection`/`renderStrawCollection`（插草靶收藏、可累积回看）。

## 六、健壮性

- 纯 vanilla 单文件，零外部依赖（无 React / Babel / CDN / 外部图片 / 外部字体）。
- RAF / 蒸汽粒子随页面可见性暂停，卸载取消；快速操作不叠加定时器。
- 高频鼠标事件直接操作 DOM / Canvas，不触发重渲染。
- `prefers-reduced-motion` 下冷却以静态渐变呈现、动画降级。
- 适配 1440 / 1024 / 768 / 390，实测四尺寸均无横向溢出。

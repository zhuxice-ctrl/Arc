## 圆角与间距

- 卡片圆角 12px，按钮 8px，幕布/舞台模块直角
- 主内容最大宽度 1200px，段落行高 1.8，字距适度收紧

## 组件

- 幕布舞台 Hero：左右帘布 + 金色镶边，可拉开揭幕
- 皮影剪影层：4 层差速视差，角色各自周期摇曳
- 剧目卡片：3D 倾斜 + 光束扫过 + 悬停上浮
- 数据统计带：数字计数滚动（IntersectionObserver 触发）
- 票务卡：4 档票价，悬停光泽扫过按钮
- 班社头像：脉冲发光环
- SVG 场地地图：标记脉冲

## 动效系统

18+ 组件级特效，全部基于 RAF 积分器 / 弹簧 / 主题语义：

1. 幕布拉开揭幕（左右帘缓动）
2. 皮影剪影多层视差（mousemove 直改 transform）
3. 皮影角色摇曳（各异周期 sway）
4. 自定义光标（朱红粗环 + 鎏金内点 + 暖光外晕，三态切换）
5. 点击涟漪扩散
6. 剧目卡片 3D 倾斜
7. 光束扫过卡片（light sweep）
8. 数字计数滚动
9. 打字机循环（Hero 副标题 4 句）
10. 滚动渐入（错位延迟）
11. 导航栏滚动形态变化
12. 班社头像脉冲发光
13. 金色粒子浮游（RAF 驱动）
14. 票券悬停上浮 + 光泽按钮
15. 工坊舞台 3D 透视悬停
16. 地图标记脉冲
17. 标题汉字逐字入场
18. 灯笼光晕呼吸律动

健壮性：所有 RAF/setTimeout 统一管理，visibilitychange 自动暂停/恢复；prefers-reduced-motion 全面降级为静态；mousemove 类动画直接操作 DOM 不触发重渲染。

## 页面结构

开幕 Hero（皮影幕布舞台）→ 数据统计带 → 剧目单（皮影/提线/布袋/杖头 Tab 切换）→ 参展班社（8 家）→ 票务信息（4 档）→ 幕后工坊体验 → 场地交通（SVG 地图）→ 页脚

## 技术栈

React 18 + Babel standalone（JSX 内联于 `<script type="text/babel">`），单文件 index.html，无构建步骤。

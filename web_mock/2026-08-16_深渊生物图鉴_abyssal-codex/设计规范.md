## 主题

深渊生物图鉴杂志/科普官网 —— 把深海生物做成一本可滚动的博物学图鉴。访客从刊头声呐波纹走进，依次浏览图鉴档案、深度带、荧光画廊、深渊科考史时间线、季刊订阅。博物学杂志气质 + 深海仪器读数感。

## 动效原理（13）

1. 自定义光标：白环 + 荧光内点 + 发光，弹簧跟随，悬停变色膨胀，点击涟漪。
2. 生物荧光粒子漂流：正弦洋流波动 + 呼吸式透明度。
3. 深度读数弹簧插值 + 深度带切换。
4. 卡片 3D 倾斜：Hooke 弹簧 + 阻尼。
5. 数字计数：easeOutCubic。
6. 滚动渐入 reveal。
7. Hero canvas 海洋雪粒子。
8. 声呐波扩散（错峰周期）。
9. 发光脉冲：logo / 卡片光环 / 画廊光点。
10. 光泽扫过：CTA 按钮 + 画廊图。
11. 深度带层激活。
12. Hero 多层视差：弹簧滚动。
13. 导航栏滚动收缩 + 毛玻璃。

## 健壮性

- visibilitychange 暂停/恢复 RAF，beforeunload 统一清理。
- resize 防抖；prefers-reduced-motion 全量降级。
- 光标开页即显示在屏幕中央，z-index 最高。
- 零未定义引用。

# 茶焙志 · 设计规范

## 主题

武夷岩茶焙火工艺——以焙笼垂直剖面为空间模型的热力梯度网站。

## 核心概念

将竹制焙笼的纵剖面映射为页面空间：用户从顶部鲜叶层向下滚动，逐层深入走水焙→焙火→炖火→热气层→炭火层，颜色随深度模拟热力梯度（绿→琥珀→棕→炭黑→余烬橙）。温度=颜色是贯穿全局的母题。

## 空间模型

### 焙笼纵剖面结构

- **焙笼壁**：左右两侧 `position: fixed` 竹编纹理（45°/-45° 交叉渐变），768px 以下隐藏
- **9 层深度**：每层 `min-height: 100vh`（移动端 auto），背景渐变与相邻层衔接
- **内容区**：`max-width: 900px`，居中，左右 padding 80px（移动端递减至 24px）
- **温度计进度条**：右侧固定，4 段标签（鲜叶/走水/焙火/炭火），768px 以下隐藏

### 响应式断点

| 断点 | 变化 |
|------|------|
| ≤1024px | padding 60px，焙火三档变单列，进度条右移 |
| ≤768px | 焙笼壁隐藏，layer 高度 auto，温度计横置，进度条隐藏 |
| ≤480px | padding 24px，标题间距收紧，交互区高度 280px |

## 动效系统（18 个组件级特效）

### 主题驱动动效

1. **烟雾 Canvas 粒子** — 热气层 + 炭火层，生成率/上升速度响应 `fireStrength`
2. **耙灰控火 Canvas** — 拖动拨开灰烬，灰烬高度数据数组实时更新
3. **炭块发光** — 火力超阈值时 `.exposed` class 切换发光渐变
4. **炭火光晕脉动** — `sin(Date.now()/1000)` 正弦波呼吸
5. **火星迸溅** — `setInterval` 定时生成，带重力抛物线轨迹
6. **灰烬飞溅粒子** — 拨灰时生成，带重力和缩放衰减
7. **温度计实时填充** — 跟随 `fireStrength` 高度变化
8. **温度阶段文字切换** — 6 段描述（炖火/走水焙后期/走水焙/轻火/中火/足火）

### 环境氛围动效

9. **热气波纹** — 走水焙 + 焙火区，横向 CSS 动画流动
10. **蒸汽上升** — 鲜叶层底部，8 个 CSS 动画粒子
11. **鲜叶装饰** — 8 牊随机位置/旋转/透明度茶叶
12. **竹篾纹理** — 交叉线条 repeating-linear-gradient

### 交互反馈动效

13. **自定义光标** — 余烬光晕，RAF 节流，暗区增强亮度
14. **滚动进度温度计** — 填充高度跟随滚动百分比
15. **焙火等级卡片 hover** — translateY(-4px) + 边框增亮
16. **风味标签 hover** — translateY(-2px) + 背景加深
17. **滚动提示浮动** — floatDown 2s 循环
18. **术语 tooltip** — hover 显示，scale + opacity 过渡

### 健壮性保障

- 所有 RAF 通过 `RAF` 对象管理，`visibilitychange` 暂停/恢复
- `beforeunload` 取消所有 RAF + 清除所有 setInterval
- 鼠标事件 `passive: true`，光标 RAF 节流
- `prefers-reduced-motion` 关闭所有动画 + 恢复系统光标
- 触屏设备隐藏自定义光标，拨灰改用 touch 事件

## 内容真实度

- 真实工艺温度：走水焙 100-110°C、轻火 120°C、中火 125°C、足火 130°C、炖火 80-90°C
- 真实工序名称：走水焙、焙火、炖火、退火静置
- 真实名枞：大红袍、肉桂、水仙、奇兰
- 真实引文：陆羽《茶经》"茶者，南方之嘉木也"
- 真实材料：杂木炭、龙眼木炭、谷灰/砻糠灰

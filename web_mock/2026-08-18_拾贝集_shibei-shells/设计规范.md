## 页面结构（7 板块）

1. 首屏 Hero：大标题「拾贝集」+ 打字机副标题 + 展期/地点/展品三栏 + 潮汐波浪底饰
2. 展览前言：左图右文 + 首字下沉 + 策展人署名
3. 数据统计条：300 种 / 126 件 / 42 米 / 180 天（滚动数字计数）
4. 标本画廊：6 件标本卡 + 5 类分类筛选（全部/头足/腹足/宝螺/双壳）
5. 展区导览：四大展区（潮汐之境 / 螺旋秘境 / 深海遗珍 / 贝饰人文）
6. 策展人：林屿舟介绍 + 引言 + 研究数据
7. 参观预约：参观信息 + 可提交预约表单（含成功反馈态）
8. 页脚：导航 + 联系信息

## 动效系统（14 项）

1. 自定义光标：弹簧物理跟随 + 白色粗环 + 珊瑚色内点 + 发光光晕 + 悬停放大变色 + 点击涟漪
2. 标本卡片 3D 倾斜：RAF 阻尼积分器，mousemove 直接操作 transform
3. 贝壳光泽扫过：悬停斜向高光扫过
4. 潮汐波浪：三层不同相位正弦波，8 秒周期错相
5. 首屏视差：鼠标移动背景/漂浮贝壳不同速率位移
6. 数字计数：cubic ease-out，滚动入视口触发
7. 打字机：副标题逐字打出 + 闪烁光标
8. 滚动渐入：IntersectionObserver 淡入上移
9. 磁性按钮：反平方引力模型
10. 脉冲环：预约按钮呼吸式光晕
11. 滚动粒子：Canvas 正弦波粒子，受滚动值驱动
12. 导航栏滚动收缩：背景模糊 + 高度变化
13. 漂浮贝壳装饰：两组不同周期旋转浮动
14. 预约成功脉冲动画

## 组件

- 导航栏（滚动收缩/毛玻璃）、标本卡（3D 倾斜+光泽扫过）、分类筛选 Tab、数据计数条、磁性按钮、预约表单、页脚链接组。

## 技术栈

React 18 + Babel standalone（JSX/CSS 全部内联 index.html），无构建步骤。支持 prefers-reduced-motion 降级；RAF/定时器随 visibilitychange 暂停、卸载取消。

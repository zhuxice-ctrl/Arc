# 设计规范 · 青出于蓝 · 蓝染织物艺术馆

> 方向：V1 网页设计｜日期：2026-08-17｜形态：单页沉浸式官网

## 色彩系统

主配色：靛蓝 + 米白 + 柿橙（纯色，禁止蓝紫渐变）。

| 角色 | 色值 | 用途 |
|---|---|---|
| 靛青（主色） | `#1D3A6E` | 主背景 / 标题 / 主按钮 |
| 玄青（最深） | `#0F2247` | 深色区块 / 页脚 |
| 夜靛 | `#0A1A38` | 极暗衬底 |
| 蔚蓝 | `#2C5192` | 次级强调 |
| 天青 | `#3A5F9A` | 链接 / 辅助 |
| 雾蓝 | `#8BA8CC` | 弱化文字 / 描边 |
| 素棉（米白） | `#F5EFE2` | 亮色区块底 / 正文反白 |
| 陈米 | `#E8DFCC` | 卡片表面 |
| 柿橙（点缀） | `#D9622B` | 强调 / 数据 / 涟漪 |
| 浅柿 | `#E8844A` | hover 高亮 |

## 字体

- 标题：`"Noto Serif SC", serif`（衬线，模拟织物题签质感）
- 正文：`"Noto Sans SC", "PingFang SC", "Microsoft YaHei", sans-serif`
- 数字/代码：`"Noto Serif SC", monospace`

## 页面结构

1. 首屏 Hero：巨型衬线标题 + 绞缬织物 3D 倾斜卡片 + 三项数据统计
2. 四大染缬工艺：绞缬 / 蜡缬 / 夹缬 / 型染（起源朝代、工艺流程、染色次数）
3. 织物典藏：6 件藏品 + 分类标签切换（全部 / 古代 / 民艺 / 当代）
4. 守蓝匠人：3 位非遗传承人简介 + 从艺数据
5. 染缸色号：5 级青蓝色阶（月白→天青→蔚蓝→靛青→玄青）+ 动态染缸可视化
6. 工坊体验预约：4 项特色 + 6 个场次 + 预约表单

## 动效系统（16 个组件级特效，基于物理 / 语义）

1. 自定义光标（外白环 + 橙内点 + 光晕，惯性跟随，悬停三态，点击涟漪）
2. 染液粒子（25 颗染料颗粒正弦漂移 + 下沉）
3. 英雄织物 3D 倾斜（反平方磁力 + 阻尼弹簧）
4. 滚动渐入（IntersectionObserver + 错位延迟）
5. 打字机（变速节奏，标点停顿）
6. 数字计数（easeOutCubic 物理减速）
7. 导航滚动态切换
8. 藏品标签切换（渐隐 + 错峰渐现）
9. 染缸涟漪扩散（不规则周期）
10. 色阶悬停染缸变色（径向渐变过渡）
11. 匠人头像脉冲环（三层错峰）
12. 工艺卡片 3D 倾斜（磁力弹簧）
13. 光泽扫过（藏品卡斜向高光）
14. 场次选择器（互斥激活）
15. 表单提交状态机
16. 平滑滚动导航

## 组件规范

- 卡片圆角 `16px`；按钮圆角 `10px`；标签胶囊 `999px`
- 阴影：`0 8px 30px rgba(10,26,56,.18)`
- hover 抬升：`translateY(-6px)` + 阴影加深

## 健壮性

零未定义引用 / `visibilitychange` 暂停 RAF 与定时器 / `beforeunload` 统一清理 / `prefers-reduced-motion` 全量降级 / mousemove 直接操作 transform 不触发重渲染。

# 翡翠矿脉博物馆 · 设计规范

> 日期：2026-08-17 · 方向：V1 网页设计 · 主题：翡翠矿脉博物馆（虚拟矿物晶体博物馆官网）

## 色彩系统

以深翡翠绿为底，玉绿为主色，铜青辅助，米色为文字/卡片底，金色点缀强调。禁蓝紫渐变。

| 角色 | 色值 | 用途 |
|------|------|------|
| 底色（深翡翠绿） | `#062e1f` | 页面背景、最深层级 |
| 次底色 | `#041e14` | Hero / 页脚最深底 |
| 主色（玉绿） | `#1fb589` | 主交互色、强调线、按钮 |
| 主色亮 | `#2fd1a0` / `#3de0b0` | 高亮、hover、渐变末端 |
| 主色深 | `#179470` / `#0a3a29` | 悬浮态暗调、分隔 |
| 辅助色（铜青） | `#5fb89e` / `#7ccfba` | 次级强调、卡片描边 |
| 表面色（暖米色） | `#e8dcc3` / `#f5ecd9` | 文字浅底、卡片底 |
| 文字米色 | `#e8dcc3` | 正文浅色文字 |
| 点缀色（金色） | `#d4a946` / `#e8c36b` | 细线、徽标、数字强调 |
| 辅助暖灰 | `#b8a88a` / `#7a6f5a` | 次级文字、边框 |

## 字体

系统无衬线栈为主，标题加大字重；数字/计数器使用等宽倾向。无外部字体 CDN 依赖。

## 圆角与间距

- 卡片圆角：12px / 16px；按钮圆角：8px；徽标圆角：999px（胶囊）。
- 间距体系：8 / 12 / 16 / 24 / 32 / 48 / 64 px 节奏。

## 页面结构

单页九大板块，纵向滚动叙事：

1. 顶部导航栏（吸顶，滚动渐变）
2. Hero 首屏（大标题 + 矿脉流光背景 + Canvas 粒子）
3. 数据统计（数字计数动画）
4. 六大主题展厅（卡片网格，3D 倾斜）
5. 晶体标本图鉴（分类 Tab 切换 + 卡片光泽扫过）
6. 矿脉形成科普（双层视差）
7. 馆藏珍品（三件轮播 + 打字机名称）
8. 参观预约表单（可提交）
9. 页脚

## 动效系统（14 个组件级特效）

| # | 动效 | 物理模型 / 语义 |
|---|------|----------------|
| 1 | 自定义光标 | 白环+玉绿内点+多层发光，三态切换，点击涟漪 |
| 2 | Canvas 粒子系统 | 矿脉连线，粒子漂浮+邻近连线 |
| 3 | 3D 卡片倾斜 | 弹簧阻尼（Hooke + 阻尼回归），鼠标驱动 |

| 5 | 悬停发光 + 晶面光泽扫过 | 线性光泽划过卡面 |
| 6 | 打字机 | 珍品名称逐字轮播 |
| 7 | 数字计数 | easeOutExpo 缓动 |
| 8 | 鼠标涟漪 | 点击扩散衰减 |
| 9 | 双层视差 | Hero 滚动视差 + 科普图鼠标驱动 |
| 10 | 光泽扫过 | 按钮与标本卡 |
| 11 | 矿脉流光脉冲 | 周期性流光沿矿脉走线 |

| 14 | 珍品星芒闪烁 | 旋转星芒+透明度脉冲 |

## 健壮性

- visibilitychange 自动暂停 RAF / 定时器；beforeunload 统一清理。
- safeSetTimeout / registerRAF 中心化管理，重建前先 clear 旧句柄。
- 高频 mousemove 直接操作 DOM transform，不触发重渲染。
- prefers-reduced-motion 完整降级为静态。
- 单文件零外部 JS 依赖，纯 vanilla HTML/CSS/JS。

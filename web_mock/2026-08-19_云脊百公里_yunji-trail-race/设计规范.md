# 设计规范 · 云脊百公里越野赛网站

## 主题与类型
越野跑赛事网站（赛事/数据编辑型）。整站 = 一条 100km 赛道的连续海拔剖面，滚动即沿赛道行进。

## 空间模型
continuous_elevation_profile_spine（连续横向海拔剖面主轴）。所有节点（起点/CP1/CP2/主垭口/CP3/终点）锚定公里数，内容挂在剖面上，不脱离主轴游离。

## 配色（禁蓝紫渐变，纯色语义化）
- 花岗岩深灰 `#2E3440` / `#1F2A24` 底
- 冰川白纸面 `#D4BFA3`/`#D4A574` 系
- 救援橙 `#E4572E`（实取 `#C73E1D`/`#B8421C`）——仅关键动作/关门/节点旗标
- 高山松绿 `#3A5A40`/`#588157` 辅助（爬升段填充）
- 苔藓绿 `#6B8E23`/`#8FBC3A` 爬坡强度指示

## 字体
- 里程/数据：`JetBrains Mono`（等宽，计时牌质感）
- 正文：`Noto Sans SC`
- 标题：`Noto Serif SC`

## 动效系统（≥12 组件级，均服务剖面语义）
剖面游标沿海拔线滑动、进度路径描边生长、节点沿剖面方向滑入（非 fade-up）、节点标题下划线条纹生长、统计数字弹入、补给站抵达闪光、终点冲线光泽扫过、爬坡强度实时表、垭口等高线加密（签名时刻）、夜间段画面变暗、顶部导航下划线生长、自定义光标 hover 放大+公里标签。无整图缩放 Ken Burns。

## 核心交互
垂直滚动驱动横向赛道行进（输入量≈位移量）；节点点击展开详情；拖拽海拔游标快速跳转任意公里数。

## 签名时刻
抵达最陡爬升段（约 62km，1800→2600m）时剖面骤陡、等高线加密、呼吸收紧，翻过垭口瞬间视野展开。

## 自定义光标
救援橙圆点 + mix-blend-mode difference，开页居中，悬停放大、点击收缩、节点处显示公里标签，z-index 9999。移动端回退原生光标。

## 健壮性
RAF 随 visibilitychange 暂停/恢复，beforeunload 取消；滚动 rAF 节流、resize 防抖；prefers-reduced-motion 降级为静态剖面+锚点跳转；1440/1024/768/390 四档可用。

## 技术栈
纯 vanilla（HTML + CSS + JS，无框架/无构建）。字体经飞书字体 CDN 加载。

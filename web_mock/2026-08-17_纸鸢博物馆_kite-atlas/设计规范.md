# 设计规范 · 纸鸢博物馆 Kite Atlas

> 方向：网页设计（V1） · 日期：2026-08-17 · 主题：世界纸鸢/风筝文化与制作工艺

## 色彩系统

朱砂红 + 天青 + 宣纸米 + 墨黑 + 金赤 五色体系，取自传统东方风筝的纸绢颜料与竹骨色调。

| 角色 | 色值 | 用途 |
|------|------|------|
| 主色 | #D43F3F | 朱砂红，标题、强调按钮、时间线节点 |
| 辅助色 | #2A8B8B | 天青，次级标题、链接、地图标记 |
| 背景色 | #F5EDD8 | 宣纸米，页面底色、卡片背景 |
| 文字色 | #1a1a2e | 墨黑，正文、次要文字 |
| 强调色 | #C9A84C | 金赤，装饰线、光晕、数字计数高亮 |
| 深红 | #A82E2E | 悬停态、激活态 |
| 深青 | #1E6A6A | 链接悬停、地图深色区域 |
| 浅米 | #E8DDC4 | 卡片交替背景、分隔区 |
| 浅金 | #E0C371 | 光泽扫过、装饰渐变 |
| 暗灰紫 | #2d2d44 | 深色区块背景 |

## 字体系统

- 标题字体：`'Noto Serif SC', 'Songti SC', Georgia, serif` — 衬线体，传达古典文化气质
- 正文字体：`-apple-system, 'PingFang SC', 'Microsoft YaHei', sans-serif` — 无衬线体，清晰易读
- 字重使用：标题 700/900，正文 400/500

## 组件规范

- 卡片：圆角 12px，宣纸米底色，box-shadow: 0 4px 20px rgba(26,26,46,0.08)
- 按钮：圆角 8px，朱砂红底白字，hover 光泽扫过 0.6s
- 时间线节点：圆形 16px，朱砂红填充，脉冲发光动画
- 地图标记：脉冲光点 + 光环扩散，天青色
- 图鉴卡片：3D 倾斜，perspective 800px，hover rotateX/rotateY 跟随鼠标

## 页面结构

1. Hero 首屏 — 大标题"放飞纸鸢 与风对话"，漂浮风筝+粒子背景+卷轴入场
2. 历史长河 — 7 段时间线，左右交错布局
3. 制作四艺 — 扎/糊/绘/放四步工艺图解，悬停抬升+金线展开
4. 世界地图 — 深色背景，8 个文化地标脉冲光点
5. 飞行模拟器 — 实时操控风速/线长/风向，风筝物理模拟
6. 风筝图鉴 — 6 款经典造型，3D 倾斜交互

## 技术栈

纯 vanilla HTML/CSS/JS 单文件，无 React/Babel/CDN 依赖。Canvas 2D 渲染粒子和飞行模拟。CSS Custom Properties 管理设计令牌。

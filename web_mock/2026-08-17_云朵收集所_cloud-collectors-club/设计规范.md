# 设计规范 · 云朵收集所 The Cloud Collector's Club

> 日期：2026-08-17 ｜ 方向：V1 网页设计 ｜ 主题：观云爱好者协会官网

## 色彩系统

| 角色 | 色值 | 用途 |
|------|------|------|
| 底色 云白 | `#F7F4EE` | 页面背景、卡片表面 |
| 主色 雾灰蓝 | `#8FA3B5` | 导航、云层描边、次级文字 |
| 强调色 杏桃橙 | `#F2A65A` | CTA、高亮、数据峰值 |
| 文字色 深石板 | `#33404C` | 标题与正文 |
| 点缀色 淡金 | `#D9B98A` | 会员徽章、装饰线条 |

整体浅色低饱和，禁蓝紫渐变；局部用雾灰蓝→云白纵向柔光过渡模拟天光。

## 字体

- 标题：`'Noto Serif SC', serif`（衬线，营造手账/博物气质）
- 正文：`'Noto Sans SC', system-ui, sans-serif`
- 数字/标签：`'Playfair Display', serif`（斜体用于英文副标题）

## 圆角 / 阴影

- 卡片圆角 `18px`；按钮 `999px`（胶囊）；图鉴圆角 `12px`
- 阴影：`0 12px 40px rgba(51,64,76,.10)`，悬停加深至 `.18`

## 页面结构（单页完整网站）

1. Hero 首屏 — 标题 + 副标题 + CTA「加入协会」
2. 今日云图鉴 — 积云特辑 + 数据统计（数字计数动效）
3. 收集图鉴画廊 — 8 种云型卡片 + 分类筛选 chips
4. 观云指南 — 四步入门（滚动渐入级联）
5. 会员故事 — 横向滚动卡片（头像脉冲光环）
6. 加入协会 — 表单 + 提交成功态（打字机文案）
7. 页脚

## 动效系统（14 个组件级特效，均贴合云主题语义）

1. 自定义光标：白环 + 杏色内点 + 薄雾尾迹，悬停放大，点击涟漪
2. Hero 三层云层视差滚动（滚动驱动云量变化）
3. 云层自由漂移（正弦运动，周期各异）
4. 粒子云聚散系统：60 粒子 + 鼠标磁性反平方引力
5. 卡片 3D 倾斜（mousemove 直接操作 transform，不 setState）
6. 光泽扫过卡片（悬停触发）
7. 数字计数动画（缓出 + IntersectionObserver 触发）
8. 打字机效果（加入区描述文本）
9. 滚动渐入（各章节 reveal，阻尼缓动）
10. 导航栏滚动毛玻璃化
11. 头像脉冲光环（会员故事卡片）
12. 滚动指示线下落动效
13. 导航链接下划线展开
14. 大云朵漂浮动画（今日云图鉴）

## 健壮性

- 所有 RAF / 定时器随 `visibilitychange` 自动暂停、卸载取消
- 高频 mousemove 直接操作 DOM transform，不触发 React 重渲染
- 支持 `prefers-reduced-motion` 降级为静态
- JSX 与 CSS 全部内联在 `index.html`

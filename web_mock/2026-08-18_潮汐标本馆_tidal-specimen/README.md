# 潮汐标本馆 Tidal Specimen

> 日期：2026-08-18 · 方向：V1 网页设计 · 主题：潮间带生物与海洋标本自然博物馆官网

## 简介

「潮汐标本馆」是一座虚构的海洋自然博物馆官方网站：深墨绿的展厅底色上浮动着珊瑚橘的强调光，浪潮曲线在英雄区实时生成，标本卡片可 3D 倾斜把玩，潮汐波谱柱随页面节律呼吸。整站以中文文案为主，内容（馆藏、特展、参观信息）均围绕主题真实组织。

## 动效亮点

- 开屏即居中显示的自定义光标：弹簧跟随、悬停放大变色、点击涟漪、多层发光
- 浪潮 SVG 双正弦实时路径动画 + 海面气泡粒子（随机周期）
- 标本卡鼠标驱动 3D 倾斜（弹簧阻尼）+ 光泽扫过
- 潮汐波谱柱：20 根柱体多正弦叠加，模拟潮汐节律
- 打字机标题（随机速率抖动）、数字计数、磁性按钮（反平方引力）、Hero 视差

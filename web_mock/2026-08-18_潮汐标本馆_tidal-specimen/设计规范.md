# 潮汐标本馆 · 设计规范

> 日期：2026-08-18 · 方向：V1 网页设计 · 主题：潮汐标本馆（潮间带生物与海洋标本自然博物馆官网）

## 色彩系统

| 角色 | 色值 | 用途 |
|---|---|---|
| 深墨绿（主色） | `#0E3B33` | 页面主背景、导航、页脚 |
| 深渊绿（暗部） | `#061E1A` / `#0A2C26` | 背景深浅分层、卡片暗面 |
| 珊瑚橘（强调色） | `#FF6B4A` | 主按钮、悬停态、光标内点、重点数据 |
| 海泡石绿（辅助色） | `#7FB69E` | 次级信息、标签、图标点缀 |
| 贝壳白（表面色） | `#F7F2E9` | 浅色分区背景、正文反白 |
| 沙金（点缀色） | `#D9A441` / `#E8C36E` | 藏品编号、徽章、装饰线 |

无蓝紫渐变；渐变仅在同色系墨绿 ↔ 深渊绿之间微妙过渡。

## 字体

- 标题：`"Noto Serif SC", serif`（衬线，博物馆气质）
- 正文：`"Noto Sans SC", -apple-system, "PingFang SC", sans-serif`
- 数字 / 编号 / 标签：`"Noto Mono", monospace`

## 页面结构（单页纵向叙事）

1. 英雄区：打字机标题 + 浪潮 SVG 双正弦路径动画 + 气泡粒子 + 视差大图
2. 馆藏标本精选：3D 倾斜标本卡 + 光泽扫过
3. 馆藏数据统计：数字计数（三次方缓动）
4. 三大特展：Tab 切换淡入
5. 研究方向：滚动渐入卡片
6. 参观信息与票务：磁性按钮
7. 订阅通讯 + 页脚

## 动效系统（14 项组件级特效）

自定义光标（弹簧跟随/悬停变形/点击涟漪/多层发光，开屏居中）、气泡粒子上升、打字机（随机速率抖动）、滚动渐入（IntersectionObserver）、数字计数、标本卡 3D 倾斜（弹簧阻尼+光泽扫过）、潮汐波谱柱（20 柱正弦叠加）、浪潮 SVG 路径动画、Hero 视差（lerp 惯性）、磁性按钮（反平方引力）、导航滚动形态变化、跑马灯信息条、展览 Tab 淡入、移动端菜单错位进场。

## 健壮性

- 全部 RAF / 定时器随 `visibilitychange` 自动暂停，卸载统一取消
- 高频 mousemove 直操 DOM transform，不触发 React 重渲染
- 重建定时器前先清旧；零未定义引用
- `prefers-reduced-motion` 全量降级为静态
- JSX 全部内联于 `<script type="text/babel">`，无外部 src

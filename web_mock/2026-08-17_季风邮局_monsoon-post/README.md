# 季风邮局 The Monsoon Post

> 日期：2026-08-17　方向：V1 网页设计　形态：单页艺术展 / 品牌官网

## 简介

「季风邮局」——一个虚构的"把季节装进信封寄给你"的艺术展官网。围绕不同季风时节的信件藏品、邮票珍藏墙、邮戳博物、寄信人故事与季节之信订阅，构建一座暖调复古印刷风的纸面邮局。所有内容（信件标题、寄信人、日期、地点、邮票名称）真实可信，无 lorem ipsum。

## 设计说明

- 配色：芥末黄 `#D9A621` + 砖红 `#B23A2E` + 墨黑 `#1A1714` + 米白 `#F5EFE2`，牛皮纸 / 活字印刷 / 火漆印质感
- 字体：ZCOOL XiaoWei（展示）/ Noto Serif SC（正文）/ JetBrains Mono（打字机）
- 详见 [`设计规范.md`](./设计规范.md)

## 动效亮点

自定义光标（弹簧跟手 + 点击涟漪）、季风粒子（叶/尘两类正弦摆动）、火漆按下→信封翻盖→信纸滑出序列、邮票打孔边悬停发光、滚动驱动盖印邮戳、弹簧数字计数、打字机逐字（标点停顿）、蜡封导航旋转、按钮光泽扫过等共 15+ 组件级特效，全部基于物理/主题语义。

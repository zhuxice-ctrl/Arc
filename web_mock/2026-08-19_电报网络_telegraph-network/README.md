# 电报网络·摩尔斯收发局

## 主题

一座清末民初的电报局网络档案馆。界面是一张铺开的电报网络图——节点是各地电报局（真实地名+开通年份），连线是开通的电报线路（年份+里程）。你坐到黄铜电键前，亲手敲击摩尔斯电码，脉冲沿选定线路发光行进，抵达对端电报局后被解码、烙印在匀速上移的电报纸带上。

让用户体会"电报"的物理本质：信息不是即时弹出的，而是被一记记敲击编码、沿铜线跋涉、在另一端被逐字解码——感受那一代「距离」与「时延」。

## 简介

- **空间主体**：1871–1911 电报网络节点图（9 局 + 7 线，年份可切换），非水平脊柱/非滚动叙事。
- **签名交互**：黄铜电键敲击编码摩尔斯（按下 <180ms=点·、≥180ms=划—）→ BFS 求多跳最短路径 → 金色脉冲沿 SVG 线路逐段行进 → 对端纸带逐字烙印解码。键盘空格/字母键亦可输入。
- **档案内容**：南北八局名录（同治/光绪年号 + 大北公司/丁日昌/李鸿章/张之洞史料）、铜线千里线路表（含里程与类别）、五等电报与资费、四码电报制度（电7193/报1032/网4848/络4827）。
- **配色**：石墨灰 #1E2226 + 黄铜 #C8923E + 信号朱 #D6453A + 电报纸米 #EDE4D3（工业金属系，禁蓝紫渐变）。
- **光标**：开页居中的黄铜环 + 内点，高对比、层级最高，按键变红。

## 技术栈

- 纯 HTML / CSS / JavaScript（vanilla，单文件，零 React / Babel / CDN）。
- SVG 绘制网络图与线路路径；`requestAnimationFrame` 驱动脉冲行进。
- 健壮性：`visibilitychange` 暂停 RAF、`beforeunload` 取消；高频鼠标事件直接操作 DOM；支持 `prefers-reduced-motion`（脉冲瞬现、纸带静止逐字）。
- 响应式适配 1440 / 1024 / 768 / 390。

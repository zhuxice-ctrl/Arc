# 设计规范 · 电报网络·摩尔斯收发局

> 清末民初电报网络档案馆 · V1 网页设计 · 2026-08-19

## 一、设计母题与空间模型

**母题**：电报网络·摩尔斯收发局。一座铺开的电报网络档案——节点是各地电报局（真实地名+开通年份），连线是开通的电报线路（年份+里程）。用户坐到黄铜电键前，亲手敲击摩尔斯电码，脉冲沿选定线路发光行进，抵达对端后被解码、烙印在匀速上移的电报纸带上。

**空间模型**：`network_graph_node_link`（电报网络节点图，非水平脊柱/非滚动叙事/非径向轮盘）。网络图为视觉主体舞台，黄铜电键交互区与收报纸带为联动副舞台；其下为电报局名录、线路档案、五等电报资费、四码电报制度等编辑式档案区，构成"图→册→表→制"的叙事节奏。

**网站类型**：Archive / Editorial（档案·编辑式）。

## 四、核心交互（唯一主交互）

**黄铜电键敲击编码摩尔斯**：
- `mousedown`/`mouseup`（或键盘空格）触发；`HOLD_THRESHOLD = 180ms`，按下时长 < 180ms = 点（·），≥ 180ms = 划（—）。
- 静默 `LETTER_GAP = 500ms` 提交一个字母，`WORD_GAP = 1200ms` 提交一个词；通过 `MORSE_REV` 反查表将点划序列解码为字母/数字，实时显示当前编码与预览字母。
- 字母键可直接输入待发文本；退格删除。
- 选定目的电报局 → 点击"发送电报" → `findPath()` BFS 求多跳最短路径 → 脉冲点/划沿 SVG 线路逐段发光行进 → 对端纸带逐字烙印解码文本。
- 点击网络图任一节点可设为发端局。

## 五、动效语言（≥12 组件级，符合物理/主题逻辑）

1. 自定义光标：黄铜环+内点，`mix-blend-mode` 高对比，开页居中，悬停放大、按键变红（`pressing` 态）。
2. 电键按压：键钮/键臂/接点同步下沉回弹（`pressed` 态，机械 clack 感）。
3. 摩尔斯编码实时累积显示（点划字符串 + 预览字母）。
4. 字母/词静默提交定时器（标准摩尔斯时序）。
5. 节点设端高亮（`setSource`）。
6. 线路按选中路径高亮（发送中黄线）。
7. 脉冲点/划沿 SVG 路径匀速发光行进（`requestAnimationFrame` 驱动 `pulseTick`，电气线性感）。
8. 多跳中继逐站脉冲接力（`startNextSegment` / `runPulsesForSegment`）。
9. 节点收到脉冲黄铜高亮（`pulseNode`）。
10. 收报纸带匀速上移烙印点划（`scrollTape` / `addToTape`，机械线性感）。
11. 对端逐字解码浮现。
12. 发送/错误反馈（`flashSendError`、`receiveDot` 状态）。
13. 网络图年份过滤切换、节点 `@keyframes node` 微动。
14. 品牌 `@keyframes brand` 信号脉冲、按钮 `@keyframes btn`、接收 `@keyframes receive`。

**禁**：Ken Burns 整图缩放、无理由粒子、鼠标跟随光斑。**`prefers-reduced-motion`**：脉冲改为瞬现、纸带静止逐字（2 处降级）。

## 六、健壮性红线

- 纯 vanilla 单文件 HTML，零 React / Babel / CDN。
- `requestAnimationFrame` 驱动脉冲；`visibilitychange` 暂停 RAF、`beforeunload` 取消。
- 高频鼠标事件直接操作 DOM，不触发重渲染。
- 快速操作不叠加定时器（`clearTimers` 统一清理 letterTimer/wordTimer）。
- 零未定义引用；零 Console Error；零 404。

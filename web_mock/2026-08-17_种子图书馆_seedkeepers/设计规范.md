## 字体

- `--font-display`: `'Cormorant Garamond', 'Noto Serif SC', Georgia, serif` — 标题

- `--font-mono`: `'DM Mono', 'Courier New', monospace` — 数据 / 标签

## 圆角与间距

- 圆角：卡片 `16px` / `20px`，胶囊 `12px`，罐体 `20px 20px 30px 30px`，徽章 `2px`
- 间距刻度：8 / 12 / 16 / 24 / 32 / 48 / 64 / 96 px

## 组件规范

- 种子卡片：玻璃罐造型，3D 倾斜跟随鼠标（反平方式衰减），hover 光泽扫过
- 频谱柱：28 根，低/中/高频不同振动速度与能量分布
- 数字计数：ease-out cubic 缓动，进入视口触发
- FAQ 手风琴：高度平滑过渡 + 加号旋转 45°
- 按钮：芥末黄底，点击涟漪径向扩散

## 动效系统

15 项组件级特效，均基于物理 / 语义模型：

1. 自定义光标（白环 + 芥末黄内点 + 三层发光，三弹簧速度，hover 放大变色，点击涟漪）
2. 漂浮种子粒子（重力 + 正弦横向漂移 + 底部反弹 + 旋转，25 粒各周期不同）
3. 罐内种子浮动（40 粒错相浮动）
4. 种子卡片 3D 倾斜（反平方式，弹簧阻尼回归）
5. 滚动渐入（IntersectionObserver 错峰上浮淡入）
6. 滚动视差（英雄区背景 / 内容不同速率）
7. 频谱可视化（28 柱 idle 呼吸 / playing 活跃两态）
8. 数字计数（ease-out cubic）
9. FAQ 手风琴（高度过渡 + 加号旋转）
10. 打字机眉标（自然变速逐字）
11. 按钮涟漪（径向扩散）
12. 玻璃罐 3D 倾斜（transform-style preserve-3d）
13. 光泽扫过（卡片 hover 斜向光带）
14. Nav logo 种子呼吸脉冲（4s 周期微缩放）
15. 背景纹理鼠标视差（2% 阻尼偏移）

## 页面结构

英雄区（大字 + 打字机眉标 + 漂浮粒子）→ 使命介绍（3D 玻璃罐 + 4 项数字计数）→ 馆藏目录（6 张种子卡）→ 种子之声（28 柱频谱 + 播放控制）→ 借阅规则（4 步流程卡）→ 田间笔记（3 篇文章卡）→ 创始人引言 → FAQ 手风琴 → 订阅 CTA → 页脚。

## 健壮性

visibilitychange 自动暂停 / 恢复 RAF；reduced-motion 全面降级；移动端隐藏自定义光标回退系统光标；mousemove 全部直操作 DOM transform 不触发重渲染；定时器重建前先清除。

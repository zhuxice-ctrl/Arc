# 声之形 Sonic Formations — 新媒体声音艺术展官网

> 2026-08-16 · 网页设计

## 简介

一场关于声音可视化与沉浸式听觉的新媒体艺术展官网。全站按「共振 / 潮汐 / 静默 / 衍射」四大篇章组织，模拟从声波物理现象到艺术感知的完整叙事。深色沉浸基底 + 青绿 / 琥珀金 / 暖橙高级艺术色调，所有动效基于声波物理逻辑设计。

## 文件说明

| 文件 | 说明 |
|------|------|
| `index.html` | 浏览页（双击即可打开预览） |
| `styles.css` | 全部样式（含动画 keyframes） |
| `main.js` | 交互逻辑（频谱驱动、光标、倒计时、轮播、FAQ 等） |
| `package.json` | 依赖声明 |
| `设计规范.md` | 设计规范文档（色彩 / 字体 / 动效 / 页面结构） |

## 动效亮点

- 12 根声波柱独立振动 + 8 圈地面涟漪三色扩散
- 36 根频谱条逐帧独立随机游走 + 节拍脉冲
- 60 颗粒子上升 + 三色光球漂浮 + SVG 波形流动
- 自定义光标（白色粗环 + 琥珀实点 + 三层发光）
- 卡片 3D 倾斜视差 + Hero 打字机标题 + 数字计数

# 活字印坊 · 设计规范

活字印刷博物馆官网 — 围绕毕昇泥活字、木活字转轮、铜活字、武英殿聚珍版等核心藏品叙事，以古典书卷气为视觉基调。

## 字体系统

- **主字体**：`"Songti SC", "SimSun", "STSong", serif` — 宋体衬线，呼应活字印刷的雕版传统
- **正文行高**：1.8
- **标题字重**：700 / 900
- **正文字重**：400

## 圆角与间距

- 卡片圆角：8px
- 按钮圆角：4px
- 印章元素：50%（圆形）
- 内容最大宽度：1200px
- 区段间距：80px（桌面端）

## 组件规范

- **活字方块**：正方形容器，`rotateY` 翻转动画，随机翻字周期 2-5s
- **时间轴节点**：圆形锚点 + 竖线连接，交错延迟入场
- **馆藏卡片**：3D 倾斜（mousemove 驱动 transform），悬停光泽扫过
- **印章按钮**：朱砂红圆形，弹性缩放 + 墨晕扩散点击反馈
- **打字机区域**：逐字显示，标点处停顿，循环重置

## 页面结构

1. Hero 大标题 — 活字阵背景 + 浮动方块 + 视差
2. 历史沿革时间轴 — 交错渐入节点
3. 馆藏珍品 6 宫格 — 3D 倾斜卡片
4. 典籍摘钞 — 打字机效果
5. 数据统计 — 数字计数
6. 活字互动矩阵 — 磁场斥力
7. 参观预约表单 — 磁性按钮 + 印章反馈
8. Footer

## 健壮性

- `visibilitychange` 自动暂停/恢复所有 RAF 与定时器
- `prefers-reduced-motion` 全面降级（关闭动效 + 恢复系统光标）
- `beforeunload` 统一清理
- 高频 mousemove 全部直接操作 DOM，无 React setState 开销
- 纯内联单文件，零外部依赖

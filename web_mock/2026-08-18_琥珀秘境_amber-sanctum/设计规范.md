# 琥珀秘境标本馆 · 设计规范

- 日期：2026-08-18
- 方向：V1 网页设计
- 主题：琥珀秘境标本馆——收藏远古琥珀标本的自然史博物馆官网

## 色彩系统

暖琥珀色系，全程禁用蓝紫渐变。

| 角色 | 色值 | 用途 |
|---|---|---|
| 主色·金琥珀 | `#C8761D` | 主按钮、强调线、标题描边 |
| 辅助·琥珀橙 | `#E9A853` | 次级强调、hover 高光 |
| 辅助·浅琥珀 | `#FFCF7A` | 光泽、光晕、渐变亮端 |
| 深琥珀 | `#8A4A10` | 文案副标、深色块 |
| 墨棕 | `#3A2412` / `#2A1A0C` | 正文、页脚底色 |
| 奶油纸色 | `#F7EDE0` / `#FBF4E8` | 页面背景、卡片底 |
| 浅米 | `#ECD9BD` | 分隔带、次级背景 |
| 点缀·苔绿 | `#556B3D` | 标签、状态色 |

## 字体

- 标题：展示衬线字（马善政体 / Noto Serif SC 系），大字号重字重
- 正文：Noto Sans SC / 无衬线体
- 字重层级：900 / 700 / 500 / 400

## 圆角

- 卡片：`var(--radius-lg)` ≈ 20–28px
- 按钮/标签：`var(--radius-md)` ≈ 12px，胶囊用 `999px`
- 琥珀形态有机块：`52% 48% 61% 39% / 45% 55% 45% 55%`（仿天然琥珀不规则边）

## 组件规范

- 顶部导航栏：滚动收缩，磨砂底 + 底边细线
- 标本卡片：3D 倾斜（RAF 弹簧积分直接操作 transform）、悬停抬升 + 发光、点击涟漪
- Hero 区：琥珀涟漪 canvas（半径平方缓动扩散 + 线性衰减）
- 筛选标签：四分类（全部/昆虫/植物/脊椎），选中态金琥珀底
- 时光之旅：四 Tab 横向切换，顶栏 scaleX 展开
- 预约表单：输入校验 + 提交成功态

## 动效系统（12+）

| 动效 | 物理/语义依据 |
|---|---|
| 自定义光标 | 弹簧 Hooke 积分（外环软簧 + 内点硬簧），悬停三态，点击涟漪 |
| 漂浮琥珀粒子 | 正弦横向漂移 + 匀速上升 + 独立闪烁相位 |
| Hero 涟漪 canvas | 半径平方缓动 + 线性衰减 |
| 琥珀 blob 视差 | 三阶段缓动漂浮 |
| 卡片 3D 倾斜 | RAF 弹簧积分，DOM 直写 |
| 卡片点击涟漪 | 缩放淡出 |
| 标本悬停抬升发光 | translateZ 深度分层 |
| 打字机副标题 | 随机键入节奏 |
| 数字计数器 | 弹簧缓动积分，进视口触发 |
| 滚动渐入 | IntersectionObserver + cubic-bezier |
| 光泽扫过 | 对角线线性扫掠，周期各异 |
| 脉冲发光 | 正弦呼吸 |
| 流程卡顶栏展开 | scaleX 左→右 |
| 滚动提示液滴 | 缓动下落循环 |

## 健壮性

- `visibilitychange` 自动暂停全部 RAF；卸载统一取消
- 重建定时器前 `clearTimeout` / `cancelAnimationFrame`
- 高频 mousemove 直接 DOM transform，无 React setState
- `prefers-reduced-motion` 全量降级
- JSX/CSS 全部内联在 index.html，无外部 src 引用

## 页面结构

导航 → Hero（琥珀涟漪 + 打字机副标题 + 数字计数）→ 标本分类筛选卡墙 → 时光之旅四阶段 → 参观预约表单 → 页脚。

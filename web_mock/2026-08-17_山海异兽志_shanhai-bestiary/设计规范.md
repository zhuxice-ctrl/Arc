# 山海异兽志 · 东方神兽沉浸图鉴展 — 设计规范

> 方向：网页设计（V1） · 日期：2026-08-17 · 主题：东方神兽图鉴沉浸展官网

## 色彩系统（玄墨图鉴体系）

| 角色 | 色值 | 用途 |
|------|------|------|
| 玄墨黑 | `#140e0a` / `#1e1712` | 主背景、深色画底 |
| 宣纸米白 | `#f2ead6` / `#e8dfc8` / `#d9cea9` | 正文纸面、卡片底 |
| 朱砂红 | `#d94e3e` / `#b8342a` / `#8a2319` | 印章、强调、按钮 |
| 赭石金 | `#e2b858` / `#c89a3c` / `#8c6a20` | 标题描金、数据条、光晕 |
| 黛绿点缀 | `#4a7a5a` | 神兽属性辅色 |
| 深墨 | `#2a2119` | 次级文本 |

主色不使用蓝紫渐变；朱砂与赭金形成东方图鉴的「印 + 金」双色锚点。

## 字体

- 标题：衬线 / 书法风字体栈（系统衬线 + 中文书法）
- 正文：`font-family: inherit`，跟随系统中文衬线
- 强调数字：等宽衬线

## 组件规范

- 神兽卡片：宣纸米白底 + 朱砂左色条 + 鳞片光泽扫过（hover 触发斜向 shimmer）
- 印章按钮：朱砂填充滑动 + 光泽扫过
- 数据条：赭金渐变填充 + easeOutCubic 数字计数
- 卷轴序章：上下卷轴展开动效

## 动效系统（12+ 组件级特效）

1. 自定义光标（白环 + 赭金内点 + 六层粒子尾迹，弹簧阻尼跟随）
2. 光标悬停三态切换 + 点击涟漪
3. Hero 粒子网络（金红双色粒子 + 距离连线频谱）
4. Hero 标题逐字升起
5. 神兽字符浮动（正弦缓动，不同相位不同周期）
6. Hero 鼠标视差（内容层与墨色背景反向位移）
7. 卡片 3D 倾斜（RAF 弹簧积分器，直接操作 DOM transform）
8. 鳞片光泽扫过（hover shimmer）
9. 数据条填充 + 数字计数
10. 滚动渐入（IntersectionObserver，错位延迟）
11. 打字机（随机字速 + 换行停顿 + 循环，visibilitychange 暂停）
12. 展厅神兽悬浮呼吸 + 神坛光环脉冲
13. 印章/朱砂按钮填充滑动

动效基于物理模型（弹簧胡克定律 / 阻尼 / RAF 积分器）与主题语义（墨晕染 / 卷轴展开 / 烛火摇曳 / 鳞片光泽）。

## 页面结构

- 序章：古卷重现 · 图鉴溯源 · 沉浸观感 · 薪火相传（卷轴式序言）
- 十二神兽图鉴：应龙、白泽、九尾狐、烛阴、帝江、毕方、饕餮、精卫、麒麟、巴蛇、凤凰、刑天（每只含出处、考据文案、神力/智慧/仁德三维数据）
- 神兽显形：六神兽转盘 + 神台显形 + 浮动呼吸
- 共赴山海：观展预约表单 + 提交反馈 + 累计观展/展品/展期余日计数

## 健壮性

- 所有 RAF / 定时器在 `visibilitychange` 时暂停，卸载时取消
- 鼠标高频事件直接操作 DOM，不走 setState
- 完整 `prefers-reduced-motion` 降级
- 零外部 JSX/CSS 引用，全部内联

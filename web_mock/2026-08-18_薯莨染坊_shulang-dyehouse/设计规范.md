# 薯莨染坊 设计规范

## 色彩系统

| 角色 | 色值 | 用途 |
|------|------|------|
| 主色 | #8B3A2F | 薯莨红棕，标题、强调、按钮主色 |
| 主色深 | #6B2A22 | 深红棕，hover、阴影、深色块 |
| 主色亮 | #A84B3D | 亮红棕，辅助强调 |
| 强调色 | #D4A017 | 栀子金黄，高亮、数字、装饰线 |
| 强调色亮 | #E8B830 | 亮金，光泽、hover 金边 |
| 辅助色 | #6B4423 | 茶褐，次要文字、边框 |
| 底色 | #F5E6D3 | 生坯米白，页面背景 |
| 底色暖 | #E8D4BC | 暖米，卡片背景、分区 |
| 文字 | #1A1612 | 炭黑，正文文字 |
| 深褐 | #4A2E15 | 深褐，深色区块文字 |

## 字体

- 正文：`'Noto Sans SC', -apple-system, BlinkMacSystemFont, sans-serif`
- 标题：`'Noto Serif SC', serif`
- 装饰标题：`'ZCOOL XiaoWei', 'Noto Serif SC', serif`

## 圆角

- 通用卡片：2px
- 装饰元素：50%（圆形）
- 细线分隔：1px

## 页面结构

1. Hero 首屏——大字"莨"染料渗出血脉字 + 打字机副标题 + 布料波浪 SVG 动画
2. 工艺溯源——薯莨染历史叙事，滚动渐入段落
3. 染色流程——6 步工艺 3D 倾斜卡片（采集→粉碎→煎煮→浸染→晾晒→复染），数字计数动画
4. 作品展示——画廊网格 + 分类筛选 + 光泽扫过 hover + Lightbox 弹窗
5. 工坊预约——预约表单（姓名/日期/人数）含校验与成功态
6. 页脚——联系方式 + 社交图标悬停发光

## 动效系统

| 动效 | 物理模型/主题语义 |
|------|------|
| 自定义光标 | 白色粗环 + 薯莨红内点 + 多层发光，悬停变金放大，点击涟漪 |
| 染料晕染 blob | 视差滚动驱动漂浮，模拟染料在水中扩散 |
| 打字机副标题 | 逐字显现，光标闪烁 |
| 布料波浪 | SVG animate 布料飘动，模拟晾晒布匹随风 |
| 染透渐变 | 卡片悬停从底部浸透 + 金色光泽，模拟染色浸透过程 |
| 数字计数 | 滚动触发 IntersectionObserver，数字递增动画 |
| 3D 倾斜卡片 | mousemove 驱动 rotateX/rotateY，perspective 透视 |
| 滚动渐入 | reveal 动画，opacity+translateY |
| 光泽扫过 | 画廊作品悬停 linear-gradient 扫光 |
| 染料渗出血脉字 | "莨"字 SVG path 渐变填充动画 |
| 悬停发光 | 按钮/图标 box-shadow 过渡 |
| 涟漪 | 点击产生扩散圆，水波物理模型 |

## 技术栈

纯 vanilla HTML/CSS/JS 单文件，无 React/Babel/CDN 依赖。所有动效用 requestAnimationFrame + IntersectionObserver 实现，支持 prefers-reduced-motion 降级。

# 古运河志 · 设计规范

## 作品信息
- **主题**：京杭大运河长卷航行体验
- **日期**：2026-08-19
- **方向**：V1 网页设计
- **类型**：Editorial / Archive / 横向长卷
- **技术栈**：纯 vanilla HTML + CSS + JS（单文件，无外部依赖）

## 设计母题
传统中国长卷画（手卷）的数字展开。用户从北端（北京通州）向南端（杭州）横向拖拽浏览，沿一条贯穿全卷的运河水线依次经过 12 个真实运河站点。整幅画卷 15600px 宽，是一段连续的横向旅程，不使用竖向滚动。

## 色彩系统
| 变量 | 色值 | 用途 |
|------|------|------|
| --paper | #f0e5cf | 陈纸米色底 |
| --paper-dark | #e2d4b0 | 纸面阴影区 |
| --paper-edge | #c9b68a | 卷轴边缘 |
| --ink | #1c1c1c | 墨黑主文字 |
| --ink-mid | #3d3d3d | 次级文字 |
| --ink-light | #6b6b6b | 辅助文字 |
| --cinnabar | #b22222 | 朱砂红标记 |
| --cinnabar-light | #c94a3e | 朱砂亮色 |
| --water | #6e9e8e | 运河水面青绿 |
| --water-light | #8fb8aa | 水面亮色 |
| --seal | #a01a1a | 印章红 |

**色彩逻辑**：水墨画三色体系——纸（米色系）、墨（黑色系）、朱（红色系），加上水（青绿）。每种颜色承担明确语义：纸=背景/留白、墨=文字/线条、朱=重要标记/印章、水=运河主线。

全站使用楷体/宋体 serif 字族，模拟书法与古籍排版感。竖排注释使用细体。

## 空间模型
- **横向长卷式**：整页 15600px × 720px 的横向画布
- 运河水线贯穿全卷，是视觉主线和导航轴
- 三层远山（远/中/近）做视差滚动，制造空间纵深
- 疏密节奏交替：繁华码头区（密集建筑+船只+人物）→ 空旷水面（大留白+远山）→ 下一个码头

## 12 个运河站点（真实历史内容）
1. **通州** — 漕运终点码头，元明清三代粮仓所在
2. **天津** — 运河与海河交汇，漕运转运枢纽
3. **沧州** — 铁狮子故地，运河沿岸军事重镇
4. **德州** — 苏禄王墓所在，运河外交见证
5. **临清** — 运河钞关所在地，明清关税重镇
6. **济宁** — 河道总督驻所，运河最高管理机构；船闸所在地
7. **徐州** — 运河与黄河交汇处，治水关键节点
8. **淮安** — 漕运总督驻地，运河管理中枢；船闸所在地
9. **扬州** — 盐运中心，运河最繁华的商埠
10. **苏州** — 丝绸外运起点，运河经济文化重心
11. **嘉兴** — 粮仓所在，运河江南段枢纽
12. **杭州** — 拱宸桥，运河南端终点

## 船闸机制
经过济宁船闸和淮安船闸时，运河水线高度有视觉变化，体现船闸升降原理——水位落差通过水线 Y 坐标变化表示，配合船闸开合动画。

## 动效系统（16 项组件级动效）
1. 水面涟漪扩散
2. 朱砂标记点脉动呼吸
3. 内容进入视口时墨迹晕染
4. 船闸开合动画
5. 船只在水面漂浮
6. 飞鸟掠过画卷
7. 云层缓慢飘移
8. 竹林摇曳
9. 印章钤盖效果
10. 水纹流动
11. 进度条跟随滚动
12. 毛笔尖光标跟随
13. 站点高亮脉冲
14. 三层远山视差
15. 滚动提示呼吸动画
16. 卷尾印章落款

## 自定义光标
毛笔尖形状，开页显示在屏幕中央，高对比度，z-index 最高。拖拽画卷时笔尖"落下"。

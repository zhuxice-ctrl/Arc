# 设计规范 · 绿洲驿站 · 沙漠绿洲文化杂志网站

> 日期：2026-08-17 · 方向：V1 网页设计 · 主题：丝路沙漠绿洲文化线上杂志

## 色彩系统

| 角色 | 色值 | 用途 |
|------|------|------|
| 主色 · 沙金 | `#D9A441` | 刊头强调、按钮、节点脉冲 |
| 深主 · 赤陶 | `#B4552D` | CTA 实色、链接悬停 |
| 辅 · 赤陶深 | `#9C4A24` | 暗态强调 |
| 点缀 · 绿洲碧 | `#1F7A6D` | 成功态、图鉴标识 |

| 中性 · 米白 | `#F4EAD8` | 正文底、卡片表面 |
| 中性浅 | `#E8DCC0` | 次级表面、分隔 |
| 中性深 | `#5C4A3A` | 次要文字 |

整体为高对比暖调，底色深棕、内容面米白，强调色沙金与赤陶双层。无蓝紫渐变。

## 字体系统

- `--display`：`"Cormorant Garamond", "Noto Serif SC", Georgia, serif` —— 刊头大标题，衬线古典
- `--serif`：`"Noto Serif SC", "Cormorant Garamond", Georgia, serif` —— 章节标题
- `--sans`：`"Noto Sans SC", "PingFang SC", "Microsoft YaHei", sans-serif` —— 正文与 UI

## 圆角

卡片 `11px`、标签 `4px`、分隔线 `2px`、节点 `50%`。整体克制，倾向硬朗直角与微小圆角混用。

## 页面结构

1. 卷首 Hero —— 沙丘粒子 Canvas 背景、驼队剪影视差、打字机刊头、CTA 光泽扫过
2. 本期专题 —— 5 篇文章卡片，悬停光泽扫过 + 图片微放大 + 滚动渐入错落
3. 绿洲图鉴 —— 4 分类 Tab、6 张卡片 3D 倾斜跟随鼠标、点击翻面
4. 古商路交互地图 —— 6 节点（长安→敦煌→楼兰→喀什→撒马尔罕→帕尔米拉）脉冲呼吸、右侧故事面板联动
5. 数字计数 —— 商路里程 / 绿洲数 / 文明跨度 / 深度报道，easeOutCubic 计数
6. 驿丞信箱 —— 涟漪按钮 + 邮箱订阅成功态
7. 页脚 —— 四栏信息架构

## 动效系统

自定义光标（白环 + 金点 + 多层发光，悬停变形、点击涟漪）、沙丘粒子场（噪声流动 + 鼠标斥力）、刊头打字机三句循环、驼队剪影视差、卡片光泽扫过、滚动渐入（IntersectionObserver）、3D 卡片倾斜翻转、地图节点脉冲呼吸、按钮涟漪、数字计数、导航栏滚动收缩变色、Tab 切换内容流动、信封图标脉冲。共 13+ 组件级特效，周期各异。

## 健壮性

- RAF 随页面可见性自动暂停，卸载统一取消
- 高频鼠标事件直接操作 DOM transform
- 支持 `prefers-reduced-motion` 全面降级
- JSX 全部内联于 `<script type="text/babel">`，无外部 src
- 零未定义引用

## 技术栈

单文件 HTML（内联 CSS + Babel JSX），Canvas 2D 粒子，IntersectionObserver 滚动驱动。

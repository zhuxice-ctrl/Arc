# 设计规范 · 游廊纪行（苏州园林框景漫步）

**类别**：Web Mock　**日期**：2026-08-19　**形态**：网页（单文件 HTML）

## 一、设计母题
「移步换景」——整站是一段苏州园林游廊漫步，竖向滚动即沿游廊前行，粉墙在侧，漏窗与门洞依次框出园景。空间模型为游廊式连续框景序列，非 Landing Page、非卡片网格。

## 二、空间模型
- **游廊式**：粉墙+廊柱以固定节奏（约 350px 廊柱间距）贯穿全程，墙长约 10000px
- **框景机制**：园景嵌在墙体漏窗中，而非独立 Section
- **月洞门 iris 转场**：章节切换=圆孔收放，共 3 座月洞门贯穿四园

## 三、信息结构（四园真实内容）
1. 拙政园 — 远香堂 / 借景北寺塔（爱莲说竖排引文）
2. 留园 — 冠云峰 / 五峰仙馆
3. 网师园 — 月到风来亭 / 濯缨水阁
4. 沧浪亭 — 复廊 / 看山楼

## 五、字体
- 宋体（serif）— 标题与景名
- 楷体 — 竖排古典引文
- 无衬线（sans）— 正文
- 等宽（mono）— 营造尺寸标注

## 六、漏窗纹样（SVG 镂空蒙版，≥6 种）
冰裂纹、海棠纹、万字纹、如意纹、竹节纹、六角龟背纹——以 SVG pattern 作镂空蒙版框住景致，点击漏窗可探身全屏细览。

## 七、动效系统（≥16 组件级特效）
竹影摇曳投粉墙并随滚动偏移、池面涟漪、锦鲤缓游、月洞门 iris 收放、漏窗棂影随时辰偏移、花瓣飘落、远山视差、漏窗悬停放大、窗景视差、灯笼光标微动、水面倒影、月景星点、荷池荷花、庭院假山、柳树垂枝、前景灌木。全部符合园林物理语义，非整图缩放。

## 八、自定义光标
白纸灯笼——开页屏幕居中、层级最高（z-index top）、可点击处变亮。prefers-reduced-motion 时降级为系统光标。

## 九、核心交互
- 滚动 = 行走（滚动量直接映射廊柱与窗景位移）
- 点击漏窗 = 探身（窗景放大全屏细览，再点收回）
- 右侧进度点定位四园

## 十、健壮性红线
- 零未定义引用 / 零 Console Error（QA 四档尺寸均通过）
- RAF 随 visibilitychange 暂停、cancelAnimationFrame 卸载取消
- 高频滚动/鼠标事件直接操作 DOM
- prefers-reduced-motion 降级
- 响应式：1440 / 1024 / 768 / 390 四档无横向溢出

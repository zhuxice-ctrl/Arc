# Windborne 御风节 · 设计规范

> 方向：V1 网页设计 ｜ 日期：2026-08-17 ｜ 主题：城市风筝节官方网站（单页艺术品级官网）

## 色彩系统

| 角色 | 色值 | 用途 |
|------|------|------|
| 主色·珊瑚红 | `#FF6B4A` | 主 CTA、强调、风筝主色、悬停态 |
| 主色·深松绿 | `#17443A` | 页脚、深色分区、导航底色 |
| 表面·米纸白 | `#F6F1E5` | 页面主背景 |
| 中性·墨色 | `#22201B` | 正文文字、标题 |
| 点缀·麦金 | `#E8B34B` | 次级强调、标签、图标 |
| 辅助·松绿亮阶 | `#1F5A4D` | 深绿分区内的层次 |
| 辅助·珊瑚亮阶 | `#FF8A6A` / `#E85A3A` | 悬停过渡、渐变端点 |

| 辅助·麦金暗阶 | `#D4A03A` / `#8B6914` | 点缀深色变体 |

约束：无蓝紫渐变；暖色（珊瑚红/麦金）与冷色（松绿）双主角形成视觉节奏。

## 字体

- 展示标题：`'Playfair Display', 'Noto Serif SC', serif`（衬线，节庆仪式感）
- 正文 / UI：`'Inter', 'Noto Serif SC', sans-serif` 与 `'Inter', sans-serif`

## 页面结构（单页滚动）

1. 导航栏（滚动收缩 + 毛玻璃）
2. Hero：大标题逐行入场 + 主风筝 SVG + 风筝线摇摆 + 多层视差漂浮风筝
3. 实时风况条：风速 / 风向 / 气温 / 湿度 / 放飞指数（数值实时小幅波动）
4. 三日日程：12 个活动时段，工坊 / 竞技 / 展演 / 音乐四类标签
5. 风筝画廊：蟠龙 / 三角洲 / 盒式 / 沙燕 / 星夜夜光 5 款 SVG 风筝
6. 场地地图：3D 视差倾斜 + 三枚弹性跳动定位图钉
7. 票种：轻风 / 御风 / 云霄三档
8. 开幕倒计时（天时分秒实时递减）
9. 观众评价横向无限滚动 + 邮件订阅 + 页脚

## 动效系统（15+ 组件级）

- 自定义光标：白色粗环 + 珊瑚红内点 + 多层发光；开页即居屏幕中央；悬停放大变色三态；点击涟漪
- 画布风粒子系统（正弦波动、速度/周期各异）
- 弹簧物理光标跟随（stiffness/damping 积分器）
- Hero 风筝视差漂浮 + 风筝线摇摆（主题语义：风与牵引）
- 天空浮动风筝（深度分层视差 + 正弦漂移）
- 标题逐行上滑入场、滚动渐入（IntersectionObserver 错峰 delay）
- 日程卡 / 画廊 / 票卡 3D 倾斜（独立 RAF 平滑插值，直接写 DOM transform）
- 场地地图鼠标视差、定位图钉弹性跳动
- 按钮光泽扫过、画廊悬停放大 + 渐入叠加层
- 倒计时实时递减（visibility 切换自动暂停）
- 评价无限滚动（hover 减速）、导航滚动收缩

## 健壮性

- 全部 RAF / 定时器随 `visibilitychange` 暂停，`beforeunload` 统一清理
- 高频鼠标事件直接操作 DOM transform，不触发框架重渲染
- `prefers-reduced-motion` 完整降级；触屏设备自动隐藏自定义光标
- 响应式：1024px / 768px 双断点，移动端汉堡菜单

## 技术栈

单文件 HTML（内联 CSS + JS），SVG 插画，Canvas 粒子，无外部图片依赖。

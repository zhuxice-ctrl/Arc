# 铜人腧穴图经 · 设计规范

## 主题

天圣五年（1027年），王惟一铸针灸铜人两具，著《铜人腧穴针灸图经》。本设计以数字铜人为载体，重现经脉流注与腧穴定位的古典医学图谱。

### 配色逻辑

磁青底色模拟铜人氧化后的深绿锈层；鎏金经脉对应古代铜人表面的金汞齐涂覆工艺；朱砂穴位点取自传统针灸图谱中标注腧穴的朱红色墨点。三色构成「铜—金—砂」的物质层级，无蓝紫渐变。

## 布局结构

三栏网格布局，`grid-template-columns: 220px 1fr 320px`：

- **左栏（220px）**：经脉导航——任脉、肺经、胃经、脾经四条经脉卡片，竖向排列，点击激活
- **中栏（1fr）**：SVG 铜人正面图，viewBox `0 0 400 800`，含人体轮廓、面部细节、经脉路径、55 个腧穴点
- **右栏（320px）**：档案面板——展示当前经脉概述或选中穴位的定位、主治、刺灸法

响应式断点：1200px / 1024px / 768px / 390px。窄屏切换为纵向单列堆叠。

### 交互逻辑

- **经脉激活**：点击左栏经脉项 → 清除上一经脉动画 → 描线流注（1.2s）→ 逐穴依次点亮（step×1 帧延迟）
- **穴位选中**：点击铜人上的穴位点 → 如果属当前经脉直接选中；如果属其他经脉则先激活该经脉（1.4s 后自动选中）→ 面板切换显示穴位档案
- **面板标签代理**：面板内穴位标签可点击，直接选中对应穴位
- **重置**：点击重置按钮恢复铜人介绍态

## 自定义光标

- RAF lerp（系数 0.15）跟随鼠标，初始化在屏幕正中央 `(innerWidth/2, innerHeight/2)`
- `z-index: 9999`，`pointer-events: none`，28×28px
- 悬停可交互元素时放大
- `visibilitychange`：页面隐藏时 `cancelAnimationFrame` 暂停，恢复时重启
- `beforeunload`：取消 RAF + 清除所有动画定时器
- `prefers-reduced-motion`：所有动画/过渡降至 0.01ms，禁用脉冲循环

## 技术栈

- 纯 vanilla 单文件 HTML（无 React/Babel/CDN 依赖）
- SVG 矢量铜人 + 经脉路径 + 穴位点
- CSS Grid 三栏布局
- CSS Custom Properties 主题变量
- `requestAnimationFrame` 光标动画
- `setTimeout` 队列管理穴位逐一点亮
- 总计 1614 行，54KB

## 内容数据

4 条经脉共 55 个腧穴，均为真实中医数据：

- **任脉**（12穴）：起于会阴，止于承浆，沿前正中线上行
- **肺经**（11穴）：起于中府，止于少商，沿上肢内侧前缘下行
- **胃经**（19穴）：起于承泣，止于厉兑，沿面前及下肢外侧前缘下行
- **脾经**（13穴）：起于隐白，止于大包，沿足内侧及下肢内侧前缘上行

每个穴位包含：穴名、坐标位置、解剖定位、主治症候、刺灸方法。

# 缂丝录 设计规范

> 日期：2026-08-17 · 方向：V1 网页设计 · 主题：中国缂丝织造数字博物馆

## 色彩系统

| 色彩角色 | 色值 | 用途 |
|---------|------|------|
| 朱砂红 | `#9C2A2A` | 主强调色，展厅卡片、按钮、标题装饰 |
| 古金 | `#C4A747` | 次强调色，光标内点、装饰线、数字 |
| 墨蓝 | `#1B2845` | 背景主色，深色底 |
| 墨蓝深 | `#0F1830` | 渐变深色端 |
| 生绢色 | `#F5EDD8` | 文字主色、浅色卡片底 |
| 暗木 | `#3E2A1A` | 页脚、深色区块底 |
| 古金亮 | `#E0C97A` | 悬停态高亮 |
| 朱砂亮 | `#C04040` | 悬停态强调 |

## 字体系统

- 正文：`'Noto Sans SC', sans-serif`
- 标题：大字衬线感，通过 font-weight 加粗呈现

## 圆角与间距

- 卡片圆角：12px
- 按钮圆角：6px
- 头像/光标：50%（圆形）
- 区块间距：80px 垂直，最大宽度 1200px 居中

## 组件规范

- 导航栏：固定吸顶，滚动后背景模糊+半透明
- 展厅卡片：深色底 + 金色边框，悬停时织线穿梭动画
- 名作画廊：悬停放大 1.05 倍，纹样高亮叠加
- 时间轴：滚动驱动进度线，节点逐一点亮
- 按钮：古金色底，涟漪效果

## 动效系统

| 编号 | 动效 | 触发方式 | 物理模型/语义 |
|------|------|---------|-------------|
| 1 | 自定义光标 | 鼠标移动 | 白色粗环+古金内点+多层发光 |
| 2 | 织线粒子动画 | 页面加载 | Canvas 绘制丝线流动 |
| 3 | 标题逐字渐入 | 页面加载 | 延迟序列动画 |
| 4 | 展厅卡片织线穿梭 | 悬停 | 金色线条穿越卡片 |
| 5 | 滚动渐入 | 滚入视口 | IntersectionObserver 触发 |
| 6 | 织机模拟器交互 | 拖拽 | Canvas 经纬线切换 |
| 7 | 画廊悬停放大 | 悬停 | transform scale |
| 8 | 时间轴滚动推进 | 滚动 | 滚动进度映射 |
| 9 | 导航吸顶模糊 | 滚动 | position fixed + backdrop-filter |
| 10 | 数字计数 | 滚入视口 | requestAnimationFrame 插值 |
| 11 | 匠人卡片浮起 | 悬停 | box-shadow + translateY |
| 12 | 底部织纹条动画 | 页面加载 | CSS 动画循环 |
| 13 | 按钮涟漪 | 点击 | 点击位置扩散 |
| 14 | 图片视差 | 滚动 | transform translateY 滚动映射 |

## 页面结构

1. Hero 首屏：织线粒子背景 + 标题 + 副标题 + 滚动提示
2. 数据统计栏：4 项核心指标数字计数
3. 六大展厅网格：织造源流/纹样谱系/传世名作/匠人列传/技法解构/数字修复
4. 织机交互模拟器：Canvas 绘制，可拖动梭子、调节经线密度、切换视图
5. 传世名作画廊：4 件缂丝名作展示
6. 千年时间轴：汉-宋-元-明-清-今 6 个节点
7. 匠人列传：3 位传承人卡片
8. 页脚：四栏导航 + 织纹装饰条

## 技术栈

纯 vanilla HTML/CSS/JS 单文件，无外部依赖，Canvas 绘制粒子与织机模拟器。

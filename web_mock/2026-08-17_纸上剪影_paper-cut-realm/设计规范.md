# 纸上剪影 · 中国剪纸艺术展 — 设计规范

> 日期：2026-08-17 · 方向：V1 网页设计 · 主题：中国剪纸艺术展单页网站

## 一、色彩系统

| 角色 | 色值 | 用途 |
|---|---|---|
| 主色 · 剪纸朱红 | `#C93B2E` | 标题、强调、剪纸主体、按钮主色 |
| 深朱红 | `#A42E23` | 主色按压态、阴影描边 |
| 背景米白 | `#F5EFE3` | 页面主底色（宣纸质感） |
| 浅米白 | `#EDE5D2` | 卡片表面、分区底色 |
| 鎏金 | `#C9A24B` | 装饰线、图标、数字、强调点缀 |
| 浅金 | `#E0BE6A` | 鎏金悬停态、光晕 |
| 墨黑 | `#1C1A17` | 正文文字、深色区块底 |
| 炭墨 | `#2A2724` | 次级文字、边框 |

整体为「朱红 × 鎏金」东方暖调，背景宣纸米白营造剪纸贴纸的纸面感；禁用蓝紫渐变。

## 二、字体

- 标题 / 装饰：`'Ma Shan Zheng', serif`（马善政书法体，用于英雄区与展区标题，呼应手写刀刻感）
- 正文：系统衬线 / 无衬线兜底
- 数字：等宽字体计数

## 三、组件规范

- **卡片**：圆角 8–16px，宣纸底 + 鎏金细描边，悬停 3D 倾斜（直接操作 DOM transform）
- **按钮**：朱红实底 + 鎏金描边变体；磁性按钮（反平方引力吸附）
- **灯箱**：全屏深底 + 鎏金画框，展品居中放大，左右切换 + 键盘 ESC/方向键
- **导航栏**：滚动收缩 + 阴影渐显
- **团花纹样**：SVG 对称图案，匀速转动，鼠标靠近按反平方磁力加速

## 四、动效系统（15 个组件级特效）

1. 自定义光标（弹簧跟随 + 白色粗环 + 朱红内点 + 多层发光 + 悬停放大变色 + 点击涟漪）
2. 英雄区剪纸刀刻逐笔描边显现（blade draw，stroke-dashoffset 动画）
3. 纸屑粒子飘落（重力 + 摩擦 + 滚动速度联动，菱形纸屑）
4. 滚动触发区段渐入（IntersectionObserver）
5. 展品卡片 3D 倾斜（mousemove 直接改 DOM transform，非 setState）
6. 展品灯箱放大 + 悬停自转
7. 纹样画廊对称图案 + 悬浮浮现文案
8. 数字计数器（弹簧 Hooke 缓动）
9. 预约区团花纹样匀速转动 + 鼠标靠近加速（反平方磁力）
10. 打字机轮播诗句（光标闪烁、停顿、删除）
11. 英雄区鼠标视差（剪纸背景微动）
12. 磁性按钮（反平方引力吸附）
13. 展品透纸光晕（随滚动距离变化）
14. 导航栏滚动收缩 + 阴影
15. 预约成功脉冲光环

## 五、页面结构

固定导航 → 英雄区（刀刻标题 + 视差剪纸背景）→ 展览导览（4 件展品 + 灯箱前后切换 + 键盘交互）→ 纹样画廊（9 种纹样横向滚动 + 控制按钮）→ 工艺工序（六道工序）→ 数据统计（数字计数）→ 观展预约表单 → 页脚。

## 六、技术栈

纯 HTML/CSS/JS 单文件（`index.html`），所有 JSX/CSS 内联；自定义光标、粒子、视差、灯箱均原生 JS 实现；支持 `prefers-reduced-motion` 降级、`visibilitychange` 暂停动画。

# 设计规范 — 漆 · 千年流光（漆器美术馆）

| 髹漆黑 | `#0D0807` | 页面主背景，模拟推光漆面 |
| 深漆褐 | `#1A1210` | 次级背景、卡片底色 |
| 漆褐 | `#3D2B1F` | 边框、分割线 |
| 朱砂深 | `#4A0E0E` | 强调暗部 |

| 描金 | `#C9A54A` | 金色文字、高亮、描边 |

## 字体

- 标题：`'Noto Serif SC', serif`（思源宋体）
- 正文：`'Noto Sans SC', sans-serif`（思源黑体）
- 装饰大字：思源宋体加粗，金色流光渐变

## 组件规范

- 藏品卡片：3D 倾斜跟随鼠标，悬停金色光泽扫过，圆角 12px
- 工序条目：悬停顶边金色描出，左侧序号放大
- Tab 切换：选中态下划线滑动，内容淡入
- 灯箱：点击图片放大，背景遮罩淡入，关闭按钮旋转
- 导航栏：滚动收缩，背景从透明到漆黑半透明

## 页面结构

1. Hero 首屏 — 大标题金色流光 + 视差背景 + 滚动提示
2. 典藏精品 — 三张 3D 倾斜藏品卡（剔红 / 螺钿 / 描金）
3. 髹漆工艺 — 六道工序流程（制胎→髹漆→装饰→阴干→推光→成器）
4. 匠人传承 — 传承人介绍 + 数字计数动画
5. 当前展览 — 四展厅 Tab 切换
6. 艺术长廊 — 八格瀑布流画廊 + 灯箱
7. 参观预约 — 时间/地址/门票三卡 + 页脚

## 技术栈

- 纯 HTML/CSS/JS 单文件
- 无外部依赖（无 React / 无 Babel / 无 CDN）
- IntersectionObserver 实现滚动渐入
- Canvas 实现金箔粒子系统
- RAF 积分器驱动数字计数
- visibilitychange 自动暂停所有动画循环
- prefers-reduced-motion 全量降级

# 纸鸢气象站 · 设计规范

> 日期：2026-08-18 · 方向：V1 网页设计 · 主题：风筝文化与风之档案品牌官网

## 色彩系统

主色板取自传统纸鸢与天色的黛青、纸白、茜红、藤黄，无蓝紫渐变。

| 角色 | 色值 | 用途 |
|---|---|---|
| 主底 / 黛青 | `#1F3A44` | 页面深底、Hero、导航深色态 |
| 深黛 | `#13262D` / `#1A2E36` | 渐进深色层、阴影底 |
| 青灰 | `#2A4E5C` | 次级面板、悬浮层 |
| 纸白 | `#F6F1E7` | 纸面内容区、正文底 |
| 米纸 | `#E8E1D1` / `#E8BD63` | 次级表面、卡片底 |
| 茜红 | `#C7433B` | 强调、按钮、印章 |
| 深茜 | `#A3352E` | 强调按压态、标题重点 |
| 藤黄 | `#D9A441` | 点缀、装饰线、光标内点 |

## 字体

- 展示字体 `var(--font-display)`：Noto Serif SC（衬线大标题，节气/板块标题）
- 正文 `var(--font-body)`：Noto Sans SC
- 毛笔体 `var(--font-brush)`：马善政毛笔体（Logo、节气书法字）

## 组件规范

- 圆角：卡片 `8px` / `20px`，按钮 `4px`，胶囊 `50%`，细线分隔 `2px`
- 卡片：纸白底 + 细底边 + 悬停发光（茜红辉光）+ 光泽扫过
- 按钮：茜红实底，点击涟漪从触发点扩散
- 导航：滚动后转为半透明毛玻璃，吸顶

## 动效系统

15 个组件级特效，均基于 RAF 积分器 / 物理弹簧 / 主题语义：

1. 自定义光标（白环 + 藤黄内点 + 茜红发光，弹簧跟随，悬停变形，点击涟漪）
2. 全页风场粒子（2D 噪声流线 + 纸鸢菱形颗粒）
3. Hero 风筝摇曳（弹簧物理摆动 + S 形飘带，双鸢周期不同）
4. 打字机文案循环
5. 数字计数（缓动 + 视口触发）
6. 6 张风筝卡 3D 倾斜（mousemove 直操 DOM transform）
7. 卡片悬停发光 + 光泽扫过
8. 滚动渐入（IntersectionObserver 错峰）
9. 风速仪表指针（噪声驱动波动）
10. 按钮涟漪
11. 导航滚动毛玻璃
12. 节气时间线交替布局 + 图标悬停放大
13. 工坊 Tab 切换（交叉淡入 + 下划线滑动）
14. 诗词卡悬停位移
15. CTA 光泽 + 箭头位移

健壮性：RAF / 定时器随 `visibilitychange` 暂停、卸载取消；高频鼠标事件直操 DOM；支持 `prefers-reduced-motion`。

## 页面结构

单页滚动：固定导航 → Hero（风筝摇曳 + 风场 + 打字机）→ 数据计数 → 风筝档案画廊（6 卡 3D 倾斜）→ 风之物语杂志 → 放飞节气时间线 → 扎糊绘放工坊（Tab）→ 诗词卡 → CTA → 页脚。

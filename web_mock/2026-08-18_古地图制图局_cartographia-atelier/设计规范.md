## 1. 色彩体系

| 色名 | 色值 | 用途 |
|------|------|------|
| 羊皮米黄 (Parchment) | `#F2E6C8` | 页面基底色 |
| 深羊皮 (Parchment Deep) | `#E8D9B0` | 区块过渡、卡片底 |
| 暗羊皮 (Parchment Dark) | `#D9C692` | 深底对比 |
| 墨蓝深靛 (Ink) | `#1B2A4A` | 主色、标题、正文深色 |
| 墨蓝柔 (Ink Soft) | `#2B3A5A` | 次级文字 |
| 朱砂红 (Vermilion) | `#B8342C` | 强调色、印章、CTA |
| 朱砂深红 | `#8A241E` | 朱砂阴影/深色态 |
| 古铜金 (Gilt) | `#A67C3A` | 装饰、分割线、标签 |
| 古铜金浅 | `#C9A04F` | 深色底上的金色文字 |
| 古铜金深 | `#7A5A26` | 浅色底上的金色文字 |
| 墨灰 (Sepia) | `#3D3A33` | 正文文字 |
| 墨灰柔 | `#6B6458` | 辅助说明文字 |

### 色彩使用原则
- 正文永远用墨灰 / 墨蓝，保证可读性
- 朱砂红只用于最高优先级的强调（印章、主按钮、关键词下划线）
- 古铜金用作装饰性元素（分割线、角标、图标描边），不用于大段文字
- 深色区块（Process / Footer）用墨蓝深靛做底，反白文字

## 2. 字体体系

### 字体族
- **展示字体**: `Noto Serif SC` (思源宋体) — 标题、品牌名、数字
- **正文字体**: `Noto Sans SC` (思源黑体) — 正文、按钮、表单
- **拉丁标识**: `Cinzel` — 英文标签、年份、尺寸标注

### 字号层级
| 层级 | 字号 | 字重 | 用途 |
|------|------|------|------|
| Hero 标题 | clamp(42px, 7vw, 88px) | 700 | 首屏主标题 |
| 区块标题 | clamp(32px, 5vw, 52px) | 700 | 各区块主标题 |
| CTA 标题 | clamp(32px, 5vw, 48px) | 700 | 行动号召区 |
| 卡片标题 | 20px | 600 | 舆图卡片标题 |
| 工序标题 | 18px | 600 | 工艺步骤标题 |
| 正文 | 15px | 400 | 段落正文 |
| 辅助文字 | 13px | 400 | 标签、说明 |
| 小字标注 | 11-12px | 400 | 眉标、提示 |

### 字距
- 标题: `letter-spacing: 0.04em ~ 0.08em`
- 标签/眉标: `letter-spacing: 0.2em ~ 0.5em`
- 按钮: `letter-spacing: 0.2em ~ 0.3em`

## 3. 间距体系

以 8px 为基准单位：
- 微间距: 8px
- 小间距: 16px
- 中间距: 24px
- 大间距: 32px / 48px
- 区块内边距: 120px (桌面) / 80px (平板)
- 最大内容宽度: 1280px

## 4. 组件规范

### 按钮
- **主按钮** (btn-primary): 朱砂红底 + 羊皮纸白字 + 光泽扫过动效
- **幽灵按钮** (btn-ghost): 墨蓝描边 + 透明底 + 悬停从下往上填充
- **提交按钮**: 墨蓝底 + 羊皮纸白字 + 悬停变朱砂红

### 卡片
- 舆图卡片: 1px 古铜金描边 + 淡阴影 + 悬停上浮 8px + 3D 倾斜
- 制图师卡片: 圆形金边头像 + 居中文字 + 标签胶囊
- 工序步骤: 圆形线框图标 + 悬停变红放大发光

### 印章
- 朱砂红底 + 白色篆字 + 微旋转（-4° ~ 6°）
- 用于品牌标识、图片角标、CTA 区视觉焦点

### 分割线
- 浅色底: 1px solid rgba(166, 124, 58, 0.25)
- 深色底: 1px solid rgba(242, 230, 200, 0.1)
- 虚线分隔: 1px dashed rgba(166, 124, 58, 0.3)

---

## 5. 动效规范

### 缓动函数
- 标准: `cubic-bezier(.2,.8,.2,1)` (快入慢出，有弹性感)
- 填充/覆盖: `cubic-bezier(.7,0,.3,1)`
- 弹性归位: `cubic-bezier(.34,1.56,.64,1)`

### 时长
- 微交互 (hover): 0.3s ~ 0.45s
- 入场动画: 0.9s ~ 1.2s
- 滚动渐入: 0.9s
- 计数动画: 1.8s

### 降级
- `prefers-reduced-motion: reduce` 时关闭所有动画与过渡
- 移动端关闭自定义光标（还原系统光标）

---

## 6. 响应式断点

- **桌面**: ≥ 960px — 多列网格布局
- **平板/手机**: < 960px — 单列堆叠，导航收起
- **小屏**: < 560px — 进一步压缩，按钮堆叠

---

## 7. 材质与纹理

- 羊皮纸纹理: SVG noise + 径向渐变叠加，`mix-blend-mode: multiply`
- 古旧图片滤镜: `sepia(0.4) contrast(0.95)`，悬停还原为 `sepia(0.2)`
- 羊皮纸污渍: 两束径向渐变（朱红 + 古铜金）模拟岁月痕迹

---

## 8. 签名交互

**可拖拽罗盘（Draggable Compass Rose）**
- 位于 Hero 区中央，200px 直径
- 鼠标按下拖动即可旋转
- 松手后带惯性阻尼衰减（friction = 0.95 / frame）
- 开页时有自动微旋转的入场动画（+20°）
- 触摸设备同样支持
- 页面可见性切换时暂停 RAF 循环

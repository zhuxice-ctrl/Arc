# 盐风琴 Salt Organ · 设计规范

> 日期：2026-08-17 · 方向：V1 网页设计 · 主题：海岸盐田声光艺术装置品牌官网

## 色彩系统（盐田色阶）

| 角色 | 色值 | 用途 |
|---|---|---|
| 盐晶白 | #FAF7EF | 主背景 / 高光面板 |
| 沙白 | #F5F0E6 | 次背景 / 卡片底 |
| 海雾青 | #8BA89F | 辅助色 / 风琴管冷光 / 次级强调 |
| 赭石红 | #C75B39 | 主强调色 / 光标内点 / 按钮 / 高亮 |
| 深海墨 | #2D3A3A | 正文 / 深色面板 / 阴影基色 |

- 半透明衍生：深海墨 `rgba(45,58,58,.05~.8)` 用于阴影/分隔/玻璃质感；赭石红 `rgba(199,91,57,.2~.4)` 用于光晕与涟漪；盐晶白 `rgba(250,247,239,0~.9)` 用于渐隐与雾化。
- 全局禁用蓝紫渐变；盐田色阶由蒸发结晶的乳白→青→赭红→墨色递进。

## 字体

- 标题展示：`"ZCOOL XiaoWei","Noto Serif SC",serif`（带衬线韵味的书法体）
- 正文 / 标签：`"Noto Sans SC","PingFang SC",sans-serif`
- 装饰引文：`"Noto Serif SC",serif`

## 圆角

- 卡片 / 面板：4px
- 微元素 / 标签：2px
- 圆形元素（光标环、头像、管口）：50%

## 组件

- 导航栏：滚动收缩 + 玻璃拟态背景，半透明盐晶白底 + 细底边。
- 风琴管阵：11 根管，距鼠标越近发光越强，管口光晕，频谱波纹向上扩散。
- 盐田色卡：色块拼接 + 光泽扫过。
- 艺术家卡：头像脉冲环（双层错频）+ 3D 倾斜。
- 预约表单：磁性提交按钮（鼠标距离映射位移）。

## 动效系统（14 项）

1. 自定义光标（白环 + 赭红内点 + 多层发光，开页居中，悬停放大变色，点击涟漪）
2. Hero 盐晶粒子系统（鼠标磁性吸引 + 惯性阻尼 + 边界循环）
3. 11 根风琴管阵（距离驱动发光 + 频谱波纹上扩 + 管口光晕）
4. 打字机效果（装置介绍正文）
5. 数字计数动画（128 根管 / 20 公顷 / 6 年 / 32 Hz）
6. 滚动渐入（IntersectionObserver 分级延迟）
7. 3D 倾斜卡片（弹簧阻尼跟随）
8. 磁性按钮（距离映射位移）
9. 光泽扫过（色卡 / 频率条 / 艺术家卡）
10. 头像脉冲环（双层错频）
11. 声波可视化 Canvas（4 层叠加正弦波 + 渐变填充）
12. 盐晶漂浮纹理（CSS 渐变多速位移）
13. 滚动进度条（顶部渐变色）
14. 导航栏滚动收缩（玻璃拟态）

- 物理模型：粒子磁性吸引 = 反平方衰减 + 惯性阻尼 RAF 积分器；3D 倾斜 = 弹簧回弹（Hooke + 阻尼）。
- 健壮性：所有 RAF/定时器随 `visibilitychange` 暂停、卸载清理；`prefers-reduced-motion` 全量降级；高频鼠标事件直接操作 DOM transform，不触发 React 重渲染。

## 页面结构

导航 → Hero（粒子 + 管阵 + 标题）→ 装置介绍（打字机 + 数字计数）→ 盐田色卡 → 声学原理（声波 Canvas）→ 展演日程（8/9/10 月切换）→ 创作团队（艺术家卡 3D 倾斜）→ 预约参观表单（磁性按钮 + 真实提交反馈）→ 页脚。

## 技术栈

React 18 + Babel standalone（JSX 全部内联 `<script type="text/babel">`），CSS 内联 `<style>`，无构建步骤，单文件 index.html。

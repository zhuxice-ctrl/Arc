# 设计规范 · 手冲咖啡冲煮 · 注水萃取曲线

## 设计观点
"咖啡是手艺也是测量"——温热有机的厨房静物质感（滤纸 / 玻璃滤杯 / 木托盘 / 咖啡液）与精密实验室色谱测量层（网格刻度 / 等宽数字 / 曲线）并置。整站是一台可亲手注水的手冲冲煮仪表。

## 空间模型
固定视口仪表盘式（非 Landing Page、非卡片网格）：
- 顶部 60px 标题栏
- 中部三列网格：左 280px 冲煮参数 | 中 1fr 冲煮模拟舞台 | 右 280px 风味轮与萃取科学
- 底部 220px 萃取曲线横向时间脊（液量 + TDS 双轴，三萃取区段语义底色）
- 80px 页脚（标语 / 计时 / 版本）
- 响应式：1024→220px 侧栏；768→单列堆叠；390→单列紧凑

## 字体
- 标题：Noto Serif SC（衬线，自带/CDN）
- 正文：系统无衬线
- 数字与测量：JetBrains Mono（等宽）
- 外部字体声明：通过 miaoda.feishucdn.com 字体 CDN 加载；离线/沙箱环境回退系统字体，不影响功能。

## 材质语言
- 玻璃滤杯：半透明 + 折射高光（canvas 渐变模拟）
- 滤纸：褶皱纹理
- 木托盘：木纹横向条纹
- 咖啡液：深棕透光，液面涟漪
- 测量层：细网格 + 左缘刻度 + 等宽数字叠加于暖色静物之上

## 动效系统（≥12 个组件级特效，均服务"手艺×测量"双线）
1. 注水柱（按住时从滤杯口下落的水流）
2. 滤杯液面上升 + 涟漪
3. 闷蒸膨胀（粉层隆起）+ CO₂ 细密气泡上升
4. 闷蒸后缓缓塌陷
5. 滴落液滴 + 落入分享壶溅起颗粒
6. 滴速脉冲环
7. 蒸汽上升
8. 研磨颗粒（粉层细节）
9. 温度针微摆
10. 滤杯倾角响应注水位置
11. 萃取曲线 stroke 实时绘制（液量线 + TDS 虚线）
12. 风味轮分段填充联动萃取区段
13. 自定义水滴光标（默认 / 注水时 scale 1.3）

动效原则：液体物理 + 色谱测量 + 有机细节；禁整图缩放 Ken Burns；prefers-reduced-motion 下降级（仅保留注水/滴落必要状态变化）。

## 核心交互
- 唯一输入：长按滤杯上方（dripperTopY 开口处）注水；松开停止
- 闷蒸：首次注水触发，粉层膨胀冒泡
- 萃取曲线：随注水实时绘制，可沿曲线拖动游标回看任意时刻的液量 / 浓度 / 风味状态
- 风味轮：8 维（酸 / 花香 / 果香 / 甜 / 焦糖 / 坚果 / 苦 / 醇厚）随萃取区段显色——先出花香果酸、中段甜感焦糖、尾段坚果醇厚苦
- RESET：重置整杯冲煮

## 内容（真实）
- 参数：粉量 15g / 水温 92℃ / 粉水比 1:15 / 研磨度中细 / 目标液量 225g
- 闷蒸：30s · 30g；三段注水 60→120→180→225g；滴滤完成约 2:30
- 萃取科学：溶解与扩散；风味析出顺序
- 注水手法：中心注水 / 画圈注水
- 萃取三区段：不足（0:25 前）/ 黄金（0:50–1:40）/ 过萃（1:40 后）

## 技术栈
纯 vanilla 单文件 HTML（无 React / Babel / JS CDN）；canvas + SVG 混合渲染；CSS 变量主题化；响应式 1440 / 1024 / 768 / 390；RAF 随 visibilitychange 暂停且 beforeunload 取消；快速操作不叠加定时器；高频鼠标事件直接操作 DOM。

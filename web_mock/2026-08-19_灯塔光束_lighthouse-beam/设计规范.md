# 设计规范 · 灯塔 · 光束显影

> 本文件所有色值、字体栈均从 `index.html` 源码中实测提取。

## 主题与设计母题
**母题**：灯塔 ·「光束显影」。整站是一片漆黑夜海，画面中心偏左矗立一座灯塔，页面唯一光源是塔顶灯室射出的旋转光束。用户拖动光束绕塔旋转（带阻尼惯性），圆周分 6 个扇区，每扇区藏一章内容；光束扫到哪个方位，哪章内容就从黑暗中显影。**光束即导航，光即阅读行为本身。**

## 网站类型
展览型 / 实验媒体（Editorial-Exhibition）。单屏固定舞台，非 Landing Page，非 Section 堆叠。

## 空间模型
- 全屏固定舞台，灯塔位于水平约 38%、垂直居中偏上；海平线约在 72% 高度。
- 以塔为圆心，圆周均分 6 扇区（每扇 60°），光束角度 0° = 正右方；进入扇区中心 ±30° 时该扇区激活、内容显影。
- 内容面板按当前激活扇区显影；离开光束渐隐回黑暗。
- 顶部一行极简章节索引（01–06），点击驱动光束沿最短弧缓动到对应扇区。

## 配色（实测，禁蓝紫渐变）
| 角色 | 色值 | 用途 |
|---|---|---|
| 夜海近黑 | `#060B0F` / `#0A1216` | 画面底色、舞台 |

| 光束钠金 | `#F0BE5A` | 光束、一切可交互物、激活态 |
| 光束光晕 | `#F5D78A` / `#FFF4D6` | 光带渐亮端、高光 |
| 玻璃青灰 | `#7E939C` | 透镜、标注线、结构线 |
| 海雾白 | `#E8E4D8` / `#C8C4B8` / `#D0CCC0` | 正文文字、次级文字 |

## 六扇区真实内容
1. **菲涅尔透镜** — 1822 年菲涅尔发明；阶梯棱镜收束平行光；分六级，一级透镜可高逾两米、放大亮度数万倍；SVG 透镜剖面，hover 环层高光标注。
2. **灯质** — 单闪 / 联闪三次 / 等明暗三种可切换节奏，塔顶光点同步真实闪烁。
3. **灯守人** — 上油、点灯、重锤上发条驱动透镜旋转、擦镜、记日志、雾中鸣号；一日作息时刻表。
4. **雾号** — 雾钟 / 雾炮 / 雾笛（diaphone）；「鸣放雾号」按钮 WebAudio 合成低沉雾笛 + 声波环扩散（首次手势创建 AudioContext，失败静默降级）。
5. **灯塔档案** — 花鸟山灯塔（浙江嵊泗，1870 年，"远东第一大灯塔"）、老铁山灯塔（辽宁旅顺，1893 年，黄渤分界）、小青岛灯塔（山东青岛，1900 年）、木兰灯塔（海南文昌，1995 年，塔高约 72 米，亚洲最高灯塔之一）。档案编号排版，非圆角卡片网格。
6. **守灯日志** — 文学化但合理的守灯人手记（风浪、灯油、透镜、候鸟撞灯），稿纸式排版显影。

## 动效系统（13 项，全部符合光学 / 海事物理）
1. 光束锥形光带惯性旋转，亮度随角速度微变
2. 扇区内容显影 / 渐隐过渡（opacity + 位移 + blur，约 600ms）
3. 塔顶透镜棱镜高光随角度掠过
4. 三层海面波浪错峰缓动起伏
5. 浪脊在光带扫过处叠加鳞光
6. 浮标灯红 / 绿各自节奏闪烁
7. 海雾粒子缓慢漂移
8. 稀疏星点极克制微闪
9. 塔身窗洞暖光呼吸
10. 章节索引 hover 微光 + 点击驱动光束转动（最短弧缓动）
11. 灯质演示：塔顶光点按所选节奏闪烁
12. 雾号声波环扩散
13. 档案编号错峰墨显

禁：整图缩放 Ken Burns、每段重复 Fade Up、Stagger 卡片、无意义粒子。

## 核心交互
- 主交互：页面任意处水平拖拽（或塔旁黄铜手柄）驱动光束旋转，单 RAF 主循环 + 阻尼惯性，松手角速度衰减；快速连续拖拽不叠加定时器。
- 光束角度 → 扇区映射：进入扇区中心 ±30° 显影，离开渐隐。
- 章节索引点击 → 光束沿最短弧 tween 到目标扇区。
- 灯质演示控件：三种节奏可切换。
- 鸣放雾号按钮：WebAudio 低音脉冲 + 声波环。

## 自定义光标
开页即位于屏幕中央；亮金圆环 + 中心点；`mix-blend-mode: difference` 高对比；`z-index` 最高；拖拽时放大变白；`body{cursor:none}`。

## 工程红线
- 纯 vanilla 单文件 `index.html`（48.5 KB）；无 React / Babel / 外部 JS / CSS / 字体 / 图片（全部 SVG / CSS 绘制）。
- 单 RAF 主循环；`document.visibilitychange` 暂停恢复 RAF；`beforeunload` 清理。
- 高频 `pointermove` 直接写 DOM style / CSS 变量。
- `prefers-reduced-motion`：关闭光束微动 / 波浪 / 雾 / 星闪，保留拖拽显影核心功能。
- 响应式：桌面完整体验；`<768px` 内容面板堆叠到底部单栏，无横向溢出。

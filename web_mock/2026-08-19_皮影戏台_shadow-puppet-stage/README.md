# 皮影戏台·白蛇传

> 形态：网页设计（Web Mock）

一方可以"上手演"的皮影戏台。鼠标即操纵杆，拖动墨黑皮影人物在暖黄羊皮幕布上移动，主角走到朱砂折目标记便换场推进剧情——《白蛇传》五折：游湖借伞、断桥相会、水漫金山、断桥重圆、雷峰塔镇。油灯在幕后轻轻摇曳，旁白竖排字幕逐折浮现，已演完的折目盖上一枚朱砂"完"字印章。

## 核心交互
- 按住皮影剪影拖动，操纵杆连线实时跟随
- 主角进入右侧"下一折"朱砂光圈 → 幕布明暗换场 → 切换至下一折
- 底部五段折目进度条，可点击跳折
- 自定义竹签操纵杆光标（开页居中、高对比、层级最高）

## 文件说明
- `index.html` — 单文件完整实现（纯 vanilla，无外部依赖）
- `设计规范.md` — 色彩 / 字体 / 动效 / 交互系统
- `preview.png` — 首屏渲染截图（1440×900）

## 技术栈
纯 HTML + CSS + JavaScript 单文件，无框架、无 CDN。RAF 物理驱动油灯 flicker 与换场；`visibilitychange` 暂停、`prefers-reduced-motion` 降级。

## 设计观点
不做"介绍皮影戏的网页"，而把网页本身做成戏台——浏览方式即演出方式。

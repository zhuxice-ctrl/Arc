# 皮影戏台·白蛇传 — 设计规范

> 单一 index.html（纯 vanilla，无 React / Babel / CDN），打开即演。

## 设计母题
中国皮影戏。整站是一方固定戏台，不滚动；观众以"操纵杆"拖动皮影人物，走到舞台折目标记即推进剧情。空间模型 = 固定戏台 + 横向舞台，导航 = 操纵杆拖拽 + 折目进度跳折。

## 剧目与结构
《白蛇传》五折：① 游湖借伞 ② 断桥相会 ③ 水漫金山 ④ 断桥重圆 ⑤ 雷峰塔镇。
- 戏台木框（回纹雕花）包边，中央半透明羊皮幕布
- 底部五段折目进度条：当前折朱砂高亮、已完折盖"完"字印章、可点击跳折
- 右侧宣纸底竖排旁白字幕，顶部剧名印章

## 色彩（真实色值）
| 用途 | 色值 |
|---|---|
| 幕布暖光主色 | `#E8B45A` → 边缘 `#C98A3E`（径向渐变） |
| 幕布高光 | `#FFD88A` / `#D4A056` |
| 宣纸字幕底 | `#F0E6D2` / `#E0D4B8` |
| 戏台深褐木框 | `#3A2418` / `#5A3826` / `#7A5030` |
| 朱砂（折目标记/印章/剧名） | `#B23A2E` / `#8A2A20` |
| 皮影剪影 | 墨黑（近 `#0A0806`） |

禁蓝紫渐变，整体暖色调。

## 字体
- 剧名 / 折目标题：`Kaiti SC / STKaiti / KaiTi` 楷书 serif
- 旁白正文：`Songti SC / SimSun / STSong` 宋体 serif（竖排）

## 动效系统（≥12 组件级，服务皮影氛围）
1. 油灯暖光 RAF sub-pixel 摇曳（flicker）
2. 幕布明暗换场过渡（~600ms）
3. 皮影剪影淡入 / 淡出
4. 操纵杆连线实时跟随光标
5. 折目标记呼吸光圈 + 虚线旋转
6. 旁白字幕逐字浮现
7. 朱砂印章盖下弹跳
8. 折目进度条段填充
9. 皮影拖动时晃动 + 暖光投影
10. 幕布噪点纹理流动
11. 戏台雕花 hover 微亮
12. 换场尘光粒子（克制少量）

无整图 Ken Burns；动效均与"皮影戏"主题有因果。

## 自定义光标
竹签操纵杆造型，开页居中、高对比（暖黄+墨黑描边）、层级最高（z-index 顶层、pointer-events:none）；按住皮影拖动时变"握持/挑起"态。`prefers-reduced-motion` 时降级系统光标。

## 健壮性
零未定义引用；RAF/定时器随 `visibilitychange` 暂停、卸载取消；快速拖动不叠加定时器；高频鼠标直接操作 DOM；支持 `prefers-reduced-motion`（减少 flicker/粒子/光标动效）；1440/1024/768/390 不溢出不裁切。

## 核心交互
按住皮影剪影沿幕布拖动 → 主角进入右侧朱砂"下一折"光圈 → 触发换场（灯暗→旧影淡出→新影淡入→字幕切换）。底部折目条可跳折。

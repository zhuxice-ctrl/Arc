# 松烟墨砚博物馆 · 设计规范

| 角色 | 色值 | 用途 |
|------|------|------|
| 主色·墨黑 | #1a1a2e | 深色背景、标题、首屏 |
| 背景色·宣纸 | #f5f0e8 | 页面主背景、浅色展区 |
| 强调色·朱砂红 | #c23b22 | 印章、按钮、高亮元素 |
| 辅助色·墨灰 | #4a4a5a | 次级文字、分割线 |

| 纸暖 | #efe9dd | 卡片背景 |

## 字体

- 标题：衬线体（思源宋体 / Noto Serif SC），font-serif 类
- 正文：无衬线体（系统默认）

## 页面结构

1. **首屏 Hero** — 博物馆名称「松烟墨砚博物馆」，水墨粒子动态背景，副标题"千年松烟·万石凝墨"
2. **关于展区** — 博物馆简介、建馆理念、馆藏统计数字
3. **制墨六序** — 炼烟→和料→捣磨→压模→晾干→描金，交互式时间轴
4. **四大名砚** — 端砚、歙砚、洮砚、澄泥砚，3D 倾斜卡片
5. **名墨典藏** — 历代名墨画廊，视差滚动
6. **墨匠传承** — 李廷珪、潘谷、程君房、曹素功等制墨名家
7. **参观信息** — 开放时间、地址、联系方式

## 组件规范

- 卡片圆角：8px
- 按钮圆角：4px
- 卡片阴影：0 4px 20px rgba(0,0,0,0.08)
- 分割线：1px solid rgba(74,74,90,0.15)

## 动效系统

| 序号 | 动效名称 | 实现方式 | 物理模型/语义 |
|------|---------|---------|-------------|
| 1 | 自定义光标 | DOM transform | 白环+朱砂内点+发光，悬停放大 |
| 2 | 水墨粒子背景 | Canvas RAF | 墨滴扩散粒子模拟 |
| 3 | 滚动渐入 | IntersectionObserver | 各展区进入视口渐入 |
| 4 | 名砚3D倾斜 | mousemove→DOM transform | 鼠标跟随倾斜 |
| 5 | 工序节点序列 | CSS animation delay | 依次亮起 |
| 6 | 墨迹连线 | SVG stroke-dashoffset | 路径绘制动画 |
| 7 | 名墨视差 | scroll→transform translateY | 不同速度滚动 |
| 8 | 墨匠卡片发光 | CSS box-shadow hover | 边缘发光 |
| 9 | 数字计数 | RAF counter | 数字递增 |
| 10 | 朱砂印章 | CSS transform scale+rotate | 印章盖落 |
| 11 | 加载进度条 | CSS animation | 毛笔书写式 |
| 12 | 返回顶部 | 固定定位+click | 墨滴形态按钮 |

## 健壮性

- requestAnimationFrame 随 visibilitychange 暂停
- 高频鼠标事件直接操作 DOM transform
- 支持 prefers-reduced-motion 降级
- 纯 vanilla HTML/CSS/JS 单文件实现

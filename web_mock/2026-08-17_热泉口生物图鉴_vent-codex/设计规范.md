# 设计规范 · 热泉口生物图鉴 (Hydrothermal Vent Codex)

方向：V1 网页设计 · 日期：2026-08-17 · 主题：深海热泉口生态系统生物田野图鉴

## 色彩系统

| 角色 | 色值 | 用途 |
|------|------|------|
| 底色 | #0A0E10 | 全站深炭黑背景 |
| 主色 | #D4502A | 赤铜橙，主操作 / 标题强调 |
| 强调 | #F2C14E | 硫磺黄，高亮 / 数据 / 链接 |
| 辅色 | #3A8E7C | 冷青绿，生物发光 / 次要标签 |
| 表面 | #1B2428 / #2A3338 | 卡片表面 / 分层 |
| 中性 | #C8B89A / #E8DFD0 | 米沙色文字 / 浅描边 |

无蓝紫渐变。整体为深海底色 + 热泉暖光对比。

## 字体

- 展示标题：DM Serif Display（英文衬线）+ Noto Serif SC（中文衬线）
- 正文：Inter / PingFang SC
- 数据/终端：JetBrains Mono（打字机终端）

## 组件

- Hero 大标题 + 打字机终端通讯行 + 下滑指示器
- 数字计数 KPI 条（物种 / 深度 / 温度 / 考察次数）
- 生物卡片画廊（5 类筛选 chip + 标本详情弹窗）
- 全球热泉口 SVG 地图（脉冲标记 + tooltip）
- 科考日志时间线（左右交替节点）
- 深度阅读长文卡片
- 右侧固定深度指示条 + 顶部深度数值导航

## 动效系统（12+ 组件级，主题语义化）

1. 自定义光标（白环 + 铜色内点 + 多层发光 + hover 旋转放大 + 点击涟漪）
2. 上升气泡 canvas + 下沉热粒子双系统
3. 打字机终端循环（潜水器通讯）
4. 数字计数（滚动触发）
5. 卡片 3D 倾斜（mousemove 直接操作 transform）
6. 生物发光脉冲点（双环扩散）
7. 卡片光泽扫过
8. 地图热泉口脉冲扩散
9. 滚动渐入 reveal
10. Hero 烟囱热羽流上升
11. 深度阅读卡片点击涟漪
12. 导航 logo 脉冲 + 下滑线
13. 右侧深度条随滚动填充

## 健壮性

- RAF 统一调度，visibilitychange 自动暂停，卸载取消
- 高频 mousemove 直接操作 DOM transform，不触发重渲染
- 支持 prefers-reduced-motion 降级
- 快速筛选切换不叠加定时器

## 技术栈

纯 HTML/CSS/JS 单文件，无外部依赖，无 React/Babel。

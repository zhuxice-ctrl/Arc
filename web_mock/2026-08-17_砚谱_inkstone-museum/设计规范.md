# 砚谱·端歙砚博物馆 — 设计规范

> 日期：2026-08-17 · 方向：V1 网页设计 · 主题：砚台博物馆官网

## 色彩系统

| 角色 | 色值 | 用途 |
|------|------|------|
| 砚石墨黑 | `#1A1A1E` | 主背景、深色区块底 |
| 赭石红 | `#9C3B2E` | 印章、强调、标题点缀 |
| 宣纸白 | `#EDE6D3` | 浅色区块底、正文 |
| 古铜金 | `#B8924A` | 高亮、分割线、金属质感 |
| 苍苔绿 | `#5C6B4E` | 辅助、次要标签 |
| 辅助墨褐 | `#3A3028` / `#2A2018` | 卡片层次、阴影 |

整体为砚石墨黑底 + 宣纸白前景的东方博物馆调性，赭石红与古铜金作为印章/金线点缀，禁止蓝紫渐变。

## 字体

- 正文 / 标题：`"Songti SC", "STSong", "SimSun", "Noto Serif SC", serif`（宋体衬线，贴合古籍砚台主题）
- 数字 / 拉丁：`"Times New Roman", serif`

## 圆角与间距

- 卡片圆角：6–10px（克制，偏方正）
- 印章元素：直角 + 1px 金线描边
- 章节纵向间距：96–128px，留白充足

## 组件

- 印章 Logo：朱砂红方印 + 馆名
- 名砚卡：墨色底 + 金线描边 + 3D 倾斜
- 纹理图鉴：Canvas 绘制 8 种砚石纹理 + 放大镜
- 工艺时间轴：六步竖向时间轴，自动轮播
- 临展 Tab：三栏切换指示器

## 动效系统（13 项）

1. 自定义双层光标（白环 + 金点 + 发光，悬停形变，点击涟漪）
2. Hero 墨晕粒子系统（鼠标排斥 + 粒子连线）
3. 3D 卡片倾斜（transform 直操 DOM）
4. 滚动渐入（IntersectionObserver + 分级 delay）
5. 砚台剪影视差滚动
6. 文字墨晕逐字入场
7. 卡片光泽扫过（glaze sweep）
8. 数字计数（easeOutExpo）
9. 工艺步骤自动轮播 + 进度条
10. Tab 指示器滑动
11. 纹理图放大镜跟随
12. 顶部滚动进度条
13. 回到顶部按钮浮动

物理/语义逻辑：墨晕粒子用鼠标斥力（反平方衰减）；光泽扫过为线性扫光；数字计数 easeOutExpo 缓动。

## 页面结构

首屏 Hero → 馆藏名砚（三方）→ 纹理图鉴（8 种）→ 制砚工艺（六步时间轴）→ 临展活动（三栏 Tab）→ 页脚。

# 砚谱·端歙砚博物馆

> 日期：2026-08-17 · 方向：V1 网页设计 · 主题：砚台博物馆官网

![预览](./thumbnail.png)

## 简介

「砚谱」是一座虚拟砚台博物馆官网，展示端砚、歙砚、洮河砚、澄泥砚等名砚。首屏以墨晕粒子背景与砚台剪影视差开场；馆藏名砚以墨色金线卡片呈现并支持 3D 倾斜；纹理图鉴用 Canvas 绘制 8 种砚石纹理（石眼、火捺、罗纹、金星、鸭头绿、蟹壳青、鱼脑冻、眉子）并配放大镜；制砚工艺为六步时间轴自动轮播；临展活动三栏 Tab 切换。整体砚石墨黑 + 赭石红 + 宣纸白 + 古铜金的东方博物馆调性。

## 动效亮点

- 双层自定义光标（白环 + 金点 + 发光），悬停形变、点击涟漪
- Hero 墨晕粒子（鼠标斥力 + 粒子连线）
- 3D 卡片倾斜、光泽扫过、逐字墨晕入场
- 纹理图 Canvas 绘制 + 放大镜跟随
- 工艺时间轴自动轮播 + 进度条
- 顶部滚动进度条、回到顶部浮动按钮

## 配色

砚石墨黑 `#1A1A1E` / 赭石红 `#9C3B2E` / 宣纸白 `#EDE6D3` / 古铜金 `#B8924A` / 苍苔绿 `#5C6B4E`。

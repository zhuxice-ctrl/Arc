## 字体

- 标题：`'Fraunces', serif`（展示衬线，火山地质的考据感）
- 正文：`'Inter', system-ui, -apple-system, sans-serif`
- 数据 / 代码：`'JetBrains Mono', monospace`

## 圆角与间距

- 卡片圆角 `12–16px`，按钮 `8px`，徽章胶囊 `999px`
- 章节纵向间距 `96–120px`，卡片内边距 `24–32px`

## 组件

- 火山档案卡（3D 倾斜 + 光泽扫过）
- 喷发年表时间线（上下交错节点）
- 监测仪器阵列网格（6 种传感器卡）
- 预警级别图鉴（4 级色块）
- 地层剖面分层视差带
- 状态跑马灯 / Hero 地震波 Canvas

## 动效系统

1. 自定义光标：白环 + 熔岩色内点 + 多层发光，阻尼跟随，悬停形变，点击涟漪
2. 地热粒子上升（35 粒，正弦横向漂移，不同速度/周期）
3. 实时地震波形描线（Canvas，多频率叠加 + 偶发尖峰，领先点发光）
4. 岩浆温度数字滚动（RAF + easing 阻尼趋近）
5. 打字机副标（逐字键入 + 光标闪烁）
6. 数字计数（IntersectionObserver 触发，ease-out cubic）
7. 3D 卡片倾斜（鼠标驱动透视，弹簧阻尼回归）
8. 滚动渐入 fade-up
9. 地层视差滚动（每层不同速率）
10. Hero 背景视差（0.3 倍率）
11. 状态脉冲 LED（2s 呼吸）
12. 光泽扫过（hover 斜向高光位移）
13. 熔岩流动分隔带（多层径向渐变交替位移）
14. 跑马灯无限滚动（40s 线性）
15. 滚动指示器（熔岩色光点沿线下落）

所有 RAF / 定时器随 `visibilitychange` 暂停，卸载统一清理；高频鼠标事件直接操作 DOM transform；支持 `prefers-reduced-motion`（动画归零 + 光标隐藏）。

## 页面结构

Hero（大标题 + 打字机副文 + 实时地震波 + 读数） → 状态跑马灯 → 火山档案（4 座）→ 喷发年表（10 事件）→ 监测仪器阵列（6 传感器）→ 预警级别图鉴（4 级）→ 火山灰样本馆 → 地层剖面视差（5 层）→ 订阅 CTA → 页脚。

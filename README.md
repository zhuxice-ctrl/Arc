# Arc — 每日设计 Mock

每日自动生成的精品设计 Mock 仓库。每天产出三版设计——**网页设计**、**手机应用 UI**、**UX 交互设计**，每版一件艺术品级单品，风格随机、不复制固定模板。

所有设计遵循统一的创作原理：真实可交互（非图片占位）、动效 ≥ 12 个组件级特效且符合物理 / 主题逻辑、自定义光标开页即显示、禁蓝紫渐变、配色三版互斥每天重抽、健壮性红线（零未定义引用、RAF 随可见性暂停、支持 `prefers-reduced-motion`）。

## 子文件夹命名规则

`<日期>_<中文名称>_<英文标识>`，例如 `2026-08-16_声之形_sonic-formations`。日期前缀便于按时间排序，中文名为内容注释，英文标识为 URL 友好 slug。

## 每个子文件夹包含

- **源码** — 完整可运行的源代码文件
- **设计规范文档** — `设计规范.md`，记录色彩系统、字体、组件、动效、页面结构
- **浏览页 HTML** — `index.html`，可直接在浏览器打开预览
- **README** — 该项的单独介绍、截图展示、妙搭在线预览链接

## 在线预览

每个子文件夹的 README 中保留了妙搭（Miaoda）在线预览链接，可在浏览器中直接体验完整交互效果。

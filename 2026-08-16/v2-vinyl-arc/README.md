# Vinyl Arc — 黑胶唱片收藏 App

> Arc 每日设计 Mock · 2026-08-16 V2 · 手机应用 UI

## 主题

一场复古暖调的黑胶收藏与播放体验。整套配色是暖棕陶土 + 深棕底 + 奶白文字，无任何蓝紫渐变。

## 页面（8 屏，同一手机外壳内可切换）

1. 首页·收藏
2. 发现页
3. 唱片详情（大封面视差头图 + 按 Side 分组曲目）
4. 全尺寸播放器
5. 动态时间线
6. 个人中心
7. 设计规范
8. 接口文档

## 签名动效（按物理逻辑实现，非简单缩放）

- 全尺寸播放器：黑胶持续旋转 + 唱针平滑摆动入场
- 唱片卡片：3D 倾斜跟随鼠标，hover 时黑胶从封套里露出
- 唱针式自定义光标：内环精准点 + 外环缓动跟随，悬停可交互元素时放大，初始即显示在屏幕中央
- 列表交错入场、Mini Player 悬停弹出、进度条实时推进、Toast 提示

## 内置文档

- 设计规范与接口文档内嵌于 App（第 7、8 页）
- 8 个 REST 端点，可展开查看参数与返回
- 底部 Tweaks 面板：可调强调色、风格主题、唱片旋转开关等

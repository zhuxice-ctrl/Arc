# V3 — KINETIC · 动力学交互实验室

> UX 交互设计 · 2026-08-16

## 概念

把 UX 运动原理本身当展品——整页是一座可以亲手把玩的交互美术馆，5 个展区每个都得上手玩。

## 五大展区

1. **01 弹性弹簧振荡** — 拖拽荧光球松手，Hooke 定律下的真实振荡衰减
2. **02 惯性拖拽滑动** — 抓住轨道甩出去，动量 + 摩擦衰减的自然滑行
3. **03 磁性吸附按钮** — 悬停时核心被反平方引力场拖拽
4. **04 滚动驱动形变** — 往下滚，方形→圆形→流体，滚动进度即形变时间轴
5. **05 视差纵深空间** — 移动鼠标，四层以不同速率独立位移

## 技术实现

- 所有运动均为 RAF 弹簧积分器驱动的物理模型（F = -kx + 阻尼/摩擦/弹性边界），非 CSS 过渡
- 自定义光标：8 段拖尾 + 抓取/悬停/拖拽三态形态切换
- 无未定义引用；RAF/定时器随页面可见性切换自动暂停
- 快速来回操作不叠加定时器

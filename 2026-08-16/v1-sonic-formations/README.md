# 声之形 / Sonic Formations — 新媒体声音艺术展官网

> 2026-08-16 · V1 · 网页设计

## 项目简介

一个自拟主题的完整艺术展官网，主题为「声之形 / Sonic Formations」——一场关于声音可视化与沉浸式听觉的新媒体艺术展。全站按「共振 / 潮汐 / 静默 / 衍射」四大篇章组织，模拟从声波物理现象到艺术感知的完整叙事。

## 设计风格

- **基调**：深色沉浸基底 + 青绿 / 琥珀金 / 暖橙高级艺术色调
- **排版**：衬线中文 × 等宽英文混排，先锋科技与艺术交融
- **卡片**：去毛玻璃纯白实底 + 细底边 + 悬停发光
- **氛围**：多层动态光晕、粒子系统、声波物理动效

## 动效系统

全部基于声波物理逻辑设计，非简单缩放：

| 层级 | 动效 | 说明 |
|------|------|------|
| 背景 | 声波柱振动 | 12 根竖条各自独立缓慢伸缩（周期 5.8–8.1s） |
| 背景 | 地面涟漪扩散 | 8 圈椭圆涟漪从地面向外扩散，三色错开 |
| 背景 | 底部呼吸光 | 涟漪区整体明暗缓动 |
| 背景 | 光晕漂浮 | 青绿 / 琥珀金 / 暖橙三颗光球缓慢漂移呼吸 |
| 背景 | 波形流动 | 三条 SVG 波形从右向左流动 |
| 背景 | 粒子系统 | 60 颗光点粒子 + 白色微光点从底部上飘 |
| 前景 | 频谱条跳动 | 36 根条逐帧驱动，独立随机游走 + 正弦起伏 + 节拍脉冲 |
| 交互 | 自定义光标 | 白色粗环 + 琥珀实点 + 三层发光，悬停放大变色，点击涟漪 |
| 交互 | 卡片 3D 倾斜 | 作品卡片随鼠标视差倾斜 + 光晕跟随 |
| 交互 | 滚动渐入 | 各板块元素滚动进入视图时渐显 |
| 文字 | 打字机 | Hero 标题中英文逐字出现 |
| 文字 | 数字计数 | 底部信息栏数字从 0 滚入 |

所有动效周期不同步，避免机械感。

## 页面结构

1. **Hero 主视觉** — 展期 / 地点 / 艺术家信息栏 + 频谱条 + 打字机标题
2. **策展理念** — 策展人引言
3. **四大篇章卡片** — 共振 / 潮汐 / 静默 / 衍射，各带独立强调色
4. **展期倒计时** — 天 / 时 / 分 / 秒实时跳动
5. **观展动线时间线** — 入场 → 共振 → 潮汐 → 静默 → 衍射 5 站
6. **艺术家语录轮播** — 4 位艺术家金句自动播放
7. **精选作品** — 8 位参展艺术家卡片
8. **合作伙伴** — 8 家机构网格
9. **FAQ 手风琴** — 6 个常见问题
10. **场馆信息与票务预约**
11. **页脚**

## 技术实现

- 纯 HTML + CSS + JavaScript，无框架依赖
- `index.html` — 页面结构
- `styles.css` — 全部样式（含动画 keyframes）
- `main.js` — 交互逻辑（频谱驱动、光标、倒计时、轮播、FAQ 等）
- 桌面 / 平板 / 移动端全响应式

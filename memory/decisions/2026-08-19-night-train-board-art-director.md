## Novelty / Pattern Pressure 检查
- A「split_flap_departure_board」spatial_model：web 库 34 条 + pattern_stats 全量零重复；主交互 clock_step_cascade_flip 非拖拽、非 scroll-descent、非 tap-reveal-overused，与今日全部 34 版正交。
- 翻牌级联签名：机械 3D 翻转（rotateY 翻牌半幅），非 glow / 非 Ken Burns / 非整图缩放，符合 global.md 动效须服务机制。
- 配色正交：深汽油青(#0E3A38) 主导框架 + 薄荷淡绿(#DCE7DA) 翻牌面 + 墨黑(#141414) 文字 + 珊瑚红(#E8564A) 终呼/紧迫 + 深青(#0A2A28) 凹陷区。禁蓝紫、禁纸本水墨木色、禁石墨灰主导（与 telegraph 的 graphite+brass+vermilion+cream 拉开：主导色青 vs 灰、牌面薄荷 vs 奶油、强调珊瑚 vs 朱砂）。
- 无 SATURATED 模式。空间模型、主交互、签名均为全库首现。

## accepted_patterns
- 机械翻牌（3D rotateY 半幅）——内容驱动的真实物件机制，非装饰特效。
- 时钟步进（点击推进，非拖拽）——驱动翻牌级联，符合"用户输入量≈状态变化量"。

## Design Contract（锁定本轮）

### Core Idea
夜行候车厅——整个网站是一只候车厅里活着的机械翻牌发车牌。翻牌板是唯一脊柱：每一行是一趟今夜出发的夜行列车，牌面翻动=时间在推进、车次在终呼、在离站。围绕"看着发车牌翻动等一趟夜车"这一候车体验展开，附以夜行列车衰落与复兴的编辑正文、一趟精选线路的纵深（站点阶梯 + 卧铺车厢铺位剖面）、全球卧铺网络的地理图。

### Experience Goal
用户像深夜坐在一座长途夜车终点站的候车厅里，抬头看头顶那只机械翻牌发车牌：牌面一下下翻动，时间往前走，车次从"准点"翻成"终呼·即将发车"，再翻成"已发车"灰着滑走，下一趟顶上来。点一趟车，打开它的线路纵深——站点阶梯、铺位剖面、里程与时刻。整站是写给夜行列车的一封情书。

### Must Keep
1. 机械翻牌发车牌为唯一脊柱（≥6 行真实夜车，每行牌面可翻动），非竖向 section 堆叠、非卡片网格、非固定单舞台、非横向脊柱迹线。
2. 时钟步进驱动翻牌级联：点击推进时间 → 多行牌面 3D rotateY 翻牌级联更新（机械翻转，非 glow/非缩放）；临近发车车次翻成珊瑚红"终呼·即将发车"，到点后翻成"已发车"灰出滑走，下趟顶上。
3. 点击车次 → 线路纵深：垂直站点阶梯（真实站点 + 里程 + 时刻，stroke-dashoffset 绘制）+ 卧铺车厢铺位剖面（上/中/下铺位剖面图，铺位依占用点亮）。
4. ≥6 趟真实夜行列车（ÖBB Nightjet / Caledonian Sleeper / 西伯利亚大铁路 / 日本 Sunrise 出云·濑户 / 法国 Intercités de Nuit / 中国直达特快 Z 字头），线路、站点、里程、铺位类型、行程时长为可考证真实数据；时刻为示意性样表（README 诚实声明）。
5. 自定义光标：列车员打孔剪票器（圆环 + 十字准星），开页居中显示、高对比、层级最高。
6. 动效≥12 个组件级特效且符合机械/铁路物理（翻牌翻转、终呼脉冲、离站滑出、铺位依次点亮、站点阶梯绘制、线路弧绘制、票根齿孔进度、票根撕边等），禁整图缩放 Ken Burns、禁 glow 球、禁鼠标跟星光斑。
7. 纯 vanilla 单文件（无 React/Babel/CDN 外部依赖）；RAF/定时器随可见性暂停且卸载取消；快速操作不叠加定时器；高频鼠标事件直接操作 DOM；支持 prefers-reduced-motion（翻牌降级为即时切换、绘制即时完成、铺位静态点亮）。
8. 响应式：1440 / 1024 / 768 / 390 自检无横向溢出、无重叠裁切。

### Must Not Regress To
1. 竖向 section 堆叠 / 卡片网格 / 蓝紫渐变 / 纸本水墨木色 / 石墨灰主导 / 通用 landing page / 拖拽时间游标 / 固定单舞台 / 横向脊柱迹线。
2. 把发车牌做成冷仪表盘（必须保留候车厅编辑灵魂）。
3. 假功能（点不了的车次 / 空 Tab / 装饰按钮）。

### Primary Interaction
候车看牌：抬头看翻牌板 → 点击"推进时间"按钮 → 牌面级联翻动 → 临近车次终呼 → 到点离站滑出 → 下趟顶上；点击任一车次 → 打开该线路纵深（站点阶梯 + 铺位剖面 + 里程时刻）。

### Motion Language
机械优先：翻牌 3D rotateY 半幅翻转（带轻微落位震颤）、终呼珊瑚红脉冲、离站灰出左滑、站点阶梯 stroke-dashoffset 绘制、铺位依占用依次点亮、线路弧 dashoffset 绘制、票根齿孔进度推进、票根撕边。所有动效服务"机械候车"机制，prefers-reduced-motion 下全部即时/静态。

### Signature Moment
推进时钟到某趟夜车的发车时刻——那一行牌面开始翻动级联，从"准点"翻过一串状态定锚在珊瑚红"终呼·即将发车"，几秒后翻成"已发车"灰着向左滑走，下面一趟夜车顶上补位；同时若点开该线路，站点阶梯从起点向终点逐站绘制点亮，卧铺车厢铺位依次亮起。

### Success Condition
1. 翻牌板可推进时钟、可点击车次打开线路纵深，全程因果真实。
2. 删动画后多行翻牌板信息层级仍成立（车次/目的地/时刻/状态/站台清晰可读）。
3. 灰度下层级仍成立（状态/车次/目的地靠空间尺寸对比，不靠颜色）。
4. 轮廓与今日 34 版无相似（翻牌板脊柱独一无二）。
5. 首屏即答"这是夜行列车候车厅的发车牌"。
6. 无白屏、无 Console Error、四尺寸无溢出/重叠/裁切。
7. 内容真实可考证（非 Lorem Ipsum / Feature One）。

### Technical Boundary
纯 vanilla 单文件 HTML（无 React/Babel/CDN 外部依赖）；CSS 3D transform 实现翻牌；SVG 实现站点阶梯/铺位剖面/线路弧；自定义光标 pointer 事件直接操作 DOM；prefers-reduced-motion 媒体查询降级；响应式 1440/1024/768/390。

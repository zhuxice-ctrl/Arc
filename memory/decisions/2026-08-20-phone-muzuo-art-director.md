# 2026-08-20 Phone V2 · Art Director 决策记录

## 形态
原生 App（上一版「招领处」= 微信小程序，交替）

## 5 候选
1. 篆刻印稿设计台 —— 印章/朱砂母题历史 6+ 次，novelty 低
2. 家酿米酒发酵日志 —— 「随天数照看变化」机制同构于晾晒/蜂箱/菌谱/茶宠
3. 戏曲水袖练功房 —— 练习-打卡家族（琴房/弓道/临帖），布料模拟风险高
4. 短波电台收听日志 —— 拖游标签名交互重复（潮汐/高度游标），日志结构常见
5. **木作开料·套裁工坊**（选定）—— 计算型排版工具，木工母题零历史，机制零重复

## 评分
- novelty_score: 9/10（套裁计算型工具在全部 phone 指纹中无同构）
- fit_score: 9/10（原生 App 形态：每日工坊场景、拖拽排版天然触屏、页面栈导航）
- execution_risk: 中低（矩形拖拽+吸附+利用率计算，纯 DOM/SVG 可实现，无物理模拟）

## Design Contract
- core_idea: 木工爱好者的开料套裁工具 App。输入家具零件清单 → 选板材规格 → 在整板示意上拖拽零件块套裁排版 → 实时利用率与锯路损耗 → 保存开料图与料单复用。
- 首屏 = 开料工作台（整板即主对象），非问候语模板。
- must_keep:
  - 原生 App 形态（状态栏、底部 TabBar、页面栈 push/pop、半屏弹层、返回手势语义）
  - 完整 user flow：建零件清单 → 选板 → 拖拽套裁 → 保存方案 → 方案库载入复用
  - 拖拽零件块磁性吸附对齐 + 双击/按钮旋转 90°，木纹方向指示
  - 利用率实时真实计算（零件面积/板材面积），锯缝 4mm 间隔
  - 真实内容：三层小书架/板凳等真实家具零件数据、真实木材（松木/榉木/黑胡桃）
  - localStorage 持久化方案库
  - 设计规范页 + 接口文档页
  - 签名动效：拖动吸附 + 放下时木屑轻溅 + 利用率数字滚动
  - 健壮性红线（零未定义引用、RAF/定时器随可见性暂停、快速操作不叠加定时器、高频指针事件直接操作 DOM、prefers-reduced-motion）
- must_not_regress_to:
  - 问候语+搜索+Banner 首页模板
  - 图鉴收集盖章机制
  - 网页缩进手机
  - 假功能（每个按钮都必须有真实状态变化）
  - 蓝紫渐变
- success_condition: 用户能不靠指引完成一次完整套裁：加零件→拖上板→旋转→看利用率→保存→在方案库重新载入。
- 色彩逻辑：松木浅黄（板材/工作面）+ 深胡桃墨线（文字/锯缝）+ 角尺钢灰（辅助）+ 安全橙（仅操作与警示）+ 纸白底。区别于琴房 walnut_cream_brass：主调为浅松木非深胡桃奶油。

# Design Contract

## Core Idea
「云顶索道运行图」——整张网页是一张活的索道运行图（Marey 时间-距离图）：横轴为营业日时间（07:00–19:10），纵轴为海拔与五个站点（云溪镇 580m → 望湖台 960m → 松垭口 1280m → 风穴 1680m → 云顶 2110m），6 辆吊厢的上下行轨迹以斜线穿越图纸，斜线交点即会车点。图纸即网站，不是图纸插图。

## Experience Goal
用户像索道调度员一样俯瞰全天运行：图纸持续走动，点击任一吊厢追踪它的全天往返，点击会车点跳到双厢交会瞬间，点击站点看发车时刻带。三分钟理解一条索道的脉搏。

## Must Keep
1. 运行图为绝对主角（占视口 ≥65%），SVG 实时绘制，吊厢持续运动
2. 主交互：点击吊厢斜线→全天轨迹追踪+吊厢档案；点击会车点（预计算斜线交点）→跳转交会瞬间；点击站点名→发车时刻带高亮；播放/暂停/倍速调度控制
3. 图纸美学：暖白图纸底+墨黑网格线+上行朱红/下行靛青功能色（灰度下以实线/虚线区分）+等宽数字标注；中文为主
4. 内容真实：5 站点海拔里程、6 辆吊厢（编号/载客量/累计里程）、班次表由同一套时刻数学生成、风速告警（≥17m/s 区间在图上标灰）
5. 自定义光标（图纸十字准星式，开页即显示在屏幕中央、高对比、层级最高）

## Must Not Regress To
1. 时间游标拖动 scrub（轮渡时刻已用）/横向脊柱滚动/纵向 section 堆叠
2. Landing Page 模板、卡片堆积、Bento、蓝紫渐变
3. 装饰性图片拼贴——图纸本身是内容

## Primary Interaction
图纸自动播放（内置时钟驱动，可暂停/1×/8×）；点击吊厢→全天轨迹高亮+吊厢档案弹出；点击会车点→时间跳转+双厢交会特写；站点行点击→该站发车时刻带高亮。

## Motion Language
机械-图纸语言：吊厢沿斜线匀速运动（电气线性）、会车瞬间微停顿后交错（机械避让）、档案弹出为图章式盖章、告警为调度信号节奏闪烁。支持 prefers-reduced-motion（静态图纸+当前时刻快照）。

## Signature Moment
会车——上下行吊厢斜线在 3 号支架区间交叉，点击交叉标记后图纸聚焦，特写视窗中两吊厢在山谷间擦身而过，铃声一声。

## Success Condition
1. 图纸自动运行流畅，6 辆吊厢轨迹全天一致（任一时刻位置可由时刻表数学复算）
2. 三类点击交互全部真实工作，无假功能
3. 1440/1024/768/390 四尺寸可读（390 降级为站点列表+下一班信息）
4. 无白屏、无严重 Console Error；删动画后图纸完整成立；灰度下上/下行靠线型（实线/虚线）区分
5. 动效 ≥12 个组件级特效且符合机械/图纸逻辑，禁 Ken Burns

## Technical Boundary
纯 vanilla 单文件 HTML，无 React/Babel/CDN；SVG 绘制运行图；RAF 随页面可见性暂停、卸载取消；高频鼠标事件直接操作 DOM；相对路径。

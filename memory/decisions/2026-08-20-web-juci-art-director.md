# 2026-08-20 V1 Web Art Director 决策日志 · 锔瓷

## 主题抽取
锔瓷（金刚钻与铜锔钉）——47 件 web 历史作品未覆盖瓷器修复题材。「没有金刚钻，别揽瓷器活」。

## 五候选（正交）
1. **裂纹主轴**：整页=南宋龙泉窑葵口青瓷碗侧影纵剖，主裂纹贯穿全页=唯一导航，七枚锔钉随滚动逐颗铆合，碗底「完璧」。
2. 碎拼工作台：拖碎片磁吸对缝→打孔→上钉状态机。降权：与 8-20 糖画摊 stall_workbench、8-19 活字 workbench_topdown 撞结构。
3. 锦盒套层揭幕：开盒→揭棉纸→取碗→观裂→显微。降权：与 8-20 一字一世界 scale_zoom_dive 尺度递进逻辑相邻（作 Restart 备选）。
4. 环视转碗：拖拽旋转环视裂纹。降权：与 8-19 物候环 drag_rotate_damped_inertia 撞主交互。
5. 锔钉形制图谱：钉阵标本索引。淘汰：标本馆模式已用（蝶翼标本馆），题材可替换性强。

## 选择
**候选 1（裂纹主轴）**。
- novelty_score：高——空间模型「单一器物的裂纹纵剖」无历史记录；主交互 scroll_rivet_staples 无历史记录。
- fit_score：极高——裂纹即导航与锔瓷不可分离，通过题材可替换性测试。
- execution_risk：中——SVG 裂纹路径+章节锚定+铆合触发为成熟 vanilla 技术栈。
- 竖向滚动复用 justification：历史竖向作品主轴为标尺/道路/深度计，本作主轴是一条「活的裂纹」且修复方向自下而上的对立语义（伤→路），结构判定为新模式 `crack_spine_repair_vertical`。

## Design Contract（摘要）
- core_idea：整页即碎碗侧影，裂纹=导航主轴，滚动=修复进程，七钉逐颗铆合至完璧。
- must_keep：裂纹贯穿导航；七钉逐颗铆合（瓷屑+弹跳锁定）；真实锔瓷工序与蚂蟥绊典故；青瓷/黄铜/宣纸配色；金刚钻钻杆光标居中；纯 vanilla 单文件。
- must_not_regress_to：landing page / card grid / 蓝紫渐变 / 通用非遗站 / 裂纹退化为装饰。
- signature_moment：第一枚锔钉跨缝铆合（裂纹拉拢+铜钉阻尼弹跳+WebAudio 轻嗒）。
- success_condition：换题材立即不成立；删动画后裂纹-锔钉-章节空间关系仍成立。

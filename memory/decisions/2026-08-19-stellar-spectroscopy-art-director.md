## 当天差异化判断
今日已入库 34+ 版 web，题材密度集中在：传统中式工艺（大运河/日晷/廊桥/活字/物候/金鱼/游廊/药铺/年画/皮影/算盘/龙舟/茶马/蜀道/窑火/调香/潮汐/制表/漆扇/古琴/铜人/结绳）、纸本水墨木色配色、拖拽类主交互、scroll-descent 叙事、固定舞台、径向轮盘、横向脊柱迹线、机械翻牌。

## 题材
恒星光谱学（stellar spectroscopy）。近 34 条 web 记忆与 web_mock 全量目录均无天体光谱/夫琅禾费线/恒星分类主题（flyway 是鸟类不是恒星，light-pollution 是光污染尺不是光谱），正交。光谱学自带科学灵魂——人类通过星光中的暗线推断恒星化学成分，是天文学最深刻的发现之一。

## Novelty / Pattern Pressure 检查
- A「spectral_band_horizontal」spatial_model：web 库 34+ 条 + pattern_stats 全量零重复；主交互 drag_along_spectrum 非传统拖拽（拖的是波长轴而非物理物件）、非 scroll-descent、非 tap-reveal，与今日全部版本正交。
- 吸收线点击签名：夫琅禾费暗线作为可交互对象（点击→元素识别+电子跃迁），是内容驱动的真实物理机制，非 glow / 非 Ken Burns / 非整图缩放。
- 配色正交：暗房琥珀(#C8842A) 主导（暖色暗房光，非冷色深空黑）+ 底片奶白(#E8E2D0) 数据面 + 暖调近黑(#1A1410) 背景 + 光谱色仅作内容（非 UI 装饰）。禁蓝紫渐变——光谱带是天体物理内容本身（可见光波长的物理映射），不是陈词滥调装饰渐变；UI 外壳全暖色（琥珀/奶白/暖黑/铜），与近期纸本水墨木色、石墨灰、深空黑全部拉开。
- 无 SATURATED 模式。空间模型、主交互、签名均为全库首现。

## Design Contract（锁定本轮）

### Core Idea
星谱暗室——整个网站是一座天文台暗房。琥珀色安全灯下，一条水平光谱色散带横贯屏幕，这是一颗恒星的光被棱镜分解后的可见光谱。用户沿光谱拖拽光标分析不同波长，暗色吸收线（夫琅禾费线）切割光谱——点击任一暗线即识别出吸收该波长的化学元素及其电子跃迁。围绕"在暗房中读星光"这一体验展开，附以恒星光谱分类（OBAFGKM）、温度-颜色关系、元素丰度的编辑正文。

### Experience Goal
用户像一位在天文台暗房里工作的天体物理学家：琥珀色安全灯映着一切，面前是一条恒星光谱色散带——从红端到紫端的连续彩带，上面散布着暗色吸收线。拖动光标沿光谱移动，不同波长处的恒星数据实时显现（该波段对应什么元素、什么温度的恒星在此处最强）。点击一条吸收暗线，暗房里响起快门般的轻响，那根线高亮，旁边浮现出是哪种元素的哪条电子跃迁造成了这根暗线，以及这告诉你这颗恒星是什么类型。

### Must Keep
1. 光谱色散带为唯一导航脊柱（水平全宽，可见光波长 380-750nm 连续映射，红端在左紫端在右），非竖向 section 堆叠、非卡片网格、非固定单舞台、非横向滚动画卷。
2. 沿光谱拖拽光标→实时恒星数据显现：当前波长、对应频率/能量、该波段主要吸收元素、该波段在哪种恒星类型中最强。拖拽是连续的（pointer 事件直接操作 DOM，非 RAF 节流）。
3. 吸收线可点击：≥8 条真实夫琅禾费线（H-alpha 656.3nm 氢 / H-beta 486.1nm 氢 / Na-D 589.0nm 钠 / Mg-b 518.4nm 镁 / Ca-K 393.4nm 钙 / Ca-H 396.8nm 钙 / Fe 527.0nm 铁 / H-d 410.2nm 氢），点击→元素识别+电子跃迁图+该线强度对应的恒星类型推断。
4. 恒星分类知识区（OBAFGKM 七型，每型真实温度范围+代表恒星+颜色），与光谱带联动：拖到某波段时高亮该波段最强的恒星类型。
5. 自定义光标：放大镜光标（铜框圆环+十字准星），开页居中显示、高对比、层级最高。
6. 动效≥12 个组件级特效且符合暗房/光学物理（安全灯呼吸、底片显影式内容入场、光谱带微脉动、吸收线点击铜框放大镜聚焦、电子跃迁轨道动画、恒星类型卡片切换、波长读数滚动、暗房粒子尘埃等），禁整图缩放 Ken Burns、禁 glow 球、禁鼠标跟星光斑。
7. 纯 vanilla 单文件（无 React/Babel/CDN 外部依赖）；RAF/定时器随可见性暂停且卸载取消；快速操作不叠加定时器；高频鼠标事件直接操作 DOM；支持 prefers-reduced-motion（光谱即时响应、内容即时显现、跃迁静态）。
8. 响应式：1440 / 1024 / 768 / 390 自检无横向溢出、无重叠裁切。

### Must Not Regress To
1. 竖向 section 堆叠 / 卡片网格 / 蓝紫装饰渐变 / 纸本水墨木色 / 石墨灰主导 / 通用 landing page / 拖拽物理物件 / 固定单舞台 / 横向滚动画卷 / 冷色深空黑主导。
2. 把光谱做成装饰背景条（必须保留分析仪器功能——拖拽可读数据、吸收线可点可识别）。
3. 假功能（点不了的吸收线 / 空 Tab / 装饰按钮）。

### Primary Interaction
暗房读谱：拖动光标沿光谱色散带移动 → 当前波长处实时显示恒星数据 → 遇到吸收暗线点击 → 元素识别+电子跃迁+恒星类型推断。

### Motion Language
暗房光学优先：安全灯琥珀色呼吸（极缓慢亮度脉动）、内容以底片显影方式渐入（opacity+轻微 contrast 变化，非 fade-up）、光谱带微脉动（色相微移模拟大气色散）、吸收线点击→铜框放大镜聚焦缩放+电子跃迁轨道绘制（stroke-dashoffset）、恒星类型卡片横向滑动切换、波长读数数字滚动、暗房微粒尘埃缓慢飘浮。所有动效服务"暗房读谱"机制，prefers-reduced-motion 下全部即时/静态。

### Signature Moment
拖动光标到 656.3nm 处——那里横着一根 H-alpha 吸收暗线。点击它，暗房里铜框放大镜聚焦到这根线上，旁边浮现氢原子能级图，n=3→n=2 的电子跃迁轨道以 stroke-dashoffset 绘制出弧线，一个电子沿轨道跳跃；随后推断文字显现："这条吸收线的强度告诉你：如果它很强且窄，这颗恒星是 M 型红巨星；如果很弱，可能是 O 型蓝白星。"

### Success Condition
1. 光谱带可拖拽分析、吸收线可点击识别，全程因果真实。
2. 删动画后光谱带+吸收线+数据层级仍成立（波长/元素/恒星类型清晰可读）。
3. 灰度下层级仍成立（吸收线/数据/分类靠空间尺寸对比，不靠颜色）。
4. 轮廓与今日 34+ 版无相似（光谱色散带脊柱独一无二）。
5. 首屏即答"这是天文台暗房里的恒星光谱分析台"。
6. 无白屏、无 Console Error、四尺寸无溢出/重叠/裁切。
7. 内容真实可考证（夫琅禾费线波长/元素/跃迁、OBAFGKM 分类均为天文学稳定事实）。

### Technical Boundary
纯 vanilla 单文件 HTML（无 React/Babel/CDN 外部依赖）；CSS 线性渐变实现可见光谱（映射真实波长-色域映射）；SVG 实现氢原子能级图/电子跃迁轨道/恒星类型图示；pointer 事件直接操作 DOM 实现拖拽分析；prefers-reduced-motion 媒体查询降级；响应式 1440/1024/768/390。

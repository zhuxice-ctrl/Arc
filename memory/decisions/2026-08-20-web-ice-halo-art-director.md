# 2026-08-20 Web Art Director 决策日志 · 冰晶晕象仪

## 当天随机主题
大气光学现象（日晕 / 佛光 / 蜃楼 / 虹霓 / 月华）——历史 50+ web 作品从未触及的光学题材。

## 候选（5 选）
- A. 高山佛光观景台（拖云幕/人影投环）：主交互「拖太阳」与日晷 drag_sun_shadow_follow 直接撞；fixed_stage 压力 MEDIUM → 弃
- B. 蜃楼大气温度剖面（拖温度曲线）：剖面类（菌物/蜀道）last_20 压力 MEDIUM → 第二候选
- C. 冰晶晕象生成仪：天穹穹顶投影 + 冰晶微舱双窗联动，拨动冰晶取向分布生成对应晕象。spatial/interaction/motif 三项在 pattern_stats 中 0 次 → **选中**
- D. 雨滴虹霓对照舱：垂直雨幕与 alpaca rope_array_vertical_curtain 近似 → 弃
- E. 月华衍射夜云：夜景环与灯塔 radial_beam_sweep 近似 → 弃

## 选择理由
新颖性：晕象题材、天穹投影空间、冰晶取向交互三者均为首次出现。
适配度：晕象的本质=冰晶取向分布决定天象形态，交互即成因，题材不可替换性极强。
执行力：纯 vanilla SVG+Canvas 双窗联动，角度几何可控，风险 LOW。

## Design Contract（摘要）
整站是一台「冰晶晕象仪」：上半部天穹穹顶（太阳+晕象），下半部冰晶舱（数百六棱冰晶）。
拨动取向拨杆（纷乱↔定向）+ 切换晶形（片晶/柱晶/卷晶）→ 天穹实时生成 22°晕、幻日、46°晕、
环天顶弧、上切弧等真实晕象。签名时刻：冰晶从纷乱到定向瞬间，弥散晕环收拢碎裂成两个幻日。

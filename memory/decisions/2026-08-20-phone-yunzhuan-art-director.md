## 历史避重检查
- 识别类（古籍/鸣虫/树木/菌物/观鸟）、训练日志类（琴房/弓道/夜跑/冲浪/攀岩/咖啡）、每日养护类（茶宠/菜园/蜂箱）、盖章收藏类签名 → 全部避开
- stamp/seal_collect 签名在历史中出现 ≥6 次 → 本版签名改用「检票钳物理打孔（M 形缺口镂空）+ 蓝笔手写划线」，明确区别于印章下落
- 铁路/车次/运转领域：phone.json 27+ 指纹中零出现 → novelty 高

## 选择
**候选 1 铁道运转手帐**
- novelty_score：高（新领域+新机制+新签名）
- fit_score：高（火车迷「运转」是真实亚文化行为，产品存在理由充分）
- execution_risk：低（vanilla 单文件，打孔镂空用 CSS mask/SVG 即可）

## Design Contract（摘要，全文见 designer brief）
- core_idea：火车迷运转记录原生 App，一张硬板票 = 一次真实乘车闭环
- must_keep：原生 App 形态、完整 user flow、10 个真实车次、检票钳打孔签名、水牌墙点亮、localStorage、规范页+接口页
- must_not_regress_to：问候语搜索 Banner 首页模板、假功能、网页缩进手机、印章收藏套路、蓝紫渐变
- success_condition：用户可完成「车次簿→登记→出票→长按打孔→票入夹→水牌点亮」全流程且状态持久
